# HyperMesh Entity Type Index

Purpose: authoritative index of every HyperMesh entity type name, for use as the
"vocabulary" that all `hm_getvalue` / `hm_getentityvalue` / `*createmark` /
`*setvalue` calls address. This file exists so an AI agent building Tcl code
without a live HyperMesh session can pick a correct, real entity type string
instead of guessing.

Verification status:

```text
RUNTIME-TESTED (LOCAL-INSTALL):
  Generated by actually calling `hm_getentitytypes all` and
  `hm_getentitytypes named` in a real `hmbatch.exe -tcl` session against
  HyperMesh. This is not from Altair help text — it is the live
  output of the command Altair's own scripts use internally (see
  hm/scripts/br/common/helpers.tcl, hm/scripts/browser/replace_part.tcl) to
  enumerate entity types.

NOT YET DONE:
  Per-type Data Names enumeration (valid dataname strings for hm_getvalue on
  each type) is a separate, much larger task and is NOT included here yet.
```

How to reproduce / refresh on a different install:

```tcl
set all_types [hm_getentitytypes all]
set named_types [hm_getentitytypes named]
```

`all` = every entity type including unnamed/internal ones (174 on this
install). `named` = subset that have a user-visible name/label (157).
Types in `all` but not in `named`: entity kinds that are id-only, no label
(e.g. `elems`, `nodes`, `results`, `sets`, `analysis`, `cards`, `faces`,
`morphvolumes`, `optiresponses`, `directmatrixinputs`, `points`, `lines`,
`solids`, `surfs`, `vectors`).
