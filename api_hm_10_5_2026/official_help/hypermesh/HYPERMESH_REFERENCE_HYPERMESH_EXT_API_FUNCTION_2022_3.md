If this member does not contain any points then the edge is considered "free". This member is empty if the num_points member of the HM_PolyLine structure is set to zero. In this case number and positions of meshing grid points on the edge specified by HM_Edge structure are found automatically by meshing algorithm. If the member num_points of the HM_PolyLine structure specified by this member is not zero, then the points specified by the points member of HM_PolyLine structure are used to specify positions of the meshing grid points on the edge. mesh_size(optional) Set individual mesh size for the edge specified by this HM_Edge structure. Set to positive value in order for individual mesh size to be used for this edge. Set to -1 to have the mesh size the same as the value specified by global mesh size parameter.
