## How to read the route counts

The complete shared HWD Index Terms set contains 11,569 non-index page URLs and is reconciled in [HWD_API_HELP_INDEX_2022_3.md](HWD_API_HELP_INDEX_2022_3.md). That exact route set partitions into HyperMesh reference (4,498), shared Tcl reference (4,077), shared tutorials (17), and other shared Desktop Help (2,977). The product-specific summaries separately cover 1,290 HyperMesh and 704 HyperView pages. The Help-home pages above add discovery routes that are not all counted by those Index Terms. Do not add duplicate fragment links as new pages, and do not treat page totals as command/API totals.
