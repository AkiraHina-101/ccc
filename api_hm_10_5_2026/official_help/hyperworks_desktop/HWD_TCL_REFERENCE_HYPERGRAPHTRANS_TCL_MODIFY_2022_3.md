This file will be parsed as Tcl. | **Inputs:** filename Filename must be the path name of a Tcl file. |
| [hgtrans control SetEnd](https://2022.help.altair.com/2022.3/hwdesktop/hwd/topics/reference/tcl/hgtrans_control_setend.htm) | HyperGraphTrans Tcl Modify | `hgtrans control SetEnd index` | This command sets the index of the last step to read from each channel in the file. It is primarily used to filter out later data points that are not significant. The index is one-based. | **Inputs:** index index must be an integer greater or equal to one. The special value of negative one is taken to mean that all values should be read. |
| [hgtrans control SetFile](https://2022.help.altair.com/2022.3/hwdesktop/hwd/topics/reference/tcl/hgtrans_control_setfile.htm) | HyperGraphTrans Tcl Modify | `hgtrans control SetFile filename` | This command sets the file that will be used as an input for the translation process. | **Inputs:** filename Filename must be the path name of a file of a supported format. |
| [hgtrans control SetIncrement](https://2022.help.altair.com/2022.3/hwdesktop/hwd/topics/reference/tcl/hgtrans_control_setincrement.htm) | HyperGraphTrans Tcl Modify | `hgtrans control SetIncrement value` | This command sets the increment between data points read from each channel in the input file. It is primarily used to pair down large data sets. | **Inputs:** value Value must be an integer greater or equal to one. The default values is one (all data points are translated). |
| [hgtrans control SetOutputFile](https://2022.help.altair.com/2022.3/hwdesktop/hwd/topics/reference/tcl/hgtrans_control_setouputfile.htm) | HyperGraphTrans Tcl Modify | `hgtrans control SetOutputFile filename` | This command sets the name of output file that will be used as the target for the translation process. The output file is always written in the Altair Binary Format (ABF). If the file already exists, it will be overwritten. | **Inputs:** filename Filename must be the path name of the file to write. |
| [hgtrans control SetStart](https://2022.help.altair.com/2022.3/hwdesktop/hwd/topics/reference/tcl/hgtrans_control_setstart.htm) | HyperGraphTrans Tcl Modify | `hgtrans control SetStart index` | This command sets the index of the first step to read from each channel in the file. It is primarily used to filter out early data points that are not significant. The index is one-based. | **Inputs:** index Index must be an integer greater or equal to one. |
| [hgtrans control SetTimeScaleFactor](https://2022.help.altair.com/2022.3/hwdesktop/hwd/topics/reference/tcl/hgtrans_control_settimescalefactor.htm) | HyperGraphTrans Tcl Modify | `hgtrans control SetTimeScaleFactor value` | This command sets the scale factor that is applied to time channels. By default, the factor is one. | **Inputs:** value Value must be a positive, non-zero number. |
