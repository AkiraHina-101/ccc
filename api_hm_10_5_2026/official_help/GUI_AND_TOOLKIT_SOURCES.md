## Selecting a toolkit

For current public source routes, start with the official HWTK and HWAT entries above. The release-matched 2022.3 coverage, function counts and known gaps are summarized in the [HWTK/HWAT source guide](toolkits/GUI_TOOLKITS_HWTK_HWAT_2022_3.md) and its [Simulation Help Index Terms mapping](toolkits/ALTAIR_SIMULATION_HELP_INDEX_2022_3.md). Current page URLs are unversioned; the portal advertises 2026 while the linked HWAT Functions landing page labels itself 2025.1. Keep that version ambiguity visible rather than infer that all current-route articles have an identical release scope.

- A Tcl script that runs in a Classic-era HyperMesh panel/dialog should start with the release-matched HWD Tcl/Tk source. Search the 2022.3 HWD mapping for the exact command or widget and inspect its linked page.
- HWTK supplies Altair-style reusable Tcl/Tk widgets and examples. HWAT supplies automation helpers and widgets above core Tcl commands. Do not assume they are interchangeable or that their command names exist in every release/client.
- Python extension UI in the current HyperMesh API uses `hwx.gui`; its reference is separate from Tcl/Tk/HWTK/HWAT.
- Shared HWI/HWC or session commands belong to the Desktop/client branch. Record their documented Application/client scope before using them in HyperMesh or HyperView.
- A catalog entry is only a route. Summarize the linked page's purpose, call form, inputs, outputs/side effects and release before using it as a command reference.

The [2022.3 HWTK quick reference](toolkits/HWTK_WIDGET_REFERENCE_2022_3.md) covers 40 widget pages and 3 topic pages linked from the Simulation Help Index Terms. The [current HWTK quick reference](toolkits/HWTK_WIDGET_REFERENCE_CURRENT.md) independently crawls five category pages and covers 40 widget pages and 3 topic pages; all 43 linked source pages were retrieved. No direct downloadable sample files were linked from those pages; the guide's sample-code route is represented by page examples. The [current HWAT quick reference](toolkits/HWAT_FUNCTION_REFERENCE_CURRENT.md) contains 179 function pages from six namespaces. Keep Tcl/Tk HWTK separate from the current Python GUI toolkit, and keep HWAT's unlisted Tk-specific category as an open source gap.
