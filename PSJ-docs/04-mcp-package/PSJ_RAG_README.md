# PSJ local documentation search

`search_psj` searches the PSJ reference index already present on the Jupiter computer. It has three modes:

- `filename`: quick lookup when the API or command name is known.
- `semantic`: search by natural-language description.
- `auto`: try filename lookup first, then semantic search.

The search index and its local service are part of the prepared PSJ runtime. This note covers use only; it does not describe setup or distribution of runtime components.

If search is unavailable, continue with the references in `03-api-reference/`. Do not invent function names or parameters. Keep generated work within the Jupiter/PSJ task folders.
