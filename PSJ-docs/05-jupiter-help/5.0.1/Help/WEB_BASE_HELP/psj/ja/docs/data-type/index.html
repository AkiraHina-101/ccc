データ型

PSJ には 3 つのデータ型があります。

  • Python 標準の組み込み型
  • PSJ-コマンドタイプ
  • PSJ-ユーティリティタイプ

構造と使用法

Python 標準の組み込み型​

主要な組み込み型は、数値、シーケンス、マッピング、クラス、インスタンス、および例外です。 詳細については、Python official documentをご覧ください。

PSJ-コマンドタイプ​

PSJ-コマンド関数で使用されるデータ型には次のものがあります。

ビルトインタイプ​

以下を含むすべての PSJ-Commands 関数で使用されるデータ型

int, double, string, cursor, position, vector, bool, int list, double list, string list, List of Cursor, List of Cursor list, position list, vector list, bool list, cursor pair, cursor pair list, TSheetd

詳細については、 detailed information here..をご覧ください。

列挙型​

次の目的で使用される列挙が含まれます。

  • アイテムタイプを表す
  • 要素タイプを表す
  • メッシュと解析のデータ構造を表す

PSJ-ユーティリティタイプ​

PSJ で使用されるデータ型-ユーティリティ関数（以下を含む）

ビルトインタイプ​

主にモデルデータベースの保存に使用されるデータ構造。

BodyVector, VersionInfo, DBody, DEdge, DElem, DFace, DGroup, DItem, DItemVector, DNode, DoubleVector, EdgeVector, ElemVector, FaceVector, GroupVector, NodeVector, StringVector, TVector3d, VersionInfo

詳細なリストはbuilt-in-typesをご覧ください。

列挙型​

次の目的で使用されるデータ構造が含まれます。

  • ユニットの操作
  • 関連するピックを表す
  • 指定されたパスへのリンクを表す
  • 表を表す
  • ブール値を表す
  • メッセージボックスの種類を表す
  • 選択メソッドの表現
