Customized shell

Customized Shell (or Python API window) can be displayed by checking the checkbox in Home » Window » Python API.

① Log window​

Python commands and execution results are displayed in this area.

  • Black color: PSJ-command information
  • Blue color: Script execution result
  • Red color: Error message
Useful tip

User can double mouse click on error line information to jump to the specified line in the Customized IDE.

② IDE launcher button​

Launch the Customized IDE.

③ Command Line Interface (CLI)​

User can run PSJ line by line directly using this Command Line Interface (CLI).

  • Copy ^ Ctrl + C and Paste ^ Ctrl + V operations are supported (for single or multiple lines command)
  • Previous commands can be navigated back and forth using the ↑ Up or ↓ Down key button. User can also double click on a line in the Log window to quickly copy and paste the command to this CLI
  • Auto-fill keywords for Macro, PSJ-Command and PSJ-Utility using ⇥ Tab key. After a keyword is filled, user can use ^ Ctrl + ↑ Up to go backward or ^ Ctrl + ↓ Down to go forward to the near keyword
