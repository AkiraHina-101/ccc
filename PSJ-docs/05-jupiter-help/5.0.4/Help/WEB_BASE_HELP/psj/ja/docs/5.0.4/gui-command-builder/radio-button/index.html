RadioButton

Create a radio button.

Preview dialog:

Parameters​

Text​

Enter the text appears next to the radio button.

Name​

Enter name of the radio button.

Checked​

Specify the default status.

  • Check On : Default is checked
  • Check Off : Default is unchecked

Size​

  • Width : Specify the minimum width of the radio button. (in pixels)
  • Height : Specify the minimum height of the radio button. (in pixels)

Enable​

Specify whether to enable it or not.

  • Check On : Available
  • Check Off : Unavailable (grayed out)

Left text​

Display the text on the left side of the radio button.

  • Check On : Text will be on the left side
  • Check Off : Text will be on the right (default) side

Group​

The below radio button components in the Hierarchy window will be in the same group.

API associated with​

  • dlg.add_radiobutton : Add a RadioButton to the creating dialog.
  • dlg.set_radiobutton_state : Set the state of the RadioButton to checked or unchecked.
