V5.0.4 リリースノート

Highlight updates

V5.0.4では、主に表示操作を強化するためのAPI機能を追加しました。また、新機能や新オプション用にマクロやPSJ Commandを更新しています。

  • OOBB配置（新機能）コントロール用の新規データタイプ、マクロ、APIを追加しました。
  • パーツ外観表示を変更するマクロ・APIを追加しました。
  • ライセンス状況をより簡単に確認できるマクロ・APIを追加しました。
  • 画像キャプチャマクロ・APIに、画像トリミングのオプションを追加しました。
  • 値を取得するAPIに、表示中のエンティティのみに限定するオプションを追加しました。

🚀 新機能​

📦 データタイプ​

  • PSJ-Command:

    • 列挙型　AnalysisType に新規タイプを追加しました。

      新規追加Post Analysis型一覧
      整数表記POST ANALYSISタイプ
      10JPT.PostAnalysisType.POST_ANALYSIS_SHAPE_OPTIMIZATION
      11JPT.PostAnalysisType.POST_ANALYSIS_TOPOLOGY_OPTIMIZATION

  • PSJ-Utility:

    • 列挙型　DTableType に新規タイプを追加しました。

      新規追加Post DTables型一覧
      整数表記POST DTABLEタイプ
      96JPT.DTableType.DTABLE_POST_NODE
      97JPT.DTableType.DTABLE_POST_ELEM

⌘ PSJ-Command​

新規オプションの追加や、操作性・保守性向上のためのPSJコマンド更新を実施しました。

新規追加コマンド一覧
  • MainWindow.RightClick.SetPartAppearance: パート外観の表示・非表示に対応しました。
更新コマンド一覧
- また、下記のコマンドが変更されました。
  • Home.CopyToClipboard: 表示されているエンティティの範囲に合わせてキャプチャされた画像を切り取るオプションが追加されました。
  • Home.ToImage: 表示されているエンティティの範囲に合わせてキャプチャされた画像を切り取るオプションが追加されました。
  • Home.ToPPTX: 表示されているエンティティの範囲に合わせてキャプチャされた画像を切り取るオプションが追加されました。

🛠 PSJ-Utility​

📝 API​

  • 新規に10個のAPIコマンドを追加しました。

    新規追加API一覧
    • JPT.GetAllPostNodes : 全てのPost節点 （読み取り専用）を取得します。 Postドキュメントでのみ動作します。
    • JPT.GetAllPostElems : 全てのPost要素 （読み取り専用）を取得します。 Postドキュメントでのみ動作します。
    • JPT.EnableAllLicenses : 利用可能なすべてのライセンスを有効にします。
    • JPT.GetAllContacts : 全ての存在する接触情報を取得します。
    • JPT.GetAllLicensesStatus : すべてのライセンス状態を取得します。
    • JPT.GetInternalIDRefItem: 参照エンティティの内部IDを取得します。
    • JPT.GetResultTitle: 結果がロードされているとき、タイトルの内容を取得します。
    • JPT.GetScreenHeight : メインウィンドウの高さを取得します。
    • JPT.GetScreenPositionOfEntities : 指定したエンティティのメインウィンドウ内での位置を取得します。
    • JPT.GetScreenWidth : メインウィンドウの幅を取得します。

  • また、下記のコマンドが変更されました。

    変更コマンド一覧
    • JPT.GetAllNodes : Postドキュメント上で実行された場合、この関数がPreドキュメント専用であることを表示するようにしました。
    • JPT.GetAllElems : Postドキュメント上で実行された場合、この関数がPreドキュメント専用であることを表示するようにしました。
    • JPT.GetMaxResultId : 表示されているエンティティについてのみ値を取得できるようにしました。
    • JPT.GetMaxResultValue : 表示されているエンティティについてのみ値を取得できるようにしました。
    • JPT.GetMinResultId : 表示されているエンティティについてのみ値を取得できるようにしました。
    • JPT.GetMinResultValue : 表示されているエンティティについてのみ値を取得できるようにしました。

📐 PSJ-GUI​

📏 GUI Command Builder​

  • ツールボックスのすべてのコンポーネントのプロパティに、「表示」オプションが追加されました。: Layout, GroupBox, TabWnd, TabItem, Label, TextBox, RichEditCtrl, ComboBox, ListBox, CheckBox, RadioButton, Button, ImageCtrl, Spin, SliderBar, Separator, Browser, Table, PageCtrl, PageItem.

📝 API​

  • 新規に1個のコマンドを追加しました。

    新規追加コマンド一覧
    • dlg.set_item_visible: コンポーネントの状態を「表示」または「非表示」に設定します。

⚙ Macro​

  • 新規に10個のマクロを追加しました。

    新規追加マクロ一覧
    • ALIGNMENTBYOOBB : OOBB（Object Oriented Boundary Box）を使用して、対象パートの位置を基準パートの位置に合わせる機能のマクロです。
    • CmdWriteCSVForGeneralReportLinearStatic: レポート機能（静解析）をCSVファイルにエクスポートするためのマクロです。
    • CmdWriteCSVForGeneralReportModal: レポート機能（モード解析）をCSVファイルにエクスポートするためのマクロです。
    • ExportGroup: グループのエクスポートマクロを追加しました。
    • ExportWindowSettings: ウィンドウ設定エクスポートマクロを追加しました。
    • ImportGroup: グループのインポートマクロを追加しました。
    • SetHidingElementFactor:（トポロジー最適化用）非表示要素の係数と結果を指定するマクロを追加しました。
    • SetPartAppearance : パート外観の表示・非表示を切り替えるマクロを追加しました。
    • ToPre: ポストドキュメントをプレドキュメントに変換するためのマクロを追加しました
    • ToPost: macro for convert Pre document to Post document.

  • また、下記のマクロが変更されました。

    変更マクロ一覧
    • ADVC_Structure:　gray_scale_ratio_tol及びoutput_gray_scale_ratioを出力するオプションを追加しました。
    • Capture_CopyToClipboardEx: 表示されているエンティティの範囲にキャプチャされた画像をトリミングするオプションが追加されました。
    • Capture_ToPPT: 表示されているエンティティの範囲にキャプチャされた画像をトリミングするオプションが追加されました。
    • Capture_ToImageEx: 表示されているエンティティの範囲にキャプチャされた画像をトリミングするオプションが追加されました。
    • Prop2DShell: ERP設定及び温度変化設定用オプションが追加されました。

🐛 不具合修正​

⌘ PSJ-Command​

  • Measureコマンドが指定された値と異なる精度を返す不具合を修正しました。
  • Tools.TotalLoadコマンドが間違った値を返すことがある不具合を修正しました。

📐 PSJ-GUI​

📝 API​

  • DNODEクラスのisFloatingアトリビュート確認時に時間がかかる問題を修正しました。

📏 GUI Command Builder​

  • RichEditControl のデフォルトテキストが *.jdb ファイルを再読み込みしたときに保持されない不具合を修正しました。
  • Spin のdouble型のプロパティが *.jdb ファイルを再読み込みした際に保持されない不具合を修正しました。

🛠 PSJ-Utility​

📝 API​

  • PostドキュメントでJPT.GetAllByTypeID()を使用した場合、POST_NODEおよびPOST_ELEMタイプに対して間違った値を返す不具合を修正しました。
  • DNODEクラスのisFloating属性をチェックするのに時間がかかる問題を修正しました。
  • JPT.GetMaxIDEntity()が誤った値を返す不具合を修正しました。

⚙ Macro​

  • DeleteFaceマクロが引数としてエンティティの内部IDを要求する不具合を修正しました。
  • いくつかのケースでMeasureTotalLoad_マクロが誤った値を返す不具合を修正しました。
