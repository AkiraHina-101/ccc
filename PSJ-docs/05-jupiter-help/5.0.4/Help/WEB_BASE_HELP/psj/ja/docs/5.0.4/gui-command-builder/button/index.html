Button

Create a button.

Preview dialog:

Parameters​

Text​

Enter the text appears on the button.

Name​

Enter name of the button.

Enable​

Specify whether to enable it or not.

  • Check On : Available
  • Check Off : Unavailable (grayed out)

Size​

  • Width : Specify the minimum width of the button. (in pixels)
  • Height : Specify the minimum height of the button. (in pixels)

Image​

Specify whether to use image button or not.

  • Check On : Use image button
  • Check Off : Use normal button

Image File​

Specify the path of an image to be displayed on the button.

Image Location​

Specify the location of the image on the button.

  • Left : Locate the image at the left of the button
  • Right : Locate the image at the right of the button
  • Center : Locate the image at center of the button

Color​

  • Background Color : Specify the background color of text box.
  • Text Color : Specify the color of text displayed in the text box.

Font​

  • Size : Specify the size of text displayed in the text box.
  • Bold : Specify whether to enable the bold text.
    • Check On : Make the text bold
    • Check Off : Do not make the text bold
  • Italic : Specify whether to italicize of text.
    • Check On : Italicize of text
    • Check Off : Do not italicize of text
  • Underline : Specify whether to underline text.
    • Check On : Underline text
    • Check Off : Do not underline text
  • StrikeOut : Specify whether to cross text out by drawing a line through it.
    • Check On : Cross text out by drawing a line through it
    • Check Off : Do not cross text out

API associated with​

  • dlg.add_button : Add a Button to the creating dialog.
  • dlg.on_button_clicked : Bind a created function to a Button/RadioButton/CheckBox.
