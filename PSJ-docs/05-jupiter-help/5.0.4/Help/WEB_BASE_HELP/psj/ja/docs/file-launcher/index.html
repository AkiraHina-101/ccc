ファイルランチャー

ファイルランチャーは、PSJ をフローティングウィンドウに割り当てて、簡単に実行することができます。

インターフェース​

ボタン説明
SPython ファイルを登録します
C登録済みの Python ファイルをクリアします
R登録済みの Python ファイルを別の Python ファイルに置き換えます
Func登録した Python プログラムを実行します

操作方法​

  1. Sボタンをクリックして、Python ファイルを選択します。

  2. ファイルを選択すると、ファンクションボタンの左側にある緑色のマークが赤に変わります。

  3. ファンクションボタンをクリックしてプログラムを実行します。
