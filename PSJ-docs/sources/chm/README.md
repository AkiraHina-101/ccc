# Văn bản CHM

Toàn bộ stream HTML/HTM/HHC/HHK/CSS/JS/TXT/XML đọc từ 9 CHM trong Help Jupiter 5.0.4 bằng Windows ITStorage. Ảnh/binary không nằm trong bản trích văn bản; CHM gốc được giữ tại `../05-jupiter-help/` để xem đầy đủ. Manifest ghi nguồn và số file trích thành công. Nội dung CHM Shift-JIS được giải mã theo charset khi đưa vào corpus.
