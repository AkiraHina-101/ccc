List Box

リストボックスを追加します。



   作成イメージ図：



  • Name

       List Boxコンポーネント名を入力します。

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •
  • Allow Multiple Selection

       複数のアイテム（List Boxコンポーネントのアイテム）が選択できます。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •
  • Width

       コンボボックスの最小幅を指定します。（単位：ピクセル）

  • Height

       コンボボックスの最小高さを指定します。（単位：ピクセル）

  • Source File

       テキストファイルからオプションを入力します。

       Source Fileの構造：

        Option1
        Option2
        Option3
        Option4
        Option5
         ↓
        入力した結果：



  • Option Count

       選択オプションの数を指定します。

  • Options *

       選択オプション名を入力します。


    • 使用コマンド

    コマンド説明サンプルコード
    dlg.get_listbox_sel("name") リストボックスにて選択されているアイテムの位置を取得します。

    listbox = ["1", "2", "3", "4", "5"]
    "4"を選択している場合

    Input:

    a = dlg.get_listbox_sel("listbox")

    Output:

    > a = 3
    dlg.get_len_listbox("name") リストボックスの長さ（アイテム数）を取得します。

    listbox = ["1", "2", "3", "4", "5"]

    Input:

    a = dlg.get_len_listbox("listbox”)

    Output:

    > a = 3
    dlg.set_listbox_sel(“Name”, Index) リストボックスで選択されている値を切り替えます。

    listbox = ["1", "2", "3", "4", "5"]

    Input:

    dlg.set_listbox_sel(“ListBox”, 3)

    ⇒ 選択されている値=”4”
    dlg.insert_listbox_option("name", position, "text") リストボックスの特定の位置にオプションを1つ追加します。

    Input:

    dlg.insert_listbox_option("name", 1, "text")
    dlg.insert_listbox_options("name", position, [アイテムリスト]) リストボックスの特定の位置に複数のオプションを追加します。

    Input:

    dlg.insert_listbox_options("name", 3, [アイテムリスト])
