Check Box

チェックボックスを追加します。



   作成イメージ図：



  • Text

       チェックボックスの横に表示されるテキストを入力します。

  • Name

       Check Boxコンポーネント名を入力します。

  • Checked

       デフォルト値を指定します。

    • チェックオン : チェックする。
    • チェックオフ : チェックしない。
      •
  • Width

       チェックボックスの最小幅を指定します。（単位：ピクセル）

  • Height

       チェックボックスの最小高さを指定します。（単位：ピクセル）

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •
  • Left text

       チェックボックスの左側にテキストを表示させます。

    • チェックオン : テキストを左側に表示させます。
    • チェックオフ : テキストを右側に表示させます。
      •

    使用コマンド

    コマンド説明サンプルコード
    dlg.isbutton_checked("component name") チェックボックスにチェックが入っているかどうか確認します。
    ブール値(True/False)を返します。

    Input:

    dlg.isbutton_checked("CheckBoxButton")

    Output:

    > True/False
    dlg.set_checkbox_state("name", Bool) チェックボックスのステータス（チェックの有無）を指定します。

    Input:

    dlg.set_checkbox_state("CheckBox1", True)
