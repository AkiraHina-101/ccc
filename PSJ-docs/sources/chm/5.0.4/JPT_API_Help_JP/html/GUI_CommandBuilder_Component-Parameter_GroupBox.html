Group Box

グループボックスを作成します。



   作成イメージ図：



  • Text

       グループ名を入力します。

  • Name

       Group Boxコンポーネント名を入力します。

  • Has Check Label
    • No : 常にグループ内のコンポーネントを操作可能にします。
    • Yes(Default==Checked) : グループ内のコンポ―ネントの操作を制御します。（デフォルト：チェックON）
    • Yes(Default==Unchecked) : グループ内のコンポーネントの操作を制御します。（デフォルト：チェックOFF）
      •
  • IsCollapsed

       グループボックスの折りたたみ表示の設定をおこないます。

    • No : 折りたみ設定しない。
    • Yes(Default==Collapsed) : 折りたたみの操作を制御します。（デフォルト：折りたたむ）
    • Yes(Default==Expanded) : 折りたたみの操作を制御します。（デフォルト：折りたたまない）
      •
  • Orientation

       コンポーネントの並びを指定します。

    • Horizontal : コンポーネントを横並びにします。
    • Vertical : コンポーネントを縦並びにします
      •
  • Width

       グループボックスの最小幅を指定します。（単位：ピクセル）

  • Height

       グループボックスの最小高さを指定します。（単位：ピクセル）

  • Enable

       使用の可否を指定します

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます。）
      •
