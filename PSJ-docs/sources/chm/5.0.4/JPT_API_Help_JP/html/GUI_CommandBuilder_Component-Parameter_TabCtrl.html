Tab Control

タブアイテム（ページ）のグループを作成します。



   作成イメージ図：


    ※Tab ControlはTab Itemとセットで使用します。


  • Name

       Tab Controlコンポーネント名を入力します。

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •
  • Width

       ページの最小幅を指定します。（単位：ピクセル）

  • Height

       ページの最小高さを指定します。（単位：ピクセル）
