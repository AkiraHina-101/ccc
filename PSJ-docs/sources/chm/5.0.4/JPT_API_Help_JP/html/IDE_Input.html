文字入力

ハイライト表示

単語をダブルクリックしたとき重複した単語がハイライト表示（黄色）されます。
ハイライト表示のデータは、データベースフォルダに保存されています。


自動補完

自動補完をサポートしています。例えば、「Geometry.Sol」"と入力すると、リストボックスに"Sol"から始まる単語が表示されます。
自動補完のデータは、データベースフォルダに保存されています。

本機能は以下をサポートしています。

  • IDEの全ての単語
  • Pythonキーワード
  • PSJ-Utility

ツールチップ

ツールチップをサポートしています。例えば、「JPT.ClearLog(」と入力すると、JPT.ClearLogのドキュメントを示すツールチップが表示されます。
ツールチップのデータは、データベースフォルダに保存されています。


ユーザー定義関数のツールチップ

ユーザー関数にも対応しています。
