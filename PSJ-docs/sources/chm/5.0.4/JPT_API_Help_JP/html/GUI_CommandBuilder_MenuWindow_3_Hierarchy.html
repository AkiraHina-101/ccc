Hierarchy ウィンドウ

使用中のすべてのコンポーネントがツリー形式で表示されます。
コンポーネントの位置の変更や複製・削除することができます。



Hierarchy ウィンドウ詳細
アイコン名称説明
Move item out of current container選択したコンポーネントを１つ上のコンテナに移動します。
Move item into next container選択したコンポーネントを１つ下のコンテナに移動します。
Move item forward one level選択したコンポーネントを同コンテナ内の1つ上のレベルに移動します。
Move item backward one level選択したコンポーネントを同コンテナ内の1つ下のレベルに移動します。
Copy item and insert it選択したコンポーネントを複製します。
Delete selected item選択したコンポーネントを削除します。
