Text Box

テキストボックスを追加します。



   作成イメージ図：



  • Default

       デフォルトで入力されているテキストを入力します。

  • Align

       テキストの表示位置を指定します。

    • Left : 左揃え
    • Right : 右揃え
    • Center : 中央揃え
      •
  • ReadOnly
    • チェックオン : テキストの編集不可。(コピーは可能)
    • チェックオフ : テキストの編集可能
      •
  • Name

       Text Boxコンポーネント名を入力します。

  • Width

       テキストボックスの最小幅を指定します。（単位：ピクセル）

  • Height

       テキストボックスの最小高さを入力します。（単位：ピクセル）

  • Type

       テキストボックスに入力可能なデータ型を指定します。

  • Type

       テキストボックスに入力可能なデータ型を指定します。

    • String : 文字列型
    • Double : 倍精度浮動小数点型
    • Integer : 整数型
      •
  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •

    • 使用コマンド

    コマンド説明サンプルコード
    dlg.set_item_text("component name","text") テキストボックスに表示するテキストを設定します

    Input:

    dlg.set_item_text("Item", "text")
    dlg.get_item_text("component name") 入力されたテキスト情報を取得します。

    Input:

    dlg.get_item_text("TextBox")
