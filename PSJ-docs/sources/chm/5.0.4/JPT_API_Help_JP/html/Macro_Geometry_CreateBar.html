CreateBar

Description

Create Bar Body

Syntax

CreateBar(string bodyName, int meshCount, cursor startNode, cursor endNode)

Inputs

  1. String

    Insert body name

  2. Int

    Mesh counting

  3. Cursor

    Start node cursor(10:Node ID)

  4. Cursor

    End node cursor(10:Node ID)

Return Code

  • 1

    Succeeded

  • 0

    Failed
