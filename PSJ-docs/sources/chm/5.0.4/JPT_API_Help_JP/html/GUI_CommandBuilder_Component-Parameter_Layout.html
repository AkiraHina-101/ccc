Layout

コンポーネントのレイアウトを設定します。



   作成イメージ図：Orientation

  • Name

       Layoutコンポーネント名を入力します。

  • Orientation

       コンポーネントの並びを指定します。

    • Horizontal : コンポーネントを横並びにします。
    • Vertical : コンポーネントを縦並びにします。
      •
  • Margin

       Left : Group Boxの左に余白を入れます。（単位：ピクセル）

       Top : Group Boxの上に余白を入れます。（単位：ピクセル）

       Right : Group Boxの右に余白を入れます。（単位：ピクセル）

       Bottom : Group Boxの下に余白を入れます。（単位：ピクセル）

    • 使用コマンド

    コマンド説明サンプルコード
    dlg.show_layout("name") 指定されているレイアウトを表示します。

    Input:

    dlg.show_layout("Layout5")
    dlg.hide_layout("name") 指定されているレイアウトを非表示にします。

    Input:

    dlg.hide_layout("Layout5")
