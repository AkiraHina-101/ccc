Slider Bar

スライドバーを追加します。



   作成イメージ図：



  • Name

       Slider Barコンポーネント名を入力します。

  • Width

       スライドバーの最小幅を指定します。（単位：ピクセル）

  • Height

       スライドバーの最小の高さを指定します。（単位：ピクセル）

  • Min

       スライドバーの最小値。

  • Max

       スライドバーの最大値。

  • Pos

       スライドバーのデフォルト値（デフォルト位置）。

  • Vertical

       スライドバーの表示方向を指定します。

    • チェックオン : 垂直方向に表示。
    • チェックオフ : 水平方向に表示。
      •
  • Show Minor Type in Tick Mark

       補助目盛線の表示/非表示を指定します。

    • チェックオン : 表示する。
    • チェックオフ : 表示しない。
      •
  • ShowBorder

       スライドバーの境界線の表示/非表示を指定します。

    • チェックオン : 表示する。
    • チェックオフ : 表示しない。
      •
  • Show tick marks on both side

       目盛の表示位置を指定します。

    • チェックオン : 目盛を両側に表示。
    • チェックオフ : 目盛を片側にのみ表示。
      •
  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
