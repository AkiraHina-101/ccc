Debugger

Description

Console debugger for PSJ

Inputs

  1. any type, any argument number

Return Code

None

Sample Code

  • debug enum list

    • JPT.Debugger(JPT.DItemType.values)

  • debug python standard type

    • JPT.Debugger(1, "abcd", list, tuble, dict, ....)

  • debug Jupiter data type

    • JPT.Debugger(JPT.GetAllNodes()[0].id)

    JPT.Debugger(JPT.GetAllNodes()[0])

    JPT.Debugger(JPT.GetAllNodes())
