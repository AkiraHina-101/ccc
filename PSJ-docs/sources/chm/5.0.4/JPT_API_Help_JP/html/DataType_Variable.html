変数・数値

Python API変数
変数名 説明
id エンティティの外部IDです。一部のエンティティIDは、リナンバー機能で変更可能です。
key エンティティの内部IDです。全てのエンティティは重複しない固有の内部IDを持っています。ユーザーによる変更は不可です。
name エンティティの名称です。
Type エンティティの種類です。
typeID エンティティの種類のIDです。参照
Cursor エンティティを指定する整数のペアです。TypeID:IDの形式で記述します。
2147483647 整数値フィールドで、空白が入力されたことを意味します。
1.79769e+308 実数値フィールドで、空白が入力されたことを意味します。
children アッセンブルツリー内で、アッセンブルアイテムのサブアッセンブリを指します。
parent アッセンブルツリー内で、アイテムの親となるサブアッセンブリを指します。
masters 接続/接触のマスター側フェース/エッジ/節点を指します。
slaves 接続/接触のスレーブ側フェース/エッジ/節点を指します。
info パーツ・フェースのエンティティ情報です。メッシュ数等を含みます。
