ImportDirectWithColor

Description

bReadColorInfoフラグ（12番目）を1に設定すると、Parasolidファイルインポート時に、フェースに与えられた色毎にフェースグループを作成します。
bEnableSkipColorを1にした上でskipColorで特定の色を指定した場合、指定色のフェースグループは作成しません。

Syntax

ImportDirectWithColor(CString []strFiles, double dChordHeightTol, double dChordAngleTol, bool nConvertIsolatedCurve, double dSurfacePlaneTol, double dSurfacePlaneAngle, double dMaxFacetWidth, double dMinFacetWidth, bool nICADFlag, int VRMLColorGroups, double dScale, bool bReadColorInfo, bool bEnableSkipColor, RGB skipColor)

Inputs

  1. Cstring[]

    Multiple CAD Files

  2. Double

    Chord Height Tolerance

  3. Double

    Chord Angle Tolerance in degree

  4. Bool

    Convert Isolated curve on or off flag true=1, false=0

  5. Double

    Surface Plane Tolerance

  6. Double

    Surface Plane Angle Tolerance in degree

  7. Double

    Max Facet width

  8. Double

    Min Facet width

  9. Bool

    iCAD flag true=1, false=0

  10. Int

    VRML Color groups

  11. Double

    Scale value

  12. Bool

    Read color info flag read=1, ignore=0

  13. Bool

    Skip color flag enable=1, disable=0

  14. RGB

    Indicate skip color [R(0-255), G(0-255), B(0-255)]

Return Code

  • 1

    Succeeded

  • 0

    Failed

    • Sample Code

    カラー情報読み込みなし
    ImportDirectWithColor(["D:/ImportFile/Parasolid_Test.X_T"], 0, 7, 0, 0, 20, 0.1, 0, 0, 0, 0.001,0,0,[])

    カラー情報を読み込み、グループ作成
    ImportDirectWithColor(["D:/ImportFile/Parasolid_Test.X_T"], 0, 7, 0, 0, 20, 0.1, 0, 0, 0, 0.001,1,0,[])

    カラー情報を読み込み、グループ作成。ただし、色[127,127,127]のグループは作成しない
    ImportDirectWithColor(["D:/ImportFile/Parasolid_Test.X_T"], 0, 7, 0, 0, 20, 0.1, 0, 0, 0, 0.001,1,1,[127,127,127])
