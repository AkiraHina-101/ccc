DItem

Description

Jupiter内の全てのアイテムのベースクラスです。

Properties

属性説明
isValid

使用できるかどうか判定します。使用可能な場合、Trueとなります。

#Entityが使用可能かチェック、使用可能な場合True、不可の場合、False
type

アイテムの種類です。

#EntityのItemTypeを取得、戻り値ItemType文字列
typeID

アイテムの種類のIDです。DItemTypeです。

#EntityのItemTypeの整数値を取得、戻り値 int
key

アイテムの内部IDです。各TypeID内での一意のIDです。ユーザーによる変更は不可。

#Entityの内部Key取得、戻り値Id（int)
id

アイテム外部IDです。各TypeID内で重複可能ですが、推奨はされません。一部のエンティティIDは、リナンバー機能で変更可能です。

#Entityの外部ID取得、戻り値Id（int)
name

アイテムの名称です。

#Entityの名称取得または、名称設定
targets

Itemが保持する別Itemです。

#Entityに設定されているEntityの取得、戻り値DItemの配列。
masters

接続/接触のマスター側フェース/エッジ/節点を指します。

#Entityに設定されているMasterEntityの取得、戻り値DItemの配列
slaves

接続/接触のスレーブ側フェース/エッジ/節点を指します。

#Entityに設定されているSlaveEntityの取得、戻り値DItemの配列
children

アッセンブルツリー内で、アッセンブルアイテムのサブアッセンブリを指します。

＃ツリー上で入れ子になっている場合の子供のEntityの取得、戻り値DItemの配列。
parent

アッセンブルツリー内で、アイテムの親となるサブアッセンブリを指します。

＃ツリー上で入れ子になっている場合の親のEntityの取得、DItem
info

パーツ・フェースのエンティティ情報です。メッシュ数等を含みます。

#Entityの情報表示、ツリーItemまたは、PartItemである必要あり。
