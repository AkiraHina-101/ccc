Rich Edit Control

リッチテキストボックスを追加します。



   作成イメージ図：



  • Default

       デフォルトで入力されているテキストを入力します。

  • Name

       Rich Edit Controlコンポーネント名を入力します。

  • Width

       リッチテキストボックスの最小幅を指定します。（単位：ピクセル）

  • Height

       リッチテキストボックスの最小高さを指定します。（単位：ピクセル）

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
