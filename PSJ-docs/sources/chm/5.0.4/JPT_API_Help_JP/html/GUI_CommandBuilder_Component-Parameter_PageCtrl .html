Page Control

ページコンテナーを作成します（ウィザードに使用）。



   作成イメージ図：


    ※Page CtrlはPage Itemとセットで使用します。


  • Name

       Page Controlコンポーネントを入力します。

  • Show Header

       ページアイテムのヘッダーテキストの表示/非表示を指定します。

    • チェックオン : 表示します。
    • チェックオフ : 表示しません。
      •
  • Default Page

       デフォルトで表示するページを指定します。
       ※　入力値は0からです。

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）。
      •
