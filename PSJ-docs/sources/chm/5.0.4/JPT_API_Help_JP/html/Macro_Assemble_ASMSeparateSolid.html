ASMSeparateSolid

Description

Separate assembled parts in a solid model

Syntax

ASMSeparateSolid(int[] bodyID, int[] faceID, bool createGroup)

Inputs

  1. int[]

    given body ids to be separated

  2. int[]

    given face ids to be assmbled

  3. bool

    group creation option

Return Code

  • 1

    Succeeded

  • 0

    Failed

    • Sample Code

    ASMSeparateSolid([2, 29], [], 0)
