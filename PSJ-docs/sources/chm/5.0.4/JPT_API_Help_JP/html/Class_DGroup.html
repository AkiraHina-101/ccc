DGroup

Description

グループクラスです。

Properties

typeID

アイテムの種類のID(=79)です。

#EntityのItemTypeの整数値を取得、戻り値 int(DItemw::GetItemTypeInt)
key

アイテムの内部IDです。各TypeID内での一意のIDです。ユーザーによる変更は不可。

#Entityの内部Key取得、戻り値Id（int)
id

アイテムの外部IDです。各TypeID内で重複可能ですが、推奨はされません。一部のエンティティIDは、リナンバー機能で変更可能です。

#Entityの外部ID取得、戻り値Id（int)
name

アイテムの名称です。
targets

グループの内容を保持しています。DItemクラスの配列です。
