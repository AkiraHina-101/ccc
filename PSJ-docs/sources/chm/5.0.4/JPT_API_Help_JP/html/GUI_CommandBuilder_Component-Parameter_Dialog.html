Dialog

作成ダイアログのタイトルや実行ボタン、クリックボタン（選択リスト）に関する設定をおこないます。



   作成イメージ図：



  • Title

       ダイアログのタイトルを入力します。

  • Resizable

       ダイアログのサイズ変更の可否を設定します。

    • チェックオン ：ダイアログのサイズを自由に変えられます。
    • チェックオフ ：ダイアログのサイズは固定されます。
      •
  • Validation

       ダイアログへの入力内容の確認の有無を設定します。（書式やデータ形式など）

    • チェックオン：確認する。
    • チェックオフ：確認しない。
      •
  • Apply Button

       Applyボタンの作成の有無を設定します。

    • チェックオン：作成する。
    • チェックオフ：作成しない。
      •
  • OK Button

       OKボタンの作成の有無を設定します。

    • チェックオン：作成する。
    • チェックオフ：作成しない。
      •
  • Cancel Button

        Cancelボタンの作成の有無を設定します。

    • チェックオン：作成する。
    • チェックオフ：作成しない。
      •
  • Description

       ここに入力した内容はダイアログの先頭に記載されます。

  • Selector

       選択リストをつけるオプションです。

       ※サポートしている選択タイプ：
       Node Selector, Part Selector, Bar Part Selector, Element Edge Selector,
       1D Element Selector, 2D Element Selector,3D Element Selector,Face Selector, Edge Selector, Vertex Selector.


    • 使用コマンド

    コマンド説明サンプルコード
    dlg.on_command(“name”, function) 作成したコンポーネントに実行機能を組み込みます。

    Input:

    dlg.on_command(“ButtonOk”, on_click_exec_button)
    dlg.add_space(orientation = "horizontal, layout = "Layout") 指定した向きでプレースホルダーを追加します。

    Input:

    dlg.add_space(orientation="horizontal",layout="footer")
    dlg.get_selected_entities(int selector_id) 指定されているSelectorの選択したエンティティを取得します。

    Input:

    dlg.get_selected_entities(0)
    dlg.disable_item("component name") コンポーネントのプロパティのステータスを有効から無効に変更します。

    Input:

    dlg.disable_item("TextBox")
    dlg.enable_item("component name") コンポーネントのプロパティのステータスを無効から有効に変更します。

    Input:

    dlg.enable_item("TextBox")
