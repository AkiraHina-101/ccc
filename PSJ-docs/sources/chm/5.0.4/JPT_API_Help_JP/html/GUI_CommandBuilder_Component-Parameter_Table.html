Table

テーブルを追加します。



   作成イメージ図：



  • Name

       Tableコンポーネントを入力します。

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •
  • Show Grid Line

       グリッドラインの表示を指定します。

    • チェックオン : グリッドラインを表示します。
    • チェックオフ : グリッドラインを表示しません。
      •
  • Show Row Number

       ライン番号の表示を指定します。

    • チェックオン : ライン番号を表示します。
    • チェックオフ : ライン番号を表示しません。
      •
  • Width

       テーブルの最小幅を指定します。（単位：ピクセル）

  • Height

       テーブルの最小高さを指定します。（単位：ピクセル）

  • Pop Menu Options

       右クリックメニューを表示します。

       サポートされるオプション：
       Cut, Copy, Paste, Insert Row, Delete Row, Clear Content, Read From File, Write To File

  • Total Rows Count

       行数を指定します。

  • Total Columns Count

       列数を指定します。

  • Column Setting

       列のタイプを指定します。
       Heading*：列のコンテンツタイプを指定します。


    • 使用コマンド

    コマンド説明サンプルコード
    dlg.set_cell_value("table name", "(cell_row_id, cell_column_id)", "value") 指定したインデックスの行・列に値をセットします。

    Input:

    dlg.set_cell_value("table name", "(1, 1)", "value")
    dlg.get_cell_value("table name", "(cell_row_id, cell_column_id)") 指定したインデックス行・列の値を取得します。

    Input:

    dlg.get_cell_value("table name", "(1,1)")
    dlg.get_total_row("table name") テーブルの総行数を取得します。

    Input:

    dlg.get_total_row("table name")
    dlg.get_total_column("table name") テーブルの総列数を取得します。

    Input:

    dlg.get_total_column("table name")
