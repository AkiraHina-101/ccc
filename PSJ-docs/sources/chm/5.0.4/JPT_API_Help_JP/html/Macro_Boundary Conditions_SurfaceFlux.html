SurfaceFlux

Description

create surface flux

Syntax

SurfaceFlux(string strName, double dFlux, int iDistributionMethod, cursor crTable, cursor[] taTarget, cursor crEdit)

Inputs

  1. String

    Surface flux name

  2. Double

    Surface flux value

  3. Int

    Input unit type*

    *0: MW/mm^2

     1: W/m^2

     2:MiuW/mm^2

     3: kcal/mm^2*h

     4: Lbf/ft*s

     5: Lbf/in*s

  4. Cursor

    Table field data cursor(81:FieldData ID)

  5. Cursor[]

    Target entities cursor

  6. Cursor

    N/A: Edit cursor

Return Code

  • 1

    Succeeded

  • 0

    Failed

    • Sample Code

    SurfaceFlux("SurfaceHeatFlux1", 1000, 1, 81:4, [6:3, 11:693], 0:0)
