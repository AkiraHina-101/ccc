Open File/Folder

ファイル/フォルダオープンダイアログを追加します。



   作成イメージ図：



  • Name

       Open File/Folderコンポーネント名を入力します。

  • Enable

       使用の可否を指定します。

    • チェックオン : 使用可能。
    • チェックオフ : 使用不可。（グレーアウトされます）
      •
  • Mode

       選択モードを指定します。

    • File : ファイルタイプのみが選択できます。
    • Folder : フォルダタイプのみが選択できます。
      •
  • Default

       表示するデフォルト値（File/Folder）リンクです。

  • Filter

       選択できるファイルの種類を指定します。

       ファイルのフォーマット：

        Description 1 (Extension 1, Extension 2, …), Description 2 (Extension 1, Extension 2, …), …

  • Allow Multiple Selection

       複数のファイルを選択できるかどうか指定します。

    • チェックオン : 複数選択できます。
    • チェックオフ : 複数選択できません。
