PrintJPT

Description

Print strings on console. This function is mainly used in background mode to display arbitrary strings on console.

Syntax

PrintJPT(string String)

Inputs

  1. String

    String to display

Return Code

  • Nothing

    Succeeded

  • Nothing

    Failed

    • Sample Code

    PrintJPT("test")

    list = [1,2]

    JPT.Exec('PrintJPT({0})'.format(list[1]))

    JPT.Exec('PrintJPT({0})'.format(123))
