CreateElement

Description

Add Element Items from Element Edges

Syntax

CreateElement(int Elem Type, int Parent Entity ID, int[] Node ID)

Inputs

  • int

    Element Type of Newly Created Element

  • int

    Parent Entity ID

  • int[]

    Target Nodes for Creating New Element

    • Return Code

  • 1

    Succeeded

  • 0

    Failed

    • Sample Code

    CreateElement(0, 0, [187,196,205])
