Show Adjacent | Elements

By setting the elements and boundary to start the search (elements and angle), select collective elements within the specified boundary.

Options

  • Number of Layer

    •    Specify the number of layers to be a search range.

  • Include Stop Elements

    •    When check on, the user can also select the boundary elements.

  • Stop Angle up to

    •    Specify the angle as a boundary.

  • Preview

    •    Users can see the elements which are selected. Those elements will be shown in the Main Windows with the colour you've selected.

  • Reset

    •    Reset the elements identified in Preview button.

  • Stop By Nonmanifold

    •    Stop the search in a non-manifold.

  • Show Part Only

    •    Select only the parts displayed in the Main Windows.

    - Operating Procedure -

    1.  Select the Start Elem. (User can select more than one element at distant location)
    2.  Select the Stop Elem. (If the user only specify a boundary angle, the user do not need to select stop element)
    3.  Specify the number of layers and the angle to stop.
    4.  Check the selection in the Preview/Reset.
    5.  Click the Apply/OK button.
