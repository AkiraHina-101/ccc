Show Adjacent | Faces

By setting the face and the border of starting the search (face and angle), select adjacent face in the specified boundary.

Options

  • All

    •    When check on, the search area will be all the faces. When unchecked, the number of layers specified in the Number of Layers will be the search range.

  • Number of Layers

    •    Specify the number of layers to be a search range.

  • Include Stop Faces

    •    When check on, the user can also select the boundary surfaces.

  • Stop Angle up to

    •    Specify the angle as a boundary.

  • Preview

    •    Users can see the faces which are selected. Those faces will be shown in the Main Windows with the color you've selected.

  • Reset

    •    Reset the faces identified in Preview button.

  • Stop By Nonmanifold

    •    Stop the search in a non-manifold.

  • Show Part Only

    •    Select only the parts displayed in the Main Windows.

    - Operating Procedure -

    1.  Select the Start Face. (User can select more than one element at distant location)
    2.  Select the Stop Face. (If the user only specify a boundary angle, the user do not need to select stop face)
    3.  Specify the number of layers and the angle to stop.
    4.  Check the selection in the Preview/Reset.
    5.  Click the Apply/OK button.
