IN Boundary | Limited Boundary | Rotation

Rotates the limit plane of the infinite boundary.

Rotation

  • Coordinate system

    •    Specify the coordinate system to reference.

  • Rotation Axis

    •    Specify the axis of rotation.

    • X Axis : Rotates around the X axis of the selected coordinate system.
    • Y Axis : Rotates around the Y axis of the selected coordinate system.
    • Z Axis : Rotates around the Z axis of the selected coordinate system.
    • Arbitrary Axis : Rotates by an angle around the axis specified by the X, Y, and Z direction vectors.
    • 2 Nodes :  Rotates by an angle around the axes of the two nodes directions selected from the screen.
    • Edge : Rotates by an angle around the axis in the edge direction selected from the screen.
      •
  • Axis-X, Axis-Y, Axis-Z

    •     Specify the X, Y, and Z coordinates of the center of rotation.

  • Center

    •    Specify the center position of rotation.

    • Part Center : Make the center of Part the center of rotation.
    • Node : Make the node selected from the screen the center of rotation.
    • Input : Specify the center of rotation in Center-X, Center-Y, Center-Z.
      •
  • Angle

    •    Specify the rotation angle.

    - Operating Procedure -

    1.  Select Part.
    2.  To rotate around the existing coordinate system axis, select the existing coordinate system from the coordinate system and select X-axis, Y-axis, or Z-axis from the rotation axis.
    3.  To rotate in any direction, select any axis from the rotation axes and specify the direction vector in the X-axis, Y-axis, and Z-axis input boxes.
    4.  To rotate in the direction of the selected 2 nodes, select 2 nodes from the rotation axis and select 2 nodes from the screen.
    5.  To move in the direction of the selected edge, select the edge from the rotation axis and select the edge from the screen.
    6.  To make the center of the part the center of rotation, select the center of the part from the center.
    7.  To set the center of the Part to the node position, select the node from the center and pick the node from the screen.
    8.  To enter the center of Part directly, select Input from Center and specify the center of rotation in the Center-X, Center-Y, Center-Z input boxes.
    9.  Specify the rotation angle in angle input boxes.
    10.  Click the Apply/OK button.
