Assembly

Create an assembly between the surface meshes of each part.

Assembly

  • Tolerance

    •    Set the assembly tolerance.

  • Find

    •    Find the target faces of the assembly.

  • Min Elem Length

    •    The minimum element length on the assembly edge.

    - Operation Procedure -

    1.  Input the tolerance value according to the gap between the parts.
    2.  Click the Find button to find the target faces.
    3.  Input the minimum element length.
    4.  Execute by pressing the Apply or OK button.
