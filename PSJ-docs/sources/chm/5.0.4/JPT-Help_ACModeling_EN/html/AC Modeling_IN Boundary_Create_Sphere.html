In Boundary｜Create Sphere

Create the shape (sphere) of the infinite boundary surface.

Sphere

  • Type of Sphere

    Specify the sphere type.

    • Sphere : Create a sphere.

    • Hemisphere : Create a hemisphere.
      •
  • Center

    •    Enter the center coordinates of the sphere.

  • Radius

    •    Enter the radius of the sphere.

    - Operating procedure -

    Sphere type How to use

    1.  Select a part and enter the center coordinates of the sphere.
    2.  Enter a radius value.
    3.  Press the Apply / OK button.

    Hemisphere type How to use

    1.  Select a part and enter a radius value.
    2.  Select the face at the cut position.
    3.  Press the Apply / OK button.
