Surf. w/Hole

Using the acoustic boundary surface (ACBoundary) model, the outer surface of the structural analysis model is remained and extracted the node ID.

The size of the vibration calculation result file in the acoustic calculation is reduced by creating a node group for the outer surface from the extracted model.

Surf. w/Hole

  • Tolerance

    •    Specify the distance from the acoustic boundary of the shape to be extracted.

  • Structural Model

    •    Specify the document for the structural analysis model.

  • Tight Wrapping

    •    Specify the document for the acoustic boundary.

    - Operating Procedure -

    1.  Specify the surface of the structural analysis model to be extracted by the distance from the acoustic boundary surface. Enter a distance for the Tolerance.
    2.  Select the Structural Analysis Model document from the Structural Model menu.
    3.  Select the Acoustic Boundary Model document from the Tight Wrapping menu.
    4.  Click Apply/OK button.
