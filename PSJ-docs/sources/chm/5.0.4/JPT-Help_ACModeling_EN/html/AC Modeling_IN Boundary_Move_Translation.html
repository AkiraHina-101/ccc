IN Boundary | Limited Boundary | Translation

Moves the limiting plane of the infinite boundary.

Translation

  • Coordinate System

    •    Specify the coordinate system to reference.

  • Axis

    •    Specify the axis that determines the direction of translation.

    • X Axis : Translates by magnitude in the X-axis direction of the selected coordinate system.
    • Y Axis : Translates by magnitude in the Y-axis direction of the selected coordinate system.
    • Z Axis : Translates by magnitude in the Z-axis direction of the selected coordinate system.
    • Arbitrary Axis : Translates by the magnitude of the X, Y, and Z direction vectors.
    • 2 Nodes : Translates by magnitude in the two nodes directions selected from the screen.
    • Edge : Translates by magnitude in the direction of the edge selected from the screen.
  • X,Y,Z

    •    When specifying an arbitrary axis, enter each component and specify the direction.

  • Magnitude

    •    Specify the magnitude to move.

    - Operating Procedure -

    1.  Select part.
    2.  To move in the direction of the existing coordinate system, select the existing coordinate system from the coordinate system, select one of the X-axis, Y-axis, and Z-axis from the axis, and specify the magnitude.
    3.  To move in any direction, select any axis from the axis and specify the direction vector and magnitude, respectively.
    4.  To move in the direction of the selected two nodes, press the node button and select two nodes from the screen. The distance between the two nodes is automatically entered in the magnitude.
    5.  To move in the direction of the selected edge, press the edge button and select the edge from the screen. The edge length is automatically entered in the magnitude.
    6.  Change the magnitude as needed.
    7.  Click the Apply/OK button.
