AC Space

Create a solid mesh of AC space between the AC boundary mesh and the infinite boundary mesh.

Attributes

  • Set the parameters for creating a solid mesh. Please access to Solid Meshing for more information.

    • Force Clean

  • Set the automatic correction option for solid mesh creation. Please access to Solid Meshing for more information.

    • PML

  • Width

    •    Specifie the width of the PML.

  • Layer

    •    Specifie the number of PML layers.

    Sweep to Ground

  • Axis

    •    Specifie the normal direction of the face.

  • Coordinate

    •    Enter the coordinate of the ground.

  • Mesh Size

    •    Specifie the size of the penta element in the sweep direction.

  • Layer

    •    Specifie the number of element layers from the specified face to the ground.

    Connect to Ground

  • Connecting Boundary

    •    Combine the contact areas of the AC boundary and infinite boundary faces.

    - Operation Procedure -

    The method of using the PML option

    1.  Select the AC Boundary mesh Part and the Infinite Boundary mesh Part.
    2.  Check the PML check box.
    3.  Input the PML width and PML layer, then press the OK button.

    The method of using the Sweep to Ground option

    1.  Select the AC Boundary mesh part and the Infinite Boundary mesh part.
    2.  Check the Sweep to Ground checkbox.
    3.  The Axes will be selected automatically, so input the coordinate of the ground in the Coordinate textbox and input the Mesh Size textbox.
    4.  Input the number of layer and press the OK button.

    The method of using Connect to Ground

    1.  Select the AC Boundary mesh part and the Infinite Boundary mesh part.
    2.  Check the Connecting Boundary check box and press the OK button.
