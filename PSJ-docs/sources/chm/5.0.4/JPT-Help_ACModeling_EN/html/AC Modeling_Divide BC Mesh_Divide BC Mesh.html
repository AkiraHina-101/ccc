Divide BC Mesh

Divide the PID of the AC boundary mesh from the PID setting of the structural mesh.

Settings

  • Structural Model(PID)

    •    Specify the structure mesh file.

  • BC Mesh

    •    Specify the file for the boundary mesh.

    - Operating Procedure -

    1.  In Structural Model(PID), specify the structural model file.
    2.  In BC Mesh, specify the boundary mesh file.
    3.  Click the Apply/OK button.
