Tight Wrap

Create a wrapping model on the surface of the structural mesh.

Option

  • Thickness

    •    Specify the magnitude offset from the structural surface.

  • Width

    •    Specify the range of joins between shapes.

  • Meshing

    •    After creating the wrapping model, create a mesh.

  • Mesh Size

    •    Specify the mesh size.

  • Shell Wrapping

    •    Offset to both sides of the face.

  • Select Domain

    •    Specify the direction for offset.

    • Outside : Only the outer surface of the model is offset.
    • Inside : Only the inner surface of the model is offset.
    • Both : Both side of the model is offset.

    - Operating Procedure -

    1.  Enter the width from the shape and element size of the target model.
    2.  Specify the mesh size.
    3.  Select domain to offset.
    4.  Click the Apply/OK button.
