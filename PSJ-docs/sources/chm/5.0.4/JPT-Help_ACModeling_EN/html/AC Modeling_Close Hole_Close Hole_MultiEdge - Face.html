Close Hole｜MultiEdge-Face

Close bolt holes, etc. with a mesh of triangular linear elements.
Select multiple edges and faces to close multiple bolt holes at once.

Options

  • Remesh

    •    Meshing is performed on the closed face.

  • Element Size

    •    Specify the mesh size.

  • Select Belong Part

    •    User can select the part to which the closed face belongs.

  • Specified Part

    •    Specify the part to which the closed face belongs.

  • New Part

    •    Create a new part of the closed face.

  • Part name

    •    Specify the name of the new part.

    - Operating Procedure -

    1.  Select a face on which the edge of multiple holes.
    2.  Edit options as needed.
    3.  Click the Apply/OK button.
