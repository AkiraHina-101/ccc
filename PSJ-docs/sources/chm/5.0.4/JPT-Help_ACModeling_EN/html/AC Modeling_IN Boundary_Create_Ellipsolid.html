In Boundary｜Create Ellipsoid

Creates an infinite interface shape (ellipse).

Ellipsoid

  • Auto

    •    Create an auto-spheroid.

  • Tolerance

    •    Specify the minimum distance from the acoustic boundary to the ellipsoid.

  • Center

    •    Center coordinates of the spheroid.

  • Major Point

    •    Long-axis endpoint coordinates of the ellipsoid.

  • Minor Point

    •    Short-axis endpoint coordinates of the ellipsoid.

    - Operating procedure -

    1.  Enter the tolerance.
    2.  Press the OK / Apply button.
    3.  A spheroid that is offset by the tolerance is created.
    4.  The output tab of the output window contains the coordinate information of the ellipse.
    5.  It also creates an axis model represented by beam elements. When you start Jupiter again and check the axis of the ellipsoid, please get the coordinate information from here.
