Field mesh

Create a field mesh by entering the coordinates of the start and end points.

Part Name

  • Part Name

    •    Enter the name of the newly created part.

    First Coordinate

  • X,Y,Z

    •    Enter the coordinates of the start point.

    Last Coordinate

  • X,Y,Z

    •    Enter the coordinates of the end point.

    Number of Elements

  • X,Y,Z

    •    Specify the number of divisions of the element for each coordinate axis. Create a plane if either axis is 0.

    - Operating procedure -

    1.  Enter the coordinates of the start point.
    2.  Enter the coordinates of the end point.
    3.  Specify the number of divisions for each axis.
    4.  Click the OK button to execute.
