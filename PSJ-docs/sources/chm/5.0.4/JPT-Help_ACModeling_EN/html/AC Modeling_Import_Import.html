Import AC FEM Model

Read the mesh data used in the vibration analysis and create a surface triangle primary element model for each part.
The input data is a model consisting of tetrahedral secondary elements, pentahedral primary elements, and hexahedral primary elements in the Nastran input data format, and the surface quadrangle of the pentahedron and hexahedron is arbitrarily divided into triangles.
At the same time, the surface data is output in Tri6 and Tri3 data in Nastran data format.

Nastran data

  • Face Angle

    •    The element angle for creating face information.

  • Import

    •    Specify the mesh data used in the vibration analysis.

  • Output Shell File

    •    Structural shell element output option.

    - Operating procedure -

    1.  It is executed by selecting the input data from the Import button and pressing the OK button.
    2.  The Save As dialog will be launched, so create an input file for the shell element.
