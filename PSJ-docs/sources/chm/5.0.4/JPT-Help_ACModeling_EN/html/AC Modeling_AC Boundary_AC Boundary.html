AC Boundary

Extract the mesh of AC Boundary faces (outer faces of the model).

Method

  • Method

    •    Select a method to handle AC boundary.

    • Method1 : Create a space to recognize and extract the outer face.
    • Renumber : Only renumbering will be executed.
      •

    Options

  • Merge Body

    •    Merge the parts into one.

  • ID renumbering

    •    Rearrange the nodes and elements in order starting from 1.

  • Select Outer Faces

    •    Select the faces to be extracted.

    - Operation Procedure -

    1.  Press the Apply/OK button.
    2.  As shown above, the internal structure will be removed and only the outer faces be extracted.
      ※Since only the outer faces are extracted, gaps and holes leading to the inner structure need to be plugged in advance.
