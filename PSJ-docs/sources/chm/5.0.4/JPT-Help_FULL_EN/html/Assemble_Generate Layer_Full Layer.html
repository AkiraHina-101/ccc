Full Layer

Offset the entire surface mesh of the parts inwards for creating a layer (PRISM6 parts).

In this function the original parts are divided into layer parts and internal parts.
This function is supported only by the mesh modelling of internal layers in PRISM6 by Tet4. Therefore, it has the following conditions:

    A. This function is valid for the surface mesh parts made of Tri3. It does not work properly if there is a mesh error, therefore confirmation and fixes are required in advance.
    B. It will conduct a solid meshing with Tet4 for internal parts.

Parameters

  • Operation

    Switch the type of operation.

    • Make Layer

      Create a layer.

  • Layer Width

    Enter the depth of the layer.

  • Layer Number

    Enter the number of layers.

  • Use Pyramid

    Create a pyramid element to tie the layer parts and the internal parts (for pyramid elements supporting solver).

    • - Operating Procedure -

    1.  Select the parts to create a layer.
    2.  Enter the depth and number of layers.
    3.  If necessary, set the other parameters.
    4.  Click Apply/OK button.
    5.  The selected parts are divided into layer parts and internal parts. After this, run the solid meshing with Tet4 for internal parts.
