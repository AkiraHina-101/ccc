Fillet Map Meshing

Performs fully automatic map meshing on fillet surfaces of the part.


Searching for fillet faces creates a face group named "Fillet_Face_ *".
Performing fillet map meshing creates a face group named "FilletMapped _ *".


Selection list

Part：Target parts
Face：Searched fillet faces

Search

  • Arc Length

    Arc length range of search fillet.

  • Arc Radius

    Radius range of search fillet.


  • Convex

    It is an option to search for convex fillets.

  • Concave

    It is an option to search for concave fillets.

  • Search

    Perform search of fillet face. Then, a face group named "Fillet_Face _ *" is created.

    • Map Meshing

  • Layer Angle

    Angle between layers. The number of divisions in the arc direction is defined.


    Ex）A = 30, B = 10

    • Axis Size

  • Aspect Ratio

    The target aspect ratio of the map mesh. The mesh length in the axial direction is defined by the number of layers and this value.

    Ex）A = 3.0, B = 1.0

  • Min Size

    This option sets the minimum mesh length in the axial direction.

  • Max Size

    This option sets the maximum mesh length in the axial direction.

    Ex）A = Off, B = On

  • Min Mesh Count

    Option to skip short fillets. For example, if you enter 2, fillet faces with an axial number of meshes of 1 or less will be skipped.

  • Tri3 / Quad4

    Select mesh type.

  • Preview

    Perform preview display.

    • Option

  • Single Layer_Length

    With this option, thin fillets are one layer. The input value is the arc length threshold. If the arc length is shorter than this threshold, it is a thin fillet that becomes 1 layer.

  • Single Layer_Radius

    With this option, thin fillets are one layer. The input value is the arc radius threshold. If the arc radius is smaller than this threshold, it is a thin fillet that becomes 1 layer.

    Ex）A = Off, B = On

  • Min Num Layers

    This option sets the minimum number of layers. For example, even if it is computed as one layer at an angle between layers, if 3 is entered for this option, it becomes 3 layers.

    Ex）A = Off, B = On

  • Create Reference

    Create a reference part when you run meshing to preserve the original shape.

  • Use Local Mesh Setting

    Refer Local mesh setting to suggest mesh size/mesh count.
    Function will use edge mesh count and face mesh size from Local Mesh settings (the face mesh size takes precedence).
    If there is Freeze Mesh, fillet map meshing cannot work.

  • Skip complex face

    Skip complex fillet surfaces.

    • - Operating procedure -

    1. Set parameters.

    2. Select the part.

    3. [Skip allowed] Click the Search button.
      Fillet faces are searched. A face group named "Fillet_Face_ *" is created.

    4. Check in advance with the preview and modify the parameters as needed.

    5. Click Apply / OK.
      Fillet map meshing is executed. A face group named "FilletMapped _ *" is created.

    - Operating procedure (Pre-processing for whole meshing) -

    1. Perform the above procedure to the CAD part to freeze the face group "FilletMapped_ *" with local settings.

    2. Performs surface meshing.

    3. If necessary, remove the freeze in the local settings and modify the mesh.

    - Notes -

    • If the fillet is bent, It defines the large radius as Axis of the fillet and the smaller radius as Arc of the fillet.

    • If the facets or meshes around the fillet are large, fillet map meshing may corrupt the shape of that area.
      When executing to CAD, it is recommended to set the maximum facet length of CAD import parameters.

    • The fillet search capability is better for CAD models than for mesh models.

    • Complex fillet shapes may be skipped.
