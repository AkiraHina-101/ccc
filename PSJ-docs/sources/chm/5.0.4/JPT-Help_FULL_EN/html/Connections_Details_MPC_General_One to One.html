MPC General | Semi Auto

This command is used to create a one-to-one MPC pair between multiple nodes within an arbitrary tolerance.

Semi-Auto

  • Name

    Specify the name for registration.

    • Parameters

  • Coordinate

    Specify the reference coordinate system.

  • TX Displacement - TZ Displacement

    Specify constraints in the translational direction.

  • RX Displacement - RZ Displacement

    Specify constraints in the rotational direction.

  • Tolerance

    Create MPCs between nodes within the range of the input value.

    • - Operating Procedure -

    1.  Select the target nodes.
    2.  Specify parameters.
    3.  Click the Apply/OK button.
