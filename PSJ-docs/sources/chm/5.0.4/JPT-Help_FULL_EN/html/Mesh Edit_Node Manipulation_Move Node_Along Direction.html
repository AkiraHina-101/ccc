Along Direction

Move the selected node or floating point to the specified offset vector position.
Directional vector is defined by either "Element Edge", "2 Nodes", or "direct input of DX, DY, DZ".
The movement of the node along directional vector is defined by Vector Magnitude, User Input or Destination by Face or Element.

Vector Direction

  • 2 Nodes

    Click to select the two nodes or floating points to define the directional vector.

  • Elem Edge

    Click to select the an element edge to define the directional vector.

  • DX, DY, DZ

    Components of the directional vector will be automatically displayed after selecting 2 Nodes or Element Edge. You can also manually input into these fields.

  • Reverse Direction

    Click to reverse the direction of the selected vector.

    • Parameters

  • Move Amount

    The Move Amount is automatically displayed after selecting 2 Nodes or Element Edge when in "Use Vector Magnitude". The Move Amount can also be manually input by users when in "User Input".

  • Use Vector Magnitude

    When in "Use Vector Magnitude", the Move Amount is automatically displayed after selecting 2 Nodes or Element Edge.

  • User Input

    When in "User Input", the Move Amount is manually input by users.

  • Destination by Face or Element

    When in "Destination by Face or Element", the movement of the nodes is defined by the destination chosen by users as Face or Element.

    • - Operating Procedure -

      1) Define the directional vector for moving by any of the followings.
          a) Click the 2 Nodes button to select the two nodes.
          b) Click the Elem Edge button to select the Element Edge.
          c) Enter values directly into the DX, DY, DZ.
      2) Define the movement of the chosen nodes by any of the followings.
          a) When User Vector Magnitude is ON, Move Amount is automatically displayed after selecting 2 Nodes or Element Edge.
          b) When User Input is ON, enter a value directly to Move Amount.
          c) When Destination by Face or Elem is ON, select face or element, the chosen nodes will be moved to the surface containing that face or element.
      3) Select the node(s) to be moved.
      4) Click Apply / OK button.
