Select the target face and the reference face to perform deformation (morphing) of the mesh. Move the face smoothly along with nodes that is within the specified range from the selection face while moving the face.

Parameters

  • Effective Distance

       Specify the range of morphing to deform the selected entities.Nodes detected in the range moves smoothly as per selected entities.

  • Src Obverse

       Specify the front side target face to be deformed

  • Dst Obverse

       Specify the front side reference face

  • Src Reverse

       Specify the back side target face to be deformed

  • Dst Reverse

       Specify the back side reference face

  • Fixed Group

       Specify the faces not to be moved.

    • *It is possible to fix the back side faces by specifying the faces on fixed groupｷ

    -  Operating Procedure -

    1.  Click the src Obverse button from the selection list window and select the frontside surface to be deformed.
    2.  Click the dst Obverse button from the selection list window and select the reference surface.
    3.  Click the Src Reverse button from the selection list window and select the backside surface to be deformed.
    4.  Click the dst Reverse button from the selection list window and select the backside reference surface.
    5.  Click the fixed group button from the selection list window and select the surface not to be moved.
    6.  Specify the effective distance.
    7.  Press apply or ok button
