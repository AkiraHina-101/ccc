Perpendicular Line to Edge

Create a line on the selected face, perpendicular to the selected edge from the selected point.

Option

  • Break Face

    •    Break the face.


    - Operating Procedure -

    1.  Press the face button and select the face to be imprinted from the screen. Multiple face selections are possible.
    2.  Press the edge button and select the edge to drop the vertical line from the screen.
    3.  Press the node button and select the start point of the imprint line from the screen.
    4.  Clear the Break Face check box if necessary. In this case, the imprinted face is not divided from the original face.
    5.  Click the Apply / OK button.
