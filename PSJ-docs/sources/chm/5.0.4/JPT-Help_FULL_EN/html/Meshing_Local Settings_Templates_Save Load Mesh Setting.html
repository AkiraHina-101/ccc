Save/Load Mesh Setting

Save the local setting to an external file (xml format). In addition, read the saved setting.

Type

  • Operation Type

       Select the operation type.

    • Save : Save the local setting to an external file.

    • Load : It reads the local setting from an external file.
      •

    • - Operating Procedure -

  • Save Procedure
    1.  Select Save in the Operation Type.
    2.  Click Apply / OK button.
    3.  Enter the name of the file.
    4.  Click the Save button.

  • Load Procedure
    1.  Select Load in the Operation Type.
    2.  Click Apply / OK button.
    3.  Select the saved xml file.
    4.  Click the button to open.
