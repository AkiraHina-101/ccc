Nastran | Linear Static (SOL 101)

Output the Input Deck for Nastran Linear Static analysis (SOL 101)

Job Option


　　　
  • Job

    Program: Select the type of Nastran Solver
        MSC: MSC Nastran
        NX: NX Nastran
    Job Name: Enter the name of the job. Output set by this name will be saved in the tree.
    Job Description: Enter a description for your job.

    　　　
    • 　　　
  • Solver Option

    Method: Choose the solution method.
        Direct: Direct method
        Iterative: Iterative method
    Epsilon value: Specify the convergence parameter in the iterative method.
    Run Nastran: Run the Nastran on the local machine.
    Memory (MB): Define the memory allocation amount.

    　　　
    • 　　　　
  • System Cell and FMS

    System Cell: Enter data directly card to Nastran (System) section.
    FMS: Enter text data directly in file management statement section.

    　　　
    • 　　　
  • Executive Control Option

    GEOMCHECK, NONE: Disable the geometry checking option.
    Direct text input: Enter the text data directly to the executive control section.

    　　　
    • 　　　
  • Case Control Option

    ECHO: Define the echo output of bulk data.
        NONE: No output
        SORT: Sorted output
        UNSORT: Unsorted output
        BOTH: Both sorted and unsorted output
    TITLE: Define the title at the time of print output.
    Direct text input: Enter text directly to the case-control section.

    　　　
    • 　　　
  • Bulk Data Option

    Write Type: Specify the output target.
        By Model: Output to a single file
        By Each Part: Print a separate file for each part
        Selected Parts: Output of selected parts only
    GRID Format Type: Specify the Grid output format
        Single: Small field format output
        Double: Large field format output
        Single F.P.: Specify the floating-point number small field format output
    Delete Floating Nodes: Floating node is removed at the time of exporting output data.
    Continuance Marker +: Output the continuation pointer + in at the time of exporting output data.
    Include Bulk Data: Insert the bulk data file.
    Direct text input: Enter text directly to the bulk data section.

    　　　

    • Loading / Boundary Conditions


    　　　
  • Base:

    Define the boundary conditions that act on the entire analysis to be defined on the specific SUBCASE.
    Specify the boundary conditions case to be used in each of the boundary conditions. It will include all of the boundary conditions in Default.
    LOAD: Specify the load set
    SPC: Specify the constraints set
    MPC: Specify the multi-point constraint set
    Initial Temperature: Specify the initial temperature set
    Temperature Load: Specify the temperature load set
    Define LBC ID: Specify the identification ID of load, restraint and multi-point restraint

    　　　
    • 　　　
  • Subcase Option:

    Define the SUBCASE.
    Specify the boundary conditions case to be used in each SUBCASE

    Existing ID: Specify an existing SUBCASE ID
        Add: Add New SUBCASE
        Remove: Delete existing SUBCASE
        Apply: Update existing SUBCASE
    ID: Specify the SUBCASE ID
    Subtitle:Enter the title at the time of print output
    LOAD: Specify the load case
    SPC: Specify the constraint set
    MPC: Specify the multi-point constraint set
    DISPLACEMENT: Specify the displacement output request
    STRESS: Specify the element stress output request
    STRAIN: Specify the element strain output request
    Direct text input: Enter text data directly to SUBCASE

    　　　

    • Output Request


    　　　
  • Result type

    Specify the output request.
        PLOT: op2 Output
        PRINT: f06 Output
        PLOT&PRINT: op2 and f06 output
        Blank: No output

    DISPLACEMENT: Specify the displacement output request
    SPCFORCES: Specify the single point constraint force output request
    OLOAD: Specify the applied load output request
    MPCFORCES: Specify the multi-point constraint force output request
    STRESS: Specify the element stress output request
    STRAIN: Specify the element strain output request
    FORCE: Specify the element forces output request
    ESE: Specify the element strain energy output request

    　　　
    • 　　　
  • Group (SET)

    The extent to which the elements results are output element and limits to specify the node group (set).
        ALL: Output all the elements, with respect to all the nodes
        Group: Output elements in the specified group, relative to node

    DISPLACEMENT: Specify the output range with respect to the displacement output request
    SPCFORCES: Specify the output range with respect to the single-point constraint force output request
    OLOAD: Specify the output range with respect to the applied load output request
    MPCFORCES: Specify the output range with respect to the multi-point constraints force output request
    STRESS: Specify the output range with respect to the element stress output request
    STRAIN: Specify the output range with respect to the element strain output request
    FORCE: Specify the output range with respect to the element forces output request
    ESE: Specify the output range with respect to the element strain energy output request

    　　　

    • Parameter


    　　　
  • Parameter:

    Define the parameters.

    POST: Specify the output type for the post-processing results file.
        0: XDB Output
        -1: op2 Output (For Patran)
        -2: op2 Output (For I-DEAS)
    OGEOM: Control the geometry output to OP2
        YES: Yes geometry output
        NO: No geometry output
    AUTOSPC: Control the automatic restraint for stiffness singularity
        YES: Automatic constraint
        NO: No automatic constraint
    GRDPNT: Control the weight information output
    WTMASS: Define Mass correction factor
    K6ROT: Define the load factor for rotational stiffness of shell elements normal
    MAXRATIO: Define the matrix pseudo-singularity determination ratio
    BAILOUT: Control the execution against the pseudo-singularity
         0: Continue run
        -1: End run
    PRGPST: Control the print output for singularity summary table
        YES: Yes output
        NO: No output

    　　　


    • - Operating Procedure -

    　　　
  • General output method (if you do not define a SUBCASE) 　　　
      • 　　　
    1.  Keeping Loading / Boundary Conditions to be default, select the result to be output for post by selecting PLOT in each result item for the output request.
      2. 　　　
    2.  Click Apply(OK) button and define the name to output the input data file.


    　　　
  • If you want to define a SUBCASE (example: Keep constraint conditions constant and change the load condition for each SUBCASE) 　　　
      • 　　　
    1.  Define Load case such as constraint case in advance by Boundary Conditions > Load Case command.
      2. 　　　
    2.  Select a Blank in Loading / Boundary Conditions for Base>LOAD, and then select a constraint case to be used in all SUBCASE in the SPC.
      3. 　　　
    3.  Enter the Subcase Option>SUBCASE number to ID, select the load case to be used in the LOAD and then click the ADD button.

      4. 　　　
    4.  Type the following SUBCASE number to Subcase Option>ID, select the load case to be used in LOAD and click on the ADD button.

      5. 　　　
    5.  Define the other necessary option and then click the Apply(OK) button to output the input data file. SUBCASE setting will be output as shown below in the image.



    　　　
  • How to edit SUBCASE (example: Delete SUBCASE 1 and change load cases of SUBCASE2) 　　　
      • 　　　
    1.  Right click on the analysis under the assembly tree and select Edit. Nastran output dialog box will open.

      2. 　　　
    2.  Select Subcase Option>Existing ID 1 from the Loading / Boundary Conditions and click on Remove button to delete SUBCASE 1.

      3. 　　　
    3.  Select 2 in Existing ID and a different load case in LOAD. When you click the apply buttons, contents of SUBCASE 2 will be changed.

      4. 　　　
    4.  Define the other necessary options and click on the Apply(OK) button to output the input data file.
