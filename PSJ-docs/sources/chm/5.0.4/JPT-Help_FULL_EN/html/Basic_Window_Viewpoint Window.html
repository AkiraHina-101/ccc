Viewpoint Window

Viewpoint window provides various view options related to a selected local coordinate system.


Toolbar

Viewpoint operation toolbar contains icons that can be clicked to create the user's desired viewpoint.

IconNameDescription
AddAdd the current view to the user viewpoint.
RenameChange the name of an existing user view point.
DeleteDelete the user view point.
ImportImport the user viewpoint file.
ExportExport the user viewpoint file.

Viewpoint Tree

  • User Viewpoint

    • Double-Click on the user viewpoint items to change the view.
    User can also enable/disable the rotation, movement and zoom parameters with the check box displayed from the right mouse click.

  • User Frame

    • Items of User Frame are added by "Single" or "Multiple" command of Rectangular Capture in Home ribbon. Double-Click on the user viewpoint items to show user frame to capture on main window.

    Preset View

    Click on the icon to change the Preset view.

    View Control

  • Center

    • Set a center of rotation of a model.

    • X,Y,Z : input a center coordinate.
    • Set : set the input coordinate to the center.
    • Reset : reset the settings.
      •
  • Rotate

    • Set rotation angle of a model.

    • X,Y,Z,Edge,Normal : input rotation angle.
      • X: rotate around the X-axis
      • Y: rotate around the Y-axis
      • Z: rotate around the Z-axis
      • Edge: rotate around the selected edge.
      • Normal: Rotate around an axis that is perpendicular to the screen.
    • Rotate : Rotate around the specified axis by the specified angle.
    • Show : Show or hide a rotation vector.
      •
  • Pan

    • Sets the movement distance on the screen.

    • Left←,Right→ : Move horizontally by the specified distance.
    • Up↑,Down↓ : Move vertically by the specified distance.
      •
  • Zoom

    • Set the magnification on the screen.

    • Zoom In : Zoom in by the spefified value.
    • Zoom Out : Zoom out by the specified value.
    • Fit : Fit an entire model to main window.
      •

    - Operating Procedure -

    1.  Move the model to an arbitrary position on the screen of the main window.
    2.  Click the "Add" icon in the viewpoint window.
    3.  The user view point name dialog will be displayed. Enter an arbitrary name and click OK. A new user viewpoint is added.
    4.  Move the model again to an arbitrary position and double click on the newly added user view point. The view at the time of new user viewpoint is restored.
    * User can restore viewpoint arbitrarily in main window by right clicking on added user viewpoint and turning off the tick mark of Pan and Zoom.
