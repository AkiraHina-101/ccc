Pretension | ADVC

Set initial tension (bolt axial force) for ADVC。 User can select multiple faces or multiple cross sections but they must have the same normal vector.

※When a bolt modeling command is executed from V4.1、create a group for each bolt created。
Bolt groups are placed under the Bolt Connection subgroup。

Structural

  • Step name

    Enter the name of the item to be created。

    Pretension-1

  • Pretension Force

    Enter the initial tension (bolt axial force)。

  • Input Unit

    Select unit system。

  • Ref.Node ID

    Enter ID of reference node。
    If you select a reference node in the selection list, the ID will be entered automatically。

  • Coordinates

    Enter coordinate values of reference node。
    If you select a reference node in the selection list, its node coordinate values are automatically input。

  • Pretension direction

    Specify the bolt tightening direction。
    It is automatically input by section face selection. Change if necessary。

  • Direction update

    Specify whether or not the tightening direction has been updated。

    • Yes ： Update
    • No ： Do not update
      •

  • Bolt FixLength

    If checked, a zero value forced speed will be created to hold the bolt tightening amount。

    • - Operating Procedure -

      Prepare bolt parts with partition cross section in advance using functions such as part cutting.

    1.  Select partition cross section or faces.
      Reference nodes are automatically defined at the cross section center. If you have created a reference node in advance, open the selection list, select Ref.Mode, and select that node.
    2.  Enter the axial force.
    3.  Change unit system, select additional options as needed.
    4.  Click Apply or OK button.



      5. *Forced speed load is created when selecting bolt fixed length option.
       After creating a process at the time of ADVC output, open LBC manager and press the bolt setting button, and it will be set automatically from the second process to make the forced speed for clamping amount setting effective.
