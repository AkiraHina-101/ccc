Extend Face

Create an extension face.

Direction Parameters

  • Metric

    Choose the method you want to create the face.
    ・Coordinate system： The direction of extension is specified as a parameter. ・2 Nodes： Select two nodes and determine the direction. ・Element Edge： Select an element edge to determine the direction of extension. ・Offset： Extend in the direction of the selected face. ・Cylinder： Cylindrical face extension

  • Coordinate System

    Coordinates to be referenced

  • Direction(Metric: only for Coordinate)

    ・X, Y, Z: These parameters determine the orientation.
    Enter a value for the direction in which the face will be extended, in the direction of the vector created by the values entered for X, Y and Z.

  • Both Directions

    Creates an extended face in both directions.

  • Reverse Direction

    Create a face in the opposite direction.


    • -----Metric: Cylinder only-----

  • Method

    Select the method you want to create the extended face of the cylindrical surface.
    ・To Axis： The direction of extension is specified as a parameter.
    ・To Face： Extends the face to the selected face.
    ・Arc Angle： Specifies the arc angle of the face to be extended.
    ・Arc Length：Specifies the arc length of the face to be extended.
    ・Sweep：Creates an extended face along a cylindrical shape.

    • Mesh Parameters

  • Destination

    Length： Specifies the length of the extension face.
    To Face： An extension face is created up to the selected face.

  • Num of Divisions

    Specifies the number of mesh divisions for the extended face.

  • Mesh Size

    Specifies the mesh size of the extension face.

  • Bias factor

    Specifies the bias factor.

  • Elem Type

    Specifies the element type of the extension face.

  • Arc Radius

    Specifies the radius of the arc face to be created.

  • Arc Node Num

    Specifies the number of nodes on the arc face to be created.

  • Angle Offset

    Specifies the angle of the arc face to be created.

  • Arc Length

    Specifies the circumference of the arc face to be created.(/p>

  • Length

    Specifies the length of the sweep.

    • Advance Options

  • Merge Faces

    Merges the original and extended faces.

  • Merge Edges(Angle)

    Specifies the allowed angle at which edges are merged.

  • Connect

    Connects the extension-face to the destination-face by a shared nodal point.

  • Create New Part

    Creates the extension face as a new part.

  • Preview

    Displays a preview of the extension face to be created.

    • - Operating Procedure -

    1. Select Metric.(If Cylinder is selected, you also need to select the Method.)
    2. Select the entities displayed in the selection list.
    3. Enter parameters as required.
    4. Click Apply/OK.
