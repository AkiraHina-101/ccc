Pressure | Function Load to Cylinder (Quadratic)

Define the pressure load on the basis of the quadratic function distribution to the selected Face or Element surface.

　　

Structural

  • Name

    Enter the name of the pressure loading conditions.

    • 　　

    Quadratic Curve : y=ax²+b

      Set up the quadratic function.


  • a

    Define the a quadratic function.

  • b

    Define the b of the quadratic function.

  • Input Unit

    Specify the input unit system.

  • Coordinate System for Load

    Select the coordinate system to determine the angle range of the load application.

  • Angle Range

    Specify the angle of the load application range from the Y axis on the XY plane in the above coordinate system.
    Enter the load coverage angle in the range 0~PI or 0°

  • Input Unit

    Specify the input unit system.

  • Pressure Direction

    Specify the pressure load direction.

    • Normal ： Perpendicular to the element plane
    • Vector ： Specify any direction
  • Coordinate System for Direction

    If the pressure direction specified is "Vector (specify any direction)" then select the coordinate system to reference.

  • Direction

    If the pressure direction specified is "Vector (specify any direction)", enter a comma-separated direction vector in the order of X, Y, Z.


    • On the surface which is included in the load coverage, the pressure which uses secondary function is loaded. The depth direction is constant.
    In the coordinate system specified in the X, use the element centre X coordinate value.

    - Operating Procedure -

    1.  From the selection list, select the Face or Element surface for applying pressure load, from the screen. (Multiple selections are possible).
    2.  Enter a name for the load.
    3.  Enter the numeric value of the second order function expression of a and b.
    4.  Specifies the angle of load application for quadratic functions
    5.  If the pressure direction is set to vector, specify the coordinate system and the direction vector.
    6.  Click the apply or OK button.
