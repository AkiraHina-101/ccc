Contacts | MSC Nastran - Contact Group by Matrix

Define contact settings for MSC Nastran between specified groups.
Create groups that will be master faces and slave faces in advance, and define contact pairs on the matrix table.

Contact

　　　
  • Name

    Enter the contact pair name.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Face-to-face contact

    　　　
    • 　　　　
  • Pair Selection

    The existing groups are displayed in matrix.
    Contact pairs are defined by checking the cells in the paired group positions.
        Switch Slave / Master: After selecting a cell, specify whether it becomes master or slave for the group in the left column
        All On: Consider all contact pairs
        All Off: Release all contact pairs

    　　　
    • 　　
  • Type

    Select the behavior type of contact definition.
        General: Sliding contact
        Tied: Tied contact
        Tied & Maintain Gap: Tied & Maintain Gap contact
        Tied & Full moment: Tied & Full moment contact
        Tied & Full moment & Maintain Gap: Tied & Full moment & Maintain Gap contact

    　　　

    • Contact Properties | General

    　　　
  • Touching Distance Range（ERROR)

    Distance below which a node is considered touching a body.

    　　　
    • 　　　
  • Separation Force (FNTOL)

    Separation force or stress on above which a node separates from a body.

    　　　
    • 　　　
  • Friction Coefficient (FRIC)

    Friction coefficient.

    　　　
    • 　　　
  • Interference Closure (CINTERF)

    Interference closure amount, normal to the contact surface.

    　　　
    • 　　　
  • Searching Order(ISEARCH)

    Option for contact searching order, from Slave to Master or from Master to Slave, for deformable contact bodies.
        Double : The search order is from lower BCBODOY ID's to higher ones first.
        Slave to Master : The searching order is from Slave to Master.
        Program decision : Let the program decide which search order.;

    　　　
    • 　　　
  • Modify Coordinates (ICOORD)

    Modify Coordinates.
        None : No modification.
        Modify position : Modify the coordinates of a node in contact with a deformable body so that stress-free initial contact can be obtained.
        Delay sliding : Extend the tangential error tolerance at sharp corners of deformable bodies to delay sliding off a contacted segment.
        Both effect : Have both Modify position and Delay sliding active.

    　　　
    • 　　　
  • Friction Stress Limit (FRLIM)

    Friction stress limit. This entry is only used for friction type 6 (Coulomb friction using the bilinear model).

    　　　
    • 　　　
  • Tolerance Bias Factor (BIAS)

    Contact tolerance bias. A non-blank entry will override the BIAS entered on the BCBODY entry.

    　　　
    • 　　　
  • Condition Check (ISTYP)

    Check of contact conditions. For a deformable body:
        Double Side : Symmetric penetration, double sided contact.
        Optimized : Double-sided contact with automatic optimization of contact constraint equations.

    　　　
    • 　　　
  • Shell element face (Slave)

    Shell element face (Slave) has the following options:
        Top&Btm Thk. offset : Both top and bottom faces will be in the contact description, thickness offset will be included.
        Btm w/ Thk. offset : Only bottom faces will be in the contact description, thickness offset will be included.
        Btm w/o Thk. offset : Only bottom faces will be in the contact description, shell thickness will be ignored.
        Top w/ Thk. offset : Only top faces will be in the contact description, thickness offset will be included.
        Top w/o Thk. offset : Only top faces will be in the contact description, shell thickness will be ignored.
        Top&Btm w/o Thk. offset : Both top and bottom faces will be in the contact description, shell thickness will be ignored.

    　　　
    • 　　　
  • Bearm/Bar Shell Elem, Edge (Slave)

    Bearm/Bar Shell Elem, Edge (Slave) has the following options:
        Beam/Bar Edge only : Only the beam/bar edges are included in the contact description.
        Free&Hard Edge only : Only the free and hard shell edges are included in the contact description.
        Both : Both the beam/bar edges and the free and hard shell edges are included in the contact description.

    　　　
    • 　　　
  • Shell element face (Master)

    Shell element face (Master) has the following options:
        Top&Btm Thk. offset : Both top and bottom faces will be in the contact description, thickness offset will be included.

    • 　　　
  • Bearm/Bar Shell Elem, Edge (Master)

    Bearm/Bar Shell Elem, Edge (Master) has the following options:

    • 　　　

    - Operating Procedure -

      　　　
    1.  Create a master face, slave face or element face group in advance.
      2. 　　　
    2.  [Pair Selection] checks the cell between the groups to be a contact pair, and the Switch Master / Slave button defines a master / slave for the left row group.
      3. 　　　
    3.  Define detailed settings for contact pairs as required, and click the Apply or OK button to define contact pairs.
