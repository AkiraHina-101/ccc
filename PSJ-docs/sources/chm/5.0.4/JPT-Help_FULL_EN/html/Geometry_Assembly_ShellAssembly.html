Shell Assembly

For the assembly model of multiple shell parts, connect between the face. Create a node and edge to the connection point.

Parameters

  • Method

    Specify the surrounding elements to be connected.

    • Tri3

      In case the mesh on the face is a Tri3 mesh.

    • Quad4

      In case the mesh on the face is a Quad4 mesh.

  • Tolerance

    Enter the tolerance between the faces to be connected.

    • - Operating Procedure -

      　　　
    1.  Select multiple parts or multiple faces as target.
      2. 　　　
    2.  Change the value of tolerance from the default value, if necessary.
      3. 　　　
    3.  Click the Apply / Ok button.
