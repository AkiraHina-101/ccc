Force | Normal Direction

Define the load in the normal direction of the selected nodes and selected faces.

Structural Force

　　
  • Name

    Set the force load name.

    Force

    　　
  • X/Y/Z

    Display the component of X, Y, and Z axial direction load for the selected element surface.

    　　　
    • 　　
  • Value

    Enter the load value.

    　　　
    • 　　
  • Input Unit

    Specify the input unit system.

    Options

    　　
  • Arrow Direction

    Set the drawing position of the marker display.
       Start at Node：The marker is displayed starting from a node
       End at Node：The marker is displayed ending at a node

    　　　
    • 　　
  • Distribution Method

    Set up the method of distribution for load.
       Per selected entity ：Apply the load value for each of the selected Entity
       Per node ：Apply equal load value to all the nodes on the selected Entity
       Total of Selected entity ：The total value of the load for the selected Entities

    　　　

    • - Operating Procedure -

      　　　
    1.  Select the node to apply the force in the normal direction. You can have multiple selections.
      2. 　　　
    2.  Choose one of the surface that refer to the normal direction.
      3. 　　　
    3.  Enter the load value.
      4. 　　　
    4.  Select and enter the method of distribution for load value.
      5. 　　　
    5.  Select and enter other parameters as required.
      6. 　　　
    6.  Click the Apply or OK button.
