Mesh Copy

Mesh Copy Dialog Box

In this command, mesh pattern is copied in forward direction for the face of same shape.


- Operating Procedure -

  1.  Select two faces of the same shape from the view window. Select the source to copy to destination.
  2.  Select the two nodes of the same position from the view window. Select the source to copy to destination.
  3.  Select the Apply or OK button to transfer a copy of the original mesh pattern to the destination.
