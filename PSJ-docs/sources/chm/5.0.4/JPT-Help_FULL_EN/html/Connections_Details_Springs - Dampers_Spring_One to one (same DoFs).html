Connection | Spring - One to one - same DoFs

It is a function to create a one-to-one scalar spring element.
＊The 1st group node and the 2nd group node can be selected in part units, face units, edge units, element units, and node units.

The 1st group node and the closest 2nd group node (within the connection range) are connected.
This feature allows you to combine multiple degrees of freedom (the 1st and 2nd group nodes have similar degrees of freedom).

Connection

  • Name

    Enter the name to be registered.

    • Search Area

  • All

    Specify the connection range as infinite.

  • Tolerance

    Enter the radius of the connection range.

    • Spring

  • Grounded

    Specify the grounded spring option.

  • X Stiffness - RZ Stiffness

    Enter the spring stiffness in the degree of freedom to combine.

  • Damping Coef (for Nastran)

    Enter the damping coefficient.

  • Stress Coef (for Nastran)

    Enter the stress coefficient.

    • Analysis Coordinate Frame

  • Coordinate

    Select a reference coordinate system.

    • - Operating Procedure -

    1.  Set the connection range.
    2.  Select 1st group node from part, face, edge, element, node.
    3.  Select 2nd group node from part, face, edge, element, node.
    4.  Enter the spring stiffness in the degree of freedom to combine.
    5.  Set other parameters.
    6.  Click the Apply / OK button.
