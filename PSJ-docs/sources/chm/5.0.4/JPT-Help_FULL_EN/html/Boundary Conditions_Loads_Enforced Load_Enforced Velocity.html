Enforced Velocity

Select faces, edge, node to define the enforced velocity.


Structural

  • Name

       Set the enforced velocity load name.

    • Value

  • Translation X/Y/Z

       Set the enforced velocity value for X, Y, and Z-translational direction.

  • Arrow Direction

       Specify the drawing position of marker display.
       Start at Node：The marker is displayed starting from a node.
       End at Node：The marker is displayed ending at a node.

  • Input Unit

       Specify the input unit system.

    • Value

  • Rotation X/Y/Z

       Set the forced velocity value with X, Y, Z direction of rotation.

  • Input Unit

       Specify the input unit system. ※ Set the default value to the Document unit system.

    • Analysis Coordinate Frame

  • Coordinate

       Select the load direction of the reference coordinate system of the load.

    • Tables

  • Select Table

       Select the table which refers to frequency and time history.

    • Phase-Delay

  • Phase

       Enter the phase of the load.

  • Phase Table

       Select the phase table of load.

  • Delay

       Enter the delay value of the load.

    • Multi-Excitation Load Export

  • Translation X/Y/Z

       Select the table of Plural point input for X, Y and Z translational direction.

  • Rotation X/Y/Z

       Select the table of Plural point input for X, Y and Z rotational direction.


    • - Operating Procedure -

    1.  Select a face, node, edge to apply the enforced velocity load. You can have multiple selection.
    2.  In accordance with the load direction, input the load value for each X, Y, and Z translational and rotational value respectively.
    3.  Select and enter the other parameters as required.
    4.  Click the Apply or OK button.
