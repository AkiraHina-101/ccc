Contacts | FrontISTR - Share Face

Define the FrontISTR contact settings from the specified face.
Shared faces are separated (to create a double nodal state) and the contact pairs are defined between its separated face.

Basic

　　　
  • Name Prefix

    Enter the name you want to give to the contact pair.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Contact between the face to face

    　　　
    • 　　　
  • Type

    Select the behaviour type of contact definition.
        General: Sliding contact
        Tied: Fixed

    　　　
    • 　　　
  • Information

        Show Information: Part name appears to be associated with the selected shared surface.

        Highlight Body: Part associated with the selected shared surface will be highlighted.

    　　　

    • Contact Properties

    　　　
  • Contact Type

    Define contact type for contact FrontISTR, easily control for same contact type setting.

        ID: Input ID.
        Interaction: Select neccessary interaction method.
        Normal Direction Convergence (NTOL): Input normal direction convergence parameter.
        Tangential Direction Convergence (TTOL): Input tangential direction convergence parameter.
        Normal Direction Penalty (NPENALTY): Input normal direction penalty parameter.
        Tangential Direction Penalty (TPENALTY): Input tangential direction convergence parameter.

    List Contact Type Created: Shows all previously created contact types. Also right click to get features like Edit and Delete.
        Edit: Modify parameter of Contact Type.
        Delete: Delete Contact Type.

    　　　
    • 　　　
  • Friction Coefficient (FCOEF)

    Input friction coefficient.

    　　　
    • 　　　
  • Friction Penalty Stiffness (FACTOR)

    Input friction penalty stiffness.

    　　　
    • 　　　

    Others

  • Color Setting

    Contact Color
        Define the contact pair display marker color.
        Reset: Initialize to the default color.

    　　　

    • - Operating Procedure -

      　　　
    1.  Create a shared face in advance by the assembly function and leave the display on shared face.
      2. 　　　
    2.  Select the shared face that you want to define as a contact.
      3. 　　　
    3.  Define the advanced settings for the pair of contacts, click the Apply (OK) button to create contact definition.

    Shared faces are separated (the face to create a double nodal state) and the contact pairs are defined between its faces.
