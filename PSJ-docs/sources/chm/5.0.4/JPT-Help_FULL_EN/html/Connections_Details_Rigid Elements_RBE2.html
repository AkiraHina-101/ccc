RBE2

To create a RBE2 (rigid element).

  • One to many

    This function is to create one to many (Master : Slave) RBE2 (Rigid Element).

  • One to one

    This function is to create one to one (Master : Slave) RBE2 (Rigid Element).

  • To center

    This function is to create one to many (Master : Slave) RBE2 (Rigid Element). The master node is created in the average coordinate of the selected slave node or any coordinates.
    This is useful when you want to define a master node outside the model.

  • To circle center

    This function is to create one to many (Master : Slave) RBE2 (Rigid Element). The master node is created on the coordinates of the centre of the selected arc.
    This is useful when you want to create a RBE2 for a circle or a cylindrical shape.
