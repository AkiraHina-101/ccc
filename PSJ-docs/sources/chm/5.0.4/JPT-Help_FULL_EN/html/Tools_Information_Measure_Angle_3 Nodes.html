Angle [3 Nodes]

Measure the angle ∠ABC of the three nodes.

　　

Option

  • Coordinate System

       Choose a projection coordinate system.

    • Output

  • Angle

       Measurement result is displayed.

  • Input Unit

       Set the preferred unit system .

  • On Local XY

       Projection angle in the specified coordinate system XY plane.

  • On Local YZ

       Projection angle in the specified coordinate system YZ plane.

  • On Local ZX

       Projection angle in the specified coordinate system ZX plane.

    • - Operating Procedure -

    1.  Choose three nodes on the screen (In the order Node A, B and C).
    2.  If you want to measure the projection angle in the co=ordinate system plane, select the co-ordinate system in the Local co-ordinate system.
    3.  Value of the angle ∠ABC of the three nodes is displayed under angle, while the angle projected in the specified coordinate system plane is displayed to the local co-ordinate system XY (YZ, ZX).
