Angle [2 Edges]

Measure the angle between 2 edges.

　　

Option

  • Coordinate System

       Choose a projection destination coordinate system.

    Output

  • Angle

       Measurement result is displayed.

  • Input Unit

       Set the preferred unit system .

  • On Local XY

       Projection angle in the specified coordinate system XY plane.

  • On Local YZ

       Projection angle in the specified coordinate system YZ plane.

  • On Local ZX

       Projection angle in the specified coordinate system ZX plane.

    • - Operating Procedure -

    1.  Select the two edges from the screen.
    2.  If you want to measure the projection angle in the coordinate system plane, select the coordinate system in the local coordinate system.
    3.  Value of the angle between the two edges is displayed along with the angle that was projected to the specified coordinate system plane is displayed to the local coordinate system XY (YZ, ZX).
