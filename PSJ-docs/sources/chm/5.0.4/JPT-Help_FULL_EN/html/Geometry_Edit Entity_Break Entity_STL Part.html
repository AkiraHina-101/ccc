STL Part

Perform entity division of STL parts.



  • Minimum Number of Facet

    Enter the number of facets to be considered as one entity.

  • Method
    • Face based: Separate by face base.
    • Facet based: Separate on a facet basis, ignoring face configurations.

    - Operation Procedure (Node position division) -

    1.  Select the target part.
    2.  Enter the minimum number of faces.
    3.  Choose a method.
    4.  Click the Apply / OK button.
