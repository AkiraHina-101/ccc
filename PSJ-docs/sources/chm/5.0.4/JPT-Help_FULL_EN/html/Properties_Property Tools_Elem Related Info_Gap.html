Element Related Information | Gap Dialog Box

You can individually change the direction vector and end release information of elements included in the selected edge or directly selected elements.

　　
  • Switch End-A / End-B

    Swap the node numbers of A end and B end.

    　　　
    • 　　
  • Orientation Vector

    Overwrite the orientation vector of the gap element with the direction cosine of X, Y, Z.

    　　　
    • 　　
  • Cid

    Overwrite the reference coordinate system of the orientation vector with the coordinate system number.

    　　　
    • 　　
  • Select All

    All elements displayed in the gap connection list are to be overwritten. All check boxes will be checked.

    　　　
    • 　　
  • Select None

    Remove all elements displayed in the gap connection list from overriding. All check boxes will be cleared.

    　　　
    • 　　
  • Set Selected

    Target elements are selected on the screen and displayed in the selection list or elements are picked and highlighted in the gap connection list. Only the selected element's check box is selected and displayed in the selection list.

    　　　

    • - Operating Procedure -

      　　　
    1.  Selecting a command will display all existing gap elements in the list. Initially, the check boxes for all element IDs are checked, and all elements are subject to overwrite.
      2. 　　　
    2.  To overwrite only specific elements, press No selection below the list and deselect all elements. The check box is cleared.
      3. 　　　
    3.  Select the target element from the list on the screen or in the dialog box, specify it and press the select button. The target element's check box is selected.
      4. 　　　
    4.  Enter the value to be changed to an item such as a orientation vector and press the setting button. The target item on the list is overwritten.
      5. 　　　
    5.  Click Apply or OK to apply your changes.
