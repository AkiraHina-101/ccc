Local CS [Rotate]

Rotate the a coordinate system to an angle that is specified by selecting from the screen.

　　

Coordinate

  • Type

       Choose the Type of the coordinate system.

    • Rectangular : Select the Cartesian coordinate system.
    • Cylindrical : Select the cylindrical coordinate system.
    • Spherical : Select a spherical coordinate system.

  • Name

       Enter the name of the coordinate system to be created.

    • Refer Coordinate Frame

  • Coordinate

       Select the global coordinate system or existing local coordinate system.

    • Rotate

  • RX/RY/RZ

       Enter the angle around the X / Y / Z axis of the reference coordinate system.

  • Create New

       Choose to create a new coordinate system.


    • - Operating Procedure -

    1.  Select the type of coordinate system from Type.
    2.  Enter the name of the coordinate system to be created.
    3.  Select the direction of rotation of the reference coordinate system from the coordinate.
    4.  Choose one of the coordinate system to refer to the rotation.
    5.  Enter each of the angle of rotation around X, Y and Z- axis as RX, RY and RZ.
    6.  When you want to create a new coordinate system after rotation, check the New box.
    7.  Press the Apply or OK button.
