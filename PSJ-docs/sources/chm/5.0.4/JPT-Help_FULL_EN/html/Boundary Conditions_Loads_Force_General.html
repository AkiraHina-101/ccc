Force | General

Add the Force and moment load in the analysis model.


　　

Structural

  • Name

       Enter the name of the load condition.

  • Coordinate

       Enter the global coordinate system or Local coordinate system load conditions references.

  • Type

       Specify a coordinate system or vector direction to define the direction of force.

    • Coordinate system ： Specify the coordinate system.
    • Vector ： Specify the vector direction.
      •

    • Force

  • Force X

       Enter the load value of the coordinate system X direction.

  • Force Y

       Enter the load value of the coordinate system Y direction.

  • Force Z

       Enter the load value of the coordinate system Z direction.

  • Input Unit

       Specify the input unit of the load value.

    • Moment

  • Moment X

       Enter the moment value of the coordinate system X direction.

  • Moment Y

       Enter the moment value of the coordinate system Y direction.

  • Moment Z

       Enter the moment value of the coordinate system Z direction.

  • Input Unit

       Specify the input unit of the Moment value.

    • Options

  • Arrow Direction

       You can adjust the display of the load marker.

    • Start at Node ： The marker is displayed starting from a node
    • End at Node ： The marker is displayed ending at a node
      •

  • Distribution Method

       Determine how to distribute the input load.

    • Per Selected Entity ： Apply the load value for each of the selected Entity
    • Per Node ： Apply equal load value to the node on the selected Entity
    • Total of Select ： The total value of the load for the selected Entities
      •

    • Tables

  • Select Table

       Defined in the Field Data. Currently not supported.

    • Phase Delay

  • Phase

       Enter the phase.

  • Phase Table

       Select the phase Table that you entered in the Field Data.

  • Delay

       Enter the Delay.

    • Multi-Excitation Load Export

     : Collectively define the load of each degree of freedom direction. Load will be created for every degree of freedom you have defined
  • Arrow Direction

       You can adjust the display of the load marker.

    • Translation X ： Specify the frequency table for the translational X-direction load. Input required for Values-Translation X
    • Translation Y ： Specify the frequency table for the translational Y-direction load. Input required for Values-Translation Y
    • Translation Z ： Specify the frequency table for the translational Z-direction load. Input required for Values-Translation Z
    • Rotation X ： Specify the frequency table for the X-axis rotation direction load. Input required of Values-Rotation X
    • Rotation Y ： Specify the frequency table for the Y-axis rotation direction load. Input required of Values-Rotation Y
    • Rotation Z ： Specify the frequency table for the Z-axis rotation direction load. Input required of Values-Rotation Z
      •

    • FrontISTR Rotational Torque Load

  • Rotational Torque Center

       Select boundary that contains Rotational Torque Center, normally only one node.


    • - Operating Procedure -

    1.  Select one of the Face, Edge and Node button from the selection list and select the load application object from the screen.
    2.  Enter the name for the load.
    3.  Select the coordinate system if necessary.
    4.  Enter the load value and the moment values in each X,Y and Z direction.
    5.  Change the direction of arrow and distribution direction if necessary.
    6.  Click the Apply or OK button.
