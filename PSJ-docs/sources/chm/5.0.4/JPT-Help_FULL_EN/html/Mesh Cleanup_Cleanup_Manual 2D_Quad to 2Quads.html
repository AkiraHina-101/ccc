Quad to 2 Quads

Convert one quadrilateral elements into two quadrilateral element.
When you move mouse over the element to preview, if there are multiple splitting patterns, you can split by confirming the change in the preview display of split pattern.

Settings

  • Auto Transition

    When checked, to ensure the integrity of the mesh division it will automatically create the mesh division of elements other than those specified.

    If you do not check this box, the integrity of the mesh division around after the split will no longer be observed because it will not place a mesh division of elements other than those specified.

  • Merge Nodes

    When checked, it will join the nodes created by automatic mesh division for the elements other than those specified.

  • CAD Projection

    If you check, it puts the node that was created by mesh division into CAD geometry.

  • Auto Execution

    When checked, it will convert automatically when you select an element.

    • - Operating Procedure (to increase the integrity of the mesh division) -

    1.  Turn on the Auto Transition check box.
    2.  Turn on the Auto Execution check box.
    3.  Hover mouse over the quadrilateral element that you want to convert, and then select the dividing line while displaying preview.
    4.  Simultaneously convert selected.
