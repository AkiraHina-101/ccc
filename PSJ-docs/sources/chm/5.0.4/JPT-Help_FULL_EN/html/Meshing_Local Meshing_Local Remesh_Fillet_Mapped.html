Fillet ISO Mesh

This command extracts fillets and creates an ISO mesh (mapped mesh) of setting values in the extracted fillets.

Step

  • Operation

       Choose a method to extract the fillets.

       Select: Extract the fillet portion.
       Mapped: Creates a mapped mesh.

    • Select

  • Minimum Face Width

       Specify the minimum face width to search.

  • Maximum Face Width

       Specify the maximum face width to search.

  • Minimum Curve Radius

       Specify the minimum radius of the fillet to search.

  • Maximum Curve Radius

       Specify the maximum radius of the fillet to search.

  • Minimum Angle

       Specify the minimum value of the fillet angle to search.

  • Maximum Angle

       Specify the maximum value of the fillet angle to search.

  • Convex

       Search for convex fillets.




  • Concave

       Search for concave fillets.

    • Mapped Mesh

  • Circumference Division

       Set the number of divisions in the fret circumferential direction.

  • Axis Average Size

       Set the average mesh size in the fret axis direction.

  • Error Tolerance

       Set the tolerance.

    • - Operating Procedure -

    1.  Select "Select" from the operation and select the target part or face group.
    2.  Enter the maximum and minimum face width of the fillet to search.
    3.  Enter the maximum and minimum curvature radius of the fret to be searched.
    4.  Enter the minimum and maximum angle of the fret to be searched.
    5.  Specify whether the fret to be searched is convex or concave.
    6.  When the Apply button is clicked, fillet faces within the specified range are selected from the target part.
    7.  Select "Mapped" from the operation.
    8.  Enter the number of divisions in the circumferential direction of the fret mesh to be created.
    9.  Enter the average mesh size in the axial direction of the fret mesh to be created.
    10.  Enter the error tolerance when creating the mesh.
    11.  Click the Apply / OK button to create an ISO mesh (mapped mesh) on the selected fillet face.
