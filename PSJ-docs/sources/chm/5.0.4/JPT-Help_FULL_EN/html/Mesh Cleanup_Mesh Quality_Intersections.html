Intersections

For Element intersection error detection.

Number of Edges

  • Tolerance

    •    Set the Tolerance for element intersection display.

  • Number of Element

    •    It displays the element number of elements intersection.

  • Display Type

    •    Select the type of elements intersection display.

    • Body Intersection Only : It displays the element intersection on the Part.
    • All Intersection : The element intersection section between parts and on part is displayed.
    • Between Bodies Intersection : It displays the element intersection only between parts.

    Layers

  • Number of Layers

    •    Set the number of layers for mesh display around the element intersection position.

  • Layer Update

    •    To update the number of display layer.

    Auto Cleanup

  • Cleanup

    •    Intersecting parts will be automatically corrected.

  • Aggressive Cleanup

    • When checked, the function will clean up mesh quality over shape reproducibility.

    Output Options

  • Error Test

    •    When it is turned on, the information of intersection is output to the Output window with the Text data and the Temp folder of Install Path.

    - Operating Procedure -

    1.  Select the Part to be checked.
    2.  Change the Tolerance and Display Type, if necessary.
    3.  Click the Apply or OK button.
    4.  After checking, click the Reset to Normal Display Mode icon  in the main window to return to the original display.
