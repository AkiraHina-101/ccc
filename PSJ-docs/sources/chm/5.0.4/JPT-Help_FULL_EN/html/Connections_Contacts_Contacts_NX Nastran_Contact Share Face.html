Contacts | NX Nastran - Share Face

Define contact settings for NX Nastran from the sharing side.
Shared faces are separated (faces with double nodal states are created), and contact pairs are defined between the faces.

Basic

　　　
  • Name Prefix

    Enter the name given at the beginning of the contact pair name.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Face-to-face contact

    　　　
    • 　　　
  • Type

    Select the behavior type of contact definition.
        General: Sliding contact
        Tied: Tied contact

    　　　
    • 　　　
  • Information

        Show Information: Display the part name associated with the selected shared face.

        Highlight Body: The parts related to the selected shared face are highlighted.

    • - Operating Procedure -

      　　　
    1.  Create the shared face in advance by the assembly function and display the shared face.
      2. 　　　
    2.  Select the shared face you want to define the contact on.
      3. 　　　
    3.  Define detailed settings for contact pairs as required, and click the Apply (OK) button to define contact pairs.

    Shared faces are separated (faces with double nodal states are created), and contact pairs are defined between the faces.
