Change Topology Element

Selected elements will be moved to another part.

Options

  • Create New Part

    When checked, it creates new parts from selected elements.

    If you do not put a check, element will belong to the selected parts.

    • - Operating Procedure -

    1.  Select the face.
    2.  If you want the elements to belong to a different part, select the parts. (Create New Part check off)
    3.  Check the Create New Part, if you want to create a new part.
    4.  Click Apply or OK button for the function to be executed.
