Change Pattern

Change the mesh pattern of the selected face.

Entity Type

  • Change Pattern Type

    Selecting Standard changes it to a standard map mesh.

    When a Union Jack is selected, it changes to the union jack mesh pattern.

    • - Operating Procedure -

    1.  Select a face.
    2.  Select a mesh pattern in Change Pattern Type.
    3.  The function is executed with the Apply or OK button.
