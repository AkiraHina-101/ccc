Contacts | ADVC - Group By Matrix

Define the contact set between the specified group for ADVC.
Create a group and master and slave faces beforehand to define the contact pairs on the matrix table.

Basic

　　　
  • Name

    Enter the name of the contact body.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Contact between the face to face

    　　　
    • 　　　
  • Type

    Select the behaviour type of contact definition.
        General: Sliding contact
        Tied: Fixed

    　　　
    • 　　　
  • Pair Selection

    Displays a matrix of existing groups.
    Contact pairs defined by checking a check box to a cell group where they are paired.
        Switch Slave/Master: After selecting the cell, specify master or slave for the group in the left column
        All On: Considering all of the contact pair
        All Off: Cancel all of the contact pair

    　　　

    • Contact Properties

    　　　
  • Behavior

    Define the presence or absence of contact.
        Separation: Remove the contact restraint when the tensile force is generated
        No Separation: Binding on all of the contact pairs were found at the beginning of the contact search

    　　　
    • 　　　
  • Formulation

    Select the contact formulation type.
        Node to Segment: Node - face contact
        Segment to Segment: Face - face contact

    　　　
    • 　　　
  • Constraint Type

    Define the contact constraint type.
        Lagrange: Lagrange undetermined multiplier method
        Penalty: Penalty method

    　　　
    • 　　　
  • Constraint Type Explicit

    Define the contact constraint type in the explicit dynamic analysis.
        Kinematic: Constraint method
        Penalty: Penalty method

    　　　
    • 　　　
  • Penalty Fact

    Define the penalty scale factor.

    　　　
    • 　　　
  • Penalty Fact Explicit

    Define the penalty scale factor in the explicit dynamic analysis.

    　　　
    • 　　　
  • Adjust

    Select whether you want to move the slave node on the master surface so that the clearance goes to zero.
        Yes: Move all of the slave node
        Value: Defines the distance to enable the node movement.

    　　　
    • 　　　
  • Auto shrink

    Define the presence or absence of penetration elimination.
        Yes: Penetration elimination
        No: Without Penetration elimination

    　　　
    • 　　　
  • Finite Sliding

    Consider a finite sliding contact.

    　　　
    • 　　　
  • Clearance

    Define the clearance amount.

    　　　
    • 　　　
  • Search Gap

    Define the normal direction search distance for the gap surface.

    　　　
    • 　　　
  • Search Depth

    Define the normal direction search distance for the penetration surface.

    　　　
    • 　　　
  • Search Width

    Define the inside and outside determination parameter in the direction of the contact surface.

    　　　
    • 　　　
  • Search Angle

    Define the search angle of normal vector of the master / slave surface.

    　　　
    • 　　　
  • Initial State

    Specify the initial contact state.
        Auto: Auto-detect
        Open: Start analysis from the non-contact state
        Close: Start analysis from the contact state

    　　　
    • 　　　
  • Initial State Tol

    Enter the tolerance value to determine the initial contact state.

    　　　
    • 　　　
  • Adjust to Clearance

    Choose whether you want to avoid the collapse element in accordance with node movement by Adjust function.
        Yes: The gap amount is replaced with 0, without moving the node.
        No: Without avoidance

    　　　

    • General Parameter

    　　　
  • Friction Coef.

    Define the coefficient of static friction.

    　　　
    • 　　　
  • Kinetic Friction Coef.

    Define the dynamic coefficient of friction.

    　　　
    • 　　　
  • Exponential Coef.

    Define the exponential damping coefficient.

    　　　
    • 　　　
  • Max Shear Stress

    Define the maximum shear stress.

    　　　
    • 　　　
  • Elastic Slip

    Define the allowable amount of slip.

    　　　
    • 　　　
  • Slip Tolerance

    Define the allowable slip tolerance.

    　　　
    • 　　　
  • Critical Penetration

    Define the critical penetration amount.

    　　　
    • 　　　
  • Impact Time Estimation

    Choose contact pairs using prediction of collision and release time.
        No: Not used
        Yes: Use

    　　　

    • Stabilization

    　　　
  • Type

    Select the type of contact stabilization coefficient
        Stiffness: Stiffness ratio
        Area: Area ratio

    　　　
    • 　　　
  • Residual Factor

    Define the residual factor used to define the correction coefficient C1.

    　　　
    • 　　　
  • Effective Distance

    Define the effective distance that is used to define the correction coefficient C2.

    　　　
    • 　　　
  • Normal Factor Cn

    Define the normal direction stabilization coefficient.

    　　　
    • 　　　
  • Tangential Factor Ct

    Define the tangential direction stabilization coefficient.

    　　　

    • Color Setting

    　　　
  • Contact Color

    Define the contact pair display marker color.
        Reset: Initialize to the default color

    　　　
    • 　　　

    Thermal Conductance

    　　　
  • Data Type

    Define the heat transfer coefficient of clearance dependency.
        Clearance Dependency: Define the heat transfer coefficient of the clearance dependency.

        Conductivity: Coefficient of heat transfer
        Clearance: Clearance

    　　　

    • - Operating Procedure -

      　　　
    1.  Make a face or element faces group consisting of a slave and master surface.
      2. 　　　
    2.  By Pair Selection, check the cell between the groups that define contact pair, to define the master / slave for the left column group by Switch Slave / Master button.
      3. 　　　
    3.  Define the advanced settings for the pair of contacts, click the Apply (OK) button to create contact definition.
