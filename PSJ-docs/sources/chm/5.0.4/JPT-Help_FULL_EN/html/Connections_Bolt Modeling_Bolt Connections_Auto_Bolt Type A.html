Bolt Type A

This is the dialog that opens from the Auto Bolt Connection function to set the FEM conditions for bolt type A.
Auto Bolt Connection Help

For bolt type A, RBE2/RBE3 elements are created in a circular shape on the upper and lower seating surface and join their center by Bar/RBE2 element.
Bolt tightening force certainly can be added with the Pre Tension Load option.


Seat Settings

  • Connection

    Specify the type of rigid body that is to be created on the upper and lower seating surfaces of the bolt holes.


  • Seat Diameter(Node)

    Specify the diameter range that the rigid body is created at the nodes within.

  • Seat Layer(Face)

    Specify the number of layers of faces around the bolt hole that the rigid body is created.

    • Shaft Settings

  • Shaft

    Specify the type of rigid body (RBE2/Bar) to be created for the bolt shaft.


  • Bar Property

    Specify the Bar property applied for the bolt from existing properties when Shaft is defined as Bar element.
    If None is specified, the Bar element is set no property.

    • Center Settings

  • Connection

    Specify the type of rigid body to be created at the shaft center.
    Only Spring can be specified when RBE3 is used for the seat and RBE2 is used for the shaft.

    • None : No rigid body at the center of the shaft.
    • Spring : Create a Spring at the center of the shaft.
    • PreTension : Create a PreTension at the center of the shaft.


    • Pre Tension Load

    Set the bolt tightening force.

  • Solver

    Specify the target solver.

    • All : Specify all solvers.
    • Abaqus : Use the ABAQUS PreTension command.
      •


  • Value

    Specify the bolt tightening force value.

  • Input Unit

    Specify the unit system used for inputted values.

  • Bolt Fix Length

    Specify whether to allow remaining unchanged the bolt tightening amount.

    • - Operating Procedure -

    1. Select the rigid body types and enter the parameters.

    2. Click the OK button. This dialog closes and highlights the button of the corresponding bolt type in the Auto Bolt Connection dialog.
