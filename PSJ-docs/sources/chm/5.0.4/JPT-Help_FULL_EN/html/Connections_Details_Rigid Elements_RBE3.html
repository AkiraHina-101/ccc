RBE3

Create the RBE3 (rigid elements).

  • One to many

    This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element).

  • One to one

    This function is to create one to one (Slave : Master) RBE3 (Interpolation constraining Element).

  • To center

    This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element). The slave node is created in the average coordinate of the selected master node or arbitrary coordinates.
    This is useful when you want to define a slave node outside the model.

  • To circle center

    This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element). The slave node is created in the average coordinate of the selected master node or arbitrary coordinates.
    This is useful when you want to create a RBE3 for a circle or a cylindrical shape.
