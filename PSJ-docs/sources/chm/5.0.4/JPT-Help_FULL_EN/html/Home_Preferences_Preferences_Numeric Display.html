Numeric Display

Set up the numeric display format in Jupiter-Pre.

  • Real Type(123.456)

    • Display the numerical values in real number format.

  • Power Type(1.234E-005)

    • Display the numerical values in exponential format.

    • Width

      • Specify the number of digits to display.

    • Precision

      • Specify the number of decimals to display.
  • Auto

    • Display numerical values in optimum format.

    - Operating Procedure -

    1.  Activate the command, specify each option and click Apply or OK button.
