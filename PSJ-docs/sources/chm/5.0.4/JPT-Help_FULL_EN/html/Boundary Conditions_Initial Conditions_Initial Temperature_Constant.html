Initial Temperature | Constant

This command sets the initial temperature.

　　

Thermal

  • Name

       Enter the initial temperature name.

    • Value

  • Temperature

       Enter a constant temperature value.

  • Input Unit

       Specify the input unit of temperature.

  • Use Default Temperature

       Designate a constant temperature load throughout the model without selecting parts.
       At the time of solver input data output, the data volume and output time are reduced because all nodes are uniform.


    • - Operating Procedure -

    1.  Select the part, face, edge or node button and select the initial temperature target from the screen.
    2.  Enter the initial temperature name.
    3.  Enter a constant temperature as the boundary temperature.
    4.  Change the input unit if necessary.
    5.  Press the Apply or OK button.
