Project Line

Project the selected edge vertically onto the selected face.

Option

  • Break Face

    •    Break the face.

  • Vector Direction

    •    Specify the projection method.

    • Target Face Normal: Project in the normal direction of the target face.
    • Two Nodes: Project in the direction of the specified 2 nodes.
    • Nearest Vector: Project onto the face closest to the selected edge.
      •
  • Gap

    •    Limit the projection distance to the input value.



    - Operating Procedure -

    1.  Press the edge or face button and select the edge to imprint from and the face to be imprinted from the screen.
    2.  From the preview, check that the projection destination is correct.
    3.  Set the projection method and gap amount as necessary.
    4.  Clear the Split Faces check box if necessary. In this case, the imprinted face is not divided from the original face.
    5.  Click the Apply / OK button.
