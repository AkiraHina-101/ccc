Morphing | Rib Thickness


Change the thickness of the existing rib by deformation of the mesh (morphing).

※After the morphing function is executed, the mesh is trimmed with the partial remeshing function.

Options

  • Move Distance

       Specify the thickness increase (+) and decrease (-) value. The moving distance in the thickness direction increases or decreases by 2 from the center of rib.

  • Strong Effect Distance

       Specify the range that is strongly affected by the movement of the selected entity as a distance. The nodes included in this range move by 1/2 of the distance specified in the movement distance.

  • Weak Effect Distance

       Specify the range affected by the movement of the selected entity as a distance. The Movement Amount of the nodes included in this distance range is 0 < Movement Amount < Move Distance/2, and decreases as the distance from the selected entity increases.

    • - Operating Procedure -

    1.  Select the face in the thickness direction of the rib whose thickness you want to change.
    2.  Enter the parameters and press OK to change the rib thickness.
