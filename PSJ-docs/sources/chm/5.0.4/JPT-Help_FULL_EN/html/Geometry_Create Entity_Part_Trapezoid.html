Trapezoid

Create a trapezoid body.

Part Properties

  • Part Name

    Enter the name of the trapezoid body to be created.

    • Trapezoid

  • Local Coordinates

    Select any of the coordinate system.

  • Circle Segment

    When checked, it creates the input vertices in Radius R (radius)

  • Origin-X,Y,Z

    Specify the origin coordinates.

  • Length in X(Top)

    Enter the length of the X-axis direction (Top).

  • Length in X(Bottom)

    Enter the length of the X-axis direction (Bottom).

  • Length in Y, Z

    Enter the length of the each of the Y, Z-axis direction.

  • Radius

    If you check the Circle Segment, enter the radius.

  • Number of Nodes in X, Y, Z

    Enter the number of nodes in X, Y, Z-axis direction, respectively.

    • - Operating Procedure -

    1.  Enter the part name in the Parts Name.
    2.  Specify the origin coordinates in Origin-X, Y, Z
    3.  Enter the length of the X-axis direction (Top) in Length in X (Top).
    4.  Enter the length of the X-axis direction (Bottom) in Length in X (Bottom).
    5.  Enter the length of the each of the Y, Z-axis direction in Length in Y and Length in Z respectively.
    6.  Enter the number of nodes in X, Y, and Z-axis direction in Number of Nodes in X, Y, Z respectively.
    7.  Click Apply / OK button.
