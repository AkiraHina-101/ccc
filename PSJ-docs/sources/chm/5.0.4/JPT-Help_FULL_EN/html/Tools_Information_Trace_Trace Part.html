Trace | Part

This command shows or hides parts using the connection information between parts.
You can check which part is connected to the selected part and to which part it is connected.


Search

  • All

       If checked, all parts in the model will be searched regardless of the number of layers.

  • Number of Layers

       Enter the number of layers to search when the Apply, Increase, or Decrease button is pressed.

    • 　　

    Trace Part

  • Shared Faces / Nodes

       When checked, the part with the displayed part and the shared plane / shared node is displayed.

  • Contact Conditions

       If checked, the part that is in contact with the displayed part will be displayed.

  • Beam element / Bar element

       When checked, the part being connected by the displayed part and the beam / bar element is displayed.

  • Spring / Bush / Gap

       When checked, the displayed part and the part connected with the spring element / bush / gap element are displayed.

  • Rigid Elements

       When checked, the displayed part and the part connected by the rigid wall are displayed.

  • MPC

       When checked, the displayed part and the part connected by MPC are displayed.

  • Increase Layer

       The hierarchy for tracing connection information is +1.

  • Decrease Layer

       The hierarchy for tracing connection information is -1.

    • Reset

  • Reset

       Reset the display (display all parts regardless of connection information).


    • - Operating Procedure -

    1.  Select a part to display connection information.
    2.  Set connection information in Trace Part.
    3.  Press Apply button.
    4.  You can change the display of the hierarchy tracing the connection information and check it with the button of Add Layer / Reduce Layer.
    5.  Press the reset button to restore the part display.
