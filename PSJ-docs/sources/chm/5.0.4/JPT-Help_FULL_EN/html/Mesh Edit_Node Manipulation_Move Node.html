Move Node

Move a node or a floating node.



  • Absolute

       Move to any position.

  • Offset

       Move in any direction.

  • Normal Offset

       Move in the vertical direction of the face.

  • Along Direction

       Move in any direction.

  • Point

       Indicate the destination by specifying an arbitrary point, and move the node.

  • CAD Follows

       By dragging a node, you move it anywhere on the face.

  • Project To Line

       Move on a straight line.

  • Project To Plane (Element)

       Project the selected nodes or floating points at the shortest distance onto the plane defined by the element.

  • Project To Plane (3 Nodes)

       Move any target node on the plane defined by the three reference nodes by the shortest distance.

  • Straighten Midnodes

       Move the mid node to the linear interpolation position of the corner node.

  • Along Cylinder

       Move the nodes on the defined virtual cylinder.

  • Coincident Nodes

       Move multiple nodes to the same position.

  • Equalize

       Arrange nodes on selected edges evenly.

  • Scale

       Scale the selected node group while maintaining the ratio between nodes.

    • Smoothing

  • Refine Quality

       Smooth on the basis of element quality.

  • Laplacian

       Smooth referring to surrounding nodes and element centers.
