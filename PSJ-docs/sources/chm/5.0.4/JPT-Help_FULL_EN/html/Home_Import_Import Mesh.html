Import Mesh

This command is used to import mesh data into Jupiter.

  • Nastran BDF

    •    Import Nastran data (.bdf/.dat/.nas).

  • Ansys Dat

    •    Import Ansys data (.dat/.cdb).

  • ADVC ADX

    •    Import ADVC data (.adx).

  • Abaqus INP

    •    Import Abaqus data (.inp).

  • LS DYNA

    •    Import LS DYNA data (.k/.dyn).

  • TSV-Pre

    •    Import TSV-Pre data (.vdb).

  • Universal

    •    Import Universal data (.unv).
