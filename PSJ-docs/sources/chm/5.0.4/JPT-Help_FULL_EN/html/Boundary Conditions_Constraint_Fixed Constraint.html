Fixed Constraint

Create fixed constraint conditions to be used in the analysis model.

　　

Structural

  • Name

       Enter the name of the fixed constraint conditions to be created.

  • Coordinate

       Select an existing coordinate system from the pull-down menu to bound degrees of freedom.

    • Fixed Component

     Select the direction of freedom to restraint from the check box.
  • Translation X

       Check constraints with the translational movement in the X direction.

  • Translation Y

       Check constraints with the translational movement in the Y direction.

  • Translation Z

       Check constraints with the translational movement in the Z direction.

    • Fixed Component

  • Rotate X

       Check constraints with the rotational movement around the X axis.

  • Rotate Y

       Check constraints with the rotational movement around the Y axis.

  • Rotate Z

       Check constraints with the rotational movement around the Z axis.

    • Tables

  • Select Table

       Defined in the Field Data. Currently not supported.

    • Other Function

      You can set the other functions.
  • Type

       Select the Option.

    • SUPPORT : The SUPPORT card of Nastran is defined in the Node.
    • USET : The USET card of Nastran is defined in Node.
      •
  • Set Name

       When USET is selected. SET name is selected from U1 ~ U6.

    • Abaqus Option

     This is the setting for ABAQUS IF.
  • Fixed

       Retention of the amount of deformation of previous step.

    • - Operating Procedure -

    1.  Press the Face, Edge or Node button and select the constraint target object from the screen.
    2.  Enter the name of constraint to be created.
    3.  Select the coordinate system to be referenced by the Node, from the coordinate system menu.
    4.  Check the translation direction and the direction of rotation of degrees of freedom, to constraint the displacement.
    5.  Press the Apply or OK button.
