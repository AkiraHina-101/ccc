Offset Line

Create an offset for the edges that make up a face.

Options

  • Method

    •    Select a method to specify the offset line.

    • Both sides : Create offset lines on both sides of the selected edge.
    • One side : Create an offset line only on one side of the selected edge.
      •
  • Auto Preview

    •    If checked, the preview of the offset line created at any time on the selected edge face will be displayed and updated.

  • Break Face

    •    Break the face.

  • Extend

    •    Extend the offset edge to the border edge.

  • Merge

    •    Connect the edges at the intersection if the offset edges intersect.

    Parameter

  • Layer Method

    •    Specify how to create offset edges.

    • Distance with number : Edges are created by using the offset distance interval and the number of offset edges.
    • Layer with number : Edges are created by using the layer offset distance.
      •
  • Offset (Distance)

    •    Enter the movement distance of the selected edge.

  • Layer Number

    •    Enter the number of edges to create at one time.

  • Layer Offset (Distance)

    •    Enter the movement distance of the selected edge for the number of edges to be created at one time.


    - Operation Procedure (Distance with number) -

    1.  Press the edge or face button and select the edge to imprint from and the face to be imprinted from the screen. You can select multiple edges and faces.
    2.  Set the options as required.
    3.  Specify the distance and the number of layers as the layer creation method.
    4.  Enter the distance to move the edge in Offset (distance).
    5.  Change the number of layers as needed.
    6.  Click the Apply / OK button.

    - Operation Procedure (Layer with number) -

    1.  Press the edge or face button and select the edge to imprint from and the face to be imprinted from the screen. You can select multiple edges and faces.
    2.  Set the options as required.
    3.  Specify a layer width sequence as the layer creation method.
    4.  Enter the distance to move the edge to the layer offset (distance) in number sequence. Example: 1, 1, 2
    5.  Click the Apply / OK button.
