Temperature Loads | Whole Mapping

This command maps temperature results of the Heat Transfer analysis from Nastran, ADVC (format2), ABAQUS, and CSV to the whole model as Temperature Loads.

Name

  • Name

    Set the Temperature Load name.

    • Value

  • Result Type

    Select the format of the Temperature results file.

  • Mapping Result Selection

    Locate the Temperature results file.

  • Step(Subcase) in Result

    Specify the ID of the step (subcase) that contains the temperature results.

  • Input Unit

    Specify the input unit of temperature result values.

    • Preview

  • Mapping data Preview

    Show the preview of mapping data on selected part(s) same as original result data.

  • Clear

    Remove the mapping data in preview.

  • Result Preview

    Show the preview of mapping results on selected part(s).

  • Clear

    Remove the mapping results in preview.

    • Mapping Option

  • Method

    Select the mapping method.

    • Nearest : Use the result of the nearest node.
      •

    • Output Mapped Results

  • Browse

    Locate a destination to output the mapped file.

    • - Operating Procedure -

    1. Select the parts to apply the Temperature Load. Multiple selections are accepted.
    2. From Result Type, select the format of the Temperature results file.
    3. Locate the Temperature Load file by pressing the Browse button.
    4. Select a method used for mapping from Method.
    5. Click the Mapping data Preview or Result Preview button to show the mapping data or mapping results in preview as needed. Click Clear button to remove the preview.
    6. Change other parameters as needed.
    7. Click Apply/OK button.
