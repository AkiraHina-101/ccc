Cylinder Layer Dialog box

Create a cylindrical surface that is offset to the cylindrical surface inside of the cylindrical body.

Cylinder Layer

Select the node that determines the face and the length including the extension you want for the edge.
Edges are extended to nodal position selected in the normal direction of the cylindrical surface.
There are no options.

- Operating Procedure -

  1.  Select the node to specify the distance to extend the cylindrical surface and the circle edge, including the circle edge to be executed from the screen.
  2.  Click the Apply or OK button to execute the operation.
