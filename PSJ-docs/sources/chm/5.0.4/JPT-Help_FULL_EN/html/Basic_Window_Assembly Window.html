Assembly Window

The Assembly window shows geometries and mesh models displayed in the Main window as a tree structure. If the imported CAD data includes a sub-tree, the sub-tree is displayed as a sub-assembly.

Tree View

The assembly/part structure and boundary constraint condition/property settings are displayed in a tree format.
Boundary constraint condition/property settings are added as a sub-tree of the whole model and also as a sub-tree of the defined parts.
Click each tree item with the left mouse button to focus on that item. The settings of the selected item will be displayed in the Property view.

  • By clicking on an item and highlighting it, the entity you are configuring is now previewed on the main window.
  • The command window when creating an item now opens in edit mode by double-clicking the item.
  • When the command dialog is launched in edit mode, highlighting another tree item with mouse click or arrow keys now switches to the command window (edit mode) of the highlighted item.

  • Property view

    • You can change the color, hide or show details of the focused tree item in the tree view.

    • When viewing All Parts: number of parts, number of nodes, number of elements, number of configuration entities, file information (Jupiter version that created the file) etc. FEM element column shows the number of elements for which material properties have been set. Jupiter element items column shows the number of all elements.
    • When viewing a part item: ID, number of nodes, number of elements, number of configuration entities, information of mesh size, etc.
    • When viewing a boundary condition item: Content of each boundary condition setting.
      • In order to change the boundary condition setting, right click the tree view item to select the Edit command from the shortcut menu.

    • Surface
      Colors: Change the color of the surface faces, mesh lines and edges of the focused part and the transparency of the part.
      Show/Hide: Toggle between showing and hiding faces, mesh lines and edges of the focused part.
    • Section
      Colors: Change the colour of surface faces, mesh lines and edges of the section.
      Show/Hide: Enable/disable the display/hiding of cross sections, capping, section edges, section elements and mesh lines.
      Note 1) This option can be applied when the section ribbon option is activated.
      Note 2) Contour is only applicable when using Post mode.
