Solid Meshing

Create a tetrahedral solid elements.

Mesh Type

  • TET4

       Create a primary tetrahedron element.

  • TET10

       Create a secondary tetrahedral elements.

    • Attributes

  • Grading Factor

       Enter the values of the elements for grading.

  • Stretch Limit

       Specify the limit values for the elements stretch when creating a mesh.

  • Speed Vs Qual

       Set the speed versus quality.

    • Fastest : Priority for mesh generation speed.

    • Optimized : Give priority to mesh quality.
      •
  • Speed Vs Mem

       The setting of speed versus memory usage.

    • Standard : Priority for mesh generation speed.

    • Low Memory : Give priority to the reduction of memory usage.
      •
  • Region

       Set the creation of solid elements into the open space within the part.

    • Main Region : Create the solid elements in only the main area of part.

    • All Region : Create solid element to all the area of the part.
      •
  • Internal Node

       Create a node in internal parts. When turned off, creates the solid element using for nodes on the surface.

  • SafeMode

       If you have created very small element, it can be improved by putting the check.

  • Parallel Meshing

       Configure the settings for parallel processing. Parallelization is done by assigning a Core to every body.

    • 1～32Cores : Core number 1 ~ 32 ?The default is to refer the number of Core which are mounted on the machine.
      •

    • ForceClean

  • Surface Nodes

       It may slightly move the surface node to ensure the element quality.

  • Edge Nodes

       It may slightly move the edge node to ensure the element quality.

  • Preservation

       Ignore the Preserve, if you want to move the node.

  • Internal Mesh Only

       When you use auto-correct at the time of solid elements creation, it makes corrections only for internal elements without changing the surface element.

    • Options

  • Mesh Color

       You can choose the color of the parts after creating the solid mesh.

    • - Operating Procedure -

    1.  Select the Mesh Type.
    2.  Select the parts for target.
    3.  Click Apply / OK button.
