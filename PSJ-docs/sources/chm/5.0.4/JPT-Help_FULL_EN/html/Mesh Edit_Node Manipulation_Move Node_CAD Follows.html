CAD Follows

By dragging a node, you can move it to any position on the face. In addition, it also displays element quality for the node you are dragging.
To have the position with the best element quality, you can also move automatically.

Position

  • X, Y, Z

    Display the coordinates of the nodal point you are dragging.

    • Element Quality

  • Metric

    Specify the evaluation type for elements quality
    For more information about the element quality, see the Mesh Clean up> Mesh Quality> Auto Check / Manual Check.

    • Stretch

      Check the stretch for Tri/Quad/Tet/Hex element.

    • Aspect Ratio

      Check the aspect ratio for Tri/Quad/Tet/Hex element.

    • Warping

      For the Quad element, divide the quadrilateral elements into two triangles, and then check the maximum value of the angle that occurs between them.

    • Skewness

      For the Quad element, check angle of the two line connecting the midpoint of the opposite sides.

    • Edge Length

      For the Tri / Quad / Tet / Hex element, check the element edge length.

    • Area

      For the Tri / Quad element, check the element area.

    • Node Valence

      For the Tri / Quad element, for a particular node, check the number of elements containing the node.

    • Interior angle

      For the Tri / Quad element, check the lowest value among the angle between the elements Edge around the node.

    • Taper

      For the Quad element, check the Maximum difference between the average value of the triangular area that connects the 3 nodes in the quadrilateral element.

  • Applied Elements

    Specify the element type for applying the element quality specified in Metric

  • Auto

    To have the position with the best element quality, move automatically.

    • - Operating Procedure (manual movement to arbitrary position) -

    1.  Specify the type of element quality to evaluate in the Metric.
    2.  Drag one of the nodes.
    3.  Click Apply / OK button.

    - Operating Procedure (automatic movement to the optimum element quality position) -

    1.  Specify the type of element quality to evaluate in the Metric.
    2.  Drag one of the nodes.
    3.  Click the Auto button.
