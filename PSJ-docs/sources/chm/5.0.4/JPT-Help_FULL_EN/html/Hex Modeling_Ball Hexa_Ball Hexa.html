Ball Hexa

This command is used to create a true sphere using Hexa 8 node elemenets.

Ball Hexa

  • Part Name

    Enter the name of the part to be created.

  • Type

    Hexa：Creates the sphere using Hexa elements only including the center of the sphere.
    Hexa+Tetra：Creates the sphere using Hexa elements for the specified layers of the outer shell and tetra elements for the center.

  • Center X, Center Y, Center Z

    Enter the coordinate values for the sphere center.

  • Radius

    Enter the radius value of the sphere.

  • Mesh Size

    Specify the mesh size.
    ※The minimum mesh size is limited to 5% of the radius.

  • Make Center Node

    Select this checkbox to position a node at the center of the sphere.

    • ※When an existing body is selected, values are automatically entered in the Center X/Y/Z、Radius、Mesh Size fields.
    Cancel the part selection in order to change the value.

    - Operating Procedure -

    1.  Enter the name of the mesh part to be created.
    2.  Select the Hexa or Hexa+Tetra mesh type.
    3.  Select a spherical part in the model or enter the center position, radius or mesh size.
    4.  In case the Hexa+Tetra type is selected, enter the number of layers.
    5.  Select the checkbox in order to position a node at the center of the mesh part.
    6.  Click the Apply/OK button.
