Force | Function Load to Cylinder (Quadratic)

Define the force load on selected faces, edges or nodes based on the distribution of the quadratic function.

　　

Structural Force

  • Name

    Enter the name of the force load condition.

    • 　　

    Quadratic Curve  y=ax²+b

    Define the quadratic curve.

  • Total Force

    Enter the total value of the force load.

  • Input Unit

    Specify the unit system for the force load value.

  • a

    Define a of the quadratic function.

  • b

    Define b of the quadratic function.

  • Co.System for load

    Select the coordinate system for defining the angle of the load application range.

  • Angle Range

    Enter the angle from the Y axis on the coordinate syste XY plane used to specify the load application range.
    The load application range is angle 0 - PI and is entered within the range of 0°< angle < 90°.

  • Input Unit

    Specify the unit system for input.

    • 　　

    Options

  • Arrow Direction

    Specify the vector direction.

    • 　
    • Start at Node: Display the vector arrow starting at the node.
    • End at Node: Display the vector arrow ending at the node.

    The force based on the fuction is applied on surfaces included in the load application range.
    The depth direction is fixed. The total load is the sum of the load values of all nodes in the load application range.
    The force load is applied in the -Y direction of the specified coordinate system, using the origin of the specified coordinate system as the central position.
    The force load distribution ratio is calculated for x in the function equation using the Z coordinate value of the node in the specified coordinate system.

    - Operating Procedure -

    1.  Select the target face(s), edge(s) or node(s) of the force load from the selection list or screen. (Multiple targets can be selected.)
    2.  Enter the name of the load.
    3.  Enter the sum of all load values as the total load value.
    4.  Enter values for a and b in the quadratic function equation.
    5.  Specify the coordinate system and angle for the load application range of the quadratic function.
    6.  Select the display direction of the arrow as necessary.
    7.  Click the Apply or OK button.
