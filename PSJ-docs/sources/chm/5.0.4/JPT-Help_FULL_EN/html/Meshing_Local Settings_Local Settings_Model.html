Local Settings Model

Set the mesh size for the whole model faces in the specified space

Mesh Parameters

  • Name

    Set the mesh control name.

    Space Meshing

  • Average

    Set the average size of the element

  • Minimum

    Set the minimum size of the element.

  • Maximum

    Set the maximum size of the element.

  • Body Type

    Specify the spatial shape.

    • Cube

      Specify the origin position and the length in each axis direction to select the entities in rectangular space.

    • Spheroid

      Specify the origin position, Major Point and Minor Point in each axis direction to select the entities in spheroid space.

      •
  • Enclose

    Selects the faces that are completely covered by space shape.

    • Preview

  • Preview

    Preview the spatial shape by selecting the user desired color for spatial shape and face.

  • Reset

    Reset the preview.

    • Curve Meshing

  • Curve Meshing

       Turn on the curve meshing and specify angle to divide the fillet part.

  • Maximum Element Angle (Degrees)

       Set the division angle.

  • Minimum Element Size

       Set the element minimum size of the fillet part.

    • *The minimum mesh size must be set below this size.

    -   Operating Procedure   -

    1.  Enter each item of mesh size.
    2.  Select the spatial shape from the part type, enter the parameters and click the preview button.
    3.  The faces overlapping with the spatial shape are displayed in preview color.
    4.  Click on enclosed check-in box to Select the faces that are completely covered by space shape.
    5.  Click the Apply / OK button.
