Connector | Face to Face

Create a connector element between the two faces.

Connection

　　
  • Name 　　

    　 Set the name of the connector element to be created.

    　　

    • Connection Type

    　　
  • Type 　　

    Define a connection type.

    　　
    • 　　
    Effective axis number Constraint axis number
    Parallel 0 None
    Translation 0 , 1 , 2 None
    Rotation 3 , 4 , 5 None
    Bushing 0 , 1 , 2 , 3 , 4 , 5 None
    Cylindrical 0 , 3 1 , 2 , 4 , 5
    Joint None 0 , 1 , 2
    RigidRod None 0
    RigidBar None 0 , 1 , 2 , 3 , 4 , 5
    　　
  • Coordinate System 　　

    Define the direction of the characteristic. 　　

    • ・ Global　:　Define the direction in the global coordinate system.
    ・ Elm　　 :　Define from 2 nodes.

    　　
  • Reference Node 　　

    Specify a node to refer to when determining the coordinate system. 　　

    • ・ 0　：　Reference the first node.
    ・ 1　：　Reference the second node.

    　　
  • Elasticity 0 　　

    　 Set table data of elastic property.

    　　
    • 　　
  • Damping 0 　　

    　Set table data of viscosity characteristics.

    　　
    • 　　

    ※Table data for each characteristic is created with the Field Data command.
    ・ Elastic property table type: Displacement, Force
    ・ Viscosity characteristic table type: Velocity, Force

    - Operating Procedure -

    1.  Create table data from Boundary condition > Field data.
    2.  Click Connection > Connector > Face to Face.
    3.  Specify each connection type.
    4.  Open the selection list and select the master and slave faces respectively.
    5.  Click the Apply / OK button.

      6. Supplement: You can select the degree of freedom specified in [Type]. By setting “Translation”, input in three directions of translation is possible. (If there is only the X axis, there is no problem with keeping the default.)
