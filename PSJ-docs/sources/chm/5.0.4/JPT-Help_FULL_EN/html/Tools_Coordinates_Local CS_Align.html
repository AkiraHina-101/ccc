Local CS [Align]

Edges, Element edges and two nodes are selected from the screen to form the axis of coordinate system.

　　

Coordinate

  • Type

       Choose the Type of the coordinate system.

    • Rectangular : Select the Cartesian coordinate system.
    • Cylindrical : Select the cylindrical coordinate system.
    • Spherical : Select a spherical coordinate system.

  • Name

       Enter the name of the coordinate system to be created.

    • CD Axis

  • Coordinate

       Select the coordinate system axis direction as a reference to align

    • X : Referenced to the X-axis direction of the reference coordinate system.
    • Y : Referenced to the Y-axis direction of the reference coordinate system.
    • Z : Referenced to the Z-axis direction of the reference coordinate system.

  • Create New

       Choose to create a new coordinate system.


    • - Operating Procedure -

    1.  Select the type of the coordinate system from the Type.
    2.  Enter the name of the coordinate system to be created.
    3.  Select the coordinate and the coordinate system axis direction as a reference to align.
    4.  Press the Element Edge button and select the entity Edge or Node to orient in the direction for alignment. In case of node, two points are required.
    5.  Press the coordinate button for selection list, select the coordinate system of the subject to align.
    6.  If you want to create a new coordinate system, check the Create New box.
    7.  Press the Apply or OK button.
