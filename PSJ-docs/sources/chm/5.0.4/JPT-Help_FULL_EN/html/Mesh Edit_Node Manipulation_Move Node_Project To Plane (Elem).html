Move Node | Project to Plane (Element)

Project the selected nodes or floating points at the shortest distance onto the plane defined by the element.
The selected node or floating point is moved to the projected position.


- Operating Procedure -

  1.  Select one element to define the plane to project.
  2.  Select the node or floating point to move. (You can select more than one)
  3.  Click the Apply / OK button.
