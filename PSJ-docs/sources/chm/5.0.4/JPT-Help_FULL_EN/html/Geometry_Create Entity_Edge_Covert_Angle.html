Angle

Change the selected edge automatically to the adjacent element edge within a specified angle from the selected element edge.
While checking the preview, you can change the direction of the automatic selection by selecting an element edge.

Options

  • Break Face

    When this option is checked, the face will split where possible after creating an edge.

  • Angle

    Specify the angle.

  • Curvature Mode

    The angle from two elements edge is calculated to automatically select an element edge in a circle.

  • Element Edges

    Selected element edges will be displayed.

    • - Operating Procedure -

    1.  Select the element edge.
    2.  Click Apply / OK button.
