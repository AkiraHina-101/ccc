Create Node

Create a node or floating node.



  • Absolute

       Create a node or floating node at any position.

  • Offset

       Create a node or floating node at the position where the selected node is copied in the specified direction.

  • Node

       Create a floating node at the selected node position.
  • Point

       Create a floating node at any point you pick.
  • Between 2 Nodes

       Create at an intermediate position between the two selected nodes.

  • Between 3 Nodes

       Create at the center of the circle defined by the three selected nodes.
  • Circle Center

       Create at the center of the circle defined by the selected arc edge.

  • Import

       Load node data from file and create it.

  • Project to Line

       Project any floating point on a straight line.

  • Project To Plane

       Project any node on the Face.

  • Center of Cylinder

       Create a floating node at the center of the selected cylindrical shape.
  • Center of Sphere

       Create a floating node at the center of the selected sphere shape.
  • Intersection Node

       Create a floating node at the intersection of a part or face with a line segment defined by the two selected nodes or edges.
