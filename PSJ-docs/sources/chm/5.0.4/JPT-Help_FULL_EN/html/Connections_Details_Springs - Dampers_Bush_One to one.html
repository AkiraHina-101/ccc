One to one (Nodes with tolerance)

This command is used to automatically create Bush elements (Generalized Spring - Damper) between the selected nodes within an specified tolerance.

Connection

　　
  • Name

    • Specify the name for the bush element to be created.

    　　
  • Tolerance

    • Specify the search range of the connection point.

    Bush

    　　
  • Grounded

    • Select this checkbox to define one end as grounded (spring).

    　　
  • Orientation By

    • Select the method for defining the orientation for bush elements.

      　　
    • Orientation vector
      • Specify the orientation by a direction vector. 　　
    • Coordinate System
      • Specify the orientation by a coordinate system.
    　　
  • Coordinate System

    • Select an exsting coordinate system from the list in case the orientation is defined by the coordinate system.

    　　
  • Orientation Vector

    • Enter the direction vector in the X, Y, Z order using comma separations in case the orientation is defined by an orienation vector.

    　　
  • Stiffness 1～6

    • Enter the stiffness value for each DOF.

    　　
  • Input Unit

    • Select the unit system for entering the stiffness value.

    　　
  • Damping Coef 1～6

    • Specify the damping coefficient for each DOF.

    　　
  • Input unit

    • Select the unit system for entering the damping coefficient value.

    　　
  • Damping Coef 1～6

    • Specify the structural damping coefficient for each DOF.

    　　
  • Local unit

    • Select the unit system for entering the structural damping coefficient value.

    　　
  • Stress Recovery Translation

    • Specify the stress recovery coefficient for translational components.

    　　
  • Stress Recovery Rotation

    • Specify the stress recovery coefficient for rotational components.

    　　
  • Strain Recovery Translation

    • Specify the strain recovery coefficient for translational components.

    　　
  • Strain Recovery Rotation

    • Specify the strain recovery coefficient for rotational components.

    - Operating Procedure -

      　　　
    1.  Select multiple nodes from the Main window.
      2. 　　　 　　　
    2.  Select the specification method of the direction vector.Enter the direction vector according to the selected specification method.
      3. 　　　
    3.  Enter the stiffness, damping, structural damping, recovery coefficient values in the respective fields.
      4. 　　　
    4.  Click the Apply/OK button to create bush elements between nodes.
