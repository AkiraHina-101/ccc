Generate hexa meshing for parts which already have thickness (Material property for shell).

- Operating Procedure -

  1.  Set material property: 2D-Shell Property with thickness for part.
  2.  Select the parts which already have material property.

    3. ※Note: You can use this function for several parts, but the parts which have been selected must have material property with thickness.
  3.  Click the Apply or OK button to generate hexa meshing.
