Change Pattern

Change the mesh pattern of the selected faces.

Entity Type

  • Change Pattern Type

    When you select Standard, it changes to the standard map mesh.

    When you select the Union Jack, it changes to the mesh pattern of Union Jack.

    • - Operating Procedure -

    1.  Select the face.
    2.  Select the mesh pattern in the Change Pattern Type.
    3.  Function in the Apply or OK button is executed.
