Rotation

Rotate the selected part.

Operation

  • Create New Part

    •    Copy the part after the parallel move, as a new Part.

  • LBC Copy

    •    Also copy load constraints that were added to the existing part to a new part.

  • Copy Count

    •    Enter the number of repetitions of the copy.

    Rotation

  • Coordinate System

    •    Select the coordinate system to reference.

  • Rotation Axis

    •    Select the axis of rotation.

    • X Axis : Rotate around the X-axis of the selected coordinate system.
    • Y Axis : Rotate around the Y-axis of the selected coordinate system.
    • Z Axis : Rotate around the Z-axis of the selected coordinate system.
    • Arbitrary Axis : To rotate for a specified angle value, about an axis that is specified in the X, Y, Z direction Vector.
    • 2 Nodes : To rotate for a specified angle value, about the axis of the two Node directions selected from the screen.
    • Edge : To rotate for a specified angle value, around the axis of the Edge direction that has been selected from the screen.
      •

  • Axis-X

    •    Enter the X coordinate of the rotation center location.

  • Axis-Y

    •    Enter the Y coordinate of the rotation center location.

  • Axis-Z

    •    Enter the Z-coordinate of the rotation center position.

  • Center

    •    Decide the position of the center of rotation.

    • Part Center : To define the center of the Part as the center of rotation.
    • Node : To define the selected node from the screen as the center of rotation.
    • Input : Enter the center of rotation in Center Global-X, Center Global-Y, the Center Global-Z. These are set in Global Coordinate.
      •

  • Rotation Angle

    •    Enter the rotation angle.

  • Merge Nodes

    •    If checked, Face for rotate that are copied as the body in the model will have the nodes joined in the case where there is contact of the Face with copy source for body.

  • Merge Tol.

    •    Enter the Tolerance of the coupling for Merge Node.


    - Operating Procedure -

    1.  If you want to create a new Part after the rotation, select the Create New Part.
    2.  Turn on the LBC Copy to copy a load restraint conditions of the existing part to the new part.
    3.  To repeat copy, enter the number of copies.
    4.  Press the Part button and select the Part for rotation from the screen.
    5.  If you want to rotate around the existing coordinate system axis, select an existing coordinate system from the Coordinate System and select one of the Rotation Axis from the X-axis, Y-axis, Z-axis.
    6.  To rotate in arbitrary direction, select the Arbitrary Axis from Rotation Axis and enter the direction vector to X, Y, Z input box.
    7.  To rotate around the selected 2 Node direction, select the 2 Nodes from Rotation Axis, and then select the two Node from the screen.
    8.  To rotate around the selected Edge direction, select the Edge from Rotation Axis, and then select the Edge from the screen.
    9.  For the rotation around the center of the Part, select the Part Center from Center.
    10.  For the center of the Part as the Node position, select the Node from the Center, you pick the Node from the screen.
    11.  To direct input the center of the Part, select the Input from the Center, enter the center of rotation in the Center Global-X, Center Global-Y, Center Global-Z in global coordinate.
    12.  Enter the angle of rotation in the rotation angle.
    13.  To Merge original Part and the Nodes after the copy, check the Merge Nodes, enter the Merge Tol. for the coupling tolerance.
    14.  Press the Apply or OK button.
