Linear

Create a solid mesh by sweeping in the parallel direction from surface meshes (Tri and Quad mesh).

Linear Parameters

  • Length

    Enter the length to sweep.

  • No. of Layers

    Enter the number of layers.

  • Direction

    Select the direction for the sweep from the pull-down
    Plane Normal ：Perpendicular to the selected element
    Arbitrary ：Arbitrary direction of the vector you entered X,Y,Z :X, Y, Z direction of the vector
    X,Y,Z ：X, Y, Z direction of the vector
    Node,ElemEdge ：Element edges showing the direction and node serving as a reference
    Face to Face ：Between the face (Quad4 pattern for mesh must be the same)
    Dir X,Y,Z ：Direction vector X, Y, Z

    • Auto Interface Penta5/Tet4

  • Interface Elems

    If you check, it creates a penta element to the boundary surface.

    • Auto Delete Original Parts

  • Delete Original (Source) Part

    When a check is put in, the original (sweep source) part is deleted automatically. Delete the shape of the tip (direction / face-face)

    ※If you select and execute an entity that contains secondary elements, a warning will be displayed.
    Convert to primary element and execute.

    • - Operating Procedure -

    1.  Select the surface to sweep.
    2.  Specify the length of the sweep.
    3.  Specify the number of layers.
    4.  Specify the direction of the sweep.
    5.  Click the Apply or OK button.
