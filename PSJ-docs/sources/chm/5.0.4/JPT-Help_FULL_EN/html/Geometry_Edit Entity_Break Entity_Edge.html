Break Edge

  • Auto By Angle

    When checked ON, it automatically divides the edge for the specified angle for the selected nodes.

  • Angle

    Angle [deg]

    • - Operating Procedure (Node position split) -

    1.  Select the node location for division.
    2.  Click Apply / OK button.

    - Operating Procedure (Angle division) -

    1.  Click the Auto by Angle.
    2.  Enter the number specified in the Angle.
    3.  Select the part to be split.
    4.  Click Apply / OK button.
