Mass [Manual]

Measure the mass of the Solid Part. In this case, Mass is calculated based on the selected material or set density by manual.

　　

Measure

  • Coordinate System

       Reference coordinate system.

    • Input

  • Density

       Mass density.

    • Output

  • Value

       Measurement result (mass) is displayed.

    • Gravity Center

  • X/Y/Z

       Specify the position of the centre of gravity in the reference coordinate system.

    • Moment of Inertia

  • Axis
    • Principal : Using the principal axis of inertia for the moment of inertia calculation.
      • 11,22,33 : The value of the principal moments of inertia
      • Rotation Angle : Rotation angle of the main axis
      • 1/2/3  X,Y,Z : Direction of each of the principal axis of inertia (centre of gravity coordinate is 0)

    • XYZ : Using the reference coordinate system for the moment of inertia calculation.
      • XX/YY/ZZ/XY/XZ/YZ : The value of the moment of inertia around the reference coordinate system

    - Operating Procedure -

    1.  Select the solid parts from the screen.
    2.  Enter the mass density(select the material from material library).
    3.  Total value of mass of the selected part is displayed.
