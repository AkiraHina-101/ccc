Import

Read the node data from a CSV file or BDF files. From the loaded node data, Create a floating node that does not belong to the part.
＊The CSV file means the file of the CSV type with which X ,Y and Z [Enter] is described.
＊BDF file means the file of Nastran BDF format and TSV Geometry BDF format.

- Operating Procedure -

  1.  Select the extension in the file selection window.
  2.  Select the file you want to import and click the OK button.
  3.  Click the OK / Cancel button on the confirmation screen.
