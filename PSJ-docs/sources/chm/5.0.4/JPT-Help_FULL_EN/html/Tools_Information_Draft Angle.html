Draft Angle

This function allows you to check the draft angle (*1) of the mesh of the mold model.
By checking the inverse slope of the surface mesh with this function, it is possible to modify the mesh model using the re-mesh function, etc., before analysis with sliding.
The draft angle is calculated for all surface meshes of the selected part.

*1) Draft angle [deg]: The angle defined by two axes - The normal vector of the surface mesh and the arbitrarily specified draft direction.

In addition to the contour view, you can create nodal groups (Draft_Angle) for each surface error.

Selection List

Part: Part to be measured (Reference parts cannot be selected)

Draft Direction

  • X, Y, Z

    Enter the direction vector of the draft.

    • Contour

  • Num. Digit

    The number of decimal places of the error distance to be displayed.

  • Num. Division

    The number of contour divisions.

  • Max/Min

    The maximum and minimum value of the contour.

  • Show/Hide

    Switch to show and hide the contour (or can use to update).

    • Group

  • Num. Digit

    The number of decimal places of the draft angle to be created for the group.

  • Max/Min

    The maximum and minimum value of the draft angle to be created in a group.

  • Create Group

    Create (or update) nodal groups in a dedicated group tree.

    • - Operating Procedure (Draft Angle Calculation) -

    1. Select a Part.

    2. Enter the direction of the draft.

    3. Click the "Apply" button.

    4. Calculate the draft angle of the surface mesh in memory.

    5. Show/Hide and Create Group buttons will be enabled.

    - Operating Procedure (Contour Display * Possible after the draft angle calculation) -

    1. Enter the contour parameters.

    2. Click Show/Hide.

    3. The contour is shown/hidden (updated).

    - Operating Procedure (Nodal Group Creation * Possible after draft angle calculation) -

    1. Enter the parameters of the group.

    2. Click Create Group.

    3. The nodal groups for each draft angle are created (and updated).
