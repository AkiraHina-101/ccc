Contacts | ADVC - Contact Clearance

Use only if you want to define a different clearance for each node on the slave surface. In the case of constant slave surface clearance, specify in Clearance of contact definition.

    • - Operating Procedure -

      　　　
    1.  Select the nodes on the slave surface.
      2. 　　　
    2.  Specify the Clearance amount.
      3. 　　　
    3.  Click the Apply or OK button.
      4. 　　　
    4.  Click the Clearance Selection of the Add / Remove button on the contact setting. (Contacts > ADVC > Manual Group, etc.)
      5. The slave node clearance definition appears in the Contact Clearances.
      　　　
    5.  Select the required clearance value and click the Add button to assign the gap amount to slave nodes of the contact pair.
