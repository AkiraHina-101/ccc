Export VTFX File

Export Geometry information or Geometry and Result information for the active document in Web Viewer format(*.vtfx).

Path Settings

  • Model Name

    •    Input file name to export the data. If the text box is blank, show an error message and cancel the execution.

  • Output Folder Path

    •    Input path to export the data. If the text box is blank, show an error message and cancel the execution.

    Options

  • Model Type

    •    Select an exporting model type.

    • Pre

      Export only Geometry.

    • Post

      Export Geometry and selected result.

      •
  • Exclude bar part

    •    Bar parts (parts that contain only Edge) will not be exported if checked on.

  • Export Surface Data Only

    •    3D element will not be exported if checked on. Moreover, results on 3D elements will not be exported.

  • Export data position control button

    •    This button displays when Model Type is Post. After clicking this button, the below dialog will open. Select result position of 2D shell on it.

    2D Element Data

  • Top / Bottom / Average

    •    Select position.

  • Data Location

    •    When there are 2 position about data location you can select it from pull down menu.

    Result Selection list

       This list displays when Model Type is Post. Here is same information as Result Tree on Result window, and export checked results.

       Display following two context menu when right click on the tree.

  • Select result of all steps

    •    Select that result in all other timesteps.

  • Unselect result of all steps

    •    Deselect that result in all other timesteps.

    - 操作手順(Model Type : Pre) -

    1.  Input Model Name and Output Folder Path.
    2.  Select Pre on Model Type.
    3.  Check on options if you need.
    4.  Click Apply or OK button.

    - 操作手順(Model Type : Post) -

    1.  Input Model Name and Output Folder Path.
    2.  Select Post on Model Type.
    3.  Check on options if you need.
    4.  If you have result for 2D shell, you can select result position of it by opening Data Position Control dialog from Export data position control button.
    5.  Check on results you want to export.
    6.  Click Apply or OK button.

    - Note -

    1.  This command doesn't export Solid Principal Stress. Although Solid Principal Stress is the result as which Jupiter displayes 2 vectors of Max Principal Stress and Min Principal Stress, Web Viewer V1.1 doesn't support it. After Web Viewer can support it, Jupiter will update for exporting Solid Principal Stress.
    2.  Export Solid Tresca when check ON a check box of Preference > Save/Load > Post > Tresca Stress option.
