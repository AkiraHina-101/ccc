Morphing | One Node


Perform mesh deformation (morphing). While moving the selected node, move smoothly the nodes within the specified range from the selected node.
It is used when changing the board thickness.

※After the morphing function is executed, the mesh is trimmed with the partial remeshing function.

Parameters

  • Strong Effect Distance

       Specify the range that is strongly affected by the movement of the selected entity as a distance. The nodes included in this range are moved by the distance specified by Move Distance.

  • Weak Effect Distance

       Specify the range affected by the movement of the selected entity as a distance. The amount of movement of the nodes included in this distance range is 0 < Movement Amount < Movement Distance, and decreases as the distance from the selected entity increases.

  • Effect Range

       Specify how to set the Strong Effect Distance / Weak Effect Distance.

    • Both Side Faces

      Center the selected entity and set it to be spherical. The effects of movement extend to all nodes in the model.

    • Selected Faces

      Set to follow the face connected to the selected entity.

      •
  • Direction Type

       Specify the movement type.

    • Offset Values

      Move in the specified direction.

    • Normal Offset

      Move in the direction perpendicular to the surface of the mesh.

      •

    ※In the case of 1 node and in the case of face, the moving direction of the corner part is different.

    Move Distance

  • Coordinates

       (Direction type: Normal Offset) Specify the amount of movement in the direction of each axis.

  • Move Distance

        (Direction type: Offset Values) Specify the movement amount.

    • Options

  • Show Influence Node

       Preview the moving node.

  • Show Preview

       The amount of movement of each node to be moved is previewed with an arrow.

    • - Operating Procedure -

    1.  Select a node on the screen. The Influence nodes are previewed.
    2.  Change the parameters to adjust the movement amount.
    3.  If you want to see the actual movement amount, turn on Show Preview.
    4.  Press the Apply or OK button to move the nodes.
