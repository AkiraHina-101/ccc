Solid Bolt Modeling | Size

Create a solid bolt from three different head types, specifying the size.
Check ON the Pretension Load checkbox to add a pretension setting.

Bolt Type

  • Bolt Type

    Selecting a type switches the image diagram.
    Refer to the image for each value. After entering a value, a preview of the bolt is displayed.

    • Setting

  • Solid Bolt Name

    Enter the name of the solid bolt to be created.

  • Seat Angle(deg)

    Enter the inclination angle of the bolt seating area.

    Angle=0Angle=5
  • Mesh Size

    Enter the mesh size.

    • Pretension

  • Solver Type

    Select the pretension settings for each solver.
    ※Only Sunshine is supported in V5.0.1

  • Value

    Enter the pretension force.

  • Input Unit

    Select the input unit system.

  • Distance from Seat

    Enter the distance from the seat portion to the point where the pretension is to be set.



    • - Operating Procedure -

    1. Select the solid bolt type.
    2. Enter the size of each dimension of the solid bolt.
    3. Enter the name of the solid bolt to be created.
    4. If the bolt seating area is sloped, enter the seating angle.
    5. Specify mesh size and pretension parameters.
    6. Click Apply or OK button.
