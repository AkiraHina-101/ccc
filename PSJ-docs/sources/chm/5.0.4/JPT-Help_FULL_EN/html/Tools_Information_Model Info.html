Model Info

Display the Information of the currently opened Model.

　　

Model Info

  • Part Info

       Display the following information of every part in the model:

    1.  Part Name
    2.  Part ID
    3.  Property Name
    4.  Property ID
    5.  Property Type
    6.  Material Name
    7.  Material ID
    8.  Material Type
  • Selected Part Info

       Display the number of nodes and elements of the selected part.

       Check ON Property Assigned to display only the number of nodes and elements belonging to selected part the has assigned property.

  • Model Summary

       Display the number of nodes and elements of the whole model.

       Check ON Property Assigned to display only the number of nodes and elements belonging to parts the have assigned properties.

  • LBC Count

       Display the number of all types of LBCs of the whole model.

  • Property Count

       Display the number of all types of properties of the whole model.


    • - Operating Procedure -

    1.  Open Model Info Dialog either by Tool > Information > Model Info or by Right Clicking on Model in Assemby Tree and clicking Model Info.
    2.  Choose Export to file to export the Model Info into a text file.
