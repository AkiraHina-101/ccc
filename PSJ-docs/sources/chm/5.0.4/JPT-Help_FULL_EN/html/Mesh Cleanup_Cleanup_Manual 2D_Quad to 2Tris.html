Quad to 2 Tris

Convert one quadrilateral elements into two triangular element.
When you move mouse over the element to preview, if there are multiple splitting patterns, you can split by confirming the change in the preview display of split pattern.

Settings

  • Auto Execution

    When checked, it will convert automatically when you select an element.

    • - Operating Procedure -

    1.  Turn on the Auto Execution check box.
    2.  For the elements that you want to convert into triangular elements, select the dividing line while displaying preview.
    3.  Convert selected simultaneously.
