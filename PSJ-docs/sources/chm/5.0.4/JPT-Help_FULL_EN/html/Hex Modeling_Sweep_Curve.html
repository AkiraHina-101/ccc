Sweep - Curve

Create solid mesh swept along the curve from surface meshes (Tri and Quad mesh).

Curve Parameters

  • Mesh Size

    Specify the element size to be created.

    • - Operating Procedure (Constant section) -

    1.  Select the surface to sweep.
    2.  Select the path.
    3.  Specify the element size.
    4.  Click the Apply or OK button.

    * If you select and run an entity that contains 2nd element, a warning will be displayed.
    Convert to primary element and execute.

    - Operating Procedure (Not a constant section) -

    1.  Select the surface to sweep.
    2.  Select the first path.
    3.  Select the second path.
    4.  Specify the element size.
    5.  Click the Apply or OK button.
