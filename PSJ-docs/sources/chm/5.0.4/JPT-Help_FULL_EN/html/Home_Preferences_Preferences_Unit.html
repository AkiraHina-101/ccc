Model Unit

  • Default Unit

    • Set the default unit system for Jupiter-Pre. All new documents will be created in this unit system.

  • Current Unit

    • Sets the unit system for the currently opened document.

  • Preset unit system

    • Load a preset for the unit system setting.

  • Base Unit Show

    • Click on the check-in box to display the basic unit system with scale display at the bottom of main window.

    Results Display Unit

  • Original Unit

    • The resulting values will be read in this unit system.

  • Current Unit

    • Sets the unit system for the currently opened document.

  • Preset unit system

    • Load a preset for the unit system setting.

    - Operating Procedure  -

    1. Select the target of the unit system setting from Default unit system/Current unit system.

    2. Specify the unit system individually from the pull-down menu for each unit item in the unit system table on the right. Alternatively, select a set of unit systems from the preset unit systems.

    3. Click the Apply or OK button to apply the changes.
