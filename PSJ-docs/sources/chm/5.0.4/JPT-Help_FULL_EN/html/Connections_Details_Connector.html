Connector

Create a connector element between 2 nodes / 2 edges / 2 faces.

Connection

　　
  • Name　・・・　Set the name of the connector element to be created.

    • Connection Type

    　　
  • Type　・・・　Define a connection type.

    • ・ Parallel　 　Effective axis number: 0
    ・ Translation　Effective axis number: 0 , 1, 2
    ・ Rotation　 　Effective axis number: 3 , 4, 5
    ・ Bushing　 　Effective axis number: 0 , 1, 2, 3, 4, 5
    ・ Cylindrical　Effective axis number: 0 , 3　　　　　　　Constraint axis number: 1,2,4,5
    ・ Joint　　　　　　　　　　　　　　　　　　　Constraint axis number: 0,1,2
    ・ RigidRod　　　　　　　　　　　　　　　　　Constraint axis number: 0
    ・ RigidBar　　　　　　　　　　　　　　　　　Constraint axis number: 0 , 1, 2, 3, 4, 5

    　　
  • Coordinate System　・・・　Define the direction of the characteristic.

    • ・ Global　:　Define the direction in the global coordinate system.
    ・ Elm　　 :　Define from 2 nodes.

    　　
  • Reference Node　・・・　Specify a node to refer to when determining the coordinate system.

    • ・ 0　：　Reference the first node.
    ・ 1　：　Reference the second node.

    　　
  • Elasticity 0　・・・　Set table data of elastic property.
    • 　　
  • Damping 0　・・・　Set table data of viscosity characteristics.

    • ※Table data for each characteristic is created with the Field Data command.
    ・ Elastic property table type: Displacement, Force
    ・ Viscosity characteristic table type: Velocity, Force

    - Operating Procedure -

      　　　
    1.  Create table data from Boundary condition > Field data.
      2. 　　　
    2.  Click Connection > Connector > Node to Node / Edge to Edge / Face to Face.
      3. 　　　
    3.  Specify each connection type.
      4. 　　　
    4.  Open the selection list and select the nodes / edges / faces that will be the master and slave.
      5. 　　　
    5.  Click the Apply / OK button.
      6. 　　　
      Supplement: You can select the degree of freedom specified in [Type]. By setting “Translation”, input in three directions of translation is possible.
      　　(If there is only the X axis, there is no problem with keeping the default.)
