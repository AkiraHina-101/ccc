Local CS [Face]

Create a coordinate system from the selected face and two nodes that forms an axis.

　　

Coordinate

  • Type

       Choose the Type of the coordinate system.

    • Rectangular : Select the Cartesian coordinate system.
    • Cylindrical : Select the cylindrical coordinate system.
    • Spherical : Select a spherical coordinate system.

  • Order

       Select the Entity in the order of for order Face.0.X.You can select only in this order.

    • Face.O.X : Select the Face, Node for coordinate system origin and the nodes on the X-axis.

  • Name

       Enter the name of the coordinate system to be created.

    • Refer Coordinate Frame

  • Coordinate

       Select the entire coordinate system.

    • Origin

  • X/Y/Z

       X / Y / Z coordinate value of the first selected node is displayed.

    • Point 2

  • X/Y/Z

       X / Y / Z coordinate value of the second selected node is displayed.


    • - Operating Procedure -

    1.  Select the type of coordinate system from type.
    2.  Enter the name of coordinate system to be created.
    3.  Choose one of the Face or Element surface.
    4.  Press the node button and select the node for origin and the node that becomes the X-axis.
    5.  Press the Apply or OK button.
