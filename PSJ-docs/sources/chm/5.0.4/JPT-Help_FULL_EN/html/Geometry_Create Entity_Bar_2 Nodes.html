Bar

Create the Bar Part from the two nodes that have been selected.

Bar Property

  • Bar Name

       Enter the name of the Bar Part to be created.

    • Mesh Size

     Enter the number of divisions for the Bar Part element.
  • Mesh Size

    •    Split the Bar Body at the specified length of Mesh Size.

  • Mesh Count

    •    Split the Bar Part into specified number of divisions.


    - Operating Procedure -

    1.  Enter the name to create the Bar Part.
    2.  Select the Mesh Size or Mesh number, enter the Mesh Size length or the number of divisions.
    3.  Press the Node button in the Selection List to select two Node from the screen.
    4.  Click Apply / OK button.
