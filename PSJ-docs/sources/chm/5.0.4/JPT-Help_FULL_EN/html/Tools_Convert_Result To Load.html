Convert Result to Load

Convert the post result (limited type) to LBCs for Pre side.

At current the below result type is supported:

- Temperature result ⇒ Temperature Loads/ Initial Temperature/ Boundary Temperature.

- Displacement result ⇒ Initial Displacement/ Enforced Displacement.

- Reaction Force/ Reaction Moment ⇒ Force.

- Contact Pressure ⇒ Pressure.

- Contact Force ⇒ Force.

　　

Source

  • Source Document

       Select the post document from which you want to convert result.

  • Step/Process

       Select step/process of post result.

    • 　　

    LBC

  • Enable

        Items with a check mark are subject to convert result to selected LBC respectively.

  • Result Name

       Display the limited supporting result which come from result post file.

  • Convert Load type

       Select the load type for Pre which can be convert from enable items.

    • - Operation Procedure -

    1.  Import post result into Jupiter.
    2.  Select the post source document and step/process.
    3.  Enable result items which want to convert to LBCs.
    4.  Select the entity for selection list.
    5.  Press the Apply or OK button to execute the command.
