Coincident Nodes

Move multiple nodes to the same position.

Position

  • Tolerance

    •    Specify the tolerance value between the nodes to be matched.

  • Descending Order

    •    Match the position to the node with the largest node ID among the selected nodes.


    - Operating Procedure -

    1.  Select the node to move.
    2.  Specify the tolerance value between the nodes to be matched.
    3.  Check the descending order if you want the node to be moved to match the node with the largest node ID among the selected nodes.
    4.  Press the Apply or OK button.

      5.   ※When Descending Order is turned off, nodes with the same node ID will be matched among the selected nodes.
