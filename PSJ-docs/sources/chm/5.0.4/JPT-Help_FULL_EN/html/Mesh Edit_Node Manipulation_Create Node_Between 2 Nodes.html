Between 2 Nodes

Add the Node between two selected nodes.

Property

  • Node ID

    •    Enter the Node number.

  • X

    •    X-coordinate of the intermediate position of the selected two points will be displayed.

  • Y

    •    Y-coordinate of the intermediate position of the selected two points will be displayed.

  • Z

    •    Z-coordinate of the intermediate position of the selected two points will be displayed.

  • Number of Nodes

    •    Specify the number of Nodes.

  • Imprint

    •    Create a node on the Part.


    - Operating Procedure -

    1.  Select the 2 Nodes.  ※ Select the two Nodes and Face.(If you want to Imprint)
    2.  Specify the Node number.
    3.  Specify the number of nodes.
    4.  Press the Apply or OK button.
