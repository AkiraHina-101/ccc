Auto Collapse

Delete and combine elements. This feature incorporates automatic processing into element edge selection / execution.

Auto Collapse

  • Auto Select (Element Edge)

    Among the element edges connected to the selected node, the shortest edge below tolerance is automatically selected. In free edge mode, functions can be executed continuously because the selection of nodes is not canceled.

  • Collapse All Element Edges

    Among the element edges connected to the selected node, pull all element edges below tolerance into the node and delete the element.

  • Tolerance

    Specify the maximum length of the element edge selected at the time of automatic selection and execution.


    • - Operating Procedure (Element edge automatic selection)-

    1.  Select the nodes you want to keep. The shortest element edge is automatically selected among element edges of a sub-tolerance length connected to the selected node.
    2.  Click Apply button.
    1. Node selection (element edge automatic selection) 2. Click Apply

    - Operating Procedure (Element edge automatic selection + free edge mode)-

    1.  Select the nodes you want to keep. The shortest element edge is automatically selected among element edges connected to the selected node that have lengths below tolerance.
    2.  Click Apply button. The other node of the selected element edge is connected to the selected node, and the element in between is deleted. Also, among the remaining element edges, the shortest element edge is selected.
    3.  Click Apply button. (Same repetition)
    1. Node selection
    (element edge automatic selection)    		 2. Click Apply
    (hold node selection, element edge automatic selection)    		 3. Click Apply
    (hold node selection, element edge automatic selection)    		 4. Repeat

    - Operating Procedure (Collapse all connected element edges)-

    1.  Select the nodes you want to keep.
    2.  Click Apply button to execute collapse using selected nodes and all element edges below tolerance.
    1. Node selection 2. Click Apply
    (All element edges below tolerance are collapsed)
