Meshing Surf Meshing

Generate triangular-quadrilateral element mesh to form the surface.

Mesh Type

  • Tri3

       Create the triangular elements.

  • Quad4

       Create the quadrilateral element.

    • Quad F-mesher : Use the high-speed Mesher to create the elements of a adjusted size.

    • Pure Quad Mesh : Generate only Quad 4 mesh.
      •

    • Mesh Size

  • Average

       Set the average Mesh size.

  • Minimum

       Set the minimum mesh size.

  • Maximum

       Set the maximum Mesh size.

  • Reduction Factor

       Average, Min, Max factor is applied respectively to the internal area for mesh size.

  • Curvature Control

       Place nodes on vertices where the curvature of the CAD geometry changes drastically.

    • Curve Meshing

  • Curve Meshing

       Specify a circular element setting.

  • Max Elem Angle

       Maximum element angle for elements of the circular geometry that are smaller than average.

  • Min Elem Size

       Set the circular element minimum size.

    • Mesh Gradation

  • Grading Factor

       Set the degree of change for mesh.

    • Clean up

  • Min Stretch

       Set the value of the minimum stretch for mesh quality.

    • Performance

  • Speed Vs Quality

       Set the speed versus quality.

    • Fastest : Priority for mesh generation speed.

    • Good Quality : Create the mesh at normal speed and quality.

    • Best Quality : Priority for mesh quality.
      •

    • Auto Settings

  • Merge Edges

       Combine the edges that are on the same plane.

  • Merge Faces

       Join the face on the same plane.

  • Merge Face Angle

       When you check for Merge Edge or Merge Face, it will be join the angle of the coupling edge or a face.

  • Map.Mesh Min Angle

       Perform automatic setting for Map mesh.

    • 0=θ : Create the Map mesh on all the surface for quadrilateral geometry.

    • 1=θ : Iso mesh is generated for all faces of a cylinder with a quadrilateral geometry.

    • 1<θ : Mapped mesh is generated for the cross section of the cylinder if the angle is below θ.Please refer to the below figure. A mapped mesh is generated only if the cylindrical face is quadrilateral.
  • Bad CAD Model

       You can create the surface mesh, even if there is a geometry face with area 0.

  • Close Holes

       You can create the surface mesh to fill the hole between the elements.

  • Delete Cir.Chamfer

       Automatically remove the chamfer below the minimum value. (minimum mesh size)

    • Mesh Color

  • Mesh Color

       You can specify the color of the parts after mesh creation.

    • Tiny Face Merge

  • Tiny Face Merge

       Create mesh as well as modify the tiny-face at the same time.

  • Min Face Width

       Specify the minimum width of the target Face.

  • Max Face Width

       Specify the maximum width of the target Face.

    • - Operating Procedure -

    1.  Specify Average, minimum and maximum mesh size.
    2.  Select the target parts.
    3.  Click Apply / OK button. ※You can abort a mesh creation process with the Cancel button
