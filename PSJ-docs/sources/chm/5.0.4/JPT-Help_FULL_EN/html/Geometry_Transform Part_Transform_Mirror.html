Mirror

Mirror symmetry move or copy the selected Part.

Operation

  • Create New Part

    •    Copy the part after the parallel move, as a new Part.

  • LBC Copy

    •    Also copy load constraints that were added to the existing part to a new part.

    Mirror

  • Offset

    •    Enter the Offset amount from the mirror symmetry plane.

  • Merge Nodes

    •    If checked, Face for mirror symmetry that are copied as the part will have the nodes joined in the case where there is contact of the Face with copy source for body.

  • Merge Node Tol.

    •    Enter the Tolerance of the coupling for Merge Node.

  • Copy Property Info

    •    It copies Property information of the source part to part after copy.

  • Remove Duplicate Faces

    •    Remove the Face which overlaps the copy with the original Part.


    - Operating Procedure -

    1.  When you want to create a new part after Part movement, select the Create New Part.
    2.  Turn on the LBC Copy to copy a load restraint conditions of the existing part to the new part.
    3.  Click the Part button, and select the Part for mirror symmetry from the screen.
    4.  Press the Element or Node button, and select from the screen the Element or three Node to become a mirror symmetry plane.
    5.  Enter the Offset amount from the mirror symmetry plane to Offset.
    6.  To Merge original Part and the Nodes after the copy, check the Merge Nodes, enter the Merge Tol. for the coupling tolerance.
    7.  To copy the source Property information to the Part after copy, click to select the Copy Property Info.
    8.  Click Apply / OK button.
