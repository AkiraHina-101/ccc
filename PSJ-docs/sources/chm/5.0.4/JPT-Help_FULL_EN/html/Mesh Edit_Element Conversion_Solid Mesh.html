Solid Mesh

Convert the order of the solid elements.

Conversion Type

  • To Linear(Tet4,Penta6,Hex8,Pyramid5)

       Convert to primary element.

  • To Quadratic(Tet10,Penta15,Hex20,Pyramid13)

       Convert to a secondary element.

  • Hexa to Penta6

       Convert Hex element to Penta element.

  • Hexa/Penta to Tet4

       Convert Hexa element and Penta element to Tetra primary element.
