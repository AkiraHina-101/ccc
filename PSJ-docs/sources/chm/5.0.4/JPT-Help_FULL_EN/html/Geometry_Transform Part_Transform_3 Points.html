3 Points

Move the Target Part from the original position to the new position by the 3 pairs of coordinates points.

Selection list

Edge: Select the circular edge or the arc to determine the center position.
Node: Select the Node to get the coordinate position value.
Part: Select the Target Part to be moved.

Coordinates

  • Original Position

    •    Specify the coordinates of 3 points that define the original positions on the Target Part.

  • Next Position

    •    Specify the coordinates of 3 points that define the destination positions.

    Operation

  • Preview

    •    Display temporary results as a preview (not the final result of the mesh).

  • Create New Part

    •    Copy the Target Part after moving as a new part.

  • LBC Copy

    •    Also copy Load and Boundary Condition that were added to the existing part to a new part.

  • Property Copy

    •    Also copy properties that were added to the existing part to a new part.

  • Reference Copy

    •    Also copy references that were added to the existing part to a new part.

    - Operating Procedure -

    1.  Select the circular edges to get the original center coordinates on the Target Part.
    2.  Select the circular edges to get the destination center coordinates.
    3.  Select the Target Part to be moved.
    4.  If you want to create a new Part after moving, turn on the Create New Part check box.
    5.  Turn on the LBC Copy to copy Load and Boundary Condition of the existing part to the new part.
    6.  Turn on the Property Copy to copy properties of the existing part to the new part.
    7.  Turn on the Reference Copy to copy references of the existing part to the new part.
    8.  Press the Apply or OK button.

    - Notes -

    • The input coordinates will automatically switch after each selection. Users can flexibly select between Edges and Nodes instead of selecting only Edges or Nodes.
    • Users can identify the current selection by the highlighted textbox. Moreover, the markers are also supported to show in the Main Window to recognize the position.
