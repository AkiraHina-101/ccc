Parts

Merge multiple parts in a single part.
Load conditions and material properties, etc., which has been set in Face and edges, will be updated to merged part.

Options

  • Remove Share Face

    Removing the check leaves a shared plane as the partition. To Remove the shared surface, keep the check.

  • Tolerance

    Set the tolerance when you perform the merge.

    • - Operating Procedure -

    1.  Set the parameters.
    2.  Select the multiple parts to be merged.
    3.  Click Apply / OK button.
