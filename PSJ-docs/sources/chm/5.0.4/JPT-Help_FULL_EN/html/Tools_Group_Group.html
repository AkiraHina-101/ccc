Create a Group of the each Entity.

　　

Group

  • Name

       Enter name of the Group.

  • Entity

       Select the Entity to create a Group.

    • Manual ID Input

     : Select the Entity by specifying the ID.
  • Entity ID

       Entity When you enter the Entity ID and press the "Add" button, the Entity corresponding to the ID is added to the selected list.

    • Import from CSV file

     :  How to Create a Group ID from the CSV file
  • Open File

        Select the Entity ID by specifying from the CSV file.

    • Examle of CSV file Format
      ＊ This format is different from CSV file of Group Windows

    • - Operating Procedure -

    1.  Enter the name of the group which you wish to create.
    2.  Select the Entity type from Entity, for which you want to create a Group.
    3.  Press the Entity button and select the Entity you want turned into group from the screen.
    4.  Press the apply or OK button.
    5.  Group that you have created are stored in the corresponding tree item for the entity. 

      6. ※If you wish to switch on the display of the group you have created, click on the 'Group mode on/off' Icon  in the main window.
        When you click again, display will be returned to normal.
