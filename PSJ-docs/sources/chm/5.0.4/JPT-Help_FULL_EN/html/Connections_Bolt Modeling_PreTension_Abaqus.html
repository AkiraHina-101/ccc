PreTension Abaqus

Set the pre tension for ABAQUS. User can select multiple faces or multiple cross sections but they must have the same normal vector.

Structural

  • Step Name

    Enter the name of the pre tension you want to create.

    PreTension-1

  • Value

    Enter the pre tension.

  • Input Unit

    Select the input unit system.

  • Ref.Node ID

    Enter ID of reference node。
    If you select a reference node in the selection list, the ID will be entered automatically。

  • Coordinates

    Enter coordinate values of reference node。
    If you select a reference node in the selection list, its node coordinate values are automatically input。

  • Pretension Direction

    Display the direction of pre tension.

  • Bolt FixLength

    If you check this box, it retains the tightening force of the bolt.

    • - Operating Procedure (Selecting a cross-section or faces) -

      Use the functions such as Body cut to prepared in advance the bolt parts by creating partition cross section.

    1.  Select the partition cross-section or faces.
    2.  Enter the pre tension.
    3.  Change the unit system if necessary, and then select additional options.
    4.  Click the Apply or OK button.

    - Operating Procedure (Selecting the beam elements) -

      Prepare the bolt parts in advance by dividing beam element into three or more using a function such as Bar Meshing.

    1.  Click the 1D Element from Selection List and select the beam elements.
    2.  Enter the pre tension.
    3.  Change the unit system if necessary, and then select additional options.
    4.  Click the Apply or OK button.
