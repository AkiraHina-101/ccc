Thickness Distribution

2D Property Thickness Distribution Dialog Box

Contour display the manual configuration of sheet thickness from 2d property and the automatic thickness information extraction from mid-plane function. Edit the contents of the contour display by changing the value of the Max / Min Thickness ※Mid-surface extraction feature is an optional feature.

Thickness Models

Contour display settings.

  • Display Mode

    Specify the display system.

    • By Property thickness Mode

      Contour display the thickness information in the Property.
      ※Use the plate thickness information and material after setting.

    • Thickness Value

    Display the sheet thickness.

  • Max Thickness

    Maximum plate thickness value is specified.

  • Min Thickness

    Minimum plate thickness value is specified.

    • Distribution

    Contour range setting.

  • Division Number

    The number of divisions of the contour. (2 to 99)

    • By Each Thickness

    Use only when By Property thickness Mode is selected.

  • By Each Different Thickness

    Automatically specify the maximum value, minimum value and number of divisions of the contour display by referencing the property information.

    • - Operating Procedure -

      　　　
    1.  Select the By Property thickness Mode from Thickness Models.
      2. 　　　
    2.  Enter the minimum and maximum value of the thickness range for contour display to Max / Min Thickness.
      3. 　　　
    3.  Enter the number of divisions of the plate thickness for contour display in the Distribution of Division Number.
      4. 　　　
    4.  If you want to change the contour display to be evenly split as the actual plate thickness, check the By Each Different Thickness check box.
      5. 　　　
    5.  Click the Apply or OK button to display the plate thickness contour diagram.
    6.  To hide the contour display, select the Reset from normal display mode icon.

    Contour Settings

    Turning on the show property thickness/load data in contour mode. While the Contour Settings ribbon is activated, it enable detailed of data settings such as name of data, input unit, max-min... User can change the Max-Min value and division number of contour bar .

    Command function list

  • Close

    Close the Settings ribbon.

  • 2D/3D

    Display the thickness of shell under 2D or 3D view shape.

  • Data

    Display the type of data as below:

    - Pressure

    - Initial Temperature

    - Temperature Load

    - Boundary Temperature

    - Heat Flux

    - Convection

    - Thickness

  • Input Unit

    Display the unit of data. It is based on defined type of data when creating the LBCs.

  • Component

    Display the component of data, for example Convection | Mapping, component can display as Temperature or Coefficient depend on user's selection on define Mapping LBCs.

  • Value
    • Max: Set the maximum setting for the contour display.
    • Min: Set the minimum for the contour display.
  • Division Number
    • Continous: Sets the number of color contour divisions.(2 to 100).
    • By Each Data: By Each Data is used for thickness property only.
    • Create Group (thickness property only): Create face group base on the thickness property.
  • Display Method
    • Color Contour: Select to display contour color on model.
    • Show shape: Select to display model.
    • No Properties: Select to display the face which does not has the property assigment.
