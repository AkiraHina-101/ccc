Temperature Load | Constant

Add the constant temperature load in the analysis model.

　　

Structural

  • Name

       Enter the name of the temperature load conditions.

    • Values

  • Temperature

       Enter the constant temperature value.

  • Input Unit

       Specify the input unit of temperature load amount.

  • Use Default Temperature

       Designate a constant temperature load throughout the model without selecting parts.
       At the time of solver input data output, the data volume and output time are reduced because all nodes are uniform.

    • Tables

  • Select Table

       Select the Table that you entered in the Field Data.


    • - Operating Procedure -

    1.  Select one of the buttons for Part, Face, Edge or Node and select the temperature load application object from the screen.
    2.  Enter a name for the load.
    3.  Select the Constant or Nastran Punch file from type.
    4.  Select the constant temperature in boundary temperature.
    5.  Change the local units as needed.
    6.  Press the Apply or OK button.
