2 Points

Measure the distance between two points.

Output

  • Distance

       Measurement result is displayed.

  • Delta X

       X distance in the basic coordinate system.

  • Delta Y

       Y distance in the basic coordinate system.

  • Delta Z

       Z distance in the basic coordinate system.

  • Input Unit

       Set the preferred unit system .


    • - Operating Procedure -

    1.  Choose two points from the screen.
    2.  Distance in value and delta axial distance in the basic co-ordinate system will be displayed.
