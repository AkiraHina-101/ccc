Spline

Create a spline curve-shaped Edge through Selected Node and to create the Bar Part, including the newly created edge.

Body Name

  • Name

       If you want to create a new Bar Part, enter the name of Part.


    • - Operating Procedure (Create an arc Edge to an existing Part) -

    1.  Select multiple Nodes.
    2.  Click the Apply/OK button.
    3.  Create a circular Edge passing through the selected Node, belonging to the selected part.

        4. - Operating Procedure (Create an arc Edge and Bar Part) -

        1.  Select multiple Nodes.
        2.  Enter the Part name in Name.
        3.  Click Apply/OK button.
        4.  Create a new Bar Part. Create an arc Edge through the selected Node.
