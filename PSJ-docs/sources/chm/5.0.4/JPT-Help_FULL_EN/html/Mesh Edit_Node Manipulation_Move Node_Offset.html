Offset

Offset

Moves the node by Offset amount in the input.

Position

  • Coordinate

    •    Specify the coordinate system.

  • X

    •    Enter the Offset amount of the X-coordinate.

  • Y

    •    Enter the Offset amount of the Y-coordinate.

  • Z

    •    Enter the Offset amount of the Z-coordinate.


    - Operating Procedure -

    1.  Select the Node that you want to move.
    2.  Specify the coordinate system that is used to specify the position.
    3.  Specify Offset amount in the each axis.
    4.  Specify the unit for amount of movement in the Coordinate.
    5.  Click the Apply or OK button.

      6.   ※When specifying a spherical coordinate system X / Y / Z is R / θ / δ、, at the time of specifying cylindrical coordinate system it will be changed to R / θ / Z.
