Shared Faces

Display the shared surface created in the Assemble Faces command.

Shared Face Information

　　
  • Show Information

    When you put a check and select a shared surface, Shared Face Key, Body 1 Name and Body 2 Name, Name ID are displayed.
    In addition to this, face and pars ID are displayed on the main window.

    　　
  • Shared Face Key

    Display the name ID of the selected share face.

    　　
  • Body1 Name

    Display the part name that owns the selected shared name.

    　　
  • Body2 Name

    Display the other part name that owns the selected shared name.

    Non Assemble Face

    　　
  • Create Assemble Face

    In the following cases, Assembled Faces will be created after an automatic recognition of shared nodes.

      There are several parts in a certain model, which have shared nodes between the parts.
      In the model created by reading a solver input file which does not have the Assemble Faces definition as in Jupiter Pre.
