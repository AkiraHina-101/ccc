Extract Surfaces

Create a new part from the face that has been extracted by the specified angle.
With this feature, you can extract one side of the surface from the model of a thin sheet.

Extract Surfaces

  • Angle

    Enter the angle. This angle is set to the angle between the face to be extracted, and faces with angle below this setting are extracted.
    ※Enter -1 in the value of the Angle to extract only the face you have selected

    Options

  • Part Name

    The name of the new parts that are created after the face extraction.

  • Select Face

    Display the face ID currently selected.

  • Preview

    You can see the surfaces to be extracted.

  • Reset

    Reset the surfaces identified in Preview button.

  • Merge to one part

    If you select faces of multiple parts and extract faces, as many extraction faces are created as the number of parts from which to extract. By turning on this option, the extracted faces are combined into one part.
    ※The default is ON.
