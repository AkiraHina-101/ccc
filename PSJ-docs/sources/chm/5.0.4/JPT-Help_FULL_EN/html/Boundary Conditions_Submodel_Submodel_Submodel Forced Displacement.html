Submodel Forced Displacement

Set the sub-model node forced displacement.

Structure

  • Name

       Specify the condition name.

  • Solver

       Solver selection.

    • Global

  • Path

       ADVC designated global model results folder path on the server.

  • Process No.

       Specify the process number in the global model.

    • Mapping dof

  • Translate X/Y/Z

       Selection of the degree of freedom translational XYZ to perform the mapping.

    • Option

  • Refer Type

       Global model results type.

  • extension_range

       Search tolerance in the entire coordinate system.

  • extension_tol

       Search tolerance of an element coordinate system.

  • extension_limit_to

       Newton-Raphson iteration convergence tolerance.

  • global_element_set

       Global model element group for search target.

  • use_bucket

       Bucket method selection.

  • num_bucket_max_x

       Maximum number of divisions in x direction for Bucket method.

  • num_bucket_max_y

       Maximum number of divisions in y direction for Bucket method.

  • num_bucket_max_z

       Maximum number of divisions in z direction for Bucket method.

  • prev_bc

       Maintain the specified boundary conditions.

    • - Operating Procedure -

    1.  Specify the item name in the Name.
    2.  Specify the path of the results folder on the ADVC compute server to Path.
    3.  Enter the process number of ADVC calculation results to Process No.
    4.  Select the face to set the sub-model.
    5.  Click Apply/OK button.
