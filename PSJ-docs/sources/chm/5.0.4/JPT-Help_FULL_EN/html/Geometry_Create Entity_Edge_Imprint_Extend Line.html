Extend Line

Extend the selected Edge in the same direction or in the same curvature.

Options

  • Method

    •    Choose a method to extend the Edge.

    • Straight : Extend in a straight line in the Edge direction.
    • Same Curvature : Extend while maintaining the curvature of the Edge.
      •

  • Position To Extend

    •    Select the position to extend the Edge.

    • Nearest Edge : Extend from the Edge end point to the nearest Edge.
    • Boundary Edge : Extend the selected Edge to Edge Face boundary.
      •

  • Break Face

    •    Split the Face.


    - Operating Procedure -

    1.  Press the button Edge and select the Edge extension target from the screen.
    2.  Select the method of selecting the Edge from Method.
    3.  Select the end point of the extended destination from the Position To Extend.
    4.  Clear the break face check box, if necessary. In this case, the Face after Imprint is not split from the original Face.
    5.  Click Apply / OK button.
