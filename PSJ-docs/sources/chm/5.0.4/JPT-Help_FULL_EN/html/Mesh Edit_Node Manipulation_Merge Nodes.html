Merge Nodes

Merge the nodes.

Merge Nodes

  • Tolerance

    Enter the tolerance between the merged node.

  • Type

    Specify the node to remain after the merge.

    • First Entity

      Leaves a node on the first selected entity.

    • Second Entity

      Leaves a node on the entity selected later.

    • Highest Id

      The node with the highest ID remains.

    • Lowest Id

      The node with the lowest ID remains.

    • Options

  • Create Group

    When the check is ON, it creates a group from the merged node.

  • Preview

    By highlighting the node for merge, you can check in advance.

  • Reset

    Cancel the preview.

    • - Operating Procedure -

    1.  Select the entity to merge the node. (Part, face, edge, element, node)
    2.  In order to define the merge range, enter the Tolerance.
    3.  Specify the node to remain after the merge, and then select the Type.
    4.  If necessary, turn ON the check for Create Group.
    5.  If you want to check in advance, click the Preview button to highlight the nodes of the merge candidate.
      Clear highlighting by clicking the Reset button.
    6.  Click Apply / OK button.
