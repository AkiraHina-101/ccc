General Layer

Create a new face by offsetting a face inside the part.

  • Width

    Enter the offset amount for the surface to be created.

  • Width On Surface

    Checking this box would be interpreted as the amount of offsets along the shape of the model plane.

  • Num of Layer

    Enter the number of layers to be created.

  • Separate Body

    Layer part will be created in a different body. ※Boundary layer part and original part have a shared surface.

  • Force Stitch To Side

    Conform to outside of the model geometry and offset.

  • Smoothing Edge

    Prepare the edge of the offset face.

  • No Imprint

    Not imprint the adjacent surface after the creation of the offset face.


    • - Operating Procedure -

    1.  Select the face group from the screen which will be offset.
    2.  Enter Width of the offset amount and the number of layer in Num of Layer.
    3.  Check ON the Separate body and the layer part will be created in a different part.
    4.  Click the Apply or OK button to execute.
      Layer part created will become another part with the boundary surface being a shared surface.
      Similarly in case of multiple layers, it will be separate parts respectively.
