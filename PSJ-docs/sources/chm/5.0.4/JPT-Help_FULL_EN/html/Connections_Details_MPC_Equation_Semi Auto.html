MPC Equation | Semi Auto

This function automatically creates the MPC between the nodes of the following distance tolerance.

Semi Auto

  • Name

    Enter the name to be registered.

    • Parameters

  • Coordinate

    Select the reference coordinate system.

    • MPC Term

  • Coef1(Slave)

    Enter the coefficients of the slave.

  • DOF1(Slave)

    Choose the degree of freedom of the slave.

  • Coef2(Master)

    Enter the coefficients of the master.

  • DOF2(Master)

    Choose the degree of freedom of the master.

  • Tolerance

    Specify the distance between the entities to create an MPC.

  • 1:1

    Master and slave are connected one to one.

    • - Operating Procedure -

    1.  Select the master entity.
    2.  Select the slave entity.
    3.  Enter the tolerance.
    4.  Set the other parameters.
    5.  Click Apply / OK button.
