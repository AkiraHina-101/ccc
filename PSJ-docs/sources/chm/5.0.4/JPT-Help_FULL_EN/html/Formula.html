Formula

Users are allowed to enter formula in the load value column followed by (=) symbol in Pressure (General) and Force (General).
When specifying force value for nodes by formula in force (General), set the distribution method to "Per node". The force at each node is applied according to the formula entered.

Function/symbolDefinition
+ Addition
- Subtraction
* Multiplication
/ Division
^ Exponentiation
pi Ratio of a circle's circumference to its diameter.
sin(...) Sine Function
cos(...) Cosine Function
tan(...) Tangent Function
arctan(...)Arctan Function
cot(...) Cotangent Function
sqrt(...) square root
fabs(...) Absolute Value
xn(i,LCS)X coordinate of the node i from the local coordinate system LCS
yn(i,LCS)Y coordinate of the node i from the local coordinate system LCS
zn(i,LCS)Z coordinate of the node i from the local coordinate system LCS
xe(i,LCS)X coordinate of element i center from local coordinate system LCS
ye(i,LCS)Y coordinate of element i center from local coordinate system LCS
ze(i,LCS)Z coordinate of element i center from local coordinate system LCS
*i, LCS uses the ID of the node, element, local coordinate system and converts the value in the global coordinate system unless you enter the local coordinate system LCS.
