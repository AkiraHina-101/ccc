Adjust Orientation

Prepares the orientation of the selected part or face of element, based on the selected element.

  • Entity

    Part： Correct the orientation of the elements for the parts unit.

    Face： Correct the orientation of the element for the face unit.

    • - Operating Procedure  -

    1.  Select the part or face to modify.
    2.  Select the reference element.
    3.  Function will be executed in the Apply or OK button.
