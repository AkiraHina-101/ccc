Model Filter

Create groups by mutually referencing element types, properties, and material information in the model.

　　

Filter Type

  • Element Type

       Switch the display contents by element type such as bar or triangle shell.

  • Property

       The display content is switched according to the property (element characteristic) information used in the model.

  • Material

       The display content is switched according to the material information used in the model.

  • Group

       Switch the display content by the existing group.

  • Reset

       Reset the selected content for all filter types.

    • 　　

    Target

       The items used for the body displayed in the view window are listed according to each filter.
       When you pick an item from the list, the item is highlighted for selection and the corresponding element is displayed in the view window.
       Items other than element types are sorted in ascending order and listed.

       Pick the item again to deselect the item.

       You can select multiple items in standard Windows operation using Shift key or Ctrl key.

       By switching the filter and selecting an item, you can further narrow the range.
       The example shows an element group that uses Solid Property 1 in the HEXA, PENTA element type.

    　　

    New Group

  • Node Group

       When checked, nodes are included in the created group.

  • Element Group

       When checked, elements are included in the created group.

  • Name

       Enter the name of the group to be created.

  • Create New Group

       Press the button to create a new group.


    • - Operating Procedure -

    1.  Display the range for creating a group of models in the view window.
    2.  Press the element type button from the filter type, and select the element type for which you want to create a group.
    3.  Furthermore, press the property or material button from the filter type, select an item from the list and narrow the display range.
    4.  When you finish filtering, enter a name for the new group and press the Create New Group button.
    5.  Now that a new group has been created, select a group from the filter type and check the list.
      To display the group, select Reset from Filter Type, reset the previous selection history, and then select an item.
    6.  Click the upper right X button to finish the command.

      7. ※To display the created group, click the Group display mode icon in the main window.
        Click again to restore the display to normal.
