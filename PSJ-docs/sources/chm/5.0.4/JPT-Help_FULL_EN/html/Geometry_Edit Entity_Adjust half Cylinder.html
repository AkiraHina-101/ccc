Adjust Half Cylinder | Coordinate

This command is used to adjust the split position of the cylinder face for example the bolt or bolt hole.
By using this function, unevenly meshing caused by the difference of split positions can be avoided.



- Operating Procedure -

  1.  Select the target face for adjusting the split position.
  2.  Select the reference coordinate system from the pull-down list.
  3.  Select the reference coordinate plane for adjustment.
  4.  Click the Apply/OK button.
