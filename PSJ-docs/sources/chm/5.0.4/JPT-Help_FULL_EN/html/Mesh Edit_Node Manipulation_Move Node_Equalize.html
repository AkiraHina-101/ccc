Move Node | Equalize

Arrange the nodes included in the edge at equal intervals.
If multiple edges are selected, they will be equally spaced within each edge.

- Operating Procedure -

  1.  Select the edge for which you want to adjust the node spacing.
  2.  Press the Apply or OK button.

    3.   ※In the case of a curve, it may not be equally spaced.
