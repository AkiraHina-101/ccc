Assemble Faces

For the assembly model of multiple parts, this dialog automatically searches for contact and creates a share surface with that face between the parts in the model. When you create a shared surface, a group of face pairs is created in Group tree of Group window.

Mating

  • Tolerance

    Enter the tolerance distance between the two adjacent faces that are in contact.

  • Find

    Start the search of the face that is in contact when pressed Find button.

  • Mating Face No./Assembled Face No.

    Display the number of face pairs in contact that are searched through the Find button.

    If you click the Apply button to create a shared surface, the option name will be changed to Assembled Face No. which displays the number of shared surface pairs that are created.

  • Find Result/Assembled Faces

    Display the list of face pairs in contact that have been searched through the Find button.

    If you click the Apply button to create a shared surface, the option name will be changed to Assembled Faces. which displays a list of shared surface pairs that are created.

  • No.

    Serial number for searching the order in which they will be created. A check box is displayed at the top of the ID number, only when share surface is created.

  • Find Result

    Display a list of face pairs that have contacts based of part name.

  • Select All

    Select all the check boxes that are displayed and then turn them on.

  • Unselect All

    Select all the check boxes that are displayed and then turn them off.

    • Imprinting

  • Fit Edge

    When checked, it will prevent edge split after creation of a shared surface.

    • - Operating Procedure (If you want to create a shared surface targeting the model) -

    1.  Change the value of tolerance from the default value, if necessary.
    2.  Click on the Find button.
    3.  Result of the face pair are listed.
    4.  Click each line of the list, face will be selected and displayed on the screen.
    5.  If there is no need to create a shared surface from a face pair, uncheck the corresponding check box.
    6.  Click Apply/OK button.

    - Operating Procedure (If you want to create a shared surface for multiple parts) -

    1.  Select more than one part.
    2.  Change the value of tolerance from the default value, if necessary.
    3.  Click on the Find button.
    4.  Results of the face pairs are listed.
    5.  Click each row of the list, face will be selected and displayed on the screen.
    6.  If there is no need to create a shared surface from a face pair, uncheck the corresponding check box.
    7.  Click Apply/OK button.
