2Quads to Quad

Convert the two adjoining quadrilateral element to one quadrilateral element.

Settings

  • Auto Execution

    When checked, it will convert automatically when you select the two-elements.

    • - Operating Procedure -

    1.  Turn on the Auto Execution check box.
    2.  Select the two quadrilateral elements that are adjacent to each other.
    3.  Simultaneously convert selected.
