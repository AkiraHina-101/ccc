Circular

Create an axis specified solid meshing from surface meshes (Tri and Quad mesh) by sweeping in axial symmetry.

Circular Parameters

  • Angle

    Enter the angle of sweep.

  • No. of Layers

    Enter the number of layers.

  • Center Type

    Select the setting of the center of rotation from the pull-down.
    Edge Center ：Center of the selected edge
    Node ：The selected node
    Arbitrary ：Arbitrary direction of the vector you entered
    Local Co-ord ：Specify the direction of Local Co-ord.
    Center X,Y,Z ：Center position X, Y, Z component

  • Axis Type

    Select the setting of rotation axis from the pull-down.
    Nodes ：Specify two of contacts you have selected
    Elem Edge ：Specify selected element edge
    Arbitrary ：Arbitrary direction of the vector you entered
    Local Co-ord ：Specifies the direction of Local Co-ord
    Axis X,Y,Z ：Axial vector X, Y, Z component
    Local Co-ord ：Choose the direction of Local Co-ord

  • Axis Tolerance

    You can specify a tolerance for axis of rotation.

    • Auto Interface Penta5/Tet4

  • Interface Elems

    If checked, a penta element to the boundary surface will be created.

    • Auto Delete Original Parts

  • Delete Original Parts

    When checked, the original part is deleted automatically.

    • Total Revolution and Extrusion

  • Total Revolution and Extrusion

    Check to enable rotation angle and extrusion distance.

  • Translation Distance

    Define the extrusion distance.

    • * If you select and run an entity that contains 2nd element, a warning will be displayed.
    Convert to primary element and execute.

    - Operating Procedure -

    1.  Select the rotation sweep surfaces.
    2.  Specify the angle of rotation sweep.
    3.  Specify the number of layers.
    4.  Set the rotation axis and the center.
    5.  Click the Apply or OK button.
