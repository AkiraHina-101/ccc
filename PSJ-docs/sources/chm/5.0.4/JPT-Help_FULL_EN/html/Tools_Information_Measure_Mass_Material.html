Mass [Manual]

Measure the mass of the Solid Part. For material, select the material properties from the Material Library.

　　

Measure

  • Coordinate System

       Reference coordinate system.

    • Material Library

    Select the material from the material Library.

  • Material

       Select the material from drop-down box to refer to the mass density of the material Library file.

  • Density

       Density of the selected material will be displayed automatically.

    • Output

  • Value

       Measurement result (mass) is displayed.

  • Input Unit

       Set the preferred unit system .

    • Gravity Center

  • X/Y/Z

       Specify the position of centre of gravity in the reference coordinate system.

    • Moment of Inertia

  • Axis
    • Principal : Using the principal axis of inertia for the moment of inertia calculation.
      • 11,22,33 : The value of the principal moments of inertia.
      • Rotation Angle : Rotation angle of main axis.
      • 1/2/3  X,Y,Z : Direction of each of the principal axis of inertia (centre of gravity coordinate is 0)

    • XYZ : Using the reference coordinate system for moment of inertia calculation.
      • XX/YY/ZZ/XY/XZ/YZ : The value of moment of inertia around the reference coordinate system.

    - Operating Procedure -

    1.  Choose the solid part from the screen.
    2.  Mass density input (selection of material from the material library).
    3.  The value of total mass of the selected part will be displayed.
