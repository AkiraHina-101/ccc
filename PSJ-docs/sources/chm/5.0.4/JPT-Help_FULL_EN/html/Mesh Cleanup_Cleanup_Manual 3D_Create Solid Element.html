Manual 3D Create Tetra / Create Hexa / Create Penta / Create Pyramid

Create a solid element from the selected elements or nodes.




Selection List

Element: 2D Element linked with the solid element.
Node: Nodes linked with the solid element.
Part: The part to which the created solid element belongs (if not selected, the solid element will be created as a new part).

Parameter

  • Target

    Select a solid element type to be created.

    • Tet : Creates a Tetra element (Tetrahedron).
    • Hex : Create a Hexa element (Hexahedron).
    • Penta : Create a Penta element (Triangular Prism).
    • Pyramid : Create a Pyramid element (Square Pyramid).
      •
  • Use OrderNode

    When the check box is selected, the number of the next selection order is displayed in the main window from the fourth node.

  • Direction

    Reverse the direction of the solid element to be created.

  • Height

    Specify the height of the solid element to be created.

  • Keep Part Selection

    Specify whether to keep the selected part in the Selection list after the Apply button is executed.

    1. Turn on the Use OrderNode option and create a solid element (in this case, a Hexa element as an example) by selecting the nodes.

    2. Select three nodes to create an element. In this case, select the three nodes in a counterclockwise direction. If select these nodes in a clockwise direction, then the green guidelines will not appear in the intended direction. It's shown in the figure below.

    3. Next, select a node where the element is to be created, in the direction where the number 4 appears in the main window.

    5. Next, select a node where the element is to be created, in the direction where the number 6 appears in the main window.

    6. Next, select a node where the element is to be created, in the direction where the number 7 appears in the main window.

    7. Next, select a node where the element is to be created, in the direction where the number 8 appears in the main window. After selecting all the nodes, the preview will appear.

    - Special Notes -

    1. When the "Use OrderNode" option is OFF, automatic generation of concave shapes is not possible.
    2. The secondary order elements are also supported. If the order of the selected element is different, an error message will be displayed.
    3. Only Keep Part Selection does not save the GUI settings.
