Property Renumber

3D Property Table Dialog Box

Renumber property ID / material ID in the document in the table.

Property Table

　　
  • Set

    Select Renumber target from property / material.

    　　　
    • 　　
  • Table

    List all the properties / materials currently present in the document.

    • Name
      Name of property / material. Partial match search allows you to filter out the rows.
    • Current ID
      Current ID of the property / material.
    • Renumbered ID
      ID after property / material renumbering. Enter IDs so that they do not overlap in the model.
    • Material (for properties only)
      The material used for the property. Partial match search allows you to filter out the rows.
    • Enable
      Only the checked columns will actually be renumbered. 　　　
    　　　
  • All On

    Activate all columns.

    　　　
  • All Off

    Disable all columns.

    　　　
  • Switch

    Reverse enable / disable.

    　　　

    • Options

    Select basic property data of solid element.

  • Start ID

    ID after renumbering of visible line is numbered sequentially from specified ID.

  • Increment Step

    Specify the interval value at the time of numbering.

    • Sort Order

  • Ascending

    The numbers after renumbering are numbered in ascending order.

  • Descending

    The numbers after renumbering are numbered in descending order.

  • Update Table

    Change the ID after renumbering according to the current option sort order setting.

    • - Operating Procedure -

    1.  Prepare a model with assigned properties / materials.
    2.  Start property table.
    3.  In the setting list, select Renumber target from Properties / Material.
    4.  Specify the ID after renumbering by any of the following methods.
    •  Click the "Renumbered ID" cell and edit the value directly.
    •  Optionally enter a start ID, an incremental value, specify the sort order, and click the Update Table button.
    5) Uncheck the checkboxes that are not valid for the columns you do not want to renumber.
    6) Click the Apply button to renumber.
