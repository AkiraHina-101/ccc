Find Feature

From the specified parts select a face or edge of a particular shape.

Options

  • Face

    Select the type of the following face:

    • 4 Sided

      Select the face of the four corners.

    • Planar

      Select the planar face.

    • Full Cylinder

      Select the face of the cylindrical surface.

    • Half Cylinder

      Select the face of the semi-cylindrical surface.

    • Disc

      Select the disk-shaped face.

    • Map Mesh

      Select the face of map mesh.

      • Cylinder

        When you check, it selects the face of the cylindrical surface.

      • Disc

        When you check, it selects a disk-shaped face.

      • Four Corners

        When you check, it selects the face with four corners.

    • Circular Chamfer

      Select to Delete the chamfer surface.

      • Min Thickness

        Specify the minimum thickness of the circular chamfer surface.

      • Max Thickness

        Specify the minimum thickness of the circular chamfer surface.

      • Remove

        Delete the selected chamfer part and make it a pin corner.

    • Fillet

      Select the fillet surface.

      • Min Face Width

        Specify the minimum face width to search.

      • Max Face Width

        Specify the maximum face width to search.

      • Min Curve Radius

        Specify the minimum radius of the fillet to search.

      • Max Curve Radius

        Specify the maximum radius of the fillet to search.

      • Min Angle

        Specify the minimum value of the angle of the fillet to search.

      • Max Angle

        Specify the maximum value of the angle of the fillet to search.

      • Convex

        Search for convex fillets.

      • Concave

        Search for concave fillets.

    • Edge

      Select the type of edge of following:

      • Line

        Select the straight edge line.

      • Loop

        Select the edge of loop shape.

      • Full Circle

        Select the edge of circle.

      • Half Circle

        Select the edge of semicircle.

      • Bolt Hole

        Select the bolt hole edge between the specified minimum and maximum diameter values.
        The bolt holes correspond to not only parts but also edge selection by face selection.
        The number of divided bolt hole edges that can be searched is 0, 1/2 and 1/4.

        • Min Diameter

          Minimum diameter of bolt hole.

        • Max Diameter

          Maximum diameter of bolt hole.

      • Concentric Circles

        Select the concentric edge of the specified edge.

      • - Operating Procedure (Face, Planar or Full Cylinder or Half Cylinder or Disc) -

      1.  Specify the Feature> Face
      2.  Specify the Type.
      3.  Select the part you want to search.
      4.  Click Apply / OK button.

      - Operating Procedure (Face, Map Mesh) -

      1.  Specify the Feature> Face.
      2.  Specify the Type> Map Mesh.
      3.  Check the shape to be extracted.
      4.  Select the part you want to search.
      5.  Click Apply / OK button.

      - Operating Procedure （Face, Circular Chamfer) -

      1.  Specify the Feature> Face.
      2.  Specify the Type> Circular Chamfer.
      3.  Check the shape to be extracted.
      4.  Enter the minimum and maximum thickness of the chamfer surface.
      5.  Click Apply / OK button.
      6.  If you want to remove the chamfer surface and make it a pin corner, click the Delete button.

      - Operating Procedure (Edge, Line or Loop or Full Circle or Half Circle) -

      1.  Specify the Feature> Edge.
      2.  Specify the Type.
      3.  Select the part you want to search.
      4.  Click Apply / OK button.

      - Operating Procedure (Edge, Bolt Hole) -

      1.  Specify the Feature> Edge.
      2.  Specify the Type> Bolt Hole.
      3.  Enter the radius of the bolt hole.
      4.  Select the part you want to search.
      5.  Click Apply / OK button.

      - Operating Procedure (Concentric Circles) -

      1.  Specify Feature> Edge.
      2.  Specify Type> Concentric Circles.
      3.  Select the curve edge to be the basis of Concentric Circles.
      4.  Click the Apply / OK button.
