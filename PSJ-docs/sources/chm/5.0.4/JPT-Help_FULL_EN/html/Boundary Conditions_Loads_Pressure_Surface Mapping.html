Pressure | Surface Mapping

Map the pressure of fluid analysis calculation result of Fluent and StarCD by Nearest neighbor method.
The values in the file are read in document units and output in the units.

Mapping Pressure

  • Name

       Specify the condition name.

  • Export by

       Specify the fluid analysis solver from which the result file was output.

    • Fluent
    • StarCD
      •
  • Mapping File

       Specify the fluid analysis result file.

  • Pressure Tag

       Select the column number to map.

  • Scale Factor

       The mapping result can be corrected with a factor.

    • Transform Data

  • Rotation X / Y / Z

       The analysis results can be rotated to correct the position.

  • Displacement X / Y / Z

       The analysis result can be moved in the translational direction to correct the position.

  • Coordinate Scale

       You can correct the scale of analysis results.

    • Preview

  • CFD points

       The point cloud of the analysis result after correction can be displayed, and the position with the target model can be confirmed.

  • Clear

       Clear CFD points preview contents.

    • Search Range

  • Auto

       Specify the data search range automatically.

  • Input(TSV)

       Enter any tolerance.

  • Mapp Preview

       Display a preview of the mapping.

  • Clear

       Clear the mapping preview contents.

    • - Operating Procedure -

    1.  Enter the condition name in Name.
    2.  Specify a solver for fluid analysis.
    3.  Click the mapping file button and specify the fluid analysis result.
    4.  Specify the result column by pressure tag.
    5.  Check the position of target model and analysis result with data point button.
    6.  Select the face to map.
    7.  Set the data search scope as required.
    8.  Click the mapping preview button to display the contour color of the mapping result.
    9.  Click the Apply / OK button to apply the mapping.
