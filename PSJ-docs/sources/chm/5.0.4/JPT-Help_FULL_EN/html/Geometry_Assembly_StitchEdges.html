Stitch Edges

Connect the edge that are slightly apart.
Select the edge which is connected as master (Master). Select the edge to connect as a slave (Slave).
Slave (Slave) edge will connect to the master (Master) edge.

Settings

  • Tolerance

    Enter the possible connection distance. Connect the edges with values less than the specified value.

  • Keep Slave Nodes

    Retain the nodes on the edge of the selected slave (Slave).

    • - Operating Procedure -

      　　　
    1.  Open the Selection List window, click the Master button.
      2. 　　　
    2.  Select edge to create a connection.
      3. 　　　
    3.  Click the Slave button of Selection List window.
      4. 　　　
    4.  Select the edge to be connected.
      5. 　　　
    5.  Change the value of Tolerance from the default values if necessary.
      6. 　　　
    6.  Click Apply / OK button.
