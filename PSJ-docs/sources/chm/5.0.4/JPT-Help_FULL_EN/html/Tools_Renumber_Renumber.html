Renumber

Renumber the IDs assigned to nodes and elements.

General Settings

  • Set
    • By Part
      Perform renumbering on parts.
    • By Group
      Perform renumbering on groups.
  • Target
    • Node
      Renumber node ID.
    • 3D Element
      Renumber solid element ID.
    • 2D Element
      Renumber face element ID.
    • 1D Element
      Renumber 1D element ID.
    • Edge
      Renumber edge ID.
    • Face
      Renumber face ID.
  • Auto Renumber

       ID numbers are assigned sequentially from the StartID on the top line.

    • List

    Display a list of renumbering targets.

  • Part ID

       Display part ID.

  • Name

       Display part name.

  • Counter

       Display the number of targets contained in the part.

  • Start ID

       Enter the minimum ID of the part after renumbering. At start up, the minimum ID of the current part is displayed.

  • End ID

       The maximum ID of the part after renumbering is displayed. At startup, the maximum ID of the current part is displayed.

  • Enable

       Items with a check mark are subject to renumbering and automatic renumbering.

    • Options

  • Resolve Conflict

       Determine how to assign IDs of shared nodes and shared surface elements.

    • Lower ID priority
      The shared node / face element ID belongs to the smaller part ID.
    • Higher ID priority
      The ID of shared node / face element belongs to the larger part ID.
  • Display only property assigned entities

       Only the element to which the property is assigned is displayed in the list.

    - Operation Procedure -

    1.  Turn on the check in the Enable column of the part line you want to renumber (default: ON).
    2.  Enter an arbitrary ID for Start ID.
    3.  Press the Apply or OK button.
