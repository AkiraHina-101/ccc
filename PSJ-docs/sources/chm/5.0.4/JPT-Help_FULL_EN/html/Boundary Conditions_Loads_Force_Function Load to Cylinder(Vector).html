Force | Load to Cylinder (Vector)

When defining the force load on selected faces, edges or nodes based on the distribution of the sine function, the force is defined in the X, Y axis direction using a vector.
Multiple data prepared in advance as a CSV file can be specified simultaneously on multiple faces.

　　

Structural Force

  • Name

    Enter the name of the force load condition.

    • 　　

    Sine Curve : y=a*sine(rad)

      Define the sine curve.

  • Total Force

    Display the total value of the force load.

  • X

    Specify the force in the X direction.

  • Y

    Specify the force in the Y direction.

  • Input Unit(Force)

    Specify the unit system for entering force loads.

  • a

    Define the coefficient a of the sine function.

  • Co.System for load

    Select the coordinate system for defining the angle of the load application range.

  • Angle Range

    Enter the angle from the Y axis on the coordinate syste XY plane used to specify the load application range.
    The load application range is angle 0 - PI and is entered within the range of 0°< angle < 90°.

  • Input Unit(Angle)

    Specify the input unit system for angle values.

  • Direction

    Specify parallel or normal for the maximum load direction.

  • Direction in Axis

    Specify distribution in the depth direction.

  • Multiple Set From File

    Specify distribution in the depth direction by importing a .csv file.

    　　

    Force Data Setting Dialog

  • Name

    Enter the name of the force load condition.

  • Data

    Display the data selected from the list below.

  • Register

    Create the force load condition.

    • 　　

    Option

  • Arrow direction

    Specify the vector display setting.

    • Start at Node: Display the vector arrow starting at the node.
    • End at Node: Display the vector arrow ending at the node.

    - Operating Procedure (Single data setting) -

    1.  Select the target face(s), edge(s) or node(s) of the force load from the selection list or screen. (Multiple targets can be selected.)
    2.  Enter the name of the load.
    3.  Specify the vector for each axis direction in X and Y. The sum of all load values is the total load value.
    4.  Enter a value for a in the sine function equation.
    5.  Specify the coordinate system and angle for the load application range of the sine function.
    6.  Select a direction for the distribution in the depth direction as necessary.
    7.  Select the display direction of the arrow as necessary.
    8.  Click the Apply or OK button.

    - Operating Procedure (Multiple data settings) -

    1.  Click the Multiple Set From File button to open the Force Data Setting dialog.
    2.  Import the CSV file including the load data. Each line in the CSV file includes X,Y, Angle, Direction(start/end) data.
      3. (Example of CSV file）
      1000, -1000, 30, start ,
      500, 1000, 60, end ,
      300, 300, 30, start ,
      0, 600, 30, start ,
      100, 0, 45, end ,
      -500, 1000, 45, start,
    3.  Display the imported data. Click the line to select the target data.
    4.  Define other parameters. Parameters defined in the Command window are ignored while this dialog is used.
    5.  Display the content of the selected data. Select the target face in the Main window and click the Register button to define the load.
