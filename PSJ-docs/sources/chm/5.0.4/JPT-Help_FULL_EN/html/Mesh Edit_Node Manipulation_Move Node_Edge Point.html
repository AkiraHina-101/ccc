Edge Point

The destination to move the Node was instructed by the specified Point on the Edge.

Position

  • X

    •    X direction for coordinates are specified.

  • Y

    •    Y direction for coordinates are specified.

  • Z

    •    Z direction for coordinates are specified.


    - Operating Procedure -

    1.  Select the Edge Point button on the select list.
    2.  Specify the Point on the Edge to become a destination.
    3.  Select the Node button on the select list.
    4.  Select the Node that you want to move.
    5.  Press the Apply or OK button.
