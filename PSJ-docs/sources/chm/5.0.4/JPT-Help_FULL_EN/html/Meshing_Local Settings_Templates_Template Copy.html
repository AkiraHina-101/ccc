Template Copy

Form the shape, copy the local setting of same entity and topology, to the same entity.

Copy Settings

  • Method

     Specify how to copy.

    • By Shape : Copy based on the shape.

    • By Topology : Copy based on the topology.
      •
  • Include Sub Entity

     Copy all of the local settings that are included in the reference source entity.

  • Tolerance

     Set the tolerance of the shape error.

    • - Operating Procedure -

    1.  Select the Master button in the Selection List.
    2.  Select the reference source of the face for the local setting.
    3.  Select the Slave button in the Selection List.
    4.  Select the destination of the face.
    5.  Click Apply / OK button.
