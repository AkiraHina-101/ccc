Translation

Mirror, symmetry, move or copy the selected part.

Operation

  • Create New Part

    •    Copy the part after the parallel move, as a new Part.

  • LBC Copy

    •    Also copy load constraints that were added to the existing part to a new part.

  • Copy Count

    •    Enter the number of repetitions of the copy.

    Translation

  • Coordinate System

    •    Select the coordinate system to be referred for the parallel movement.

  • Axis

    •    Select the axis that determines the direction for parallel movement.

    • X Axis : To move parallel defined value in the X-axis direction of the selected coordinate system.
    • Y Axis : To move parallel defined value in the Y-axis direction of the selected coordinate system.
    • Z Axis : To move parallel defined value in the Z-axis direction of the selected coordinate system.
    • Arbitrary Axis : To move parallel in direction vector X, Y, Z value.
    • 2 Nodes : To move parallel defined value in the two Node direction that has been selected from the screen.
    • Edge : To move parallel defined value in the Edge direction that has been selected from the screen.
      •

  • X

    •    The translation amount is entered in Z-axis direction of the coordinate system.

  • Y

    •    The translation amount is entered in Z-axis direction of the coordinate system.

  • Z

    •    The translation amount is entered in Z-axis direction of the coordinate system.

  • Magnitude

    •    Enter the amount of movement.


    - Operating Procedure -

    1.  If you want to create a new Part after the parallel movement, turn on the Create New Part check box.
    2.  Turn on the LBC Copy to copy a load restraint conditions of the existing part to the new part.
    3.  To repeat copy, enter the Copy Count.
    4.  Press the Part button to select the Part to be copied and moved from the screen.
    5.  If you to move along an existing coordinate system direction, select an existing coordinate system from the Coordinate System, select one of the axis from X-axis, Y-axis, Z-axis and enter the amount of movement in Magnitude.
    6.  To move in any direction select an arbitrary axis from Axis, and input the value in the X, Y, Z and Magnitude entry boxes, respectively.
    7.  To move to the selected 2Node direction, press the Node button and select the two Node from the screen. The distance between 2 Node is automatically entered in magnitude.
    8.  To move to the selected Edge direction, press the Edge button and select the Edge from the screen. Edge length Magnitude is automatically entered.
    9.  Change the amount of movement in the Magnitude if necessary.
    10.  Press the Apply or OK button.
