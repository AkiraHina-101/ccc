Material

Material Dialog Box

Create material data that is referenced in the property data.
Read from the material library, or you can create new ones.

　　
  • Search

    You can search for material by putting the string to the left for input box, and pressing the Search button.

    　　　
    • 　　
  • User Data Base

    It lists the material data that has been registered in the material database for use.
    It has the following features to list.

    • [Double Click] You can edit an item.
    • [Double Click：New] Allows you to create a new material data.
    • [Double Click：Save] Permits you to store an item in the library.
    • [Double Click：Delete] You can delete the item you have clicked.

    　　　
    • 　　
  • Library Database

    It lists the contents of the specified material library.
    You can register material data on the User database from the import in the right-click menu or drag and drop.
    It has the following features

    • [Double-click] You can edit an item.
    • [Right Click:Import] It will register material data to the User Database.
    ※Material not registered in the User Database can not be used.
    ※Specify from the default material library Home>Preference>Material Library.

    　　　
    • 　　
  • Library Path

    You can temporarily add material library.
    Select the library you want to add from the right edge of the folder icon.

    - Operating Procedure -

    Create a new material

      　　　
    1.  Select New from the right-click menu of the mouse on the User Data Base table.
      Edit Material dialog box appears.
      2. 　　　
    2.  Enter the material name in the Name.
      3. 　　　
    3.  Change the other parameters as needed. You can use Type, Standard and Description freely as an optional identifier. Material ID can not be duplicated in the material library.
      4. 　　　
    4.  Select the material constant item that you want to input from Structure, Thermal, Gasket and Fluid.
      Input the contents of the material constants are displayed on the right side of the Property window.
      5. 　　　
    5.  Enter the Material parameters in accordance with the above description.
      6. 　　　
    6.  Press the OK button to create the data. Data that is created will be added to the User Data Base table.
      7. 　　　
    7.  To save the created data to any of the library, select Save from the right-click menu of the target item on the mouse specifying the library file.
      8. 　　　
    8.  To delete the created data, select Delete from the right-click menu of the target item on the mouse.

    Acquiring existing data from material library

      　　　
    1.  Since the Library Data Base has table data of the default material library displayed, copy by drag-and-drop to the User Data Base table.
      You can also perform the same operation by selecting Import from the right-click mouse menu button on the library of items.
      Material that has been added to the User Data Base table can be referred to at the time of creating property data.
      2. 　　　
    2.  To add a material library to the Library Data Base table, please select the library file from a folder icon in the Library Path.
      Material data that is included in the library will be added to the display.
      3. 　　　
    3.  From Jupiter v5.0.2, when saving the created data to the material library , the version of file (*.mlib) is upgraded to 4 < JPT-MATERIAL-LIBRARY Version="4" >.
      The convert temperature unit for Reference Temperature of Expansion is supported only for < JPT-MATERIAL-LIBRARY Version="4" > .
