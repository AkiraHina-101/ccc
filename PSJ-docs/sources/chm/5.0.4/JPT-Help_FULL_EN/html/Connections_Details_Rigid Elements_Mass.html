Mass

Create a mass element

Properties

  • Name

    Enter the name to be registered.

  • Mass Value

    Enter the mass.

  • Coordinate

    Enter the local coordinate system.

    • DoF

  • DoF

    Choose the degree of freedom.

    • UX - RZ

      Select to define only one degree of freedom.
      ＊For the Nastran output file (.bdf), CMASS2 is defined. Offset distance and mass moment of inertia will be ignored.

    • UXUYUZ

      Select to define the degree of freedom of the translation component.
      ＊For the Nastran output file (.bdf), CONM2 is defined.

    Offset

  • X1, X2, X3

    Enter the offset distance from the node to the centre of mass.

    • Inertia

  • I11 - I33

    Enter the mass moment of inertia around the centre of mass.

    • Local Unit

  • Length

    Specify the local unit of length.

  • Mass

    Specify the local unit of mass.

    • - Operating Procedure -

    1.  Select the node(s).
    2.  Enter the mass in the Mass Value.
    3.  If necessary, set the other parameters.
    4.  Click Apply / OK button.
