Main Window

The geometry or mesh model is displayed. When multiple documents are open at the same time, click the tab at the top of the window or use the main window operation button on the right side of the ribbon menu to display the document you want to view.


Mouse Operation

A list of mouse operations in the main window.

Mouse OperationFunction
Scroll button click and dragRotate the view
Wheel scrollZoom in or out of the model view
Right button click and dragTranslate the view (Pan)
Left button clickSelect one of the entity
Left button click and dragDefine the range to select multiple entities within the range
Right button clickDisplay shortcut menu
Mouse settings can be changed in the preferences within the Home menu.

Main Window Operation Buttons

Control the display of the document window of the main window.

IconNameDescription
MinimizeMinimize the active document display
CascadeIndicate arranging the document you open inside the main window
CloseClose the document in display
Settings can be changed in the preference command from the Home menu.

Toolbar

The main window has four toolbars: View toolbar, View option toolbar, Selection toolbar, and Selection option toolbar. These are used by clicking on the icon with the left mouse button. The settings of the display / non-display and arrangement of each toolbar can be changed from the Preference command in the Home menu.

    Cursor Peripheral Entity Function

    By holding the Alt key and double-clicking the left mouse button on an entity, the list of entities near the double-clicked point of mouse cursor is displayed.

    It is possible to check each entity in the list, for example, in a part where detailed entities are concentrated.
    Also, by clicking on an item in the list, the corresponding entity is highlighted in the main window.
