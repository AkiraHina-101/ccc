Area [Part]

Measure the area of the Part.

　　

Output

  • Area

       Measurement result (Area of the Part) is displayed.

  • Total Value

       Measurement result (Total area of the Part) is displayed.

  • Input Unit

       Set the preferred unit system .


    • - Operating Procedure -

    1.  Select the Part.
    2.  Area of the last selected part will be displayed in the area, while area of the all selected part will be displayed in the total value.
