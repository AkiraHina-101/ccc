Nastran | Modal Transient Response (SOL 112)

Output the Input Deck for Nastran Modal Transient Response analysis (SOL 112)

Job Option


　　　　
  • Job

    Program: Select the type of Nastran Solver
        MSC: MSC Nastran
        NX: NX Nastran
    Job Name: Enter the name of the job. Output set by this name will be saved in the tree.
    Job Description: Enter a description for your job.

    　　　
    • 　　　
  • Solver Option

    Run Nastran: Run Nastran on the local machine.
    Memory (MB): Define the memory allocation.

    　　　
    • 　　　
  • System Cell and FMS

    System Cell: Enter data directly card to Nastran (System) section.
    FMS: Enter text data directly in file management statement section.

    　　　
    • 　　　
  • Executive Control Option

    GEOMCHECK, NONE: Disable the geometry checking option.
    Direct text input: Enter the text data directly to the executive control section.

    　　　
    • 　　　
  • Case Control Option

    ECHO: Define the echo output of bulk data
        NONE: No output
        SORT: Sorted output
        UNSORT: Unsorted output
        BOTH: Both sorted and unsorted output
    TITLE: Define the title at the time of print output
    Direct text input: Enter text directly to the case-control section

    　　　
    • 　　　
  • Bulk Data Option

    Write Type: Specify the output target
        By Model: Output to a single file
        By Each Part: Print a separate file for each part
        Selected Parts: Output of selected parts only
    GRID Format Type: Specify the Grid output format
        Single: Small field format output
        Double: Large field format output
        Single F.P.: Specify the floating-point number small field format output
    Delete Floating Nodes: Floating node is removed at the time of exporting output data
    Continuance Marker +: Output the continuation pointer + in at the time of exporting output data
    Include Bulk Data: Insert the bulk data file
    Direct text input: Enter text directly to the bulk data section

    　　　

    • Transient Response


    　　　
  • Frequency range for eigenvalue extraction:

    Define Frequency range and number of modes for the eigenvalues extraction.

    Starting Frequency: Specify the start frequency
    Ending Frequency: Specify the end frequency
    Number of Modes: Specify the number of modes

    　　　
    • 　　　
  • Time Step:

    Define the transient time-step configuration.

    Num. of Steps: Specify the number of time step
    Time Increment: Specify the time increment
    Output Interval: Specify the output interval

    　　　

    • Loading / Boundary Conditions


    　　　
  • Base:

    Define the boundary conditions that act on the entire analysis to be defined on the specific SUBCASE.
    Specify the boundary conditions case to be used in each of the boundary conditions. It will include all of the boundary conditions in Default.

    DLOAD: Specify the dynamic load case
    SPC: Specify the constraints set
    MPC: Specify the multi-point constraint set
    Damping Type: Select the type of modal damping.
        Critical Damping Ratio: Critical damping ratio CRIT
        Structural Damping: Equivalent viscous damping G
        Q Factor: The amplification factor Q
    Modal Damping: Select the table of modal damping
    RESVEC: Control the consideration of the residual vector
        YES: Consider
        NO: Not consider
    Define LBC ID: Specify the identification ID of load, restraint and multi-point restraint

    　　　
    • 　　　
  • Subcase Option:

    Define the SUBCASE.
    Specify the boundary conditions case to be used in each SUBCASE

    Existing ID: Specify an existing SUBCASE ID
        Add: Add New SUBCASE
        Remove: Delete existing SUBCASE
        Apply: Update existing SUBCASE
    ID: Specify the SUBCASE ID
    Subtitle:Enter the title at the time of print output
    DLOAD: Specify the dynamic load case.
    SPC: Specify the constraint set
    MPC: Specify the multi-point constraint set
    DISPLACEMENT: Specify the displacement output request
    STRESS: Specify the element stress output request
    STRAIN: Specify the element strain output request
    ACCELERATION: Specify the acceleration output request
    VELOCITY: Specify the velocity output request
    Direct text input: Enter text data directly to SUBCASE

    　　　

    • Output Request


    　　　
  • Result type

    Specify the output request.
        PLOT: op2 Output
        PRINT: f06 Output
        PLOT&PRINT: op2 and f06 output
        Blank: No output

    DISPLACEMENT: Specify the displacement output request
    SPCFORCES: Specify the single point constraint force output request
    OLOAD: Specify the applied load output request
    MPCFORCES: Specify the multi-point constraint force output request
    STRESS: Specify the element stress output request
    STRAIN: Specify the element strain output request
    FORCE: Specify the element forces output request
    ESE: Specify the element strain energy output request
    SDISPLACEMENT: Specify the displacement output request of solving set (modal variable)
    ACCELERATION: Specify the acceleration output request
    VELOCITY: Specify the velocity output request
    MEFFMASS: Specify the modal effective mass output request
        YES: Output
        NO: No output
    Grid ID: Specify the node to be used in the rigid body mass matrix calculation

    　　　
    • 　　　
  • Group (SET)

    The extent to which the elements results are output element and limits to specify the node group (set).
        ALL: Output all the elements, with respect to all the nodes
        Group: Output elements in the specified group, relative to node

    DISPLACEMENT: Specify the output range with respect to the displacement output request
    SPCFORCES: Specify the output range with respect to the single-point constraint force output request
    OLOAD: Specify the output range with respect to the applied load output request
    MPCFORCES: Specify the output range with respect to the multi-point constraints force output request
    STRESS: Specify the output range with respect to the element stress output request
    STRAIN: Specify the output range with respect to the element strain output request
    FORCE: Specify the output range with respect to the element forces output request
    ESE: Specify the output range with respect to the element strain energy output request
    SDISPLACEMENT: Specify the output range with respect to the displacement output request of solving set (modal variable)
    ACCELERATION: Specify the output range with respect to the acceleration output request
    VELOCITY: Specify the output range with respect to the speed output request

    　　　

    • Parameter


    　　　
  • Parameter:

    Define the parameters.

    POST: Specify the output type for the post-processing results file
        0: XDB Output
        -1: op2 Output (For Patran)
        -2: op2 Output (For I-DEAS)
    OGEOM: Control the geometry output to OP2
        YES: Yes geometry output
        NO: No geometry output
    AUTOSPC: Control the automatic restraint for stiffness singularity
        YES: Automatic constraint
        NO: No automatic constraint
    GRDPNT: Control the weight information output
    WTMASS: Define Mass correction factor
    K6ROT: Define the load factor for rotational stiffness of shell elements normal
    MAXRATIO: Define the matrix pseudo-singularity determination ratio
    BAILOUT: Control the execution against the pseudo-singularity
        0: Continue run
        -1: End run
    PRGPST: Control the print output for singularity summary table
        YES: Yes output
        NO: No output
    G: Define the structural damping coefficient
    W3 (for G): Define the angular frequency to convert overall structural damping in to equivalent viscous damping (rad / sec)
    W4 (for GE): Define the angular frequency to convert the element structural damping in the equivalent viscous damping (rad / sec)
    LFREQ: Define the lower natural frequency of the mode to be used in the modal method
    HFREQ: Define the upper limit of the natural frequency of the mode to be used in the modal method

    　　　


    • - Operating Procedure -

    　　　
  •  Create a time-dependent table for excitation load

      • 　　　
    1.  Select Boundary Conditions>Misc>Field Data command.
      2. 　　　
    2.  Click the add button in the Field Data dialog.
      3. 　　　
    3.  In Add/Edit Tables dialog, enter an arbitrary name in the Table Name and select the Time in the Table type. From the Import button read the file in csv format to create a table [Time, Value]. In case of manual input add only the required number of data input from the Insert button. After the data input click OK button to create the table.
      Input data table can be displayed in the Chart by selecting Time and Value in X, Y and clicking the Draw XYZ button.



    　　　
  •  Create a modal damping table

    • Continue to create the time depended excitation table as well as frequency dependent damping table. Table type is set to Frequency.
    Damping type (critical damping ratio CRIT, equivalent viscous damping G, the amplification factor Q) is selected during Nastran data output.


    　　　
  •  Set of excitation conditions

    • Set the time dependent excitation conditions. In the following set the forced displacement excitation.
      　　　
    1.  Select the Boundary Conditions>Loads>Enforced Loads>Enforced Displacement command.
      2. 　　　
    2.  Enter the amount of displacement in the intended direction and select a time table for excitation that was created earlier in the Select Table menu.

      3. 　　　
    3.  Select excitation node from the model and click Ok to create the forced displacement excitation.


    　　　
  •  Creating Nastran input data

    • Output the input data of Nastran for modal transient response analysis (SOL112)
      　　　
    1.  Select the Analysis>Analysis>Nastran>Modal Transient Response (SOL112) command.
      2. 　　　
    2.  Set the eigenvalues extracted with Transient response>Frequency range for eigenvalue extraction and the time step in Time Step settings (number of steps, time increment, output interval).

      3. 　　　
    3.  For mode damping type (critical damping ratio CRIT, equivalent viscous damping G, the amplification factor Q) select Base>Damping Type from Loading / Boundary Conditions and then select the mode damping table in the Modal Damping.

      4. 　　　
    4.  If you want to output the result of only specified node and element, create a group of nodes, elements and specify the group in the Output request of Group (SET).
      5. 　　　
    5.  Define the other necessary option and click Apply(OK) button to output the input data file.
