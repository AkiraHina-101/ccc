Bolt Connections

Model the bolt for analysis.

Creation Method

  • Edge

    Select the edges to create.

  • Face

    Select the face to create.

  • There are four types for Bolt modelling i.e, Type A, Type B, Type C and Type D.
    • Type A : On the upper and lower surfaces of the bolt holes create a RBE2 element in a circle, and then join the centre with the bar element or RBE2 elements.
    • Type B : Creates a RBE2 element in a circle on the top surface of the bolt hole, places RBE2 on the lower end that combines side face for the bolt holes and then joins the centre with the bar element or RBE2 elements.
    • Type C : Place the RBE2 or RBE3 element on the side surfaces of the bolt hole and then join the centre with the spring element or RBE2 elements.
    • Type D : Join opposite surfaces with MPC within the specified range around the bolt holes.
      •

  • For the Type A and Type B there is a Pretension Option, you can create a bolt model and set a bolt tightening force.
    Bar element of the bolt shaft is divided at its centre position for the bolt tightening using MPC bond

    • - Operating Procedure -

    1.  Specify how to create (Edge / Face).
    2.  Select the bolt type you want to create.
    3.  Open the command dialog for the selected bolt type, select entity and if necessary, select the option and input parameters.
