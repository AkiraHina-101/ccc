Command Dialog/Selection List Window

Launch the command from the ribbon menu to display the Command window as a floating dialog. Or, click the > icon on the right corner of the Command window to display the Selection list window.


・Command window
Enter a value for each item in the Command window and click the Apply/OK button to execute the command. Click the Cancel button to close the window without executing the command.
The Command window can only be used for one command at a time. In case another command has been previously launched, it will automatically canceled when a new command is launched.

・Selection list window
When an entity is selected while a command is launched, and that entity can be used for that command, the entity will be displayed in the List window sorted by type.
The entities available for the active command can be confirmed by clicking the Entity button in the List window. When the Entity button is clicked, the selection mode will be activated for the target entity. The previously selected entity will be displayed on the top of the Entity list.
Click the Clear icon in the List window in order to empty the Entity list.
Click an item displayed in the Entity list with the left mouse button to highlight the item in the list and the Main window. Press the Delete key to delete the highlighted item from the Entity list.
Press the Shift key or Ctrl key to select multiple items from the Entity list.
