Circle

Imprint a circular Edge on the Part.

Options

  • Break Face

    •    Split the Face.

    Parameter

  • Inner Radius

    •    Enter the inner radius.
       Note:
        1. If the value of No of Layers = 1, this option will be grayed out
        2. If the value of No of Layers > 1, this option can be used

  • Outer Radius

    •    Enter the outer radius.

  • No. of Layers

    •    Enter the number of layers to be created.

  • No. of Divisions

    •    Enter the number of divisions.


    - Operating Procedure -

    1.  Click the Node, Face Point and the Edge Point button, to select Node on Face where we would like to imprint edge, Face Point and Edge Point from the screen.
    2.  Turn off the Break Face, if necessary.
    3.  Select Outside radius and enter the outer radius value. (This value is required)
    4.  If you want to split Layers, enter the inner radius value to the inner radius, and then enter the Layer number.
    5.  Enter the circumferential direction Edge division to the number of divisions as needed.
    6.  Click Apply / OK button.
