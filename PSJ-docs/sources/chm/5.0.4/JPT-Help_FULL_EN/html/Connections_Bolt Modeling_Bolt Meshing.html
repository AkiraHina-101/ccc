Bolt Meshing

This command is used to divide CAD bolts into upper and lower parts for meshing and defining load and boundary condition for ADVC.



  • Name

    Enter the capital letter of the load and boundary condition to be created.

  • Cutting

    Define the surface for dividing the bolts into upper and lower parts. Refer to the Body Cut command for details.

  • Surface Meshing

    Define the mesh settings. Refer to the Surface Meshing command for details.

  • PreTension

    Define load conditions. Refer to the PreTension command for details.

    If "Partition Only" is selected, create Abaqus pretension with setting of cross section and normal direction.


    • - Example of function execution -

    - Operating Procedure -

    1.  Select the CAD bolt parts.
    2.  Enter the capital letter of the load condition of the bolt in the Name field.
    3.  Define the position for dividing the bolts.
    4.  Define the mesh settings for bolts.
    5.  Define the load condition setting of the bolts.
    6.  Click the Apply/OK button.
