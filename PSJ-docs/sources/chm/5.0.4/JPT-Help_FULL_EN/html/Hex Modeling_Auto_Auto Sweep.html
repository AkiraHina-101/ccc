Auto Sweep

Recognize the shape of the selected part (s), to create a hex mesh of shape which conforms to the conditions.

Auto Sweep

  • Mesh Size

    Enter the size of the hexa element to be created.

    • Layers

  • Layer Mesh

    If you check this box, it will specify the number of layers.

  • Layers

    Specify the number of layers. It will specify number of layers in the thin direction in the case of thin plate.

    • - Operating Procedure -

    1.  Select the CAD part.
    2.  Specify the mesh size.
    3.  Specify the a number of layers, if required.
    4.  Click the Apply or OK button.
