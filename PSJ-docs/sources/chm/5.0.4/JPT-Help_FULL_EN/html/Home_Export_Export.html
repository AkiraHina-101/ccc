Export

Export selected shape in TSG format.

Options

  • Vertex

    Output vertex coordinates.

  • Edge

    Output edge information.

  • Surface

    Output surface mesh.

  • Solid

    Output solid mesh.

    • - Operating Procedure （Export） -

    1.  Select the part / face you want to output.
    2.  Select Home> Export> Export.
    3.  A Save As dialog box will be displayed, so give it a name of your choice.
    4.  A dialog will be displayed. Make sure that the shape you want to save is checked and click OK.
