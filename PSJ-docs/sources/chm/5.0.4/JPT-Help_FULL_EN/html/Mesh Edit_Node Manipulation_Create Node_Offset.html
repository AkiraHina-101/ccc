Offset

Translate and copy the selected node or floating point to create a node.
If you specify the number of copies, it creates copies at the specified intervals of offset vector.

Position

  • X, Y, Z

    Enter the offset vector of the copied location.

  • Repeat (times)

    Enter the number of copies.

  • Coordinate

    Set the reference coordinate system.

    • - Operating Procedure -

    1.  Select the node or floating node to copy.
    2.  Enter the offset vector values to X, Y, Z.
    3.  Enter the number of copies to Repeat (time).
    4.  If necessary, change the reference coordinate system.
    5.  Click Apply / OK button.
