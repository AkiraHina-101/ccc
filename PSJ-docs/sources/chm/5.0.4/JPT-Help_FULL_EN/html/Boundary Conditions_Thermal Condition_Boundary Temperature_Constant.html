Boundary Temperature - Constant

Set the boundary temperature for the heat transfer analysis model. During heat transfer calculation, specify a point where the temperature is constant.


　　

Thermal

  • Name

       Enter a name for the boundary temperature condition.

    • Value

  • Temperature

       Enter a constant temperature value.

  • Input Unit

       Specify the input unit of temperature.

    • Tables

  • Select Table

       During transient heat transfer analysis, select the time dependency table in Field data.

     ※When a table is referenced, the value is the product of the temperature input value in the dialog box and the system value in the table.


    • - Operating Procedure -

    1.  Select the Face, Edge, Node button, and select the boundary temperature addition target from the screen.
    2.  Enter a name for the boundary temperature condition.
    3.  Enter a constant temperature for temperature.
    4.  Change the input unit if necessary.
    5.  If the temperature value changes with time in the transient heat transfer analysis, select the change history from the table.
    6.  Press the Apply or OK button.
