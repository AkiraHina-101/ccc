Field Data

You can create any table in this command.
Table that you create can be used when you set load, the boundary conditions, etc…

  • Delete

    • - Operating Procedure -

    1.  When you want to create a new data table, click the Add button.
          If you want to edit the existing data, select an item from the list and click the Edit button. Add / Edit Tables dialog box opens.
    2.  Enter the name of the data table to be created in the Table Name.
    3.  Select the type of data table to be created from the Table Type.
    4.  Enter the data in accordance with the contents of the selected data type.
          Click the Insert button to add a row of data and to remove the data line, press the Delete button after selecting the appropriate data line.
    5.  If you want to read the data from a CSV format file, click the Import button.
          Specify the csv file from a standard file specification dialog box.
    6.  To draw an XY plot, select the variable you want to display to the axis from the X, Y from the pull-down menu dialog box located at the right end.
          When you press the Draw XYZ button, XY plot is displayed in the Chart window.
    7.  Click the OK button to close the Add / Edit Tables dialog box. The data table which is created and edited will be displayed in the list.
    8.  Click the Close button to close the dialog box.
