Connection | Spring - Nodes with tolerance - same DoFs

This command is used to create 1:1 scalar spring elements.

Spring elements are automatically created between the selected nodes within an specified tolerance.
Multiple Dofs can be connected at once using this function. Nodes with younger IDs are defined as the 1st group.

Connection

  • Name

    Specify the name for registration.

    • Method

  • Nodes tolerance

    Specify the search range of the connection point.

    • Spring

  • X Stiffness - RZ Stiffness

    Enter the spring stiffness of the DOF to be connected.

  • Damping Coef (for Nastran)

    Specify the damping coefficient.

  • Stress Coef (for Nastran)

    Specify the stress coefficient.

    • Analysis Coordinate Frame

  • Coordinate

    Select the reference coordinate system.

    • - Operating Procedure -

    1.  Specify the Nodes tolerance.
    2.  Select multiple nodes from the Main window.
    3.  Enter the spring stiffness for the nodes to be connected.
    4.  Define other parameters.
    5.  Click the Apply/OK button.
