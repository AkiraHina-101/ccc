Contacts | SunShine - Manual Face

Define contact settings between specified faces.
Select the master face and the slave face, and define the contact settings.



Basic

  • Name

       Enter the contact pair name.

  • Algorithm

       Select the contact setting target entity.

    • Face to Face: Face-to-face contact
  • Type

       Select the behavior type of contact definition.

    • General : (IGLUE:0)Sliding contact
    • Tied : (JGLUE:0)Tied contact
    • Tied w/Frictionless Sliding : (JGLUE:1)Tied contact with frictionless sliding
      •
  • Master

       Select the face to be the master face.

  • Slave

       Select the face to be the slave face.

  • Switch M/S

       Swap master and slave.

    • Contact Properties

  • Touching Distance Range (ERROR)

       Distance below which a node is considered touching a body.

  • Friction Coefficient (FRIC)

       Friction Coefficient.

  • Interference Closure(CINTERF)

       Interference closure amount, normal to the contact surface.
       CINTERF>0:overlap between bodies.
       CINTERF<0:Gap between bodies.

  • Delayed Slide Off (SLIDE)

       Delayed slide off distance. This entry should not be made unless ICOORD >= 2. When using the delayed slide off option, a node sliding on a segment will slide off this segment only if it passes the node or edge at a sharp corner over a distance larger than the delayed slide off distance.

  • Modify Coordinates (ICOORD)
    • None : (0) to ignore this option.
    • Modify position : (1) to modify the coordinates of a node in contact with a deformable body so that stress-free initial contact can be obtained.
    • Delay sliding : (2) to extend the tangential error tolerance at sharp corners of deformable bodies to delay sliding off a contacted segment.
    • Both effect :  (3) to have both Modify position and Delay sliding active.
  • Type of Tied Contact
    • Penalty Method : (IGLUE:1) Using Penalty method.
    • MPC Method : (IGLUE:2) Using multiple points constraint(MPC) internally.
      *It's stable, but need care to avoid duplication with D.O.F of other constrait.
      •
  • Penalty Factor (SFACT)

       Factor for increasing time steps due to number of iterations.

  • Penalty Factor (SFACTT)

       Scale factor of penalty method tangential coefficients.

  • Contact Damping (CDAMP)

       Contact Damping Coefficient.

  • Shell elemet face (Slave)

       Shell element face (Slave) has the following options:

    • Btm w/ Thk. offset : Only bottom faces will be in the contact description, thickness offset will be included.
    • Btm w/o Thk. offset : Only bottom faces will be in the contact description, shell thickness will be ignored.
    • Top w/ Thk. offset : Only top faces will be in the contact description, thickness offset will be included.
    • Top w/o Thk. offset : Only top faces will be in the contact description, shell thickness will be ignored.
  • Shell element face (Master)

       Shell element face (Master) has the following options:

    • Btm w/ Thk. offset : Only bottom faces will be in the contact description, thickness offset will be included.
    • Btm w/o Thk. offset : Only bottom faces will be in the contact description, shell thickness will be ignored.
    • Top w/ Thk. offset : Only top faces will be in the contact description, thickness offset will be included.
    • Top w/o Thk. offset : Only top faces will be in the contact description, shell thickness will be ignored.

    • Color Setting

  • Contact Color

       Define the contact-to-display marker color.

    • Reset: Initialize to default color

    • - Operating Procedure -   

    1.  Select the face that will be the master face in the master. Then select the face that will be the slave face in the slave.
    2.  Define detailed settings for contact pairs as required, and click the Apply (OK) button to define contact pairs.
