FrontISTR-Solver - Linear Elastic Static

Export input data of linear elastic static analysis for FrontISTR-Solver

Analysis Setting

　　　
  • FrontISTR Job

    Job name: Enter the job name. The output settings are saved in the tree with this name.
    Solver version: The current version is 3 (default).
    Analysis type: FrontISTR analysis type. Currently only linear elastic static analysis is supported.

    　　　
    • 　　　
  • Analysis settings

    Method of Matrix Solver: Select a solution.
    CG, BiCGSTAB, GMRES, GPBiCG, DIRECT, DIRECTmkl, MUMPS.
    Preconditioner of Matrix Solver: Select a solution.
    SSOR, SSOR(MCO), Diagonal Scaling, AMG, ILU(0), ILU(1), ILU(2).
    Output Iteration: Select the number of output iterations.
    YES: Output the number of iterations.
    NO: The number of iterations is not output.
    Output Elapsed Time: Select to output elapsed time.
    YES: Output elapsed time.
    NO: Elapsed time is not output.
    Ordering for Vector Machine.
    Diagonal Scaling.
    Method of MPC.
    Iteration Count: Enter the number of iterations (default = 20000).
    Iteration Count of Additive Schwartz: Enter the number of Additive Schwartz iterations (default = 2).
    Number of Krylov Subspaces: Enter the number of Krylov Subspaces.
    Target Number of Colors: Enter the number of target colors.
    Threshold: Enter the convergence threshold (default = 1e-6).
    SIGMA_DIAG: Enter SIGMA_DIAG (default = 1).
    SIGMA: Enter SIGMA value.

    　　
    • 　　
  • Contact Analysis 　　

    Algorithm: Select Algorithm for contact analysis.
        Extended Lagrange Multiplier Method.
        Lagrange Multiplier Method.

  • Thermal Stress Analysis

    Number of Steps of Thermal Analysis: Enter the number of thermal analysis steps.
    Intial Step Number: Enter the number of initial steps.
    Result File Name of Thermal Analysis: Enter the thermal analysis result file name.

    Step Setting

    　　　
  • Auto-Incremental and Time Points Settings: Input necessary parameter for Auto Increment.

    　
        Name: Input name of Auto Increment.
    　　
        Reduction Condition: Input 5 parameters as RS, NS_MAX, NS_SUM, NS_COUNT, N_S.

        Increase of Time Increment: Input 5 parameters as RS, NS_MAX, NS_SUM, NS_COUNT, N_S.

        Additional Parameter: Input 2 parameters as RC, N_C.

    • 　　

  • Time Points Setting: Input necessary parameter for Time Points.


        Name: Input name of Time Points.

        GENERATE: Select on/off GENERATE feature.

        Type: Select STEP/TOTAL type.

        TIME: Input GENERATE=OFF, input only Time is enough.

        STIME: Input GENERATE=ON, input starting time.

        ETIME: Input GENERATE=ON, input ending time

        INTERVAL: Input GENERATE=ON, input interval same as increment.

    • 　　　

  • Step Analysis 　　

    　　NAME: Enter the step analysis name.
    　　TYPE: Select the type of analysis.
    　　    STATIC.
    　　    VISCO.
    　　CONVERG: Enter the convergence threshold (default = 1e-5).
    　　SUBSTEPS: Enter SUBSTEPS (default = 10).
    　　MAXITER: Enter the maximum number of iterations.
    　　DTIME: Input DTIME value.
    　　ETIME: Input ETIME value.
    　　Create Step: Click the button to create an analysis step.
        LBC Manager: Launches the LBC Manager dialog for setting boundary constraint conditions and load cases.

    LBC Manager Dialog

        Move Left: Moves the selected process to the left column.
        Move Right: Moves the selected process to the right column.
        Process Edit: Edit the process settings.
        Delete Process: Delete the process.
        Active: Enable the displayed condition.
        Inactive: Disable the displayed condition.

    • Output Setting

    Result Data: Select to output the result type to the output data.
    Visualize Data: The output result type can be visualized in post-processing.
    Output Model Info to Log File: Nodes and elements are output to the log file.
        YES: Nodes and elements are outputted to the log file.
    　　     NO: Nodes and elements are not outputted to the log file.
    Visualize File Type: Select a visualization file type.
        AVS
        BMP
        VTK
        COMPLETE_AVS
        COMPLETE_REOPRDER_AVS
        SEPARATE_COMPLETE_AVS
        COMPLETE_MICROAVS
        BIN_COMPLETE_AVS
        FSTR_FEMAP_NEUTRAL
        BIN_VTK
    Output Interval: Specify the output interval.
    Output Filename: Specify the output file name.

    Option Setting

    Group Manage: Manage all group that created manually.

        Check All: Select all grop of this field.
        Uncheck All: Deselect all grop of this field.
        Reverse All Check Status: Change status of all checked group.
        Output Type: Select Node Group or Surface Group or Element Group.
        Filter: Filter group name.
    Exporting Selection: Select file type to export.
        .msh file: Output only .msh file including node, element, material, selected group.
        .cnt file: Output .cnt & .msh file.

    Parallel Setting

    Parallel Setting: Specify the parallel calculation setting.
        OFF: No parallel calculation settings are set (single calculation is execute).
        ON: Specify the parallel calculation setting.
    Number of Computation Nodes: Specify the calculated node number.
    Number of Processors per Computation Nodes: Specify the number of processors per number of calculated nodes.
    Refine Level: Enter the refine level.

    Execution Setting

    Direct Execution: Specify direct execution.
        OFF: Direct execution is not set.
        ON: Specify direct execution.
    Single Core Calculation ( Enable when Parallel calculation setting = OFF)
        Exe file path: Specify the calculation execution file path.
        Calculation exe file: Specify the calculation execution file.
    Parallel Core Calculation
    MPI: Setting for the MPI environment.
        Path: Specify path of MPI folder.
        Exe file: Specify the Exe file.
        Option.
    FrontISTR: Setting for the FrontIST environment
        Exe file path: Specify path of FrontISTR solver folder.
        Area division exe file: Specify the area division executable file.
        Calculation exe file: Specify the Exe file.

    - Operation procedure -

    1.  Specify the job name.
    2.  Create a process in Create Process. This is not necessary if you want to analyze in the default time increments.
    3.  Assign boundary conditions to the process in LBC Manager.
    4.  Select an output item in the Output Manager.
    5.  Click the Apply / OK button to execute function.
