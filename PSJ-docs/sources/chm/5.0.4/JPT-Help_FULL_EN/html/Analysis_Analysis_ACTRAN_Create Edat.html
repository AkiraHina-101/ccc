Actran Analysis

This dialog is used to export ACTRAN Edat input files.

ACTRAN Job

  • Job Name

       Specify the job name.

  • Job Description

       Specify the job description.

    • Import Edat file

  • Select Edat file

       Import the Edat file.

    • Analysis Type

  • Select Analysis Type

       

    • Basic Analysis Direct  : Specify the basic analysis type.
    • Basic Analysis Green  : Specify the Green analysis calculation.
    • Panel Contribution Analysis Green  : Specify the Panel Contribution analysis type.
    • Mode Contribution Analysis Green  : Specify the Mode Contribution analysis type.
    • Waterfall Analysis Green  : Specify the Waterfall analysis type.

    • Acoustic Model

  • File Path

       Specify the file path.

  • Nastran Bulk Data

       Specify the file by selection.

  • Infinite Space Type

       Specify the infinite boundary type.

    • 2D Infinite Boundary (NRBC)

  • Model Property

       Select the non-reflective boundary 2D mesh elements property.

  • Elem.Prop.ID

       Specify the element property ID for the non-reflective boundary 2D mesh.

    • 3D PML Layer

  • Model Property

       Select the sound-absorbing layer 3D mesh element property.

  • Elem.Prop.ID

       Specify the element property ID for the sound-absorbing layer 3D mesh.

    • Reflection

  • X,Y,Z Plane

       Specify the reflective boundary surface by entering the coordinate value.

    • 2D Acoustic Boundary

  • Model Property

       Select the acoustic structural boundary 2D mesh elements property.

  • Elem.Prop.ID

       Specify the element property ID for the acoustic structural boundary 2D mesh.

  • GAP_TOL

       Specify the GAP_TOL.

  • PLANE_TOL

       Specify the PANEL_TOL.

    • 3D Acoustic Boundary

  • Model Property

       Select the acoustic space 3D mesh elements property.

  • Elem.Prop.ID

       Specify the element property ID for the acoustic space 3D mesh.

  • Material

       Specify the acoustic space material.

    • Structure Model

  • File Path

       Specify the structural model input file path.

  • Nastran Bulk Data

       Specify the structural model input file path by selection.

  • File Path

       Specify the structural analysis OP2 file path.

  • Surface Vibration Data

       Specify the structural analysis OP2 file.

  • Subcase

       Specify the subcase ID (load case).

  • State Value

       Specify the structural analysis result type.

    • Analysis Condition

  • Frequency Definition Method

       Select the definition method of the calculation frequency.

    • Manual  : Specify the frequency intervals by user input.
    • Auto  : Specify the frequency intervals automatically.

    • Frequency Range

  • Start Frequency

       Specify the start frequency.

  • End Freq

       Specify the end frequency.

  • Frequency Increment

       Specify the frequency interval.

  • Solver

       Specify the Green Analysis DB file.

    • Plot

  • File Name

       Specify the PLT file name.

  • ACTRAN PLT

       Specify the export location of the PLT file.

    • MAP File

  • Use MAP File

       Specify the MAP file.

  • Format

       Specify the MAP file name.

  • File Name

       Specify the export location of the MAP file.

  • ACTRAN PLT

       Specify the MAP file name.

    • Field Points

  • Method

       Specify the definition method of the field point by selection.

    • Group  : Define the field point by specifying the node group.
    • Table  : Define the field point by entering the coordinate value in the table.
  • Table

       Display the dialog for entering the coordinate value.

  • Add

       Enter and registers a coordinate value.

  • Delete

       Delete a registered item.

  • Paste

       Paste and register the content of the clipboard.

  • CSVFile

       Import and register a CSV file.
