Centrifugal Force (Coordinate System)

Add the centrifugal force load to refer to the coordinate system in the analysis model.

　　

Structural

  • Name

       Enter the name of the centrifugal force load conditions.

    • 　　

    Rotation Axis

  • Axis

       Select the rotation axis of coordinate system from X, Y, Z-axis.

    • Analysis Coordinate Frame

  • Coordinate

       Select the coordinate system in which the centrifugal force is referenced.

    • 　　

    Value

  • Rotational Velocity

       Enter the angular velocity value

  • Input Unit

       Specify the input unit of angular velocity value

  • Rotational Acceleration

       Enter the angular acceleration value

  • Input Unit

       Specify the input unit of angular acceleration value

    • - Operating Procedure -

    1.  Enter a name for the load.
    2.  Select rotation axis from the list of X, Y, and Z axis.
    3.  Select the coordinate system frame from the existing coordinate system list.
    4.  Enter the angular velocity value. You can change the Local units as needed.
    5.  Enter the angular acceleration value. You can change the local units as needed.
    6.  Press the Apply or OK button.

      7. ※Since the centrifugal force is to be added to the entire model, therefore there is no selection for Part in the selection list.
