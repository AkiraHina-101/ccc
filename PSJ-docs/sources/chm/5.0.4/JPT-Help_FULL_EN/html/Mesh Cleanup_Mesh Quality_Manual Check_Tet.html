Mesh Quality - Manual Check [Tet]

Make corrections to the solid mesh (Tet4 / Tet10) according to the selected quality standard.

Element Quality

Metric: Select how to measure element quality from the pull-down menu.

  • Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value.
  • Aspect Ratio: If checked, detect and display elements with aspect ratio greater than or equal to the specified value.
  • Volume: If checked, elements with volumes below the specified value will be detected and displayed.
  • Jacobian: If checked, detect and display elements of Jacobian value below the specified value.
  • Tet Collapse: If checked, elements of Tet Collapse below the specified value will be detected and displayed.
  • Tet Skew: If checked, elements of Tet Skew value greater than the specified value will be detected and displayed.
  • Edge Length: If checked, element edges with a length greater than or equal to the specified value will be detected and displayed.
  • Unstable: When checked, detect and display an element that is unstablely connected with other elements at corner nodes.
    • ※Please refer to ＜definition of quality check method＞ for each item.

    Cutoff Value

  • Minimum: Display the minimum value of the set check type.
  • Maximum: Display the maximum value of the set check type.
  • Average: Display the average value of the set check type.
  • Number of Entities: Display the number of element types in the selected model.

    • Display

  • Condition: Set the inequality sign for the set value.
  • Value: Enter the setting value of the element to be displayed.
  • Number of Entities: Display the number of displayed elements.

    • Auto Cleanup

  • Cleanup: You can fix elements automatically by pressing the Cleanup button.
  • Mode: Switch the mode when cleaning up.
    • Standard: Perform clean-up prioritizing local mesh settings.
    • Aggressive: Make mesh correction priority over mesh setting and clean up.
  • Non-manifold: Check to fix non-manifold.

    • Refresh

  • Show Model: Press the Show Model button to restore the model display.

    • - Operating Procedure -

    1.  Select the body you want to check the element shape.
    2.  Select the element quality measurement method.
    3.  Set the threshold of the element to be displayed.
    4.  Press the Apply or OK button.
    5.  If you want to restore the model view, press Show Model.

      6. ※The automatic cleanup feature can not automatically fix all elements. If there are elements that can not be fixed automatically, you need to manually fix the elements using the manual cleanup function.
