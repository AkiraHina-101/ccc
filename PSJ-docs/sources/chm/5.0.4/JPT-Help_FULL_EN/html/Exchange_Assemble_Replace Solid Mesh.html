Replace Solid Mesh

This is an assembly function for solid mesh parts. This function is useful for replacing parts in a solid mesh model or adding new parts.
Between solid mesh parts, the mesh pattern of one part will be replaced by the other part. The area around the replaced mesh will be remeshed and the nodes will be shared (shared faces will be created).


Ex) Add a new bolt (solid mesh)

  1. Unmatched threaded mesh (solid mesh hidden)
  2. Remesh around the threaded mesh of the case.
  3. Threaded mesh shares nodes (solid mesh hidden)

The remeshed elements and nodes will be grouped under the name "ReplaceSolidMesh".



Selection list

Source Face: Additional part to assemble.
Target Face: Original assembly part(s).

Options

  • Tolerance

    Enter the distance between the parts to extract the face pair.
    Replaces the mesh of the source face with the target face between the parts within the entered distance.

    • - Operating Procedure -

    1. Select a Source Face.
    2. Select a Target Face.
    3. Change the parameters of Option as needed.
    4. Click the Apply/OK button. The area around the target face will be remeshed and a Share Face will be created.

    - Operating Procedure (When a Mesh Error Occurs) -

    1. If a mesh error occurs, the remesh range will remain as a part.
    2. Manually correct the mesh error of the relevant parts.
    3. Merge the relevant parts back into the original part.

    - Precautions -

    • This function requires that the area of the source face be contained within the area of the target face.
    • The side of the target face that will be remeshed must be a tetrahedral element.
    • If the element types of the source face and target face parts do not match, the nodes are shared, but the shared face is not created.
    • Only one Source Face and one Target Face pair are supported. It is not possible to run on multiple distant pairs at the same time.
