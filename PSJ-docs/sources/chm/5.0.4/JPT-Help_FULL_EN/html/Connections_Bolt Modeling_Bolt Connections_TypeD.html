BoltConnections Type D

Join opposite surfaces with MPC within the specified range around the bolt holes.

Bolt Modeling

  • MPC Name

    Enter the name of the MPC item you want to create.

  • Show Bolt Image

    Display a summary view of the bolt. It is possible to change the bolt type you wish to create.

  • Connection Radius

    Specify the range of connection using MPCs, enter with radius R.

  • Plane Tolerance

    Specify the tolerance value for the MPCs when the target face is not flat.

    • Top Part Edge

  • Edges

    Turn on the button and select the top side of the edge. It displays the ID of the selected edge.

    • Bottom Part Edge

  • Edges

    Turn on the button and select the bottom side of the edge. It displays the ID of the selected edge.

    • - Operating Procedure -

    1.  Turn on the radio button of the Top Part Edge.
    2.  Select the target edge of the top side. (Multiple selection possible)
    3.  Turn on the radio button of the Bottom Part Edge.
    4.  Select the target edge of the bottom side. (Multiple selection possible)
    5.  Enter the Connection Radius R, that specifies the binding range.
    6.  Click the Apply or OK button.
