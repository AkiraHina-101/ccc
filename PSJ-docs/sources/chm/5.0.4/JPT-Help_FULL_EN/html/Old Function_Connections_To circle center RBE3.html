Connection | RBE3 - To Circle Center

This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element).
＊Master node is available for selection on face basis and edge basis.

Slave node and master node (in the connection range) are connected. Slave node is created on the coordinates of the centre of the selected arc.
This is useful when you want to create a RBE3 for a circle or a cylindrical shape.

In this function, you can set up multiple master term. For each section set the node, the weighting factor and the degree of freedom.

Connection

  • Name

    Enter the name to be registered.

    • Search Area

  • All

    Specify the connection range as infinite.

  • Tolerance

    Enter the radius R of the connection range.

    • Slave Dofs

  • UX - RZ

    Specify the component of slave degree of freedom.

    • Master Dofs

  • Term

    When you have finished the settings, number of section is displayed.

    • Add

      Add a section.

    • Remove

      Remove the section number that is displayed in the Term.

    • Edit

      Edit the section number that is displayed in the Term.

  • Weight

    Enter the weighting factor.

  • UX - RZ

    Specify the component degrees of freedom with a weighting factor.

    • Analysis Coordinate Frame

  • Coordinate

    Select the reference coordinate system.

    • Options for Abaqus

  • Surface Definition Output

    Select how to define the surface.

    • By Node Set

      Specify the node as a reference surface.

    • By Element Set

      Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output.

    • Options

  • Only corner nodes

    Connect only to the corner nodes of the selected entity.

    • - Operating Procedure -

    1.  Set the connection range.
    2.  Select the edge. Now, the coordinates of the slave node is defined at the center of the edge.
    3.  Enter the parameters of the slave.
    4.  [Repeat for each Term] Select a Face for the master nodes. If you do not select a face, edge nodes are specified as master.
    5.  [Repeat for each Term] Enter the parameters of the master.
    6.  [Repeat for each Term] Term > Add button. Setting 4) and 5) will be added to the Term.
    7.  If necessary, edit the coordinates of the slave node to arbitrary coordinate.
    8.  Click Apply / OK button.

    - Operating Procedure (Deletion of Term) -

    1.  Select the number of Term to be deleted.
    2.  Click the Term > Remove button. Term will be deleted.

    - Operating Procedure (Editing the Term) -

    1.  Select the number of Term to be edited.
    2.  Change the master nodes.
    3.  Change the parameters of master nodes.
    4.  Click the Term > Edit button. Term is edited.
