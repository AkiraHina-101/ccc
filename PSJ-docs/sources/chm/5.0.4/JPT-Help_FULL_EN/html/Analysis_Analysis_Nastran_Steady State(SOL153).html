Nastran | Steady State Heat Transfer (SOL 153)

Output the Input Deck for Nastran Steady State Heat Transfer analysis (SOL 153)

Job Option


　　　
  • Job

    Program: Select the type of Nastran Solver
        MSC: MSC Nastran
        NX: NX Nastran
    Job Name: Enter the name of the job. Output set by this name will be saved in the tree.
    Job Description: Enter a description for your job.

    　　　
    • 　　　
  • Solver Option

    Temperature: Specify the temperature tolerance
    Load: Specify the load tolerance
    Work: Specify the work tolerance
    Run Nastran: Run Nastran on the local machine
    Memory (MB): Define the memory allocation

    　　　
    • 　　　
  • System Cell and FMS

    System Cell: Enter data directly card to Nastran (System) section
    FMS: Enter text data directly in file management statement section

    　　　
    • 　　　
  • Executive Control Option

    GEOMCHECK, NONE: Disable the geometry checking option
    Direct text input: Enter the text data directly to the executive control section

    　　　
    • 　　　
  • Case Control Option

    ECHO: Define the echo output of bulk data
        NONE: No output
        SORT: Sorted output
        UNSORT: Unsorted output
        BOTH: Both sorted and unsorted output
    TITLE: Define the title at the time of print output
    Direct text input: Enter text directly to the case-control section

    　　　
    • 　　　
  • Bulk Data Option

    Write Type: Specify the output target
        By Model: Output to a single file
        By Each Part: Print a separate file for each part
        Selected Parts: Output of selected parts only
    GRID Format Type: Specify the Grid output format
        Single: Small field format output
        Double: Large field format output
        Single F.P.: Specify the floating-point number small field format output
    Delete Floating Nodes: Floating node is removed at the time of exporting output data
    Continuance Marker +: Outputs the continuation pointer + in at the time of exporting output data
    Include Bulk Data: Insert the bulk data file
    Direct text input: Enter text directly to the bulk data section

    　　　

    • Loading / Boundary Conditions


    　　　
  • Base:

    Define the boundary conditions that act on the entire analysis to be defined on the specific SUBCASE.
    Specify the boundary conditions case to be used in each of the boundary conditions. It will include all of the boundary conditions in Default.

    LOAD: Specify the load set
    SPC: Specify the constraints set
    MPC: Specify the multi-point constraint set
    Initial Temperature: Specify the initial temperature set

    　　　

    • Output Request


    　　　
  • Result type

    Specify the output request.
        PLOT: op2 Output
        PRINT: f06 Output
        PLOT&PRINT: op2 and f06 output
        Blank: No output

    Temperature: Specify the temperature output request
    FLUX: Specify the temperature gradient and heat flux output request
    SPCFORCES: Specify the single point constraint force output request
    OLOAD: Specify the applied load output request
    MPCFORCES: Specify the multi-point constraint force output request

    　　　
    • 　　　
  • Group (SET)

    The extent to which the elements results are output element and limits to specify the node group (set).
        ALL: Output all the elements, with respect to all the nodes
        Group: Output elements in the specified group, relative to node

    Temperature: Specify the output range with respect to the temperature output request
    FLUX: Specify the output range with respect to the temperature gradient and heat flux output request
    SPCFORCES: Specify the output range with respect to the single-point constraint force output request
    OLOAD: Specify the output range with respect to the applied load output request
    MPCFORCES: Specify the output range with respect to the multi-point constraints force output request

    　　　

    • Parameter


    　　　
  • Parameter:

    Define the parameters.

    POST: Specify the output type for the post-processing results file
        0: XDB Output
        -1: op2 Output (For Patran)
        -2: op2 Output (For I-DEAS)
    OGEOM: Control the geometry output to OP2
        YES: Yes geometry output
        NO: No geometry output
    AUTOSPC: Control the automatic restraint for stiffness singularity
        YES: Automatic constraint
        NO: No automatic constraint
    GRDPNT: Control the weight information output
    WTMASS: Define Mass correction factor
    K6ROT: Define the load factor for rotational stiffness of shell elements normal
    MAXRATIO: Define the matrix pseudo-singularity determination ratio
    BAILOUT: Control the execution against the pseudo-singularity
        0: Continue run
        -1: End run
    PRGPST: Control the print output for singularity summary table
        YES: Yes output
        NO: No output

    　　　


    • - Operating Procedure -

      　　　
    1.  The default output request is only the temperature result. You can change the result types in the output request. Once the changes are done, click the Apply (OK) button to output the data file.
