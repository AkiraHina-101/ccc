Line(2 Nodes)-Node

Measure the distance of a perpendicular line from a node toward the line defined by the two nodes.

Output

  • Distance

       The measurement result is displayed.

  • Input Unit

       Indicate the unit of distance to be displayed.


    • - Operating Procedure -

    1.  Select two nodes on the screen. These two nodes define a line segment.
    2.  Select the third node.
    3.  The distance shows the shortest distance between the line segment and the node.
