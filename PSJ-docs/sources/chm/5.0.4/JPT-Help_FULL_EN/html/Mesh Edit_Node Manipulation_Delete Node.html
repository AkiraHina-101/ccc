Delete Node

Remove all of the floating node or the specified floating node in the model.

Delete Floating Node

- Operating Procedure -

  • If you want to remove the selected node only
    1.  Select the floating node that you want to delete.
    2.  Click the Apply or OK button.

  • If you want to delete all the Floating Node
    1.  Click the Apply or OK button. (without selecting a node)
