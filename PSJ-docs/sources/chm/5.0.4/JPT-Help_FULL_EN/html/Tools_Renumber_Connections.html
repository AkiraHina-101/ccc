Renumber | Renumber Connections

Renumber the connection element ID.

Setting

  • Connection Type

    Select the type of connection element.

  • Auto Renumber

    Rows with the Enable column checked are renumbered starting from the Start ID of the top row.

    Options

  • Solver Type

    Select the solver type from Nastran / ADVC.

  • Search ID

    Click the "Search" button to highlight the row containing the specified ID in the table.

    - Operation Procedure -

    1.  From the solver type selection, specify the solver type.
    2.  Specify the entity you want to renumber from the connection type.
    3.  Specify the Start ID of each column. Or, after specifying the Start ID on the top line, click the Auto Renumber button.
    4.  Press the Apply button to execute the renumbering.

    ※Connection element ID at export starts from maximum ID + 1 of element if renumbering is not performed.
