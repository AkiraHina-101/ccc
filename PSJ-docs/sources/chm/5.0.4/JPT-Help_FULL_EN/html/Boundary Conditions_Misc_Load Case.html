Load Case

Load Case Dialog Box

This command creates a load case that bundles loads and constraints.
Load cases can be referenced when creating analysis solver input data.

  • Name

    Enter the name of the load case to be created.

  • ID

    Specify LOAD, SPC and MPC ID for Nastran.

  • Coefficient

    Enter the load factor for Nastran that applies to the entire load case to be created.
    Used when multiplying the load by a factor.

  • All Created Boundary Conditions

    List existing created loads and constraints.
    Use the checkboxes to make a selection.

  • Selected Boundary Conditions

    List the loads and restraints used in the load case to be created.
    Enter a coefficient for each load.


    • - Operating Procedure -

    1.  Enter the load case name to be created in Name.
    2.  Enter a weighting factor for the factor if necessary (for Nastran).
    3.  From the list of all created boundary conditions, select the Load and Constraint checkboxes to be placed in the load case.
      The selected condition is displayed in the selected boundary condition list.

    4.  Press the Apply or OK button to create a load case.


      5. *The created load case is specified by Nastran output under "Loading / Boundary Conditions" or with the subcase option "LOAD".

       The LOAD card as shown below is output.
