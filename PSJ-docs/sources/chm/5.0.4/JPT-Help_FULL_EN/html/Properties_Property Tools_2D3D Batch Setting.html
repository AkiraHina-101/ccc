2D3D Batch Setting

Set material properties for each part at once. Material properties that can be set are 2D / 3D / Gasket.
The name of the material property will be the same as the part name.



Material Setting

  • Browse material lib

    The name of the currently set material library. You can specify any material library.

  • Table Table The first row of each column allows you to sort and filter by any name.
    • Part

      A list of part names.

    • Material

      Select a material from the material library.

    • Type

      Select a material property type from 2D / 3D / Gasket.

    • Thickness

      Type = 2D parameter. Enter the plate thickness of the element.

    • ThicX/Y/Z

      Type = Gasket parameter. Specify the thickness direction of the gasket with a direction vector.

    • Uniaxial

      Type = Gasket parameter. Select the thickness direction behavior option. Only valid for ADVC and ABAQUS.


    • - Operating Procedure -

    1. Specify the material library.

    2. In the list, specify the material and type to set for each part.

    3. Change the parameters in the list as needed.

    4. Click the Apply button. Material properties are set for each part at once.

    - Operating Procedure : Input / output of table settings -

    1. Click the Export Setting File button. Outputs the table settings (* .csv).

    2. Click the Import Setting File button. Read the table settings (* .csv).

    - Notes -

    • This function selects a material from the material library. Create a material library in advance with Material command.
