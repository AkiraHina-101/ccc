Actran Execute Job

This dialog is used to perform Actran calculations.
In order to perform Actran calculations from Jupiter, the ACTRAN_PATH environment variable (Ex. c:\FFT) and ACTRAN_PRODUCTLINE environment variable (Ex. c:\FFT\Actran_11.2) must be accurately defined.

Actran Job

  • Job Description

       Specify the job description.

    • Actran Execution

  • Job Type

       Specify the analysis type.

    • Direct  : Specify the basic analysis type.
    • Green Analysis(Sequential)  : Specify the Green analysis (Sequential) calculation.
    • Green Analysis(Solution)  : Specify the Green analysis (Solution) calculation.
  • Infinite Space Type

       Specify the infinite boundary type.

    • PML  : Specify the model using the sound-absorbing layer.
    • IFEM  : Specify the model using the infinite boundary surface.
