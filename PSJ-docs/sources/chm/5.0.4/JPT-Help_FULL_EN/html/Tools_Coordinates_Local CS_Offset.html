Local CS [Offset]

Move the coordinate system selected from the screen to the specified position.

　　

Coordinate

  • Type

       Choose the Type of the coordinate system.

    • Rectangular : Select the Cartesian coordinate system.
    • Cylindrical : Select the cylindrical coordinate system.
    • Spherical : Select a spherical coordinate system.

  • Name

       Enter the name of the coordinate system to be created.

    • Refer Coordinate Frame

  • Coordinate

       Select the global coordinate system or existing local coordinate system.

    • Translate

  • TX/TY/TZ

       Enter the amount of movement of the X / Y / Z direction of the reference coordinate system.

  • Create New

       Choose to create a new coordinate system.


    • - Operating Procedure -

    1.  Select the type of coordinate system from Type.
    2.  Enter the name of the coordinate system to be created.
    3.  Select the direction of movement of the reference coordinate system from the Coordinate.
    4.  Choose one of the coordinate system to refer to the movement.
    5.  Enter the amount of offset in each of X, Y and Z direction in TX, TY and TZ.
    6.  If you want to create a new coordinate system after the offset, check the New Box.
    7.  Press the Apply or OK button.
