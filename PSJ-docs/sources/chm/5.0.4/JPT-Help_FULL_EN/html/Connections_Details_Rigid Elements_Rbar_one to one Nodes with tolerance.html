Connection | RBar - One to One (Nodes with tolerance)

This command is used to create one to one (master/slave) RBARs (rigid body elements).
The only cases supported are those with all components of the independent degrees of freedom are on one side of the nodes.

RBARs are automatically defined between nodes selected within the specified range. The node with the younger ID is defined as the master node.

Connection

  • Name

    Specify the name for registration.

    • Search Area

  • Tolerance

    Specify the search range of the connection point.

    • Master Dofs

  • UX - RZ

    All components of the independent degrees of freedom are specified for the selected master node.

    • Analysis Coordinate Frame

  • Coordinate

    Specify the reference coordinate system.

    3.  Define parameters.
