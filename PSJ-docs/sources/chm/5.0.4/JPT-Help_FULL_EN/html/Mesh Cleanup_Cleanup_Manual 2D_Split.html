Split

Split the elements.

Split

  • Equivalence

    When checked, it will combine the node and the selected nodes that have been created in the element division.

  • Parameter

    Set the ratio while splitting.
    ※Used to split the selected elements into two. Please note that you cannot specify otherwise.

    • - Operation Procedure (1) -

  • To split the two selected element
    1.  Select the edge of the elements you want to divide.
    2.  Click the Apply button.
    3.  Edge of the selected element will be split.

    - Operation Procedure (2) -

  •  If the number of divisions in the elements that are adjacent do not match, it splits the element and aligns.
    1.  Check the Equivalence.
    2.  Select the edge of the elements you want to divide.
    3.  Select the node which is to be the starting point of divide.
    4.  Click the Apply button.
    5.  Selected element edge will be split from the selected node as the starting point of the division. In this case, the selected node and the newly created node is integrated.
