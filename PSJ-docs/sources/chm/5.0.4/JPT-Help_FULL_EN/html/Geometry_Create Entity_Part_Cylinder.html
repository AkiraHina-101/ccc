Cylinder

Create a cylindrical body.

Part Properties

  • Part Name

    Enter the name of the cylindrical body to be created.

    • Cylinder

  • Local Coordinates

    Select any of the coordinate system.

  • Hollow Cylinder

    When checked, it creates a hollow shape.

  • Tapered

    When checked, it creates a cylindrical shape in a tapered form.

  • Origin-X,Y,Z

    Specify the origin coordinates.

  • Inner Radius

    Enter the inner radius of the cylindrical body.

  • Outer Radius

    Enter the outer radius of the cylindrical body.

  • Inner Radius2

    Enter the inner radius of the lower side of cylindrical body. (For Taper only)

  • Outer Radius2

    Enter the outer radius of the lower side of cylindrical body. (For Taper only)

  • Height

    Enter the height of the cylindrical body.

  • Number of Nodes in Circle

    Enter the number of nodes to be generated on the arc.

  • Number of Nodes in Axis

    Enter the number of divisions in the axial direction of the cylinder.

    • - Operating Procedure -

    1.  Enter the part name in the Parts Name.
    2.  Specify the origin coordinates in Origin-X, Y, Z.
    3.  Enter the outer radius of the cylindrical body in Outer Radius.
    4.  Enter the height of the cylindrical body in Height.
    5.  Enter the number of nodes to be generated on the arc in Number of Nodes in Circle.
    6.  Enter the number of divisions of the cylinder axis direction in Number of Nodes in Axis.
    7.  Click Apply / OK button.
