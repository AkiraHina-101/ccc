Free Edges

It will detect the Free Edge and Non-manifold error.

Number of Edges

  • Free

    •    It displays the number of Free Edges.

  • Nonmanifold

    •    It displays the number of Non-manifold.

    Display Options

  • Mesh Color

    •    Set the display mesh number of layers around the Free Edge and Non-manifold.

    • Original : Change only the color of edge, without changing the color of Mesh.
    • Gray : It displays the color of the existing Edge.
      •

  • Display All

    •    If you have turned on, you will see all the Mesh around the Free Edge and Non-manifold. Number of Layers will be grayed out.

  • Number of Layers

    •    Set number of layers of the display Mesh around the Free Edge and Non-manifold.

  • Free Edges

    •    If you turn on, it displays the Free Edge.

  • Nonmanifold

    •    If you turn on, it displays the Non-manifold.

  • Nonmanifold Threshold

    •    Enter the minimum number of elements connection for the Non-manifold.

  • Hide Boundary Edges

    •    It displays the Free Edge other than outer frame of the shell shape.

    Close Gap

  • Dist. Tolerance

    •    Set the distance between nodes that can be moved up to at the time of execution.
       (For more than 1mm gap, Non-manifold does not automatically junction with respect to the model that is not closed, such as the mid-plane).

  • Close Gap

    •    Automatically joining gaps between the elements.

    Output Options

  • Error Text

    •    When it is turned on, the information of Free Edge is output to the Output window with the Text data and the Temp folder of Install Path.

    - Operating Procedure -

    1.  Select the Part to be checked.
    2.  Change the Layer number and check items in the Display Option if necessary.
    3.  Press the Apply or OK button.
    4.  After checking, click the Reset to Normal Display Mode icon  in the main window to return to the original display.
