Contacts | Pattern Match

Check the mesh pattern on the mating face.Pattern match function detects the contact and displays the mesh pattern ,whether matches or not between pair faces to be defined.



  • Show mismatched pattern

       Displays the part where the mesh pattern does not matches.

  • Show matched pattern

       Displays the part where the mesh pattern matches.

  • Search tolerance

       Enter the distance between faces to detect the mesh pattern.

    • - Operating Procedure - 

    1.  Select two or more adjacent parts.
    2.  If necessary, Change the tolerance value from the default value.
    3.  If necessary, Select "Show mismatched pattern" and "Show matched pattern" checkbox.
    4.  Click Apply. If "Show matched pattern" is checked, mesh is displayed in blue where mesh patterns matches each other. If "Show mismatched pattern" is checked, meshes are displayed in red where mesh pattern does not match each other.
