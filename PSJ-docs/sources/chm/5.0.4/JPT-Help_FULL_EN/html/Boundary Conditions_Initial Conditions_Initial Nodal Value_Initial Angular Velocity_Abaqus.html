Initial Angular Velocity | Abaqus

Set the initial angular velocity for motion analysis.

　　

Structural

  • Name

    Enter a name for the initial angular velocity.

    • 　　

    Parameters

  • Value

    Enter the initial angular velocity value.

  • Input Unit

    Specify the input unit.

  • Axis point 1

    Enter the start point coordinates.
    (Input method: x, y, z)

  • Axis point 2

    Enter the end point coordinates.
    (Input method: x, y, z)



    • - Operating Procedure -

    1.  Select the entity to set the initial angular velocity.
    2.  Enter the initial angular velocity value.
    3.  Enter the start point coordinates.
    4.  Enter the end point coordinates.
    5.  Press the Apply or OK button.
