By Surface

Select parts to split along the specified surface.

※This function doesn't support cutting the shared face.

Selection Plane

  • Partition Only

    When it is checked, a partition is created inside. In this case, the parts are not split.

  • Make Section Face

    If you check this box, in the case of dividing the parts, a face is created at the section.

  • Shared Face

    When this box is checked while dividing the parts, a shared surface is created at the division plane.

  • Separate Face

    When this box is checked while dividing the parts, if you want to create a face to the division place, it prevents the face to be coupled (merge) in the enclave.

    • - Operation Procedure (When dividing a part and creating a face at the divided part) -

    1.  Select the coordinate plane to split.
    2.  Open the selection list window and click the Target button.
    3.  Select the parts to split.
    4.  Click the Cut button in the selection list window.
    5.  Select the face to be divided.
    6.  Select the Make Section Face check box.
    7.  Click the Apply / OK button.

    - Operation Procedure (When creating partitions only without dividing parts) -

    1.  Open the selection list window and click the Target button.
    2.  Select the parts to split.
    3.  Click the Cut button in the selection list window.
    4.  Select the face to be divided.
    5.  Select the Partition Only check box.
    6.  Select the Make Section Face check box.
    7.  Click the Apply / OK button.
