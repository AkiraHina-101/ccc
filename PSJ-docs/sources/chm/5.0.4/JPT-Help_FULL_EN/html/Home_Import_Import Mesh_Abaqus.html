Import Abaqus Inp

This command is used to import Abaqus files（.inp）.

Import Type

  • Standard Abaqus Inp

    •    Import the model geometry only.

  • Standard Abaqus Inpby Property

    •    Import the model geometry and material property. A body is created for each material property.

    Angle

  • Face Angle

    •     Specify the tolerance angle in order to determine the face division. Define a face by creating an edge between adjacent elements with an angle smaller than the specified value.

  • Edge Angle

    •     Specify the tolerance angle in order to determine the edge division. Divide an edge by creating a vertex on adjacent edge elements with an angle smaller than the specified value.

    - Operating Procedure -

    1.  Launch the command, specify each option and click the OK button.
    2.  Select the target data in the dialog and click the Open button.
