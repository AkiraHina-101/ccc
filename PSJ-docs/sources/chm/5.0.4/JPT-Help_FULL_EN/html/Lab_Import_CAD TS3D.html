Import CAD TS3D

Import CAD data into Jupiter. It is offered as a trial version of the new Import CAD function.
*It has possiblity to change functionality or eliminated in future version.

File Path

   Find and select CAD data file.

Tessellation Level

   Set parameters for importing CAD data.

  • Mid

       The number of divisions is automatically adjusted so that the elements (facets) that make up the face of the loaded CAD model have mid density.

  • High

       The number of divisions is automatically adjusted so that the elements (facets) that make up the face of the loaded CAD model have high density.

  • Extra High

       The number of divisions is automatically adjusted so that the elements (facets) that make up the face of the loaded CAD model have extra high density.

  • Max Length of Tri Edge

       If enabled, specifies the length of the maximum element edge of the triangular primary elements that make up the faces of the CAD model. The applicable unit is mm.

  • Tolerance for auto stitch

       If enabled, sets the tolerance value for auto stitch. The applicable unit is mm.

    - Operating Procedure -

    1.  Select CAD data files.
    2.  Change the Tessellation Level settings as required.
    3.  Click the Apply / OK button.
