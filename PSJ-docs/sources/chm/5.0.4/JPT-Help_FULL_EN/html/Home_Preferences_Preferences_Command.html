Save/Load

Allows you to configure default settings for command dialogs and menu.

Common

  • Options

    • Data Validation

      • Enables it and set data validation check for input are af each command dialog. Enables it and avoid to input wrong value for the command. Disable allows to input any value there.

    • Display confirmation dialog for the model target functions

      • It displays dialog to confirm before execute a command when it targets whole the model if no selection.
  • Dialog Boxes State
    • Reset button

      • Reset all the values in command dialog to the default settings. Until click this button, basically the latest input value is kept in those fields.

    • Keep the latest position of Selection List Dialog

      • Enables it and set the position of Selection List of Command Dialog not to next to the command dialog but anywhere user moved and keeps.

    Mesh Size for Auto Setting

    Specify the original value for Auto setting of Surface Meshing and Local Remesh command and its value.

    Post

    Configure the settings for Post documents.

  • Animation Section Settings

    • Specify default value of Section Display Method in Animation Settings.

  • Chart Setting

    • Specify defalut value of LogDype in Chart ribbon.

    - Operating Procedure -

    1.  Specify each option and click Apply or OK button.
