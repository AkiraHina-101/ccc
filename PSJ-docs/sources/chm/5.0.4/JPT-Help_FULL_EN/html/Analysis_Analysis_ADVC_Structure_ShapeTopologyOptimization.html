Shape/Topology Optimization

Output the Shape/Topology Optimization Analysis file to ADVENTURE Cluster (Hereafter ADVC).

User can refer ADVC Structure Analysis for more details about ADVC Process, Interval Definition, Output Definition,...

Objective Function

  • Type Of Function

    • First: Shape Optimization supports 10 functions. Topology Optimization supports all except Displacement, Eigen Frequency, Surfae Area.

    • Second: User can select multiple Objective Function by Add button.

    • Third: Supports show/blurred for the required parameters for the corresponding function.

    • Fourth: Supports yellow out for wrong type or blank, show warning log when the required parameter is not full out.

    • Fifth: When exporting Objective Function, .adx file include $ComplianceFunction (Optional Parameter) and $Objective Function command.

    • Sixth: The process number used in process number is a number assigned to each process consecutively from 0 in the order of analysis in the process configuration.

    • Seventh: If you specify All, specify all the processes in the process configuration. If you specify Last, specify the last process in the process configuration.

    • Eighth: If you omit the process number without specifying it and specify only the process configuration ID, the Last process is specified.
      •
    • Edit: Support editing parameter directly after wrong typo or next analysis.

    • Add: Support adding function directly, show parameter in information area.

    • Delete: Support deleting function directly.

    • Up: Change order of function by moving up.

    • Down: Change order of function by moving down.

  • Shape Optimization

    Optional Parameter

    • Max Iteration: Specify maximum number of Shape Optimization iterations.

    • Max Strain: Specify maximum strain magnitude.

    • H1 Tolerance: Specify convergence tolerance for Shape Optimization.

    • Output Last: Select whether to output the final result of the optimization iteration.

    • Output Interval: Specify the output interval of the optimization analysis result.

    • Resout Last: Select whether to output the final result of the optimization iteration as a restart file.

    • Resout Interval: Specify the output interval of the optimization restart file.

    • Armijo Check: Select whether to use Armijo criteria to choose whether to adjust the step size.

    • Armijo Parameter: Specify Armijo parameter.

    • Auto Increment: Select either automatic step width or fixed step width for optimization.

    • Stabilization Factor: Specify the stabilization factor for Shape Optimization. The larger value, the more effective it is to suppress the overall movement.

    • Poisson Ratio: Specify Poisson's ratio used in the H1 gradient method.

    • Auto Frozen: Automatically disable all degrees of freedom in areas with specific boundary conditions in load cases or not.

    • Matrix: Select StiffnessLinear or Stiffness use for Shape Optimization.

    • Wolfe Check: Select whether to use for Wolfe criteria - increase the step size. The Wolfe standard is dual to the Armijo standard and sets a lower limit for each step size.

    • Wolfe Parameter: Specify Wolfe parameter.

    • Element D.Stiffness: Select Yes or No use for Shape Optimization.
      •

  • Topology Optimization

    Optional Parameter

    • Initial Density: Specify the initial value of the density ratio (value from 0 to 1).

    • Density Random: Specify value from 0 ? rwidth ? 0.5 adds a normal random number in the range (?rwidth, rwidth) to the initial density ratio (phase) of the optimized iterative method.

    • Alpha: The SIMP (solid isotropic material with penalization) rule is used, and φα (θ (x)) is used as the correction of the physical property value.

    • Max Iteration: Specify maximum number of Topology Optimization iterations.

    • Max Theta: Specify the maximum value of the magnitude of the phase change.

    • H1 Tolerance: Specify convergence tolerance for Topology Optimization.

    • Output Last: Select whether to output the final result of the optimization iteration.

    • Output Interval: Specify the output interval of the optimization analysis result.

    • Resout Last: Select whether to output the final result of the optimization iteration as a restart file.

    • Resout Interval: Specify the output interval of the optimization restart file.

    • Armijo Check: Select whether to use Armijo criteria to choose whether to adjust the step size.

    • Armijo Parameter: Specify Armijo parameter.

    • Auto Increment: Select either automatic step width or fixed step width for optimization.

    • Stabilization Factor: Specify the stabilization factor for Topology Optimization. The larger value, the more effective it is to suppress the overall movement.

    • Auto Frozen: Automatically disable all degrees of freedom in areas with specific boundary conditions in load cases or not.

    • Wolfe Check: Select whether to use for Wolfe criteria - increase the step size. The Wolfe standard is dual to the Armijo standard and sets a lower limit for each step size.

    • Wolfe Parameter: Specify Wolfe parameter.

    • Gray Scale Ratio: Specify gray scale ratio.

    • Output Gray Scale Ratio: Specify output following gray scale ratio or not.
      •
  • Topology Optimization Die Drawing

    Required Parameter

    • Direction: Specify the constraint conditions to obtain a shape that can be die-cut by Topology Optimization. Define X Y Z, for example 0 0 1 (X=0,Y=0,Z=1).
      •

    • Optional Parameter

    • Element Set: Select area using for Topology Optimization Die Drawing by element group or property.

    • Punching|Oneside: Specify the type of die cutting. Punching is punched and Oneside is one-sided die punching.

    • Coordinate: Specify the coordinate system of the die-cutting vector. If not specified, it will be the entire coordinate system.
      •

    Output Parameter

  • All types of output request for Shape/Topology Optimization

    • Shape Variation: Specify Shape Variation for Shape Optimization, can avoid obtaining an extremely different shape from the initial shape.

    • Nodal Density Ratio: Nodal density ratio as a result of Topology Optimization.

    • Density Ratio: DensityRatio as a result of Topology Optimization.

    • Sensitivity: Sensitivity is the sum of the sensitivity of the Objective Function & Constraint Function multiplied by the Lagrange undetermined multiplier calculated to satisfy the constraint value.

    • Sensitivity Of Objective Function: Sensitivity of the sensitivity of the Objective Function.

    • Sensitivity Of Constraint Function: Sensitivity of the sensitivity of the Constraint Function.

    • Sensitivities: If specify Sensitivities, you can specify all sensitivity information at once.
      •

    • - Operating Procedure -

    1.  Specify the Job Name.
    2.  Create a process with Make Process. If you want to perform the analysis in increments of default time, you do not particularly need to specify the time.
    3.  Assign the boundary conditions in the LBC Manager.
    4.  Select the output item in the Output Manager.
    5.  Click to Shape/Topology Optimization button for setting all parameters.
    6.  Need to set up at least 4/5 pages for completed calculation, Non-Designable Area may be needed or not. Please pay attention to Required Parameter.
    7.  Click Apply/OK button.
