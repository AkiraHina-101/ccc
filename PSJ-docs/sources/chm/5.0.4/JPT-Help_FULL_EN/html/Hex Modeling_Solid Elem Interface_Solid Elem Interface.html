Solid Element Interface

This command creates a pyramid element whose base is a square element.

Options

  • Flip Normal

    If checked, it will be created behind the face.



    - Operating Procedure -

    1.  Open the selection list window and click the face button.
    2.  Choose a face to create a solid element.
    3.  If you want to create on the back of the face, select the Flip Normal check box.
