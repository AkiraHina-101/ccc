Contacts | ANSYS - Contact Table

The gap distance between parts automatically detects contact pairs and creates contact definitions.

Contact

　　　
  • Finding Tolerance

    Enter the gap distance between parts to detect contact pairs. Detect faces below input tolerance and displays contact pair candidates.

    　　　
    • 　　　
  • Tolerance for TIED

    Enter the gap distance between parts for tied definition. Among the detected contact pairs, the contact pair candidate that is less than the entered tolerance is automatically defined as the tied definition. Other than that, it is a sliding contact definition.

    　　　
    • 　　　
  • Input Unit

    Specify the unit system of tolerance.

    　　　
    • 　　　
  • Search Area

    Specify the range of contact pairs and candidate faces. When minimized, only faces found with search tolerance will be displayed as potential contact pairs. When maximized, it will display as a contact pair candidate up to the face that smoothly connects with the searched face.

    　　　
    • 　　　
  • Master Basis

    Specify the contact segment judgment criteria to be the master face of the detected contact pairs.
    Mesh size: Segment group with large element surface area average value
    Area: Segment group with large total area

    　　　
    • 　　　
  • Find Contact

    Faces are detected based on input tolerance and contact pair candidates are displayed in a table.
    When running without selecting a part, you will see a confirmation message about performing a search across the part.

    　　　
    • 　　　
  • Options

    Select the contact option to display in the table.

    　　　

    • Table


    　　　
  • Option Title Bar

    Clicking on each title will sort the contact pair candidates by the item name. To change the option to display, specify from the option button.

    　　　
    • 　　　
  • Search Box

    Only show partial matching contact candidates. Click the X button to cancel the search.

    　　　
    • 　　　
  • Checkbox

    Of the detected contact pairs, check the contact pairs that you actually define. Click Apply (OK) button to create a contact pair.

    　　　
    • 　　　
  • Contact table

    Selecting the contact pair candidate displayed in the table highlights the contact pair in the model window. The color of the master / slave contact segment depends on the Home > Preferences > Screen Settings > LBC Master Color / Slave Color setting.

    　　　
    • 　　　
  • Contact Option Setting

    Edit the displayed contact options in the table.
    For each contact option, the input method is divided into check box, pull-down selection, numerical input, and another dialog display button. Even after creating contact pairs, the contact options can be edited individually.

    　　　
    • 　　　
  • Table Function Buttons

    All On: Select all contact pair candidates.
    Switch Master / Slave: Switch master / slave segment group of contact pair.
    All Off: Deselect all contact pairs.
    Edit: Open and edit the contact pair candidate selected in the table in the manual group dialog.
    Delete: Delete the contact pair candidate selected in the table.
    Export: Output contact option information of existing contact pairs (contact pairs without check box on / off of table) to csv file.
    Import: Load a csv file of contact option information and update the existing contact pair information in the table.

    　　　

    • - Operating Procedure -

    　　　
  • Procedure for creating a new contact pair 　　　
      • 　　　
    1.  Enter the respective tolerance values for Finding tolerance and Tied tolerance and press the contact search button.
         If you want to narrow the detection range, select multiple parts and press the button. The default (parts not selected) detects contact between all parts.
      2. 　　　
    2.  Select the contact pair candidate displayed in the table and check the location on the model window.
      3. 　　　
    3.  Change the contact option of contact pair if necessary. Also, uncheck the checkbox if there is an unnecessary contact pair.
      4. 　　　
    4.  Press the OK button to define the contact pair.
      5. 　　　
    5.  A contact pair is created under All Items > Contacts in the assembly window. Each contact pair can be edited by right click> Edit.


    　　　
  • Confirmation and addition of contact pairs using the contact table 　　　
      • 　　　
    1.  Start contact table command with contact pairs defined.
         The existing contact pairs are displayed in the table.
      2. 　　　
    2.  By selecting an existing contact pair displayed in the table, you can check the location on the model window.
      3. 　　　
    3.  When searching for a new contact pair, after entering the tolerance, select the part to be detected and press the Find Contact button.

         If a newly detected contact pair candidate overlaps with an existing contact pair, the candidate is displayed in red.
      4. 　　　
    4.  Change the contact options as required and click the OK button to define the contact pair.
         A new contact pair with the check box marked is added.


    　　　
  • Output and update contact option information for existing contact pairs 　　　
      • 　　　
    1.  Start contact table command with contact pairs defined.
      2. 　　　
    2.  Press the export button below the table to output the contact option information file.
      3. 　　　
    3.  Open the output csv file and change the contact option settings. Master / slave group names can not be changed.
      4. 　　　
    4.  Click the Import button to import the edited csv file.

         The contact option settings are updated with the contents edited in the csv file.
