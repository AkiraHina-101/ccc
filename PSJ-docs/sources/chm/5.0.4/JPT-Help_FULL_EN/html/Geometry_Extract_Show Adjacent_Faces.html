Faces

By setting the face and the border of starting the search (face and angle), select adjacent face in the specified boundary.
By using this feature, you can perform easy removal of the surface of mold parts and extraction of the water jacket of engine parts.

Search

  • All

    When checked, the search area will be all the faces. When unchecked, the number of layers specified in the Number of Layers will be the search range.

  • Number of Layers

    Enter the number of layers to be a search range.

    • Stop

  • Include Stop Faces

    When you check, you can also select the boundary surface.

  • Stop Angle up to

    Enter the angle as a boundary.

    • Preview

  • Preview

    You can see all the faces which are selected. Those faces will be shown in the Main Windows with the colour you've selected.

  • Reset

    Reset the faces identified in Preview button.

    • - Operating Procedure -

    1.  Select the Start Face. (You can select more than one element at distant location)
    2.  Select the Stop Face. (If you only specify a boundary angle, you do not need to select stop element)
    3.  Set the search range.
    4.  Set the boundary.
    5.  Check the selection in the Preview / Reset.
    6.  Click Apply / OK button.
    7.  By making the Group of the extracted faces, it is easier to carry out any modification if you find any errors.
