Section

You can register a cross-sectional in the library.

Buttons

  • Add

    Open the Cross Section dialog box, and then register a new cross-section.

  • Modify

    Open the Cross Section dialog box, and then edit the cross-section.

  • Delete

    Remove the cross-section.

  • Import

    Load section performance in slib format of 1D property library.

  • Export

    Export cross section performance in slib format of 1D property library.

    • Cross Section Dialog Box

    Calculate the cross-section property values. Created value is registered in the Section pull-down menu.

    General

    Enter the general cross-section properties.

    Name
    Enter the name of the cross-section properties to be registered.

    Type
    Selected calculation type is displayed.

    Shape
    Select the general cross section to be applied. Dimensions variable name will be displayed to the right of the image and the size table, according to the selected shape.

    Tapered
    The cross-sectional size of left and right side of the selected beam will be different. It will be the two input to be specified in the size variable.

    Size Table
    Enter a value in the dimensions variable to be displayed.

    Elem Y-dimension Dir
    Select the Y-axis direction of the cross section.

    Input Unit
    Select the local coordinate system of the cross-section calculation.

    Library

    Use the cross-sectional shape library of Nastran.

    Name
    Enter the name of the cross-section properties to be registered.

    Type
    Selected calculation type is displayed.

    Shape
    Select the type of cross section library in Nastran. Dimensions variable name of Nastran will be displayed to the right of the image and the size table, according to the selected shape.

    Tapered
    The cross-sectional size of left and right side of the selected beam will be different. It will be the two input to be specified in the size variable.

    Size Table
    Enter a value in the dimensions variable to be displayed.

    Elem Y-dimension Dir
    Can not be selected.

    Input Unit
    Select the local coordinate system of the cross-section calculation.

    - Operation Procedure (Add) -

    1.  Click the Add button to open the Cross Section dialog box.
    2.  Enter the parameters.
    3.  Click the OK button in the Cross Section dialog box.

    - Operating Procedure (Edit)  -

    1.  Click the edit section of the cross-section table.
    2.  Click on the Modify button to open the Cross Section dialog box.
    3.  ＊Even if you double-click cross-section table, it opens the Cross Section dialog box for editing.
    4.  Enter the parameters.
    5.  Click the OK button in the Cross Section dialog box.

    - Operating Procedure (Delete) -

    1.  Click Delete the target of the cross-section table (Multiple selections are possible).
    2.  Click the Delete button.
