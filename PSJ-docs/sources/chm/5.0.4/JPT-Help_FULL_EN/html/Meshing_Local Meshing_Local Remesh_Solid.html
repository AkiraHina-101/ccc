Local Remesh | Solid

Solid mesh the specified range (sphere) of the tetra solid mesh model again.
It is used to regenerate the solid mesh while maintaining the surface mesh when there is a poor quality tetra element.

Remesh Region

  • Origin-X,Y,Z

       Enter the center coordinates of the remesh range (sphere).
       It is automatically input by node selection. When specifying multiple ranges, coordinate value input is not supported, so select multiple nodes.

  • Radius

       Enter the radius of the remesh range.

    • Attributes

  • Grading Factor

       Enter the grading factor value of the element.

  • Stretch Limit

       Specify the element stretch limit value at mesh creation.


    • - Operating Procedure -

    1.  In advance, display the places where the element quality is bad.
    2.  Select the part to be remeshed. If no part is selected, all parts included in the range will be remeshed.
    3.  Select the center node of the remesh range. If there are multiple locations, select multiple nodes.
    4.  Enter the radius, narrow the remesh range, and click the Apply / OK button.


      5. Fixing the surface mesh makes it difficult to improve the quality or it may appear elsewhere. In that case, please perform element editing manually including surface mesh.
