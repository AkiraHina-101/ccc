- Definition of Quality Check Method -

① Stretch

  • Check the values obtained by the following formula for Tri / Quad / Tetra / Hexa elements.

    •    Tri = R × 2√3 / maxSide
       Quad = √(√2 × minSide / maxDiag)
       Tetra = (6√6 × V) / ( S× maxSide)
       Hexa = (maxLen / minLen) × √3

             R             :  Inscribed circle radius
             maxSide  :  Maximum element edge length
             minSide   :  Minimum element edge length
             maxDiag  :  Maximum diagonal length
             V             :  Element volume
             S             :  Element surface area



    ② Aspect Ratio

  • Check the values calculated by the following formula for Tri / Quad / Tetra / Hexa elements.

    •    Tri = ( √3 × maxSide2) / (4 × Area)
       Quad = maxMidLen / minMidLen
       Tetra = (S × maxSide) / (6√6 × V)
       Hexa = maxLen / minLen

             maxSide      :  Maximum element edge length
             Area            :  Element area
             maxMidLen  :  Maximum opposite side middle point distance
             minMidLen   :  Minimum distance between opposite sides
             S                 :  Element surface area
             V                 :  Element volume



    ③ Edge Length

  • Check element edge length for Tri / Quad / Tetra / Hexa elements


    • ④ Area

  • Check element area for Tri / Quad elements.


    • ⑤ Node Valence

  • For a Tri / Quad element, check the number of elements including a particular node.


    • ⑥ Interior Angle

  • For Tri / Quad elements, check the smallest value among the element edge angles around the nodes.


    • ⑦ Node Free Edges

  • Check the number of free edges connected to one node for Tri / Quad elements.


    • ⑧ Duplicate Elements

  • Check the number of duplicate elements for Tri / Quad elements.


    • ⑨ Warping

  • For a Quad element, divide the Quad element into two Tri's and check the maximum value of the angle between them.

    •    value = MAX (Angl , Ang 2)



    ⑩ Skewness

  • Check the angle formed by two lines connecting the midpoints of opposite sides of a Quad element.


    • ⑪ Taper

  • Check the maximum difference between the Quad element and the average value of the Tri area connecting 3 nodes in the Quad element.

    •    value = MAX (aRatio i)    i = 1~4
       aRatio i = ABS {( triArea i - triAreaAvg) / triAreaAvg}
       triAreaAvg = (triArea1 + triArea2 + triArea3 + triArea4) / 4

             triArea i  :  Tri i 's area
             Tri1        :  Triangle consisting of Node 1, 2, 3
             Tri2        :  Triangle consisting of Node 3, 4, 1
             Tri3        :  Triangle consisting of Node 2, 3, 4
             Tri4        :  Triangle consisting of Node 4, 1, 2



    ⑫ Volume

  • Check element volume for Tetra / Hexa elements.


    • ⑬ Jacobian Factor

  • For the Tetra element, check the value obtained by the following formula.
       If the midpoint is on the line connecting the vertices, then Jacob.Factor will be 1.

    •    value = minJacDet / V

             minJacDet  :  Minimum value of Jacobian determinant at each node
             V               :  Element volume



    ⑭ Tet Collapse

  • For the Tetra element, check the value obtained by the following formula.

    •    value = MIN ( h i / maxSide i )    i = 1~4

             h i             :  Height from the i th vertex to the opposite surface
             maxSide i  :  Maximum element edge length of face opposite to i th vertex



    ⑮ Tet Skew

  • For Tetra elements, check the difference ratio between the volume of the tetrahedron and the element volume obtained from the element circumscribed sphere radius.

    •    value = ( Vr - V ) / Vr
          Vr   =  8× R3 / 9√3

             V        :  Element volume
             R        :  Sphere radius



    ⑯ Unstable factor (Tetra / Hexa and Tri + Quad)

  • Check the number of (corner) nodes connecting with adjacent elements. It is used to detect elements of 1 (2) point connection where rigid motion occurs.
       (For solid elements, correction with surface model after detection is recommended.)


    • ⑰ CFL condition

  • For the Tri / Quad / Tet element, check the Courant conditions.

    •    Expression for the Shell element is below.

       △t = Ls / c
        Ls = [(1+β) As] / [max(L1,L2,L3,(1-β)×L4)]
        β = 0  (Quadrilateral element)), 1  (Triangular element)

             As       :  Area
             Li        :  Shell element length of each side  (i=1,2,3,4)
             c         :  Speed of sound





       Expression for Solid element is below.

       △t = Le / c
        Ls = Ve / Ae max (Solid element of 8Node) , Minimum height （TETRA element of 4Node）

             Ve        :  Volume
             Ae max  :  The area of the Maximum surface
             c          :  Speed of sound





    ⑱ Time Step (LS-DYNA) (Tetra / Hexa and Tri + Quad)

  • For Tri / Quad elements, check ⊿tc in the CFL condition by the LS-DYNA formula. The threshold time increment ⊿t is calculated by "Safety factor x Set value".

    •   ⊿tc＝Lc/c
      Lc = S/MAX(Lside)
      c = √(E/(ρ(1-ν²)))

             Lc    : Element representative length
             Lside   :  Element edge length
             S   :  Element surface area
             c   :  Stress propagation speed
             E   :  Young's modulus
             ρ   :  Density
             ν   :  Poisson's ratio
  • We will explain GUI items not found in other measurement methods.

    •   Safety factor            :  ⊿t = Safety factor x Set value
      Stress propagation speed   :  By selecting a material, you can check the stress propagation rate of that material.



    ⑲ Time Step (Abaqus) (Tetra / Hexa and Tri + Quad)

  • For Tri / Quad / Tetra / Hexa elements, check ⊿tc in the CFL condition with Abaqus formula. The threshold time increment ⊿t is calculated by "Safety factor x Set value".

    •   ⊿tc＝lc/c
      L1 = S/MAX(Ldiag)    : In case of Tri / Quad element
      L2 = MIN(Lside,Ldiag)    : In case of Tri / Quad element
      Lc = MAX(L1,L2)    : In case of Tri / Quad element
      Lc = 0.816MIN(Lside)    : In the case of Tetra primary element
      Lc = 0.264MIN(Lside)    : In the case of Tetra quadratic element
      Lc = V/MAX(S)    : In the case of Hexa element
      c = √(E/(ρ(1-ν²)))    : In case of Tri / Quad element
      c = √(E(1-ν)/(ρ(1+ν)(1-2ν)))    : In case of Tetra / Hexa element

             Lc    : Element representative length
             Lside   :  Element edge length
             Ldiag   :  Element diagonal length
             S   :  Element surface area
             V   :  Element volume
             c   :  Stress propagation speed
             E   :  Young's modulus
             ρ   :  Density
             ν   :  Poisson's ratio
  • We will explain GUI items not found in other measurement methods.

    •   Safety factor            :  ⊿t = Safety factor x Set value
      Include the diagonal :  When ON, include element diagonal length in calculation of representative length of element.
      Stress propagation speed   :  By selecting a material, you can check the stress propagation rate of that material.
