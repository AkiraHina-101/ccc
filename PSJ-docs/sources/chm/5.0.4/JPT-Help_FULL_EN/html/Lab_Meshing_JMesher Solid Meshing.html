JMesher Solid Meshing

Create a tetrahedral solid element. It is offered as a trial version of the new solid mesher.

Element type

  • TET4

       Create a tetrahedron primary element.

  • TET10

       Create a tetrahedron quadratic element.

    • General

       Enter the basic parameters to create solid mesh.
       You can change the following three parameters of the generated solid element: Min Edge Length, Max Edge Length, and Gradation. You can also control the internal mesh size.
       Both Min Edge Length and Max Edge Length can be omitted, but Gradation must be set.

    Edge Length

  • Min Edge Length

       Enter a positive real number.
       To create a coarser mesh, set a minimum edge length that is larger than the average surface mesh size.

  • Max Edge Length

       Enter a positive real number.
       To create a finer mesh, set the maximum edge length smaller than the average surface mesh size.

    • Mesh Gradation

  • Gradation

       Gradation controls mesh uniformity. A gradation equivalent to 1.05 means that the mesh is mostly homogeneous.
       The priority of gradation is higher than those of Min Edge Length and Max Edge Length. Therefore, if the user sets the gradation to 1.05, the conditions of minimum edge length and maximum edge length may not be observed.

    • Attribute

  • Speed vs. Quality

       Basically, run the mesher with optimization and then run it again in optimization only mode one or more times.
       Running the mesher several times can increase meshing time due to redundant post processing.
       There are three modes:
        - Fastest: The Mesher runs only once in the default optimization process.
        - Standard: The Mesher runs once in the default optimization process, and once more in optimization only mode.
        - Optimized: The mesher runs once in the default optimization process and then four times in optimization only mode.
       In most cases, it should be enough to get rid of "bad shape elements" in Standard mode.

    • Multiple CPU mesh

  • Max Theads

       It is not supported in V4.0. We plan to support this in future versions.

       Set up parallel processing. Parallelization is performed by assigning a core to each body.
       It is recommended to select one thread per available core on the machine used to achieve the best performance. Thus, on a 4-core machine, the optimal maximum number of threads is 4 threads (1 per core).

    • Advanced

       Enter detailed parameters for solid mesh creation.

    Algorithm

  • No Internal Points

       The meshing algorithm generates volume meshes using only surface nodes.

  • Central Point

       Mesh generation algorithms use the centroid to generate the mesh.

    •    Left: There are no internal nodes. Right: There are internal nodes.

    Optimization

       The optimization phase can be controlled by several parameters.

  • Optimization level

       The higher the optimization level, the slower the execution.
        - Light
        - Standard
        - Strong

  • Optimization mode

       Optimization mode when using multithreading.
        -None
        -Safe - Sequential mode: Safer, higher quality mesh.
        -Aggressive - Parallel mode: Fast, but the quality of the mesh may be degraded.

    • Other

       Enter the other parameters for solid mesh creation.

    Volume Proximity

  • Use Volume Proximity

       If you have very close surfaces, you can use the Volume Proximity Layer in these areas to automatically generate finer meshes.

  • Volume Proximity Layers

       You can specify the number of layers created between their faces in this text box.



    • Force Clean

       Enter forced cleanup parameters for solid mesh creation.

  • Stretch limit

       Enter the threshold value for the stretch value of the tetra element to be generated.

  • Surface node

       If checked, the surface node may be slightly moved to ensure element quality.

  • Edge node

       If checked, edge nodes may be moved slightly to ensure element quality.

  • Preserve

       If checked, the node may be moved ignoring the preserve.

  • Internal node only

       During automatic correction when creating solid elements, only internal elements are corrected without changing surface elements.
