Create Element QUAD4

If an element is missing, select the node of the missing element and create an element there.

Create Element QUAD4

  • Auto

    Check the box, selecting the 4th node automatically creates an element.

  • Keep Selection

    If checked, the original node will remain selected after element creation.

  • Belong Face

    Check the box and select a face to create an element on the selected face.

    • Face ID

      Display the selected face ID.

    - Operating Procedure -

    1.  Select 3 nodes of the missing element.
    2.  If necessary, select the Specify Face option. If you check the option, select the face to which you want to add a new element to be created.
    3.  Click Apply button.
    4.  An element enclosed by the selected node is created.
