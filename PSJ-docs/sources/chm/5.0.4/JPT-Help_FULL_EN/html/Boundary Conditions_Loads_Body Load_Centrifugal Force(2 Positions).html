Centrifugal Force (2 Positions)

Add the centrifugal force load in the analysis model.

　　

Structural

  • Name

       Enter the name of the centrifugal force load conditions.

    • 　　

    Rotation Axis

  • BasePoint X

       Enter the X coordinate of the rotation axis reference point.

  • BasePoint Y

       Enter the Y coordinate of the rotation axis reference point.

  • BasePoint Z

       Enter the Z coordinate of the rotation axis reference point.

  • TipPoint X

       Enter the X coordinate of the rotation axis vertex.

  • TipPoint Y

       Enter the Y coordinate of the rotation axis vertex.

  • TipPoint Z

       Enter the Z coordinate of the rotation axis vertex.

    • Value

  • Rotational Velocity

       Angular velocity

  • Input Unit

       Specify the input unit of the angular velocity

  • Rotational Acceleration

       Angular acceleration

  • Input Unit

       Specify the input unit of angular acceleration

    • - Operating Procedure -

    1.  Select the Node button from selection list and choose the base point and vertex from the screen.
    2.  Enter a name for the load.
    3.  Enter the angular velocity. You can change the Local units as required.
    4.  Enter the angular acceleration. You can change the Local units as required.
    5.  Press the Apply or OK button.

      6. ※Since the centrifugal force is to be added to the entire model, therefore there is no selection for Part in the selection list.
