Key Bind

Make settings for key binds (shortcut keys).



Key Bind Table

It is a setting table of key binds consisting of general keys (a-z, F1-F12, Insert, Delete, Space, Home, PageUp, PageUp) and special keys (None, Ctrl, Shift, Ctrl + Shift).


Command Table

It is a function table. Arbitrary functions can be assigned to any key combination by describing the numerical value of # in the combination position of the Key Binds table.

  • Add button

    • Register a new command in the command table.

    • Language

      Check the command name displayed when specifying each language.

    • Command name

      Enter the key bind name.

    • Function

      Enter the execution function with a macro.

  • Edit button

    • Edit the registered command selected on the command table.

  • Remove button

    • Remove the command selected on the command table from the command table.

    h3>– Operation Procedure (New key binding registration) –
    1.  Get the macro command of the command you want to register. (Execute the command and get right-click → copy the character string displayed in the macro window.)
    2.  Click Home > Preferences > Default Settings > Key Binds > Customize to display the Key Binds dialog.
    3.  Click the Add button, and enter the key bind name as the command name and the macro as the function in the dialog that appears.
    4.  Click the OK button to create a new key bind in the command table.
    5.  Enter the value assigned to the new key bind in any position of the key bind table. (The red cells are reserved keys and can not be changed.)
    6.  Click OK to complete the registration.
    7.  If Save the Customized Keybind Setting, Click the Exportbutton & Define the Directory.
