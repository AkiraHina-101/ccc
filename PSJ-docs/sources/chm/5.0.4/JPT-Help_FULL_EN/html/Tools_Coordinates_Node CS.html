Create Coordinate System of Nodes

This command sets the coordinate system that defines the position information of the nodes.
With Nastran and ADVC (format 2) input files, this setting refers to the local coordinate system as the node method.



- Operating Procedure -

  1.  Select the local coordinate system created in the coordinate system.
  2.  Select the part, face, edge or node for which you want to set the nodal coordinate system.
  3.  Click the Apply / OK button.
  4.  If you want to group the nodes in which the local coordinate system is set, press the group creation button.
  5.  Press the Show / Hide button to color-mark and visualize the nodes for which the local coordinate system has been set.
