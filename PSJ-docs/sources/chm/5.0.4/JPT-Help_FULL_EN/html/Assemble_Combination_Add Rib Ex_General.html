General

Add a ribbed shape to an existing surface mesh.
The rib shape is added to the existing surface mesh by specifying the mounting surface and the start and end points of the rib.

Rib Parameters

  • Rib Thickness

    Set the width of the ribs.

  • Rib Height

    Set the height of the ribs above the rib mounting surface.

  • Coordinate

    Specify the coordinate system to be used as a reference when mounting the ribs.

  • Direction Set By Coordinate

    Align the direction of the ribs with the direction of the coordinate plane specified by the coordinate axes specified in the coordinate system.

  • Rib Plane

    Specify the coordinate plane.
    ・XY plane: The ribs are aligned in the XY plane.
    ・YZ plane: The ribs are aligned in the YZ plane.
    ・XZ plane: The ribs are aligned in the ZX plane.

    • Offset

    Offset the ribbed position in the specified direction.
    The direction is set in Coordinate.

  • X

    Movement in X direction

  • Y

    Movement in Y direction

  • Z

    Movement in Z direction

    • Option

    Set other creation options and preview settings.

  • Triangle

    The ribs are created as triangular ribs with the starting side higher.

  • Plane Top

    If the rib mounting surface is curved, the rib top should still be flat.

  • Create New Part

    Create the rib as a new part.

  • Merge

    Merge ribs and mounting parts.

  • Preview

    Turn on/off the display of the preview.

    • - Operating Procedure  -

    1. Specify the mounting surface of the ribs and the start and end points of the ribs.
    2. Enter the respective parameters.
    3. Click on the Apply/OK button.
