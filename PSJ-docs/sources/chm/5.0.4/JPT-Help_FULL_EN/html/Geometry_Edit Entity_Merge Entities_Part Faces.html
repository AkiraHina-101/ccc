Part Faces

From parts or face, refer the angle or face width for the adjacent surface, to automatically merge with adjacent face.

Options

  • Angle

    If checked, it enables automatic merge due to the angle between adjacent surfaces.

  • Tolerance Angle

    Merge below the input angle for the adjacent surface.

  • Width

    When you check, it enables automatic merge by the width of the face.

  • Tolerance Width

    Merge the adjacent surface below entered width.

    • - Operating Procedure -

    1.  Select the part or faces to merge.
    2.  If necessary, check the Angle check box to enter the tolerance angle.
    3.  If necessary, check the Width check box, enter the tolerance width.
    4.  Click Apply / OK button.
