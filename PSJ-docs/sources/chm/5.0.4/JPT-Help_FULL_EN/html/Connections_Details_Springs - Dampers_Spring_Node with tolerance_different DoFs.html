Connection | Spring - Nodes with tolerance - different DoFs

This command is used to create 1:1 scalar spring elements.

Spring elements are automatically created between the selected nodes within an specified tolerance.
Different DoFs can be connected from the 1st group node and 2nd group node using this function. The node with the younger ID is defined as the 1st group.

Connection

  • Name

    Specify the name for registration.

    • Method

  • Nodes tolerance

    Specifythe search range of the connection point.

    • Spring

  • Stiffness

    Enter the spring stiffness value.

  • DoF at 1st G

    Specify the DoF of the 1st group.

  • DoF at 2nd G

    Specify the DoF of the 2nd group.

  • Damping Coef (for Nastran)

    Specify the damping coefficient.

  • Stress Coef (for Nastran)

    Specify the stress coefficient.

    • Analysis Coordinate Frame

  • Coordinate
