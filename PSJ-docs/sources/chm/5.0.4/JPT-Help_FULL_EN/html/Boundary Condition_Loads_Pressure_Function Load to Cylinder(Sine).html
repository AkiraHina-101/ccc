Pressure | Function Load to Cylinder (Sine)

Define the pressure load on the basis of the Sin function distribution for the selected Face or Element surface.

　　

Structural

  • Name

       Enter the name of the pressure loading conditions.

    • 　　

    Quadratic Curve : y=a×sinθ

      Sets of Sin function
  • a

       Define the value of coefficient a of Sin function

    • In the case of o-type input

      It is also possible for formula input other constants in a. Expression input begins with =, parentheses and arithmetic operator () can be used.
      In addition, the coordinate values X, Y, Z of the load point of the pressure load can be expressed by CX, CY, CZ respectively. (In each case always reference the entire coordinate system with only uppercase letters.)

      For Example: To cite the X coordinate value of the calculation point
      =12-3×(13+4)×CX

      •
  • Input Unit

       Specify the input unit of a input.

  • Coordinate System for Load

       Specify the coordinate system which refers to the XY plane of the load range of applications.

  • Angle Range

       Specify the angle of the load application range from the Y axis on the XY plane in the above coordinate system.
       Enter the load coverage angle in the range 0~PI or 0°

  • Input Unit

       Specify the input unit of the angle input.

  • Distribution in Axis

       Specify the presence or absence of the depth direction distribution.
    If you check depth direction for the distribution of Sine function is specified.

  • Pressure Direction

       Specify the pressure load direction.

    • Normal ： Perpendicular to the element plane
    • Vector ： Specify any direction
  • Coordinate System for Direction

       If the pressure direction specified is "Vector (specify any direction)" then select the coordinate system to reference.

  • Direction

       If the pressure direction specified is "Vector (specify any direction)", enter a comma-separated direction vector in the order of X, Y, Z.

  • Total Force Adjustment

       If you check this box, you can adjust the value to specify the total value of the pressure.

  • Total Force

       The total of the specified value of the pressure.

  • Corner Nodes Distribution

       Calculate the pressure load value at the position of the element and outputs.


    •  Load the pressure onto the surface in the load application range by using the Sin function.
    The depth direction is constant as long as there is no specification of Distribution in Axis.

    - Operating Procedure -

    1.  Select the Face or Element button from the selection list to select the Face or Element surface from the screen for applying the pressure loading.
    2.  Enter a name for the load.
    3.  Enter the numeric value or expression of “a” of Sine function expression in a.
    4.  Enter the angle to specify the distribution range of Sin function of the angle.
    5.  If necessary use direction, pressure direction, pressure total value adjustments and the element Node position distribution option.
    6.  Click the Apply or OK button.
