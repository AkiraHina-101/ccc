Output Window

This window is used to display text information such as log messages.

During entity selection: Displays the ID, type, values of the selected entity.
During command execution: Displays execution/error information, etc.

Mouse Operation

The following list shows the mouse operations available in the Output window.

Mouse OperationFunction
Left mouse clickHighlight the line. Press the Ctrl/Shift keys to perform a range selection.
Mouse wheelScroll the window.

Shortcut Menu

Each command can be used from the menu displayed by right-clicking the tree item.
CommandContent
Select AllHighlight all contents in the macro window.
