Shrink Mode Display

By turning on the shrink mode display, each element is reduced in size by the shrink ratio. While the shrink mode display is ON, the shrink ribbon is displayed and detailed settings are available.

Command List

PanelNameDescription
CloseCloseEnds using shrink mode.
1D/2D/3D 1D1D elements are targeted for shrink mode display.
2D2D elements are targeted for shrink mode display (default: ON).
3D3D elements are targeted for shrink mode display.
Shrink Mode Settings Shrink FactorShrink factor can be adjusted. Numerical increments = 0.01.
Property AssignedFilters display of elements to which the property is assigned (Default: OFF).
DefaultReset shrink ratio to default (0.80).
ApplyTo change the shrink ratio, enter the shrink ratio and then click the Apply button to reflect the change in the display.
