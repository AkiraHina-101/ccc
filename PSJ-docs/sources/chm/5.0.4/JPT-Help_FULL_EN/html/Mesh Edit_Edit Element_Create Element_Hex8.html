Create Element HEX8

If an element is missing, select the node of the missing element and create an element there.

Create Element HEX8

  • Auto

    Check the box and select 2 elements to create elements automatically.

  • Number of Layers

    Enter the number of divisions (number of layers) between the selected elements.

  • Belong Part

    If checked and a part is selected, an element will be created on the selected part.

    • Part ID

      Display the selected part ID.

  • Create New Part

    Create an element as a new part.

    • - Operating Procedure -

    1.  Select 2 elements of missing elements.
    2.  Enter the number of layers.
    3.  If necessary, check the Belong Part option. If the option is checked, select the part to which you want to add a new element to be created.
    4.  Click Apply button.
    5.  An element surrounded by the selected element is created.
