Smooth Face

Creates a face in the area surrounded by the selected nodes (or edges). It can be created if a preview is displayed.
Faces can be either mesh or geometric faces. In the case of mesh faces, the shape is interpolated based on the continuity with the surroundings.



Selection list: Share Face = OFF

Edge: Select the boundary nodes of the face by edges.
Node: Select the boundary nodes of the face.
Part: Part to which the created face belongs (single part only) ※If not selected, it will be created as a new part.

Selection list: Share Face = ON

Edge: Select the boundary nodes of the face by edges.
Node: Select the boundary nodes of the face.
Part: Part A to which the shared surface belongs (single part only).
Part: Part B to which the shared surface belongs (single part only).

Face Type

  • Geometry Face

    Create a geometry face.

  • Mesh Face

    Create a mesh faces with shape interpolation.

  • Share Face

    Create a shared surface between two parts. When this option is ON, two Parts are displayed in the Selection List. Select each Part of the shared surface to be created.

  • Interpolation

    Interpolate free-edge shapes, etc., by making the facet size and mesh size uniform.
    Free edges may be created, so please refer to the notes.

    • Mesh Face Parameter

  • TRI

    Create the face from TRI elements.

  • QUAD

    Create the face from QUAD elements.

  • Gradation Factor

    Specify the factor (1 <=) of the surrounding element size to define the mesh size of the mesh face . If geometry faces, it is automatically set to 0.5.

  • Connection continuity

    Select the continuity level.

    • G0 (Point Continuity) : The face to be created and the adjacent faces share the same boundary edge. The joint will be bent. Recommended for creating flat mesh faces.
    • G1 (Tangent Continuity) : The normal vectors of the face to be created and the adjacent faces are the same at the boundary edges. The joint will be smooth. Recommended for creating curved mesh faces.
      •

    • - Operating procedure (Create a mesh face) -

    1. In Geometry Face/Mesh Face, select Mesh Face.
    2. Select boundary nodes (by edges) surrounding the face.
    3. Select a part to which the face belongs as needed.
    4. In TRI/QUAD, select an option.
    5. Set the Gradation Factor and Connection continuity while watching the preview.
    6. Turn on Interpolation as needed.
    7. Click Apply/OK. A mesh face is created for the selected part. If part is not selected, a mesh face is created as a new part.

    - Operating procedure (Create a geometry face) -

    1. In Geometry Face/Mesh Face, select Geometry Face.
    2. Select boundary nodes (by edges) surrounding the face.
    3. Select a part to which the face belongs as needed.
    4. Turn on Interpolation as needed.
    5. Click Apply/OK. A geometry face is created for the selected part. If part is not selected, a geometry face is created as a new part.
    • Example: Preview the enclosed geometry face.


    • Example: Preview the bridging geometry face.


    - Operating procedure (Create a shared face) -

    1. Turn on Share Face. The Part in Selection List will be duplicated.
    2. In Geometry Face/Mesh Face, select an option.
    3. Select boundary nodes (by edges) surrounding the face creation range.
    4. Select each part that the shared face belongs to.
    5. For creating a mesh face, select TRI element type.
    6. For creating a mesh face, set the Gradation Factor and Connection continuity while watching the preview.
    7. Click Apply/OK. A shared face is created for 2 selected parts.
    • Example: To close a hole in the shared surface of three parts, create a shared surface for each range between two parts.


    - Notes -

    • 1. If the preview does not show up.


      As above figure, the preview is not displayed when the top and bottom curved edges are selected. The solution is to create separate faces on an existing region instead of one. It is obtained by dividing the bounding edges into smaller ones, then selected a little at a time or selecting a few nodes at a time.

    • Warning message when selecting parts.
      Share Face = OFF : If the number of parts belonging to the selected nodes is not one, a warning message will be displayed because the face to be created may be a shared face. If this is not a problem, click OK.
      Share Face = ON : If the number of parts belonging to the selected nodes is not two, a warning message will be displayed because it may be better to confirm the range of the shared face to be created. If this is not a problem, click OK.

    • Front and back of the face.
      In some cases, the normal direction of the created face may be different from the surrounding faces. In this case, select the face and Right-click > Flip to correct the normal direction of the face.

    • Free Edge by Interpolation option
      Interpolation option also changes the mesh size between the selected entities. Therefore, If the distance between the selected nodes is significantly different from the average, free edges may be created.

  • Multiple separated closed area
    This function cannot create faces for multiple separated closed area at the same time. Apply/OK button will be deactivated. Please execute them one by one or automate them with PSJ.
