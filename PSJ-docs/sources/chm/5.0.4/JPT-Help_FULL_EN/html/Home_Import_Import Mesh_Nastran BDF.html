Nastran BDF

This commmand is used to import Nastran analysis files (.bdf/.dat/.nas).

※In order to import .bdf files (Geometry BDF files), the Import CAD＞TechnoStar Geometry command should be specified.

Import Type

  • Standard Nastran BDF

    •    Import the BDF model geometry only.

  • Standard Nastran BDF by Property

    •    Import the BDF model geometry and material property. A body is created for each material property.

    • 1D-Edge, 2D-Face, 3D-Part

      • The 1D, 2D material properties are applied to edges or faces of a single part. 3D material properties are applied to each part. (Hollow 1D material properties are applied to each part.)

    • 1D2D3D-Face

      • All material parts are applied to each part.

    Angle

  • Face Angle

    •    Specify the tolerance angle in order to determine the face division. Define a face by creating an edge between adjacent elements with an angle smaller than the specified value.

  • Edge Angle

    •    Specify the tolerance angle in order to determine the edge division. Divide an edge by creating a vertex on adjacent edge elements with an angle larger than the specified value.

    - Operating Procedure -

    1.  Launch the command, specify each option and click the OK button.
    2.  Select the target data in the dialog and click the Open button.
