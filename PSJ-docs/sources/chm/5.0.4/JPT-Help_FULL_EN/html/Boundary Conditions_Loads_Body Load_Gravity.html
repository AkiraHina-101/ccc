Gravity

Define the acceleration load of gravity to the selected Part.

Structural

  • Name

       Set the gravity load name.

    Value

  • X/Y/Z

    •    Define the acceleration value of each direction.

  • Input Unit

    •    Specify the input unit system.

    Analysis Coordinate Frame

  • Coordinate

    •    Select the coordinate system in which the load is to defined.


    - Operating Procedure -

    1.  Select the parts to apply the gravity load. You can select more than one.
    2.  Enter the acceleration values in each of X, Y or Z direction.
    3.  Select and enter the other parameters as required.
    4.  Click the Apply or OK button.
