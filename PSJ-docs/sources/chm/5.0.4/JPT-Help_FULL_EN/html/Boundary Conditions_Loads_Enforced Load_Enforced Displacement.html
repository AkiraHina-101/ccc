Enforced Displacement

Add the enforced displacement on the analysis model.

　　

Structural

  • Name

       Enter the name of the enforced displacement load conditions.

    • Values

  • Translation X

       Enter the forced displacement value in the X direction of translation.

  • Translation Y

       Enter the forced displacement value in the Y direction of translation.

  • Translation Z

       Enter the forced displacement value in the Z direction of translation.

  • Arrow Direction

       Adjust the display of the load marker.

    • Start at Node ： Arrow of the marker displaying the load, starts from a node.
    • End at Node ： Arrow of the marker displaying the load, ends at the node.
      •

  • Input Unit

       Specify the input unit of forced displacement value.

    • Values

  • Rotate X

       Enter the forced displacement value in the X direction of rotation.

  • Rotate Y

       Enter the forced displacement value in the Y direction of rotation.

  • Rotate Z

       Enter the forced displacement value in the Z direction of rotation.

  • Input Unit

       Specify the input unit of forced rotational displacement value.

    • Analysis Coordinate Frame

  • Coordinate

       Choose a coordinate system that is referenced by forced displacement value.


    • Tables

  • Select Table

       Defined in the Field Data. Currently not supported.

    • Phase Delay

  • Phase

       Enter the phase.

  • Phase Table

       Select the phase table that you entered in Field Data.

  • Delay

       Enter the Delay.

    • Multi-Excitation Load Export

      Collectively define the load of each degree of freedom direction. Load will be created for every degree of freedom you have defined.
  • Translation X

       Specify the frequency table for the translational X-direction load. Input required for Values-Translation X

  • Translation Y

       Specify the frequency table for the translational Y-direction load. Input required for Values-Translation Y

  • Translation Z

       Specify the frequency table for the translational Z-direction load. Input required for Values-Translation Z

  • Rotation X

       Specify the frequency table for the X-axis rotation direction load. Input required for Values-Rotation X

  • Rotation Y

       Specify the frequency table for the Y-axis rotation direction load. Input required for Values-Rotation Y

  • Rotation Z

       Specify the frequency table for the Z-axis rotation direction load. Input required for Values-Rotation Z

    • FrontISTR Rotational Constraint

  • Rotational Constraint Center

       Select boundary that contains Rotational Constraint Center, normally only one node.


    • - Operating Procedure -

    1.  Select one of the Face, Edge, Node buttons from the selection list and then select the target of forced displacement from the screen.
    2.  Enter the name for the load.
    3.  Enter the translation on rotation forced displacement value in X, Y, and Z direction. You can change the local unit as required.
    4.  Adjust the starting point and end point of the load marker for specifying Arrow Direction as required.
    5.  Select the coordinate system to reference the forced displacement value, if necessary.
    6.  Press the Apply or OK button.
