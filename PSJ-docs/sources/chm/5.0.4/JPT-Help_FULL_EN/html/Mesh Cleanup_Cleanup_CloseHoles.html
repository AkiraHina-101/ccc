Close Holes

Target the model, find the locations (holes) where faces or elements are missing and create a face in those holes.

Free Edges

  • Length Min

    Specify the minimum edge length around the hole.

  • Length Max

    Specify the maximum edge length around the hole.

  • Find

    Find the edge around the hole.

    • Hole Filling Conditions

  • Area Min

    Specify the threshold of minimum area to create a face for the hole. Create a face for the hole of greater than or equal to the value specified here.

  • Area Max

    Specify the threshold of maximum area to create a face for the hole. Create a face for the hole of less than or equal to the value specified here.

    • Options

  • Merge Faces

    When checked, combine the adjacent face after creating the face.

  • Merge Edges

    When checked, combine the edge around the face that you created.

    • - Operating Procedure -

    1.  Click the Find button to find Free Edges. Search targets are:
      For Auto： Model all the holes
      For Edges： Hole belonging to the selected edge
      For Parts： Hole on the selected parts
    2.  Specify the threshold of maximum and minimum area to create a face to the Area Min and Area Max.
    3.  Click Apply / OK button.
