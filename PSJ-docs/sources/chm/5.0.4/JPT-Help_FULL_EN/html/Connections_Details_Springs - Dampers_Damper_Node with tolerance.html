Connection | Damper - Nodes with tolerance

This command is used to create 1:1 damper elements.

Damper elements are automatically created between the selected nodes within an specified tolerance.
Multiple Dofs can be connected at once using this function. Nodes with younger IDs are defined as the 1st group.

    Specify the search range of the connection point.
