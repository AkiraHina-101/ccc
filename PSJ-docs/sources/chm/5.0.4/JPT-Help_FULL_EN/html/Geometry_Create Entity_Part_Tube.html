Tube

Create a hollow tube around the selected edge.




Select list

Edge: Edge that is the central axis of Tube.

Part Properties

  • Part name

    Enter the name of the Tube.

    • Tube

    Select the type of 2D element of the Tube you want to create.

    • Tri3 : Create a Tube with triangular elements.
    • Quad4 : Create a Tube with quadrilateral elements.
      •
  • Radius

    Enter the radius value of the tube.

  • Mesh Size(Axis)

    Enter the axial mesh size of the Tube.

  • Mesh Size (circumferential direction)

    Enter the mesh size of the tube to be created in the circumferential direction.

  • Number of Node (circumferential direction).

    Enter the number of nodes in the circumferential direction of the Tube to be created.

    • - Operating procedure -

    1. Select an edge.



    2. Enter the radius and mesh size value.

    3. Click the Apply/OK button.
