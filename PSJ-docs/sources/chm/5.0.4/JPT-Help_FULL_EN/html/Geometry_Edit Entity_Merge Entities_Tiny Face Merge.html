Tiny Face Merge

In this command, small face are selected automatically to merge.
In the first operation, tiny-faces with width less than input width are automatically selected. In the next operation from the selected tiny-faces, the face will be merged into the adjacent face if the angle between the faces is less than 30 °. If there is more than one adjacent face, it will be merged into the smaller face ID.
It can also be applied to the assembly model where there is a shared surface.

Step

  • Method

    Specify the operation.

    • Select

      Find the tiny faces within the set range of the width, and then select.

    • Merge

      Merge the selected tiny-faces into the adjacent face.

    Select

  • Min Face Width

    Enter the minimum width of the tiny-face search range.

  • Max Face Width

    Enter the maximum width of the tiny-face search range.

  • Connection Face

    Include the face width that will be changed after merging.

    • Merge

  • Refer Local Setting

    If the contents of the Local Settings contain Keep Entity specified, that face will be retained.

  • Preview

    Face color for the faces to be merged is changed.

  • Reset

    Replace the display for preview.

    • - Operating Procedure -

    1.  Specify the Method> Select.
    2.  Select the part or face to find tiny faces.
    3.  Enter the search range in the value Min Face Width and MaxFace Width.
    4.  Click the Apply button. Tiny-face will be selected.
    5.  Specify the Method > Merge.
    6.  Confirm the preview and deselect the faces to be excluded from merge, if necessary.
    7.  Click Apply / OK button. Tiny-face will be merged.
