Path Setting

Set the path for various operations.

  • Jupiter-Post executable path

    • Specify the path of Jupiter-Post executable file. User can start Jupiter-Post with the start button.

  • TS-Solver path

    • Specify the path of TS - Solver executable file.
    Use Launcher:Use Solver Launcher function when solver is activated.
    Direct Execution:Batch file starts directly when solver starts.
    Delete DB/MSTR:DB and MSTR file will be deleted after the solver ends,If the checkbox is checked.

  • Nastran path

    • Specify the path of Nastran executable file.

  • PTC Creo path

    • Specify the path of Creo executable file.

  • Ansys path

    • Specify the path of Ansys executable file.

  • Default material library

    • Specify the path of the material library.

    - Operating Procedure -

    1.  Activate the command and set the user preferred executable file path by cliking the browse button on the right side of each item.
    2.  Click the apply button or OK button to apply the setting.
