Background

This command is used to define the background color of the Main window.

  • Background Color

    • Define the background color of the Main window.

  • Gradient Color

    • Specify the gradient color.

  • Use Gradient Background

    • Select this checkbox to turn on the gradient color setting.

  • Capturing Background Color

    • Select Current / White / Transparent background to use when capturing an image.

  • Image Output Size

    • Check Fixed size to input width and height of image output.

    - Operating Procedure -

    1.   Launch the command, specify options and click the Apply or OK button.
