Face Element

Set the local size to the elements on the face. Define the settings for the entire mesh creation process, before the mesh creation.

Mesh Parameters

  • Name

    Set the mesh control name.

    • Freeze Mesh

  • Freeze Mesh

    When checked, it maintains the current mesh.

    • Mesh Size

  • Mesh Size

    Set the size of the element.

    　　　
    • 　　
  • Average

    Set the average mesh size.

    　　　
    • 　　
  • Minimum

    Set the minimum mesh size.

    　　　
    • 　　
  • Maximum

    Set the maximum mesh size.

    Keep Entity

    　　　
    • 　　
  • Keep Entity

    When checked, it preserves the shape of the face at the time of creating mesh.

    • Mesh Pattern

  • Mesh Pattern

    Set a mesh pattern.

    • Unstructured

      Set the free mesh pattern.

    • Structured

      Set the regular grid (mapped mesh) pattern.

    • Imprinting-Iso

      You can also create an Iso mesh in case where the surface is Unfinished or perforated, such as a cylindrical surface.

    Advanced Option

    　　
  • Local Mesh Preview

    When checked, you can preview the selected face element mesh with a required Mesh count.
    Note: If a small mesh size is set for the model size, it may take time to display the mesh preview.

    　　　
    • 　　
  • Preview Color

    Select the preview face element color from the color list.

    　　　

    • - Operating Procedure -

    1.  Select the element.
    2.  Enter mesh size of the each item.
    3.  Click Apply / OK button.
