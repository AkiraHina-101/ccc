Contacts | NX Nastran - Manual Group

Define contact settings for NX Nastran between specified groups.
Create groups that will be master faces and slave faces in advance, select contact groups for each contact pair, and define contact settings.

    • - Operating Procedure -

      　　　
    1.  Create a master face, slave face or element face group in advance.
      2. 　　　
    2.  Select the master group as the master face and the slave group as the slave face.
      The selected group is highlighted in the model window. It is also possible to confirm by turning off the group display mode.    
      It is possible to do partial match search or ID search of the name of the group from the search button.

       If you want to edit the faces included in the existing group, double-click the group in the list to enter group edit mode.
      After editing such as adding faces in the model window, the contents of the group are changed by pressing the Modify button.
      Please note that the edited group is used as it is with other contact pairs.

      　　　
    3.  Define detailed settings for contact pairs as required, and click the Apply or OK button to define contact pairs.
