Alignment

Move and/or rotate the target part which has circular edges to the reference/destination part to be straightly aligned.


Transform

  • Method

    •    Specify the method of alignment. There are two alignment methods:

    • Axis Alignment: The target part is aligned by axis.

      •    Selection list
            Part: Specify the target part to transform. Multiple parts are acceptable.
            Target Edge: Specify the edge on the target part to be moved. Maximum number of edge is 2.
            Ref Edge: Specify the edge on the reference/destination part. Maximum number of edge is 2.

    • Plane Alignment: The target part is aligned by plane.

      •    Selection list
            Part: Specify the target part to transform. Multiple parts are acceptable.
            Target Face: Specify the face on the target part to define the angle of rotation. Target Face allows selecting one face only.
            Ref Face: Specify the face on the reference/destination part to define the angle of rotation. Ref Face allows selecting one face only.
            Center Node: Specify the node to define the center of rotation.
            Center Edge: Specify the edge to define the center of rotation.
            ※To define the center of rotation, just specify either Center Node or Center Edge is enough. If both Center Node and Center Edge are specified, the latest one will be used to define the center of rotation.
  • Translation Length

    •    An offset value to specify the distance between target part and reference part when transforming.


  • Coplanar (for Plane Alignment Method only)

    •    Set the Target Face (on the target part) to be coplanared with the Reference Face (on reference part). When this option is selected, Translation Length's value will be measured automatically.

    Operation

  • Preview

    •    Display temporary results as a preview.

  • Create New Part

    •    Copy the Target Part after transform as a new part.

  • LBC Copy

    •    Also copy Load and Boundary Condition that were added to the existing part to a new part.

  • Property Copy

    •    Also copy properties that were added to the existing part to a new part.

  • Reference Copy

    •    Also copy references that were added to the existing part to a new part.

    Direction

    Specify the direction for alignment. There are two alignment directions:

  • Opposite Direction: Move and/or rotate the target part to the reference part by making the both faces have the opposite direction of normal vector.

  • Same Direction: Move and/or rotate the target part to the reference part by making the both faces have the same direction of normal vector.

    • - Operating Procedure -

    Operation 1 (Method: Axis Alignment)

    1.  Select the target part to transform.
    2.  Select the circular target edge on the target part.
    3.  Select the circular reference edge on the reference part.
    4.  Input the Translation Length's value, if necessary.
    5.  Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively.
    6.  Specify a direction for alignment.
    7.  Press the Apply or OK button to execute the function.

    Operation 2 (Method: Axis Alignment, mating 2 pairs of edge at the same time)

    1.  Select the target part to transform.
    2.  Select the circular target edges on the target parts.
    3.  Select the circular reference edges on the reference parts.
    4.  Input the Translation Length's value, if necessary.
    5.  Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively.
    6.  Specify a direction for alignment.
    7.  Press the Apply or OK button to execute the function.

    Operation 3 (Method: Plane Alignment)

    1.  Select the target part to transform.
    2.  Select the target face on the target part.
    3.  Select the reference face on the reference part.
    4.  Specify the Center Node or Center Edge to define the center of rotation.
    5.  Input the Translation Length's value and check on Coplanar to set the Target Face to be coplanared with the Reference Face, if necessary.
    6.  Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively.
    7.  Specify a direction for alignment.
    8.  Press the Apply or OK button to execute the function.

    Operation 4 (Method: Axis Alignment and Plane Alignment)

      ※Axis Alignment:
    1.  Select the target part to transform.
    2.  Select the target edge on the target part.
    3.  Select the reference edge on the reference part.
    4.  Input the Translation Length's value, if necessary.
    5.  Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively.
    6.  Specify a direction for axis alignment.
    7.  Press the Apply or OK button to execute the function.
    ※Plane Alignment:

    After axis alignment is executed sucessfully, the selected reference edge is changed to Center Edge if user want to continue transform the part with Plane Alignment.

    1.  Select the target part to transform.
    2.  Select the target face on the target part.
    3.  Select the reference face on the reference part.
    4.  Input the Translation Length's value and check on Coplanar to set the Target Face to be coplanared with the Reference Face, if necessary.
    5.  Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively.
    6.  Specify a direction for plane alignment.
    7.  Press the Apply or OK button to execute the function.

    - Notes -

    1.  This function does not support in case of target part is 1D bar part.
    2.  The required profile type for edges of each method.
      • For Axis Alignment Method: Target edges/reference edges must be circular edge.

      • For Plane Alignment Method: Center Edge to define the center of rotation must be circular edge. Faces for alignment must be the flat plane, curve faces can not apply.

        •
    3.  Direction of translation uses reference part’s normal vector direction as positive direction for translation.
    4.  Translation of target part bases on combination of the specified direction and the angle defined by normal vectors of target part and reference part (Θ).
      • Θ < 90° and Direction is Same Direction: Rotate Target Part an angle Θ around the specified rotation center (The new position of Target Face corresponds to case of Translation Length = 0).

      • Θ < 90° and Direction is Opposite Direction: Rotate Target Part an angle Θ around the specified rotation center. Then, symmetrically project the target part, take reference face as symmetrical plane (The new position of Target Face corresponds to case of Translation Length = 0).

      • Θ > 90° and Direction is Opposite Direction: Rotate Target Part an angle (180° - Θ) around the specified rotation center (The new position of Target Face corresponds to case of Translation Length = 0).

      • Θ > 90° and Direction is Same Direction: Rotate Target Part an angle (180° - Θ) around the specified rotation center. Then, symmetrically project the target part, take reference face as symmetrical plane (The new position of Target Face corresponds to case of Translation Length = 0).
