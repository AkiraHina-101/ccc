Auto Bolt Connection

This command can search the bolt holes from the selected part pair, set the conditions of the bolt type, and create the rigid bolts automatically. There are four types of rigid bolts to choose from.


Rigid bolts consist of multiple FEM conditions, and for each bolt created, a group of them is created. The bolt group will be placed under the Bolt Connection subgroup.



Selection list

Upper Part: Bolt seat side part.
Lower Part: Bolt thread side part.

Bolt Modeling

  • Bolt Name

    Specify the name of the rigid bolt.

  • Bolt Hole Size

    Specify the bolt hole size from the list and entered it automatically into the minimum and maximum diameters below.
    Bolt hole size and minimum/maximum are referenced from "*installation folder*\bin\common\template\LBC\BoltModeling\BoltSizeInfomation.DAT".

  • Min Circle Diameter

    Specify the minimum diameter of the bolt holes to be searched.

  • Max Circle Diameter

    Specify the maximum diameter of the bolt holes to be searched.

    • Bolt Setting List

    Mating Face

  • Gap Tolerance

    Specify the gap tolerance between the upper and lower parts. Bolt holes with the mating surface less than or equal to this gap are to be searched for.

  • Angle Tolerance

    Specify the angle tolerance in degrees of the mating surface between the upper and lower part. This parameter is used to determine the planarity of the mating surfaces and does not usually need to be changed.

  • Fit the Previewed pair

    The viewpoint of the main window will fit the selected bolt pair from the list.

  • Find

    Find the bolt holes from the selected part pair.

  • Check All On/Off

    Switches the state of all checkboxes in the list to On or Off.

  • Check Box

    Set up bolt modeling of the rigid body for the checked bolt pairs.
    The check box state is reversed when right-clicking on it.

  • Master Face

    Display the ID of faces of the bolt holes in the upper part.

  • Slave Face

    Display the ID of faces of the bolt holes in the lower part.

  • Modification

    By clicking the "Edit" button, the members of the master/slave faces can be edited (adding or removing) by selecting face manually.
    After editing, click the "Apply" button in the list to save the modification.



  • Bolt Type

    Specify the type of rigid bolt to be created. The display switches when the FEM conditions for Bolt Type are set. Only a bolt type is possible to set for each bolt hole.

  • Right-click menu on the list
    • Copy : Only displayed on bolt types. Copy the bolt type.
    • Paste : Only displayed on bolt types. Paste the copied bolt type.
    • Insert : Add an empty row to the list.
    • Delete : Delete the selected row.
    • Clear All : Clear out the list.

    • Bolt Type

    Set the FEM conditions for each bolt type.
    The button for the bolt type that has been set will be highlighted. The highlighted bolt type means that the setup is ready.
    There are four bolt types: Type A, Type B, Type C, and Type D. Please see the help for each bolt type GUI from the link below.


    • Help for Type A : Create RBE2/RBE3 elements in a circular shape on the upper and lower seating surfaces and connect their centers with a Bar/RBE2 element.
    • Help for Type B : Create an RBE2/RBE3 element in a circular shape on the seating surface of the bolt hole and an RBE2/RBE3 element on the threaded part, and connect their centers with a Bar/RBE2 element.
    • Help for Type C : Create RBE2/RBE3 elements in the bolt hole and connect its center with a Spring/RBE2 element.
    • Help for Type D : Create RBE2/MPC elements around the bolt hole on the mating surface and join them together.

    Local Settings Face

    Create the local setting for the searched bolt hole faces. It is useful when executing on parts before meshing.
    And not required when executing on mesh parts.

  • Average Mesh Size

    Specify the average size of the element. The minimum is automatically set to 0.1 times the average, and the maximum is automatically set to twice the average.

    • - Operating Procedure -

    1. Select one Upper Part and one Lower Part.

    2. Change the search parameters (Min Circle Diameter, Max Circle Diameter, Gap Tolerance).

    3. Click the "Find" button. The found bolt pairs will be listed.

    4. Check the listed bolt pairs and modify them if necessary.

    5. Click the button of the desired bolt type to set the FEM conditions. The button will be highlighted.

    6. When the bolt pair is present in the list and the bolt type button is highlighted, then Apply/OK button is activated.
      Click the Apply/OK button. The rigid bolts will be created automatically.
