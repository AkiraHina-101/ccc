Create Element Tet / Hex / Penta / Pyramid

Create a solid element from the selected elements or nodes.





Selection List

Element：2D elements that connect solid elements.
Node：Nodes to connect solid elements.
Part：The part to which the created solid element belongs (if not selected, the solid element will be created as a new part).

Parameter

  • Target

    Select the solid element type to be created.

    • Tet : Creates a tetra element (tetrahedron).
    • Hex : Create a hexa element (hexahedron).
    • Penta : Create a penta element (triangular prism).
    • Pyramid : Create a pyramid element (square weight).
      •
  • Use OrderNode

    When the checkbox is turned on, the number of the next selection order will be displayed in the main window after the three nodes are selected.

  • Direction

    Switch the direction of the element to be created.

  • Height

    Enter the height of the element to be created.

  • Keep Part Selection

    Retain the selected state of the selected parts even after the Apply button is executed.

    • - Operating Procedure (Use OrderNode option) -

    1. Turn on the Use OrderNode option and create a solid element (in this case, a hexa element as an example) by selecting the nodes.

    2. Select three nodes to create the element. In this case, select the three nodes in a counterclockwise direction, because the green guidelines will not appear in the intended direction if you select them in a clockwise direction as shown in the figure below.

    3. Next, select the node where want to create the element, in the direction where the number 4 appears in the main window.

    4. Next, select the node where want to create the element, in the direction where the number 5 appears in the main window.

    5. Next, select the node where want to create the element, in the direction where the number 6 appears in the main window.

    6. Next, select the node where want to create the element, in the direction where the number 7 appears in the main window.

    7. Next, select the node where want to create the element, in the direction where the number 8 appears in the main window. After selecting the node, the green guideline will change and the preview will appear.

    - Special Notes -

    1. When the Use OrderNode option is OFF, automatic generation is not possible if the finished shape has a concavity.

    2. The secondary order elements are also supported. If the order of the selected element is different, an error message will be displayed.

    3. Only Keep Part Selection does not save the GUI settings.
