Scale

Scale the selected node group while maintaining the ratio between nodes.

Scale Factor

   Coordinate: Select a coordinate system that defines the direction component to be scaled.

   DX/DY/DZ： Enter the scale factor of each direction component.

   Uniform： Check to enter equal proportions for all direction components.

- Operating Procedure -

  1.  Select all nodes in the range to be scaled.
  2.  Select a node to be scaled.
  3.  Check the scale factor in each direction or enter one value when uniform.
  4.  Press the Apply or OK button.
