Template Copy(Window to Window)

Copy the local setting to the other window of the model.

Local Setting Copy

  • Source Document

       Specify the window of the model to be the copy source for the local setting.

  • Target Document

       Specify the window of the model to be copied for the local setting.

  • Input Unit

       You can specify units of correction value between the model.

  • Coordinate System

       Specifies correction direction of the coordinate system between the model.

  • Magnitude

       Enter the correction distance between the model.

  • Tolerance

       Enter the error tolerance between the model.

  • Axis

       How to specify and select Inter-model correction direction.

    • Arbitrary : Enter a component of the XYZ to specify the direction.

    • X Axis : Specifies the X direction.

    • Y Axis : Specifies the Y direction.

    • Z Axis : Specifies the Z direction.

    • 2Nodes : Select the 2 nodes to specify the direction.

    • Edge : It specifies the direction to select the edge.
  • X/Y/Z

       XYZ components of the correction direction vector between the model is displayed.

    • - Operating Procedure -

    1.  Open the local setting copy source and target model in the software.
    2.  After start-up, specify the window of the model from which to copy in Source Document.
    3.  Specifies the window of the model to be copied in Target Document.
    4.  If the position correction between the models is required, specify the coordinate system of the correction direction in Coordinate System.
    5.  Enter the correct distance between the model in Magnitude.
    6.  Enter the allowable value of the error between the model in Tolerance.
    7.  Specify the Arbitrary in Axis.
    8.  Specify the direction, enter the component of the XYZ.
    9.  Click Apply / OK button.
