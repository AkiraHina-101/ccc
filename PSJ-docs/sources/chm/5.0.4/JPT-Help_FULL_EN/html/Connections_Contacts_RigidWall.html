Rigid Wall

Set up a rigid wall.

Rigid Wall

  • Name

       Enter the rigid wall name.

    　　　
    • 　　　
  • Type

       Specify the rigid wall type.

    • Infinite：Infinite body
    • Finite：Finite body
      •
    　　　
    • 　　　
  • Motion

       Specify the behavior.

    • Static：Stationary
    • Moving：Movable
      •
    　　　
    • 　　　
  • Friction

       Specify the condition of friction.

    • Frictionless: No friction
    • No Sliding: No slip
    • Coulomb Friction: Coulomb friction
    • Weld with Frictionless: Frictionless welding
    • Weld with No Sliding: Non-slip welding
      •
    　　　
  • Forces

       Specify whether to consider reaction force.

    • No：Do not consider
    • Yes：Consider
      •
    　　　
  • All Node Slave

       If checked, all nodes will be subordinate points.

    　　　

    • Rigid Wall Position

    Determine the position of the rigid wall in the coordinate system.

  • Coordinate

       Select a coordinate system.



    • - Operating Procedure -

      　　　
    1.  Enter rigid wall name.
      2. 　　　
    2.  Specify the type of rigid wall to create.
      3. 　　　
    3.  Choose a motion.
      4. 　　　
    4.  Specify the condition of friction.
      5. 　　　
    5.  Specify the presence or absence of reaction force.
      6. 　　　
    6.  Check "All Node Slave" if necessary.
      7. 　　　
    7.  Specify the coordinate system.
      8. 　　　
    8.  Select an entity and click the Apply or OK button.
