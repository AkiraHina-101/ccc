Cross Section

Turning on the section view will display a 3D mouse in the main window. While the 3D mouse is activated, the section ribbon is displayed, enabling detailed display settings. The cross-sectional view, which is displayed by cutting the shape at an arbitrary cross section, is adjusted using the 3D mouse displayed in the main window.

About 3D Mouse Operation

Adjust the position of the cutting plane by hovering mouse over the axes or symbol of the 3D mouse, and operating the part that changes color by clicking and dragging the left button of the mouse.

Section View Shift Control Dialog

Adjust the cutting plane position by numerical input and button click.


  • Center

    Specify the center position of the 3D mouse. When the "Set" button is clicked, the input coordinate position is set as the center position of the 3D mouse. Return to initial position by reset.

  • Direction

    Specify the direction perpendicular to the plane of the section as a vector (X, Y, Z). Click the "Set" button to make the direction of the input vector the direction perpendicular to the cross section.

    • X : Click to make the X axis perpendicular to the cross section.

    • Z : Click to make the Y axis perpendicular to the cross section.

    • X : Click to make the Z axis perpendicular to the cross section.

    • ISO : Click to make the direction of the vector (1, 1, 1) perpendicular to the cross section.
      •
  • Rotate

    Rotate the 3D mouse.

    • Angle : Specify the rotation angle.

    • Global X : Rotate around the x-axis of the global coordinate system.

    • Global Y : Rotate around the Y axis of the global coordinate system.

    • Mouse X : Rotate around the X axis of the 3D mouse.

    • Mouse Y : Rotate around the Y axis of the 3D mouse.

    • Reset : Reset the 3D mouse rotation to its initial state.

      •
  • Drag

    The 3D mouse is offset moved by the input value in the face direction.
