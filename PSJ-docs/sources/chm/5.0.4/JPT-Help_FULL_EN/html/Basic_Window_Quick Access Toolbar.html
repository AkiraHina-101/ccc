Quick Access Toolbar

This toolbar can be customized to use arbitrary commands selected by the user.


Default Setting

IconNameDescription
Undo Click this icon to undo the previously executed operation. Click the triangular icon on the right side to display a list of previously executed operations. Multiple operations can be cancelled.
Redo Click this icon to redo the previously cancelled operation. Click the triangular icon on the right side to display a list of previously cancelled operations. Multiple operations can be re-executed.

Customized Setting

The Quick Access Toolbar can be edited as listed below.

・Show/hide icons
The displaying of the command icons registered in the Quick Access Toolbar can be switched ON or OFF.

・Other commands
Arbitrary commands can be registered in the Quick Access Toolbar.

・Display at the bottom of the ribbon
Display the Quick Access Toolbar at the bottom of the tab menu.

・Minimize the ribbon
Minimize the display of the tab menu.
