Add Rib

Add Rib Dialog Box

Add the ribs to the body. Additionally, Surface Mesh is possible for rib after creation.

Parameters

  • Type

    Specify how to create the ribs.

    • By rib part

      The Rib part is prepared separately, and attached to the parts after Surf Meshing.

    • By three points

      Create a Rib part by the specified parameter.

  • Width

    Specify the width of the rib (When By three points is selected).

  • Depth

    Specify the distance from the rib surface (When By three points is selected).

  • Auto Remesh

    After the ribs are created, run the Local Remesh near the attachment surface.


    • - Operating Procedure (Rib attachment) -

    1.  Select By rib part from Type.
    2.  Select the Rib part and the attachment surface.
    3.  Click the Apply or OK button to execute.
    →
    Rib Part Attachment Surface Selection (2) After Execution Auto Mesh:ON

    - Operating Procedure (Rib created) -

    1.  Select By three points from the type.
    2.  Select the Start and End points for the Ribs.
    3.  Specify the point that determines the direction for Ribs.
    4.  Specify the attaching surface for the ribs.
    5.  Click the Apply or OK button to execute.

    ※To specify the point, Node, Face Point or Edge Point can be used.
