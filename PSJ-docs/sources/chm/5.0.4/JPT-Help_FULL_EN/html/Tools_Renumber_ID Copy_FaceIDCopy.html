Face ID Copy

Copy the face ID of similar shape parts in two different documents.

　　

Source

  • Source Document

       Select the document from which you want to copy ID.

  • Source Body

       Select the part from which you want to copy ID.

  • Source Face

       Select the face from which you want to copy ID.

    • 　　

    Target

  • Target Document

       Select the document to which you want to copy ID.

  • Target Body

       Select the part to which you want to copy ID.

  • Target Face

       Select the face to which you want to copy ID.

    • 　　

    Option

  • Tolerance

       Enter the tolerance to judge the node position as a match.※Node IDs are copied only for nodes whose node positions are determined to match.

    • 　　

    Copy Information

  • Start Solid Node ID

       The start node ID of the uncopied node is displayed. This is the ID obtained by adding 1 to the maximum value of the copied node ID. This ID is displayed for confirmation.

  • Solid Node Count

       The number of nodes is displayed. This number is displayed for confirmation.

  • End Solid Node ID

       The maximum value of the end node ID predicted from the start node ID and the number of nodes is displayed. This ID is displayed for confirmation.

  • Start Solid Element ID

       The start element ID of the solid element not copied is displayed. This is an ID obtained by adding 1 to the maximum value of copied element IDs. This ID is displayed for confirmation.

  • Solid Element Count

       The number of solid elements is displayed. This number is displayed for confirmation.

  • End Solid Element ID

       Displays the maximum value of the end element ID predicted from the start element ID and the number of elements. This ID is displayed for confirmation.


    • - Operation Procedure -

    1.  Import both documents containing source and target parts into Jupiter.
    2.  Select the copy source document and copy source part from the list.
    3.  Select the copy target document and copy target part from the list.※Make sure that the copy source and copy target documents are not the same.
    4.  Enter a tolerance value as required.
    5.  Press the Apply or OK button to execute the command.
