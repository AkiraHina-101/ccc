Position

Select the Three Node pair A, B, and C, to move the Target Part to Base Part position.
After the movement, Target Part is moved to a position such that the three node pair overlaps.

Operation

  • Create New Part

    •    Copy the part after the parallel move, as a new Part.

  • LBC Copy

    •    Also copy load constraints that were added to the existing part to a new part.

    Position

  • Clear All Selection

    •    Clear all of the selected nodes.

    Option

  • A(Target)　

    •    For Node pair A, enter the Node for Target (moving target Part) from the screen.

  • A(Base)

    •    For Node pair A, enter the Node for Base (movement reference Part) from the screen.

  • B(Target)

    •    For Node pair B, enter the Node for Target from the screen.

  • B(Base)

    •    For Node pair B, enter the Node for Base from the screen.

  • C(Target)

    •    For Node pair C, type the Node for Target from the screen.

  • C(Base)

    •    For Node pair C, type the Node for Base from the screen.


    - Operating Procedure -

    1.  When you want to create a new part after Part movement, select the Create New Part.
    2.  Turn on the LBC Copy to copy a load restraint conditions of the existing part to the new part.
    3.  Press the Part button, and select the Part for movement from the screen.
    4.  Select in the order of A (Target), A (Base), B (Target), B (Base), C (Target), C (Base).
         Select the appropriate Node from the screen after you click on the input box. Selected Node number is displayed in the input box.
    5.  If you want to Clear the selected Node, press the Clear All Selection, and select the Node again.
    6.  Press the Apply or OK button.
