Connection | BarBeam

This command is used to create bar/beam elements by selecting two points.
＊1D Property data must be prepared previously.

Connections

  • Name

    Enter the name of the bar parts to be created.

    • Property

  • Property

    Select the 1D Property to be specified.

  • Orientation vector

    Define the orientation vector.

    • Vector

      Specify the vector by user input.

    • Node

      Specify node.

    • Local Unit

  • Length

    Specify the local unit for defining the length.

  • Mass

    Specify the local unit for defining the weight.

    • - Operating Procedure -

    1.  Select 2 nodes.
    2.  Select the property.
    3.  Specify the orientation vector.
    4.  Click the Apply/OK button.
