XX-YY On 1 Point

Select parts to split along the specified coordinate plane with one node as a starting point.

Selection Plane

  • Select

    Select the coordinate plane to split.

    • Y-Z On 1 Point

      Select Y-Z Coordinate plane to split, along with the node on the same plane which is to be the starting point of division.

    • X- Z On 1 Point

      Select X-Z Coordinate plane to split, along with the node on the same plane which is to be the starting point of division.

    • X-Y On 1 Point

      Select X-Y Coordinate plane to split, along with the node on the same plane which is to be the starting point of division.

  • Offset

    Enter the offset value. They are separated by a distance that is offset from the split plane specified by three points.

  • Partition Only

    When it is checked, a partition is created inside. In this case, the parts are not split.

  • Make Section Face

    If you check this box, in the case of dividing the parts, a face is created at the section.

  • Shared Face

    When this box is checked while dividing the parts, a shared surface is created at the division plane.

  • Coordinate System

    Select the coordinate system for coordinate plane to split.

  • Separate Face

    When this box is checked while dividing the parts, if you want to create a face to the division place, it prevents the face to be coupled (merge) in the enclave.

    • - Operating Procedure (while splitting the parts, to create a face to the split point)  -

      　　　
    1.  Select the coordinate plane to split.
      2. 　　　
    2.  Open the Selection List window and click the Target button.
      3. 　　　
    3.  Select the part to be split.
      4. 　　　
    4.  Click the Cut button in the Selection List window.
      5. 　　　
    5.  Select a node on the coordinate plane you selected, which is to be the starting point of division.
      6. 　　　
    6.  Turn on the check box for Make Section Face.
      7. 　　　
    7.  Change the coordinate system from the default if necessary.
      8. 　　　
    8.  Click Apply / Ok button.

    - Operating Procedure (without dividing the parts, to create partitions only) -

      　　　
    1.  Select the coordinate plane to split.
      2. 　　　
    2.  Open the Selection List window and click the Target button.
      3. 　　　
    3.  Select the part to be split.
      4. 　　　
    4.  Click the Cut button in the Selection List window.
      5. 　　　
    5.  Select a node on the coordinate plane you selected, which is to be the starting point of division.
      6. 　　　
    6.  Turn on the Partition Only check box.
      7. 　　　
    7.  Turn on the check box for Make Section Face.
      8. 　　　
    8.  Change the coordinate system from the default if necessary.
      9. 　　　
    9.  Click the Apply/Ok button.
