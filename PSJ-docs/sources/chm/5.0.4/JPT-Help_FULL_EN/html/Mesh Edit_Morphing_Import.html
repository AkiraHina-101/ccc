Import

Read the displacement results to move the nodes of the mesh model.


Position

  • Solver

       Select the solver for displacement results.

  • Browse

       Select the data for displacement results.

  • Step(Subcase)

       Specify the Step, Subcase, Process, to use the displacement results.

  • Scale

       Specify the scale for displacement results.


    • - Operating Procedure -

    1.  Select a Part from the screen.
    2.  Click the Browse, and select data for displacement results (op2 file).
    3.  Specify Step, Subcase, Process to use the displacement results.
    4.  Specify the scale of the displacement results.
    5.  Click the Apply or OK button.
