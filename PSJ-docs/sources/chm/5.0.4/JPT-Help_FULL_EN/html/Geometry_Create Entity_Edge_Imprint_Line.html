Line

Imprint a straight line Edge on the Part.

Options

  • Break Face

    •    In the case of enabled this function, the splittable face will be split.


    - Operating Procedure -

    1.  Select Nodes, Face points or edge points which you want to create a closed edge to imprint on a face or faces.
    2.  Select face or faces where you would like to imprint edges.
    3.  If you want to split the selected faces, check ON the Break Face option.
      If you don't want to split the selected faces, check OFF the Break Face option.
    4.  Click Apply / OK button to execute the function.
      Note: Before clicking Apply / OK button, the function will show the result as preview
