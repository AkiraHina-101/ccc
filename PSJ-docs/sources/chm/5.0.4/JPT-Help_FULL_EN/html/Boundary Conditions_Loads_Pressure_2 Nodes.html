Pressure | 2 Nodes

Add the distribution pressure load specified by the two nodes in the analysis model.

　　

Structural

  • Name

       Enter the name of the pressure load conditions.

    • 　　

    2 Nodes

     Set up the pressure load.
  • Direction

       Select a method for distribution.

  • Node A

       Select the starting point of the distribution.

  • Value A

       Enter the value of the distribution pressure for the start position.

  • Node B

       Select the starting point of the distribution.

  • Value B

       Enter the value of the distribution pressure for the start position.

  • Input Unit

       Specify the input unit of the pressure value.


    • - Operating Procedure -

    1.  Select one of the buttons for Face or Element from the selection list and choose the pressure load application object from the screen.
    2.  Enter a name for the load.
    3.  Select the node button from selection list and select the two points in order from the screen. Each will be registered in Node A, Node B.
    4.  Enter each of the value A and value B.
    5.  Click the Apply or OK button.
