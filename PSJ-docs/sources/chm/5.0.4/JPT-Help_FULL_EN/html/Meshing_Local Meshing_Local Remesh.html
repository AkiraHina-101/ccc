Local Remesh

After Surface Mesh created, you can remesh the Surface Mesh.

Remesh Type

  • Tri3

       Remesh the triangular elements.

  • Quad4

       Remesh the quadrilateral element.

    • Quad F-Mesher : Use the high-speed Mesher to create the elements of a adjusted size.
      •

    • Mesh Size

  • Average

       Set the average Mesh size.

  • Minimum

       Set the minimum mesh size.

  • Maximum

       Set the maximum Mesh size.

  • Mesh Setting

       Remesh using the Local Mesh configuration.

  • Pattern Override

       Specify the Mesh Pattern.

    • Iso Mesh : Create a IsoMesh on Remesh part. This method can only be applied where Mapped Mesh creation is possible
    • Free Mesh : Create a Free Mesh on Remesh part
      •

  • Grading

       Remesh the selected Face and the surrounding faces. When turned off, it will be Remesh the selected Face only.

  • Keep Connection

       Keep the node position of the connecting component parts, such as springs, rigid, beams.

  • Project CAD

       Place Remesh on a CAD geometry.

    • Mesh Gradation

  • Grading Factor

       Set the degree of the change for Mesh.

    • Tiny Face Merge

  • Tiny Face Merge

       Create mesh as well as modify the tiny-face at the same time.

  • Min Face Width

       Specify the minimum width of the target Face.

  • Max Face Width

       Specify the maximum width of the target Face.


    • - Operating Procedure -

    1.  Select the Mesh Type.
    2.  Select the target entity.
    3.  Click Apply / OK button.
