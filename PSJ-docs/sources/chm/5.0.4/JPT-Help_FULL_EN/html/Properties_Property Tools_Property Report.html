Property Report

Property Report dialog box

Outputs a list of which properties and materials are assigned to each part in the document as a report in HTML file format.

Set working difectory to export html file

　　
  • Select folder to save the creating html file

    Specify the folder to save the HTML file and the folder to store the captured images.

    　　　

    • Change Part color (Optional)

    　　
  • Option

    Option to change the part color when capturing.

    • Random

      Temporarily changes the current part surface color to a random color and captures it.

    • By Material

      Temporarily change the part surface color to the material color and capture it.

    • By Property

      Temporarily change the part surface color to the property color and capture it.

      •

    　　　

    • - Operating Procedure -

    1. Prepare the model with properties/materials assigned.
    2. Launch the Property Report command.
    3. Select folder to save the creating html file.
    4. Select options as needed.
    5. Click the Apply/OK button to output the report.
      "DocumentName.html" and DocumentName_image folder will be created in the html file saving folder.
    6. Open the "DocumentName.html" file in your browser.
