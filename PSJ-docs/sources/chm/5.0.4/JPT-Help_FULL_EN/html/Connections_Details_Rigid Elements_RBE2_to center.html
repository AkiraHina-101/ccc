Connection | RBE2 - To Center

This function is to create one to many (Master : Slave) RBE2 (Rigid Element).
＊Slave node can be selected on the parts basis, face basis, edge basis, element-wise or on node basis.

Master node and slave node (in the connection range) are connected. The master node is created in the average coordinate of the selected slave node or any coordinates.
This is useful when you want to define a master node outside the model.

Connection

  • Name

    Enter the name to be registered.

    • Search Area

  • All

    Specify the connection range as infinite.

  • Tolerance

    Enter the radius R of the connection range.

    • Positon of master node

  • X Y Z

    The coordinates of the master node is displayed.
    The coordinate will be set automatically to the average coordinates of the selected slave nodes. You can also edit it to any coordinate value.

  • Update the coordinate to center of latest selected edge

    The coordinates of the latest selected edge are displayed and used as the master node of RBE2.
    If the selected edge is a curve, the coordinates will be the average center coordinates of the curve, and if it is a straight line, the coordinates will be the average coordinates of the nodes.
    For example, the center of the bearing surface of a bolt (circle or cylinder shape) will be used as the master.

    • Reference Dofs

  • UX - RZ

    Specify the component of the dependent DOF.

    • Analysis Coordinate Frame

  • Coordinate

    Select the reference coordinate system.

    • Abaqus

  • Surface Definition Output

    Select how to define the surface.

    • By Node Set

      Specify the node as a reference surface.

    • By Element Set

      Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output.

    • Options

  • Only corner nodes

    Connect only to the corner nodes of the selected entity.

    • - Operating Procedure -

    1.  Set the connection range.
    2.  The slave nodes are selected from parts, face, edge, element and node.
    3.  If necessary edit the coordinates of master nodes to any value.
    4.  Set the parameters.
    5.  Click Apply / OK button.
