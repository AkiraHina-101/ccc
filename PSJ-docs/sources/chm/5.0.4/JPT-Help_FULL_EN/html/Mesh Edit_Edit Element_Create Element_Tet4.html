Create Element TET4

If an element is missing, select the node of the missing element and create an element there.

Create Element TET4

  • Auto

    Check the box and select the 4th node or 1 element 1 node to create an element automatically.

  • Belong Part

    If checked and a part is selected, an element will be created on the selected part.

    • Part ID

      Display the selected part ID.

  • Create New Part

    Create an element as a new part.

    • - Operating Procedure -

    1.  Select the 4th node or 1 element and 1 node of the missing element.
    2.  If necessary, check the Belong Part option. If the option is checked, select the part to which you want to add a new element to be created.
    3.  Click Apply button.
    4.  An element enclosed by the selected node is created.
