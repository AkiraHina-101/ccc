Element Related Information | Shell Dialog Box

You can individually change the direction vector and end release information of elements included in the selected edge or directly selected elements.

　　
  • θ

    Enter the direction angle of the material property and overwrite.

    　　　
    • 　　
  • CS

    Enter a coordinate system and overwrite it.

    　　　
    • 　　
  • Z Offset

    Input offset amount from element reference plane and overwrite.

    　　　
    • 　　
  • Select All

    All elements displayed in the shell element list are to be overwritten. All check boxes will be checked.

    　　　
    • 　　
  • Select None

    Remove all elements displayed in the shell element list from the overwrite target. All check boxes will be cleared.

    　　　
    • 　　
  • Set Selected

    Target elements are selected from the screen and displayed in the selection list or elements are picked and highlighted in the shell element list. Only the selected element's check box is selected and displayed in the selection list.

    　　　

    • - Operating Procedure -

      　　　
    1.  Selecting a command will display all existing shell elements in the list. Initially, the check boxes for all element IDs are checked, and all elements are subject to overwrite.
      2. 　　　
    2.  To overwrite only specific elements, press Select None below the list and deselect all elements. The check box is cleared.
      3. 　　　
    3.  Select the target element from the list on the screen or in the dialog box, specify it and press the select button. The target element's check box is selected.
      4. 　　　
    4.  Enter the value to be changed to an item such as a direction vector and press the Set Selected button. The target item on the list is overwritten.
      5. 　　　
    5.  Click Apply or OK to apply your changes.
