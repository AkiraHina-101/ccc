Boundary Condition Copy

LBC Copy Dialog Box

This command copies loads and constraints set from one part to another part.
You can also specify parts in different documents as copy destination.

Source

  • Source document

    Specify the document to copy from.

  • Type

    Select the type of entity to copy. The existing entities in the model are in the list below:
    LBC   ： Copy existing boundary conditions.
    Property   ： Copy existing property information.
    Connection   ： Copy an existing connection.
    Group   ： Copy an existing group.

  • Auto / Manual

    ※This feature is not used in V4.0.

  • Match method

    Select the method to use for target matching judgment of copy source and copy destination.
    Node   ： This matching method matches the exact nodes of the target to get matching results. This method is useful when the target features are different.
    However, if you select a solid body as the target, the solid mesh will always have a failed match, as it is very rare that the body looks exactly the same but will have the same nodal position.
    In this case, you need to switch to the feature method.
    Feature   ：This matching method is very fast, especially for large models, and requires face-to-face, vertex to vertex like feature matching.

  • All Data


    Select the listed entities at once. From the left, Check All, Uncheck All, Reverse All Check Status.

  • Entity Type

    All types of fields displayed in the table below are registered. If you select a specific type here, the table below will be shortened according to your selection. Select All to confirm all items.

  • Filter

    Filter the displayed items by part of the name entered to facilitate selection.

  • Method

    Select the method of aligning to the copy destination position. The LBC copy function determines the copy destination entity by the position.
    Translation   ：The copy destination is searched by translation in the X, Y, and Z directions.
    Rotation   ：The copy destination is searched by the rotational movement of the specified axis.
    Mirror   ：Search the copy destination by plane and offset amount. To define a plane, select 3 nodes or 2D elements.

  • Input Unit

    Select a unit system of length. Valid for all length input values.


    • When Translation movement is selected

  • Coordinate System

    All coordinate systems in the current document are displayed and can be selected.

  • Axis

    Select an axis to determine the movement direction. You have the following options:
    Arbitrary Axis   ：Directly enter the direction cosine in the lower X, Y, Z input box to define the axis direction.
    X axis, Y axis, Z axis   ：Define the axis direction from the X, Y, Z axes of the selected coordinate system.
    2 Nodes   ：Select two nodes from the View window and define the axis direction.
    Edge   ：Select an edge from the View window to define the axis direction.

  • Magnitude

    Enter the move distance of the copy destination.

  • Tolerance

    Enter the tolerance value to be used for determination of conformity. Unit of length.


    • When Rotation movement is selected

  • Coordinate System

    All coordinate systems in the current document are displayed and can be selected.

  • Center

    Define the center of rotation. You have the following options:
    Body Center   ：Adopt the center of the boundary box containing all the parts in the document as the center of rotation.
    Node   ：Adopt the selected node as the rotation center.
    Input   ：Enter the rotation center coordinates directly in the lower center -X, center -Y, center -Z input box.

  • Rotation Axis

    Define the rotation axis. You have the following options:
    Arbitrary Axis   ：Enter the direction cosine of the rotation axis direction in the lower X-axis, Y-axis, and Z-axis input boxes.
    X axis, Y axis, Z axis   ：The selected axis direction of the selected coordinate system is adopted as the rotation axis.
    2 Nodes   ：Select two nodes from the View window and define the rotation axis.
    Edge   ：Select an edge from the View window to define the rotation axis.

  • Angle

    Enter the copy destination rotation angle.

  • Tolerance

    Enter the tolerance value to be used for determination of conformity. Unit of length.


    • When Mirror is selected

  • Offset

    Select 3 nodes or 2D elements from the View window and enter the offset amount from the specified plane.

  • Tolerance

    Enter the tolerance value to be used for determination of conformity. Unit of length.

    • Target

  • Target Document

    Specify the document to copy to. Documents that are currently open in Jupiter-Pre are listed, so you can specify a different document from the one you copied from.

  • Auto / Manual

    ※This feature is not used in V4.0.


    • - Operating Procedure -

    1.  From the source document, select the LBC etc. to be used for copying.
    2.  Select the entity type to copy from the type. The existing entities are displayed in the table below according to your selection.
    3.  Select the appropriate method for nodes or features from the matching method.
    4.  Select the method of specifying the copy destination position from Translation, Rotation, or Mirror, and enter the copy destination position appropriately.
      ※When 2 nodes or edges are selected, it is necessary to select nodes or edges from the View window.
    5.  Select the LBC etc. document to be used for copying from the copy destination document and press the Apply or OK button.
       The selected LBC etc. is copied to the copy destination part and placed.
