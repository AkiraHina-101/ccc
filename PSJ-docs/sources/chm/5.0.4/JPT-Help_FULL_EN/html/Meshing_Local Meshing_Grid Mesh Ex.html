Grid Mesh

This command creates a grid mesh (mapped mesh) not only for simple square shapes but also for complex shapes.

Face Shape

  • Operation

       Select the type of face to enter (triangle or rectangle)
       ※Note: Quad4 can not be used for meshing if you select a triangle

       How to change the selected vertex:
       If you want to change the recommended vertex, click on the red dot on the display and select the destination vertex.

    • Element Number

  • X、Y

       Number of elements in the X and Y directions (the length of X is shorter than Y)

  • Fixed

       Fix the number of X and Y elements when selecting another face.

    •    If the check box is not checked: This function automatically recommends the number of divisions from the local mesh settings or the shape of the selected entity.

       If the check box is checked: The fixed number of divisions is retained even after selecting a new entity.

    Transition Region

  • Neighbor Faces

       Create a transition region in the surrounding face (there is only one layer of transition elements around the border of the selected face, and the location of this layer is outside the border of the selected face).

  • Target Faces

       Change the mesh of the selected face only (keep the mesh of the other face).

    • Grid Mesh Type

  • Tri

       Generate triangle element (Tri3 element).

  • Quad

       Generate a quadrilateral element (Quad4 element).

    • Multiple Selection

  • Independent

       Generate each mesh on the selected face.

  • Merged

       If the selected face is a continuous face, the faces are merged into one face and a mesh of this combined face is generated.
       ※Note: After merging, the merged faces will show the smallest ID of the selected faces.

    • Flip Element

       Change the mesh pattern to make the mesh quality better.
       ※Note: This option is only available for triangular elements (Tri3).

  • None

       Do not use this option.

  • 1 Layer

       Change the mesh of one layer near the border of the selected face (the location of this layer is within the border of the selected face)

  • All

       Change all elements of the selected face.

    Advanced Options

  • Add to GridMeshFaces group

       Add mesh faces to the GridMeshFaces group.

  • Use Local Mesh Setting

       Use local mesh settings
       ※Note: You can only use the edge mesh number and the face mesh size (the face mesh size takes precedence).

  • Preview

       Display temporary results as a preview (not the final result of the mesh).

    • - Operating Procedure -

    1.  Select the face shape type for which you want to create a grid mesh from operations: rectangle or triangle.
    2.  Select one or more faces to be targeted. The recommended values for the number of element divisions in the X and Y directions are displayed according to the surrounding element division situation.
    3.  If necessary, enter the desired number of element divisions in X, Y of the element number. Also, if you want to fix the number of divisions while working, check the Fixed check box.
    4.  Select the transition area creation target from the transition area as required.
    5.  Select the element type to use for mesh division from the grid mesh type according to need.
    6.  When multiple faces are selected, select whether to create a mesh for each face independently from multiple selection or to create a mesh as a single sheet.
    7.  If you selected a triangular element, select the range to flip the element from the flip element if necessary.
    8.  From the advanced options, select Create group, Apply local mesh settings, and with or without preview, if necessary.
    9.  Press the Apply or OK button to execute the function.
