Contacts | Abaqus - Share Face

Define the Abaqus contact settings from the specified face.
Shared surfaces are separated (to create a double nodal state) and the contact pairs are defined between its separated face.

Basic

　　　
  • Name Prefix

    Enter the name you want to give the contact pair name.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Contact between face-to-face
        Node to Face: Contact between the slave face-to-face by the specified node

    　　　
    • 　　　
  • Type

    Select the behaviour type of contact definition.
        General: Sliding contact
        Tied: Fixed
        All with self: Automatic contact detection

    　　　
    • 　　　
  • Information

        Show Information: Part name associated with the selected shared surface is displayed.

        Highlight Body: Part associated with the selected shared surface will be highlighted.

    　　　

    • Contact Properties

    　　　
  • Adjust

    Specify the adjustment width of the initial node position.

    　　　
    • 　　　
  • Extension Zone

    Specify an extended area.

    　　　
    • 　　　
  • TIE

    The fixed conditions and contact pair
        On: Fixed specified

    　　　
    • 　　　
  • Max Penetration

    Specify the maximum penetration amount.

    　　　
    • 　　　
  • Smooth

    Specify the smoothing angle.

    　　　
    • 　　　
  • Small Sliding

    Specify the consideration of small-slip.
        Off: Disable
        On: Enable

    　　　
    • 　　　
  • Formulation

    Specify the contact formulation type.
        Node to Surface: Node - face contact
        Surface to Surface: Surface - surface contact

    　　　

    • Friction Properties

    　　　
  • Friction Type

    Specify the friction characteristics type.
        None: Friction is not considered
        General: General Contact
            Friction Coef.1: Friction coefficient 1
            Friction Coef.2: Friction coefficient 2
            Shear Stress Limit: Shear stress limit
            Slip Tol.: The maximum allowable elastic slip for surface dimension ratio
        Lagrange: Lagrange multiplier method
            Friction Coef.1: Friction coefficient 1
            Friction Coef.2: Friction coefficient 2
            Shear Stress Limit: Shear stress limit
        Rough: Rough (no slip)
        Static&Kinetic: Specify the static and dynamic friction
            Slip Tol.: The maximum allowable elastic slip for surface dimension ratio
            Static Friction Coef: Coefficient of static friction
            Kinetic Friction Coef: Dynamic friction coefficient
            Decay Coef: Reduction factor

    　　　

    • Normal Behavior

    　　　
  • Pressure-Overclosure

    Contact thickness of the contact direction behaviour, to define the penetration characteristics type.
        Hard Contact: Rigid contact
            Allow Separation: Separation permit
        Exponential: Index
            Input Data: Pressure 0: exponential curve for definition of pore volume and pore volume 0: pressure input
        Linear: Linear
            Contact Stiffness: Rigid contacts
        Tabular: Table form
            Input Data: Table input pressure, penetration depth

    　　　

    • Thermal Conductance

    　　　
  • Date Type

    Specify the contact characteristic definition method of heat conduction
        Clearance Dependency: Gap value dependent
            Input Data: Pore volume dependent thermal conductivity table input
        Pressure Dependency: Pressure dependence
            Input Data: Pressure-dependent thermal conductivity table input
        Clearance and Pressure Dependency: Gap value and pressure dependence
            Input Data: Pore volume and pressure-dependent thermal conductivity table input

    　　　

    • Color Setting

    　　　
  • Contact Color

    Define the contact-display marker color.
        Reset: Return to the default color.

    　　　

    • - Operating Procedure -

      　　　
    1.  Create a shared surface in advance by the assembly function and leave the display on shared surface.
      2. 　　　
    2.  Select the shared surface that you want to define as a contact.
      3. 　　　
    3.  Define the advanced settings for the pair of contacts, click the Apply (OK) button to create contact definition.

    Shared surfaces are separated (the face to create a double nodal state) and the contact pairs are defined between its faces.
