Angle [2 Nodes Axis]

Measure the angle between the axis formed by two nodes and the coordinate system axis.

　　

Option

  • Coordinate System

       Choose a projection coordinate system.

  • Axis

       Axis in the specified coordinate system.

    • Output

  • Angle

       Measurement result is displayed.

  • Input Unit

       Set the preferred unit system .

  • On Local XY

       Projection angle in the specified coordinate system XY plane.

  • On Local YZ

       Projection angle in the specified coordinate system YZ plane.

  • On Local ZX

       Projection angle in the specified coordinate system ZX plane.

    • - Operating Procedure -

    1.  Select two nodes which becomes the axis from the screen.
    2.  Select the coordinate system and the axis in the Local coordinate system.
    3.  Value of the angle and the projected angle plane consisting of two node axis and axis to local coordinate system XY (YZ,ZX) is displayed.
