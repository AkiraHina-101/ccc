Reference Window

Display the structure of the original CAD model in tree format after meshing the CAD model.


Control Menu

Adjust the display of the tree.

IconNameDescription
Clear SelectionClear all selected tree items.
Expand AllExpand all subtrees.
Collapse AllCollapse all subtrees.
Toggle SortSort the part in order by name or ID.
Show BothDisplay the overlapped mesh and reference
Show MeshDisplay the mesh of the currently displayed parts.
Show ReferenceDisplay the reference of the currently displayed parts.

Tree View

Display the structure of CAD parts in tree format.


  • Shortcut menu

    • Right-click on any item in reference window to display the shortcut commands list. Execute the command by clicking on the command.

    MenuContent
    SelectSelect the reference of the part under the highlighted item.
    HideHide the reference of the part under the highlighted item.
    Hide OnlyHide only the highlighted part item reference and display all references for other parts.
    ShowDisplay the reference of the highlighted part item.
    Show OnlyHide the reference of the parts other than the highlighted part item.
    Show AllDisplay all references of parts in the model.
    Hide AllHide all references of parts in the model.B
    Invert Hide/ShowReverse the display / non-display state of parts reference in the model.

  • Shortcut key list

    • Shortcut key gives quick access to some of the functions through keyboard keys.

    Shortcut keyFunction
    Up and down arrow keysMove the highlight of tree item .
    FFit the selected parts to the screen. Fit the entire model to the screen if parts are not selected.
    EDeselect the selected entity
    Ctrl+Mouse left clickHighlight multiple tree items.
    Shift+Mouse left clickHighlight multiple consecutive tree items.
