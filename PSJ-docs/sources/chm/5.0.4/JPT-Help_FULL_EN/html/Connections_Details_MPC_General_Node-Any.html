MPC General | Node-Any

This function creates an MPC between 1 node and multiple entities.

Node-Any

  • Name

    Enter the name to be registered.

    • Parameters

  • Coordinate

    Select the reference coordinate system.

  • TX Displacement - TZ Displacement

    Specify the constraints for translation direction.

  • RX Displacement - RZ Displacement

    Specify the constraints for rotation direction.

    • - Operating Procedure -

    1.  Select the master node.
    2.  Select the other entity as slave.
    3.  Set the parameters.
    4.  Click Apply / OK button.
