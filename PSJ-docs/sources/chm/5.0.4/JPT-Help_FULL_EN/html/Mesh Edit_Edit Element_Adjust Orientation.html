Adjust Orientation

Adjust the orientation of the selected part or face element relative to the selected element.

Adjust Orientation

  • Entity

    Part: Modify the element orientation on a part-by-part basis.

    Face: Modify the element's orientation on a face-by-face basis.

    • ※It is also possible to modify multiple entities (parts or faces) at once.
    In this case, select elements contained in the selected entity one by one as elements of the criteria.

    - Operating Procedure -

    1.  Select the part or face to be modified.
    2.  Select a reference element
    3.  The function is executed with the Apply or OK button.
