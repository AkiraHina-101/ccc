Advanced Shell Assembly

Connect faces between assembly models of multiple shell parts.

Parameters

  • Mesh Type

    Specify the surrounding element to connect.

    • Tri3

      Specify if the mesh on the face is a triangular primary element. (Default)

    • Quad4

      Specify if the mesh on the face is a quadrilateral primary element. The mesh around the assembly edge is remeshed into a square.

      •
  • Assembly Type

    Specify how to connect between faces.

    • Extend Face

      Within the interval threshold, the free edge detects a portion not in contact with the face and stretches the free edge to the face to imprint and connect.

    • Connect Edge

      Connect the edges that exist within the interval threshold.

    • Cross Face

      Detect face intersections and imprint the edges.

    • Automatically

      The above three patterns are automatically judged and the edges are imprinted and connected appropriately.

      •
  • Gap Tolerance

    Enter the distance to determine that the face and the edge, and the edge and the edge are connected.

    • - Operating Procedure -

    1.  Select the target multiple parts or multiple faces.
    2.  Select the assembly type as required.
    3.  If necessary, change the interval threshold value from the default value.
    4.  Click the Apply / OK button.
