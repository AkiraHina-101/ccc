    • Options

  • Write Group

       Output the face, element, and node groups as $SurfaceSegment, $ElementSet, and $NodeSet respectively.

  • Separate File

       When the scale of analysis is large, outputting the data separately reduces the size of the input file for analysis control and makes it easier to change commands by manual input. Only node and element data are output in separate files.

    • None : Output all data to a single file.
    • By Model : Output node and element data in one separate file.
    • By Body : Output node and element data in separate files for each body.
    • By Selected Body : Output all LBCs related to the selected body.
    • Select LBCs : Output only the selected boundary conditions to a file.

  • Boundary Conditions

       Output boundary conditions, contact pairs, and contact segments to separate files.

  • Use Entity Name

        Output all LBCs related to the selected body.

  • Delete Floating Node

       Delete and output all unused floating nodes in the model.

  • BC Duplicate Check

       Check whether the same type of boundary condition with different values overlaps on a node.

  • Separate part info file

       Output node and element data of the selected body in separate files for each body.

       Select the method of specifying the heat transfer coefficient (Direct, Indirect).

  • Contact Parameter

       Specify the contact iteration and the convergence tolerance concerning friction.

  • Contact Parameters

       Specify whether to use contact iteration parameters.

  • Subdivide_mode

       Specify what to do when the maximum number of contact iterations is reached.

    • Yes : Recalculation one more time with a smaller time step.
    • No : Fix the contact state in the step and proceed further.
      •
  • Contactloop_max

       Specify the maximum number of external contact iterations.

  • Internal_contactloop_max

       Specify the maximum number of internal contact iterations.

  • Separation_tol

       Specify the contact pressure which determines that tension has occurred.

  • Relative_separation_tol

       Specify the tolerance for calculating the relative contact pressure, which determines that tension has occurred.

  • Penetration_tol

       Specify the penetration tolerance.

  • Relative_penetration_tol

       Specify the relative penetration tolerance.

  • Maxchp

       Specify the contact iteration convergence tolerance.

  • Friction_onset

       Specify the timing of the contact state to be referenced when considering friction.

    • delayed : No friction is considered for contact pairs that are open at the beginning of the increment.
    • immediate : Consider friction for contact pairs that are closed at the end of the increment.
  • Stick_slip_tol

       Specify the stick slip tolerance.

  • Friction_tol

       Specify the friction convergence tolerance.

  • Estimate_impact_time

       Specify whether to estimate the time of impact/separation in dynamic analysis.

    • No : Not estimate the impact/separation time.
    • Yes : Estimate the impact/separation time.

       Specify the mode number to be extracted. (available with Eigensolver=cgcgpi only).

  • Frequency Range

       Specify interval frequency to be extracted. (available with Eigensolver=Lanczos only).

    • max_frequency  :  Specifies the maximum search frequency range.
    • min_frequency   : Specifies the minimum search frequency range.
    • max_num_eigenvalues_on_interval   : Specifies the maximum number of eigenfrequencies and eigenmodes to be found for the generated search interval.
  • Eigen Value Parameter (Eigensolver=cgcgpi)

       Specify parameters for the eigenvalue analysis.

  • Eigen Parameters

       Specify whether to use parameters for eigenvalue analysis.

  • eigen_norm

       Specify the normalization method of the eigenvector to be output as the analysis result.

    • Mass : Normalize the generalized mass.
    • Max : The maximum displacement component is normalized to 1.
    • Unity : {U} T {u} is normalized to 1. {U} is the eigenvector to be obtained.
      •
  • shift

       Specify the shift value.

  • output_init

       Specifies whether to output results at the start of the process.

    • yes : Output results at the start of the process.
    • no : Not output results at the start of the process.
      •
  • output_lower_limit_frequency

       Specifies the natural frequency below which the result output will be lower.

  • output_participation_factors

       Specifies whether to output the stimulus coefficients corresponding to the obtained natural frequencies (eigen modes).

    • yes : Outputs stimulus coefficients using the same calculation method as origin.
    • no : Do not output stimulus coefficients.
    • gravity_center : Outputs stimulus coefficients with the center of rotation as the center of gravity.
    • origin : Outputs stimulus coefficients with the center of rotation as the origin.
    • x; y; z  : Outputs stimulus coefficients with the center of rotation as coordinates (x; y; z). User need to input rotation center coordinates.
  • cgcgpi_tol

       Specify the convergence determination tolerance with respect to the magnitude of the residual vector of CGCGPI method.

  • cgcgpi_eig_tol

       Specify the convergence determination tolerance for the eigenvalues of the CGCG method.

  • cgcgpi_loop_max

       Specify the upper limit of the number of iterations of the CGCG method.

  • cgcgpi_inner_tol

       Specify the tolerance of CGCG solver used inside the CGCGPI method.

  • cgcgpi_block_size

       Specify the number of eigenvectors that would be tried to converge at the same time.

  • cgcgpi_extra_mode

       Specify the number of additional modes n to be calculated to the number of modes specified by Extra mode from eigenvalues.

  • Eigen Value Parameter (Eigensolver=Lanczos)

    • - Operating Procedure -

    1.  Specify the Job Name.
    2.  Create a process with Make Process. If you want to perform the analysis in increments of default time, you do not particularly need to specify the time.
    3.  Assign the boundary conditions in the LBC Manager.
    4.  Select the output requests in the Output Manager.
    5.  Click Apply/OK button.
