Contacts | ADVC - Manual Group

Define the ADVC for contact set between the specified group.
Create a group with master and slave surfaces beforehand to define the contact in the contact settings.

Basic

　　　
  • Name

    Enter the name of the contact body.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Contact between the face to face

    　　　
    • 　　　
  • Type

    Select the behaviour type of contact definition.
        General: Sliding contact
        Tied: Fixed

    　　　
    • 　　　
  • Master

    Select the group that becomes the master surface.
        Search: Find the group in the definition name, and define as a master surface

    　　　
    • 　　　
  • Slave

    Select the group to be a slave surface.
        Search: Find the group in the definition name, and define it as a slave surface.

    　　　
    • 　　　
  • Switch Group

    Switch the master / slave segment group.

    　　　

    • Contact Properties

    　　　
  • Behavior

    Define the presence or absence of contact.
        Separation: Remove the contact restraint when the tensile force is generated
        No Separation: Binding on all of the contact pairs that were found at the beginning of the contact search

    　　　
    • 　　　
  • Formulation

    Select the contact formulation type.
        Node to Segment: Node - face contact
        Segment to Segment: Face - face contact

    　　　
    • 　　　
  • Constraint Type

    Define the contact constraint type.
        Lagrange: Lagrange undetermined multiplier method
        Penalty: Penalty method

    　　　
    • 　　　
  • Constraint Type Explicit

    Define the contact constraint type in the explicit dynamic analysis.
        Kinematic: Constraint method
        Penalty: Penalty method

    　　　
    • 　　　
  • Penalty Fact

    Define the penalty scale factor.

    　　　
    • 　　　
  • Penalty Fact Explicit

    Define the penalty scale factor in the explicit dynamic analysis.

    　　　
    • 　　　
  • Adjust

    Select whether you want to move the slave node on the master surface so that the clearance goes to zero.
        Yes: Move all of the slave node
        Value: Define the distance to enable the node movement.

    　　　
    • 　　　
  • Auto shrink

    Define the presence or absence of penetration elimination.
        Yes: Penetration elimination
        No: Without Penetration elimination

    　　　
    • 　　　
  • Search Gap

    Define the normal direction search distance for the gap surface.

    　　　
    • 　　　
  • Search Depth

    Define the normal direction search distance for the penetration surface.

    　　　
    • 　　　
  • Search Width

    Define the inside and outside determination parameter in the direction of the contact surface.

    　　　
    • 　　　
  • Search Angle

    Define the search angle of normal vector of the master / slave surface.

    　　　
    • 　　　
  • Initial State

    Specify the initial contact state.
        Auto: Auto-detect
        Open: Start analysis from the non-contact state
        Close: Start analysis from the contact state

    　　　
    • 　　　
  • Initial State Tol

    Enter the tolerance value to determine the initial contact state.

    　　　
    • 　　　 　　　
  • Finite Sliding

    Consider a finite sliding contact.

    　　　
    • 　　　
  • Clearance Selection

    Define the different clearance for each slave node.

    　　　
    • 　　　
  • Clearance

    Define the clearance amount.

    　　　
    • 　　　
  • Adjust to Clearance

    Choose whether you want to avoid the collapse element in accordance with node movement by Adjust function.
        Yes: The gap amount is replaced with 0, without moving the node.
        No: Without avoidance

    • - Operating Procedure -

      　　　
    1.  Create a master face, slave face or element face group in advance.
      2. 　　　
    2.  Select the master group as the master face and the slave group as the slave face.
         The selected group is highlighted in the model window. It is also possible to confirm by turning off the group display mode.
         It is possible to perform partial match search by entering a name in "Enter text here". You can also sort groups by clicking on the ID and Name fields.

      3.    If you want to edit the faces included in the existing group, double-click the group in the list to enter group edit mode. After editing the face such as adding a face in the model window, the group contents are changed by pressing the update button. Please note that the edited group is used as it is with other contact pairs.

      　　　
    3.  If necessary, define the detail settings for contact pairs, and click the OK button to define contact pairs.
