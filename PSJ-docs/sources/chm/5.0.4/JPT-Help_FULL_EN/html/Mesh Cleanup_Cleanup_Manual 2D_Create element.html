Create Element

If the element is missing, select the node of missing element to create a element.

Creation Element

  • Auto

    When checked, select 3-node (Type = Tria3) or 4-node (Type = Quad4) to automatically create element.

  • Keep Selection

    When checked, Leave the original node selected after element creation.

  • Type

    Specify the type of the element to create.

    • Tri3

      Create a Tria3 element.

    • Quad4

      Create a Quad4 element.

  • Belong Face

    When you put the check to select a face to, it creates an element to the selected faces.

    • Face ID

      Display the selected faces ID.

    - Operating Procedure -

    1.  Select the node of missing element. If you want to create a Tria3 element select 3 nodes, for creating a Quad4 element select 4 nodes.
    2.  Click the Apply button.
    3.  Element surrounded by the selected node is created.

    - Operating Procedure (Belong Face option) -

    1.  Create a type, and change it to QUAD4.
    2.  Check the Belong Face option.
    3.  Select the 4 nodes.
    4.  Select the faces you want to add an element.
    5.  Click the Apply button.
    6.  The newly created element will be added to the selected face component.
