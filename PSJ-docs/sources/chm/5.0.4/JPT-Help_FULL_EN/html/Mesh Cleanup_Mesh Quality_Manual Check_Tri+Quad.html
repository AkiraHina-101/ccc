Mesh Quality - Manual Check [Tri+Quad]

Make corrections to the surface for Surface mesh (Tri3 / Tri6) and (Quad4 / Quad8) simultaneously.

Element Quality

  • Metric　： It specifies the quality verification method.
    • ※Please refer to the ＜definition of quality confirmation method＞ for each menu item.

    Cutoff Value Tri

  • Minimum　： It displays the minimum value of the defined check type.
  • Maximum　： It displays the maximum value of the defined check type.
  • Average　： It displays the maximum value of the defined check type.
  • Num of Entities　： It displays the number of element type of the selected model.

    • Cutoff Value Quad

  • Minimum　： It displays the minimum value of the defined check type.
  • Maximum　： It displays the maximum value of the defined check type.
  • Average　： It displays the maximum value of the defined check type.
  • Num of Entities　： It displays the number of element type of the selected model.

    • Display Tri

  • Condition　： Set the inequality for the defined value.
  • Value　： Enter the settings of elements to be displayed.
  • Num of Entities　： It displays the number of elements that are displayed.
  • Display Bar　： You can see a bar chart distribution of the defined check type.

    • Display Quad

  • Condition　： Set the inequality for the defined value.
  • Value　： Enter the settings of elements to be displayed.
  • Num of Entities　： It displays the number of elements that are displayed.
  • Display Bar　： You can see a bar chart distribution of the defined check type.

    • Auto Cleanup

  • Cleanup　： You can automatically correct the element by pressing Cleanup button.
  • Mode　： Switch the mode at the time of the Cleanup.
    • Standard　： Standard
    • Aggressive　： Perform Cleanup taking into account the local settings, such as preserve.
  • Nonmanifold　： To check and fix non manifold.

    • Refresh

  • Show Model　： Replace the model display by pressing the Show Model button.

    • Defualt Settings

  • Save as Default　： Save the Mesh Statistics settings as default.

    • - Operating Procedure -

    1.  Select the body you want to check for element shape.
    2.  Specify the quality verification method.
    3.  Configure setting of elements to be displayed.
    4.  Press the Apply or OK button.
    5.  If you want to return to the original model display, press the Show Model button.

      6. ※Auto Cleanup function can not modify all of the elements automatically. If certain elements can not be corrected automatically, you must manually modify the elements using the Manual Cleanup feature.
