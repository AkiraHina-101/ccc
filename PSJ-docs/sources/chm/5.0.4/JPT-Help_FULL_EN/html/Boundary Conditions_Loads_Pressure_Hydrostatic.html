Pressure | Hydrostatic

Add the pressure load on the analysis model.

　　

Structural

  • Name

       Enter the name of the pressure loading conditions.

    • 　　

    Hydrostatic Pressure : |r×g×h|

     Set up the hydrostatic pressure load.
  • r. Fluid Density

       Enter the density of the fluid [r] that is referred by hydrostatic pressure.

  • Input Unit

       Specify the input unit of the fluid density.

  • Gravity Direction

       Select the direction of gravity in the model (the global coordinate system).

  • g. Gravity

       Enter the value of gravity [g].

  • Input Unit

       Specify the input unit of gravity values.

  • Coordinate of Water Surface

       Enter the coordinates [x] of the water surface position in the model.

  • Input Unit

       Specify the input unit of the coordinate values.


    • - Operating Procedure -

    1.  Select one of the Face or Element buttons from the selection list to choose the hydrostatic load object from the screen.
    2.  Enter a name for the load.
    3.  Enter Fluid density values, direction of gravity, gravity values and each coordinates of water surface.
    4.  Press the Apply or OK button.
