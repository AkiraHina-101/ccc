Total Load [Model]

Display the total value of force or pressure defined on the selected model.

　　

Measure

  • Method

       Measurement object for load.

  • Coordinate System

       Reference coordinate system.

    • Output

     : Display the measurement value
  • X

       Load in the X direction.

  • Y

       Load in the Y direction.

  • Z

       Load in the Z direction.

  • Total

       The absolute value of the total load.


    • - Operating Procedure -

    1.  In method select model.
    2.  Select the model for measurement from the screen.
    3.  The total value for the load applied on the selected node appears in the Output.
