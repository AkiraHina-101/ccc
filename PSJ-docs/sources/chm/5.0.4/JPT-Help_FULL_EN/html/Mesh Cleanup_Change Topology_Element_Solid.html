Change Topology | Element | Solid

Make the selected solid element belong to another part.

Options

  • Create New Part

    If checked, a new part will be created with the selected element.

    If you do not select it, the element belongs to the selected part.

    • - Operating Procedure -

    1.  Select a solid element.
    2.  If you want it to belong to another part, select the part.
    3.  If you want to create a new part, check Create New Part.
    4.  The function is executed with the Apply or OK button.
