Edge Options

Divide or combine the edges of the whole model from angle specification.

  • Break Edges

    If checked, the edge is split.

  • Merge Edges

    When checked, join the edges.

    • Face Options

  • Merge Planar Faces

    Check to combine faces in consecutive planes.

    • Vertex Options

  • Remove Extra Vertices

    If checked, extra vertices (such as vertices on floating nodes) will be removed from the whole model.

    • - Operating Procedure -

    1.  Select a part.
    2.  Set the options as required.
    3.  Click the Apply or OK button.
