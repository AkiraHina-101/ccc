Move the node by the coordinate input.

Position

  • Coordinate

    •    Specify the coordinate system.

  • X

    •    Enter the X coordinate.

  • Y

    •    Enter the Y coordinate.

  • Z

    •    Enter the Z coordinate.


    - Operating Procedure -

    1.  Select the Node that you want to move.
    2.  Specify the coordinate system to which it refers.
    3.  Indicate the location of destination in the coordinates.
    4.  Specify the unit for amount of movement in the local unit system.
    5.  Click the Apply or OK button.

      6.   ※If you turn off the check box at the top of X / Y / Z, it does not perform the movement in the direction you have turned off.
        ※When specifying a spherical coordinate system X / Y / Z is R / θ / δ、, at the time of specifying cylindrical coordinate system it will be changed to R / θ / Z.
