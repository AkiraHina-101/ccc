Cone

Create a cone.

Part Properties

  • Part Name

    Enter the name of the cone to be created.

    • Cone

  • Local Coordinates

    Select any of the coordinate system.

  • Frustum

    When checked, it makes a plane on the conical tip section.

  • Origin-X,Y,Z

    Specify the origin coordinates.

  • Top Radius

    If you put a check for Frustum, specify the radius of the plane of distal end portion.

  • Bottom Radius

    Enter the radius of the bottom.

  • Height

    Enter the height of the cone.

  • Number of Nodes in Circle

    Enter the number of nodes to be generated on the arc.

  • Number of Nodes in Axis

    Enter the number of divisions in the axial direction of the cone.

    • - Operating Procedure -

    1.  Enter the part name in the Parts Name.
    2.  Specify the origin coordinates in Origin-X, Y, Z.
    3.  Enter the radius of the bottom in Bottom Radius.
    4.  Enter the height of the cone in Height.
    5.  Enter the number of nodes to be generated on the arc in Number of Nodes in Circle.
    6.  Enter the number of divisions in the axial direction of the cone in Number of Nodes in Axis.
    7.  Click Apply / OK button.
