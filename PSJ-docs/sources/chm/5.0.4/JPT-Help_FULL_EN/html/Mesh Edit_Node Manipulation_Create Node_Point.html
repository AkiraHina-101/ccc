Point

Create a node by referring to the coordinate value of the arbitrary point.

Property

  • Node ID

    The ID of the created node is displayed.

  • X, Y, Z

    The coordinates of the created node are displayed. The coordinates of the selected arbitrary point will be entered.

  • Imprint

    If checked, imprint the nodes on the face. If checked off, a floating node will be created.

    • - Operating Procedure -

    1.  Select any point.
    2.  Set the imprint, if necessary.
    3.  Click the Apply / OK button.
