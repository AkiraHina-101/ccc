    • Options

  • Write Group

       Output the face, element, and node groups as $SurfaceSegment, $ElementSet, and $NodeSet respectively.

  • Separate File

       When the scale of analysis is large, outputting the data separately reduces the size of the input file for analysis control and makes it easier to change commands by manual input. Only node and element data are output in separate files.

    • None : Output all data to a single file.
    • By Model : Output node and element data in one separate file.
    • By Body : Output node and element data in separate files for each body.
    • By Selected Body : Output all LBCs related to the selected body.
    • Select LBCs : Output only selected boundary conditions to a file.
      •
  • Boundary Conditions

       Output boundary conditions, contact pairs, and contact segments to separate files.

  • Use Entity Name

        Output a file using the entity name on Jupiter.

        Output ADVC table data user defined name in Field Data.

  • Export related All LBCs

        Output all LBCs related to the selected body.

  • Delete Floating Node

       Delete and output all unused floating nodes in the model.

  • BC Duplicate Check

       Check whether the same type of boundary condition with different values overlaps on a node.

  • Separate part info file

       Output node and element data of the selected body in separate files for each body.

  • Heat Convection

       Select the method of specifying the heat transfer coefficient (Direct, Indirect).

    • Reference Restart Data

  • Data Dir

       Specify the directory where the restart file is located.

  • Process Number

       Specify the process number of the restart data.

  • Step Number

       Specify the step number of the restart data.

  • Coordinates Type

       Specify the coordinate system to be referenced in the restart analysis.

    • Initial : The displacement is the total value, including the value before the restart.
    • Deformation : The displacement is only the deformation component after the restart.
      •
  • Update Contact Search

       Specify whether to update the contact search with the deformation state at the time the restart analysis is started.

    • No : The contact search inherits the result of the restart data.
    • Yes : If no deformation is specified for the Coordinate Type, the behavior is the same as No.

    • ADVC Fixed Phrase

  • Template file

       List all template .adx files which are stored in the ADVC template folder.

  • Edit

       Edit the selected template .adx file.

    • Dummy Property

       Configure the dummy property settings.

  • Auto assign

       If checked, dummy properties will be automatically assigned to parts that do not have any properties assigned.

  • Material

       Specify the material of the part to which the dummy property is assigned.

       You can select a material that has already been registered in the user database for the material command. If the material is not registered in the user database, or if the material is registered but the blank is selected, a dummy material is assigned.

       In the case of dummy material, the material property value is output without being written.

  • Output Geometry ID

       If checked, output the geometry ID (PartID, FaceID, and EdgeID) for which dummy property is set.

    • - Operating Procedure -

    1.  Specify the Job Name.
    2.  Create a process with Make Process. If you want to perform the analysis in increments of default time, you do not particularly need to specify the time.
    3.  Assign the boundary conditions in the LBC Manager.
    4.  Select the output requests in the Output Manager.
    5.  Click Apply/OK button
