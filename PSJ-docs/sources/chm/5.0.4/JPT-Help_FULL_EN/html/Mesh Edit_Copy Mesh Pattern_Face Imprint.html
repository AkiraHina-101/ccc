Face Imprint

Face Imprint Dialog Box

In this command, the second selected face is imprinted on the face of the first selected face.

Options

  • Copy Mesh

    When you imprint the face shape, mesh pattern is also copied.


    • - Operating Procedure -

    1.  Select in order, the original face and the destination face from the view window.
    2.  Select the Apply or OK button to mirror transfer a copy of the original mesh pattern to the destination.
