Watch Selected Window

Display selected entity information.


・Select tab
Display a list of selected entities.

・Lock List tab
Display selected entities that are temporarily saved (locked).

Display the ID, type, value, etc. of the selected entity when the following operations are performed:
  • Entity selection
  • Double-click an entity in the selection list on the Watch Selected Window.
  • Click an entity in the fast pick window.
Display information and error information at the time of command execution.

- Operation Procedure -

  1.  When you select entities by picking in the main window, entities will be displayed in the selection list.
  2.  When you click the entity column in the selection list, the clicked entity is highlighted in the main window. In addition, detailed information is displayed in the output window.
