Mating Face

Mirror symmetry move or copy the selected Part.

Operation

  • Create New Part

    •    Copy the part after the parallel move, as a new Part.

  • LBC Copy

    •    Also copy load constraints that were added to the existing part to a new part.

    Option

  • Interactive

    •    When check is turned ON, the Body movement changes moment by moment.

    Target Bodies

  • Target Bodies

    •    Select the Body to be moved.

    Mating Face / Element

  • Source

    •    Specify the Face / Element of Body which is to be moved.

  • Destination

    •    Specify the Face / Element of Body as a reference.

  • Opposite Direction

    •    Invert the Body which is to be moved.

    Alignment Edges

  • Method

    •    Specify how the Edges are aligned.

    • 2 Edges : Specifies 2Edge
    • Edge - Vector : Specifies Edge and Vector
      •

  • Source

    •    Specify the Edge of Body which is to be moved.

  • Destination

    •    Specify the Edge / Vector of Body as a reference.

  • Angle (Degrees)

    •    Specify the angle.

  • Opposite Direction

    •    Invert the Body which it to be moved.

    Position Adjustment

  • Method

    •    Specify location adjustment.

    • 2 Points : Specifies 2Node
    • Points - Coordinate : Specifies Node and coordinates

  • Source Point

    •    Specify the nodes of Body which is to be moved.

  • Destination Point

    •    Specify the Body of Node / coordinate as reference.

  • Direction of Projection

    •    Projection direction.

    • Face Normal : The normal direction of the surface
    • Vector : Vector direction
      •

  • Vector (Global)

    •    Vector value. (Global coordinate system)

    Reset

  • Reset

    •    Restore the position of Body.


    - Operating Procedure -

    1.  Select the Body that has to be moved.
    2.  Select the Face of Body to move.
    3.  Select the Face serving as a reference Body.
    4.  Select the Edge of Body to move.
    5.  Select the Edge of Body as a reference.
    6.  Press the Apply or OK button.
