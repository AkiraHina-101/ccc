Universal Files

Output the selected part in Universal format.

This method supports triangle and quadrilateral elements for 2D elements, and tetrahedron and hexahedron elements for 3D elements.

Selection List
Part: Part to be output in Universal format (support selecting multiple parts)

- Operation Procedure -

  1. Select the part you want to output.

  2. Click the Apply or OK button.

  3. Enter the file path and file name, and save the file.

- Node order of each element -

  1. Linear triangular element

  2. Quadratic triangular element

  3. Linear quadrilateral element

  4. Quadratic quadrilateral element

  5. Linear tetrahedral element

  6. Quadratic tetrahedral element

  7. Linear hexahedral element

  8. Quadratic hexahedral element

- Special Note -

  1. There is no formal specification for the nodal ordering of universal format finite elements. The nodal ordering used by some software is different from Jupiter and other software, and in some cases the corner nodal IDs are sandwiched between intermediate nodal IDs.
