Import CAD

This command is used to import CAD data into Jupiter.
※An option license for each CAD type must be purchased in order to use this function.

  • Parasolid※1

    • Import Parasolid data.

  • TechnoStar Geometry

    • Import TechnoStar Geometry BDF files (General purpose geometry data for TSV/Jupiter).

  • VRML

    • Import VRML(Virtual Reality Modeling Language) data.

  • STL

    • Import STL(STereoLithography) data.

  • ACIS※2

    • Import ACIS data.

  • STEP※2

    • Import STEP data.

  • IGES※2

    • Import IGES data.

  • CATIA

    • Import CATIA V5※2 / CATIA V4※3 data.

  • JT※2

    • Import JT data.

  • Pro-E/Creo※1

    • Import Pro Engineer / Creo data.

  • NX※4

    • Import NX data.

    ※1Use the CAD data import function of Techno Star products.

    ※2Use the CAD data import function of Spacial or Elysium products.

    ※3Use the CAD data import function of Spacial products.

    ※4Use the CAD data import function of Elysium products.
