Point

Point

Indicate the destination by specifying an arbitrary point, and move the node.

Position

  • X

    •    Coordinates in the X direction are specified.

  • Y

    •    Coordinates in the Y direction are specified.

  • Z

    •    Coordinates in the Z direction are specified.


    - Operating Procedure -

    1.  Select an arbitrary point button in the selection list.
    2.  Specify an arbitrary point to move to.
    3.  Select the node button in the selection list.
    4.  Select the node to move.
    5.  Press the Apply or OK button.
