Solid Bolt Modeling | Mating Face

The following operations are automatically performed on solid bolts created in advance.
・Automatic placement of solid bolts
・Create a face for the seating area
・Setting Analysis Conditions
   Pretension for SunShine setting and contact setting
The Solid Bolt Modeling > Size function allows you to create a solid bolt model.
The solid bolt model (*.jth5) to be used should be placed in [User Profile]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB
※This folder is created when the Mating Face dialog is started.

Selection list
Part(Head) 　 ：The part from which the head part of the bolt
Part(Shaft)　 ：The part where the shaft portion of the bolt
Edge(Head) 　 ：The Edge of the area where the head of the bolt (manual operation)
Face(Shaft) ：The Face of the area where the shaft of the bolt(manual operation)

Mating Face Parameters

  • Gap Tolerance

    Enter the clearance tolerance between the upper and lower parts of the mating surfaces. Bolt holes on the mating surfaces that are less than or equal to this gap will be searched.

  • Angle Tolerance

    Enter the mating surface angle tolerance (deg) between the upper and lower parts. This parameter is used to determine the flatness of the mating surfaces and normally does not need to be changed.

    • Fastening Holes Parameters

  • Presets Size

    The bolt hole size selected in this menu is automatically entered into the minimum and maximum circle ranges below.
    The preset size of the bolt holes and the minimum and maximum indexes refer to 「[user profile]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB\Bolt_range_size_chart.xlsx」
    Edit this file if you want to change the minimum and maximum values that define the preset size.

  • Min Circle Range

    Enter the minimum diameter of the bolt hole to be searched.

  • Max Circle Range

    Enter the maximum diameter of the bolt hole to be searched.

    • Seat Parameters

  • Radius Factor

    Enter the radius factor for the bolt seating surface that creates the face.

    • Contact Parameters

  • Contact Type

       Select the type of contact to be set up.

    • Mating Face : General (Sliding contact)
    • Bolt Hole : Tied contact
    • Seat : General (Sliding contact)

      •
  • Activation

       Turn ON to activate the function

  • Touching Distance Range(ERROR)

       Distance below which a node is considered touching a body.

  • Friction Coefficient (FRIC)

       Friction Coefficient.

  • Interference Closure(CINTERF)

        Specify interference closure amount, normal to the contact surface (define for two faces in confact).

  • Delayed Slide Off(SLIDE)

       Delayed slide off distance. This entry should not be made unless ICOORD >= 2. When using the delayed slide off option, a node sliding on a segment will slide off this segment only if it passes the node or edge at a sharp corner over a distance larger than the delayed slide off distance.

  • Modify Coordinates（ICOORD)

       None: to ignore this option.

        Modify position: to modify the coordinates of a node in contact with a deformable body so that stress-free initial contact can be obtained.

       Delay sliding: to extend the tangential error tolerance at sharp corners of deformable bodies to delay sliding off a contacted segment.

       Both effect: to have both Modify position and Delay sliding active.

  • Type of Tied Contact(JGLUE)

       This option is only relevant if the glue option is invoked (JGLUE > 0).

       Choose 0 if a node should not separate.

       Choose 1 to invoke the standard separation behavior based on the maximum residual force.

       Choose 2 to activate breaking glue.

  • Penalty Factor(SFACT)

       Factor for increasing time steps due to number of iterations.

  • Penalty Factor(SFACT T)

       Penalty factor (stiffness) used for segment-to-segment contact analysis, the program will calculate the value but the user can change it to improve convergence.

  • Contact Damping(CDAMP)

       Contact Damping Coefficient.

  • Shell elemet face (Slave)

       Shell element face (Slave) has the following options:

        Top＆BtmThk. offset  : Both top and bottom faces will be in the contact description, thickness offset will be included.
        Btm w/ Thk. offset  : Only bottom faces will be in the contact description, thickness offset will be included.
        Btm w/o Thk. offset  : Only bottom faces will be in the contact description, shell thickness will be ignored.
        Top w/ Thk. offset : Only top faces will be in the contact description, thickness offset will be included.
        Top w/o Thk. offset :  Only top faces will be in the contact description, shell thickness will be ignored.
        Top&Btm w/o Thk. offset :  Both top and bottom faces will be in the contact description, shell thickness will be ignored.
  • Shell element face (Master)

       Shell element face (Master) has the following options:

        Top＆BtmThk. offset  : Both top and bottom faces will be in the contact description, thickness offset will be included.
        Btm w/ Thk. offset  : Only bottom faces will be in the contact description, thickness offset will be included.
        Btm w/o Thk. offset : Only bottom faces will be in the contact description, shell thickness will be ignored.
        Top w/ Thk. offset  : Only top faces will be in the contact description, thickness offset will be included.
        Top w/o Thk. offset : Only top faces will be in the contact description, shell thickness will be ignored.
        Top&Btm w/o Thk. offset  : Both top and bottom faces will be in the contact description, shell thickness will be ignored.

    If the bolt used has a pretension setting, the value can be changed. Currently only Sunshine is supported.

  • Shortcut Menu

    Right-click on the list to display a shortcut menu.

        Copy : Copy (Ctrl+c) the contents of the characteristic cell for each setting.
        Paste : Paste (Ctrl+v) the copied cell contents into another cell.
        Set as First : Change the bolt number 1 location to any location.
        Inverse Order : Reverses the bolt numbering sequence
        Sort Position : Specify the location of bolt number 1.
        Insert : If not found in the automatic search, add it to the list manually.※
        Delete : The selected item will be deleted.
        Clear All : All will be removed from the list.

  • ※How to add manually
    1. Select the curve edge to be set on the bolt head side.

    2. Select the face of the bolt shaft section. When setting the contact, it will be set to the face selected here.

    3. Add with "Insert". It will be added to the list.


    - Operating Procedure -

    1. In advance, place the solid bolt model (*.jth5) to be used in the[User Profile]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB
    2. Adjust the Bolt parameter and select the head side part and the shaft side part in the selection list, respectively.
    3. Change the seating surface and contact parameters if necessary.
    4. Click the Search button.
    5. Review the list within the search results and change the bolt type and pretension if necessary.
    6. Click the Apply or OK button.
