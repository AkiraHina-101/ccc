Group Window

This window is used to display/edit groups created by the Group command.
When the Group mode is turned ON, all entities other than the displayed group will be hidden.


Tree Control Menu

Control the tree display.

IconNameDescription
Clear Selection Clear all selections of the tree items.
Expand AllExpand all sub-trees.
Collapse AllCollapse all sub-trees.
Toggle SortSort the groups according to the name or ID.
Sort SettingLaunch the Group Sort Settings dialog.

Group Sort Setting Dialog

Change the order of the group tree.

  • Sort type

    Specify the sorting criteria by selecting the following statements.

    • By Group Name : Sort groups in ascending/descending alphabetical order of the name.
    • By Group ID : Sort groups in ascending/descending numerical order of the ID.
    • By Number of Nodes : Sort groups in ascending/descending order of the node number.
    • By Number of Elements : Sort groups in ascending/descending order of the element number.

    Tree View

    The group settings are displayed in a tree format. Each tree item can be highlighted by clicking it with the left mouse button. Double-click each tree item with the left mouse button in order to select all inside entities.

    ※ From V4.0, "Select Group" and "Deselect Selected Entity in Group" by double-click a group have been deleted, and only "Select Entity in Group" has been changed. Even if the deselection mode is ON, the entity is selected when using this function.

    Shortcut Menu

    Each command can be used from the menu displayed by right-clicking the tree item.

    ・Commands are available when no group is selected:
    CommandFunction
    Enable Group ViewEnable to display in group mode.
    Exit Group ViewReturn to display in normal mode.

    ・Commands are available when a subgroup item is selected:
    CommandFunction
    Select Entities Select the entities included in the highlighted group.
    Select Group Select the groups included in the highlighted group.
    Add Subgroup Add an empty subgroup under the group item.
    Copy Copy the highlighted group between documents.
    Create Material Group Create a group including entities associated with the same material.
    Create Property Group Create a group including entities associated with the same property.
    Create Hidden Entities Group Create a group including faces, elements and parts that are currently hidden.
    Create Entity Group Create a group for each entity.
    Create Group - Model Filter Create groups, filtering by element type and properties.
    Import Read the group information from a CSV format file that is exported in the Export menu.
    Export Export the contents of the highlighted group to a CSV format file.
    Paste Move the cut/copied group to the bottom of the highlighted subgroup.
    Delete Group Delete the highlighted group. Pressure, surface load, or contact condition applied on the selected groups are not deleted.
    Delete Entity Delete the highlighted group and all inside entities.

    ・Commands are available when a group item is selected:
    CommandFunction
    HideHide the highlighted groups.
    Hide Only Hide the highlighted group only and show all other groups.
    ShowShow the highlighted groups.
    Show Only Show the highlighted group only and hide all other groups.
    Show AllShow all groups.
    Hide AllHide all groups.
    Invert Hide/Show Reverse the display state of groups.
    Edit ※ Display a dialog for editing the highlighted group.
    Rename Change the name of the highlighted group.
    Associated Pick Select the entities associated with the highlighted group.
    Marker Change the color of the group marker to a random or specified color.
    ※The shortcut key [F3] is set to [Edit].

    ・Commands are available when multiple group items of the same type are selected:
    CommandFunction
    Boolean + Create a new group by combining all inside entities the highlighted group into a group.
    Boolean - Create a new group by subtracting overlapping entities in the second selection from entities in the first selection.
    Boolean x Create a new group from the common entities of the highlighted group.
