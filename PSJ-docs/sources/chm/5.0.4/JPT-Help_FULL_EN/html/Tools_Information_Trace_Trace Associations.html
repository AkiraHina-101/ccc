Trace | Association

Find all elements and connections associated with a node and display them. You can check the connected elements and connection.

Trace Part

  • Increase Layer

    •    The entities associated with the node of the selected entity are displayed.

  • Decrease Layer

    •    Reduce the display of currently displayed entities.

    Reset

  • Reset

       Reset the current display to the normal display.


    • - Operating Procedure -

    1.  Select an entity in the Selection list.
    2.  From the increase button or the apply button, the entity related to the selected entity and the node of that entity is displayed.
    3.  From the increase button or the apply button, the entity currently displayed and the entity related to the node of that entity are displayed.
    4.  Layers are displayed from the increase button or the decrease button.
    5.  Return to the normal display from the reset button.
