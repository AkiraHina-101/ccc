Clay Work

It is a function to make a simple design change for solid mesh parts.
Specifically, small spheres are stacked and the wrapped shape is piled up or scraped into parts by solid remesh. After executing this function, you can re-analyze as it is.


Ex) Considering to add ribs next to bolt holes.

  1. Sphere arrangement
  2. Solid mesh shape added (Remesh only arround new shape)

The remeshed elements and nodes are grouped by the name "ClayWork".


Selection list：Process = Spheres

Face Point : Select the center position of the sphere at the face arbitrary point.
Edge Point : Select the center position of the sphere at the edge arbitrary point.
Node : Select the center position of the sphere at the node.

Selection list：Process = Boolean + / Boolean -

Part : A part to fill or scrape the wrapping shape.

Operation

  • Process Select the operation to perform.
    • Spheres

      Create spheres.

    • Boolean +

      Wrap the sphere and add its shape on the selected part.

    • Boolean -

      Wrap the sphere and scrape its shape from the selected part.

    • Spheres Parameter

  • Radius The radius parameter of the sphere. You can change it during the preview.

    • Wrapping Method

  • Type Select method to wrap the sphere.
    • Tight

      Create a wrapping shape by enclosing the entire sphere.

    • Convex

      Enclose the entire sphere with the smallest convex shape to create a wrapping shape.


    • - Operating procedure -

    1. In Process, select Spheres.

    2. Select Face Point / Edge Point / Node to specify the center position of the sphere. A preview of the sphere is displayed.

    3. Change the radius as needed.

      • When wrapping with a tight sphae : Place spheres like they form the desired shape.

      • When wrapping with a convex shape : Place spheres at the convex position of the desired shape.

    4. Delete unnecessary spheres or add new spheres as needed.

    5. Click the Apply button. Sphere parts is created.

      • Sphere parts are added to the subassembly tree named "Temp_Sphere".

    6. In Process, select Boolean + / Boolean -.

    7. Select Type.

      • If you select Tight : Creates a wrapping shape that encloses the entire sphere.

      • If you select Convex : Enclose the entire sphere with the smallest convex shape to create a wrapping shape.

    8. Select a target part. A preview of the sphere's wrapping shape is displayed.

    9. Click the Apply / OK button.

      • If you select Boolean +: Wrap the sphere and add its shape on the selected part.

      • If you select Boolean-, wrap the sphere and scrape its shape from the selected part.

    - Notes -

    • The remesh size is the average mesh size of the selected parts around the sphere.

    • If the meshing error occurs with Boolean sum / difference (Boolean +/-), the following are possible.

      • The size of the stacked spheres is large relative to the selected parts.

      • The stacked spheres are small compared to the surrounding mesh size.

    • Tight: Applicable to any shape. The spheres should be placed tightly. The wrapping time when selecting parts is a little slow. The remesh time is equivalent.

    • Convex: Not applicable for curved or longitudinally curved arrangements. The arrangement of the sphere is only the convex part. The wrapping time when selecting parts is fast. The remesh time is equivalent.
