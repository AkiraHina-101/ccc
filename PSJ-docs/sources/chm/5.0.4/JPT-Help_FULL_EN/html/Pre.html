Pre Ribbon

Perform operations on Jupiter documents.

  • New

    • Create a new, empty document.

  • Open

    • Open a saved document (.jtdb file).

  • Add JTDB

    • Add a saved document (.jtdb file) to the current document.

  • Save

    • Save the current document as a .jtdb file.

  • Save As

    • Alias the current document and save it as a .jtdb file.

  • Close

    • Close the current document.
