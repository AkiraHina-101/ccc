Move Node | Along Cylinder

Move the nodes on the defined virtual cylinder.

Position

  • Direction

    • Select the cylindrical axis direction indication method.

       Normal: Normal direction of the defined circle

       2 Nodes: Direction by node specification

       X/Y/Z/-X/-Y/-Z：Axis direction of coordinate system

  • X/Y/Z

    •    Display the components of the direction vector.

  • Define Circle

    •    Move to operation of circle definition.

  • Circle Center X

    •    Enter the circle center x coordinate.

  • Circle Center Y

    •    Enter the circle center Y coordinate.

  • Circle Center Z

    •    Enter the circle center Z coordinate.

  • Radius

    •    Enter the cylinder radius.

  • Height

    •    Enter the cylinder height.


    - Operating Procedure -

    1.  Select the method for specifying the cylinder axis direction.
    2.  When 2 nodes are selected, select 2 Node button and select 2 nodes to define the direction.
    3.  Select the Define Circle button.
    4.  Select an edge that contains 3 nodes or 3 nodes that define a circle.
    5.  Change the center coordinates of the circle.
    6.  Change the height radius of the cylinder.
    7.  Press the Apply or OK button.
