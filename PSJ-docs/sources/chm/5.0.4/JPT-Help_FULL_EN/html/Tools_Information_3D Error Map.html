3D Error Map

Measure the surface error of two parts (target and reference).

In addition to the contour view, user can create nodal groups (3D Error Map) for each surface error.

The main applications to be the one of following:

  • Measure the surface error/difference between mesh and CAD. For example, if a fillet is lost due to meshing, the stiffness will change. This feature allows you to measure the surface error before analysis and correct it in advance.
  • Measure the surface error between the imaging data and the CAD/mesh. This function allows you to check the accuracy of reverse engineering results.

Selection List

Measure Part: Parts to be measured (Reference parts cannot be selected).
Criterion Part: Reference parts (Both ordinary parts and reference parts can be selected).

Measurement

  • Corner

    • Measure only the surface error of the corner nodes.

  • Corner + Mid

    • Measure the surface error of both corner nodes and middle nodes.

    Contour

  • Num. Digits

    • Specify the number of decimal places of the surface error to be displayed.

  • Num. Division

    • Specify the number of contour divisions.

  • Max/Min

    • Specify the maximum and minimum contour values.

  • Show/Hide(Update)

    • Switch between the display/non-display contour. This option is used to update the contour division number and the contour range.

    Group

  • Num. Digits

    • Specify the number of decimal of the surface error distance to create a group.

  • Max/Min

    • Specify the maximum and minimum value of the surface error to be created in a group.

  • Create Group(Update)

    • Create (or update) nodal groups in a dedicated group tree.

    - Operating Procedure (Error Calculation) -

    1. Select a Measure part.
    2. Select a Criterion part.
    3. Click Apply.
    4. The error of the surface nodes of the measurement part is calculated in memory.
    5. Show/Hide (Update) and Create Group (Update) buttons will be enabled.

    - Operating Procedure (Contour Display *Available after Surface Error Calculation) -

    1. Enter the parameters for the Contour.
    2. Click on Show/Hide (Update) button.
    3. The contour will be shown/hidden (updated).

    - Operating Procedure (Nodal Group Creation *Available after Surface Error Calculation) -

    1. Enter the parameters for the Group.
    2. Click Create Group (Update) button.
    3. The nodal groups for each surface error are created (or updated).

    - Special Notes -

    • If there is no reference mesh in the search range, "1.7976931348623158e+308" will be set as the error value.
