Planar Line

Create a line at the position where the specified plane crosses the selected face.

Option

  • Break Face

    •    When checked, break faces after imprinting.

  • Coordinate

    •    Select a coordinate system referenced in the coordinate plane.

  • Axis Plane

    •    Select a method to specify the plane to divide the face.

    • YZ : Select the YZ plane of the coordinate system specified by the coordinate system.
    • ZX : Select the ZX plane of the coordinate system specified by the coordinate system.。
    • XY : Select the XY plane of the coordinate system specified by the coordinate system.
      •
  • 3Points

    •    Define a plane from 3 points selected on the screen.


    - Operating Procedure -

    1.  Press the Face button, and select the Imprint target Face from the screen. There can be multiple selection of Face.
    2.  Turn off the face break check box, if necessary. In this case, the Face after Imprint is not split from the original Face.
    3.  Select the plane that divides the Face from Axis Plane. If you select 3 Point, select the Face Point, Edge Point or Node button and select the three points from the screen.
    4.  Select the coordinate system to reference from Coordinate.
    5.  Click Apply / OK button.
