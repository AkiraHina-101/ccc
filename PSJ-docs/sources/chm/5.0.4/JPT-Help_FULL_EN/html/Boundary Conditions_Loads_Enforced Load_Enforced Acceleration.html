    • - Operating Procedure -

      　　　
    1.  Select the face, edge, node on which force acceleration load will be applied. You can have multiple selections.
      2. 　　　
    2.  In accordance with the load direction, input the load value of X, Y, Z, translational and rotational value respectively.
      3. 　　　
    3.  Select and enter the other parameters as required.
      4. 　　　
    4.  Click the Apply or OK button.
