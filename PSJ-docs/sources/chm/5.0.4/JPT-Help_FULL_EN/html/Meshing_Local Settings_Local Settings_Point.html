Point

When you create Surface mesh, to ensure node creation at a specified location, specify setting for fixed node position (Hard Point).

Mesh Parameters

  • Name

    Set the mesh control name.

    Mesh Size

  • Mesh Size

    Set element size around fixed node position (hard point).

  • Average

    Set the average size of the element.

  • Minumum(<=0.7*Average)

    Set the minimum size of the element.

  • Maximum(>=1.4*Average)

    Set the maximum size of the element.

    • Hard Points

    Specify the coordinate values and the node ID after meshing of the node.

    • Load CSV

      Load the CSV file in the table. The format of the CSV file is X,Y,Z.

    • Add

      Add a row to the table.

    • Delete

      Delete the selected row.

    • Preview

      Display a preview of the set position of the Hard Point.

    • Reset

      Reset the preview for set position of the Hard Point.

      • - Operating Procedure (Main view specified) -

      1.  Specify the nodes creation position in the Face Point / Edge Point selection.
      2.  Click Apply / OK button.

      - Operating Procedure (CSV file specified) -

      1.  Specify the CSV file in the dialog box that appears when you click the Load CSV button, read the contents of the CSV file into a table by the "open".
      2.  Select the Face or Part to create the Hard Point.
      3.  Click the Preview button, check the position for Hard Point creation.
      4.  Click Apply / OK button.
