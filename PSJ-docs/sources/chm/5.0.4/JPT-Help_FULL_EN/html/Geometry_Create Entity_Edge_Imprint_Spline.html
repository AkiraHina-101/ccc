Spline

Select three or more points to create a spline curve-shaped edge that passes through those points.

Option

  • Break Face

    At the time of edge creation, in the case face break is possible, break the face.

    • - Operating Procedure -

    1.  Select three or more points.
    2.  A preview will be displayed, so make sure there are no problems with imprinting. If necessary, you can delete selected entities in the selection list dialog.
    3.  Click Apply / OK button.
    4.  Create a spline curve-shaped edge through the specified point.
