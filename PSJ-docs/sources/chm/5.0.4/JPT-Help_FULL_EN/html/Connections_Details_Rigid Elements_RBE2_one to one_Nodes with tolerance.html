Connection | RBE2 - One to one (Nodes with tolerance)

This command is used to create one to one (master/slave) RBE2s (rigid body elements).

Rigid body elements are automatically defined between nodes selected within the specified range.
Nodes with younger IDs are defined as master nodes.

Connection

  • Name

    Specify the name for registration.

    • Method

  • Nodes tolerance

    Specify the search range of the connection point.

    • Reference Dofs

  • UX - RZ

    Specify the components of the slave DOFs.

    • Analysis Coordinate Frame

  • Coordinate

    Specify the reference coordinate system.

    • Abaqus

  • Surface Definition Output

    Specify the surface definition method.

    • By Node Set

      Specify nodes as the reference plane.

    • By Element Set

      Specify elements as the reference plane. An error message will appear if the entity (node, edge) selected as the slave cannot configure an element.

    • - Operating Procedure -

    1.  Specify the distance tolerance between nodes.
    2.  Select multiple nodes from the Main window.
    3.  Define parameters.
    4.  Click the Apply/OK button.
