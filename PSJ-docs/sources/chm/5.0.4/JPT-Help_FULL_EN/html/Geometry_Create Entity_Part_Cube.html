Cube

Create a cuboid.

Part Properties

  • Part Name

    Enter the name of the cuboid to be created.

    • Cube

  • Local Coordinates

    Select any of the coordinate system.

  • Origin-X,Y,Z

    Specify the origin coordinates.

  • Length in X,Y,Z

    Enter each length of the X, Y, Z-axis direction.

  • Number of Nodes in X,Y,Z

    Enter each number of nodes in the X, Y, Z-axis direction.

    • - Operating Procedure -

    1.  Enter the part name in the Parts Name.
    2.  Specify the origin coordinates in Origin-X, Y, Z.
    3.  Enter the length of the each axis direction in Length X, Y, Z.
    4.  Enter the number of nodes in each axis direction of the X, Y, Z in Number of Nodes.
    5.  Click Apply / OK button.
