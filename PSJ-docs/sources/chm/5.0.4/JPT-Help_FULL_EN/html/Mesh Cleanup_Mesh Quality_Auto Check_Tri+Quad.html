Mesh Quality - Auto Check [Tri+Quad]

The surface mesh (Tri3 / Tri6 / Quad4 / Quad8) of the surface is corrected by multiple quality criteria.

Quality Standard

  • Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value.
  • Aspect Ratio: If checked, detect and display elements with aspect ratio greater than or equal to the specified value.
  • Edge Length: If checked, detect and display elements with edge lengths less than the specified value.
  • Area: If checked, the element of the area below the specified value will be detected and displayed.
  • Node Valence: If checked, elements with more than the specified node valence will be detected and displayed.
  • Interior Angle: If checked, detect and display elements with angles less than the specified value.
  • Duplicate Elements: If checked, duplicates will be detected and displayed.
    • ※Please refer to ＜definition of quality check method＞ for each item.

    Display

  • Number of Tri / Quad Elements: Display the number of displayed Tri / Quad elements.

    • Auto Cleanup

  • Cleanup: You can fix elements automatically by pressing the Clean Up button.
  • Mode: select the cleanup mode from Standard or Aggressive.
    • Cleanup processStandardAggressive
    Allowable face normal angle change of neighboring elements60 degree90 degree
    Collapse elem edges on an edgeNoYes
  • Non-manifold: Check to fix non-manifold.

    • Refresh

  • Show Model: Press the Show Model button to restore the model display.

    • - Operating Procedure -

    1.  Select the body you want to check the element shape.
    2.  Check the check box of the quality standard you want to check.
    3.  Press the Apply or OK button.
    4.  If you want to restore the model view, press Show Model.

      5. ※The automatic cleanup feature can not automatically fix all elements. If there are elements that can not be fixed automatically, you need to manually fix the elements using the manual cleanup function.
