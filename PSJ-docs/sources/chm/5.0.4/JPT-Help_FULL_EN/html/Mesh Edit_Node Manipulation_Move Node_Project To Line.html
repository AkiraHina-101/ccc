Move Node | Project to Line

Move any target node on the straight line defined by the two reference nodes by the shortest distance.
It is also possible to select target nodes by searching from reference nodes.


Align Node

  • On Shortest Pass

       Find the shortest path node between two reference nodes and select it as the target node.

  • On the Direction the Reference Nodes

       Find the shortest path node in the direction defined by the two reference nodes and select it as the target node.

  • On Selected Entity

       Find a node on the selected entity and select it as the target node.


    • - Operation Procedure (When moving the shortest path node between reference nodes) -

    1.  Select 2 nodes to define a straight line to project.
    2.  Select "On Shortest Pass" from the search method of the target node.
    3.  Click the "Search" button. The shortest path node between reference nodes is selected.
    4.  Click the Apply / OK button.

    - Operation Procedure (When moving the shortest path node between reference nodes in the direction of reference node) -

    1.  Select 2 nodes to define the line and direction to project.
    2.  From the search method of the target node, select "On the Direction the Reference Nodes".
    3.  Click the "Search" button. The shortest path node is selected in the direction between the reference nodes.
    4.  Click the Apply / OK button.
    ※If an unintended node is selected here, please select another reference node additionally. Project the target node onto the plane defined by the 3 reference nodes.

    - Operation Procedure (When moving all nodes on the selected entity) -

    1.  Select 2 nodes to define the line and direction to project.
    2.  Select "On Selected Entity" from the search method of the target node.
    3.  Select the entity you want to move the node, such as edge or face.
    4.  Click the "Search" button. All nodes on the selected entity are selected.
    5.  Click the Apply / OK button.

    - Operation Procedure (When moving any node) -

    1.  Click "Reference Nodes" in the selection list and select 2 nodes to define a straight line to project.
    2.  Click "Object Node" in the selection list and select the node or floating node to move. (You can select more than one)
    3.  Click the Apply / OK button.
