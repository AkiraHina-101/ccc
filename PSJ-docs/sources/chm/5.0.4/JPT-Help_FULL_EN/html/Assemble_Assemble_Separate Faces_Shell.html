Separate Faces | Shell

Separate the node that is shared between the shell parts into double nodes.

Separate Face

　　
  • Picked Type

    Specify the type of entity to select.

      　　
    • Model

      Separate all of the shared nodes that are in the model into double nodes.

      　　
    • Parts

      Separate the share nodes that are included between the selected parts to double nodes.

      　　
    • Edge

      Divide the shared nodes on the selected edge to double nodes.
      (When the adjacent edge of the selected edge has a shared node, the shared node of the selected edge is not a double node)

    　　　

    • - Operating Procedure -

      　　　
    1.  Select the desired entity: model, part or edge.
      2. 　　　
    2.  Click Apply/OK button.
