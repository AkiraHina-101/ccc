  • Distance

  • Minimum

    After selecting a node, press the Minimum button to select the shortest element edge connected to the selected node.

  • Next>

    While selecting node and element edges, pressing the 「Next>」button switches the selection to the next shorter edge of the selected element edge.

  • If the number of divisions in the elements that are adjacent do not match, align the number of divisions to remove the element
    1.  Select the node you want to keep.
    2.  Select the edge of the elements which is in contact with the selected node.
    3.  Click the Apply button.
    4.  The node you have selected is combined with the other node of the selected element edge, by removing the elements in between.
