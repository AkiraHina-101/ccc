Rbar

Create a Rbar (Rigid beam element).

  • One to many

    This function is to create one to many (Master : Slave) Rbar (Rigid Beam Element).
    In this feature, only that case is supported in which all independent degrees of freedom are on one side of the node.

  • One to one

    This function is to create one to one (Master : Slave) Rbar (Rigid Beam Element).
    In this feature, only that case is supported in which all independent degrees of freedom are on one side of the node.
