Mesh Size for Auto Setting

Set the mesh size automatic specification when the surface meshing automatic check box is turned on.

  • Average

    • Specify the average mesh size, the maximum and minimum mesh sizes will be calculated automatically.

  • Minumum = Average *

    • Specify the minimum mesh size and calculate the maximum and average mesh size automatically. Enter the calculation parameters for the minimum mesh size in the right column.

  • Maximum = Average *

    • Specify the maximum mesh size and calculate the average and minimum mesh sizes automatically. Enter the calculation parameters for the maximum mesh size in the right column.
