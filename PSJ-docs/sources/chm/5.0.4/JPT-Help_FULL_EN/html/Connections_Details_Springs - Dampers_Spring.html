Spring

Create a scalar spring element.

  • One to one (same DoFs)

    This function is used to create a one-to-one scalar spring element.
    In this function, you can combine together multiple degrees of freedom (the degree of freedom of the 1st group node and the 2nd group node are similar).

  • One to one (different DoFs)

    This function is used to create a one-to-one scalar spring element.
    In this function, you can combine the different degrees of freedom in the 1st group node and the 2nd group node.
