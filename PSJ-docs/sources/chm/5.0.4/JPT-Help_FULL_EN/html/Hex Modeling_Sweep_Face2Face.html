Sweep - Face to Face

This command is used to automatically create a Hexa mesh for parts with two complex geometries with the same shape facing one another like a gear.

Sweep - Face to Face

Auto Delete Original Parts

  • Delete Original Part

    Select this checkbox in order to automatically delete the original part of two specified faces facing one another.

    • - Operating Procedure -

    1.  Specify one of the faces as the Source Face in the Selection List.
    2.  Specify the other face as the Target Face in the Selection List.
      ※The number of layers in the direction of extension is defined by the current number of meshes.
    3.  Select the Delete Original Part checkbox if the original part is not needed.
    4.  Click the Apply or OK button.
