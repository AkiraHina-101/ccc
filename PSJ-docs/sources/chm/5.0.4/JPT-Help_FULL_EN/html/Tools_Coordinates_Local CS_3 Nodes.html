Local CS [3 Nodes]

Select any three nodes from the screen to create a coordinate system.

　　

Coordinate

  • Type

       Choose the Type of the coordinate system.

    • Rectangular : Select the Cartesian coordinate system.
    • Cylindrical : Select the cylindrical coordinate system.
    • Spherical : Select a spherical coordinate system.

  • Order

       Specifies the meaning of the order in for the selection of the nodes.

    • O.Z.ZX Plane : Select in the order of Origin, a point on the Z-axis and a point on the ZX plane.
    • O,X,ZX Plane : Select in the order of Origin, a point on the X-axis and a point on the ZX plane.
    • O,Y,XY Plane : Select in the order of Origin, a point on the Y-axis and a point on the XY plane.
    • O,X,XY Plane : Select in the order of Origin, a point on the X-axis and a point on the XY plane.
    • O,Z,YZ Plane : Select in the order of Origin, a point on the Z-axis and a point on the YZ plane.
    • O,Y,YZ Plane : Select in the order of Origin, a point on the Y-axis and a point on the YZ plane.

  • Name

       Enter the name of the coordinate system to be created.

    • Refer Coordinate Frame

  • Coordinate

       Choose from the default for coordinate system which is referred by the coordinate system to be created.

    • Origin

  • X/Y/Z

       X / Y / Z coordinate value of the first selected node is displayed.

    • Point 2

  • X/Y/Z

       X / Y / Z coordinate value of the second selected node is displayed.

    • Point 3

  • X/Y/Z

       X / Y / Z coordinate value of the third selected node is displayed.


    • - Operating Procedure -

    1.  Select the type of coordinate system from the Type.
    2.  Select the meaning of the order in which you select the node.
    3.  Choose the three nodes. Coordinate values of the selected node will be displayed.
    4.  Press the apply or OK button.
