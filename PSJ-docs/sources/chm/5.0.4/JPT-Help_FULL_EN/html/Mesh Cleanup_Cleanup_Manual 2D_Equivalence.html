Equivalence

Combine the neighbouring nodes.

Equivalence

  • Distance

    Display the distance between two selected node.

  • Tolerance

    Set the tolerance within which the command is operable.

  • Merge Towards

    Choose the node towards which the other node will be merged. There are 3 options: First Node, Second Node and Mid-point.

  • Multiple Node

    Join the nodes for the case where the multiple selected nodes are within tolerance.

    • - Operating Procedure -

  • Equivalence 1 Pair of Nodes (Multiple Node is off)
    1.  Select the first node.
    2.  Select the second node.
    3.  Select one of the Merge Towards options: First Node, Second Node or Mid-point.
    4.  Click the Apply button.
    5.  One of the two nodes will be merged to the First node/Second Node/Mid-point that you selected.

  • Equivalence Many Pairs of Nodes (Multiple Node is on)
    1.  Select the first node of the first node pair.
    2.  Select the second node of the first node pair.
    3.  Go on selecting other node pairs.
    4.  Select one of the Merge Towards options: First Node, Second Node or Mid-point.
    5.  Click the Apply button.
    6.  One of the two nodes of each pair will be merged to the First node/Second Node/Mid-point that you selected.
