Preferences

Perform various settings of Jupiter-Pre.

List Menu

  • Mouse

    • Configure mouse operation settings on the main window.

  • Display

    • Configure various display settings on the main window.

  • Color

    • Set the color of the entity displayed on the main window.

  • Toolbar

    • Set the display position and display / non-display of the toolbar on the main window.

  • Background

    • Set the background color of the main window.

  • Unit

    • Set the unit system.

  • License

    • Set the license option ON / OFF.

  • Language

    • Set language display setting of GUI.

  • CAD Importing

    • Set parameters when reading CAD.

  • Path Setting

    • Set each folder path.

  • Numeric Display

    • Set the numerical display format in Jupiter-Pre.

  • Default Settings

    • Set other default values.

    Common Buttons

  • Import

    • Load the file in which setting items have been saved.

  • Export

    • Save setting items to a file.

  • OK

    • Apply changes and exit Preferences.

  • Cancel

    • Cancel your changes and exit Preferences.

  • Apply

    • Apply the change.
