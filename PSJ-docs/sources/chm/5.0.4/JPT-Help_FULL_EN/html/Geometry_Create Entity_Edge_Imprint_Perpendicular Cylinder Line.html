Perpendicular Cylinder Line

Create a perpendicular line to the selected cylinder Face.

Options

  • Method

    •    Select how to specify the Imprint Line.

    • Center Angle : Enter the angle at the cylindrical center of a perpendicular position. First selected Node will be the origin of the angle.
    • Arc length : Enter the distance on the circumference of a perpendicular position. First selected Node will be the base point of the distance.
      •

  • Length / Angle Offset

    •    Enter the center angle or distance on the circumference.

  • Opposite Side

    •    If you select the check box, it also creates Imprint line in opposite 180-degrees.

  • Break Face

    •    Split the Face.


    - Operating Procedure -

    1.  Press the Face button, select the cylindrical Face as the Imprint target from the screen.
    2.  Press the Node button, select the two nodes from the screen in order to determine the direction. The first Node will be the base point. Imprint line is created along the axial direction of the cylindrical surface.
    3.  Enter Offset amount at an angle or distance in the length / angle Offset.
    4.  Turn on the opposite side check boxes as needed. In this case, you even create an Imprint line in opposite 180-degrees.
    5.  Clear the face break check box, if necessary. In this case, the Face after Imprint is not split from the original Face.
    6.  Click Apply / OK button.
