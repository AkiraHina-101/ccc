Sweep | From Midplane

Create a hexa-mesh by sweeping the set thickness against the neutral plane part to which the shell property (specification of thickness) is assigned.

- Operating Procedure -

  1.  Assign 2D shell properties to the neutral plane part in advance and specify the thickness.




  2.  Select a part.


    3. ※Note: Multiple parts can be selected. All selected parts must have 2D shell properties assigned.
  3.  Click the "Apply" or "OK" button to generate the mesh.
