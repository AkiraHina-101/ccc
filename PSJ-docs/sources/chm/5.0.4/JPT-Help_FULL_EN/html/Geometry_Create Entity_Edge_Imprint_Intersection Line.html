Intersection Line

Create a Line at the intersection of two selected Faces.

Options

  • Break Face

    •    Split the Face.


    - Operating Procedure -

    1.  Press the Face button, select Imprint target from the screen at the intersection of two faces.
    2.  Turn off the break face check box, if necessary. In this case, the Face after Imprint is not split from the original Face.
    3.  Click Apply / OK button.
