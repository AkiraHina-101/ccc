1D Property Bar Dialog Box

    Set the name of the property.

    Enter the ID of the property.

    • BAR

    　　
  • Input Shape

    • 　　
  • Material

    Specify the material properties.

    　　　
    • 　　
  • Section

    Choose from existing elements characteristic list.

    　　　
    • 　　
  • Vector

    Enter the direction vector to determine the element coordinate system.

    • Cross Section Dialog Box

    To calculate the cross-section property values. Created value is registered in the Section pull-down menu.

    General

    Enter the general cross-section properties.

    Name
    Enter the name of the cross-section properties to be registered.

    Type
    Selected calculation type is displayed.

    Shape
    Select the general cross section to be applied. Dimensions variable name will be displayed to the right of the image and the size table, according to the selected shape.

    Tapered
    The cross-sectional size of left and right side of the selected beam will be different. It will be the two input to be specified in the size variable.

    Size Table
    Enter a value in the dimensions variable to be displayed.

    Elem Y-dimension Dir
    Select the Y-axis direction of the cross section.

    Local Unit
    Select the local coordinate system of the cross-section calculation.

    Library

    Use the cross-sectional shape library of Nastran.

    Name
    Enter the name of the cross-section properties to be registered.

    Type
    Selected calculation type is displayed.

    Shape
    Select the type of cross section library in Nastran. Dimensions variable name of Nastran will be displayed to the right of the image and the size table, according to the selected shape.

    Tapered
    The cross-sectional size of left and right side of the selected beam will be different. It will be the two input to be specified in the size variable.

    Size Table
    Enter a value in the dimensions variable to be displayed.

    Elem Y-dimension Dir
    Can not be selected.

    Local Unit
    Select the local coordinate system of the cross-section calculation.

    - Operating Procedure -

      　　　
    1.  Enter the name of the property in Name.
    2.  Enter the cross-sectional performance. There are three different ways.
    •  Enter directly into the input box, such as Area, Intertia.
    •  Selection Type pull-down menu to select the method of calculation of the cross-section performance from, and enter using a calculation dialog box from the Input Shape button.
    •  Select an existing cross-section performance from Section pull-down menu.
      3. Choose the material already registered, from the Material pull-down menu.
      4. Choose how to specify the direction vector from Orientation By pull-down menu.
      5. Enter the direction vector in the Vector.
      6. Pin flag settings, offset vector, and set the local unit system as needed.
