Renumber | By Selection | Position

Renumber the ID of the selected entity according to the coordinate values.

  • Entity Type
    • Nodes

      Renumber nodes in the selected entity.

    • １D Elements

      Renumber 1D elements in the selected entity.

    • 2D Elements

      Renumber 2D elements in the selected entity.

    • 3D Elements

      Renumber 3D elements in the selected entity.

    • Parts

      Renumber selected parts.

    • Coordinate Systems

      Renumber the selected coordinate systems.

  • Start ID

    Set the renumber start ID.

  • Increment Step

    • Set the renumber increment value.

  • Sort Order
    • Ascending

      Renumber in ascending order.

    • Descending

      Renumber in descending order.

    Position

  • Coordinate

    Select a coordinate system. Options: Global Coordinate System / Arbitrary Local Coordinate System / Cylindrical Surface

  • LCS setting (only when cylindrical surface is selected in the coordinate system)

    Create a temporary coordinate system from selected nodes and cylindrical surfaces.

  • Save created LCS (only when selecting cylindrical surface in coordinate system)

    If checked, the temporary coordinate system will be left in the document after renumbering.

  • Sort Table
    • Sort Priority

      Grouping of target entities。

    • Sort

      Specify whether to enable or disable sorting in each axis direction. Uncheck to disable. Also, sort priority 1st and 3rd can not be enabled simultaneously.

    • Axis

      Specify the sorting target axis.

    • Sort Order

      ・ Sort order: Specify ascending / descending order.

    • Offset ID

      Specify the offset ID between grouped entities.

    • Tolerance

      This is the threshold (distance) for grouping.

  • Preview

    By clicking the preview button, the IDs before and after the target number of the renumbered entity are displayed.

  • Apply

    Perform renumbering.

  • Cancel

    Close the dialog without executing renumbering.

    • - Operation Procedure (Global Coordinate System / Local Coordinate System) -

    1.  Specify the entity that you want to renumber from the choice of entity type.
    2.  Specify start ID and increment value.
    3.  From the coordinate system, select a global coordinate system or a created local coordinate system.
    4.  Specify each item of sort setting table.
    5.  Select an entity in the main window.
    6.  Click the preview button to check the IDs before and after the renumber.
    7.  Press the Apply button to execute the renumbering.

    - Operation Procedure (Cylindrical Surface) -

    1.  Specify the entity that you want to renumber from the choice of entity type.
    2.  Specify start ID, increment value, and sort order.
    3.  Select a cylindrical surface from the coordinate system.
    4.  Select 3 nodes in order. First point: start position, second point: Z direction, third point: circumferential direction (+).
    5.  Select the cylindrical surface and click the LCS setup button. A preview of the coordinate system is displayed.
    6.  Select an entity in the main window.
    7.  Click the preview button to check the IDs before and after the renumber.
    8.  Press the Apply button to execute the renumbering.
