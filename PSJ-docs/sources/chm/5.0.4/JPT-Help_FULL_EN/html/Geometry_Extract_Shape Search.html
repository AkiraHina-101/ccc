Shape Search

Search and select the edges and faces of a specific shape from the selected parts.


Selection List

  • Part :  Display the parts used to search for a specific shape
  • Face :  Display the searched faces
  • Edge :  Display edge to search for concentric circle and the searched edges
    •

Edge

Search and select edges corresponding to the selected shape types in the selected parts.

  • Arc

    Search and select the arc edge. This method supports searching not only for semi-circular arcs but also arcs created by an edge.

    • All : Search and select all arc edges in the selected parts.
    • Minimum radius : Enter the minimum radius of the arc edge to search and select it in the selected parts.
    • Maximum radius : Enter the maximum radius of the arc edge to search and select it in the selected parts.
      • The Max/Min radius will be used to search the target edges when option All is checked off.


  • Circle/Concentric

    Search and select circular edges. This method supports searching not only for circles created by multiple edges but also by a single edge.
    In addition, when this option is selected, the concentric circles are searched and selected base on the selected target circle.

    • All : Search and select all circular/concentric circular edges in the selected parts.
    • Minimum radius : Enter the minimum radius of the circular/concentric circular edge to search and select it in the selected parts.
    • Maximum radius : Enter the maximum radius of the circular/concentric circular edge to search and select it in the selected parts.
      • The Max/Min radius will be used to search the target edges when option All is checked off.

  • Tiny Face

    • Create Group

    Create a group for the searched faces and edges.

    • Non : Do not create group.
    • All One : Create a group containing all searched results (faces, edges) of all specified shape types for searching in the selected parts.
    • One By One : Create separate groups containing the searched results (faces, edges) corresponding to each specified shape type for searching in the selected parts.
      •
  • Group name

    Enter the name of the group to be created.

    In the Group creation:
    • If the option All One is selected and the group name is blank, a group called "FindFeature_Group_number" will be created.
    • If a string (group name) is entered into the group name when the option All One is selected, a group will be created using that name.
    • If the option One by One is selected and the group name is blank, a group called "(Edge / Face)_(searched shape name)_number" will be created.
    • If a string (group name) is entered into the group name when the option One by One is selected, a group with name "Entered name + (Edge/Face)_(searched shape name)" will be created.
      •

    • - Operation Procedure (General) -

    1. Check the option of shape type you want to search for.
    2. Check "All" option or enter required values.
    3. Change group creation options if needed.
    4. Select target part (support to select multiple parts).
    5. Click the Apply/OK button.

    - Operation Procedure (Concentric circle) -

    1. Check the "Circle/concentric" option.
    2. Check "All" option or enter required values.
    3. Change group creation options if needed.
    4. Select target part (support to select multiple parts).
    5. Select a circle (or many circles) to be the target circle (The searched circles will be concentric with this target circle).
      You can select circles created by a single edge or multiple edges as long as they create a closed circle.
    6. Click the Apply/OK button.
