Mesh Quality - Manual Check [Tri+Quad] Time Step (LS-Dyna)

Perform element quality check and automatic correction of surface mesh (Tri3 / Tri6, Quad4 / Quad8).

Element Quality

  • Metric　： Specify the type of element quality to check.
    • ※In Time Step (LS-Dyna), check the timestep (⊿tc) in LS-DYNA by the following formula.
    　lc(Element representative length) = A/MAX(L1,L2,L3,L4) In the case of Quad
    　lc(Element representative length) = A/MAX(L1,L2,L3) In the case of Tri
    　c(Stress propagation speed) = (E/(ρ(1-ν^2)))^1/2
    　⊿tc＝lc/c
    ※The calculation is performed for each material property value set for each element. Therefore, it is a condition that 2D material property is set.

    Cutoff Value Tri

  • Minimum　： The minimum value of element quality is displayed.
  • Maximum　： The maximum value of element quality is displayed.
  • Average　： The average value of element quality is displayed.
  • Num of Entities　： Indicate the number of Tri elements of the selected entity.

    • Cutoff Value Quad

  • Minimum　： The minimum value of element quality is displayed.
  • Maximum　： The maximum value of element quality is displayed.
  • Average　： The average value of element quality is displayed.
  • Num of Entities　： Display the number of Quad elements of the selected entity.

    • Display Tri

  • Condition　： Set the inequality sign for the following threshold.
  • Value　： Enter a threshold value that causes element quality to be insufficient.
  • Num of Entities　： The number of elements displayed as element quality shortage is displayed.

    • Display Quad

  • Condition　： Set the inequality sign for the following threshold.
  • Value　： Enter the threshold for the element quality deficiency.
  • Num of Entities　： Display the number of elements displayed as element quality shortage.

    • Stress Propagation Speed

  • Material　： By selecting the material, you can check the stress development rate and physical properties.

    • Auto Cleanup

  • Cleanup　： You can automatically correct elements by clicking the Cleanup button.

    • Refresh

  • Show Model　： Click the Show Model button to restore the model display.

    • - Operating Procedure -

    1.  Specify the element quality check method in Time Step (LS-Dyna).
    2.  Select the target entity.
    3.  Enter the threshold for the element quality deficiency.
    4.  Click the Apply button.
    5.  The confirmation result of element quality is displayed in the command. The main window also switches to element quality check mode
    6.  Click the Cleanup button if you want to make an automatic correction.
    7.  Click the Show Model button to restore the model display.

      8. ※The Cleanup feature can not automatically fix all elements. If there is an element that can not be automatically corrected, you need to manually correct the element using the Manual Cleanup function.
