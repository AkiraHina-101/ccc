Elements

By setting the elements and boundary to start the search (elements and angle), select collective elements within the specified boundary.
By using this feature, you can perform easy removal of the elements of mold parts and extraction of the water jacket of engine parts.

Search

  • Number of Layers

    Enter the number of layers to be a search range.

    • Stop

  • Include Stop Elements

    When you check, you can also select the boundary elements.

  • Stop Angle up to

    Enter the angle as a boundary.

    • Preview

  • Preview

    You can see the elements which are selected. Those elements will be shown in the Main Windows with the colour you've selected.

  • Reset

    Reset the elements identified in Preview button.

    • - Operating Procedure -

    1.  Select the Start Elem. (You can select more than one element at distant location)
    2.  Select the Stop Elem. (If you only specify a boundary angle, you do not need to select stop element)
    3.  Set the search range.
    4.  Set the boundary.
    5.  Check the selection in the Preview / Reset.
    6.  Click Apply / OK button.
    7.  By making the Group of the extracted elements, it is easier to carry out any modification if you find any errors.
