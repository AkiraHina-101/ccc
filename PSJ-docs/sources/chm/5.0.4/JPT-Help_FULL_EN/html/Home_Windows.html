Window

Switch the display of each window.

  • Window Display Check Box

    • Switch display / hide of each window.

    • Assembly

      • Show / hide the assembly window.

    • Output

      • Toggle the display of the output window.

    • Group

      • Toggle the display of group windows.

    • Status Bar

      • Toggle the display of the Status Bar.

    • Macro

      • Switch the macro window on / off.

    • Python Output

      • Toggle the display of the Python output window.

    • History

      • Toggle the display of the history window.

    • Watch Selected

      • Toggle the display of the watch window.

    • View Point

      • Toggle the display of the viewpoint window.

    • Reference

      • Toggle the display of the reference window.

    • Data

      • Toggle the display of the data window.

    • Recent

      • Toggle the display of recently used function windows.

    • Advanced Search

      • Toggle the display of the advanced search window.

    • View Selection Toolbar

      • Toggle the display of the selection toolbar window.
  • View Control

    • Control the current view by numerical input.

  • Fullscreen

    • Make the currently opened document full screen. To cancel the full screen display, press the Esc key or click the "Close Full Screen" button displayed when the Full Screen is displayed.

  • Synchronize

    • Synchronize the view state when multiple documents are opened.

  • Windows

    • Change the order of documents on the main window when multiple documents are open.

    Using Ctrl+Shift+Arrow Left/Right to move target window to desired position.

    • Tile Horizontal

      • Arrange horizontally and display.

    • Tile Vertical

      • Arrange vertically and display.

    • Tile Box

      • Display side by side.

    • Cancel

      • Cancel the set document order.

    • Windows...

      • Specify how multiple documents will be displayed.
      You can select multiple documents by Ctrl + click.
