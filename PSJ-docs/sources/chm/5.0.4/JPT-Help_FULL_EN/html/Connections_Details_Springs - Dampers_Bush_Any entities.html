Connection | Bush - Any Entities

Create a Bush element (generalized spring - damper) from the node pair included between the selected entity pair.

Connections

　　
  • Name

    • Set the name of bush element to be created.

    　 　　
  • All

    • Check for the case in which all the nodes of the selected entity are to be targeted. If unchecked you can enter the Tolerance for the connection range below, the nodes within the range will be connected.

    　　
  • Tolerance

    • Enter the connection range value.

    　　
  • 1:1

    • Limit a bond for bush element only to one-to-one connection.

    Bush

    　　
  • Grounded

    • When you check this box, one side is defined as the ground (spring).

    　　
  • Orientation by

    • Select the orientation method of the bush element.

      　　
    • Orientation Vector
      • Specified by the direction vector 　　
    • Coordinate system
      • Specified by the coordinate system
    　　
  • Coordinate System

    • If you select specified by the coordinate system, select an existing coordinate system you want to use from the list.

    　　
  • Orientation Vector

    • If you select specified by the direction vector, enter a comma-separated direction vector in the order of X, Y, Z.

    　　
  • Stiffness 1～6

    • Enter stiffness value for each degree of freedom.

    　　
  • Local Unit

    • Select the unit system to be used in the stiffness value input.

    　　
  • Damping coefficients 1～6

    • Enter the damping coefficient for each degree of freedom.

    　　
  • Local Unit

    • Select the unit system to be used in the damping coefficient input.

    　　
  • Damping constant 1～6

    • Enter structural damping constant for each degree of freedom.

    　　
  • Local Unit

    • Select the unit system to be used in the structural damping constant input.

    　　
  • Stress recovery translation

    • Enter the stress recovery coefficient of the translation component.

    　　
  • Stress recovery rotation

    • Enter the stress recovery coefficient of the rotation component.

    　　
  • Strain recovery translation

    • Enter the strain recovery factor of the translation component.

    　　
  • Strain recovery rotation

    • Enter the strain recovery coefficient of the rotation component.

    - Operating Procedure -

      　　　
    1.  Click the Master button of Selection List to selects the body, face, edge and node, where the node of one end of the bush element is included.
      2. 　　　
    2.  Click the Slave button of Selection List to selects the body, face, edge and node, where the node of other end of the bush element is included.
      3. 　　　
    3.  If you specify a range for connection, remove the All check box and enter the range value for Tolerance.
      4. 　　　
    4.  Rather than the default for 1-to-1 binding, when you define a bond only in the shortest distance, 1: 1 check box is turned off.
      5. 　　　
    5.  Choose how to specify the direction vector from Orientation By. Enter the direction vector according to the specified method.
      6. 　　　
    6.  Enter the values such as stiffness value, damping coefficient, structural damping constant, recovery factor in the input field.
      7. 　　　
    7.  Click the Apply or OK button to create the bush element between the nodes.
