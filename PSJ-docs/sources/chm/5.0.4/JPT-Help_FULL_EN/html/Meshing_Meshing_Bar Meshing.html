Bar Meshing

Change the number of divisions of the beam element.

Options

  • Mesh Size

       Specify the size of the beam element.

  • Num of Element

       Specify the number of divisions of the beam element.

    • - Operating Procedure -

    1.  Specify the method of dividing the beam elements.
    2.  Enter the mesh size or the number of divisions.
    3.  Select the bar or edge.
    4.  Click Apply / OK button.
