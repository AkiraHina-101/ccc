Contacts | TS Solver - Auto Find Contact

Automatically searches for contact conditions between parts in an assembly model and adds contact conditions.



Contact

  • Method

       Automatic search only.

  • Tolerance

       Enter the tolerance value for detecting contact between two adjacent faces.

  • Master basis

        Select the method for determining which face of the detected face pair will be the master face for defining contact conditions.

    • Mesh size : Calculation is performed based on mesh size.
                           The comparison is made with the average length of the element edges within the detected face pair.
                          The face with the longer average length is selected as the master face.
    • Area          : Calculation is performed based on area (per face)
      •
  • Find Contact

       Press the button to start the searching for the contact.

  • Search Area

       Specify the range of contact pairs and candidate faces. When minimized, only faces found with search tolerance will be displayed as potential contact pairs. When maximized, it will display as a contact pair candidate up to the face that smoothly connects with the searched face.

    　　
  • Cylinder Priority

       When checked, the contact of the cylindrical surface is preferentially searched.

  • Interference Closure

       Specify the distance for the solver to determine contact between two faces.

  • Input Unit

       Specify the unit for specifying tolerance and interference closure.

  • Search

       Enter the part name of face ID in the text box on the left side of the dialog in order to narrow down the contact search result.

  • Clear

       Cancel the refined search result display.

  • Contact DB

       Display a list of existing contact conditions when the command is launched.
       A list of face pairs in contact found by the Find Contact button is also displayed.

    • No.                 :  The face pairs are numbered according to the order of detection.
                                A checkbox is displayed in front of the ID number, and contact settings are defined only for the selected face pairs.
    • Master key    :  Display the Face ID (or part name) detected on the master side.
    • Slave key       :  Display the Face ID (or part name) detected on the slave side.
    • Contact Type :  Display the contact setting type (Glue or General). By default, the Glue type is selected.
      •
  • Select All

       Deselect all checkboxes and highlights all lines.

  • Switch Master/Slave

       Switch the master and slave faces displayed in each line. This operation is performed only for highlighted lines.

  • Switch Glue/General

       Switch the Glue and General contact types displayed in each line. This operation is performed only for highlighted lines.


    • - Operating Procedure -  When creating a new contact condition 

    1.  Press the Part button and select all target parts for contact setting from the screen.
    2.  Change the tolerance value from the default setting as necessary.
    3.  Switch the search algorithm of the master side face as necessary.
    4.  Change the Interference Closure value from the default setting as necessary.
    5.  Switch the local unit for defining the tolerance, interference closure value as necessary.
    6.  Press the ⌈Find Contact⌋ button. A list of detected face pairs is also displayed.
    7.  Select each line in the list to display the faces on the screen. Faces of the master side are displayed in red, and faces of the slave side in blue.
    8.  Deselect the checkboxes of the faces that do not require contact settings.
    9.  Select the checkboxes of the faces that require switching and click the ⌈Switch Master/Slave⌋ button to switch the master/slave faces.
    10.  Select the checkboxes of the faces that require switching and click the ⌈Switch Glue/General ⌋ button to switch the glue/general contact types.
    11.  Select the checkboxes of the lines to create and click the Apply or OK button.

    - Operating Procedure -  When a contact condition exists (can be used for confirmation purpose) 

    1.  Hide all contacts from the assembly tree.
    2.  Launch the command to display a list of all existing contact conditions.
    3.  Select each line in the list to display the faces on the screen.
          Faces of the master side are displayed in red, and faces of the slave side in blue.
    4.  After confirming, click the Apply or OK button to close the dialog.
