Add BOSS | By Plug

This command is used to create a BOSS geometry (cylinder shape) from an upper part and attach it to selected part.

Option

  • Merge

    When checked ON, new BOSS part will be merged with the selected part.

    Top Center

      Specify the position of the top face of the BOSS (on the upper part).
    • Set By

      Selected entity type to set top center:
      - Face
      - 3 Points
      - Edge
      - Node
      - Face Point
      - Edge Point

    • X

      X coordinate of top center.

    • Y

      Y coordinate of top center.

    • Z

      Z coordinate of top center.

    • Direction

    • X

      X coordinate of BOSS directional vector.

    • Y

      Y coordinate of BOSS directional vector.

    • Z

      Z coordinate of BOSS directional vector.

    • Coordinate System

      Specify Coordinate system for the BOSS directional vector.

    • Rotation Axis

      Specify the rotation axis on the coordinate system (X axis, Y axis, Z axis).

    • Angle

      Specify the rotation angle of the rotation axis.

    BOSS Shape

    • Hollow

      Select this checkbox to create the BOSS as a hollow geometry.

    • Inner Radius

      Enter the inner radius of the cylinder geometry (in case of a hollow geometry).

    • Outer Radius

      Enter the outer radius of the cylinder geometry.

    • Taper Angle (degree)

      Enter the taper angle from the top to bottom direction of the cylinder geometry.

    • No of Nodes in Circle

      Enter the number of nodes in in the arc direction of the cylinder.

    • No of Nodes in Axis

      Enter the number of nodes in in the axis direction of the cylinder.

    • Height

      Enter the height of the cylinder geometry.

    • Calculate Height

      Automatically sets the height of the BOSS


    - Operating Procedure -

    1.  Select either Face/3 Points/Edge/Node/Face Point/Edge Point from Set By and click the top face of the BOSS (in case 3Points was selected, click 3 points to define the face).
      The clicked positions will be automatically entered as the Top Center XYZ (center point of the BOSS).
    2.  Select a body for creating the BOSS. The Direction will be modified to the body direction.
    3.  Enter the Outer Radius of the BOSS and click the Calculate Height button. The preview geometry will be displayed.
    4.  Click the Apply button to generate the geometry.
