Capture

This function is used to capture screen shots of the Main window of the currently displayed document.

  • Copy to Clipboard

    • Copy the screen shot of the Main window to the clipboard.

  • To Image

    • Save the screen shot of the Main window as an image file.

  • Rectangular Capture

    • Save the specified range of the Main window as an image file.

    - Operating Procedure (Copy to Clipboard) -

    1.  Click the Copy to Clipboard button in order to copy the screen shot of the Main window to the clipboard.
    2.  Launch an image viewer or editing software and press the Ctrl+V key to paste the image.

    - Operating Procedure (To Image) -

    1.  Click the To Image button in order to open the File Save dialog.
    2.  Specify the file format and save the file in an arbitrary folder.

    - Operating Procedure (Rectangular Capture) -

    1.  Click the Rectangular Capture button and click/drag within the Main window. The rectangular area defined by the mouse is specified as the target range for capturing.
    2.  Launch an image viewer or editing software and press the Ctrl+V key to paste the image.
