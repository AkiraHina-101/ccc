Mouse

Mouse operation setting on the main window can be changed as per user preference. Different CAD / CAE software mouse settings can be used by selecting the existing presets. User can also create the new presets with different mouse buttons.

Presets

It is a mouse button setting list. Click the item in the list to select it.

  • New

    • Click on new to create a new mouse button setting(MyPreset #).

  • Delete

    • Click to delete the highlighted preset(Applicable only for newly created presets).

    Pointer speed

    Adjust the speed of rotation, translation, scaling.

    Mouse button mapping

    Details of the setting selected in the preset will be displayed. You can arbitrarily assign mouse buttons and keys to newly created presets.

  • Rotate View

    • Specify mouse button and key to perform rotate operation.

  • Pan View

    • Specify the mouse button and key to perform parallel translation operation.

  • Zoom View

    • Specify the mouse button and key for Zoom in/Zoom out operation.

  • Zoom in operation

    • Specify the mouse button and key for Zoom in/Zoom out operation.

  • Select entity

    • Specify mouse button and key to perform entity selection operation.

    - Operating procedure (Existing Presets) -

    1.  Activate the command,select the Preferred preset,adjust the pointer speed and click Apply or OK button.

    - Operation Procedure (New Presets) -

    1.  Activate the command and click the New button.
    2.  Click and highlight the MyPreset # (# is an integer), since it is newly created in the preset.
    3.  There are many arbitrary mouse button settings. Click on checkin boxes (mouse button mapping) to select the mouse operation as per user preference. Click again on the checkin box to unselect the option. User can also reset each item.
    4.  Click on Apply or OK button to save your changes.
