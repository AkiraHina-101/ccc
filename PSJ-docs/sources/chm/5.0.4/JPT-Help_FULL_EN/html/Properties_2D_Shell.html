Shell

2D Property Shell Dialog Box

Create a property data of the two-dimensional Shell element.

　　
  • Property ID

    Enter the ID of the property. Property ID is entered so as not to overlap in the model.

    　　　
    • 　　
  • Name

    Set the name of the property.

    　　　

    • Shell

    　　
  • Membrane Material

    Select the material for membrane behavior.

    　　　
    • 　　
  • Bending Material

    Select the material for bending behavior.

    　　　
    • 　　
  • Shear Material

    Select the material for lateral shear behavior.

    　　　
    • 　　
  • Coupling Material

    Select the material for coupled film-bending behavior.

    　　　
    • 　　
  • Thickness

    To enter the thickness of the element.

    　　　
    • 　　
  • Bending Stiffness

    Enter the ratio of the inertia to the bending.

    　　　
    • 　　
  • Thickness Ratio

    Enter the thickness ratio of the lateral shear stiffness.

    　　　
    • 　　
  • Non-structural Mass

    Enter the non-structural mass per unit area.

    　　　
    • 　　
  • Fiber Dist.1/2

    Enter the stress calculated distance from the reference plane.

    　　　
  • Material Orientation By

    Select the material axis definition method.

    • Angle: Specify the angle (degree).
    • Coordinate system: Specify in the coordinate system. The X axis of the coordinate system is projected to the element plane.

    　　　
    • 　　
  • Plate Offset

    Enter the offset value.

    　　　

    • Integration Points Storage

    　　
  • No.SHELL Integration Points

    Specify the integral number of shell elements.

    　　　

    • Element Related Information

  • Element related information

    The property information list of the selected element is displayed and can be edited.
    ※This function is used in edit mode.

    • Equivalent Radiated Power(Nastran)

  • ERP 　　

    Select the checkbox to enable the function. 　

  • Panel label name 　　

    Enter a name for the panel label. 　

  • Panel label ID 　　

    Enter the panel label ID.

    • Abaqus

    　　
  • Temperature variation

    Enter the temperature change value. (Natural numbers only)

    　　　

    • Input Unit

    　　
  • Length

    Select the unit of length.

    　　　
    • 　　
  • Mass

    Select the unit of mass.

    　　　

    • - Operating Procedure  -

      　　　
    1.  Enter the name of the property in Name.
      2. 　　　
    2.  Enter the property ID to the Property ID.
      3. 　　　
    3.  Select the already registered material from the Membrane Material pull-down menu.
      The same material as Membrane is set to Bending and Shear automatically,but you can also overwrite changes.
      4. 　　　
    4.  Enter the thickness in Thickness.
      5. 　　　
    5.  Enter other parameters as needed.
      6. 　　　
    6.  Click the Apply or OK button to create a property.
