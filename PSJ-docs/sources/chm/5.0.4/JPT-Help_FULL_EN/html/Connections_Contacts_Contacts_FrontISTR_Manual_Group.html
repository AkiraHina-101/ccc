Contacts | FrontISTR - Manual Group

Define the FrontISTR for contact set between the specified group.
Create a group with master and slave surfaces beforehand to define the contact in the contact settings.

Basic

　　　
  • Name

    Enter the name of the contact body.

    　　　
    • 　　　
  • Algorithm

    Select the contact setting target entity.
        Face to Face: Contact between the face to face.     Node to Face: Contact between the node to face.

    　　　
    • 　　　
  • Type

    Select the behaviour type of contact definition.
        General: Sliding contact.
    　　　

    • 　　　
  • Master

    Select the group that becomes the master surface.
        Search: Find the group in the definition name, and define as a master surface.

    　　　
    • 　　　
  • Slave

    Select the group to be a slave surface.
        Search: Find the group in the definition name, and define it as a slave surface.

    　　　
    • 　　　
  • Switch Group

    Switch the master / slave segment group.

    　　　

    • Contact Properties

    　　　
  • Contact Type

    Define contact type for contact FrontISTR, easily control for same contact type setting.

        ID: Input ID.
        Interaction: Select neccessary interaction method.
        Normal Direction Convergence (NTOL): Input normal direction convergence parameter.
        Tangential Direction Convergence (TTOL): Input tangential direction convergence parameter.
        Normal Direction Penalty (NPENALTY): Input normal direction penalty parameter.
        Tangential Direction Penalty (TPENALTY): Input tangential direction convergence parameter.

    List Contact Type Created: Shows all previously created contact types. Also right click to get features like Edit and Delete.
        Edit: Modify parameter of Contact Type.
        Delete: Delete Contact Type.

    　　　
    • 　　　
  • Friction Coefficient (FCOEF)

    Input friction coefficient.

    　　　
    • 　　　
  • Friction Penalty Stiffness (FACTOR)

    Input friction penalty stiffness.

    　　　
    • 　　　

    Others

  • Color Setting

    Contact Color
        Define the contact pair display marker color.
        Reset: Initialize to the default color.

    　　　

    • - Operating Procedure -

      　　　
    1.  Create a master face, slave face or element face group in advance.
      2. 　　　
    2.  Select the master group as the master face and the slave group as the slave face.
         The selected group is highlighted in the model window. It is also possible to confirm by turning off the group display mode.
      　　　
    3.  If necessary, define the detail settings for contact pairs, and click the OK button to define contact pairs.
