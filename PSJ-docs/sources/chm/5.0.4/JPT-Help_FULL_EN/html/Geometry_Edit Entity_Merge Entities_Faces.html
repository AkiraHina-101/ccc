Faces

Merge the adjacent face to a single face.

Merge Face

  • Merge Edges

    When you check, it merges the edge that are included with the face.

  • Remove Non-Boundary Edges

    Unchecked to keep edges that are not border edges in the face to be merged.

  • High Speed Processing

    If checked, speedup will be enabled. If unchecked, the processing time will be the same as previous version.
    This is especially effective when there are many faces.

    • - Operating Procedure -

    1.  Check if necessary.
    2.  Select the multiple of the face you want to merge.
    3.  Click Apply / OK button.
