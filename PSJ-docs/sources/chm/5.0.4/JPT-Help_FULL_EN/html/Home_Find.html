Find

This command is used to search for entities in the document.

  • Match checkbox

    • Search for entities that completely match the search string.

    - Operating Procedure -

    1.  Enter the target string/ID/coordinate value in the blank field.
      Strings should be inserted between double quotation marks ("").
      Multiple IDs should be separated by blanks. Ex: 1 2 3
      Coordinate values should be entered separated commas (x,y,z). Only one point can be used for searching coordinate values. Ex: 10,10,10
    2.  Select the search target entity from the combo box under then blank field.
    3.  Click the Find button. If the search succeeds, the target will be selected.
