Lab | Alignment | OOBB Alignmen

For each part, a bounding box that encloses it with as little margin as possible is defined. The function performs part movement by aligning these bounding boxes with each other.。

※Note
If the height, width, and depth of the bounding box are the same, it may fail to align correctly as the direction cannot be determined.

Alignment is performed in the following order:
  1. Create a local coordinate system for the bounding box at the center of each part.
  2. Move the preview of the moving part to align the central positions of the local coordinate systems.
  3. Move the central position according to the selected Fit position.
  4. Rotate around the central position according to the rotation input value.
  5. Perform parallel movement according to the input value for parallel movement.

Fit Position

  • Coordinate Value

    Specify the position that will be the reference for alignment.

    • Translation

  • X,Y,Z

    • Used when you want to move parallelly from the initial alignment position. Enter the step size for the movement amount in the text box on the right side of each axis and adjust the movement amount with the spin control.

    Rotation

  • X,Y,Z

    Used when you want to rotate from the initial alignment position. Enter the step size for the rotation amount in the text box on the right side of each axis and adjust the rotation amount with the spin control. The unit is degrees.

    OOBB Display Settings

  • Reference Frame

    Set the visibility, color, and line width of the frame enclosing the reference part.

  • Moving Frame

    Set the visibility, color, and line width of the frame enclosing the Moving Part.

    • - Operation Procedure -

    1. Launch the OOBB alignment function.
    2. Select the part that will be the destination for alignment. In the selection list, the choice will be entered in 'Target Part'. Also, the focus will automatically move to 'Moving Part'.
    3. Select the part to move. In the selection list, the choice will be entered in 'Target Part'.。
    4. The bounding box is displayed. Adjust the movement position with the fit position selection and parallel movement/rotation.。
    5. Apply or OK button will execute the function.
