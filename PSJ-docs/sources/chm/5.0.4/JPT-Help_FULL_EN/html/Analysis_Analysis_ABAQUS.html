Abaqus Export Setting Dialog

Abaqus Export Setting Dialog

　　　
  • Analysis type: Define the analysis type.

      Structure : Specify the structural analysis type.
      Thermal : Specify the thermal analysis type.

    　　　
    • 　　　
  • Abaqus Job: Define the job setting.

      Job name : Specify the job name.
      Job description : Specify the job description.
      Export Model Unit System : Specify the unit system for the analysis input data.

    　　　
    • 　　　
  • Job Manager : The following settings are defined by the Job Manager:

      Load Case : Display the load case.
      Load : Display the existing boundary constraint conditions.
      Load Filter : Specify the display filter of the boundary constraint condition type.
      Step Type : Specify the Abaqus step type.
        Structure
          Static General : Specify the static general analysis type.
          Natural Frequency : Specify the normal mode analysis type.
          Dynamic, Implicit : Specify the implicit dynamic analysis type.
          Dynamic, Explicit : Specify the explicit dynamic analysis type.
          Coupled Temp-Disp : Specify the implicit temperature-strucural coupled analysis type.
          Dynamic Temp-Displacement, Explicit : Specify the explicit temperature-strucural coupled analysis type.
          Static, Riks : Specify the static incremental arc-length method analysis type.
        Thermal
          Heat Transfer, Steady State : Specify the steady state heat transfer analysis type.
          Heat Transfer, Transient : Specify the transient heat transfer analysis type.
      Add Step: This button is used to add steps.

    　　　
    • 　　　
  • Export Settings: Define export settings for the model data.

      Separate File : Specify settings of the export model.
      Surface Definition : Specify the surface definition method.
      RBE2 to MPC Type BEAM : Specify whether or not to convert RBE2 elements into MPC beam elements before export.
      Rename Process : Specify whether or not to change the process name.

    • - Operating Procedure -

    1.  Prepare the model with boundary condition settings such as loads and constraints defined.
    2.  Specify the analysis type (structural / heat transfer).
    3.  Select the step type and define basic, increment and other settings as well as output settings. Add the step.
    4.  Use the Job Manager to specify boundary conditions according to the step.
    5.  Define other necessary options and click the Apply/OK button to export the input data file.
