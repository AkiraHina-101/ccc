Part Exchange

This is an exchange function allows user can replace the existing part with the New Part and re-assigning all LBCs, Connection, Property, Group information of the Original Part to the New Part.
The replacement part can be CAD part, mesh part or solid part but it must not have any shape error.



The New Part could be managed the LBCs, Connections, Local Mesh Setting, Group, Contacts and Property to edit/update before apply.


For simplified confirmation, you can check the number of entities before and after the function is executed in the columns for the Num. Original and Num. New.

Moreover, when modifying a specific LBCs, Connections, Local Mesh Setting, Group, Contacts or Property, a Mini View window will pop-up to easily illustrate the location of setting between Original Part and replacement part, and it hepls user to confirm the setting is correct or not, or add/remove the entities of setting. The 3D mouse and view is both syncronized between the Main Window and the Mini View.


Selection list

New Part: The New Part to be replaced
Original Part: The existing part on the model
Delete Part: The part to be removed with all related LBCs, Connection,...

Exchange Informations

Parameters

  • New Part

    Select the New Part to be the replacement part.
    This option is related to selection list, the ID of New Part in selection list will automatically fill in the combo box

  • Original Part

    Select the Original Part to be exchanged by New Part.
    This option is related to selection list, the ID of Original Part in selection list will automatically fill in the combo box

  • Delete Part

    Select the Delete Part to be removed.
      ∗It is a particular case to remove part, it is recommended that users should confirm before removing it.

    • Tolerance

  • Tolerance

    Specify the threshold value for the range of the surface or element between the New Part to be replaced and the Original Part.

  • Face duplication ratio

    Specify the threshold ratio value of the area ratio between 2 faces of the New Part and the Original Part.
    This value will use to judge the LBCs item can be applied on the New Part's face or not. If the actual area ratio is greater than the threshold value, LBCs is considered to assign on the New Part's face.

    • Options

  • Exclude Tiny Faces

    Specify the tiny faces in LBC target entity to be excluded.

  • Max Face Width

    Specify the maximum threshold width value for the tiny faces to be excluded.
    The minimum face width is always fixed to 0, the maximum face width is equal to input value.

    • Show Result

    Show Result Button: To open the management dialog to control the information of result. It needs the selections have been specified before using the button.

    • Group: Specify the Group information of the Orignal Part and list all of them on the table.

    • Load and Boundary: Specify the Load and Boundary information of the Orignal Part and list all of them on the table.

    • Local Mesh Setting: Specify the Local Mesh Setting information of the Orignal Part and list all of them on the table.

    • Contact: Specify the Contact information of the Orignal Part and list all of them on the table.

    • Connection: Specify the Connection information of the Orignal Part and list all of them on the table.

    • Property: Specify the Property information of the Orignal Part and list all of them on the table.

    • Name[ID]: Item name and ID.

    • Num. Original: Number of entities selected for the item in the original part before moving to the new part

    • Num. New: Number of entities selected in the item after moving to a new part.

    • Modification: Display of the Mini View window. Change selection entity.

    - Operating Procedure: General workflow -

    1. Select a New Part.
    2. Select a Original Part.
    3. Change the parameters (Parameter) as needed.
    4. Click the Show Result button. The dialog will expand to show more information of the selection.
    5. Check on each information which is needed to convert to the New Part from the Original Part
    6. Confirm the information setting, position, selection entities between the New Part and the Original Part by the Mini View window
    7. Click Apply/OK button to replace the Original Part by the New Part.

      ∗From step 4-6, below operation will show how it works.

    - Operating Procedure: Detail operation when to edit the information(Add/Remove selection entities) -

    1. Click the Show Result button, the dialog will expand to show more information of the selection.
    2. Specify information result types which will apply to New Part, all the related information will be listed on the table. In this case, all information will be checked and converted to the New Part.
    3. Check and confirm the information items from Original Part on the table by clicking on Edit button.

    4. Add or remove the entity on the selection list for each setting item.
    5. After confirmation all settings are OK, click Apply/OK button to replace the Original Part by the New Part.

    - Special Notes -

    • This function supports CAD part, mesh part or solid part but without any shape error.
    • The selection should be finished before clicks on Result button, if not, a failed dialog will show
    • Only one New Part is supported. Therefore, the New Face must also be selected from a single part.
    • This function allows selecting multiple parts, but it will be hard to control the information if there is so much information. It was recommended that one-by-one selection get high efficiency and restraint the failed problem.
