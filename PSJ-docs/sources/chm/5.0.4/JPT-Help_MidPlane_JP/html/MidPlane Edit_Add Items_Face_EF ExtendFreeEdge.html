フリーエッジを延伸投影

選択したエッジに属するフェースの延長面と選択したフェースの交点にエッジを投影して、生成されたエッジと選択したエッジ間にフェースを作成します。

オプション

  • 隣接エッジ方向

    選択したエッジに属するフェースの形状を考慮してエッジをフェースに投影して生成されたエッジと選択したエッジ間にフェースを作成します。

  • フェースをマージ

    作成されたフェースをマージします。

  • エッジをマージ

    元のフェースと作成したフェースのエッジ間角度が入力値以上の場合に、エッジもマージします。

  • 複数エッジと複数フェース

    複数エッジと複数フェースを選択し、複数フェースを作成します。また、作成したフェース間にフェースを作成します。 エッジとフェースを選択する順番は、対象となるエッジとフェース毎に選択します。

    • - 操作手順 -

    1. １つのエッジと１つのフェースを選択します。
    2. 必要に応じて、オプションを設定します。
    3. 適用またはOKボタンを押します。
