シェル交差部接続(アドバンスト)

シェルモデル向けのフェース間接続機能です。
複数パーツのフェース間を接続します。自己交差オプションを有効にすると、同じパーツ内のフェース間も接続します。
※本機能は「シェル交差部を接続」機能の、機能改良版です。

パラメーター

  • メッシュ種類

    接続する周囲の要素を指定します。

    • 三角形一次要素

      フェース上のメッシュが三角形一次要素の場合に指定します。

    • 四角形一次要素

      フェース上のメッシュが四角形一次要素の場合に指定します。

      •
  • 自己交差

    このオプションをONにすると、同じパーツ内のフェース間も接続します。

  • アッセンブルタイプ

    フェース間の接続方法を指定します。

    • フェース延伸

      間隙トレランスの範囲内で、フリーエッジをフェースに引き伸ばして接続します。延伸方向は直線です。

    • エッジ接続

      間隙トレランスの範囲内で、エッジとエッジを接続します。

    • フェース交差

      フェースとフェースの交差部を接続します。

    • 自動

      上記３つのパターンを自動的に判定して適宜フェース接続します。

      •
  • 接続位置

    アッセンブルタイプ > エッジ接続のオプションです。エッジとエッジの接続位置を指定します。

    • 最初のエンティティ
    • 二番目のエンティティ
    • 中間位置
      •
  • 間隙トレランス

    接続範囲の半径距離を入力します。

  • 面を分割

    接続によりインプリントされたエッジで、フェースを分割します。

    • - 操作手順 -

    1. 対象の複数パーツ、または複数フェースを選択します。
    2. 同じパーツ内のフェース間も接続する場合は、自己交差を有効にします。
    3. アッセンブルタイプを選択します。
    4. 間隙トレランスの値を調整します。
    5. 必要に応じて、他のパラメータを変更します。
    6. 適用/OKボタンをクリックします。
