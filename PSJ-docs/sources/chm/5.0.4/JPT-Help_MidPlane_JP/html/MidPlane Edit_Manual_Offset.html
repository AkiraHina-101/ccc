オフセット

任意のシェルを板厚の半分量オフセットして、中立面を作成します。

選択リスト
フェース：オフセットするフェース（複数パーツのフェース対応）

オフセット

  • 板厚[mm]

    中立面作成対象パーツの板厚を入力します。単位はmmです。

  • 検索ボタン

    選択したフェースと面間角度60°で連続している面を自動で検索して選択します。

    オプション

  • 初期メッシング

    このオプションをオンにすると、中立面作成前に任意の平均メッシュサイズでメッシングします。 形状が複雑なパーツの中立面を取る際にこのオプションをオンにして頂きますと、 フリーエッジ等形状崩れが起きにくくなります。

  • 平均メッシュサイズ

    初期メッシングの際の平均メッシュサイズを入力します。

  • 新規作成

    このオプションをオンにすると、中立面パーツが選択したフェースのパーツと別パーツで作成されます。

  • 新規パーツ名

    新規作成オプションで中立面パーツを作成した際の、新しいパーツの名前を入力します。

    • 2D プロパティ

  • 材料選択

    中立面を作成と同時に、選択した材料を中立面パーツに定義します。ここには、材料ダイアログのユーザーデータベース内にある材料がプルダウンメニューで表示されます。

    • - 操作手順 -

    1. 中立面を作成したいパーツの外側、もしくは内側フェースを選択します。
    2. 必要に応じて検索ボタンをクリックして、フェースを複数選択します。検索ボタンクリック後も、メインウィンドウからマウス左クリックで選択、選択解除も可能です。
    3. 板厚を入力します。（オフセット量の2倍の数値）
    4. 必要に応じてオプションを設定します。
    5. 材料を定義したい場合は、材料選択から材料を選択します。
    6. 適用またはOKボタンをクリックします。
