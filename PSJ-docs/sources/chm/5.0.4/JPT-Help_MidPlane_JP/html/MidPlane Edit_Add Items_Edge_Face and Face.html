フェース＆フェース

延長フェースの延長先にエッジを作成します。
複数フェースに対応しておりますが、エッジの投影が複数フェースにまたがることはできません。

フェース・フェースオプション

  • 延長タイプ
    • 延長 : エッジをフェースに投影します。
    • 交差 : フェースの形状を考慮して、エッジをフェースに投影します。
      •
  • 円筒形状の延長

       ？？

    • - 操作手順 -

    1. 「参照フェース」を選択します。
    2. 「延長フェース」を選択します。
    3. 必要に応じて、オプションを設定します。
    4. 適用またはOKボタンを押します。
