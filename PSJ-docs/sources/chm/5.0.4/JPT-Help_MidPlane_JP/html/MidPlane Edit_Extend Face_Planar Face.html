平面

このコマンドでは、平面を延長します。

オプション

  • 延長タイプ

    •    延長するタイプを選択します。

    • 平面：平面で延長します。
    • 円筒面：円筒面で延長します。
  • 方法

    •    方法を選択します。

    • 軸方向へ：延長するフェースの方向を座標平面で指定します。
    • フェースへ：指定したフェースまで平面を延長します。
    • エッジオフセット：指定したフェースを指定した長さで延長します。
    • 座標系：任意の座標系を指定し、座標方向にエッジを引き伸ばしフェースを作成します。

    パラメーター

  • 座標平面

    •    延長する座標平面を指定します。

    • XY ： XY平面上
    • YZ ： YZ平面上
    • ZX ： ZX平面上
  • z/x/y

    •    XY を選択した場合、Z 方向の座標値を入力します。

       YZ を選択した場合、X 方向の座標値を入力します。

       ZX を選択した場合、Y 方向の座標値を入力します。

    エッジオフセット

  • 長さ

    •    オフセット値を入れます。

    座標系

  • 座標系

    •    任意の座標系を指定し、座標方向にエッジを引き伸ばしフェースを作成します。

  • 軸

    •    延長するフェースの方向を指定します。

  • マグニチュード

    •    延長する値を入力します。

    その他

  • 平面法線と同方向

    •    チェックを入れると反対方向にフェースを作成します。

  • 円弧の半径

    •    円筒面の円弧の半径を入力します。

  • 円弧の節点数

    •    円筒面の円弧の分割数を入力します。

    - 操作手順（平面｜軸方向へ) -

    1.  選択リストを開き「フェース」をクリックして延長したいフェースを選択します。
    2.  「エッジ」をクリックして延長したいエッジを選択します。
    3.  延長する座標平面を指定します。
    4.  z/x/yに座標値を入力します。
    5.  適用またはOKをクリックします。

    - 操作手順（平面｜フェースへ) -

    1.  選択リストを開き「フェース」をクリックして延長したいフェースを選択します。
    2.  「リファレンス」をクリックして延長先のフェースを選択します。
    3.  適用またはOKをクリックします。

    - 操作手順（平面｜エッジオフセット) -

    1.  選択リストを開き「フェース」をクリックして延長したいフェースを選択します。
    2.  「エッジ」をクリックして延長したいエッジを選択します。
    3.  オフセット値を入力します。
    4.  適用またはOKをクリックします。

    - 操作手順（平面｜座標系) -

    1.  選択リストを開き「フェース」をクリックして延長したいフェースを選択します。
    2.  「エッジ」をクリックして延長したいエッジを選択します。
    3.  軸のプルダウンメニューから延長するフェースの方向を指定します。
    4.  マグニチュードに延長する値を入力します。
    5.  適用またはOKをクリックします。

    - 操作手順（円筒面｜軸方向へ) -

    1.  選択リストを開き「フェース」をクリックして延長したいフェースを選択します。
    2.  「エッジ」をクリックして延長したいエッジを選択します。
    3.  延長する座標平面を指定します。
    4.  z/x/yに座標値を入力します。
    5.  シリンダー面の円弧の半径と節点数を入力します。
    6.  適用またはOKをクリックします。

    - 操作手順（円筒面｜フェースへ) -

    1.  選択リストを開き「フェース延伸」をクリックして延長したいフェースを選択します。
    2.  「リファレンス」をクリックして延長先のフェースを選択します。
    3.  軸のプルダウンメニューから延長するフェースの方向を指定します。
    4.  円弧の半径と節点数を入力します。
    5.  適用またはOKをクリックします。
