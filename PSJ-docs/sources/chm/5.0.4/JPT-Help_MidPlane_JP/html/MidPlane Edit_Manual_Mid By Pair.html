ペアによる中立面作成

ペアとなるフェース群を手動選択して、中立面を抽出します。

オプション

  • フェースをステッチ

    中立面フェースを縫合する範囲を入力します。

  • フェースをマージ

    上記で縫合されたフェースをマージします。

  • エッジをマージ

    上記でマージされたフェース縫合部の、エッジ間角度が入力値以上の場合に、エッジもマージします。

  • フェースを延伸

    中立面フェースを「参照フェース」で選択されたフェースまで延伸します。

  • 延伸トレランス

    上記で延伸するトレランス範囲を入力します。

  • ペアフェースを非表示

    機能実行後、「基準フェース」と「ペアフェース」を自動的に非表示にします（作成された中立面フェースを直ぐに視認できます）

    • - 操作手順 -

    1. 「基準フェース」で、中立面フェースにするフェースを選択します。
    2. 「ペアフェース」で、ベースの相手側フェースを選択します。
    3. 「対象パーツ」で、中立面フェースを作成するパーツを選択します。新規パーツとして作成する場合は、選択しません。
    4. 「フェース延伸」を実行する場合、「参照フェース」で、延伸先のフェースを選択します。
    5. 必要に応じて、オプションを設定します。
    6. 適用／OKボタンをクリックします。
