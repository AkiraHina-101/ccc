プレス

自動で複数のソリッドパーツから中立面を抽出します。対象形状は、一枚板で加工された板厚一定の薄肉形状です。
∗ソリッドパーツとは、ソリッドメッシュではなくソリッド形状のパーツを意味します。

この機能により、ソリッドパーツがシェルパーツに更新され、ソリッドパーツはリファレンスツリーにストアされます。
計算された板厚は、材料プロパティとして設定されます。




  • 選択リスト

    • パーツ : プレスするパーツ（複数パーツ対応）

    パラメーター

  • 微小中空円筒深さ

    • プレスするパーツにある、凹み深さを入力します。入力された値分の凹みは平面として認識されます。

    オプション

  • 桁数

    • 板厚数値の桁数を選択します（1を選択した場合は、板厚数値は小数点第一位までです。例えば、実際の板厚が2.15の場合は、繰り上がり2.2になります）

    2Dプロパティ

  • 材料選択

    • シェル材料を指定します。材料ダイアログのユーザーデータベース内にある材料が、プルダウンメニューで表示されます。

    - 操作手順 -

    1. パーツを選択します。

    2. 「材料選択」で材料を選択します。
    3. 必要に応じてオプションを設定します。
    4. 適用／OKボタンをクリックします。
    5. 結果ダイアログが表示されます。
    6. アセンブリウィンドウ内、実行したパーツ下のレファレンスに'オリジナルCADモデルの構造と抽出された中立面が作成されます。
      中立面は、'∗_MidPlane'で作成されます。

    - 操作手順/エラーおよびワーニングの確認 -

    1. 中立面抽出に失敗したパーツがある場合、ワーニングメッセージが表示されます。
    2. 出力ウィンドウに、エラー判定されたパーツIDが表示されます。
    3. グループツリーに、エラー判定されたフェースグループ、もしくはパーツグループ（'Failed Parts_∗'）が作成されます。
    4. 各エラーを確認して、エラー箇所の手修正や削除、もしくはソリッドパーツに戻してからリトライをします。

    - 操作手順/リトライ例 -

    CADモデルのファセットエラーにより、中立面が崩れる場合がございます。
    その場合は、一度メッシングした後でプレスを実行すると、中立面抽出の精度が向上します。

    1. やり直したいシェルパーツをアセンブリツリー上で右クリックします
    2. 「オリジナルパーツに置き換え」でソリッドパーツに戻します。
    3. 「サーフェースメッシング」を実行します。
    4. 再度「プレス」を実行します。
