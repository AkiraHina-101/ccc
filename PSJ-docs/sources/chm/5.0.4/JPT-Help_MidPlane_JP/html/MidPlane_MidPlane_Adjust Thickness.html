板厚を調整

パーツの板厚情報からパーツの総重量を表示させ、CAD などで計算した総重量 に変更し、全体板厚の微調整をします。

基本パラメーター

  • 材料ＩＤ

    •    材料IDを入力します。

  • 材料

    •    材料を選択します。

  • 質量密度

    •    質量密度を入力します。

    元のデータ

  • 要素数表示

    •    このボタンを押すと、割り当てられた材料で計算された数値がそれぞれ に表示されます。

  • 最小板厚

    •    最小板厚を入力します。

  • 最大板厚

    •    最大板厚を入力します。

  • 平均板厚

    •    平均板厚を入力します。

  • 合計面積

    •    合計面積を入力します。

  • 合計質量

    •    合計質量を入力します。

    データの調整

  • フェース板厚を調整

    •    チェックを入れると、実際の総重量に合わせて、中立面モデル板厚を自 動調整し、割り当てることができます。

  • 板厚プロパティを調整

    •    チェックを入れると、実際の総重量に合わせて、メッシュモデルの板厚 を自動調整して、割り当てることができます。

  • 合計質量（実部）

    •    実際の総重量を入力します。

    - 操作手順 -

    1.  対象のパーツを選択します。
    2.  材料を設定します。
    3.  要素数表示をクリックします。
    4.  合計質量(実部)に正しい重量の値を入力します。
    5.  適用またはOKをクリックします。
