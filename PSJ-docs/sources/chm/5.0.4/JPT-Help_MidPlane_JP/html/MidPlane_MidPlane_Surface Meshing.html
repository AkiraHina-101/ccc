メッシング | サーフェースメッシング

形状表面に三角形・四角形要素を生成します。


メッシュタイプ

  • Tri3

       三角形要素を作成します。

  • Quad4

       四辺形要素を作成します。

    • Quad F-メッシャー : 平均/最小/最大に同サイズを指定し、整ったサイズの要素を作成するタイプの高速タイプメッシャーです。

      •

    • メッシュサイズ

  • 平均

       平均メッシュサイズを設定します。

  • 最小

       最小メッシュサイズを設定します。

  • 最大

       最大メッシュサイズを設定します。

  • 減少係数

       平均、最小、最大それぞれのメッシュサイズに内部的にかかる係数です。

       <例>減少係数1.1で平均5.0を入力した場合、平均5.5でメッシュを作成します。

  • 曲率コントロール

       CAD形状の曲率が大きく変化する場所の頂点に節点を置くように調節します。

    • 曲面メッシング

    フィレット部を指定角度で分割する設定を行います。

  • 最大要素角度（度）

       分割角度を設定します。

    • メッシュのグラデーション

  • グラデーション係数

       メッシュ変化の度合いを設定します。

    • クリーンアップ

  • メッシュストレッチ

       メッシュ品質の最小ストレッチの値を設定します。

    • パフォーマンス

  • 速度対品質

       速度対品質を設定します。

    • 最速 : メッシュ作成速度を優先します。
    • 品質良 : 通常の速度と品質でメッシュを作成します。
    • 最高品質 : メッシュ品質を優先します。
      •
  • 最適化

       メッシュ品質の設定を行います。

    • 無効 : 設定なし。
    • レベル１～５ : 設定あり。
      •

  • 複数CPUメッシュ

       並列処理の設定を行います。並列化はボディ毎にコアを割り当てて実行されます。

    • 1～32Cores : コア数1～32※デフォルトはマシンに搭載されているコア数を参照します。
      •

    • 自動設定

  • エッジをマージ

       同一平面上にあるエッジを結合します。

  • フェースをマージ

       同一平面上にあるフェースを結合します。

  • マージフェース角度

       マージエッジ又はフェースマージのチェックを入れた際に、結合するエッジやフェースの許容角度になります。

  • マップドメッシュ最小角度

       マップドメッシュの自動設定を行います。

    • 0=θ : 全ての四辺形形状のある面にマップドメッシュを作成します。

    • 1=θ : 全ての円筒形状の四辺形形状のある面にIsoメッシュを作成します。

    • 1<θ : 下記図の場合の円筒形状（断面）のθ以下の角度に作成されるメッシュ形状がMapメッシュ形状になります。但しマップドメッシュが作成されるためには円筒面が四辺形形状である必要があります。
  • 不正なCADモデル

       面積0のジオメトリフェースがあった場合でも表面メッシュを作成できます。

  • 穴を閉じる

       要素間にできた穴を埋めたサーフェスメッシュを作成できます。

  • チャンファー面を削除

       最小(最小メッシュサイズ)値以下の面取りを自動で除去します。

  • 微小円筒面メッシング

       油路など細い円筒形状のメッシングの際、メッシュの潰れを防ぎます。

    • 微小フェースのマージ

  • 微小フェースのマージ

       メッシュ作成と同時に微小フェースを修正できます。

  • 最小フェース幅

       対象のフェースの最少幅を指定します。

  • 最大フェース幅

       対象のフェースの最大幅を指定します。

    • 円エッジ頂点位置揃え

  • 円エッジ頂点位置揃え

       同心円状の頂点位置を揃えます。

  • メッシュカラー

       メッシュ作成後のパーツの色を指定します。

    • - 操作手順 -

    1.  平均、最少、最大メッシュサイズを指定します。
    2.  対象のパーツを選択します。
    3.  適用/OKボタンをクリックします。※メッシュ作成中キャンセルボタンで中止することができます。
