板厚プロパティ作成

このコマンドでは、中立面の板厚情報をサーフェースモデルに割り当てます。

基本パラメーター

  • 板厚差

    •    板厚情報値の許容範囲を入力します。

    設定方法

  • エンティティタイプ

    •    エンティティタイプを選択します。

  • プロパティ分離

    •    ？？？

    その他のパラメーター

  • 膜挙動の材料

    •    膜挙動に対する材料を選択します。

  • 曲げ挙動の材料

    •    曲げ挙動に対する材料を選択します。

  • 横せん断挙動の材料

    •    横せん断挙動に対する材料を選択します。

  • 膜-曲げ連成挙動の材料

    •    膜-曲げ連成挙動に対する材料を選択します。

  • 材料の方向

    •    材料座標系を入力します。

  • 厚さ

    •    板厚を入力します。

  • 曲げ剛性

    •    曲げに対する断面２次モーメントの比率を入力します。

  • 板厚比率

    •    横せん断厚さの比率を入力します。

  • 非構造質量

    •    単位面積あたりの非構造質量を入力します。

  • 応力積算距離1.2

    •    参照面からの応力算出距離を入力します。

  • 平板オフセット

    •    オフセット値を入力します。

    積分点の格納

  • シェル要素の積分点の数

    •    シェル要素の積分点を指定します。

    板厚設定

  • 最大板厚

    •    板厚分布の最大値を入力します。

  • 最小板厚

    •    板厚分布の最小値を入力します。

    - 操作手順 -

    1.  中立面メッシュパーツと中立面パーツを選択します。
    2.  膜挙動の材料・曲げ挙動の材料・横せん断挙動の材料で、定義した材料データを選択します。
    3.  適用またはOKボタンをクリックして中立面の板厚情報を中立面メッシュモデルに割り当てます。
