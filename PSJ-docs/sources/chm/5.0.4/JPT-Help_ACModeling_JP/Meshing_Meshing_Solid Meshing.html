ソリッド メッシング

四面体のソリッド要素を作成します。

メッシュタイプ

  • TET4

       四面体1次要素を作成します。

  • TET10

       四面体2次要素を作成します。

    • 属性

  • グレーディング係数

       要素のグレーディングの値を入力します。

  • ストレッチ限度

       メッシュ作成時の要素ストレッチの制限値を指定します。

  • 速度対品質

       速度対品質の設定を行います。

    • 最速 : メッシュ作成速度を優先します。

    • 最適化 : メッシュ品質を優先します。
      •
  • 速度対メモリ使用量

       速度対メモリ使用量の設定をします。

    • 標準 : メッシュ作成速度を優先します。

    • 低メモリ : メモリ使用量の削減を優先します。
      •
  • 領域

       パーツ内の空間へソリッド要素の作成領域を設定します。

    • 主領域 : パーツ内の主領域のみソリッド要素を作成します。

    • すべての領域 : パーツ内すべて領域へソリッド要素を作成します。
      •
  • 内部節点

       パーツ内部に節点を作成します。オフにすることでサーフェス上の節点を使用してソリッド要素を作成します。

  • セーフモード

       微少要素を作成された場合、チェックを入れることで改善することができます。

  • 複数CPUメッシュ

       並列処理の設定を行います。並列化はボディ毎にコアを割り当てて実行されます。

    • 1～32Cores : コア数1～32※デフォルトはマシンに搭載されているコア数を参照します。
      •

    • 強制的な調整

  • サーフェース節点

       要素品質確保するの為わずかに表面節点を動かす場合があります。

  • エッジ節点

       要素品質確保するの為わずかにエッジ節点を動かす場合があります。

  • プリザーブ

       プリザーブを無視して節点を動かす場合があります。

  • 内部節点のみ

       ソリッド要素作成時の自動修正する際、表面要素を変更せずに内部要素のみ修正を行います。

    • オプション

  • メッシュカラー

       ソリッドメッシュ作成後のパーツの色を選択することができます。

    • - 操作手順 -

    1.  メッシュタイプを選択します。
    2.  対象のパーツを選択します。
    3.  適用/OKボタンをクリックします。
