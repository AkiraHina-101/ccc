タイトラップ

構造メッシュの表面にラッピングモデルを作成します。

オプション

  • 厚さ

    •    構造表面からのオフセット量を指定します。

  • 幅

    •    形状間の結合の範囲を指定します。

  • メッシング

    •    ラッピングモデル作成後、メッシュを作成します。

  • メッシュサイズ

    •    メッシュサイズを設定します。

  • シェルオプション

    •    フェース両側にオフセットします。

  • 領域選択

    •    抽出領域を選択します。

    • 外側 : モデル外表面のみ抽出されます。
    • 内側 : モデル内表面のみ抽出されます。
    • 両側 : モデル全表面抽出されます。

    - 操作手順 -

    1.  対象モデルの形状、要素サイズから幅を入力します。
    2.  メッシュサイズを入力します。
    3.  抽出領域を選択します。
    4.  Apply/OKボタンを押します。
