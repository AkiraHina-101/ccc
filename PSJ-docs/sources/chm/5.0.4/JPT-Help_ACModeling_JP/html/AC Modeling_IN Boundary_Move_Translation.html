無限境界 | 制限境界 | 平行移動

無限境界の制限面の移動を行います。

平行移動

  • 座標系

    •    平行移動に参照する座標系を選択します。

  • 軸

    •    平行移動の方向を決める軸を選択します。

    • X軸 : 選択された座標系のX軸方向にマグニチュード分、平行移動します。
    • Y軸 : 選択された座標系のY軸方向にマグニチュード分、平行移動します。
    • Z軸 : 選択された座標系のZ軸方向にマグニチュード分、平行移動します。
    • 任意の軸 : X、Y、Zの方向ベクトルとマグニチュード分、平行移動します。
    • 2節点 : 画面から選択された2つのNode方向にマグニチュード分、平行移動します。
    • エッジ : 画面から選択されたエッジ方向にマグニチュード分、平行移動します。
  • X,Y,Z

    •     方向ベクトルのXYZ成分が表示されます。任意軸指定時は、各成分を入力し方向を指定します。

  • マグニチュード

    •    移動量を入力します。

    - 操作手順 -

    1.  Partを選択します。
    2.  既存の座標系方向に移動させる場合には、座標系から既存の座標系を選択し、軸からX軸、Y軸、Z軸のいずれかを選択し、マグニチュードに移動量を入力します。
    3.  任意の方向に移動させるには、軸から任意の軸を選択し、X、Y、Zおよびマグニチュードに方向ベクトルと移動量をそれぞれ入力します。
    4.  選択した2節点方向に移動させるには、節点ボタンを押し、画面から節点を２つ選択します。マグニチュードに節点2つ間の距離が自動的に入力されます。
    5.  選択したエッジ方向に移動させるには、エッジボタンを押し、画面からエッジを選択します。マグニチュードにエッジ長さが自動的に入力されます。
    6.  必要に応じてマグニチュードの移動量を変更します。
    7.  OKボタンを押します。
