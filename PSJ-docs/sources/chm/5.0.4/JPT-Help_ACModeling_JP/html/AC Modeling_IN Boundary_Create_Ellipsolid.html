無限境界｜楕円作成

無限境界面の形状（楕円）を作成します。

楕円

  • 自動

    •    自動回転楕円体を作成します。

  • トレランス

    •    音響境界から楕円体までの最小距離を指定します。

  • 中心

    •    回転楕円体の中心座標。

  • メジャー点

    •    楕円体の長軸端点座標。

  • マイナー点

    •    楕円体の短軸端点座標。

    - 操作手順 -

    1.  トレランスを入力します。
    2.  OK/Applyボタンを押します。
    3.  トレランス分オフセットされた回転楕円が作成されます。
    4.  出力ウィンドウの出力タブに楕円の座標情報が記載されます。
    5.  また、梁要素で表現された軸モデルが作成されます。再度、Jupiterを起動し、楕円体の軸を確認する際は、こちらから座標情報を取得してください。
