無限境界 | 制限境界 | 回転

無限境界の制限面の回転を行います。

  • 座標系

    •    参照する座標系を選択します。

  • 軸

    •    回転軸を選択します。

    • X軸 : 選択された座標系のX軸回りに回転します。
    • Y軸 : 選択された座標系のY軸回りに回転します。
    • Z軸 : 選択された座標系のZ軸回りに回転します。
    • 任意の軸 : X、Y、Zの方向ベクトルで指定された軸回りにアングル分回転します。
    • 2節点 :  画面から選択された2つのNode方向の軸回りにアングル分回転します。
    • エッジ : 画面から選択されたEdge方向の軸回りにアングル分回転します。
      •
  • X軸,Y軸,Z軸

    •     回転中心位置のX、Y、Z座標を入力します。

  • 中心

    •    回転の中心位置を決めます。

    • Part Center : Partの中心を回転中心にします。
    • Node : 画面から選択したNodeを回転の中心にします。
    • Input : 回転中心を中心-X、中心-Y、中心-Zに入力します。
      •
  • 角度

    •    回転角度を入力します。

    - 操作手順 -

    1.  Partを選択します。
    2.  既存の座標系軸回りに回転させる場合には、座標系から既存の座標系を選択し、回転軸からX軸、Y軸、Z軸のいずれかを選択します。
    3.  任意の方向に回転させるには、回転軸から任意軸を選択し、X軸、Y軸、Z軸入力ボックスに方向ベクトルを入力します。
    4.  選択した2節点方向に回転させるには、回転軸から2節点を選択し、画面から節点を２つ選択します。
    5.  選択したエッジ方向に移動させるには、回転軸からエッジを選択し、画面からエッジを選択します。
    6.  Partの中心を回転中心にするには、中心からパーツ中心を選択します。
    7.  Partの中心を節点位置にするには、中心から節点を選択し、画面から節点をピックします。
    8.  Partの中心を直接入力にするには、中心から入力を選択し、回転中心を中心-X、中心-Y、中心-Zに入力します。
    9.  回転角度に回転する角度を入力します。
    10.  OKボタンを押します。
