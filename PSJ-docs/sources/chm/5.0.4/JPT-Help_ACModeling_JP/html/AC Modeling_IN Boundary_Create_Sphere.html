無限境界｜球作成

無限境界面の形状（球体）を作成します。

球

  • 球体のタイプ

    球体タイプを指定します。

    • 球体 : 球体を作成します。

    • 半球 : 半球を作成します。
      •
  • 中心

    •    球体の中心座標を入力します。

  • 半径

    •    球の半径を入力します。

    - 操作手順 -

    球タイプ使用方法

    1.  パーツを選択し、球体の中心座標を入力します。
    2.  半径の値を入力します。
    3.  Apply/OKボタンを押します。

    半球タイプ使用方法

    1.  パーツを選択し、半径の値を入力します。
    2.  カット位置のフェースを選択します。
    3.  Apply/OKボタンを押します。
