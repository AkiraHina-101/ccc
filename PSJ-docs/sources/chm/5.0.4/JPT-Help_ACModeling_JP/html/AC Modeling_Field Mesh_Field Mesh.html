フィールドメッシュ

起点と終点の座標を入力しフィールドメッシュを作成します。

パーツ名

  • パーツ名

    •    新規で作成されるパーツ名を入力します。

    始点座標

  • X,Y,Z

    •    始点の座標を入力します。

    終点座標

  • X,Y,Z

    •    終点の座標を入力します。

    要素数

  • X,Y,Z

    •    各座標軸のエレメントの分割数を指定します。いずれかの軸が0の場合平面を作成します。

    - 操作手順 -

    1.  始点の座標を入力します。
    2.  終点の座標を入力します。
    3.  各軸の分割数を指定します。
    4.  OKボタンで実行します。
