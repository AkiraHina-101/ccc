隣接面選択｜要素

探索を開始する要素と境界（要素や角度）を設定することで、指定した境界内の要素を纏めて選択します。

オプション

  • レイヤー数

    •    探索範囲となるレイヤ数を入力します。

  • 停止要素を含める

    •    停止となる境界要素も選択します。

  • 指定した角度で停止

    •    停止の境界となる角度を入力します。

  • プレビュー

    •    選択される要素を確認できます。

  • リセット

    •    プレビュー表示をリセットします。

  • ノンマニフォールドで停止

    •    ノンマニフォールドで探索を停止します。

  • 表示パーツのみ

    •    画面上に表示されているパーツ上のみ選択します。

    - 操作手順 -

    1.  開始要素を選択します。
    2.  停止要素を選択します。
    3.  レイヤー数、停止する角度を入力します。
    4.  プレビューボタン選択し、選択要素を確認します。
    5.  Apply/OKボタンをクリックします。
