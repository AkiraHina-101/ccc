構造メッシュインポート

振動解析で使用したメッシュデータを読み込み、各パーツの表面三角形一次要素モデルを作成します。
入力されるデータは、Nastran入力データ形式の四面体二次要素、五面体一次要素、六面体一次要素からなるモデルとし、五面体、六面体の表面四角形形状は任意に三角形に分割されます。
同時に、表面データをTri6およびTri3データをNastranデータ形式で出力します。

Nastranデータ

  • 面角度

    •    フェース情報を作成する要素角度です。

  • 読み込み

    •    振動解析で使用したメッシュデータを指定します。

  • シェルファイル出力

    •    構造面のシェル要素出力オプションです。

    - 操作手順 -

    1.  Importボタンから入力データを選択し、OKボタンを押すことで実行されます。
    2.  名前を付けて保存ダイアログが起動するので、シェル要素の入力ファイルを作成します。
