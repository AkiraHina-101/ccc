フェース抽出

探索を開始するフェースと境界（フェースや角度）を設定することで、指定した境界内のフェースを纏めて選択します。

オプション

  • レイヤー数

    •    探索範囲となるレイヤ数を入力します。

  • ストップフェースを含める

    •    チェックをすると、ストップとなる境界面も選択します。

  • 指定した角度で停止

    •    ストップの境界となる角度を入力します。

  • プレビュー

    •    選択されるフェースを確認できます。

  • ノンマニフォールドで停止

    •    ノンマニフォールドで探索を停止します。

    - 操作手順 -

    1.  開始フェースを選択します。
    2.  ストップフェースを選択します。
    3.  ストップフェースを選択します。
    4.  レイヤー数、停止する角度を入力します。
    5.  Apply/OKボタンをクリックします。
