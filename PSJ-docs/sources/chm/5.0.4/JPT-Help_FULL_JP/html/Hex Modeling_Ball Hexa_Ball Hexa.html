球体ヘキサメッシュ

このコマンドではヘキサ8節点要素で真球を作成します。

球体ヘキサメッシュ

  • パーツ名

    作成するパーツの名前を入力します。

  • タイプ

    Hexa：球の中心まで全ての要素をヘキサ要素で作成します。
    Hexa+Tetra：球の外殻にヘキサ要素を指定したレイヤー数作成し、球の中心にテトラ要素の混合メッシュを作成します。

  • 中心X、中心Y、中心Z

    球体の中心座標を入力します。

  • 半径

    球体の半径を入力します。

  • メッシュサイズ

    メッシュサイズを指定します。
    ※最小で半径の5%の制限があります。

  • レイヤー数

    Hexa+Tetraオプションを選択時に、外殻のヘキサメッシュ層数を指定します。

  • 中心に節点を作成

    チェックするとパーツの中心に節点が来るように調整します。

    • ※既存のBodyを選択することで自動的に中心 X/Y/Z、半径、メッシュサイズの値が入力されます。
    値を変更する際はパーツの選択状態を解除してください。

    - 操作手順 -

    1. 作成するメッシュパーツの名前を入力します。
    2. 作成するメッシュタイプをHexaまたはHexa+Tetraから選択します。
    3. モデル内の球形状パーツを選択するか、中心位置、半径、メッシュサイズを入力します。
    4. Hexa+Tetraタイプを選択した場合は、レイヤー数を入力します。
    5. メッシュパーツの中心に節点が必要な場合はチェックボックスをチェックします。
    6. 適用もしくはOKボタンをクリックします。
