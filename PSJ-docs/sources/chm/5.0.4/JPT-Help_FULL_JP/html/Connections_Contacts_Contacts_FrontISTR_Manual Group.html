接触 | グループ指定 | FrontISTR

指定グループ間にFrontISTR用接触設定を定義します。
予めマスター面およびスレーブ面となるグループを作成しておき、接触対毎に接触グループを選択し、接触設定を定義します。

基本

　　　
  • 名前

    接触対の名称を入力します。

    　　　
    • 　　　
  • アルゴリズム

    接触設定対象エンティティを選択します。
        フェース-フェース: フェース対フェース間接触     節点-フェース: 節点対フェース間接触

    　　　
    • 　　　
  • タイプ

    接触定義の挙動タイプを選択します。
        一般接触: 滑り接触
    　　　

    • 　　　
  • マスター

    マスター面となるグループを選択します。

    　　　
    • 　　　
  • スレーブ

    スレーブ面となるグループを選択します。

    　　　
    • 　　　
  • グループ切替え

    マスター/スレーブセグメントグループを切り替えます。

    　　　

    • コンタクトプロパティ

    　　　
  • コンタクトタイプ

    FrontISTRの接触タイプを定義し、同じ接触タイプの設定を簡単にコントロールします。

        ID: IDを入力します。
        相互作用: 必要な方法を選択します。
        法線方向収束(NTOL): 法線方向収束パラメーターを入力します。
        接線方向収束 (TTOL): 接線方向収束パラメーターを入力します。
        法線方向ペナルティ (NPENALTY): 法線方向ペナルティパラメーターを入力します。
        接線方向ペナルティ (TPENALTY): 接線方向ペナルティパラメーターを入力します。

    List Contact Type Created: 作成したコンタクトタイプをすべて表示します。また、右クリックで編集や削除などの機能を利用することができます。
        編集: コンタクトタイプのパラメータを変更します。
        削除: コンタクトタイプを削除します。
    　　　

    • 　　　
  • 摩擦係数 (FCOEF)

    摩擦係数を入力します。

    　　　
    • 　　　
  • 摩擦ペナルティ剛性 (FACTOR)

    摩擦ペナルティ剛性を入力します。

    　　　
    • 　　　

    色設定

  • 接触の色

        接触対表示マーカー色を定義します。
        リセット: デフォルト色に初期化

    　　　

    • - 操作手順 -

      　　　
    1.  予めマスター面、スレーブ面となるフェースもしくは要素面グループを作成しておきます。
      2. 　　　
    2.  マスターでマスター面となるグループ、スレーブでスレーブ面となるグループを選択します。
         選択したグループがモデルウィンドウでハイライト表示されます。グループ表示モードをオフにして確認することも可能です。
      　　　
    3.  必要により接触対に対する詳細設定を定義し、OKボタンをクリックして接触対を定義します。
