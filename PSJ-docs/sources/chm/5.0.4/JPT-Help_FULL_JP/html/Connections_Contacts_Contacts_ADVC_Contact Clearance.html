ADVC接触面間隙量

接触設定のスレーブ節点間隙量を定義します。
スレーブ面上の節点毎に異なる間隙量を定義したい場合にのみ使用ます。スレーブ面で一定の場合は接触定義のクリアランスで指定します。

構造

　　　
  • 名前

    接触対の名称を入力します。

    　　　

    • 間隙量

    　　　
  • 間隙量間隙量

    間隙量を指定します。

    　　　
    • 　　　
  • 入力単位系

    入力単位系を指定します。

    　　　

    • - 操作手順 -

      　　　
    1. スレーブ面上の節点を選択します。
      2. 　　　
    2. クリアランスで間隙量を指定します。
      3. 　　　
    3. 適用またはOKボタンをクリックします。
      4. 　　　
    4. 接触設定(接触>ADVC>グループ指定など)のクリアランス選択の追加/削除ボタンをクリックします。
      5. 　　　
      接触面クリアランスに作成されたスレーブ節点間隙量定義が表示されます。 　　　
    5. 必要な間隙量定義を選択し、追加ボタンをクリックし、接触対のスレーブ節点に間隙量を割り当てます。
