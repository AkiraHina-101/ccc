ブッシュ | すべてのエンティティ

選択したエンティティペア間に含まれる節点ペアにブッシュ要素 （一般化ばね‐ダンパー）要素を作成します。

接続

　　
  • 名前

    • 作成するブッシュ要素名を設定します。

    　 　　
  • すべて

    • 選択したエンティティの全ての節点をターゲットにする場合にチェックをします。チェックを外すと下のトレランスに接続範囲を入力ができ、その範囲が接続されます。

    　　
  • トレランス

    • 接続範囲を数値入力します。

    　　
  • 1:1

    • ブッシュ要素の結合を1対1接続のみに限定します。

    ブッシュ

    　　
  • グラウンド

    • チェックをすると片端が接地（バネ）として定義されます。

    　　
  • 方向付け基準

    • ブッシュ要素の方向付けの方法を選択します。

      　　
    • 方向ベクトル
      • 方向ベクトルによる指定 　　
    • 座標系
      • 座標系による指定
    　　
  • 座標系

    • 座標系による指定を選択した場合に、使用する既存の座標系をリストから選択します。

    　　
  • 方向ベクトル

    • 方向ベクトルによる指定を選択した場合に、方向ベクトルをX,Y,Zの順にコンマ区切りで入力します。

    　　
  • 剛性1～6

    • 各自由度の剛性値入力します。
    剛性が非線形の場合は、各自由度ごとに定義されたテーブルを選択します。

    　　
  • 入力単位系

    • 剛性値入力で使用する単位系を選択できます。

    オプション(Nastran)

    　　
  • 減衰係数 1～6

    • 各自由度の減衰値を入力します。
    減衰値が非線形の場合は、各自由度ごとに定義されたテーブルを選択します。

    　　
  • 入力単位系

    • 減衰値入力で使用する単位系を選択できます。

    　　
  • 減衰係数 1～6

    • 各自由度の構造減衰値入力します。
    構造減衰値が非線形の場合は、各自由度ごとに定義されたテーブルを選択します。

    　　
  • 入力単位系

    • 構造減衰値入力で使用する単位系を選択できます。

    　　
  • 応力リカバリ(並進)

    • 並進成分における応力リカバリ係数を入力します。

    　　
  • 応力リカバリ（回転）

    • 回転成分における応力リカバリ係数を入力します。

    　　
  • ひずみリカバリ(並進)

    • 並進成分におけるひずみリカバリ係数を入力します。

    　　
  • ひずみリカバリ（回転）

    • 回転成分におけるひずみリカバリ係数を入力します。

    - 操作手順 -

      　　　
    1. ブッシュ要素の一端の節点が含まれるボディ、フェース、エッジ、 節点を選択リストのマスターボタンを押してから選択します。
      2. 　　　
    2. ブッシュ要素の他端の節点が含まれるボディ、フェース、エッジ、 節点を選択リストのスレーブボタンを押してから選択します。
      3. 　　　
    3. 接続する範囲を指定する場合には、すべてチェックボックスを外し、 トレランスに範囲値を入力します。
      4. 　　　
    4. デフォルトの1対1結合ではなく、最短距離のみで結合を定義する 場合には、1:1チェックボックスをオフにします。
      5. 　　　
    5. 方向ベクトルの指定方法を方向付け基準から選択します。 指定方法に従って方向ベクトルを入力します。
      6. 　　　
    6. それそれの入力欄に剛性値、減衰値、構造減衰値、リカバリ係数を入力します。
      7. 　　　
    7. 適用またはOKボタンを押すとブッシュ要素が節点間に作成されます。
