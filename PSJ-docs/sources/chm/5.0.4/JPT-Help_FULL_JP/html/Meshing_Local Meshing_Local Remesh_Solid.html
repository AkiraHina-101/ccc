ローカル リメッシュ｜ソリッド

テトラソリッドメッシュモデルの指定範囲(球)を再度ソリッドメッシングします。
品質の悪いテトラ要素がある場合に、表面メッシュを保持したままソリッドメッシュを再生成する場合に使用します。

リメッシュ領域

  • 原点-X,Y,Z

       リメッシュ範囲(球)の中心座標を入力します。
       節点選択により自動入力されます。複数範囲指定時は座標値入力は対応していませんので複数節点を選択します。

  • 半径

       リメッシュ範囲の半径を入力します。

    • 属性

  • グレーディング係数

       要素のグレーディングの値を入力します。

  • ストレッチ限度

       メッシュ作成時の要素ストレッチの制限値を指定します。


    • - 操作手順 -

    1.  予め要素品質の悪い箇所を表示しておきます。
    2.  リメッシュ対象とするパートを選択します。パート未選択の場合、範囲に含まれるパート全てがリメッシュされます。
    3.  リメッシュ範囲の中心節点を選択します。複数箇所ある場合は複数節点を選択します。
    4.  半径を入力し、リメッシュ範囲を絞り、適用/OKボタンをクリックします。


      5. 表面メッシュを固定しているため、品質改善が困難であったり、別の箇所に出現する可能性があります。その場合は表面メッシュ含め手動にて要素編集を実施ください。
