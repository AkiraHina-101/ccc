要素作成 | ペンタ

要素が欠落している場合に、欠落している要素の節点を選択しそこに要素を作成します。

要素作成 | ペンタ

  • 自動

    チェックを入れ、2要素を選択すると自動で要素を作成します。

  • パーツに追加

    チェックを入れてパーツを選択すると、選択したパーツに要素を作成します。選択し直さない限り、パーツ情報は保持されます。

    • パーツID

      選択したパーツIDを表示します。

  • 新規作成

    要素を新しいパーツとして作成します。

    • - 操作手順 -

    1. 欠落している要素の2要素を選択します。
    2. 必要に応じて、パーツに追加オプションにチェックを入れます。オプションにチェックを入れた場合は、新しく作成する要素を追加したいパーツを選択します。
    3. 適用ボタンをクリックします。
    4. 選択した要素に囲まれた要素が作成されます。
