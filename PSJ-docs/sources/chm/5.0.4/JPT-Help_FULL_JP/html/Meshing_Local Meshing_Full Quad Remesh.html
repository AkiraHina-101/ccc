全Quadリメッシュ

選択した範囲を全て四角形要素でリメッシュします。

選択リスト

要素：リメッシュする要素

パラメーター

  • Triメッシュのハイライト

    表示パーツの三角形要素をハイライトします。

  • パターン

    リメッシュパターンの候補数を表示します。

  • 前/次ボタン

    リメッシュパターンを切り替えます。これに準じてメインウィンドウではプレビュー表示も切り替わります。

  • 自動検出

    選択された三角形要素とペアになる近い三角形要素と、その周囲の要素を自動で検索して選択します。
    ユーザーが三角形要素を選択する前に選択した四角形要素は、システムが自動選択したパターンと重複しない場合、自動的に入れ替わり選択解除になります。

  • 検索ボタン

    自動検出チェックボタンがオフの時、かつ三角形要素を一つ選択した状態で有効になります。
    ボタンを押すと、選択された三角形要素とペアになる近い三角形要素と、その周囲の要素を自動で検索して選択します。
    ユーザーが三角形要素を選択する前に選択した四角形要素は、システムが自動選択したパターンと重複しない場合、自動的に入れ替わり選択解除になります。

  • 要素選択ステータス

    要素の選択状態を自動で判断して、メッセージを表示します。

    • メッセージなし

      現在の選択状態で機能実行可能です。

    • 選択範囲を確認してください

      要素未選択の場合、もしくは選択範囲が三角形か四角形、五角形から乖離している場合に表示されます。選択範囲を変更してください。

    • Tri要素をもう1つ選択してください

      三角形要素が奇数個選択されている場合に表示されます。三角形要素を偶数個選択するようにしてください。

      •

    - 操作手順（三角形要素を四角形要素にする場合） -

    1. 必要に応じて、TriメッシュのハイライトをONにします。
    2. 条件を満たすように、リメッシュ範囲の三角形要素や四角形要素を選択します。

    3. 必要に応じて、前ボタンや次ボタンで要素パターンのプレビューを切り替えます。
      ※三角形要素が奇数ある場合や、選択範囲に問題がある場合は、プレビュー表示されません。
    4. 適用/OKボタンをクリックします。
    5. 選択範囲が全て四角形要素でリメッシュされます。

    - 操作手順（四角形要素をスムージングする場合） -

    1. 必要に応じて、TriメッシュのハイライトをONにします。
    2. 条件を満たすように、リメッシュ範囲の四角形要素を選択します。

    3. 必要に応じて、前ボタンや次ボタンでリメッシュ結果のプレビューを切り替えます。
      ※選択範囲に問題がある場合は、プレビュー表示されません。
    4. 適用/OKボタンをクリックします。
    5. 選択範囲の四角形要素の節点がスムージングされ再配置されます。

    - 特記事項:本機能の実行条件 -

    1. リメッシュ範囲に含まれる三角形要素が偶数個であること。
    2. リメッシュ範囲の形状が、三角形か四角形か五角形に近いこと。

    - 注意事項 -

    1. リメッシュ範囲は１か所ずつに対応しております。離れた場所を同時に実行することはできません。
    2. リメッシュ範囲内部のエッジは保持されません。
    3. リメッシュ範囲の表面位置は、リファレンスパーツの表面に合わせられます。ソリッドCADと中立面のリファレンスパーツがある場合は、中立面のリファレンスパーツの表面を優先します。
      リファレンスがない場合、リメッシュ範囲は平らになるのでご注意ください。
    4. Triメッシュのハイライトオン時、以下の場合はチェックボックスをオン/オフすることで、ハイライト状況の更新をお願いします。
      • パーツの表示/非表示を変更した場合
      • UndoもしくはRedoを実行した場合
