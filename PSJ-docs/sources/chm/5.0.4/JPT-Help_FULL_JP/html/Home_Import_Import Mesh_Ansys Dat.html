Ansys Dat

Ansys ファイル（.dat/.cab）を読み込みます。

インポートタイプ

  • 標準インポート

    •    モデル形状のみを読み込みます。

  • プロパティで分けてインポート

    •    モデル形状と材料プロパティを読み込みます。材料プロパティ毎にボディが作成されます。

    角度

  • 面角度

    •    フェース分割を判定するための、トレランス角度です。指定した角度以下で隣り合うエレメント間にエッジを作成し、フェースを定義します。

  • エッジ角度

    •    エッジ分割を判定するための、トレランス角度です。指定した角度以上で隣り合うエッジ要素に頂点を作成し、エッジを分割します。

    - 操作手順 -

    1.  コマンドを起動し、各オプションを指定してOKボタンをクリックします。
    2.  「ファイルを開く」ダイアログが表示されますので、読み込みたいデータを選択して「開く」ボタンをクリックします。
