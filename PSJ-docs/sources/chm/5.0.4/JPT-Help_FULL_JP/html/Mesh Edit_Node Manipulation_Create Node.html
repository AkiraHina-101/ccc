節点作成

節点または浮遊節点を作成します。



  • 任意

       任意の位置に節点または浮遊節点を作成します。

  • オフセット

       選択した節点を、指定方向にコピーした位置に節点または浮遊節点を作成します。

  • 節点

       選択した節点の位置に浮遊節点を作成します。
  • 任意点

       ピックした任意点位置に浮遊節点を作成します。
  • 2節点の中点

       選択した2つの節点の中間位置に作成します。

  • 3節点の中心

       選択した3つの節点で定義される円の中心位置に作成します。
  • 円弧エッジの中心

       選択した円弧エッジで定義される円の中心に作成します。

  • 重心位置

       選択した形状の重心位置に浮遊点を作成します。

  • インポート

       ファイルから節点データを読み込んで作成します。

  • 直線に投影

       直線上に任意の浮遊点を投影します。

  • 平面に投影

       フェース上に任意の節点を投影します。

  • 円筒面の中心

       選択した円筒形状の中心位置に浮遊節点を作成します。
  • 球の中心

       選択した球形状の中心位置に浮遊節点を作成します。
  • 線分との交点
