モーフィング | インポート

変位結果を読み込み、メッシュモデルの節点を移動します。


ポジション

  • ソルバー

       変位結果のソルバーを選択します。

  • ブラウズ

       変位結果のデータを選択します。

  • ステップ(サブケース)

       変位結果を使用するStep、Subcase、Processを指定します。

  • スケール

       変位結果のスケールを指定します。


    • - 操作手順 -

    1.  画面上からPartを選択します。
    2.  Browseを押し、変位結果のデータ(op2ファイル)を選択します。
    3.  変位結果を使用するステップ,サブケース,Processを指定します。
    4.  変位結果のスケールを指定します。
    5.  適用またはOKボタンを押します。
