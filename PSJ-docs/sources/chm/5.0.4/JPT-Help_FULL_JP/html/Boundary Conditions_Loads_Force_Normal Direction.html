力 | 法線方向

選択した節点に、選択したフェースの法線方向に荷重を定義します。

構造力

　　
  • 名前

    力荷重名を設定します。

    力

    　　　
    • 　　
  • 荷重X/Y/Z

    選択された要素面から荷重のX,Y,Z各軸方向の成分を表示します。

    　　　
    • 　　
  • 値

    負荷する荷重値を入力します。

    　　　
    • 　　
  • 入力単位系

    入力単位を指定します。

    オプション

    　　　
    • 　　
  • 矢印方向

    マーカー表示の描画位置を設定をします。
       節点が始点：節点を始点として、マーカーを表示します。
       節点が終点：節点を終点として、マーカーを表示します。

    　　　
    • 　　
  • 分配方法

    力の分配方法の設定をします。
       選択したエンティティ毎 ：選択したエンティティ毎に設定した値がかかります。
       節点毎 ：全節点に入力した荷重値が設定されます。
       選択したエンティティの合計 ：選択したエンティティに設定した値が振分けられます。

    　　　

    • - 操作手順 -

      　　　
    1. 法線方向の加重を負荷する節点を選択します。複数の選択が可能です。
      2. 　　　
    2. 法線方向を参照するサーフェスを一つ選択します。
      3. 　　　
    3. 負荷する荷重値を入力入力します。
      4. 　　　
    4. 入力した荷重値の分配方法選択します。
      5. 　　　
    5. 必要に応じて他のパラメータを選択、入力します。
      6. 　　　
    6. 適用またはOKボタンをクリックします。
