グラウンドばね

グラウンドばね要素を作成する機能です。

指定したエンティティ上の節点に、グラウンドばねが定義されます。

接続

  • 名前

    登録される名前を入力します。

    • ばね

  • X剛性 - Z剛性, RX剛性 - RZ剛性

    ばね剛性を入力します。

  • 減衰係数(Nastran向け)

    減衰係数を入力します。

  • 応力係数(Nastran向け)

    応力係数を入力します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • - 操作手順 -

    1. メインウィンドウから節点を複数選択します。
    2. ばね剛性を入力します。
    3. 他のパラメータを設定します。
    4. 適用/OKボタンをクリックします。
