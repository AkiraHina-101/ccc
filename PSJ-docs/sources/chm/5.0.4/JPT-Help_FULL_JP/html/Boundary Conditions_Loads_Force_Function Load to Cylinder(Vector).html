力 | 円筒面に負荷(ベクトル)

選択したフェース、エッジまたは節点に正弦関数分布に基づいた力荷重を定義する際に、力をX,Y軸方向のベクトルで定義します。
また、CSVファイルにあらかじめ用意した複数のデータを、複数のフェースに対して一度に設定することが可能です。

　　

構造力

  • 名前

    力荷重条件の名前を入力します。

    • 　　

    正弦曲線 : y=a*sine(rad)

      正弦関数の設定をします。

  • 合計値

    力荷重合計値が表示されます。

  • X

    X方向の力を入力します。

  • Y

    Y方向の力を入力します。。

  • 入力単位系（力）

    力荷重の入力単位を指定します。

  • a

    正弦関数の係数aを定義します。

  • 荷重座標系

    荷重適用範囲の角度を決定する座標系を選択します。

  • 角度

    荷重適用範囲を指定した座標系XY平面におけるY軸からの角度を入力します。
    荷重適用範囲は角度0～PIとなり、0°＜角度＜90°の範囲で入力します。

  • 入力単位系（角度）

    角度の入力単位系を指定します。

  • 方向

    最大荷重方向に平行もしくは面直方向に与えます。

  • 分布方向

    奥行き方向にも分布を与えます。

  • ファイルから複数設定

    .csvファイルの読み込みから、奥行き方向にも分布を与えます。

    　　

    複数データ設定ダイアログ

  • 名前

    力荷重条件の名前を入力します。

  • データ

    下の表から選択したデータが表示されます。

  • 登録

    力荷重条件を作成します。

    • 　　

    オプション

    　　
  • 矢印方向
       マーカー表示の描画位置を設定をします。
       節点が始点：節点を始点として、マーカーを表示します。
       節点が終点：節点を終点として、マーカーを表示します。
    　　　

    • - 操作手順（単一設定） -

    1.  選択リストから、画面上から力荷重の対象となるフェース、またはフェースグループを選択します。(複数の選択が可能です)
    2.  荷重につける名前を入力します。
    3.  X, Yに各軸方向のベクトルを入力します。合計時が合計荷重となります。
    4.  正弦関数式のaの数値を入力します。
    5.  正弦関数の荷重適用範囲の座標系と角度を指定します。
    6.  必要に応じて奥行き方向の分布を分布方向から選択します。
    7.  必要に応じて矢印の表示方向を矢印方向から選択します。
    8.  適用またはOKボタンを押します。

    - 操作手順（複数設定） -

    1.  ファイルから複数設定ボタンをクリックします。複数データ設定ダイアログが開きます。
    2.  荷重データを記載したCSVファイルを読み込みます。CSVファイルには、X,Y,角度,方向(start/end)を１行毎に記述します。
      3. (CSVファイルの例）
      1000, -1000, 30, start ,
      500, 1000, 60, end ,
      300, 300, 30, start ,
      0, 600, 30, start ,
      100, 0, 45, end ,
      -500, 1000, 45, start,
    3.  読み込んだデータが表示されます。行をクリックすることで、設定するデータを選択します。
    4.  他のパラメータを設定します。ダイアログ利用中は、コマンドウィンドウで設定したパラメータは無視されます。
    5.  選択中のデータ内容が表示されます。メインウィンドウ上で設定対象のフェースを選択し、登録ボタンをクリックすることで、荷重が設定されます。
