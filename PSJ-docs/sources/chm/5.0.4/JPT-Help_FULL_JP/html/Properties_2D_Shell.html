2Dプロパティ | シェル

2Dプロパティ | シェルダイアログボックス

2次元シェル要素のプロパティデータを作成します。

　　
  • 名前

    プロパティの名前を指定します。

    　　　
    • 　　
  • プロパティID

    プロパティのIDを指定します。プロパティIDはモデル内で重複しないようにします。

    　　　
    • 　　
  • 色

    プロパティの色を指定します。

    　　　

    • シェル

    　　
  • 膜挙動の材料

    膜挙動に対する材料特性を選択します。

    　　　
    • 　　
  • 曲げ挙動の材料

    曲げ挙動に対する材料特性を選択します。

    　　　
    • 　　
  • 横せん断挙動の材料

    横せん断挙動に対する材料を選択します。

    　　　
    • 　　
  • 膜-曲げ連成挙動の材料

    膜-曲げ連成挙動に対する材料を選択します。

    　　　
    • 　　
  • 厚さ

    要素の板厚を入力します。

    　　　
    • 　　
  • 曲げ剛性

    曲げ剛性に対する断面2次モーメントの比率を入力します。

    　　　
    • 　　
  • 板厚比率

    横せん断剛性に対する厚さの比率を入力します。

    　　　
    • 　　
  • 非構造質量要素

    単位面積あたりの非構造質量を入力します。

    　　　
    • 　　
  • 応力積算距離1, 2

    参照面からの応力算出距離を入力します。

    　　　
    • 　　
  • 材料の方向基準

    材料座標系を選択します。

    　　　
    • 　　
  • 平板オフセット

    オフセット値を入力します。

    　　　

    • 積分点の格納

  • シェル積分点の数

    シェル要素の積分点数を指定します。

    　　

    • 要素の関連情報

  • 要素の関連情報

    選択した要素のプロパティ情報一覧が表示され、編集することができます。
    ※この機能は編集モードで使用する機能です。

    • 等価放射パワー(Nastran)

  • ERP 　　

    チェックボックスを選択して機能を有効にします。 　

  • パネルラベル名 　　

    パネルラベルの名前を入力します。 　

  • パネルラベルID 　　

    パネルラベルのIDを入力します。

    • Abaqus

  • 温度変化 　　

    温度変化値を入力します。(自然数のみ)

    入力単位系

  • 長さ

    長さの単位を選択します。

  • 質量

    質量の単位を選択します。


    • - 操作手順 -

      　　　
    1. 名前にプロパティの名前を入力します。
      2. 　　　
    2. プロパティIDにプロパティIDを入力します。
      3. 　　　
    3. 膜挙動の材料プルダウンメニューからすでに登録された材料を 選択します。
      曲げ、横せん断には膜挙動と同じ材料が自動的に設定されます が、上書き変更も可能です。
      4. 　　　
    4. 厚さに板厚を入力します。
      5. 　　　
    5. 必要に応じて他のパラメータも入力します。
      6. 　　　
    6. 適用またはOKボタンをクリックしてプロパティを作成します。
