ボルトメッシング

このコマンドではCADボルトに対しボルトを上下に分割、メッシュ作成およびADVC用の荷重境界条件を設定します。

※V4.0よりボルトモデリングコマンドが実行されたときに、作成されたボルト1本ごとにグループを作成します。
ボルトグループはBolt Connectionサブグループの下に置かれます。

ボルトメッシング

  • 名前

    作成する荷重境界条件名を入力します。

    • カット

  • 選択／オフセット／パーティションのみ／座標系

    ボルトを上下に分ける平面を定義します。詳細はボディカットコマンドを参照ください。

    • サーフェースメッシング

  • サイズ／曲面メッシング／メッシュのグラデーション／クリーンアップ

    メッシュ設定を定義します。詳細はサーフェースメッシュコマンドを参照ください。

    • プリテンション

  • 値／入力単位系／方向／ボルト固定長／座標系

    荷重条件を定義します。詳細はプリテンションコマンドを参照ください。

    「パーティションのみ」チェックボックスにチェックを入れた場合、Abaqusのプリテンションを断面位置、法線方向の設定で作成します。


    • - 機能実行例 -

    - 操作手順 -

    1. CADボルトのパーツを選択します。
    2. 名前欄にボルトの荷重条件につける頭文字を入力します。
    3. ボルト分割位置を定義します。
    4. ボルトのメッシュ設定を定義します。
    5. ボルトの荷重条件設定を定義します。
    6.  適用/OKボタンをクリックします。
