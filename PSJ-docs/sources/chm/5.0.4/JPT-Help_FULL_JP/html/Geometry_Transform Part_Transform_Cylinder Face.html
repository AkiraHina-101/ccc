円筒面

異なるパーツからそれぞれ選択された2つの円筒面が重なり合うように移動します。

操作

  • 新規作成

    •    移動後にパーツをコピーし、新規パーツとします。新規パーツの名称は、
          元パーツ名_POS
       となります。

  • LBCコピー

    •    新規パーツに既存パーツに付加した荷重境界条件もコピーします。

  • プロパティコピー

    •    新規パーツに既存パーツに付加したプロパティもコピーします。

  • リファレンス

    •    新規パーツに既存パーツに付加したリファレンスもコピーします。


    - 操作手順 -

    1.  パーツ移動後に新しいパーツを作成する場合には、新規作成をオンにします。
    2.  既存パーツの荷重拘束条件を新規パーツにコピーするにはLBCコピーをオンにします。
    3.  フェースボタンを押し、異なるパーツから円筒面を一つずつ選択します。
    4.  適用またはOKボタンを押します。
