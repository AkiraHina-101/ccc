インポートCAD TS3D

CADデータをJupiterに読み込みます。新しいインポートCAD機能の試用版として提供されます。
*以後のバージョンで機能変更もしくは廃止される可能性があります。

ファイルパス

   CADデータファイルを検索し、選択します。

テッセレーションレベル

   CADデータをインポートする際のパラメーターを設定します。

  • 中間

       読み込んだCADモデルのフェースを構成する要素(ファセット)が、中密度になるように分割数を調整します。

  • 密

       読み込んだCADモデルのフェースを構成する要素(ファセット)が、高密度になるように分割数を調整します。

  • 超高密

       読み込んだCADモデルのフェースを構成する要素(ファセット)が、超高密度になるように分割数を調整します。

  • Tri要素エッジ最大長さ

       有効にした場合、 CADモデルのフェースを構成する三角形1次要素の最大要素エッジの長さを指定します。単位はmmです。

  • 自動ステッチトレランス

       有効にした場合、自動ステッチのトレランス値を設定します。単位はmmです。

    - 操作手順 -

    1.  CADデータファイルを選択します。
    2.  必要に応じてテッセレーションレベルの設定を変更します。
    3.  適用/OKボタンをクリックします。
