ブッシュ | 2 節点

選択した2つの節点にブッシュ要素（一般化ばね‐ダンパー）要素を作成します。

接続

　　
  • 名前

    • 作成するブッシュ要素名を設定します。

    ブッシュ

    　　
  • グラウンド

    • チェックをすると片端が接地（バネ）として定義されます。

    　　
  • 方向付け基準

    • ブッシュ要素の方向付けの方法を選択します。

      　　
    • 方向ベクトル
      • 方向ベクトルによる指定 　　
    • 座標系
      • 座標系による指定
    　　
  • 座標系

    • 座標系による指定を選択した場合に、使用する既存の座標系をリストから選択します。

    　　
  • 方向ベクトル

    • 方向ベクトルによる指定を選択した場合に、方向ベクトルをX,Y,Zの順にコンマ区切りで入力します。

    　　
  • 剛性1～6

    • 各自由度の剛性値入力します。
    剛性が非線形の場合は、各自由度ごとに定義されたテーブルを選択します。

    　　
  • 入力単位系

    • 剛性値入力で使用する単位系を選択できます。

    オプション(Nastran)

    　　
  • 減衰係数 1～6

    • 各自由度の減衰値を入力します。
    減衰値が非線形の場合は、各自由度ごとに定義されたテーブルを選択します。

    　　
  • 入力単位系

    • 減衰値入力で使用する単位系を選択できます。

    　　
  • 減衰係数 1～6

    • 各自由度の構造減衰値入力します。
    構造減衰値が非線形の場合は、各自由度ごとに定義されたテーブルを選択します。

    　　
  • 入力単位系

    • 構造減衰値入力で使用する単位系を選択できます。

    　　
  • 応力リカバリ(並進)

    • 並進成分における応力リカバリ係数を入力します。

    　　
  • 応力リカバリ(回転)

    • 回転成分における応力リカバリ係数を入力します。

    　　
  • ひずみリカバリ(並進)

    • 並進成分におけるひずみリカバリ係数を入力します。

    　　
  • ひずみリカバリ(回転)

    • 回転成分におけるひずみリカバリ係数を入力します。

    - 操作手順 -

      　　　
    1. 選択リストのマスターボタンがアクティブであるのを確認し、 ブッシュ要素の一端の節点選択します。
      2. 　　　
    2. 選択リストがスレーブボタンに切り替わったのを確認し、 ブッシュ要素の他端の節点選択します。
      3. 　　　 　　　
    3. 方向ベクトルの指定方法を方向付け基準から選択します。 指定方法に従って方向ベクトルを入力します。
      4. 　　　
    4. それそれの入力欄に剛性値、減衰値、構造減衰値、リカバリ係数を入力します。
      5. 　　　
    5. 適用またはOKボタンを押すとブッシュ要素が節点間に作成されます。
