TS SS (SunShine) | 定常熱伝導解析(SOL 153)

SunShineの定常伝熱解析(SOL153)用入力データを出力します。

ジョブオプション

　　
  • ジョブ

    ジョブ名: ジョブ名を入力します。ツリーにこの名称で出力設定が保存されます。
    ジョブの説明: ジョブの説明を入力します。

    　　　
    • 　　　
  • ソルバーオプション

    方法: 解法を選択します。
        直接法: 直接法
        反復法: 反復法
        イプシロン値: 反復法計算許容誤差
    実行オプション:
        使用CPUコア数: 使用CPUコア数
        メモリー（GB）: 割り当てメモリー量
    Run SunShine: ローカルマシン上のSunShineを実行します。

    　　　
    • 　　　 　　　
  • 実行コントロールオプション

    GEOMCHECK, NONE: 形状チェックオプションを無効にします。
    直接テキスト入力: エグゼクティブコントロールセクションにデータカードを直接入力します。

    　　　
    • 　　　
  • ケースコントロールオプション

    ECHO: バルクデータのエコー出力を定義します。
        NONE: 出力なし
        SORT: ソート出力
        UNSORT: 未ソート出力
        BOTH: ソートおよび未ソートの両方出力
    TITLE: プリント出力時のタイトルを定義します。
    直接テキスト入力: ケースコントロールセクションにデータカードを直接入力します。

    　　　
    • 　　　
  • バルクデータオプション

    出力タイプ: 出力対象を指定します。
        モデル: 一つのファイルに出力
        パーツ毎: パーツ毎にファイルを分けて出力
        選択したパーツ: 選択されたパーツのみ出力
    グリッドフォーマットタイプ: GRIDカードの出力フォーマットを変更します。
        1回: スモールフィールドフォーマット出力
        ダブル: ラージフィールドフォーマット出力
        シングル浮動小数点: 指数不使用のスモールフィールドフォーマット出力
    浮遊節点を削除: データ出力時に浮遊節点を削除します。
    継続行マーク +: データ出力時に継続ポインタ+を出力します。
    バルクデータを含める: バルクデータファイルを挿入します。
    直接テキスト入力: バルクデータセクションにデータカードを直接入力します。

    　　　

    • 荷重 / 境界条件


    　　　
  • ベース

    サブケース指定の上に定義する解析全体に作用する境界条件を定義します。
    各境界条件で使用する境界条件ケースを指定します。デフォルトには全ての境界条件が含まれます。

    LOAD: 熱荷重ケースを指定します。
    SPC: 温度拘束ケースを指定します。
    MPC: 多点温度拘束ケースを指定します。
    初期温度: 初期温度ケースを指定します。

    　　　
    • 　　　
  • Thermal-Structureal Coupling

    熱構造連成解析。
    現在まだサポートしておりません。

    　　　
    • 　　　 　　　

    出力要求


    　　　
  • 結果タイプ

    出力要求を指定します。
        PLOT: op2出力
        PRINT: f06出力
        PLOT&PRINT: op2およびf06出力
        ブランク: 未出力

    温度: 温度出力要求を指定します。
    FLUX: 温度勾配および熱流束出力要求を指定します。

    　　　
    • 　　　
  • 結果に出力するグループ(SET)の選択

    結果出力する範囲を要素、節点グループ(セット)を指定して制限します。
        すべて: 全要素、全節点に対して出力
        グループ: 指定グループ内の要素、節点に対して出力

    温度: 温度出力要求に対して出力範囲を指定します。
    FLUX: 温度勾配および熱流束出力要求に対して出力範囲を指定します。

    　　　

    • パラメーター


    　　　
  • パラメーター

    パラメータを定義します。

    POST: ポスト処理用結果ファイルの出力タイプを指定します。
        -1: op2(Patran向け)出力
    OGEOM: OP2への形状出力を制御します。
        YES: 形状出力あり
        NO: 形状出力なし
    AUTOSPC: 剛性特異性の自動拘束を制御します。
        YES: 自動拘束
        NO: 自動拘束なし
    GRDPNT: 重量情報出力を制御します。
    WTMASS: 質量補正係数定義します。
    K6ROT: シェル要素法線回転剛性に対する付加係数を定義します。
    MAXRATIO: マトリクス擬似特異判定比率を定義します。
    BAILOUT: 擬似特異性に対する実行を制御します。
        0: 継続実行
        -1: 終了
    PRGPST: 特異性サマリーテーブルのプリント出力を制御します。
        YES: 出力あり
        NO: 出力なし

    　　　
    • 　 　　　

    増分設定(NLPARM)


    　　　
  • 増分設定(NLPARM)

    増分設定をします。

    増分数(NINC): 解析に用いる増分数を指定します。
    剛性評価法(KMETHOD): 剛性評価法を選択します(Version4.1では無効）。
    AUTOSPC: 剛性特異性の自動拘束を制御します。
        YES: 自動拘束
        NO: 自動拘束なし
    最大反復数(MAXITER): 収束繰り返し計算最大回数
    温度: 温度収束閾値を設定します。
    荷重: 荷重収束閾値を設定します。
    仕事量: 仕事収束閾値を設定します。

    　　　
    • 　　

    その他の設定



  • ダミープロパティ

    ダミープロパティの設定を行います。

    自動割り当て: チェックを入れると、プロパティが割り当てられていないパーツにダミープロパティを自動で割り当てます。
    出力ジオメトリーID: チェックを入れると、フェースID、エッジID、パートIDなどのエンティティIDが出力されます。
    材料: ダミープロパティを割り当てるパーツの材料を指定します。
            材料コマンドのユーザーデータベースに登録済の材料が選択可能です。ユーザーデータベースに材料未登録の場合、登録済でもブランクを選択した場合はダミー材料を割り当てます。
            ダミー材料の場合、材料特性値は書かれない状態で出力されます。


    • - 操作手順 -

      　　　
    1. 出力要求に関しては追加、変更する場合は出力要求で変更した後、適用(OK)ボタンをクリックして、入力データファイルを出力します。
