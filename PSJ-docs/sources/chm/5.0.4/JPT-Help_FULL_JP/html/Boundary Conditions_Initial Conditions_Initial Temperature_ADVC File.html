初期温度 | ADVCファイル

Adventure ClusterソルバーのFormat2形式で出力された温度結果を読み込み、初期温度として定義します。
※伝熱解析モデルと構造解析モデルは一致している必要があります。
また、ソルバーはAdventure Clusterにのみ対応しております。

熱

  • 名前

    初期温度の名前を設定します。

    値

    　　　
  • ブラウズ

    温度結果ファイルを検索し選択します。

    　　　
    • 　　
  • 入力単位系

    入力単位系を指定します。

    　　　

    • - 操作手順 -

      　　　
    1. 初期温度を設定するパーツを選択します。複数の選択が可能です。
      2. 　　　
    2. ブラウズボタンを押して、温度荷重ファイルを検索し、選択します。
      3. 　　　
    3. 必要に応じて入力単位を変更します。
      4. 　　　
    4. 適用またはOKボタンをクリックします。
