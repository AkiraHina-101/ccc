接続 | バー要素（閾値）

一対一（マスター：スレーブ）のRbar（剛体要素）を作成する機能です。
本機能では、全独立自由度が片側の節点にあるケースのみをサポートします。

指定された範囲内の選択された節点間に自動でRbarが定義されます。 節点IDの若い方がマスターとして定義されます。

接続

  • 名前

    登録される名前を入力します。

    • 検索範囲

  • トレランス

    接続先の検索範囲を入力します。

    • マスター自由度

  • UX - RZ

    マスターで選択された節点に、独立自由度の全成分が指定されています。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • - 操作手順 -

    1. 節点間距離トレランスを設定します。
    2. メインウィンドウから節点を複数選択します。
    3. パラメータを設定します。
    4. 適用/OKボタンをクリックします。
