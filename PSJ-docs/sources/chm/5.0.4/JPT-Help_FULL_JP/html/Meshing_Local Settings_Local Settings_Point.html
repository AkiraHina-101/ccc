任意点

サーフェースメッシュ作成時に、指定した位置に節点が作成されるように、固定節点位置（ハードポイント）設定を行います。

メッシュパラメーター

  • 名前

    メッシュコントロール名を設定します。

    メッシュサイズ

  • メッシュサイズ

    固定節点位置（ハードポイント）周りの要素サイズを設定します。

  • 平均

    要素の平均サイズを設定します。

  • 最小(<=0.7*平均)

    要素の最小サイズを設定します。

  • 最大(>=1.4*平均)

    要素の最大サイズを設定します。

    • ハードポイント

    節点の座標値及びメッシング後の節点IDの指定を行います。

    • CSV読み込み

      テーブル内にCSVファイルを読み込みます。CSVファイルのフォーマットは、X,Y,Zです。

    • 追加

      テーブルに行を追加します。

    • 削除

      選択行を削除します。

    • プレビュー

      ハードポイントの設定位置のプレビューを表示します。

    • リセット

      ハードポイントの設定位置のプレビューをリセットします。

      • - 操作手順（メインビュー指定） -

      1. 節点作成位置を任意点/エッジ上任意点選択で指定します。
      2. 適用/OKボタンをクリックします。

      - 操作手順（CSVファイル指定） -

      1. CSV読み込みボタンをクリックして表示されるダイアログ上でCSVファイルを指定し、「開く」でCSVファイルの内容をテーブルに読み込みます。
      2. ハードポイントを作成するフェースあるいはパーツを選択します。
      3. プレビューボタンをクリックして、ハードポイント作成位置を確認します。
      4. 適用/OKボタンをクリックします。
