Nastran BDF

Nastran解析ファイル（.bdf/.dat/.nas）を読み込みます。

※JupiterV3.0以前もしくはTSV-Preよりエクスポートした、Geometry BDFファイル（.bdf）の読み込みには、インポートCAD＞Technostar Geometryをご利用ください。

メッシュデータ（2D/3D要素）からの形状データ作成は、下記手順で行われます。
  1. パーツの表面の要素面を検索もしくは作成します。
  2. 要素面を面角度以下で分割して、各フェースをい作成します。
  3. フェースの端をエッジとし、エッジ角度以下で分割して、各エッジを作成します。

インポートタイプ

  • 標準Nastran出力

    •    BDFのモデル形状、境界条件を読み込み、１D/2D/3D要素毎にパーツを作成します。元データの材料、特性は維持されません。

  • Nastran BDFプロパティでインポート

    •    BDFのモデル形状、境界条件、材料プロパティを読み込み、プロパティ毎にパーツを作成します。

    • 1D-エッジ, 2D-フェース, 3D-パーツ

      • 2D及び3Dのプロパティ毎にパーツを作成します。1Dのプロパティは、パーツに所属するエッジ に割り当てられます。

    • 1D2D3D-フェース

      • 全てのプロパティ毎にパーツを作成します。

    角度

  • 面角度

    •    フェース分割を判定するための、トレランス角度です。検索したパーツ表面の要素面を、指定した面角度以下で分割します。

  • エッジ角度

    •    エッジ分割を判定するための、トレランス角度です。フェースの端をエッジとして、指定したエッジ角度以下でエッジを分割します。

    コメント読込

  • Jupiterコメントを読む

    •    Jupiterのコメント内のパーツ分割を参照し、コメント内の名称を使用して各パーツ、プロパティ、材料を作成します。

    - 操作手順 -

    1.  コマンドを起動し、各オプションを指定してOKボタンをクリックします。
    2.  「ファイルを開く」ダイアログが表示されますので、読み込みたいデータを選択して「開く」ボタンをクリックします。
