オフセットライン

フェースを構成するエッジのオフセットを作成します。

オプション

  • 方法

    •    オフセットラインを指定する方法を選択します。

    • 両側 : 選択エッジの両側にオフセットラインを作成します。
    • 片側 : 選択エッジの片側にのみオフセットラインを作成します。
      •
  • 方向切替ボタン

    •    方法で片側を指定した場合に、エッジを作成する方向を反対側に切り替えます。

  • 自動プレビュー表示

    •    チェックすると、選択エッジ・フェース上に、随時作成されるオフセットラインのプレビューを表示・表示更新を行います。

  • 面を分割

    •    フェースを分割します。

  • 延長

    •    オフセットされたエッジを、境界エッジまで延長します。

  • マージ

    •    オフセットされたエッジ同士が交差する場合に、交差部でエッジを接続します。

  • 自動要素コラプス

    •    オフセット後に作成される細かい要素をクリーンアップします。

    パラメーター

  • レイヤー作成方法

    •    オフセットエッジの作成方法を指定します。

    • 距離とレイヤー数 : オフセット距離間隔で、オフセットエッジ数のエッジが作成されます。
    • レイヤー幅の数列 : 入力した数列の数、入力数値の幅のエッジが作成されます。
      •
  • オフセット(距離）

    •    選択したエッジの移動距離を入力します。

  • レイヤー数

    •    一度に作成するエッジ数を入力します。

  • レイヤーオフセット

    •    選択したエッジの移動距離を、一度に作成するエッジ数ぶん入力します。


    - 操作手順（距離とレイヤー数） -

    1.  エッジまたはフェースボタンを押し、インプリント元になるエッジとインプリント対象のフェースを画面より選択します。エッジとフェースは複数選択が可能です。
    2.  必要に応じてオプションを設定します。
    3.  レイヤー作成方法として、距離とレイヤー数を指定します。
    4.  オフセット（距離）にエッジを移動する距離を入力します。
    5.  必要に応じてレイヤー数を変更します。
    6.  適用/OKボタンをクリックします。

    - 操作手順（レイヤー幅の数列） -

    1.  エッジまたはフェースボタンを押し、インプリント元になるエッジとインプリント対象のフェースを画面より選択します。エッジとフェースは複数選択が可能です。
    2.  必要に応じてオプションを設定します。
    3.  レイヤー作成方法として、レイヤー幅の数列を指定します。
    4.  レイヤーオフセット（距離）にエッジを移動する距離を数列で入力します。例：1,1,2
    5.  適用/OKボタンをクリックします。
