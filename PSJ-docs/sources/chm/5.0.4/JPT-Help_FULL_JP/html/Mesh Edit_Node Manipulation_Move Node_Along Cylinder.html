節点移動 | 円筒面に沿って

定義した仮想円筒上へ節点を移動します。

ポジション

  • 方向

    • 円筒軸方向指示方法を選択します。

       法線面：定義した円の法線方向

       2節点：節点指定による方向

       X/Y/Z/-X/-Y/-Z：座標系の軸方向

  • X/Y/Z

    •    方向ベクトルの成分を表示します。

  • 円の定義

    •    円定義の操作へ移行します。

  • 円中心X座標

    •    円中心X座標を入力します。

  • 円中心Y座標

    •    円中心Y座標を入力します。

  • 円中心Z座標

    •    円中心Z座標を入力します。

  • 半径

    •    円筒半径を入力します。

  • 高さ

    •    円筒高さを入力します。


    - 操作手順 -

    1.  円筒軸方向の指定方法を選択します。
    2.  2節点を選択した場合は、2節点ボタンを選択し方向を定義する2節点を選択します。
    3.  円の定義ボタンを選択します。
    4.  円を定義する3節点もしくは3節点を含むエッジを選択します。
    5.  円の中心座標を変更します。
    6.  円筒の高さ半径を変更します。
    7.  適用またはOKボタンを押します。
