Actranジョブ実行

Actranの計算を実行します。
JupiterからACTRAN計算をするためには，ACTRAN_PATH環境変数（例えば，c:\FFT）およびACTRAN_PRODUCTLINE環境変数（例えば，c:\FFT\Actran_11.2）が正しく設定されている必要があります。

ATCTRANジョブ

  • ジョブ名

       ジョブの名前を設定します。

  • ジョブの説明

       ジョブの説明を記載します。

    • ATCTRAN実行

  • ジョブタイプ

       解析タイプの指定。

    • Direct  : 基本解析
    • Green Analysis(Sequential)  : Green analysis(Sequential)解析
    • Green Analysis(Solution)  : Green analysis(Solution)解析
  • 無限空間タイプ

       無限境界のタイプ指定。

    • PML  : 吸音層を用いたモデル
    • IFEM  : 無限境界面を用いたモデル
  • 入力ファイル1のパス

       Edatファイルパスの入力。

  • Select input file

       EdatEdatファイルの指定。

  • Input File 2 path

       Edatファイルパスの入力。

  • Select input file

       Edatファイルの指定。

  • メモリ(MB)

       最大使用メモリ量指定（MB単位）。

  • No. of Threads

       スレッドの番号を指定。

    • - 操作手順 -

    1.  ジョブ名を指定します。
    2.  ジョブタイプを指定します。
    3.  無限空間タイプを指定します。
    4.  OKボタンをクリックして、入力データファイルを出力します。
