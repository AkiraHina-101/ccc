フェース位置揃え（フェースを平面化）

曲面やがたつきのあるフェースを平面化します。
平面化したいフェースを選択し、基準平面として3節点もしくは要素を選択することで、フェースが基準平面に合わせて平面化されます。

フェースを平面化

　　
  • タイプ

    基準平面の選択タイプを指定します。

      　　　
    • 3節点

      基準面として3節点を選択します。

      　　　
      • 　 　
    • 要素

      基準面として要素を選択します。

      　　　
    　

    • オプション

    　　
  • フェースをマージ

    平面化されたフェースをマージします。
    また、隣合うフェースが同じ法線方向のフェースであった場合、それらのフェースもマージされます。

    　　　

    • - 操作手順（基準平面が3節点の場合） -

    1. タイプ > 3節点を指定して、基準平面となる3節点を選択します。
    2. 平面化するフェースを選択します。
    3. 適用/OKボタンをクリックします。

    - 操作手順（基準平面が要素の場合） -

    1. タイプ > 要素を指定して、基準平面となる要素を選択します。
    2. 平面化するフェースを選択します。
    3. 適用/OKボタンをクリックします。
