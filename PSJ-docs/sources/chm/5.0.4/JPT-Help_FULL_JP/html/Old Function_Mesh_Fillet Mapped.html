フレットISOメッシュ

このコマンドではフィレットを抽出し、抽出したフィレットに設定値のISOメッシュ（マップドメッシュ）を作成します。

ステップ

  • 操作

       フィレット部分を抽出する方法を選びます。

       選択 ：フィレット部分を抽出します。
       マッピングされた形状 ：マップドメッシュを作成します。
       XML ：情報をXMLファイル形式で入力します。

        適用/OKボタンを押すと、ファイル入力ダイアログボックスが表示されます。

    • 選択

  • 最小フェース幅

       検索するフェース幅の最小値を指定します。

  • 最大フェース幅

       検索するフェース幅の最大値を指定します。

  • 最小曲率半径

       検索するフィレットの半径の最小値を指定します。

  • 最大曲率半径

       検索するフィレットの半径の最大値を指定します。

  • 最小角度

       検索するフィレットの角度の最小値を指定します。

  • 最大角度

       検索するフィレットの角度の最大値を指定します。

  • 凸面体

       凸面フィレットを検索します。

  • 凹面体

       凹面フィレットを検索します。


    • マップドメッシュ

  • 円周上の分割数

       フレット円周方向の分割数を設定します。

  • 軸の平均サイズ

       フレット軸方向の平均メッシュサイズを設定します。

  • エラートレランス

       トレランスを設定します。

    • - 操作手順 -

    1.  操作から”選択”を選び、対象となるパーツかフェース群を選択します。
    2.  検索するフィレットのフェース幅の最大値、最小値を入力します。
    3.  検索するフレットの曲率半径の最大値、最小値を入力します。
    4.  検索するフレットの角度の最大値、最小値を入力します。
    5.  検索するフレットが凸形状か凹形状か指定します。
    6.  適用ボタンをクリックすると、指定した範囲内のフィレットフェースが対象パーツから選択されます。
    7.  操作から”マッピングされた形状”を選びます。
    8.  作成するフレットメッシュの円周方向の分割数を入力します。
    9.  作成するフレットメッシュの軸方向の平均メッシュサイズを入力します。
    10.  メッシュ作成時のエラートレランスを入力します。
    11.  適用/OKボタンをクリックすると、選択されたフィレットフェースにISOメッシュ（マップドメッシュ）を作成します。
