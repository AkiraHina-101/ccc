節点移動 | 方向に沿って

選択したノードまたは浮動小数点を指定したオフセットベクトル位置に移動します。
方向ベクトルは、「要素エッジ」、「2 節点」、または「DX、DY、DZの直接入力」のいずれかによって定義されます。
方向ベクトルに沿ったノードの動きは、ベクトルマグニチュード、ユーザー入力、またはフェースまたは要素による目的地によって定義されます。

ベクトル方向

  • 2 節点

    2 節点または浮遊節点をクリックして選択し、方向ベクトルを定義します。

  • 要素エッジ

    要素のエッジをクリックして選択し、方向ベクトルを定義します。

  • DX, DY, DZ

    2 節点または要素エッジを選択すると、方向ベクトルのコンポーネントが自動的に表示されます。 フィールドは編集可能です。

  • 反対方向

    クリックして、選択したベクトルの方向を反転します。

    • パラメーター

  • 移動量

    「ベクトルの大きさを使用」で2 節点または要素エッジを選択すると、移動量が自動的に表示されます。 移動量は、「ユーザー入力」時には編集可能となります。

  • ベクトルの大きさを使用

    「ベクトルの大きさを使用」の場合、2 節点または要素のエッジを選択すると、移動量が自動的に表示されます。

  • ユーザー入力

    「ユーザー入力」の場合、移動量はユーザーが手動で入力します。

  • フェースまたは要素による目的地

    「フェースまたは要素による目的地」では、ノードの移動は、ユーザーがフェースまたは要素として選択した目的地によって定義されます。

    • - 操作手順 -

    1. 次のいずれかで移動する方向ベクトルを定義します。
      1. 2 節点ボタンをクリックして、2 節点を選択します。
      2. 要素エッジボタンをクリックして、要素エッジを選択します。
      3. DX、DY、DZに値を直接入力します。
    2. 選択したノードの動きを次のいずれかで定義します。
      1. ユーザーベクトルの大きさがオンの場合、2 節点または要素のエッジを選択すると、移動量が自動的に表示されます。
      2. ユーザー入力がオンの場合、移動量に直接値を入力します。
      3. フェースまたは要素による目的地がオンの場合、面または要素を選択すると、選択したノードがその面または要素を含むサーフェスに移動します。
    3. 移動する節点を選択します。（複数可）
    4. 適用/OKボタンをクリックします。
