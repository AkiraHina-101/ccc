アッセンブルウィンドウ

メインウィンドウに表示されている形状やメッシュモデルの構造がツリー形式で表示されます。サブツリーを持つCADを読み込んだ場合、サブツリーはサブアセンブリとして表示されます。

ツリービュー

アセンブリ・パーツの構造及び境界拘束条件・プロパティの設定状態をツリー形式で表示します。
境界条件やプロパティの設定は、モデル全体のサブツリーとして追加される他、設定したパーツのサブツリーとしても追加されます。
各ツリーアイテムをマウス左ボタンクリックすることでツリーアイテムがハイライトされます。ハイライトされたたアイテムの設定内容をプロパティビューに表示します。

V4.0より、ツリーアイテムが編集モードで編集可能な場合に、以下の操作が可能になりました。

  • アイテムをクリックし、ハイライトすることで、設定先のエンティティがメインウィンドウ上でプレビュー表示されるようになりました。
  • アイテムをダブルクリックすることで、アイテム作成時のコマンドウィンドウが、編集モードで開くようになりました。
  • コマンドダイアログが編集モードで起動している際、他のツリーアイテムをマウスクリックもしくは矢印キーを使用してハイライトすると、ハイライト先のアイテムのコマンドウィンドウ（編集モード）に切り替わるようになりました。

  • プロパティビュー

    • ツリービューでフォーカスしたツリーアイテムの色の変更や表示非表示、詳細が表示されます。

    • すべてのパーツフォーカス時 ：パーツ数・節点数・要素数・構成エンティティ数・ファイル情報（ファイルを作成したJupiterバージョン）など。FEM要素には、材料プロパティが設定された要素数が表示されます。Jupiter要素アイテムには、全ての要素数が表示されます。
    • パーツアイテムフォーカス時 ：ID・節点数・要素数・構成エンティティ数・メッシュサイズ情報など
    • 各境界条件アイテムフォーカス時 ：各境界条件の設定内容
    • 境界条件の設定内容を変更するには、ツリービューのアイテムを右クリックすることで表示されるショートカットメニューの“編集”から行ってください。

    • 表面
      色       ：フォーカスしたパーツの表面フェース・メッシュライン・エッジの色、パーツの透明度を変更します。
      表示/非表示 ：フォーカスしたパーツのフェース・メッシュライン・エッジの表示/非表示を切り替えます。
    • セクション
      色        ：断面の表面フェース・メッシュライン・エッジの色を変更します。
      表示/非表示　：断面の表示/非表示・キャッピング・断面エッジ・断面要素・メッシュラインの有効/無効を切り替えます。
      ※1 断面リボンのオプションが有効になっているときに適用できます。
      ※2 コンターはPostモード使用時のみ適用されます。
      ※3 断面表示モードでのソリッド要素色はこちらの設定が反映されます。
