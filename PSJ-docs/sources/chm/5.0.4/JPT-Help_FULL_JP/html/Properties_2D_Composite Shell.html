2Dプロパティ | 積層材

積層材要素特性を作成します。

プロパティ

  • 名前

    • プロパティの名前を指定します。

  • プロパティID

    • プロパティのIDを指定します。プロパティIDはモデル内で重複しないようにします。

  • 色

    • プロパティの色を指定します。

シェル

  • 積層材選択

    • あらかじめ作成した積層材を選択します。

  • 積層材作成

    • 積層複合材料を作成します。(作成手順は後述)

  • 底面までの距離

    • 参照平面から積層底面までの距離を入力します。

  • 非構造質量

    • 単位面積あたりの非構造質量を入力します。

  • 許容せん断応力

    • 接着材の許容せん断応力を入力します。

  • 破壊理論

    • リストから破壊則を選択します。

    • 選択なし：破壊評価をしない
    • HILL：Hill則
    • HOFF：Hoffman則
    • TSAI：Tsai-Wu則
    • STRN：最大ひずみ則

  • 参照温度

    • 参照温度を入力します。

  • 構造減衰

    • 減衰係数を入力します。

  • 積層オプション

    • 積層オプションを選択します。

    • 選択なし：全ての積層を定義し、計算に使用します。
    • SYM：積層の半分まで定義し、残りは対称とします。
    • MEM：全ての積層を定義しますが、面内のみ計算されます。
    • BEND：全ての積層を定義しますが、曲げのみ計算されます。
    • SMEAR：全ての積層を定義しますが、積層順は無視されます。
    • SMCORE：全ての積層を定義しますが、最終層で芯板特性を定義し、 それまでの層では面板特性を定義します。

  • 層の応力

    • 積層応力の出力を選択します。

    • NO
    • YES

  • 平板オフセット

    • 積層板のオフセット量を入力します。

  • 材料の方向基準

    • 材料軸の定義方法を選択します。

    • 角度：角度(度)で指定します。
    • 座標系：座標系で指定します。座標系のX軸が要素面に投影されます。

入力単位

  • 長さ

    • 長さの単位を選択します。

  • 質量

    • 質量の単位を選択します。

積層材作成

  • 複合材料（シェル）

    • 作成: 新規作成します。
    • 編集: 既存材料を編集します。
    • コピー: 既存材料をコピーします。
    • リネーム: 既存材料の名前を変更します。
    • 削除: 既存材料を削除します。
    • OK: 材料を更新してダイアログを閉じます。
  • 複合材料（シェル）編集

    • 名前: 積層材料名を作成します。
    • 説明: 積層材料について記載します。
    • 材料: 各積層の材料特性を選択します。
    • 厚さ: 各積層の厚さを入力します。
    • 角度: 要素材料軸と各積層の縦方向との角度を入力します。
    • 適用: 各積層情報を反映させます。
    • コピー: 既存の積層をコピーします。
    • 保存: 既存積層情報をcsvファイルに出力します。
    • 荷重: csvファイルから積層情報を読み込みます。

− 操作手順 −

  1. 名前にプロパティの名前を入力します。
  2. プロパティIDにIDを入力します。
  3. 積層材作成ボタンを押し、続けて作成ボタンを押します。
  4. 複合材料(シェル)編集ダイアログの層定義で既存の材料を選択後、その層の厚さ、材料方向角度を指定します。指定後適用ボタンを押して次の層定義に移ります。
  5. 全積層の定義が終了したらOKボタンを押し、積層材選択プルダウンメニューから作成した積層材を選択します。
  6. 必要に応じて他のパラメータも入力します。
  7. 該当のフェース、パーツを選択し、適用またはOKボタンをクリックしてプロパティを作成します。
