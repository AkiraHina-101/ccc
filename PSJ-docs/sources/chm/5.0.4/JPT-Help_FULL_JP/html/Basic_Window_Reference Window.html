リファレンスウィンドウ

CADモデルをメッシュ化した後に、オリジナルCADモデルの構造をツリー形式で表示します。


ツリーコントロールメニュー

ツリーの表示を調節します。

アイコン名称説明
選択解除選択されているツリーアイテムをすべて選択解除します。
すべて開くサブツリーをすべて展開します。
すべて閉じるサブツリーをすべて閉じます。
ソート順切り替えパーツの順番を名前順またはID順に並び替えます。
メッシュ/リファレンスを表示メッシュおよびリファレンスを重ねて表示します。現在表示されているメッシュもしくはリファレンスについて、メッシュおよびリファレンスパーツを重ねて表示します 。
メッシュを表示メッシュ/リファレンス同時表示やリファレンス表示から通常のメッシュパーツ表示に戻します。現在表示されているメッシュもしくはリファレンスのメッシュパーツのみ表示します。
リファレンスを表示表示されているメッシュパーツのリファレンスのみ表示します。現在表示されているメッシュもしくはリファレンスの最も古いリファレンスパーツ(通常はCAD)のみ表示します。

ツリービュー

CADパーツの構造をツリー形式で表示します。


  • ショートカットメニュー

    • ツリーアイテムをマウス右クリックで選択することで表示されるメニューから、各コマンドを使用可能です。

    メニュー内容
    選択ハイライトしたアイテム下のパーツのリファレンスを選択状態にします。
    非表示ハイライトしたアイテム下のパーツのリファレンスを非表示にします。
    選択のみ非表示ハイライトしたパーツアイテムのリファレンスのみを非表示にし、他のパーツのリファレンスを全て表示します。
    表示ハイライトしたパーツアイテムのリファレンスを表示します。
    選択のみ表示ハイライトしたパーツアイテム以外のパーツのリファレンスを非表示にします。
    すべて表示モデル内のパーツのリファレンスを全て表示します。
    すべて非表示モデル内のパーツのリファレンスを全て非表示にします。
    表示/非表示を反転モデル内のパーツのリファレンスの表示/非表示状態を反転させます。

    ショートカットキー一覧

    アッセンブルウィンドウにフォーカスがある場合には、下記ショートカットキーを利用可能です。
  • ビュー操作
    • ショートカットキー動作
    上下矢印キーツリーアイテムのハイライトを移動します。
    F選択パーツを画面にフィットします。パーツ未選択の場合、モデル全体を画面にフィットさせます。
    E選択エンティティを選択解除します。
    Ctrl＋マウス左クリック複数のツリーアイテムをハイライトします。
    Shift＋マウス左クリック複数の連続したツリーアイテムをハイライトします。
