表面熱流束

選択されたフェースまたは要素面に熱流束を定義します。

熱

　　
  • 名前

    表面熱流束荷重名を設定します。

    値

    　　　
    • 　　
  • 表面熱流束

    表面熱流束値を入力します。

    　　　
    • 　　
  • 入力単位系

    入力単位を指定します。

    　　　
    • 　　

    テーブル

  • テーブル選択

       フィールドデータで選択したテーブルを選択します。

    • 　　　

    - 操作手順 -

      　　　
    1. 表面熱流束荷重を負荷するフェースまたは要素面を選択します。
      複数の選択が可能です。
      2. 　　　
    2. 表面流速に集中熱流束値を入力します。
      3. 　　　
    3. 必要に応じてその他のパラメータを変更します。
      4. 　　　
    4. 適用またはOKボタンをクリックします。
