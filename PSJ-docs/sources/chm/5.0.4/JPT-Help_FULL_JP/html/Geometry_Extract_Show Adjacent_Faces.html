フェース

探索を開始するフェースと境界（フェースや角度）を設定することで、指定した境界内のフェースを纏めて選択します。
この機能により、エンジン部品のウォータジャケットの取り出しや型部品の表面の取り出しなどを容易に行う事が出来ます。

検索

  • すべて

    チェックをすると、探索範囲が全フェースになります。チェックを解除すると、レイヤー数のレイヤ数が探索範囲になります。

  • レイヤー数

    探索範囲となるレイヤ数を入力します。

    • 停止

  • ストップフェースを含める

    チェックをすると、境界面も選択します。

  • 指定した角度で停止

    境界となる角度を入力します。

    • プレビュー

  • プレビュー

    選択されるフェースを確認できます。

  • リセット

    プレビューボタンで確認したフェースをリセットします。

    • - 操作手順 -

    1. 開始フェースを選択します。（離れた場所の複数のフェースを選択できます）
    2. 停止フェースを選択します。（角度だけを境界とする場合には、必要ありません）
    3. 探索範囲を設定します。
    4. 境界を設定します。
    5. プレビュー/リセットで選択範囲を確認します。
    6. 適用/OKボタンをクリックします。
    7. グループ作成を行うことで、抽出したフェースに間違いなどがあった場合の変更作業が容易になります。
