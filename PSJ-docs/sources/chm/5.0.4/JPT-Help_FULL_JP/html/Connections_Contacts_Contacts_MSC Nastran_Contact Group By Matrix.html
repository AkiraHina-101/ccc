接触 | グループマトリックス | MSC Nastran

指定したグループ間でMSC Nastranの接触設定を行います。
あらかじめマスターフェースとスレーブフェースとなるグループを作成し、マトリクステーブル上に接触ペアを定義しておきます。

コンタクト

　　　
  • 名前

    コンタクトペア名を入力します。

    　　
    • 　　　
  • アルゴリズム

    コンタクト設定の対象となるエンティティを選択します。
        フェース-フェース: フェースとフェースの接触。

    　　　
    • 　　　
  • ペアの選択

    既存のグループがマトリクス状に表示されます。
    コンタクトペアは、ペアとなるグループの位置にあるセルをチェックすることで定義されます。
        スレーブ/マスターの入替： セルを選択したら、そのセルを左列のグループのマスターにするかスレーブにするかを指定する。
        すべてオン： すべてのコンタクトペアを検討します。
        すべてオフ： すべてのコンタクトペアを解除します。

    　　　
    • 　　
  • タイプ

    コンタクト定義の動作タイプを選択します。
        General： スライディングコンタクト。
        Tied： タイドコンタクト。
        Tied & Maintain Gap： タイドとギャップを維持のコンタクト。
        Tied & Full moment： タイド＆フルモーメントコンタクト。
        Tied & Full moment & Maintain Gap： タイド＆フルモーメント＆マインティン・ギャップのコンタクト。

    　　　

    • コンタクトプロパティ | General

    　　　
  • 接触距離範囲(ERROR)

    ノードがボディに接触しているとみなされる距離。

    　　　
    • 　　　
  • 解離力 (FNTOL)

    ノードがボディから解離する際にかかる解離力または解離応力。

    　　　
    • 　　　
  • 摩擦係数（FRIC）

    摩擦係数の指定。

    　　　
    • 　　　
  • 干渉閉鎖距離(CINTERF)

    接触サーフェスに垂直な干渉閉鎖量。

    　　　
    • 　　　
  • 探索順序(ISEARCH)

    変形体接触ボディにおける接触探索順序オプション。
        Double : （両方向探索）探索順序は、BCBODOYのIDが小さいIDから大きいIDとする。接触が検出されなかった場合は逆の順序で探索する。
        Slave to Master : （一方向探索）探索順序は、スレーブからマスターへ。
        Program decision : （一方向探索）プログラムが探索順序を判断する。

    　　　
    • 　　　
  • 節点の座標修正(ICOORD)

    節点座標の修正オプション
        None : 座標の修正は行われない。
        Modify position : 無応力初期接触状態を得られるように変形体と接触する節点座標を修正する。
        Delay sliding : 変形体の鋭角部における接線方向の許容誤差を拡大させて、接触される側のセグメントの滑り出しを遅らせる。
        Both effect : Modify positionとDelay slidingの両方を有効化する。

    　　　
    • 　　　
  • 摩擦応力の限度(FRLIM)

    摩擦応力の限界。この項目は、摩擦タイプ6（バイリニアモデルを用いたクーロン摩擦）にのみ使用されます。

    　　　
    • 　　　
  • 接触許容量のバイアス(BIAS)

    接触許容値のバイアス係数。ブランク以外の入力は、BCPARAで入力されたBIASを上書きします。

    　　　
    • 　　　
  • 接触条件のチェック(ISTYP)

    接触条件のチェック。変形体のみ有効。
        Double Side : 対称貫通、両面接触。
        Optimized : 接触拘束式の自動最適化を行う両面接触。

    　　　
    • 　　　
  • シェル要素面(スレーブ)

    シェル要素のフェース（スレーブ）には以下のオプションがあります。
        Top&Btm Thk. offset : 上面と下面の両方がコンタクトの説明に含まれ、厚みのオフセットも含まれます。
        Btm w/ Thk. offset : コンタクトの説明には、底面のみが表示され、厚みのオフセットは含まれます。
        Btm w/o Thk. offset : シェルの厚さは無視され、底面のみがコンタクトの記述になります。
        Top w/ Thk. offset : コンタクトの説明にはトップフェースのみが表示され、厚みのオフセットは含まれます。
        Top w/o Thk. offset : シェルの厚さは無視され、上面のみがコンタクトの記述になります。
        Top&Btm w/o Thk. offset : 上面と下面の両方が接触の記述になり、シェルの厚さは無視されます。

    　　　
    • 　　　
  • 梁・シェル要素エッジ(スレーブ)

    梁・シェル要素エッジ(スレーブ)には以下のオプションがあります。
        Beam/Bar Edge only : ビーム/バーのエッジのみがコンタクトの記述に含まれます。
        Free&Hard Edge only : 自由端とハードシェル端のみがコンタクトの説明に含まれます。
        Both : Beam/Bar Edge　と　Free&Hard Edge　の　両方がコンタクトの記述に含まれます。

    　　　
    • 　　　
  • シェル要素面(マスター)

    シェル要素面(マスター)には以下のオプションがあります。
        Top&Btm Thk. offset : 上面と下面の両方がコンタクトの説明に含まれ、厚みのオフセットも含まれます。
        Btm w/ Thk. offset : コンタクトの説明には、底面のみが表示され、厚みのオフセットは含まれます。

        Top&Btm w/o Thk. offset : 上面と下面の両方が接触の記述になり、シェルの厚さは無視されます。

    梁・シェル要素エッジ(マスター)には以下のオプションがあります。
        Beam/Bar Edge only : ビーム/バーのエッジのみがコンタクトの記述に含まれます。

        Both : Beam/Bar Edge　と　Free&Hard Edge　の　両方がコンタクトの説明に含まれています。

    　　　

    • コンタクトプロパティ | Tied / Tied & Maintain Gap / Tied & Full moment / Tied & Full moment & Maintain Gap

    　　　
  • 接触距離範囲(RROR)

    ノードがボディに接触しているとみなされる距離。

    　　　
    • 　　　
  • 干渉閉鎖距離(CINTERF)

    干渉閉鎖量、接触面の垂直方向。

    　　　
    • 　　　
  • 探索順序(ISEARCH)

    変形可能な接触体の場合、スレーブからマスター、またはマスターからスレーブへの接触検索順序のオプション。
        Double : 検索順序は、BCBODOYのIDが小さいものから大きいものへと順に並んでいます。
        Slave to Master : 検索順序は、スレーブからマスターへ。
        Program decision : どのような検索順序にするかは、プログラムに任せてください。

    　　　
    • 　　　
  • 節点の座標修正(ICOORD)

    座標の修正します。
        None : 座標の修正しません。
        Modify position : 変形体と接触する節点の座標を修正して，応力のない初期接触が得られるようにします。．
        Delay sliding : 変形体の鋭角部分の接線誤差の許容範囲を拡大し、接触したセグメントからの滑り落ちを遅らせます。
        Both effect : Modify position　と　Delay sliding　の両方をアクティブにします。

    　　　
    • 　　　
  • 接触条件のチェック(ISTYP)

    接触条件の確認。変形可能なボディの場合
        Double Side : 対称的なペネトレーション、両面のコンタクト。
        Optimized : 接触拘束式の自動最適化による両面接触。

    - 操作手順 -

      　　　
    1.  あらかじめマスターフェース、スレーブフェース、要素フェースのグループを作っておきます。
      2. 　　　
    2.  [ペアの選択] グループ間のセルをチェックして接点ペアとし、「スレーブ/マスターの入替」ボタンで左列グループのマスター／スレーブを定義します。
      3. 　　　
    3.  必要に応じてコンタクトペアの詳細設定を行い、「適用」または「OK」ボタンをクリックしてコンタクトペアを定義します。
