ローカル座標系[回転]

画面から選択した座標系を指定の角度で回転します。

　　

座標系

  • タイプ

       座標系のタイプを選択します。

    • 直交 : 直交座標系を選択します。
    • 円筒 : 円筒座標系を選択します。
    • 球 : 球座標系を選択します。

  • 名前

       作成する座標系の名前を入力します。

    • 参照座標系

  • 座標系

       全体座標系または既存のLocal座標系を選択します。

    • 回転

  • RX/RY/RZ

       参照座標系のX/Y/Z軸周りの角度を入力します。

  • 新規作成

       座標系の新規作成を選択します。


    • - 操作手順 -

    1.  タイプから座標系の種類を選択します。
    2.  名前に作成する座標系の名前を入力します。
    3.  座標系から回転方向の参照座標系を選択します。
    4.  回転に参照する座標系を一つ選択します。
    5.  回転にX、Y、Z軸周りの角度をTX、TY、TZにそれぞれ入力します。
    6.  回転後に新規の座標系を作成するときは、新規作成をチェックします。
    7.  適用またはOKボタンを押します。
