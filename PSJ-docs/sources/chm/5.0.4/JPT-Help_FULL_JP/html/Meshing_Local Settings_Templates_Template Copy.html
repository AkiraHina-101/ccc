テンプレートのコピー

ローカル設定を、形状が同じエンティティ及びトポロジーが同じエンティティへコピーします。

設定のコピー

  • 方法

     コピー方法を指定します。

    • 形状 : 形状を基にコピーします。

    • トポロジー : トポロジーを基にコピーします。
      •
  • サブエンティティを含める

     参照元のエンティティに含まれる全てのローカル設定をコピーします。

  • トレランス

     形状誤差のトレランスを設定します。

    • - 操作手順 -

    1.  選択リストでマスターボタンを選択します。
    2.  ローカル設定の参照元のフェースを選択します。
    3.  選択リストでスレーブボタンを選択します。
    4.  コピー先のフェースを選択します。
    5.  適用/OKボタンをクリックします。
