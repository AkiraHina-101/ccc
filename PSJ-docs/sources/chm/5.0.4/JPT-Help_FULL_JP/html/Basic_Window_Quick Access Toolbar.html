クイックアクセスツールバー

任意のコマンドを配置し、使用することが可能です。


デフォルト設定

アイコン名称説明
新規作成新規ドキュメントを作成します。
開く既存の.jtdbドキュメントを開きます。
保存アクティブのドキュメントを.jtdbドキュメントとして保存します。
元に戻すアイコンをクリックすると、実行した操作を取り消し、ひとつ前の状態に戻します。アイコン右側の三角形アイコン をクリックすると、これまでに実行した操作の一覧が表示されますので、複数の操作を戻すことができます。
やり直しアイコンをクリックすると、取り消した操作を再実行します。アイコン右側の三角形アイコン をクリックすると、これまでに取り消した操作の一覧が表示されますので、複数の操作を再実行できます。
オプションクイックアクセスツールバーをカスタマイズメニューを表示します。

クイックアクセスツールバーをカスタマイズ

・アイコン表示のオン/オフ
クイックアクセスツールバーに登録中のコマンドの表示／非表示を切り替えます。

・他のコマンド
クイックアクセスツールバーに任意のコマンドを登録します。クイックアクセスツールバーのカスタマイズダイアログを表示します。

・リボンの下側に表示
クイックアクセスツールバーを、タブメニューの下側に表示します。

・リボンを最小化
タブメニューを最小化します。
