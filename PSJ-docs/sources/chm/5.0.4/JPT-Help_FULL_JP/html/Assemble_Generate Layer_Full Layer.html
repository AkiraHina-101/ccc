パーツ レイヤー

パーツの全表面メッシュを内側にオフセットした、レイヤ（PRISM6のパーツ）を作成します。

本機能により、元のパーツは、レイヤパーツと内部パーツに分かれます。
本機能はレイヤがPRISM6で内部がTet4のメッシュモデリングのみに対応しております。そのため、以下の条件がございます。

    A. Tri3で作られた表面メッシュパーツに対して有効な機能です。メッシュエラーがある場合は正常に動作致しませんので、予め確認と修正をお願い致します。
    B. 内部パーツはTet4でソリッドメッシングを行って頂きます。

パラメーター

  • 操作

    操作の種類を切り替えます。

    • レイヤー作成

      レイヤを作成します。

  • レイヤー幅

    レイヤの深さを入力します。

  • レイヤー数

    レイヤの数を入力します。

  • ピラミッド要素作成

    レイヤパーツと内部パーツのつなぎにピラミッド要素を作成します（ピラミッド要素対応ソルバ向け）。

    • - 操作手順 -

    1. レイヤを作成するパーツを選択します。
    2. レイヤの深さと数を入力します。
    3. 必要に応じて、他のパラメータを設定します。
    4. 適用/OKボタンをクリックします。
    5. 選択されたパーツは、レイヤパーツと内部パーツに分かれます。この後、内部パーツに対してTet4のソリッドメッシングを実行して下さい。
