ブーリアン

パーツ同士のブーリアン演算（和・差・積計算）を行います。

和・積の選択リスト 差の選択リスト

パーツプロパティ

  • パーツ名末尾文字列

    新しく作成されるパーツ名の末尾文字列を入力します。 パーツの名前は OriginalPartName_Suffix になります。

    同名のパーツが作成される場合には、文末文字列の後更に数字が追加されます。 OriginalPartName_Suffix _1 。

    ブーリアンタイプ

    実行するブール演算のタイプを選択します。

    • 和

      選択したパーツを1つに結合します。

    • 差

      対象パーツから、差し引きパーツ（複数可）の形状を取り除きます。

    • 積

      選択したパーツ同士が重複する領域のみを残します。

    オプション

  • 元のパーツを残す（デフォルト：オフ）

    元のパーツはアセンブリツリーに残ります。

  • 交差部ラインインプリント

    元のパーツを残すチェックボックスがオンの場合にのみ有効です。交差箇所のラインを元のパーツ上にインプリントします。

  • 対象パーツ（デフォルト：最初）

    複数のパーツを選択する機能の場合に、基準となるパーツがどれになるかを指定します。

    • 最初 : 最初に選択したパーツが対象パーツになります。

    • 最後 : 最後に選択したパーツが対象パーツになります。
      •

    • -操作手順（和・積）-

    1. 必要に応じて、パーツ名末尾文字列を変更します。
    2. ブーリアンタイプで和もしくは積を選択します。
    3. 演算用のパーツ複数を選択します。
      この時、対象パーツオプションで設定したパーツ（最初もしくは最後に選択したパーツ）に対して処理が行われます。
    4. 必要に応じて、他のオプションを選択します。
    5. 適用またはOKボタンをクリックして操作を実行します。

    -操作手順（差）-

    1. 必要に応じて、パーツ名末尾文字列を変更します。
    2. ブーリアンタイプで差を選択します。
    3. 差し引き元のパーツ（対象パーツ）を選択します。選択リストの選択フィルタが差し引きパーツになります。ならなかった場合には、差し引きパーツボタンをクリックしてください。
    4. 差し引かれる側のパーツを選択します。
    5. 必要に応じて、他のオプションを選択します。
    6. 適用またはOKボタンをクリックして操作を実行します。

    - 特記事項 -

    この関数は、ソリッドメッシュボディでは使用できません。
    ブール関数を実行する前に、必ずソリッドメッシュを削除してください。
