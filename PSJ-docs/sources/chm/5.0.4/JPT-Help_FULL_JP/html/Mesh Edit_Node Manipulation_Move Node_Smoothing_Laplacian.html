節点移動 | スムージング-ラプラシアン-

このコマンドでは選択した表面要素をスムージングします。



移動方法

  • 節点参照型

    周りの節点位置を基準に動かします。

  • 要素中心参照型

    周りの要素中心を基準に動かします。

  • CAD面に投影

    • 動かす節点をCAD面にのせます。

    - 機能実行例 -

    - 操作手順 -

    1. スムージングするフェースまたは要素を選択します。
    2. 移動方法を選択します。
    3. CAD面に投影のチェックオンオフを選択します、。
    4.  適用/OKボタンをクリックします。
