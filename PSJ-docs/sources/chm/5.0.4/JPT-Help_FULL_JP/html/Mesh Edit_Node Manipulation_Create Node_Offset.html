オフセット

選択した節点または浮遊節点を、指定したオフセットベクトルの位置にコピーします。
コピー回数を指定すると、指定したオフセットベクトルの間隔で、連続コピーします。

ポジション

  • X, Y, Z

    コピーされる場所のオフセットベクトルを入力します。

  • コピー回数

    コピー回数を入力します。

  • 座標系

    参照座標系を設定します。

    • - 操作手順 -

    1. コピーする節点または浮遊節点を選択します。
    2. X, Y, Zにオフセットベクトルを入力します。
    3. コピー回数にコピー回数を入力します。
    4. 必要に応じて、参照座標系を変更します。
    5. 適用/OKボタンをクリックします。
