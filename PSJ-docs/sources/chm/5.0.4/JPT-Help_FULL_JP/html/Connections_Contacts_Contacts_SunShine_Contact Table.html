接触検索

パーツ間のギャップ距離により接触対候補を自動検出し、接触定義を作成します。


既存接触ペアに対する接触検索テーブルは、アッセンブリツリーの接触上の右クリック>接触検索でも起動可能です。

コンタクト

　　　
  • 検索トレランス

    接触対を検出するパーツ間のギャップ距離を入力します。
    入力トレランス以下のフェースを検出し接触対候補を表示します。

    　　　
    • 　　　
  • 固着トレランス

    固着定義とするパーツ間のギャップ距離を入力します。
    検出された接触対のうち、入力されたトレランス以下となる接触対候補を自動的に固着定義とします。
    それ以外は滑り接触定義となります。

    　　　
    • 　　　
  • 入力単位系

    トレランスの単位系を指定します。

    　　　
    • 　　　
  • 検索範囲

    接触対候補フェースの範囲を指定します。 最小にすると、検索トレランスで検索されたフェースのみを接触対候補として表示します。 最大にすると、検索されたフェースと滑らかにつながるフェースまでを接触対候補として表示します。

    　　　
  • フェース方向考慮

    オンにすると、面の法線ベクトルが反対方向にある場合、接触ペアは作成されません。

    　　　
    • 　　　
  • マスター基準

    検出された接触対候補でマスター側とする接触セグメントの判定基準を指定します。
    メッシュサイズ: 要素面面積の平均値が大きいセグメントグループ
    面積: 総面積の大きいセグメントグループ

    　　　
    • 　　　
  • コンタクト検索

    入力トレランスに基づいてフェースが検出され、接触対候補がテーブルに表示されます。
    パーツを選択せずに実行する際は、パーツ全体で検索を実行することに対する意思確認メッセージが表示されます。

    　　　
    • 　　　
  • オプション

    テーブルに表示する接触オプションを選択します。

    　　　

    • テーブル


    　　　
  • オプションタイトルバー

    各タイトルをクリックすることでそのアイテム名称で接触対候補がソートされます。表示するオプションを変更するにはオプションボタンから指定します。

    　　　
    • 　　　
  • 検索ボックス

    部分一致する接触対候補のみ表示します。またXボタンをクリックすることで検索をキャンセルします。

    　　　
    • 　　　
  • チェックボックス

    検出された接触対候補のうち、実際に定義する接触対にチェックします。適用（OK）ボタンで接触対が作成されます。

    　　　
    • 　　　
  • 接触対テーブル

    テーブルに表示された接触対候補を選択することでモデルウィンドウに接触対箇所がハイライト表示されます。マスター/スレーブ接触セグメントの色はホーム>プリファレンス>画面設定>LBCのマスター色/スレーブ色の設定によります。

    　　　
    • 　　　
  • 接触オプション設定

    表示した接触オプションについて、テーブル内で編集します。
    接触オプション毎に、チェックボックス、プルダウン選択、数値入力、別ダイアログ表示ボタンなど入力方法が分かれています。接触対作成後も個々に接触オプションは編集可能です。

    　　　
    • 　　　
  • テーブル用機能ボタン

    すべてオン: 全ての接触対候補を選択します。
    マスター/スレーブ入替え: 接触対のマスター/スレーブセグメントグループを切り替えます。
    すべてオフ: 全ての接触対候補の選択を解除します。
    編集: テーブルで選択されている接触対候補を手動グループダイアログで開き、編集します。
    削除: テーブルで選択されている接触対候補を削除します。
    エクスポート: 既存接触対(テーブルのオン/オフにチェックボックスがない接触対)の接触オプション情報をcsvファイルに出力します。
    インポート: 接触オプション情報のcsvファイルを読み込み、テーブル内の既存接触対の情報を更新します。

    　　　
    • 　　　
  • フィット

    チェックを入れると選択しているフェースペアをメインウィンドウのサイズに合わせて表示します。

    　　　
  • 関連部品表示

    チェックを入れると選択中のフェースペアに関連する部品が表示されます。



    - 操作手順 -

    　　　
  • 接触対の新規作成手順 　　　
      • 　　　
    1. 検索トレランスと固着トレランスにそれぞれのトレランス値を入力し、コンタクト検索ボタンを押します。
         検出範囲を絞りたい場合はパーツを複数選択後にボタンを押します。デフォルト(パーツ未選択状態)では全てのパーツ間の接触を検出します。
      2. 　　　
    2. テーブルに表示された接触対候補を選択し、モデルウィンドウ上で箇所を確認します。
      3. 　　　
    3. 必要により接触対の接触オプションを変更します。また不要な接触対があればチェックボックスをオフにします。
      4. 　　　
    4. OKボタンを押して接触対を定義します。
      5. 　　　
    5. アッセンブルウィンドウ内すべてのアイテム>コンタクト下に接触対が作成されます。それぞれの接触対は右クリック>編集で編集可能です。


    　　　
  • 接触テーブルを使用した接触対の確認と追加 　　　
      • 　　　
    1. 接触対が定義されている状態で、コンタクトテーブルコマンドを起動します。
         既存の接触対がテーブルに表示されます。
      2. 　　　
    2. テーブルに表示された既存の接触対を選択することで、モデルウィンドウ上でその箇所を確認できます。
      3. 　　　
    3. 新規に接触対を検索する場合、トレランスを入力した後、検出対象のパーツを選択しコンタクト検索ボタンを押します。

         新規に検出された接触対候補が既存の接触対と重複する場合はその候補が赤色で表示されます。
      4. 　　　
    4. 必要により接触オプションを変更し、OKボタンをクリックして接触対を定義します。
         チェックボックスに印のついた接触対が新たに追加されます。


    　　　
  • 既存の接触対に関する接触オプション情報の出力と更新 　　　
      • 　　　
    1. 接触対が定義されている状態で、コンタクトテーブルコマンドを起動します。
      2. 　　　
    2. テーブル下のエクスポートボタンを押し、接触オプションの情報ファイルを出力します。
      3. 　　　
    3. 出力したcsvファイルを開き、接触オプションの設定を変更します。マスター/スレーブグループ名称などは変更できません。
      4. 　　　
    4. 読み込みボタンを押し、編集したcsvファイルを読み込みます。

         接触オプション設定がcsvファイル内で編集した内容で更新されます。
