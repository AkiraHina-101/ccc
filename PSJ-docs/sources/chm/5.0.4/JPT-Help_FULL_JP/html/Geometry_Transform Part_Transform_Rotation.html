回転

選択されたパーツを回転します。

操作

  • 新規作成

    •    移動後にパーツをコピーし、新規パーツとします。新規パーツの名称は、
          元パーツ名_ROT
       となります。

  • LBCコピー

    •    新規パーツに既存パーツに付加した荷重境界条件もコピーします。

  • プロパティコピー

    •    新規パーツに既存パーツに付加したプロパティもコピーします。

  • リファレンス

    •    新規パーツに既存パーツに付加したリファレンスもコピーします。

  • コピー数

    •    コピーの繰り返し数を入力します。

    回転

  • 座標系

    •    参照する座標系を選択します。

  • 回転軸

    •    回転軸を選択します。

    • X軸 : 選択された座標系のX軸回りに回転します。
    • Y軸 : 選択された座標系のY軸回りに回転します。
    • Z軸 : 選択された座標系のZ軸回りに回転します。
    • 任意の軸 : X、Y、Zの方向ベクトルで指定された軸回りにアングル分回転します。
    • 2 節点 : 画面から選択された2つの節点方向の軸回りにアングル分回転します。
    • エッジ : 画面から選択されたエッジ方向の軸回りにアングル分回転します。
      •

  • X軸

    •    回転中心位置のX座標を入力します。

  • Y軸

    •    回転中心位置のY座標を入力します。

  • Z軸

    •    回転中心位置のZ座標を入力します。

  • 中心

    •    回転の中心位置を決めます。

    • パーツ中心 : パーツの中心を回転中心にします。
    • 節点 : 画面から選択した節点を回転の中心にします。
    • 入力 : 回転中心（グローバル座標系で指定）を中心 Global-X、中心 Global-Y、中心 Global-Zに入力します。
      •

  • 回転角度

    •    回転角度を入力します。

  • 節点をイクイバランス

    •    チェックするとモデル内に回転コピーされたボディのフェースが、コピー元のボディのフェースと接する場合にその節点を結合します。

  • イクイバランストレランス

    •    節点結合判定のトレランスを入力します。


    - 操作手順 -

    1.  回転後に新しいパーツを作成する場合は、新規作成をオンにします。
    2.  既存パーツの荷重拘束条件を新規パーツにコピーする場合はLBCコピーをオンにします。
    3.  繰り返しコピーする場合は、コピー数を入力します。
    4.  グループボタンまたはパーツボタンを押し、画面から回転対象のグループまたはパーツを選択します。
    5.  既存の座標系軸回りに回転させる場合は、座標系から既存の座標系を選択し、回転軸からX軸、Y軸、Z軸のいずれかを選択します。
    6.  任意の方向に回転させる場合は、回転軸から任意の軸を選択し、X、Y、Z入力ボックスに方向ベクトルを入力します。
    7.  選択した2節点方向に回転させる場合は、回転軸から2節点を選択し、画面から節点を２つ選択します。
    8.  選択したエッジ方向に移動させる場合は、回転軸からエッジを選択し、画面からエッジを選択します。
    9.  パーツの中心を回転中心にする場合は、中心からパーツ 中心を選択します。
    10.  パーツの中心を節点位置にする場合は、中心から節点を選択し、画面から節点をピックします。
    11.  パーツの中心を直接入力にする場合は、中心からインプットを選択し、回転中心を中心 Global-X、中心 Global-Y、中心 Global-Zにグローバル座標系の座標値で入力します。
    12.  回転角度に回転する角度を入力します。
    13.  コピー後の節点を元のパーツとマージする場合は、節点マージをオンにし、マージトレランスに結合判定許容値を入力します。
    14.  適用/OKボタンをクリックします。
