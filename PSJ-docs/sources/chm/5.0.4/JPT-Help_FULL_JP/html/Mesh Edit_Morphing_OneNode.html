モーフィング | 1節点

メッシュの変形（モーフィング）を行います。選択ノードを移動させるとともに、選択ノードから指定範囲内にある節点を、なめらかに追従して移動させます。
板厚の変更を行うような場合に使用します。

※モーフィング機能実行後に部分リメッシュ機能でメッシュを整えます。

パラメーター

  • 影響力強の適用距離

       選択エンティティの移動の影響が強く及ぶ範囲を距離で指定します。 この範囲に含まれたノードは、Move Distanceで指定した距離だけ移動します。

  • 影響力弱の適用距離

       選択エンティティの移動の影響が及ぶ範囲を距離で指定します。 この距離範囲に含まれたノードの移動量は0<移動量<移動距離で、選択エンティティからの距離が離れると小さくなります。

  • 効果範囲

       影響力強の適用距離/影響力弱の適用距離の設定方法を指定します。

    • 両側フェース

      選択エンティティを中心とし、球状に設定します。移動の影響は、モデル内のノード全てに及びます。

    • 選択フェース

      選択エンティティに接続する面を辿るように設定します。

      •
  • 方向タイプ

       移動タイプを指定します。

    • 並行移動

      指定方向へ移動します。

    • 法線方向

      メッシュの面直方向へ移動します。

      •

    ※1節点の場合と、フェースの場合では、角部分の移動方向が異なります。

    移動距離

  • 座標系

        (方向タイプ: 並行移動）各軸方向の移動量を指定します。

  • 移動距離

        (方向タイプ: 法線方向）移動量を指定します。

    • オプション

  • 影響を受ける節点を表示

       移動する節点をプレビュー表示します。

  • プレビューを表示

       移動する各節点の移動量を、矢印でプレビュー表示します。

    • - 操作手順 -

    1.  画面上から節点を選択します。影響を受ける節点がプレビュー表示されます。
    2.  パラメータを変更して、移動量を調節します。
    3. 実際の移動量を見たい場合には、プレビューを表示をONにします。
    4.  適用またはOKボタンを押して、節点を移動させます。
