ライセンス

"Pre", "Post"ベースライセンスの取得と解放を行います。ライセンスの取得状況により、リボン表示が制限されます。
※所有されているライセンス（ベース）の取得と解放を行います。
※ライセンス設定は、ホームリボン＞プリファレンス＞ライセンスからも設定可能です。

  • 1．Pre, Postライセンス取得時リボン表示例

    Pre, Postベースライセンスに関連するリボンが表示されます。

  • 2．Preのみライセンス取得時リボン表示

    Preベースライセンスに関連するリボンが表示されます。

  • 3．Postのみライセンス取得時リボン表示

    Postベースライセンスに関連するリボンが表示されます。

    • - 操作手順 -

    1. リボン上の"Pre", "Post"アイコンをマウスクリックします。
    2. アイコンをONにし、ライセンスを取得します。
    3. アイコンをOFFにし、ライセンスを解放します。
