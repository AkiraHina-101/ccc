チェックレポート出力

接触条件設定範囲をhtmlやエクセル形式のレポートファイルを出力し確認できます。

ピクチャー制御

　　
  • 拡大率

    接触条件設定エンティティの拡大率を入力します。

    • 　　
  • フィットグループ

    マスター・スレーブ図作成時のフィット対象を選択します。

    • パーツ

    • フェース

    • リスト制御

    リストの項目選択やリスト順を選択します。

  • 項目

    • パーツ

      パーツ毎にリストされます。

    • 接触条件

      接触条件毎にリストされます。
  • 並び

    • 名前

      名前昇順にリストされます。

    • ID

      ID順（作成順）にリストされます。

    • 出力ファイル形式

    　　
  • 形式

    レポートファイル出力形式を選択します。

    • html

    • excel

    • - 操作手順 -

    1. 接触条件設定済みのモデルをメインウィンドウ上に表示します。
    2. コマンドを起動し、図の拡大率を入力します。
    3. フィット対象となるエンティティを選択します。
    4. 項目でリスト対象をパーツか接触条件か選択します。
    5. 並びで順番を名前順かID順を選択します。
    6. 出力ファイル形式でhtmlかexcelを選択します。
    7. 適用またはOKボタンを選択します。
    8. 出力ダイログが開きますので、出力ファイル名を入力し、保存ボタンを選択します。
    9. 出力先のファイルを開いて、接触条件設定範囲を確認します。
