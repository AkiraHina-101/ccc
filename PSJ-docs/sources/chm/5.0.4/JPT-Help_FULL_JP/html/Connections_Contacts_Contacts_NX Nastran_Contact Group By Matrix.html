グループマトリックス

指定グループ間にNX Nastran用接触設定を定義します。
予めマスター面およびスレーブ面となるグループを作成しておき、マトリクステーブル上で接触対を定義します。

コンタクト

　　　
  • 名前

    接触対の名称を入力します。

    　　　
    • 　　　
  • アルゴリズム

    接触設定対象エンティティを選択します。
        フェース-フェース: フェース対フェース間接触

    　　　
    • 　　　
  • タイプ

    接触定義の挙動タイプを選択します。
        一般接触: 滑り接触
        固着: 固着

    　　　
    • 　　　
  • ペアの選択

    既存グループがマトリクス表示されます。
    対となるグループ位置にあるセルにチェックを入れることで接触対が定義されます。
        スレーブ/マスターの入れ替え: セルを選択後、左列にあるグループに対してマスターもしくはスレーブとなるかを指定
        すべてオン: 全ての接触対を考慮
        すべてオフ: 全ての接触対を解除

    　　　

    • コンタクトプロパティ｜一般接触

    　　　
  • 法線ペナルティ係数

    法線ペナルティ係数を入力します。

    　　　
    • 　　　
  • 接線ペナルティ係数

    接線ペナルティ係数を入力します。

    　　　
    • 　　　
  • 力収束トレランス

    力の収束許容値を入力します。

    　　　
    • 　　　
  • 力の最大反復数

    力ループの最大反復数を入力します。

    　　　
    • 　　　
  • ステータスの最大反復数

    ステータスの最大反復数を入力します。

    　　　
    • 　　　
  • 番号を変更

    コンタクトチェンジ許容回数を入力します。

    　　　
    • 　　　
  • 最小接触率

    最小接触率を入力します。

    　　　
    • 　　　
  • シェル板厚

    シェル板厚を含めるかどうか指定します。
        含める: シェル板厚を含める
        含めない: シェル板厚を含めない

    　　　
    • 　　　
  • 接触ステータス

    接触の状態を指定します。
        前回: 以前の状態
        初期: 初期の状態

    　　　
    • 　　　
  • 初期ギャップ/貫通量

    初期開き／貫通の状態を指定します。
        修正なし: モデル通り
        貫通量をリセット: 貫通のみリセット
        両方をリセット: 開き／貫通ともにリセット

    　　　
    • 　　　
  • 最小検索範囲

    最小検索範囲を入力します。

    　　　
    • 　　　
  • 最大検索範囲

    最大入力範囲を入力します。

    　　　
    • 　　　
  • 摩擦係数

    摩擦係数を入力します。

    　　　
    • 　　　
  • 領域細分化

    領域の設定を行います。
        細分化：改善する。
        細分化なし：改善しない。

    　　　
    • 　　　 　　　
  • 評価ポイント

    評価ポイントを指定します。
        低：低
        中：中
        高：高

    　　　

    • コンタクトプロパティ｜固着

    　　　
  • 領域細分化

    領域の設定を行います。
        細分化：改善する。
        細分化なし：改善しない。 　　　

    • 　　　 　　　
  • 評価ポイント

    評価ポイントを指定します。
        低：低
        中：中
        高：高

    　　　
    • 　　　
  • 検索範囲

    接触を検索する範囲を入力します。

    　　　
    • 　　　
  • ペナルティ比例係数

    ペナルティ比例係数を入力します。

    　　　

    • 色設定

    　　　
  • 接触の色

    接触対表示マーカー色を定義します。
        リセット: デフォルト色に初期化

    　　　
    • 　　　

    - 操作手順 -

      　　　
    1. 予めマスター面、スレーブ面となるフェースもしくは要素面グループを作成しておきます。
      2. 　　　
    2. ［ペアの選択］により、接触対とするグループ間のセルにチェックを付け、マスター/スレーブ入替えボタンにより左列グループに対してマスター/スレーブを定義します。
      3. 　　　
    3. 必要により接触対に対する詳細設定を定義し、適用またはOKボタンをクリックして接触対を定義します。
