グリッドメッシュ

このコマンドは単純な四角形形状はもちろん、複雑な形状にも格子状メッシュ（マップトメッシュ）を作成します。

フェース形状

  • 操作

       入力するフェースのタイプを選択します（四角形または三角形またはディスク）
       ※注意：三角形を選択した場合、Quad4をメッシングに使用できません

       選択したバーテックスを変更する方法：
       推奨バーテックスを変更したい場合は、ディスプレイ上の赤い点をクリックし、変更先のバーテックスを選択します。

  • 自動

    フェースタイプを自動(頂点数やエッジ数)で判断します。理想のフェースタイプと異なる場合は、手動でフェースタイプを変更してください。

    • 要素数

  • X

       X方向の要素数（Xの長さはYより短い）

  • Y

       Y方向の要素数（Xの長さはYより短い）

       エッジを選択することで、分割数を選択エッジ側に合わせることができます。

    四角形

    ディスク

  • 固定

       別のフェースを選択するときにXとYの要素数を固定します。

    •    チェックボックスがチェックされていない場合：この機能は、ローカルメッシュ設定または選択したエンティティの形状から分割数を自動的に推奨します。

       チェックボックスがチェックされている場合：新しいエンティティを選択した後にも固定した分割数が保持されます。

    遷移領域

  • 隣接フェース

       周囲のフェースに遷移領域を作成します（選択されたフェースの境界の周りに1層のみの遷移要素があり、この層の位置は選択フェースの境界線の外側にあります）。

  • ターゲットフェース

       選択したフェースのメッシュのみを変更します（他のフェースのメッシュを維持する）。

    • グリッドメッシュタイプ

  • 三角形

       三角形要素を生成します（Tri3要素）。

  • 四角形

       四角形要素を生成します（Quad4要素）。

    • 複数選択

  • 独立

       選択されたフェースに各々のメッシュを生成。

  • マージ

       選択したフェースが連続したフェースの場合、フェースは1つのフェースにマージされ、この結合されたフェースのメッシュが生成されます。
       ※注意：マージ後、マージされたフェースには、選択されたフェースのIDの内、最も小さいIDが表示されます

    • フリップ要素

       メッシュの品質をより良くするためにメッシュパターンを変更します。
       ※注意：このオプションは、三角形要素（Tri3）にのみ使用できます。

  • なし

       このオプションを使用しない。

  • 1 レイヤー

       選択したフェースの境界付近の1層のメッシュを変更します（この層の位置は選択フェースの境界内にあります）

  • すべて

       選択したフェースのすべての要素を変更します。

    アドバンストオプション

  • グリッドメッシュグループ追加

       GridMeshFacesグループにメッシュフェースを追加します。

  • ローカルメッシュ設定を使用

       ローカルメッシュ設定を使用
       ※注意：エッジのメッシュ数とフェースのメッシュサイズのみを使用できます（フェースのメッシュサイズを優先します）。

  • プレビュー

       プレビューとして一時的な結果を表示します（メッシュの最終結果ではありません）。

  • CADプロジェクション

       グリッドメッシュをリファレンスの表面にプロジェクション(投影)します
       投影先は最もIDが小さい(古い)リファレンスです。ただし、Jupiter機能で中立面を作成したパーツは、投影先のリファレンスは「*_MidPlane」になります。

    •    リファレンスからマージフェースなどでエッジやフェースの構成が変わっていると、元の構成を追従せず最短距離のみで動きます。エッジ崩れの原因になりますのでご注意ください。

    - 操作手順 -

    1.  操作からフェースの形状タイプを選択します。もしくは自動をONにします。
    2.  対象となるフェースを一つまたは複数選択します。周りの要素分割状況に合わせて、X,Y方向の要素分割数の推奨値が表示されます。
    3.  要素数のX,Yに希望する要素分割数を入力します。また、分割数を作業中に固定したい場合には、固定チェックボックスをチェックします
    4.  必要に応じて、繊維領域、グリッドメッシュタイプ、複数選択、フリップ要素、アドバンストオプションを設定します。
    5.  適用またはOKボタンをクリックします。
