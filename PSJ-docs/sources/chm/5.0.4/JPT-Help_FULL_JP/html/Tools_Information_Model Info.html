モデル情報

現在開いているモデルの情報を表示します。

　　

モデル情報

  • パーツ情報

       モデル内のすべてのパーツに関する次の情報を表示します。

    1.  パーツ名
    2.  パーツID
    3.  プロパティ名
    4.  プロパティID
    5.  プロパティタイプ
    6.  材料名
    7.  材料ID
    8.  材料タイプ
  • 選択したパーツ情報

       選択したパーツのノードと要素の数を表示します。

       [プロパティ割当済エンティティのみ表示]をオンにすると、プロパティが割り当てられている選択したパーツに属するノードと要素の数のみが表示されます。

  • モデルの概要

       モデル全体のノードと要素の数を表示します。

       [プロパティ割当済エンティティのみ表示]をオンにすると、プロパティを割り当てたパーツに属するノードと要素の数のみが表示されます。

  • LBC数

       モデル全体のすべてのタイプのLBCの数を表示します。

  • プロパティ数

       モデル全体のすべてのタイプのプロパティの数を表示します。


    • - 操作方法 -

    1.  [ツール]> [情報]> [モデル情報]または[Assembyツリーでモデルを右クリックして[モデル情報]をクリックして、モデル情報ダイアログを開きます。
    2.  [ファイルにエクスポート]を選択して、モデル情報をテキストファイルにエクスポートします。
