スイープ | 曲線

指定したフェース内のサーフェスメッシュ(Tri,Quadメッシュ)を、指定したカーブに沿ってスイープしてソリッドメッシュを作成します。

曲線パラメーター

  • メッシュサイズ

    作成する要素サイズを指定します。

    • ※2次要素が含まれるエンティティを選択し実行した場合は、ワーニングが表示されます。
    1次要素に変換し実行します。

    - 操作手順（中心パスを指定） -

    1. スイープ元の面を選択します。
    2. スイープするパスを選択します。
    3. 要素サイズを指定します。
    4. 適用もしくはOKボタンをクリックします。

    - 操作手順（サイドのパス２本を指定） -

    1. スイープ元の面を選択します。
    2. スイープするパスを選択します。
    3. 選択リストでReference Edgeをクリックし、スイープの参照パスを選択します。
    4. 要素サイズを指定します。
    5. 適用もしくはOKボタンをクリックします。
