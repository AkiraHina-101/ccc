管

選択したエッジを中心軸とした中空の管を作成します。




選択リスト

エッジ：管の中心軸となるエッジ

パーツプロパティ

  • パーツ名

    作成する管の名前を入力します。

    • 管

    作成する管の2D要素を選択します。

    • Tri3 : 三角要素で管を作成します。
    • Quad4 : 四辺形要素で管を作成します。
      •
  • 半径

    作成する管の半径を入力します。

  • メッシュサイズ（軸方向）

    作成する管の軸方向のメッシュサイズを入力します。

  • メッシュサイズ（周方向）

    作成する管の周方向のメッシュサイズを入力します。

  • 節点数（周方向）

    作成する管の周方向の節点数を入力します。

    • - 操作手順 -

    1. エッジを選択します。


    2. 半径やメッシュサイズを入力します。

    3. 適用/OKボタンをクリックします。
