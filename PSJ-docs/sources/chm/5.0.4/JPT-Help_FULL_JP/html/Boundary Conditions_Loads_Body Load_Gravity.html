パーツ荷重 | 重力

選択したパーツに重力などの加速度荷重を定義します。 （パーツ指定対応ソルバー：Abaqus）

構造

  • 名前

       重力荷重名を設定します。

    値

  • X/Y/Z

    •    各方向の加速度値を定義します。

  • 入力単位系

    •    入力単位を指定します。

    解析座標系

  • 座標系

    •    荷重が参照する座標系を選択します。


    - 操作手順 -

    1.  重力荷重を負荷するパーツを選択します。複数の選択が可能です。
    2.  X、Y、Zにそれぞれの方向の加速度値を入力します。
    3.  必要に応じて他のパラメータを選択、入力します。
    4.  適用またはOKボタンをクリックします。
