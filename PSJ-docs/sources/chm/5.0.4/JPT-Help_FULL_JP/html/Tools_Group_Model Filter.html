モデルフィルター

モデルの要素タイプ、プロパティ、材料情報を相互に参照しながらグループを作成します。

　　

フィルタータイプ

  • 要素タイプ

       バー、三角形シェルなどの要素タイプによって表示内容を切替えます。

  • プロパティ

       モデルに使用されているプロパティ（要素特性）情報によって表示内容を切替えます。

  • 材料

       モデルに使用されている材料情報によって表示内容を切替えます。

  • グループ

       既存のグループによって表示内容を切替えます。

  • リセット

       全てのフィルタータイプにおいて選択された内容をリセットします。

    • 　　

    ターゲット

       ビューウインドウに表示状態にあるボディに使用されているアイテムが、各フィルターに対応してリスト表示されます。
       リストからアイテムをピックするとアイテムが反転して選択表示になり、対応した要素がビューウインドウに表示されます。
       要素タイプ以外のアイテムは昇順にソートされてリスト表示されます。

       再度アイテムをピックするとアイテムが選択解除されます。

       ShiftキーやCtrlキーを使用するWindows標準操作でアイテムの複数選択ができます。

       フィルターを切替え、更にアイテムの選択をすると、更に範囲の絞り込みができます。
       例ではHEXA、PENTA要素タイプでSolid Property1を使用する要素グループを表示します。

    　　

    新規グループ

  • 節点グループ

       チェックすると作成するグループに節点を含めます。

  • 要素グループ

       チェックすると作成するグループに要素を含めます。

  • 名前

       作成するグループの名前を入力します。

  • 新規グループ作成

       ボタンを押すと新規グループを作成します。


    • - 操作手順 -

    1.  ビューウインドウにモデルのグループ作成対象となる範囲を表示します。
    2.  フィルタータイプから要素タイプボタンを押し、グループ作成対象となる要素タイプを選択します。
    3.  さらにフィルタータイプからプロパティや材料ボタンを押し、リストからアイテムを選択して表示範囲を絞り込みます。
    4.  絞り込みが終わったら、新規グループの名前を入力し、新規グループ作成ボタンを押します。
    5.  新しいグループが作成されましたので、フィルタータイプからグループを選択し、リストを確認します。
      グループを表示させるには、フィルタータイプからリセットを選択し、今までの選択履歴をリセットしてからアイテムを選択します。
    6.  コマンドを終了するには、右上のXボタンをクリックします。

      7. ※作成したグループの表示を行う場合は、メインウィンドウ内の'グループ表示モードアイコンをクリックします。
        再度クリックすると、表示を通常に戻せます。
