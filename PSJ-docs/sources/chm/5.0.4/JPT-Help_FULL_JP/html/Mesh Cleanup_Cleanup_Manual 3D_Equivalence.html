イクイバランス

選択した節点ペアを一つの節点にマージします。

イクイバランス

  • 距離

    選択した2節点の距離を計測し表示します。入力はできません。

  • マージ先

    節点をマージする位置をリストから選択します。
    1番目の節点：　1番目に選択した節点の位置でマージします。
    2番目の節点：　2番目に選択した節点の位置でマージします。
    中間位置：　2節点の中間位置でマージします。

  • 複数節点

    選択すると一度に複数の節点が処理できます。節点の入力順番は節点ペアを順番に入力します。

    • - 操作手順 -

  • 選択した節点ペアを一つの節点にマージします。
    1. マージしたい2節点を順に選択します。距離ボックスに2節点間の距離が表示されます。
    2. 必要に応じてマージ先をリストから選択、変更します。
    3. 複数節点を一度に処理したい場合には、複数節点チェックボックスをチェックします。複数節点ペアを順に入力します。
    4. 適用ボタンをクリックします。
    5. 入力した節点ペアが指定位置で一つの節点にマージされます。この時に関連する要素の節点構成が更新されます。
