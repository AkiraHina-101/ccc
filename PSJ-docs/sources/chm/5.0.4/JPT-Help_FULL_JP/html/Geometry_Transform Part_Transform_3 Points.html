3点

3対の座標点で、選択パーツを元の位置から新しい位置に移動します。

選択リスト

エッジ：円または円弧エッジを選択して、中心位置の座標値を取得します。
節点：節点を選択して、座標値を取得します。
パーツ：移動するターゲットパーツを選択します。

座標系

  • 元の位置

    •    選択パーツの移動前の位置を定義する3点の座標を指定します。

  • 次の位置

    •    選択パーツの移動後の位置を定義する3点の座標を指定します。

    操作

  • プレビュー

    •    プレビューを表示します。

  • 新規作成

    •    元のパーツは移動せず、移動後のパーツを新規作成します。

  • LBCコピー

    •    新規パーツに、元のパーツの荷重境界条件をコピーします。

  • プロパティコピー

    •    新規パーツに、元のパーツの材料プロパティをコピーします。

  • リファレンスコピー

    •    新規パーツに、元のパーツのリファレンスパーツをコピーします。

    - 操作手順 -

    1.  移動前の位置を定義する3点の座標を指定します。本例では、ボルトフランジの円弧エッジを選択しています。
    2.  移動後の位置を定義する3点の座標を指定します。本例では、ボルト穴座面の円弧エッジを選択しています。
    3.  移動するパーツを選択します。移動後のプレビューが表示されます。
    4.  [適用]または[OK]ボタンをクリックします。

    - 注意事項 -

    • 入力座標は、エッジやノードを選択するたびに自動的に切り替わります。 ユーザーは、エッジとノードの選択で柔軟に座標値を入力できますし、手入力で座標値を編集することもできます。
    • ユーザーは、強調表示されたテキストボックスで現在の選択を識別できます。 さらに、マーカーはメインウィンドウに表示して位置を認識することもできます。
    • 3点位置合わせのロジックです。
      • 元の位置 1点目は、次の位置 1点目の位置に移動
      • 元の位置 2点目は、次の位置 1,2点目の線上に移動
      • 元の位置 3点目は、次の位置 1,2,3点目の平面上に移動
