平行移動

選択されたパーツを平行移動またはコピーします。

操作

  • 新規作成

    •    平行移動後にパーツをコピーし、新規パーツとします。新規パーツの名称は、
          元パーツ名_TRANS
       となります。

  • LBCコピー

    •    新規パーツに既存パーツに付加した荷重境界条件もコピーします。

  • プロパティコピー

    •    新規パーツに既存パーツに付加したプロパティもコピーします。

  • リファレンス

    •    新規パーツに既存パーツに付加したリファレンスもコピーします。

  • コピー数

    •    コピーの繰り返し数を入力します。

    平行移動

  • 座標系

    •    平行移動に参照する座標系を選択します。

  • 軸

    •    平行移動の方向を決める軸を選択します。

    • X軸 : 選択された座標系のX軸方向にマグニチュード分、平行移動します。
    • Y軸 : 選択された座標系のY軸方向にマグニチュード分、平行移動します。
    • Z軸 : 選択された座標系のZ軸方向にマグニチュード分、平行移動します。
    • 任意の軸 : X、Y、Zの方向ベクトルとマグニチュード分、平行移動します。
    • 2 節点 : 画面から選択された2つの節点方向にマグニチュード分、平行移動します。
    • エッジ : 画面から選択されたエッジ方向にマグニチュード分、平行移動します。
    • 円弧エッジ : 画面から選択された円弧エッジから得られる中心点方向にマグニチュード分、平行移動します。
      •

  • X

    •    座標系のX軸方向に入力した分平行移動します。

  • Y

    •    座標系のY軸方向に入力した分平行移動します。

  • Z

    •    座標系のZ軸方向に入力した分平行移動します。

  • マグニチュード

    •    移動量を入力します。


    - 操作手順 -

    1.  平行移動後に新しいパーツを作成する場合には、新規作成をオンにします。
    2.  既存パーツの荷重拘束条件を新規パーツにコピーするには境界条件コピーをオンにします。
    3.  繰り返しコピーするには、コピー数を入力します。
    4.  パーツボタンを押し、画面から移動/コピー対象のパーツを選択します。
    5.  既存の座標系方向に移動させる場合には、座標系から既存の座標系を選択し、軸からX軸、Y軸、Z軸のいずれかを選択し、マグニチュードに移動量を入力します。
    6.  任意の方向に移動させるには、軸から任意の軸を選択し、X、Y、Zおよびマグニチュード入力ボックスに方向ベクトルと移動量をそれぞれ入力します。
    7.  選択した２節点方向に移動させるには、節点ボタンを押し、画面から節点を２つ選択します。マグニチュードに２節点間の距離が自動的に入力されます。
    8.  選択したエッジ方向に移動させるには、エッジボタンを押し、画面からエッジを選択します。マグニチュードにエッジ長さが自動的に入力されます。
    9.  画面から選択された円弧エッジから得られる中心点方向に移動させるには、エッジボタンを押し、画面からエッジを選択します。最初に移動元の円弧エッジを選択し、次に移動先の円弧エッジを選択します。マグニチュードに２中心間の距離が自動的に入力されます。
    10.  必要に応じてマグニチュードの移動量を変更します。
    11.  適用/OKボタンをクリックします。
