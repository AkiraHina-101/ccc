節点移動 | 節点一致

複数節点を同一位置に移動します。

ポジション

  • トレランス

    •    一致させる節点間のトレランス値を指定します。

  • 降順

    •    選択された節点の中で節点ID最大の節点に位置を一致させます。


    - 操作手順 -

    1.  移動する節点を選択します。
    2.  一致させる節点間のトレランス値を指定します。
    3.  移動先となる節点について、選択された節点の中で節点IDが大きい節点に一致させる場合は降順にチェックを入れます。
    4.  適用またはOKボタンを押します。

      5.   ※降順をオフにした場合は、選択された節点の中で節点IDが小さい節点に一致します。
