抜き勾配角度(Draft Angle)

型モデルのメッシュの抜き勾配角度(*1)を確認する機能です。
本機能により表面メッシュの逆勾配を確認することで、摺動を伴う解析前に、リメッシュ機能などでメッシュモデルを修正することができます。
抜き勾配角度を計算する対象は、選択されたパーツのすべての表面メッシュです。

*1) 抜き勾配角度[deg]：表面メッシュの法線と任意指定の抜き勾配方向の、2軸間角度です。

コンター表示のほかに、表面誤差ごとの節点グループ（Draft_Angle）を作成できます。

選択リスト

パーツ(Part)：計測するパーツ（リファレンスパーツの選択は不可）

抜き勾配方向(Draft Direction)

  • X, Y, Z

    抜き勾配の方向ベクトルを入力します。

    • コンター(Contour)

  • 桁数(Num. Digits)

    表示する誤差距離の小数点桁数です。

  • 分割数(Num. Division)

    コンターの分割数です。

  • 最大／最小(Max/Min)

    コンターの最大最小値です。

  • 表示／非表示(Show/Hide)

    コンター表示／非表示の切替（更新）を実行します。

    • グループ(Group)

  • 桁数(Num. Digits)

    グループ作成する抜き勾配角度の小数点桁数です。

  • 最大／最小(Max/Min)

    グループ作成する抜き勾配角度の最大最小値です。

  • グループ作成(Create Group)

    専用のグループツリーで節点グループの作成（更新）を実行します。

    • - 操作手順（抜き勾配角度計算） -

    1. パーツ(Part)を選択します。

    2. 抜き勾配方向を入力します。

    3. 適用(Apply)ボタンをクリックします。

    4. 表面メッシュの抜き勾配角度計算を、メモリに計算します。

    5. 表示／非表示(Show/Hide)とグループ作成(Create Group)が有効になります。

    - 操作手順（コンター表示 ※抜き勾配角度計算の後に可能） -

    1. コンターのパラメータを入力します。

    2. 表示／非表示(Show/Hide)をクリックします。

    3. コンターが表示／非表示（更新）されます。

    - 操作手順（節点グループ作成 ※抜き勾配角度計算の後に可能） -

    1. グループのパラメータを入力する。

    2. グループ作成(Create Group)をクリックする。

    3. 抜き勾配角度ごとの節点グループが作成（更新）されます。
