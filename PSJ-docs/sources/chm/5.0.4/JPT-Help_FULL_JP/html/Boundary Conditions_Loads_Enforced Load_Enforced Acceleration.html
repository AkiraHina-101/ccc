強制加速度

選択したフェース、エッジ、節点に強制加速度荷重を定義します。

対応ソルバー：Nastran Sol111、Sol112/ADVC静解析/Abaqus静解析(Ansys/LSDynaは未対応)

構造

　　
  • 名前

    強制加速度荷重名を設定します。

    値

    　　　
    • 　　
  • 変位 X/Y/Z

    X,Y,Z並進方向の強制加速度値を設定します。

    　　　
    • 　　
  • 矢印方向

    マーカー表示の描画位置の指定をします。
       節点が始点：節点を始点として、マーカーを表示します。
       節点が終点：節点を終点として、マーカーを表示します。

    　　　
    • 　　
  • 入力単位系

    入力単位を指定します。（V3.0未対応）

    　　　

    • 値

    　　　 　　
  • 回転 X/Y/Z

    X,Y,Z回転方向の強制加速度値を設定します。

    　　　
    • 　　
  • 入力単位系

    入力単位を指定します。※デフォルト値をドキュメント単位系にします。

    　　　

    • 解析座標系

    　　
  • 座標系

    荷重の負荷方向の参照座標系を選択します。

    　　　

    • テーブル

    　　
  • テーブル選択

    時刻歴、周波数を参照するテーブルを選択します。

    　　　

    • フェーズ遅れ

    　　
  • フェーズ

    荷重の位相を入力します。

    　　　
    • 　　
  • フェーズテーブル

    荷重の位相テーブルを選択します。

    　　　
    • 　　
  • 遅れ

    荷重の遅れ値を入力します。

    　　　

    • 複数加振力出力

    　　
  • 変位 X/Y/Z

    X,Y,Z並進方向の複数点入力のテーブルを選択します。

    　　　
    • 　　
  • 回転 X/Y/Z

    X,Y,Z回転方向の複数点入力のテーブルを選択します。

    　　　

    • - 操作手順 -

      　　　
    1. 強制加速度荷重を負荷するフェース、エッジ、節点を選択します。複数の選択が可能です。
      2. 　　　
    2. 荷重方向に従い、それぞれ並進と回転のX,Y,Zに荷重値を入力します。
      3. 　　　
    3. 必要に応じて他のパラメータを選択、入力します。
      4. 　　　
    4. 適用またはOKボタンをクリックします。
