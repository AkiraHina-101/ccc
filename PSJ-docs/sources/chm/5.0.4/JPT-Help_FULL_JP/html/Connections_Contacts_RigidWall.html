剛体壁

剛体壁を設定します。

剛体壁

  • 対象

       剛体壁の対象は平面剛体壁です。

    　　　
  • 名前

       剛体壁の名前を入力します。

    　　　
    • 　　　
  • タイプ

       剛体壁のタイプを指定します。無限体もしくは有限体から選択します。

    • 無限体 : 無限体。
    • 有限体 : 有限体。
      •
    　　　
    • 　　　
  • モーション

       挙動を指定します。静止もしくは可動から選択します。

    • 静止
    • 可動
      •
    　　　
    • 　　　
  • 摩擦

       摩擦の条件を下記より指定します。

    • 摩擦無し
    • 滑り無し
    • クーロン摩擦
    • 摩擦無し溶着
    • 滑り無し溶着
      •
    　　　
  • 力

       反力の考慮の有無を指定します。

    • 考慮しない : 反力を考慮しません。
    • 考慮する : 反力を考慮します。
      •
    　　　
  • すべての節点をスレーブに

       チェックを入れると全ての節点を従属点にします。

    　　　

    • 剛体壁の位置

    座標系で剛体壁の位置を決定します。

  • 座標系

       座標系を選択します。



    • - 操作手順 -

      　　　
    1. 名前を入力します。
      2. 　　　
    2. 作成する剛体壁のタイプを指定します。
      3. 　　　
    3. モーションを選択します。
      4. 　　　
    4. 摩擦の条件を指定します。
      5. 　　　
    5. 反力の有無を指定します。
      6. 　　　
    6. 必要に応じて「すべての節点をスレーブに」にチェックを入れます。
      7. 　　　
    7. 座標系を指定します。
      8. 　　　
    8. エンティティを選択し、適用またはOKボタンをクリックします。
