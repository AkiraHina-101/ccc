グループウィンドウ

グループコマンドで作成したグループの表示・編集を行います。
グループモードをONにした場合、表示されているグループ以外のエンティティは非表示となります。


ツリーコントロールメニュー

ツリーの表示を調節します。

アイコン名称説明
選択解除選択されているツリーアイテムをすべて選択解除します。
すべて開くサブツリーをすべて展開します。
すべて閉じるサブツリーをすべて閉じます。
ソート順切り替えグループツリーの並び順をソート設定ダイアログで設定された順に、昇順または降順に並び替えます。
ソート設定グループソート設定ダイアログを起動します。

グループソート設定ダイアログ

グループツリーの並び順を変更します。

  • ソート順

    グループツリーの並び順の基準を選択します。

    • グループ名順 : グループアイテムをアルファベット順に昇順/降順で並べます。
    • グループID順 : グループアイテムをグループID順に昇順/降順で並べます。
    • 節点数順 : グループアイテムを、各グループに含まれる節点数順に昇順/降順で並べます。
    • 要素数順 : グループアイテムを各グループに含まれる指定要素順に昇順/降順で並べます。

    ツリービュー

    グループの設定状態をツリー形式で表示します。 各ツリーアイテムをマウス左ボタンクリックすることでツリーアイテムをハイライトします。また、各ツリーアイテムをマウス左ボタンダブルクリックすることで、グループ内のエンティティを選択状態にします。
    ※V4.0より、グループアイテムのダブルクリックによる"グループの選択"及び"グループ内の選択エンティティの選択解除"が削除され、"グループ内エンティティの選択"のみに変更されました。選択解除モードがONの場合でも、本機能使用時にはエンティティが選択されます。

    グループ/サブグループ複数のグループの親グループです。また、グループ内に復数の異なる種類のエンティティが存在している場合にも、このアイコンが表示されます。
    パーツグループパーツのみのグループです。

    ショートカットメニュー

    マウス右クリックメニューで表示されるメニューから、各コマンドを使用します。

    ・アイテム未選択時に利用できるメニュー
    コマンド機能
    グループビューで表示メインウィンドウの表示を、グループモードに変更します。
    グループビュー終了メインウィンドウの表示を、標準画面に戻します。

    ・常に利用できるメニュー
    コマンド機能
    エンティティ選択ハイライトしたグループに含まれるエンティティを選択状態にします。
    グループ選択ハイライトしたグループ自身を選択状態にします。
    サブグループを追加空のサブグループをグループアイテム下に追加します。
    コピーハイライトしたグループをアセンブリ間でコピーします。
    材料グループ作成同じマテリアルが割り当てられたエンティティのグループを作成します。
    プロパティグループ作成同じプロパティが割り当てられたエンティティのグループを作成します。
    非表示エンティティグループ作成現在非表示になっているフェース、エレメント及びパーツのグループを作成します。
    エンティティグループ作成グループコマンドが起動され、エンティティ毎のグループを作成します。
    グループ作成-モデルフィルターモデルフィルターコマンドが起動され、要素タイプやプロパティでフィルターしながらグループを作成します。
    インポートエクスポートメニューでCSV形式ファイルに出力されたグループの情報を読み込みます。
    エクスポートハイライトしたグループの内容をCSV形式ファイルに書き出します。
    貼付けカット/コピーしたグループを、ハイライトしたアセンブリ下に移動させます。
    グループ削除ハイライトしたグループを削除します。
    圧力やサーフェース荷重、接触条件に使用されているフェースグループは、削除されません。
    エンティティ削除ハイライトしたグループ内に含まれるエンティティを削除します。

    ・グループアイテム選択時に利用できるメニュー
    コマンド機能
    非表示ハイライトしたグループを非表示にします。
    選択のみ非表示ハイライトしたグループのみを非表示にし、他のグループを表示します。
    表示ハイライトしたグループを表示します。
    選択のみ表示ハイライトしたグループのみを表示し、他のグループを非表示にします。
    すべて表示すべてのグループを表示します。
    すべて非表示ハイライトしたグループを非表示にします。。
    表示/非表示を反転現在の表示、非表示設定を反転します。
    編集※ハイライトしたグループを編集するためのダイアログが開きます。
    リネームハイライトしたグループのグループ名を変更します。
    関連選択ハイライトしたグループに関連するエンティティを選択します。
    グループマーカーグループマーカーの色をランダムに、または指定色に変更します。

    ※「編集」にショートカットキー［F3］が設定されています。

    ・同一タイプのグループアイテム復数選択時に利用できるメニュー
    コマンド機能
    ブーリアン（和）ハイライトした復数のグループ内のエンティティを足し合わせた、新しいグループを作成します。
    ブーリアン（差）２つの同一のタイプのグループアイテムを順にクリックしたとき、先にハイライトしたグループ内のエンティティから、後にハイライトしたグループ内のエンティティを取り除いた、新しいグループを作成します。
    ブーリアン（積）ハイライトした復数のグループ内のエンティティの共通のアイテムについて新しいグループを作成します。

    ショートカットキー一覧

    グループウィンドウにフォーカスがある場合には、下記ショートカットキーを利用可能です。
  • ビュー操作
    • ショートカットキー動作
    F2ツリーアイテムをハイライトしてキーを押下すると、アイテムをリネームします。
    F3ツリーアイテムをハイライトしてキーを押下すると、右クリックメニューの「編集」を実行します。
    上下矢印キーツリーアイテムのハイライトを移動します。
    F選択パーツを画面にフィットします。パーツ未選択の場合、モデル全体を画面にフィットさせます。
    E選択エンティティを選択解除します。
    Aコマンドダイアログ起動時、コマンドを実行します。
    Spaceコマンドダイアログ起動時、コマンドを実行します。
    Ctrl＋マウス左クリック複数のツリーアイテムをハイライトします。
    Shift＋マウス左クリック複数の連続したツリーアイテムをハイライトします。
