リナンバー | 接続要素のリナンバー

接続要素のIDを振り直し（リナンバー）します。

設定

  • 接続のタイプ

    接続要素のタイプを選択します。

  • 自動リナンバー

    Enableの列にチェックが付いている行を、一番上の行のStart IDから順にリナンバーします。

    オプション

  • ソルバータイプ

    ソルバーの種類をNastran/ADVCから選択します。

  • ID検索

    「検索」ボタンをクリックすることで、表内で指定IDを含む行をハイライト表示します。

    - 操作手順 -

    1.  ソルバータイプの選択肢より、ソルバータイプを指定します。
    2.  接続のタイプより、リナンバーを行いたいエンティティを指定します。。
    3.  各列のStart IDを指定します。もしくは、一番上の行のStart IDを指定した後、自動リナンバーボタンをクリックします。
    4.  適用ボタンを押して、リナンバーを実行します。

    ※エクスポート時の接続要素のIDは、リナンバーを行わない場合要素の最大ID＋1から開始します。
