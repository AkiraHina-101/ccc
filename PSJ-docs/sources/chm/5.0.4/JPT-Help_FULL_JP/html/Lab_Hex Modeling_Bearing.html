ヘキサモデリング | ベアリング

選択したフェースをリメッシュしてヘキサベアリングパーツを作成し、選択フェースとの間でメッシュパターンができるだけ一致するようにします。

パラメーター

  • ベアリングタイプ

    完全円筒形のベアリング（360）もしくは半円筒形x2のベアリングか（180x2）を選択します。

  • 角度分割数

    円周方向のメッシュ分割数を指定します。

  • 要素タイプ

    ヘキサ１次要素（Hex8）もしくはヘキサ２次要素（Hex20）から選択します。

  • L1：外側幅

    L1の寸法を指定します。

  • L2：内側幅

    L2の寸法を指定します。

  • L2要素数

    L2の要素数が表示されます。

  • L2分割(比率)

    L2のメッシュ分割を比率で入力します。
    例） 幅12mmのベアリングに対し、「1,2,2,1」と入力
    →ベアリング幅方向の要素数は4、幅は2mm, 4mm, 4mm, 2mm。

  • T1: 外側厚み

    T1の寸法を入力します。

  • T2: 内側厚み

    T2の寸法を入力します。

  • T2要素数

    T2の要素数を入力します。

  • プレビューチェックボックス

    チェックボックスがONのとき、作成されるベアリング形状のプレビュー表示を行います。

  • 画像を表示ボタン

    ベアリングの断面形状の参考画像(断面パラメータ）を表示します。L1, L2, T1, T2入力時の参考となります。

    • - 操作手順 -

    1. ベアリングパーツの取付先となるパーツに対して、あらかじめメッシュを作成しておきます。
    2. フェースを選択します。選択フェースに合わせて自動的にパラメータが入力されます。また、プレビューチェックボックスがONの場合かつパラメータに問題が無い場合には、プレビューが表示されます。
    3. パラメータを任意に変更します。
    4. 適用またはOKボタンで機能が実行されます。ベアリングパーツと、取付先のフェースのパターンは、ベアリングパーツ基準でできるだけ合致するように編集されます。
