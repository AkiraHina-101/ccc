インポートADVCV2

このコマンドは、ADVCファイル（.adx）をインポートするために使用されます。

インポートタイプ

  • 標準インポートファイル

    •     モデルジオメトリのみをインポートします。

  • プロパティで分けてインポート

    •     モデルの形状と材料特性をインポートします。 ボディは、材料特性ごとに作成されます。

    角度

  • 面角度

    •     面の分割を決定するために、許容角度を指定します。 指定した値よりも小さい角度で隣接する要素間にエッジを作成して、面を定義します。

  • エッジ角度

    •     エッジ分割を決定するために、許容角度を指定します。 指定された値よりも小さい角度で隣接するエッジ要素に頂点を作成して、エッジを分割します。

    オフセット/リナンバー

  • ファイル名

    •     インポートするファイル名の一覧です。Current Modelは現在のドキュメントを指します。

  • ストラテジー

    •  オフセットかリナンバーから選択します。

  • 入力

    •  ストラテジーによって入力内容を変更します。

    • オフセット: 入力値ぶんだけIDが増加します。（新しいID =古いID +入力値）

    • リナンバー: 入力値が開始IDとなります。（新しいIDの開始ID =入力値）

      •
  • 開始

    •  開始IDを自動的に取得します。 開始IDは、ストラテジーでオフセット/リナンバーを変更すると更新されます。

  • 終了

    •  終了IDを自動的に取得します。 終了IDは、ストラテジーでオフセット/リナンバーを変更すると更新されます。

  • リセット

    •     すべてのパラメータを元の状態に復元します。

    - 操作手順 -

    1.  コマンドを起動し、各オプションを指定して、[OK]ボタンをクリックします。

    2.  1つまたは複数のADVCファイルを選択し、[開く]ボタンをクリックします。

    3.  複数ファイルのインポート時、IDの重複があった場合には警告ダイアログが表示されます。 ユーザーは、Adjust、、Yes（自動ID変更）、No（キャンセル）の3つの方法のいずれかを指定します。

    4.  Adjustを選択した場合、オフセット/リナンバーダイアログが表示されます。ストラテジーを選択し、入力セルにIDを入力してOKをクリックします。
