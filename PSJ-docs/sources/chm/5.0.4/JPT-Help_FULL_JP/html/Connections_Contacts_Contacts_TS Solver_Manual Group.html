グループ指定

指定グループ間に接触設定を定義します。
予めマスター面およびスレーブ面となるグループを作成しておき、接触対毎に接触グループを選択し、接触設定を定義します。



基本

  • 名前

       接触対の名称を入力します。

  • アルゴリズム

       接触設定対象エンティティを選択します。

    • フェース-フェース: フェース対フェース間接触
  • タイプ

       接触定義の挙動タイプを選択します。

    • 一般接触 : 滑り接触
    • 固着 : 固着
      •
  • マスター

       マスター面となるグループを選択します。

    • 検索: 名称またはIDでグループを検索し、マスター面として定義します。
  • スレーブ

       スレーブ面となるグループを選択します。

    • 検索: 名称またはIDでグループを検索し、スレーブ面として定義します。
  • スイッチ

       マスター/スレーブセグメントグループを切り替えます。

    • コンタクトプロパティ

  • 干渉閉鎖距離(CINTERF)

       ソルバーに2つのフェースが接触している判定距離を指示します。

  • 摩擦係数(FRIC)

       コンタクト検索結果に対して、左側のテキストボックスにパーツ名または面IDを入力して絞り込み表示を行います。

    • - 操作手順 -   

    1.  予めマスター面、スレーブ面となるフェースもしくは要素面グループを作成しておきます。
    2.  マスターでマスター面となるグループ、スレーブでスレーブ面となるグループを選択します。

      3.  選択したグループがモデルウィンドウでハイライト表示されます。グループ表示モードをオフにして確認することも可能です。
       検索ボタンよりグループの名称の部分一致検索またはID検索をすることが可能です。

       既存グループに含まれるフェースを編集したい場合は、リスト内のグループをダブルクリックすることでグループ編集モードとなります。
      モデルウィンドウでフェースを追加選択など編集後、修正ボタンを押すことでグループ内容が変更されます。
      編集したグループは他の接触対でもそのまま利用されますのでご注意ください。

    3.  必要により接触対に対する詳細設定を定義し、OKボタンをクリックして接触対を定義します。
