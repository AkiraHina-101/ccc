配置

選択したパーツを軸揃えや平面揃えにより、すばやく整列します。


移動

  • 方法

    •    移動する方法を指定します。2種類の方法があります。

    • 軸で揃えます: パーツを軸で揃えます。

      •    選 択 リ ス ト
            パーツ: 移動するパーツを選択します（複数パーツ可です）
            ターゲットエッジ: 移動元の円弧エッジを選択します（最大2つ）
            参照エッジ: 移動先の円弧エッジを選択します（最大2つ）

    • 平面で揃えます: パーツを平面で揃えます。

      •    選 択 リ ス ト
            パーツ: 移動するパーツを選択します（複数パーツ可です）
            対象フェース: 移動元の平面フェースを選択します（1つ）
            参照フェース: 移動先の平面フェースを選択します（1つ）
            中心節点: 回転中心の節点を選択します。
            中心エッジ: 回転中心をエッジ中心で定義する場合は、円弧エッジを選択します。
            ※回転中心むけの選択は、中心節点か中心エッジの何方かで十分です。両方が選択された場合は、最新の選択が回転中心を定義するために使用されます。
  • 平行移動距離

    •    移動後にパーツを平行移動する距離です。


  • 同一 平面 (平面で揃える方法のみ)

    •    対象フェースが参照フェースと同一平面上に移動するように、平行移動距離の値を自動計算されます。

    操作

  • プレビュー

    •    プレビューを表示します。

  • 新規作成

    •    元のパーツは移動せず、移動後のパーツを新規作成します。

  • LBCコピー

    •    新規パーツに、元のパーツの荷重境界条件をコピーします。

  • プロパティコピー

    •     新規パーツに、元のパーツの材料プロパティをコピーします。

  • リファレンスコピー

    •    新規パーツに、元のパーツのリファレンスパーツをコピーします。

    方向

    移動する方向を指定します。2種類の方向があります。

  • 反対方向: 移動元と移動先の法線ベクトルが逆向きになるように、パーツを移動します。

  • 同方向: 移動元と移動先の法線ベクトルが同じ方向になるように、パーツを移動します。

    • - 操作手順 -

    操作手順 1 : 軸で揃えます。

    1.  方法を「軸で揃える」にします。
    2.  移動するパーツを選択します。
    3.  移動元の円弧エッジを、ターゲットエッジで選択します。
    4.  移動先の円弧エッジを、参照エッジで選択します。
    5.  必要に応じて、平行移動距離の値を入力します。
    6.  新しいパーツを作成するチェックボックスをオンにすると、移動後に新しいパーツが作成されます。LBCコピー、プロパティコピー、リファレンスコピーのチェックボックスをそれぞれオンにすると、既存のパーツの荷重と境界条件、プロパティ、リファレンスも新しいパーツにコピーされます。
    7.  方向を指定します。
    8.  適用/OKボタンをクリックすると、パーツが移動します。

    操作手順 2 : 2組の軸で揃えます。

    1.  方法を「軸で揃える」にします。
    2.  移動するパーツを選択します。
    3.  1組目の移動元の円弧エッジを、ターゲットエッジで選択します。
    4.  1組目の移動先の円弧エッジを、参照エッジで選択します。
    5.  2組目の移動元の円弧エッジを、ターゲットエッジで選択します。
    6.  2組目の移動先の円弧エッジを、参照エッジで選択します。
    7.  必要に応じて、平行移動距離の値を入力します。
    8.  新しいパーツを作成するチェックボックスをオンにすると、移動後に新しいパーツが作成されます。LBCコピー、プロパティコピー、リファレンスコピーのチェックボックスをそれぞれオンにすると、既存のパーツの荷重と境界条件、プロパティ、リファレンスも新しいパーツにコピーされます。
    9.  方向を指定します。
    10.  適用/OKボタンをクリックすると、パーツが移動します。

    操作手順 3 : 平面で揃えます。

    1.  方法を「平面で揃える」にします。
    2.  移動するパーツを選択します。
    3.  移動元の平面フェースを、対象フェースで選択します。
    4.  移動先の平面フェースを、参照フェースで選択します。
    5.  回転中心の定義のため、中心節点または中心エッジで選択します。
    6.  必要に応じて、平行移動距離の値を入力します。同一平面にチェックを入れると、移動元フェースが移動先フェースの同一平面上に移動するよう、自動入力されます。
    7.  新しいパーツを作成するチェックボックスをオンにすると、移動後に新しいパーツが作成されます。LBCコピー、プロパティコピー、リファレンスコピーのチェックボックスをそれぞれオンにすると、既存のパーツの荷重と境界条件、プロパティ、リファレンスも新しいパーツにコピーされます。
    8.  方向を指定します。
    9.  適用/OKボタンをクリックすると、パーツが移動します。

    操作手順 4 : 軸で揃えた後、平面で揃えます。

      ※軸で揃えます：
    1.  方法を「軸で揃える」にします。
    2.  移動するパーツを選択します。
    3.  移動元の円弧エッジを、ターゲットエッジで選択します。
    4.  移動先の円弧エッジを、参照エッジで選択します。
    5.  必要に応じて、平行移動距離の値を入力します。
    6.  新しいパーツを作成するチェックボックスをオンにすると、移動後に新しいパーツが作成されます。LBCコピー、プロパティコピー、リファレンスコピーのチェックボックスをそれぞれオンにすると、既存のパーツの荷重と境界条件、プロパティ、リファレンスも新しいパーツにコピーされます。
    7.  方向を指定します。
    8.  適用/OKボタンをクリックすると、パーツが移動します。
      ※平面で揃えます：

      「軸で揃える」で移動した後「平面で揃える」に切り替えると、自動的に、「軸で揃える」で選択した参照エッジが「平面で揃える」の中心エッジになります。

    1.  方法を「平面で揃える」にします。
    2.  移動するパーツを選択します。
    3.  移動元の平面フェースを、対象フェースで選択します。
    4.  移動先の平面フェースを、参照フェースで選択します。
    5.  回転中心の定義のため、中心節点または中心エッジで選択します。
    6.  必要に応じて、平行移動距離の値を入力します。同一平面にチェックを入れると、移動元フェースが移動先フェースの同一平面上に移動するよう、自動入力されます。
    7.  新しいパーツを作成するチェックボックスをオンにすると、移動後に新しいパーツが作成されます。LBCコピー、プロパティコピー、リファレンスコピーのチェックボックスをそれぞれオンにすると、既存のパーツの荷重と境界条件、プロパティ、リファレンスも新しいパーツにコピーされます。
    8.  方向を指定します。
    9.  適用/OKボタンをクリックすると、パーツが移動します。

    - 注意事項・参考情報 -

    1.  ターゲットパーツが1Dバーパーツの場合は、本機能はサポートされません。
    2.  選択するエッジやフェースの形状の条件。
      • 軸で揃える方法の場合: ターゲットエッジ/参照エッジは、円弧を選択してください。

      • 平面で揃える方法の場合: 中心エッジは、円弧を選択してください。対象フェースや参照フェースは、平面を選択してください。

        •
    3.  平面で揃える方法の場合：移動方向は、移動先の法線ベクトル方向が正の方向とします。
    4.  平面で揃える方法の場合：回転角度（Θ < 90° OR Theta; > 90°）と方向（同方向 OR 反対方向）の組合せによる、パーツの移動例(Θ)。
      • Θ < 90°、同方向に移動する場合： パーツを角度 Θ だけ回転させます。

      • Θ < 90°、反対方向に移動する場合： パーツを角度Θだけ回転させます。その後、参照フェースを対称面として、パーツを面対称に回転させます。

      • Θ > 90°、反対方向に移動する場合： パーツを角度（180° - Θ）だけ回転させます。

      • Θ > 90°、同方向に移動する場合： パーツを角度（180° - Θ）だけ回転させます。その後、参照フェースを対称面として、パーツを面対称に回転させます。
