接続 | バー要素（１対多）

一対多（マスター：スレーブ）のRbar（剛体梁要素）を作成する機能です。
本機能では、全独立自由度が片側の節点にあるケースのみをサポートします。
＊マスター節点とスレーブ節点は、パーツ単位、フェース単位、エッジ単位、要素単位、節点単位での選択が可能です。

マスター節点と（接続範囲内の）スレーブ節点が接続されます。
スレーブ自由度の２重結合を防ぐため、複数のマスター節点の接続範囲内にあるスレーブ節点は、一番近いマスター節点とだけ接続されます。

接続

  • 名前

    登録される名前を入力します。

    • 検索範囲

  • すべて

    接続範囲を無限として指定します。

  • トレランス

    接続範囲の半径Rを入力します。

    • マスター自由度

  • UX - RZ

    マスターで選択された節点に、独立自由度の全成分が指定されています。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • - 操作手順 -

    1. 接続範囲を設定します。
    2. マスター候補の節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    3. スレーブ候補の節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    4. パラメータを設定します。
    5. 適用/OKボタンをクリックします。
