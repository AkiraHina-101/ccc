節点移動

節点または浮遊節点を移動します。



  • 任意

       任意の位置に移動します。

  • オフセット

       任意の方向に移動します。

  • 鉛直オフセット

       フェースの鉛直方向に移動します。

  • 方向に沿って

       任意の方向に移動します。

  • 任意点

       移動先を任意点の指定によって指示し、節点を移動します。

  • CADフォロー

       節点をドラッグすることで、フェース上の任意の場所に移動します。

  • 直線に投影

       直線上に移動します。

  • 平面に投影（要素）

       選択した節点または浮遊点を、要素により定義される平面に、最短距離で投影します。

  • 平面に投影（3節点）

       任意の対象節点を、3つの参照節点で定義された平面上に、最短距離で動かします。

  • 中間節点を主節点の中間へ

       中間節点を、コーナー節点の線形補間位置に移動します。

  • 円筒面に沿って

       定義した仮想円筒上へ節点を移動します。

  • 節点一致

       複数節点を同一位置に移動します。

  • 均等配置

       選択したエッジ上の節点群を均等に配置します。

  • 拡大/縮小

       選択した節点群を節点間の比率を保持しながら拡大、縮小します。

    • スムージング

  • 要素品質

       要素品質を基準にスムージングします。

  • ラプラシアン

       周りの節点や要素中心を参照してスムージングします。
