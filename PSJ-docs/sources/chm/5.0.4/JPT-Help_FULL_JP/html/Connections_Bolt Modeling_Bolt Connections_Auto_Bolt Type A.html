ボルトタイプA(Bolt TypeA)

自動ボルト接続(Auto Bolt Connection)機能から開く、ボルトタイプAのFEM条件を設定するダイアログです。
自動ボルト接続(Auto Bolt Connection)のヘルプ

ボルトタイプAは、ボルト穴の上下座面にRBE2要素／RBE3要素を円形に作成、その中心をバー要素／RBE2要素で結合します。
プリテンションオプションで、ボルト締め付け力を追加できます。


座面設定(Seat Settings)

  • 接続(Connection)

    ボルト穴の上下座面に作成する剛体の種類(RBE2／RBE3)を選択します。


  • 座面直径(節点)(Seat Diameter(Node))

    入力した直径の範囲内にある節点に、剛体を作成します。

  • 座面レイヤー(フェース)(Seat Layer(Face))

    入力した層数のボルト穴周りのフェース（節点）に、剛体を作成します。

    • シャフト設定(Shaft Settings)

  • シャフト(Shaft)

    ボルト軸に作成する剛体の種類(RBE2／バー(Bar))を選択します。


  • バープロパティ(Bar Property)

    シャフト(Shaft)でバー(Bar)を選択した場合、Bar要素のプロパティを選択します（アッセンブルツリーにバープロパティがある場合のみ、メニューに表示されます）
    Noneを選択すると、プロパティなしでBar要素が設定されます。

    • 中心設定(Center Settings)

  • 接続(Connection)

    シャフト中心に作成する剛体の種類を選択します。
    座面にRBE3かつシャフトにRBE2を選択した場合は、Springのみ選択可能です。

    • None : 軸の中心に剛体なし。
    • Spring : 軸の中心にSpringを作成します。
    • PreTension : 軸の中心にPreTensionを作成します。


    • プリテンション荷重(Pre Tension Load)

    ボルト締め付け力を設定します。

  • ソルバー(Solver)

    対象のソルバーを選択します。

    • All : 全てのソルバーに使用できます。
    • Abaqus : Abaqusのプリテンションコマンドで設定します。


  • 値(Value)

    ボルト締め付け力を入力します。

  • 入力単位系(Input Unit)

    入力単位系を選択します。

  • ボルト固定長(Bolt Fix Length)

    ボルト締め付け量を保持します。

    • - 操作手順 -

    1. 各種剛体を選択して、パラメータを入力します。

    2. OKボタンをクリックします。このダイアログが閉じ、自動ボルト接続(Auto Bolt Connection)の、ボルトタイプのボタンがハイライトされます。
