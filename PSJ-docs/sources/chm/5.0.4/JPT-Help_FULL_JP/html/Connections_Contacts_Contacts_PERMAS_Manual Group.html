グループ指定

指定グループ間にPERMAS用接触設定を定義します。
予めマスター面およびスレーブ面となるグループを作成しておき、接触対毎に接触グループを選択し、接触設定を定義します。
※各パラメータの詳細はインテス社のPERMASマニュアルをご参照ください。

基本

　　　
  • 名前

    接触対の名称を入力します。

    　　　
    • 　　　
  • アルゴリズム(一般接触のみ)

    接触設定対象エンティティを選択します。
        サーフェス-サーフェス節点間: フェース対ノード間接触
        サーフェス間: フェース対フェース間接触

    　　　
    • 　　　
  • タイプ

    接触定義の挙動タイプを選択します。
        一般: 滑り接触
        固着: 固着

    　　　
    • 　　　
  • マスター

    マスター面となるグループを選択します。
        検索: 名称またはIDでグループを検索し、マスター面として定義します。

    　　　
    • 　　　
  • スレーブ

    スレーブ面となるグループを選択します。
        検索: 名称またはIDでグループを検索し、スレーブ面として定義します。

    　　　
    • 　　　
  • スイッチ

    マスター/スレーブセグメントグループを切り替えます。

    　　　

    • コンタクトプロパティ

    　　　
  • 初期隙間(一般接触のみ)

    初期隙間量を入力します。

    　　　
    • 　　　
  • 間隙タイプ(一般接触のみ)

    隙間幅指定値。Gap Typeにより振舞いが異なります。($CONTACT LOAD GAPWIDTH)
    ・ABS: Gap Typeに入力した初期隙間幅は、絶対的な隙間幅として使用されます。 ・ADD: Gap Typeに入力した初期隙間幅は、幾何学的ギャップ幅に追加されます。

    　　　
    • 　　　
  • 接触面法線方向(一般接触のみ)

    特殊条件の指定。($CONTACT LOAD NORMAL)

    　　　
    • 　　　
  • 距離トレランス

    距離検索の許容範囲。($CONTACT SURFACE DISTOL)

    　　　
    • 　　　
  • 境界外トレランス(一般接触のみ)

    境界外の検索許容範囲。($CONTACT SURFACE OUTTOL)

    　　　

    • 摩擦プロパティ(一般接触のみ)

    　　　
  • 摩擦

    摩擦考慮の有無を指定します。
    ・なし: なし。
    ・両面: yCおよびzC方向の摩擦。

    　　　
    • 　　　
  • 方向

    摩擦考慮の有無を指定します。
    ・FREE: 接線方向の自由度は(接触が開いていても閉じていても)接続されないままです。
    ・ISO: 等方性摩擦データ。
    ・ANISO: 異方性(直方性)摩擦データ。

    　　　
    • 　　　
  • 静止摩擦係数 　　

    静摩擦係数を入力します。(ISOの時入力)

    　　　
    • 　 　　　
  • 静止摩擦係数Y 　　

    接線方向のyC方向の静止摩擦係数を入力します。(ANISOの時入力)

    　　　
    • 　　　
  • 静止摩擦係数Z 　　

    接線方向のzC方向の静止摩擦係数を入力します。(ANISOの時入力)

    　　　
    • 　　　 　　　
  • 動摩擦係数

    動摩擦係数を入力します。(ISOの時入力)

    　　　
    • 　　　
  • 動摩擦係数Y

    接線方向のyC方向の動摩擦係数を入力します。(ANISOの時入力)

    　　　
    • 　　　
  • 動摩擦係数Z

    接線方向のzC方向の動摩擦係数を入力します。(ANISOの時入力)

    　　　

    • カップリング自由度(固着のみ)

    　　
  • 方法

    自由度の指定方法
    ・固定: TX-RX固定 ・手動: 自由度を個別に指定

    　　　

    • 色設定

    　　　
  • 接触の色

    接触対表示マーカー色を定義します。
        リセット: デフォルト色に初期化

    　　　

    • - 操作手順 -

      　　　
    1. 予めマスター面、スレーブ面となるフェースもしくは要素面グループを作成しておきます。
      2. 　　　
    2. マスターでマスター面となるグループ、スレーブでスレーブ面となるグループを選択します。
      選択したグループがモデルウィンドウでハイライト表示されます。グループ表示モードをオフにして確認することも可能です。
      検索ボタンよりグループの名称の部分一致検索またはID検索をすることが可能です。
      　　　
    3. 必要により接触対に対する詳細設定を定義し、適用またはOKボタンをクリックします。
