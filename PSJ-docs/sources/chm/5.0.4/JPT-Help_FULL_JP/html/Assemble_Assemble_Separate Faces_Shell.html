シェル

シェルのパーツ間で共有している節点を二重節点に変更します。

共有面分離

　　
  • 選択タイプ

    選択するエンティティのタイプを指定します。

      　　
    • モデル

      モデルに含まれるすべての共有節点を二重節点に変更します。

      　　
    • パーツ

      選択したパーツ間に含まれる共有節点を二重節点に変更します。

      　　
    • エッジ

      選択したエッジ上に含まれる共有節点を二重節点に分けます。
      (選択したエッジの隣接エッジが共有節点の際は、選択エッジ両端の共有節点は 二重節点にはなりません)

    　　　

    - 操作手順 -

      　　　
    1. 選択するエンティティタイプがパーツの場合は、対象のパーツを選択します。モデルの場合は選択しません。エッジの場合は対象のエッジを選択します。
      2. 　　　
    2. 適用/OKボタンをクリックします。
