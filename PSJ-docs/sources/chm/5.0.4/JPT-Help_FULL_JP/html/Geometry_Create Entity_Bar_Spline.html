スプライン

選択した節点を通るスプラインカーブ状のエッジを作成、または、作成したエッジを含むバーパーツを新規に作成します。

パーツ名

  • 名前

       新規にバー パーツを作成する場合に、パーツ名を入力します。


    • - 操作手順(既存のパーツに円弧エッジを作成する場合) -

    1.  複数の節点を選択します。
    2.  適用/OKボタンをクリックします。
    3.  選択した節点が所属するパーツに、選択した節点を通るエッジを作成します。

    - 操作手順(円弧エッジとバー　パーツを作成する場合) -

    1.  複数の節点を選択します。
    2.  名前にパーツ名を入力します。
    3.  適用/OKボタンをクリックします。
    4.  新規にバー　パーツを作成します。そこに選択した節点を通るエッジを作成します。
