  • 名前

    内部発熱条件名を設定します。

    内部発熱量の入力単位系を指定します。

  • テーブル選択

    あらかじめ定義された時刻歴テーブルを選択します。

    　　　

    • - 操作手順 -

      　　　
    1. 内部発熱条件を定義するパーツを選択します。複数の選択が可能です。
      2. 　　　
    2. 内部流束に内部発熱量を入力します。
      3. 　　　
    3. 必要に応じてその他のパラメータを変更します。
      4. 　　　
    4. 適用またはOKボタンをクリックします。
