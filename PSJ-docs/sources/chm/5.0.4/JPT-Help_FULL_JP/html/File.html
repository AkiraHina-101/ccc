Fileリボンメニュー

Jupiterドキュメントに関する操作を行います。

  • 新規作成

    • 新規に空のドキュメントを作成します。

  • 開く

    • 保存済のドキュメント（.jtdbファイル）を開きます。

  • Preドキュメントを追加

    • 現在のドキュメントに、保存済みのPreドキュメント（.jtdb/.jth5ファイル）を追加読み込みします。

  • 保存

    • 現在のドキュメントを.jtdbファイルとして保存します。

  • 別名保存

    • 現在のドキュメントに別名をつけ、.jtdbファイルとして保存します。

  • 閉じる

    • 現在のドキュメントを閉じます。

  • 最近しようしたファイル

    • 使用したファイル名が表示されます。クリックすると開きます。
