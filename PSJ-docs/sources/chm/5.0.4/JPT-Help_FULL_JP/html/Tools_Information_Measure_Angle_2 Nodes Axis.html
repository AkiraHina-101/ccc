角度[2節点の軸]

2つの節点による軸と座標系軸間角度を計測します。

　　

オプション

  • 座標系

       投影先座標系を選択します。

  • 軸

       指定座標系の軸

    • 出力

  • 角度

       計測結果が表示されます。

  • 入力単位系

       表示する角度の単位を指示します。

  • ローカル座標系 XY

       指定座標系XY平面での投影角度

  • ローカル座標系 YZ

       指定座標系YZ平面での投影角度

  • ローカル座標系 ZX

       指定座標系ZX平面での投影角度

    • - 操作手順 -

    1.  画面上から軸となる2つの節点を選択します。
    2.  ローカル座標系で座標系と軸を選択します。
    3.  値に角度、2節点からなる軸をローカル座標系XY(YZ,ZX)平面に投影した角度が表示されます。
