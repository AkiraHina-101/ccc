接続 | 質量要素

質量要素を作成します。

プロパティ

  • 名前

    登録される名前を入力します。

  • 質量値

    質量を入力します。

  • 座標系

    ローカル座標系を入力します。

    • 自由度

  • 自由度

    自由度を選択します。

    • UX - RZ

      自由度を１つだけ定義する場合に選択します。
      ＊Nastran向け出力ファイル（.bdf）ではCMASS2が定義されます。オフセット距離と質量慣性モーメントは無視されます。

    • UXUYUZ

      並進成分の自由度を定義する場合に選択します。
      ＊Nastran向け出力ファイル（.bdf）ではCONM2が定義されます。

    オフセット

  • X1, X2, X3

    節点から質量重心までのオフセット距離を入力します。

    • 慣性

  • I11 - I33

    質量重心まわりの質量慣性モーメントを入力します。

    • 入力単位系

  • 長さ

    長さの入力単位を指定します。

  • 質量要素

    重さの入力単位を指定します。

    • - 操作手順 -

    1. 節点を選択（複数可）します。
    2. 質量値に質量を入力します。
    3. 必要に応じて、他のパラメータを設定します。
    4. 適用/OKボタンをクリックします。
