各パートに対してできるだけ余白が出ないように囲む直方体（バウンディングボックス）を定義し、それらの直方体同士での位置合わせによりパート移動を行う機能です。

※注意
バウンディングボックスの縦・横・高さが同じ場合には、方向が確定できないため位置合わせに失敗する場合があります。

位置合わせは、
  1. 各パートの中心にバウンディングボックスの局所座標系を作成
  2. 局所座標系同士の中心位置を合わせるように移動パートのプレビューを移動
  3. フィット位置の選択肢に従って、中心位置を移動
  4. 回転の入力値に従って、中心位置中心に回転
  5. 平行移動の入力値にしたがって平行移動
の順序で行われます。

フィット位置

  • 座標値

    位置合わせの基準となる位置を指定します。

    • 平行移動

  • X,Y,Z

    • 初期位置合わせ位置から平行移動させたい時に使用します。移動量の刻み幅を各軸の右側にあるテキストボックスに入力し、スピンコントロールで移動量を調節します。

    回転

  • X,Y,Z

    初期位置合わせ位置から回転移動させたい時に使用します。回転量の刻み幅を各軸の右側にあるテキストボックスに入力し、スピンコントロールで回転量を調節します。単位は度です。

    OOBB表示設定

  • 参照フレーム

    参照パートを囲むフレームの表示/非表示、色、線幅を設定します。

  • 移動フレーム

    移動パートを囲むフレームの表示/非表示、色、線幅を設定します。

    • - 操作手順 -

    1. OOBB配置機能を起動します。
    2. 位置合わせの移動先となるパートを選択します。選択リストでは「対象パート」に選択が入力されます。また、自動でフォーカスが「移動パーツ」に移ります。
    3. 移動させるパートを選択します。選択リストでは「対象パート」に選択が入力されます。
    4. バウンディングボックスが表示されます。フィット位置の選択及び平行移動・回転で移動位置を調節します。
    5. 適用またはOKボタンで機能が実行されます。
