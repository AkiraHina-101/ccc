接続 | ばね要素　1対1(閾値) - 異なる自由度

一対一のスカラーばね要素を作成する機能です。

指定された範囲内の選択された節点間に自動でばね要素が定義されます。
この機能では、1stグループ節点と2ndグループ節点で、異なる自由度を結合することができます。 節点IDの若い方が1stグループとして定義されます。

接続

  • 名前

    登録される名前を入力します。

    • 方法

  • 節点間距離トレランス

    接続先の検索範囲を入力します。

    • ばね

  • グラウンド

    接地バネのオプションを指定します。

  • 剛性

    ばね剛性を入力します。

  • 第1Gにおける自由度

    1stグループの自由度を指定します。

  • 第2Gにおける自由度

    2ndグループの自由度を指定します。

  • 減衰係数(Nastran向け)

    減衰係数を入力します。

  • 応力係数(Nastran向け)

    応力係数を入力します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • - 操作手順 -

    1. 節点間距離トレランスを設定します。
    2. メインウィンドウから節点を複数選択します。
    3. ばね剛性を入力します。
    4. 1stグループの自由度と2ndグループの自由度を指定します。
    5. 他のパラメータを設定します。
    6. 適用/OKボタンをクリックします。
