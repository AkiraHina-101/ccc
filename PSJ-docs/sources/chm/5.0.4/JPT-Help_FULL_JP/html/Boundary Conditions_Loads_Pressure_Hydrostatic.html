圧力 | 静水圧

解析モデルに圧力荷重を追加します。

　　

構造

  • 名前

       圧力荷重条件の名前を入力します。

    • 　　

    静水圧 : |r×g×h|

     静水圧荷重の設定をします。
  • 流体密度

       静水圧に参照される流体の密度[r]を入力します。

  • 入力単位系

       流体密度の入力単位を指定します。

  • 重力方向

       モデル内の重力のかかる方向を選択します（全体座標系）。

  • 重力

       重力の値[g]を入力します。

  • 入力単位系

       重力値の入力単位を指定します。

  • 水面高さ

       モデル内の水面の位置の座標[h]を入力します。

  • 入力単位系

       座標値の入力単位を指定します。


    • - 操作手順 -

    1.  選択リストからフェースまたは要素のいずれかのボタンを選択し、画面上から静水圧荷重付加対象を選択します。
    2.  荷重につける名前を入力します。
    3.  流体密度値、重力方向、重力値、水面の座標をそれぞれ入力します。
    4.  適用またはOKボタンを押します。
