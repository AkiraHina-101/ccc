ボルトモデリングタイプD

相対する面のボルト穴周りの指定範囲内をMPCで結合します。

※V4.0よりボルトモデリングコマンドが実行されたときに、作成されたボルト1本ごとにグループを作成します。
ボルトグループはBolt Connectionサブグループの下に置かれます。


ボルトモデリング

  • MPC名

    作成するMPCアイテムの名前を入力します。

  • ボルトイメージを表示

    ボルトの概要図を表示します。作成するボルトタイプの変更が可能です。

  • 接続半径

    MPCで結合する範囲、半径Rを入力します。

  • 平面トレランス

    MPCが作成されるフェースが平面でない場合のMPC作成限界角度を指定します。

    • - 操作手順 -

    1. 選択リストを開き、上面エッジのボタンをクリックします。
    2. トップ側の対象エッジを選択します。（複数選択可能）
    3. 選択リストの底面エッジのボタンをクリックします。
    4. ボトム側の対象エッジを選択します。（複数選択可能）
    5. 接続半径に結合する範囲、半径Rを入力します。
    6. 適用またはOKボタンをクリックします。
