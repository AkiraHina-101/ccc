節点-エッジ間

CAD投影(節点からエッジ） ダイアログボックス

メッシュパーツの中間節点やコーナー節点を、選択した節点のみ CAD形状のエッジ上に乗せることができます。

オプション

  • 方向

    プロジェクション方向を指定します。

    • 最小

      フェースへの最短距離方向にプロジェクションします。

    • X/Y/Z/-X/-Y/-Z

      選択した方向の選択した正負の方向にある選択したCADエッジまで プロジェクションします。


    • - 操作手順 -

    1. 選択リストのCADエッジボタンを押し、画面からプロジェクション ターゲットとなるエッジを選択します。
    2. 選択リストのメッシュド節点ボタンを押し、画面からプロジェクション対象 となるメッシュパーツの節点を選択します。
    3. 必要に応じて方向のオプションを変更します。
    4. 適用またはOKボタンをクリックしてプロジェクションを実行します。
      選択した節点がCADモデルのエッジ上に移動します。
