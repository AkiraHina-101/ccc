ADVC | 熱伝導解析

ADVENTURECluster(以後ADVC)の伝熱解析向けの入力ファイルを出力します。

温度の拘束条件に関し、同じ節点自由度に対して重複した場合、かつ設定されている値が異なる場合、ワーニングメッセージを表示します。
重複判定は、各プロセス毎かつ各項目毎に判断されます。

/

ADVCジョブ

  • ジョブ名

       ADVCジョブの名前を設定します。

  • ジョブの説明

       ジョブの説明を記載します。

  • ジョブタイプ

       解析種別の選択します。

    • 構造 : 構造解析

    • 熱伝導 : 伝熱解析
      •

    • ADVCプロセス

  • プロセスを作成

       プロセスを作成するADVCプロセス設定ダイアログを起動します。

    • 間隔の定義

  • LBCマネージャ

       境界拘束条件やロードケースを設定するLBCマネージャダイアログを起動します。

  • 接触マネージャ

       接触条件の状態を設定する接触マネージャダイアログを起動します。

    • 出力定義

  • 出力マネージャ

        チェックボックスを選択し、出力要求を設定する出力マネージャダイアログを起動します。

    • オプション

  • フォーマットタイプ

        節点、境界条件のデータを単精度（シングル）で出力するか、倍精度（ダブル）で出力するかを選択します。

    • シングル : 単精度で出力します。書式は%13.6eです。
    • ダブル : 倍精度で出力します。書式は%23.15eです。

  • グループ出力

        フェース、要素、節点グループを$SurfaceSegment、$ElementSet、$NodeSetとして出力します。

  • ファイル分割単位

        節点、要素データのみ別ファイルで出力します。解析規模が大きい場合、分けて出力することで解析制御用の入力ファイルのサイズが小さくなり、手入力によるコマンド変更が容易になります。

    • なし : 全データを一つのファイルに出力します。
    • モデル : 節点、要素データを 1つの別ファイルで出力します。
    • パーツ毎 : 節点、要素データを パーツ毎に別ファイルで出力します。
    • 選択したパーツのみ : 選択したパーツに関連する LBC をすべて出力します。
    • 選択した境界条件のみ : 選択した境界条件のみファイル出力します。
      •

  • 境界条件

       ファイル分割単位がパーツの場合に、境界条件、接触対、接触セグメントを別ファイルに出力します。

  • エンティティ名を使用

        Jupiter上のエンティティ名を使用してファイル出力します。


  • 関連するすべてのLBCを出力

        選択したパーツに関連するLBCをすべて出力します。


  • 浮遊点削除

       チェックすると、モデル内の使用されない浮遊節点が削除されて出力します。


  • 熱伝達

       熱伝達係数の指定方法を選択します。（直接入力、参照入力）

    • ADVCプロセス設定ダイアログ

       過程の設定を行います。

  • プロセス名

       過程名を指定します。

  • プロセスを個別に設定

       1つずつ過程を定義します。

  • 複数プロセスを設定

       複数の同一内容の過程を定義します。

  • プロセス数

       過程数を指定します。

  • ジョブタイプ

       解析タイプを選択します。

    • 熱伝導 : 伝熱解析
      •
  • 解法タイプ

       解法タイプを選択します。

    • Transient : 非定常熱伝導解析

    • Steady State : 定常熱伝導解析
      •
  • 終了条件

       解析終了条件を指定します。

  • 終了タイプ

       解析終了条件を選択します。

    • Max Time : 解析時間を指定します。

    • Stedy Rate : 定常状態終了となる単位時間当たりの温度変化の最大値を指定します。

    • Both : 最大時間と一定温度の両方を指定します。
      •
  • 最大時間

       解析時間を指定します。

  • 一定温度

       定常状態終了となる単位時間当たりの温度変化の最大値を指定します。

  • 増分

       時間増分数を指定します。

  • タイプ

       時間刻みの方法を選択します。

    • Auto : 自動時間刻みを指定します。

    • Fixed : 固定時間刻みを指定します。
      •
  • 最大温度変化量

       最大温度変化を指定します。

  • 初期変化時間

       初期変化時間を指定します。

  • 最大変化時間

       時間刻み幅の上限を指定します。

  • 最小変化時間

       時間刻み幅の下限を指定します。

  • 固定変化時間

       固定変化時間を指定します。

  • 出力間隔の定義

       構造 の プロセスを作成、出力間隔の定義 ご参照

        開始結果出力: 過程開始時点の結果出力を指定します。
        出力間隔: サーモスタットでの履歴出力間隔を指定します。

  • 収束パラメーター

       構造 の プロセスを作成、収束パラメーター ご参照

  • 接触パラメーター

       構造 の プロセスを作成、接触パラメーターご参照

  • パラメーター自動増分

       構造 の プロセスを作成、パラメーター自動増分 ご参照

    • ※その他、各解析用パラメーターに関しては、ADVCのマニュアルをご参照ください。

    LBCマネージャダイアログ

  • 左に移動

       選択したプロセスを左の列に移動します。

  • 右に移動

       選択したプロセスを右の列に移動します。

  • プロセス編集

       プロセス設定内容を編集します。

  • プロセスを削除

       プロセスを削除します。

  • アクティブ

       表示された条件を有効にします。

  • 非アクティブ

       表示された条件を無効にします。

  • 設定ファイル出カ

       LBCマネージャーは.csvファイル形式で出カされます。

  • 設定ファイル読み

       LBCマネージャーは、読み.csvファイルによって設定されます。

  • OK

       設定した内容を保持してダイアログを閉じます。

  • キャンセル

       設定した内容を破棄してダイアログを閉じます。

  • LBCフィルタ

       条件表示にフィルターをかけます。

    • すべて : 全ての条件を表示します。

    • 荷重 : 荷重条件のみ表示します。

    • BC : 拘束条件のみ表示します。

    • 温度 : 温度条件のみ表示します。

    • 検索 : 入力されたキーワードから条件を表示します。
      •

    • 接触マネージャダイアログ

  • 検索

       入力されたキーワードから条件を表示します。

  • Contact Name

       接触条件名を表示します。

  • Parameters

       設定条件の項目を表示します。

    • Status : 接触条件の有効/無効を表示します。

    • Interference : 干渉量/間隙量を指定します。

    • Shrink : 貫入解消を指定します。

    • Stabilization : 接触安定化パラメータを設定します。

    • Set : 接触安定化パラメータ設定ダイアログを表示します。

      • ※全プロセスを対象とした接触安定化用のチェックボックスとSETボタンが追加されました。
       チェックON/Offで全てのProcessに反映させることができます。
  • 接触の安定化ダイアログ

       接触安定化パラメータを設定します。

    • 残留ファクター : 残留要因

    • 有効距離 : 影響の適用距離

    • タイプ : 入力タイプ

      •    剛性 : 剛性比例型

         面積 : 面積比例型


    • 法線方向安定化係数 : 法線方向安定化係数

    • 接線方向安定化係数 : 接線方向安定化係数
      •
  • アクティブ

       表示された条件を有効にします。

  • 非アクティブ

       表示された条件を無効にします。

  • M/Sを入れ替え

       接触条件のマスター面とスレーブ面を入れ替えます。

  • Reference Data Directory

       伝熱解析時の接触面での熱伝達係数定義向けに、接触状況を参照する構造解析結果を指定します。
    合わせてダイアログテーブル内ReferenceContactStateのProcess Numberでその構造解析結果で参照するプロセス番号を入力します。

    • 出力マネージャダイアログ

  • すべてのプロセスで同じ出力

       すべてのプロセスへ設定した出力パラメータを適用します。

  • プロセス

       設定する出力パラメータのプロセスを指定します。

  • 出力グループ設定

       指定したグループのみ結果出力させることができます。

  • OK

       設定を確定しダイアログを閉じます。

  • キャンセル

       設定を確定せずにダイアログを閉じます。

    • リスタートデータ参照

  • データディレクトリ

       リスタートファイルがあるディレクトリを入力します

  • プロセス番号

       リスタートデータのプロセス番号を指定します。

  • ステップ番号

       ステップ番号にはリスタートデータのステップ番号を指定します。

  • 座標タイプ

       初期  : 変位がリスタート前も含めたトータルの値となります。

       変形  : 変位がリスタート後の変形成分のみとなります。

  • 接触探索更新

       はい : 座標タイプに変形の指定がない場合、いいえ と同じ挙動となります。

       いいえ : 接触探索は、リスタートデータの結果を引き継ぎます。

    • ADVC 定型文

  • テンプレートファイル

       ADVCテンプレートフォルダごとにフォルダに保存されているすべてのテンプレート.adxファイルを表示します。

  • 編集

       選択したテンプレート.adxファイルを編集できます。

    ダミープロパティ

    　　ダミープロパティの設定を行います。

  • 自動割り当て

       チェックを入れると、プロパティが割り当てられていないパーツにダミープロパティを自動で割り当てます。

  • 材料

       ダミープロパティを割り当てるパーツの材料を指定します。
       材料コマンドのユーザーデータベースに登録済の材料が選択可能です。ユーザーデータベースに材料未登録の場合、登録済でもブランクを選択した場合はダミー材料を割り当てます。
       ダミー材料の場合、材料特性値は書かれない状態で出力されます。

  • 出力ジオメトリーID

       チェックを入れると、フェースID、エッジID、パートIDなどのエンティティIDが出力されます。

    • 解析テンプレート設定

  • .csvテンプレートを使用してLBCマネージャーを定義する:

       チェックボックスを選択して、.csvファイルを使用してLBCマネージャーを定義します。

  • ファイル :

       .csvファイルを選択します。

  • .csvテンプレートを使用して接触マネージャーを定義する:

       チェックボックスを選択して、.csvファイルを使用して接触マネージャーを定義します。

  • ファイル :

       .csvファイルを選択します。

  • テンプレート: すべてのADVCテンプレート.xmlファイルを保存して表示します。
    デフォルトのフォルダは　C:\Users\XXX\AppData\Roaming\TechnoStar\JPT5.0.0\AnalysisSetting\ADVC
  • 削除 : 選択したテンプレートが削除されます。
  • 追加 : 現在のADVC設定ダイアログが入力名として保存されます。

    - 操作手順 -

    1.  ジョブ名を指定します。
    2.  プロセスを作成でプロセスを作成します。デフォルトの時間刻みで解析を行う場合は、特に必要ありません。
    3.  LBCマネージャでプロセスに境界条件を割り当てます。
    4.  出力マネージャで出力項目を選択します。
    5.  適用/OKボタンをクリックします。
