Nastran | 線形静解析(SOL 101)

Nastranの線形静解析(SOL101)用入力データを出力します。

ジョブオプション

　　　
  • ジョブ

    プログラム: Nastranのタイプを選択します。
        MSC: MSC Nastran
        NX: NX Nastran
    ジョブ名: ジョブ名を入力します。ツリーにこの名称で出力設定が保存されます。
    ジョブの説明: ジョブの説明を入力します。

    　　　
    • 　　　
  • ソルバーオプション

    方法: 解法を選択します。
        直接法: 直接法
        反復法: 反復法
    イプシロン値: 反復法での収束パラメータを指定します。
    Nastranを実行: ローカルマシン上のNastranを実行します。
    メモリー (MB): メモリ割り当て量を定義します。

    　　　
    • 　　　
  • システムセルとFMS

    システムセル: Nastran(System)セクションにデータカードを直接入力します。

    システムセルテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。
    ファイル管理セクション: ファイル管理文セクションにデータカードを直接入力します。
    FMSテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。

    　　　
    • 　　　 　　　
  • モデル単位系を出力

    解析入力データの単位系設定を行います。

    　　　
    • 　　　
  • 実行コントロールオプション

    GEOMCHECK, NONE: 形状チェックオプションを無効にします。
    直接テキスト入力: エグゼクティブコントロールセクションにデータカードを直接入力します。
    実行テンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。

    　　　
    • 　　　
  • ケースコントロールオプション

        ECHO: バルクデータのエコー出力を定義します。
        NONE: 出力なし
        SORT: ソート出力
        UNSORT: 未ソート出力
        BOTH: ソートおよび未ソートの両方出力
        TITLE: プリント出力時のタイトルを定義します。
        直接テキスト入力: ケースコントロールセクションにデータカードを直接入力します。
        ケースコントロールテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
        編集: 選択した.bdfファイルが編集されます。

    　　　
    • 　　　
  • バルクデータオプション

        出力タイプ: 出力対象を指定します。
        モデル: 一つのファイルに出力
        パーツ毎: パーツ毎にファイルを分けて出力
        選択したパーツ: 選択されたパーツのみ出力
        グリッドフォーマットタイプ: GRIDカードの出力フォーマットを変更します。
        シングル: スモールフィールドフォーマット出力
        ダブル: ラージフィールドフォーマット出力
        シングル浮動小数点: 指数不使用のスモールフィールドフォーマット出力
        浮遊節点を削除: データ出力時に浮遊節点を削除します。
        継続行マーク +: データ出力時に継続ポインタ+を出力します。
        バルクデータを含める: バルクデータファイルを挿入します。
        テキスト入力: バルクデータセクションにデータカードを直接入力します。
        バルクデータテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
        編集: 選択した.bdfファイルが編集されます。

    　　　

    • 荷重 / 境界条件


    　　　
  • ベース

    SUBCASE指定の上に定義する解析全体に作用する境界条件を定義します。
    各境界条件で使用する境界条件ケースを指定します。Defaultには全ての境界条件が含まれます。

    LOAD: 荷重ケースを指定します。
    SPC: 拘束ケースを指定します。
    MPC: 多点拘束ケースを指定します。
    初期温度: 初期温度ケースを指定します。
    温度荷重: 熱荷重ケースを指定します。
    LBC IDを定義: 荷重、拘束、多点拘束の識別IDを指定します。
    固有ID: 荷重、拘束、多点拘束でそれぞれ固有のIDが自動指定されます。

    　　　
    • 　　　
  • サブケースオプション

    SUBCASEを定義します。
    各SUBCASEで使用する境界条件ケースを指定します。

    既存 ID: 既存SUBCASE IDを指定します。
        追加: 新規SUBCASEの追加
        削除: 既存SUBCASEの削除
        適用: 既存SUBCASEの更新
    ID: SUBCASE IDを指定します。
    Subtitle:プリント出力時のタイトルを入力します。
    LOAD: 荷重ケースを指定します。
    SPC: 拘束ケースを指定します。
    MPC: 多点拘束ケースを指定します。
    DISPLACEMENT: 変位出力要求を指定します。
    応力: 要素応力出力要求を指定します。
    ひずみ: 要素応力出力要求を指定します。
    直接テキスト入力: SUBCASEにデータカードを直接入力します。

    　　　

    • 出力要求


    　　　
  • 結果タイプ

    出力要求を指定します。
        PLOT: op2出力
        PRINT: f06出力
        PLOT&PRINT: op2およびf06出力
        ブランク: 未出力

    DISPLACEMENT: 変位出力要求を指定します。
    SPC力S: 単点拘束力出力要求を指定します。
    OLOAD: 作用荷重出力要求を指定します。
    MPC力S: 多点拘束力出力要求を指定します。
    応力: 要素応力出力要求を指定します。
    ひずみ: 要素応力出力要求を指定します。
    力: 要素力出力要求を指定します。
    ESE: 要素応力エネルギー出力要求を指定します。

    　　　
    • 　　　
  • 結果に出力するグループ(SET)の選択

    結果出力する範囲を要素、節点グループ(セット)を指定して制限します。
        すべて: 全要素、全節点に対して出力
        グループ: 指定グループ内の要素、節点に対して出力

    DISPLACEMENT: 変位出力要求に対して出力範囲を指定します。
    SPC力S: 単点拘束力出力要求に対して出力範囲を指定します。
    OLOAD: 作用荷重出力要求に対して出力範囲を指定します。
    MPC力S: 多点拘束力出力要求に対して出力範囲を指定します。
    応力: 要素応力出力要求に対して出力範囲を指定します。
    ひずみ: 要素応力出力要求に対して出力範囲を指定します。
    力: 要素力出力要求に対して出力範囲を指定します。
    ESE: 要素応力エネルギー出力要求に対して出力範囲を指定します。

    　　　

    • パラメーター


    　　　
  • パラメーター

    パラメータを定義します。

    POST: ポスト処理用結果ファイルの出力タイプを指定します。
        0: XDB出力
        -1: op2(Patran向け)出力
        -2: op2(I-DEAS向け)出力
    OGEOM: OP2への形状出力を制御します。
        YES: 形状出力あり
        NO: 形状出力なし
    AUTOSPC: 剛性特異性の自動拘束を制御します。
        YES: 自動拘束
        NO: 自動拘束なし
    GRDPNT: 重量情報出力を制御します。
    WTMASS: 質量補正係数定義します。
    K6ROT: シェル要素法線回転剛性に対する付加係数を定義します。
    MAXRATIO: マトリクス擬似特異判定比率を定義します。
    BAILOUT: 擬似特異性に対する実行を制御します。
        0: 継続実行
        -1: 終了
    PRGPST: 特異性サマリーテーブルのプリント出力を制御します。
        YES: 出力あり
        NO: 出力なし

    　　　
    • 　　　 　　

    その他の設定


  • ダミープロパティ

    ダミープロパティの設定を行います。

    自動割り当て: チェックを入れると、プロパティが割り当てられていないパーツにダミープロパティを自動で割り当てます。
    出力ジオメトリーID: チェックを入れると、フェースID、エッジID、パートIDなどのエンティティIDが出力されます。
    材料: ダミープロパティを割り当てるパーツの材料を指定します。
            材料コマンドのユーザーデータベースに登録済の材料が選択可能です。ユーザーデータベースに材料未登録の場合、登録済でもブランクを選択した場合はダミー材料を割り当てます。
            ダミー材料の場合、材料特性値は書かれない状態で出力されます。

  • 解析テンプレート設定

    Nastranダイアログの解析パラメータは、テンプレートファイルを読込することで自動設定されます。

    テンプレート: すべてのNastranテンプレート.xmlファイルを保存して表示します。
    デフォルトのフォルダは　C:\Users\XXX\AppData\Roaming\TechnoStar\JPT5.0.0\AnalysisSetting\Nastran
    削除: 選択したテンプレートが削除されます。
    追加: 現在のNastran設定ダイアログが入力名として保存されます。

    • - 操作手順 -

    　　　
  • 一般的な出力方法(SUBCASEを定義しない場合) 　　　
      • 　　　
    1. 荷重 / 境界条件などはデフォルトのまま、Post処理用に出力する結果を選択する場合は出力要求の各結果でPLOTを選択します。
      2. 　　　
    2. 適用(OK)ボタンをクリックして、入力データファイル名を定義して出力します。


    　　　
  • SUBCASEを定義する場合(例:拘束条件一定、荷重条件をSUBCASE毎に変更) 　　　
      • 　　　
    1. 予め境界条件 > ロードケースコマンドで荷重ケース、拘束ケースなどを定義しておきます。
      2. 　　　
    2. 荷重 / 境界条件のベース>LOADでブランクを選択し、SPCで全SUBCASEで使用する拘束ケースを選択します。
      3. 　　　
    3. サブケースオプション>IDにSUBCASE番号を入力し、LOADで使用する荷重ケースを選択し、Addボタンをクリックします。
      4. 　　　
    4. サブケースオプション>IDに次のSUBCASE番号を入力し、LOADで使用する荷重ケースを選択し、Addボタンをクリックします。
      5. 　　　
    5. その他必要なオプションを定義し、適用(OK)ボタンをクリックして、入力データファイルを出力します。下図のようなSUBCASE設定が出力されます。


    　　　
  • SUBCASEの編集方法(例:SUBCASE1の削除とSUBCASE2の荷重ケース変更) 　　　
      • 　　　
    1. Assemblyツリー下の解析設定を右クリックしEditを選択します。Nastran出力のダイアログが開きます。
      2. 　　　
    2. Loading / Boundary ConditionsのSubcase Option>Existing IDで1を選択し、Removeボタンをクリックすると、SUBCASE1が削除されます。
      3. 　　　
    3. Existing IDで2を選択し、LOADで別の荷重ケースを選択し、Applyボタンをクリックすると、SUBCASE2の内容が変更されます。
      4. 　　　
    4. その他必要なオプションを定義し、Apply(OK)ボタンをクリックして、入力データファイルを出力します。
