ロゴ部 削除

ロゴやボルトを構成するフェースを、自動的に削除します

ロゴ部 削除

  • ロゴ部またはボルト穴のフェース

    削除したいロゴやボルトの一部のフェースを選択します。

  • 停止フェース

    削除したい形状に隣接した（残したい）フェースを選択します。

  • フェースをマージ

    チェックを入れるとロゴやボルトを削除後に隣接面(Stop Face)と結合します。

  • 削除の深さ(レイヤー）

    ボルトの削除の際、選択した削除したいフェースからの深さ方向のレイヤ数を指定します。

    • - 操作手順 -

    1. Start Faceのフェースを選択します。
    2. Stop Faceのフェースを選択します。
    3. 他のパラメータを設定します。
    4. 適用/OKボタンをクリックします。
