接触 | SunShine - フェース指定

指定フェース間に接触設定を定義します。
マスター面となるフェース、およびスレーブ面となるフェースを選択し、接触設定を定義します。



基本

  • 名前

       接触対の名称を入力します。

  • アルゴリズム

       接触設定対象エンティティを選択します。

    • フェース-フェース: フェース対フェース間接触
  • タイプ

       接触定義の挙動タイプを選択します。

    • 一般接触 : (IGLUE:0)滑り接触
    • 固着 : (JGLUE:0)固着
    • 滑り可能固着 : (JGLUE:1)摩擦なし滑り可能な固着
  • マスター

       マスター面となるフェースを選択します。

  • スレーブ

       スレーブ面となるフェースを選択します。

  • M/S入替

       マスター/スレーブセグメントグループを切り替えます。

    • コンタクトプロパティ

  • 接触距離範囲(ERROR)

       節点がボディに接触していると見なされる距離。

  • 摩擦係数(FRIC)

       摩擦係数。

  • 干渉閉鎖距離(CINTERF)

       接触フェースに垂直な方向の干渉閉鎖量。
       CINTERF>0 の場合、ボディ間のオーバーラップ。
       CINTERF<0 の場合は、ボディ間のギャップ。

  • 接触面延伸距離(SLIDE)

       接触面延伸距離。
       ICOORD >= 2 でない限り、この入力は行わないでください。
       接触面延伸距離オプションを使用する場合、セグメント上をスライドする節点は、設定値以上に鋭角上の節点やエッジを超えて通る場合のみセグメントから滑り落ちます。

  • 節点の座標修正（ICOORD)
    • 無し : (0) このオプションを無視します。
    • 位置を修正 : (1) 変形パーツと接触しているノードの座標を修正して，応力のない初期接触が得られるようにします。
    • 滑り出し遅れ : (2) 接触したセグメントから滑り落ちるのを遅らせるために、ボディコーナーでの接線誤差の許容範囲を拡張します。
    • 両方を有効化 :  (3) 位置を修正と滑り出し遅れの両方を有効化します。
  • 固着接着タイプ
    • ペナルティ法 : (IGLUE:1)ペナルティ法を使用します。
    • MPC法 : (IGLUE:2)内部的に多点拘束(MPC)を使用します。
      *安定的ですが他の拘束自由度との重複に注意が必要です。
      •
  • ペナルティファクタ(SFACT)

       ペナルティ法スケール係数。

  • ペナルティファクタ(SFACT T)

       ペナルティ法接線スケール係数。

  • 接触ダンピング(CDAMP)

       接触減衰係数。

  • シェル要素フェース(スレーブ)

       シェル要素面（スレーブ）には、次のオプションがあります。

    • 裏・板厚考慮 : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
    • 裏・板厚考慮しない : 接触の説明には底面のみが含まれ、シェルの厚さは無視されます。
    • 表・板厚考慮 : 接触の説明には上面のみが含まれ、厚さのオフセットが含まれます。
    • 表・板厚考慮しない : 接触の説明には上面のみが含まれ、シェルの厚さは無視されます。
  • シェル要素フェース(マスター)

       シェル要素面（マスター）には、次のオプションがあります。

    • 裏・板厚考慮 : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
    • 裏・板厚考慮しない : 接触の説明には底面のみが含まれ、シェルの厚さは無視されます。
    • 表・板厚考慮 : 接触の説明には上面のみが含まれ、厚さのオフセットが含まれます。
    • 表・板厚考慮しない : 接触の説明には上面のみが含まれ、シェルの厚さは無視されます。

    • 色設定

  • 接触の色

       接触対表示マーカー色を定義します。

    • リセット: デフォルト色に初期化

    • - 操作手順 -   

    1.  マスターでマスター面となるフェースを選択します。続いてスレーブでスレーブ面となるフェースを選択します。
    2.  必要により接触対に対する詳細設定を定義し、適用（OK）ボタンをクリックして接触対を定義します。
