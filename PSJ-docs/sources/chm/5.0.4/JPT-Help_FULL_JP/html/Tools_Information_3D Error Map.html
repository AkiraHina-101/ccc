3D誤差マップ(3D Error Map)

2つのパーツ（計測対象、基準）の、表面誤差を計測します。

コンター表示のほかに、表面誤差ごとの節点グループ（3D Error Map）を作成できます。

主な用途は下記を想定しています。

  • メッシュとCADの表面誤差を計測します。例えば、メッシングによりフィレットがなくなると、剛性が変わります。本機能により、解析前に表面誤差を計測して、事前修正ができます。
  • 撮像データとCAD/メッシュの表面誤差を計測します。本機能により、リバースエンジニアリング結果の精度を確認できます。

選択リスト

計測パーツ(Measure Part)：計測するパーツ（リファレンスパーツの選択は不可）
基準パーツ(Criterion Part)：基準のパーツ

計測(Measurement)

  • 主節点(Corner)

    • コーナー節点の表面誤差を計測します。

  • 主節点＋中間節点(Corner + Mid )

    • コーナー節点と中間節点の表面誤差を計測します。

    コンター(Contour)

  • 桁数(Num. Digits)

    • 表示する表面誤差の小数点桁数です。

  • 分割数(Num. Division)

    • コンターの分割数です。

  • 最大／最小(Max/Min)

    • コンターの最大最小値です。

  • 表示／非表示（更新）(Show/Hide(Update))

    • コンター表示／非表示の切替（更新）を実行します。

    グループ(Group)

  • 桁数(Num. Digits)

    • グループ作成する表面誤差の小数点桁数です。

  • 最大／最小(Max/Min)

    • グループ作成する表面誤差の最大最小値です。

  • グループ作成（更新）(Create Group(Update))

    • 専用のグループツリーで節点グループの作成（更新）を実行します。

    - 操作手順（誤差計算） -

    1. 計測パーツ(Measure Part)を選択します。
    2. 基準パーツ(Criterion Part)を選択します。
    3. 適用(Apply)をクリックします。
    4. 計測パーツの表面節点の誤差を、メモリに計算します。
    5. 表示／非表示（更新）(Show/Hide(Update))とグループ作成（更新）(Create Group(Update))が有効になります。

    - 操作手順（コンター表示 ※表面誤差計算の後に可能） -

    1. コンターのパラメータを入力します。
    2. 表示／非表示（更新）(Show/Hide(Update))をクリックします。
    3. コンターが表示／非表示（更新）されます。

    - 操作手順（節点グループ作成 ※表面誤差計算の後に可能） -

    1. グループのパラメータを入力する。
    2. グループ作成（更新）(Create Group(Update))をクリックする。
    3. 表面誤差ごとの節点グループが作成（更新）されます。

    - 特記事項 -

    • 検索範囲に基準メッシュがない場合は、"1.7976931348623158e+308"がエラー値として設定されます。
