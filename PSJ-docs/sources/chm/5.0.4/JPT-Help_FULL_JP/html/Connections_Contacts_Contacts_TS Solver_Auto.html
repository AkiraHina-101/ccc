コンタクト検索

複数パーツのアッセンブルモデルに対して、パーツ間の接触条件を自動的に検索し接触条件を追加します。



コンタクト

  • 方法

       自動検索のみ選択できます。

  • トレランス

       2枚の隣接するフェースが接触していると判定する距離を入力します。

  • マスター基準

       検索されたフェースペアに関して、どちらを接触条件のマスター側にするか決定する計算方法を選択します。

    • メッシュサイズ : メッシュのサイズで計算
                          比較対象は、検索されたペア面の中にある要素エッジの平均長さです。
                          平均の長さが長い方をマスターとします。
    • 面積          : 面積で計算（フェース単位）
      •
  • コンタクト検索

       ボタンを押すとコンタクトの検索を始めます。
       パーツを選択せずに実行する際は、パーツ全体で検索を実行することに対する意思確認メッセージが表示されます。

  • 円筒面優先

       チェックを入れると円筒面の接触を優先的に検索します。

  • 干渉閉鎖距離

       ソルバーに2つのフェースが接触している判定距離を指示します。

  • 入力単位系

       トレランスと干渉弊社距離の入力単位系を指定します。

  • 検索

       コンタクト検索結果に対して、左側のテキストボックスにパーツ名または面IDを入力して絞り込み表示を行います。

  • クリアー

       絞り込み表示を解除します。

  • コンタクトデータベース

       コマンド立ち上げ時に既存の接触条件の一覧表示をします。
       また、コンタクト検索ボタンで検索された、接触しているフェースペアの一覧表示をします。

    • No.                 : 検索された順に通し番号が振られます。
                               ID番号の先頭にはチェックボックスが表示され、チェックされた場合のみ接触設定が作成されま。
    • マスターキー    : マスター側に検索されたフェース ID（パーツ名）が表示されます。
    • スレーブキー       : スレーブ側に検索されたフェース ID（パーツ名）が表示されます。
    • コンタクトタイプ : 接触設定のタイプが固着、一般から表示されます。デフォルトは固着が選択されています。
      •
  • すべて選択

       No.のチェックボックスををすべてチェックし、行全てをハイライトします。

  • マスター/スレーブ入替

       各行に表示されているマスターとスレーブのフェースを入れ替えます。ハイライト行のみが対象になります。

  • 固着/一般入替

       各行に表示されている固着と一般のコンタクトタイプを切替えます。ハイライト行のみが対象になります。

  • 関連部品表示

       チェックを入れると選択中のフェースペアに関連する部品が表示されます。


    • - 操作手順 -  接触条件を新規作成する場合 

    1.  パーツボタンを押し、画面上から接触設定の対象となるすべてのパーツを選択します。デフォルト(パーツ未選択状態)では全てのパーツ間の接触を検出します。　
    2.  必要に応じてトレランスの値をデフォルト値から変更します。
    3.  必要に応じてマスター側フェースの検索アルゴリズムを切り替えます。
    4.  必要に応じて干渉閉鎖距離の値をデフォルト値から変更します。
    5.  必要に応じてトレランス、干渉閉鎖距離入力の入力単位系を切り替えます。
    6.  ⌈コンタクト検索⌋を押します。フェースペアの検索結果がリスト表示されます。
    7.  リストの各行を選択すると、画面上にフェースが選択表示されます。このときマスター側フェースは赤、スレーブ側フェースは青色で表示されます。
    8.  接触設定の必要ないフェースペアがあれば、チェックボックスを外し、作成されないように切り替えます。
    9.  切り替えたい行のみ選択し、⌈マスター/スレーブ入替⌋ボタンでマスター側とスレーブ側のフェースを入れ替えます。
    10.  切り替えたい行のみチェックボックスをチェックし、⌈固着/一般入替⌋ボタンでコンタクトタイプを固着または一般に切り替えます。
    11.  作成したい行のみチェックボックスをチェックし、適用またはOKを押します。

    - 操作手順 -  既存の接触条件がある場合（確認目的のみで利用できます） 

    1.  アッセンブルツリーからすべてのコンタクトを非表示にします。
    2.  コマンドを立ち上げると、既存の接触条件の一覧が表示されます。
    3.  リストの各行を選択すると、画面上にフェースが選択表示されます。
          この時、マスター側フェースは赤、スレーブ側フェースは青色で表示されます。
    4.  確認後、OKまたはキャンセルボタンを押してダイアログを閉じます。
