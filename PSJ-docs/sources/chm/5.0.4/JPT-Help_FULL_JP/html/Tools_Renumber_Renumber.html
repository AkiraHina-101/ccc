リナンバー

節点・要素に割り振られているIDを振り直します（リナンバー）。

一般設定

  • 設定
    • パーツ
      パーツ対象にリナンバを行います。
    • グループ
      パーツ対象にリナンバを行います。
  • ターゲット
    • 節点
      節点IDのリナンバーを行います。
    • 3D 要素
      ソリッド要素IDのリナンバーを行います。
    • 2D 要素
      面要素IDのリナンバーを行います。
    • 1D 要素
      1D要素IDのリナンバーを行います。
    • エッジ
      エッジIDのリナンバーを行います。
    • フェイス
      フェイスIDのリナンバーを行います。
  • 自動リナンバー

       一番上の行の開始IDから順に連番でIDを振ります。

    • リスト

    リナンバ対象のリストを表示します。

  • パーツID

       パーツIDを表示します。

  • 名前

       パーツ名を表示します。

  • ID数

       パーツに含まれるターゲットの数を表示します。

  • 開始 ID

       リナンバ後のパーツの最小IDを入力します。起動時には、現在のパーツの最小IDが表示されます。

  • 終了 ID

       リナンバ後のパーツの最大IDが表示されます。起動時には、現在のパーツの最大IDが表示されます。

  • 有効

       チェックが入ったアイテムは、リナンバ及び自動リナンバーの対象となります。

    • オプション

  • 競合の解決

       共有節点・共有面要素のIDの振り方を決めます。

    • より小さいID(<)
      共有節点/面要素のIDは、パーツIDの小さい方に所属します。
    • より大きいID(>)
      共有節点/面要素のIDは、パーツIDの大きい方に所属します。
  • プロパティ割当済エンティティのみ表示

       プロパティを割り当てた要素のみリストに表示します。

  • 表面一次節点からリナンバ

       各パーツでの節点のID並び順が表面1次節点→表面2次節点→ソリッド内部節点の順に昇順となるようにリナンバーします。
       （ターゲットが節点の場合のみ利用可能。）

    - 操作手順 -

    1.  リナンバー対象を、設定及びターゲットから選択します。
    2.  モデルに共有面がある場合、オプションの競合の解決から、共有面上のターゲットをパーツIDの大きい方・小さい方どちらに所属させるのかを指定します。（デフォルト：より小さいID）
    3.  リナンバー対象を、設定及びターゲットから選択します。
    4.  ターゲットが1D/2D/3D要素で、かつ、プロパティ未割り当ての要素に対してリナンバーを行いたい場合、オプションの「プロパティ割当済エンティティのみ表示」チェックボックスをOFFにします。
    5.  リナンバーを行いたい行の、「有効」欄のチェックをONにします（デフォルト：ON）。
    6.  開始 IDに任意のIDを入力します。終了IDに、開始ID＋ID数-1が入力されます。
    7.  適用またはOKボタンを押します。

    - 操作手順（自動リナンバー機能） -

    1.  リナンバー対象を、設定及びターゲットから選択します。
    2.  リナンバーを行いたい行の「有効」欄のチェックをONにします（デフォルト：ON）。
    3.  自動リナンバーボタンをクリックすると、１行目から順に、すべての行に１から順に自動でIDが割り振られます。
    4.  行を左マウスクリックしてハイライトすると、その行のみ自動で１からIDが割り振られます。CtrlもしくはShifキーを使用して、複数行を対象にすることができます。
    5.  自動リナンバーを任意のIDから指定したい場合は、1行目の開始IDセルに任意のIDを入力し、テーブルの外側をクリックして行のハイライトを消してからじどう
    6.  適用またはOKボタンを押します。

    - 操作手順（任意IDからの自動リナンバー機能） -

    1.  リナンバー対象を、設定及びターゲットから選択します。
    2.  リナンバーを行いたい行の「有効」欄のチェックをONにします（デフォルト：ON）。
    3.  1行目の開始IDセルに任意のIDを入力します。
    4.  テーブルの外側のなにもない箇所を１回クリックして、行のハイライトを消します。
    5.  直後に自動リナンバーボタンをクリックすると、1行目から順に、すべての行に任意IDから順に自動でIDが割り振られます。
    6.  行を左マウスクリックしてハイライトすると、その行のみ自動で任意IDから順にIDが割り振られます。CtrlもしくはShifキーを使用して、複数行を対象にすることができます。
    7.  適用またはOKボタンを押します。
      8. ※この処理は、任意IDを入力した直後の１回目のクリックのみ有効です。２回目のクリック以降は１から順の自動リナンバーに戻ります。
