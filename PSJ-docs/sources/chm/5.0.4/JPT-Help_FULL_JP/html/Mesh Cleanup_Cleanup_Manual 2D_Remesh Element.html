要素のリメッシュ

選択要素をリメッシュします。

※メッシュサイズが周囲の要素よりも大きい場合には動作しません。

リメッシュタイプ

  • Tri3

    リメッシュ後のメッシュを三角形１次要素にします。

  • Quad4

    リメッシュ後のメッシュを四角形２次要素にします。

    • メッシュサイズ

  • 周囲のメッシュサイズを参照

    選択した要素の周囲のメッシュサイズから、平均メッシュサイズを自動入力します。

  • 平均

    平均メッシュサイズを入力します。

  • メッシュのオーバーライド

    メッシュパターンを指定します。

    • Isoメッシュ : リメッシュ部分にIsoメッシュを作成します。※Mapped Mesh作成可能面のみ適用
    • フリーメッシュ : リメッシュ部分にフリーメッシュを作成します。
      •

    • - 操作手順 -

    1. 要素を選択します。
    2. 適用ボタンをクリックすると、選択した要素のリメッシュを行います。
    　1.要素選択 2.Applyをクリック
