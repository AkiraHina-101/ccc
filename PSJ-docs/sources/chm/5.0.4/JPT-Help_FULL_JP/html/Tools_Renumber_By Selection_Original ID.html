選択エンティティをリナンバー | ID順

選択したエンティティのIDを、元のID順に振り直し（リナンバー）します。

  • エンティティタイプ
    • 節点

      選択エンティティ内の節点を対象としてリナンバーします。

    • １D要素

      選択エンティティ内の1D要素を対象としてリナンバーします。

    • 2D要素

      選択エンティティ内の2D要素を対象としてリナンバーします。

    • 3D要素

      選択エンティティ内の3D要素を対象としてリナンバーします。

    • エッジ

      エッジIDのリナンバーを行います。

    • フェイス

      フェイスIDのリナンバーを行います。

    • パーツ

      選択パーツをリナンバーします。

    • 座標系

      選択座標系をリナンバーします。

  • 開始ID

    リナンバーの開始IDを設定します。

  • 増分値ID

    • リナンバーの増分値を設定します。

  • ソート順
    • 昇順

      昇順にリナンバーします。

    • 降順

      降順にリナンバーします。

  • プレビュー

    プレビューボタンをクリックすることで、リナンバー対象エンティティのりナンバー前後のIDを表示します。

  • 適用

    リナンバーを実行します。

  • キャンセル

    リナンバーを実行せずに、ダイアログを終了します。

    • - 操作手順 -

    1.  エンティティタイプの選択肢より、リナンバーを行いたいエンティティを指定します。
    2.  開始ID、増分値、ソート順を指定します。
    3.  メインウィンドウ上でエンティティ選択します。
    4.  プレビューボタンをクリックして、リナンバー前後のIDを確認します。
    5.  適用ボタンを押して、リナンバーを実行します。
