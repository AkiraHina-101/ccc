ギャップ | 2 節点

選択した2つの節点にギャップ要素を作成します。

接続

　　
  • 名前

    • 作成するギャップ要素名を設定します。

    GAP

    　　
  • 方向付け基準

    • ギャップ要素の方向付けの方法を選択します。

      　　
    • 方向ベクトル
      • 方向ベクトルによる指定 　　
    • 座標系
      • 座標系による指定
    　　
  • 座標系

    • 座標系による指定を選択した場合に、使用する既存の座標系をリストから選択します。

    　　
  • 方向ベクトル

    • 方向ベクトルによる指定を選択した場合に、方向ベクトルをX,Y,Zの順にコンマ区切りで入力します。

    　　
  • U0

    • 初期ギャップ開き量を入力します。

    　　
  • F0

    • 初期荷重値を入力します。

    　　
  • KA

    • 閉じたギャップに対する軸剛性値を入力します。

    　　
  • KB

    • 開いたギャップに対する軸剛性値を入力します。

    　　
  • KT

    • ギャップが閉じている時の横せん断剛性値を入力します。

    　　
  • MU1

    • アダプティブギャップ要素の静摩擦係数値を入力します。

    　　
  • MU2

    • アダプティブギャップ要素の動摩擦係数値を入力します。

    　　
  • TMAX

    • ペナルティ値調整に用いる最大許容貫通量を入力します。

    　　
  • MAR

    • アダプティブペナルティ値KAおよびKTに対する最大許容調整比を入力します。

    　　
  • TRMIN

    • 許容貫通量の下限を定義するTMAXの比率を入力します。

    入力単位系

    入力単位系を指定します。

    　　
  • 長さ

    • 長さの単位を選択します。

    　　
  • 力

    • 力の単位を選択します。

    - 操作手順 -

      　　　
    1. 選択リストのマスターボタンがアクティブであるのを確認し、 ギャップ要素の一端の節点選択します。
      2. 　　　
    2. 選択リストがスレーブボタンに切り替わったのを確認し、 ギャップ要素の他端の節点選択します。
      3. 　　　 　　　
    3. 方向ベクトルの指定方法を方向付け基準から選択します。 指定方法に従って方向ベクトルを入力します。
      4. 　　　
    4. それそれの入力欄にギャップ要素の軸剛性などの数値を入力します。 必要に応じて入力単位系から長さと力の単位を選択します。
      5. 　　　
    5. 適用またはOKボタンを押すとギャップ要素が節点間に作成されます。
