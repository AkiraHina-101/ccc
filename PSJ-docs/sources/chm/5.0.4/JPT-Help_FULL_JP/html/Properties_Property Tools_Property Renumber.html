プロパティリナンバー

3D プロパティテーブルダイアログボックス

ドキュメント内のプロパティID/材料IDをテーブルでリナンバーします。

プロパティテーブル

　　
  • 設定

    リナンバー対象をプロパティ/材料から選択します。

    　　　
    • 　　
  • テーブル

    現在ドキュメントに存在する全てのプロパティ/材料をリストします。

    • 名前
      プロパティ/材料の名称です。部分一致検索により、行のフィルタリング表示が可能です。
    • 現在のID
      プロパティ/材料の現在のIDです。
    • リナンバー後のID
      プロパティ/材料のリナンバー後のIDです。IDはモデル内で重複しないように入力します。
    • 材料（プロパティの場合のみ）
      プロパティの使用している材料です。部分一致検索により、行のフィルタリング表示が可能です。
    • 有効
      チェックをつけた列のみ、実際にリナンバーを行います。 　　　
    　　　
  • 全てオン

    全ての列を有効にします。

    　　　
  • 全てオフ

    全ての列を無効にします。

    　　　
  • スイッチ

    有効/無効を反転させます。

    　　　

    • オプション

    ソリッド要素の基本プロパティデータを選択します。

  • 開始ID

    可視行のリナンバー後のIDを指定IDから順にナンバリングします。

  • 増分値

    ナンバリング時の間隔値を指定します。

    • ソート順

  • 昇順

    リナンバー後のIDを昇順にナンバリングします。

  • 降順

    リナンバー後のIDを昇順にナンバリングします。

  • テーブル更新

    現在のオプション・ソート順設定により、リナンバー後のIDを変更します。

    • - 操作手順 -

    1. プロパティ/材料を割り当てたモデルを準備します。
    2. プロパティテーブルを起動します。
    3. 設定リストで、リナンバー対象をプロパティ/材料から選択します。
    4. 下記いずれかの方法で、リナンバー後のIDを指定します。
      • "リナンバー後のID"セルをクリックし、直接値を編集します。
      • オプションで開始ID,増分値を入力し、ソート順を指定し、テーブル更新ボタンをクリックします。
    5. リナンバーを行いたくない列の、有効のチェックボックスをOFFにします。
    6. 適用ボタンをクリックして、リナンバーを行います。
