スムーズフェース(Smooth Face)

選択した節点（エッジ）で囲まれた部分にフェースを作成します（プレビューが表示される場合は作成されます）。
フェースはメッシュかジオメトリの何方かを選べます。メッシュフェースの場合は、周囲との連続性などにより形状を補間します。



選択リスト(Selection list)：共有面(Share Face) = OFF

エッジ(Edge)：フェース作成範囲の境界節点をエッジで選択
節点(Node)：フェース作成範囲の境界節点を選択
パーツ(Part)：フェースが所属するパーツ（1つ）※選択しない場合は新規パーツとして作成されます。

選択リスト(Selection list)：共有面(Share Face) = ON

エッジ(Edge)：フェース作成範囲の境界節点をエッジで選択
節点(Node)：フェース作成範囲の境界節点を選択
パーツ(Part)：共有面を挟むパーツA（1つ）
パーツ(Part)：共有面を挟むパーツB（1つ）

フェースタイプ(Face Type)

  • ジオメトリ―フェース(Geometry Face)

    ジオメトリフェースを作成します。

  • メッシュフェース(Mesh Face)

    形状補間によりメッシュフェースを作成します。

  • 共有面(Share Face)

    2つのパーツに挟まれた共有面を作成します。本オプションがONのとき、選択リスト(Selection list)にパーツ(Part)が2つ表示されます。作成する共有面を挟むパーツをそれぞれ1つずつ選択してください。

  • 補間(Interporation)

    ファセットサイズやメッシュサイズを均一にすることで、自由端の形状などを補間します。
    フリーエッジが作成される場合があるので、注意事項をご参照ください。

    • メッシュフェースパラメーター(Mesh Face Parameter)

  • TRI

    TRI要素を作成します。

  • QUAD

    QUAD要素を作成します。

  • グラデーション係数(Gradation Factor)

    メッシュフェースのメッシュサイズを定義するため、周りの要素サイズに対する係数（1<=）を入力します。ジオメトリフェースの場合は、自動的に0.5が設定されます。

  • 接続連続性(Connection continuity)

    連続性の次数を選択します。

    • G0:（位置連続）作成するフェースと隣接フェースの接合部分で、エッジを共有している状態です。接合部分で折れ曲がりが発生します。平面メッシュフェースを作成したい場合にお勧めします。
    • G1:（接線連続）作成するフェースと隣接フェースの境界で、両フェースの法線ベクトルが同じ場合の状態です。接合部分は滑らかになります。曲面メッシュフェースを作成する場合にお勧めします。
      •

    • - 操作手順（メッシュフェースを作成） -

    1. フェースタイプ(Face Type)で、メッシュフェース(Mesh Face)を選択します。

    2. 選択リスト(Selection list)のエッジ(Edge)か節点(Node)で、フェース作成範囲の境界節点を選択します。

    3. 必要に応じて、選択リスト(Selection list)のパーツ(Part)で、フェースが所属するパーツを選択します。

    4. メッシュフェースパラメーター(Mesh Face Parameter)で、TRIかQuadを指定します。

    5. プレビューを見ながら、グラデーション係数(Gradation Factor)と接続連続性(Connection continuity)を設定します。

    6. 必要に応じて、補間(Interporation)を設定します。

    7. 適用(Apply)／OKボタンをクリックします。選択したパーツにメッシュフェースが作成されます。パーツを選択していない場合は、新規パーツとしてメッシュフェースが作成されます。
    • 例：囲まれた平面メッシュフェースのプレビュー（接続連続性(Connection continuity) = G0）


    • 例：囲まれた曲面メッシュフェースのプレビュー（接続連続性(Connection continuity) = G1）


    • 例：橋渡し平面メッシュフェースのプレビュー（補間(Interporation) = Off）


    • 例：橋渡し曲面メッシュフェースのプレビュー（補間(Interporation) = On）


    - 操作手順（ジオメトリフェースを作成） -

    1. フェースタイプ(Face Type)で、ジオメトリ―フェース(Geometry Face)を選択します。

    2. 選択リスト(Selection list)のエッジ(Edge)か節点(Node)で、フェース作成範囲の境界節点を選択します。

    3. 必要に応じて、選択リスト(Selection list)のパーツ(Part)で、フェースが所属するパーツを選択します。

    4. 必要に応じて、補間(Interporation)を設定します。

    5. 適用(Apply)／OKボタンをクリックします。選択したパーツにジオメトリフェースが作成されます。パーツを選択していない場合は、新規パーツとしてジオメトリフェースが作成されます。
    • 例：囲まれたジオメトリフェースのプレビュー


    • 例：橋渡しジオメトリフェースのプレビュー


    - 操作手順（共有面を作成） -

    1. Share FaceをONにします。Selection ListのPartが一つ増えます。

    2. フェースタイプ(Face Type)で、ジオメトリ―フェース(Geometry Face)かメッシュフェース(Mesh Face)を選択します。

    3. 選択リスト(Selection list)のエッジ(Edge)か節点(Node)で、フェース作成範囲の境界節点を選択します。

    4. 選択リスト(Selection list)の2つのパーツ(Part)で、共有面が所属するパーツをそれぞれ一つずつ選択します。

    5. メッシュフェース(Mesh Face)作成の場合、メッシュフェースパラメーター(Mesh Face Parameter)で、TRIを指定します。

    6. メッシュフェース(Mesh Face)作成の場合、プレビューを見ながら、グラデーション係数(Gradation Factor)と接続連続性(Connection continuity)を設定します。

    7. 適用(Apply)／OKボタンをクリックします。選択した2つのパーツに共有面が作成されます。
    • 例：3パーツの共有面の穴を閉じる場合。2つのパーツで挟まれた範囲毎に、共有面を作成。


    - 注意事項 -

    • プレビューが表示されない場合


      フェース作成範囲を分けてください。下記では、上下の曲線エッジを選択してもプレビューが表示されないため、エッジを分割して少しずつ選択したり、節点ごとに少しずつ選択しています。

    • パーツ選択時のワーニングメッセージ
      共有面(Share Face)=Off：選択した節点に所属するパーツ数が1つではない場合、作成するフェースは共有面の方が良い場合があるため、ワーニングメッセージを表示します。問題ない場合は、OKをクリックしてください。
      共有面(Share Face)=On：選択した節点に所属するパーツ数が2つではない場合、作成する共有面の範囲を見直した方が良い場合があるため、ワーニングメッセージを表示します。問題ない場合は、OKをクリックしてください。

    • フェースの裏表
      作成されたフェースの法線方向が周りと異なる場合がございます。その場合は、フェースを選択して、右クリック(Right Click) > 反転(Flip)でフェースの法線方向を修正してください。

    • 補間(Interporation)によるフリーエッジ
      補間(Interporation)は選択されたエンティティ間のメッシュサイズも変更します。そのため、節点を選択して、それらの節点の間隔が平均と大きく異なる場合、フリーエッジが作成される場合があります。

  • 複数の離れた閉空間
    本機能は、複数の離れた閉空間に対して、同時にフェースを作成することはできません。適用(Apply)／OKボタンが非アクティブになります。1つ1つ実行して頂くか、PSJによる自動化をお願い致します。
