フェース

隣接するフェースを一つのフェースにマージします。

フェースマージ

  • エッジをマージ

    チェックをすると、フェースに付属するエッジもマージします。

  • 非境界エッジを削除

    チェックを外すと、マージ対象フェース内の境界エッジでないエッジを保持します。

    元データ非境界エッジを削除：ON非境界エッジを削除：OFF
  • 高速化処理

    チェックをすると、高速化が有効になります。チェックを外すと、従来と同じ処理時間になります。
    フェース数が多い場合に特に有効です。

    - 操作手順 -

    1. 必要に応じてチェックをします。
    2. マージする複数のフェースを選択します。
    3. 適用/OKボタンをクリックします。
