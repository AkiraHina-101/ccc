プレス

自動で複数部品の薄物モデルの中立面を作成します。

パラメーター

  • 接続
    • 剛体要素：機能実行後に複数部品間を剛体要素で繋ぐため、自動で部品間のエッジにローカル設定を設定します。
    • シェル：複数部品間をシェルで繋ぎます。
    • なし：パーツ間の縫合は行いません。別の機能で実施します。
  • 合わせ面トレランス

    •    部品間の距離を指定します。

  • メッシュサイズ(溶接)

    •    パーツ全体の平均メッシュサイズを設定します。

    オプション

  • 切り上げ桁

    •    板厚数値の有効桁を入力します（0.1と入力された場合は、板厚数値は小数点第一位まで）

    ２Ｄプロパティ

  • 材料選択

    •    シェル材料を指定します。材料ダイアログのユーザーデータベース内にある材料が、プルダウンメニューで表示されます。

    - 操作手順 -

    1.  パーツを選択します。
    2.  「材料選択」で材料を選択します。
    3.  必要に応じてオプションを設定します。
    4.  適用またはOKボタンをクリックします。
    5.  結果ダイアログが表示されます。
