形状/トポロジー最適化

ADVENTURECluster（以下ADVC）の形状/トポロジー最適化解析ファイルを出力します。

解析>ADVC>構造コマンドでADVCプロセス、間隔定義、出力定義などの詳細設定を設定します。

目的関数

  • 関数の種類

    • 1: 形状最適化では10の関数を対応します。 トポロジー最適化では、変位、固有振動数、表面積を除くすべてを対応します。

    • 2: ユーザーは、[追加]ボタンで複数の目的関数を選択できます。

    • 3: 関数によって必要なパラメーターが表示/非表示されます。

    • 4: 間違った入力または必要なパラメーターが入力されていない場合に警告ログを表示します。

    • 5: 目的関数をエクスポートする場合、.adxファイルには$ComplianceFunction（オプションのパラメーター）と$Objectiveドキュメントが出力されまれます。

    • 6: Prosess Numberで使用されるプロセス番号は、プロセス構成での解析順に、0から連続して各プロセスに割り当てられる番号です。

    • 7: プロセス構成内のすべてのプロセスを指定するにはAllを定義します。 プロセス構成の最後のプロセスを指定するにはLastを定義します。

    • 8: プロセス番号を指定せずに省略し、プロセス構成IDのみを指定すると、最後のプロセスが指定されます。
      •
    • 編集: 入力ミスまたは次の解析向けにパラメータを直接編集します。

    • 追加: 関数を追加し、情報領域にパラメータを表示します。

    • 消去: 関数を削除します。

    • 上: 上に移動して関数の順序を変更します。

    • 下: 下に移動して関数の順序を変更します。

  • Shape Optimization / 形状最適化パラメーター

    オプションのパラメーター

    • 最大反復: 形状最適化の反復の最大数を指定します。

    • 最大ひずみ: 最大ひずみの大きさを指定します。

    • H1トレランス: 形状最適化の収束許容値を指定します。

    • 最終結果の出力: 最適化の反復の最終結果を出力するかどうかを選択します。

    • 出力間隔: 最適化解析結果の出力間隔を指定します。

    • リスタートファイル最終結果出力: 最適化反復の最終結果を再起動ファイルとして出力するかどうかを選択します。

    • リスタートファイルの出力間隔: 最適化再開ファイルの出力間隔を指定します。

    • Armijoチェック: Armijo基準を使用するかどうかを選択して、ステップサイズを調整するかどうかを選択します。

    • Armijoパラメーター: Armijoパラメータを指定する。

    • 自動増分: 最適化のために、自動ステップ幅または固定ステップ幅のいずれかを選択します。

    • 安定化係数: 形状最適化の安定化係数を指定します。

    • ポアソン比: H1勾配法で使用されるポアソン比を指定します。

    • 自動設計不可領域: 荷重ケース内に特定の境界条件(拘束、節点荷重)が設定されている場合、領域内の全自由度を自動的に設計不可にします。

    • マトリックス: H1勾配法計算時に、2次要素を1次要素として扱うか指定します。StiffnessLinearまたはStiffnessを選択します。

    • Wolfe規準: Wolfe規準を用いたステップ幅調節の有無を選択し、Wolfe規準で用いるパラメーター値を指定します。

    • Wolfeパラメーター: Wolfeパラメータを指定する。

    • 要素体積感度調整: 体積に応じた感度の調整を行うかどうか指定します。
      •

  • Topology Optimization / 位相最適化

    オプションのパラメーター

    • 初期密度: 濃度比の初期値（0から1の値）を指定します。

    • 密度変数: 0から値を指定しますか？ rwidth？ 0.5は、最適化された反復法の初期密度比（位相）に範囲（？rwidth、rwidth）の通常の乱数を追加します。

    • アルファ: SIMP（ペナルティのある固体等方性材料）ルールが使用され、φα（θ（x））が物性値の補正として使用されます。

    • 最大反復: トポロジー最適化の反復の最大数を指定します。

    • 最大シータ: 位相変化の大きさの最大値を指定します。

    • H1トレランス: トポロジ最適化の収束許容値を指定します。

    • 最終結果の出力: 最適化の反復の最終結果を出力するかどうかを選択します。

    • 出力間隔: 最適化解析結果の出力間隔を指定します。

    • リスタートファイル最終結果出力: 最適化反復の最終結果を再起動ファイルとして出力するかどうかを選択します。

    • リスタートファイルの出力間隔: 最適化再開ファイルの出力間隔を指定します。

    • Armijoチェック: Armijo基準を使用するかどうかを選択して、ステップサイズを調整するかどうかを選択します。

    • Armijoパラメーター: Armijoパラメータを指定する。

    • 自動増分: 最適化のために、自動ステップ幅または固定ステップ幅のいずれかを選択します。

    • 安定化係数: トポロジー最適化の安定化係数を指定します。 値が大きいほど、全体の動きを抑える効果があります。

    • 自動設計不可領域: 荷重がかかっているかどうかに関係なく、特定の境界条件を持つ領域のすべての自由度を自動的に無効にします。

    • Wolfe基準: Wolfe基準に使用するかどうかを選択します-ステップサイズを増やします。 Wolfe標準はArmijo標準と二重であり、各ステップサイズの下限を設定します。

    • Wolfeパラメーター: Wolfeパラメータを指定する。

    • グレースケール比: グレースケール比を指定します。

    • 出力グレースケール比: 出力をグレースケール比に従うかどうかを指定します。
      •
  • Toporogy Optimaization Die Drawing / 位相最適化型抜き制約

    必要なパラメーター

    • 方向: トポロジー最適化でダイカットできる形状を取得するための拘束条件を指定します。 X Y Zを定義します。たとえば、0 0 1（X = 0、Y = 0、Z = 1）です。
      •

    • オプションのパラメーター

    • 要素セット: 要素グループまたはプロパティごとに、トポロジ最適化ダイ描画に使用する領域を選択します。

    • 打ち抜き|片側型抜き: 型抜きの種類を指定します。 Punchingは打ち抜きで、Onesideは片側型抜きです。

    • 座標系: 型抜きベクトルの座標系を指定します。 指定しない場合は、座標系全体になります。
      •

    出力パラメータ

  • 形状/トポロジー最適化のためのすべてのタイプの出力要求

    • 形状変動: 形状最適化の形状変動。

    • 節点密度比: 位相最適化の節点密度比。

    • 密度比: 位相最適化の密度比。

    • 全感度: 全感度は目的関数と制約関数の感度にラグランジュの未定乗数を掛けた和。

    • 目的関数の感度: 目的関数の感度。

    • 各制約関数の感度: 制約関数の感度。

    • 感度一括指定: 感度を指定すると、すべての感度情報を一度に指定できます。
      •

    • - 操作手順 -

    1.  ジョブ名を指定します。
    2.  プロセスを作成でプロセスを作成します。 デフォルト時間の増分で分析を実行する場合は、特に時間を指定する必要はありません。
    3.  LBCマネージャーで境界条件を割り当てます。
    4.  出力マネージャで出力項目を選択します。
    5.  [形状/トポロジの最適化]ボタンをクリックし、すべてのパラメータを設定します。
    6.  計算を完了するには、少なくとも4ページ設定する必要があります。非設計領域は任意指定です。 必須パラメータに注意してください。
    7.  [適用/ OK]ボタンをクリックします。
