断面

　　 断面表示をONにすることで、メインウィンドウに3Dマウスが表示されます。
　　 3Dマウス起動中は、断面リボンが表示され、細かい表示の設定が可能になります。
　　 形状を任意断面で切断した状態で表示する断面表示は、メインウィンドウに表示される3Dマウスを利用して調節します。
　　
V5より、以下の条件を満たしたグループに対してもキャッピングが適用されるようになりました。
1. Body要素またはSolid要素のグループ
2. 断面のエッジがループしている

3Dマウス操作について

3Dマウスの軸やシンボルをマウスオーバーし、色が変わる部分をマウスの左ボタンクリック＆ドラッグによって操作することで、切断面の位置を調節します。

断面ビューシフトコントロールダイアログ

数値入力とボタンクリックにより、切断面の位置を調節します。


  • 中心

    3Dマウスの中心位置を指定します。設定ボタンをクリックすると、入力した座標位置を3Dマウスの中心位置とします。リセットで初期位置に戻します。

  • 方向

    断面の面直方向をベクトル（X, Y, Z） で指定します。設定ボタンをクリックすると、入力したベクトルの方向を断面の面直方向にします。

    • X : クリックすると、X軸を断面の面直方向にします。

    • Z : クリックすると、Y軸を断面の面直方向にします。

    • X : クリックすると、Z軸を断面の面直方向にします。

    • ISO : クリックすると、ベクトル（1,1,1）の方向を断面の面直方向にします。
      •
  • 回転

    3Dマウスをその場で回転させます。

    • 角度 : 回転角度を指定します。

    • グローバル X : 全体座標系のX軸を中心に回転させます、

    • グローバル Y : 全体座標系のY軸を中心に回転させます、

    • マウス X : 3DマウスのX軸を中心に回転させます。

    • マウス Y : 3DマウスのY軸を中心に回転させます。

    • リセット : 3Dマウスの回転を初期状態に戻します。

      •
  • ドラッグ

    3Dマウスを面直方向に入力値だけオフセット移動します。また、スライドバーの操作でも移動することができます。
