1Dプロパティ | バー要素

1Dプロパティ | バー要素ダイアログボックス

１次元バー要素のプロパティデータを作成します。

  • 名前

    • プロパティの名前を指定します。

  • プロパティID

    • プロパティのIDを入力します。

  • 断面タイプ

    • 特性入力タイプを指定します。

    • 一般 ：一般断面特性を入力します。
    • Nastran Lib ：Nastranの断面形状ライブラリを使用します。
  • 色

    • プロパティの色を指定します。

BAR

  • 形状を入力

    • 主要断面形状に関して、断面寸法を入力することで、断面特性が計算されます。 ライブラリーを選択した場合、その寸法がPBARLとして出力されます。

  • 材料

    • 材料特性を指定します。

  • 断面

    • 既存の要素特性リストから選択します。

  • ベクトル

    • 要素座標系を決める方向ベクトルを入力します。
    方向ベクトル定義方法については[方向ベクトルについて]をご参照下さい。

  • 方向付け基準
    • ベクトル ：方向ベクトルによる要素座標系定義
    • 節点 ：指定節点による要素座標系定義(Nastran用)
  • 面積

    • 断面積の値を入力します。

断面の詳細

  • 慣性 I1/Izz

    • Z軸周りの断面2次モーメントを入力します。

  • 慣性 I2/Iyy

    • Y軸周りの断面2次モーメントを入力します。

  • ねじり定数

    • ねじり定数を入力します。

  • 非構造質量

    • 単位長さあたりの非構造質量を入力します。

  • Cy/Cz/Dy/Dz/Ey/Ez/Fy/Fz

    • C、D、E、F点における応力算出位置を入力します。

  • せん断面積係数Y

    • Y方向せん断面積係数

  • せん断面積係数Z

    • Z方向せん断面積係数

  • 慣性 I12/Izy

    • ZY軸周りの断面2次モーメントを入力します。

ピンフラグ-A点

  • UX/UY/UZ/RX/RY/RZ

    • A点の他のバーボティとの結合設定
    ※A点、B点はIDの若い順に設定されます。

ピンフラグ-B点

  • UX/UY/UZ/RX/RY/RZ

    • B点の他のバーボティとの結合設定
    ※A点、B点はIDの若い順に設定されます。

オフセットベクトル

  • A点

    • A点のオフセット量をコンマ区切りで入力します。

  • B点

    • B点のオフセット量をコンマ区切りで入力します。

入力単位系

  • 長さ

    • 長さの単位を選択します。

  • 質量

    • 質量の単位を選択します。

プレビュー

  • プレビュー

    • 入力したパラメーターでプレビューを表示します。

     

断面ダイアログボックス

断面特性値を計算します。作成された値は断面プルダウンメニューに登録されます。

一般

一般断面特性を入力します。

  • 名前

    • 断面特性の登録名前を入力します。

  • タイプ

    • 選択された計算タイプが表示されます。

  • 形状

    • 一般断面計上を選択します。 選択された形状に従って寸法変数名が右のイメージとサイズ表に表示されます。

  • テーパー

    • 梁の左右の断面サイズが異なる場合に選択します。 サイズ変数を2種類入力できるようになります。

  • サイズ表

    • 表示された寸法変数に値を入力します。

  • 要素Y方向

    • 断面のY軸方向を選択します。

  • 入力単位系

    • 断面計算の入力単位を選択します。

ライブラリー

Nastranの断面形状ライブラリを使用します。

  • 名前

    • 断面特性の登録名前を入力します。

  • タイプ

    • 選択された計算タイプが表示されます。

  • 形状

    • Nastranの断面ライブラリのタイプを選択します。 選択された形状に従ってNastranの寸法変数名が右のイメージとサイズ表に表示されます。

  • テーパー

    • 梁の左右の断面サイズが異なる場合に選択します。 サイズ変数を2種類入力できるようになります。

  • サイズ

    • 表示された寸法変数に値を入力します。

  • 要素Y方向

    • 選択できません。

  • 入力単位系

    • 断面計算の入力単位を選択します。


[方向ベクトルについて]

方向ベクトルは要素断面の向きを定義するために指定し、平面1(要素座標系XY平面上)が定まるように定義します。

Bar/Beamの要素座標系は下記のように決定されます。


  1. 節点AからBに向かう方向がX軸となる。
  2. 方向ベクトル(orientation vector)を指定する。
  3. 要素X軸と方向ベクトルによる外積方向に要素Z軸が決定する。
    方向ベクトルを要素X軸と同じ向きにするとZ軸が定まらないため注意します。
  4. 要素X軸とZ軸でY軸が決定し、平面1,2が定まる。
    方向ベクトルが同じ平面上にある限り、要素座標系は同じ向きとなります。

− 操作手順 −

  1. 名前にプロパティの名前を入力します。
  2. 断面性能を入力します。以下の3つの方法があります。
    • 面積、慣性などの入力ボックスに直接入力します。
    • Section Typeプルダウンメニューから断面性能の計算方法を選択し、
      形状を入力ボタンから計算ダイアログボックスを利用して入力します。
    • 断面プルダウンメニューから既存の断面性能を選択します。
  3. 材料プルダウンメニューからすでに登録された材料を選択します。
  4. Orientation Byプルダウンメニューから方向ベクトルの指定方法を選択します。
  5. ベクトルに方向ベクトルを入力します。
  6. 必要に応じてピンフラグ設定、オフセットベクトル、入力単位を設定します。
  7. 適用またはOKボタンをクリックします。
