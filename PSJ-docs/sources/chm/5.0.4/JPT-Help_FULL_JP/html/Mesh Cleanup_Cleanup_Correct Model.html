モデル修正

モデルのトポロジエラーを修正します。

エッジオプション

モデル全体のエッジを角度指定から分割又は、結合します。

  • エッジを分割

    チェックを入れると、エッジを分割します。

  • エッジ角度

    エッジ分割の角度を指定します。指定角度以上の角度を持つエッジを分割します。

  • エッジをマージ

    チェックを入れると、エッジを結合します。

  • マージエッジ角度

    エッジマージ用の角度を指定します。指定角度以下で接続しているエッジをマージします。

    • フェースオプション

  • 平面フェースをマージ

    チェックを入れると、連続した平面のフェースを結合します。

    • 頂点オプション

  • 過剰な頂点を削除

    チェックを入れるとモデル全体から過剰な頂点（浮遊節点上の頂点など）を削除します。

    • - 操作手順 -

    1. パーツを選択します。
    2. 必要に応じてオプションを設定します。
    3. 適用またはOKボタンをクリックします。
