メッシュ設定の保存/読み込み

ローカル設定を外部ファイル（xml形式）へ保存します。また、保存した設定を読み込みます。

タイプ

  • 演算方法

       オペレーションタイプを選択します。

    • 保存 : ローカル設定を外部ファイルに保存します。

    • 読み込み : ローカル設定を外部ファイルから読み込みます。
      •

    • - 操作手順 -

  • 保存手順
    1.  演算方法に保存を選択します。
    2.  適用/OKボタンをクリックします。
    3.  ファイル名を入力します。
    4.  保存ボタンをクリックします。

  • 読み込み手順
    1.  演算方法に荷重を選択します。
    2.  適用/OKボタンをクリックします。
    3.  保存したxmlファイルを選択します。
    4.  開くボタンをクリックします。
