グループ

各エンティティのグループを作成します。

　　

グループ

  • 名前

       グループの名前を入力します。

  • エンティティ

       グループを作成するエンティティを選択します。

    • マニュアルID入力

      IDを指定してエンティティを選択します。
  • エンティティ番号

       エンティティ IDを入力して「追加」ボタンを押すと、選択リストに対応するエンティティが格納されます。

    • CSVファイルから読込み

      CSV ファイルに記載したIDでグループを作成します。
  • ファイル を開く

       指定したTypeのEntityのIDをCSV fileから読み込み、Entityを選択します。

    • 読込むCSV fileフォーマットの例
      ＊ グループウィンドウにてExportしたcsvファイルのフォーマットとは異なります。

    • 補足

    右クリックメニュー「コマンドダイアログを起動」からグループ作成も可能です。

    - 操作方法 -

    対象のエンティティを選択し、右クリック → グループ作成 > コマンドダイアログを起動　を選択します。


    作成するグループ名を入力し、適用またはOKボタンを押します。

    - 操作手順 -

    1.  選択リスト上の各エンティティボタンを押して、画面からグループ化したいエンティティを選択します。
    2.  作成するグループ名を入力します。
    3.  適用またはOKボタンを押します。
    4.  作成したグループは、対応するエンティティのツリーに格納されます。

      5. ※作成したグループの表示を行う場合は、メインウィンドウ内の'グループ表示モードアイコンをクリックします。
        再度クリックすると、表示を通常に戻せます。
