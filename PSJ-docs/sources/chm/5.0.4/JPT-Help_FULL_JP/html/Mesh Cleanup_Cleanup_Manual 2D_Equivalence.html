イクイバランス

近接する節点を結合します。

イクイバランス

  • 距離

    選択した2節点間の距離を表示します。

  • トレランス

    トレランスを設定します。

  • マージ先

    他のノードがマージされるノードを選択します。 3つのオプションがあります：1番目の節点、2番目の節点、および中間位置。

  • 複数節点

    複数選択した節点間がトレランス以内の場合に、節点を結合します。 （トレランス以下の節点がランダムに結合されるため、形状が悪くなる場合があります）

    • - 操作手順 -

  • イクイバランスノード1ペア（複数節点がオフ）
    1.  1番目の節点を選択します。
    2.  2番目の節点を選択します。
    3.  1番目の節点、2番目の節点、または中間位置のいずれかのオプションを選択します。
    4.  [適用]ボタンをクリックします。
    5.  2つのノードの1つは、選択した1番目の節点/ 2番目の節点/中間位置にマージされます。

  • イクイバランスの多くのノードのペア（複数節点がオン）
    1.  最初のノードペアの1番目の節点を選択します。
    2.  最初のノードペアの2番目の節点を選択します。
    3.  他のノードペアの選択に進みます。
    4.  1番目の節点、2番目の節点、または中間位置のいずれかのオプションを選択します。
    5.  [適用]ボタンをクリックします。
    6.  各ペアの2つのノードの1つが、選択した1番目の節点/ 2番目の節点/中間位置にマージされます。
