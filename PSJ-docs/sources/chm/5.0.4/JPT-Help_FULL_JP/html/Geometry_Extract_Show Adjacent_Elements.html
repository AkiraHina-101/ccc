要素

探索を開始する要素と境界（要素や角度）を設定することで、指定した境界内の要素を纏めて選択します。
この機能により、エンジン部品のウォータジャケットの取り出しや型部品の表面の取り出しなどを容易に行う事が出来ます。

オプション

  • レイヤー数

    探索範囲となるレイヤ数を入力します。

  • 停止要素を含める

    チェックをすると、境界面も選択します。

  • 指定した角度で停止

    境界となる角度を入力します。

  • プレビュー

    選択される要素を確認できます。

  • リセット

    プレビューボタンで確認した要素をリセットします。

    • - 操作手順 -

    1. 開始要素を選択します。（離れた場所の複数の要素を選択できます）
    2. 停止要素を選択します。（角度だけを境界とする場合には、必要ありません）
    3. 探索範囲を設定します。
    4. 境界を設定します。
    5. プレビュー/リセットで選択範囲を確認します。
    6. 適用/OKボタンをクリックします。
    7. グループ作成を行うことで、抽出した要素に間違いなどがあった場合の変更作業が容易になります。
