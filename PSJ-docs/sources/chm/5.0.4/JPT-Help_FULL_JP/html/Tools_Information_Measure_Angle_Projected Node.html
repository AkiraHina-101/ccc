角度[投影節点]

座標系平面への投影角度を計測します。

　　

オプション

  • 座標系

       節点投影の座標系を選択します。

    出力

  • 入力単位系

       表示する角度の単位を指示します。

  • ローカル座標系 XY

       指定座標系XY平面での投影角度

  • ローカル座標系 YZ

       指定座標系YZ平面での投影角度

  • ローカル座標系 ZX

       指定座標系ZX平面での投影角度

    • - 操作手順 -

    1.  画面上から節点を選択します。
    2.  ローカル座標系で節点を投影する座標系を選択します。
    3.  節点を指定座標系平面に投影した位置と各座標系軸との角度が表示されます。
