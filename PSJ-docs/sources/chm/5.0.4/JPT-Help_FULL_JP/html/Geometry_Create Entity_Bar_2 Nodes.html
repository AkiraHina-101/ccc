バー

選択された2つの節点からバーパーツを作成します。

バープロパティ

  • バー名前

       作成するバー パーツの名前を入力します。

    • メッシュサイズ

     バー パーツをパーツ要素で分割する数を入力します。
  • メッシュサイズ

    •    指定した長さのメッシュ サイズでバー パーツを分割します。

  • メッシュ数

    •    指定した分割数でバー パーツを分割します。


    - 操作手順 -

    1.  バー 名前に作成するバー パーツの名前を入力します。
    2.  メッシュ サイズまたはメッシュ数を選択し、メッシュ サイズ長さまたは分割数を入力します。
    3.  選択 リストで節点ボタンを押し、画面上から2つの節点を選択します。
    4.  適用/OKボタンをクリックします。
