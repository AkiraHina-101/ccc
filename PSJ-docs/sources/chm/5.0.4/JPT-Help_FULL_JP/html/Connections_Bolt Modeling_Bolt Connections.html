ボルト接続

解析用にボルトをモデル化します。

Creation Method

  • エッジ

    エッジを選択し作成します。

  • フェース

    フェースを選択し作成します。

  • ボルトのモデル化は、Type A, Tyep B, Type C, Type Dの4タイプあります。
    • タイプA : ボルト穴の上面と下面にRBE2要素を円形に作成、その中心をバー要素またはRBE2要素で結合します。
    • タイプB : ボルト穴の上面にRBE2要素を円形に作成、また下端にはそのボルト穴の側面を結合したRBE2を配置し、その中心をバー要素またはRBE2要素で結合します。
    • タイプC : ボルト穴の側面にRBE2またはRBE3要素を配置し、その中心をばね要素またはRBE2要素で結合します。
    • タイプD : 相対する面のボルト穴周りの指定範囲内をMPCで結合します。
      •

  • タイプA とタイプBには、プリテンションオプションがあり、ボルト締め付け力の設定を追加したボルトモデルを作成することができます。
    ボルト軸のバー要素はその中心位置で分割され、MPC結合を利用したボルト締め付け力を定義します。

    • - 操作手順 -

    1. 作成方法（エッジ / フェース）を指定します。
    2. 作成するボルトタイプを選択します。
    3. 選択したボルトタイプのコマンドダイアログが開き、必要に応じてエンティティの選択、パラメーターの入力、オプションの選択を行います。
