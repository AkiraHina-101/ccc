エッジ

エッジ単位のメッシュサイズを設定します。全体メッシュ作成前に予め設定し、全体メッシュ作成時に
設定したメッシュサイズが適用されます。

メッシュパラメーター

　　
  • 名前

    メッシュコントロール名を設定します。

    メッシュをフリーズ

    　　　
    • 　　
  • メッシュをフリーズ

    チェックを入れると、現在のメッシュを保持します。

    メッシュサイズ

    　　　
    • 　　
  • メッシュサイズ

    要素のサイズを設定します。

    　　　
    • 　　
  • 平均

    要素の平均サイズを設定します。

    　　　
    • 　　
  • 最小

    要素の最小サイズを設定します。

    　　　
    • 　　
  • 最大

    要素の最大サイズを設定します。

    エンティティをキープ

    　　　
    • 　　
  • エンティティをキープ

    チェックを入れると、メッシュ作成時にフェースの形状を保持する設定を行います。

    メッシュ数

    　　　
    • 　　
  • メッシュ数

    チェックを入れると、エッジの分割数を指定します。

    　　　
    • 　　
  • 分割数

    分割数を指定します。

    　　　
    • 　　
  • 方法

    分割方法を指定します。

    　　　
      • 　　
    • Equal

      等分割

      　　　
      • 　　
    • Bias

      指定端（節）点位置から偏向分割（始点となる節点も選択）

      　　　
        • 　　
      • Bias-Center

        中央が密な偏向分割

        　　　
        • 　　
      • Bias-Center

        中央が密な偏向分割

        　　　
        • 　　
      • Bias-Sides

        両端が密な偏向分割

        　　　

      　　
    • 偏向係数

      バイアス係数を指定します。(等比r もしくは等差 d)

      　　　
      • 　　
    • 数列

      数列を指定します。

      　　　
        • 　　
      • 等比

        等比(*r)偏向

        　　　
        • 　　
      • 等差

        等差(+d)偏向

      　　　

      ジオメトリー近似

      　　
    • ジオメトリー近似

      チェックを入れると、形状再現性に関する設定をします。

      　　　
      • 　　
    • トリム角度

      トリムを行う最大ファセット角度を指定します。

      　　　

      • 詳細設定

      　　
    • ローカルメッシュプレビュー

      オンにすると、選択したエッジメッシュを必要なメッシュ数でプレビューできます。
      注：モデルサイズに対して小さいメッシュサイズを設定した場合、メッシュのプレビュー表示に時間がかかる場合があります。

      　　　
      • 　　
    • プレビューの色

      カラーリストからプレビューのエッジの色を選択します。

      　　　

      • - 操作手順 -

        　　　
      1. エッジを選択します。
        2. 　　　
      2. メッシュサイズの各項目を入力します。
        3. 　　　
      3. 適用/OKボタンをクリックします。
