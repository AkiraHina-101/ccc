パーツ移動｜合わせ面選択

選択されたパーツを鏡対称移動またはコピーします。

操作

  • 新規作成

    •    移動後にパーツをコピーし、新規パーツとします。新規パーツの名称は、
          元パーツ名_MATING
       となります。

  • LBCコピー

    •    新規パーツに既存パーツに付加した荷重境界条件もコピーします。

  • プロパティコピー

    •    新規パーツに既存パーツに付加したプロパティもコピーします。

  • リファレンス

    •    新規パーツに既存パーツに付加したリファレンスもコピーします。

    オプション

  • インタラクティブ

    •    チェックがONの場合パーツの移動が刻々と変化します。

    コピー先パーツ

  • コピー先パーツ

    •    移動するパーツを選択します。

    共有面/要素検索

  • コピー元

    •    移動させるパーツのフェース/要素を指定

  • 移動先

    •    基準となるパーツのフェース/要素を指定

  • 方向反転

    •    移動させるパーツを反転

    エッジに整列

  • 方法

    •    位置合わせエッジの方法を指定

    • 2 エッジ : エッジ指定
    • エッジベクトル : エッジとベクトル指定
      •

  • コピー元

    •    移動させるパーツのエッジを指定

  • 移動先

    •    基準となるパーツのエッジ/ベクトルを指定

  • 角度（Degrees）

    •    角度を指定

  • 方向反転

    •    移動させるパーツを反転

    位置を調整

  • 方法

    •    位置調整の方法を指定します。

    • 2 任意点 : 2節点指定
    • 点と座標系 : 節点と座標指定
      •

  • ソースポイント

    •    移動させるパーツの節点を指定

  • 移動先ポイント

    •    基準となるパーツの節点/座標を指定

  • プロジェクション方向

    •    投影方向

    • 面に垂直 : 面の法線方向
    • ベクトル : ベクトル方向
      •

  • ベクトル(グローバル)

    •    ベクトル値(グローバル座標系)

    リセット

  • リセット

    •    パーツの位置を元に戻します。


    - 操作手順 -

    1.  移動させるパーツを選択します。
    2.  移動させるパーツのフェースを選択します。
    3.  基準となるパーツのフェースを選択します。
    4.  移動させるパーツのエッジを選択します。
    5.  基準となるパーツのエッジを選択します。
    6.  適用またはOKボタンを押します。
