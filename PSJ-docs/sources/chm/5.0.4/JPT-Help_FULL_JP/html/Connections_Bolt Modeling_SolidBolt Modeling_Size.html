ソリッドボルトモデリング | サイズ

３種類のヘッドタイプから、サイズを指定してソリッドボルトを作成します。
プリテンション荷重のチェックボックスにチェックを入れプリテンション設定を付加できます。

ボルトタイプ

  • ボルトタイプ

    タイプを選択すると、イメージ図が切り替わります。
    各値についてはイメージ図を参照してください。値を入力するとボルトのプレビューが表示されます。

    • 設定

  • ソリッドボルト名

    作成するソリッドボルトの名前を入力します。

  • 座面角度(deg)

    ボルト座面部分の傾斜角度を入力します。

    角度=0角度=5
  • メッシュサイズ

    メッシュサイズを入力します。

    • プリテンション

  • ソルバータイプ

    各ソルバー用のプリテンション設定を選択します。
    ※V5.0.1ではSunshineのみサポートされています。

  • 値

    プリテンション力を入力します。

  • 入力単位系

    入力単位系を選択します。

  • 座面からの距離

    座面部分からプリテンションを設定する箇所までの距離を入力します。



    • - 操作手順 -

    1. ソリッドボルトタイプを選択します。
    2. ソリッドボルトの各寸法サイズを入力します。
    3. 作成するソリッドボルトの名前を入力します。
    4. ボルト座面部分に傾斜を付ける場合、座面角度を入力します。
    5. メッシュサイズ、プリテンションの各パラメータを指定します。
    6. 適用もしくはOKボタンをクリックします。
