延長線

選択したエッジを同じ方向または同じ曲率で延長します。

オプション

  • 方法

    •    エッジを延長する方法を選択します。

    • 直線 : エッジをエッジ方向に直線に延長します。
    • 同じ曲率 : エッジをエッジの曲率を保ったまま延長します。
      •

  • 位置を延長

    •    エッジを延長する位置を選択します。

    • もっとも近いエッジ : エッジ端点からもっとも近いエッジまで延長します。
    • 境界エッジ : 選択したエッジのあるフェース境界のエッジまで延長します。
      •
  • 曲率計算節点数

    •    (方法：「同じ曲率」の場合)曲率を計算する節点数を指定します。

  • 分割数

    •    (方法：「同じ曲率」の場合)延長した曲線のなめらかさを分割数で指定します。

  • 面を分割

    •    フェースを分割します。


    - 操作手順 -

    1.  エッジボタンを押し、延長対象のエッジを画面より選択します。
    2.  方法からエッジを選択する方法を選択します。
    3.  位置を延長から延長先の終点を選択します。
    4.  必要に応じて面を分割チェックボックスをオフにします。この場合はインプリント後のフェースが元のフェースから分割されません。
    5.  適用/OKボタンをクリックします。
