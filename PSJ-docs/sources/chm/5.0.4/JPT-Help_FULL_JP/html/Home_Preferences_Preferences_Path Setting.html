パス設定

各フォルダパス設定を行います。

外部モジュール

外部アプリケーションへのパスを指定します。

  • Pre
    • Nastranソルバーパス
      Nastran実行ファイルへのパスを指定します。
    • Ansysソルバーパス
      Ansys実行ファイルへのパスを指定します。

    Jupiter機能

    Jupiterの使用するパスを指定します。

  • Pre

    • Preドキュメントが参照するパスです。

    • デフォルト材料ライブラリー
      材料ライブラリーへのパスを指定します。
    • Nastranテンプレートフォルダー
      Nastranテンプレートフォルダーへのパスを指定します。
    • ADVCテンプレートフォルダー
      ADVCテンプレートフォルダーへのパスを指定します。
  • 共通

    • Pre,Postドキュメントが参照するパスです。

    • PSJコマンド
      PSJで作成したコマンドへのパスです。カスタムリボン上にPSJコマンドを表示する際に使用します。
    • テンプレートパス
      Pre/Postのビューポイント、断面、及びPostのアニメーション、コンター、ベクトル、円図、ダイアグラム図、変形のテンプレート情報を保存しているファイルへのパスを指定します。
    • Sun Shineパス
      SunShineソルバー実行ファイルへのパスを指定します。
      ランチャー使用： ソルバー起動時にソルバーランチャ機能を使用します。
      直接起動： ソルバー起動時にバッチファイルを直接起動します。
      DB/MSTRを削除： チェックするとソルバー終了後にDBとMSTRファイルを削除します。

    ドキュメント

    Jupiterのウェブドキュメントを保存する場所
    • ローカルディレクトリ
      • ドキュメントがユーザーのPCにインストールされている場所。
      - デフォルト： C:\Program Files\TechnoStar\Jupiter_5.0\Help\WEB_BASE_HELP
      - ドキュメントは、リンクhttp://localhost:7000/psj/を使用してブラウザで開かれます。ここで、7000は未使用のポートです。 このデフォルトポートを変更したい場合は、「デフォルトポートの変更」チェックボックスを有効にして、ポート番号を入力できます。
    • イントラネット
      • ドキュメントがLANサーバーに保存されている場所。
      - サーバー：サーバー名またはIPアドレス。
      - ポート：開いたポート。
    • インターネット
      • TechnoStarが提供するオンラインドキュメントを開きます。
      サポートチームから提供されたユーザー名とパスワードを入力してください。

    - 操作手順 -

    1.  コマンドを起動し、各項目右側のブラウズボタンで設定したいパスをファイル指定により設定します。
    2. 適用もしくはOKボタンをクリックして設定を反映させます。
