3Dプロパティ | ガスケット

3Dプロパティ | ガスケットダイアログボックス

ガスケット要素のプロパティデータを入力します。

プロパティ

　　
  • 名前

    プロパティの名前を指定します。

    　　　
    • 　　
  • プロパティID

    プロパティのIDを指定します。プロパティIDはモデル内で重複しないようにします。

    　　　
    • 　　
  • 色

    プロパティの色を指定します。

    　　　

    • ガスケット

    ガスケット要素のプロパティデータを入力します。

  • 材料

    あらかじめ定義されたガスケット材料特性を選択します。

  • 板厚方向 X/Y/Z

    ガスケットの厚み方向を方向ベクトルで指定します。

  • 一軸

    厚さ方向挙動オプションを選択します。ADVCとABAQUSのみ有効です。

    • - 操作手順 -

      　　　
    1. 名前にプロパティの名前を入力します。
      2. 　　　
    2. プロパティIDにプロパティIDを入力します。
      3. 　　　
    3. 材料プルダウンメニューからすでに登録されたガスケット材料情報を 選択します。
      4. 　　　
    4. 必要に応じて他のパラメータも入力します。
      5. 　　　
    5. 対象パーツを選択します。
      6. 　　　
    6. 適用またはOKボタンをクリックしてプロパティを作成します。
