シェル交差部を接続

複数シェルパーツのアセンブリモデルに対して、フェース間を接続します。接続箇所に節点とエッジを作成します。

パラメーター

  • 方法

    接続する周囲の要素を指定します。

    • Tri3

      フェース上のメッシュがTri3の場合に、指定します。

    • Quad4

      フェース上のメッシュがQuad4の場合に、指定します。

  • トレランス

    フェースとフェースが接続していると判定する距離を入力します。

    • - 操作手順 -

      　　　
    1. 対象の複数パーツ、または複数フェースを選択します。
      2. 　　　
    2. 必要に応じてトレランスの値をデフォルト値から変更します。
      3. 　　　
    3. 適用/OKボタンをクリックします。
