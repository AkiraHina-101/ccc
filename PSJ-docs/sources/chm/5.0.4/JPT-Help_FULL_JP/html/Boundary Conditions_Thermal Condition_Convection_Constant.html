表面対流

選択されたフェースまたは要素面に自然対流条件を定義します。

熱

　　
  • 名前

    自然対流条件名を設定します。

    値

    　　　
    • 　　
  • 雰囲気温度

    対流条件の外部環境温度を入力します。

    　　　
    • 　　
  • 入力単位系（温度）

    温度の入力単位系を指定します。

    　　　
    • 　　
  • 時間依存

    時間依存性がある場合には時刻歴テーブルを選択します。

    　　　
    • 　　
  • 熱伝達係数

    対流条件の熱伝達係数を入力します。

    　　　
    • 　　
  • 入力単位系

    熱伝達係数の入力単位系を指定します。

    　　　
    • 　　
  • 時間依存

    時間依存性がある場合には時刻歴テーブルを選択します。

    　　　
    • 　　
  • 温度依存

    温度依存性がある場合には温度歴テーブルを選択します。

    　　　
    • 　　
  • フィールド入力

    テーブルタイプ[ExtTemp_ConvCoeff_ElemID_FaceID]の要素面対象の対流テーブルを選択します。ADVCのみ対応しています。

    　　　

    • - 操作手順 -

      　　　
    1. 自然対流条件を定義するフェースまたは要素面を選択します。
      複数の選択が可能です。
      2. 　　　
    2. 雰囲気温度に外部環境温度を入力します。
      3. 　　　
    3. 熱伝達係数に熱伝達係数を入力します。
      4. 　　　
    4. 必要に応じてその他のパラメータを変更します。
      5. 　　　
    5. 適用またはOKボタンをクリックします。
