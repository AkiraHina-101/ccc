パーツトレース

このコマンドでは、パーツ間の接続情報をたどってパーツの表示/非表示を切り替えます。
選択したパーツにどのパーツがどのように接続しているか、更にその先はどのパーツに接続しているのか確認できます。


　　

検索

  • すべて

       チェックすると、レイヤー数に関わらず、モデル内のすべてのパーツを検索します。

  • レイヤー数

       適用、増やす、減らすボタンを押したときに検索するレイヤー数を入力します。

    • 　　

    トレース｜パーツ

  • 共有フェース/節点

       チェックすると、表示中のパーツと共有面/共有節点を持つパーツを表示します。

  • 接触条件

       チェックすると、表示中のパーツと接触条件で接触したパーツを表示します。

  • はり要素/バー要素

       チェックすると、表示中のパーツとはり要素/バー要素で接続したパーツを表示します。

  • ばね要素/ブッシュ/ギャップ

       チェックすると、表示中のパーツとばね要素/ブッシュ/ギャップ要素で接続したパーツを表示します。

  • 剛体要素

       チェックすると、表示中のパーツと剛体要素で接続したパーツを表示します。

  • MPC

       チェックすると、表示中のパーツとMPCで接続したパーツを表示します。

  • レイヤーを増やす

       接続情報を検索するレイヤーを入力したレイヤー数分増やします。

  • レイヤーを減らす

       接続情報を検索するレイヤーを入力したレイヤー数分減らします。

    • リセット

  • リセット

       表示をリセットします（接続情報にかかわらず全てのパーツを表示します）。


    • - 操作手順 -

    1.  接続情報を検索する開始地点のパーツを選択します。
    2.  検索で増減するレイヤー数を設定します。
    3.  トレース｜パートで検索する接続情報を選択します。
    4.  適用ボタンを押します。
    5.  レイヤーを増やす/レイヤーを減らすボタンで接続情報を辿る階層を変えることができます。
    6.  リセットボタンを押し、パーツの表示を元に戻します。
