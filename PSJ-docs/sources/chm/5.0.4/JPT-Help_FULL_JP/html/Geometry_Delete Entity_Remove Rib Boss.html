リブ/ボス 削除

リブ/ボスを構成するフェースを、自動的に削除してフェースを作成します

リブ/ボス 削除

  • リブまたはボスの周りのフェースを一周するように選択します。 　　　　
    • 　　　　

    パラメーター

  • グラデーション

    作成するフェースのメッシュ粗密を設定します。

  • 接続連続性

    作成するフェースの形状追従性を設定します。

  • プレビュー

    作成されるフェースのプレビューが表示されます。

  • リセット

    作成されるフェースのプレビューがリセットされます。

    • - 操作手順 -

    1. 対象形状の周りのフェースを一周するように選択します。
    2. 必要なパラメータを設定します。
      3. 　　　　
    3. プレビューを表示します。
    4. 適用/OKボタンをクリックします。
