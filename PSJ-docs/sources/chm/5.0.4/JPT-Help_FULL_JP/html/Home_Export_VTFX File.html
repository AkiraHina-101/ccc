VTFXファイル出力

アクティブになっているドキュメントのジオメトリー情報、もしくはジオメトリー情報と選択した結果情報をWeb Viewer向けフォーマット(*.vtfx)で出力します。

パス設定

  • モデル名

    •    出力するデータのファイル名を入力します。ブランクのまま実行すると、エラーメッセージが表示されて実行がキャンセルされます。

  • 出力フォルダのパス

    •    データの出力先を入力します。ブランクのまま実行すると、エラーメッセージが表示されて実行がキャンセルされます。

    オプション

  • モデルタイプ

    •    出力するモデルの種類を選択します。

    • Pre

      ジオメトリー情報だけが出力されます。

    • Post

      ジオメトリー情報と、選択した結果情報が出力されます。

      •
  • バーパーツを除く

    •    チェックを入れるとバーパーツを出力しません。

  • サーフェース情報のみ出力

    •    チェックを入れると3D要素および、3D要素の結果を出力しません。

  • 出力データ位置コントロールボタン

    •    モデルタイプがPostの時のみ表示されます。ボタンをクリックすると、データ位置コントロールダイアログが開き、2D要素(シェル)の結果表示位置を指定できます。

    2D要素データ

  • 上面 / 下面 / 平均

    •    2D要素上の結果表示位置を指定します。

  • データ位置

    •    解析結果に選択可能なデータ位置がある場合、プルダウンメニューから選択できます。

    結果選択リスト

       モデルタイプがPostの時のみ表示されます。ResultウインドウのResult Treeが反映され、チェックを入れた解析結果が出力されます。

       ツリー上で右クリックをすると、右クリックメニューが2種類表示されます。

  • 全ステップの結果を選択

    •    右クリックした結果について、すべてのステップで同じ結果にチェックを入れます。

  • 全ステップの結果選択を解除

    •    右クリックした結果について、すべてのステップで同じ結果のチェックを外します。

    - 操作手順(モデルタイプPre) -

    1.  モデル名とモデル出力パスを指定します。
    2.  モデルタイプでPreを選びます。
    3.  必要に応じてオプションにチェックをいれます。
    4.  適用またはOKボタンをクリックします。

    - 操作手順(モデルタイプPost) -

    1.  モデル名とモデル出力パスを指定します。
    2.  モデルタイプでPostを選びます。
    3.  必要に応じてオプションにチェックをいれます。
    4.  シェルの結果がある場合、出力データ位置コントロールボタンをクリックして、結果表示位置を指定します。
    5.  出力したい解析結果にチェックをいれます。
    6.  適用またはOKボタンをクリックします。

    - 注意事項 -

    1.  現在のバージョンでは、Solid Principal Stressは出力しません。Jupiter上では最大主応力と最小主応力のベクトルを同時表示する結果ですが、Web Viewer V1.1では二つのベクトルを同時表示に対応しておりません。Web Viewerでのベクトル表示が対応になり次第、出力対応致します。
    2.  Solid Trescaは、Preference > Save/Load > Post > Tresca Stressオプションにチェックが入っている場合に出力します。
