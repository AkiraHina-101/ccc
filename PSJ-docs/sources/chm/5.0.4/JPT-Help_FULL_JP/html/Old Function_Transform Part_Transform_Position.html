座標値

3つの節点ペアA、B、Cを選択し、ターゲットパーツをベースパーツ位置に移動します。
移動後は3つの節点ペアが重なる位置にターゲットパーツが移動します。

操作

  • 新規作成

    •    移動後にパーツをコピーし、新規パーツとします。新規パーツの名称は、
          元パーツ名_POS
       となります。

  • LBCコピー

    •    新規パーツに既存パーツに付加した荷重拘束条件もコピーします。

    3点指示

  • すべてをクリアー

    •    選択したすべての節点を解除します。

    オプション

  • A(ターゲット)　

    •    節点ペア Aについて、ターゲット（移動対象パーツ）の節点を画面から入力します。

  • A(ベース)

    •    節点ペア Aについて、ベース（移動参照パーツ）の節点を画面から入力します。

  • B(ターゲット)

    •    節点ペア Bについて、ターゲットの節点を画面から入力します。

  • B(ベース)

    •    節点ペア Bについて、ベースの節点を画面から入力します。

  • C(ターゲット)

    •    節点ペア Cについて、ターゲットの節点を画面から入力します。

  • C(ベース)

    •    節点ペア Cについて、ベースの節点を画面から入力します。


    - 操作手順 -

    1.  パーツ移動後に新しいパーツを作成する場合には、新規作成をオンにします。
    2.  既存パーツの荷重拘束条件を新規パーツにコピーするにはLBCコピーをオンにします。
    3.  パーツボタンを押し、画面から回転対象のパーツを選択します。
    4.  A(ターゲット)、A(ベース)、B(ターゲット)、B(ベース)、C(ターゲット)、C(ベース)の順番に、
         入力ボックスをクリックした後に画面から該当節点を選択します。選択された節点番号が入力ボックスに表示されます。
    5.  選択した節点を解除したい場合には、すべてをクリアーを押し、再度節点を選択します。
    6.  適用またはOKボタンを押します。
