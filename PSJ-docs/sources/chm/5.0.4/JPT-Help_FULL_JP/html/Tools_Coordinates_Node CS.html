節点の座標系

このコマンドでは節点の位置情報を定義する座標系を設定します。
Nastran , ADVC(format2)の入力ファイルではこの設定により節点方法に局所座標系を参照します。



- 操作手順 -

  1. 座標系に作成したローカル座標系を選択します。
  2. 節点座標系を設定したい対象のパーツ、フェース、エッジ、もしくは節点を選択します。
  3.  適用/OKボタンをクリックします。
  4. ローカル座標系を設定した節点をグループ化する場合は、グループ作成ボタンを押します。
  5. ローカル座標系を設定した節点を色分けして可視化する場合、表示/非表示ボタンを押します。。
