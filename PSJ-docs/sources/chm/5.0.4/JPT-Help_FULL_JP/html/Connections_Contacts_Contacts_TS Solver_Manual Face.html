フェース指定

指定フェース間に接触設定を定義します。
マスター面となるフェース、およびスレーブ面となるフェースを選択し、接触設定を定義します。



基本

  • 名前

       接触対の名称を入力します。

  • アルゴリズム

       接触設定対象エンティティを選択します。

    • フェース-フェース: フェース対フェース間接触
  • タイプ

       接触定義の挙動タイプを選択します。

    • 一般接触 : 滑り接触
    • 固着 : 固着
      •
  • マスター

       マスター面となるフェースを選択します。

  • スレーブ

       スレーブ面となるフェースを選択します。

  • M/S入替

       マスターとスレーブを入れ替えます。

    • コンタクトプロパティ

  • 干渉閉鎖距離(CINTERF)

       接触フェースに垂直な方向の干渉閉鎖量を入力します。CINTERF>0 の場合、ボディ間のオーバーラップ。CINTERF<0 の場合は、ボディ間のギャップ。

  • 摩擦係数(FRIC)

       摩擦係数の入力します。

  • 接触面延伸距離(SLIDE)

       接触面延伸距離を入力します。 ICOORD >= 2 でない限り、この入力は行わないでください。
       接触面延伸距離オプションを使用する場合、セグメント上をスライドする節点は、設定値よりも長い距離場合延伸がオフになります。

  • 節点の座標修正（ICOORD)
    • いいえ : このオプションを無視します。
    • はい : 変形パーツと接触しているノードの座標を修正して，応力のない初期接触が得られるようにします。
  • ペナルティファクタ(SFACT)

       反復回数による時間ステップの増加の要因。

  • シェル要素面(スレーブ)

       シェル要素面(スレーブ)には以下のオプションがあります。

    • 表。板厚考慮 : 接触の説明には上面のみが含まれ、厚さのオフセットが含まれます。
    • 表。板厚考慮しない : 接触の説明には上面のみが含まれ、シェルの厚さは無視されます。
    • 裏。板厚考慮 : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
    • 裏。板厚考慮しない : 接触の説明には底面のみが含まれ、シェルの厚さは無視されます。
      •
  • シェル要素面(マスター)

       シェル要素面(マスター)には以下のオプションがあります。

    • 表。板厚考慮 : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
    • 表。板厚考慮しない : 接触の説明には上面のみが含まれ、シェルの厚さは無視されます。
    • 裏。板厚考慮 : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
    • 裏。板厚考慮しない : 接触の説明には底面のみが含まれ、シェルの厚さは無視されます。
      •

    • 色設定

  • 接触の色

       接触対表示マーカー色を定義します。

    • リセット: デフォルト色に初期化

    • - 操作手順 -   

    1.  マスターでマスター面となるフェースを選択します。続いてスレーブでスレーブ面となるフェースを選択します。
    2.  必要により接触対に対する詳細設定を定義し、適用（OK）ボタンをクリックして接触対を定義します。
