圧力 | 円筒面に負荷 (二次)

選択したフェースまたは要素面に2次関数分布に基づいた圧力荷重を定義します。

　　

構造

  • 名前

    圧力荷重条件の名前を入力します。

    • 　　

    二次曲線 : y=ax²+b

     二次関数の設定をします。


  • a

    2次関数のaを定義します。

  • b

    2次関数のbを定義します。

  • 入力単位系

    入力単位を指定します。

  • 荷重座標系

    荷重適用範囲の角度を決定する座標系を選択します。

  • 角度

    荷重適用範囲を指定した座標系XY平面におけるY軸からの角度を入力します。
    荷重適用範囲は角度0～PIとなり、0°＜角度＜90°の範囲で入力します。

  • 入力単位系

    入力単位を指定します。

  • 圧力方向

    圧力荷重方向を指定します。

    • 法線 ： 要素面垂直
    • ベクトル ： 指定任意方向
      •
  • 方向座標系

    圧力方向が「ベクトル（指定任意方向）」の場合に、参照する座標系を選択します。

  • 方向

    圧力方向が「ベクトル（指定任意方向）」の場合に、方向ベクトルをX,Y,Zの順にカンマ区切りで入力します。


    • 荷重適用範囲に含まれるサーフェース上に、2次関数を使用した圧力が負荷されます。奥行き方向は一定です。
    xには指定した座標系における要素中心X座標値を使用します。

    - 操作手順 -

    1.  選択リストから、画面上から圧力荷重の対象となるフェースまたは要素面を選択します。(複数の選択が可能です)
    2.  荷重につける名前を入力します。
    3.  2次関数式のaとbの数値を入力します。
    4.  2次関数の荷重適用範囲の座標系、角度を指定します。
    5.  圧力方向がベクトルの場合、座標系と方向ベクトルを指定します。
    6.  適用またはOKボタンを押します。
