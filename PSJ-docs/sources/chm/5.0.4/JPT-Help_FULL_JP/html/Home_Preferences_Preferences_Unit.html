単位

単位系の設定を行います。

モデル単位系

  • デフォルト単位系

    • モデルのデフォルト単位系を設定します。新規ドキュメントのモデル表示単位系は全てこの単位系で作成されます。

  • 現在の単位系

    • 現在開いているドキュメントの単位系を設定します。

  • プリセット単位系

    • 単位系設定のプリセットを読み込みます。

  • 基本単位系 表示

    • ONにすると、メインウィンドウ下部のスケール表示に、現在のドキュメントの基本単位系を追加表示します。

    ※V5.0.1より、下記の単位系が追加されました。
    タイプ単位
    Force(力)mN
    Moment(モーメント）mN*mm
    Stiffness（剛性）mN/mm
    Rotate Stiffness（回転剛性）mN*mm/rad
    mN*mm/deg
    Damping Coefficient（減衰係数）mN*s/mm
    Rotate Damping Coefficient（回転減衰係数）mN*mm*s/rad
    mN*mm*s/deg

    結果表示単位系

  • 元の単位系

    • 解析結果の数値はこの単位系で読み込まれます。

  • 現在の単位系

    • 現在開いているドキュメントの単位系を設定します。

  • プリセット単位系

    • 単位系設定のプリセットを読み込みます。

    - 操作手順 -

    1. 単位系の設定対象をデフォルト単位系/現在の単位系から選択します。

    2. 右側の単位系のテーブルの単位の各項目のプルダウンメニューから、単位系を個別に指定します。あるいは、プリセット単位系から単位系セットを選択します。

    3. 適用もしくはOKボタンをクリックして、変更を反映させます。
