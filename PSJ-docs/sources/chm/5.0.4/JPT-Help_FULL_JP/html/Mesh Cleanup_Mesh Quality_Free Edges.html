フリーエッジ

フリーエッジ及びノンマニフォールドエラーを検出します。

エッジ数

  • フリー

    •    フリーエッジの個数を表示します。

  • ノンマニフォールド

    •    ノンマニフォールドの個数を表示します。

    表示オプション

  • メッシュカラー

    •    フリーエッジやノンマニフォールドの周りの表示メッシュ層数を設定します。

    • オリジナル : メッシュの色を変えず、エッジの色だけを変更します。
    • グレー : 既存のエッジの色に表示します。
      •

  • すべて表示

    •    オンにした場合、フリーエッジやノンマニフォールドの周りのメッシュが全て表示されます。レイヤー数はグレーアウトされます。

  • レイヤー数

    •    フリーエッジやノンマニフォールドの周りの表示メッシュ層数を設定します。

  • フリーエッジ

    •    オンにした場合、フリーエッジを表示します。

  • フリーエッジをパーツ毎に確認(*1)

    •    オンにした場合、フリーエッジの確認を、パーツ毎に行います。

  • ノンマニフォールド

    •    オンにした場合、ノンマニフォールドを表示します。

  • ノンマニフォールド閾値

    •    ノンマニフォールドの最低接続要素数を入力します。

  • 境界エッジを非表示

    •    シェル形状の外枠以外のフリーエッジを表示します。

    クローズギャップ

  • トレランス距離

    •    実行時に最大に動かすことの出来る節点間の距離を設定します。
       (1mm以上の隙間、ノンマニフォールド、中立面などの閉じてないモデルに関しては自動接合は行いません)。

  • クローズギャップ

    •    要素間の隙間を自動接合します。

    出力オプション

  • エラーテキスト

    •    オンにした場合、フリーエッジの情報を出力ウィンドウとInstall PathのTempフォルダにテキストデータで出力します。

    - 操作手順 -

    1.  チェックするパーツを選択します。
    2.  必要があれば表示オプションでレイヤー数とチェック項目を変更します。
    3.  適用またはOKボタンを押します。
    4.  チェック後、メインウィンドウ内の標準画面に戻すアイコン をクリックし、表示を元に戻します。

    <補足>
    適用またはOKボタン押下後、NキーまたはBキーでフリーエッジの要素を順に拡大表示することができます。
    ※V4.0.2以前では、フリーエッジはモデル全体で確認していました。 フリーエッジ箇所が共有節点で接続した２つのパーツがあるような場合、モデル全体ではフリーエッジが無いと表示されますが、パーツを個別に確認するとフリーエッジが発生し、ソリッドメッシュの作成ができないケースがありました。 V4.1で、パーツごとに確認するオプションを追加し、デフォルトをONとしました。 シェルメッシュを作成する場合には、本オプションをOFFとし、「境界エッジを非表示」オプションをONとして使用すると、注意すべきフリーエッジの確認がスムーズになります。
