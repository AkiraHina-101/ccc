円

パーツ上に円形エッジをインプリントします。

オプション

  • 面を分割

    •    フェースを分割します。

    パラメーター

  • 内径

    •    内径を入力します。

  • 外径

    •    外径を入力します。

  • レイヤー数

    •    作成したいレイヤー数を入力します。

  • 分割数

    •    分割数を入力します。


    - 操作手順 -

    1.  ラインを引きたいフェースと、ラインを引きたいフェース上の節点/フェース上任意点/エッジ上任意点を画面から選択します。
    2.  必要に応じて面を分割をオフにします。
    3.  外径に外径半径を入力します。(この値は必須です)
    4.  レイヤー分割を行う場合は、内径に内径半径値を入力し、さらにレイヤー数を入力します。
    5.  必要に応じて分割数に円形状の周方向エッジ分割数を入力します。
    6.  適用/OKボタンをクリックします。
