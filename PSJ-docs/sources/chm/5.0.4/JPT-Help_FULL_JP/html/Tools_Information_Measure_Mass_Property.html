質量[プロパティ]

パーツに定義された材料プロパティから質量を計測します。

計測

  • 座標系

       参照座標系

    • 出力

  • 値

       計測結果（質量）が表示されます。

  • 入力単位系

       表示する質量の単位を指示します。

    • 重心

  • X/Y/Z

       参照座標系における重心位置を指定します。

    • 慣性モーメント

  • 軸
    • Principal : 慣性モーメント計算に慣性主軸を用います。
      • 11,22,33 : 主慣性モーメントの値
      • 回転角度 : 主軸の回転角度
      • 1/2/3  X,Y,Z : 各慣性主軸の方向(重心座標が0)

    • XYZ : 慣性モーメント計算に参照座標系を用います。
      • XX/YY/ZZ/XY/XZ/YZ : 参照座標系まわりの慣性モーメントの値

    - 操作手順 -

    1.  画面上からパーツを選択します。
    2.  値に選択されたパーツ全体の質量が表示されます。
      3. ※パーツ選択されなかった場合、ドキュメント内のすべてのパーツが計測対象となります。
