リナンバー | 選択エンティティ | 座標値

選択したエンティティのIDを、座標値に従って振り直し（リナンバー）します。
※座標値によるリナンバーでは、トレランス設定が不適切な場合、予想した結果となりません。 トレランスの指定方法については、こちらをご確認ください。

  • エンティティタイプ
    • 節点

      選択エンティティ内の節点を対象としてリナンバーします。

    • １D要素

      選択エンティティ内の1D要素を対象としてリナンバーします。

    • 2D要素

      選択エンティティ内の2D要素を対象としてリナンバーします。

    • 3D要素

      選択エンティティ内の3D要素を対象としてリナンバーします。

    • パーツ

      選択パーツをリナンバーします。

    • 座標系

      選択座標系をリナンバーします。

  • 開始ID

    リナンバーの開始IDを設定します。

  • 増分値ID

    • リナンバーの増分値を設定します。

  • ソート順
    • 昇順

      昇順にリナンバーします。

    • 降順

      降順にリナンバーします。

    ポジション

  • 座標系

    座標系を選択します。選択肢：グローバル座標系/任意のローカル座標系/円筒面

  • LCS設定（座標系で円筒面選択時のみ）

    選択節点及び円筒面からテンポラリの座標系を作成します。

  • 作成されたLCSを保存（座標系で円筒面選択時のみ）

    チェックすると、テンポラリの座標系をリナンバー後にドキュメント内に残しておきます。

  • Z軸に沿ったリナンバリング

    チェックすると、円筒形状に欠けがある場合に円筒長手方向の節点ID下数桁を揃えます。

  • ソートテーブル
    • ソート優先度

      対象エンティティのグルーピング順です。

    • ソート

      各軸方向のソートの有効/無効を指定します。チェックを外すと無効になります。また、ソート優先度1番目と３番目を同時に有効にすることはできません。

    • 軸

      ソート対象軸を指定します。

    • ソート順

      ・ ソート順：昇順/降順を指定します。

    • オフセット ID

      グルーピングされたエンティティ間のオフセットIDを指定します。

    • トレランス

      グルーピング時の閾値（距離）です。

  • プレビュー

    プレビューボタンをクリックすることで、リナンバー対象エンティティのりナンバー前後のIDを表示します。

  • 適用

    リナンバーを実行します。

  • キャンセル

    リナンバーを実行せずに、ダイアログを終了します。

  • Z軸に沿ったリナンバリングオプション使用例

    - 操作手順 （グローバル座標系/ローカル座標系）-

    1.  エンティティタイプの選択肢より、リナンバーを行いたいエンティティを指定します。
    2.  開始ID、増分値を指定します。
    3.  座標系から、グローバル座標系もしくは作成済のローカル座標系を選択します。
    4.  ソート設定テーブルの各項目を指定します。
    5.  メインウィンドウ上でエンティティを選択します。
    6.  プレビューボタンをクリックして、リナンバー前後のIDを確認します。
    7.  適用ボタンを押して、リナンバーを実行します。

    - 操作手順(円筒面) -

    1.  エンティティタイプの選択肢より、リナンバーを行いたいエンティティを指定します。
    2.  開始ID、増分値、ソート順を指定します。
    3.  座標系から、円筒面を選択します。
    4.  節点を３点、順に選択します。１点目：開始位置、２点目：Z方向、３点目：円周方向（＋）。
    5.  円筒面を選択し、LCS設定ボタンをクリックします。座標系のプレビューが表示されます。
    6.  メインウィンドウ上でエンティティ選択します。
    7.  プレビューボタンをクリックして、リナンバー前後のIDを確認します。
    8.  適用ボタンを押して、リナンバーを実行します。
