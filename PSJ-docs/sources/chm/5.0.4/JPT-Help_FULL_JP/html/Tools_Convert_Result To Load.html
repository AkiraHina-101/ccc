結果を荷重に変換

ポスト結果（限定タイプ）をPREのLBCに変換します。

現在、以下の結果タイプがサポートされています:

- 温度結果⇒温度負荷/初期温度/境界温度。

- 変位結果⇒初期変位/強制変位。

- 反力/反モーメント⇒力。

- 接触圧力⇒圧力。

- 接触力⇒力。

　　

コピー元

  • コピー元ドキュメント

       結果を変換するポストドキュメントを選択します。

  • ステップ/プロセス

       ポスト結果のステップ/プロセスを選択します。

    • 　　

    LBC

  • 有効

        チェックマークの付いた項目は、それぞれ選択したLBCに結果を変換する必要があります。

  • 結果名

       ポスト結果ファイルからの限定されたサポート結果を表示します。

  • 荷重タイプ変換

       有効項目から変換できるPreの荷重タイプを選択します。

    • - 操作手順 -

    1.  ポスト結果をJupiterにインポートします。
    2.  ポストソースドキュメントとステップ/プロセスを選択します。
    3.  LBCに変換する結果アイテムを有効にします。
    4.  選択リストのエンティティを選択します。
    5.  [適用]または[OK]ボタンを押して、コマンドを実行します。
