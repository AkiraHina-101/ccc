AbaqusInpインポート

このコマンドは、Abaqusファイル（.inp）をインポートするために使用されます。

インポートタイプ

  • 標準のAbaqusInp

    •     モデルジオメトリのみをインポートします。

  • AbaqusInpをプロパティで分けて読み込み

    •     モデルの形状と材料特性をインポートします。 ボディは、材料特性ごとに作成されます。

    角度

  • 面角度

    •     面の分割を決定するために、許容角度を指定します。 指定した値よりも小さい角度で隣接する要素間にエッジを作成して、面を定義します。

  • エッジ角度

    •     エッジ分割を決定するために、許容角度を指定します。 指定された値よりも大さい角度で隣接するエッジ要素に頂点を作成して、エッジを分割します。

    オフセット/番号の付け直し

  • ファイル名

    •     複数のファイルをインポートしてすべてのモデルを配置し、ファイル名をアルファベット順に並べ替えます。

  • 節点

    • ストラテジー: IDが重複している場合の変更方法をOffsetとRenumberから選択します。

    • 入力: ストラテジーによって入力内容が変わります。

    • 入力-オフセット: 入力値ぶんだけIDが増加します。新しいID =古いID +入力値。

    • 入力-番号を付け直します: 入力値が開始IDとなります。開始ID =入力値。

    • 開始: 開始IDを自動的に取得します。 開始IDは、オフセット/リナンバーを変更すると更新されます。

    • 終了: 最後のIDを自動的に取得します。 最後のIDは、オフセット/リナンバーを変更すると更新されます。
      •
  • 要素

    • ストラテジー: IDが重複している場合の変更方法をOffsetとRenumberから選択します。

    • 入力: ストラテジーによって入力内容が変わります。

    • 入力-オフセット: 入力値ぶんだけIDが増加します。新しいID =古いID +入力値。

    • 入力-番号を付け直します: 入力値が開始IDとなります。開始ID =入力値。

    • 開始: 開始IDを自動的に取得します。 開始IDは、オフセット/リナンバーを変更すると更新されます。

    • 終了: 最後のIDを自動的に取得します。 最後のIDは、オフセット/リナンバーを変更すると更新されます。
      •
  • リセット

    •     すべてのパラメータを元の状態に復元します。

    - 操作手順 -

    1.  コマンドを起動し、各オプションを指定して、[OK]ボタンをクリックします。

    2.  ユーザーは、ダイアログで1つまたは複数のターゲットデータを選択し、[開く]ボタンをクリックできます。

    3.  複数ファイルのインポートには2つのケースがあります。

      4.  最初のケース：インポートプロセスは、開いた後にスムーズに実行されます。 警告ログのみで、IDの重複などの特別なバグはありません。

       2番目のケース：IDが重複している場合、警告ログが表示されます。 ユーザーは、調整、はい（自動番号変更）、キャンセルなどの3つの方法のいずれかを指定します。

    4.  バグが存在する場合は、いくつか変更を加えます。 次に、インポートプロセスを終了します。
