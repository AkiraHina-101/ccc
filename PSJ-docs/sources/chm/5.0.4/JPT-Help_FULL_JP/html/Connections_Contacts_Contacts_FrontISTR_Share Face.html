接触 | 共有面 | FrontISTR

共有面からFrontISTR用接触設定を定義します。
共有面が分離(二重節点状態のフェースが作成)され、そのフェース間に接触対が定義されます。

基本

　　　
  • 名前

    接触対の名称を入力します。

    　　　
    • 　　　
  • アルゴリズム

    接触設定対象エンティティを選択します。
        フェース-フェース: フェース対フェース間接触

    　　　
    • 　　　
  • タイプ

    接触定義の挙動タイプを選択します。
        一般: 滑り接触

    　　　
    • 　　　
  • 共有フェース情報

        情報表示: 選択された共有面に関連するパーツ名が表示されます。

        パーツをハイライト: 選択された共有面に関連するパーツがハイライト表示されます。

    　　　

    • コンタクトプロパティ

    　　　
  • コンタクトタイプ

    FrontISTRの接触タイプを定義し、同じ接触タイプの設定を簡単にコントロールします。

        ID: IDを入力します。
        相互作用: 必要な方法を選択します。
        法線方向収束(NTOL): 法線方向収束パラメーターを入力します。
        接線方向収束 (TTOL): 接線方向収束パラメーターを入力します。
        法線方向ペナルティ (NPENALTY): 法線方向ペナルティパラメーターを入力します。
        接線方向ペナルティ (TPENALTY): 接線方向ペナルティパラメーターを入力します。

    List Contact Type Created: 作成したコンタクトタイプをすべて表示します。また、右クリックで編集や削除などの機能を利用することができます。
        編集: コンタクトタイプのパラメータを変更します。
        削除: コンタクトタイプを削除します。

    　　　
    • 　　　
  • 摩擦係数 (FCOEF)

    摩擦係数を入力します。

    　　　
    • 　　　
  • 摩擦ペナルティ剛性 (FACTOR)

    摩擦ペナルティ剛性を入力します。

    　　　
    • 　　　

    色設定

  • 接触の色

        接触対表示マーカー色を定義します。
        リセット: デフォルト色に初期化

    　　　

    • - 操作手順 -

      　　　
    1.  予めアセンブリ機能により共有面を作成し、共有面を表示しておきます。　
      2. 　　　
    2.  接触を定義したい共有面となるフェースを選択します。
      3. 　　　
    3.  必要により接触対に対する詳細設定を定義し、適用（OK）ボタンをクリックして接触対を定義します。

    共有面が分離(二重節点状態のフェースが作成)され、そのフェース間に接触対が定義されます。
