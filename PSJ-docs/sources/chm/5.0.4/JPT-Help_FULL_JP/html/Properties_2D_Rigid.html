剛体ダイアログボックス

シェル要素に剛体として定義します。
*ADVCおよびAbaqus出力に対応しています。
　ADVC向けに使用する場合は、シェル要素特性を先に与えてから、剛体特性を与えます。Abaqus向けには不要です。
　またADVC向けにはソリッド要素表面にも対応しています。

プロパティ

  • 名前

    プロパティの名前を設定します。

  • プロパティID

    プロパティのIDを入力します。プロパティIDはモデル内で重複しないように 入力します。

    • 参照節点

  • 参照節点ID

    剛体の参照節点を指定します。

    • - 操作手順 -

    1. 予め剛体とするシェル要素に対してシェル要素特性を定義します。(Abaqusの場合は不要)
    2. 剛体コマンドを起動し、フェース(もしくはシェル要素)を選択します。
    3. 続いて剛体の制御点となる参照節点を選択します。
