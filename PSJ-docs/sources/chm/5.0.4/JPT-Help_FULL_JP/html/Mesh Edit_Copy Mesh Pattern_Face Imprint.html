フェースのインプリント

このコマンドでは、最初に選択されたフェース形状を次に選択されたフェース上にインプリントします。
2番目に選択するフェースは最初に選択したフェースの法線方向にあるフェースを選択します。

オプション

  • メッシュをコピー

    フェース形状をインプリントする際に、メッシュパターンもコピーします。

    ※本機能は、ソリッドメッシュ作成済のパーツに対して実行した場合には、表面メッシュと内部メッシュに不整合が生じます。
    実行前にソリッドメッシュを削除するか、実行後にソリッドメッシュを再作成してください。


    • - 機能実行例 -


  • メッシュをコピーオプション

    1. 先にコピーしたいメッシュパターンのフェースを選択し、次にCADモデルのフェースを選択しOKボタンを押します。
    2. CADモデル上のフェースにメッシュパターンとインプリント線がコピーされます。
    3. コピー後のメッシュパターンはローカルメッシュ設定（メッシュをフリーズ）からメッシュパターンを保持しての全体メッシュ作成が可能になります。


    • - 操作手順 -

    1. ビューウインドウからコピー元のフェースとコピー先のフェースを順番に選択します。
    2. 適用またはOKボタンを選択し、コピー元のフェース形状をコピー先フェース上にインプリントします。
