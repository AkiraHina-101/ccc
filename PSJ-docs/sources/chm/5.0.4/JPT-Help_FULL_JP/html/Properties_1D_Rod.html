1Dプロパティ | ロッド

1D プロパティ | ロッドダイアログボックス

１次元Rod要素のプロパティデータを作成します。

  • 名前

    • プロパティの名前を指定します。

  • プロパティID

    • プロパティのIDを入力します。プロパティIDはモデル内で重複しないように入力します。

  • 色

    • プロパティの色を指定します。

ロッド

  • 材料

    • 材料特性を指定します。

  • 断面

    • 既存の要素特性リストから選択します。

  • 面積

    • 断面積の値を入力します。

  • ねじり定数

    • ねじり定数を入力します。

  • ねじり応力係数

    • ねじり応力係数を入力します。

  • 非構造質量

    • 非構造質量を入力します。

入力単位系

  • 長さ

    • 長さの単位を選択します。

  • 質量

    • 質量の単位を選択します。

プレビュー

  • プレビュー

    • 入力したパラメーターでプレビューを表示します。

     

- 操作手順 -

  1. 名前にプロパティの名前を入力します。
  2. 材料プルダウンメニューからすでに登録された材料を選択します。
  3. ロッド要素の断面係数を、断面のリストから選択するか、面積、ねじり定数に値を入力します。
  4. 必要に応じてねじり応力係数、非構造質量要素、入力単位を設定します。
  5. 適用またはOKボタンをクリックします。
