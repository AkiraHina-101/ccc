ローカル座標系[3節点]

画面上から任意の節点を3点選択し、座標系を作成します。

　　

座標系

  • タイプ

       座標系のタイプを選択します。

    • 直交 : 直交座標系を選択します。
    • 円筒 : 円筒座標系を選択します。
    • 球 : 球座標系を選択します。

  • 順番

       節点の選択する順番の意味を指定します。

    • O.Z.ZX 平面 : 原点、Z軸上の点、ZX平面上の点の順に選びます。
    • O,X,ZX 平面 : 原点、X軸上の点、ZX平面上の点の順に選びます。
    • O,Y,XY 平面 : 原点、Y軸上の点、XY平面上の点の順に選びます。
    • O,X,XY 平面 : 原点、X軸上の点、XY平面上の点の順に選びます。
    • O,Z,YZ 平面 : 原点、Z軸上の点、YZ平面上の点の順に選びます。
    • O,Y,YZ 平面 : 原点、Y軸上の点、YZ平面上の点の順に選びます。

  • 名前

       作成する座標系の名前を入力します。

    • 参照座標系

  • 座標系

       作成する座標系が参照する既存の座標系から選択します。

    • 原点

  • X/Y/Z

       最初に選択した節点のX/Y/Z座標値が表示されます。

    • 2点目

  • X/Y/Z

       2番目に選択した節点のX/Y/Z座標値が表示されます。

    • 3点目

  • X/Y/Z

       3番目に選択した節点のX/Y/Z座標値が表示されます。


    • - 操作手順 -

    1.  タイプから座標系の種類を選択します。
    2.  順番から節点を選択する順番の意味を選択します。
    3.  3つの節点を順に選択します。選んだ節点の座標値が表示されます。
    4.  適用またはOKボタンを押します。
