プリテンション | SunShine

SunShine用初期張力を設定します。

構造

  • ステップ名

    作成するアイテムの名前を入力します。

    軸力

  • 値

    初期張力を入力します。

  • 入力単位系

    入力単位系を選択します。

    • - 操作手順(パーツを選択する場合)  -

      ボルトを2つの部分に切断して準備します。

    1. 2つの部分のボルトを選択します。
    2. 初期張力を入力します。
    3. 必要に応じて単位系の変更します。
    4. 適用またはOKボタンをクリックします。

    - 操作手順(断面を選択する場合)  -

      ボルトを2つの部分に切断して準備します。

    1. 切断位置でボルトの2つの面を選択します。
    2. 初期張力を入力します。
    3. 必要に応じて単位系の変更します。
    4. 適用またはOKボタンをクリックします。

    - 操作手順（梁要素を選択する場合） -

      1D メッシング等の機能を使用し3分割以上された梁要素のボルトパーツを予め用意します。

    1. 選択リストのエッジをクリックし、エッジを選択します。
    2. 初期張力を入力します。
    3. 必要に応じて単位系の変更、オプションを追加選択します。
    4. 適用またはOKボタンをクリックします。
