1Dプロパティ | 断面設定

断面性能をライブラリに登録できます。

ボタン

  • 追加

    断面ダイアログボックスを開いて、新しい断面性能を登録します。

  • 修正

    断面ダイアログボックスを開いて、断面性能を編集します。

  • 削除

    断面性能を削除します。

  • インポート

    断面性能を1Dプロパティライブラリのxml形式、もしくはslib形式で読み込みます。

    ※slib形式で読み込んだ1Dプロパティは、ノート列に「SLIB」と記載されます。形状の修正ができない代わりに細かいプロパティを個別に設定することができます。

    slib形式
    <?xml version="1.0" encoding="UTF-8">
    <JPT-BAR-PROPERTY-LIBRARY>
    <Bar-Property Name="M3" A="7.068583" Izz="3.976078" Iyy="3.976078" J="7.952157" Cy="1.5" Cz="0" Dy="0" Dz="-1.5" Ey="-1.5" Ez="0" Fy="0" Fz="1.5" K1="0.9" K2="0.9"/>
    </JPT-BAR-PROPERTY-LIBRARY>

    xml形式
    <?xml version="1.0" encoding="UTF-8"?>
    <JPT-BAR-PROPERTY-LIBRARY>
    <Section Name="M34" Type="General" Dir="90" Taper="false">
    <Detail Type="CIRCLE" a="0" b="0" h="0" t1="0.017" t2="0" t3="0">
    </Detail></Section>
    </JPT-BAR-PROPERTY-LIBRARY>

  • エクスポート

    断面性能を1Dプロパティライブラリのxml形式で書き出します。

    • 断面ダイアログボックス

    断面特性値を計算します。作成された値は断面プルダウンメニューに 登録されます。

    一般

    一般断面特性を入力します。

  • 名前

    断面特性の登録名前を入力します。

  • タイプ

    選択された計算タイプが表示されます。

  • 形状

    一般断面計上を選択します。選択された形状に従って寸法変数名が右のイメージとサイズ表に表示されます。

  • テーパー

    梁の左右の断面サイズが異なる場合に選択します。サイズ変数を2種類入力できるようになります。

  • サイズ表

    表示された寸法変数に値を入力します。

  • 要素Y方向

    断面のY軸方向を選択します。

  • 入力単位系

    断面計算の入力単位を選択します。

    • ライブラリー

    Nastranの断面形状ライブラリを使用します。

  • 名前

    断面特性の登録名前を入力します。

  • タイプ

    選択された計算タイプが表示されます。

  • 形状

    Nastranの断面ライブラリのタイプを選択します。選択された形状に従ってNastranの寸法変数名が右のイメージとサイズ表に表示されます。

  • テーパー

    梁の左右の断面サイズが異なる場合に選択します。サイズ変数を2種類入力できるようになります。

  • サイズ表

    表示された寸法変数に値を入力します。

  • 要素Y方向

    断面のY軸方向を定義します。

  • 入力単位系

    断面計算の入力単位を選択します。

    • - 操作手順（追加） -

    1. 追加ボタンをクリックして、断面ダイアログボックスを開きます
    2. パラメータを入力します。
    3. 断面ダイアログボックスのOKボタンをクリックします。

    - 操作手順（編集） -

    1. テーブル上で編集対象の断面性能をクリックします。
    2. 修正ボタンをクリックして、断面ダイアログボックスを開きます
    3. ＊テーブル上で断面性能をダブルクリックした場合も、編集用の断面ダイアログボックスが開きます。
    4. パラメータを入力します。
    5. 断面ダイアログボックスのOKボタンをクリックします。

    - 操作手順（削除） -

    1. テーブル上で削除対象の断面性能をクリックします（複数選択可）。
    2. 削除ボタンをクリックします。
