RBE3

RBE3（剛体要素）を作成します。
複数のRBE3でスレーブ節点が重複する場合、意思確認メッセージが表示されます。

  • 1対多

    一対多（スレーブ：マスター）のRBE3（内挿拘束要素）を作成する機能ですす。

  • 1対1

    一対一（スレーブ：マスター）のRBE3（内挿拘束要素）を作成する機能です。

  • 中心へ

    一対多（スレーブ：マスター）のRBE3（内挿拘束要素）を作成する機能です。スレーブ節点は、選択したマスター節点の平均座標または任意座標に作成されます。
    モデル外の位置にスレーブ節点を定義したい場合に便利な機能です。

  • 円弧エッジの中心へ

    一対多（スレーブ：マスター）のRBE3（内挿拘束要素）を作成する機能です。スレーブ節点は、選択したマスター節点の平均座標または任意座標に作成されます。
    円や円筒形状に対してRBE3を作成したい場合に便利な機能です。
