エッジ

エッジを分割します。
節点位置分割と角度分割が可能です。

エッジを分割

  • 指定角度で自動分割

    チェックをONにすると、指定された角度以下の節点で、エッジを自動的に分割します。

  • 角度

    角度[deg]を入力します。

    • - 操作手順（節点位置分割） -

    1. 分割位置の節点を選択します。
    2. 適用/OKボタンをクリックします。

    - 操作手順（角度分割） -

    1. 指定角度で自動分割をクリックします。
    2. 角度に指定数値を入力します。
    3. 分割するパーツを選択します。
    4. 適用/OKボタンをクリックします。
