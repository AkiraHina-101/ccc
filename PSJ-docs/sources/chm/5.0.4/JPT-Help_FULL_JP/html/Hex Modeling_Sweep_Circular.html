スイープ | 円形

作成したサーフェスメッシュ(Tri,Quadメッシュ)からソリッドメッシュを
指定した軸に軸対称にスイープして作成します。

円形パラメーター

  • 角度

    スイープする角度を入力します。

  • レイヤー数

    層数を入力します。

  • 中心タイプ

    回転中心の設定をプルダウンから選択します。

    • エッジの中心 : 選択したエッジの中心
    • 節点 : 選択した節点
    • 任意 : 入力した任意方向のベクトル
    • ローカル座標系 : ローカル座標系の方向を指定します。
      •
  • 中心X,Y,Z

    中心位置X,Y,Z成分

  • 軸タイプ

    回転軸の設定をプルダウンから選択します。

    • 節点 : 選択した２つの節点で指定
    • 要素エッジ : 選択した要素エッジで指定
    • 任意 : 入力した任意方向のベクトル
    • ローカル座標系 : ローカル座標系の方向を指定します。
      •
  • 軸X,Y,Z

    軸方向ベクトルX,Y,Z成分

  • 軸トレランス

    回転軸のトレランスを指定できます。

    • 自動インターフェースPenta5/Tet4

  • インターフェース要素

    チェックすると境界面にペンタ要素を作成します。

    • 元の形状を自動消去

  • 元の形状を消去

    チェックすると自動で元の部品を削除します。

    • 回転角度と押し出し距離

  • 回転角度と押し出し距離

    チェックすると回転角度と押し出し距離を可能にします。

  • 押し出す距離

    押し出し距離を定義します。

    • ※2次要素が含まれるエンティティを選択し実行した場合は、ワーニングが表示されます。
    1次要素に変換し実行します。

    - 操作手順 -

    1. 回転スイープする面を選択します。
    2. 回転スイープする角度を指定します。
    3. 層数を指定します。
    4. 回転軸および中心を設定します。
    5. 適用もしくはOKボタンをクリックします。
