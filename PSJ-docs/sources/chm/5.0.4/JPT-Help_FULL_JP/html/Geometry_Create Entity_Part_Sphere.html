球

球体を作成します。

パーツプロパティ

  • パーツ数

    作成する球体の名前を入力します。

    • 球

  • ローカル座標系

    任意の座標系を選択します。

  • 原点-X,Y,Z

    原点座標を指定します。

  • 半径

    球の半径を入力します。

  • 緯度の節点数

    緯度方向の分割数を入力します。

  • 経度の節点数

    経度方向の分割数を入力します。

    • - 操作手順 -

    1. パーツ名にパーツ名を入力します。
    2. 原点-X,Y,Zに原点座標を指定します。
    3. 半径に球の半径を入力します。
    4. 緯度の節点数に緯度方向の分割数を入力します。
    5. 経度の節点数に経度方向の分割数を入力します。
    6. 適用/OKボタンをクリックします。
