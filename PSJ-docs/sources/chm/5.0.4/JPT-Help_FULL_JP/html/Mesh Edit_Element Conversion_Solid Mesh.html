要素の変換 | ソリッドメッシュ

ソリッド要素の次数変換を行います。

変換タイプ

  • 一次要素へ(Tet4,Penta6,Hex8,Pyramid5)

       一次要素へ変換します。

  • 二次要素へ(Tet10,Penta15,Hex20,Pyramid13)

       二次要素へ変換します。

  • Hex to Penta6

       Hex要素をPenta6要素へ変換します。

  • Hex/Penta to Tet4

       Hex要素,Penta要素をTetra一次要素へ変換します。

    • - 操作手順 -

    1. 変換方法を指定します。
    2. 対象のパーツを選択します。
    3. 適用/OKボタンをクリックします。
