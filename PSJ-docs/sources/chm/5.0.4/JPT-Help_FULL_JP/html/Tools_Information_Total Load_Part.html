合計荷重[パーツ]

選択したパーツに設定されている、力と圧力の合計値を荷重で表示します。

　　

計測

  • 方法

       荷重の計測対象

  • 座標系

       参照座標系

    • 出力

      計測値を表示します。
  • 入力単位系

       入力単位を指定します。

  • X

       X方向の荷重

  • Y

       Y方向の荷重

  • Z

       Z方向の荷重

  • 合計

       合計荷重の絶対値


    • - 操作手順 -

    1.  計測対象のパーツを選択します。
    2.  出力に選択されたパーツにかかる荷重の合計値が表示されます。
