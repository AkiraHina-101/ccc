３節点

選択したパーツを、3点で分割平面を定義し分割します。

選択する平面

  • オフセット

    オフセット値を入力します。3点で指定した分割平面からオフセットした距離で分割します。

  • パーティションのみ

    チェックを入れると、パーツ上に交差線のみを作成します。この場合パーツは分離せず、Face分割のみ行います。

  • 断面フェースを作成

    チェックを入れると、パーツを分割した場合に、分割した箇所にフェースを作成します。

  • 共有面

    チェックを入れると、パーツを分割し、分割した箇所にフェースを作成する場合に、共有面を作成します。

  • 共有面分離

    チェックを入れると、パーツを分割し、分割した箇所にフェースを作成する場合に、フェースが飛び地で結合（マージ）されることを防ぎます。

    • - 操作手順（パーツを分割し、分割した箇所にフェースを作成する場合） -

    1. 選択リスト ウインドウを開き、ターゲットボタンをクリックします。
    2. 分割するパーツを選択します。
    3. 選択リスト ウインドウのCut Nodeボタンをクリックします。
    4. 分割する平面を定義するために、3節点選択します。
    5. 断面フェースを作成のチェックボックスをオンにします。
    6. 適用/OKボタンをクリックします。

    - 操作手順（パーツを分割せず、パーティションのみ作成する場合） -

    1. 選択リスト ウインドウを開き、ターゲットボタンをクリックします。
    2. 分割するパーツを選択します。
    3. 選択リスト ウインドウのCut Nodeボタンをクリックします。
    4. 分割する平面を定義するために、3節点選択します。
    5. パーティションのみ のチェックボックスをオンにします。
    6. 断面フェースを作成のチェックボックスをオンにします。
    7. 適用/OKボタンをクリックします。
