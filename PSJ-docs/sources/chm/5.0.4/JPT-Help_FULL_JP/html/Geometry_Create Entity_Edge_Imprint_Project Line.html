ライン投影

選択したエッジを選択したフェース上に垂直に投影します。

オプション

  • 面を分割

    •    フェースを分割します。

  • ベクトル方向

    •    投影方法を指定します。

    • ターゲットフェースの法線：投影先フェースの法線方向に投影します。
    • ２節点：指定した２節点の方向に投影します。
    • 最近接方向：選択エッジに最も距離の近いフェース上に投影します。
      •
  • 間隙量

    •    投影距離を入力値までに制限します。



    - 操作手順 -

    1.  エッジまたはフェースボタンを押し、インプリント元になるエッジとインプリント対象のフェースを画面より選択します。
    2.  投影先が正しいか、プレビューが表示から確認します。
    3.  必要に応じて、投影方法や間隙量を設定します。
    4.  必要に応じて面を分割チェックボックスをオフにします。この場合はインプリント後のフェースが元のフェースから分割されません。
    5.  適用/OKボタンをクリックします。
