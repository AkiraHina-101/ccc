自由度定義

このコマンドではTS-SolverのASETを定義します。



構造

  • 名前

       作成する自由度定義の名前を入力します。

  • 座標系

       拘束する自由度が参照する既存の座標系をプルダウンメニューから選択します。

    • 自由度成分

     拘束する自由度の方向をチェックボックスから選択します。
  • 変位X

       チェックするとX方向の並進移動を拘束します。

  • 変位Y

       チェックするとY方向の並進移動を拘束します。

  • 変位Z

       チェックするとZ方向の並進移動を拘束します。

  • 回転X

       チェックするとX軸周りの回転移動を拘束します。

  • 回転Y

       チェックするとY軸周りの回転移動を拘束します。

  • 回転Z

       チェックするとZ軸周りの回転移動を拘束します。

    • - 機能実行画面と出力例 -

    - 操作手順 -

    1. ASETを設定するフェース、エッジ、もしくは節点を選択します。
    2. 各方向成分を設定します。
    3.  適用/OKボタンをクリックします。
