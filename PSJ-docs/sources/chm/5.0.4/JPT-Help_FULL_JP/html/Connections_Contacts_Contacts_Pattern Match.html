メッシュパターン確認

合い面のメッシュパターンを確認します。接触定義するペアフェース間で、メッシュパターンが合致しているかどうかを検出・表示します。



  • 不一致パターンを表示

       メッシュパターンが一致していない箇所を表示します。
       ※V4.0から不一致の要素数を出力ウインドウに表示します。

  • 一致するパターンを表示

       メッシュパターンが一致している箇所を表示します。
       ※V4.0から一致の要素数を出力ウインドウに表示します。

  • 検索トレランス

       メッシュパターンを検出するフェース間距離を入力します。

    • - 操作手順 - 

    1.  隣接するパーツを２つ以上選択します。
    2.  必要に応じてトレランスの値をデフォルト値から変更します。
    3.  必要に応じて「不一致パターンを表示」「一致するパターンを表示」チェックボックスを切り替えます。
    4.  適用をクリックします。「一致するパターンを表示」にチェックを入れている場合には、メッシュパターンが合い面間で合致しているメッシュが青色で表示されます。「不一致パターンを表示」にチェックを入れている場合には、メッシュパターンが合い面間で合致していないメッシュが赤色で表示されます。
