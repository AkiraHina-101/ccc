表示桁数

Jupiter上の数値表示形式の設定を行います。

  • 名前

    • 設定対象です。

    • 均一設定

      • Jupiter一般の設定です。

    • コマンドウィンドウ

      • コマンドウィンドウの設定です。

    • 凡例

      • コンター凡例数値の設定です。

    • アッセンブルウィンドウ

      • アッセンブルウィンドウ内に関する設定です。

    • 結果ウィンドウ

      • 結果ウィンドウ内に関する設定です。

    • タイトル

      • メインウィンドウ上に表示されるタイトルの設定です。

    • ウォッチデータ

      • ウォッチデータウィンドウに表示される数値の設定です。

    • CSV出力

      • CSVファイルにウォッチデータウィンドウから値を出力した際に、出力ファイル内に書き出される数値の設定です。
  • 均一表示使用

    • チェックを入れることで、均一設定と同じ設定を使用します。

  • タイプ

    • 数値表示形式を、実数形式(123.456)もしくは指数形式(1234E-005)から選択します。

  • 幅

    • 数値の表示幅を指定します。

  • 小数点

    • 小数点以下の表示桁数を指定します。

  • （オプション）

    • 各項目のオプションです。

    • 自動調整

      • 数値を最適な形式で表示します。

    • オリジナル桁数

      • 持っているデータをそのまま出力します。

    - 操作手順 -

    1.  コマンドを起動し、各オプションを指定して適用もしくはOKボタンをクリックします。
