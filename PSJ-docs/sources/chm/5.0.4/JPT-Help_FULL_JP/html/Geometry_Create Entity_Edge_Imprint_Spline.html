スプライン

3点以上のポイントを選択し、それらのポイントを通るスプラインカーブ状のエッジを作成します。

オプション

  • 面を分割

    エッジ作成後に、フェースが分割可能な場合に、分割します。

    • - 操作手順 -

    1. インプリント先のフェースと、節点/任意点を3点以上選択します。
    2. プレビューが表示されますので、インプリントに問題がないか確認します。必要に応じて、選択リストダイアログ内の選択エンティティを削除可能です。
    3. 適用/OKボタンをクリックします。
    4. 指定した節点/任意点を通るスプラインカーブ状のエッジを作成します。
