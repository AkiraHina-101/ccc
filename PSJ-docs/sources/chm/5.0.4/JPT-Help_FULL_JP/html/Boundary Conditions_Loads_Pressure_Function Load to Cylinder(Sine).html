圧力 | 円筒面に負荷 (正弦)

選択したフェースまたは要素面にSin関数分布に基づいた圧力荷重を定義します。

　　

構造

  • 名前

       圧力荷重条件の名前を入力します。

    • 　　

    正弦曲線 :  y=a×sine(rad)

      Sin関数の設定をします。
  • a

       Sin関数の係数aの値を定義します

    • 式入力の場合

      aには定数の他に式入力も利用できます。式入力は=で開始し、四則演算子と括弧（）が使用できます。
      また、圧力荷重の負荷点の座標値X,Y,ZをそれぞれCX,CY,CZで表現できます。（いずれも大文字のみで、常に全体座標系を参照）

      例) 計算点のX座標値を引用する場合
      =12-3×(13+4)×CX

      •
  • 入力単位系

       入力単位を指定します。

  • 荷重座標系

       荷重適用範囲のXY平面が参照する座標系を指定します。

  • 角度

       荷重適用範囲を指定した座標系XY平面におけるY軸からの角度を入力します。
       荷重適用範囲は角度0～PIとなり、0°＜角度＜90°の範囲で入力します。

  • 入力単位系

       入力単位を指定します。

  • 分布方向

       奥行き方向分布の有無を指定します。
    チェックを入れた場合に、奥行き方向もSin関数の分布がされます。

  • 圧力方向

       圧力荷重方向を指定します。

    • 法線 ： 要素面垂直
    • ベクトル ： 指定任意方向
      •
  • 方向座標系

       圧力方向が「ベクトル（指定任意方向）」の場合に、参照する座標系を選択します。

  • 方向

       圧力方向が「ベクトル（指定任意方向）」の場合に、方向ベクトルをX,Y,Zの順にカンマ区切りで入力します。

  • 圧力合計値調整

       チェックを入れた場合に、圧力の合計値を指定した値に調整します。

  • 合計値

       圧力の合計の指定値

  • 要素節点位置分布

       圧力荷重値を要素節点位置で計算し出力します。


    •  荷重適用範囲に含まれるサーフェース上に、Sin関数を使用した圧力が負荷されます。
    分布方向の指定がない限り奥行き方向は一定です。

    - 操作手順 -

    1.  選択リストからフェースまたは要素ボタンを選択し、画面上から圧力荷重の対象となるフェースまたは要素面を選択します。
    2.  荷重につける名前を入力します。
    3.  aにSin関数式のaの数値または数式を入力します。
    4.  角度にSin関数の分布範囲を指定する角度を入力します。
    5.  必要に応じて分布方向、圧力方向、圧力合計値調整、要素節点位置分布オプションを利用します。
    6.  適用またはOKボタンを押します。
