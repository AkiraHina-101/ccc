自動コラプス

要素の削除と結合をします。要素エッジの選択・実行に、自動処理を組み込んだ機能です。

自動コラプス

  • 要素エッジ自動選択

    選択節点に接続する要素エッジの中で、トレランス以下の最も短いエッジを自動選択します。フリーエッジモードでは、節点の選択が解除されないため、連続的に機能を実行できます。

  • 接続する要素エッジ全てをコラプス

    選択節点に接続する要素エッジの中で、トレランス以下の全ての要素エッジを節点に引き込み、要素を削除します。

  • トレランス

    自動選択・実行の際に選択される要素エッジの最大長さを指定します。


    • - 操作手順 （要素エッジ自動選択）-

    1. 残したい節点を選択します。選択節点に接続している、トレランス以下の長さの要素エッジの中で、最も短い要素エッジが自動的に選択されます。
    2. 適用ボタンをクリックします。
    1.節点選択(要素エッジ自動選択) 2.Applyをクリック

    - 操作手順 （要素エッジ自動選択＋フリーエッジモード）-

    1. 残したい節点を選択します。選択節点に接続している、トレランス以下の長さの要素エッジの中で、最も短い要素エッジが自動的に選択されます。
    2. 適用ボタンをクリックします。選択した節点に、選択した要素エッジのもう片方の節点が結合され、間にあった要素が削除されます。また、残った要素エッジの中で、最も短い要素エッジが選択されます。
    3. 適用ボタンをクリックします。（同繰り返し）
    1.節点選択(要素エッジ自動選択) 2.Applyをクリック
    （節点選択保持、要素エッジ自動選択）    		 3.Applyをクリック
    （節点選択保持、要素エッジ自動選択）    		 4.繰り返し

    - 操作手順 （接続する要素エッジ全てをコラプス）-

    1. 残したい節点を選択します。
    2. 適用ボタンをクリックすると、選択節点とトレランス以下の全ての要素エッジを用いてコラプスを実行します。
    1.節点選択 2.Applyをクリック
    （トレランス以下の要素エッジを全てコラプス）
