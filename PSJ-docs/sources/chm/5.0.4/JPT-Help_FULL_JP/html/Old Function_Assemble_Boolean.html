ブーリアン

ブーリアンダイアログボックス

選択された2つのボディに対してブーリアンオペレーションを実施します。

演算方法

  • 選択

    実行するブーリアンオペレーションのタイプを選択します。

    • 結合（論理和）

      選択した2つのボディを1つのボディにします。

    • 削除（論理差）

      ボディを2つ選択して、ボディの重複部分を削除して、1つ目に選択したボディ のみ残ります。

    • 重複部（論理積）

      ボディを2つ選択して、ボディの重複部分を抽出します。

    • 交差エッジ作成

      ボディを2つ選択して、ボディが交差しているフェースにエッジを作成します。

    • 削除と交差エッジ作成

      ボディを2つ選択して、1つ目のボディはボディの重複部分を削除します。 2つ目のボディはボディが交差しているフェースにエッジを作成します。

    • 重複部分削除

      ボディ間に貫入部分がある2つのパーツを選択して、ボディとボディの重複部分 を削除します。溶着部分などのモデル化において、共有面を作成する処理で使用します。
      ※重複部分削除オプションは、このコマンドを実行する前に、アッセンブル＞共有面作成コマンドで、検索ボタンを実行する必要があります。
      この処理により、本オプションの削除対象面が認識されます。操作手順をご参照ください。

  • 位置トレランス

    トレランスを設定します。


    • - 操作手順 -

      一般ブーリアンオペレーションの場合（重複部分削除オプションを除く）
    1. 選択から実行するブーリアンオペレーションのタイプを選択します。
    2. 画面から実行対象となるボディを２つ選択します。実行タイプによって 選択順に意味がありますので注意します。
    3. 必要に応じてトレランスに値を入力します。
    4. 適用またはOKボタンをクリックして演算を実行します。
      重複部分削除オプションの場合
    1. アッセンブル＞共有面作成コマンドを起動します。対象となる貫入量をトレランスに入力し、検索ボタンを実行します。
    2. 対象となる面が検索されたら、適用、OK、キャンセルボタンを押さないまま、ブーリアンコマンドを起動します。
    3. 選択から重複部分削除オプションを選択します。
    4. 対象となる貫入量を位置トレランスに入力します。
    5. 画面から実行対象となるボディを２つ選択します。
    6. 適用またはOKボタンをクリックして演算を実行します。重複部分が削除されます。
    7. 必要に応じてアッセンブル＞共有面作成コマンドを起動し、通常の操作で接触面に共有面を作成します。
