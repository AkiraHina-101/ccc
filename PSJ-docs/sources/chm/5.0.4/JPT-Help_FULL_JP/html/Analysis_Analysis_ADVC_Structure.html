構造

ADVENTURECluster(以後ADVC)の構造解析向けの入力ファイルを出力します。

変位、速度、加速度の拘束条件に関し、同じ節点自由度に対して重複した場合、かつ設定されている値が異なる場合、ワーニングメッセージを表示します。
重複判定は、各プロセス毎かつ各項目毎に判断されます。

ADVCジョブ

  • ジョブ名

       ADVCジョブの名前を設定します。

  • ジョブの説明

       ジョブの説明を記載します。

  • ジョブタイプ

       解析種別の選択します。

    • 構造 : 構造解析

    • 熱伝達 : 伝熱解析
      •

    • ADVCプロセス

  • プロセスを作成

       プロセスを作成するADVCプロセス設定ダイアログを起動します。

    • 間隔の定義

  • LBCマネージャ

       境界拘束条件やロードケースを設定するLBCマネージャダイアログを起動します。

  • 接触マネージャ

       接触条件の状態を設定する接触マネージャダイアログを起動します。

    • 結果参照

  • プロセス

       参照結果ダイアログを起動します。

       Step欄ではStep番号の他、All, Lastを指定することも可能です。

    • 出力定義

  • 出力マネージャ

       チェックボックスを選択し、出力要求を設定する出力マネージャダイアログを起動します。

    • オプション

  • フォーマットタイプ

        節点、境界条件のデータを単精度（シングル）で出力するか、倍精度（ダブル）で出力するかを選択します。

    • シングル : 単精度で出力します。書式は%13.6eです。
    • ダブル : 倍精度で出力します。書式は%23.15eです。

  • グループ出力

       フェース、要素、節点グループを$SurfaceSegment、$ElementSet、$NodeSetとして出力します。

  • ファイル分割単位

        節点、要素データのみ別ファイルで出力します。解析規模が大きい場合、分けて出力することで解析制御用の入力ファイルのサイズが小さくなり、手入力によるコマンド変更が容易になります。

    • なし : 全データを一つのファイルに出力します。
    • モデル : 節点、要素データを 1つの別ファイルで出力します。
    • パーツ毎 : 節点、要素データを パーツ毎に別ファイルで出力します。
    • 選択したパーツのみ : 選択したパーツに関連する LBC をすべて出力します。
    • 選択した境界条件のみ : 選択した境界条件のみファイル出力します。
      •

  • 境界条件

       ファイル分割単位がパーツの場合に、境界条件、接触対、接触セグメントを別ファイルに出力します。

  • エンティティ名を使用

       Jupiter-Pre上の各アイテム名をそのままIDとして使用します。

  • 浮遊点削除

       チェックすると、モデル内の使用されない浮遊節点を出力しません。

  • 境界条件重複チェック

       強制変位、速度、加速度、温度が、同一プロセス内、同一節点、同一自由度において異なる値を持つ場合にワーニングを出力します。

    • 形状/トポロジー最適化

       形状/トポロジー最適化を参照してください

    • Nonlinear : 幾何学的非線形性を考慮します。
    • Total Lagrange : トータルラグランジュ法による幾何学的非線形性を考慮します。
    • Updated Lagrange : アップデートラグランジュ法による幾何学的非線形性を考慮します。

  • タイムステップ

  • 時間

    • Fixed : Fixed時間刻みを指定します。

  • 増分数

  • 荷重タイプ

    • Step : Stepを指定すると、過程開始時刻から終了時刻まで指定された荷重値とします。

    • Ramp : Rampを指定すると、過程開始時刻から終了時刻までを線形補間した荷重値とします。

  • Subdivide_mode

  • Relative_separation_tol

       貫通が発生したと判定する相対貫通量を求めるためのトレランスを指定します。

  • Stick_slip_tol

  • Friction_tol

    • NO : 予想を行いません。※ADXファイルにEstimate_impact_time＝Noが出力されません。

    • YES : 予測を行います。※ADXファイルにEstimate_impact_time＝Yesが出力されます。

  • Temperature_incr_max

  • Use_temperature_incr_max

  • Stra_tol

  • Creep_stra_tol

  • Rdnlk_stra_tol

    • max_num_eigenvalues_on_interval   : 生成された検索区間に対して，求める固有周波数および固有モードの最大数を指定します。

    • Unity : {u} T {u}が１となるように正規化します。{u} は求める固有ベクトルです。

    ダミープロパティ

    　　ダミープロパティの設定を行います。

  • Auto割り当て

       チェックを入れると、プロパティが割り当てられていないパーツにダミープロパティをAutoで割り当てます。

  • 材料

       ダミープロパティを割り当てるパーツの材料を指定します。
       材料コマンドのユーザーデータベースに登録済の材料が選択可能です。ユーザーデータベースに材料未登録の場合、登録済でもブランクを選択した場合はダミー材料を割り当てます。
       ダミー材料の場合、材料特性値は書かれない状態で出力されます。

  • 出力ジオメトリーID

       チェックを入れると、フェースID、エッジID、パートIDなどのエンティティIDが出力されます。

    • 解析テンプレート設定

  • .csvテンプレートを使用してLBCマネージャーを定義する:

       チェックボックスを選択して、.csvファイルを使用してLBCマネージャーを定義します。

  • ファイル :

       .csvファイルを選択します。

  • .csvテンプレートを使用して接触マネージャーを定義する:

       チェックボックスを選択して、.csvファイルを使用して接触マネージャーを定義します。

  • ファイル :

       .csvファイルを選択します。

  • テンプレート: すべてのADVCテンプレート.xmlファイルを保存して表示します。
    デフォルトのフォルダは　C:\Users\XXX\AppData\Roaming\TechnoStar\JPT5.0.0\AnalysisSetting\ADVC
  • 削除 : 選択したテンプレートが削除されます。
  • 追加 : 現在のADVC設定ダイアログが入力名として保存されます。

    - 操作手順 -

    1.  ジョブ名を指定します。
    2.  プロセスを作成でプロセスを作成します。デフォルトの時間刻みで解析を行う場合は、特に必要ありません。
    3.  LBCマネージャでプロセスに境界条件を割り当てます。
    4.  出力マネージャで出力項目を選択します。
    5.  適用/OKボタンをクリックします。
