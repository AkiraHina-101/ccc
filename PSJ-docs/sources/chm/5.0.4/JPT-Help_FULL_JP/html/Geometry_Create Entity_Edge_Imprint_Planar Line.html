平面との交線

選択したフェースを指定した平面が横切る位置にラインを作成します。

オプション

  • 面を分割

    •    チェックすると、インプリント後に分割可能なフェースを分割します。

  • 座標系

    •    座標平面で参照される座標系を選択します。

  • 座標平面

    •    フェースを分割する平面を指定する方法を選択します。

    • YZ : 座標系で指定された座標系のYZ平面を選択します。
    • ZX : 座標系で指定された座標系のZX平面を選択します。
    • XY : 座標系で指定された座標系のXY平面を選択します。
      •
  • 3点指定

    •    画面上から選択される3点から平面を定義します。


    - 操作手順 -

    1.  インプリント対象のフェースを画面より選択します。複数のフェース選択が可能です。
    2.  必要に応じて面を分割チェックボックスをオフにします。この場合はインプリント後のフェースが元のフェースから分割されません。
    3.  座標平面からフェースを分割する平面を選択します。3点指定を選択した場合は、節点/フェース上任意点/エッジ上任意点ボタンを選択し、画面上から3点を選択します。
    4.  座標系から参照する座標系を選択します。
    5.  適用/OKボタンをクリックします。
