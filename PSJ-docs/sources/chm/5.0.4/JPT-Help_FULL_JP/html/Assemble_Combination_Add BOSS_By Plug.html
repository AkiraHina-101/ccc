ボス追加 | 參照位置から差し込む

このコマンドを使用して、ボスジオメトリ（円柱形状）を作成し、選択したパーツに含める事が出来ます。

オプション

  • マージ

    オンにすると、新しいボスパーツが選択したパーツとマージされます。

    上面の中心

      ボスの上面の位置（上部）を指定します。
    • 設定方法

      上面の中心を設定するために選択されたエンティティタイプ：
      - フェース
      - 3点
      - エッジ
      - ノード
      - フェイス任意点
      - エッジ任意点

    • X

      上面の中心のX座標。

    • Y

      上面の中心のY座標。

    • Z

      上面の中心のZ座標。

    • 方向

    • X

      ボス方向ベクトルのX座標。

    • Y

      ボス方向ベクトルのY座標。

    • Z

      ボス方向ベクトルのZ座標。

    • 座標系

      ボス方向ベクトルの座標系を指定します。

    • 回転軸

      座標系の回転軸（X軸、Y軸、Z軸）を指定します。

    • 角度

      回転軸の回転角度を指定します。

    ボス形状

    • 中空円筒

      このチェックボックスを選択すると、ボスが中空のジオメトリとして作成されます。

    • 内側半径

      円柱ジオメトリの内径を入力します（中空ジオメトリの場合）。

    • 外側半径

      円柱ジオメトリの外半径を入力します。

    • テーパー角（度）

      円柱ジオメトリの上から下へのテーパー角度を入力します。

    • サークル内のノードの数

      円柱の円弧方向のノード数を入力します。

    • 軸のノードの数

      円柱の軸方向のノード数を入力します。

    • 高さ

      円柱ジオメトリの高さを入力します。

    • 高さを計算

      ボスの高さを自動的に設定します


    - 操作手順 -

    1.  設定方法からフェース / 3点 / エッジ / ノード / フェイス任意点 / エッジ任意点を選択し、ボスの上面をクリックします （3点が選択された場合、3つのポイントをクリックして面を定義します）。
      クリックした位置は、上面の中心 XYZ（ボスの中心点）として自動的に入力されます。
    2.  ボスを作成するボディを選択します。 方向は身体の方向に変更されます。
    3.  ボスの外側半径を入力し、[高さを計算]ボタンをクリックします。 プレビュージオメトリは表示されます。
    4.  [適用]または[OK]ボタンをクリックして実行します。
