初期回転角度

動解析のための初期回転角を設定します。


構造

  • 名前

       初期回転角の名前を入力します。

    • 初期変位

  • 値 X,Y,Z

       各軸方向の初期回転角を入力します。

  • 入力単位系

       入力単位を指定します。

    • 解析座標系

  • 座標系

       座標系を指定します。

    • テーブル

  • テーブル選択

       フィールドデータで定義します。現在サポートされていません。


    • - 操作手順 -

    1.  初期角速度を設定するエンティティを選択します。
    2.  各軸の初期回転角を入力します。
    3.  適用またはOKボタンを押します。
