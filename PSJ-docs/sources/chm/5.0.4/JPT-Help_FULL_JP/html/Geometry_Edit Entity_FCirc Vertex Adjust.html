円エッジ 頂点位置揃え

同心円上の頂点位置を揃えます。

円の頂点の調整

  • 円筒形を90度で分割

    チェックをするとパーツに含まれる一周つながった円筒面（完全円筒面）、トーラス面を90度位置で4分割します。分割することでマップトメッシュの作成が容易になります。
    最小半径以上の面が分割の対象になります。

  • 内角が90度以上の円筒形を90度で分割

    チェックをするとパーツに含まれる円筒面で内角が90度以上のものを、90度位置で分割します。
    最小半径以上の面が分割の対象になります。

  • 最小半径

    分割の対象となる面の半径を入力します。入力値以下の半径の面は分割されません。

    • - 操作手順 -

    1. 頂点位置を揃えるパーツを選択します。
    2. 必要に応じてオプションを選択、入力します。
    3. 適用/OKボタンをクリックします。
