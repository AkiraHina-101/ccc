Lab | カスタムノート

モデル上の任意の位置を指すノートを追加し、ファイル内に保存できる機能です。

カスタムノートを1つでも追加すると、アッセンブルウィンドウ内のアッセンブルツリーの「すべてのアイテム」の下に「カスタムノート」アイテムが追加され、その下に指定したコレクション名でコレクションアイテムと、その下にカスタムノートアイテムが追加されます。

ノート

  • ノート名

    ノートの名称を入力します。

    • オプション

  • 座標値

    ノートを追加する位置を座標値で指定します。

    節点/任意点/エッジ上任意点のいずれかを選択した状態でカスタムノートを作成すると、選択エンティティの座標値を自動入力します。

    1D, 2D, 3D要素のいずれかを選択した状態でカスタムノートを作成すると、選択エンティティの中央の座標値を自動入力します。

    Preドキュメントでエンティティ指定のカスタムノートを作成した場合、その位置はモデルの編集には追従しません。

    Postドキュメントで節点指定のカスタムノートを作成した場合、その位置は変形表示に追従します。それ以外のエンティティ指定のカスタムノートの場合は、その位置は変形表示に追従しません。

  • 新規コレクション作成チェックボックス

    新しいコレクションを作成し、その中に新規カスタムノートを追加します。

  • コレクションコンボボックス

    新規カスタムノートを追加するコレクションを指定します。

    • 内容

    ノートの内容を記載します。最大20行まで内容を保持します。

    スタイル

  • フォントサイズ

    ノート内文字のフォントサイズを指定します。

  • フォント色（フォントサイズ右側の色選択）

    フォントの色を指定します。

  • 太字チェックボックス

    ノート内文字を太字にします。

  • 配置コンボボックス

    現在は左揃えのみです。

  • ノート背景色

    ノートの地の色を指定します。

  • ノート枠線

    幅及びその右側の色選択で、ノート枠線の幅と色を指定します。

  • ノート矢印

    サイズ及びその右側の色選択で、ノートから座標値に伸びる線の太さと色を指定します。サイズを0にすると、線が非表示になります。

  • タイプコンボボックス

    座標値を指す形状タイプを、「なし」もしくは「矢印」から選択します。

    • - 操作手順 -

    1. カスタムノート機能を起動します。
    2. 座標値を入力するか、節点/任意点/エッジ上任意点/要素を選択します。
    3. 適用またはOKボタンで機能が実行されます。
    4. 適用またはOKボタンで機能が実行されます。
    5. メインウィンドウ右クリックメニューの「ノートの再配置」を実行すると、ノート位置を適度に分散させることができます。
