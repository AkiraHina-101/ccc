ローカル設定のコピー(ウインドウ間）

ローカル設定を他のウィンドウのモデルへコピーします。

ローカル設定のコピー

  • コピー元ドキュメント

       ローカル設定のコピー元となるモデルのウィンドウを指定します。

  • コピー先ドキュメント

       ローカル設定のコピー対象となるモデルのウィンドウを指定します。

  • 入力単位系

       モデル間補正値の単位を指定できます。

  • 座標系

       モデル間補正方向の座標系を指定します。

  • マグニチュード

       モデル間補正距離を入力します。

  • トレランス

       モデル間誤差の許容値を入力します。

  • 軸

       モデル間補正方向指定方法選択します。

    • 任意の軸 : XYZの成分を入力し方向を指定します。

    • X軸 : X方向を指定します。

    • Y軸 : Y方向を指定します。

    • Z軸 : Z方向を指定します。

    • 2節点 : 節点2点を選択し方向を指定します。

    • エッジ : エッジを選択し方向を指定します。
      •
  • X/Y/Z

       モデル間補正方向ベクトルのXYZ成分が表示されます。

    • - 操作手順 -

    1.  事前にソフト内にローカル設定コピー元とコピー対象のモデルを開きます。
    2.  コマンド起動後、ソースドキュメントにコピー元となるモデルのウィンドウを指定します。
    3.  ターゲットドキュメントにコピー対象となるモデルのウィンドウを指定します。
    4.  モデル間の位置補正が必要な場合は、座標系に補正方向の座標系を指定します。
    5.  マグニチュードにモデル間の補正距離を入力します。
    6.  トレランスをモデル間の誤差の許容値を入力します。
    7.  軸に任意の軸を指定します。
    8.  XYZの成分を入力し方向を指定します。
    9.  適用/OKボタンをクリックします。
