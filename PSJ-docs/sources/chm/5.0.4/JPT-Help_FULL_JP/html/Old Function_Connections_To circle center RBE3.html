接続 | 内挿拘束要素 中心円周間

一対多（スレーブ：マスター）のRBE3（内挿拘束要素）を作成する機能です。
＊マスター節点は、フェース単位、エッジ単位での選択が可能です。

スレーブ節点と（接続範囲内の）マスター節点が接続されます。 スレーブ節点は、選択した円弧の中心座標に作成されます。
円や円筒形状に対してRBE3を作成する場合に便利な機能です。


この機能では、複数項のマスターを設定できます。 項ごとに節点、重み係数、自由度を設定して下さい。

接続

  • 名前

    登録される名前を入力します。

    • 検索範囲

  • すべて

    接続範囲を無限として指定します。

  • トレランス

    接続範囲の半径Rを入力します。

    • スレーブ自由度

  • UX - RZ

    従属自由度の成分を指定します。

    • マスター自由度

  • 項目

    設定し終わった項の番号が表示されます。

    • 追加

      項を追加します。

    • 削除

      項目に表示されている番号の項を削除します。

    • 編集

      項目に表示されている番号の項を編集します。

  • 質量

    重み付け係数を入力します。

  • UX - RZ

    重み付け係数を有する自由度の成分を指定します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • Abaqus

  • サーフェース定義出力

    面の定義方法を選択します。

    • 節点セット

      基準面として節点を指定します。

    • 要素セット

      基準面として要素を指定します。スレーブに要素を構成できないエンティティ（節点、エッジ）を選択していると、エラーが出力されます。

    • オプション

  • 主節点のみ接続

    選択したエンティティの主節点（コーナー節点）のみに接続します。

    • - 操作手順 -

    1. 接続範囲を設定します。
    2. エッジを選択します。これで、スレーブ節点の座標がエッジの中心位置に定義されます。
    3. スレーブのパラメータを入力します。
    4. [項目ごとに繰り返し]マスター候補の節点を、フェースで選択します。フェースを選択しない場合は、エッジの節点がスレーブ節点になります。
    5. [項目ごとに繰り返し]マスターのパラメータを入力します。
    6. [項目ごとに繰り返し]項目 > 追加ボタンをクリックします。4)と5)の設定が項目に追加されます。
    7. 必要に応じて、スレーブ節点の座標を任意座標に編集します。
    8. 適用/OKボタンをクリックします。

    - 操作手順（項目の削除） -

    1. 項目から削除対象の番号を選択します。
    2. 項目 > 削除ボタンをクリックします。項目が削除されます。

    - 操作手順（項目の編集） -

    1. 項目から編集対象の番号を選択します。
    2. マスター候補の節点を変更します。
    3. マスターのパラメータを変更します。
    4. 項目 > 編集ボタンをクリックします。項目が編集されます。
