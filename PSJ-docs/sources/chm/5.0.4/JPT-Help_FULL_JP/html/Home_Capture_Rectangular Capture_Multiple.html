ユーザーフレーム(Single/Multiple)

キャプチャー向けフレームを作成し、ビューポイントウインドウの"ユーザーフレーム"ツリーに保存します。 作成したフレームは、"PPT形式で保存"、"画像ファイルに保存" コマンドで使用します。

  • 開始点（X, Y）

    フレームの始点を指定します。メインウインドウの左上を原点(0,0)としています。

  • フレームサイズ（幅, 高さ）

    フレームサイズを指定します。フレームをマウスドラッグし、開始点やサイズ変更可能です。

  • スイッチ

    操作するモード（サイズ変更/再配置）を切り替えます。

  • サイズ変更

    メインウインドウ上に表示されているフレームサイズを変更するモードになります。

  • 再配置

    メインウインドウ上に表示されているフレームを移動するモードになります。

    • - 操作手順（サイズ変更） -

    1. メインウインドウ上に表示されているフレームをマウスドラッグまたは数値入力し、サイズを変更します。
    2. ［適用］ボタンを押下します。

    - 操作手順（再配置） -

    1. [スイッチ]ボタンを押下し、"再配置"モードに切り替えます。
    2. メインウインドウ上に表示されているフレームをマウスドラッグし移動します。
    3. ［適用］ボタンを押下します。

    - 操作手順（作成済みフレーム呼び出し） -

    1. ビューポイントウインドウ内"ユーザーフレーム"ツリーからアイテムをマウスダブルクリックします。
    2. コマンドダイアログとフレームが起動します。
    3. 必要に応じサイズ変更、再配置を行います。
    4. 必要に応じ［適用］ボタンを押下し、更新します。

    - 操作手順（フレーム使用例） -

    1. "ユーザーフレーム"を起動し、サイズ調整を行います。
    2. [適用]ボタンを押下し、フレームを作成します。
    3. "PPT形式で保存" を起動します。
    4. 定義したフレーム内の画像が出力されます。
    5. ※"画像ファイルに保存"も同様です。
