MPC一般 | 節点-その他間

１節点と多エンティティ間でMPCを作成する機能です。

節点-その他

  • 名前

    登録される名前を入力します。

    • パラメーター

  • 座標系

    参照座標系を選択します。

  • TX変位 - TZ変位

    並進方向の拘束を指定します。

  • RX変位 - RZ変位

    回転方向の拘束を指定します。

    • - 操作手順 -

    1. マスターの節点を選択します。
    2. スレーブの他エンティティを選択します。
    3. パラメータを設定します。
    4. 適用/OKボタンをクリックします。
