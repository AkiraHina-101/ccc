要素交差

要素交差エラーを検出します。

エッジ数

  • トレランス

    •    要素交差部表示のトレランスを設定します。

  • 要素数

    •    要素交差部の要素個数を表示します。

  • 表示タイプ

    •    要素交差の表示タイプを選択します。

    • 各パーツの要素交差 : パーツ上の要素交差部を表示します。
    • すべての要素交差 : パーツ間とパーツ上の要素交差部を表示します。
    • パーツ間の要素交差 : パーツ間のみ要素交差部を表示します。
      •

    レイヤー

  • レイヤー数

    •    要素交差部箇所周りの表示メッシュ層数を設定します。

  • レイヤー更新

    •    表示を設定レイヤー数で更新します。

    自動クリーンアップ

  • クリンアップ

    •    要素交差部分が自動的に修正されます。

  • アグレッシブクリーンアップ

    •    チェックを入れると、形状の再現性よりもメッシュ品質を優先してクリーンアップを行います。

    出力オプション

  • エラーテキスト

    •    チェックを付けると、要素交差の情報を出力ウィンドウとTempフォルダにテキストデータで出力します。

    - 操作手順 -

    1.  チェックするパーツを選択します。
    2.  必要があればトレランスや表示タイプを変更します。
    3.  適用またはOKボタンを押します。
    4.  チェック後、メインウィンドウ内の標準画面に戻すアイコン をクリックし、表示を元に戻します。
