ローカル座標系[フェース]

選択したフェースと軸を決める2節点から座標系を作成します。

　　

座標系

  • タイプ

       座標系のタイプを選択します。

    • 直交 : 直交座標系を選択します。
    • 円筒 : 円筒座標系を選択します。
    • 球 : 球座標系を選択します。

  • 順番

       選択するエンティティの順番を選択します。フェース.0.X のみ選択できます。

    • フェース.O.X : フェース、座標系原点の節点、X軸上の節点の順に選択します。

  • 名前

       作成する座標系の名前を入力します。

    • 参照座標系

  • 座標系

       全体座標系を選択します。

    • 原点

  • X/Y/Z

       最初に選択した節点のX/Y/Z座標値が表示されます。

    • 2点目

  • X/Y/Z

       2番目に選択した節点のX/Y/Z座標値が表示されます。

  • 自動指定

       フェースまたは要素面の指定のみで座標系を作成します。


    • - 操作手順 -

    1.  タイプから座標系の種類を選択します。
    2.  名前に作成する座標系の名前を入力します。
    3.  フェースまたは要素面を一つ選択します。
    4.  節点ボタンを押して、原点となる節点とX軸上の節点を選択します。（自動指定がオンの場合は不要）
    5.  適用またはOKボタンを押します。
