フェースIDコピー

2つの異なるドキュメントにある類似形状パーツのフェースIDをコピーします。

　　

コピー元

  • コピー元ドキュメント

       IDのコピー元になるドキュメントをリストから選択します。

  • ソースパーツ

       IDのコピー元になるパーツをリストから選択します。

  • ソースフェース

       IDのコピー元になるフェースをリストから選択します。

    • 　　

    コピー先

  • コピー先ドキュメント

       IDのコピー先になるドキュメントをリストから選択します。

  • ターゲットパーツ

       IDのコピー先になるパーツをリストから選択します。

  • ターゲットフェース

       IDのコピー先になるフェースをリストから選択します。

    • 　　

    オプション

  • トレランス

       節点位置を一致と判断するトレランスを入力します。※節点IDは節点位置が一致したと判断される節点のみコピーされます。

    • 　　

    コピー情報

  • 開始節点ID

       コピーされなかった節点の開始節点IDが表示されます。これはコピーされた節点IDの最大値に1を加えたIDとなります。このIDは確認のために表示されます。

  • 節点数

       節点数が表示されます。この数値は確認のために表示されます。

  • 終了節点ID

       開始節点IDと節点数から予測される終了節点IDの最大値が表示されます。このIDは確認のために表示されます。

  • 開始ソリッド要素ID

       コピーされなかったソリッド要素の開始要素IDが表示されます。これはコピーされた要素IDの最大値に1を加えたIDとなります。このIDは確認のために表示されます。

  • ソリッド要素数

       ソリッド要素数が表示されます。この数値は確認のために表示されます。

  • 終了ソリッド要素ID

       開始要素IDと要素数から予測される終了要素IDの最大値が表示されます。このIDは確認のために表示されます。


    • - 操作手順 -

    1.  コピー元とコピー先のパーツが含まれたドキュメントを両方ともJupiterに読み込みます。
    2.  コピー元ドキュメントとコピー元パーツをリストから選択します。
    3.  コピー先ドキュメントとコピー先パーツをリストから選択します。※コピー元とコピー先のドキュメントは同じにならないようにしてください。
    4.  必要に応じてトレランス値を入力します。
    5.  適用またはOKボタンを押してコマンドを実行します。
