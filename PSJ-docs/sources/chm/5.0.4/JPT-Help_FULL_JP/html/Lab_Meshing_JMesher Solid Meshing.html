JMesherソリッド メッシング

四面体のソリッド要素を作成します。新しいソリッドメッシャーの試用版として提供されます。

要素タイプ

  • TET4

       四面体1次要素を作成します。

  • TET10

       四面体2次要素を作成します。

    • General

       ソリッドメッシュ作成に関する基本的なパラメータを入力します。
       ユーザーは、生成されるソリッド要素の最小エッジ長（Min Edge Length）、最大エッジ長（Max Edge Length）およびグラデーション（Gradation）の3つのパラメータを変更することによって、 内部メッシュサイズを制御できます。
       Min Edge LengthとMax Edge Lengthはどちらも省略できますが、Gradationは設定する必要があります。

    エッジ長さ

  • Min Edge Length

       空白またはゼロより大きい正の実数値を入力します。
       より粗いメッシュを作成するためには、平均表面メッシュサイズよりも大きい最小エッジ長を設定します。

  • Max Edge Length

       空白またはゼロより大きい正の実数値を入力します。
       より精細なメッシュを作成するためには、平均表面メッシュサイズよりも小さい最大エッジ長を設定します。

    • メッシュのグラデーション

  • Gradation

       グラデーションはメッシュの均一性を制御します。 1.05に相当するグラデーションは、メッシュが最も均質になることを意味します。
       Min Edge LengthやMax Edge Lengthよりも優先度が高くなります。 したがって、ユーザーがグラデーションを1.05に設定した場合、最小エッジ長さと最大エッジ長さの条件が守れない場合があります。

    • 属性

  • 速度対品質

       基本的には、最適化を含めたメッシャーを実行してから、最適化専用モードで1回以上再度実行します。
       メッシャーを数回実行すると、冗長な後処理のためにメッシング時間が長くなる可能性があります。
       3つのモードがあります。
        - Fastest：Mesherはデフォルトの最適化プロセスで一度だけ実行されます。
        - Standard：Mesherはデフォルトの最適化プロセスで1回実行され、さらに最適化モードのみでもう1回実行されます 。
        - Optimazed：メッシャーはデフォルトの最適化プロセスで1回実行され、さらに最適化モードのみで4回実行されます。
       ほとんどの場合、Standardモードで「不良形状要素」を取り除くのに十分なはずです。

    • 複数CPUメッシュ

  • Max Theads

       V4.0では未対応となっております。今後のバージョンアップで対応させて頂く予定です。

       並列処理の設定を行います。並列化はボディ毎にコアを割り当てて実行されます。
       最高のパフォーマンスを達成するために使用されるマシンで使用可能なコアごとに1つのスレッドを選択することをお勧めします。 したがって、4コアマシンでは、最適な最大スレッド数は4スレッド（コアあたり1）です。

    • Advenced

       ソリッドメッシュ作成に関する詳細なパラメータを入力します。

    アルゴリズム

  • No Internal Points

       メッシングアルゴリズムは、表面節点のみを使用してボリュームメッシュを生成します。

  • Central Point

       メッシュ生成アルゴリズムは、重心を使用してメッシュを生成します。

    •    左：内部節点なし。 右：内部節点あり

    Optimization

       最適化段階は、いくつかのパラメーターによって制御できます。

  • Optimization level

       最適化レベルが高いほど、実行が遅くなります。
        - Lght
        - Standard
        - Strong

  • Optimization mode

       マルチスレッド機能を使用するときの最適化モード。
        -None
        -Safe - シーケンシャルモード：より安全で、より高品質のメッシュです。
        -Aggressive - 並列モード：高速ですが、メッシュの品質が低下する可能性があります。

    • Other

       ソリッドメッシュ作成に関するその他のパラメータを入力します。

    Volume Proximity

  • Use Volume Proximity

       非常に近接したサーフェスがある場合は、これらの領域でボリュームプロキシミティレイヤを使用してより細かいメッシュを自動的に生成することができます。

  • Volume Proximity Layers

       ユーザーは、このテキストボックスでそれらの面の間に作成されるレイヤの数を指定できます。



    • Force Clean

       ソリッドメッシュ作成に関する強制クリーンアップパラメータを入力します。

  • ストレッチ限度

       生成するテトラ要素のストレッチ値の閾値を入力します。

  • サーフェース節点

       チェックすると要素品質を確保する為にわずかに表面節点を動かす場合があります。

  • エッジ節点

       チェックすると要素品質を確保する為にわずかにエッジ節点を動かす場合があります。

  • プリザーブ

       チェックするとプリザーブを無視して節点を動かす場合があります。

  • 内部節点のみ

       ソリッド要素作成時の自動修正する際、表面要素を変更せずに内部要素のみ修正を行います。

    • - 操作手順 -

    1.  要素タイプを選択します。
    2.  対象のパーツを選択します。
    3.  必要に応じてメッシュ作成パラメータを入力します。
    4.  適用/OKボタンをクリックします。
