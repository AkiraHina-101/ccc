スイープ | フェース間

歯車のように2つの向かい合う同じ形状を持つ複雑形状のパーツにヘキサメッシュを自動作成します。

元の形状を自動消去

  • 元の形状を消去

    チェックすると向かい合う２つのフェースを指定した元のパーツを自動的に削除します。

    • - 操作手順 -

    1. 向かい合うフェースの一方を選択リストのSource Faceに選択します。
    2. 向かい合う反対側のフェースを選択リストのTarget Faceに選択します。
      ※層数は引き延ばし方向の現在のメッシュ数が使用されます。
    3. 元のパーツが要らない場合は、元の形状を削除をチェックします。
    4. 適用もしくはOKボタンをクリックします。
