節点移動 | エッジに沿って

選択したエッジ上の節点を指定した座標へ移動します。 (複数の節点を同時に実行可能)

設定

  • タイプ
     節点の移動方法を選択します
    • 再配置なし : 指定した節点のみ移動します。
    • 再配置 : 指定した節点を移動後、同エッジ上のほか節点の位置は計算され再配置されます。 (節点の数で計算される)
  • X/Y/Z
     節点を移動する座標を入力します。 (最大2つのみ選択可能)

- 操作手順 -

  1.  移動する節点を選択します。(複数の節点を同時に選択可能)
  2.  節点の移動方法を選択します。
  3.  1つ/2つの座標系を選択し、移動する座標を入力します。
  4.  プレビューを確認します。
  5.  適用またはOKボタンを押します。
