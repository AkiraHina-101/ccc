温度荷重

熱応力解析モデル全体に対して、一定の温度を設定します。

　　

名前

  • 名前

       温度荷重条件の名前を入力します。

    • 値

  • 温度

       一定の温度値を入力します。

  • 入力単位系

       温度の入力単位を指定します。

  • 規定の温度を使用

       パーツ選択なしでモデル全体に一定温度荷重を指定します。
       ソルバー入力データ出力時、全節点一様となるためデータ量、出力時間が削減されます。

    • テーブル

  • テーブル選択

       フィールドデータで入力したテーブルを選択します。(対応ソルバー：ADVC)


    • - 操作手順 -

    1.  パーツ、フェース、エッジまたは節点のいずれかのボタンを選択し、画面上から温度荷重付加対象を選択します。
    2.  荷重につける名前を入力します。
    3.  境界温度に一定の温度を入力します。
    4.  必要に応じて入力単位を変更します。
    5.  適用またはOKボタンを押します。
