2要素エッジ

2つの要素エッジのなす角度を計測します。

　　

オプション

  • 座標系

       投影先座標系を選択します。

    • 出力

  • 角度

       計測結果が表示されます。

  • 入力単位系

       表示する角度の単位を指示します。

  • ローカル座標系 XY

       指定座標系XY平面での投影角度

  • ローカル座標系 YZ

       指定座標系YZ平面での投影角度

  • ローカル座標系 ZX

       指定座標系ZX平面での投影角度

    • - 操作手順 -

    1.  画面上で要素エッジを2つ選択します。
    2.  座標系平面での投影角度を測定する場合、ローカル座標系で座標系を選択します。
    3.  値に2つの要素エッジのなす角度、ローカル座標系XY(YZ,ZX)にそれを指定座標系平面に投影した角度が表示されます。
