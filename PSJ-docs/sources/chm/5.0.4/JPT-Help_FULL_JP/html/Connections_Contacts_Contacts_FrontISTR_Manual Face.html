接触 | フェース指定 | FrontISTR

指定フェース間にFrontISTR用接触設定を定義します。
マスター面となるフェース、およびスレーブ面となるフェースを選択し、接触設定を定義します。

基本

　　　
  • 名前

    接触対の名称を入力します。

    　　　
    • 　　　
  • アルゴリズム

    接触設定対象エンティティを選択します。
        フェース-フェース: フェース対フェース間接触

    　　　
    • 　　　
  • タイプ

    接触定義の挙動タイプを選択します。
        一般接触: 滑り接触

    　　　
    • 　　　
  • マスター

    マスター面となるフェースを選択します。

    　　　
    • 　　　
  • スレーブ

    スレーブ面となるフェースを選択します。

    　　　
    • 　　
  • M/S入替

    マスターとスレーブを入れ替えます。

    　　　

    • コンタクトプロパティ

    　　　
  • コンタクトタイプ

    FrontISTRの接触タイプを定義し、同じ接触タイプの設定を簡単にコントロールします。

        ID: IDを入力します。
        相互作用: 必要な方法を選択します。
        法線方向収束(NTOL): 法線方向収束パラメーターを入力します。
        接線方向収束 (TTOL): 接線方向収束パラメーターを入力します。
        法線方向ペナルティ (NPENALTY): 法線方向ペナルティパラメーターを入力します。
        接線方向ペナルティ (TPENALTY): 接線方向ペナルティパラメーターを入力します。

    List Contact Type Created: 作成したコンタクトタイプをすべて表示します。また、右クリックで編集や削除などの機能を利用することができます。
        編集: コンタクトタイプのパラメータを変更します。
        削除: コンタクトタイプを削除します。

    　　　
    • 　　　
  • 摩擦係数 (FCOEF)

    摩擦係数を入力します。

    　　　
    • 　　　
  • 摩擦ペナルティ剛性 (FACTOR)

    摩擦ペナルティ剛性を入力します。

    　　　
    • 　　　

    色設定

  • 接触の色

        接触対表示マーカー色を定義します。
        リセット: デフォルト色に初期化

    　　　

    • - 操作手順 -

      　　　
    1.  マスターでマスター面となるフェースを選択します。続いてスレーブでスレーブ面となるフェースを選択します。
      2. 　　　
    2.  必要により接触対に対する詳細設定を定義し、適用（OK）ボタンをクリックして接触対を定義します。
