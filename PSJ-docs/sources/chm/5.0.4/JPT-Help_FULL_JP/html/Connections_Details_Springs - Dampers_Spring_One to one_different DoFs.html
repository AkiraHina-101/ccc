接続 | ばね要素　すべてのエンティティ間(1対1) - 異なる自由度

一対一のスカラーばね要素を作成する機能です。
＊1stグループ節点と2ndグループ節点は、パーツ単位、フェース単位、エッジ単位、要素単位、節点単位での選択が可能です。

1stグループ節点と（接続範囲内で）一番近い2ndグループ節点が接続されます。
この機能では、1stグループ節点と2ndグループ節点で、異なる自由度を結合することができます。

接続

  • 名前

    登録される名前を入力します。

    • 検索範囲

  • すべて

    接続範囲を無限として指定します。

  • トレランス

    接続範囲の半径を入力します。

    • ばね

  • 剛性

    ばね剛性を入力します。

  • 第1Gにおける自由度

    1stグループの自由度を指定します。

  • 第2Gにおける自由度

    2ndグループの自由度を指定します。

  • 減衰係数(Nastran向け)

    減衰係数を入力します。

  • 応力係数(Nastran向け)

    応力係数を入力します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • - 操作手順 -

    1. 接続範囲を設定します。
    2. 1stグループの節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    3. 2ndグループの節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    4. ばね剛性を入力します。
    5. 1stグループの自由度と2ndグループの自由度を指定します。
    6. 他のパラメータを設定します。
    7. 適用/OKボタンをクリックします。
