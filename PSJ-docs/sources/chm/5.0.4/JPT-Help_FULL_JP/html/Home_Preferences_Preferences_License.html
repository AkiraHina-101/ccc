ライセンス

ライセンスの設定を行います。
チェックボックスをONにすると、ライセンスが取得され、各機能を使用できます。 ホームリボンのPre,Postモード切替ボタンがオフの場合、ライセンスはオフの状態で表示されます。Pre,Postモード切替ボタンがオンの場合、現在使用されているライセンスにチェックがついて表示されます。

  • フィーチャー

    • ご購入頂いたライセンスの一覧が表示されます。項目横のチェックボックスをクリックしてONにすると、ライセンスが使用可能になります。
    また、太文字の項目（ベース, オプションなど）を右クリックすると、その下のチェックボックス全てをON/OFFすることができます。
    使用中のフィーチャーをクリックすると、下部に有効期限が表示されます。

  • 内容

    • ライセンスの内容が表示されます。

  • すべてオン

    • すべてのチェックボックスをONにします。

  • すべてオフ

    • すべてのチェックボックスをOFFにします。

    - 操作手順 -

    1.  コマンドを起動し、使用するライセンス横のチェックボックスをクリックしてONにします。
    2. 適用もしくはOKボタンをクリックして適用します。
