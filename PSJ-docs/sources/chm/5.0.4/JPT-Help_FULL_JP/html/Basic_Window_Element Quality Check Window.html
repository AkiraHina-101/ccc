要素品質確認

要素品質確認には、コマンドウィンドウと同時に使用できるエラーチェックおよび品質チェック機能が含まれています。

要素エラー確認

このタブは、コマンドウィンドウと同時に使用できるように調整されたメッシュクリーンアップリボンのフリーエッジおよび 交差と機能に基づいています。
フリーエッジ
フリーエッジ及びノンマニフォールドエラーを検出します。

  • エッジ数
    - フリー: フリーエッジの個数を表示します。
    - ノンマニフォールド: ノンマニフォールドの個数を表示します。

  • 表示オプション
    - メッシュカラー: フリーエッジやノンマニフォールドの周りの表示メッシュ層数を設定します。
    --> オリジナル : メッシュの色を変えず、エッジの色だけを変更します。
    --> グレー : 既存のエッジの色に表示します。
    - すべて表示: オンにした場合、フリーエッジやノンマニフォールドの周りのメッシュが全て表示されます。レイヤー数はグレーアウトされます。
    - レイヤー数: フリーエッジやノンマニフォールドの周りの表示メッシュ層数を設定します。
    - フリーエッジ: オンにした場合、フリーエッジを表示します。
    - フリーエッジをパーツ毎に確認: オンにした場合、フリーエッジの確認を、パーツ毎に行います。
    - ノンマニフォールド: オンにした場合、ノンマニフォールドを表示します。
    - ノンマニフォールド閾値: ノンマニフォールドの最低接続要素数を入力します。
    - 境界エッジを非表示: シェル形状の外枠以外のフリーエッジを表示します。

  • クローズギャップ
    - トレランス距離: 実行時に最大に動かすことの出来る節点間の距離を設定します。 (1mm以上の隙間、ノンマニフォールド、中立面などの閉じてないモデルに関しては自動接合は行いません)。
    - クローズギャップ: 要素間の隙間を自動接合します。

  • 出力オプション
    • - エラーテキスト: オンにした場合、フリーエッジの情報を出力ウィンドウとInstall PathのTempフォルダにテキストデータで出力します。

  • チェックボタン
    • フリーエッジのチェックを開始します。
    要素交差
    要素交差エラーを検出します。

  • エッジ数
    - トレランス: 要素交差部表示のトレランスを設定します。
    - 要素数: 要素交差部の要素個数を表示します。
    - 表示タイプ: 要素交差の表示タイプを選択します。
    --> 各パーツの要素交差 : パーツ上の要素交差部を表示します。
    --> すべての要素交差 : パーツ間とパーツ上の要素交差部を表示します。
    --> パーツ間の要素交差 : パーツ間のみ要素交差部を表示します。

  • レイヤー
    - レイヤー数: 要素交差部箇所周りの表示メッシュ層数を設定します。
    - レイヤー更新: 表示を設定レイヤー数で更新します。

  • 自動クリーンアップ
    - クリンアップ: 要素交差部分が自動的に修正されます。
    - アグレッシブクリーンアップ: チェックを入れると、形状の再現性よりもメッシュ品質を優先してクリーンアップを行います。

  • 出力オプション
    • - エラーテキスト: チェックを付けると、要素交差の情報を出力ウィンドウとTempフォルダにテキストデータで出力します。

  • チェックボタン
    • 要素交差のチェックを開始します。

    - 操作手順 (要素エラー確認 - フリーエッジ) -

    1.  チェックするパーツを選択します。
    2.  必要があれば表示オプションでレイヤー数とチェック項目を変更します。
    3.  適用またはOKボタンを押します。
    4.  チェック後、メインウィンドウ内の標準画面に戻すアイコン をクリックし、表示を元に戻します。

    - 操作手順 (要素エラー確認 - 要素交差) -

    1.  チェックするパーツを選択します。
    2.  必要があればトレランスや表示タイプを変更します。
    3.  適用またはOKボタンを押します。
    4.  チェック後、メインウィンドウ内の標準画面に戻すアイコン をクリックし、表示を元に戻します。

    要素品質確認

    このタブは、コマンドウィンドウと同時に使用できるように調整されたメッシュクリーンアップリボン自動チェックおよび手動チェック 機能に基づいています。

    2D要素
    表面のサーフェースメッシュ(三角形/四角形/三角形+四角形)に対し、復数の品質基準による修正を行います。

  • 要素タイプ
    品質をチェックする要素タイプのいずれかを選択します：三角形/四角形/三角形+四角形。

  • メッシュ品質ツール
    - ストレッチ　　： チェックすると、指定値以下のストレッチ値を持つ要素を検出・表示します。
    - アスペクト比　： チェックすると、指定値以上のアスペクト比を持つ要素を検出・表示します。
    - ワーピング : 四角形要素に対して、四角形要素を2つの三角形に分け、その間に生じる角度の最大値をチェックします。
    - スキュウネス: 四角形要素に対して、対辺の中点を結んだ2つの線のなす角度をチェックします。
    - エッジ長さ　　： チェックすると、指定値以下のエッジ長さを持つ要素を検出・表示します。
    - 面積　　　　　： チェックすると、指定値以下の面積の要素を検出・表示します。
    - 節点接続数　　： チェックすると、指定値以上の節点接続数を持つ要素を検出・表示します。
    - 内部角度　　 ： チェックすると、指定値以下の角度を持つ要素を検出・表示します。
    - テーパー : 四角形要素に対して、四角形要素内の3節点を結んだ三角形面積の平均値との最大差分をチェックします。
    - 節点フリーエッジ : 三角形/四角形要素に対して、一つの節点につながっているフリーエッジの数をチェックします。
    - 重複要素　　　： チェックすると、重複要素を検出・表示します。
    - 不安定要素 : 隣接する要素と接続する(コーナー)節点数をチェックします。 剛体運動が発生するような1(2)点接続の要素を検出するのに使用します。
    - 時間間隔(LS-DYNA) : 三角形/四角形要素に対して、クーラン条件における⊿tcをLS-DYNAの算式で確認します。閾値となる時間増分⊿tは「安全率x設定値」で計算されます。
    - 時間間隔(Abaqus): 三角形/四角形/テトラ/ヘキサ要素に対して、クーラン条件における⊿tcをAbaqusの算式で確認します。閾値となる時間増分⊿tは「安全率x設定値」で計算されます。
    チェックボタン：メッシュ品質のチェックを開始します。
    モデル表示のボタン：元の表示に戻ります。

  • 自動クリーンアップ
    - 自動クリーンアップ: クリンアップボタン押すことで要素を自動修正することができます。
    - モード　： クリンアップをするときのモードを切り替えます。
    --> 標準　： スタンダード
    --> アグレッシブ　： プリザーブなどのローカル設定を考慮してクリンアップを行います。
    - ノンマニフォールド　： チェックするとノンマニフォールドも修正します。

  • 手動クリーンアップ
    • 手動クリーンアップ機能を選択します。
    - 節点ドラッグ
    - スプリット
    - 2TrisからQuad
    - コラプス
    - 2QuadsからQuad
    - スワップ
    - Quadから2Tris
    - イクイバランス

    3D要素
    ソリッドメッシュ(テトラ/ヘキサ)に対し、復数の品質基準による修正を行います。

  • 要素タイプ
    品質をチェックする要素タイプのいずれかを選択します： テトラ, ヘキサ。

  • メッシュ品質ツール
    - ストレッチ　　： チェックすると、指定値以下のストレッチ値を持つ要素を検出・表示します。
    - アスペクト比　： チェックすると、指定値以上のアスペクト比を持つ要素を検出・表示します。
    - 最小角度 : チェックした場合、最小角度が指定した値以下の要素を検出して表示します。
    - 最大角度 : チェックされている場合、指定された値以上の最大角度を持つ要素を検出して表示します。
    - 体積 ： テトラ/ヘキサ要素に対して、要素体積をチェックします。
    - ヤコビアンファクター : テトラ要素についてはヤコビアンを確認してください。
    - テットコラプス : テトラ要素のテットコラプスをチェックします。
    - テットスキュー : テトラ要素のテットスキューを確認します。
    - エッジ長さ　　： チェックすると、指定値以下のエッジ長さを持つ要素を検出・表示します。
    - 不安定要素 : 隣接する要素と接続する(コーナー)節点数をチェックします。 剛体運動が発生するような1(2)点接続の要素を検出するのに使用します。
    - 時間間隔(Abaqus): 三角形/四角形/テトラ/ヘキサ要素に対して、クーラン条件における⊿tcをAbaqusの算式で確認します。閾値となる時間増分⊿tは「安全率x設定値」で計算されます。
    チェックボタン：メッシュ品質のチェックを開始します。
    モデル表示のボタン：元の表示に戻ります。

  • 自動クリーンアップ (テトラ要素のみ)
    - 自動クリーンアップ: クリンアップボタン押すことで要素を自動修正することができます。
    - テットコラプスの手法：クリーンアップ時にTet Collapseメソッドを切り替えます。
    --> S
    --> A
    --> D
    - モード　： クリンアップをするときのモードを切り替えます。
    --> 標準　： スタンダード
    --> アグレッシブ　： プリザーブなどのローカル設定を考慮してクリンアップを行います。
    - ノンマニフォールド　： チェックするとノンマニフォールドも修正します。

  • 手動クリーンアップ
    • 手動クリーンアップ機能を選択します。
    - 節点ドラッグ
    - スプリット
    - 鉛直オフセット
    - コラプス
    - 方向に沿って
    - スワップ
    - 中間節点を主節点の中間へ
    - イクイバランス

    - 操作手順 (要素品質確認 - 2D要素) -

    1.  チェックするパーツを選択します。
    2.  要素タイプ三角形/四角形/三角形+四角形を選択し、チェックするメッシュ品質ツールを選択します。
    3.  [チェック]ボタンを押して、エラーのチェックを開始します。
    4.  必要に応じて、エラーを修正する自動クリーンアップ方法を選択します。
    5.  必要に応じて、手動クリーンアップツールを選択してエラーを修正します。
    6.  チェックした後、モデルの表示ボタンをクリックして元の表示に戻ります。

    - 操作手順 (要素品質確認 - 3D要素) -

    1.  チェックするパーツを選択します。
    2.  要素タイプテトラ/ヘキサを選択し、チェックするメッシュ品質ツールを選択します。
    3.  [チェック]ボタンを押して、エラーのチェックを開始します。
    4.  必要に応じて、エラーを修正する自動クリーンアップ方法を選択します。
    5.  必要に応じて、手動クリーンアップツールを選択してエラーを修正します。
    6.  チェックした後、モデル表示のボタンをクリックして元の表示に戻ります。
