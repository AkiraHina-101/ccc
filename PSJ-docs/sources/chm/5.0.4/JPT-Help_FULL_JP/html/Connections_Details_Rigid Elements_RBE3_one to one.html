接続 | 内挿拘束要素　すべてのエンティティ間（１対１)

一対一（スレーブ：マスター）のRBE3（内挿拘束要素）を作成する機能です。
＊スレーブ節点とマスター節点は、パーツ単位、フェース単位、エッジ単位、要素単位、節点単位での選択が可能です。

スレーブ節点と（接続範囲内で）一番近いマスター節点が接続されます。

接続

  • 名前

    登録される名前を入力します。

    • 検索範囲

  • すべて

    接続範囲を無限として指定します。

  • トレランス

    接続範囲の半径Rを入力します。

    • スレーブ自由度

  • UX - RZ

    従属自由度の成分を指定します。

    • マスター自由度

  • 質量

    重み付け係数を入力します。

  • UX - RZ

    重み付け係数を有する自由度の成分を指定します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • Abaqus

  • サーフェース定義出力

    面の定義方法を選択します。

    • 節点セット

      基準面として節点を指定します。

    • 要素セット

      基準面として要素を指定します。マスターに要素を構成できないエンティティ（節点、エッジ）を選択していると、エラーが出力されます。

    • - 操作手順 -

    1. 接続範囲を設定します。
    2. スレーブ候補の節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    3. マスター候補の節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    4. パラメータを設定します。
    5. 適用/OKボタンをクリックします。
