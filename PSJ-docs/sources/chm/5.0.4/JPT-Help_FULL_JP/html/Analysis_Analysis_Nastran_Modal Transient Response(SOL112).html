Nastran | モーダル過渡応答解析(SOL 112)

Nastranのモーダル過渡応答解析(SOL112)用入力データを出力します。

ジョブオプション

　　　
  • ジョブ

    プログラム: Nastranのタイプを選択します。
        MSC: MSC Nastran
        NX: NX Nastran
    ジョブ名: ジョブ名を入力します。ツリーにこの名称で出力設定が保存されます。
    ジョブの説明: ジョブの説明を入力します。

    　　　
    • 　　　
  • ソルバーオプション

    Nastranを実行: ローカルマシン上のNastranを実行します。
    メモリ(MB): メモリ割り当て量を定義します。

    　　　
    • 　　　
  • システムセルとFMS

    システムセル: Nastran(System)セクションにデータカードを直接入力します。
    システムセルテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。
    ファイル管理セクション: ファイル管理文セクションにデータカードを直接入力します。
    FMSテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。

    　　　
    • 　　　 　　　
  • モデル単位系を出力

    解析入力データの単位系設定を行います。

    　　　
    • 　　　
  • 実行コントロールオプション

    GEOMCHECK, NONE: 形状チェックオプションを無効にします。
    直接テキスト入力: エグゼクティブコントロールセクションにデータカードを直接入力します。
    実行テンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。

    　　　
    • 　　　
  • ケースコントロールオプション

    ECHO: バルクデータのエコー出力を定義します。
        NONE: 出力なし
        SORT: ソート出力
        UNSORT: 未ソート出力
        BOTH: ソートおよび未ソートの両方出力
    TITLE: プリント出力時のタイトルを定義します。
    直接テキスト入力: ケースコントロールセクションにデータカードを直接入力します。
    ケースコントロールテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。

    　　　
    • 　　　
  • バルクデータオプション

    出力タイプ: 出力対象を指定します。
        モデル: 一つのファイルに出力
        パーツ毎: パーツ毎にファイルを分けて出力
        選択したパーツ: 選択されたパーツのみ出力
    グリッドフォーマットタイプ: GRIDカードの出力フォーマットを変更します。
        シングル: スモールフィールドフォーマット出力
        ダブル: ラージフィールドフォーマット出力
        シングル浮動小数点: 指数不使用のスモールフィールドフォーマット出力
    浮遊節点を削除: データ出力時に浮遊節点を削除します。
    継続行マーク +: データ出力時に継続ポインタ+を出力します。
    バルクデータを含める: バルクデータファイルを挿入します。
    直接テキスト入力: バルクデータセクションにデータカードを直接入力します。
    バルクデータテンプレート:すべての.bdfテンプレートファイルを保存して表示します。
    編集: 選択した.bdfファイルが編集されます。

    　　　

    • 過渡応答


    　　　
  • 固有値抽出の周波数範囲

    固有値抽出の周波数範囲、根の数を定義します。

    開始周波数: 固有値抽出範囲の開始周波数を指定。
    最終周波数: 固有値抽出範囲の終了周波数を指定します。
    モード数: 求解根数を指定します。

    　　　
    • 　　　
  • タイムステップ

    過渡時間ステップ設定を定義します。

    ステップ数: 時間ステップ数を指定します。
    時間増分: 時間増分を指定します。
    出力間隔: 出力間隔を指定します。

    　　　

    • 荷重 / 境界条件


    　　　
  • ベース

    サブケース指定の上に定義する解析全体に作用する境界条件を定義します。
    各境界条件で使用する境界条件ケースを指定します。デフォルトには全ての境界条件が含まれます。

    DLOAD: 動荷重ケースを指定します。
    SPC: 拘束ケースを指定します。
    MPC: 多点拘束ケースを指定します。
    減衰タイプ: モーダル減衰のタイプを選択します。
        臨界減衰比: 臨界減衰比 CRIT
        構造減衰係数: 等価粘性減衰 G
        Q値: 増幅率 Q
    モーダル減衰: モーダル減衰のテーブルを選択します。
    RESVEC: レジデュアルベクトルの考慮を制御します。
        YES: 考慮
        NO: 未考慮
    LBC IDを定義: 荷重、拘束、多点拘束の識別IDを指定します。
    固有ID: 荷重、拘束、多点拘束でそれぞれ固有のIDが自動指定されます。

    　　　
    • 　　　
  • サブケースオプション

    サブケースを定義します。
    各サブケースで使用する境界条件ケースを指定します。

    既存ID: 既存サブケース IDを指定します。
        追加: 新規サブケースの追加
        削除: 既存サブケースの削除
        適用: 既存サブケースの更新
    ID: サブケース IDを指定します。
    サブタイトル:プリント出力時のタイトルを入力します。
    DLOAD: 動荷重ケースを指定します。
    SPC: 拘束ケースを指定します。
    MPC: 多点拘束ケースを指定します。
    DISPLACEMENT: 変位出力要求を指定します。
    応力: 要素応力出力要求を指定します。
    ひずみ: 要素ひずみ出力要求を指定します。
    ACCELERATION: 加速度出力要求を指定します。
    VELOCITY: 速度出力要求を指定します。
    直接テキスト入力: サブケースにデータカードを直接入力します。

    　　　

    • 出力要求


    　　　
  • 結果タイプ

    出力要求を指定します。
        PLOT: op2出力
        PRINT: f06出力
        PLOT&PRINT: op2およびf06出力
        ブランク: 未出力

    DISPLACEMENT: 変位出力要求を指定します。
    SPC力S: 単点拘束力出力要求を指定します。
    OLOAD: 作用荷重出力要求を指定します。
    MPC力S: 多点拘束力出力要求を指定します。
    応力: 要素応力出力要求を指定します。
    ひずみ: 要素ひずみ出力要求を指定します。
    力: 要素力出力要求を指定します。
    ESE: 要素ひずみエネルギー出力要求を指定します。
    SDISPLACEMENT: 求解セットの変位出力(モーダル変数)要求を指定します。
    ACCELERATION: 加速度出力要求を指定します。
    <<<<<<< .mine ERP: 等価放射電力出力要求を指定します。
    ||||||| .r1547 ======= ERP: 等価放射パワー出力要求を指定します。
    >>>>>>> .r1610 VELOCITY: 速度出力要求を指定します。
    MEFFMASS: モーダル有効質量出力要求を指定します。
        YES: 出力
        NO: 未出力
    グリッドID: 剛体質量マトリクス計算で使用する節点を指定します。

    　　　
    • 　　　
  • 結果に出力するグループ(SET)の選択

    結果出力する範囲を要素、節点グループ(セット)を指定して制限します。
        ALL: 全要素、全節点に対して出力
        グループ: 指定グループ内の要素、節点に対して出力

    DISPLACEMENT: 変位出力要求に対して出力範囲を指定します。
    SPC力S: 単点拘束力出力要求に対して出力範囲を指定します。
    OLOAD: 作用荷重出力要求に対して出力範囲を指定します。
    MPC力S: 多点拘束力出力要求に対して出力範囲を指定します。
    応力: 要素応力出力要求に対して出力範囲を指定します。
    ひずみ: 要素ひずみ出力要求に対して出力範囲を指定します。
    力: 要素力出力要求に対して出力範囲を指定します。
    ESE: 要素ひずみエネルギー出力要求に対して出力範囲を指定します。
    SDISPLACEMENT: 求解セットの変位出力(モーダル変数)要求に対して出力範囲を指定します。
    ACCELERATION: 加速度出力要求に対して出力範囲を指定します。
    VELOCITY: 速度出力要求に対して出力範囲を指定します。

    　　　

    • パラメーター


    　　　
  • パラメーター

    パラメータを定義します。

    POST: ポスト処理用結果ファイルの出力タイプを指定します。
        0: XDB出力
        -1: op2(Patran向け)出力
        -2: op2(I-DEAS向け)出力
    OGEOM: OP2への形状出力を制御します。
        YES: 形状出力あり
        NO: 形状出力なし
    AUTOSPC: 剛性特異性の自動拘束を制御します。
        YES: 自動拘束
        NO: 自動拘束なし
    GRDPNT: 重量情報出力を制御します。
    WTMASS: 質量補正係数定義します。
    K6ROT: シェル要素法線回転剛性に対する付加係数を定義します。
    MAXRATIO: マトリクス擬似特異判定比率を定義します。
    BAILOUT: 擬似特異性に対する実行を制御します。
        0: 継続実行
        -1: 終了
    PRGPST: 特異性サマリーテーブルのプリント出力を制御します。
        YES: 出力あり
        NO: 出力なし
    G: 構造減衰係数を定義します。
    W3(G): 全体構造減衰を等価粘性減衰に変換する角周波数(rad/sec)を定義します。
    W4(GE用): 要素構造減衰を等価粘性減衰に変換する角周波数(rad/sec)を定義します。
    LFREQ: モーダル法で使用するモードの下限固有周波数を定義します。
    HFREQ: モーダル法で使用するモードの上限固有周波数を定義します。

    その他の設定



  • ダミープロパティ

    ダミープロパティの設定を行います。

    自動割り当て: チェックを入れると、プロパティが割り当てられていないパーツにダミープロパティを自動で割り当てます。
    出力ジオメトリーID: チェックを入れると、フェースID、エッジID、パートIDなどのエンティティIDが出力されます。
    材料: ダミープロパティを割り当てるパーツの材料を指定します。
            材料コマンドのユーザーデータベースに登録済の材料が選択可能です。ユーザーデータベースに材料未登録の場合、登録済でもブランクを選択した場合はダミー材料を割り当てます。
            ダミー材料の場合、材料特性値は書かれない状態で出力されます。

  • 解析テンプレート設定

    Nastranダイアログの解析パラメータは、テンプレートファイルを読込することで自動設定されます。

    テンプレート: すべてのNastranテンプレート.xmlファイルを保存して表示します。
    デフォルトのフォルダは　C:\Users\XXX\AppData\Roaming\TechnoStar\JPT5.0.0\AnalysisSetting\Nastran
    削除: 選択したテンプレートが削除されます。
    追加: 現在のNastran設定ダイアログが入力名として保存されます。


    • - 操作手順 -

    　　　
  • 加振用時間依存テーブルの作成

    • 時間依存の加振荷重を作成するため、時間テーブルを作成します。
      　　　
    1. 境界条件>その他>フィールドデータコマンドを選択します。
      2. 　　　
    2. フィールドデータダイアログで追加ボタンをクリックします。
      3. 　　　
    3. テーブルの追加/編集ダイアログでテーブル名に任意の名前を入力、テーブルタイプで時間を選択します。インポートボタンからcsv形式で作成しておいた[時間,係数]のテーブルを読み込みます。手入力の場合、必要なデータ数だけ挿入ボタンでデータを追加し入力します。 データ入力後、OKボタンをクリックし、テーブルを作成します。
      入力したデータテーブルは、Xで時間、Yで値を選択し、XYZ描画ボタンをクリックすることでチャートに表示できます。

    　　　
  • モード減衰テーブルの作成

    • 続けて周波数依存のモード減衰テーブルを加振用時間依存テーブルと同様に作成します。テーブルタイプは周波数とします。
    減衰タイプ(臨界減衰比CRIT、等価粘性減衰G、増幅率Q)は、Nastranデータ出力時に選択します。



    　　　
  • 加振条件の設定

    • 時間依存の加振条件を設定します。以下では強制変位加振を設定します。
      　　　
    1. 境界条件>荷重>強制荷重>強制変位コマンドを選択します。
      2. 　　　
    2. 意図する方向の変位量を入力し、テーブル選択で先に作成した加振用時間テーブルを選択します。

      3. 　　　
    3. 加振節点をモデル上から選択し、OKボタンをクリックし強制変位加振を作成します。


    　　　
  • Nastran入力データの作成

    • Nastranのモーダル過渡応答解析(SOL112)用入力データを出力します。
      　　　
    1. 解析>解析>Nastran>モーダル過渡応答解析(SOL112)コマンドを選択します。
      2. 　　　
    2. 過渡応答>固有値抽出の周波数範囲で固有値抽出の設定を行い、タイムステップで時間ステップ(ステップ数、時間増分、出力間隔)の設定をします。

      3. 　　　
    3. 荷重 / 境界条件のベース>減衰タイプでモード減衰のタイプ(臨界減衰比、構造減衰係数、Q値)を選択し、モーダル減衰でそのモード減衰テーブルを選択します。

      4. 　　　
    4. 指定節点や要素のみの結果を出力する場合は、節点、要素グループを作成し、出力要求のグループ(SET)でそのグループを指定します。
      5. 　　　
    5. その他必要なオプションを定義し、適用(OK)ボタンをクリックして、入力データファイルを出力します。
