3D要素マニュアル修正 テトラ要素作成 / ヘキサ要素作成 / ペンタ要素作成 / ピラミッド要素作成

選択した要素または節点から、ソリッド要素を作成します。





選択リスト

要素：ソリッド要素を接続する2D要素
節点：ソリッド要素を接続する節点
パーツ：作成したソリッド要素が属するパーツ（選択しない場合は、ソリッド要素が新しいパーツとして作成されます）

パラメーター

作成するソリッド要素を選択します。

  • テトラ : テトラ要素(四面体)を作成します。
  • ヘキサ : ヘキサ要素(六面体)を作成します。
  • ペンタ : ペンタ要素(三角柱)を作成します。
  • ピラミッド : ピラミッド要素(四角錘)を作成します。
    •
  • 節点順を使用

    チェックボックスをONにすると、3節点を選択したのち、次に選択する順の番号がメインウィンドウに表示されます。

  • 方向

    作成する要素の方向を切り替えます。

  • 高さ

    作成する要素の高さを入力します。

  • パーツ選択を保持

    選択したパーツの選択状態を適用ボタン実行後も保持します。

    • - 操作手順(節点順を使用オプション) -

    1. 節点順を使用オプションをONにして、節点選択することによりソリッド要素(ここでは一例としてヘキサ要素)を作成します。

    2. 要素を作成する節点を3点選択します。この場合、下図のように時計回りで選択すると、緑色のガイドラインが意図した方向に出ない為、反時計回りに3節点を選択します。

    3. 次は、メインウィンドウに4と数字が出ている方向にある、要素を作成したい節点を選択します。

    4. 次は、メインウィンドウに5と数字が出ている方向にある、要素を作成したい節点を選択します。

    5. 次は、メインウィンドウに6と数字が出ている方向にある、要素を作成したい節点を選択します。

    6. 次は、メインウィンドウに7と数字が出ている方向にある、要素を作成したい節点を選択します。

    7. 次は、メインウィンドウに8と数字が出ている方向にある、要素を作成したい節点を選択します。節点選択後、緑のガイドラインから変わってプレビューが表示されたら実行可能です。

    - 要素作成方法(テトラ要素) -

    1. テトラ要素の作成方法は、下図の通り選択が3通りあります。

    - 要素作成方法(ヘキサ要素) -

    1. ヘキサ要素の作成方法は、下図の通り選択が5通りあります。

    - 要素作成方法(ペンタ要素) -

    1. ペンタ要素の作成方法は、下図の通り選択が6通りあります。

    - 要素作成方法(ピラミッド要素) -

    1. ピラミッド要素の作成方法は、下図の通り選択が6通りあります。

    - 特記事項 -

    1. 節点順を使用オプションがオフの際、完成形状に凹みがある場合は、自動生成ができないようになっています。

    2. 2次要素にも対応しています。選択した要素の次数が異なる場合は、エラーメッセージを表示します。

    3. 「パーツ選択を保持」だけは、GUI設定が保存されません。
