一般

既存のサーフェスメッシュにリブ形状を追加します。
取り付け面と、リブの始点・終点を指定し、既存のサーフェスメッシュ上にリブ形状を追加します。

リブパラメータ

  • リブ板厚

    リブの幅を設定します。

  • リブ高さ

    リブ取り付け面からのリブの高さを設定します。

  • 座標系

    リブ取り付けの際に参照する座標系を指定します。

  • 座標系から方向を指定

    リブの方向を、座標系で指定した座標軸で指定される座標平面方向に揃えます。

  • リブ平面

    座標平面を指定します。
    ・XY平面　：リブをXY平面方向に揃えます。
    ・YZ平面　：リブをYZ平面方向に揃えます。
    ・XZ平面　：リブをZX平面方向に揃えます。

    • オフセット

    リブ作成位置を指定方向にオフセットします。

  • X

    X方向の移動量

  • Y

    Y方向の移動量

  • Z

    Z方向の移動量

    • オプション

    その他の作成オプション・プレビューの設定を行います。

  • 三角形

    リブを、始点側が高い三角リブとして作成します。

  • 平面上部

    リブ取り付け面が曲面の場合でも、リブトップを平面にします。

  • 新規作成

    リブを新規パーツとして作成します。

  • マージ

    リブと取り付けパーツをマージします。

  • プレビュー

    プレビューの表示をON/OFFします。

    • - 操作手順 -

    1. 取り付け面とリブの始点・終点を指定します。
    2. 各パラメータを入力します。
    3. 適用/OKボタンをクリックします。
