スイープ | レイヤー

作成したサーフェスメッシュ(Tri,Quadメッシュ)からソリッドメッシュを
法線方向にスイープして作成します。

レイヤーパラメーター

  • 基となるフェース位置

    スイープ元のフェースが、スイープ後にできる形状のどの位置になるのかを指定します。
    下面 ：指定フェースを最下面とし、表側に向かってスイープ形状を作成します。
    中面 ：指定フェースを中心に、表裏両側にスイープ形状を作成します。
    上面 ：指定フェースを最上面とし、裏側に向かってスイープ形状を作成します。

  • レイヤー幅

    レイヤー１層の厚みを指定します。

  • レイヤー数

    層数を指定します。

    • レイヤーオプション

  • パーツの分離

    作成したレイヤーパーツの分離/統合状態を指定します。
    マージ ：全てのレイヤーを１つのパーツに統合します。
    分離 ：レイヤーをそれぞれ異なるパーツに分離します。
    表側と裏側を分割 ：表側のレイヤーと裏側のレイヤーとでそれぞれ異なるパーツにします。

  • レイヤーとの境界部

    作成されたレイヤーと、選択フェースの境界部に対する処理を指定します。
    なし ：特別な処理を行いません。
    サーフェースを作成 ：選択フェースをコピーし、新規サーフェースパーツを作成します。
    マージ ：レイヤーパーツと選択フェースの境界部の節点をマージします。

    • ※2次要素が含まれるエンティティを選択し実行した場合は、ワーニングが表示されます。
    1次要素に変換し実行します。

    - 操作手順 -

    1. スイープする面を選択します。
    2. 一層の厚みを指定します。
    3. 層数を指定します。
    4. パーツのレイヤーの設定をします。
    5. 適用もしくはOKボタンをクリックします。
