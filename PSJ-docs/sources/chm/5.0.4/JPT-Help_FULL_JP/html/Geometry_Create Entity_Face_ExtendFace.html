フェースを延長

延長フェースを作成します。

距離パラメーター

  • 計測方法

    フェースの作成方法を選択します。
    ・座標系：延長方向をパラメータ指定します
    ・2節点：2節点を選択して方向を決定します。
    ・要素エッジ：要素エッジを選択して延長方向を決定します。
    ・オフセット：選択フェースの方向に延長します。
    ・円筒：円筒形状のフェース延長

  • 座標系

    参照する座標

  • 方向(計測方法：座標系の場合のみ)

    ・X, Y, Z：方向を決定するパラメータです。
    面を延長する方向の値を入力します。X、Y、Zに入力された値で作られたベクトル方向に面を延長します。

  • 両方向

    延長フェースを両方向に作成します。

  • 方向を反転

    反対方向に面を作成します。


    • -----計測方法：円筒のみ-----

  • 方法

    円筒面の延長フェースの作成方法を選択します。
    ・軸まで：延長方向をパラメータ指定します
    ・フェースまで：選択したフェースまでフェースを延長します。
    ・円弧角度：延長するフェースの円弧角度を指定します。
    ・円弧長さ：延長するフェースの円弧長さを指定します。
    ・スイープ：円筒形状に沿って延長フェースを作成します。

    • メッシュパラメーター

  • 移動先

    長さ：延長フェースの長さを指定します。
    フェースまで：選択したフェースまで延長フェースが作成されます。

  • 分割数

    延長フェースのメッシュ分割数を指定します。

  • メッシュサイズ

    延長フェースのメッシュサイズを指定します。

  • 偏向係数

    バイアス係数を指定します。

  • 要素タイプ

    延長フェースの要素タイプを指定します。

  • 円弧の半径

    作成する円弧フェースの半径を指定します。

  • 円弧の節点数

    作成する円弧フェースの節点数を指定します。

  • 角度オフセット

    作成する円弧フェースの角度を指定します。

  • 円周長さ

    作成する円弧フェースの円周を指定します。(/p>

  • 長さ

    スイープする長さを指定します。

    • アドバンスオプション

  • フェースをマージ

    延長元のフェースと延長フェースをマージします。

  • マージエッジ(角度)

    エッジをマージする許容角度を指定します。

  • 接続

    延長フェースと延長先のフェースを共有節点で接続します。

  • 新規作成

    延長フェースを新規パーツとして作成します。

  • プレビュー

    作成する延長フェースをプレビュー表示します。

    • - 操作手順 -

    1. 計測方法を選択します。(円筒の場合方法も選択します。)
    2. 選択リストに表示されているエンティティを選択します。
    3. 必要に応じてパラメーターを入力します。
    4. 適用/OKボタンをクリックします。
