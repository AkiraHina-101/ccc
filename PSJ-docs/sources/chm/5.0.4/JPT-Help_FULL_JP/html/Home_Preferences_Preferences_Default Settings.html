デフォルト設定

その他既定値の設定を行います。

メッシュサイズ自動調整

サーフェースメッシングの自動チェックボックスをONにした場合の、メッシュサイズ自動指定を設定します。

  • 平均

    • 平均メッシュサイズを指定し、最大・最小メッシュサイズは自動的に計算します。

  • 最小 = 平均 *

    • 最小メッシュサイズを指定し、最大・平均メッシュサイズは自動的に計算します。右の欄には、最小メッシュサイズの計算パラメータを入力します。

  • 最大 = 平均 *

    • 最大メッシュサイズを指定し、平均・最小メッシュサイズは自動的に計算します。右の欄には、最大メッシュサイズの計算パラメータを入力します。

    オプション

    オプションのON/OFFを設定します。

  • 履歴ツリー保存

    • チェックを入れると、ヒストリー機能をONにします。
    ※ヒストリー機能は開発中です。

  • データ検証

    • チェックを入れると、不正値チェック機能をONにします。各コマンドでパラメータ入力時に、不正値を入力すると適用/OKがグレーアウトします。

    ※パラメータの不正値チェックについて

    入力値のタイプに応じて、下記の設定が有効にされています。
    ブランク値不可:空欄にしていると不正となります。
    範囲設定:設定値を超える範囲で指定すると不正となります。
    整数値:整数値の0から9の数字及び+、-以外のすべての文字（スペースを含む）が不正となります。
    実数値:0から9の数字、.、+、-及び指数表記用e、E以外のすべての文字（スペースを含む）が不正となります。
    関数:関数表記に使用できる文字以外が不正となります。
    文字列:いずれの文字を入力しても不正となりません。

  • 初期視点

    • ドキュメントを開いた際の視点を指定します。

  • モデル対象用機能確認ダイアログを表示

    • このチェックボックスがONのとき、以下のモデル対象機能（パーツ未選択の際に全パーツが対象となる機能）について、パーツ未選択の際に警告ダイアログを表示します。
    デフォルト：OFF

    対象機能：
    • メッシングリボン＞メッシング＞サーフェースメッシング
    • メッシングリボン＞メッシング＞ソリッドメッシング
    • メッシュ修正リボン＞要素品質＞フリーエッジ
    • メッシュ修正リボン＞要素品質＞要素交差
    • メッシュ修正リボン＞要素品質＞自動チェック
    • メッシュ修正リボン＞要素品質＞手動チェック

    ダイアログボックスの状態

  • ダイアログボックスの状態をデフォルトに戻す

    • リセットボタンをクリックすると、ダイアログボックスの入力値を初期値にリセットします。

  • 選択リストダイアログの最終表示位置を保存

    • チェックボックスにチェックを入れると、コマンドダイアログ付属の選択リストダイアログの位置が、最終表示位置に保持されるようになります。コマンドダイアログの「>(<)」ボタンをクリックした場合には、元の位置（コマンドダイアログの右隣）に戻ります。

    キーバインド

  • キーバインド有効

    • キーバインド（ショートカットキー）の設定を有効にします。

  • カスタマイズボタン

    • キーバインド設定ダイアログを表示します。

  • リセットボタン

    • キーバインド（ショートカットキー）の設定をリセットします。

    ※V4.0からキーバインドの設定ファイルはバージョン毎に独立し、バージョン間のコンフリクトが無くなりました。

    オートセーブ

    指定時間毎に開いているドキュメントをTempフォルダ（%temp%\Technostar）内に保存する機能です。
    ドキュメントを保存せずに終了した、Jupiter-Preがクラッシュした、といった場合に作業していたドキュメントのバックアップを取得することができます。
    ドキュメントはファイル名_YYYYMMDDHHMMSS.jtdbとして保存されています。

    ※Tempフォルダ内のファイルは、Jupiter-Pre起動時に消去されます。セーブファイルは、新たにJupiter-Preを起動する前に取得してください。

    ※ファイル保存中は一時的に待機状態になります。

  • オートセーブを有効化

    • オートセーブの設定を有効にします。

  • 保存時

    • セーブ時間間隔を指定します。

  • セーブファイル数

    • １つのドキュメントをいくつのファイルで保存するか指定します。

    初期ツリー状態

    jtdb読み込み時、またソルバーデータ(ADVC,Nastran,Abaqus)読み込み時のアッセンブルウィンドウ内ツリー各項目の初期表示状態を制御します。チェックをオフにすることで非表示となります。

  • すべてのパーツ

    • 初期状態でのパーツの表示を制御します。

  • すべてのアイテム

    • 初期状態でのすべてのアイテムの表示を制御します。

    ローカルメッシュ設定, 境界条件, 接触, 座標系, 接触要素 : 初期状態ですべてのアイテム以下の個々のアイテム表示を制御します。

    - 操作手順 -

    1.  コマンドを起動し、各オプションを指定して適用もしくはOKボタンをクリックします。
