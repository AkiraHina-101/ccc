拡大/縮小

選択した節点群を節点間の比率を保持しながら拡大、縮小します。

スケール係数

   座標系： 拡大、縮小する方向成分を定義する座標系を選択します。

   DX/DY/DZ： それぞれの方向成分の拡大、縮小比率を入力します。

   均等： 全ての方向成分に均等な比率を入力する場合にチェックします。

   Delta： 均等をチェックした場合に、全ての方向に使用する比率を入力します。

- 操作手順 -

  1.  拡大縮小する範囲の節点群をすべて選択します。
  2.  拡大縮小する基準となる節点を選択します。
  3.  拡大縮小する比率をそれぞれの方向または均等をチェックして1つの値を入力します。
  4.  適用またはOKボタンを押します。
