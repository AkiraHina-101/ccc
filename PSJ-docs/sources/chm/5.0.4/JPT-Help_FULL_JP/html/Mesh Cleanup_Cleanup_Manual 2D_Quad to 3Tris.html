Quadから3Tris

1つの四角形要素を3つの三角形要素に変換します。
要素上をマウスオーバーすると分割線をプレビュー表示し、分割パターンが複数ある場合は、分割パターンのプレビュー表示が切り替わるため、確認しながら分割が行えます。

設定

  • 自動遷移

    チェックを入れると、周りのメッシュ分割との整合性を図るため、指定した以外の周りの要素のメッシュ分割を自動で行います。

    チェックを入れない場合は、指定した以外の周りの要素のメッシュ分割を行わないため、分割後周りのメッシュ分割との整合性は合わなくなります。

  • 節点マージ

    チェックを入れると、メッシュ分割をしたことによって作成された節点と指定した以外の周りの要素の節点を自動で結合します。

  • CAD投影

    チェックを入れると、メッシュ分割をしたことによって作成された節点をCAD形状に乗せます。

  • 自動実行

    チェックを入れると、要素を選択すると自動で変換します。

    • - 操作手順（ 周りのメッシュ分割との整合性を図る場合） -

    1. 自動遷移のチェックボックスをオンにします。
    2. 自動実行のチェックボックスをオンにします。
    3. 変換する四角形要素上をマウスオーバーし、分割線をプレビュー表示したまま選択します。
    4. 選択と同時に変換します。
