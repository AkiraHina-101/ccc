材料

材料ダイアログボックス

プロパティデータに参照される材料データを作成します。
材料ライブラリからの読み込み、または新規作成ができます。

　　
  • ユーザーデータベース

    使用中のドキュメントの材料データベースに登録された材料データを一覧表示します。
    表示された材料データは、ライブラリーデータベースへドラック＆ドロップ、または↓ボタンでライブラリーデータベースに保存できます。
    一番上の行は検索行です。ID、 材料名、説明それぞれで材料データの検索が可能です。
    また、マウス右クリックメニューで表示されるメニューから、各コマンドを使用します。
    コマンド機能
    新規作成使用中のドキュメント内に、新規材料を作成します。
    編集ハイライトした材料を編集します。
    削除ハイライトした材料を削除します。

    • ※ユーザーデータベースに登録されない材料は使用できません。
    　　
  • ライブラリーデータベース

    指定された材料ライブラリの内容を一覧表示します。
    表示された材料データは、ユーザーデータベースへドラック＆ドロップ、または↑ボタンでユーザーデータベースに登録できます。
    また、マウス右クリックメニューで表示されるメニューから、各コマンドを使用します。
    コマンド機能
    新規作成表示されているライブラリ内に、新規材料を作成します。
    編集ハイライトした材料を編集します。
    削除ハイライトした材料をライブラリから削除します。
    ※デフォルトの材料ライブラリはホーム>プリファレンス>パス設定>デフォルト材料ライブラリ
    で指定します。

  • ライブラリパス

    現在表示されている材料ライブラリの名前です。

  • ライブラリを開く

    材料ライブラリを指定し、ライブラリーデータベースに内容を表示します。

  • 新規ライブラリ

    新規ライブラリを指定の名称で作成します。ライブラリファイルはデフォルト材料ライブラリのあるパスと同じ場所に作成されます。

    • 材料修正ダイアログボックス

    新規材料データ作成及び既存の材料データを編集する際に使用するダイアログです。

  • 名前

    材料名を入力します。

  • 材料ID

    材料IDを入力します。材料IDはユーザーデータベース一覧表内で
    重複できません。重複しないIDを選んでください。

    　　　
    • 　　
  • 説明

    材料に関する追加説明を入力します。（任意入力）

    　　　
  • 色

    材料に設定している色です。設定が無い場合には黒が設定されます。特定の機能(色の再割り当て・プロパティレポート)でパーツのサーフェースカラーとして使用されます。

  • 構造、熱、ガスケット、流体プルダウンメニュー

    それぞれ構造、伝熱、ガスケット、流体解析に使用する材料の項目がプルダウンメニューから選択できます。
    選択された項目は、下の性質リストに追加されます。

      に開き編集できます。
    • [右クリック：New]新しい項目を追加できます。項目の内容は
      構造、熱、ガスケット、流体プルダウンメニューと同じです。

    　　　

    • プロパティウインドウ

    選択された項目の材料定数が右側のプロパティウインドウに表示されます。

    - 操作手順 -

    新規材料作成

    1. ユーザーデータベース表上でマウスの右クリックメニューから新規作成を選択します。
      材料修正ダイアログボックスが表示されます。
    2. 名前に材料名を入力します。
    3. 必要に応じてその他のパラメータを変更します。説明には任意の文字列を入力できます。材料IDは材料ライブラリで重複できません。
    4. 構造、熱、ガスケット、流体から入力する材料定数項目を選択します。
      右側のプロパティウインドウに材料定数の入力内容が表示されます。
    5. 上記説明に従って材料定数を入力します。
    6. OKボタンを押してデータを作成します。作成されたデータはユーザーデータベース表に 追加されます。
    7. 作成されたデータを削除するには、対象アイテム上マウスの 右クリックメニューから削除を選択します。

    材料ライブラリからのデータの取得

    1. （ライブラリーデータベースが空欄の場合）ライブラリーを開くで材料ライブラリを指定し、を読み込みます。
    2. ライブラリーデータベースに表示された材料ライブラリのデータをマウスクリックでハイライトし、ユーザーデータベース表にドラッグ＆ドロップもしくは↑ボタンをクリックしてください。
    ※ユーザーデータベース表に追加された材料はプロパティデータ作成時に参照できます。
    ※材料ライブラリファイル(*.mlib)内で1.171915E+16 (=e^37 　e：自然対数の底)を越える値は、TSV-Preではブランクとして扱いますが、JPT-Preではその値のまま読み込みます。

    現在のドキュメント内材料から、新規材料ライブラリ作成

    1. ライブラリーデータベースの新規ライブラリをクリックします。
    2. 新規ライブラリ名を入力するダイアログボックスが表示されますので、ライブラリ名を入力します。
    3. ライブラリーデータベースの表が空になり、ライブラリパスにライブラリ名が表示されます。
    4. ユーザーデータベースの材料をマウスクリックでハイライトし、↓ボタンをクリックするか、ライブラリーデータベースへドラッグ＆ドロップします。
    5. 適用/OKで、デフォルト材料データベースと同じ場所に、新規ライブラリが保存されます。

    塑性材料の作成

    1. 材料修正ダイアログで>塑性>塑性を選択します。
    2. 直接入力する場合は、テーブル入力上で右クリックし後ろに挿入(もしくは前に挿入)で行を増やしてから入力します。
      最初の応力は降伏応力となります。
      csvデータから入力する場合は、テーブル入力上で右クリックしファイルから読み込みを選択しcsvデータを読み込みます。


      3. 温度依存の応力-塑性ひずみテーブルを入力する場合は、"温度依存データを使用"をチェックし、temp列を表示してからcsvファイル等を読み込みます。

    ガスケット材料厚さ方向特性の定義

    1. 材料修正ダイアログでガスケット>ガスケット厚さ挙動を選択します。
    2. 荷重曲線を直接入力する場合は、テーブル入力上で右クリックし後ろに挿入(もしくは前に挿入)で行を増やしてから入力します。
      csvデータから入力する場合は、テーブル入力上で右クリックしファイルから読み込みを選択しcsvデータを読み込みます。

      3.      
    3. 塑性圧力は、降伏開始方法で"Closure_value"を選択し、降伏点の閉鎖量を指定します(テーブルからその閉鎖量での圧力値を拾います)。
    4. 引張方向剛性係数は、引張剛性係数/値で"Value"を選択し、剛性係数を入力します。
    5. 除荷曲線タイプをタイプで"弾性_塑性"(弾塑性型)もしくは"ダメージ"(損傷弾性型)をから選択します。
    6. 除荷曲線の設定は、除荷タブを開き、"ユーザー定義の除荷曲線を含める"をチェックします。
      7. 荷重曲線と同様にテーブルデータを作成します。複数の除荷曲線に対応するため、Plastic/Max.Closureには、それぞれの除荷曲線の最大閉鎖量(下図では3,6,10の閉鎖量)を、その除荷曲線の全てのポイントで入力します。各除荷曲線の終点は荷重曲線の点と一致します。
      損傷弾性型の場合は、各除荷曲線の始点の圧力および閉鎖量は0.とします。
