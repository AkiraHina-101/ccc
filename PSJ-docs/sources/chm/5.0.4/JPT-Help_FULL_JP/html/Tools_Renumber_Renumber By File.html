ファイルによるリナンバー

CSVファイルに記載された情報をもとにリナンバーを行います。

　　

リナンバーテーブル

　　 各パーツに含まれる、節点/2D要素/3D要素のカウント数と開始IDを一覧表示します。
　　
  • CSVファイルインポート

       テーブルに、CSVファイルの内容をインポートします。

  • CSVファイルエクスポート

       ・テーブルの内容をCSVファイルにエクスポートします。
       ・パーツIDソート順でエクスポートされます。

    • 　　

    オプション

  • 競合の解決

       共有節点・共有面要素のIDの振り方を決めます。

    • より小さいID(<)
      共有節点/面要素のIDは、パーツIDの小さい方に所属します。
    • より大きいID(>)
      共有節点/面要素のIDは、パーツIDの大きい方に所属します。
  • 片方のパーツのみで共有節点をカウント

       IDのコピー先になるパーツをリストから選択します。
       共有IDを、衝突の解消オプションで決められたパーツに所属するのものとしてカウントします。

    • チェックオンの場合
      現状と同じ。
    • チェックオフの場合
      ID数カウントの際に、IDを共有している両方のパーツでIDが重複してカウントされます。

    • - 操作手順 -

    1.  モデルを作成します。
    2.  CSVファイルエクスポートボタンをクリックし、現在のモデルのナンバリング情報をCSVファイルに書き出します。
    3.  手順2で書き出したCSVファイルを編集し、任意のIDを指定します。
    4.  CSVファイルインポートボタンをクリックし、手順3で編集したCSVファイルを読み込みます。
    5.  適用ボタンをクリックし、リナンバーを実行します。

      

    - 注意事項 -
  •  CSVファイルは同一モデルにのみ適用可能です。
  •  CSVファイルエクスポート/インポート前後で、パーツ数・節点数・要素数に変更がないことが前提です。
  •  リナンバー対象は、節点及び2D/3D要素のみで、1D要素のリナンバーは対象外です。
