ボス追加 | 指定箇所に追加

このコマンドを使用して、ボスジオメトリ（円柱形状）を作成し、選択したパーツに含める事が出来ます。

オプション

  • マージ

    オンにすると、新しいボスパーツが選択したパーツとマージされます。

    底面の中心

      選択したパーツが接続されているボスの底面の位置を指定します。
    • 設定方法

      底面の中心を設定するために選択されたエンティティタイプ：ノードまたはフェイスポイント。

    • X

      底面の中心のX座標。

    • Y

      底面の中心のY座標。

    • Z

      底面の中心のZ座標。

    • 方向

    • X

      ボス方向ベクトルのX座標。

    • Y

      ボス方向ベクトルのY座標。

    • Z

      ボス方向ベクトルのZ座標。

    • 座標系

      ボス方向ベクトルの座標系を指定します。

    • 回転軸

      座標系の回転軸（X軸、Y軸、Z軸）を指定します。

    • 角度

      回転軸の回転角度を指定します。

    ボス形状

    • 中空円筒

      このチェックボックスを選択すると、ボスが中空のジオメトリとして作成されます。

    • 内側半径

      円柱ジオメトリの内径を入力します（中空ジオメトリの場合）。

    • 外側半径

      円柱ジオメトリの外半径を入力します。

    • テーパー角（度）

      円柱ジオメトリの上から下へのテーパー角度を入力します。

    • サークル内のノードの数

      円柱の円弧方向のノード数を入力します。

    • 軸のノードの数

      円柱の軸方向のノード数を入力します。

    • 高さ

      円柱ジオメトリの高さを入力します。


    - 操作手順 -

    1.  設定方法からフェイスポイントまたはノードを選択し、ボスを作成する位置でフェイスポイントまたはノードをクリックします。
      クリックされた位置は、底面の中心（ボス作成位置の中心点）として自動的に入力され、クリックされた位置の法線は（ボスの）方向として自動的に入力されます。
    2.  ボスの外側半径と高さを入力します。 プレビュージオメトリが表示されます。
    3.  [適用]または[OK]ボタンをクリックして実行します。
