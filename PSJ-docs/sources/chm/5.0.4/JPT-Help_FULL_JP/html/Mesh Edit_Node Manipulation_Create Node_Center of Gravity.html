重心位置

選択したパーツ、フェースの図心または重心位置に浮遊点を作成します。

プロパティ

  • 作成タイプ

       作成タイプを指定します。

    • 図心 ： 選択したエンティティの図心位置に浮遊点を作成します。
    • 重心 ： 選択したエンティティの重心位置に浮遊点を作成します。
      •
  • 節点番号

    作成される浮遊点のIDが表示されます。

  • X, Y, Z

    作成される浮遊点の座標が表示されます。

    • - 操作手順 -

    1. 作成タイプを指定します。
    2. パーツまたはフェース（図心のみ）を選択します。
    3. 必要に応じて節点番号を変更します。既存の節点番号と重複はできません。自動的に重複を避けて振替えられます。
    4. 必要に応じて座標値（X,Y,Z）を変更します。
    5. 適用/OKボタンをクリックします。
