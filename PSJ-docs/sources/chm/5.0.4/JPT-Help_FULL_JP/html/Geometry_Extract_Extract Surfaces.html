サーフェース抽出

角度指定により抽出されたフェースから、新規パーツを作成します。
この機能により、薄板形状のモデルより片側のサーフェスを抽出することができます。

サーフェース抽出

  • フェース間角度

    角度を入力します。この角度は抽出されるフェース間の角度を設定し、この設定した角度以下のフェースを抽出します。
    ※角度の数値に-1を入力した場合は、選択したフェースのみを抽出します。

    オプション

  • パーツ名

    フェース抽出後に作成される新規パーツの名前を入力します。

  • 面選択

    選択中のフェースIDを表示します。

  • プレビュー

    抽出される要素を確認できます。

  • リセット

    プレビューボタンで確認した要素をリセットします。

  • １パーツにマージ

    複数パーツのフェースを選択してフェースを抽出した場合、抽出フェースは抽出元のパーツの数だけ作成されます。本オプションをONにすることで、抽出したフェースを１つのパーツにまとめます。
    ※デフォルトはONです。
    例：
    １パーツにマージがOFFの場合

    １パーツにマージがONの場合

    • - 操作手順 -

    1. 抽出する角度を入力します。
    2. 新規パーツ名を入力します。
    3. フェースを選択します。
    4. プレビュー/リセットで抽出範囲を確認します。
    5. 必要に応じて、「１パーツにマージ」オプションをチェックします。
    6. 適用/OKボタンをクリックします。
