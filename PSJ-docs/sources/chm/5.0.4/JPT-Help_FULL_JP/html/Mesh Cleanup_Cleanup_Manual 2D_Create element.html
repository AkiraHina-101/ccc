要素作成

要素が欠落している場合に、欠落している要素の節点を選択しそこに要素を作成します。

要素作成

  • 自動

    チェックを入れると、3節点目（タイプ=Tri3）または4節点目（ タイプ=Quad4）を選択すると自動で要素を作成します。

  • 選択を保持

    チェックを入れると、要素作成後に元の節点を選択したままにします。

  • タイプ

    作成する要素のタイプを指定します。

    • Tri3

      Tria3要素を作成します。

    • Quad4

      Quad4要素を作成します。

  • フェースを指定

    チェックを入れてフェースを選択すると、選択したフェースに要素を作成します。

    • フェースID

      選択したフェースIDを表示します。

    - 操作手順 -

    1. 欠落している要素の節点を選択します。Tria3要素を作成する場合は3節点、Quad4要素を作成する場合は4節点選択します。
    2. 適用ボタンをクリックします。
    3. 選択した節点に囲まれた要素が作成されます。

    - 操作手順(フェースを指定オプション使用) -

    1. 作成タイプを、QUAD4に変更します。
    2. フェースを指定オプションにチェックを入れます。
    3. 4節点を選択します。
    4. 新しく作成する要素を追加したいフェースを選択します。
    5. 適用ボタンをクリックします。
    6. 選択したフェースに新しく作成された要素が追加されます。
