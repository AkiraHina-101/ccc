自動接触変換

各ソルバーの接触を自動変換します。

ソルバータイプ

　　
  • 現在の接触設定は、選択したターゲット接触ソルバーに変換されます。 　　

    • ADVC : 現在の接触設定は、ADVC接触ソルバーに変換されます。

    • Abaqus : 現在の接触設定は、Abaqus接触ソルバーに変換されます。

    • SunShine : 現在の接触設定は、SunShine接触ソルバーに変換されます。

    • NX-Nastran : 現在の接触設定は、NX-Nastran接触ソルバーに変換されます。

    • MSC Nastran: 現在の接触設定は、MSC Nastran接触ソルバーに変換されます。

      • - 操作手順 -

      1. 変換する接触ソルバーのターゲットを選択します。
      2. 適用またはOKボタンを選択します。
