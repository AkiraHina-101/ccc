RBE2

RBE2（剛体要素）を作成します。

  • 1対多

    一対多（マスター：スレーブ）のRBE2（剛体要素）を作成する機能です。

  • 1対1

    一対一（マスター：スレーブ）のRBE2（剛体要素）を作成する機能です。

  • 中心へ

    一対多（マスター：スレーブ）のRBE2（剛体要素）を作成する機能です。マスター節点は、選択したスレーブ節点の平均座標または任意座標に作成されます。
    モデル外の位置にマスター節点を定義したい場合に便利な機能です。

  • 円弧エッジの中心へ

    一対多（マスター：スレーブ）のRBE2（剛体要素）を作成する機能です。マスター節点は、選択した円弧の中心座標に作成されます。
    円や円筒形状に対してRBE2を作成したい場合に便利な機能です。



    • ※V4.0からRBE2などを削除するときに、中心節点がフローティング節点として残り、問題になることがありました。
    この問題を解決するために、RBE2などを削除するときにフローティング節点が残る場合には、確認メッセージを出力し、削除を促すように改良しました。
