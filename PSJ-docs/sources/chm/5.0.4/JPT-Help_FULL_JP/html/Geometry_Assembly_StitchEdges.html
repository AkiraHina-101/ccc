ステッチエッジ

わずかに離れているエッジを接続します。
接続の基準となるエッジをマスターとして選択します。接続させるエッジをスレーブとして選択します。
スレーブエッジがマスターエッジに接続します。

設定

  • トレランス

    接続可能な距離を入力します。ここで指定した値以内のエッジを接続します。

  • スレーブ節点を保持

    選択したスレーブとなるエッジ上の節点を保持します。

    • - 操作手順 -

      　　　
    1. 選択リストウインドウを開き、マスターボタンをクリックします。
      2. 　　　
    2. 接続の基準となるエッジを選択します。
      3. 　　　
    3. 選択リストウインドウのスレーブボタンをクリックします。
      4. 　　　
    4. 接続させるエッジを選択します。
      5. 　　　
    5. 必要に応じてトレランスの値をデフォルト値から変更します。
      6. 　　　
    6. 適用/OKボタンをクリックします。
