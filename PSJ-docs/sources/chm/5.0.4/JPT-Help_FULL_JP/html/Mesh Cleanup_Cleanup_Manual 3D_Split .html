要素を分割します。

分割

  • 分割位置

    エッジの分割位置を指定した節点からの比率で指定します。

    • - 操作手順(1) -

  • 選択した要素を2分割します。
    1. 分割したい要素のエッジを選択します。
    2. 適用ボタンをクリックします。
    3. 選択した要素のエッジが分割されます。

    - 操作手順(2) -

  • 要素分割位置を比率で指定します。
    1. 分割したい要素のエッジと参照節点を選択します。
    2. 分割位置に参照節点からの比率で指定します。0.5が中央になりますのでここでは0.2を使用します。
    3. 適用ボタンをクリックします。
    4. 選択した位置で要素のエッジが分割されます。
