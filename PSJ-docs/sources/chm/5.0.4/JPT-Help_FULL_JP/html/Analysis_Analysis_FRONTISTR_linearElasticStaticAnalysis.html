FrontISTR-Solver - 線形弾性静解析

FrontISTR-Solver - 線形弾性静解析用入力データを出力します。

Analysis Setting

　　　
  • FrontISTR Job

    ジョブ名: ジョブ名を入力します。ツリーにこの名称で出力設定が保存されます。
    ソルバーバージョン: 現在のバージョンは3（デフォルト)。
    解析タイプ: FrontISTR解析タイプ。
    現在線形弾性静解析のみがサポートされています。

    　　　
    • 　　　
  • 解析設定

    マトリクスソルバー方法: 解法を選択します。
    CG; BiCGSTAB,GMRES,GPBiCG,DIRECT,DIRECTmkl,MUMPS
    マトリクスソルバープレコンディショナ－: 解法を選択します。
    SSOR,SSOR(MCO),Diagonal Scaling,AMG,ILU(0),ILU(1),ILU(2)。
    出力反復数:出力反復数を選択します。
    YES: 出力反復数。
    NO: 反復数出力されない。
    出力経過時間: 出力経過時間を選択します。
    YES: 出力経過時間。
    NO: 経過時間出力されない。
    ベクターマシン用オーダー。
    対角スケーリング。
    MPC方法。
    反復数 :反復数を入力(デフォルト=20000)。
    Additive Schwartz反復数 : Additive Schwartz反復数を入力(デフォルト=2)。
    クリロフ部分空間数 :クリロフ部分空間数を入力。
    対象色数:対象色数を入力。
    閾値:収束の閾値を入力します(デフォルト=1e-6)。
    SIGMA_DIAG: SIGMA_DIAGを入力します(デフォルト=1e-6)。
    SIGMA: SIGMAを入力します。

    　　
    • 　　
  • 接触解析 　　

    アルゴリズム: アルゴリズムを選択します。
        Extended Lagrange Multiplier Method。
        Lagrange Multiplier Method。

  • 熱応力解析

    熱解析ステップ数: 熱解析ステップ数を入力します。
    初期ステップ数: 初期ステップ数を入力します。
    熱解析結果ファイル名: 熱解析結果ファイル名を入力します。

    Step Setting

    　　　
  • 自動増分および出力時刻設定：自動増分に必要なパラメータを入力します。

    　
        名前: 名前を入力します。
    　　
        減少条件: RS, NS_MAX, NS_SUM, NS_COUNT, N_Sの5つのパラメーターを入力します。

        時間増分の増加: RL, NL_MAX, NL_SUM, NL_COUNT, N_Lの5つのパラメーターを入力します。

        追加パラメータ: RC, N_Cの2つのパラメーターを入力します。

    • 　　

  • 出力時刻設定: 出力時刻に必要なパラメータを入力します。


        名前: 名前を入力します。

        開始時間: 開始時間のON/OFFを選択します。

        Type: STEP/TOTALを選択します。

        時刻: 開始時間=OFF の場合は、時刻のみの入力で十分です。

        開始時刻: 開始時間=ONにすると、開始時刻が入力できます。

        ETIME: 開始時間=ONにすると、終了時間が入力できます。

        時刻点の間隔: 開始時間=ONにすると、入力した間隔は増分と同じになります。

    • 　　　

  • ステップ解析 　　

    　　NAME: ステップ解析名を入力します。
    　　TYPE: 解析のタイプを選択します。
    　　    STATIC。
    　　    VISCO。
    　　CONVERG: 収束の閾値を入力します(デフォルト=1e-5)。
    　　SUBSTEPS: SUBSTEPSを入力します(デフォルト=10)。
    　　最大反復数(MAXITER): 最大反復数を入力します。
    　　DTIME: DTIMEを入力します。
    　　ETIME: ETIMEを入力します。
    　　    ステップ作成: ボタンをクリックして解析ステップを作成します。
        LBCマネージャ: 境界拘束条件やロードケースを設定するLBCマネージャダイアログを起動します。

    LBCマネージャダイアログ

        左に移動:選択したプロセスを左の列に移動します。
        右に移動:選択したプロセスを右の列に移動します。
        プロセス編集:プロセス設定内容を編集します。
        プロセスを削除:プロセスを削除します。
        アクティブ: 表示された条件を有効にします。
        非アクティブ:表示された条件を無効にします。

    • Output Setting

    結果データ: 結果タイプを出力データに出力する場合に選択します。
    データ視覚化: 出力結果タイプは後処理で視覚化できます。
    モデル情報をログファイルに出力: 節点と要素はログファイルに出力されます。
         YES :節点と要素はログファイルに出力されます。
    　　    NO : 節点と要素はログファイルに出力されません。
    視覚化ファイルタイプ: 視覚化ファイルタイプを選択します。
        AVS
        BMP
        VTK
        COMPLETE_AVS
        COMPLETE_REOPRDER_AVS
        SEPARATE_COMPLETE_AVS
        COMPLETE_MICROAVS
        BIN_COMPLETE_AVS
        FSTR_FEMAP_NEUTRAL
        BIN_VTK
    出力間隔:出力間隔を指定します。
    出力ファイル名:出力ファイル名を指定します。

    Option Setting

    グループマネージャー: 手動で作成したすべてのグループを管理します。

        Check All: すべてのグループを選択します。
        Uncheck All: すべてのグループの選択を解除します。
        Reverse All Check Status: チェックしたすべてのグループのステータスを反転させます。
        出力タイプ: 節点グループ、要素グループ、サーフェスグループを選択します。
        フィルター: 入力した名前により表示項目をフィルタリングします。
    選択項目出力: エクスポートするファイルの種類を選択します。
        .msh ファイル: ノード、要素、材料、選択されたグループを含む.mshファイルのみを出力します。
        .cnt ファイル: .cntファイルと.msh ファイルを出力します。

    Parallel Setting

    平行計算設定: 平行計算設定を指定します。
        OFF :平行計算設定は設定されません。
        ON :平行計算設定を指定します。
    計算節点数: 計算節点数を入力します。
    計算節点数あたりのプロセッサ数: 計算節点数あたりのプロセッサ数を入力します。
    細分化レベル: 細分化レベルを入力します。

    Execution Setting

    直接実行: 直接実行を指定します。
        OFF :直接実行は設定されません。
        ON :直接実行を指定します。
    単一コア計算 (平行計算設定= OFF)
        計算実行ファイルパス:計算実行ファイルパスを指定します。
        計算実行ファイル : 計算実行ファイルを指定します。
    平行コア計算
    MPI: MPI環境を指定します。
        パス:パスを指定します。
        Exeファイル : Exeファイルを指定します。
        オプション。
    FrontISTR: FrontISTR環境を指定します。
        計算実行ファイルパス:計算実行ファイルパスを指定します。
        エリア分割実行ファイル : エリア分割実行ファイルを指定します。
        計算実行ファイル: 計算実行ファイルを指定します。

    - 操作手順 -

    1.  ジョブ名を指定します。
    2.  プロセスを作成でプロセスを作成します。デフォルトの時間刻みで解析を行う場合は、特に必要ありません。
    3.  LBCマネージャでプロセスに境界条件を割り当てます。
    4.  出力マネージャで出力項目を選択します。
    5.  適用/OKボタンをクリックします。
