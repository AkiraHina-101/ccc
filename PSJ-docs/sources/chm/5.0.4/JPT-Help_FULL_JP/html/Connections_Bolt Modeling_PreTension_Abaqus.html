プリテンション | Abaqus

ABAQUS用初期張力を設定します。ユーザーは複数の面または複数の断面を選択できますが、それらは同じ法線ベクトルを持っている必要があります。

※V4.0よりボルトモデリングコマンドが実行されたときに、作成されたボルト1本ごとにグループを作成します。
ボルトグループはBolt Connectionサブグループの下に置かれます。

構造

  • ステップ名

    作成するアイテムの名前を入力します。

    プリテンション-1

  • 値

    初期張力を入力します。

  • 入力単位系

    入力単位系を選択します。

  • 参照節点ID

    参照節点のIDを入力します。
    選択リストで参照節点を選択した場合、IDが自動入力されます。

  • プリテンション方向

    初期張力の方向を表示します。

  • ボルト固定長

    チェックを入れた場合に、ボルトの締め付け量を保持します。

    • - 操作手順（断面を選択する場合または顔） -

      パーツ切断等の機能を使用しパーティション断面が入ったボルトパーツを予め用意します。

    1. パーティション断面を選択しますまたは顔。
    2. 初期張力を入力します。
    3. 必要に応じて単位系の変更、オプションを追加選択します。
    4. 適用またはOKボタンをクリックします。

    - 操作手順（梁要素を選択する場合） -

      1D メッシング等の機能を使用し3分割以上された梁要素のボルトパーツを予め用意します。

    1. 選択リストの1D要素をクリックし、梁要素を選択します。
    2. 初期張力を入力します。
    3. 必要に応じて単位系の変更、オプションを追加選択します。
    4. 適用またはOKボタンをクリックします。
