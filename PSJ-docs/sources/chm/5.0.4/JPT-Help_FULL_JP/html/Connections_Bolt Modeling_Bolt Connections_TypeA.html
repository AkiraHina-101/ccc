ボルトモデリングタイプA

ボルト穴の上面と下面にRBE2要素を円形に作成、その中心をバー要素またはRBE2要素で結合します。
タイプA には、プリテンション オプションがあり、ボルト締め付け力の設定を追加したボルトモデルを作成することができます。
ボルト軸のバー要素がその中心位置で分割され、MPC結合を利用したボルト締め付け力を定義します。

※V4.0よりボルトモデリングコマンドが実行されたときに、作成されたボルト1本ごとにグループを作成します。
ボルトグループはBolt Connectionサブグループの下に置かれます。



ボルトモデリング

  • RBE名

    作成するRBEアイテムの名前を入力します。

  • バー名前

    作成するバーアイテムの名前を入力します。

  • ボルトイメージを表示

    ボルトの概要図を表示します。作成するボルトタイプの変更が可能です。

  • シャフトタイプ

       Rbe間の接続方法を選択します。

    • Cbar : Rbe間をCbarで接続します。

    • RBE2 : Rbe間をRBE2で接続します。
      •
  • バープロパティ

    作成するボルトが使用するバー要素プロパティを既存のプロパティから選択します。

  • 平面トレランス

    Rbeが作成されるフェースが平面でない場合のRbe作成限界角度を設定します。

  • ボルト穴最大長さ

    Rbe間を接続するシャフト部の最大長さを設定します。

  • 最大直径

    抽出するボルト穴の最大直径を設定します。（作成方法がフェースのとき）

  • 最小直径

    抽出するボルト穴の最小直径を設定します。（作成方法がフェースのとき）

    • プリテンション荷重

  • ソルバー

       ソルバーを選択します。

    • All : すべてのソルバーに使用できます。

    • Abaqus : ABAQUSのプリテンションコマンドで設定します。
      •
  • 値

    ボルトの締め付け荷重を入力します。

  • 入力単位系

    入力単位系を指定します。

  • 方向

    ボルトの締め付け方向を選択します。（すべてのみ）

  • 座標系

    ボルトの締め付け方向が参照する座標系を選択します。（すべてのみ）

  • ボルト固定長

    ボルトの締め付け量の保持が行えます。

    • 上面Rbe

  • スロット

    ボルト穴が長穴の場合にチェックを入れると、長穴の中心にボルトモデルを作成します。

  • 係数

    穴の直径を1としたRbe作成範囲を設定します。

  • 穴の直径

    Rbe作成範囲の基準値を設定します。
    （デフォルトでは、選択したエッジの直径を表示します）

  • RBE直径

    Rbe作成範囲を直径サイズで設定します。
    係数で設定している場合は、自動で反映されています。
    ※直接入力し、係数 x 穴の直径 ≠ RBE直径となった場合は、RBE直径が優先されます。

    • 底部Rbe

  • スロット

    ボルト穴が長穴の場合にチェックを入れると、長穴の中心にボルトモデルを作成します。

  • 係数

    穴の直径を1としたRbe作成範囲を設定します。

  • 穴の直径

    Rbe作成範囲の基準値を設定します。
    （デフォルトでは、選択したエッジの直径を表示します）

  • RBE直径

    Rbe作成範囲を直径サイズで設定します。
    係数で設定している場合は、自動で反映されています。
    ※直接入力し、係数 x 穴の直径 ≠ RBE直径となった場合は、RBE直径が優先されます。

    • - 操作手順 (エッジ選択作成) -

    1. シャフトタイプからRBE2 / Cbarを選択します。
    2. 選択リストを開き、上面エッジのボタンをクリックした後、トップ側のエッジを選択します。（複数選択可能）
    3. 必要に応じて、係数の値を変更します。
    4. 選択リストの底面エッジのボタンをクリックした後、ボトム側のエッジを選択します。（複数選択可能）
    5. 必要に応じて、係数の値を変更します。
    6. 適用またはOKボタンをクリックします。

    - 操作手順 (フェース選択作成) -

    1. シャフトタイプからRBE2 / Cbarを選択します。
    2. 最大 / 最小直径に抽出するボルト穴の最大／最小直径を入力します。
    3. 選択リストを開き、上面フェースのボタンをクリックした後、トップ側のフェースを選択します。（複数選択可能）
    4. 上面Rbeの穴の直径にボルト穴の直径を入力します。
    5. 選択リストの底面フェースのボタンをクリックした後、、ボトム側のフェースを選択します。（複数選択可能）
    6. 底部Rbeの穴の直径にボルト穴の直径を入力します。
    7. プレビュー ボタンをクリックし、RBE2作成範囲を確認します。
    8. 必要に応じて、上面Rbeと底部Rbeの係数の値を変更します。
    9. 適用またはOKボタンをクリックします。
