圧力 | サーフェース荷重

選択したフェースに指定した方向の荷重を定義します。 (対応ソルバー：ADVC　※NastranはV3.1より対応)

構造

　　
  • 名前

    圧力荷重名を設定します。

    力

    　　　
    • 　　
  • X/Y/Z

    X,Y,Z各軸方向の力を設定します。

    　　　
    • 　　
  • 入力単位系

    入力単位を指定します。

    　　　
    • 　　
  • 矢印方向

    マーカー表示の描画位置を設定をします。
       節点が始点：節点を始点として、マーカーを表示します。
       節点が終点：節点を終点として、マーカーを表示します。

    　　　

    • 解析座標系

    　　
  • 座標系

    荷重方向に任意のローカル座標系を選択できます。

    　　　

    • - 操作手順 -

      　　　
    1. サーフェス荷重を負荷するフェースを選択します。複数の選択が可能です。
      2. 　　　
    2. 荷重方向に従い、X,Y,Zに荷重値を入力します。
      3. 　　　
    3. 必要に応じて他のパラメータを選択、入力します。
      4. 　　　
    4. 適用またはOKボタンをクリックします。
