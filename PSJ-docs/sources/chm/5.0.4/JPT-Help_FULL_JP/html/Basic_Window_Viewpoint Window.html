ビューポイントツリー

  • ユーザービューポイント

    • アイテムをダブルクリックすることで、プリセットビューポイントにビューを動かします。
    また、 ユーザービューポイントダブルクリック時に回転・移動・ズームの各パラメータの有効・無効を、マウス右クリックから表示されるチェックボックスで操作可能です。

  • ユーザーフレーム

    • ユーザーフレームは、ホームリボン内の範囲選択キャプチャからユーザーフレームコマンドで追加されます。
    追加されたアイテムをダブルクリックすることで、範囲選択キャプチャフレームがメインウインドウに表示されます。

    プリセットビュー

    アイコンをクリックし、プリセットビューポイントにビューを動かします。

    ビューコントロール

  • 中心

    • モデルの回転中心を設定します。

    • X,Y,Z : 中心座標を入力します。
    • セット : 指定した座標系に設定します。
    • リセット : 設定を元に戻します。
      •

  • 回転

    • モデルの回転角度を設定します。

    • X,Y,Z,エッジ,法線 : 回転角度を入力します。
      • X: X軸中心に回転します。
      • Y: Y軸中心に回転します。
      • Z: Z軸中心に回転します。
      • エッジ: 選択エッジを中心軸として、軸中心に回転します。
      • 法線: 画面に対して垂直方向の軸を中心として、軸中心に回転します。
    • 回転 : 指定した角度で各軸まわりに回転します。
    • 表示 : 回転矢印を表示/非表示にします。
      •

  • パン

    • 画面上での移動距離を設定します。

    • 左←,右→ : 指定した距離で水平方向に移動します。
    • 上↑,下↓ : 指定した距離で垂直方向に移動します。
      •

  • ズーム

    • 画面上での拡大率を設定します。

    • ズームイン : 指定した値で拡大します。
    • ズームアウト : 指定した値で縮小します。
    • フィット : モデルをウィンドウの最適サイズに設定します。
      •

    - 操作手順（ユーザービューポイントの追加） -

    1.  メインウィンドウの画面上で、ビューを任意の位置に動かします。
    2.  ビューポイントウィンドウの「追加」アイコンをクリックします。
    3.  ユーザービューポイント名ダイアログが表示されますので、任意の名称を入力してOKをクリックします。新規ユーザービューポイントが追加されます。
    4.  ビューを動かした後、追加されたユーザービューポイントをダブルクリックします。追加した際のビューが復帰します。
    ※追加したユーザービューポイント右クリックから、PanとZoomのチェックをOFFにすることで、現在のビューのフォーカス位置を保持したままモデルを回転することができます。これにより、任意座標系ビューとして使用することができます。

    - 操作手順(中心) -

    1. x/y/zに座標値を入力します。
    2. 「設定」ボタンをクリックします。

    - 操作手順(回転) -

    1. x/y/zに回転角度を入力します。
    2. 「回転」ボタンをクリックします。

    - 操作手順(パン) -

    1. 右/上に移動量を入力します。
    2. 「パンイン」または「パンアウト」ボタンをクリックします。

    - 操作手順(ズーム) -

    1. 拡大または縮小させる倍率を入力します。
    2. 「ズームイン」または「ズームアウト」ボタンをクリックします。
    3. モデル全体をメインウィンドウのサイズに合わせて表示したい時は「フィット」ボタンをクリックします。
