パーツ フェース

パーツまたは複数のフェースから、隣接面との角度またはフェース幅を参照し、自動的に隣接するフェースをマージします。

オプション

  • 角度

    チェックすると、隣接面との角度による自動マージを有効にします。

  • トレランス角度

    入力した角度以下の隣接面をマージします。

  • 幅

    チェックをすると、フェースの幅による自動マージを有効にします。

    ＜以下の計算式によってマージ対象フェースの判定しています。＞
    　ratio = (area × 16) / (totLen × totLen)
    　　 ※ area = フェースの面積, totLen = total edge length of face(フェースを構成する4辺の長さ)
    thick = ratio × totLen / 8.0
    対象のフェース <= 入力値　となるときにフェースをマージ

  • 幅のトレランス

    入力した幅以下の隣接面をマージします。

    • - 操作手順 -

    1. マージするパーツを選択します。
    2. マージする対象から除外したいフェースがある場合はそのフェースを選択します。
    3. 必要に応じて、角度チェックボックスをチェックして、トレランスを入力します。
    4. 必要に応じて、幅チェックボックスをチェックして、トレランスを入力します。
    5. 適用/OKボタンをクリックします。
