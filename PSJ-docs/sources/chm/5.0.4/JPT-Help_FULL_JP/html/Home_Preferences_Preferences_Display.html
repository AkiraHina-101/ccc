画面設定

メインウィンドウ上の各種表示設定を行います。

LBC

境界拘束条件の表示条件を設定します。

  • 対象エンティティを表示
    境界拘束条件を設定したエンティティの色を変更して表示します。
    • オフ
      表示しません。
    • 常に表示
      常に表示します。
    • 選択
      エンティティを選択した際のみ表示します。

  • マーカー密度 マーカーの密度を設定します。
    • エンティティ毎に１つ
      １か所の設定に対して、１つ（１ペア）のマーカーを表示します。
    • 粗
      設定個所の節点にランダムにマーカーを表示します。（低密度）
    • 中間
      設定個所の節点にランダムにマーカーを表示します。（高密度）
    • 密
      設定個所の全節点にマーカーを表示します。（最高密度）
    • 有効なエリアのみ
      接触マーカーを実接触面の範囲のみに限定します。
    • LBC毎に１つ
      １つの境界条件に対して、１つ（１ペア）のマーカーを表示します。

  • 値の表示
    設定値を表示します。
    • オフ
      設定値を表示しません。
    • スクリーン上
      メインウィンドウの左上に表示します。
    • 3D上
      マーカー上に表示します。
    • 3D上（単位付き）
      マーカー上に単位とともに表示します。

  • LBC表示を追従
    パーツの表示・非表示を切り替えた際に、そのパーツに設定されているLBCの表示も一緒に表示・非表示にします。
    • オフ
      機能を有効にします。
    • オン
      機能を無効にします。
  • 透過率
    接触設定した面に対するマーカーの透過率を設定します。
  • マスター色
    接触設定で、マスター側の面の色を指定します。
  • スレーブ色
    接触設定で、スレーブ側の面の色を指定します。
  • 3Dマーカー
    マーカー表示を立体的にします。

グラフィックス

  • 表示モード
    パーツ表面のシェーディング（陰影色）のタイプを変更します。
    • 要素シェーディング
      要素毎に陰影色を計算し、それぞれ単一の陰影色を塗ります。
    • スムースシェーディング
      節点で陰影色を計算し、要素内で陰影色をなめらかに補完して塗ります。
  • 光源を有効にする
    画面に点光源を設置し、色合いに陰影を付けます。
  • FPS表示
    画面左下にモデル移動時のFPSを表示します。
  • 浮遊節点を接続先に同期
    接続要素に接続している浮遊節点を、接続要素を表示・非表示した際に一緒に表示・非表示にします。

ビュー回転方法

メインウィンドウでの回転の方法を指定します。

  • 2D/3Dの自動切替
    楕円空間内のドラッグは３D回転、空間外のドラッグは2D回転と自動的に判断します。
  • 3D回転エリア表示
    2D/3Dの自動切替がONのときに楕円空間を表示
  • プリセットビュー操作時に自動フィット
    プリセットビューによるモデル移動後に、モデルが画面全体に収まるように自動フィットします。
  • 高速回転
    モデル回転時に境界条件・接続要素を非表示にすることで、モデル回転速度を向上させます。
  • 初期ビューポイント
    新規ドキュメント作成時の視点を設定します。デフォルト：アイソメトリックビュー（+Z1）

LBC表示切替

LBCの見た目を変更します。オリジナルを選択するとシンプル表示、詳細表示を選択するとより情報量の多い表示となります。

  • 拘束
    拘束条件の見た目を変更します。
  • ばね要素
    ばね要素の見た目を変更します。
  • RBE2/RBE3
    RBE2/RBE3接続要素の見た目を変更します。
  • 質量
    質量要素の見た目を変更します。
  • MPC
    MPC拘束条件の見た目を変更します。
  • ブッシュ
    ブッシュ要素の見た目を変更します。

ラベル

チェックボックスをチェックすると、該当する機能のラベルを表示します。

  • 軸ラベル文字
    全体座標系を示す軸に、X,Y,Zのラベル文字を表示します。
  • コンター数値
    コンター凡例が表示されている場合に、その横に数値を表示します。
