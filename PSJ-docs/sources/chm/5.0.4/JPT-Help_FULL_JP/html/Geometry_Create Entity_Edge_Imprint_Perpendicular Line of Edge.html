エッジから垂線を作成

選択したフェースに選択した節点2つと垂直にラインを作成します。

オプション

  • オフセット

    •    垂線からのオフセット量を入力します。最初に選んだ節点が基点になります。

  • 面を分割

    •    フェースを分割します。


    - 操作手順 -

    1.  フェースボタンを押し、インプリント対象のフェースを画面より選択します。複数のフェース選択が可能です。
    2.  節点ボタンを押し、方向を決める2つの節点を順番に画面より選択します。最初の節点がオフセット量の基点になります。インプリント線はこの方向の垂直方向に定義されます。
    3.  オフセットに垂直方向からのオフセット量を入力します。
    4.  必要に応じて面を分割チェックボックスをオフにします。この場合はインプリント後のフェースが元のフェースから分割されません。
    5.  適用/OKボタンをクリックします。

      6. ※対象フェースは平面と円筒面です。
