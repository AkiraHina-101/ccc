リボンをカスタマイズ

リボンをカスタマイズします。カスタマイズしたリボンをファイルに出力し、他マシンに読み込めます。

リボンをカスタマイズ

  • 新しいタブ

    新しいタブをカスタマイズツリーに追加します。

  • 新しいグループ

    新しいグループをカスタマイズツリーに追加します。

  • リネーム

    選択している名前を他の名前に変更します。

  • 追加

    選択したコマンドをカスタマイズツリーに追加します。

  • 削除(※)

    選択したアイテムをカスタマイズツリーから除外します。

  • インポート

    ファイルを読み込むためのダイアログが開きます。リボンファイルを指定します。

  • エクスポート

    ファイルを保存するためのダイアログが開きます。リボンファイル「*.rib」を作成します。

  • カスタマイゼーション リセット

    カスタマイズしたリボンをJupiter-Preのデフォルトに戻します。
    「Delete all Ribbon customizations for this program?」から［はい］をクリックしデフォルトに戻します。

  • ※[削除]ボタンについて

    カスタマイズツリーからアイテムを削除した場合に、下記メッセージダイアログが開きます。
    「If you want to re-import this ribbon tab please restart Jupiter, ignore this message when you do normal delete!」
    こちらはリボンファイルをインポートする際の注意喚起です。
    アイテムを削除後、リボンファイルを読み込む場合は、Jupiter-Preを再起動しリボンファイルを読み込みます。
    削除後リボンファイルの読込みを行わない場合は、Jupiter-Preの再起動は不要です。［OK］ボタンをクリックしカスタマイズを続けます。

    • - 操作手順（コマンド追加方法） -

    1. 「コマンドを選択」からリボンに追加するコマンドを選択します。
    2. 「リボンをカスタマイズ」にて、追加場所を選択し、[追加>>]ボタンをクリックします。
    3. 必要に応じて、［新しいタブ］、［新しいグループ］ボタンをクリックし、枠を追加後コマンドを追加します。
    4. OKボタンをクリックします。

    - 操作手順（リボンファイルの出力と読込み方法） -

    1. [エクスポート]ボタンをクリックします。
    2. 「名前を付けて保存」にてリボンファイルの名前、出力先を指定し、[保存]ボタンをクリックします。
    3. [インポート]ボタンをクリックします。
    4. 「開く」からリボンファイルを指定し、[開く]ボタンをクリックします。
    5. OKボタンをクリックします。
