接続 | ダンパー　1対1(閾値) - 一様自由度

一対一の減衰要素を作成する機能です。(対応ソルバーNastran)

指定された範囲内の選択された節点間に自動で減衰要素が定義されます。
この機能では、複数の自由度を纏めて結合できます。 節点IDの若い方が1stグループとして定義されます。

接続

  • 名前

    登録される名前を入力します。

    • 方法

  • 節点間距離トレランス

    接続先の検索範囲を入力します。

    • ダンパー

  • グラウンド

    接地バネのオプションを指定します。

  • Xダンパー - RZダンパー

    結合する自由度に減衰を入力します。

  • 減衰係数

    減衰係数を入力します。

  • 応力係数

    応力係数を入力します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • - 操作手順 -

    1. 節点間距離トレランスを設定します。
    2. メインウィンドウから節点を複数選択します。
    3. 結合する自由度に減衰を入力します。
    4. 他のパラメータを設定します。
    5. 適用/OKボタンをクリックします。
