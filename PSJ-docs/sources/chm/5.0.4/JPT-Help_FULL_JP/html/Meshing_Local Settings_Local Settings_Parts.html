パーツ

パーツ単位のメッシュサイズを設定します。 全体メッシュ作成前に予め設定し、全体メッシュ作成時に
設定したメッシュサイズが適用されます。

メッシュパラメーター

  • 名前

    メッシュコントロール名を設定します。

    メッシュサイズ

  • メッシュサイズ

    要素のサイズを設定します。

  • 平均

    要素の平均サイズを設定します。

  • 最小

    要素の最小サイズを設定します。

  • 最大

    要素の最大サイズを設定します。

    • ソリッドメッシングオプション

  • 浮遊節点を使用

    パーツをソリッドメッシングした際に、指定した浮遊節点位置にソリッドメッシュの節点が存在するようにメッシュを作成します。

    • 詳細設定

    　　
  • ローカルメッシュプレビュー

    オンにすると、選択したパーツメッシュを必要なメッシュサイズでプレビューできます。
    注：モデルサイズに対して小さいメッシュサイズを設定した場合、メッシュのプレビュー表示に時間がかかる場合があります。

    　　　
    • 　　
  • プレビューの色

    カラーリストからプレビューのパーツの色を選択します。

    　　　

    • - 操作手順 -

    1. パーツを選択します。
    2. メッシュサイズの各項目を入力します。
    3. 適用/OKボタンをクリックします。

    - 操作手順（ソリッドメッシングオプション） -

    1. パーツ内部の任意の場所に、浮遊節点を作成します。
    2. パーツを選択します。
    3. 浮遊節点を選択します。
    4. 適用/OKボタンをクリックします。
