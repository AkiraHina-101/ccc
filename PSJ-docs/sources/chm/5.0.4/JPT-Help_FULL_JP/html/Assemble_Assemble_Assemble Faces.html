共有面作成

複数パーツからなるアセンブリモデルに対し、パーツ間に共有面を作成します。
まず、検索によってトレランス距離内にあるパーツ間の合わせ面をフェースペアとして自動抽出します。次に、フェースペア単位で共有面を作成します。

合わせ面検索

  • トレランス

    フェースペアを抽出するためのパーツ間の距離を入力します。
    入力した距離以内にあるパーツ間のフェースを抽出し、フェースペアを作成します。

  • 自動計算

    チェックを入れると、トレランスをモデルより自動計算して入力します。

  • 検索

    フェースペアの抽出を行います。

  • 合わせ面数/共有面数

    検索ボタンクリックにより抽出したフェースペア数を表示します。
    共有面作成後は、名称が共有面数に変更になり、作成した共有面の数を表示します。

  • 検索結果/共有面

    検索ボタンクリックにより抽出したフェースペアの一覧を表示します。
    共有面作成後は、名称が共有面に変更になり、作成した共有面の一覧を表示します。

  • No.

    検索した順に通し番号が振られます。番号の先頭のチェックボックスにチェックが入っているフェースペアに対し、共有面を作成します。

  • マスター

    マスター側となるフェースが所属するパーツ名が表示されます。

  • スレーブ

    スレーブ側となるフェースが所属するパーツ名が表示されます。

  • 検索結果フェース名

    フェースペア名のを表示します。

  • すべて選択

    全ての行をハイライトします。

  • すべて選択解除

    全ての行のハイライトを解除します。

  • チェック

    ハイライトされた行のチェックボックスのチェックを入れます。

  • チェックを外す

    ハイライトされた行のチェックボックスのチェックを外します。

  • 選択のみチェック

    ハイライトされた行のチェックボックスにのみチェックを入れ、そのほかの行のチェックを外します。

  • マスター/スレーブ入替

    ハイライトした行のマスター/スレーブを入れ替えます。

  • 検索結果をグループに保存

    合わせ面にリストされているフェースペアをフェースグループにしてドキュメントに保存します。保存されたフェースグループは、グループウィンドウの、Shared Face Candidateサブグループ内にリストされます。

  • 検索結果をグループから読み込み

    グループウィンドウの、Shared Face Candidateサブグループ内のフェースペアをテーブルに表示します。

    • 共有面作成

  • 共有面作成位置

    共有面の作成位置を指定できます。

    • 　　　　
    • マスター側

      マスターフェースの位置を固定して共有面を作成します。スレーブフェースの共有面はマスターフェースの位置に移動します。

    • 中間位置

      マスターフェースとスレーブフェースの中間の位置で共有面を作成します。

      •
  • エッジを結合

    チェックを入れた場合、共有面作成時に、フェースの境目で細かいエッジ分割が起きるのを防ぎます。

    元データエッジを結合：ONエッジを結合：OFF
  • 選択フィルター

    ボックスに入力した文字列で、合わせ面候補をフィルタリング表示します。

    • オン

      ボックスに入力した文字列を含むペアをリストに表示します。

    • オフ

      ボックスに入力した文字列を含まないペアをリストに表示します。

    • 選択

      フィルタリングを実行し、表示行をハイライトします。

    • リセット

      フィルタリングを解除します。

      •

    - 操作手順(モデルを対象に共有面を作成する場合) -

    1. 必要に応じてトレランスの値をデフォルト値から変更します。
    2. 検索ボタンをクリックします。
    3. フェースペアの抽出結果がリスト表示されます。
    4. リストの各フェースペアをクリックすると、モデル上の該当するフェースが色付きで表示されます。
    5. 共有面作成を行わないフェースペアがある場合は、チェックボックスを外します。
    6. 適用/OKボタンをクリックします。

    - 操作手順(複数パーツを対象に共有面を作成する場合) -

    1. 対象のパーツを複数選択します。
    2. 必要に応じてトレランスの値をデフォルト値から変更します。
    3. 検索ボタンをクリックします。
    4. フェースペアの抽出結果がリスト表示されます。
    5. リストの各フェースペアをクリックすると、モデル上の該当するフェースが色付きで表示されます。
    6. 共有面作成を行わないフェースペアがある場合は、チェックボックスを外します。
    7. 適用/OKボタンをクリックします。
