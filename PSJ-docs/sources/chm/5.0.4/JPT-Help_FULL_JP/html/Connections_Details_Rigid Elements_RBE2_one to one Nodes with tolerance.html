接続 | 剛体要素　1対1(閾値)

一対一（マスター：スレーブ）のRBE2（剛体要素）を作成する機能です。

指定された範囲内の選択された節点間に自動で剛体要素が定義されます。
節点IDの若い方がマスターとして定義されます。

接続

  • 名前

    登録される名前を入力します。

    • 方法

  • 節点間距離トレランス

    接続先の検索範囲を入力します。

    • 参照自由度

  • UX - RZ

    従属自由度の成分を指定します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • Abaqus

  • サーフェース定義出力

    面の定義方法を選択します。

    • 節点セット

      基準面として節点を指定します。

    • 要素セット

      基準面として要素を指定します。スレーブに要素を構成できないエンティティ（節点、エッジ）を選択していると、エラーが出力されます。

    • - 操作手順 -

    1. 節点間距離トレランスを設定します。
    2. メインウィンドウから節点を複数選択します。
    3. パラメータを設定します。
    4. 適用/OKボタンをクリックします。
