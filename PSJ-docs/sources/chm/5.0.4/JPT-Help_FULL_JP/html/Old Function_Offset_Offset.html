Offset（オフセット）

フェースをオフセットして中立面を作成します。

Offset（オフセット）

  • Distance（板厚）

    オフセットする距離を入力します。正値が板の裏方向です。

  • Cylinder（円筒体）

    円筒面のオフセット時に指定して下さい。

  • New Part Name（新規―パーツ名）

    新規パーツとして作成するときの名前を入力してください。

    • - 操作手順 -

    1. オフセット移動したい側のフェースを選択します。
    2. 他のパーツ内にフェースを作成する場合は、対象のパーツを1つ選択してください。新規パーツとして作成する場合はパーツを選択しません。
    3. 「オフセット」を入力します。
    4. （必要に応じて、オプションを指定します）
    5. 適用／OKボタンをクリックします。
