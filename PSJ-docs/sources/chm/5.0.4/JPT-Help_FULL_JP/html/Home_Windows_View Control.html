ビューコントロール

現在のビューを数値入力でコントロールします。

中心

入力した座標をモデルの回転中心とします。

  • リセット

    • 回転中心がリセットされます。　※入力中の数値はリセットされません。

    回転

    各軸を中心に、入力した角度分回転します。

    パン

    ビューを平行移動（パン）します。

  • パンイン

    入力した数値の分だけ右または上方向に移動します。

  • パンアウト

    入力した数値の分だけ左または下方向に移動します。

    • 拡大/縮小

    ビューを入力した数値の倍率で拡大/縮小表示します。

  • フィット

    ボタンをクリックするとモデル全体をメインウィンドウのサイズに合わせて表示します。

    • - 操作手順(中心) -

    1. x/y/zに座標値を入力します。
    2. 「設定」ボタンをクリックします。

    - 操作手順(回転) -

    1. x/y/zに回転角度を入力します。
    2. 「回転」ボタンをクリックします。

    - 操作手順(パン) -

    1. 右/上に移動量を入力します。
    2. 「パンイン」または「パンアウト」ボタンをクリックします。

    - 操作手順(拡大/縮小) -

    1. 拡大または縮小させる倍率を入力します。
    2. 「拡大」または「縮小」ボタンをクリックします。
    3. モデル全体をメインウィンドウのサイズに合わせて表示したい時は「フィット」ボタンをクリックします。
