拘束

解析モデルに使用する変位固定条件を作成します。

　　

構造

  • 名前

       作成する変位固定条件の名前を入力します。

  • 座標系

       拘束する自由度が参照する既存の座標系をプルダウンメニューから選択します。

    • 拘束方向

     拘束する自由度の方向をチェックボックスから選択します。
  • 変位X

       チェックするとX方向の並進移動を拘束します。

  • 変位Y

       チェックするとY方向の並進移動を拘束します。

  • 変位Z

       チェックするとZ方向の並進移動を拘束します。

  • 回転X

       チェックするとX軸周りの回転移動を拘束します。

  • 回転Y

       チェックするとY軸周りの回転移動を拘束します。

  • 回転Z

       チェックするとZ軸周りの回転移動を拘束します。

    • テーブル

  • テーブル選択

       フィールドデータで定義します。現在サポートされていません。

    • 他の機能

      他の機能を設定できます
  • タイプ

       オプションを選択します。

    • SUPPORT : NastranのSUPORTカードを節点に定義します。
    • USET : NastranのUSETカードを節点に定義します。
      •
  • セット名

       USETを選択した場合、SET名をU1～U6から選択します。

    • Abaqusオプション

     ABAQUSI/F向けの設定になります。
  • 固定

       前ステップの変形量の保持

    • - 操作手順 -

    1.  フェース、エッジまたは節点ボタンを押し、画面上から拘束条件付加対象を選択します。
    2.  名前に作成する拘束条件の名前を入力します。
    3.  座標系から拘束する節点が参照する座標系を選択します。参照される座標系はあらかじめ作成しておく必要があります。
    4.  変位を拘束する並進方向と回転方向の自由度のチェックボックスをチェックします。
    5.  適用またはOKボタンを押します。
