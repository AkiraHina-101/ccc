プロパティレポート

プロパティレポートダイアログボックス

ドキュメント内の各パーツにどのプロパティ・材料が割り当ててあるかの一覧を、HTMLファイル形式のレポートとして出力します。

html ファイル出力フォルダの指定

　　
  • htmlファイル保存フォルダ

    HTMLファイルと、キャプチャ画像の格納フォルダを保存するフォルダを指定します。

    　　　

    • パーツ色変更（オプション）

    　　
  • オプション

    キャプチャ時のパーツカラー変更オプションです。

    • ランダム色

      現在のパーツ表面色を、一時的にランダムな色に変更してキャプチャします。

    • 材料色

      パーツ表面色を、一時的に材料色に変更してキャプチャします。

    • プロパティ色

      パーツ表面色を、一時的にプロパティ色に変更してキャプチャします。

      •

    　　　

    • - 操作手順 -

    1. プロパティ/材料を割り当てたモデルを準備します。
    2. プロパティレポート機能を起動します。
    3. htmlファイル保存フォルダで、保存先フォルダを指定します。
    4. 必要に応じて、オプションを選択します。
    5. 適用/OKボタンをクリックして、レポートを出力します。
      htmlファイル保存フォルダに、「ドキュメント名.html」及び、ドキュメント名_imageフォルダが作成されます。
    6. ドキュメント名.htmlファイルをブラウザで開きます。
