接触 | グループマトリックス | ADVC

指定グループ間にADVC用接触設定を定義します。
予めマスター面およびスレーブ面となるグループを作成しておき、マトリクステーブル上で接触対を定義します。

基本

　　　
  • 名前

    接触対の名称を入力します。

    　　　
    • 　　　
  • アルゴリズム

    接触設定対象エンティティを選択します。
        フェース-フェース: フェース対フェース間接触

    　　　
    • 　　　
  • タイプ

    接触定義の挙動タイプを選択します。
        一般接触: 滑り接触
        固着: 固着

    　　　
    • 　　　
  • ペアの選択

    既存グループがマトリクス表示されます。
    対となるグループ位置にあるセルにチェックを入れることで接触対が定義されます。
        スレーブ/マスターの入れ替え: セルを選択後、左列にあるグループに対してマスターもしくはスレーブとなるかを指定
        すべてオン: 全ての接触対を考慮
        すべてオフ: 全ての接触対を解除

    　　　

    • コンタクトプロパティ

    　　　
  • 挙動

    接触判定の有無を定義します。
        外す: 引張り力が発生した場合に接触拘束を外す
        外さない: 初めの接触探索で見つかった全ての接触対を拘束

    　　　
    • 　　　
  • 定式化

    接触定式化タイプを選択します。
        節点-セグメント: 点-面接触
        セグメント-セグメント: 面-面接触

    　　　
    • 　　　
  • 拘束タイプ

    接触拘束タイプを定義します。
        Lagrange: ラグランジュ未定乗数法
        Penalty: ペナルティ法

    　　　
    • 　　　
  • 拘束タイプ(陽解法)

    陽的動解析での接触拘束タイプを定義します。
        Kinematic: コンストレイント法
        Penalty: ペナルティ法

    　　　
    • 　　　
  • ペナルティ比例係数

    ペナルティスケール係数を定義します。

    　　　
    • 　　　
  • ペナルティ比例係数（陽解法）

    陽的動解析でのペナルティスケール係数を定義します。

    　　　
    • 　　　
  • ギャップ検索

    隙間側に対する法線方向探索距離を定義します。

    　　　
    • 　　　
  • 検索深度

    貫通側に対する法線方向探索距離を定義します。

    　　　
    • 　　　
  • 検索幅

    接触面内方向の内外判定用パラメータを定義します。

    　　　
    • 　　　
  • 角度検索

    マスター/スレーブ面の法線ベクトルのなす探索角度を定義します。

    　　　
    • 　　　
  • 初期状態

    初期接触状態の指定します。
        自動: 自動判別
        非接触: 非接触状態から解析開始
        接触: 接触状態から解析

    　　　
    • 　　　
  • 初期状態トレランス

    初期接触状態を判断するトレランス値を入力します。

    　　　
    • 　　　
  • 調整

    隙間および貫通がゼロになるようにスレーブ節点をマスター面上に移動させるか選択します。
        あり: すべてのスレーブ節点を移動
        値: 節点移動を有効とする距離を定義

    　　　
    • 　　　
  • 自動シュリンク

    貫入解消指定の有無を定義します。
        Yes: 貫入解消指定
        No: 貫入解消指定せず

    　　　
    • 　　　
  • すべりタイプ

    すべりタイプを選択します。
        有限すべり: 有限すべり接触
        微小すべり: 微小すべり接触
        すべらない: すべらない接触

    　　　
    • 　　　
  • 間隙量(有限滑りオフ)

    間隙量を定義します。

    　　　
    • 　　　
  • 間隙量の調整(有限滑りオフ)

    調整機能(adjust)による節点移動による要素潰れを回避するかどうか選択します。
        はい: 節点を動かさず間隙量を0.に置き換え
        いいえ: 回避せず

    　　　
    • 　　　
  • 固着タイプ

    固着タイプを選択します。
        剛結合: 剛結合接触
        すべり方向結合: すべり方向結合接触

    　　　
    • 　　　
  • 干渉(有限滑りオン)

    干渉量を定義します。
    正の場合、マスター面が実際よりも内側にあると仮定されます。

    　　　
    • 　　　
  • 干渉への調整(有限滑りオン)

    調整機能(adjust)による節点移動による要素潰れを回避するかどうか選択します。
        Yes: 節点を動かさず、スレーブ節点毎に干渉量を自動設定
        No: 回避せず

    　　　

    • 一般パラメーター

    　　　
  • 摩擦係数

    静摩擦係数を定義します。

    　　　
    • 　　　
  • 運動摩擦係数

    動摩擦係数を定義します。

    　　　
    • 　　　
  • 指数係数

    指数関数減衰係数を定義します。

    　　　
    • 　　　
  • 最大せん断応力

    最大せん断応力を定義します。

    　　　
    • 　　　
  • 弾性滑り

    許容滑り量を定義します。

    　　　
    • 　　　
  • 滑りトレランス

    許容滑りトレランスを定義します。

    　　　
    • 　　　
  • 臨界貫通量

    臨界貫通量を定義します。

    　　　
    • 　　　
  • 衝突時間の予測

    接触対を衝突/剥離時刻の予測に使用するか選択します。
        いいえ: 不使用
        はい: 使用

    　　　

    • 安定化

    　　　
  • タイプ

    接触安定化係数のタイプを選択します。
        剛性: 剛性比例型
        面積: 面積比例型

    　　　
    • 　　　
  • 残留ファクター

    補正係数C1の定義に使用される剰余係数を定義します。

    　　　
    • 　　　
  • 有効距離

    補正係数C2の定義に使用される有効距離を定義します。

    　　　
    • 　　　
  • 法線方向安定化定数

    法線方向安定化定数を定義します。

    　　　
    • 　　　
  • 接線方向安定化係数

    接線方向安定化係数を定義します。

    　　　

    • 色設定

    　　　
  • 接触の色

    接触対表示マーカー色を定義します。
        リセット: デフォルト色に初期化

    　　　
    • 　　　

    熱伝導率

    　　　
  • データタイプ

    間隙量もしくは圧力依存の接触熱伝達係数を定義します。
        Clearance Dependency: 間隙量依存
        Pressure Dependency: 圧力依存
    [入力データ]ボタンを押すと接触設定ダイアログが開き、間隙量依存の熱伝達係数を定義します。
        Clearance: 間隙量
        Pressure: 圧力
        Convection Coefficient: 熱伝達係数

    　　　

    • - 操作手順 -

      　　　
    1. 予めマスター面、スレーブ面となるフェースもしくは要素面グループを作成しておきます。
      2. 　　　
    2. ［ペアの選択］により、接触対とするグループ間のセルにチェックを付け、マスター/スレーブ入替えボタンにより左列グループに対してマスター/スレーブを定義します。
      3. 　　　
    3. 必要により接触対に対する詳細設定を定義し、適用（OK）ボタンをクリックして接触対を定義します。
