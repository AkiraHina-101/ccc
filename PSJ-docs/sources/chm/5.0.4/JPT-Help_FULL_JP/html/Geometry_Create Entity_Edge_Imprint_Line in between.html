2エッジ間ライン

2本のエッジの間に1本以上のエッジを作成します。

オプション

  • ライン数（デフォルト：1、0-100の範囲）

    •    間にあるインプリンティングラインの数。
       選択したフェースに等距離でエッジがインプリントされます。

  • 分割（デフォルト：チェックなし）

    •    新しいインプリンティングラインにより、フェースはより小さな領域に分割されます。

  • 延長（デフォルト：チェックなし）

    •    インプリンティングラインを最も近いラインまで延長します。

    -操作手順-

    1.  エッジボタンを押して、画面上のいくつかのエッジを選択します。 複数のエッジを選択できます。
    2.  フェースボタンを押して、画面上のいくつかのフェースを選択します。 複数のフェースを選択できます。
    3.  行数を指定します。
    4.  必要に応じてオプションを設定します。
    5.  適用/OKボタンをクリックします。
