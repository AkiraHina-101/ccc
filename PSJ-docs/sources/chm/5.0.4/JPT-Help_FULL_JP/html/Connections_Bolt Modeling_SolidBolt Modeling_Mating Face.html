ソリッドボルトモデリング | 合わせ面

あらかじめ作成したソリッドボルトに対して、下記のオペレーションを自動で実行します。
・ソリッドボルトの自動配置
・座面のフェース分割
・解析条件の設定
   SunShin向けプリテンション、接触
ソリッドボルトモデリング > サイズ機能で、ソリッドボルトモデルを作成することができます。
使用するソリッドボルトモデル（*.jth5）は、[ユーザープロファイル]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB に置いてください。
※このフォルダは合わせ面ダイアログ起動時に作成されます。

セレクションリスト
パーツ(ヘッド) 　：ボルトヘッド部のパーツ
パーツ(シャフト)　：ボルトシャフト部のパーツ
エッジ(ヘッド) 　：ボルトヘッド部のエッジ(マニュアル配置)
フェース(シャフト)：ボルトシャフト部のフェース(マニュアル配置)

合わせ面パラメータ

  • 間隙トレランス

    合わせ面の上部パーツと下部パーツ間の隙間トレランスを入力します。この隙間以下の合わせ面のボルト穴が検索されます。

  • 角度トレランス

    上部パーツと下部パーツ間の合わせ面角度トレランス（度）を入力します。合わせ面の平面判定のためのパラメータで、通常は変更する必要ございません。

    • ボルト穴パラメータ

  • プリセットサイズ

    このメニューで選んだボルト穴サイズが、下の最小円範囲、及び最大円範囲に自動で入力されます。
    ボルト穴のプリセットサイズと最小最大のインデックスは「[ユーザープロファイル]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB\Bolt_range_size_chart.xlsx」を参照しています。プリセットサイズを定義する最小最大値を変更したい場合は、このファイルを編集して下さい。

  • 最小円範囲

    検索するボルト穴の最小直径を入力します。

  • 最大円範囲

    検索するボルト穴の最大直径を入力します。

    • 座面パラメータ

  • 半径係数

    フェースを作成するボルト座面の半径係数を入力します。

    • 接触パラメーター

  • コンタクトタイプ

       コンタクトを設定する種類を選択します。

    • 合わせ面 : 滑り接触
    • ボルト穴 : 固着
    • 座面 : 滑り接触

      •
  • 有効化

       機能をアクティブにします。

  • 接触距離範囲(ERROR)

       ノードがボディに接触していると見なされる距離。

  • 摩擦係数(FRIC)

       摩擦係数。

  • 干渉閉鎖距離(CINTERF)

       ソルバーに2つのフェースが接触している判定距離を指示します。

  • 接触面延伸距離(SLIDE)

       接触面延伸距離を入力します。 ICOORD >= 2 でない限り、この入力は行わないでください。
       接触面延伸距離オプションを使用する場合、セグメント上をスライドする節点は、設定値よりも長い距離場合延伸がオフになります。

  • 節点の座標修正（ICOORD)

       なし：このオプションを無視します。

       位置を修正：変形可能なボディと接触している節点の座標を変更して、応力のない初期接触が得られるようにします。

       滑り出し遅れ：変形可能なボディの鋭いコーナーでの接線誤差許容値を拡張して、接触したセグメントからのスライドを遅延させます。

       両方を有効化：位置を修正と滑り出し遅れの両方をアクティブにします。

  • 固着タイプ(JGLUE)

       このオプションは、glueオプションが呼び出された場合（JGLUE > 0）にのみ関係します。

       ノードを分離しない場合は、ブランク状態にします。

       最大残留力に基づいて標準の分離動作を呼び出すには、フルを選択します。

       接着剤の破壊をアクティブにするには、滑り可能を選択します。

  • ペナルティファクタ(SFACT)

       ペナルティスケール係数を定義します。

  • ペナルティファクタ(SFACT T)

       セグメント間の接触解析に使用されるペナルティ係数（剛性）。プログラムは値を計算しますが、ユーザーは値を変更して収束を改善できます。

  • 接触ダンピング(CDAMP)

       ダンピング係数を入力します。

  • シェル要素フェース(スレーブ)

       シェル要素面（スレーブ）には、次のオプションがあります。

        Top＆BtmThk。 オフセット : 上面と下面の両方が接触の説明に含まれ、厚さのオフセットが含まれます。
        Btm w/ Thk。 オフセット : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
        Btm w/o Thk。 オフセット : 接触の説明には底面のみが含まれ、シェルの厚さは無視されます。
        Top w/ Thk。 オフセット : 接触の説明には上面のみが含まれ、厚さのオフセットが含まれます。
        Top w/o Thk。 オフセット : 接触の説明には上面のみが含まれ、シェルの厚さは無視されます。
        Top&Btm w/o Thk。 オフセット : 上面と下面の両方が接触の説明に含まれ、シェルの厚さは無視されます。
  • シェル要素フェース(マスター)

       シェル要素面（マスター）には、次のオプションがあります。

        Top＆BtmThk。 オフセット : 上面と下面の両方が接触の説明に含まれ、厚さのオフセットが含まれます。
        Btm w/ Thk。 オフセット : 接触の説明には底面のみが含まれ、厚さのオフセットが含まれます。
        Btm w/o Thk。 オフセット : 接触の説明には底面のみが含まれ、シェルの厚さは無視されます。
        Top w/ Thk。 オフセット : 接触の説明には上面のみが含まれ、厚さのオフセットが含まれます。
        Top w/o Thk。 オフセット : 接触の説明には上面のみが含まれ、シェルの厚さは無視されます。
        Top&Btm w/o Thk。 オフセット : 上面と下面の両方が接触の説明に含まれ、シェルの厚さは無視されます。

    • 色設定

  • 接触の色

       接触対表示マーカー色を定義します。

        リセット: デフォルト色に初期化

    • 検索結果

  • 虫眼鏡ボタン

    オンにすると、プレビューをフォーカスします。

  • 検索

    ボルトペアの検索を実行します。

  • チェックボックス

    チェックが入っている箇所に、ソリッドボルトの自動配置を行います。

  • マスターパーツ

    ボルトのヘッド部が設定されるパーツを選択します。

  • ボルトタイプ

    ボルトを選択します。
    （使用するソリッドボルトモデル（*.jth5）は、[ユーザープロファイル]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB に置いてください。）

  • プリテンション

    使用するボルトにプリテンション設定がある場合、値を変更できます。現在はSunshineのみサポートしております。

  • ショートカットメニュー

    リスト上で右クリックするとショートカットメニューが表示されます。

        コピー : 各設定の特性セル内容をコピー(Ctrl+c)します。
        貼付け : コピーしたセル内容を他のセルに貼付け(Ctrl+v)します。
        最初に設定 : ボルト番号の1番の場所を任意の場所に変更します。
        逆順 : ボルト番号付けの順番を反転させます
        ポジションソート : ボルト番号の1番の場所を指定します。
        挿入 : 自動検索で検索されなかった場合、手動でリストに追加します。※
        削除 : 選択した項目が削除されます。
        すべてクリアー : リストからすべて削除されます。

  • ※手動での追加方法
    1. ボルトヘッド側に設定されるカーブエッジを選択します。

    2. ボルトシャフト部分のフェースを選択します。コンタクト設定する場合、ここで選択したフェースに設定されます。

    3. 「挿入」で追加します。リストに追加されます。


    - 操作手順 -

    1. あらかじめ、使用するソリッドボルトモデル（*.jth5）は、[ユーザープロファイル]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB に置いてください。
    2. 締結穴パラメータを調整し、ヘッド側のパーツと、シャフト側のパーツをそれぞれ選択リストに選択します。
    3. 必要があれば座面、接触パラメーターを変更します。
    4. 検索ボタンをクリックします。
    5. 検索結果内のリストを確認し、必要があればボルトタイプやプリテンションを変更します。
    6. 適用もしくはOKボタンをクリックします。
