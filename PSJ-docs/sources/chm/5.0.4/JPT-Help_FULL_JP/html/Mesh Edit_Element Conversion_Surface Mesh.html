要素の変換 | サーフェースメッシュ

シェル要素の次数変換および四角形シェル要素の三角形変換を行います。

変換

  • 要素タイプ

       変更後の次数や要素タイプを選択します。

    • 一次(Tri3/Quad4) : 一次要素へ変換します。

    • 二次(Tri6/Quad8) : 二次要素へ変換します。

    • Tri3 : 四角形要素および三角形二次要素を三角形一次要素へ変換します。

    • 中間節点で分割(Tri6→Tri3x4, Quad8→Quad4x4) : 四角形二次要素および三角形二次要素を、中間節点の位置で一時要素に分割します。中間節点の位置は保持されます。
      •

    • - 操作手順 -

    1. 変換後の要素タイプを指定します。
    2. 対象のパーツを選択します。
    3. 適用/OKボタンをクリックします。
