節点移動 | 直線に投影

任意の対象節点を、2つの参照節点で定義される直線上に、最短距離で動かします。
対象節点を参照節点からの検索によって選択することも可能です。


直線に投影

  • 最短距離

       2つの参照節点間の最短経路節点を検索し、対象節点として選択します。

  • 参照節点の方向へ

       2つの参照節点で定義される方向に向かって最短経路節点を検索し、対象節点として選択します。

  • 選択エンティティ上

       選択エンティティ上の節点を検索し、対象節点として選択します。


    • - 操作手順（参照節点間の最短経路節点を動かす場合） -

    1.  投影する直線を定義するための、2節点を選択します。
    2.  対象節点の検索方法より、「最短距離」を選択します。
    3.  「検索」ボタンをクリックします。参照節点間の最短経路節点が選択されます。
    4.  適用/OKボタンをクリックします。

    - 操作手順（参照節点の方向に向かって、参照節点間の最短経路節点を動かす場合） -

    1.  投影する直線と方向を定義するための、2節点を選択します。
    2.  対象節点の検索方法より、「参照節点の方向へ」を選択します。
    3.  「検索」ボタンをクリックします。参照節点間の方向に向かって、最短経路節点が選択されます。
    4.  適用/OKボタンをクリックします。
    ※ここで意図しない節点が選択される場合、追加で参照節点をもう1点選択下さい。3参照節点で定義される平面上へと対象節点を投影します。

    - 操作手順（選択エンティティ上のすべての節点を動かす場合） -

    1.  投影する直線と方向を定義するための、2節点を選択します。
    2.  対象節点の検索方法より、「選択エンティティ上」を選択します。
    3.  エッジ・フェースなど節点を動かしたいエンティティを選択します。
    4.  「検索」ボタンをクリックします。選択エンティティ上のすべての節点が選択されます。
    5.  適用/OKボタンをクリックします。

    - 操作手順（任意の節点を動かす場合） -

    1.  選択リストの「参照節点」をクリックし、投影する直線を定義するための2節点を選択します。
    2.  選択リストの「対象節点」をクリックし、移動する節点または浮遊節点を選択します。（複数選択可）
    3.  適用/OKボタンをクリックします。
