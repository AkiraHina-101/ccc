節点移動 | 任意

座標入力によって節点を移動します。

ポジション

  • 座標系

    •    座標系を指定します。

  • X

    •    X座標を入力します。

  • Y

    •    Y座標を入力します。

  • Z

    •    Z座標を入力します。


    - 操作手順 -

    1.  移動する節点を選択します。
    2.  参照する座標系を指定します。
    3.  移動先の位置を座標で指示します。
    4.  ローカル単位系で移動量の単位を指定します。
    5.  適用またはOKボタンを押します。

      6.   ※X/Y/Z先頭のチェックボックスをオフにすると、オフにした方向への移動を行いません。
        ※X/Y/Zは球座標系指定時にはR/θ/δ、円筒座標系指定時にはR/θ/Zに変更されます。
