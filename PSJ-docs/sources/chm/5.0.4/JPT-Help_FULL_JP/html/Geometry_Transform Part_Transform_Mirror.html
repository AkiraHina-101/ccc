ミラー

選択されたパーツを鏡面対称移動またはコピーします。

操作

  • 新規作成

    •    移動後にパーツをコピーし、新規パーツとします。新規パーツの名称は、
          元パーツ名_Mirror
       となります。

  • LBCコピー

    •    新規パーツに既存パーツに付加した荷重境界条件もコピーします。

  • プロパティコピー

    •    新規パーツに既存パーツに付加したプロパティもコピーします。

  • リファレンス

    •    新規パーツに既存パーツに付加したリファレンスもコピーします。

    ミラー

  • オフセット

    •    鏡面対称面からのオフセット量を入力します。

  • 節点をイクイバランス

    •    チェックすると鏡面対称コピーされたパーツのフェースが、コピー元パーツのフェースと接する場合にその節点を結合します。

  • 節点をイクイバランストレランス

    •    節点結合判定のトレランスを入力します。

  • 重複面を削除

    •    コピー元パーツと重なるフェースを除去します。また鏡面対称位置の1D要素はコピーされません。


    - 操作手順 -

    1.  鏡面対称移動後に新しいパーツを作成する場合には、新しいパーツを作るチェックボックスをオンにします。
    2.  既存パーツの荷重拘束条件を新規パーツにコピーするには境界条件コピーをオンにします。
    3.  パーツ、バーボタンを押し、画面から鏡面対称移動対象のパーツを選択します。
    4.  要素または節点ボタンを押し、画面から鏡面対称面になる要素または3つの節点を選択します。
    5.  オフセットに鏡面対称面からのオフセット量を入力します。
    6.  コピー後の節点を元のパーツとマージするには、節点マージをオンにし、節点マージトレランスに結合判定許容値を入力します。
    7.  コピー後のパーツにコピー元のプロパティ情報をコピーするには、プロパティ情報をコピーをオンにします。
    8.  適用/OKボタンをクリックします。
