スイープ | 線形

作成したサーフェスメッシュ(Tri,Quadメッシュ)からソリッドメッシュを
指定した方向と平行にスイープして作成します。

線形パラメーター

  • 長さ

    スイープする長さを入力します。

  • レイヤー数

    層数を入力します。

  • 方法

    分割方法を選択します。

    • 等分割 : パーツを均等に分割します。
    • 偏向分割 : 指定端から偏向分割。
    • 偏向分割・両端 : パーツの両端が密な偏向分割。
    • 偏向分割・中心 : パーツの中央が密な偏向分割。
      •
  • 偏向係数

    係数を入力します。

  • 数列

    分布方法を選択します。

    • 等比 : 等比(*r)偏向
    • 等差 : 等差(+d)偏向
      •
  • 方向

    スイープする方向を選択します。

    • 平面の法線 : 選択した要素に垂直
    • 任意 : 入力した任意方向のベクトル
    • X,Y,Z : X,Y,Z方向のベクトル
    • 節点-要素エッジ : 基準となるノードと方向を示すエレメントエッジ
    • フェース-フェース : フェース間（Quad4メッシュのパターンは同じである必要があります）
      •
  • X,Y,Z方向

    方向ベクトルX,Y,Z

    • 自動インターフェース Penta5/Tet4

  • インターフェース要素

    チェックすると境界面にペンタ要素を作成します。

    • 元の形状を自動消去

  • スイープ元の形状を消去

    チェックを入れると、自動で元（スイープ元）の形状を削除します。

  • スイープ先の形状を消去 （方向/フェース-フェース時）

    チェックと入れると、自動でスイープ先の形状を削除します。

    ※2次要素が含まれるエンティティを選択し実行した場合は、ワーニングが表示されます。
    1次要素に変換し実行します。



    • - 操作手順 -

    1. スイープする面を選択します。
    2. スイープする長さを指定します。
    3. 層数を指定します。
    4. スイープする方向を指定します。
    5. 適用もしくはOKボタンをクリックします。
