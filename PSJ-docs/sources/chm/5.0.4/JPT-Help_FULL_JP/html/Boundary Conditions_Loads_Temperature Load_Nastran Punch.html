Nastran Punch

Nastran Punch形式で出力された温度結果を 読み込み、温度荷重として定義します。
※伝熱解析モデルと構造解析モデルは一致している必要があります。
　また、ソルバーはNastranにのみ対応しております。

名前

　　
  • 名前

    温度荷重名を設定します。

    　　　

    • 値

    　　
  • ブラウズ

    温度結果ファイルを検索し選択します。

    　　　
    • 　　
  • 材料参照温度として使用

    チェックをすると、設定した温度情報を温度依存性材料の参照温度して使用します。

    　　　
    • 　　
  • 入力単位系

    入力単位系を指定します。

    　　　

    • - 操作手順 -

      　　　
    1. 温度荷重を負荷するパーツを選択します。複数の選択が可能です。
      2. 　　　
    2. ブラウズボタンを押して、温度荷重ファイルを検索し、選択します。
      3. 　　　
    3. 必要に応じてその他のパラメータを変更します。
      4. 　　　
    4. 適用またはOKボタンをクリックします。
