3Dプロパティ | ソリッド

3D プロパティ | ソリッドダイアログボックス

3次元ソリッド要素のプロパティデータを入力します。

プロパティ

　　
  • 名前

    プロパティの名前を入力します。

    　　　
    • 　　
  • プロパティID

    プロパティのIDを入力します。プロパティIDはモデル内で重複しないようにします。

    　　　
    • 　　
  • 色

    プロパティの色を入力します。

    　　　

    • ソリッド

    ソリッド要素の基本プロパティデータを選択します。

  • 材料

    あらかじめ定義された材料特性を選択します。

  • 材料座標系ID

    材料座標系を選択します。

    • Global

      材料座標系に全体座標系を選択します。

    • Element CS

      材料座標系に要素座標系を選択します。

    • NASTRAN

    Nastranソルバーに関連した設定を行います。

  • 積分ネットワーク

    積分ネットワーク

    • TWO

      2次関数を用います。

    • THREE

      3次関数を用います。

    • BUBBLE

      BUBBLE関数を用います。

  • 出力位置

    応力出力位置

    • GAUSS

      ガウスポイントで応力の出力をします。

    • GRID

      節点での出力をします。

  • 積算スキーマ

    積分手法

    • REDUCED

      次数低減せん断積分を用います。

    • FULL

      標準アイソパラメトリック積分を用います。

  • 流体要素フラグ

    流体要素フラグ

    • PFLUID

      流体要素を用います。

    • SMECH

      構造要素を用います。

    • ABAQUS

    ABAQUSソルバーに関連した設定を行います。

    　　
  • ハイブリッド

    ハイブリッド要素を使用する場合に使用します。

    　　　
    • 　　
  • 非互換

    非適合要素を使用する場合に使用します。

    　　　
    • 　　
  • 修正済み

    修正要素を使用する場合に使用します。

    　　　
    • 　　
  • 低減積分

    縮退積分要素を使用する場合に使用します。

    　　　
    • 　　
  • 温度-変位連成

    熱構造連成解析用の要素を使用する場合に使用します。

    　　　
    • 　　
  • 音響

    音響要素を使用する場合に使用します。

    　　　
    • 　　
  • 設定...

    追加のABAQUS用設定を入力する場合に用います。
    ABAQUS設定ダイアログボックスが開きます。

    要素コントロール
    アワーグラスコントロール:
    • デフォルトを使用

      デフォルト設定を用います。

    • 拡張

      強化型設定を用います。

    • 剛性

      剛性設定を用います。

    • 変位アワーグラス

      変位アワーグラススケーリングファクターを入力します。

    　　　

    • ADVC

    Advencture Clusterソルバーに関連した設定を行います。

    　　
  • 非互換

    非適合要素を使用する場合に使用します。

    　　　
    • 　　
  • 修正済み

    修正要素を使用する場合に使用します。

    　　　
    • 　　
  • 低減積分

    縮退積分要素を使用する場合に使用します。

    　　　

    • LS-Dyna

    LS-Dynaソルバーに関連した設定を行います。

    　　
  • アダプティブメッシュ

    Dynaアダプティブメッシュを用います。

    　　　
    • 　　
  • リメッシュ: 最小エッジ長さ

    最小エッジ長

    　　　
    • 　　
  • リメッシュ: 最大エッジ長さ

    最大エッジ長

    　　　

    • - 操作手順 -

      　　　
    1. 名前にプロパティの名前を入力します。
      2. 　　　
    2. プロパティIDにプロパティIDを入力します。
      3. 　　　
    3. 材料プルダウンメニューからすでに登録された材料情報を選択します。
      4. 　　　
    4. 必要に応じて他のパラメータも入力します。
      5. 　　　
    5. 対象パーツを選択します。
      6. 　　　
    6. 適用またはOKボタンをクリックしてプロパティを作成します。
