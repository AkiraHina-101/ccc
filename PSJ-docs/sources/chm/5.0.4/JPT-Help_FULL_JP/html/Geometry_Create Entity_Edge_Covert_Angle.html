角度

選択した要素エッジから指定角度以内で隣合う要素エッジを自動で選択しエッジに変更します。
プレビューを確認しながら、追加して要素エッジを選択することで自動選択の方向を変えることができます。

オプション

  • 面を分割

    チェックを入れると、エッジを作成後にフェースが分割可能であれば分割します。

  • 角度

    角度を指定します。

  • 曲率モード

    2つの要素エッジから角度を計算し、円状に要素エッジを自動選択します。

  • 要素エッジ

    選択した要素エッジが表示されます。

    • - 操作手順 -

    1. 要素エッジを選択します。
    2. 適用/OKボタンをクリックします。
