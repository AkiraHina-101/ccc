トレース｜関連要素

ノードに関連したすべての要素やコネクションを検索し、それを表示します。接続した要素やConnectionを確認することが出来ます。

パーツトレース

  • レイヤを増やす

    •    選択したエンティティのノードに関連したエンティティが表示されます。

  • レイヤを減らす

    •     現在表示しているエンティティの表示を減らします。

    リセット

  • リセット

       現在の表示を通常の表示にリセットします。


    • - 操作手順 -

    1.  Selection listにて、エンティティを選択します。
    2.  増やすボタンもしくは、適用ボタンより、選択したエンティティとそのエンティティのノードに関連したエンティティが表示します。
    3.  増やすボタンもしくは、適用ボタンより、現在表示のエンティティとそのエンティティのノードに関連したエンティティが表示します。
    4.  増やすボタンもしくは、減らすボタンより、レイヤ表示します。
    5.  リセットボタンより、通常の表示に戻ります。
