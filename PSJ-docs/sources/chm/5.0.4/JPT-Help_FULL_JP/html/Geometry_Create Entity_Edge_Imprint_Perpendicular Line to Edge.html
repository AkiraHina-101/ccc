エッジへ垂線を作成

選択したノードから選択したエッジに垂直なエッジを、選択したフェース上に作成します。

オプション

  • 面を分割

    •    フェースを分割します。

  • 延長

    •    オフセットされたエッジを、境界エッジまで延長します。

  • 自動

    •    面を選択すると、角度オプションが有効になります。 2本の線の間の角度です。 入力値以上の場合は、その間のノード（およびその反対側のエッジ）が選択されます。


    - 操作手順 -

    1.  フェースボタンを押し、インプリント対象のフェースを画面より選択します。複数のフェース選択が可能です。
    2.  エッジボタンを押し、垂線を下ろす先のエッジを画面より選択します。
    3.  節点ボタンを押し、インプリント線の開始点を画面より選択します。
    4.  必要に応じて面を分割チェックボックスをオフにします。この場合はインプリント後のフェースが元のフェースから分割されません。
    5.  必要に応じて延長チェックボックスをオフにします。この場合はインプリントされるエッジが選択時の節点・エッジ間のみ作成されます。
    6.  適用/OKボタンをクリックします。
