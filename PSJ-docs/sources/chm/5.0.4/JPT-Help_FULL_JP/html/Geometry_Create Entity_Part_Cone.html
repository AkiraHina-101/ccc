円錐体

円錐体を作成します。

パーツプロパティ

  • パーツ名

    作成する円錐体の名前を入力します。

    • コーン

  • ローカル座標系

    任意の座標系を選択します。

  • 円錐台

    チェックを入れると、円錐先端部に平面を作ります。

  • 原点-X,Y,Z

    原点座標を指定します。

  • 上面半径

    円錐台にチェックを入れた場合に、先端部分の平面の半径を指定します。

  • 底面半径

    底面の半径を入力します。

  • 高さ

    円錐体の高さを入力します。

  • 円内の節点数

    円弧上に生成する節点数を入力します。

  • 節点数-軸

    円錐の軸方向の分割数を入力します。

    • - 操作手順 -

    1. パーツ名にパーツ名を入力します。
    2. 原点-X,Y,Zに原点座標を指定します。
    3. 底面半径 に底面の半径を入力します。
    4. 高さ に円錐体の高さを入力します。
    5. 円内の節点数に円弧上に生成する節点数を入力します。
    6. 節点数-軸に円錐の軸方向の分割数を入力します。
    7. 適用/OKボタンをクリックします。
