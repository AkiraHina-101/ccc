ソリッドボルトモデリング（エッジ）

ボルト穴上下のエッジを選択し、入力した寸法パラメーターに沿って選択したエッジ間に、ヘキサ要素で構成されたソリッドボルトを作成します。
プリテンション荷重のチェックボックスにチェックを入れプリテンション設定を付加できます。


ソリッドボルトモデリング

  • ソリッドボルト名

    作成するソリッドボルトの名前を入力します。

  • ボルトイメージを表示

    ソリッドボルト作成概要図を表示します。作成するボルトタイプの変更が可能です。

  • ボルト穴最大長さ

    ボルト穴の最大長さを指定します。

    • プリテンション荷重

  • ソルバー

       プリテンションの設定タイプを選択します。

    • All : 一般的なプリテンションを設定します。

    • Abaqus : Abaqus用のプリテンションを設定します。
      •
  • 値

    プリテンション力を入力します。

  • 入力単位系

    入力単位系を選択します。

  • 方向

    プリテンションの方向を選択します。（ソルバー：All）

  • 座標系

    プリテンション力の方向を決める座標系を選択します。（ソルバー：All）

  • ボルト固定長

    チェックを入れた場合に、ボルトの締め付け量を保持します。

    • トップエッジ

  • ねじ呼び径

    ねじ呼び径（直径）を入力します。

  • ボルト頭部対角距離

    ボルト頭部対角距離を入力します。

  • ボルト頭部高さ

    ボルト頭部高さを入力します。

  • 首下長さ

    首下長さを入力します。

  • ねじ部長さ

    ねじ部長さを入力します。

  • ボルト頭部高さ方向メッシュ分割数

    ボルト頭部外周半径方向のメッシュ分割数を入力します。

    - 機能実行例 -

  • プリテンション荷重オプション無し

    ねじ切り部に接触設定が行えるようにパーツが分かれます。
    パーツ間断面は節点共有されます。


  • プリテンション荷重オプション付き（ソルバー：All）

    ボルト中間位置（ねじ切り部除外）でパーツ分けし、プリテンション荷重をパーツ間断面に設定します。
    上項同様に、ねじ切り部も接触設定向けにパーツが分かれます。


  • プリテンション荷重オプション付き（ソルバー：Abaqus）

    ボルト中間位置（ねじ切り部除外）にパーティションを作成し、プリテンション荷重を設定します。
    上項同様に、ねじ切り部も接触設定向けにパーツが分かれます。


    • - 操作手順 -

    1. 作成するソリッドボルトの名前を入力します。
    2. 必要に応じボルト穴の最大長さを指定します。
    3. ソリッドボルトの寸法パラメーターを入力します。
    4. 選択リストウインドウを開きます。
    5. 上面エッジボタンをクリックし、上部パーツのボルト穴エッジ（上端）を選択します。（複数選択可能）
    6. 底面エッジボタンをクリックし、下部パーツのボルト穴エッジ（下端）を選択します。（複数選択可能）
    7. 適用またはOKボタンをクリックします。

    - 操作手順（プリテンション荷重オプション付き） -

    1. 作成するソリッドボルトの名前を入力します。
    2. 必要に応じボルト穴の最大長さを指定します。
    3. プリテンション荷重のチェックボックスにチェックを入れます。
    4. ソルバーからプリテンション設定タイプを指定します。
    5. プリテンション力の入力と必要に応じ他パラメーターを指定します。
    6. ソリッドボルトの寸法パラメーターを入力します。
    7. 選択リストウインドウを開きます。
    8. 上面エッジボタンをクリックし、上部パーツのボルト穴エッジ（上端）を選択します。（複数選択可能）
    9. 底面エッジボタンをクリックし、下部パーツのボルト穴エッジ（下端）を選択します。（複数選択可能）
    10. 適用またはOKボタンをクリックします。
