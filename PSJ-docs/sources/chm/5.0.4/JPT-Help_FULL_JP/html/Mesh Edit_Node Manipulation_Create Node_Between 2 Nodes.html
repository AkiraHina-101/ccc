2節点の中点

選択した2つの節点間に節点を追加します。

プロパティ

  • 節点番号

    •    節点番号を入力します。

  • X

    •    選択した2点の中間位置のX座標が表示されます。

  • Y

    •    選択した2点の中間位置のY座標が表示されます。

  • Z

    •    選択した2点の中間位置のZ座標が表示されます。

  • 節点数

    •    作成する節点数を指定します。

  • インプリント

    •    パーツ上に節点を作成します。


    - 操作手順 -

    1.  節点を2つ選択します。  ※(インプリントする場合)節点を2つ&フェースを選択します。
    2.  節点番号を指定します。
    3.  節点数を指定します。
    4.  適用またはOKボタンを押します。
