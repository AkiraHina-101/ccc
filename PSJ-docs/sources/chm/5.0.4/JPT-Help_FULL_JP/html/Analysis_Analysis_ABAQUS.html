      これは下部構造解析用です。 モデルに自由度定義がある場合にのみ有効です。

      ソルバータイプ  : ソルバータイプを選択します: EXCITE/ADAMS/GENERIC/SID/SIMPACK。
      ライブラリー  : 下部構造ライブラリの入力名。
      上書きする : ライブラリ内の同じTYPE識別子で既存のサブ構造を上書きします (デフォルト = NO)。
      縮退マトリクス : 縮小行列を計算する。
      質量 : 下部構造の換算質量行列を計算します (デフォルト = NO)。
      粘性減衰 : 下部構造の低減された粘性減衰行列を計算します (デフォルト = NO)。
      構造減衰 : 下部構造の縮小構造減衰行列を計算します (デフォルト = NO)。
      リカバリーマトリクス  : 下部構造の任意の自由度の解を回復できます。
      デフォルト = YES, 除去された変数の回復がほとんどの分析手順で可能であることを示します。
      セット = NO, 要素または節点情報の出力がこの下部構造内で使用できないことを指定する。
      モデルデータ  :
      モデルデータ = ODB (デフォルト), 復元された結果に関連する下部構造モデルデータファイルの生成。
      モデルデータ = NONE, 下部構造モデルデータファイルの生成を抑制する。
      自由度定義 : 保持された自由度定義する　(All/特定)。
      ソート後 : 下部構造を使用するかどうかに関係なく、ノードの順序を並べ替えます。
      保持固有モード指定 : このオプションは、使用するモードを選択し、一意のモードのリストを生成します。 （デフォルトの増分= 1）。
