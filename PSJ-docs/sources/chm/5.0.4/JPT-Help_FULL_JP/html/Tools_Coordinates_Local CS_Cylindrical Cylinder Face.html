ローカル座標系[円筒面]

選択した円筒面の中心軸に沿って座標系を作成します。

　　

座標系

  • タイプ

       座標系のタイプを選択します。

    • 直交 : 直交座標系を選択します。
    • 円筒 : 円筒座標系を選択します。
    • 球 : 球座標系を選択します。

  • 名前

       作成する座標系の名前を入力します。


    • - 操作手順 -

    1.  タイプから座標系の種類を選択します。
    2.  名前に作成する座標系の名前を入力します。
    3.  フェースを選択します。円筒面の軸が座標系のZ軸になります。
    4.  適用またはOKボタンを押します。
