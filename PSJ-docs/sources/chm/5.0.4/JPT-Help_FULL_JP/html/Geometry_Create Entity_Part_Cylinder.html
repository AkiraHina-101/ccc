円筒体

円筒体を作成します。

パーツプロパティ

  • パーツ名

    作成する円筒体の名前を入力します。

    • 円筒

  • ローカル座標系

    任意の座標系を選択します。

  • 中空円筒

    チェックを入れると、中空形状を作成します。

  • テーパー

    チェックを入れると、テーパーの付いた中実形状の円筒形状を作成します。

  • 原点-X,Y,Z

    原点座標を指定します。

  • 内側半径

    円筒体の内側の半径を入力します。

  • 外側半径

    円筒体の外側の半径を入力します。

  • 内側半径2

    円筒体の下側の内側半径を入力します。（テーパー時のみ）

  • 外側半径2

    円筒体の下側の外側半径を入力します。（テーパー時のみ）

  • 高さ

    円筒体の高さを入力します。

  • 円内の節点数

    円弧上に生成する節点数を入力します。

  • 節点数-軸

    円筒の軸方向の分割数を入力します。

    • - 操作手順 -

    1. パーツ名にパーツ名を入力します。
    2. 原点-X,Y,Zに原点座標を指定します。
    3. 外側半径 に円筒体の半径を入力します。
    4. 高さ に円筒体の高さを入力します。
    5. 円内の節点数 に円弧上に生成する節点数を入力します。
    6. 節点数-軸に円筒軸方向の分割数を入力します。
    7. 適用/OKボタンをクリックします。
