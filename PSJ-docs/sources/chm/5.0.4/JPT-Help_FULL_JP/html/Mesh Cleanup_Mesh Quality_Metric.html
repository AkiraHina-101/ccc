      • value = R × 2√3 / maxSide
    • テトラ
      • value = (6√6 × V) / ( S× maxSide)
    • ヘキサ
      • value = (minLen / maxLen) × √3

             R             :  内接円半径
             maxSide  :  最大要素エッジ長
             minSide   :  最小要素エッジ長
             V             :  要素体積
             S             :  要素表面積

    ② アスペクト 比

  • 三角形/四角形/テトラ/ヘキサ要素に対して、以下の算出式によって求まる値をチェックします。
    • 三角形

       value = ( √3 × maxSide2) / (4 × Area)

    • 四角形
       value = maxMidLen / minMidLen
    • テトラ
       value = (S × maxSide) / (6√6 × V)
    • ヘキサ
       value = maxLen / minLen

             maxSide      :  最大要素エッジ長
             面積            :  要素面積
             maxMidLen  :  最大対辺中点間距離
             minMidLen   :  最小対辺中点間距離
             S                 :  要素表面積
             V                 :  要素体積



    ③ エッジの長さ

  • 三角形/四角形/テトラ/ヘキサ要素に対して、要素エッジ長をチェックします


    • ④ 面積

  • 三角形/四角形要素に対して、要素面積をチェックします。


    • ⑤ 接点接続数

  • 三角形/四角形要素に対して、一つの節点に対して、その節点を含む要素の数をチェックします。


    • ⑥ 内部角度

  • 節点周りの要素エッジ間角度の中で最も小さい値をチェックします。


    • ⑦ 三角形高さ

  • 四面体要素に対して、要素内の各三角形の面の高さを確認します。


    • ⑧ 節点 FreeEdges

  • 三角形/四角形要素に対して、一つの節点につながっているフリーエッジの数をチェックします。


    • ⑨ 重複要素

  • 三角形/四角形要素に対して、重複要素の数をチェックします。


    • ⑩ ワーピング

  • 四角形要素に対して、四角形要素を2つの三角形に分け、その間に生じる角度の最大値をチェックします。

    •    value = MAX (Angl , Ang 2)



    ⑪ スキュウネス

  • 四角形要素に対して、対辺の中点を結んだ2つの線のなす角度をチェックします。


    • ⑫ テーパー

  • 四角形要素に対して、四角形要素内の3節点を結んだ三角形面積の平均値との最大差分をチェックします。

    •    value = MAX (aRatio i)    i = 1~4
       aRatio i = ABS {( triArea i - triAreaAvg) / triAreaAvg}
       triAreaAvg = (triArea1 + triArea2 + triArea3 + triArea4) / 4

             triArea i  :  Tri i の面積
             Tri1        :  Node1, 2, 3からなる三角形
             Tri2        :  Node3, 4, 1からなる三角形
             Tri3        :  Node2, 3, 4からなる三角形
             Tri4        :  Node4, 1, 2からなる三角形



    ⑬ 体積

  • テトラ/ヘキサ要素に対して、要素体積をチェックします。


    • ⑭ ヤコビアンファクター

  • テトラ要素に対して、以下の算出式によって求まる値をチェックします。
       中間節点が頂点を結ぶ線上にある場合、Jacob.Factorは1になります。

    •    value = minJacDet / V

             minJacDet  :  各節点でのヤコビアン行列式の最小値
             V               :  要素体積



    ⑮ テットコラプス

  • テトラ要素に対して、以下の算出式によって求まる値をチェックします。

    •    value = MIN ( h i / maxSide i )    i = 1~4

             h i             :  i 番目の頂点から対向する面までの高さ
             maxSide i  :  i 番目の頂点に対向する面の最大要素エッジ長



    ⑯ テットスキュー

  • テトラ要素に対して、要素外接球半径から求まる正四面体の体積と要素体積の差分割合をチェックします。

    •    value = ( Vr - V ) / Vr
          Vr   =  8× R3 / 9√3

             V        :  要素体積
             R        :  外接球半径



    ⑰ 不安定要素 (テトラ/ヘキサおよび三角形＋四角形)

  • 隣接する要素と接続する(コーナー)節点数をチェックします。 剛体運動が発生するような1(2)点接続の要素を検出するのに使用します。
       (ソリッド要素に関しては、検出後サーフェスモデルでの修正が推奨されます。)


    • ⑱ 時間間隔(LS-DYNA) (テトラ/ヘキサおよび三角形＋四角形)

  • 三角形/四角形要素に対して、クーラン条件におけるΔtcをLS-DYNAの算式で確認します。閾値となる時間増分Δtは「安全率x設定値」で計算されます。

    •   Δtc＝Lc/c
      Lc = S/MAX(Lside)
      c = √(E/(ρ(1-ν²)))

             Lc    : 要素の代表長さ
             Lside   :  要素エッジ長
             S   :  要素表面積
             c   :  応力伝播速度
             E   :  ヤング率
             ρ   :  密度
             ν   :  ポアソン比
  • 他の計測方法にはないGUI項目の説明をします。

    •   安全率            :  Δt = 安全率 x 設定値
      応力伝搬速度   :  材料を選択すると、その材料の応力伝搬速度を確認できます。



    ⑲ 時間間隔(Abaqus) (テトラ/ヘキサおよび三角形＋四角形)

  • 三角形/四角形/テトラ/ヘキサ要素に対して、クーラン条件におけるΔtcをAbaqusの算式で確認します。閾値となる時間増分Δtは「安全率x設定値」で計算されます。

    •   Δtc＝lc/c
      L1 = S/MAX(Ldiag)    : 三角形/四角形要素の場合
      L2 = MIN(Lside,Ldiag)    : 三角形/四角形要素の場合
      Lc = MAX(L1,L2)    : 三角形/四角形要素の場合
      Lc = 0.816MIN(Lside)    : テトラ１次要素の場合
      Lc = 0.264MIN(Lside)    : テトラ２次要素の場合
      Lc = V/MAX(S)    : ヘキサ要素の場合
      c = √(E/(ρ(1-ν²)))    : 三角形/四角形要素の場合
      c = √(E(1-ν)/(ρ(1+ν)(1-2ν)))    : テトラ/ヘキサ要素の場合

             Lc    : 要素の代表長さ
             Lside   :  要素エッジ長
             Ldiag   :  要素対角線長
             S   :  要素表面積
             V   :  要素体積
             c   :  応力伝播速度
             E   :  ヤング率
             ρ   :  密度
             ν   :  ポアソン比
  • 他の計測方法にはないGUI項目の説明をします。

    •   安全率            :  Δt = 安全率 x 設定値
      対角線を含める :  ONの場合、要素の代表長さの計算で要素対角線長を含めます。
      応力伝搬速度   :  材料を選択すると、その材料の応力伝搬速度を確認できます。
