接続 | 剛体要素　中心-すべてのエンティティ間

一対多（マスター：スレーブ）のRBE2（剛体要素）を作成する機能です。
＊スレーブ節点は、パーツ単位、フェース単位、エッジ単位、要素単位、節点単位での選択が可能です。

マスター節点と（接続範囲内の）スレーブ節点が接続されます。 マスター節点は、選択したスレーブ節点の平均座標または任意座標に作成されます。
モデル外の位置にマスター節点を定義したい場合に、便利な機能です。

接続

  • 名前

    登録される名前を入力します。

    • 検索範囲

  • すべて

    接続範囲を無限として指定します。

  • トレランス

    接続範囲の半径Rを入力します。

    • マスター節点の位置

  • X Y Z

    マスター節点の座標が表示されます。
    スレーブに選択されている節点の平均座標が自動設定されます。任意座標に編集することもできます。

  • 最後に選択したエッジの中心に座標を更新

    マスター節点の座標を、最後に選択したエッジの中心位置にします。
    該当エッジが曲線の場合は曲線の平均中心座標に、直線の場合は節点の平均座標になります。
    例えば、ボルト（円や円筒形状）の座面中心をマスターにできます。

    • 参照自由度

  • UX - RZ

    従属自由度の成分を指定します。

    • 解析座標系

  • 座標系

    参照座標系を選択します。

    • Abaqus

  • サーフェース定義出力

    面の定義方法を選択します。

    • 節点セット

      基準面として節点を指定します。

    • 要素セット

      基準面として要素を指定します。スレーブに要素を構成できないエンティティ（節点、エッジ）を選択していると、エラーが出力されます。

    • オプション

  • 主節点のみ接続

    選択したエンティティの主節点（コーナー節点）のみに接続します。

    • - 操作手順 -

    1. 接続範囲を設定します。
    2. スレーブ候補の節点を、パーツ、フェース、エッジ、要素、節点から選択します。
    3. 必要に応じて、マスター節点の座標を任意座標に編集します。
    4. パラメータを設定します。
    5. 適用/OKボタンをクリックします。
