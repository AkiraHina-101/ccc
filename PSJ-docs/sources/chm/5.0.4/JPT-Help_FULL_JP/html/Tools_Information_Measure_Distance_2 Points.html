2 点

2つのPoint間の距離を計測します。

オプション

  • 座標系

       投影先座標系を選択します。

    • 出力

  • 距離

       計測結果が表示されます。

  • デルタ X

       基本座標系におけるX距離

  • デルタ Y

       基本座標系におけるY距離

  • デルタ Z

       基本座標系におけるZ距離

  • 入力単位系

       表示する距離の単位を指示します。


    • - 操作手順 -

    1.  画面上から２点を選択します。
    2.  値に距離、デルタに座標系軸方向距離が表示されます。
