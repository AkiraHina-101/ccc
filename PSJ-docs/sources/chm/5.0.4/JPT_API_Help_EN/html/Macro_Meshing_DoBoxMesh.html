DoBoxMesh

Description

Box Mesh

Syntax

DoBoxMesh(double size, Cursor[] body, bool keep_reference)

Inputs

  1. double

    mesh size

  2. Cursor[]

    body list

  3. bool

    keep reference data 0=No 1=Yes

Return Code

  • 1

    Succeeded

  • 0

    Failed

    • Sample Code

    DoBoxMesh(0.005, [3:1], 1)
