PageCtrl

Create a group of page items (wizard).



   Creation image：


    ※PageCtrl is used as a set of PageItem.


  • Name

       Enter the PageCtrl component.

  • Show Header

       Specify the display of the Text (header) of the PageItem.

    • Check On : Display the header.
    • Check Off : Does not display the header.
      •
  • Default Page

       Specify the page to be displayed by default.
       ※　The number to be entered starts at zero.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
