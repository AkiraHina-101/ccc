Button

Add a button.



   Creation image：



  • Text

       Enter the text that appears next to the button.

  • Name

       Enter the Button component name.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）

  • Width

       Specifies the minimum width of the box. (Unit: pixels)

  • Height

       Specifies the minimum height of the box. (Unit: pixels)
