ComboBox

Add a combo box.



   Creation image：



  • Name

       Enter the name of the combo box component.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Width

       Specifies the minimum width of the combo box. (Units: pixels)

  • Height

       Specifies the minimum height of the combo box.(Units: pixels)

  • Source File

       Enter options from a text file.

       Structure of the Source File：

        Option1
        Option2
        Option3
        Option4
        Option5
         ↓
        Input result：



  • Option Count

       Specify the number of items to be selected.

  • Options *

       Enter the name of the item.

    • Command to use

    CommandDescriptionSample Code
    dlg.get_combobox_sel("name") Get the position of the item selected in the combo box.

    ComboBox = ["1", "2", "3", "4", "5"]
    When "4" is selected

    Input:

    a = dlg.get_combobox_sel("ComboBox")

    Output:

    > a = 3
    dlg.get_len_combobox("name") Get the length of the combo box.

    listbox = ["1", "2", "3", "4", "5"]

    Input:

    a = dlg.get_len_combobox("ComboBox”)

    Output:

    > a = 5
    dlg.set_combobox_sel(“Name”, Index) Switches the value selected in the combo box.

    ComboBox = [“1”, “2”, “3”, “4”, “5”]

    Input:

    dlg.set_combobox_sel(“ComboBox”, 3)

    ⇒ Selected value=”4”
    dlg.insert_combobox_option("name", position, "text") A value is added from the position selected in the combo box (1 value once).

    Input:

    dlg.insert_combobox_option("name", 1, "text")
    dlg.insert_combobox_options("name", position, [itemlist]) A value is added from the position selected in the combo box (multiple values once).

    Input:

    dlg.insert_combobox_options("name", 3, [Itemlist])
