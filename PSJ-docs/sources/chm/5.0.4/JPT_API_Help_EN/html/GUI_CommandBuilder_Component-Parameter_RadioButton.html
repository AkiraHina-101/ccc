RadioButton

Add a radio button.



   Creation image:



  • Text

       Enter the text that appears next to the radio button.

  • Name

       Enter the name of the RadioButton component.

  • Checked

       Specify the default value.

    • True : Check On
    • False : Check Off
      •
  • Width

       Specifies the minimum width of the combo box. (Units: pixels)

  • Height

       Specifies the minimum height of the combo box. (Units: pixels)

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Left Text

       Display the text to the left of the radio button.

  • Group

       The nearby Radio Button components are in one group.

    • Command to use

    CommandDescriptionSample Code
    dlg.isbutton_checked("component name") Check whether the radio button is checked or not.
    Returns a Boolean value (True/False).

    Input:

    dlg.isbutton_checked("CheckBoxButton")

    Output:

    > True/False
    dlg.set_radiobutton_state("name", Bool) Specify the radio button status (checked or unchecked).

    Input:

    dlg.set_radiobutton_state("CheckBox1", True)
