Table

Add a table.



   Creation image：



  • Name

       Enter the Table component.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Show Grid Line

       Specify the display of the grid line.

    • Check On : Displays a grid line
    • Check Off : Does not display the grid line
      •
  • Show Row Number

       Specify the display of the line number.

    • Check On : Displays the line number
    • Check Off : Does not display the line number
      •
  • Width

       Specifies the minimum width of the table.（Unit: Pixels）

  • Height

       Specifies the minimum height of the table.（Unit: Pixels）

  • Pop Menu Options

       Specify the menu of right click.

       Supported Options：
       Cut, Copy, Paste, Insert Row, Delete Row, Clear Content, Read From File, Write To File

  • Total Rows Count

       Specifies the default display of the number of lines.

  • Column Setting

       Specify the type of the column.
       Heading*：Specify the type of column to be specified.

    • Command to use

    CommandDescriptionSample Code
    dlg.set_cell_value("table name", "(cell_row_id, cell_column_id)", "value") Set the value to the row/column of the specified index.

    Input:

    dlg.set_cell_value("table name", "(1, 1)", "value")
    dlg.get_cell_value("table name", "(cell_row_id, cell_column_id)") Gets the value of the specified index row/column.

    Input:

    dlg.get_cell_value("table name", "(1,1)")
    dlg.get_total_row("table name") Gets the total number of rows in the table.

    Input:

    dlg.get_total_row("table name")
    dlg.get_total_column("table name") Gets the total number of columns in the table.

    Input:

    dlg.get_total_column("table name")
