DEdge

Description

Edge item class.

Properties

AttributeDescription
typeID

Item type ID (=5). The DItemType.

#Get the integer value of Entity ItemType. The return value is int(DItemw::GetItemTypeInt).
key

The internal ID of the item. Unique ID within each TypeID.

Cannot be changed by the user.

#Get the internal Key of Entity, the return value is Id (int).
id

The external ID of the item.

It can be duplicated within each TypeID, but it is not recommended.

Some entity IDs can be changed with the renumber function.

#Get the external ID of Entity, the return value is Id (int).
name

The name of the item.
elems

Element contained in the item (array of ElemVector class).

#Get the element information set in Edge. Return value DElemW array.
nodes

Nodes included in the item (Array of NodeVector class).

#Get the node information set in Edge. The return value is a DNodeW array.
color

Item color information.
