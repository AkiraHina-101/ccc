Open File/Folder

This is a component for linking File and Folder.



   Creation image：



  • Name

       Open Enter the File/Folder component name.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Mode

       Specify the selection mode.

    • File : Only the file type can be selected.
    • Folder : Only the Folder type can be selected.
      •
  • Default

       The default value (File/Folder) link to display.

  • Filter

       Enter the File type you can choose.

       Filter format：

        Description 1 (Extension 1, Extension 2, …), Description 2 (Extension 1, Extension 2, …), …

  • Allow Multiple Selection

       Multiple items can be selected.

    • Check On : Multiple selections available
    • Check Off : Can not select multiple
