TextBox

Add a text box.



   Creation image：



  • Default

       Enter the text that is entered by default.

  • Align

       Specify the display position of the text.

    • Left : Left alignment
    • Right : Right align
    • Center : Align in the center
      •
  • ReadOnly
    • Check On : Text cannot be edited. (Copying is possible.)
    • Check Off : You can edit the text.
      •
  • Name

       Enter the name of the text box component.

  • Width

       Specifies the minimum width of the text box. (Units: pixels)

  • Height

       Enter the minimum height of the text box. (Units: pixels)

  • Type

       Specify the data type that can be entered into the text box.

  • Type

       Specify the data type that can be entered into the text box.

    • String :  string type
    • Double : double precision floating point number type
    • Integer : integer type
      •
  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •

    • Command to use

    CommandDescriptionSample Code
    dlg.set_item_text("component name","text") Specifies the text of the selected component.

    Input:

    dlg.set_item_text("Item", "text")
    dlg.get_item_text("component name") Gets the text information of the selected component.

    Input:

    dlg.get_item_text("TextBox")
