TabItem

Create a tab page under the tab component.



   Creation image：


    ※TabItem is used as a set with TabCtrl.


  • Name

       Enter the name of the TabItem component.

  • Text

       Enter the title of the tab.

  • Orientation

       Specify the position of components.

    • Horizontal : Arrange the components horizontal
    • Vertical : Arrange the components vertically
