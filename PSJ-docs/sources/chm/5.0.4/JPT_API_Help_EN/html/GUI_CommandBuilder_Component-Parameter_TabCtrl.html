TabCtrl

Create a group of tab items (pages).



   Creation image：


    ※TabCtrl is used as a set with TabItem.


  • Name

       Enter the name of the TabCtrl component.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Width

       Specifies the minimum width of the created page. (Units: pixels)

  • Height

       Specifies the minimum height of the created page. （Units: pixels）
