Hierarchy Window

All components in use are displayed in a tree format and you can change the position of the components.



Hierarchy Window details
IconNameDescription
Move upper levelMove the selected item to a upper level.
Move lower levelMove the selected item to a lower level.
Move forwardMove the selected item up one level to the same level.
Move backwardMove the selected item down one level to the same level.
Copy and insertDuplicate the selected item.
DeleteDelete the selected item.
Import XMLImport the XML file.
