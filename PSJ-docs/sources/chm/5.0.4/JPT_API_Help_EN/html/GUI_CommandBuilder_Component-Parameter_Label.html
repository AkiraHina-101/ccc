Label

Add a label.



   Creation image：



  • Text

       Enter the text to be displayed as a label.

  • Name

       Enter the label component name.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Width

       Specifies the minimum width of the label.（Unit: Pixels）

  • Height

       Specifies the minimum height of the label.（Unit: Pixels）
