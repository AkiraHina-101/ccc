Name Description Shortcut key
Undo Cancels the executed operation and returns to the previous state. Ctrl + Z
Redo Retry the canceled operation. Ctrl + Y
Cut Cut the selected code. Ctrl + X
Copy Copy the selected code. Ctrl + C
Paste Paste the Cut/Copy code. Ctrl + V
Import Macro Log Import the macro of the executed command in the form of JPT.Exec (macro command) of PSJ-Utility. Ctrl + M
Import Python Macro Log Import the executed command PSJ-Command.
PSJ-Command is supported in V5.
 Ctrl + J
Import Script From Last Run Import the Python script code you last ran in the IDE. Ctrl + L
Find Find the specific character in the code you are writing. Ctrl + F
Comment Insert the comment tag "#". Ctrl + K
Toggle Comment Switch between comment ⇔ comment cancellation Ctrl + T
Go To Line Find the specific line in the code you are writing. Ctrl + G
Find And Replace Find and replace the specific characters in your code. Ctrl + H
