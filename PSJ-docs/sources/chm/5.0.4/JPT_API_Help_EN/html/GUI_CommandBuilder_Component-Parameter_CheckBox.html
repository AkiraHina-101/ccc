CheckBox

Add a checkbox.



   Creation image：



  • Text

       Enter the text that appears next to the checkbox.

  • Name

       Enter the name of the CheckBox component.

  • Checked

       Specify the default value.

    • Check On : Check.
    • Check Off : Not Check
      •
  • Width

       Specify the minimum width of the check box. (Unit: Pixel)

  • Height

       Specify the minimum height of the checkbox. (Units: pixels)

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use(It will be grayed out)
      •
  • Left text

       Display the text to the left of the check box.

    • Check On : Available
    • Check Off : Impossible to use (It will be grayed out)
      •

    Command to use

    CommandDescriptionSample Code
    dlg.isbutton_checked("component name") Check if the check box is checked.
    Returns a Boolean value (True/False).

    Input:

    dlg.isbutton_checked("CheckBoxButton")

    Output:

    > True/False
    dlg.set_checkbox_state("name", Bool) Specify the status (checked/unchecked) of the check box.

    Input:

    dlg.set_checkbox_state("CheckBox1", True)
