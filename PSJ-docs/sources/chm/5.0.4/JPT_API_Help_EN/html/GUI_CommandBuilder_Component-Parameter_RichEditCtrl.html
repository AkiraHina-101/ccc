RichEditCtrl

Add a rich text box.



   Creation image：



  • Default

       Enter the text that is entered by default.

  • Name

       Enter the name of the rich text component.

  • Width

       Specifies the minimum width of the rich text box.（Unit: Pixels）

  • Height

       Specifies the minimum height of the rich text box.（Unit: Pixels）

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
