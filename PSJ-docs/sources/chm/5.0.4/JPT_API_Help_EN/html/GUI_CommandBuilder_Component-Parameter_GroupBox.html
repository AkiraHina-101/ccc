Group Box

Create a component group.



   Creation image：



  • Text

       Enter the group name.

  • Name

       Enter the name of the group box component.

  • Has Check Label
    • No : Always make the components in the group operational.
    • Yes(Default==Checked) : Controls the operation of the components in the group. (Default: Check ON)
    • Yes(Default==Unchecked) : Controls the operation of the components in the group. (Default: unchecked)
      •
  • IsCollapsed

       Sets the collapsible display of the group box.

    • No : Doesn't collapsible
    • Yes(Default==Collapsed) : Controls the operation of group box collapsible. (Default: check ON)
    • Yes(Default==Expanded) : Controls the group box collapsible operation. (Default: unchecked)
      •
  • Orientation

       Specify the position of components.

    • Horizontal : Arrange the components horizontal
    • Vertical : Arrange the components vertically
      •
  • Width

       Specify the minimum width of the group box. (Unit: pixels)

  • Height

       Specify the minimum height of the group box. (Unit: pixels)

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
