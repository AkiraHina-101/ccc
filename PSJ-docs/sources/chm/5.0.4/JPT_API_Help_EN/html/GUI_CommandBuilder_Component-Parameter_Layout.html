Layout

Set the layout of the component.



   Creation image：Orientation

  • Name

       Enter the name of the layout component.

  • Orientation

       Specify the position of components.

    • Horizontal : Arrange the components horizontal
    • Vertical : Arrange the components vertically
      •
  • Margin

       Left : Put a margin to the left of the Group Box. (Units: pixels)

       Top : Put a margin above the Group Box. (Units: pixels)

       Right : Put a margin to the right of the Group Box. (Units: pixels)

       Bottom : Put a margin below the Group Box. (Units: pixels)

    • Command to use

    CommandDescriptionSample Code
    dlg.show_layout("name") Show the specified Layout.

    Input:

    dlg.show_layout("Layout5")
    dlg.hide_layout("name") Hides the specified Layout.

    Input:

    dlg.hide_layout("Layout5")
