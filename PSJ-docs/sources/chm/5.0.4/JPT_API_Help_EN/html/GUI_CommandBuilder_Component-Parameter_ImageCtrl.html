ImageCtrl

Add image.



   Creation image:



  • Name

       Enter the ImageCtrl component name.

  • Image File

       Displays the link to the image to be inserted.

    • Command to use

    CommandDescriptionSample Code
    dlg.set_image_file("name", ”link”) Updates the image of the selected ImageCtrl component.

    Input:

    dlg.set_image_file("ImageCtrl", ” C:/Users/M3.JPG”)
