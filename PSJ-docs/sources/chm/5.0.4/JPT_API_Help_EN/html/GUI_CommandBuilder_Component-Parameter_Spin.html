Spin

Add a spin button.



   Creation image：



  • Name

       Enter the name of the spin component.

  • Min

       Specifies the minimum value of the spin range.

  • Max

       Specifies the maximum value of the spin range.

  • Value

       Specify an initial value.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
