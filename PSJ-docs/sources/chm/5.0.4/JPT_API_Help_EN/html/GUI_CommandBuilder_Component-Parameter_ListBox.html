ListBox

Add the list box.



   Creation image：



  • Name

       Enter the name of the combo box component.

  • Enable

       Specify whether to use it or not.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Allow Multiple Selection

       Multiple items (items in the list box component) can be selected.

    • Check On : Available
    • Check Off : Impossible to use（It will be grayed out）
      •
  • Width

       Specifies the minimum width of the combo box. (Units: pixels)

  • Height

       Specifies the minimum height of the combo box. (Units: pixels)

  • Source File

       Enter options from a text file.

       Structure of the Source File：

        Option1
        Option2
        Option3
        Option4
        Option5
         ↓
        Input result：



  • Option Count

       Specify the number of items to be selected.

  • Options *

       Enter the name of the item.

    • Command to use

    CommandDescriptionSample Code
    dlg.get_listbox_sel("name") Gets the position of the item selected in the list box.

    listbox = ["1", "2", "3", "4", "5"]
    When "4" is selected

    Input:

    a = dlg.get_listbox_sel("listbox")

    Output:

    > a = 3
    dlg.get_len_listbox("name") Gets the length of the list box.

    listbox = ["1", "2", "3", "4", "5"]

    Input:

    a = dlg.get_len_listbox("listbox”)

    Output:

    > a = 3
    dlg.set_listbox_sel(“Name”, Index) Switches the value selected in the list box.

    listbox = ["1", "2", "3", "4", "5"]

    Input:

    dlg.set_listbox_sel(“ListBox”, 3)

    ⇒ Selected value=”4”
    dlg.insert_listbox_option("name", position, "text") The value is added from the position selected in the list box (1 value 1 time).

    Input:

    dlg.insert_listbox_option("name", 1, "text")
    dlg.insert_listbox_options("name", position, [item list]) Adds a value from the position selected in the list box (multi-value once).

    Input:

    dlg.insert_listbox_options("name", 3, [item list])
