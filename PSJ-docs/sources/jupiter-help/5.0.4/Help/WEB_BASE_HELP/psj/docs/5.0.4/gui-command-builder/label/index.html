Label

Add a label.

Preview dialog:

Parameters​

Text​

Enter the text displayed as a label.

Name​

Enter name of the label.

Enable​

Specify whether to enable it or not.

  • Check On : Available
  • Check Off : Unavailable (grayed out)

Size​

  • Width : Specify the minimum width of the label. (in pixels)
  • Height : Specify the minimum height of the label. (in pixels)

Alignment​

H.Alignment​

Specify display position of the text in horizontal direction.

  • Left : Align text to the left
  • Center : Center text
  • Right : Align text to the right

V.Alignment​

Specify display position of the text in vertical direction.

  • Top : Aligns text along their top edges
  • Middle : Aligns text horizontally through their middles.
  • Bottom : Aligns text along their bottom edges

API associated with​

  • dlg.add_label : Add a Label to the creating dialog.
