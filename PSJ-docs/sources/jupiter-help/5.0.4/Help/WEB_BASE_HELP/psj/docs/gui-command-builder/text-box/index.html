TextBox

Create a text box.

Preview dialog:

Parameters​

Default​

Enter the text that is displayed by default.

Align​

Specify display position of the text inside the box.

  • Left : Left alignment
  • Right : Right align
  • Center : Center align

ReadOnly​

  • Check On : Text cannot be edited (copy is possible)
  • Check Off : Text can be edited

Name​

Enter name of the text box.

Size​

  • Width : Specify the minimum width of the text box. (in pixels)
  • Height : Specify minimum height of the text box. (in pixels)

Type​

Specify the data type that can be entered into the text box (for validation).

  • String : String type
  • Double : Double precision floating point number type
  • Integer : Integer type

Enable​

Specify whether to enable it or not.

  • Check On : Available
  • Check Off : Unavailable (grayed out)

Color​

  • Background Color : Specify the background color of text box.
  • Text Color : Specify the color of text displayed in the text box.

Font​

  • Size : Specify the size of text displayed in the text box.
  • Bold : Specify whether to enable the bold text.
    • Check On : Make the text bold
    • Check Off : Do not make the text bold
  • Italic : Specify whether to italicize of text.
    • Check On : Italicize of text
    • Check Off : Do not italicize of text
  • Underline : Specify whether to underline text.
    • Check On : Underline text
    • Check Off : Do not underline text
  • StrikeOut : Specify whether to cross text out by drawing a line through it.
    • Check On : Cross text out by drawing a line through it
    • Check Off : Do not cross text out

API associated with​

  • dlg.add_textbox : Add a Textbox to the creating dialog.
