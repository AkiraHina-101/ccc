Version: 5.0.4

Spin

Create a spin button.

Preview dialog:

Parameters​

Name​

Enter name of the spin.

Enable​

Specify whether to enable it or not.

  • Check On : Available
  • Check Off : Unavailable (grayed out)

Integer​

Specify spin with Integer type.

  • Check On : Use Integer spin
  • Check Off : Use Double spin

Min​

Specify the minimum value of the spin range in Integer type.

Max​

Specify the maximum value of the spin range in Integer type.

Value​

Specify an initial value of the spin range in Integer type.

Increment​

Specify an increment step of the spin in Integer type.

Double​

Specify spin with Double type.

  • Check On : Use Double spin
  • Check Off : Use Integer spin

Min​

Specify the minimum value of the spin range in Double type.

Max​

Specify the maximum value of the spin range in Double type.

Value​

Specify an initial value of the spin range in Double type.

Increment​

Specify an increment step of the spin in Double type.

Precision​

Specify a precision (number of digits) of input value of Double spin.

API associated with​

  • dlg.add_spin : Add a Spin to the creating dialog.
