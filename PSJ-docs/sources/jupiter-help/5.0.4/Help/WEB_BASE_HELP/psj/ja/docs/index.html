PSJの紹介

CAE 業務における問題例​

  • 繰り返しの操作は、ユーザーが退屈で不快になる可能性があります。
  • 自動化のない反復作業は、望ましい期間内に完了できない可能性があります。
  • 手動の操作はオペレーションミスを引き起こす可能性があります。
  • 複雑なモデリングの場合、詳細なCAE トレーニングが必要になることがあります。
  • 各企業には独自のデザインルール/プロセス、デザイン仕様/テンプレートなどがあるため、各ユーザーに固有の UIがあるとより便利です。

PSJ：自動化とカスタマイズ用​

このような問題を解決し、さまざまなユーザーからの要件を満たすために、4F motoを使用して PSJ(Python Scripting for Jupiter）が開発されています。

注目機能​

PSJ を使用すると、次の機能を利用できます。

  1. Python スクリプトの Jupiter 関数

    • Jupiter Pre/Post 機能の組み込み
    • 他のソフトウェアとの接続
    • Python3.x とその膨大なライブラリと互換性があります

  2. GUI コマンドビルダー：メイン製品と同等の GUI ダイアログが簡単に作成できます。

  3. カスタマイズされた IDE：自動補完・ツールチップなどのプログラミングのサポートが充実しています。

  4. カスタマイズされたシェル：デバッグのエラー出力が可能です。

詳細情報

その他 PSJ ソリューションの詳細は、専用のサンプルアプリケーションをご覧ください。
