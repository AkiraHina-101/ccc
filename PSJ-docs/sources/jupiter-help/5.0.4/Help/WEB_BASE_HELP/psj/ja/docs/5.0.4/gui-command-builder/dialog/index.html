Dialog

Set the title, execute button, and selection list of the created dialog.

Preview dialog

Parameters​

Title​

Enter the title of the dialog.

Resizable​

Specify if the dialog can be resized or not.

  • Check On : The size of the dialog can be adjusted
  • Check Off : The size of the dialog is fixed

Validation​

Specify if user's inputs in the dialog will be checked for validation (format, number format, etc.).

  • Check On : Will be checked for validation
  • Check Off : Will not be checked for validation

Apply Button​

Specify if the Apply button will be created or not.

  • Check On : Will be created
  • Check Off : Will not be created

Ok Button​

Specify if the OK button will be created or not.

  • Check On : Will be created
  • Check Off : Will not be created

Cancel Button​

Specify if the Cancel button will be created or not.

  • Check On : Will be created
  • Check Off : Will not be created

Modal Mode​

Specify if the Modal mode will be used or not.

  • Check On : Will be used
  • Check Off : Will not be used

Icon File​

Specify the path of icon file to be displayed on the left corner of the dialog.

Description​

The information entered here will be displayed at the top of the dialog.

Selector​

Specify selectable types in selection list.

Supported Selection Types: Node Selector, Part Selector, Bar Part Selector, Element Edge Selector, 1D Element Selector, 2D Element Selector,3D Element Selector,Face Selector, Edge Selector, Vertex Selector

API associated with​

  • JDGCreator: A Class to generate Dialog in Jupiter.
  • dlg.on_command : Bind a created function to a component.
  • dlg.on_dlg_apply: Execute a created function when Apply button is clicked.
  • dlg.on_dlg_cancel: Execute a created function when Cancel button is clicked.
  • dlg.on_dlg_help : Execute a created function when help button is clicked.
  • dlg.on_dlg_ok : Execute a created function when OK button is clicked.
  • dlg.on_dlg_selector_changed : Run a created function after an item is selected.
  • dlg.generate_window : Execute the created dialog (show the dialog with all the created functions).
  • dlg.do_modal : Execute the created dialog (show the dialog with all the created functions) with Modal mode.
  • dlg.close : Close the dialog.
  • dlg.add_space : Add a space between the created components.
  • dlg.add_1delement_selector : Add "1D element" to the selection list, allowing user to select 1D elements and store the selected 1D elements to the selection list.
  • dlg.add_2delement_selector : Add "Element" to the selection list, allowing user to select 2D elements and store the selected 2D elements to the selection list.
  • dlg.add_3delement_selector : Add "Solid element" to the selection list, allowing user to select solid elements and store the selected solid elements to the selection list.
  • dlg.add_vertex_selector : Add "Vertex" to the selection list, allowing user to select vertexes and store the selected vertexes to the selection list.
  • dlg.add_node_selector : Add "Node" to the selection list, allowing user to select nodes and store the selected nodes to the selection list.
  • dlg.add_edge_selector : Add "Edge" to the selection list, allowing user to select edges and store the selected edges to the selection list.
  • dlg.add_elementedge_selector :Add "Elem edge" to the selection list, allowing user to select element edges and store the selected element edges to the selection list.
  • dlg.add_barpart_selector : Add "Bar" to the selection list, allowing user to select bar parts and store the selected bar parts to the selection list.
  • dlg.add_face_selector : Add "Face" to the selection list, allowing user to select faces and store the selected faces to the selection list.
  • dlg.add_part_selector : Add "Part" to the selection list, allowing user to select parts and store the selected parts to the selection list.
  • dlg.add_condition_selector : Add "Condition" to the selection list, allowing user to select condition and store the condition to the selection list.
  • dlg.add_coordinate_selector : Add "Coordinate" to the selection list, allowing user to select coordinate and store the coordinate to the selection list.
  • dlg.add_group_selector : Add "Group" to the selection list, allowing user to select group and store the group to the selection list.
  • dlg.get_dlg_selector_selected_entities : Get selected DItem in current Selection List.
  • dlg.get_item_text : Get text inside the component.
  • dlg.set_item_text : Set the text which will be shown inside the component.
  • dlg.set_item_font : Set font properties to the text inside the component.
  • dlg.disable_item : Change the "Enable" option of an inputted component to off (Disabled).
  • dlg.enable_item : Change the "Enable" option of an inputted component to on (Enabled).
  • dlg.isbutton_checked : Check the status of the inputted component whether it is checked or not. Currently supporting checkbox and radio button components.
  • dlg.set_icon_file : Set icon for the creating GUI dialog.
  • dlg.set_item_size_behavior : Set display behavior of TabWnd, ImgCtrl, Table, PagesCtrl.
  • dlg.show_tooltip : Show tooltip when user hover the mouse to a UI component.
  • dlg.show_dlg_help_button : Show or hide the help button in the creating dialog.
