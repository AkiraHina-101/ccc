Message box

🎯 Introduction​

In this tutorial, you'll learn how to use JPT.MessageBoxPSJ() to display a message to user:

  1. Display all message box types in Python API window, user can refer all message box types for proper usage.
  2. Create message box with information-Yes-No-Cancel type.
  3. Get and display the return value of message box button from user's selection in Python API window.

📖 Tutorial​

# Encoding for Japanese
# coding: cp932

# Clear the log message in Python API window
JPT.ClearLog()

# Display all message box types in Python API window
JPT.Debugger(JPT.MsgBoxType.values)

# Create message box with information-yes-no-cancel type,
# use "answer" to store return value of message box from user
answer = JPT.MessageBoxPSJ("Input information: content of the message", JPT.MsgBoxType.MB_INFORMATION_YESNOCANCEL)

# Get and display the return value of message box from user in Python API window
if answer == "YES":
    print ("You selected 'Yes' button")
elif answer == "NO":
    print ("You selected 'No' button")
else:
    print ("You selected 'Cancel' button")
