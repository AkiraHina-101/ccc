DCoord

Description​

This is an instance of a DCoord class, represents Coordinate item inside Jupiter.

Properties​

AttributeDescription
isValidDetermine the validation of the Coordinate.
The return value is True if the Coordinate is valid, False if not (invalid).
typeType name of the Coordinate.
The return value is Type (string).
typeIDType ID of the Coordinate (ID = 27).
The return value is an Int notation of DItem Types (int).
tableIDTable ID of the Coordinate.
The return value is an Int notation of Table Types (int).
idExternal ID of the Coordinate.
It can be duplicated, but not recommended.
ID can be changed using the renumbering function.
The return value is ID (int).
targetsHold the contents of the Coordinate.
The return value is a list of DItem.
mastersMaster face/edge/node of the Coordinate.
The return value is a list of DItem.
slavesSlave face/edge/node of the Coordinate.
The return value is a list of DItem.
parentA sub-assembly that is the parent of Coordinate in the assembly tree.
The return value is a list of DItem.
isHiddenDetermine display state of the Coordinate.
The return value is True if the Coordinate is hidden, False if the Coordinate is displayed.
nameName of the Coordinate.
coordTypeType of the Coordinate.
The return value is Type (string).
coordPointsA list of defined Points for Coordinate.
The return value is TVector3d.

Attribute​

coordType​

NameDescription
COORDINATE_RECTCartesian Coordinate System (Oxyz).
COORDINATE_CYLINCylindrical Coordinate - (r, φ, z) Coordinate System, where (r, φ, z) are (radial distance, azimuth angle, axial Coordinate or height z) respectively.
COORDINATE_SPHERESpherical Coordinate - (r, θ, φ) Coordinate System, where (r, θ, φ) are (radial distance, azimuth angle, polar angle) respectively.
