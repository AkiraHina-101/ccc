ACTRAN_ANALYSIS

Description​

A data type uses to control parameters of Actran Analysis

Attributes​

strName​

  • A String specifying name.
  • The default value is "Job_1".

strDescription​

  • A String specifying description.
  • The default value is "".

iExeType​

  • An Integer specifying exe type.
  • The default value is 0.

iAnaType​

  • An Integer specifying ana type.
  • The default value is 0.

strEdatFile​

  • A String specifying edat file.
  • The default value is "".

strAcousticFileName​

  • A String specifying acoustic file name.
  • The default value is "".

iNfSpaceType​

  • An Integer specifying nf space type.
  • The default value is 0.

iPML2DElemPID​

  • An Integer specifying p m l2 d elem p i d.
  • The default value is 0.

iPML3DElemPID​

  • An Integer specifying p m l3 d elem p i d.
  • The default value is 0.

iIFEM2DElemPID​

  • An Integer specifying i f e m2 d elem p i d.
  • The default value is 0.

iOrder​

  • An Integer specifying order.
  • The default value is DFLT_INT.

dlOrigin​

  • A List of Double specifying origin.
  • The default value is 0.0.

dlXAxis​

  • A List of Double specifying x axis.
  • The default value is 1.0.

dlYAxis​

  • A List of Double specifying y axis.
  • The default value is 0.0.

dlZAxis​

  • A List of Double specifying z axis.
  • The default value is 0.0.

strReflection​

  • A String specifying reflection.
  • The default value is "NOSYM.

iProjectionSurface2DElemPID​

  • An Integer specifying projection surface2 d elem p i d.
  • The default value is 0.

dGapTol​

  • A Double specifying gap tolerance.
  • The default value is 0.01.

dPlaneTol​

  • A Double specifying plane tolerance.
  • The default value is 0.0001.

iFiniteDomain3DElemPID​

  • An Integer specifying finite domain3 d elem p i d.
  • The default value is 0.

iMatId​

  • An Integer specifying material ID.
  • The default value is 0.

dAcousticSpeed​

  • A Double specifying acoustic speed.
  • The default value is DFLT_DBL.

dFluidDensity​

  • A Double specifying fluid density.
  • The default value is DFLT_DBL.

strStructuralModelBdfFile​

  • A String specifying structural model bdf file.
  • The default value is "".

strStructuralModelOp2File​

  • A String specifying structural model op2 file.
  • The default value is "".

strSubcase​

  • A String specifying subcase.
  • The default value is "1".

iStateValue​

  • An Integer specifying state value.
  • The default value is 1.

iNumOfPanel​

  • An Integer specifying number of panel.
  • The default value is 0.

iSummationID​

  • An Integer specifying summation i d.
  • The default value is 0.

strStructuralModelPCHFile​

  • A String specifying structural model p c h file.
  • The default value is "".

iLowerMode​

  • An Integer specifying lower mode.
  • The default value is DFLT_INT.

iUpperMode​

  • An Integer specifying upper mode.
  • The default value is DFLT_INT.

iSubcaseStart​

  • An Integer specifying subcase start.
  • The default value is DFLT_INT.

iSubcaseStop​

  • An Integer specifying subcase stop.
  • The default value is DFLT_INT.

iStartRPM​

  • An Integer specifying start r p m.
  • The default value is DFLT_INT.

iIncrementRPM​

  • An Integer specifying increment r p m.
  • The default value is DFLT_INT.

iFdmethod​

  • An Integer specifying fdmethod.
  • The default value is 0.

dStartf​

  • A Double specifying startf.
  • The default value is DFLT_DBL.

dEndf​

  • A Double specifying endf.
  • The default value is DFLT_DBL.

dIncrtf​

  • A Double specifying incrtf.
  • The default value is DFLT_DBL.

iSolver​

  • An Integer specifying solver.
  • The default value is 0.

strGreenDBFile​

  • A String specifying green database file.
  • The default value is "Green_db".

strPltfile​

  • A String specifying pltfile.
  • The default value is "AUTO".

bUseMapFile​

  • A Boolean enable/disable use map file.
  • The default value is False.

iFormat​

  • An Integer specifying format.
  • The default value is 1.

strMapFile​

  • A String specifying map file.
  • The default value is "AUTO".

iMethod​

  • An Integer specifying method.
  • The default value is 0.

iNodeGroupID​

  • An Integer specifying node group i d.
  • The default value is 0.

tshTable​

  • A Table Sheet specifying table.
  • The default value is [].

listActranDomain​

  • A ACTRAN_DOMAIN List specifying actran domain.
  • The default value is [].

iJobType​

  • An Integer specifying job type.
  • The default value is 0.

iInfiniteSpaceType​

  • An Integer specifying infinite space type.
  • The default value is 0.

strInputFile1​

  • A String specifying input file1.
  • The default value is "".

strInputFile2​

  • A String specifying input file2.
  • The default value is "".

iMemory​

  • An Integer specifying memory.
  • The default value is 500.
