# Tài liệu nhúng trong PSJ Documentation.exe

Trích xuất cục bộ ngày 2026-10-12 bằng đọc bảng asset Tauri và giải mã Brotli, không chạy EXE. `extraction-manifest.json` lưu đường dẫn asset gốc, offset/độ dài, SHA-256 và file đã lưu. 14.266 asset văn bản được giải mã; 66 asset trùng ánh xạ về nội dung đã lưu.

`site/` là các tài nguyên văn bản để tra cứu; ảnh/font không được trích nên không phải bản website hoàn chỉnh. EXE gốc vẫn là nguồn xem tài liệu đầy đủ. Danh mục hợp nhất nằm ở `../03-api-reference/API-CATALOG.md`; corpus và search index ở cùng thư mục đó.
