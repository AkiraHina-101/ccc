ERIBEAM_PIN_B_PROP

Description​

A data type uses to control parameters of Eribeam Pin B Prop

Attributes​

iPropId​

  • An Integer specifying prop ID.
  • The default value is 0.

iElemId​

  • An Integer specifying elem ID.
  • The default value is 0.
