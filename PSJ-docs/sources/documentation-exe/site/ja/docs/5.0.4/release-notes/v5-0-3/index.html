V5.0.3リリースノート

Highlight updates

V5.0.3では、主にPost処理を強化するためのAPI機能を追加しました。また、新機能や新オプション用にマクロやPSJ Commandを更新しています。

  • カスタムノート（新機能）コントロール用の新規データタイプ、マクロ、APIを追加しました。
  • Postの結果表示情報を取得するAPIを追加しました。
  • Postドキュメント上の要素・節点操作の補助となるAPIを追加しました。
  • Postドキュメント上の要素・節点取得の際の不具合を修正しました。
  • 表示中ドキュメントの有効化切り替え、選択、クローズを行うAPIを追加しました。
  • PSJ-GUIのクラッシュ問題や軽微な不具合を修正しました。
  • プリインストールされているpythonライブラリに、openpyxlを追加しました。

⌘ PSJ-指示​

新規オプションの追加や、操作性・保守性向上のためのPSJコマンド更新を実施しました。

更新コマンド一覧
  • Connections.Contacts.CheckPattern(): パターンマッチ結果をパターン一致した要素のIDリストとパターン不一致要素のIDリストとして取得できるように変更しました。
  • Connections.Pretension.Abaqus(): マクロの実装に合わせ、対象指定をフェースカーソルから任意エンティティのカーソルリストに変更しました。また、参照節点の指定用に引数を追加しました。
  • Analysis.ADVC.Structure: ADVC最適化設定を追加しました。
  • Analysis.Ansys.Structure(): 互換性のため、コマンドバージョンを指定する引数を追加しました。

🛠 PSJ-ユーティリティ​

📝 API​

  • 新規に27個のAPIコマンドを追加しました。

    新規追加コマンド一覧
    • JPT.GetAppPathInfo(): PathTypeで指定されたパス情報を取得します。
    • JPT.SelectionByIDs(): ID指定したエンティティ（複数）を取得します。
    • JPT.IsSpatialPointRendered():指定した節点が、現在のビュー上に表示されているかどうかを確認します。
    • JPT.CastDItemToDPostElem():指定したDItemオブジェクトをDROElemオブジェクトに変換し、Post要素の情報を取得可能にします。
    • JPT.CloseAllGraphViews() : 表示されている全てのチャートビュー（グラフウィンドウ）を閉じます。
    • JPT.CloseGraphViewByDocumentName(): 指定したドキュメントに付随する全てのチャートビュー（グラフウィンドウ）を閉じます。
    • JPT.ConvertCoordinateFromGlobalToLocal(): 選択したDItemのグローバル座標系を、指定したローカル座標系に変換します。
    • JPT.HighlightByID(): アッセンブルツリーのLBC及びプロパティアイテムをハイライトします。同時に、メインウィンドウ上でハイライトしたLBC/プロパティに接続したパーツ・フェースの表示を変更します。
    • JPT.SetActiveDocumentByID(): IDで指定したドキュメントを有効化します。
    • JPT.SetActiveDocumentByName(): 名前で指定したドキュメントを有効化します。
    • GetAllCustomNotes: 存在しているすべてのカスタムノートを取得します。
    • GetAllCustomNoteCollections: 存在しているすべてのコレクションを取得します。
    • JPT.GetDocumentList(): 表示中のドキュメントのリストを取得します。
    • JPT.GetActiveDocument(): 現在使用中のドキュメント（有効ドキュメント）を取得します。
    • JPT.GetDocumentByID(): IDで指定したドキュメントを取得します。
    • JPT.GetDocumentByName(): 名前で指定したドキュメントを取得します。
    • JPT.CloseDocumentByID(): IDで指定したドキュメントを閉じます。
    • JPT.GetCurrentDeformation(): 現在の変形設定を取得します。
    • JPT.GetCurrentViewPoint(): 現在のビューポイント設定を取得します。
    • JPT.GetCurrentCrossSection(): 現在の断面設定を取得します。
    • JPT.GetCurrentContour(): 現在のコンター設定を取得します。
    • JPT.GetCurrentCircle(): 現在の円図設定を取得します。
    • JPT.GetCurrentDiagram(): 現在のダイアグラム設定を取得します。
    • JPT.GetCurrentVector(): 現在のベクトル設定を取得します。
    • JPT.GetCurrentAnimation(): 現在のアニメーション設定を取得します。
    • JPT.CastDItemToDRONode(): DItemオブジェクトをDPostNodeオブジェクトに変換します。
    • JPT.CastDItemToDROElem(): DPostNodeオブジェクトをDItemオブジェクトに変換します。

  • また、下記のコマンドが変更されました。

    変更コマンド一覧
    • JPT.EnableLicenseFeature(): JPT_BASEの有効化が前提のライセンスを指定して有効化した場合、JPT_BASEを自動的に有効化するよう変更しました。

📐 PSJ-GUI​

📝 API​

  • 新規に7個のコマンドを追加しました。

    新規追加コマンド一覧
    • dlg.remove_combobox_option(): Comboboxのオプションを削除します。
    • dlg.remove_listbox_options(): Listboxのオプションを削除します。
    • dlg.get_listbox_sels(): Listboxで選択されたアイテム全てを取得します。
    • dlg.get_table_cell_fill_color(): 指定したセルの色を取得します。
    • dlg.on_spin_changed(): Spinの値が変更されたときに関数を実行します。
    • dlg.on_listbox_sel(): ListBoxのアイテムが選択されたときに関数を実行します。
    • dlg.fill_table_by_file(): GUI操作を行わずに、Table内にファイルからデータを直接入力します。

⚙ マクロ​

  • 新規に9個のマクロを追加しました。

    新規追加マクロ一覧
    • ViewRemoveMode: 選択解除モードのON/OFFを制御するマクロです。
    • ViewShowGroupMode: グループモードのON/OFFを制御するマクロです。
    • ViewShowGlobalCoordinate: 全体座標系表示のON/OFFを制御するマクロです。
    • CmdSetPreUnit: Preドキュメントの単位系を設定するマクロです。
    • SetDefaultInitialViewPoint: 初期ビューポイントを設定するマクロです。
    • ShowContactPairData: 接触対選択ダイアログでの選択表示を実施するマクロです。
    • CreateCustomNote: 新規カスタムノートを指定コレクション下に作成するマクロです。
    • CreateCollection: 新規コレクションを作成するマクロです。
    • EditCustomNoteWndPosition: 指定カスタムノートを任意の画面位置に移動するマクロです。

  • また、下記のマクロが変更されました。

    変更マクロ一覧
    • LaunchOperation(): 戻り値（成功/失敗）を設定しました。

🚅 サンプル​

  • 新規チュートリアル（中級）を追加しました。
    • 平面応力の問題を解決します。
    • モデル設定、分析、結果チェックの小さなサンプル。
    • CSVファイルを読み書きするための小さなサンプル。
  • Pythonコードの新規チュートリアルを追加しました。
    • Pythonのヒント - ファイル入出力
  • 一部チュートリアルを日本語化しました。

📝 その他​

  • プリインストールされているpythonライブラリに、openpyxlを追加しました。

🐛 不具合修正​

⌘ PSJ-指示​

  • Python API ウィンドウにAnalysis.ADVC.Structure が表示されない不具合を修正しました.
  • Analysis.MakeProcess.Staticで、一部のLBCがカーソル文字列表記を受け付けない不具合を修正しました。
  • Geometry.Transform.Translationがが空のリストを返すことによるInvalid literalエラーを修正しました。

📐 PSJ-GUI​

📝 API​

  • dlg.set_table_column_widthが66未満に設定できないバグを修正しました。22以上から設定できるようになりました。
  • dlg.on_browse がフォルダのパスを返さない不具合を修正しました。
  • dlg.on_dlg_selector_changed 実行中に選択対象が削除されるとクラッシュする不具合を修正しました。

📏 GUI コマンドビルダー​

  • テキストボックスのデータ型が*.jdbファイルに正しく保存されない問題を修正しました。
  • コンボボックスのOptions Countに間違った値を入力するとクラッシュする不具合を修正しました。
  • テーブルの全行数に間違った値を入力するとクラッシュする不具合を修正しました。
  • テーブルの全列数に間違った値を入力するとクラッシュする不具合を修正しました。

🛠 PSJ-ユーティリティ​

📝 API​

  • JPT.GetEntitiesByPositionが間違ったターゲットを見つける不具合を修正しました。
  • JPT.GetSelectedNodesで、Postドキュメントのソリッド要素節点が取得できない不具合を修正しました。
  • Postドキュメントで、JPT.MacroListTCursorToListDItemが正しく動作しない不具合を修正しました。

⚙ マクロ​

  • LoadTemplateマクロを順次実行した場合、ビューポイントが変更されないという不具合を修正しました。
  • SetDefaultInitialTreeConditionが正しく動作しない不具合を修正しました。
  • CmdShowPostContourが正しく動作しない不具合を修正しました。
  • CmdShowPostContour実行に中間節点使用アイコンの表示が追従しない不具合を修正しました。

📝 他の​

  • IDEでImport Python Macro Log (Ctrl+J)が一部のコマンドのインポートに失敗する不具合を修正しました。
