バージョン: 5.0.4

プリソーバーポスト

このサンプルには、次のようにトピックが含まれています:
  • カスタムリボンにメニューを設定する方法。
  • 制約を定義する方法。
  • 負荷を定義する方法。
  • サンシャインソルバーを実行する方法。
  • 結果op2ファイルをインポートする方法。

サンプルデータ​

  • リボンのデータ - Sample3.zip
  • テストモデル (.step)

コードの使用方法​

  1. すべてのコンテンツをコピーします Sample3.zip 「psjコマンドフォルダー」の下 %userprofile%\AppData\Roaming\TechnoStar\JPT Version\PSJ_Commands\ デフォルトで。 階層が次のように設定されるようにファイルを配置します:
  2. Jupiterを起動します。「プレートサンプル」リボンが表示されます。
  3. クリック"pre_solver"リボンのアイコン。表示されたダイアログ。
  4. 添付のステップファイルを開きます"STEP ファイル".
  5. 任意の.bdfファイル名を示します "BDF ファイル".
  6. クリック"走る"ボタン。.op2ファイルを取得します。
  7. 新しい空白のドキュメントを作成します。
  8. リボンの「投稿」アイコンをクリックします。別のダイアログが表示されました。
  9. 示す.op2 で取得するファイル "OP2 ファイル".
  10. クリック"輸入 OP2" ボタン。結果をドキュメントにインポートします。

pre_solverアイコンのコード​

import sys
import os
import numpy  as np
import subprocess

from pyjdg import *

#--------------------------------------------------------------
def importCAD(dlg):
  name_file = dlg.get_item_text('ファイル')     # FILRブラウザからファイル名を取得します
  imported_status = Home.ImportCAD.Spatial(strlPaths=[name_file],bSetFaceColor=True)
  JPT.Debugger(imported_status)

#--------------------------------------------------------------
def createMesh(dlg):
  global nid

  aname = ''
  msize = dlg.get_item_text('メッシュ')  
  aveSize = float(msize)/1000
  maxSize = aveSize*1.4
  minSize = aveSize*0.7

  listParts = JPT.GetEntitiesByName(JPT.DTableType.DTABLE_BODY, aname, JPT.BoolType.FALSE_VAL)
  npart = len(listParts)

  partname = listParts[0].name   # one(1) このサンプルモデルの一部
  nid = listParts[0].id

  surface_status = Meshing.SurfaceMeshing(crlParts=[Part(nid)], 
                   surfaceMesh=SURFACE_MESH(dAvgElemSize=aveSize, 
                                            dMaxElemSize=maxSize,
                                            dMinElemSize=minSize))
  JPT.Debugger(surface_status)

  meshing_status = Meshing.SolidMeshing(crlParts=[Part(nid)], 
                                                  bTet10=False)
  JPT.Debugger(meshing_status)
  

#------------------------------------------------
def materialList():
    global structure_steel, alminum_alloy
    global nmat, matname

    #長さ:mm   重さ:ton   力:N
    #密度:ton/mm3   ヤングモジュラス:N/mm2

    nmat = 2
    matname = ['']*nmat
    matname[0] = "Structural_Steel"
    matname[1] = "Alminum_Alloy"

    structure_steel = Properties.Material.Add(matname[0], 
                        [Density([(DENSITY, 7.85e-09)]),
                         Elastic([(YOUNGS_MODULUS, 200000.0),(POISSONS_RATIO, 0.3)])])

    alminum_alloy = Properties.Material.Add(matname[1], 
                        [Density([(DENSITY, 2.77e-09)]),
                         Elastic([(YOUNGS_MODULUS, 71000.0), (POISSONS_RATIO, 0.3)])])

#--------------------------------------------------------------
def defMaterial(dlg):
  matid = 0

  matprop = dlg.get_item_text('材料')
  for j in range(nmat):
    if matprop.replace(' ','') == matname[j]:     # ' クッション ' => 'クッション'
      matid = j
    
  created_prop =  Properties.Solid(strName="Solid Property1", 
                               iPropertyId=1,
                               crMaterial=Material(matid+1),          
                               iCordM=-2, 
                               dDispHG=DFLT_DBL, 
                               crlTargets=[Part(nid)],              
                               iFLG=-1)

#--------------------------------------------------------------
def defConstrant(dlg):
  faceID = dlg.get_item_text('Constraint')   # id=132
  fid = int(faceID)
  creating_status = BoundaryConditions.FixedConstraint(crlTargets=[Face(fid)])
  JPT.Debugger(creating_status)


#--------------------------------------------------------------
def defLoad(dlg):
  laodID = dlg.get_item_text('Load')    # id=136
  lid = int(laodID)
  created_bcs = BoundaryConditions.Force.General(strName="Force1",
                                               forceLBC=FORCE_LBC(vecForce=[0.0,
                                                                            DFLT_DBL, 
                                                                            -10.0]),
                                               crlTargets=[Face(lid)])
  JPT.Debugger(created_bcs)


#--------------------------------------------------------------
def exportFile(dlg):
  name_bdf = dlg.get_item_text('BDFファイル') 

  input_param = NASTRAN_ANALYSIS(iSolverType=6,
                               iGridFormatType=1,
                               dEpsilon=DFLT_DBL,
                               iMaxNumOfIter=DFLT_INT,
                               iNumberOfThreads=1,
                               iMemory=2,
                               iNcpu=1,
                               iSolNo=101,
                               nastranOutputRequest=NASTRAN_OUTPUT_REQUEST(iTypeStrain=0),
                               nastranNonlinear=NASTRAN_NONLINEAR(iMAXITER=DFLT_INT,
                                                                  bUseEPSW=True,
                                                                  dEPSU=DFLT_DBL,
                                                                  dEPSP=DFLT_DBL))
  export_status = Analysis.TSSS.LinearStatic(nastranAnalysis = input_param,
                                           strPath = name_bdf,
                                           iInitTempType=2)
  return name_bdf
  

#--------------------------------------------------------------
def staticAnal(name_bdf):
  sunshine = "C:\\Program Files\\TechnoStar\\Jupiter_5.1\\SunShine\\sunshine.exe"
  split_fold = name_bdf.split("\\")

  fold=split_fold[0]
  leng = len(split_fold)
  for i in range(leng-2):
      fold = fold + "\\" + split_fold[i+1]

  os.chdir(fold)
  print("現在のディレクトリ = "+os.getcwd())  
  process = subprocess.Popen(sunshine+" "+name_bdf)

#--------------------------------------------------------------
def runButton(dlg):
  global name_bdf

  print('-- CADのインポート----')
  importCAD(dlg)

  print('-- メッシュ ----')
  createMesh(dlg)

  print('-- 物質的な定義 ----')
  materialList()
  defMaterial(dlg)

  print('-- 制約定義 ----')
  defConstrant(dlg)

  print('-- ロード定義 ----')
  defLoad(dlg)

  print('-- staticの実行 ----')
  name_bdf = exportFile(dlg)    #計算用モデルファイルの書き出し
  staticAnal(name_bdf)

#--------------------------------------------------------------

    #dlg=JDGCreator(include_apply=False)
