ADVC_Structure()

説明​

ADVCジョブを作成します（構造）

構文​

ADVC_Structure(文字列 名前, 文字列 説明, int ジョブタイプ, カーソル[] 処理シーケンス,
    カーソル[] 要素位置グループ, カーソル[] 節点位置グループ, bool 書き込みグループ,
    カーソル 編集, bool 結果参照, int 分割ファイルタイプ, bool 関連LBCをエクスポート,
    bool エンティティ名を使用, bool 行列ソルバーパラメーター, int 前処理タイプ,
    int 行列構造, カーソル[] ターゲットリスト, int 負荷タイプ, bool 全プロセスで同じ出力,
    bool 浮遊節点を削除, bool 境界条件, bool 境界条件の重複を確認, bool ダミープロパティを自動割り当て,
    カーソル ダミープロパティ材料, bool 参照再起動データ, string 参照再起動データパス,
    int 参照再起動データプロセス数, int 参照再起動データステップ数,
    int 参照再起動データ座標タイプ, int 参照再起動データ更新接触サーチ,
    LoadNodeData[] ロードデータ, int 伝熱対流, bool ボルト固定長のためのプロセスを作成,
    string パス, int 数値型, int UI幅, bool ジオメトリIDをエクスポート,
    bool パート情報を別ファイルに, string ADVCテンプレートファイルパス, bool 出力定義,
    int データ形式タイプ, List 目的関数, List 制約関数, List 非設計可能エリア, List 形状トポロジー, List 最適化出力)

入力​

1. String​

ADVCジョブの名前

2. String​

ADVCジョブの説明

3. Int​

ジョブタイプ [0:構造]

4. Cursor[]​

ADVC処理シーケンス

5. Cursor[]​

要素位置グループ

6. Cursor[]​

節点位置グループ

7. Bool​

書き込みグループフラグ。true = 1、false = 0

8. Cursor​

ADVCジョブを編集

9. Bool​

結果参照フラグ。true = 1、false = 0

10. Int​

分割ファイルタイプ [0:なし、1:モデルごと、2: パートごと、3:選択した パート、4:LBCを選択]

11. Bool​

すべての関連LBCをエクスポートフラグ。true = 1、false = 0

12. Bool​

エンティティ名を使用するフラグ。true = 1、false = 0

13. Bool​

行列ソルバーパラメータを定義するフラグ。true = 1、false = 0

14. Int​

前処理タイプ [0:スケーリング、1:CGCG、2:CGCG2、3:CGCG2_Diag、4:CGCG2-SOR]

15. Int​

行列構造 [0:対称性、1:非対称性]

16. Cursor[]​

ターゲットリスト

17. Int​

負荷タイプ [0:負荷ケース、1:負荷]

18. Bool​

すべての出力が同じフラグ。true = 1、false = 0

19. Bool​

浮遊する節点を削除するフラグ。true = 1、false = 0

20. Bool​

境界条件フラグ。true = 1、false = 0

21. Bool​

境界条件の重複を確認するフラグ。true = 1、false = 0

22. Bool​

ダミープロパティを自動割り当てするフラグ

23. Cursor​

ダミープロパティ材料

24. Bool​

参照再起動データフラグ。true = 1、false = 0

25. String​

参照再起動データパス

26. Int​

参照再起動データプロセス数

27. Int​

参照再起動データステップ数

28. Int​

参照再起動データ座標タイプ

29. Int​

参照再起動データ更新接触サーチ

30. LoadNodeData[]​

ロード節点データリスト

31. Int​

伝熱対流（構造用では使用されません）、0に設定

32. Bool​

ボルト固定長のためのプロセスを作成するフラグ true = 1、false = 0

33. String​

エクスポートされたadxファイルパス

34. Int​

数値型 [0:実数、1:パワー、2:オート]

35. Int​

UI幅

36. Int​

UI精度

37. Bool​

ジオメトリIDをエクスポートフラグ。true = 1、false = 0

38. Bool​

パート情報を別ファイルにエクスポートフラグ。true = 1、false = 0

39. String​

ADVCテンプレートファイルパス

40. Bool​

出力定義フラグ true = 1、false = 0

41. Bool​

データ形式タイプ。[0:シングル、1:ダブル]

42. ObjectiveFunction​

  • Objective Functionを指定する Vector。

  • Optimization_ObjectiveConstraint_Parameter によって定義されます。メンバーは次のとおりです：

    enFunctionType​

    • 関数タイプを指定する Integer。
    ID関数説明
    -1Unknown_Function未選択
    0Compliance_Function適合性関数
    1Displacement_Function変位関数
    2Eigen_Frequency_Function固有周波数関数
    3Mass_Function質量関数
    4Maximum Displacement Function最大変位関数
    5Maximum_Mises_Stress_Function最大直応力関数
    6Maximum_Principal_Stress_Function最大主応力関数
    7Minimum_Principal_Stress_Function最小主応力関数
    8Surface_Area_Function表面積関数
    9Volume_Function体積関数
    10Optimization_Frozen_Node最適化冷凍節点
    11Optimization_Frozen_Element最適化冷凍要素
    12Shape_Optimization_Fixed_Node形状最適化固定節点
    13Shape_Optimization形状最適化
    14Shape_Optimization_Contact_pair形状最適化接触ペア
    15Shape_Optimization_Die_Drawing形状最適化ダイ図面
    16Shape_Optimization_Interference_Node形状最適化干渉節点
    17Shape_Optimization_Thickness形状最適化厚さ
    18Topology_Optimizationトポロジ最適化
    19Topology_Optimization_Die_Drawingトポロジ最適化ダイ図面
    20Optimization_Function_Type_Count最適化関数タイプ数
    • これは必須の入力です。

    strFunctionName​

    • 関数の名前を指定する String。
    • これは必須の入力です。

    iDisplacementRelation​

    • 変位関連を設定する Int。
    • デフォルト値は-1です。

    strDegreeOfFreedomNum​

    • 自由度番号を設定する String。

    dDisplacementCoefficient​

    • 変位係数を設定する Double。

    iConstraint​

    • 制約のタイプを指定する Int。
      • もし iConstraint=0 ならば: 等号
      • もし iConstraint=1 ならば: 不等号

    dConstraintTol​

    • 制約許容値を設定する Double。

    iTargetType​

    • ターゲットタイプを指定する Int。
      • もし iTargetType=0 ならば: 比率
      • もし iTargetType=1 ならば: 値

    dRatioOrValue​

    • 比率または値を指定する Double。

    dCoefficient​

    • 係数を設定する Double。

    crNodeSet​

    • 節点セットを指定する Cursor。

    crPropOrElemSet​

    • 要素セットを指定する Cursor。

    crSurfaceSet​

    • 面セットを指定する Cursor。

    iKSKernel​

    • KSカーネルのタイプを指定する Int。
      • もし iKSKernel=0 ならば: 指数
      • もし iKSKernel=1 ならば: 単項

    dRHO​

    • RHOを指定する Double。

    dExponent​

    • 指数を指定する Double。

    iEigenNumber;​

    • 固有値の番号を指定する Int。

43 制約関数​

  • 制約関数を指定する Vector。
  • Optimization_ObjectiveConstraint_Parameter によって定義されます。

44 非設計可能エリア​

  • 非設計可能エリアを指定する Vector。
  • Optimization_NonDesignableArea_Parameter によって定義されます。メンバーは次のとおりです：

    enFunctionType​

    • 関数タイプを指定する Integer。
    • これは必須の入力です。

    strFunctionName​

    • 関数の名前を指定する String。
    • これは必須の入力です。

    iOptimization = -1​

    • 最適化のタイプを指定する Int。
    • もし iOptimization=0 ならば: 形状
    • もし iOptimization=1 ならば: トポロジ

    strDegreeOfFreedomNum​

    • 自由度番号を指定する String。

    crNodeSet​

    • 節点セットを指定する Cursor。

      crPropOrElemSet​

    • 要素セットを指定する Cursor。

    vecShapeTopology​

    • 形状/トポロジを指定する Vector。
    • Optimization_ShapeTopology_Parameter によって定義されます。メンバーは次のとおりです：

      enFunctionType = Unknown_Function;​

      • 関数タイプを指定する Integer。
      • これは必須の入力です。

        strFunctionName​

      • 関数の名前を指定する String。
      • これは必須の入力です。

        dInitialDensity​

      • 初期密度を指定する Double。

        dDensityRandom​

      • 密度の乱数を指定する Double。

        dAlpha​

      • アルファを指定する Double。

        dDraftAngle​

      • ドラフト角を指定する Double。

        dGap​

      • ギャップを指定する Double。

        dDepth​

      • 深さを指定する Double。

        dAngle​

      • 角度を指定する Double。

        dClearance​

      • クリアランスを指定する Double。

        dThicknessDepth​

      • 厚さ深さを指定する Double。

        dMaxThickness​

      • 最大厚みを指定する Double。

        dMinThickness​

      • 最小厚みを指定する Double。

        iMaxIteration​

      • 最大反復数を指定する Int。

        dMaxStrain​

      • 最大ひずみを指定する Double。

        dMaxTheta​

      • 最大シータを指定する Double。

        dH1Tolerance​

      • H1許容値を指定する Double。

        iOutputLast​

      • 最後の出力の選択を指定する Int。
      • もし iOutputLast=0 ならば: いいえ
      • もし iOutputLast=1 ならば: はい

        iOutputInterval​

      • 出力間隔を指定する Int。

        iResoutLast​

      • 最終結果の選択を指定する Int。
      • もし iResoutLast=0 ならば: いいえ
      • もし iResoutLast=1 ならば: はい

        iResoutInterval​

      • リソルト間隔を指定する Int。

        iArmijoCheck​

      • Armijoチェックの選択を指定する Int。
      • もし iArmijoCheck=0 ならば: いいえ
      • もし iArmijoCheck=1 ならば: はい

        dArmijoParam​

      • Armijoパラメータを指定する Double。

        strDirection​

      • 方向を指定する String。

        iPunchingOneSide​

      • パンチング|外側の選択を指定する Int。
      • もし iPunchingOneSide=0 ならば:
