バージョン: 5.1.0

ContactAbaqus()

説明​

ABAQUS用の接触を作成します。

構文​

ContactAbaqus(String m_strName,int m_iMethod,int m_iType,int m_iAlg,double AdjustVal,
    double ExtensionZone,double MaxPenetration,int SmallSliding,double Smooth,
    int FrictionType,double FrictionCoef1,double FrictionCoef2,double ShearLimit,
    double SlipTol,double StaticFrictionCoef,double KineticFrictionCoef,double DecayCoef,
    int bAdjust,double PositonTol,int formula,int tie,int m_type,int m_bAllowSeparation,
    double m_slope,TSheetd m_table,int m_clearanceType,int m_TypeId,
    bool m_btemperatureDependency,int m_idependencies,TSheetd m_table,int m_TypeId,
    bool m_btemperatureDependency,int m_idependencies,TSheetd m_table,Cursor[] m_taTarget,
    Cursor m_crEditCursor,int m_Color)

入力​

1. String​

接触名

2. Int​

方法の種類[0:MANUAL_FACE; 1:MANUAL_GROUP; 2:BY_GROUP_MATRIX; 3:SHARE_FACE; 4:AUTO_SETTING; 5:METHOD_UNKNOWN]

3. Int​

接触の種類[0:CONTACT_GENERAL; 1:CONTACT_TIED; 2:CONTACT_ALL_SELF]

4. Int​

アルゴリズム[0:face to face; 1:node to face]

5. Double​

調整値

6. Double​

拡張ゾーン

7. Double​

最大予圧

8. Int​

小さな摺動[0:Off; 1:On]

9. Double​

スムース

10. Int​

摩擦の種類[0:None; 1:General; 2:Lagrange; 3:Rough; 4:Static and Kinematic]

11. Double​

摩擦係数1

12. Double​

摩擦係数2

13. Double​

せん断限界

14. Double​

スリップ許容差

15. Double​

静止摩擦係数

16. Double​

運動摩擦係数

17. Double​

減衰係数

18. Int​

調整[0:No; 1:Yes]

19. Double​

位置許容差

20. Int​

公式[0:Node to Surface; 1:Surface to Surface]

21. Int​

TIE[0:No]

22. Int​

圧力-過剰結合の種類[0:Hard Contact; 1:Exponential; 2:Linear; 3:Tabular]

23. Int​

分離を許可

24. Double​

接触剛性

25. TSheetd​

圧力-過剰結合の表

26. Int​

熱伝導率の種類[0:Clearance Dependence; 1:Pressure Dependence; 2:Clearance and Pressure Dependence]

27. Int​

種類[0:CLEARANCE_DEPENDENCY; 1:PRESSURE_DEPENDENCY]

28. Bool​

温度依存データの使用

29. Int​

フィールド変数の数

30. TSheetd​

間隙依存の表

31. Int​

種類[0:CLEARANCE_DEPENDENCY; 1:PRESSURE_DEPENDENCY]

32. Bool​

温度依存データの使用

33. Int​

フィールド変数の数

34. TSheetd​

圧力依存の表

35. Cursor[]​

対象

36. Cursor​

編集カーソル

37. Int​

接触メーカーの色

戻り値​

1 - 関数が正常に実行されました。

0 - 実行できません。

サンプルコード​

ContactAbaqus("Test",1,1,1,0.001,0.001,0.001,1,0.001,1,0.001,0.001,0.001,0.001,
    0.001,0.001,0.001,1,0.001,1,1,1,1,0.001,,1,1,1,1,,1,1,1,,[1:11,2:12],1:11,1)
