メッセージボックス

🎯 はじめに​

本チュートリアルでは JPT.MessageBoxPSJ() を使用してユーザーにメッセージを表示する方法を紹介します:

  1. Python APIウィンドウにすべてのメッセージボックスタイプを表示する。これによりユーザーはすべてのメッセージボックスタイプを参照して適切に使用することが出来る。
  2. 情報-はいボタン-いいえボタン-キャンセルボタンで構成されるタイプのメッセージボックスを作成する。
  3. ユーザーが選択したメッセージボタンの戻り値を取得し、Python APIウィンドウに表示する。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# Python APIウィンドウに使用可能なメッセージボックスの全種類の情報を表示します。
JPT.Debugger(JPT.MsgBoxType.values)

# 情報-はいボタン-いいえボタン-キャンセルボタンで構成されるタイプのメッセージボックスを作成します。
# ユーザーからのメッセージボックスの戻り値を格納するために"answer"を使用します。
answer = JPT.MessageBoxPSJ("入力情報: メッセージの内容が表示されます。", JPT.MsgBoxType.MB_INFORMATION_YESNOCANCEL)

# ユーザーからのメッセージボックスの戻り値を取得し、Python APIウィンドウに表示します。
if answer == "YES":
    print ("'はい'ボタンを選択しました")
elif answer == "NO":
    print ("'いいえ'ボタンを選択しました")
else:
    print ("'キャンセル'ボタンを選択しました")
