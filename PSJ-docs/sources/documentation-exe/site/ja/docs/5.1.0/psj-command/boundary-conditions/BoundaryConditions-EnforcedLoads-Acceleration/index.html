BoundaryConditions.EnforcedLoads.Acceleration()

説明​

フェース、エッジ、または節点に強制加速度を作成します。ユーザーは強制加速度パラメータを入力し、指定した場所に強制加速度を返します。

構文​

BoundaryConditions.EnforcedLoads.Acceleration(...)

リボン: BoundaryConditions » EnforcedLoads » Acceleration

入力​

strName​

  • 強制加速度ロードの名前を指定する String 。
  • デフォルト値は「EnforcedAcceleration1」です。

dAccelUx​

  • X方向の強制加速度値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dAccelUy​

  • Y方向の強制加速度値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dAccelUz​

  • Z方向の強制加速度値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dAccelRx​

  • X回転方向の強制加速度値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dAccelRy​

  • Y回転方向の強制加速度値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dAccelRz​

  • Z回転方向の強制加速度値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

crCurCoord​

  • ロードの参照座標系を指定する Cursor 型。
  • デフォルト値は None（グローバル座標）です。

iArrowDir​

  • 矢印の表示方法を指定する Integer 。このパラメータはロード設定の表示にのみ影響します。
    • 次の値のいずれかを取ります。
      • 0: 節点で始まる
      • 1: 節点で終わる
  • デフォルト値は 0 です。

crTable​

  • BoundaryConditions.FieldData 関数から作成されたテーブルを指定する Cursor 型。
  • デフォルト値は None です。

dPhase​

  • 位相値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dDelay​

  • 遅延値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

crPhaseTable​

  • BoundaryConditions.FieldData 関数から作成された位相テーブルを指定する Cursor 型。
  • デフォルト値は None です。

bExport​

  • マルチエキサイトロードエクスポートを有効または無効にするかを指定する Boolean 型。
  • デフォルト値は False です。

crMEExportUx​

  • X移動方向の複数点入力用のテーブルを指定する Cursor 型。
  • デフォルト値は None です。

crMEExportUy​

  • Y移動方向の複数点入力用のテーブルを指定する Cursor 型。
  • デフォルト値は None です。

crMEExportUz​

  • Z移動方向の複数点入力用のテーブルを指定する Cursor 型。
  • デフォルト値は None です。

crMEExportRx​

  • X回転方向の複数点入力用のテーブルを指定する Cursor 型。
  • デフォルト値は None です。

crMEExportRy​

  • Y回転方向の複数点入力用のテーブルを指定する Cursor 型。
  • デフォルト値は None です。

crMEExportRz​

  • Z回転方向の複数点入力用のテーブルを指定する Cursor 型。
  • デフォルト値は None です。

iAccelTransUnit​

  • 移動の強制加速度の入力単位系を指定する Integer 。
  • デフォルト値は 0 です。

iAccelRotUnit​

  • 回転の強制加速度の入力単位系を指定する Integer 。
  • デフォルト値は 0 です。

crlTargets​

  • 強制加速度を適用するターゲットのリストを指定する List of Cursor 型。ターゲットにはフェース、エッジ、または節点が指定できます。
  • これは必須の入力です。

crEdit​

  • 既存の強制加速度を指定する Cursor 型。
    • このパラメータを使用すると、指定された強制加速度が変更されます。
    • 使用しない場合は None のままにすると、新しい強制加速度が作成されます。
  • デフォルト値は None です。

戻り値​

作成された LBC を指定する Cursor 型。

サンプルコード​

Geometry.Part.Cube()

created_bcs = BoundaryConditions.EnforcedLoads.Acceleration(dAccelUz=0.01, 
                                                            crlTargets=[Face(26)])

JPT.Debugger(created_bcs)
