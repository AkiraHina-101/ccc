Analysis.ADVC.Structure()

説明​

構造解析のためのADVC（*.adx）ファイルを作成してエクスポートします。

構文​

Analysis.ADVC.Structure(...)

リボン: Analysis » ADVC » Structure

入力事項​

strName​

  • ADVC解析のジョブ名を指定する String の値です。この名前は、アセンブリツリー内の解析ジョブの名前であり、エクスポート後のADXファイルの名前になります。
  • デフォルト値は""です。

strDescription​

  • ADVC解析ジョブの説明を指定する String の値です。説明はADXファイルに記述され、内容はModelInfoセクションの下に書かれます。
  • デフォルト値は""です。

crlProcessSequence​

  • ADVCプロセスシーケンスのリストを指定する List of Cursor 型の値です。この引数は、プロセスソリューションタイプとその設定情報を制御します。
  • デフォルト値は[]です。

crlElemLocationGroup​

  • 要素の配置場所のリストを指定する List of Cursor 型の値です。この引数は、モデル内の要素グループ（3D要素、2D要素、1D要素など）を使用します。
  • デフォルト値は[]です。

crlNodeLocationGroup​

  • 節点の配置場所のリストを指定する List of Cursor 型の値です。この引数は、モデル内の節点グループを使用します。
  • デフォルト値は[]です。

bWriteGroup​

  • 選択されたグループの情報を出力するかどうかを指定する Boolean 型の値です。このオプションを有効にすると、ADXファイルにPart、Face、Element（3D、2D、1D）、Nodeなどのグループ情報が含まれます。
    • もし True であれば、ADXファイルにグループ情報が含まれます。
    • もし False であれば、ADXファイルにグループ情報は含まれません。
  • デフォルト値は False です。

crEdit​

  • 変更する既存のADVCジョブを指定する Cursor 型の値です。このパラメーターを使用すると、指定されたADVCジョブが変更されます。もし None のままであれば、新しいADVCジョブが作成されます。
  • デフォルト値は None です。

bResultReference​

  • Result Referenceオプションが定義されているかどうかを指定します Boolean 型の値です。
    • もし True であれば、このオプションはResult Referenceの設定を有効にします。Result Reference引数の設定は使用できます。
    • もし False であれば、このオプションはResult Referenceの設定を無効にします。この場合、Result Reference引数の設定は無視されます。
  • デフォルト値は False です。

iSeparateFile​

  • 分割ファイルタイプを指定する Integer の値です。このオプションにより、多くのエクスポートされたADXファイルに情報を分割して格納できます。
    • もし iSeparateFile=0 であれば: なし、このオプションはモデル内のすべての パート/パートの情報を含む1つのADXファイルのみをエクスポートします（ModelInfo、Unit、Geometry、LBCs、Process Sequenceなど）
    • もし iSeparateFile=1 であれば: モデルごと、このオプションは、1つ目のADXファイルが同じ名前の解析ジョブに一般情報（ModelInfo、Unit、LBCs、ジョブ名、プロセスシーケンス、ADVC構造解析の他の設定）を含む、2つのADXファイルをエクスポートします。 そして最後の1つのADXファイルは、ジオメトリ情報（Node、Part、Element ... ）が含まれます
    • もし iSeparateFile=2 であれば: パートごと、このオプションは個々のモデル内の各 パート/パートに配置されたジオメトリ情報、モデル内のグループは別のファイルに書かれます。他の情報は解析ジョブの同じ名前のADXファイルに書かれます。
    • もし iSeparateFile=3 であれば: 選択した パートに関する情報を書き込む、このオプションはADVCファイルをエクスポートします。選択が特定の パート/パートを持たない場合、Jupiterはすべての パート/パート（「なし」オプションと同じ）を書き込みます。
    • もし iSeparateFile=4 であれば: 選択したLBCs、このオプションは選択したLBCsのLBC情報を含む1つのADXファイルをエクスポートします。
  • デフォルト値は0です。

bExportRelatedAllLBCs​

  • すべての関連するLoad Boundary Conditionをエクスポートするオプションを有効にするかどうかを指定する Boolean 型の値です。このオプションは、iSeparateFile=3（選択した パートごとに）のときに使用できます。この設定は True または False に関係なくアクティブ化されます。
    • もし True であれば、このオプションは、Contact、Connection RBE、Bolt PretensionなどのLBCに関連する情報を含むADXファイルがエクスポートされます。
    • もし False であれば、このオプションはContact、Connection RBE、Bolt PretensionなどのLBCに関連する情報を含むADXファイルがエクスポートされません。
  • デフォルト値は False です。

bUseEntityName​

  • エクスポートされたファイルでエンティティ名を使用するかどうかを指定する Boolean 型の値です。
    • もし True であれば、Entity名（Part/Entity名）を、Part、Faceなどのジオメトリ情報に書き込むADXファイルをエクスポートします。
    • もし False であれば、エンティティ名を含まないADXファイルをエクスポートします。
  • デフォルト値は False です。

bMatrixSolverParam​

  • 行列ソルバーパラメーターが定義されているかどうかを指定する Boolean 型の値です。
    • もし True であれば、このオプションは、行列ソルバーパラメーターの設定を有効にします。行列ソルバーパラメーターの引数設定は使用できます。
    • もし False であれば、このオプションは、行列ソルバーパラメーターの設定を無効にします。この場合、行列ソルバーパラメーターの設定は、ユーザーが値を設定していても無視されます。
  • デフォルト値は False です。

iPreconditionType​

  • 前処理タイプを指定する Integer の値です。
    • もし iPreconditionType=0 であれば: スケーリング
    • もし iPreconditionType=1 であれば: CGCG
    • もし iPreconditionType=2 であれば: CGCG2
    • もし iPreconditionType=3 であれば: CGCG2_Diag
    • もし iPreconditionType=4 であれば: CGCG2-SOR
  • デフォルト値は0です。

iMatrixStructure​

  • 行列構造タイプを指定する Integer の値です。
    • もし iMatrixStructure=0 であれば: 対称
    • もし iMatrixStructure=1 であれば: 非対称
  • デフォルト値は0です。

crlTargets​

  • ターゲットのリストを指定する List of Cursor 型の値です。ターゲットはPartまたはLBCs項目です。
  • デフォルト値は[]です。

iLoadType​

  • 解析に使用するロードタイプを指定する Integer の値です。
    • もし iLoadType=0 であれば: Load Case、モデルに適用される特定のロードやBCをグループ化したもの。モデルは同じLBC設定を持つ多くのロードケースを適用することが可能です。ADXファイルをエクスポートすると、すべてのロードケースが書かれます。
    • もし iLoadType=1 であれば: Load、モデルの全てのロード、BCを1つのロードケースとしてエクスポートします。
  • デフォルト値は1です。

bSameOutputOnAllProcess​

  • すべてのプロセスに同じ出力リクエストを設定するかどうかを指定する Boolean 型の値です。
    • もし True であれば、定義されたすべてのプロセスに同じ出力リクエスト（変位、応力、歪みなど）が設定されます。
    • もし False であれば、各プロセスに対してユーザーが望む結果に基づく出力リクエストが設定されます。
  • デフォルト値は True です。

bDeleteFloatingNode​

  • 浮遊節点を削除するかどうかを指定する Boolean 型の値です。
    • もし True であれば、浮遊節点情報のないADXファイルがエクスポートされます。
    • もし False であれば、浮遊節点情報を含むADXファイルがエクスポートされます。
  • デフォルト値は True です。

bBC​

  • 境界条件を分離するかどうかを指定する Boolean 型の値です。この設定は_iSeparateFile=3_（選択した パートごとに）のときに使用できます。この設定は、True または False に関係なくアクティブ化されます。
    • もし True であれば、LBC情報が書かれたADXファイルがエクスポートされます。
    • もし False であれば、LBC情報を書かないADXファイルがエクスポートされます。
  • デフォルト値は True です。

bCheckBCDuplicate​

  • 境界条件が重複しているかどうかを確認するかどうかを指定する Boolean 型の値です。
    • もし True であれば、ADXファイルをエクスポートする際にLBCの重複をチェックします。
    • もし False であれば、ADXファイルをエクスポートする際にLBCの重複をチェックしません。
  • デフォルト値は False です。

bAutoAssignDummyProp​

  • ダミープロパティを自動的に割り当てるオプションを設定するかどうかを指定する Boolean 型の値です。このオプションは、まだプロパティが割り当てられていないモデルに対して使用されます。モデルにプロパティがすでにある場合
    • もし True であれば、プロパティが割り当てられていないPartにダミープロパティ（プロパティがまだ割り当てられていないPart）を割り当てます。他のすでにプロパティが割り当てられたPartは、そのプロパティ設定でエクスポートされます。
    • もし False であれば、モデル内のすべてのPartにプロパティが割り当てられている場合、ファイルはエクスポートされますが、モデル内のPartにプロパティが1つも割り当てられていない場合、このオプションを使用してファイルはエクスポートされません。
  • デフォルト値は False です。

crDummyPropMaterial​

  • ダミープロパティをエクスポートする際に使用されるダミープロパティ素材を指定する Cursor 型の値です。
  • デフォルト値は None です。

bReferenceRestartData​

  • Reference Restart Dataが定義されているかどうかを指定する Boolean 型の値です。
    • もし True であれば、このオプションはReference Restart Dataの設定を有効にします。Reference Restart Dataの引数設定は使用
