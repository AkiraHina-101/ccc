Connections.Contacts.ADVC.ManualFace()

説明​

ADVCソルバーで指定したフェース間の接触設定を定義します。

構文​

Connections.Contacts.ADVC.ManualFace(...)

リボン：Connections » Contacts » ADVC » ManualFace

入力​

crlMasterFaces​

  • マスターフェースを指定する Cursor のリスト。
  • これは必須入力です。

crlSlaveFaces​

  • スレーブフェースを指定する Cursor のリスト。
  • これは必須入力です。

strName​

  • 接触名を指定する String 。
  • デフォルト値は「ContactADVC」です。

iContactType​

  • 接触定義の挙動タイプを指定する Integer 。接触定義の挙動タイプは次のいずれかです。
    • 0: 一般タイプ（スライディング接触）
    • 1: Tied Type（シェル-ソリッド接触）
  • デフォルト値は0です。

iSlidingType​

  • スライディングタイプを指定する Integer 。
    • 0: なし。
    • 1: 有限スライディング。
    • 2: 小さなスライディング。
    • 3: スライディングしない。
  • デフォルト値は0です。

iInitialState​

  • 初期接触状態を指定する Integer 。
    • 0: なし。
    • 1: 自動 - 自動検出。
    • 2: オープン - 非接触状態から解析を開始
    • 3: クローズ - 接触状態から解析を開始します。
  • デフォルト値は0です。

dInitialStateTol​

  • 初期接触状態を決定するための許容値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dKineticFrictionCoef​

  • 動摩擦係数を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dExponentialCoef​

  • 指数減衰係数を指定する Double 。
  • デフォルト値は DFLT_DBL です。

iBehavior​

  • 接触の有無を指定する Integer 。
    • 0: 分離 - 引張力が生成されるとき、接触拘束を削除します。
    • 1: 分離なし - 接触探索の最初に見つかったすべての接触ペアにバインディングします。
  • デフォルト値は0です。

dClearance​

  • クリアランス量を指定する Double 。
  • デフォルト値は DFLT_DBL です。

iAdjustToClearance​

  • クリアランスに従って折り畳み要素を回避するかどうかを指定する Integer 。この引数は iSlidingType=0 または iSlidingType=2 の場合にアクティブです。
    • 0: なし。
    • 1: はい。
    • 2: いいえ。
  • デフォルト値は0です。

dInterference​

  • 干渉を指定する Double 。
  • デフォルト値は DFLT_DBL です。

iAdjustToInterference​

  • 干渉に対応するかどうかを指定する Integer 。この引数は iSlidingType=1 または iSlidingType=3 の場合にアクティブです。
    • 0: なし。
    • 1: はい。
    • 2: いいえ。
  • デフォルト値は0です。

iAutoShrink​

  • 浸透排除の有無を指定する Integer 。
    • 0: なし。
    • 1: はい。
    • 2: いいえ。
  • デフォルト値は0です。

iAdjust​

  • 格差をゼロにするためにスレーブ節点をマスターサーフェス上で移動するかどうかを指定する Integer 。
    • 0: なし。
    • 1: はい - すべてのスレーブ節点を移動します。
    • 2: 値 - 節点移動を有効にする距離を定義します。
  • デフォルト値は0です。

dAdjustValue​

  • 節点移動を有効にする距離を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dFrictionCoef​

  • 静止摩擦係数を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dMaxShear​

  • 最大せん断応力を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dElasticSlip​

  • 許容されるスリップ量を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dSlipTolerance​

  • 許容されるスリップ許容値を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dSearchWidth​

  • 接触面の方向における内側と外側の判定パラメータを指定する Double 。
  • デフォルト値は DFLT_DBL です。

dSearchGap​

  • ギャップ面の法線方向検索距離を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dSearchDepth​

  • 浸透面の法線方向検索距離を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dCriticalPenetration​

  • 臨界浸透量を指定する Double 。
  • デフォルト値は DFLT_DBL です。

iEstimationImpactTime​

  • 衝突および解除時間の予測により接触ペアを指定する Integer 。
    • 0: なし。
    • 1: はい。
    • 2: いいえ。
  • デフォルト値は0です。

iFormula​

  • 接触形成タイプを指定する Integer 。
    • 0: なし。
    • 1: 節点とセグメント：節点 - フェース接触
    • 2: セグメントとセグメント：フェース - フェース接触。
  • デフォルト値は0です。

iConstraintType​

  • 接触制約タイプを指定する Integer 。
    • 0: なし。
    • 1: ラグランジュ - ラグランジュ未定乗数法。
    • 2: ペナルティ - ペナルティ法。
  • デフォルト値は0です。

iThermalDataType​

  • クリアランス依存性の熱伝達係数を指定する Integer 。
    • 0: なし。
    • 1: クリアランス依存性 - クリアランス依存性の熱伝達係数を定義します。
    • 2: 導熱 - 熱伝達係数。
    • 3: クリアランス - クリアランス
  • デフォルト値は0です。

iTypeId​

  • タイプIDを指定する Integer 。
    • 0: CLEARANCE_DEPENDENCY.
    • 1: PRESSURE_DEPENDENCY.
  • デフォルト値は0です。

bTemperatureDependency​

  • 温度依存データを使用するかどうかを指定する Boolean 。
  • デフォルト値は False です。

iNumDependencies​

  • 依存関係の数を指定する Integer 。
  • デフォルト値は0です。

tshTableClearance​

  • クリアランス依存性のテーブルを指定する Table Sheet 。
  • デフォルト値は[]です。

bStabilized​

  • 安定化パラメータが定義されているかどうかを指定する Boolean 。
  • デフォルト値は0です。

iStabilizeType​

  • 接触安定化係数のタイプを指定する Integer 。
    • 0: なし。
    • 1: 剛性 - 剛性比率。
    • 2: エリア - エリア比率。
  • デフォルト値は0です。

dResidualFactor​

  • 補正係数C1を定義するために使用される残留係数を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dEffectiveDist​

  • 補正係数C2を定義するために使用される有効距離を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dCN​

  • 法線方向安定化係数を指定する Double 。
  • デフォルト値は DFLT_DBL です。

dCT​

  • 接触面での接触方向の安定化係数を指定する Double 。
  • デフォルト値は DFLT_DBL です。

crlClearances​

  • クリアランスデータのリストを指定する Cursor 。
  • デフォルト値は[]です。

crContactADVC​

  • 既存の接触設定アイテムを指定する Cursor 。このパラメータを使用すると、指定した接触設定アイテムが変更されます。 None のままにしておくと、新しい接触設定アイテムが作成されます。
  • デフォルト値は None です。

dSearchAngle​

  • マスター/スレーブサーフェスの法線ベクトルの検索角度を指定する Double 。
  • デフォルト値は DFLT_DBL です。

iConstraintTypeExplicit​

  • 明示的動力学解析における接触制約タイプを指定する Integer 。
    • 0: なし。
    • 1: Kinematic：制約方法。
    • 2: Penalty：ペナルティ法。
  • デフォルト値は0です。

dPenaltyFact​

  • ペナルティのスケールファクターを指定する Double 。
  • デフォルト値は DFLT_DBL です。

dPenaltyFactExplicit​

  • 明示的動力学解析におけるペナルティスケールファクターを指定する Double 。
  • デフォルト値は DFLT_DBL です。

iColor​

  • 接触色を指定する Integer 。
  • デフォルト値は16711680です。

iAlgorithm​

  • 接触設定の対象エンティティを指定する Integer 。
    • 0: フェースからフェース
  • デフォルト値は0です。

iMethod​

  • メソッドタイプを指定する Integer 。
    • 0: MANUAL_FACE.
    • 1: MANUAL_GROUP.
    • 2: BY_GROUP_MATRIX.
    • 3: SHARE_FACE.
    • 4: AUTO_SETTING.
  • デフォルト値は0です。

bPressureTemperatureDependency​

  • 圧力温度依存データを使用するかどうかを指定する Boolean 。
  • デフォルト値は False です。

iPressureDependencies​

  • 圧力依存データの数を指定する Integer 。
  • デフォルト値は0です。

tshPressureData​

  • 圧力依存データのテーブルを指定する Table Sheet 。
  • デフォルト値は[]です。

戻り値​

作成された接触を指定する Cursor 。

サンプルコード​

Geometry.Part.Cube(iPartColor=12537679)
Geometry.Part.Cube(dlOrigin=[0.01, 0.0, 0.0], 
                   strName="Cube_2", 
                   iPartColor=6250449)

created_contact = Connections.Contacts.ADVC.ManualFace(crlMasterFaces=[Face(24)], 
                                                       crlSlaveFaces=[Face(49)], 
                                                       strName="ContactADVC1", 
                                                       iInitialState=1, 
                                                       dInitialStateTol=1.0, 
                                                       dKineticFrictionCoef=1.0, 
                                                       dExponentialCoef=1.0, 
                                                       iBehavior=1, 
                                                       iAdjustToClearance=2, 
                                                       dInterference=2.0, 
                                                       iAdjustToInterference=1, 
                                                       iAdjust=2, 
                                                       dFrictionCoef=1.0, 
                                                       dMaxShear=1.0, 
                                                       dElasticSlip=1.0, 
                                                       dSlipTolerance=1.0, 
                                                       dSearchWidth=1.0, 
                                                       dSearchGap=1.0, 
                                                       dSearchDepth=1.0, 
                                                       dCriticalPenetration=1.0, 
                                                       iFormula=1, 
                                                       iThermalDataType=2, 
                                                       iTypeId=1, 
                                                       tshTableClearance=[1, 
                                                                          2, 
                                                                          0, 
                                                                          0], 
                                                       bStabilized=True, 
                                                       iStabilizeType=2, 
                                                       dSearchAngle=1.0, 
                                                       iConstraintTypeExplicit=2, 
                                                       dPenaltyFact=1.0, 
                                                       dPenaltyFactExplicit=1.0, 
                                                       tshPressureData=[1, 
                                                                        2, 
                                                                        0, 
                                                                        0])
