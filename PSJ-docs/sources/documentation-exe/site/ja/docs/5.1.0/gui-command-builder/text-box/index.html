TextBox

テキストボックスを作成します。

プレビューダイアログ:

パラメーター​

デフォルト​

デフォルトで表示されるテキストを入力してください。

配置​

ボックス内のテキストの表示位置を指定します。

  • 左 : 左寄せ
  • 右 : 右寄せ
  • 中央 : 中央寄せ

読み取り専用​

  • オン をチェック : テキストを編集できません（コピーは可能）
  • オフ をチェック : テキストを編集できます

名前​

テキストボックスの名前を入力してください。

サイズ​

  • 幅 : テキストボックスの最小幅を指定します。（ピクセル単位）
  • 高さ : テキストボックスの最小高さを指定します。（ピクセル単位）

タイプ​

テキストボックスに入力できるデータ型（検証用）を指定します。

  • 文字列 : 文字列型
  • 倍精度浮動小数 : 倍精度浮動小数点数型
  • 整数 : 整数型

有効​

有効にするかどうかを指定します。

  • オン をチェック : 利用可能
  • オフ をチェック : 利用不可（グレーアウト）

色​

  • 背景色 : テキストボックスの背景色を指定します。
  • テキスト色 : テキストボックス内で表示されるテキストの色を指定します。

フォント​

  • サイズ : テキストボックス内で表示されるテキストのサイズを指定します。
  • 太字 : 太字テキストを有効にするかを指定します。
    • オン をチェック : テキストを太字にします
    • オフ をチェック : テキストを太字にしません
  • 斜体 : テキストを斜体にするかを指定します。
    • オン をチェック : テキストを斜体にします
    • オフ をチェック : テキストを斜体にしません
  • 下線 : テキストに下線を付けるかを指定します。
    • オン をチェック : テキストに下線を付けます
    • オフ をチェック : テキストに下線を付けません
  • 取り消し線 : テキストに取り消し線を引いて消すかを指定します。
    • オン をチェック : 取り消し線を引いてテキストを消します
    • オフ をチェック : 取り消し線を引いてテキストを消しません

表示​

作成したテキストボックスの表示/非表示を指定します。

  • オン をチェック : 表示
  • オフ をチェック : 非表示

関連するAPI​

  • dlg.add_textbox : 作成中のダイアログにテキストボックスを追加します。
