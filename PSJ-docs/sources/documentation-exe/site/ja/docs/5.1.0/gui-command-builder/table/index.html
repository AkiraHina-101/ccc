Table

テーブルを作成します。

プレビューダイアログ:

パラメータ​

名前​

テーブルの名前を入力してください。

有効​

有効にするかどうかを指定します。

  • オン チェック：利用可能
  • オフ チェック：利用不可（グレーアウト）

グリッド線を表示​

グリッド線の表示または非表示を設定します。

  • オン チェック：グリッド線を表示
  • オフ チェック：グリッド線を非表示

行番号を表示​

行ヘッダーの表示または非表示を設定します。

  • オン チェック：行ヘッダーを表示
  • オフ チェック：行ヘッダーを非表示

カラムのヘッダーを表示​

列ヘッダーの表示または非表示を設定します。

  • オン チェック：列ヘッダーを表示
  • オフ チェック：列ヘッダーを非表示

サイズ​

  • 幅 : テーブルの最小幅を指定します（ピクセル単位）
  • 高さ : テーブルの最小高さを指定します（ピクセル単位）

挙動​

テーブルの動作状態を指定して、サイズを柔軟に制御します。

  • Greedy : ダイアログサイズに合わせてテーブルサイズを変更できる、ユーザー入力の幅と高さで表示テーブルを設定
  • Fixed : ダイアログサイズに合わせてテーブルサイズを変更しない、ユーザー入力の幅と高さで表示テーブルを設定
  • Horizontal : ユーザー入力に基づいて高さを固定した表示テーブルを設定し、テーブルサイズの変更は水平方向のみ有効
  • Vertical : ユーザー入力に基づいて幅を固定した表示テーブルを設定し、テーブルサイズの変更は垂直方向のみ有効

ポップアップメニューオプション​

右クリックメニューを表示します。

サポートされるオプション: 切り取り、コピー、貼り付け、行を挿入、行の削除、クリアー、ファイルから読み込み、ファイルに書き出し

全行数​

行数を指定します。

全列数​

列数を指定します。

列の設定​

列の種類を指定します。

Heading*：列の内容タイプを指定します。

表示​

作成したテーブルを表示/非表示にするかを指定します。

  • オン チェック：表示
  • オフ チェック：非表示

関連付けられたAPI​

  • dlg.add_table : ダイアログにテーブルを追加します。
  • dlg.add_table_right_menu : テーブルのコンテキストメニュー（右クリックイベント）にオプションを追加します。
  • dlg.enable_table_column_filter : テーブルの列のフィルターオプションを追加します。
  • dlg.enable_drag_table_row : テーブルの行を上下にドラッグできるようにします。
  • dlg.get_cell_label : テーブル内のボタンセル、チェックボックスセル、コンボボックスセルのラベルを取得します。
  • dlg.get_cell_value : テーブルの特定のセルの値を取得します。
  • dlg.get_table_column_width : テーブル内の指定された列の幅を取得します。
  • dlg.get_table_sel_cell : 選択したセルの情報と属性を取得します。
  • dlg.get_table_sel_range : 選択した範囲（複数セル）の情報と属性を取得します。
  • dlg.get_total_row : テーブルの総行数を取得します。
  • dlg.get_total_column : テーブルの総列数を取得します。
  • dlg.get_table_cell_fill_color : 選択された/指定されたセルの塗りつぶし色を取得します。
  • dlg.insert_table_rows : テーブル内の特定の位置に行を挿入します。
  • dlg.insert_table_columns : テーブル内の特定の位置に列を挿入します。
  • dlg.delete_table_row : テーブル内の特定の位置の行を削除します。
  • dlg.delete_table_column : テーブル内の特定の位置の列を削除します。
  • dlg.is_table_cell_button : 入力セルがボタンセルかどうかを確認します。
  • dlg.is_table_cell_checkbox : 入力セルがチェックボックスセルかどうかを確認します。
  • dlg.is_table_cell_combobox : 入力セルがコンボボックスセルかどうかを確認します。
  • dlg.is_table_cell_checked : チェックボックスセルの状態を確認します。
  • dlg.on_table_right_menu : コンテキストメニューを開く/実行する際のイベントを設定します。
  • dlg.on_table_sel_changed : セルを選択した際のイベントを設定します。
  • dlg.on_table_button_clicked : ボタンセルを選択した際のイベントを設定します。
  • dlg.set_cell_value : 特定のセルに値を設定します。
  • dlg.set_table_cell_fill_color : 選択された/指定されたセルに塗りつぶし色を設定します。
  • dlg.set_table_cell_text_color : 選択された/指定されたセル内のテキストの色を設定します。
  • dlg.set_table_cell_alignment : セルのテキスト配置を設定します。
  • dlg.set_table_column_width : テーブル内の指定された列の幅を設定します。
  • dlg.set_table_column_data_type : テーブルのセルのデータタイプ検証を設定します。
  • dlg.set_table_cell_button : テーブルにボタンセルを設定します。
  • dlg.set_table_cell_checkbox : テーブルにチェックボックスセルを設定します。
  • dlg.select_table_range : テーブル内の特定範囲を選択します。
  • dlg.clear_table_range : テーブル内の特定範囲のコンテンツをクリアします。
  • dlg.clear_table_all : テーブルのすべてのコンテンツをクリアします。
  • dlg.clear_table_cell : テーブル内の特定のセルのコンテンツをクリアします。
