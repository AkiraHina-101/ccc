CheckBox

チェックボックスを作成します。

プレビューダイアログ：

パラメータ​

テキスト​

チェックボックスの横に表示されるテキストを入力してください。

名前​

チェックボックスの名前を入力してください。

チェック​

デフォルトの状態を指定します。

  • オン にチェック → チェック済み
  • オフ にチェック → 未チェック

サイズ​

  • 幅 ： チェックボックスの最小幅を指定します（ピクセル単位）
  • 高さ ： チェックボックスの最小高さを指定します（ピクセル単位）

有効​

有効にするかどうかを指定します。

  • オン にチェック → 利用可能
  • オフ にチェック → 利用不可（グレー表示）

左側のテキスト​

チェックボックスの左側にテキストを表示します。

  • オン にチェック → テキストが左側に表示されます
  • オフ にチェック → デフォルト（右側）にテキストが表示されます

表示​

作成された CheckBox を表示/非表示にするかを指定します。

  • オン にチェック → 表示
  • オフ にチェック → 非表示

関連する API​

  • dlg.add_checkbox ：ダイアログに CheckBox を追加します。
  • dlg.set_checkbox_state ：CheckBox の状態をチェック済みまたは未チェックに設定します。
