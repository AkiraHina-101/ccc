Button

ボタンを作成します。

プレビューダイアログ：

パラメータ​

テキスト​

ボタンに表示されるテキストを入力します。

名前​

ボタンの名前を入力します。

有効​

有効にするかどうかを指定します。

  • Onをオンにする：利用可能
  • Offをオンにする：使用不可（グレー表示）

サイズ​

  • Width：ボタンの最小幅を指定します（ピクセル単位）
  • Height：ボタンの最小高さを指定します（ピクセル単位）

画像​

画像ボタンを使用するかどうかを指定します。

  • Onをオンにする：画像ボタンを使用
  • Offをオンにする：通常のボタンを使用

Image File​

ボタンに表示される画像のパスを指定します。

Image Location​

ボタン上の画像の表示位置を指定します。

  • 左：ボタンの左側に画像を配置
  • 右：ボタンの右側に画像を配置
  • 中央：ボタンの中央に画像を配置

Color​

  • 背景色：テキストボックスの背景色を指定します。
  • テキストの色：テキストボックスに表示されるテキストの色を指定します。

Font​

  • サイズ：テキストボックスに表示されるテキストのサイズを指定します。
  • ボールド：太字のテキストを有効にするかどうかを指定します。
    • Onをオンにする：テキストを太字にします
    • Offをオンにする：テキストを太字にしません
  • イタリック：テキストに斜体を適用するかどうかを指定します。
    • Onをオンにする：テキストを斜体にします
    • Offをオンにする：テキストを斜体にしません
  • 下線：テキストに下線を引くかどうかを指定します。
    • Onをオンにする：テキストに下線を引きます
    • Offをオンにする：テキストに下線を引きません
  • 取り消し線：テキストを打ち消し線で取り消すかを指定します。
    • Onをオンにする：テキストに打ち消し線を引きます
    • Offをオンにする：テキストに打ち消し線を引きません

表示​

作成したボタンを表示/非表示にするかを指定します。

  • Onをオンにする：表示
  • Offをオンにする：非表示

関連するAPI​

  • dlg.add_button：ダイアログにボタンを追加します。
  • dlg.on_button_clicked：作成した関数をボタン/ラジオボタン/チェックボックスにバインドします。
