Dialog

タイトル、実行ボタン、および作成されたダイアログの選択リストを設定します。

ダイアログのプレビュー

パラメータ​

タイトル​

ダイアログのタイトルを入力します。

リサイズ可能​

ダイアログをリサイズできるかどうかを指定します。

  • オン をチェック：ダイアログのサイズを調整できます
  • オフ をチェック：ダイアログのサイズが固定されます

バリデーション​

ダイアログ内のユーザーの入力がバリデーション（フォーマット、数字の形式など）にチェックされるかどうかを指定します。

  • オン をチェック：バリデーションが行われます
  • オフ をチェック：バリデーションが行われません

適用ボタン​

適用ボタンが作成されるかどうかを指定します。

  • オン をチェック：作成されます
  • オフ をチェック：作成されません

OKボタン​

OKボタンが作成されるかどうかを指定します。

  • オン をチェック：作成されます
  • オフ をチェック：作成されません

キャンセルボタン​

キャンセルボタンが作成されるかどうかを指定します。

  • オン をチェック：作成されます
  • オフ をチェック：作成されません

モーダルモード​

モーダルモードが使用されるかどうかを指定します。

  • オン をチェック：使用されます
  • オフ をチェック：使用されません

Icon File​

ダイアログの左上隅に表示されるアイコンファイルのパスを指定します。

説明​

ここに入力された情報はダイアログの上部に表示されます。

選択​

選択リストで選択可能なタイプを指定します。

サポートされている選択タイプ: 節点セレクタ、パートセレクタ、バーパートセレクタ、エッジ要素セレクタ、1D要素セレクタ、2D要素セレクタ、3D要素セレクタ、フェースセレクタ、エッジセレクタ、バーテックスセレクタ

関連API​

  • JDGCreator: Jupiterでダイアログを生成するためのクラス。
  • dlg.on_command : 作成した関数をコンポーネントにバインドする。
  • dlg.on_dlg_apply: 適用ボタンがクリックされたときに作成した関数を実行する。
  • dlg.on_dlg_cancel: キャンセルボタンがクリックされたときに作成した関数を実行する。
  • dlg.on_dlg_help : ヘルプボタンがクリックされたときに作成した関数を実行する。
  • dlg.on_dlg_ok : OKボタンがクリックされたときに作成した関数を実行する。
  • dlg.on_dlg_selector_changed : アイテムが選択された後に作成した関数を実行する。
  • dlg.generate_window : 作成したダイアログを実行する（作成したすべての関数とともにダイアログを表示する）。
  • dlg.do_modal : 作成したダイアログをモーダルモードで実行する（作成したすべての関数とともにダイアログを表示する）。
  • dlg.close : ダイアログを閉じる。
  • dlg.add_space : 作成したコンポーネント間にスペースを追加する。
  • dlg.add_1delement_selector : 選択リストに「1D要素」を追加し、ユーザーが1D要素を選択して選択された1D要素を選択リストに保存できるようにする。
  • dlg.add_2delement_selector : 選択リストに「要素」を追加し、ユーザーが2D要素を選択して選択された2D要素を選択リストに保存できるようにする。
  • dlg.add_3delement_selector : 選択リストに「ソリッド要素」を追加し、ユーザーがソリッド要素を選択して選択されたソリッド要素を選択リストに保存できるようにする。
  • dlg.add_vertex_selector : 選択リストに「頂点」を追加し、ユーザーが頂点を選択して選択された頂点を選択リストに保存できるようにする。
  • dlg.add_node_selector : 選択リストに「ノード」を追加し、ユーザーがノードを選択して選択されたノードを選択リストに保存できるようにする。
  • dlg.add_edge_selector : 選択リストに「エッジ」を追加し、ユーザーがエッジを選択して選択されたエッジを選択リストに保存できるようにする。
  • dlg.add_elementedge_selector : 選択リストに「要素エッジ」を追加し、ユーザーが要素エッジを選択して選択された要素エッジを選択リストに保存できるようにする。
  • dlg.add_barpart_selector : 選択リストに「バー」を追加し、ユーザーがバーパーツを選択して選択されたバーパーツを選択リストに保存できるようにする。
  • dlg.add_face_selector : 選択リストに「面」を追加し、ユーザーが面を選択して選択された面を選択リストに保存できるようにする。
  • dlg.add_part_selector : 選択リストに「パーツ」を追加し、ユーザーがパーツを選択して選択されたパーツを選択リストに保存できるようにする。
  • dlg.add_condition_selector : 選択リストに「条件」を追加し、ユーザーが条件を選択して条件を選択リストに保存できるようにする。
  • dlg.add_coordinate_selector : 選択リストに「座標」を追加し、ユーザーが座標を選択して座標を選択リストに保存できるようにする。
  • dlg.add_group_selector : 選択リストに「グループ」を追加し、ユーザーがグループを選択してグループを選択リストに保存できるようにする。
  • dlg.get_dlg_selector_selected_entities : 現在の選択リストで選択されたDItemを取得する。
  • dlg.get_item_text : コンポーネント内のテキストを取得する。
  • dlg.set_item_text : コンポーネント内に表示されるテキストを設定する。
  • dlg.set_item_font : コンポーネント内のテキストにフォントプロパティを設定する。
  • dlg.set_item_visible : 作成したコンポーネントの状態を表示または非表示に設定する。すべてのToolBoxタイプで使用可能。
  • dlg.disable_item : 入力されたコンポーネントの「有効」オプションをオフ（無効）に変更する。
  • dlg.enable_item : 入力されたコンポーネントの「有効」オプションをオン（有効）に変更する。
  • dlg.isbutton_checked : 入力されたコンポーネントがチェックされているかどうかの状態を確認する。現在はチェックボックスとラジオボタンコンポーネントをサポート。
  • dlg.set_icon_file : 作成するGUIダイアログにアイコンを設定する。
  • dlg.set_item_size_behavior : TabWnd、ImgCtrl、Table、PagesCtrlの表示動作を設定する。
  • dlg.show_tooltip : ユーザーがUIコンポーネントにマウスをホバーしたときにツールチップを表示する。
  • dlg.show_dlg_help_button : 作成するダイアログでヘルプボタンの表示/非表示を設定する。
