Conductivity

説明​

これは材料の導電性特性を表す導電性クラスのインスタンスです。

プロパティ​

属性説明
conductivity導電性特性のすべてのデータを指定する Tuple のリストです。
conductivityType導電性のタイプを指定する Integer です。
選択したタイプに応じて、対応する導電性パラメータがあります。
temperatureDependency温度依存データを使用するかどうかを指定する Boolean です。
dependenciesフィールド変数の数を指定する Integer です。

導電性特性​

材料の特性を定義する際には、KEY NAMEまたはIDのいずれかを使用できます。 関数で主に使用される材料の特性のIDは、Int Notation列で参照できます。 ただし、材料の特性の意味を明確に示すために、ユーザーはIDの代わりにKEY NAMEを指定することができます。 例：CONDUCTIVITYはID = 51と同等です。

conductivityType = ISOTROPIC

Int NotationKey Name説明
51CONDUCTIVITY導電性データを指定する Tuple です。
130TEMPERATURE温度依存データを指定する Tuple です。
143EXTRA_FIELDS追加フィールドデータを指定する Tuple です。
サンプルコード
sample_Mat = Properties.Material.Modify(strMaterialName="Sample_Material", 
                                        listMaterialProperty=[Conductivity(conductivity=[
                                            (CONDUCTIVITY, [59.0]), 
                                            (TEMPERATURE, [200.0])], 
                                            temperatureDependency=True)], 
                                            iMaterialID=1, 
                                            iMaterialColor=13708224, 
                                            strDescription=Conductivity)
JPT.Debugger(sample_Mat) #戻り値を確認するため
