Expansion

説明​

このクラスは、材料の膨張特性を表す Expansion クラスのインスタンスです。

プロパティ​

属性説明
expansion膨張特性 のすべてのデータを指定する Tuple 型のリスト
expansionType膨張のタイプを指定する Integer 。
選択したタイプに応じて、対応する弾性パラメータがあります。
temperatureReference温度基準のデータを指定する Double 型
temperatureDependency温度依存データの使用を指定する Boolean 型
dependencies温度の依存数を指定する Integer

Expansion Characteristic​

材料プロパティを定義する際に KEY NAME または ID を使用できます。関数で主に使用される材料プロパティの ID は、Int Notation 列で参照できます。ただし、材料プロパティの意味を明示的に記述するために、ユーザーは ID の代わりに KEY NAME を指定することができます。 例えば、ALPHA は ID = 69 と同等です。

expansionType = ISOTROPIC

INT NotationKey Name説明
69ALPHA膨張係数アルファのデータを指定する Tuple 型
130TEMPERATURE温度依存データを指定する Tuple 型
143EXTRA_FIELDS追加のフィールドデータを指定する Tuple 型
サンプルコード
sample_Mat = Properties.Material.Add(strMaterialName="Sample_Material", 
                                    listMaterialProperty=[Expansion(expansion=[
                                        (ALPHA, [1.2e-05]), 
                                        (TEMPERATURE, [100.0])], 
                                        temperatureDependency=True)], 
                                        iMaterialID=1, 
                                        iMaterialColor=11399605, 
                                        strDescription=Expansion-ISOTROPIC)
JPT.Debugger(sample_Mat) # 戻り値を確認するため
