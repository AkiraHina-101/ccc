Material Types

これはJupiterのMaterialの種類を表す列挙型です。主に関数で使用される素材特性のIDは、整数表記の列で参照できます。また、素材特性の意味を明確に説明するために、ID を指定する代わりに KEY NAME を使用することができます。
例： YOUNGS_MODULUS は、ID = 1 と等しいです。
