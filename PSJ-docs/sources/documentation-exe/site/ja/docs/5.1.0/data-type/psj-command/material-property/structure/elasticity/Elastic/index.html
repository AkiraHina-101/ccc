Elastic

説明​

これは材料の弾性特性を表すElasticクラスのインスタンスです。

プロパティ​

属性説明
elastic弾性特性のすべてのデータを指定する Tuple のリストです。
elasticType弾性率の種類を指定する Integer です。
選択した種類に応じて、対応する弾性パラメータがあります。
temperatureDependency温度依存データの使用設定を指定する Boolean です。
frequencyDependency材料の周波数依存性（Nastran）の使用設定を指定する Boolean です。
このキー名は、elasticType = 0の場合にのみ使用されます。
dependencies温度の依存性の数を指定する Integer です。
moduliモジュラスの時間スケールタイプを指定する String です（ViscoElasticity用）。
subOptionサブオプションを指定する String です。
noCompression圧縮不能の場合に使用設定を指定する Boolean です。
noTension伸縮不可能の場合に使用設定を指定する Boolean です。

弾性特性​

材料プロパティを定義する際には、KEY NAMEまたはIDのいずれかを使用できます。 関数で主に使用された材料プロパティのIDは、Int Notation列で参照できます。 ただし、材料プロパティの意味を明確に記述するために、IDを指定する代わりにKEY NAMEを使用できます。 例えば：YOUNGS_MODULUS は ID = 1 と等しいです。

elasticType = ISOTROPIC

INT表記キー名説明
1YOUNGS_MODULUSヤング率データを指定する Tuple です。
2SHEAR_MODULUSせん断率データを指定する Tuple です。
3POISSONS_RATIOポアソン比データを指定する Tuple です。
130TEMPERATURE温度依存データを指定する Tuple です。
139FREQUENCY_DEPENDENCE周波数依存データを指定する Tuple です。
143EXTRA_FIELDS追加フィールドデータを指定する Tuple です。
4NASTRAN_FAILURE_INDEX_TENSIONNastran引張り破壊指数データを指定する Tuple です。
5NASTRAN_FAILURE_INDEX_COMPRESSIONNastran圧縮破壊指数データを指定する Tuple です。
6NASTRAN_FAILURE_INDEX_SHEARNastranせん断破壊指数データを指定する Tuple です。
サンプルコード
sample_Mat = Properties.Material.Add(strMaterialName="Sample_Material", 
                                    listMaterialProperty=[Elastic(elastic=[
                                        (YOUNGS_MODULUS, [200000000000.0]), 
                                        (SHEAR_MODULUS, [80000000000.0]), 
                                        (POISSONS_RATIO, [0.3]), 
                                        (TEMPERATURE, [100.0]), 
                                        (FREQUENCY_DEPENDENCE, [150.0]), 
                                        (NASTRAN_FAILURE_INDEX_TENSION, [100000.0]), 
                                        (NASTRAN_FAILURE_INDEX_COMPRESSION, [80000.0]), 
                                        (NASTRAN_FAILURE_INDEX_SHEAR, [50000.0])], 
                                        temperatureDependency=True, 
                                        frequencyDependency=True)], 
                                        iMaterialID=1, 
                                        iMaterialColor=16131973, 
                                        strDescription="Elastic-ISOTROPIC")
JPT.Debugger(sample_Mat) #戻り値の確認
