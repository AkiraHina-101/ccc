DItem Types

これは、JupiterのDItemのタイプを表す列挙型です。
関数で主に使用されるアイテムのIDは、Int表記列で参照することができます。
また、IDの意味を明確に説明するために、IDを指定する代わりにJPT.DItemType.DItemを使用することもできます。
例：JPT.DItemType.BODYはID = 3に等しいです。
