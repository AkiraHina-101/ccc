GasketTransverseElastic

説明​

これは、材料のGasketTransverseElastic特性を表すGasketTransverseElasticクラスのインスタンスです。

プロパティ​

属性説明
gasketTransverseElasticGasketTransverseElastic特性のすべてのデータを指定する_Tuple_リスト。
データには、SHEAR_STIFFNESS_H、TEMPERATURE_H、EXTRA_FIELDS_H、SHEAR_STIFFNESS_V、TEMPERATURE_V、EXTRA_FIELDS_Vが含まれます。
temperatureDependencyH水平方向転送で温度依存データを使用するかどうかを指定する_Boolean_です。
dependenciesH水平方向転送のフィールド変数の数を指定する_Integer_です。
unitH水平方向転送の単位タイプを指定する_Integer_です。
unitV垂直方向転送の単位タイプを指定する_Integer_です。
temperatureDependencyV垂直方向転送で温度依存データを使用するかどうかを指定する_Boolean_です。
dependenciesV垂直方向転送のフィールド変数の数を指定する_Integer_です。

GasketTransverseElastic特性​

材料プロパティを定義する際には、KEY NAMEまたはIDのいずれかを使用できます。 関数で主に使用されていた材料プロパティのIDは、Int Notation列で参照できます。 ただし、材料プロパティの意味を明確に説明するために、IDの代わりにKEY NAMEを指定することも可能です。 例：YOUNGS_MODULUSはID = 1と等しいです。

INT NotationKey Name説明
137SHEAR_STIFFNESS_H水平方向転送における剛性データを指定する_Tuple_です。
138SHEAR_STIFFNESS_V垂直方向転送における剛性データを指定する_Tuple_です。
131TEMPERATURE_H水平方向転送における温度依存データを指定する_Tuple_です。
132TEMPERATURE_V垂直方向転送における温度依存データを指定する_Tuple_です。
144EXTRA_FIELDS_H水平方向転送における追加フィールドデータを指定する_Tuple_です。
145EXTRA_FIELDS_V垂直方向転送における追加フィールドデータを指定する_Tuple_です。
サンプルコード
sample_Mat = Properties.Material.Add(strMaterialName="Sample_Material", 
                                    listMaterialProperty=[GasketTransverseElastic(gasketTransverseElastic=[
                                        (SHEAR_STIFFNESS_H, [400.0]), 
                                        (TEMPERATURE_H, [200.0])], 
                                        unitH=1, 
                                        temperatureDependencyH=True, 
                                        unitV=1)], 
                                        iMaterialID=1, 
                                        iMaterialColor=3315481, 
                                        strDescription="GasketTransverseElastic")
JPT.Debugger(sample_Mat) #戻り値を確認するために使用します
