Creep

説明​

これは、材料の特性であるクリープ特性を表すCreepクラスのインスタンスです。

プロパティ​

属性説明
creepクリープ特性のすべてのデータを指定する Tuple のリストです。
lawType法律オプションを指定する Integer です。
suboption従属オプションを指定する Integer です。
advcHardenTypeADVCハーデンオプションを指定する Integer です。
advcLawTypeADVC法律オプションを指定する Integer です。
temperatureDependency温度依存データを使用するかどうかを指定する Boolean です。

クリープ特性​

材料の特性を定義するには、KEY NAMEまたはIDのどちらかを使用できます。 関数で主に使用されていた材料特性のIDは、Int Notation列で参照できます。 ただし、材料特性の意味を明示的に説明するために、ユーザーはIDを指定する代わりにKEY NAMEを使用できます。 たとえば、PRESSURE_FORCE_LOADINGはID = 63と等しいです。

lawType = Strain-Hardening

INT NotationKey Name説明
118POWER_LAW_MULTIPLIERパワーローマルチプライヤーデータを指定する Tuple です。
121EQ_STRESS_ORDEREq応力順序データを指定する Tuple です。
124TIME_ORDER時間順序データを指定する Tuple です。
130TEMPERATURE温度依存データを指定する Tuple です。
サンプルコード
sample_Mat = Properties.Material.Add(strMaterialName="Sample_Material", 
                                    listMaterialProperty=[Creep(creep=      
                                        [(POWER_LAW_MULTIPLIER, [2.0]), 
                                        (EQ_STRESS_ORDER, [1.0]), 
                                        (TIME_ORDER, [1.0]), 
                                        (TEMPERATURE, [300.0])], 
                                        lawType=0, 
                                        suboption=0, 
                                        advcHardenType=1, advcLawType=0, 
                                        temperatureDependency=1)], 
                                        iMaterialID=1, 
                                        iMaterialColor=16131973)
JPT.Debugger(sample_Mat) # 戻り値を確認するため
