Release Note V5.0.2

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

:::tip[アップデートのハイライト]
このリリースは主に新しい [PSJ-GUI](../psj-gui) と [PSJ-Utility](../psj-utility) の機能に焦点を当てています。詳細は次の通りです：

- PSJ-GUI のコマンド（API）および GUI コマンドビルダーの使いやすさを向上させました。
- 特に PSJ フォントと PSJMessageBoxといった新しい PSJ-GUI コマンド（API）を追加しました。
- PSJ-GUI と PSJ-Utility 向けの新しいデータ型を追加しました。
- PSJ-GUI で使用される引数名を修正しました。
- PSJ-GUI、GUI コマンドビルダーのクラッシュ問題といくつかの細かいバグを修正しました。

:::
import ReactPlayer from "react-player/lazy";

## 🚀 新機能

### 📦 データ型

- PSJ-Command:  新しい Enum _[`DItemType`](../data-type/psj-command/DItem-types)_ 型が追加されました。
  <details>
  <summary>新たに追加された DItemType の一覧</summary>

  | INT 表記  | DITEM のタイプ         |
  | ------------- | --------------------- |
  | 2             | `JPT.DItemType.INST`  |

  </details>

- PSJ-GUI: PSJMessageBox で使用される新しい列挙型 _[`msgbox_icon`](../data-type/psj-gui/psj-message-box/msgbox-icon-types)_、_[`msgbox_buttons`](../data-type/psj-gui/psj-message-box/msgbox-button-types)_、_[`msgbox_position`](../data-type/psj-gui/psj-message-box/msgbox-position-types)_ が追加されました。

- PSJ-Utility: 
  - 新しい Enum _[`MsgBoxType`](../data-type/psj-utility/pre-utility/enumeration-types/msgbox-types)_ 型が追加されました。
    <details>
    <summary>新たに追加された MsgBoxType の一覧</summary>

    | ID  | MSGBOX のタイプ                               |
    | --- | ----------------------------------------- |
    | 8   | `JPT.MsgBoxType.MB_CRITICAL_OK`           |

    </details>

  - API コマンド `JPT.DisableMessageBox()` の新しい Enum _[`MessageBoxOptionType`](../data-type/psj-utility/pre-utility/enumeration-types/msgbox-option-types)_ が追加されました：

    <details>
    <summary>新たに追加された MessageBoxOptionType の一覧</summary>

    | ID  | MSGBOX オプションのタイプ                        |
    | --- | ----------------------------------------- |
    | 1   | `JPT.MsgBoxOptionType.MB_OPTION_OK`       |
    | 2   | `JPT.MsgBoxOptionType.MB_OPTION_CANCEL`   |
    | 6   | `JPT.MsgBoxOptionType.MB_OPTION_YES`      |
    | 7   | `JPT.MsgBoxOptionType.MB_OPTION_NO`       |        

    </details>

### 🛠 PSJ-Utility

#### 📝 API

データベースクエリに関連する3つの新しい API コマンドが追加されました：

<details>

<summary>新たに追加されたコマンド</summary>

- `JPT.GetAllByTableTypeID()`: _[DTableType](../data-type/psj-utility/pre-utility/enumeration-types/dtable-types)_ を入力してすべてのエンティティの情報を取得します。
- `JPT.GetOutputLog()`: Output ウィンドウに存在するテキストを取得します。
- `JPT.DisableMessageBox()`: 画面上のポップアップメッセージボックスを無効にし、デフォルト値を設定します。

</details>

- また、いくつかのコマンドが以下のように修正されています：

<details>
<summary>変更および修正されたコマンドの一覧</summary>

- `JPT.DisableAnimation()`: コマンドが回転ビューをキャプチャできるように修正されました。

</details>

  ![Width/Height](../assets/GUI_CommandBuilder_Component_Label_V5.0.2.png)

  ![H.Alignment/V.Alignment](../assets/GUI_CommandBuilder_Component_Label2_V5.0.2.png)
- [TextBox](../gui-command-builder/text-box) の色やフォントプロパティを変更する新しいオプションが追加されました。
  ![TextBox](../assets/GUI_CommandBuilder_Component_TextBox_V5.0.2.png)
- [Button](../gui-command-builder/button) の色やフォントプロパティを変更する新しいオプションが追加されました。

- [PageCtrl](../gui-command-builder/pages-control) のナビゲータプロパティ（HighLight Color と Separator）を変更する新しいオプションが追加されました。
  ![PagesCtrl](../assets/GUI_CommandBuilder_Component_PageCtrl_V5.0.2.png)

  ![ShortcutKey](../assets/GUI_CommandBuilder_ShortcutKey_V5.0.2.png)

#### 📝 API

- 一部のコマンドの引数名が統一のために変更されました（新しい引数名のコードを更新してください）。

<details>

<summary>変更された引数名の一覧</summary>

| コンポーネント グループ | 旧引数名 | 新引数名 | 新しい引数名の例                                 |
| --------------- | ----------------- | ----------------- | ------------------------------------------------------------ |
| TABLE           | cell_row_id       | row               | dlg.get_cell_value(<strong>row</strong>=0,col=0…)            |
| TABLE           | cell_column_id    | col               | dlg.get_cell_value(row=0,<strong>col</strong>=0…)            |

</details>

- また、以下のように一部のコマンドが追加および変更されました：

<details>
<summary>新たに追加されたコマンドの一覧</summary>

- `PSJMessageBox()`: PSJMessageBox クラスのインスタンスで、メッセージボックスのメソッドを指定します。
- `msgbox.set_caption()`: PSJMessageBox クラスのインスタンスで、メッセージボックスのキャプションを設定します。
- `msgbox.set_header()`: PSJMessageBox クラスのインスタンスで、メッセージボックスのヘッダーを設定します。
- `msgbox.set_icon()`: PSJMessageBox クラスのインスタンスで、メッセージボックスで使用するアイコンのタイプを指定します。
- `msgbox.set_message()`: PSJMessageBox クラスのインスタンスで、メッセージボックスのメッセージコンテンツを設定します。
- `msgbox.enable_checkbox()`: PSJMessageBox クラスのインスタンスで、メッセージボックスにチェックボックスを指定します。
- `msgbox.set_buttons()`: PSJMessageBox クラスのインスタンスで、メッセージボックスでサポートされる利用可能なボタンのセットを指定します。
- `msgbox.add_button()`: ユーザーが定義したボタン名でボタンを追加する PSJMessageBox クラスのインスタンスのコマンドです。
- `msgbox.show()`: メッセージボックスを表示する PSJMessageBox クラスのインスタンスのコマンドです。
- `dlg.set_item_font()`: コンポーネント内のテキストにフォントプロパティを設定します。
- `dlg.get_cell_label()`: テーブル内のボタンセル、チェックボックスセル、またはコンボボックスセルのラベルを取得します。

</details>

<details>

<summary>変更または修正されたコマンドの一覧</summary>

- `dlg.add_pagesctrl()`: セパレータ境界のステージを指定するための新しい引数 `show_separator` および `sel_color` を追加し、PageItem を選択する際のハイライトカラーを指定します。
- `dlg.add_pageitem()`: テキストカラーと背景色の PageItem のテキストカラーと背景色を指定するための新しい引数 `text_color` と `bk_color` を追加します。
- `dlg.add_textbox()`: テキストボックスのテキストカラーと背景色を指定するための新しい引数 `text_color` と `bk_color` を追加します。
- `dlg.add_button()`: ボタンのテキストカラーと背景色を指定するための新しい引数 `text_color` と `bk_color` を追加します。
- `dlg.insert_table_row()`: 引数 `position` の使用意味を修正しました。この引数が指定されている場合、行は入力された位置の前に挿入されます（position-1）。指定されていない場合は、行はテーブルの末尾に挿入されます。
- `dlg.set_cell_value()`: 引数名を統一するため、cell_row_id/cell_column_id を row/col に変更しました。
- `dlg.get_cell_value ()`: 引数名を統一するため、cell_row_id/cell_column_id を row/col に変更しました。

</details>

### ⚙ マクロ

- ポスト処理およびテンプレートの利用に関連するマクロが追加されました：

<details>

<summary>新たに追加されたマクロの一覧</summary>

- `SetHiddingElementFactor`: 非表示要素ファクターを設定するマクロです。
- `CmdPostOptimizationAnimationIncPlay`: アニメーションを再生するマクロです。
- `CmdPostOptimizationAnimationIncPause`: アニメーションの一時停止を行うマクロです。
- `CmdPostOptimizationAnimationIncPrev`: 前のアニメーションを再生するマクロです。
- `CmdPostOptimizationAnimationIncNext`: 次のアニメーションを再生するマクロです。
- `CmdPostOptimizationAnimationIncFirst`: 最初のアニメーションを再生するマクロです。
- `CmdPostOptimizationAnimationIncLast`: 最後のアニメーションを再生するマクロです。
- `CmdPostOptimizationAnimationExportMovie`: ムービーをエクスポートするマクロです。
- `ViewSelectMethod`: 中心節点オプションをオン/オフにするマクロです。
- `ViewCappingOriginalShape`: キャップ元の形状をオン/オフにするマクロです。
- `CmdMarkupSearchNodeFromPoint`: 最も近い節点を検索するマクロです。
- `CmdMarkupSearchNodesFromMultiPoints`: CSV から位置ごとの最も近い節点を検索するマクロです。
- `CmdMarkupSearchElementsFromPoint`: 最も近い要素を検索するマクロです。
- `CmdMarkupSearchElementsFromMultiPoints`: CSV から位置ごとの最も近い要素を検索するマクロです。

</details>

- また、いくつかのマクロが以下のように修正されています：

<summary>変更および修正されたマクロの一覧</summary>

## 🐛 バグ修正

### ⌘ PSJ-Command

- Python ウィンドウで PSJ-Command Force-General を出力するときに [strName](../psj-command/boundary-conditions/BoundaryConditions.Force.General#strname) キーワード引数が欠落していた問題を修正しました。
- GUI と API コード操作間で追加された素材 ID が一致しない問題を修正しました。
- [BodyCut-XXYYOnOnePoint](../psj-command/geometry/Geometry.BodyCut.XXYYOnOnePoint) の PSJ-Command 生成時にエラーが発生する不具合を修正しました。

### 📐 PSJ-GUI

#### 📝 API

- GUI コマンドビルダーからエクスポートされた API コードを実行すると、セレクタが表示されない不具合を修正しました。
- テーブルのメニューでクリア、カットデータ、行挿入オプションを使用後、ファイルからデータを再読み込みできない不具合を修正しました。
- スピンの値を取得できない問題を修正しました。
- テーブルの Integer 列に値を設定できない問題を API コマンド `dlg.set_cell_value()` で修正しました。
- API コマンド `dlg.set_slider_vertical()`
