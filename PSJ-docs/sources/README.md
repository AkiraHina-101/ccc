# Documentation sources

- `jupiter-help/`: versioned Jupiter Help pages.
- `documentation-exe/`: decoded documentation assets and extraction metadata. Original executable binaries are not included.
- `chm/`: text streams extracted from CHM help files.
- `pdf/`: extracted PDF text and source metadata.

These are reference sources, not project runtime files. Preserve their version context and use the catalog under `reference/` for routine API lookup. Verify important claims against the source page for the relevant version.
