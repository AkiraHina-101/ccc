1.2 Main Window 
Analysis Result and Chart window are displayed. 
 
 
 
• Analysis Result window 
The analytical model is displayed. Map the results on the analytical model and visually review 
the results. The mouse action in the Analysis Result window is similar to the Main window in 
Pre. For more information about mouse operations, refer to Mouse operation in Pre. 
• Chart window 
A graph of the results of analysis and analysis on the specified node or element is displayed. Use 
the Chart ribbon to operate the Chart window. 
1.2.1 Toolbar 
The Main window has six toolbars: Viewpoint Toolbar, View Control Toolbar, View Option Toolbar, 
Select Toolbar, Select Option Toolbar, and Result Display Style Toolbar. These are used by clicking 
on the icon with the left mouse button. The Show/hide and placement settings of each toolbar can 
be changed in the Home → Preferences command.

About micro peak removal logic 
If there is a valley deeper than the step width between the peaks it is considered that the peaks are 
in different peaks, and if they are not, the peaks are in the same peak and the peaks are removed. 
The step width is defined by: 
 
 
step width = (overall maximum stress value - overall minimum stress value) * parameter 
and the parameter is set between 0 and 1. Therefore, a value of 0 means to detect all micro peaks, 
and a case of 1 means to detect the maximum stress point of the entire (each group).
