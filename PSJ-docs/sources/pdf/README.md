# Văn bản PDF

Đã trích cả 3 PDF Help, tổng cộng 728 trang. File Markdown giữ số trang để đối chiếu PDF gốc trong `../jupiter-help/`. Manifest ghi các trang không có văn bản: trang 2 của hai bộ FULL EN/JP; ảnh kiểm tra trong `verification/` cho thấy chúng trắng hoàn toàn. Bản trích phục vụ tìm kiếm văn bản, không tái tạo bố cục hoặc hình minh họa.
