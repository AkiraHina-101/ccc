# Hướng dẫn AI đọc tài liệu PSJ

- Chỉ dùng corpus này để đọc, tìm kiếm và giải thích tài liệu API PSJ/Jupiter.
- Bắt đầu từ `reference/API-CATALOG.md`; kiểm tra phiên bản và ngôn ngữ trước khi đưa ra chữ ký API.
- Đối chiếu trang nguồn trong `sources/` khi cần ngữ cảnh. Phân biệt nội dung tài liệu, kết quả runtime đã xác nhận và suy luận.
- Không coi ví dụ hoặc tên API là bằng chứng rằng lời gọi chạy được trên mọi phiên bản.
- Tài liệu này không cấp quyền chạy macro, điều khiển GUI, sửa model hoặc truy cập file ngoài corpus.
- MCP tra cứu được mô tả trong `mcp/PSJ_RAG_README.md`; server và cấu hình client được quản lý riêng.
