# Handoff: corpus tài liệu API PSJ

## Mục đích

Corpus này dành cho AI đọc, tìm kiếm và giải thích API PSJ/Jupiter. Đây là bộ tài liệu chỉ đọc, không phải runtime, project workspace hay cấu hình MCP client.

## Tra cứu

1. Tìm API trong `reference/API-CATALOG.md` hoặc `reference/API-QUICK-REFERENCE.md`.
2. Xác nhận đúng phiên bản trong `reference/RUNTIME-API.md` và metadata catalog.
3. Đọc trang nguồn tương ứng trong `sources/` để kiểm tra ngữ cảnh.
4. Ghi rõ khi kết luận là suy luận thay vì hành vi đã xác nhận bằng runtime.

## MCP

MCP tài liệu được mô tả như một giao diện tra cứu chỉ đọc gồm tìm kiếm, tra API chính xác, đọc trang dài theo phân trang và liệt kê phiên bản. Phần triển khai và thiết lập client nằm ngoài corpus này; môi trường chủ quản cung cấp đường dẫn và cấu hình.
