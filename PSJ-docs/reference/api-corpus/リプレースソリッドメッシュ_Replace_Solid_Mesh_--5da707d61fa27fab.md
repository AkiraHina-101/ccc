# リプレースソリッドメッシュ(Replace Solid Mesh)

リプレースソリッドメッシュ(Replace Solid Mesh) リプレースソリッドメッシュ(Replace Solid Mesh) ソリッドメッシュパーツ向けのアッセンブリ機能です。本機能は、ソリッドメッシュモデルのパーツ入替や、新規パーツ追加などに有効です。 ソリッドメッシュパーツ間で、片方のパーツのメッシュパターンが、もう片方のパーツにリプレースされます。置き換えられたメッシュ周りがリメッシュされ、節点共有（共有面作成）されます。 例）新しいボルト（ソリッドメッシュ）を追加 ネジ部メッシュがアンマッチ(ソリッドメッシュ非表示) ケースのネジ部メッシュ周りをリメッシュ ネジ部メッシュが節点共有(ソリッドメッシュ非表示) リメッシュされた要素と節点は、「ReplaceSolidMesh」の名前でグループ化されます。 選択リスト(Selection list) 元フェース(Source Face)：キープするフェース（複数可） 対象フェース(Target Face)：リメッシュするフェース（複数可） ※下の注意事項を確認してください。 オプション(Option) トレランス(Tolerane) フェースペアを抽出するためのパーツ間の距離を入力します。 入力した距離以内にあるパーツ間の対象フェースに、元フェースのメッシュをリプレースします。 -&nbsp操作手順&nbsp- 元フェース(Source Face)を選択します。 対象フェース(Target Face)を選択します。 必要に応じて、オプション(Option)を変更します。 適用(Apply)／OKボタンをクリックします。対象フェース(Target Face)の周りがリメッシュされ、共有面(Share Face)が作成されます。 -&nbsp操作手順：メッシュエラーが発生した場合&nbsp- メッシュエラーが発生した場合、リメッシュ範囲がパーツとして残ります。 該当パーツのメッシュエラーを、手動修正してください。 該当パーツを、元のパーツにマージしてください。 -&nbsp注意事項&nbsp- 本機能は、元フェース(Source Face)の領域が、対象フェース(Target Face)の領域内に含まれている必要があります。 リメッシュされる対象フェース(Target Face)側は、四面体要素である必要があります。 元フェース(Source Face)側と対象フェース(Target Face)側のパーツの要素タイプが一致していない場合、節点共有されますが、共有面は作成されません。 元フェース(Source Face)と対象フェース(Target Face)のペアは1つまで対応しています。離れた複数のペアに対して、同時に実行することはできません。
