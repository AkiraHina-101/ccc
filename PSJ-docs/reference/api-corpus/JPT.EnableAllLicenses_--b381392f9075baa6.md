# JPT.EnableAllLicenses()

JPT.EnableAllLicenses()

説明​

現在のJupiterに存在するすべてのライセンス機能を有効化または無効化します。

構文​

JPT.EnableAllLicenses(...)

入力​

BoolType​

ライセンスの有効状態を説明する Boolean ：

True: すべてのライセンスを有効化します。

False: すべてのライセンスを無効化します。

この入力は必須です。

戻り値​

このユーティリティ関数には出力値がありません。

サンプルコード​

# すべてのライセンスを無効化
JPT.EnableAllLicenses(False)
