# TCONTACTTABLEDATA_ADVC

TCONTACTTABLEDATA_ADVC

説明​

ADVCコンタクトテーブルデータのパラメータを制御するために使用されるデータタイプです。

属性​

strMaster​

マスターグループの名前を指定する String。

これは必須の入力です。

strSlave​

スレーブグループの名前を指定する String。

これは必須の入力です。

listFacesMaster​

マスター面を指定する List of Cursor。

これは必須の入力です。

listFacesSlave​

スレーブ面を指定する List of Cursor。

これは必須の入力です。

iContactType​

拘束タイプを指定する Integer。

デフォルト値は1です。

stAdvcParam​

コンタクトパラメータを指定する DCAD_ADVCCONTACTPARAM[./DCAD_ADVCCONTACTPARAM]

iColor​

コンタクトの色を指定する Integer。

デフォルト値は65280です。
