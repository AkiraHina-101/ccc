# PSJ-ユーティリティ

PSJ-ユーティリティ

前書き​

PSJ-ユーティリティは、モデルの情報を照会するために使用されます。 これは、マクロまたは PSJ コマンドに欠けているものを補完するために使用されます。

例:

JPT.Debugger : PSJ 用のコンソールデバッガー。 このユーティリティは、入力された値のすべての関連情報を PythonAPI ウィンドウに表示します

JPT.Exec : Jupiter マクロを実行します

JPT.GetAllParts : すべてのパーツの情報を取得します

JPT.GetMaxIDEntity : DItem タイプから最大 ID エンティティを取得します

JPT.GetSelectedElems : 選択した要素のすべての情報を取得します

JPT.ViewFitToModel : 現在のモデルのビューを Jupiter の表示ウィンドウに合わせて変更します

PSJ-ユーティリティは、右のような形式で記述します。 **JPT.Function_Name(パラメーター)**

続きを読む

利用可能な PSJ-ユーティリティの完全なリストを取得するには、スクリプトAPIを参照してください。
