# インポート

インポート インポート CSVファイルやBDFファイルから節点データを読み込みます。読み込まれた節点データから、パーツに所属しない浮遊点を作成します。 ＊CSVファイルは、X,Y,Z[Enter]で記述されたCSV形式のファイルを意味します。 ＊BDFファイルは、Nastran BDF形式とTSV Geometry BDF形式のファイルを意味します。 -&nbsp操作手順&nbsp- ファイル選択ウィンドウで拡張子を選択します。 読み込むファイルを選択して、OKボタンをクリックします。 確認画面でOK/Cancelボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
