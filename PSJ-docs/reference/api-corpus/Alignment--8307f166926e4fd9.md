# Alignment

Alignment a.no-uline {text-decoration:none} Alignment Move and/or rotate the target part which has circular edges to the reference/destination part to be straightly aligned. Transform Method &nbsp;&nbsp;&nbsp;Specify the method of alignment. There are two alignment methods: Axis Alignment :&nbsp;The target part is aligned by axis. &nbsp;&nbsp;&nbsp; Selection list &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Part: Specify the target part to transform. Multiple parts are acceptable. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Target Edge: Specify the edge on the target part to be moved. Maximum number of edge is 2. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Ref Edge: Specify the edge on the reference/destination part. Maximum number of edge is 2. Plane Alignment :&nbsp;The target part is aligned by plane. &nbsp;&nbsp;&nbsp; Selection list &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Part: Specify the target part to transform. Multiple parts are acceptable. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Target Face: Specify the face on the target part to define the angle of rotation. Target Face allows selecting one face only. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Ref Face: Specify the face on the reference/destination part to define the angle of rotation. Ref Face allows selecting one face only. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Center Node: Specify the node to define the center of rotation. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Center Edge: Specify the edge to define the center of rotation. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;※To define the center of rotation, just specify either Center Node or Center Edge is enough. If both Center Node and Center Edge are specified, the latest one will be used to define the center of rotation. Translation Length &nbsp;&nbsp;&nbsp;An offset value to specify the distance between target part and reference part when transforming. Coplanar &nbsp;(for Plane Alignment Method only) &nbsp;&nbsp;&nbsp;Set the Target Face (on the target part) to be coplanared with the Reference Face (on reference part). When this option is selected, Translation Length's value will be measured automatically. Operation Preview &nbsp;&nbsp;&nbsp;Display temporary results as a preview. Create New Part &nbsp;&nbsp;&nbsp;Copy the Target Part after transform as a new part. LBC Copy &nbsp;&nbsp;&nbsp;Also copy Load and Boundary Condition that were added to the existing part to a new part. Property Copy &nbsp;&nbsp;&nbsp;Also copy properties that were added to the existing part to a new part. Reference Copy &nbsp;&nbsp;&nbsp;Also copy references that were added to the existing part to a new part. Direction Specify the direction for alignment. There are two alignment directions: Opposite Direction :&nbsp;Move and/or rotate the target part to the reference part by making the both faces have the opposite direction of normal vector. Same Direction :&nbsp;Move and/or rotate the target part to the reference part by making the both faces have the same direction of normal vector. -&nbspOperating Procedure&nbsp- Operation 1 (Method: Axis Alignment) &nbsp;Select the target part to transform. &nbsp;Select the circular target edge on the target part. &nbsp;Select the circular reference edge on the reference part. &nbsp;Input the Translation Length's value, if necessary. &nbsp;Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively. &nbsp;Specify a direction for alignment. &nbsp;Press the Apply or OK button to execute the function. Operation 2 (Method: Axis Alignment, mating 2 pairs of edge at the same time) &nbsp;Select the target part to transform. &nbsp;Select the circular target edges on the target parts. &nbsp;Select the circular reference edges on the reference parts. &nbsp;Input the Translation Length's value, if necessary. &nbsp;Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively. &nbsp;Specify a direction for alignment. &nbsp;Press the Apply or OK button to execute the function. Operation 3 (Method: Plane Alignment) &nbsp;Select the target part to transform. &nbsp;Select the target face on the target part. &nbsp;Select the reference face on the reference part. &nbsp;Specify the Center Node or Center Edge to define the center of rotation. &nbsp;Input the Translation Length's value and check on Coplanar to set the Target Face to be coplanared with the Reference Face, if necessary. &nbsp;Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively. &nbsp;Specify a direction for alignment. &nbsp;Press the Apply or OK button to execute the function. Operation 4 (Method: Axis Alignment and Plane Alignment) ※Axis Alignment: &nbsp;Select the target part to transform. &nbsp;Select the target edge on the target part. &nbsp;Select the reference edge on the reference part. &nbsp;Input the Translation Length's value, if necessary. &nbsp;Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively. &nbsp;Specify a direction for axis alignment. &nbsp;Press the Apply or OK button to execute the function. ※Plane Alignment: After axis alignment is executed sucessfully, the selected reference edge is changed to Center Edge if user want to continue transform the part with Plane Alignment. &nbsp;Select the target part to transform. &nbsp;Select the target face on the target part. &nbsp;Select the reference face on the reference part. &nbsp;Input the Translation Length's value and check on Coplanar to set the Target Face to be coplanared with the Reference Face, if necessary. &nbsp;Turn on the Create New Part check box to create a new part after transforming, if necessary. Load and Boundary Conditions, Properties, References of the existing part also are copied to the new part if the LBC Copy, Property Copy and Reference Copy check boxes are turned on respectively. &nbsp;Specify a direction for plane alignment. &nbsp;Press the Apply or OK button to execute the function. -&nbspNotes&nbsp- &nbsp;This function does not support in case of target part is 1D bar part. &nbsp;The required profile type for edges of each method. For Axis Alignment Method : Target edges/reference edges must be circular edge. For Plane Alignment Method : Center Edge to define the center of rotation must be circular edge. Faces for alignment must be the flat plane, curve faces can not apply. &nbsp;Direction of translation uses reference part’s normal vector direction as positive direction for translation. &nbsp;Translation of target part bases on combination of the specified direction and the angle defined by normal vectors of target part and reference part (&Theta;). &Theta; &nbsp;Rotate Target Part an angle &Theta; around the specified rotation center (The new position of Target Face corresponds to case of Translation Length = 0). &Theta; &nbsp;Rotate Target Part an angle &Theta; around the specified rotation center. Then, symmetrically project the target part, take reference face as symmetrical plane (The new position of Target Face corresponds to case of Translation Length = 0). &Theta; > 90&#176; and Direction is Opposite Direction: &nbsp;Rotate Target Part an angle (180&#176 - &Theta;) around the specified rotation center (The new position of Target Face corresponds to case of Translation Length = 0). &Theta; > 90&#176; and Direction is Same Direction: &nbsp;Rotate Target Part an angle (180&#176 - &Theta;) around the specified rotation center. Then, symmetrically project the target part, take reference face as symmetrical plane (The new position of Target Face corresponds to case of Translation Length = 0).
