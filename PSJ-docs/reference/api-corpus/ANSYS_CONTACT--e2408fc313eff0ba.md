# ANSYS_CONTACT

ANSYS_CONTACT

Description​

A data type uses to control parameters of Ansys Contact

Attributes​

dFricCoef​

A Double specifying fric coeffience.

The default value is DFLT_DBL.

dPenaStiffness​

A Double specifying pena stiffness.

The default value is DFLT_DBL.

dPetrTolerance​

A Double specifying petr tolerance.

The default value is DFLT_DBL.

iStiffUpdate​

An Integer specifying stiff update.

The default value is 2.

iAlgorithm​

An Integer specifying algorithm.

The default value is 2.

iDetec​

An Integer specifying detec.

The default value is 2.

iBehavior​

An Integer specifying behavior.

The default value is 5.
