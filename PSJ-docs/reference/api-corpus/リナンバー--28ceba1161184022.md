&nbsp;&nbsp;&nbsp;チェックが入ったアイテムは、リナンバ及び自動リナンバーの対象となります。 オプション 競合の解決 &nbsp;&nbsp;&nbsp;共有節点・共有面要素のIDの振り方を決めます。 より小さいID(&lt;) 共有節点/面要素のIDは、パーツIDの小さい方に所属します。 より大きいID(&gt;) 共有節点/面要素のIDは、パーツIDの大きい方に所属します。 -&nbsp;操作手順&nbsp;- &nbsp;リナンバー対象を、設定及びターゲットから選択します。 &nbsp;モデルに共有面がある場合、オプションの競合の解決から、共有面上のターゲットをパーツIDの大きい方・小さい方どちらに所属させるのかを指定します。（デフォルト：より小さいID） &nbsp;リナンバー対象を、設定及びターゲットから選択します。 &nbsp;ターゲットが1D/2D/3D要素で、かつ、プロパティ未割り当ての要素に対してリナンバーを行いたい場合、オプションの「プロパティ割当済エンティティのみ表示」チェックボックスをOFFにします。 &nbsp;リナンバーを行いたい行の、「有効」欄のチェックをONにします（デフォルト：ON）。 &nbsp;開始 IDに任意のIDを入力します。終了IDに、開始ID＋ID数-1が入力されます。 &nbsp;適用またはOKボタンを押します。 -&nbsp;操作手順（自動リナンバー機能）&nbsp;- &nbsp;リナンバー対象を、設定及びターゲットから選択します。 &nbsp;リナンバーを行いたい行の「有効」欄のチェックをONにします（デフォルト：ON）。 &nbsp;自動リナンバーボタンをクリックすると、１行目から順に、すべての行に１から順に自動でIDが割り振られます。 &nbsp;行を左マウスクリックしてハイライトすると、その行のみ自動で１からIDが割り振られます。CtrlもしくはShifキーを使用して、複数行を対象にすることができます。 &nbsp;自動リナンバーを任意のIDから指定したい場合は、1行目の開始IDセルに任意のIDを入力し、テーブルの外側をクリックして行のハイライトを消してからじどう &nbsp;適用またはOKボタンを押します。 -&nbsp;操作手順（任意IDからの自動リナンバー機能）&nbsp;- &nbsp;リナンバー対象を、設定及びターゲットから選択します。 &nbsp;リナンバーを行いたい行の「有効」欄のチェックをONにします（デフォルト：ON）。 &nbsp;1行目の開始IDセルに任意のIDを入力します。 &nbsp;テーブルの外側のなにもない箇所を１回クリックして、行のハイライトを消します。 &nbsp;直後に自動リナンバーボタンをクリックすると、1行目から順に、すべての行に任意IDから順に自動でIDが割り振られます。 &nbsp;行を左マウスクリックしてハイライトすると、その行のみ自動で任意IDから順にIDが割り振られます。CtrlもしくはShifキーを使用して、複数行を対象にすることができます。 &nbsp;適用またはOKボタンを押します。
