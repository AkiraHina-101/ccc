# IN Boundary | Limited Boundary | Rotation

IN Boundary | Limited Boundary | Rotation IN Boundary | Limited Boundary | Rotation Rotates the limit plane of the infinite boundary. Rotation Coordinate system &nbsp;&nbsp;&nbsp;Specify the coordinate system to reference. Rotation Axis &nbsp;&nbsp;&nbsp;Specify the axis of rotation. X Axis &nbsp;:&nbsp;Rotates around the X axis of the selected coordinate system. Y Axis &nbsp;:&nbsp;Rotates around the Y axis of the selected coordinate system. Z Axis &nbsp;:&nbsp;Rotates around the Z axis of the selected coordinate system. Arbitrary Axis &nbsp;:&nbsp;Rotates by an angle around the axis specified by the X, Y, and Z direction vectors. 2 Nodes &nbsp;:&nbsp; Rotates by an angle around the axes of the two nodes directions selected from the screen. Edge &nbsp;:&nbsp;Rotates by an angle around the axis in the edge direction selected from the screen. Axis-X, Axis-Y, Axis-Z &nbsp;&nbsp;&nbsp; Specify the X, Y, and Z coordinates of the center of rotation. Center &nbsp;&nbsp;&nbsp;Specify the center position of rotation. Part Center &nbsp;:&nbsp;Make the center of Part the center of rotation. Node &nbsp;:&nbsp;Make the node selected from the screen the center of rotation. Input &nbsp;:&nbsp;Specify the center of rotation in Center-X, Center-Y, Center-Z. Angle &nbsp;&nbsp;&nbsp;Specify the rotation angle. -&nbspOperating Procedure&nbsp- &nbsp;Select Part. &nbsp;To rotate around the existing coordinate system axis, select the existing coordinate system from the coordinate system and select X-axis, Y-axis, or Z-axis from the rotation axis. &nbsp;To rotate in any direction, select any axis from the rotation axes and specify the direction vector in the X-axis, Y-axis, and Z-axis input boxes. &nbsp;To rotate in the direction of the selected 2 nodes, select 2 nodes from the rotation axis and select 2 nodes from the screen. &nbsp;To move in the direction of the selected edge, select the edge from the rotation axis and select the edge from the screen. &nbsp;To make the center of the part the center of rotation, select the center of the part from the center. &nbsp;To set the center of the Part to the node position, select the node from the center and pick the node from the screen. &nbsp;To enter the center of Part directly, select Input from Center and specify the center of rotation in the Center-X, Center-Y, Center-Z input boxes. &nbsp;Specify the rotation angle in angle input boxes. &nbsp;Click the Apply/OK button. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
