# Node to Face

Node to Face Node to Face CAD Projection(Node to Face) Dialog Box Project mid-node or corner nodes of the mesh parts, to the face of the selected CAD geometry. Options Direction Specify the projection direction. Min Project in the shortest distance direction to the face. X/Y/Z/-X/-Y/-Z Project the selected CAD edges in the selected positive and negative direction. Tolearnce Limits the distance to the projection destination to the distance set by this value or less. Auto Define tolerance by element size. Improve Quality Putting a check will adjust the element after creation, to optimize the quality. Direction is ignored in this case. Nearest 3 Nodes When checked, the projection destination is not on the nearest element, but on the plane defined by the three nearest nodes. -&nbspOperating Procedure&nbsp- &nbspPress the CAD Face button on the Selection List, select the face from the screen that becomes a projection target. &nbspPress the Meshed Node button on the Selection List, select the nodes of the mesh part from the screen that becomes the projection target. &nbspIf necessary, change the directions and the options. &nbspClick the Apply or OK button to execute the projection. Nodes on the selected faces will move on the CAD model. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
