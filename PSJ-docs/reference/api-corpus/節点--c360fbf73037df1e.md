# 節点

節点 節点 要素を作成します。 要素作成 自動 &nbsp;&nbsp;&nbsp;チェックを入れると、3節点目（タイプ=Tri3）または4節点目（ タイプ=Quad4）を選択すると自動で要素を作成します。 選択を保持 &nbsp;&nbsp;&nbsp;チェックを入れると、要素作成後に元の節点を選択したままにします。 タイプ &nbsp;&nbsp;&nbsp;TRI3：三角形要素を作成します。 &nbsp;&nbsp;&nbsp;QUAD4：四角形要素を作成します。 フェースを指定 &nbsp;&nbsp;&nbsp;チェックを入れてフェースを選択すると、選択したフェースに要素を作成します。 フェースID &nbsp;&nbsp;&nbsp;選択したフェースIDを表示します。 -&nbsp操作手順&nbsp- &nbsp;三角形要素の場合は３節点、四角形要素の場合は４節点を選択します。 &nbsp;適用またはOKをクリックします。 ※自動の時は自動で作成されます。 -&nbsp操作手順(フェースを指定）&nbsp- &nbsp;作成タイプを、QUAD4に変更します。 &nbsp;フェースを指定オプションにチェックを入れます。 &nbsp;4節点を選択します。 &nbsp;新しく作成する要素を追加したいフェースを選択します。 &nbsp;適用ボタンをクリックします。 &nbsp;選択したフェースに新しく作成された要素が追加されます。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
