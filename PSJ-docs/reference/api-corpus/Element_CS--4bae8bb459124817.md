# Element CS

Element CS Element CS View and modify the element coordinate system. Element coordinate system is a coordinate system defined by the node writing order of the elements. Operation Method Choose how to change the element coordinate system Align Direction： To change the element coordinate system for elements on the selected surface, select the node 2 points in order so that it coincides with the x-direction for each element. Align Connection： Select 2 nodes on the same surface elements in order so that its direction coincides with x-axis for element. Align the x-axis of the connection to surface elements of the previous connection source x-axis, and change the element coordinate system for elements on the selected surface. Display Type Select the definition of the element coordinate system to be displayed. 1st Element Edge： Define the x-axis of the element coordinate system so as to coincide with the first node → 2-th node direction. Nastran： Use the definition of the element coordinate system on the Nastran. x Direction Switch the x-axis direction display for ON / OFF. When switched ON, you will see an arrow indicating the position and orientation of the x-axis on the side to be connected to the 1st node → 2nd node for each element. Scale Set in multiples, the size of the arrow display that shows the x-direction. Coordinate Switch the ON / OFF for element coordinate system display.
