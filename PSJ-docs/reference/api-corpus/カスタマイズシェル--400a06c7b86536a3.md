# カスタマイズシェル

カスタマイズシェル

ホーム » ウィンドウ » Python APIのチェックボックスをオンにすると、カスタマイズシェル（または PythonAPI ウィンドウ）が表示されます。

① ログウィンドウ​

Python コマンドと実行結果、エラーメッセージが表示されます。

黒字：PSJ-コマンドの情報

青字：スクリプト実行結果

赤字：エラーメッセージ

② IDE ランチャーボタン​

カスタマイズ IDEを起動します

③ コマンドラインインターフェイス （CLI）​

PSJ を 1 行ずつ直接実行できます。

コピー^ Ctrl + Cおよび貼り付け^ Ctrl + V操作がサポートされています（1 行または複数行のコマンドをサポート）

↑ 上または↓ 下キーボタンを使用して前後のコマンドに移動できます。
ログウィンドウの行をダブルクリックし、コマンドをコピーして CLI に貼り付けることもできます。

⇥ タブを使用して マクロ、PSJ-コマンド、PSJ-ユーティリティのキーワードを自動入力します。
キーワードが入力された後、^ Ctrl + ↑ 上を使用して戻るか、^ Ctrl + ↓ 下を使用して近くのキーワードに進むことができます。
