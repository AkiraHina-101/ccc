# ImportVDB()

ImportVDB()

説明​

TSV VDBファイルをインポートします

構文​

ImportVDB(string SourceFilePath, string SaveFolderPath)

入力​

1. String​

インポートするファイルのパス

2. String​

保存するディレクトリのパス

注記

このパラメータが指定されていない場合、変換されたファイルは一時フォルダーに保存されます。

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

ImportVDB("D:/Source.vdb","D:/ConvertedMyFile/")
