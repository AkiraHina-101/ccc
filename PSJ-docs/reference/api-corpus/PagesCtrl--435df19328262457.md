# PagesCtrl

PagesCtrl

Create a page container (wizard type) to store PageItem.

Preview dialog:

Parameters​

Name​

Enter name of the pages control.

Show Header​

Display header text of the page items or not.

Check On : Display the header.

Check Off : Do not display the header.

Default Page​

Specify the page item to be displayed by default (number starts from zero).

Enable​

Specify whether to enable it or not.

Check On : Available

Check Off : Unavailable (grayed out)

Width​

Specifying the minimum width of the pages control. (in pixels)

Height​

Specifying the minimum height of the pages control. (in pixels)

Behavior​

Specify the the behavior state of pages control to flexibly control size itself.

Greedy : set the displaying pages control based on the user input width and height, allow resizing pages control size according to dialog size

Fixed : set the displaying pages control based on the user input width and height, and won't resize pages control size according to dialog size

Horizontal : set the displaying pages control with fixing height based on user input and allow resizing pages control only horizontally

Vertical : set the displaying pages control with fixing width based on user input and allow resizing pages control only vertically

API associated with​

dlg.add_pagesctrl : Add a PagesCtrl (wizard type) to the creating dialog.

dlg.get_pagesctrl_current_page : Get the index order of current selected PageItem of the PagesCtrl.

dlg.get_pagesctrl_page_name : Get the name of current selected PageItem of the PagesCtrl.

dlg.on_pagesctrl_active_page : Set event when selecting a PageItem.

dlg.set_pagesctrl_current_page : Set current displayed PageItem in PagesCtrl.
