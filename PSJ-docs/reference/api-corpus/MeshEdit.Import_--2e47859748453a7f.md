# MeshEdit.Import()

MeshEdit.Import()

Description​

Move nodes deformation

Syntax​

MeshEdit.Import(iSolverType=0, strFilePath="", iStep=0, dScale=1.0)

Ribbon: MeshEdit » Import

Inputs​

iSolverType​

An Integer specifying the solver type.

The default value is 0.

strFilePath​

A String specifying the file path.

The default value is "".

iStep​

An Integer specifying the step.

The default value is 0.

dScale​

A Double specifying the scale.

The default value is 1.0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.Import(iSolverType=0, strFilePath="", iStep=0, dScale=1.0)
