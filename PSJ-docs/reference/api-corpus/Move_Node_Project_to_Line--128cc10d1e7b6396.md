# Move Node | Project to Line

Move Node | Project to Line Move Node | Project to Line Move any target node on the straight line defined by the two reference nodes by the shortest distance. It is also possible to select target nodes by searching from reference nodes. Align Node On Shortest Pass &nbsp;&nbsp;&nbsp;Find the shortest path node between two reference nodes and select it as the target node. On the Direction the Reference Nodes &nbsp;&nbsp;&nbsp;Find the shortest path node in the direction defined by the two reference nodes and select it as the target node. On Selected Entity &nbsp;&nbsp;&nbsp;Find a node on the selected entity and select it as the target node. -&nbsp;Operation Procedure (When moving the shortest path node between reference nodes)&nbsp;- &nbsp;Select 2 nodes to define a straight line to project. &nbsp;Select "On Shortest Pass" from the search method of the target node. &nbsp;Click the "Search" button. The shortest path node between reference nodes is selected. &nbsp;Click the Apply / OK button. -&nbsp;Operation Procedure (When moving the shortest path node between reference nodes in the direction of reference node)&nbsp;- &nbsp;Select 2 nodes to define the line and direction to project. &nbsp;From the search method of the target node, select "On the Direction the Reference Nodes". &nbsp;Click the "Search" button. The shortest path node is selected in the direction between the reference nodes. &nbsp;Click the Apply / OK button. ※If an unintended node is selected here, please select another reference node additionally. Project the target node onto the plane defined by the 3 reference nodes. -&nbsp;Operation Procedure (When moving all nodes on the selected entity)&nbsp;- &nbsp;Select 2 nodes to define the line and direction to project. &nbsp;Select "On Selected Entity" from the search method of the target node. &nbsp;Select the entity you want to move the node, such as edge or face. &nbsp;Click the "Search" button. All nodes on the selected entity are selected. &nbsp;Click the Apply / OK button. -&nbsp;Operation Procedure (When moving any node)&nbsp;- &nbsp;Click "Reference Nodes" in the selection list and select 2 nodes to define a straight line to project. &nbsp;Click "Object Node" in the selection list and select the node or floating node to move. (You can select more than one) &nbsp;Click the Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
