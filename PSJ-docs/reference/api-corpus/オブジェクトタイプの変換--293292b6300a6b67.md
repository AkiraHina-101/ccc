# オブジェクトタイプの変換

オブジェクトタイプの変換

🎯 はじめに​

本チュートリアルでは、オブジェクト間のタイプの変換方法(基底クラス <--> 子クラス)について紹介します:

現在のモデルに含まれるすべてのパーツのリストを取得する。

DBodyオブジェクトの情報を確認する。

DBody オブジェクトを、より多くの情報を含む DItem エンティティオブジェクト(基底クラス)に変換する。

DItem エンティティオブジェクト(基底クラス)をDBody オブジェクトに変換して戻す。

基底クラス: エンティティ

子クラス: パーツ, フェース, エッジ, グループ, 節点, 要素, etc.

本チュートリアルではパーツオブジェクトを使用していますが、他のオブジェクトにも同様に使用できます。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# Cubeパーツを作成します。
Geometry.Part.Cube(strName="Cube_1")

# モデルをメインウィンドウのサイズに合わせて表示します。
JPT.ViewFitToModel()

# 現在のモデルに含まれるすべてのパーツのリストを取得します。
# この関数はパーツのリスト(Body)を返します。オブジェクトタイプ: DBody
# オブジェクトの情報を確認します。
listParts = JPT.GetAllParts()
cubePart = listParts[0]
JPT.Debugger(cubePart)

# DBodyオブジェクトをDItemエンティティオブジェクト(基底クラス)に変換します。
# DItemエンティティオブジェクトの情報を確認します。
cubeDItem = JPT.CastToDItem(cubePart)
JPT.Debugger(cubeDItem)

# DItemエンティティオブジェクト(基底クラス)をDBodyオブジェクトに変換し、戻します。
# DBodyオブジェクトの情報を確認します。
new_cubePart = JPT.CastDItemToDBody(cubeDItem)
JPT.Debugger(new_cubePart)
