# MeasureAngleBy2ElemEdges

MeasureAngleBy2ElemEdges MeasureAngleBy2ElemEdges Description Measure the angle created by 2 Elem edges. Syntax MeasureAngleBy2ElemEdges(cursorpair elemedge1,cursorpair elemedge2,String Target,Integer N) Inputs cursorpair elemedge cursorpair(10:*-10:**;*,**=node id) cursorpair elemedge cursorpair(10:*-10:**;*,**=node id) String Target (Angle or XY or YZ or ZX or ALL) Integer N specify the number of decimal places (0 Return Code Angle value(Target = Angle,XY,YZ,ZX), [Angle,XY,YZ,ZX] (Target = ALL) Succeeded FAILED Failed Sample Code MeasureAngleBy2ElemEdges(10:330-10:331,10:331-10:323,"Angle",6) or MeasureAngleBy2ElemEdges(10:330-10:331,10:331-10:323,"ALL",6)
