# Scaling

LBC Copy &nbsp;&nbsp;&nbsp;Also copy load constraints that were added to the existing part to a new part. Scaling Coordinate System &nbsp;&nbsp;&nbsp;Select the coordinate system to reference. Z &nbsp;&nbsp;&nbsp;Enter the enlargement / reduction ratio in the Z-axis direction of the selected coordinate system. Use Part Center &nbsp;&nbsp;&nbsp;If you check the box, center position of the Part will be at the center for Scaling.
