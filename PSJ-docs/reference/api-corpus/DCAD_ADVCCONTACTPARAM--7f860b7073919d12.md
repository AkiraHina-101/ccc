# DCAD_ADVCCONTACTPARAM

DCAD_ADVCCONTACTPARAM

Description​

A data type uses to control parameters of ADVC Contact.

Attributes​

iInitialState​

An Integer specifying initial state.

The default value is -1.

iBehavior​

An Integer specifying behavior.

The default value is -1.

dClearance​

An Integer specifying clearance.

The default value is 0.1234.

iAdjust2Clearance​

An Integer specifying adjust to clearance.

The default value is -1

iAdjust2Interference​

An Integer adjust to interference.

The default value is -1.

iAutoShrink​

An Integer specifying auto shrink.

The default value is -1.

iAdvAdjust​

An Integer specifying adjust.

The default value is -1.

iEstimationImpactTime​

An Integer specifying estimation impact time.

The default value is -1.

iFormula​

An Integer specifying formula.

The default value is -1.

iConstraintType​

An Integer specifying constraint type.

The default value is -1.
