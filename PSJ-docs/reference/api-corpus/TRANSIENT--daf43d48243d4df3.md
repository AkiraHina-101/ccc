# TRANSIENT

TRANSIENT

説明​

Transientのパラメータを制御するために使用されるデータ型です。

属性​

bTransientEffect​

トランジェントエフェクトを有効化／無効化する Boolean です。

デフォルト値は True です。

iLoadingType​

負荷タイプを指定する Integer です。

デフォルト値は0です。

dMassMatrixMultiplier​

質量行列の乗数を指定する Double です。

デフォルト値は0.0です。

dStiffMatrixMultiplier​

剛性行列の乗数を指定する Double です。

デフォルト値は0.0です。

bMidStep​

中間ステップを有効化／無効化する Boolean です。

デフォルト値は False です。

dToleranceBisection​

二分法の許容値を指定する Double です。

デフォルト値は0.0です。

dToleranceTimeStep​

タイムステップの許容値を指定する Double です。

デフォルト値は0.0です。

iTimeInterAlgorithm​

タイムインターアルゴリズムを指定する Integer です。

デフォルト値は0です。

iTimeInter​

タイムインターを指定する Integer です。

デフォルト値は0です。

dGamma​

ガンマを指定する Double です。

デフォルト値は0.005です。

dAlpha​

アルファを指定する Double です。

デフォルト値は0.25250625です。

dDelta​

デルタを指定する Double です。

デフォルト値は0.505です。

dAlphaF​

アルファFを指定する Double です。

デフォルト値は0.005です。

dAlphaM​

アルファMを指定する Double です。

デフォルト値は0.0です。

bTransientOutputTemperature​

トランジェント出力温度を有効化／無効化する Boolean です。

デフォルト値は False です。
