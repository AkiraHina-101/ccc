# JPT.ClearDraw()

JPT.ClearDraw()

Description​

Clear all the drawings in Main Window.

Syntax​

JPT.ClearDraw()

Inputs​

This utility function does not require any input value.

Return Code​

A Boolean specifying Succeeded or Failed.

True: Succeeded.

False: Failed.

Sample Code​

# Clear all the drawings.
JPT.ClearDraw()
