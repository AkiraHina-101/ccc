# SURFACE_MESH

SURFACE_MESH

Description​

A data type uses to control parameters of Surface Mesh

Attributes​

dAvgElemSize​

A Double specifying avg elem size.

The default value is 0.005.

dMaxElemSize​

A Double specifying maximum elem size.

The default value is 0.01.

dMinElemSize​

A Double specifying minimum elem size.

The default value is 0.001.

dReductionFactor​

A Double specifying reduction factor.

The default value is 1.0.

dGeomAngle​

A Double specifying geom angle.

The default value is 0.785398.

dGeomMinSize​

A Double specifying geom minimum size.

The default value is 0.001.

dGradingFactor​

A Double specifying grading factor.

The default value is 1.250000.

dMinStretchVal​

A Double specifying minimum stretch val.

The default value is 0.100000.

dGeomEdgeDev​

A Double specifying geom edge dev.

The default value is 0.100000.

dGeomQualRatio​

A Double specifying geom qual ratio.

The default value is 0.700000.

dGeomCntRatio​

A Double specifying geom cnt ratio.

The default value is 0.500000.

iPerformanceMode​

An Integer specifying performance mode.

The default value is 0.

iOptLevel​

An Integer specifying opt level.

The default value is 3.

bAutoMergeEdges​

A Boolean enable/disable auto merge edges.

The default value is False.

bAutoMergeFaces​

A Boolean enable/disable auto merge faces.

The default value is False.

dAutoMeshPatternMinElemAngle​

A Double specifying auto mesh pattern minimum elem angle.

The default value is 0.

dAutoMergeTinyFacesAngle​

A Double specifying auto merge tiny faces angle.

The default value is 0.523598756.

bOutputQuadMesh​

A Boolean enable/disable output quad mesh.

The default value is False.

bPureQuad​

A Boolean enable/disable pure quad.

The default value is False.

bBadInputModel​

A Boolean enable/disable bad input model.

The default value is False.

bCloseGaps​

A Boolean enable/disable close gaps.

The default value is False.

bLocalRemesh​

A Boolean enable/disable local remesh.

The default value is False.

bGeomApprox​

A Boolean enable/disable geom approx.

The default value is False.

bCurvatureControl​

A Boolean enable/disable curvature control.

The default value is False.

bDeleteCircChamfer​

A Boolean enable/disable delete circ chamfer.

The default value is False.

bTinyCylinderMesh​

A Boolean enable/disable tiny cylinder mesh.

The default value is False.

iNextEntityOffsetId​

An Integer specifying next entity offset ID.

The default value is 10000000.

iNextElemOffsetId​

An Integer specifying next elem offset ID.

The default value is 0.

iNextNodeOffsetId​

An Integer specifying next node offset ID.

The default value is 0.
