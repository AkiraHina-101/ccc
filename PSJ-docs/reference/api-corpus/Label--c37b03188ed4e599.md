# Label

Label

ラベルを追加してください。

プレビューダイアログ：

パラメータ​

テキスト​

ラベルとして表示されるテキストを入力してください。

名前​

ラベルの名前を入力してください。

有効​

有効にするかどうかを指定してください。

チェックオン：利用可能

チェックオフ：利用不可（グレーアウト）

サイズ​

幅：ラベルの最小幅を指定します（ピクセル単位）

高さ：ラベルの最小高さを指定します（ピクセル単位）

配置​

H.配置​

水平方向にテキストの表示位置を指定してください。

左：左揃え

中央：中央揃え

右：右揃え

V.配置​

垂直方向にテキストの表示位置を指定してください。

上：上端に揃える

中央：水平方向に中央に揃える

下：下端に揃える

表示​

作成したラベルを表示/非表示にするかを指定してください。

オンをチェック：表示

オフをチェック：非表示

関連するAPI​

dlg.add_label：作成ダイアログにラベルを追加します。
