# エクスチェンジ

エクスチェンジ エクスチェンジ 本機能は、旧パーツに付与された荷重境界条件およびグループ情報、材料情報を引き継いで新パーツに入れ替えができる機能です。 ジオメトリベースで入れ替えするため、パーツやフェース、エッジに設定されている条件が対象です。 新規パーツに引き継がれる情報は編集することが可能です。 簡易確認のため、オリジナル数と新規数の列で機能実行前後のエンティティ数を確認できます。 さらに各荷重境界条件およびグループ情報、材料情報を編集する際には、Miniビューウィンドウが表示されます。 miniビューにより、新旧パーツの付加情報の選択エンティティを比較しながら便利に編集することが可能です。3Dマウスおよび視点も同期されます。 選択リスト 新しいパート: 置き換える新パーツを選択します。 オリジナルパート:既存の旧パーツを選択します。 パーツ削除: 新旧パーツとは別で、削除するパーツがある場合は選択します。 交換情報 パラメータ 新規パーツ 新規パーツを選択するとIDが表示されます。 元のパーツ 元の旧パーツを選択するとIDが表示されます。 パーツを削除 削除するパーツを選択するとIDが表示されます。 トレランス トレランス LBCなどの各条件を引き継ぐ際の距離による閾値です。 フェース重複率 LBCなどの各条件を引き継ぐ際の閾値で面積比新規パーツの面積/旧パーツの面積になります。 オプション 微小フェース抑制 LBCなどの各条件を引き継ぐ際、微小面を候補から除外します。 最大フェース幅 上記除外微小面の最大フェース幅を指定します。 結果 結果表示ボタン: 引き継ぎ情報のマネージメントウィンドウを開きます。 グループ: テーブルでのグループ情報表示のオンオフ. 荷重と境界条件: テーブルでの荷重と境界条件情報表示のオンオフ ローカルメッシュ設定 : テーブルでのローカルメッシュ設定情報表示のオンオフ コンタクト: テーブルでのコンタクト情報表示のオンオフ 接続: テーブルでの接続要素情報表示のオンオフ プロパティ: テーブルでのプロパティ情報表示のオンオフ 名前[ID]: アイテムの名前とID オリジナル数: 新規パートに移動する前の、オリジナルパートでアイテムで選択されていたエンティティ数 新規数 : 新規パートに移動した後のアイテムで選択されているエンティティ数 修正: Miniビューウィンドウの表示。選択エンティティの変更 -&nbsp 操作フロー&nbsp- 新規パーツを選択します。 元のパーツを選択します。 必要に応じてパラメータを変更します。 結果表示ボタンクリックすると、ダイアログが広がり引き継ぎ結果を編集することができるようになります。 各引き継がれる予定の条件を確認します。 確認する条件のEditボタンを押すと、Miniビューウィンドウが表示されるので旧パーツの選択エンティティがハイライトされるので新規パーツと比較しながら修正し、完了後Updateボタンを押します Edit/Updateを必要数分繰り返します。 OKボタンを押すと入れ替えが実行されます。 -&nbspOperating 操作フロー（編集作業詳細）&nbsp- 結果表示ボタンクリックすると、ダイアログが広がり引き継ぎ結果を編集することができるようになります。 結果のエリアでテーブルに表示する各種引継ぎ対象の条件を指定します。下図ではすべての条件を表示します。 Editボタンを押して新旧パーツの引継ぎ状態をチェックします。 必要に応じて選択エンティティを編集します。 すべての編集作業が終わったらＯＫボタンを押します。 -&nbsp注意事項&nbsp- 本コマンドの結果表示ボタンを押してからCancelもしくはOKボタンを押すまで、他のコマンドを立ち上げないでください。 新旧パーツの選択は結果表示ボタンをクリックする前に完了してください。 本コマンドでは新規パーツは一つのみサポートしてます。 ジオメトリベースで入れ替えるので、節点や要素に対して付加されているものは移行されません。新規パーツでは節点や要素に対する設定が外れますので、ご注意下さい。
