# Model Filter

Model Filter a.no-uline {text-decoration:none} Model Filter Create groups by mutually referencing element types, properties, and material information in the model. Filter Type Element Type &nbsp;&nbsp;&nbsp;Switch the display contents by element type such as bar or triangle shell. Property &nbsp;&nbsp;&nbsp;The display content is switched according to the property (element characteristic) information used in the model. Material &nbsp;&nbsp;&nbsp;The display content is switched according to the material information used in the model. Group &nbsp;&nbsp;&nbsp;Switch the display content by the existing group. Reset &nbsp;&nbsp;&nbsp;Reset the selected content for all filter types. Target &nbsp;&nbsp;&nbsp;The items used for the body displayed in the view window are listed according to each filter. &nbsp;&nbsp;&nbsp;When you pick an item from the list, the item is highlighted for selection and the corresponding element is displayed in the view window. &nbsp;&nbsp;&nbsp;Items other than element types are sorted in ascending order and listed. &nbsp;&nbsp;&nbsp;Pick the item again to deselect the item. &nbsp;&nbsp;&nbsp;You can select multiple items in standard Windows operation using Shift key or Ctrl key. &nbsp;&nbsp;&nbsp;By switching the filter and selecting an item, you can further narrow the range. &nbsp;&nbsp;&nbsp;The example shows an element group that uses Solid Property 1 in the HEXA, PENTA element type. New Group Node Group &nbsp;&nbsp;&nbsp;When checked, nodes are included in the created group. Element Group &nbsp;&nbsp;&nbsp;When checked, elements are included in the created group. Name &nbsp;&nbsp;&nbsp;Enter the name of the group to be created. Create New Group &nbsp;&nbsp;&nbsp;Press the button to create a new group. -&nbsp;Operating Procedure&nbsp;- &nbsp;Display the range for creating a group of models in the view window. &nbsp;Press the element type button from the filter type, and select the element type for which you want to create a group. &nbsp;Furthermore, press the property or material button from the filter type, select an item from the list and narrow the display range. &nbsp;When you finish filtering, enter a name for the new group and press the Create New Group button. &nbsp;Now that a new group has been created, select a group from the filter type and check the list. To display the group, select Reset from Filter Type, reset the previous selection history, and then select an item. &nbsp;Click the upper right X button to finish the command. ※To display the created group, click the Group display mode icon in the main window. &nbsp;&nbsp;Click again to restore the display to normal. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
