# コネクター

コネクター コネクター 2節点 / 2エッジ / 2フェース間にコネクター要素を作成します。 接続 名前 ・・・ 作成するコネクター要素の名前を設定します。 接続タイプ タイプ ・・・ コネクションタイプを定義します。 ・ Parallel 有効軸番号： 0 ・ Translation 有効軸番号： 0 , 1, 2 ・ Rotation 有効軸番号： 3 , 4, 5 ・ Bushing 有効軸番号： 0 , 1, 2, 3, 4, 5 ・ Cylindrical 有効軸番号： 0 , 3 拘束軸番号： 1,2,4,5 ・ Joint 拘束軸番号： 0,1,2 ・ RigidRod 拘束軸番号： 0 ・ RigidBar 拘束軸番号： 0 , 1, 2, 3, 4, 5 座標系 ・・・ 特性の方向を定義します。 ・ Global : 全体座標系で方向を定義します。 ・ Elm : 2点の節点から定義します。 参照節点 ・・・ 座標系を決めるときに参照する節点を指定します。 ・ 0 ： 第1節点を参照します。 ・ 1 ： 第2節点を参照します。 弾性0 ・・・ 弾性特性のテーブルデータを設定します。 減衰0 ・・・ 粘性特性のテーブルデータを設定します。 ※各特性のテーブルデータは Field Data コマンドで作成します。 ・ 弾性特性テーブルタイプ：Displacement, Force ・ 粘性特性テーブルタイプ：Velocity, Force -&nbsp操作手順&nbsp- 境界条件 > フィールドデータ より、テーブルデータを作成します。 接続 > コネクター > 節点-節点間 / エッジ-エッジ間 / フェース-フェース間 をクリックします。 接続タイプをそれぞれ指定します。 選択リストを開き、マスターとスレーブとなる節点 / エッジ / フェース を選択します。 適用 / OKボタンをクリックします。 補足：【タイプ】で指定する自由度が選択でき。「Translation」にすることで並進3方向の入力が可能となります。 (X軸のみであればデフォルトのままで問題ありません。)
