# DItem

DItem

説明​

これは、Jupiter内の任意のアイテム（例：パート、フェース、エッジ、節点など）を表すDItemクラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | isValid | アイテムの妥当性を判断します。
アイテムが有効であればTrue、無効であればFalse（無効）が返されます。

 | type | アイテムのタイプ名です。
戻り値はタイプ（文字列）です。

 | typeID | アイテムのタイプIDです。
戻り値はDItemタイプのInt表記（int）です。

 | tableID | アイテムのテーブルIDです。
戻り値はDTableタイプのInt表記（int）です。

 | id | アイテムの外部IDです。
重複することがありますが、推奨されません。
IDは、再番号付け機能を使用して変更できます。
戻り値はID（int）です。

 | targets | アイテムの内容を保持します。
戻り値はアイテムのリストです。

 | masters | 接続/接触のマスターフェース/エッジ/節点です。
戻り値はDItemのリストです。

 | slaves | 接続/接触のスレーブフェース/エッジ/節点です。
戻り値はDItemのリストです。

 | children | アセンブリツリーのアイテムの子であるサブアセンブリです。
戻り値はDItemのリストです。

 | parent | アセンブリツリーのアイテムの親であるサブアセンブリです。
戻り値はDItemのリストです。

 | info | アイテムがパートまたはバーである場合のモデルとメッシュ情報です。

 | isHidden | アイテムの表示状態を判断します。
アイテムが非表示であればTrue、表示されていればFalseが返されます。

 | name | アイテムの名前です。
