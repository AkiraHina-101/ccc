# DCustomNoteCollection

DCustomNoteCollection

説明​

これは、Jupiter内部のカスタムノートコレクションを表すCustomNoteCollectionクラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | isValid | 指定したオブジェクトが利用可能かどうかをチェックするためのものです。
戻り値はbool型です。

 | typeID | カスタムノートコレクションのタイプID（ID = 271）です。
戻り値はDItem TypesのInt表記（int）です。

 | tableID | カスタムノートコレクションアイテムのテーブルID（ID = 155）です。
戻り値はDTable TypesのInt表記（int）です。

 | id | カスタムノートコレクションの外部IDです。
戻り値はID（int）です。

 | name | カスタムノートコレクションの名前です。
戻り値は文字列です。

 | notes | カスタムノートコレクション内の子カスタムノートです。戻り値はCustomNoteVectorです。
