# Post Result Data Load 2D Types

Post Result Data Load 2D Types

これは、ポスト結果データロード2Dタイプを表す列挙型です。

 | ID | ポスト結果データロード2Dタイプ | 説明

 | 0 | JPT.PostResultDataLoad2D.POST_LOAD2D_UNKNOWN | 未定義の2Dデータ。

 | 1 | JPT.PostResultDataLoad2D.POST_LOAD2D_TOP | シェル要素の上部結果を表示します。

 | 2 | JPT.PostResultDataLoad2D.POST_LOAD2D_BOTTOM | シェル要素の下部結果を表示します。

 | 32 | JPT.PostResultDataLoad2D.POST_LOAD2D_BOTH | シェル要素の前面と背面にある上部と下部フェースの結果を表示します。

 | 64 | JPT.PostResultDataLoad2D.POST_LOAD2D_AVERAGE | シェル要素の上部と下部フェースの平均値を表示します。
