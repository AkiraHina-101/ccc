# Morphing | Deform

Morphing | Deform a.no-uline {text-decoration:none} Morphing | Deform Select the target face and the reference face to perform deformation (morphing) of the mesh. Move the face smoothly along with nodes that is within the specified range from the selection face while moving the face. Parameters Select the target face and the reference face to perform deformation (morphing) of the mesh. Move the face smoothly along with nodes that is within the specified range from the selection face while moving the face. Parameters Effective Distance &nbsp;&nbsp;&nbsp;Specify the range of morphing to deform the selected entities.Nodes detected in the range moves smoothly as per selected entities. Src Obverse &nbsp;&nbsp;&nbsp;Specify the front side target face to be deformed Dst Obverse &nbsp;&nbsp;&nbsp;Specify the front side reference face Src Reverse &nbsp;&nbsp;&nbsp;Specify the back side target face to be deformed Dst Reverse &nbsp;&nbsp;&nbsp;Specify the back side reference face Fixed Group &nbsp;&nbsp;&nbsp;Specify the faces not to be moved. *It is possible to fix the back side faces by specifying the faces on fixed groupｷ -&nbsp; Operating Procedure&nbsp;- &nbsp;Click the src Obverse button from the selection list window and select the frontside surface to be deformed. &nbsp;Click the dst Obverse button from the selection list window and select the reference surface. &nbsp;Click the Src Reverse button from the selection list window and select the backside surface to be deformed. &nbsp;Click the dst Reverse button from the selection list window and select the backside reference surface. &nbsp;Click the fixed group button from the selection list window and select the surface not to be moved. &nbsp;Specify the effective distance. &nbsp;Press apply or ok button -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
