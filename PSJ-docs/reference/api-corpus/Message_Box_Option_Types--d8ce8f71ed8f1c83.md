# Message Box Option Types

Message Box Option Types

これは、メッセージボックスオプションタイプを表す列挙型です。

 | ID | メッセージボックスオプションタイプ | 説明

 | 1 | JPT.MsgBoxOptionType.MB_OPTION_OK | デフォルト値はOKです

 | 2 | JPT.MsgBoxOptionType.MB_OPTION_CANCEL | デフォルト値はCANCELです

 | 6 | JPT.MsgBoxOptionType.MB_OPTION_YES | デフォルト値はYESです

 | 7 | JPT.MsgBoxOptionType.MB_OPTION_NO | デフォルト値はNOです
