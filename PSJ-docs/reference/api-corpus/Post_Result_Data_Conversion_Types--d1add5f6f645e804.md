# Post Result Data Conversion Types

Post Result Data Conversion Types

これは、ポスト結果データ変換タイプを表す列挙型です。

 | ID | ポスト結果データ変換タイプ | 説明

 | 0 | JPT.PostResultDataCnv.POST_CNV_UNKNOWN | 未定義の変換。

 | 1 | JPT.PostResultDataCnv.POST_CNV_AVG | 平均変換。

 | 2 | JPT.PostResultDataCnv.POST_CNV_MAX | 最大変換。

 | 4 | JPT.PostResultDataCnv.POST_CNV_MIN | 最小変換。

 | 8 | JPT.PostResultDataCnv.POST_CNV_COMP_AVG | 成分平均変換。

 | 16 | JPT.PostResultDataCnv.POST_CNV_ALL | すべての変換。

 | 32 | JPT.PostResultDataCnv.POST_CNV_MAX_MIN | 最大と最小の変換。

 | 64 | JPT.PostResultDataCnv.POST_CNV_AVG_MATERIAL | 素材別平均変換。
