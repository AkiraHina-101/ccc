# POST_STEP_ITEM

POST_STEP_ITEM

説明​

Post Step Item のパラメータを制御するために使用するデータ型です。

属性​

postTimeStepInfo​

Post Time Step Information の属性を指定する Class POST_TIME_STEP_INFO です。

デフォルト値は POST_TIME_STEP_INFO() です。

iAnalysisType​

解析の種類を指定する Integer です。

デフォルト値は 0 です。

crPostJob​

Post Job を指定する Cursor です。

デフォルト値は None です。

iResultSet​

結果セットを指定する Integer です。

デフォルト値は 0 です。

iTimeStep​

タイムステップを指定する Integer です。

デフォルト値は 0 です。
