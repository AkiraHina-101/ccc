# MuxWeld.Prop3DWeldBead()

MuxWeld.Prop3DWeldBead()

Description​

Create Property 3D Weld Bead

Syntax​

MuxWeld.Prop3DWeldBead(strName="Bead_1", crMaterial=None, crlTargets=[], crEdit=None)

Ribbon: MuxWeld » Prop3DWeldBead

Inputs​

strName​

A String specifying the name.

The default value is "Bead_1".

crMaterial​

A Cursor specifying the material.

The default value is None.

crlTargets​

A List of Cursor specifying the target.

The default value is [].

crEdit​

A Cursor specifying the edit.

The default value is None.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MuxWeld.Prop3DWeldBead(strName="Bead_1", crMaterial=None, crlTargets=[], crEdit=None)
