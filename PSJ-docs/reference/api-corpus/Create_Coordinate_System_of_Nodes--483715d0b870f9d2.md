# Create Coordinate System of Nodes

Create Coordinate System of Nodes a.no-uline {text-decoration:none} Create Coordinate System of Nodes This command sets the coordinate system that defines the position information of the nodes. With Nastran and ADVC (format 2) input files, this setting refers to the local coordinate system as the node method. -&nbspOperating Procedure&nbsp- &nbsp;Select the local coordinate system created in the coordinate system. &nbsp;Select the part, face, edge or node for which you want to set the nodal coordinate system. &nbsp;Click the Apply / OK button. &nbsp;If you want to group the nodes in which the local coordinate system is set, press the group creation button. &nbsp;Press the Show / Hide button to color-mark and visualize the nodes for which the local coordinate system has been set. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
