# MPC Equation | Multi-Nodes

MPC Equation | Multi-Nodes MPC Equation | Multi-Nodes It is a function to create MPC between multiple nodes. Multi-Nodes Name Enter the name to be registered. Parameters Coordinate Select a reference coordinate system. Term Table Display the MPC setting table. Constant term Specify a constant term in the factor field. Slave term Specify the degrees of freedom and coefficients of slave nodes. Master terms Specify the degrees of freedom and coefficients of master nodes. Within this table, it is possible to use copy and paste by right clicking on the DOF cell and the coefficient cell. In addition, we also support shortcut keys. Copy: Ctrl + C, Paste (Paste): Ctrl + V Select all Select (check on) the list of all master nodes. Deselect all Deselect (check off) the list of all master nodes. Selection state switching Switch the selected state (check on / off). Make slave node If any node is selected (checked) and you click the button, the selected node will be the slave node. Set All Change the degrees of freedom and coefficients of all master nodes collectively. -&nbspOperating Procedure&nbsp- &nbsp;Select multiple nodes. &nbsp;Open the table from the table button. &nbsp;Set the constants, slave nodes and master nodes and close the table with the close button. &nbsp;To change the slave node, select the node you want to change in the master terms and press the S button. &nbsp;For example&nbsp;&nbsp; 1 * U1X(Node 1's X) + (-1) * U2X(Node 2's X) = 0.2&nbsp;&nbsp;If you want to set the equation, set as shown below. &nbsp;Click the Apply / OK button.
