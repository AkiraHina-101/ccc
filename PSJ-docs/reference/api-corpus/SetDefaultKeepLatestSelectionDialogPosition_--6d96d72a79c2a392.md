# SetDefaultKeepLatestSelectionDialogPosition()

SetDefaultKeepLatestSelectionDialogPosition()

説明​

コマンド ダイアログの選択リストの位置の設定を最新の位置にするかどうかを切り替えます。

構文​

SetDefaultKeepLatestSelectionDialogPosition(int Flag)

入力​

1. int​

コマンド ダイアログの選択リストの位置を最新の位置に設定する機能を有効にします。

0: オフ

1: オン

戻り値​

戻り値なし。

サンプル コード​

SetDefaultKeepLatestSelectionDialogPosition(1)
