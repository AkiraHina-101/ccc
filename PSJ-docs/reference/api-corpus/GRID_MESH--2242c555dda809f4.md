# GRID_MESH

GRID_MESH

Description​

A data type uses to control parameters of Grid Mesh

Attributes​

crlFace​

A List of Cursor specifying face.

The default value is [].

crlCorner​

A List of Cursor specifying corner.

The default value is [].

ilMeshCount​

A List of Integer specifying mesh count.

The default value is [].

iShape​

An Integer specifying shape.

The default value is -1.

iElemtype​

An Integer specifying element type.

The default value is 3.

bSwap​

A Boolean enable/disable swap.

The default value is False.

bLocalSetting​

A Boolean enable/disable local setting.

The default value is False.

bOptimize​

A Boolean enable/disable optimize.

The default value is False.
