# DEdge

DEdge

説明​

これは Jupiter 内部のエッジを表す DEdge クラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | typeID | エッジのタイプID (ID = 5)。
戻り値は DItem TypesのInt表記 (int) です。

 | id | エッジの外部ID。
IDは重複する可能性がありますが、推奨されていません。
IDは、renumbering 関数を使用して変更できます。
戻り値はID (int) です。

 | nodes | エッジに属する節点です。
戻り値は節点のリストです。

 | color* 1 | エッジの色情報です。
この値は調整できます。
戻り値はRGBカラーです。

注意​

Footnotes​

属性名にアスタリスク*がある場合、その属性は現在の値から新しい値に変更/割り当てることができることを意味します。 ↩
