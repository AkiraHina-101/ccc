# ERICONT_DAMPER_OFFSET_VEC_PROP

ERICONT_DAMPER_OFFSET_VEC_PROP

Description​

A data type uses to control parameters of Ericont Damper Offset Vec Prop

Attributes​

iConnId​

An Integer specifying connection ID.

The default value is 0.

iEndA​

An Integer specifying end A.

The default value is 0.

iEndB​

An Integer specifying end B.

The default value is 0.

dAmperOffsetVecX​

A Double specifying amper offset vec x.

The default value is 0.0.

dAmperOffsetVecY​

A Double specifying amper offset vec y.

The default value is 0.0.
