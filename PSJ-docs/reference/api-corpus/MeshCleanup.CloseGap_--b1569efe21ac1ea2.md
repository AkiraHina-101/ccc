# MeshCleanup.CloseGap()

MeshCleanup.CloseGap()

Description​

MeshCleanup Cleanup CloseGap

Syntax​

MeshCleanup.CloseGap(crlPartsCur=[], dDistanceTol=0.01)

Ribbon: MeshCleanup » CloseGap

Inputs​

crlPartsCur​

A List of Cursor specifying the part cur.

The default value is [].

dDistanceTol​

A Double specifying the distance tolerance.

The default value is 0.01.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshCleanup.CloseGap(crlPartsCur=[], dDistanceTol=0.01)
