# Find Duplicated Nodes

Find Duplicated Nodes Find Duplicated Nodes Searches for nodes with overlapping positions among the nodes contained between the selected entities. Find Tolerance Input tolerance among nodes (0.01 by default). Display Related Parts If the check is ON, only the Part associated with the nodal group below the tolerance will be displayed. Preview Highlight a group of nodes below the tolerance. Reset Cancel the preview. Options Create Group If the check is ON, a group of detected nodes is created after selecting the Apply/OK button. Select Detected Nodes If the check is ON, after selecting the Apply/OK button, the detected nodes are selected (stored in the Watch Selected window). -&nbspOperation&nbsp- Select the entity for which you want to search nodes. Input Tolerance. Click Preview button. If you want to use the nodes retrieved after the command, turn on the Create Group or Select Detected Nodes checkbox. Click Apply/OK.
