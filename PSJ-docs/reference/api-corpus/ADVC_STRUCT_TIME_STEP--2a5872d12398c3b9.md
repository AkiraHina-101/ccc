# ADVC_STRUCT_TIME_STEP

ADVC_STRUCT_TIME_STEP

説明​

ADVC Struct Time Step のパラメータを制御するために使用されるデータ型です。

属性​

iFixedOrAuto​

フィックスまたはオートを指定する Integer です。

デフォルト値は 0 です。

iNumOfInc​

増加数を指定する Integer です。

デフォルト値は 1 です。

dMaxTime​

最大時間を指定する Double です。

デフォルト値は 1.0 です。

dMaxDt​

最大 dt を指定する Double です。

デフォルト値は DFLT_DBL です。

dMinDt​

最小 dt を指定する Double です。

デフォルト値は DFLT_DBL です。

iLoadType​

ロードタイプを指定する Integer です。

デフォルト値は -1 です。

iOutputLast​

出力最終を指定する Integer です。

デフォルト値は -1 です。

iOutputInterval​

出力間隔を指定する Integer です。

デフォルト値は DFLT_INT です。

iRestartLast​

リスタート最終を指定する Integer です。

デフォルト値は -1 です。

iRestartInterval​

リスタート間隔を指定する Integer です。

デフォルト値は DFLT_INT です。

dOutputTimeInterval​

出力時間間隔を指定する Double です。

デフォルト値は DFLT_DBL です。
