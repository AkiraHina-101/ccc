# ERICONT_DAMPER_OFFSET_VEC_PROP

ERICONT_DAMPER_OFFSET_VEC_PROP

説明​

Ericont Damper Offset Vec Propのパラメータを制御するために使用されるデータ型です。

属性​

iConnId​

接続IDを指定する Integer です。

デフォルト値は0です。

iEndA​

End Aを指定する Integer です。

デフォルト値は0です。

iEndB​

End Bを指定する Integer です。

デフォルト値は0です。

dAmperOffsetVecX​

Amper offset vec xを指定する Double です。

デフォルト値は0.0です。

dAmperOffsetVecY​

Amper offset vec yを指定する Double です。

デフォルト値は0.0です。
