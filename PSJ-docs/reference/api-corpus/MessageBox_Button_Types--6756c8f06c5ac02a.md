# MessageBox Button Types

MessageBox Button Types

これは MessageBox ボタンの種類を表す列挙型です。

 | MessageBox ボタンの種類 | 説明

 | msgbox_buttons.ok | Ok ボタンのあるメッセージボックスを表示します

 | msgbox_buttons.ok_cancel | Ok ボタンとキャンセルボタンがあるメッセージボックスを表示します

 | msgbox_buttons.yes_no | Yes ボタンと No ボタンがあるメッセージボックスを表示します

 | msgbox_buttons.retry_cancel | Retry ボタンと Cancel ボタンがあるメッセージボックスを表示します

 | msgbox_buttons.yes_no_cancel | Yes ボタンと No ボタンと Cancel ボタンがあるメッセージボックスを表示します

 | msgbox_buttons.abort_retry_ignore | Abort、Retry、Ignore ボタンがあるメッセージボックスを表示します

 | msgbox_buttons.cancel_try_continue | Cancel、Try Again、Continue ボタンがあるメッセージボックスを表示します
