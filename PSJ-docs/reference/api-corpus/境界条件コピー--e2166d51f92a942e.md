# 境界条件コピー

境界条件コピー 境界条件コピー LBCコピー ダイアログボックス このコマンドでは、あるパーツに設定された荷重や拘束条件を、他のパーツにコピーします。 異なるドキュメントにあるパーツをコピー先に指定することもできます。 コピー元 コピー元ドキュメント コピー元となるドキュメントを指定します。 タイプ コピーするエンティティ、情報のタイプを選択します。モデルに既存のエンティティが下のリストに表示されます。 LBC&nbsp&nbsp&nbsp：既存の境界条件をコピーします。 プロパティ&nbsp&nbsp&nbsp：既存のプロパティ情報をコピーします。 接続要素&nbsp&nbsp&nbsp：既存の接続要素をコピーします。 グループ&nbsp&nbsp&nbsp：既存のグループをコピーします。 接触&nbsp&nbsp&nbsp：&nbsp既存の接触をコピーする. 自動/手動 ※V4.0ではこの機能は使用されません。 一致方法 コピー元とコピー先のターゲット一致判定に使用する方法を選択します。 節点&nbsp&nbsp&nbsp：この照合方法は、一致結果を得るためにターゲットの正確な節点を一致させます。 この方法は、ターゲットのフィーチャーが異なる場合に便利です。 しかし、ターゲットとしてソリッドボディを選択した場合、ソリッドメッシュはボディがまったく同じに 見えても同じ節点位置になることは非常にまれであるため、常に失敗したマッチングになることもあります。 この場合は、フィーチャー方法に切り替える必要があります。 フィーチャー&nbsp&nbsp&nbsp：この照合方法は、特に大規模モデルでは非常に高速で、向かい合わせ、頂点から頂点へのようなフィーチャの照合が必要です。 すべてのデータ リストされたエンティティを一度に選択します。左から、全選択、全選択解除、選択と非選択を反転。 エンティティタイプ 下のテーブルに表示された項目のすべてタイプが登録されています。 ここで特定のタイプを選べば、選択に従い下のテーブルは短縮されます。 すべての項目を確認するためにはAllを選択します。 フィルター 選択を容易にするため、入力した名前の一部により表示項目をフィルターします。 方法 コピー先の位置に合わせる方法を選択します。LBCコピー機能は位置によりコピー先のエンティティを判別します。 平行移動&nbsp&nbsp&nbsp：X、Y、Z方向の並進移動によりコピー先を検索します。 回転&nbsp&nbsp&nbsp：指定した軸の回転移動によりコピー先を検索します。 ミラー&nbsp&nbsp&nbsp：平面とオフセット量によりコピー先を検索します。平面を規定するには、3節点または2D要素を選択します。 入力単位系 長さの単位系を選択します。すべての長さ入力値に有効です。
