# Connection | Spring - One to one - different DoFs

Connection | Spring - One to one - different DoFs Connection | Spring - One to one - different DoFs It is a function to create a one-to-one scalar spring element. ＊The 1st group node and the 2nd group node can be selected in part units, face units, edge units, element units, and node units. The 1st group node and the closest 2nd group node (within the connection range) are connected. This function allows you to combine different degrees of freedom at the 1st and 2nd group nodes. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius of the connection range. Spring Stiffness Enter the spring stiffness. DoF at 1st G Specify the degree of freedom of the 1st group. DoF at 2nd G Specify the degree of freedom of the 2nd group. Damping Coef (for Nastran) Enter the damping coefficient. Stress Coef (for Nastran) Enter the stress coefficient. Analysis Coordinate Frame Coordinate Select a reference coordinate system. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspSelect 1st group node from part, face, edge, element, node. &nbspSelect 2nd group node from part, face, edge, element, node. &nbspEnter the spring stiffness. &nbspSpecify the degrees of freedom for the 1st group and the 2nd group. &nbspSet other parameters. &nbspClick the Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
