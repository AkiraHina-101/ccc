# DItem

DItem DItem Description Base class for all items in Jupiter. Properties Attribute Description isValid Determine if it can be used. True if available. #Check if Entity is available. True if available, False if not type The type of item. #Get ItemType of Entity. Return value is ItemType. typeID The item type ID. The DItemType. #Get the integer value of Entity ItemType. The return value is an int. key The internal ID of the item. Unique ID within each TypeID. Cannot be changed by the user. #Get the internal Key of Entity. Get the internal Key of Entity. id Item external ID. It can be duplicated within each TypeID, but it is not recommended. Some entity IDs can be changed with the renumber function. #Get the external ID of Entity. Return value Id (int). name The name of the item. #Get Entity name. Or name setting. targets Another Item that Item holds. #Acquisition of Entity set in Entity. Return value An array of DItem. masters Master/face/edge/node of connection/contact. #Acquisition of Master Entity set in Entity. Return value Array of DItem. slaves It refers to the slave side face/edge/node of connection/contact. #Acquisition of Slave Entity set in Entity. Return value Array of DItem. children Refers to a sub-assembly of an assembly item within the assembly tree. #Acquisition of child Entity when it is nested on the tree, array of return value DItem. parent A sub-assembly that is the parent of an item in the assembly tree. #Acquisition of parent Entity when nested in tree, DItem. info Entity information for parts and faces. Including the number of meshes. #Display entity information. Must be a Tree Item or PartItem.
