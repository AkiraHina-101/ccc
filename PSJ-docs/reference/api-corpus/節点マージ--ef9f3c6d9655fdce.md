# 節点マージ

節点マージ 節点マージ 節点をマージします。 節点マージ トレランス マージする節点間のトレランスを入力します。 タイプ マージ後に残す節点を指定します。 第1エンティティ 先に選択したエンティティ上の節点が残ります。 第2エンティティ 後に選択したエンティティ上の節点が残ります。 最高値のID IDの大きい節点が残ります。 最低値のID IDの小さい節点が残ります。 オプション グループ作成 チェックをONにすると、マージされた節点をグループ化します。 プレビュー マージ候補の節点をハイライト表示することで、事前に確認することができます。 リセット プレビューを解除します。 節点をイクイバランス チェックをONの場合、節点の移動とマージを行います。 チェックOFFの場合、節点の移動のみ行います。 -&nbsp操作手順&nbsp- 節点をマージするエンティティを選択します。（パーツ、フェース、エッジ、要素、節点） マージ範囲を定義するために、トレランスを入力します。 マージ後に残す節点を指定するために、タイプを選択します。 必要に応じて、グループ作成のチェックをONにします。 事前に確認する場合はプレビューボタンをクリックして、マージ候補の節点をハイライト表示します。 リセットボタンでハイライト表示を解除します。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
