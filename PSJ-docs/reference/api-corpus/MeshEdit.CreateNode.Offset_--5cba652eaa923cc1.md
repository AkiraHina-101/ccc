# MeshEdit.CreateNode.Offset()

MeshEdit.CreateNode.Offset()

Description​

MeshEdit CreateNode CreateNodeNodeOffset

Syntax​

MeshEdit.CreateNode.Offset(vecOffset=[], iRep=1, crlNodes=[], crCoord=None)

Ribbon: MeshEdit » CreateNode » Offset

Inputs​

vecOffset​

A Vector specifying the offset.

The default value is [].

iRep​

An Integer specifying the repeat times.

The default value is 1.

crlNodes​

A List of Cursor specifying the node.

The default value is [].

crCoord​

A Cursor specifying the coordinate.

The default value is None.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.CreateNode.Offset(vecOffset=[], iRep=1, crlNodes=[], crCoord=None)
