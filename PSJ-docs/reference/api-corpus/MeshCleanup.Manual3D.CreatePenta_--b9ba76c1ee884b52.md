# MeshCleanup.Manual3D.CreatePenta()

MeshCleanup.Manual3D.CreatePenta()

Description​

Create penta5 element

Syntax​

MeshCleanup.Manual3D.CreatePenta(iParentEntityId=0, crlElems=[])

Ribbon: MeshCleanup » Manual3D » CreatePenta

Inputs​

iParentEntityId​

An Integer specifying the parent entity ID.

The default value is 0.

crlElems​

A List of Cursor specifying the element.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshCleanup.Manual3D.CreatePenta(iParentEntityId=0, crlElems=[])
