# 2D Property Composite Shell

2D Property Composite Shell 2D Property Composite Shell 2D Property Composite Shell Dialog Box Create a property data of a two-dimensional composite Shell element. Properties Name ※The Name at the beginning of the input. --> Set the name of the property. Property ID Enter the ID of the property. Property ID is entered so as not to overlap in the model. Shell Layup Choose a multilayer formation that was created in advance. Distance Bottom Enter the distance from the reference plane to the stacked bottom. Non-structure Mass Enter the non-structural mass per unit area. Allowable Shear Stress Enter the allowable shear stress of the adhesive material. Failure Theory Select the failure rule from the list. No selection：No Failure theory HILL：Hill law HOFF：Hoffman law TSAI：Tsai-Wu law STRN：Maximum Strain law Reference Temperature Enter the reference temperature. Structural Damping Enter the structural damping. Laminate Option Choose a laminate option. No selection：It defines all of the laminate, and then used in the calculation. SYM：Define up to half of the lamination, the rest will be of interest. MEM：Although you define all of the stacked, it will only calculate plane. BEND：Although you define all of the laminate, only bending will be calculated . SMEAR：While you define all of the stacked, stacking sequence is ignored. SMCORE：Defines all of the laminate, but to define the core characteristics in the final layer, a layer till then defines the face sheet properties. Ply Stress Select the output of laminated stress. NO YES Plate Offset Enter the amount of offset of the laminate. Material Orientation By Select the material axis definition method. Angle: Specify the angle (degree). Coordinate system: Specify in the coordinate system. The X axis of the coordinate system is projected to the element plane. Input Unit Length Select the unit of length. Mass Select the unit of mass. ※Because it cannot be selected again. --> -&nbspOperating Procedure&nbsp- &nbspEnter the name of the property in Name. &nbspEnter the property ID to the Property ID. &nbspSelect the already registered lamination structure from Layup pull-down menu. &nbspEnter the thickness in Thickness. &nbspEnter other parameters as needed. &nbspClick the Apply or OK button to create a property. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
