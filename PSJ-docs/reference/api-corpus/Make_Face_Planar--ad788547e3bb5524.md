# Make Face Planar

Make Face Planar Make Face Planar Change curved faces or bumpy faces into planar faces. Select the faces you want to flattened, by selecting a three-node or element as a reference plane and the face is flattened according to the reference plane. Make Face Planar Type Specify the selection type for the reference plane. 3 Nodes Choose three nodes as a reference surface. Element Select elements as a reference surface. Options Merge Faces Merge the faces to change to planar. -&nbspOperating Procedure (if reference plane is 3 nodes)&nbsp- &nbspSpecify the Type > 3 Nodes and choose the 3 nodes that serves as a reference pane. &nbspSelect the face to be flattened. &nbspClick Apply/OK button. -&nbspOperating Procedure (if reference plane is element)&nbsp- &nbspSelect the Type > Element and select the reference plane element. &nbspSelect the face to be flattened. &nbspClick Apply/OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
