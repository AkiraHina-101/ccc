# WatchPoint()

WatchPoint()

説明​

ピックされた位置を Watch Data ウィンドウに入力します。

構文​

WatchPoint(vector[] positions)

入力​

1. vector[]::double​

x 座標。

2. vector[]::double​

y 座標。

3. vector[]::double​

z 座標。

戻り値コード​

なし

サンプルコード​

WatchPoint([[0.01, 0.0078796576, 0.00270456168], [0.0052604386, 0.0099999997, 0.0033876867]])
