# データベースからエンティティを削除

データベースからエンティティを削除

🎯 はじめに​

本チュートリアルでは、データベースからエンティティを削除する複数の方法を紹介します:

インストールされているJupiterのパスからサンプルモデルを取得し、Jupiterにサンプルモデルを読み込む。

すべての荷重と境界条件をデータベースから削除する。

名前から'LOCAL SETTING'エンティティを削除する。

IDから'BODY'エンティティを削除する。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# インストールされているJupiterおよびそのサンプルデータのパスを取得します。その後、サンプルモデルをJupiterに読み込みます。
jupiterPath = JPT.GetAppPathInfo(JPT.PathType.PROGRAM_PATH)
samplePath = jupiterPath + '/SampleData/PSJ/PSJ-Utility/JtdbSample/EntityModel.jtdb'
FileMenu.LoadJTDB(samplePath)

# モデルの表示をウィンドウサイズに合わせます。
JPT.ViewFitToModel()

# データベースからすべての荷重と境界条件を削除します。
JPT.RemoveAllLoadsBCs()

# モデル内のすべての「LOCAL_SETTING」エンティティのリストを取得します。
# 指定した名前と一致するローカルメッシュ設定を削除します。
listLocalSetting = JPT.GetAllByType(JPT.DItemType.LOCAL_SETTING)
for localSetting in listLocalSetting:
    if localSetting.name == "MeshParam_1":
        JPT.RemoveEntitiesByID(JPT.DItemType.LOCAL_SETTING, localSetting.id)

# ID：1の'BODY'エンティティ(パート)を削除します。
JPT.RemoveEntitiesByID(JPT.DItemType.BODY, 1)
