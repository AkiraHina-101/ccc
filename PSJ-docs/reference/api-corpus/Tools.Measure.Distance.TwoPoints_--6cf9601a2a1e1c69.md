# Tools.Measure.Distance.TwoPoints()

Tools.Measure.Distance.TwoPoints()

Description​

Measure distance 2 points

Syntax​

Tools.Measure.Distance.TwoPoints(posPoint1=[0,0,0], posPoint2=[0,0,0], strTarget="ALL", iPrecision=6, crCoordinateSystem=None)

Ribbon: Tools » Measure » Distance » TwoPoints

Inputs​

posPoint1​

A Position specifying the point1.

The default value is [0,0,0].

posPoint2​

A Position specifying the point2.

The default value is [0,0,0].

strTarget​

A String specifying the target.

The default value is "ALL".

iPrecision​

An Integer specifying the precision.

The default value is 6.

crCoordinateSystem​

A Cursor specifying the coordinate system.

The default value is None.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Tools.Measure.Distance.TwoPoints(posPoint1=[0,0,0], posPoint2=[0,0,0], strTarget="ALL", iPrecision=6, crCoordinateSystem=None)
