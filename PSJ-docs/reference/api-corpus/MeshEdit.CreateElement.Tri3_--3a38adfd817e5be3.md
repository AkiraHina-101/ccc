# MeshEdit.CreateElement.Tri3()

MeshEdit.CreateElement.Tri3()

Description​

Create element

Syntax​

MeshEdit.CreateElement.Tri3(iElemType=0, crParentEntity=None, crlNodes=[])

Ribbon: MeshEdit » CreateElement » Tri3

Inputs​

iElemType​

An Integer specifying the element type.

The default value is 0.

crParentEntity​

A Cursor specifying the parent entity.

The default value is None.

crlNodes​

A List of Cursor specifying the node.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.CreateElement.Tri3(iElemType=0, crParentEntity=None, crlNodes=[])
