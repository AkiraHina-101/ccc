# ADVC_AUTO_INCREMENT

ADVC_AUTO_INCREMENT

Description​

A data type uses to control parameters of ADVC Auto Increment

Attributes​

iNewtonResidueIncrMax​

An Integer specifying newton residue incr maximum.

The default value is DFLT_INT.

iBeginResidueIncrCheck​

An Integer specifying begin residue incr check.

The default value is DFLT_INT.

iBeginLogarithmicRateCheck​

An Integer specifying begin logarithmic rate check.

The default value is DFLT_INT.

dCutBackFactorForDivergence​

A Double specifying cut back factor for divergence.

The default value is DFLT_DBL.

dCutBackFactorForTooSlowConvergence​

A Double specifying cut back factor for too slow convergence.

The default value is DFLT_DBL.

dCutBackFactorForExcessiveDistortion​

A Double specifying cut back factor for excessive distortion.

The default value is DFLT_DBL.

iIncrEnlargeNewtonMax​

An Integer specifying incr enlarge newton maximum.

The default value is DFLT_INT.

iIncrEnlargeSuppress​

An Integer specifying incr enlarge suppress.

The default value is DFLT_INT.

dIncreaseFactorForStatic​

A Double specifying increase factor for static.

The default value is DFLT_DBL.

dIncreaseFactorForDynamic​

A Double specifying increase factor for dynamic.

The default value is DFLT_DBL.

dIncreaseFactorForCreep​

A Double specifying increase factor for creep.

The default value is DFLT_DBL.

dIncreaseFactorForRdnlk​

A Double specifying increase factor for rdnlk.

The default value is DFLT_DBL.

dTemperatureIncrMax​

A Double specifying temperature incr maximum.

The default value is DFLT_DBL.

iUseTemperatureIncrMax​

An Integer specifying use temperature incr maximum.

The default value is 0.

dHalfStepTol​

A Double specifying half step tolerance.

The default value is DFLT_DBL.

dStraTol​

A Double specifying stra tolerance.

The default value is DFLT_DBL.

dCreepStraTol​

A Double specifying creep stra tolerance.

The default value is DFLT_DBL.
