# Group Window

Group Window Group Window This window is used to display/edit groups created by the Group command. When the Group mode is turned ON, all entities other than the displayed group will be hidden. Tree Control Menu Control the tree display. Icon Name Description Clear Selection Clear all selections of the tree items. Expand All Expand all sub-trees. Collapse All Collapse all sub-trees. Toggle Sort Sort the groups according to the name or ID. Sort Setting Launch the Group Sort Settings dialog. Group Sort Setting Dialog Change the order of the group tree. Sort type Specify the sorting criteria by selecting the following statements. By Group Name &nbsp;:&nbsp;Sort groups in ascending/descending alphabetical order of the name. By Group ID &nbsp;:&nbsp;Sort groups in ascending/descending numerical order of the ID. By Number of Nodes &nbsp;:&nbsp;Sort groups in ascending/descending order of the node number. By Number of Elements &nbsp;:&nbsp;Sort groups in ascending/descending order of the element number. Tree View The group settings are displayed in a tree format. Each tree item can be highlighted by clicking it with the left mouse button. Double-click each tree item with the left mouse button in order to select all inside entities. ※ From V4.0, "Select Group" and "Deselect Selected Entity in Group" by double-click a group have been deleted, and only "Select Entity in Group" has been changed. Even if the deselection mode is ON, the entity is selected when using this function. Icon Name Description Group / Subgroup This icon indicates the parent group of multiple groups. It is also displayed when a group includes multiple entities of different types. Part Group This icon indicates a group including parts only. Face Group This icon indicates a group including faces only. Node Group This icon indicates a group including nodes only. Element Group This icon indicates a group including surface elements only. Edge Group This icon indicates a group including edges only. Solid Element Group This icon indicates a group including solid elements only. Connection Element Group This icon indicates a group including connection elements only. Condition Group This icon indicates a group including boundary conditions only. 1D Element Group This icon indicates a group including 1D elements only. Element Edge Group This icon indicates a group including element edges only. Shortcut Menu Each command can be used from the menu displayed by right-clicking the tree item. ・Commands are available when no group is selected: Command Function Enable Group View Enable to display in group mode. Exit Group View Return to display in normal mode. ・Commands are available when a subgroup item is selected: Command Function Select Entities Select the entities included in the highlighted group. Select Group Select the groups included in the highlighted group. Add Subgroup Add an empty subgroup under the group item. Copy Copy the highlighted group between documents. Create Material Group Create a group including entities associated with the same material. Create Property Group Create a group including entities associated with the same property. Create Hidden Entities Group Create a group including faces, elements and parts that are currently hidden. Create Entity Group Create a group for each entity. Create Group - Model Filter Create groups, filtering by element type and properties. Import Read the group information from a CSV format file that is exported in the Export menu. Export Export the contents of the highlighted group to a CSV format file. Paste Move the cut/copied group to the bottom of the highlighted subgroup. Delete Group Delete the highlighted group. Pressure, surface load, or contact condition applied on the selected groups are not deleted. Delete Entity Delete the highlighted group and all inside entities. ・Commands are available when a group item is selected: Command Function Hide Hide the highlighted groups. Hide Only Hide the highlighted group only and show all other groups. Show Show the highlighted groups. Show Only Show the highlighted group only and hide all other groups. Show All Show all groups. Hide All Hide all groups. Invert Hide/Show Reverse the display state of groups. Edit ※ Display a dialog for editing the highlighted group. Rename Change the name of the highlighted group. Associated Pick Select the entities associated with the highlighted group. Marker Change the color of the group marker to a random or specified color. ※The shortcut key [F3] is set to [Edit]. ・Commands are available when multiple group items of the same type are selected: Command Function Boolean + Create a new group by combining all inside entities the highlighted group into a group. Boolean - Create a new group by subtracting overlapping entities in the second selection from entities in the first selection. Boolean x Create a new group from the common entities of the highlighted group. List of Shortcut Keys When an entity is selected inside the group window, the following shortcut keys are available: View Operation Shortcut key Operation F2 Highlight a tree item and press the key to rename the item. F3 Highlight a tree item and press the key to execute "Edit" in the right-click menu. Up and down arrow keys Moves the highlight of the tree item. F Zoom the selection to fit the entire window. If no entities are selected, the entire model will be fitted to the screen. E Deselect the selected entity. A Execute a command when the command dialog is started. Space Execute a command when the command dialog is started. Ctrl＋Left-click Highlight multiple tree items. Shift＋Left-click Highlight multiple consecutive tree items.
