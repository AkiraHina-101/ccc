# MeshEdit.MoveNode.Offset()

MeshEdit.MoveNode.Offset()

Description​

MeshEdit MoveNode MoveNodeOffset

Syntax​

MeshEdit.MoveNode.Offset(dDeltaX=0.0, dDeltaY=0.0, dDeltaZ=0.0, crCoord=None, crlNodes=[])

Ribbon: MeshEdit » MoveNode » Offset

Inputs​

dDeltaX​

A Double specifying the delta x.

The default value is 0.0.

dDeltaY​

A Double specifying the delta y.

The default value is 0.0.

dDeltaZ​

A Double specifying the delta z.

The default value is 0.0.

crCoord​

A Cursor specifying the coordinate.

The default value is None.

crlNodes​

A List of Cursor specifying the node.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.Offset(dDeltaX=0.0, dDeltaY=0.0, dDeltaZ=0.0, crCoord=None, crlNodes=[])
