# Variables

Variables table, th, td { border: 1px solid black; border-collapse: collapse; padding: 10px; } Variable/number Python API variables Variable name Description id The external ID of the entity. Some entity IDs can be changed with the renumber function. key The internal ID of the entity. Every entity has a unique internal ID that is unique. It cannot be changed by the user. name The name of the entity. Type The type of entity. typeID Entity type ID. reference Cursor A pair of integers that specifies an entity. TypeID: Describe in the format of ID 2147483647 A blank was entered in the integer field. 1.79769e+308 Indicates that a blank was entered in a real number field. children Refers to a sub-assembly of an assemble item in the assemble tree. parent A sub-assembly that is the parent of an item in the assembly tree. masters It refers to the master side face/edge/node of connection/contact. slaves The slave side face/edge/node of connection/contact. info Entity information for parts and faces. Including the number of meshes.
