# Universal Files

Universal Files Universal Files Output the selected part in Universal format. This method supports triangle and quadrilateral elements for 2D elements, and tetrahedron and hexahedron elements for 3D elements. Selection List Part: Part to be output in Universal format (support selecting multiple parts) -&nbspOperation Procedure&nbsp- Select the part you want to output. Click the Apply or OK button. Enter the file path and file name, and save the file. -&nbspNode order of each element&nbsp- Linear triangular element Quadratic triangular element Linear quadrilateral element Quadratic quadrilateral element Linear tetrahedral element Quadratic tetrahedral element Linear hexahedral element Quadratic hexahedral element -&nbspSpecial Note&nbsp- There is no formal specification for the nodal ordering of universal format finite elements. The nodal ordering used by some software is different from Jupiter and other software, and in some cases the corner nodal IDs are sandwiched between intermediate nodal IDs.
