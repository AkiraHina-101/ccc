# ERICONT_OCID_PROP

ERICONT_OCID_PROP

Description​

A data type uses to control parameters of Ericont Ocid Prop

Attributes​

iConnId​

An Integer specifying connection ID.

The default value is 0.

iEndA​

An Integer specifying end a.

The default value is 0.

iEndB​

An Integer specifying end b.

The default value is 0.
