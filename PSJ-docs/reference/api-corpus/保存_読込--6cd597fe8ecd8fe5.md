# 保存/読込

保存/読込 Save/Load Allows you to configure settings for saving and loading files. Common Auto Save This function saves the open documents in the Temp folder (%temp%\Technostar) at each specified time. You can get a backup of the document you were working on in case you quit without saving the document, or if Jupiter-Pre crashes. The document is saved as the file name _YYYYMMDDHHMMSS.jtdb. *The files in the Temp folder will be erased when Jupiter-Pre is started. Save files should be retrieved before starting a new Jupiter-Pre. *While the file is being saved, it will be in a temporary standby state. Enable auto save Enables the auto-save setting. Interval Specifies the save time interval. Number of save files Specifies how many files should be saved for a single document. Items displayed when a document file is opened This controls the initial display status of each tree item in the assembly window when loading jtdb or solver data (ADVC, Nastran, Abaqus). It can be hidden by unchecking the check box. All Parts Controls the display of the part in its initial state. All Items Controls the display of all items in the initial state. LocalMeshSettings, LoadBCs, Contacts, Coordinates, Connections : Controls the display of individual items below all items in the initial state. CSV Export Format Select the output format of CSV file output from Jupiter from UTF-8 (with BOM) or UTF-8 (without BOM). The default is UTF-8 (without BOM). About BOM(Byte Order Mark) A BOM is data added to the first few bytes of text to determine which encoding type is used when a program reads text data. Microsoft&reg; Excel&reg; and some other applications determine the encoding format by the BOM at the beginning of the CSV file, so opening a file by them without a BOM may cause garbled characters. On the other hand, when reading data in a program, it is up to the programmer to decide whether or not to use the BOM, so it is easier to program the data without the BOM so that the actual data starts from the first byte. Post Configure the settings for Post documents. Automatic calculation when result file is opened Calculates the results checked when the result file is read, and adds them to the result tree. Background Import Off: Only model and result title will be loaded. And the result data will be loaded into a temporary file and displayed when the result title is selected. On: After loading the model and result title, all result data is loaded into a temporary file in the background. This improves the display speed when selecting a result title and the performance of commands that use the results of each step. *When executing macro/PSJ on Jupiter, command processing will be paused until all results import is completed. When executing macro/PSJ with batch execution, background importing processing will be deactivated. -&nbspOperating Procedure&nbsp- &nbsp;Activate the command, specify each option and click Apply or OK button. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
