# アッセンブルツリーの操作

アッセンブルツリーの操作

🎯 はじめに​

本チュートリアルでは、アッセンブルツリー(アッセンブルウィンドウ内)を操作する方法について紹介します:

新規サブアッセンブルアイテムを作成する。

サブアッセンブルアイテムを名前で検索し、削除する。

IDからサブアッセンブルアイテムを検索し、そのアッセンブル内のパートIDをPython APIウィンドウに書き出す。

サブアッセンブルアイテムとそのすべての子アッセンブルを削除する。

アッセンブルツリーを折りたたみ/展開する。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# Jupiterのインストールフォルダのパスを取得します。
jupiterPath = JPT.GetAppPathInfo(JPT.PathType.PROGRAM_PATH)
samplePath = jupiterPath + '/SampleData/PSJ/PSJ-Utility/JtdbSample/AssemblySample.jtdb'
FileMenu.LoadJTDB(samplePath)

# 新規サブアッセンブルを作成します。
JPT.CreateSubAssembly("NewSubNode", JPT.DItem())

# 名前からサブアッセンブルアイテム情報を取得します。
subObjects = JPT.FindSubAssemblyByName("NewSubNode")

# サブアッセンブルアイテムを削除します。
JPT.DeleteSubAssembly(subObjects[0])

# IDからサブアッセンブルアイテム情報を取得します。
subObject = JPT.FindSubAssemblyByID(1)

# サブアッセンブルアイテムからすべてのパートを取得します。
listParts = JPT.GetAllPartsInSubAssembly(subObject)
print("サブアッセンブル内のパートID: " + str(listParts[0].id))

# サブアッセンブルとすべての子アッセンブルを削除します。
JPT.DeleteSubAssembly(subObject)

# アッセンブルツリーを折りたたみます。
JPT.CollapseAssemblyTree()

# アッセンブルツリーを展開します。
JPT.ExpandAssemblyTree()
