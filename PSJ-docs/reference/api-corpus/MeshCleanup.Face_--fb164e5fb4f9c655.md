# MeshCleanup.Face()

MeshCleanup.Face()

Description​

Change topology face

Syntax​

MeshCleanup.Face(crlFaces=[], crlParts=[], bCreateNewPart=False)

Ribbon: MeshCleanup » Face

Inputs​

crlFaces​

A List of Cursor specifying the face.

The default value is [].

crlParts​

A List of Cursor specifying the part.

The default value is [].

bCreateNewPart​

A Boolean specifying the create new part.

The default value is False.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshCleanup.Face(crlFaces=[], crlParts=[], bCreateNewPart=False)
