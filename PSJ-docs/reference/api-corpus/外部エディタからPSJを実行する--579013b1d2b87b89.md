# 外部エディタからPSJを実行する

外部エディタからPSJを実行する

🎯 はじめに​

このチュートリアルでは、Jupiterインターフェースが実行されているときに、外部のPythonエディタ/IDEからPSJコードを実行する方法を学びます：

外部エディタから、Jupiterに接続してPSJを実行します。

Notepad++から直接PSJを実行します。

この機能は事前に_jupiterutils_ライブラリのインストールが必要です。そのため、pip install psutilを使用してインストールしてください。

📖 チュートリアル​

Jupiterに接続するためのサンプルPSJスクリプト。

# 日本語エンコーディング
# coding: cp932

# PSJインタープリタをインポート
import Utils.PSJ_Interpreter as PSJ

import pathlib

curDir = pathlib.Path(__file__).parent.absolute()

# 実行するPythonファイル
psjFilePath = str(curDir) + '/Jupiter_Path_Information.py'

# activeJupiter : Jupiter GUIをフォアグラウンドに設定
activeJupiter = False

# ファイルを実行
PSJ.RUN_FILE(psjFilePath, False)

# コードブロックを実行
PSJ.RUN_CODE('msg = "hello world"\nprint(msg)', True)

Notepad++を使用する場合、Run機能にこのコマンドラインを設定します：

"[Jupiter_Installation_Location]]\SampleData\PSJ\PSJ-Utility\Utils\PSJ_Interpreter.bat" False
