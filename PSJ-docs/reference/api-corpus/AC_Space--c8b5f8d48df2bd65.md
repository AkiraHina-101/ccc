# AC Space

AC Space AC Space Create a solid mesh of AC space between the AC boundary mesh and the infinite boundary mesh. Attributes Set the parameters for creating a solid mesh. Please access to Solid Meshing for more information. Force Clean Set the automatic correction option for solid mesh creation. Please access to Solid Meshing for more information. PML Width &nbsp;&nbsp;&nbsp;Specifie the width of the PML. Layer &nbsp;&nbsp;&nbsp;Specifie the number of PML layers. Sweep to Ground Axis &nbsp;&nbsp;&nbsp;Specifie the normal direction of the face. Coordinate &nbsp;&nbsp;&nbsp;Enter the coordinate of the ground. Mesh Size &nbsp;&nbsp;&nbsp;Specifie the size of the penta element in the sweep direction. Layer &nbsp;&nbsp;&nbsp;Specifie the number of element layers from the specified face to the ground.
