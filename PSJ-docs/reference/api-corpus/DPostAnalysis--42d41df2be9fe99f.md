# DPostAnalysis

DPostAnalysis

説明​

これはDPostAnalysisクラスのインスタンスで、Jupiter内のPost解析（解析対象）を表します。

プロパティ​

 | 属性 | 説明

 | name | 解析対象の名前。
戻り値は名前の文字列（str）です。

 | id | 解析対象のID。
戻り値はID（int）です。

 | type | 解析対象のタイプ。
戻り値はポスト解析タイプの文字列（str）です。

 | solutionType | 解析のソリューションタイプ。
戻り値はソリューションタイプの文字列（str）です。

 | load | 解析対象の荷重条件数。
戻り値は荷重数（int）です。

 | loadCase | 解析対象の荷重ケース数。
戻り値は荷重ケース数（int）です。

 | response | 解析対象の応答数。
戻り値は応答数（int）です。
