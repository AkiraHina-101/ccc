# MeshEdit.Deform()

MeshEdit.Deform()

Description​

Geometry deformation

Syntax​

MeshEdit.Deform(crlFaceSrcObverse=[], crlFaceDstReverse=[], crlFaceSrcReverse=[], crlFaceDstObverse=[], crlFaceFixed=[], dDistEffect=0.02)

Ribbon: MeshEdit » Deform

Inputs​

crlFaceSrcObverse​

A List of Cursor specifying the face source obverse.

The default value is [].

crlFaceDstReverse​

A List of Cursor specifying the face dst reverse.

The default value is [].

crlFaceSrcReverse​

A List of Cursor specifying the face source reverse.

The default value is [].

crlFaceDstObverse​

A List of Cursor specifying the face dst obverse.

The default value is [].

crlFaceFixed​

A List of Cursor specifying the face fixed.

The default value is [].

dDistEffect​

A Double specifying the dist effect.

The default value is 0.02.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.Deform(crlFaceSrcObverse=[], crlFaceDstReverse=[], crlFaceSrcReverse=[], crlFaceDstObverse=[], crlFaceFixed=[], dDistEffect=0.02)
