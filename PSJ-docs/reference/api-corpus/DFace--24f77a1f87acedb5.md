# DFace

DFace

説明​

これはDFaceクラスのインスタンスであり、Jupiter内のフェースを表します。

プロパティ​

 | 属性 | 説明

 | typeID | フェースの型ID（ID = 6）。
戻り値はDItem TypesのInt表記（int型）です。

 | id | フェースの外部ID。
IDは重複する可能性がありますが、推奨されません。
renumbering関数を使用してIDを変更できます。
戻り値はID（int型）です。

 | edges | フェースに属するエッジです。
戻り値はエッジのリストです。

 | elems | フェースに属する要素です。
戻り値は要素のリストです。

 | nodes | フェースに属する節点です。
戻り値は節点のリストです。

 | color* 1 | フェースの色情報です。
この値は調整できます。
戻り値はRGBカラーです。

注意​

Footnotes​

属性名にアスタリスク*がある場合、その属性は現在の値から新しい値に変更/割り当てることができることを意味します。 ↩
