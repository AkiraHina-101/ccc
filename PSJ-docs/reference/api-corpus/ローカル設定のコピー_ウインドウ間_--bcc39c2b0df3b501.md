# ローカル設定のコピー(ウインドウ間）

ローカル設定のコピー(ウインドウ間） ローカル設定のコピー(ウインドウ間） ローカル設定を他のウィンドウのモデルへコピーします。 ローカル設定のコピー コピー元ドキュメント &nbsp;&nbsp;&nbsp;ローカル設定のコピー元となるモデルのウィンドウを指定します。 コピー先ドキュメント &nbsp;&nbsp;&nbsp;ローカル設定のコピー対象となるモデルのウィンドウを指定します。 入力単位系 &nbsp;&nbsp;&nbsp;モデル間補正値の単位を指定できます。 座標系 &nbsp;&nbsp;&nbsp;モデル間補正方向の座標系を指定します。 マグニチュード &nbsp;&nbsp;&nbsp;モデル間補正距離を入力します。 トレランス &nbsp;&nbsp;&nbsp;モデル間誤差の許容値を入力します。 軸 &nbsp;&nbsp;&nbsp;モデル間補正方向指定方法選択します。 任意の軸 &nbsp;:&nbsp;XYZの成分を入力し方向を指定します。 X軸 &nbsp;:&nbsp;X方向を指定します。 Y軸 &nbsp;:&nbsp;Y方向を指定します。 Z軸 &nbsp;:&nbsp;Z方向を指定します。 2節点 &nbsp;:&nbsp;節点2点を選択し方向を指定します。 エッジ &nbsp;:&nbsp;エッジを選択し方向を指定します。 X/Y/Z &nbsp;&nbsp;&nbsp;モデル間補正方向ベクトルのXYZ成分が表示されます。 -&nbsp操作手順&nbsp- &nbsp;事前にソフト内にローカル設定コピー元とコピー対象のモデルを開きます。 &nbsp;コマンド起動後、ソースドキュメントにコピー元となるモデルのウィンドウを指定します。 &nbsp;ターゲットドキュメントにコピー対象となるモデルのウィンドウを指定します。 &nbsp;モデル間の位置補正が必要な場合は、座標系に補正方向の座標系を指定します。 &nbsp;マグニチュードにモデル間の補正距離を入力します。 &nbsp;トレランスをモデル間の誤差の許容値を入力します。 &nbsp;軸に任意の軸を指定します。 &nbsp;XYZの成分を入力し方向を指定します。 &nbsp;適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
