# ExportDynamisBdf()

ExportDynamisBdf()

Description​

Export Dynamis bdf file

Syntax​

ExportDynamisBdf(String strPath, Cursor job)

Inputs​

1. String​

bdf file path

2. Cursor​

job cursor

Return Code​

"1": The function can be executed

"0": The function cannot be executed

Sample Code​

ExportDynamisBdf("D:/test.dat", 135:1)
