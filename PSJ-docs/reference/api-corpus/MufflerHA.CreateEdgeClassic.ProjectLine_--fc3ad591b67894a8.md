# MufflerHA.CreateEdgeClassic.ProjectLine()

MufflerHA.CreateEdgeClassic.ProjectLine()

Description​

Create edge

Syntax​

MufflerHA.CreateEdgeClassic.ProjectLine(ilAiedgeidForMacro, ilAifaceidForMacro, bDivideFace, crlAiparttargetForMarco)

Ribbon: MufflerHA » CreateEdgeClassic » ProjectLine

Inputs​

ilAiedgeidForMacro​

A List of Integer specifying the aiedgeid for macro.

This is a required input.

ilAifaceidForMacro​

A List of Integer specifying the aifaceid for macro.

This is a required input.

bDivideFace​

A Boolean specifying the divide face.

This is a required input.

crlAiparttargetForMarco​

A List of Cursor specifying the part target for marco.

This is a required input.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MufflerHA.CreateEdgeClassic.ProjectLine(ilAiedgeidForMacro, ilAifaceidForMacro, bDivideFace, crlAiparttargetForMarco)
