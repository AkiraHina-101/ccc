# ERICONT_ORI_VEC_PROP

ERICONT_ORI_VEC_PROP

Description​

A data type uses to control parameters of Ericont Ori Vec Prop

Attributes​

iConnId​

An Integer specifying connection ID.

The default value is 0.

iEndA​

An Integer specifying end a.

The default value is 0.

iEndB​

An Integer specifying end b.

The default value is 0.

dOrientVecX​

A Double specifying orient vec x.

The default value is 0.0.

dOrientVecY​

A Double specifying orient vec y.

The default value is 0.0.
