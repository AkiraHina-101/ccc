# MessageBox Icon Types

MessageBox Icon Types

これは、MessageBox Icon Typesを表す列挙型です。

 | MessageBox Icon Types | 説明

 | msgbox_icon.default | 情報アイコンが表示されたメッセージボックス

 | msgbox_icon.error | エラーアイコンが表示されたメッセージボックス

 | msgbox_icon.exclamation | 警告アイコンが表示されたメッセージボックス

 | msgbox_icon.question | 確認アイコンが表示されたメッセージボックス

 | msgbox_icon.asterisk | アスタリスクアイコンが表示されたメッセージボックス

 | msgbox_icon.user | ユーザーアイコンが表示されたメッセージボックス
