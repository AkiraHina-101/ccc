# Element Related Information | Rod

Element Related Information | Rod Element Related Information | Rod You can individually change the direction vector and end release information of elements included in the selected edge or directly selected elements. Switch End-A / End-B Swap the node numbers of A end and B end. Select All All elements displayed in the rod element list are to be overwritten. All check boxes will be checked. Select None Remove all elements displayed in the rod element list from the overwrite target. All check boxes will be cleared. Set Selected Target elements are selected from the screen and displayed in the selection list or elements are picked and highlighted in the rod element list. Only the selected element's check box is selected and displayed in the selection list. -&nbspOperating Procedure&nbsp- &nbspSelecting a command will display all existing rod elements in the list. The check box is cleared. &nbspSelect the target element from the list on the screen or in the dialog box, specify it and press the select button. The target element's check box is selected. &nbspEnter the value to be changed into items such as direction vector and offset vector, and press the setting button.
