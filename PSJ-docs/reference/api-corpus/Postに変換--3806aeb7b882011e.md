# Postに変換

Postに変換 Postに変換 設定情報を含むモデルのデータを、開いているPreドキュメントから新しいPostドキュメントに変換します。 オプション モデルのすべてのパーツや設定情報は、次の5つのオプションによってPreドキュメントから新しいPostドキュメントに変換されます。 グループ グループ情報を引き継ぎいで変換します. 変換可能なグループの種類は、ノードグループ（ノード、頂点）、1Dグループ（バー、エッジ、1D要素エッジ、要素エッジ）、2Dグループ（面、2D要素）、3Dグループ（パーツ、ソリッド要素）です。 LBC LBCの情報を引き継いで変換します。変換できるLBCの種類は、Force、Pressure、Fixed constraintです。 接続 接続情報を引き継いで変換します。変換可能な接続タイプは、MPC、RBE2、RBE3、Bush、Connector、Gaps、RBar、Spring、Damperです。 座標系 ローカル座標情報を引き継いで変換します。 プロパティ 材料のプロパティ情報を引き継いで変換します。変換可能なマテリアル・プロパティの種類は、1Dプロパティ、2Dプロパティ、3Dプロパティです。 -&nbsp操作手順&nbsp- ダイアログを起動します。 変換するオプションを選択してください（複数のオプションを選択できます）。 OK」ボタンをクリックすると、データが変換されます。 -&nbsp特記事項&nbsp- &nbsp&nbsp&nbspオプションを選択しない場合は、設定情報は含まれません。
