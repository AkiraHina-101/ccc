# CAD Trim

CAD Trim CAD Trim In this command, you can reduce the number of the facets (triangle patch shape) for CAD shape. ＊In JPT-Pre, facet is synonymous with the triangular primary element for the previous model mesh. (When the surface mesh can not be created cleanly, it is possible that this is because of large number of facets or many facets with maximum aspect ratio. In such a case, try this function.) Attiributes Trim Size Enter the maximum size for reducing facets. Trim Angle Enter the maximum angle for reducing facets. Model Details No of Tris The current number of facets (the number of triangular elements) is displayed. No of Points The number of the current point (number of nodes) is displayed. -&nbspOperating Procedure&nbsp- &nbspSelect the part or face to reduce the number of facets. &nbspEnter the range for Trim Size and Trim Angle to reduce the facets. &nbspClick Apply / OK button. Facet is reduced, No of Tris and No of Points will change. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
