# POST_DATA_VIZ_OPT_TITLE

POST_DATA_VIZ_OPT_TITLE

Description​

A data type is used to set up the result settings for displaying the title.

Attributes​

bResultName​

A Boolean specifying whether to display result name in the main window.

The default value is True.

bConvection​

A Boolean specifying whether to display convection in the main window.

The default value is True.

bUnit​

A Boolean specifying whether to display unit in the main window.

The default value is True.

bCoordinate​

A Boolean specifying whether to display coordinate in the main window.

The default value is True.

bTotalMaxMin​

A Boolean specifying whether to display total max/min in the main window.

The default value is True.

bFileName​

A Boolean specifying whether to display file name in the main window.

The default value is True.

bLocation​

A Boolean specifying whether to display location in the main window.

The default value is True.

bVisibleMaxMin​

A Boolean specifying whether to display visible max/min in the main window.

The default value is True.

bAnimation​

A Boolean specifying whether to display animation in the main window.

The default value is True.

bDeformRatio​

A Boolean specifying whether to display deformation ratio in the main window.

The default value is True.

bDetail​

A Boolean specifying whether to display detail in the main window.

The default value is True.

iResultTitleSize​

An Integer specifying the index option of the result title's font size.

The default value is 6.

iResultDescriptionSize​

An Integer specifying the index option of the result description's font size.

The default value is 5.

iResultTitle​

An Integer specifying the index option of the result title's font size.

The default value is 6.

iResultTitleColor​

An Integer specifying the font color of the result title.

The default value is 16777215.

bResultTitleBold​

A Boolean specifying whether to display result title in bold mode.

The default value is False.

iResultDescription​

An Integer specifying the index option of the result description's font size.

The default value is 5.

iResultDescriptionColor​

An Integer specifying the font color of the result description.

The default value is 16777215.

bResultDescriptionBold​

A Boolean specifying whether to display result description in bold mode.

The default value is False.

bUseBackground​

A Boolean specifying whether to use background color.

The default value is False.

iBackgroundFillColor​

An Integer specifying the background fill color.

The default value is 16777215.

iBackgroundBorderColor​

An Integer specifying the background border color.

The default value is 16777215.

dTransparency​

An Integer specifying the background transparency.

The default value is 0.5.

bAdjustTitlePos​

A Boolean specifying whether to adjust title position for image capture.

The default value is True.
