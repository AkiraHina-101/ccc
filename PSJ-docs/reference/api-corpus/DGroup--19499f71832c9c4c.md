# DGroup

DGroup

説明​

これは、Jupiter内のグループを表すDGroupクラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | name | グループの名前です。

 | typeID | グループのタイプID（ID = 79）。
戻り値はDItem TypesのInt表記 (int)です。

 | id | グループの外部IDです。
IDは重複することができますが、お勧めしません。
IDは再番号付け機能を使用して変更できます。
戻り値はID (int)です。

 | targets | グループの内容を保持します。
戻り値はDItemのリストです。

 | color* 1 | グループの色情報です。
この値は調整できます。
戻り値はRGBカラーです。

注意​

Footnotes​

属性名にアスタリスク*がある場合、その属性は現在の値から新しい値に変更/代入できることを意味します。 ↩
