# Mesh Quality&nbsp;-&nbsp;Auto Check&nbsp;[Tri]

Mesh Quality&nbsp;-&nbsp;Auto Check&nbsp;[Tri] Mesh Quality&nbsp;-&nbsp;Auto Check&nbsp;[Tri] The surface mesh (Tri3 / Tri6) of the surface is corrected by the multiple quality standard. Quality Standard Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value. Aspect Ratio: If checked, detect and display elements with aspect ratio greater than or equal to the specified value. Edge Length: If checked, detect and display elements with edge lengths less than the specified value. Area: If checked, the element of the area below the specified value will be detected and displayed. Node Valence: If checked, elements with more than the specified node valence will be detected and displayed. Interior Angle: If checked, detect and display elements with angles less than the specified value. Duplicate Elements: If checked, duplicates will be detected and displayed. ※Please refer to ＜definition of quality check method＞ for each item. Display Number of Entities: Displays the number of displayed elements. Auto Cleanup Cleanup: Automatically correct the detected and displayed elements. Mode: select the cleanup mode from Standard or Aggressive. Cleanup process Standard Aggressive Allowable face normal angle change of neighboring elements 60 degree 90 degree Collapse elem edges on an edge No Yes Non-manifold: Check to fix non-manifold. Refresh Show Model: Press the Show Model button to restore the model display. -&nbspOperating Procedure&nbsp- &nbspSelect the body you want to check the element shape. &nbspCheck the check box of the quality standard you want to check. &nbspPress the Apply or OK button. &nbspIf you want to restore the model view, press Show Model. ※The automatic cleanup feature can not automatically fix all elements. If there are elements that can not be fixed automatically, you need to manually fix the elements using the manual cleanup function.
