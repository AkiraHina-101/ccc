# アッセンブルソリッドメッシュ(Assemble Solid Mesh)

アッセンブルソリッドメッシュ(Assemble Solid Mesh) アッセンブルソリッドメッシュ(Assemble Solid Mesh) ソリッドメッシュパーツ向けのアッセンブリ機能です。本機能は、ソリッドメッシュモデルのパーツ入替や、新規パーツ追加などに有効です。 ソリッドメッシュ間がリメッシュされ、節点共有（共有面作成）されます。 例) サイドカバーメッシュの交換 変更前 : サイドカバーの節点は他のブロックと非共有（パーツ間境界のメッシュは不一致） 変更後 : 自動リメッシュにより節点共有（パーツ間境界のメッシュが一致） リメッシュされた要素と節点は、「AssembleSolidMesh」の名前でグループ化されます。 選択リスト(Selection list) 新規パーツ(New Part)：追加でアッセンブリするパーツ（1つ） アッセンブルパーツ(Assembled Part)：元のアッセンブリパーツ（複数可） 新規フェース(New Face)：追加でアッセンブリするパーツの、共有面にしたいフェース（複数可） アッセンブルフェース(Assembled Face)：元のアッセンブリパーツの、共有面にしたいフェース（複数可） パラメータ(Parameter) トレランス(Tolerane) フェースペアを抽出するためのパーツ間の距離を入力します。 入力した距離以内にあるパーツ間のフェースをアッセンブルし、共有面を作成します。 共有面作成位置(Connect Position) 共有面の作成位置を指定します。 中間位置(Mid) &nbsp;:&nbsp;新規パーツ(New Part)の位置を固定して共有面を作成します。アッセンブルパーツ(Assembled Part)の共有面はマスターフェースの位置に移動します。 マスター側(Master) &nbsp;:&nbsp;新規パーツ(New Part)とアッセンブルパーツ(Assembled Part)の中間の位置で共有面を作成します。 リメッシュサイズ自動(Remesh Size Auto) 新規共有面周りのメッシュサイズが自動的に設定されます。 リメッシュサイズ手動(Remesh Size Manual) 新規共有面周りのメッシュサイズを手動で入力します。 平均(Ave) &nbsp;:&nbsp;平均メッシュサイズ。 最小(Min) &nbsp;:&nbsp;最小メッシュサイズ。 最大(Max) &nbsp;:&nbsp;最大メッシュサイズ。 -&nbsp操作手順&nbsp- 新規パーツ(New Part)を1つ、もしくは、新規フェース(New Face)を選択します。 アッセンブルパーツ(Assembled Part)、もしくは、アッセンブルフェース(Assembled Face)を選択します。 必要に応じて、パラメータ(Parameter)を変更します。 適用(Apply)／OKボタンをクリックします。新規パーツ(New Part)とアッセンブルパーツ(Assembled Part)の間がリメッシュされ、共有面(Share Face)が作成（節点共有結合）されます。 -&nbsp操作手順：メッシュエラーが発生した場合&nbsp- メッシュエラーが発生した場合、リメッシュ範囲がパーツとして残ります。 該当パーツのメッシュエラーを、手動修正してください。 該当パーツを、元のパーツにマージしてください。 -&nbsp特記事項：パーツで選択する場合とフェースで選択する場合&nbsp- 選択を簡単にしたい場合は、新規パーツ(New Part)とアッセンブルパーツ(Assembled Part)により、対象をフェース単位で選択してください。ただし、メッシュモデルの形状によっては、意図しないフェースが共有面として抽出される場合があります。 共有面抽出の精度を向上させたい場合は、新規フェース(New Face)とアッセンブルフェース(Assembled Face)により、共有面の対象をフェース単位で直接選択してください。また、共有面抽出範囲が選択フェースに限定されるので、大きいトレランスを入力できます。 -&nbsp注意事項&nbsp- 本機能は、四面体要素のみ対応しています。 新規パーツ(New Part)とアッセンブルパーツ(Assembled Part)の要素次数は、一致している必要があります。 新規パーツ(New Part)は1つのみ対応しています。よって、新規フェース(New Face)も1つのパーツから選択してください。
