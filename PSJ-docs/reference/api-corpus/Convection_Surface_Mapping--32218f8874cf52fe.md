Export by &nbsp;&nbsp;&nbsp;Specify the fluid analysis solver from which the result file was output. Fluent StarCD CSV Mapping File &nbsp;&nbsp;&nbsp;Specify the fluid analysis result file. Heat Transfer Coef. Tag &nbsp;&nbsp;&nbsp;Select the column number to map the heat transfer coefficient. Temperature Tag &nbsp;&nbsp;&nbsp;Select a column number to map convection temperature. Scale Factor &nbsp;&nbsp;&nbsp;The mapping result can be corrected with a factor. Transform Data Rotation X/Y/Z &nbsp;&nbsp;&nbsp;The analysis results can be rotated to correct the position. Translation X/Y/Z &nbsp;&nbsp;&nbsp;The analysis result can be moved in the translational direction to correct the position. Coordinate Scale &nbsp;&nbsp;&nbsp;You can correct the scale of analysis results. Preview CFD Points &nbsp;&nbsp;&nbsp;The point cloud of the analysis result after correction can be displayed, and the position with the target model can be confirmed. Clear &nbsp;&nbsp;&nbsp;Clear the data point preview contents.
