# BASIC

BASIC

Description​

A data type uses to control parameters of Basic

Attributes​

bBasicOutputDisplacements​

A Boolean enable/disable basic output displacements.

The default value is False.

bOutputReactionLoad​

A Boolean enable/disable output reaction load.

The default value is False.

bBasicOutputStrain​

A Boolean enable/disable basic output strain.

The default value is False.

bBasicOutputStress​

A Boolean enable/disable basic output stress.

The default value is False.

iAnalysisOption​

An Integer specifying analysis option.

The default value is 0.

bCalculatePrestressEffect​

A Boolean enable/disable calculate prestress effect.

The default value is False.

dUniformTemperature​

A Double specifying uniform temperature.

The default value is 0.0.

dReferenceTemperature​

A Double specifying reference temperature.

The default value is 0.0.

dEndLoadTime​

A Double specifying end load time.

The default value is 0.0.

iTimeStep​

An Integer specifying time step.

The default value is 0.

iStepChosen​

An Integer specifying step chosen.

The default value is 0.

iSubStepNum​

An Integer specifying sub step number.

The default value is 0.

iMaxSubStep​

An Integer specifying maximum sub step.

The default value is 0.

iMinStepNum​

An Integer specifying minimum step number.

The default value is 0.

dTimeStepSize​

A Double specifying time step size.

The default value is 0.0.

dMinTimeStep​

A Double specifying minimum time step.

The default value is 0.0.

dMaxTimeStep​

A Double specifying maximum time step.

The default value is 0.0.

iWriteResultFre​

An Integer specifying write result frequency.

The default value is 1.
