# Connection | Damper - All Entities (1 to 1) - same DoFs

Connection | Damper - All Entities (1 to 1) - same DoFs Connection | Damper - All Entities (1 to 1) - same DoFs It is a function to create 1:1 damper elements. ＊The 1st group node and the 2nd group node can be selected in part units, face units, edge units, element units, and node units. The 1st group node and the closest 2nd group node (within the connection range) are connected. This feature allows you to combine multiple degrees of freedom (the 1st and 2nd group nodes have similar degrees of freedom). Connection Name Enter the name to be registered. Search All Specify the connection range as infinite. Tolerance Enter the radius of the connection range. Damper Grounded Specify the grounding spring option. X Damper - RZ Damper Enter the damping in the degrees of freedom to combine.
