# 2D3Dバッチ設定(2D3D Batch Setting)

2D3Dバッチ設定(2D3D Batch Setting) 2D3Dバッチ設定(2D3D Batch Setting) 各パーツに材料プロパティを一括設定します。設定できる材料プロパティは、2D / 3D / Gasketです。 材料プロパティの名前は、パーツ名と同じになります。 材料設定(Material Setting) 材料ライブラリバス(Browse material lib) 現在設定されている材料ライブラリの名前です。任意の材料ライブラリを指定できます。 テーブル(Table) 各列の1行目で、任意名称でのソートやフィルタリングが可能です。 パーツ(Part) パーツ名のリストです。 材料(Material) 材料ライブラリから材料を選択します。 タイプ(Type) 2D / 3D / Gasketから材料プロパティタイプを選択します。 厚さ(Thickness) タイプ(Type) = 2Dのパラメータです。要素の板厚を入力します。 板厚方向X/Y/Z(ThicX/Y/Z) タイプ(Type) = Gasketのパラメータです。ガスケットの厚み方向を方向ベクトルで指定します。 一軸(Uniaxial) タイプ(Type) = Gasketのパラメータです。厚さ方向挙動オプションを選択します。ADVCとABAQUSのみ有効です。 -&nbsp操作手順&nbsp- 材料ライブラリを指定します。 リスト内で、各パーツに設定する材料とタイプを指定します。 必要に応じて、リストのパラメータを変更します。 適用(Apply)ボタンをクリックします。各パーツに材料プロパティが一括設定されます。 -&nbsp操作手順：テーブル設定の入出力&nbsp- 設定ファイル出力(Export Setting File)ボタンをクリックします。テーブルの設定(*.csv)を出力します。 設定ファイル読込(Import Setting File)ボタンをクリックします。テーブルの設定(*.csv)を読込みます。 -&nbsp注意事項&nbsp- 本機能は材料ライブラリから材料を選択します。予め、 材料(Material)機能 で、材料ライブラリを作成してください。
