# GENERAL_REPORT_LINEAR_STATIC_DATA

GENERAL_REPORT_LINEAR_STATIC_DATA

Description​

A data type uses to control parameters of Linear Static data.

Attributes​

strPartName​

An Integer specifying the part name.

The default value is "".

strPropName​

A String specifying the property name.

The default value is "".

strMatName​

A String specifying the material name.

The default value is "".

dValue​

A String specifying the the standard value.

The default value is 0.0.
