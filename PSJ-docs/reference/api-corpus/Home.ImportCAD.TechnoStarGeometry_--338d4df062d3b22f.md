# Home.ImportCAD.TechnoStarGeometry()

Home.ImportCAD.TechnoStarGeometry()

説明​

bdfファイルでジオメトリをインポートします。

構文​

Home.ImportCAD.TechnoStarGeometry(...)

マクロ：ImportGeomBDF

リボン：Home » ImportCAD » TechnoStarGeometry

入力​

strlPath​

パスを指定する String のリストです。

デフォルト値は [] です。

bUseUnit​

単位を使用するかどうかを指定する Boolean です。

デフォルト値は True です。

戻り値​

成功した場合は1の String を、失敗した場合は0を返します。

サンプルコード​

Home.ImportCAD.TechnoStarGeometry(strlPath=[], bUseUnit=True)
