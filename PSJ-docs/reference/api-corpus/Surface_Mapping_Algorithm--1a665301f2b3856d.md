# Surface Mapping Algorithm

Surface Mapping Algorithm Surface Mapping Algorithm Boundary Condition Ribbon pressure, temperature, heat flux, and surface convection surface mappings assume that the shapes of the data points and the shapes to be mapped are approximately equal. Therefore, the value of the data point located closest to the element center or node is mapped as the target data (interpolation between data is not performed). If there are no data points in the vicinity, please use the mapping result at your own discretion. -&nbspData Search & Mapping Algorithm&nbsp- &nbsp;Set up a grid that covers the entire data cloud (fluid data). &nbsp;The grid width is determined from the spread and number of data cloud. &nbsp;Set the search circle around the element center / node of mapping target. The radius of the search circle is the grid width (automatic) or the tolerance value (input (TSV)). &nbsp;Find the indices of a grid that intersects a circle in a 2x2 (3x3) matrix. &nbsp;In the automatic case, if there is no data in the search grid, the search grid is expanded and the search continues. &nbsp;Map the point closest to the target in the detected grid (search grid) as the target data. Data outside the circle will not be mapped even if it is inside the search grid (if P1 and P2 are not present, P3 will not be mapped). -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
