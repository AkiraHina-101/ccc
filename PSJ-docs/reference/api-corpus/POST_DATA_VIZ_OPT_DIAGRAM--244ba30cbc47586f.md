# POST_DATA_VIZ_OPT_DIAGRAM

POST_DATA_VIZ_OPT_DIAGRAM

説明​

データ型は、図を表示するための結果設定を行うために使用されます。

属性​

iScaleMethod​

ベクトルのスケーリング方法を指定する Integer です。

0: モデルサイズ比

1: 画面サイズ比

デフォルト値は0です。

dRatioModel​

モデルによるスケーリング時の比率値を指定する 倍精度浮動小数点数 です。

デフォルト値は0.03です。

dRatioScreen​

画面によるスケーリング時の比率値を指定する 倍精度浮動小数点数 です。

デフォルト値は0.03です。

iHighLightColor​

ハイライト値を指定する Integer です。

デフォルト値は255です。

iPositiveColor​

正の値の色を指定する Integer です。

デフォルト値は16777215です。

iNegativeColor​

負の値の色を指定する Integer です。

デフォルト値は51400です。

bUseContour​

輪郭を表示するかを指定する 真偽値 です。

デフォルト値は False です。

bTwoSides​

両側の表示を指定する 真偽値 です。

デフォルト値は True です。

iHighlightOption​

ハイライトする値のタイプを指定する Integer です。

デフォルト値は0です。

dHighlightValueMin​

強調表示する最小値を指定する 倍精度浮動小数点数 です。

デフォルト値は0.0です。

dHighlightValueMax​

強調表示する最大値を指定する 倍精度浮動小数点数 です。

デフォルト値は1.0です。

iDisplayTarget​

ターゲットの表示を指定する Integer です。

デフォルト値は0です。

iThresholdOption​

ベクトルの表示範囲に対する結果値のオプションを指定する Integer です。

デフォルト値は0です。

dThresholdValueMin​

比較対象となる閾値の最小値を指定する 倍精度浮動小数点数 です。

デフォルト値は0.0です。

dThresholdValueMax​

比較対象となる閾値の最大値を指定する 倍精度浮動小数点数 です。

デフォルト値は100.0です。

iComparisonOption​

閾値の比較演算子を指定する Integer です。

デフォルト値は0です。

iComparisonMinRangeOption​

最大範囲の比較演算子を指定する Integer です。

デフォルト値は0です。

iComparisonMaxRangeOption​

最小範囲の比較演算子を指定する Integer です。

デフォルト値は0です。
