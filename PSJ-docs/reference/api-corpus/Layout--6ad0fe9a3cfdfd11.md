# Layout

Layout Layout Set the layout of the component. &nbsp;&nbsp;&nbsp;Creation image：Orientation Name &nbsp;&nbsp;&nbsp;Enter the name of the layout component. Orientation &nbsp;&nbsp;&nbsp;Specify the position of components. Horizontal &nbsp;:&nbsp;Arrange the components horizontal Vertical &nbsp;:&nbsp;Arrange the components vertically Margin &nbsp;&nbsp;&nbsp; Left &nbsp;:&nbsp;Put a margin to the left of the Group Box. (Units: pixels) &nbsp;&nbsp;&nbsp; Top &nbsp;:&nbsp;Put a margin above the Group Box. (Units: pixels) &nbsp;&nbsp;&nbsp; Right &nbsp;:&nbsp;Put a margin to the right of the Group Box. (Units: pixels) &nbsp;&nbsp;&nbsp; Bottom &nbsp;:&nbsp;Put a margin below the Group Box. (Units: pixels) Command to use Command Description Sample Code dlg.show_layout("name") Show the specified Layout. Input: dlg.show_layout("Layout5") dlg.hide_layout("name") Hides the specified Layout. Input: dlg.hide_layout("Layout5")
