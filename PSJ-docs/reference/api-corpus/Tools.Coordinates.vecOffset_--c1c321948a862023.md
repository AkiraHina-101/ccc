# Tools.Coordinates.vecOffset()

Tools.Coordinates.vecOffset()

Description​

Unknown Description

Syntax​

Tools.Coordinates.vecOffset(strName="CRect1", iCoordType=0, vTranslate=[0.0,0.0,0.0], bCreateNew=True, crRefCoord=None, crEdit=None)

Ribbon: Tools » Coordinates » vecOffset

Inputs​

strName​

A String specifying the name.

The default value is "CRect1".

iCoordType​

An Integer specifying the coordinate type.

The default value is 0.

vTranslate​

A V_TRANSLATE specifying the translate.

The default value is [0.0,0.0,0.0].

bCreateNew​

A Boolean specifying the create new.

The default value is True.

crRefCoord​

A Cursor specifying the reference coordinate.

The default value is None.

crEdit​

A Cursor specifying the edit.

The default value is None.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Tools.Coordinates.vecOffset(strName="CRect1", iCoordType=0, vTranslate=[0.0,0.0,0.0], bCreateNew=True, crRefCoord=None, crEdit=None)
