# MeshEdit.MoveNode.ProjectToLine()

MeshEdit.MoveNode.ProjectToLine()

Description​

Move node by project to line

Syntax​

MeshEdit.MoveNode.ProjectToLine(crlRefNodes=[], crlObjNodes=[], iType=0)

Ribbon: MeshEdit » MoveNode » ProjectToLine

Inputs​

crlRefNodes​

A List of Cursor specifying the reference nodes.

The default value is [].

crlObjNodes​

A List of Cursor specifying the object nodes.

The default value is [].

iType​

An Integer specifying the type.

The default value is 0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.ProjectToLine(crlRefNodes=[], crlObjNodes=[], iType=0)
