# MeshEdit.MeshCopy()

MeshEdit.MeshCopy()

Description​

Mesh Copy Pattern

Syntax​

MeshEdit.MeshCopy(crlFaces=[], crlNodes=[])

Ribbon: MeshEdit » MeshCopy

Inputs​

crlFaces​

A List of Cursor specifying the face.

The default value is [].

crlNodes​

A List of Cursor specifying the node.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MeshCopy(crlFaces=[], crlNodes=[])
