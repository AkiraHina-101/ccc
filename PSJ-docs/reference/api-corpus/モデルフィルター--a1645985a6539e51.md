# モデルフィルター

モデルフィルター a.no-uline {text-decoration:none} モデルフィルター モデルの要素タイプ、プロパティ、材料情報を相互に参照しながらグループを作成します。 フィルタータイプ 要素タイプ &nbsp;&nbsp;&nbsp;バー、三角形シェルなどの要素タイプによって表示内容を切替えます。 プロパティ &nbsp;&nbsp;&nbsp;モデルに使用されているプロパティ（要素特性）情報によって表示内容を切替えます。 材料 &nbsp;&nbsp;&nbsp;モデルに使用されている材料情報によって表示内容を切替えます。 グループ &nbsp;&nbsp;&nbsp;既存のグループによって表示内容を切替えます。 リセット &nbsp;&nbsp;&nbsp;全てのフィルタータイプにおいて選択された内容をリセットします。 ターゲット &nbsp;&nbsp;&nbsp;ビューウインドウに表示状態にあるボディに使用されているアイテムが、各フィルターに対応してリスト表示されます。 &nbsp;&nbsp;&nbsp;リストからアイテムをピックするとアイテムが反転して選択表示になり、対応した要素がビューウインドウに表示されます。 &nbsp;&nbsp;&nbsp;要素タイプ以外のアイテムは昇順にソートされてリスト表示されます。 &nbsp;&nbsp;&nbsp;再度アイテムをピックするとアイテムが選択解除されます。 &nbsp;&nbsp;&nbsp;ShiftキーやCtrlキーを使用するWindows標準操作でアイテムの複数選択ができます。 &nbsp;&nbsp;&nbsp;フィルターを切替え、更にアイテムの選択をすると、更に範囲の絞り込みができます。 &nbsp;&nbsp;&nbsp;例ではHEXA、PENTA要素タイプでSolid Property1を使用する要素グループを表示します。 新規グループ 節点グループ &nbsp;&nbsp;&nbsp;チェックすると作成するグループに節点を含めます。 要素グループ &nbsp;&nbsp;&nbsp;チェックすると作成するグループに要素を含めます。 名前 &nbsp;&nbsp;&nbsp;作成するグループの名前を入力します。 新規グループ作成 &nbsp;&nbsp;&nbsp;ボタンを押すと新規グループを作成します。 -&nbsp;操作手順&nbsp;- &nbsp;ビューウインドウにモデルのグループ作成対象となる範囲を表示します。 &nbsp;フィルタータイプから要素タイプボタンを押し、グループ作成対象となる要素タイプを選択します。 &nbsp;さらにフィルタータイプからプロパティや材料ボタンを押し、リストからアイテムを選択して表示範囲を絞り込みます。 &nbsp;絞り込みが終わったら、新規グループの名前を入力し、新規グループ作成ボタンを押します。 &nbsp;新しいグループが作成されましたので、フィルタータイプからグループを選択し、リストを確認します。 グループを表示させるには、フィルタータイプからリセットを選択し、今までの選択履歴をリセットしてからアイテムを選択します。 &nbsp;コマンドを終了するには、右上のXボタンをクリックします。 ※作成したグループの表示を行う場合は、メインウィンドウ内の'グループ表示モードアイコン をクリックします。 &nbsp;&nbsp;再度クリックすると、表示を通常に戻せます。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
