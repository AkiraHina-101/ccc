# HexSweepCurve()

HexSweepCurve()

説明​

カーブスイープによる六角形メッシュを作成します

構文​

HexSweepCurve(int[] nFaceIds, int[] nEdgeIds, double dMeshSize)

入力​

1. Int[]​

円形スイープ用のフェースID配列

2. Int[]​

円形スイープ用のエッジID配列

3. Double​

メッシュサイズ

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

HexSweepCurve([247], [44], 0.0001)
