# Connection | RBE3 - One to many

Connection | RBE3 - One to many Connection | RBE3 - One to many This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element). Slave node and the master node can be selected on the parts basis, face basis, edge basis, element-wise or on node basis. Slave node and master node (in the connection range) is connected. In this function, you can set up multiple master term. For each section set the node, the weighting factor and the degree of freedom. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius R of the connection range. Slave Dofs UX - RZ It specifies the component of slave degree of freedom. Master Dofs Term When you have finished the settings, number of section is displayed. New Add a section. Remove Remove the section number that is displayed in the Term. Weight Enter the weighting factor. UX - RZ Specify the component degrees of freedom with a weighting factor. Analysis Coordinate Frane Coordinate Select the reference coordinate system. Options for Abaqus Surface Definition Output Select how to define the surface. By Node Set Specify the node as a reference surface. By Element Set Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output. Options Only corner nodes Connect only to the corner nodes of the selected entity. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspThe slave nodes are selected from parts, face, edge, element and node. &nbspEnter the parameters of the slave. &nbsp[Repeat for each Term] The master nodes are selected from parts, face, edge, element and node. &nbsp[Repeat for each Term] Enter the parameters of the master. &nbsp[Repeat for each Term] Term> New button. Setting 4) and 5) will be added to the Term. &nbspClick Apply / OK button. -&nbspOperating Procedure (Deletion of Term)&nbsp- &nbspSelect the number of Term to be deleted. &nbspClick the Term> Remove button.
