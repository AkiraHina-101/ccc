# RichEditCtrl

RichEditCtrl

様々なデータ形式や複数行に入力できるテキストボックスを作成します。

プレビューダイアログ：

パラメータ​

デフォルト​

デフォルトで表示されるテキストを入力します。

名前​

リッチエディットコントロールの名前を入力します。

サイズ​

幅：リッチエディットコントロールコンポーネントの最小幅を指定します。（ピクセル単位）

高さ：リッチエディットコントロールコンポーネントの最小高さを指定します。（ピクセル単位）

有効​

有効にするかどうかを指定します。

チェック オン：利用可能

チェック オフ：利用不可（グレーアウト）

表示​

作成した RichEditCtrl を表示するか非表示にするかを指定します。

チェック オン：表示

チェック オフ：非表示

関連する API​

dlg.add_richeditbox：ダイアログにリッチエディットボックスを追加します。
