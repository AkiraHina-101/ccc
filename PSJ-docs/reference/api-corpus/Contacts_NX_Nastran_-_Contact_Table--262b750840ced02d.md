# Contacts | NX Nastran - Contact Table

Contacts | NX Nastran - Contact Table Contacts | NX Nastran - Contact Table The gap distance between parts automatically detects contact pairs and creates contact definitions. Contact Finding Tolerance Enter the gap distance between parts to detect contact pairs. Detects faces below input tolerance and displays contact pair candidates. Tolerance for TIED Enter the gap distance between parts for tied definition. Among the detected contact pairs, the contact pair candidate that is less than the entered tolerance is automatically defined as the tied definition. Other than that, it is a sliding contact definition. Input Unit Specify the unit system of tolerance. Search Area Specify the range of contact pairs and candidate faces. When minimized, only faces found with search tolerance will be displayed as potential contact pairs. When maximized, it will display as a contact pair candidate up to the face that smoothly connects with the searched face. Master Basis Specify the contact segment judgment criteria to be the master face of the detected contact pairs. Mesh size: Segment group with large element surface area average value Area: Segment group with large total area Find Contact Faces are detected based on input tolerance and contact pair candidates are displayed in a table. When running without selecting a part, you will see a confirmation message about performing a search across the part. Options Select the contact option to display in the table. Table Option Title Bar Clicking on each title will sort the contact pair candidates by the item name. To change the option to display, specify from the option button. Search Box Only show partial matching contact candidates. Click the X button to cancel the search. Checkbox Of the detected contact pairs, check the contact pairs that you actually define. Click Apply (OK) button to create a contact pair. Contact table Selecting the contact pair candidate displayed in the table highlights the contact pair in the model window. The color of the master / slave contact segment depends on the Home > Preferences > Screen Settings > LBC Master Color / Slave Color setting. Contact Option Setting Edit the displayed contact options in the table. For each contact option, the input method is divided into check box, pull-down selection, numerical input, and another dialog display button. Even after creating contact pairs, the contact options can be edited individually. Table Function Buttons All On: Select all contact pair candidates. Switch Master / Slave: Switch master / slave segment group of contact pair. All Off: Deselect all contact pairs. Edit: Open and edit the contact pair candidate selected in the table in the manual group dialog. Delete: Delete the contact pair candidate selected in the table. Export: Output contact option information of existing contact pairs (contact pairs without check box on / off of table) to csv file. Import: Load a csv file of contact option information and update the existing contact pair information in the table. -&nbsp;Operating Procedure&nbsp;- Procedure for creating a new contact pair &nbspEnter the respective tolerance values for Finding tolerance and Tied tolerance and press the contact search button. &nbsp;&nbsp;&nbsp;If you want to narrow the detection range, select multiple parts and press the button.
