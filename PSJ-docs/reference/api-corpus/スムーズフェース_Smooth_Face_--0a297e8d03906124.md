# スムーズフェース(Smooth Face)

スムーズフェース(Smooth Face) スムーズフェース(Smooth Face) 選択した節点（エッジ）で囲まれた部分にフェースを作成します（プレビューが表示される場合は作成されます）。 フェースはメッシュかジオメトリの何方かを選べます。メッシュフェースの場合は、周囲との連続性などにより形状を補間します。 選択リスト(Selection list)：共有面(Share Face) = OFF エッジ(Edge)：フェース作成範囲の境界節点をエッジで選択 節点(Node)：フェース作成範囲の境界節点を選択 パーツ(Part)：フェースが所属するパーツ（1つ）※選択しない場合は新規パーツとして作成されます。 選択リスト(Selection list)：共有面(Share Face) = ON エッジ(Edge)：フェース作成範囲の境界節点をエッジで選択 節点(Node)：フェース作成範囲の境界節点を選択 パーツ(Part)：共有面を挟むパーツA（1つ） パーツ(Part)：共有面を挟むパーツB（1つ） フェースタイプ(Face Type) ジオメトリ―フェース(Geometry Face) ジオメトリフェースを作成します。 メッシュフェース(Mesh Face) 形状補間によりメッシュフェースを作成します。 共有面(Share Face) 2つのパーツに挟まれた共有面を作成します。本オプションがONのとき、選択リスト(Selection list)にパーツ(Part)が2つ表示されます。作成する共有面を挟むパーツをそれぞれ1つずつ選択してください。 補間(Interporation) ファセットサイズやメッシュサイズを均一にすることで、自由端の形状などを補間します。 フリーエッジが作成される場合があるので、注意事項をご参照ください。 メッシュフェースパラメーター(Mesh Face Parameter) TRI TRI要素を作成します。 QUAD QUAD要素を作成します。 グラデーション係数(Gradation Factor) メッシュフェースのメッシュサイズを定義するため、周りの要素サイズに対する係数（1 接続連続性(Connection continuity) 連続性の次数を選択します。 G0:（位置連続）作成するフェースと隣接フェースの接合部分で、エッジを共有している状態です。接合部分で折れ曲がりが発生します。平面メッシュフェースを作成したい場合にお勧めします。 G1:（接線連続）作成するフェースと隣接フェースの境界で、両フェースの法線ベクトルが同じ場合の状態です。接合部分は滑らかになります。曲面メッシュフェースを作成する場合にお勧めします。 フェース作成範囲を分けてください。下記では、上下の曲線エッジを選択してもプレビューが表示されないため、エッジを分割して少しずつ選択したり、節点ごとに少しずつ選択しています。 パーツ選択時のワーニングメッセージ 共有面(Share Face)=Off：選択した節点に所属するパーツ数が1つではない場合、作成するフェースは共有面の方が良い場合があるため、ワーニングメッセージを表示します。問題ない場合は、OKをクリックしてください。 共有面(Share Face)=On：選択した節点に所属するパーツ数が2つではない場合、作成する共有面の範囲を見直した方が良い場合があるため、ワーニングメッセージを表示します。問題ない場合は、OKをクリックしてください。 フェースの裏表 作成されたフェースの法線方向が周りと異なる場合がございます。その場合は、フェースを選択して、右クリック(Right Click) > 反転(Flip)でフェースの法線方向を修正してください。 補間(Interporation)によるフリーエッジ 補間(Interporation)は選択されたエンティティ間のメッシュサイズも変更します。そのため、節点を選択して、それらの節点の間隔が平均と大きく異なる場合、フリーエッジが作成される場合があります。 複数の離れた閉空間 本機能は、複数の離れた閉空間に対して、同時にフェースを作成することはできません。適用(Apply)／OKボタンが非アクティブになります。1つ1つ実行して頂くか、PSJによる自動化をお願い致します。
