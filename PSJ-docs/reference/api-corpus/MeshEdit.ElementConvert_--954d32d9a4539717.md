# MeshEdit.ElementConvert()

MeshEdit.ElementConvert()

Description​

Element Conversion

Syntax​

MeshEdit.ElementConvert(crlParts=[], iType=1)

Ribbon: MeshEdit » ElementConvert

Inputs​

crlParts​

A List of Cursor specifying the part.

The default value is [].

iType​

An Integer specifying the type.

The default value is 1.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.ElementConvert(crlParts=[], iType=1)
