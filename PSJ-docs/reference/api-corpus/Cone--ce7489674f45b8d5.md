# Cone

Cone Cone Create a cone. Part Properties Part Name Enter the name of the cone to be created. Cone Local Coordinates Select any of the coordinate system. Frustum When checked, it makes a plane on the conical tip section. Origin-X,Y,Z Specify the origin coordinates. Top Radius If you put a check for Frustum, specify the radius of the plane of distal end portion. Bottom Radius Enter the radius of the bottom. Height Enter the height of the cone. Number of Nodes in Circle Enter the number of nodes to be generated on the arc.
