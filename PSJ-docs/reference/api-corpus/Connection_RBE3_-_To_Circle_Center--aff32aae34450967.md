# Connection | RBE3 - To Circle Center

Connection | RBE3 - To Circle Center Connection | RBE3 - To Circle Center This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element). ＊Master node is available for selection on face basis and edge basis. Slave node and master node (in the connection range) are connected. Slave node is created on the coordinates of the centre of the selected arc. This is useful when you want to create a RBE3 for a circle or a cylindrical shape. In this function, you can set up multiple master term. For each section set the node, the weighting factor and the degree of freedom. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius R of the connection range. Slave Dofs UX - RZ Specify the component of slave degree of freedom. Master Dofs Term When you have finished the settings, number of section is displayed. Add Add a section. Remove Remove the section number that is displayed in the Term. Edit Edit the section number that is displayed in the Term. Weight Enter the weighting factor. UX - RZ Specify the component degrees of freedom with a weighting factor. Analysis Coordinate Frame Coordinate Select the reference coordinate system. Options for Abaqus Surface Definition Output Select how to define the surface. By Node Set Specify the node as a reference surface. By Element Set Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output. Options Only corner nodes Connect only to the corner nodes of the selected entity. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspSelect the edge. Now, the coordinates of the slave node is defined at the center of the edge. &nbspEnter the parameters of the slave. &nbsp[Repeat for each Term] Select a Face for the master nodes. If you do not select a face, edge nodes are specified as master. &nbsp[Repeat for each Term] Enter the parameters of the master. &nbsp[Repeat for each Term] Term > Add button. Setting 4) and 5) will be added to the Term. &nbspIf necessary, edit the coordinates of the slave node to arbitrary coordinate. &nbspClick Apply / OK button. -&nbspOperating Procedure (Deletion of Term)&nbsp- &nbspSelect the number of Term to be deleted. &nbspClick the Term > Remove button. Term will be deleted. -&nbspOperating Procedure (Editing the Term)&nbsp- &nbspSelect the number of Term to be edited. &nbspChange the master nodes. &nbspChange the parameters of master nodes. &nbspClick the Term > Edit button. Term is edited. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
