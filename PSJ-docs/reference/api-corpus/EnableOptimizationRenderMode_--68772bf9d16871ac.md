# EnableOptimizationRenderMode()

EnableOptimizationRenderMode()

説明​

最適化レンダリングモードを有効化または無効化します。
このモードは、最適化ツールキットで設定された最適化された形状パラメータによって非表示要素を表示できます。

構文​

EnableOptimizationRenderMode(int Flag)

入力​

1. int​

最適化レンダリングモードフラグをオン/オフにします。0: オフ、1: オン。

戻り値​

なし。

サンプルコード​

EnableOptimizationRenderMode(1)
