# Dialog

Dialog Dialog Set up the title, execute button, and click button (selection list) of the creation dialog. &nbsp;&nbsp;&nbsp;Creation image： Title &nbsp;&nbsp;&nbsp;Enter the title of the dialog you want to create. Resizable &nbsp;&nbsp;&nbsp;Specify whether to resize the dialog to be created. Check On &nbsp;:&nbsp;Change the size of the dialog. Check Off &nbsp;:&nbsp;The size of the dialog is fixed. Validation &nbsp;&nbsp;&nbsp;Specify whether to confirm the input in the dialog. (format, data format, etc.) Check On &nbsp;:&nbsp;Confirm Check Off &nbsp;:&nbsp;Do not confirm Apply Button &nbsp;&nbsp;&nbsp;Sets whether to create the Apply button. Check On &nbsp;:&nbsp;Create Check Off &nbsp;:&nbsp;Not created OK Button &nbsp;&nbsp;&nbsp;Sets whether to create an OK button. Check On &nbsp;:&nbsp;Create Check Off &nbsp;:&nbsp;Not created Cancel Button &nbsp;&nbsp;&nbsp; Sets whether to create the Cancel button. Check On ：Create Check Off ：Not created Description &nbsp;&nbsp;&nbsp;The information you enter here will be displayed at the top of the dialog. Selector &nbsp;&nbsp;&nbsp;Option to add a selection list. &nbsp;&nbsp;&nbsp;※Supported Selection Types： &nbsp;&nbsp;&nbsp;Node Selector, Part Selector, Bar Part Selector, Element Edge Selector, &nbsp;&nbsp;&nbsp;1D Element Selector, 2D Element Selector,3D Element Selector,Face Selector, Edge Selector, Vertex Selector. Command to use Command Description Sample Code dlg.on_command(“name”, function) Execute by incorporating the function in the created component. Input: dlg.on_command(“ButtonOk”, on_click_exec_button) dlg.add_space(orientation = "horizontal, layout = "Layout") Adds a placeholder with the specified orientation. Input: dlg.add_space(orientation="horizontal",layout="footer") dlg.get_selected_entities(int selector_id) Gets the selected entities for the specified Selector. Input: dlg.get_selected_entities(0) dlg.disable_item("component name") Changes the property status of a component from enabled to disabled. Input: dlg.disable_item("TextBox") dlg.enable_item("component name") Change the status of the component properties from disabled to enabled. Input: dlg.enable_item("TextBox")
