# Element Related Information | Bar

Element Related Information | Bar Element Related Information | Bar Element Related Information | Bar Dialog Box You can individually change the direction vector and end release information of elements included in the selected edge or directly selected elements. Switch End-A / End-B Swap the node numbers of A end and B end. Orientation Vector Overwrite the orientation vector of the beam. By Vector Enter the orientation vector as the direction cosine of X, Y, Z. Set Face Normal Direct the orientation vector to the normal direction of the surface to which the element belongs. By Node Perform element coordinate system definition by specified nodes. 節点 --> Offset Vector Give offset vector of beam as direction cosine and overwrite it. Pin Flag at A Enter the number of degrees of freedom to release the end release setting of A end and overwrite it. Pin Flag at B Enter the number of degrees of freedom to release the end release setting of B end and overwrite it. Select All All elements displayed in the bar element list are to be overwritten. All check boxes will be checked. Select None Remove all elements displayed in the bar element list from the overwrite target. All check boxes will be cleared. Set Selected Target elements are selected from the screen and displayed in the selection list or elements are picked and highlighted in the bar element list. Only the selected element's check box is selected and displayed in the selection list. -&nbspOperating Procedure&nbsp- &nbspSelecting a command will display all existing bar elements in the list. Initially, the check boxes for all element IDs are checked, and all elements are subject to overwrite. &nbspTo overwrite only specific elements, press No selection below the list and deselect all elements. The check box is cleared. &nbspSelect the target element from the list on the screen or in the dialog box, specify it and press the select button. The target element's check box is selected. &nbspEnter the value to be changed into items such as orientation vector and offset vector, and press the setting button. The target item on the list is overwritten. &nbspClick Apply or OK to apply your changes. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
