# ComboBox

ComboBox ComboBox Add a combo box. &nbsp;&nbsp;&nbsp;Creation image： Name &nbsp;&nbsp;&nbsp;Enter the name of the combo box component. Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the combo box. (Units: pixels) Height &nbsp;&nbsp;&nbsp;Specifies the minimum height of the combo box.(Units: pixels) Source File &nbsp;&nbsp;&nbsp;Enter options from a text file. &nbsp;&nbsp;&nbsp;Structure of the Source File： &nbsp;&nbsp;&nbsp;&nbsp;Option1 &nbsp;&nbsp;&nbsp;&nbsp;Option2 &nbsp;&nbsp;&nbsp;&nbsp;Option3 &nbsp;&nbsp;&nbsp;&nbsp;Option4 &nbsp;&nbsp;&nbsp;&nbsp;Option5 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↓ &nbsp;&nbsp;&nbsp;&nbsp;Input result： Option Count &nbsp;&nbsp;&nbsp;Specify the number of items to be selected. Options * &nbsp;&nbsp;&nbsp;Enter the name of the item. Command to use Command Description Sample Code dlg.get_combobox_sel("name") Get the position of the item selected in the combo box. ComboBox = ["1", "2", "3", "4", "5"] When "4" is selected Input: a = dlg.get_combobox_sel("ComboBox") Output: > a = 3 dlg.get_len_combobox("name") Get the length of the combo box. listbox = ["1", "2", "3", "4", "5"] Input: a = dlg.get_len_combobox("ComboBox”) Output: > a = 5 dlg.set_combobox_sel(“Name”, Index) Switches the value selected in the combo box. ComboBox = [“1”, “2”, “3”, “4”, “5”] Input: dlg.set_combobox_sel(“ComboBox”, 3) ⇒ Selected value=”4” dlg.insert_combobox_option("name", position, "text") A value is added from the position selected in the combo box (1 value once). Input: dlg.insert_combobox_option("name", 1, "text") dlg.insert_combobox_options("name", position, [itemlist]) A value is added from the position selected in the combo box (multiple values once). Input: dlg.insert_combobox_options("name", 3, [Itemlist])
