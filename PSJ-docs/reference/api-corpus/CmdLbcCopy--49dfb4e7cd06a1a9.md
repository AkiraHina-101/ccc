# CmdLbcCopy

CmdLbcCopy CmdLbcCopy Description Copy properties by translation There are 3 cases: Copy translation Copy rotation Copy mirror Syntax COPY TRANS: CmdLbcCopy(int Method, int MatchMethod, double[3] TransVec, double Magnitude, double Offset, double Tolerance, Cursor Coordinate, Cursor[] Target) COPY ROTATE: CmdLbcCopy(int Method, int MatchMethod, double[3] AxisVec, double[3] CenterVec, double Angle, double Tolerance, Cursor Coordinate , Cursor[] Target) COPY MIRROR: CmdLbcCopy(int Method, int MatchMethod, double[3] Points , double Offset, double Tolerance, Cursor[] Target) Inputs Int Method COPY TRANS = 0, COPY ROTATE = 1, COPY MIRROR = 2 Int Match method MATCH NODE = 0, MATCH FEATURE = 1 Double[3] Trans vector Double Magnitude Double Offset Double Tolerance Cursor Coordinate Double[3] Axis vector Double[3] Center vector Double Angle Cursor Coordinate Double[3] Points Double Offset Double Tolerance Cursor[] Target (LBC/Property/Connection/Group) Return Code 1 Succeeded 0 Failed Sample Code CmdLbcCopy(0, 0, [0.001, 0, 0], 0.03, 0, 0.0001, 0:0, [40:1])
