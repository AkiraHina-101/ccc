# Connection RBE3 To Center

Connection RBE3 To Center Connection RBE3 To Center This function is to create one to many (Slave : Master) RBE3 (Interpolation constraining Element). ＊Master node can be selected on the parts basis, face basis, edge basis, element-wise or on node basis. Slave node and master node (in the connection range) are connected. The slave node is created in the average coordinate of the selected master node or arbitrary coordinates. This is useful when you want to define a slave node outside the model. In this function, you can set up multiple master terms. For each section set the node, the weighting factor, and the degree of freedom. Connection Name Enter the name to be registered. Search Area All Specify the connection range is infinite. Tolerance Enter the radius R of the connection range. Position of slave node X Y Z The coordinates of the slave node are displayed. The coordinate will be set automatically to the average coordinates of the selected master nodes. You can also edit it to any coordinate value. Update the coordinate to center of latest selected edge The coordinates of the latest selected edge are displayed and used as the slave node of RBE3. If the selected edge is a curve, the coordinates will be the average center coordinates of the curve, if it is a straight line, the coordinates will be the average coordinates of the nodes. For example, the center of the bearing surface of a bolt (circle or cylinder shape) will be used as the slave. Slave Dofs UX - RZ Specify the component of the slave degrees of freedom. Master Dofs Term When you have finished the settings, a number of sections are displayed. New Add a section. Remove Remove the section number that is displayed in the Term. Weight Enter the weighting factor. UX - RZ Specify the component of the degrees of freedom with a weighting factor. Analysis Coordinate Frame Coordinate Select the reference coordinate system. Options for Abaqus Surface Definition Output Select how to define the surface. By Node Set Specify the node as a reference surface. By Element Set Specify the element as a reference surface. You cannot configure an element to the slave entity (node, edge), and if it has been selected an error will be output. Options Only corner nodes Connect only to the corner nodes of the selected entity. -&nbsp;Operating Procedure&nbsp;- &nbsp;Set the connection range. &nbsp;Enter the parameters of the slave. &nbsp;[Repeat for each Term] The master nodes is selected from parts, face, edge, element and node. &nbsp;[Repeat for each Term] Enter the parameters of the master. &nbsp;[Repeat for each Term] Term > Add button. Setting 4) and 5) will be added to the Term. &nbsp;If necessary, edit the coordinates of the slave node in any coordinate. &nbsp;Click Apply / OK button. -&nbsp;Operating Procedure (Deletion of Term)&nbsp- &nbsp;Select the number of Terms to be deleted. &nbsp;Click the Term > Remove button.
