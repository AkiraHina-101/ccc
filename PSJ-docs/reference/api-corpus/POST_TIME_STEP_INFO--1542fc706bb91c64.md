# POST_TIME_STEP_INFO

POST_TIME_STEP_INFO

説明​

ポストタイムステップの情報を定義するために使用するデータ型です。

属性​

iMode​

使用モードを指定する Integer です。

デフォルト値は DFLT_INT です。

dTime​

時間の値を指定する Double です。

デフォルト値は FLT_MAX です。

dFrequency​

周波数値を指定する Double です。

デフォルト値は FLT_MAX です。

iBaseAnalysisType​

ベース解析タイプを指定する Integer です。

デフォルト値は 0 です。

strResultSetName​

リザルトセット名を指定する String です。

デフォルト値は "" です。
