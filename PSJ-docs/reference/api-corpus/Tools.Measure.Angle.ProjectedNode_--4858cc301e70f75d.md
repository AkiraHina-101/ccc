# Tools.Measure.Angle.ProjectedNode()

Tools.Measure.Angle.ProjectedNode()

説明​

投影された節点の角度を測定します。

構文​

Tools.Measure.Angle.ProjectedNode(crNode, strTarget="All", iPrecision=6)

リボン：Tools » Measure » Angle » ProjectedNode

入力​

crNode​

節点を指定する Cursor です。

これは必須の入力です。

strTarget​

ターゲットを指定する String です。

デフォルト値は「All」です。

iPrecision​

精度を指定する Integer です。

デフォルト値は6です。

戻り値​

成功すると「1」、失敗すると「0」の文字列が返されます。

サンプルコード​

Tools.Measure.Angle.ProjectedNode(crNode, strTarget="All", iPrecision=6)
