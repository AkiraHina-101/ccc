# ギヤ接触力

ギヤ接触力 ギヤ接触力 はすば歯車のトルク伝達条件（RBE2 + MPC + かみ合い方向の局所座標系）を一括で作成します。 かみ合い方向は、入力パラメータの回転方向、ねじれ方向、ねじれ角、圧力角から自動計算します。 かみ合い点の位置は、ギヤの歯数と中心距離から自動計算します。 それぞれのギヤ伝達条件はグループ化されます。 制限事項：歯なしヘキサメッシュのギヤモデルのみに対応します。 選択リスト(Selection list) エッジ：ドライブギヤとドリブンギヤの円弧エッジ ギヤ接触力 名前 作成するアイテムの名前を入力します。 回転軸 回転軸の方向 歯車の軸方向を指定します。 座標 歯車の軸方向の参照座標系を指定します。 ドライブギヤ 回転方向 ドライブギヤの回転方向を指定します。（回転軸の方向に基づく） 歯数 ドライブギヤの歯数を入力します。 ねじれ方向 ドライブギヤのねじれ方向を指定します。（回転軸の方向に基づく） ねじれ角（度） ドライブギヤのねじれ角を入力します。 圧力角（度） ドライブギヤの圧力角を入力します。 ドリブンギヤ 歯数 ドリブンギヤの歯数を入力します。 -&nbsp操作手順&nbsp- &nbspドライブギヤ -> ドリブンギヤの順に、2つの円弧エッジを選択します。 &nbsp回転軸の方向を指定します。 &nbspドライブギヤとドリブンギヤのパラメータを入力します。 &nbsp適用／OKボタンをクリックします。 -&nbspOperation video&nbsp- &nbspPress the play button to play the operation video。 -->
