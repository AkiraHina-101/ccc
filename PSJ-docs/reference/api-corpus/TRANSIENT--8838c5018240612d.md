# TRANSIENT

TRANSIENT

Description​

A data type uses to control parameters of Transient

Attributes​

bTransientEffect​

A Boolean enable/disable transient effect.

The default value is True.

iLoadingType​

An Integer specifying loading type.

The default value is 0.

dMassMatrixMultiplier​

A Double specifying mass matrix multiplier.

The default value is 0.0.

dStiffMatrixMultiplier​

A Double specifying stiff matrix multiplier.

The default value is 0.0.

bMidStep​

A Boolean enable/disable mid step.

The default value is False.

dToleranceBisection​

A Double specifying tolerance bisection.

The default value is 0.0.

dToleranceTimeStep​

A Double specifying tolerance time step.

The default value is 0.0.

iTimeInterAlgorithm​

An Integer specifying time inter algorithm.

The default value is 0.

iTimeInter​

An Integer specifying time inter.

The default value is 0.

dGamma​

A Double specifying gamma.

The default value is 0.005.

dAlpha​

A Double specifying alpha.

The default value is 0.25250625.

dDelta​

A Double specifying delta.

The default value is 0.505.

dAlphaF​

A Double specifying alpha f.

The default value is 0.005.

dAlphaM​

A Double specifying alpha m.

The default value is 0.0.

bTransientOutputTemperature​

A Boolean enable/disable transient output temperature.

The default value is False.
