# CursorStr

CursorStr

説明​

単一のカーソルまたはカンマで区切られた複数のカーソルを表します。 Cursor の代わりとして、または List of Cursor の内容として使用できます。

プロパティ​

 | 属性 | 説明

 | getID() | エンティティのIDまたはエンティティのIDのリストを返します。

 | getType() | CursorStr内のエンティティのタイプを Int notation of DItem Types（int）として返します。

 | getCursorData() | エンティティのDItemデータまたはエンティティのDItemデータのリストを返します。
