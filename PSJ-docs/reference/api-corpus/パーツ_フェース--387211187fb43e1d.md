# パーツ フェース

パーツ フェース パーツ フェース パーツまたは複数のフェースから、隣接面との角度またはフェース幅を参照し、自動的に隣接するフェースをマージします。 オプション 角度 チェックすると、隣接面との角度による自動マージを有効にします。 トレランス角度 入力した角度以下の隣接面をマージします。 幅 チェックをすると、フェースの幅による自動マージを有効にします。 ＜以下の計算式によってマージ対象フェースの判定しています。＞ ratio = (area × 16) / (totLen × totLen) ※ area = フェースの面積, totLen = total edge length of face(フェースを構成する4辺の長さ) thick = ratio × totLen / 8.0 対象のフェース 幅のトレランス 入力した幅以下の隣接面をマージします。 -&nbsp操作手順&nbsp- マージするパーツを選択します。 マージする対象から除外したいフェースがある場合はそのフェースを選択します。 必要に応じて、角度チェックボックスをチェックして、トレランスを入力します。 必要に応じて、幅チェックボックスをチェックして、トレランスを入力します。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
