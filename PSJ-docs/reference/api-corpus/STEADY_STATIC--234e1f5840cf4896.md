# STEADY_STATIC

STEADY_STATIC

説明​

静的静水圧のパラメータを制御するために使用されるデータ型です

属性​

bSteadyStaticMemorySave​

静的静水圧メモリ保存を有効/無効にする Boolean です。

デフォルト値は False です。

bSteadyStaticOutputHeatFlux​

静的静水圧出力熱フラックスを有効/無効にする Boolean です。

デフォルト値は False です。

bSteadyStaticOutputTemperature​

静的静水圧出力温度を有効/無効にする Boolean です。

デフォルト値は False です。

bPivotsCheck​

ピボットのチェックを有効/無効にする Boolean です。

デフォルト値は True です。

bSteadyStaticSinglePrecision​

静的静水圧単精度を有効/無効にする Boolean です。

デフォルト値は False です。

dSteadyStaticMultiplier​

静的静水圧乗数を指定する Double です。

デフォルト値は0.0です。

dSteadyStaticTemperatureDifference​

静的静水圧温度差を指定する Double です。

デフォルト値は0.0です。

dSteadyStaticToleranceLevel​

静的静水圧許容レベルを指定する Double です。

デフォルト値は0.0です。

iAdaptiveDescent​

適応的降下を指定する Integer です。

デフォルト値は0です。

iSteadyStaticEquationSolver​

静的静水圧方程式ソルバを指定する Integer です。

デフォルト値は0です。
