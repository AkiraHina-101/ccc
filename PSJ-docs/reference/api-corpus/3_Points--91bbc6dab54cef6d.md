# 3 Points

3 Points 3 Points Divide the selected parts by a cutting plane defined by three points. Selection Plane Offset Enter the offset value. They are separated by a distance that is offset from the split plane specified by three points. Partition Only When it is checked, a partition is created inside. In this case, the parts are not split. Make Section Face If you check this box, in the case of dividing the parts, a face is created at the section. Share Face When this box is checked while dividing the parts, a shared surface is created at the division plane.
