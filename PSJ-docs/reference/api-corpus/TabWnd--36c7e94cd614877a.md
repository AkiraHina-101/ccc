# TabWnd

TabWnd

Create a tab container to store TabItem.

Preview dialog:

Parameters​

Name​

Enter name of the tab container.

Enable​

Specify whether to enable it or not.

Check On : Available

Check Off : Unavailable (grayed out)

Size​

Width : Specify the minimum width of the tab container. (in pixels)

Height : Specify the minimum height of the tab container. (in pixels)

Behavior​

Specify the the behavior state of tab window to flexibly control size itself.

Greedy : set the displaying tab window based on the user input width and height, allow resizing tab window size according to dialog size

Fixed : set the displaying tab window based on the user input width and height, and won't resize tab window size according to dialog size

Horizontal : set the displaying tab window with fixing height based on user input and allow resizing tab window only horizontally

Vertical : set the displaying tab window with fixing width based on user input and allow resizing tab window only vertically

Visible​

Specify whether to show/hide the created TabWnd.

Check On : Show

Check Off : Hide

API associated with​

dlg.add_tabwnd : Add a TabWnd (tab window) to the creating dialog.

dlg.get_tabwnd_current_page : Get the selecting page of the inputted TabWnd.

dlg.set_tabwnd_current_page : Set the current page of the TabWnd to a specific TabItem order.

dlg.on_active_tab_page : Bind a created function after a TabItem is selected.
