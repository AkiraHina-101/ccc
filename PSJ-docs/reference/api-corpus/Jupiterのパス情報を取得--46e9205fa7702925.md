# Jupiterのパス情報を取得

Jupiterのパス情報を取得

🎯 はじめに​

本チュートリアルでは、関連するJupiterのパス情報を取得する方法について紹介します。

Jupiter内部パスを取得する: Jupiterに関連する内部パス情報(Jupiterインストールフォルダパス、材料ライブラリパス、テンポラリーフォルダパスなど)を取得する。 

読み込まれたモジュールまたはPythonファイルのパスを取得する: Jupiterが使用する読み込み済モジュールやファイルのパス情報を取得する。

Python APIウィンドウにすべてのパスのタイプを一覧表示する。

Jupiterに関連するパスを取得する: インストールフォルダパス、現在開いている.jtdbファイルパス、材料ライブラリパス、IDEデータベースパス など

🧮 ユーザビリティ​

読み込んだPythonファイルのフルパスを取得するにはJPT.PATHTYPE.FILE_PATHを使用することで可能になります。

🪁 利用環境​

IDEでは、Open (File » Open)オプションを使用してPythonファイルを読み込みます。

ファイルランチャーでは、登録ボタン S でPythonファイルを読み込むことが可能です。詳しくはファイルランチャーをご覧ください。

カスタマイズ機能では、PythonファイルをPSJ-Commandのカスタムフォルダに置くことでJupiter内にリボンとして追加し、パスを返します。

📖 チュートリアル​

Jupiterの内部パスを取得

読み込まれたモジュールやPythonファイルパスを取得

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

#Python APIウィンドウにJupiterのすべてのパス情報を一覧表示します。
JPT.PrintAppPathInfo()

# Python APIウィンドウにすべてのパスのタイプを一覧表示します。
JPT.Debugger(JPT.PathType.values)

# Jupiterのインストールフォルダのパスを取得します。
programPath = JPT.GetAppPathInfo(JPT.PathType.PROGRAM_PATH)
print(programPath)

# Jupiterのテンポラリフォルダのパスを取得します。
tempPath = JPT.GetAppPathInfo(JPT.PathType.TEMP_PATH)
print(tempPath)

# JupiterのAppデータフォルダのパスを取得します。
appdataPath = JPT.GetAppPathInfo(JPT.PathType.APPDATA_PATH)
print(appdataPath)

# 現在開いているドキュメントファイルのパスを取得します。
docPath = JPT.GetAppPathInfo(JPT.PathType.DOC_PATH)
print(docPath)

# デフォルト設定されている材料ライブラリーのパスを取得します。
materialLibPath = JPT.GetAppPathInfo(JPT.PathType.MATERIAL_LIB_FILE_PATH)
print(materialLibPath)

# ユーザーが定義した材料ライブラリーのパスを取得します。
materialUserPath = JPT.GetAppPathInfo(JPT.PathType.MATERIAL_USER_FILE_PATH)
print(materialUserPath)

# Jupiterのデータベースのパスを取得します。
databasePath = JPT.GetAppPathInfo(JPT.PathType.DATABASE_PATH)
print(databasePath)

# Sunshineのパスを取得します。
sunshinePath = JPT.GetAppPathInfo(JPT.PathType.SUNSHINE_PATH)
print(sunshinePath)

# IDEのデータベースのパスを取得します。
ideDataPath = JPT.GetAppPathInfo(JPT.PathType.IDE_DATA_PATH)
print(ideDataPath)

# PSJによるカスタムリボン用フォルダのパスを取得します。
psjRibbonPath = JPT.GetAppPathInfo(JPT.PathType.PSJ_COMMAND_PATH)
print(psjRibbonPath)

"""
サンプルスクリプトをPythonファイルで保存し、読み込んでおいてください。
"""

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# 読み込んでいるPythonファイルのパスを取得します。
filePath = JPT.GetAppPathInfo(JPT.PathType.FILE_PATH)
print(filePath)
