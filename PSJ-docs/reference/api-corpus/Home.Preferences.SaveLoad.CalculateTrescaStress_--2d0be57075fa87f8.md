# Home.Preferences.SaveLoad.CalculateTrescaStress()

Home.Preferences.SaveLoad.CalculateTrescaStress()

説明​

トレスカ応力を計算し結果ツリーに追加します。

構文​

Home.Preferences.SaveLoad.CalculateTrescaStress(...)

マクロ:

リボン: Home » Preferences » SaveLoad » CalculateTrescaStress

入力​

bUseTrescaStress​

_True_であるかどうかを指定する _Boolean_型

デフォルト値は _True_です。

戻り値​

指定する _Boolean_型

サンプルコード​

Home.Preferences.SaveLoad.CalculateTrescaStress(bUseTrescaStress = False)
