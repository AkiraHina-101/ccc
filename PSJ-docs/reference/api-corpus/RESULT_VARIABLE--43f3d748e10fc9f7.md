# RESULT_VARIABLE

RESULT_VARIABLE

説明​

選択した結果を識別するために使用されるデータ型です。

属性​

crReferencePostJob​

参照ポストジョブを指定する Cursor です。

デフォルト値はありません。

strName​

変数名を指定する String です。

デフォルト値は "" です。

iAnalysisType​

解析タイプを指定する Integer です。

デフォルト値は 0 です。

iResultSet​

結果ステップを指定する Integer です。

デフォルト値は 0 です。

iTimeStep​

タイムステップを指定する Integer です。

デフォルト値は 0 です。

iResultType​

結果タイプを指定する Integer です。

デフォルト値は 0 です。

iResultPos​

結果位置を指定する Integer です。

デフォルト値は 0 です。
