# ウォッチウィンドウ

ウォッチウィンドウ ウォッチウィンドウ 現在の選択エンティティの詳細を表示します。 ・選択タブ 選択エンティティの一覧を表示します。 ・ロックリストタブ 一時保存（ロック）した選択エンティティを表示します。 ツールバー アイコン 名称 説明 保存 選択エンティティのID/エンティティ/パーツ/X/Y/Zをcsv形式で出力します。 全アイテム削除 選択エンティティを全て選択解除します。 選択アイテム削除 ハイライトしたエンティティを選択解除します。 すべてチェック IDを表示している場合、全ての選択エンティティをID表示状態にします。 すべてのチェックを外す IDを表示している場合、全ての選択エンティティを非ID表示状態にします。 すべてロック アイコンをクリックすると、現在選択タブ内にある選択エンティティ全てをロックリストに保持します。 ロックリストに保存 アイコンをクリックすると、ハイライトしたエンティティをロックリストに保持します。 ロックリストを読み出し アイコンをクリックすると、ロックリストに保持したエンティティを選択タブに戻し、選択状態にします。 ロックリストをクリア アイコンをクリックすると、ロックリストのデータを消去します。 -&nbsp操作方法&nbsp- メインウィンドウでエンティティピックするなどで選択すると、選択リストにエンティティが表示されます。 選択リスト上でエンティティの欄をクリックすると、クリックしたエンティティがメインウィンドウ上でハイライトされます。また、アウトプットウィンドウに詳細情報が表示されます。
