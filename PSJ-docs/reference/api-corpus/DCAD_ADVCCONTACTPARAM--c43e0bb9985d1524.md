# DCAD_ADVCCONTACTPARAM

DCAD_ADVCCONTACTPARAM

説明​

ADVC接触パラメータを制御するために使用されるデータタイプです。

属性​

iInitialState​

初期状態を指定する Integer。

デフォルト値は-1です。

iBehavior​

動作を指定する Integer。

デフォルト値は-1です。

dClearance​

クリアランスを指定する Integer。

デフォルト値は0.1234です。

iAdjust2Clearance​

クリアランスへの調整を指定する Integer。

デフォルト値は-1です。

iAdjust2Interference​

干渉への調整を指定する Integer。

デフォルト値は-1です。

iAutoShrink​

自動収縮を指定する Integer。

デフォルト値は-1です。

iAdvAdjust​

調整を指定する Integer。

デフォルト値は-1です。

iEstimationImpactTime​

推定衝撃時間を指定する Integer。

デフォルト値は-1です。

iFormula​

式を指定する Integer。

デフォルト値は-1です。

iConstraintType​

拘束タイプを指定する Integer。

デフォルト値は-1です。
