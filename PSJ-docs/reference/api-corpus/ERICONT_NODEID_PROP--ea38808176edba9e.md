# ERICONT_NODEID_PROP

ERICONT_NODEID_PROP

Description​

A data type uses to control parameters of Ericont Nodeid Prop

Attributes​

iConnId​

An Integer specifying connection ID.

The default value is 0.

iEndA​

An Integer specifying end a.

The default value is 0.

iEndB​

An Integer specifying end b.

The default value is 0.
