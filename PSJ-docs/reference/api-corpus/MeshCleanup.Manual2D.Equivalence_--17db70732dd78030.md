# MeshCleanup.Manual2D.Equivalence()

MeshCleanup.Manual2D.Equivalence()

Description​

Equivalence Nodes

Syntax​

MeshCleanup.Manual2D.Equivalence(crlNodes, iTypeEquiva=0, dTolerance=1.0)

Ribbon: MeshCleanup » Manual2D » Equivalence

Inputs​

crlNodes​

A List of Cursor specifying the node.

This is a required input.

iTypeEquiva​

An Integer specifying the type equiva.

The default value is 0.

dTolerance​

A Double specifying the tolerance.

The default value is 1.0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshCleanup.Manual2D.Equivalence(crlNodes, iTypeEquiva=0, dTolerance=1.0)
