# ShowContactDialog()

ShowContactDialog()

説明​

連絡先ダイアログを表示します。

構文​

ShowContactDialog(int iResultSet, int iTimeStep, string strResultTypeName, string strResultCompName, int iResultPosition)

入力​

1. int ​

結果セット。

2. int ​

タイムステップ。

3. string ​

結果タイプの名前。

4. string ​

コンポーネントの名前。

5. int ​

データ位置。

戻り値​

なし。

サンプルコード​

ShowContactDialog(1, 0, 0, ContactForceShear, Translational, 1)
