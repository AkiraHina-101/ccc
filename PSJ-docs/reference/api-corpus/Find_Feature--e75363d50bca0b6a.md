# Find Feature

Find Feature Find Feature From the specified parts select a face or edge of a particular shape. Options Face Select the type of the following face: 4 Sided Select the face of the four corners. Planar Select the planar face. Full Cylinder Select the face of the cylindrical surface. Half Cylinder Select the face of the semi-cylindrical surface. Disc Select the disk-shaped face. Map Mesh Select the face of map mesh. Cylinder When you check, it selects the face of the cylindrical surface. Disc When you check, it selects a disk-shaped face. Four Corners When you check, it selects the face with four corners. Circular Chamfer Select to Delete the chamfer surface. Min Thickness Specify the minimum thickness of the circular chamfer surface. Max Thickness Specify the minimum thickness of the circular chamfer surface. Remove Delete the selected chamfer part and make it a pin corner. Fillet Select the fillet surface. Min Face Width Specify the minimum face width to search. Max Face Width Specify the maximum face width to search. Min Curve Radius Specify the minimum radius of the fillet to search. Max Curve Radius Specify the maximum radius of the fillet to search. Min Angle Specify the minimum value of the angle of the fillet to search. Max Angle Specify the maximum value of the angle of the fillet to search. Convex Search for convex fillets. Concave Search for concave fillets. Edge Select the type of edge of following: Line Select the straight edge line. Loop Select the edge of loop shape. Full Circle Select the edge of circle. Half Circle Select the edge of semicircle. Bolt Hole Select the bolt hole edge between the specified minimum and maximum diameter values. The bolt holes correspond to not only parts but also edge selection by face selection. The number of divided bolt hole edges that can be searched is 0, 1/2 and 1/4. Min Diameter Minimum diameter of bolt hole. Max Diameter Maximum diameter of bolt hole.
