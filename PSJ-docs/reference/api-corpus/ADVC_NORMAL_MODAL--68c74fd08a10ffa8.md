# ADVC_NORMAL_MODAL

ADVC_NORMAL_MODAL

説明​

ADVCノーマルモーダルのパラメータを制御するために使用されるデータ型です

属性​

iNumberModes​

モードの数を指定する Integer です。

デフォルト値は2です。

iEigenNormalizationMethod​

固有正規化メソッドを指定する Integer です。

デフォルト値は-1です。

dShift​

シフトを指定する Double です。

デフォルト値はDFLT_DBLです。

dCGCGPITolerance​

c g c g p i 許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

dCGCGPIEigenTolerance​

c g c g p i 固有許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

iCGCGPILoopMax​

c g c g p i ループ最大数を指定する Integer です。

デフォルト値はDFLT_INTです。

dCGCGPIInnerTolerance​

c g c g p i 内部許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

iCGCGPIBlockSize​

c g c g p i ブロックサイズを指定する Integer です。

デフォルト値はDFLT_INTです。
