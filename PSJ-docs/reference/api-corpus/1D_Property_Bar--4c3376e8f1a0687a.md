# 1D Property Bar

1D Property Bar 1D Property Bar 1D Property Bar Dialog Box Create a property data of one-dimensional Bar element. Name Set the name of the property. Property ID Enter the ID of the property. Section Type Specify the characteristics input type. General ： Enter the general cross-section properties. Library ： Use the cross-sectional shape library of Nastran. BAR Input Shape By entering the cross section dimensions for the main profile, calculate section properties. If you select the Library, its dimensions will be output as PBARL. Material Specify the material properties. Section Choose from existing elements characteristic list. Vector Enter the direction vector to determine the element coordinate system. Orientation by Vector ：Element coordinate system defined by the direction vector Node ：Element coordinate system by the specified node definition (for Nastran) Area Enter the value of the cross-sectional area. Section Detail Inertia I1/Izz Enter the moment of inertia around the Z axis. Inertia I2/Iyy Enter the moment of inertia around the Y axis. Torsional Constant Enter the torsional constant. Non-structural Mass Enter the non-structural mass per unit length. Cy/Cz/Dy/Dz/Ey/Ez/Fy/Fz Enter the stress calculation position in C, D, E, and F points. Shear Area Factor Y Y direction shear area coefficient. Shear Area Factor Z Z direction shear area coefficient. Inertia I12/Izy Enter the moment of inertia around the ZY. Property ID Enter the ID of the property. --> Pin Flag-Point A UX/UY/UZ/RX/RY/RZ Coupling settings with other bar body of point A. ※A point, B point is set in ascending order of ID. Pin Flag-Point B UX/UY/UZ/RX/RY/RZ Coupling setting with other bar body of point B. ※AA point, B point is set in ascending order of ID. Offset Vectors Point A Enter the amount of offset of the A point, separated by commas. Point B Enter the amount of offset of the B point, separated by commas. Input Unit Length Select the unit of length. Mass Select the unit of mass. Cross Section Dialog Box To calculate the cross-section property values. Created value is registered in the Section pull-down menu. General Enter the general cross-section properties. Name Enter the name of the cross-section properties to be registered. Type Selected calculation type is displayed. Shape Select the general cross section to be applied. Dimensions variable name will be displayed to the right of the image and the size table, according to the selected shape. Tapered The cross-sectional size of left and right side of the selected beam will be different. It will be the two input to be specified in the size variable. Size Table Enter a value in the dimensions variable to be displayed. Elem Y-dimension Dir Select the Y-axis direction of the cross section. Local Unit Select the local coordinate system of the cross-section calculation. Library Use the cross-sectional shape library of Nastran. Name Enter the name of the cross-section properties to be registered. Type Selected calculation type is displayed. Shape Select the type of cross section library in Nastran. Dimensions variable name of Nastran will be displayed to the right of the image and the size table, according to the selected shape. Tapered The cross-sectional size of left and right side of the selected beam will be different. It will be the two input to be specified in the size variable. Size Table Enter a value in the dimensions variable to be displayed. Elem Y-dimension Dir Can not be selected.
