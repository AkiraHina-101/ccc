# DeleteFace()

DeleteFace()

Description​

Delete Face

Syntax​

DeleteFace(int[] taFaceID, bool bKeepSolid)

Inputs​

1. Int[]​

Face ID([*]*=Face ID)

2. Bool​

Keep Solid flag true=1, false=0

Return Code​

"1": The function can be executed

"0": The function cannot be executed

Sample Code​

DeleteFace([21], 1)
