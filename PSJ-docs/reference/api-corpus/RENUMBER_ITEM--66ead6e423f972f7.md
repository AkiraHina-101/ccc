# RENUMBER_ITEM

RENUMBER_ITEM

Description​

A data type uses to control parameters of Renumber Item

Attributes​

crTar​

A Cursor specifying tar.

The default value is None.

iTBegin​

An Integer specifying t begin.

The default value is 0.

iTEnd​

An Integer specifying t end.

The default value is 0.

iNodeOrElem​

An Integer specifying node or elem.

The default value is 0.

iCount​

An Integer specifying count.

The default value is 0.

iIncrement​

An Integer specifying increment.

The default value is 0.

iOrder​

An Integer specifying order.

The default value is 0.

iMethod​

An Integer specifying method.

The default value is 0.

crRefCoord​

A Cursor specifying ref coord.

The default value is None.

vecCoordOrder​

A Vector specifying coord order.

The default value is 0.

vecOffset​

A Vector specifying offset.

The default value is 0.

vecCoordTol​

A Vector specifying coord tolerance.

The default value is 0.

iConflictStrategy​

An Integer specifying conflict strategy.

The default value is 0.

iSolver​

An Integer specifying solver.

The default value is 0.

iMin​

An Integer specifying minimum.

The default value is 0.

iMax​

An Integer specifying maximum.

The default value is 0.
