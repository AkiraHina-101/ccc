# MidPlane.AdjustThickness()

MidPlane.AdjustThickness()

Description​

Adjust thickness of midplane

Syntax​

MidPlane.AdjustThickness(crlParts=[], dRatio=1.0, bAdjustFaceThick=False, bAdjustPropThick=False)

Ribbon: MidPlane » AdjustThickness

Inputs​

crlParts​

A List of Cursor specifying the part.

The default value is [].

dRatio​

A Double specifying the ratio.

The default value is 1.0.

bAdjustFaceThick​

A Boolean specifying the adjust face thickness.

The default value is False.

bAdjustPropThick​

A Boolean specifying the adjust property thickness.

The default value is False.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MidPlane.AdjustThickness(crlParts=[], dRatio=1.0, bAdjustFaceThick=False, bAdjustPropThick=False)
