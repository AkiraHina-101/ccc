# Bolt Type D

Bolt Type D Bolt Type D This is the dialog that opens from the Auto Bolt Connection function to set the FEM conditions for bolt type A. Auto Bolt Connection Help For bolt type D, RBE2/MPC elements are created around the bolt holes on the mating surface and join together. Mating Face Settings Connection Specify the type of rigid body (RBE2/MPC) that is to be created around the bolt holes on the mating surface. Connection Diameter(Node) Specify the diameter range that the rigid body is created at the nodes within. Connection Layer(Face) Specify the number of layers of faces around the bolt hole that the rigid body is created. -&nbspOperating Procedure&nbsp- Select a rigid body type and enter the parameters. Click the OK button. This dialog closes and highlights the button of the corresponding bolt type in the Auto Bolt Connection dialog.
