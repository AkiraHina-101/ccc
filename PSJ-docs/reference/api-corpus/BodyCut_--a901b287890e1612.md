# BodyCut()

BodyCut()

説明​

構文​

BodyCut(int method,double offset,int shareFace,int separateFace,int splitOnly,
    int makeSectionFace,Cursor coord,Cursor[] targets, Cursor[] cutter)

入力​

1. Int​

節点切断に使用する方法、0：YZ平面、1：XZ平面、2：XY平面、3：3点による、4：曲面による

2. Double​

切断面からのオフセット値

3. Int​

共有面かどうか、0：いいえ、1：はい

4. Int​

別々のフェースかどうか、0：いいえ、1：はい

5. Int​

分割のみかどうか、0：いいえ、1：はい

6. Int​

セクションフェースを作成するかどうか、0：いいえ、1：はい

7. Cursor​

面の切断に使用される座標系

8. Cursor[]​

切断される対象

9. Cursor[]​

3点および曲面オプションで使用可能な刃物エンティティ

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません
