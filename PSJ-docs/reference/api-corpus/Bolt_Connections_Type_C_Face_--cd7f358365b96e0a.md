# Bolt Connections Type C (Face)

Bolt Connections Type C (Face) Bolt Connections Type C (Face) Place the RBE2 or RBE3 element on the side surfaces of the bolt hole and then join the centre with the spring element or RBE2 elements. Bolt Modeling RBE Name Enter the name of the RBE item you want to create. Show Bolt Image Display a summary view of the bolt. It is possible to change the bolt type you want to create. Plane Tolerance Specify the tolerance value for the RBEs when the target face is not flat. Max Height Set the maximum length of the shaft portion for connecting between RBE. Max Diameter Configure the maximum diameter for bolt hole to be extracted. (For Face creation method) Min Diameter Set the minimum diameter for bolt hole to be extracted. (For Face creation method) Type &nbsp;&nbsp;&nbsp;Select the connection method between Rbe. Spring &nbsp;:&nbsp;Connect a spring element between Rbe. Rbe2 &nbsp;:&nbsp;Connect RBE2 between Rbe X / Y / Z Stiffness Enter the spring stiffness for translation in three directions. (Spring only) Input Unit Specify the input unit system. (Spring only) RX / RY / RZ Stiffness Enter spring stiffness for the three rotational direction. (Spring only) Input Unit Specify the input unit system. (Spring only) Coordinate Select the coordinate system to refer to the direction of the spring stiffness. (Spring only) Top Rbe Type &nbsp;&nbsp;&nbsp;Select the type of Rbe to be created on the side surfaces of the bolt hole. RBE3 &nbsp;:&nbsp;Create a Rbe3. RBE2 &nbsp;:&nbsp;Create a Rbe2. Face If you turn on the button for face and select the top side of the face, it displays the ID of the selected face. Pitch Specify the Rbe creating distance in the bolt hole direction. Remove Depth Enter the distance of the bolt hole direction. Rbe element is not created within the distance input here. Bottom Rbe Type &nbsp;&nbsp;&nbsp;Select the type of Rbe to be created on the side surfaces of the bolt hole. RBE3 &nbsp;:&nbsp;Create a Rbe3. RBE2 &nbsp;:&nbsp;Create a Rbe2. Face If you turn on the button for face and select the top side of the face, it displays the ID of the selected face. Pitch Specify the Rbe creating distance in the bolt hole direction. Remove Depth Enter the distance of the bolt hole direction. Rbe element is not created within the distance input here. Preview The preview displays the extraction results. (When creating method is the face) Reset Cancel the preview display.
