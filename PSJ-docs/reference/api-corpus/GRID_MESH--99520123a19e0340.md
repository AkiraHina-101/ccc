# GRID_MESH

GRID_MESH

説明​

グリッドメッシュのパラメータをコントロールするために使用されるデータ型です。

属性​

crlFace​

フェースを指定する Cursor のリストです。

デフォルト値は [] です。

crlCorner​

コーナーを指定する Cursor のリストです。

デフォルト値は [] です。

ilMeshCount​

メッシュカウントを指定する Integer のリストです。

デフォルト値は [] です。

iShape​

形状を指定する Integer です。

デフォルト値は -1 です。

iElemtype​

要素のタイプを指定する Integer です。

デフォルト値は 3 です。

bSwap​

スワップを有効化または無効化する Boolean です。

デフォルト値は False です。

bLocalSetting​

ローカル設定を有効化または無効化する Boolean です。

デフォルト値は False です。

bOptimize​

最適化を有効化または無効化する Boolean です。

デフォルト値は False です。
