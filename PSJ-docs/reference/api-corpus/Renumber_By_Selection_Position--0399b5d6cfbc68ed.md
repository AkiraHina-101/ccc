# Renumber | By Selection | Position

Renumber | By Selection | Position Renumber | By Selection | Position Renumber the ID of the selected entity according to the coordinate values. Entity Type Nodes Renumber nodes in the selected entity. １D Elements Renumber 1D elements in the selected entity. 2D Elements Renumber 2D elements in the selected entity. 3D Elements Renumber 3D elements in the selected entity. Parts Renumber selected parts. Coordinate Systems Renumber the selected coordinate systems. Start ID Set the renumber start ID. Increment Step Set the renumber increment value. Sort Order Ascending Renumber in ascending order. Descending Renumber in descending order. Position Coordinate Select a coordinate system. Options: Global Coordinate System / Arbitrary Local Coordinate System / Cylindrical Surface LCS setting (only when cylindrical surface is selected in the coordinate system) Create a temporary coordinate system from selected nodes and cylindrical surfaces. Save created LCS (only when selecting cylindrical surface in coordinate system) If checked, the temporary coordinate system will be left in the document after renumbering. Sort Table Sort Priority Grouping of target entities。 Sort Specify whether to enable or disable sorting in each axis direction. Uncheck to disable. Also, sort priority 1st and 3rd can not be enabled simultaneously. Axis Specify the sorting target axis. Sort Order ・&nbsp;Sort order: Specify ascending / descending order. Offset ID Specify the offset ID between grouped entities. Tolerance This is the threshold (distance) for grouping . Preview By clicking the preview button, the IDs before and after the target number of the renumbered entity are displayed. Apply Perform renumbering. Cancel Close the dialog without executing renumbering. -&nbsp;Operation Procedure&nbsp;(Global Coordinate System / Local Coordinate System)&nbsp;- &nbsp;Specify the entity that you want to renumber from the choice of entity type. &nbsp;Specify start ID and increment value. &nbsp;From the coordinate system, select a global coordinate system or a created local coordinate system. &nbsp;Specify each item of sort setting table. &nbsp;Select an entity in the main window. &nbsp;Click the preview button to check the IDs before and after the renumber. &nbsp;Press the Apply button to execute the renumbering. -&nbsp;Operation Procedure (Cylindrical Surface)&nbsp;- &nbsp;Specify the entity that you want to renumber from the choice of entity type. &nbsp;Specify start ID, increment value, and sort order. &nbsp;Select a cylindrical surface from the coordinate system. &nbsp;Select 3 nodes in order. First point: start position, second point: Z direction, third point: circumferential direction (+). &nbsp;Select the cylindrical surface and click the LCS setup button. A preview of the coordinate system is displayed. &nbsp;Select an entity in the main window. &nbsp;Click the preview button to check the IDs before and after the renumber. &nbsp;Press the Apply button to execute the renumbering. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
