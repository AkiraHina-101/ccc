# Add BOSS | By Attach

Add BOSS | By Attach Add BOSS | By Attach This command is used to create a BOSS geometry (cylinder shape) and attach it to selected part. Option Merge When checked ON, new BOSS part will be merged with the selected part. Base Center Specify the position of the bottom face of the BOSS (on which the selected part is connected). Set By Selected entity type to set base center: Node or Face Point. X X coordinate of base center. Y Y coordinate of base center. Z Z coordinate of base center. Direction X X coordinate of BOSS directional vector. Y Y coordinate of BOSS directional vector. Z Z coordinate of BOSS directional vector. Coordinate System Specify Coordinate system for the BOSS directional vector. Rotation Axis Specify the rotation axis on the coordinate system (X axis, Y axis, Z axis). Angle Specify the rotation angle of the rotation axis. BOSS Shape Hollow Select this checkbox to create the BOSS as a hollow geometry. Inner Radius Enter the inner radius of the cylinder geometry (in case of a hollow geometry). Outer Radius Enter the outer radius of the cylinder geometry. Taper Angle (degree) Enter the taper angle from the top to bottom direction of the cylinder geometry. No of Nodes in Circle Enter the number of nodes in in the arc direction of the cylinder. No of Nodes in Axis Enter the number of nodes in in the axis direction of the cylinder. Height Enter the height of the cylinder geometry. -&nbspOperating Procedure&nbsp- &nbspSelect Face Point or Node from Set By and click the face point or node on the position where you want to create the BOSS. The clicked position will be automatically entered as the Base Center (center point of the BOSS creation position) and the normal of the clicked position will be automatically entered as the Direction (of the BOSS). &nbspEnter the Outer Radius and Height of the BOSS. The preview geometry will be displayed. &nbspClick the Apply button to generate the geometry. -&nbspOperation Video&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
