# POST_DATA_VIZ_OPT_TRANSPARENCY

POST_DATA_VIZ_OPT_TRANSPARENCY

説明​

データ型は不透明度を表示するための結果設定を行うために使用されます。

属性​

iTransparencyOpt​

不透明度オプションを指定する Integer 。

デフォルト値は0です。

dTransparency​

不透明度値を指定する Double 。

デフォルト値は0.0です。

dOpaqueRangeMin​

不透明範囲の最小値を指定する Double 。

デフォルト値は0.0です。

dOpaqueRangeMax​

不透明範囲の最大値を指定する Double 。

デフォルト値は0.0です。
