# Create Element Tet / Hex / Penta / Pyramid

Create Element Tet / Hex / Penta / Pyramid Create Element Tet / Hex / Penta / Pyramid Create a solid element from the selected elements or nodes. Selection List Element：2D elements that connect solid elements. Node：Nodes to connect solid elements. Part：The part to which the created solid element belongs (if not selected, the solid element will be created as a new part). Parameter Target Select the solid element type to be created. Tet &nbsp;:&nbsp;Creates a tetra element (tetrahedron). Hex &nbsp;:&nbsp;Create a hexa element (hexahedron). Penta &nbsp;:&nbsp;Create a penta element (triangular prism). Pyramid &nbsp;:&nbsp;Create a pyramid element (square weight). Use OrderNode When the checkbox is turned on, the number of the next selection order will be displayed in the main window after the three nodes are selected. Direction Switch the direction of the element to be created. Height Enter the height of the element to be created. Keep Part Selection Retain the selected state of the selected parts even after the Apply button is executed. -&nbspOperating Procedure (Use OrderNode option)&nbsp- Turn on the Use OrderNode option and create a solid element (in this case, a hexa element as an example) by selecting the nodes. Select three nodes to create the element.
