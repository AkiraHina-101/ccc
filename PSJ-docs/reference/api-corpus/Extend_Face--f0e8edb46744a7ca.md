Direction Parameters Metric Choose the method you want to create the face. ・Coordinate system： The direction of extension is specified as a parameter. ・2 Nodes： Select two nodes and determine the direction. ・Element Edge： Select an element edge to determine the direction of extension. ・Offset： Extend in the direction of the selected face. ・Cylinder： Cylindrical face extension Coordinate System Coordinates to be referenced Direction(Metric: only for Coordinate) ・X, Y, Z: These parameters determine the orientation. Enter a value for the direction in which the face will be extended, in the direction of the vector created by the values entered for X, Y and Z. Both Directions Creates an extended face in both directions. Reverse Direction Create a face in the opposite direction. -----Metric: Cylinder only----- Method Select the method you want to create the extended face of the cylindrical surface. ・To Axis： The direction of extension is specified as a parameter. ・To Face： Extends the face to the selected face. ・Arc Angle： Specifies the arc angle of the face to be extended. ・Arc Length：Specifies the arc length of the face to be extended. ・Sweep：Creates an extended face along a cylindrical shape. Mesh Parameters Destination Length： Specifies the length of the extension face. To Face： An extension face is created up to the selected face.
