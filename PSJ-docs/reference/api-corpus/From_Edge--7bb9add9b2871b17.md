# From Edge

From Edge From Edge Add a rib shape to an existing surface mesh by specifying a mounting surface and an edge to define the path of the rib. Rib parameters Rib Thickness Set the width of the ribs. Rib Height Set the height of the ribs above the rib mounting surface. Direction Set the height of the ribs above the rib mounting surface. ・Normal Offset： The ribs are created perpendicular to the rib mounting surface. ・Offset： The ribs are created perpendicular to the plane specified in the base plane. ・Projection： The ribs are created perpendicular to the plane specified in the base plane and the top of the ribs are aligned to the specified position. Coordinate Specify the coordinate system to be referenced when creating ribs. Base plane Specify the direction in which the ribs will be pulled out if the direction is specified as offset or projection. ・XY plane： The ribs are created directly on the XY plane (direction of extraction is Z). ・YZ plane： The ribs are created directly on the YZ plane (direction of extraction is X). ・ZX plane： The ribs are created directly on the ZX plane (direction of extraction is Y). Offset Offset the ribbed position in the specified direction. The direction is set in the coordinate system. X Movement in X direction Y Movement in Y direction Z Movement in Z direction Option Set other creation options and preview settings. Triangle Make the ribs into triangular ribs. Off: Do not create triangular ribs, but create normal ribs. Forward: Creates a high triangular rib on the side of the starting point. Backwards: Creates a high triangular rib on the side of the end point. Create New Part Create the rib as a new part. Merge Merge ribs and mounting parts. Preview Turn on/off the display of the preview. -&nbspOperating Procedure&nbsp- Specify the mounting surface and the edge that will be the path of the ribs. Enter the respective parameters.
