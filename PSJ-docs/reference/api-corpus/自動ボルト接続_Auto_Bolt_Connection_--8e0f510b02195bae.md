# 自動ボルト接続(Auto Bolt Connection)

自動ボルト接続(Auto Bolt Connection) 自動ボルト接続(Auto Bolt Connection) 選択したパーツペアからボルト穴を検索し、ボルトタイプのコンディションを設定をしたら、剛体ボルトを自動作成できます。剛体ボルトは４つのタイプから選択します。 剛体ボルトは複数のFEM条件で構成されますが、作成されたボルト1本ごとに、それらのグループを作成します。ボルトグループはBolt Connectionサブグループの下に置かれます。 選択リスト(Selection list) 上部パーツ(Upper Part)：ボルト座面側パーツ 下部パーツ(Lower Part)：ボルトねじ部側パーツ ボルトモデリング(Bolt Modeling) ボルト名(Bolt Name) 剛体ボルトの名前を入力します。 ボルト穴サイズ(Bolt Hole Size) このメニューで選んだボルト穴サイズが、下の最小直径、及び最大直径に自動で入力されます。 ボルト穴サイズと最小最大は「*インストールフォルダ*\bin\common\template\LBC\BoltModeling\BoltSizeInfomation.DAT」を参照しています。 最小円直径(Min Circle Diameter) 検索するボルト穴の最小直径を入力します。 最大円直径(Max Circle Diameter) 検索するボルト穴の最大直径を入力します。 ボルト設定リスト(Bolt Setting List) 合わせ面(Mating Face) 間隙トレランス(Gap Tolerance) 上部パーツと下部パーツ間の隙間トレランスを入力します。この隙間以下の合わせ面のボルト穴が検索されます。 角度トレランス(Angle Tolerance) 上部パーツと下部パーツ間の合わせ面角度トレランス（度）を入力します。合わせ面の平面判定のためのパラメータで、通常は変更する必要ございません。 プレビューペアをフィット(Fit the Previewed pair) リストの検索されたボルトペアをクリックした際に、メインウィンドウの視点がそのボルトペアにフィットします。 検索(Find) ボルトペアの検索を実行します。 すべてをチェック(Check All On/Off) リストのチェックボックスの状態を全てオンまたはオフに切り替えます。 チェックボックス チェックが入っているボルトペアに剛体でのボルトモデリング設定をします。 チェックボックス上で右クリックすることで、チェックボックス状態を反転することができます。 マスターフェース(Master Face) 上部パーツのボルト穴のフェースIDを表示します。 スレーブフェース(Slave Face) 下部パーツのボルト穴のフェースIDを表示します。 修正(Modification) リスト内の編集(Edit)ボタンをクリックすると、手動フェース選択により、マスターフェース/スレーブフェースのメンバーを編集（追加と削除）できます。 編集後は、リスト内の適用(Apply)ボタンをクリックしてください。 ボルトタイプ(Bolt Type) 作成する剛体ボルトのタイプです。ボルトタイプ(Bolt Type)のFEM条件を設定すると表示が切り替ります。ボルト穴毎に異なるボルトタイプを設定することはできません。 リスト上での右クリックメニュー コピー(Copy) &nbsp;:&nbsp;ボルトタイプ上でのみ表示されます。ボルトタイプをコピーします。 貼り付け(Paste) &nbsp;:&nbsp;ボルトタイプ上でのみ表示されます。コピーしたボルトタイプを貼り付けます。 挿入(Insert) &nbsp;:&nbsp;リスト内に空の行を追加します。 削除(Delete) &nbsp;:&nbsp;選択した行を削除します。 すべてクリア―(Clear All) &nbsp;:&nbsp;リスト内を空にします。 ボルトタイプ(Bolt Type) 各ボルトタイプのFEM条件を設定します。 設定をしたボルトタイプのボタンがハイライトされます。ハイライトされたボルトタイプが、設定準備完了を意味します。 ボルトタイプは、Type A, Tyep B, Type C, Type Dの4タイプあります。 各ボルトタイプGUIのヘルプは、下記のリンクから表示してください。 タイプA(Type A)のヘルプ &nbsp;:&nbsp;ボルト穴の上下座面にRBE2/RBE3要素を円形に作成、その中心をバー/RBE2要素で結合します。 タイプB(Type B)のヘルプ &nbsp;:&nbsp;ボルト穴の座面にRBE2/RBE3要素を円形に作成、またねじ部にRBE2/RBE3を作成し、その中心をバー/RBE2要素で結合します。 タイプC(Type C)のヘルプ &nbsp;:&nbsp;ボルト穴にRBE2/RBE3要素を作成し、その中心をばね/RBE2要素で結合します。 タイプD(Type D)のヘルプ &nbsp;:&nbsp;合わせ面のボルト穴周りにRBE2/MPCを作成して、結合します。 各ボルトタイプがサポートしているFEM条件の組合せ一覧表です。 ローカルメッシュ設定フェース(Local Settings Face) 検索されたボルト穴フェースにローカル設定を作成します。メッシング前のパーツに対して実行する際に便利です。 メッシュパーツに対して実行する場合は不要です。 平均メッシュサイズ(Average Mesh Size) 要素の平均サイズを入力します。最小は平均の0.1倍、最大は平均の2倍が自動設定されます。 -&nbsp操作手順&nbsp- 上部パーツ(Upper Part)と下部パーツ(Lower Part)を１つずつ選択します。 検索用パラメーター（最小円直径(Min Circle Diameter)、最大円直径(Max Circle Diameter)、間隙トレランス(Gap Tolearance)）を変更します。 検索(Find)ボタンをクリックします。ボルトペアがリストアップされます。 リストアップされたボルトペアを確認し、必要に応じて修正します。 設定するボルトタイプのボタンをクリックして、FEM条件を設定します。ボタンがハイライトされます。 リストにボルトペアが存在し、ボルトタイプのボタンがハイライトされると、適用(Apply)／OKボタンがアクティブになります。 適用(Apply)／OKボタンをクリックします。剛体ボルトが自動作成されます。
