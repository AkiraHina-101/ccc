# MeshEdit.MoveNode.ProjectToPlane_3Nodes()

MeshEdit.MoveNode.ProjectToPlane_3Nodes()

Description​

Move Nodes from Node to 3 nodes created Plane

Syntax​

MeshEdit.MoveNode.ProjectToPlane_3Nodes(ilNodeList=[])

Ribbon: MeshEdit » MoveNode » ProjectToPlane_3Nodes

Inputs​

ilNodeList​

A List of Integer specifying the node list.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.ProjectToPlane_3Nodes(ilNodeList=[])
