# Lab | Custom Note

Lab | Custom Note Lab | Custom Note This is the function to add notes that point to any location on the model and save them inside the file. Adding even one custom note will add a "Custom Notes" item under "All Items" in the Assemblies tree in the Assemblies window, with a collection item under the specified collection name and a custom note item under it. Note Note Name Specify the name of the note. Option Position Specify the position of the note by coordinate. Creating a custom note with a node/arbitrary point/arbitrary point on an edge selected will automatically populate the coordinate values of the selected entity. If you create a custom note with a 1D, 2D, or 3D element selected, the center coordinate value of the selected entity will be automatically populated. If you create an entity-specific custom note in a Pre document, its position will not follow if you edit the entity. If you create a node-specified custom note in a Post document, its position will follow the deformation display. For other entity-specified custom notes, their positions will not follow the deformation display. Create New Collection check box. Create a new collection and add a new custom note to it. Collection combo box Specifies the collection to which a new custom note will be added. Content Describes the contents of the note. Holds up to 20 lines of content. Style Font Size Specifies the font size of the text of Content. Font color (color selection dialog next to Font Size) Specifies the color of the text of Content. Bold check box Bold text in the Content. Alignment combo box Currently, only left-aligning is available. Note Background Color Specifies the ground color of the creating custom note. Note Outline Width and adjacent color selection specify the width and color of the note border. Note Arrow Specifies the thickness and color of the line extending from the note to the coordinate position. Setting the size to 0 hides the line. Type combo box Select the shape type that points to the coordinate position from "None" or "Arrow". -&nbsp操作手順&nbsp- Launch Custon Note command. Input position directly or select a Node, a face Point , an Edge Point or an element. Click Apply/OK to run the command. The note positions can be distributed by executing "Spread Note" at the right-click menu of Main Window. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
