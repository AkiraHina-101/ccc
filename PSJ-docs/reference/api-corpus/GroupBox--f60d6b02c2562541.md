# GroupBox

GroupBox

グループボックスを作成して、いくつかのコンポーネントを含めることができます。

プレビューダイアログ：

パラメータ​

テキスト​

グループボックスの上部に表示されるテキストを入力します。

名前​

グループボックスの名前を入力します。

チェックボックス​

いいえ：常に内部のコンポーネントを有効にします

はい（デフォルト==チェック済み）：右上隅にチェックを入れたチェックボックスを表示します（内部のすべてのコンポーネントを使用できるようにします）

はい（デフォルト==未チェック）：右上隅にチェックを外したチェックボックスを表示します（内部のすべてのコンポーネントを使用できないようにします）

折り畳み​

グループボックスを折りたたみ可能かどうかを設定します。

いいえ：折りたたみ不可

はい（デフォルト==折りたたまれている）：グループボックスは折りたたみ可能です（デフォルト：折りたたまれている）

はい（デフォルト==展開されている）：グループボックスは折りたたみ可能です（デフォルト：展開されている）

オリエンテーション​

内部のコンポーネントの配置を指定します。

水平：内部のコンポーネントを水平に配置します

垂直：内部のコンポーネントを垂直に配置します

有効​

有効にするかどうかを指定します。

オンをチェック：有効

オフをチェック：無効（グレーアウト）

表示​

作成したGroupBoxを表示するか非表示にするかを指定します。

オンをチェック：表示

オフをチェック：非表示

関連するAPI​

dlg.add_groupbox：作成中のダイアログにGroupBoxを追加します。

dlg.set_groupbox_checked：GroupBoxのチェックボックスの初期状態を表示/非表示に設定します。表示する場合、チェックボックスの初期状態はチェックされています。

dlg.set_groupbox_collapsed：GroupBoxの折りたたみアイコンの初期状態を表示/非表示に設定します。

dlg.set_groupbox_orientation：グループボックス内のすべてのコンポーネントのレイアウトを水平または垂直方向に揃えるように設定します。
