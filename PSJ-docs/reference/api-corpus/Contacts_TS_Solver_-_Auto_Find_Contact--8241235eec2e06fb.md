# Contacts | TS Solver - Auto Find Contact

Contacts | TS Solver - Auto Find Contact a.no-uline {text-decoration:none} Contacts | TS Solver - Auto Find Contact Automatically searches for contact conditions between parts in an assembly model and adds contact conditions. Contact Method &nbsp;&nbsp;&nbsp;Automatic search only. Tolerance &nbsp;&nbsp;&nbsp;Enter the tolerance value for detecting contact between two adjacent faces. Master basis &nbsp;&nbsp;&nbsp; Select the method for determining which face of the detected face pair will be the master face for defining contact conditions. Mesh size &nbsp;:&nbsp;Calculation is performed based on mesh size. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; The comparison is made with the average length of the element edges within the detected face pair. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;The face with the longer average length is selected as the master face. Area &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;:&nbsp;Calculation is performed based on area (per face) Find Contact &nbsp;&nbsp;&nbsp;Press the button to start the searching for the contact. Search Area &nbsp;&nbsp;&nbsp;Specify the range of contact pairs and candidate faces. When minimized, only faces found with search tolerance will be displayed as potential contact pairs. When maximized, it will display as a contact pair candidate up to the face that smoothly connects with the searched face. Cylinder Priority &nbsp;&nbsp;&nbsp;When checked, the contact of the cylindrical surface is preferentially searched. Interference Closure &nbsp;&nbsp;&nbsp;Specify the distance for the solver to determine contact between two faces. Input Unit &nbsp;&nbsp;&nbsp;Specify the unit for specifying tolerance and interference closure. Search &nbsp;&nbsp;&nbsp;Enter the part name of face ID in the text box on the left side of the dialog in order to narrow down the contact search result. Clear &nbsp;&nbsp;&nbsp;Cancel the refined search result display. Contact DB &nbsp;&nbsp;&nbsp;Display a list of existing contact conditions when the command is launched. &nbsp;&nbsp;&nbsp;A list of face pairs in contact found by the Find Contact button is also displayed. No. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;:&nbsp; The face pairs are numbered according to the order of detection. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A checkbox is displayed in front of the ID number, and contact settings are defined only for the selected face pairs. Master key &nbsp;&nbsp;&nbsp;&nbsp;:&nbsp; Display the Face ID (or part name) detected on the master side. Slave key &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;:&nbsp; Display the Face ID (or part name) detected on the slave side. Contact Type &nbsp;:&nbsp; Display the contact setting type (Glue or General). By default, the Glue type is selected. Select All &nbsp;&nbsp;&nbsp;Deselect all checkboxes and highlights all lines. Switch Master/Slave &nbsp;&nbsp;&nbsp;Switch the master and slave faces displayed in each line. This operation is performed only for highlighted lines. Switch Glue/General &nbsp;&nbsp;&nbsp;Switch the Glue and General contact types displayed in each line. This operation is performed only for highlighted lines. -&nbsp;Operating Procedure&nbsp;-&nbsp;&nbsp;When creating a new contact condition&nbsp; &nbsp;Press the Part button and select all target parts for contact setting from the screen. &nbsp;Change the tolerance value from the default setting as necessary. &nbsp;Switch the search algorithm of the master side face as necessary. &nbsp;Change the Interference Closure value from the default setting as necessary. &nbsp;Switch the local unit for defining the tolerance, interference closure value as necessary. &nbsp;Press the &lceil;Find Contact&rfloor; button. A list of detected face pairs is also displayed. &nbsp;Select each line in the list to display the faces on the screen. Faces of the master side are displayed in red, and faces of the slave side in blue. &nbsp;Deselect the checkboxes of the faces that do not require contact settings. &nbsp;Select the checkboxes of the faces that require switching and click the &lceil;Switch Master/Slave&rfloor; button to switch the master/slave faces. &nbsp;Select the checkboxes of the faces that require switching and click the &lceil;Switch Glue/General &rfloor; button to switch the glue/general contact types. &nbsp;Select the checkboxes of the lines to create and click the Apply or OK button. -&nbsp;Operating Procedure&nbsp;-&nbsp;&nbsp;When a contact condition exists (can be used for confirmation purpose)&nbsp; &nbsp;Hide all contacts from the assembly tree. &nbsp;Launch the command to display a list of all existing contact conditions. &nbsp;Select each line in the list to display the faces on the screen. &nbsp;&nbsp;&nbsp;&nbsp;Faces of the master side are displayed in red, and faces of the slave side in blue. &nbsp;After confirming, click the Apply or OK button to close the dialog. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
