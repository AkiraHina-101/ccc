# ABAQUS_OUTPUT_REQUEST

ABAQUS_OUTPUT_REQUEST

Description​

A data type uses to control parameters of Abaqus Output Request

Attributes​

strName​

A String specifying name.

The default value is "".

strDescription​

A String specifying description.

The default value is "".

iId​

An Integer specifying ID.

The default value is 0.

iOutputFiletype​

An Integer specifying output filetype.

The default value is 0.

iDomainType​

An Integer specifying domain type.

The default value is 0.

iDomainId​

An Integer specifying domain ID.

The default value is 0.

iFrequencyType​

An Integer specifying frequency type.

The default value is 0.

dFrequency​

A Double specifying frequency.

The default value is 0.0.

ParamTimePoint​

A PARAM_TIME_POINT specifying time point.

The default value is TIME_POINTS().

iTiming​

An Integer specifying timing.

The default value is 0.
