# 重複ノード検索

重複ノード検索 重複ノード検索 選択したエンティティ間に含まれる節点を対象に、位置が重複している節点を検索します。 検索 トレランス 節点間のトレランスを入力します。（デフォルト値：0.01） 関連部品表示 Partの表示に関するチェックで、チェックがONの場合、トレランス以下の節点群に関連したPartのみ表示します。 プレビュー トレランス以下の節点群をハイライト表示します。 リセット プレビューを解除します。 オプション グループ作成 チェックがONの場合、適用/OKボタンを選択後、検出した節点のグループを作成します。 検出節点を選択 チェックがONの場合、適用/OKボタンを選択後、検出した節点を選択（選択監視ウィンドウに格納）します。 -&nbsp操作手順&nbsp- 節点を検索するエンティティを選択します。 トレランスを入力します。 プレビューボタンをクリックします。 コマンド後に検索された節点を使用する場合は、作成されたグループ、もしくは検出節点保存チェックをONにします。 適用/OKボタンをクリックします。
