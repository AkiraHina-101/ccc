# 任意点を通るXY平面

任意点を通るXY平面 シェルパーツ面 選択したパーツを、指定したシェルパーツ面で分割します。 選択する平面 パーティションのみ チェックを入れると、内部にパーティションを作成します。この場合は、パーツは分割しません。 断面フェースを作成 チェックを入れると、パーツを分割した場合に、分割した箇所にフェースを作成します。 共有面 チェックを入れると、パーツを分割し、分割した箇所にフェースを作成する場合に、共有面を作成します。 共有面分離 チェックを入れると、パーツを分割し、分割した箇所にフェースを作成する場合に、フェースが飛び地で結合（マージ）されることを防ぎます。 -&nbsp;操作手順（パーツを分割し、分割した箇所にフェースを作成する場合）&nbsp;- 分割する座標平面を選択します。 選択リスト ウインドウを開き、ターゲットボタンをクリックします。 分割するパーツを選択します。 選択リスト ウインドウの切断ボタンをクリックします。 分割面となるフェースを選択します。 断面フェースを作成のチェックボックスをオンにします。 適用/OKボタンをクリックします。 -&nbsp;操作手順（パーツを分割せず、パーティションのみ作成する場合）&nbsp;- 選択リスト ウインドウを開き、ターゲットボタンをクリックします。 分割するパーツを選択します。 選択リスト ウインドウの切断ボタンをクリックします。 分割面となるフェースを選択します。 パーティションのみ のチェックボックスをオンにします。 断面フェースを作成のチェックボックスをオンにします。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- -->
