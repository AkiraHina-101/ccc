# Default Settings

Default Settings Default Settings Set other default values. Mesh Size for Auto Setting Set the mesh size automatic specification when the surface meshing automatic check box is turned on. Average Specify the average mesh size, the maximum and minimum mesh sizes will be calculated automatically. Minumum = Average * Specify the minimum mesh size and calculate the maximum and average mesh size automatically. Enter the calculation parameters for the minimum mesh size in the right column. Maximum = Average * Specify the maximum mesh size and calculate the average and minimum mesh sizes automatically. Enter the calculation parameters for the maximum mesh size in the right column. Options Set the option ON / OFF. Save History Tree When checked, the history function is turned on. ※The history function is under development. Data Validation If checked, the incorrect value check function is turned on. Apply / OK will be grayed out if you enter an invalid value when entering parameters for each command. Dialog Boxes State Reset dialog boxes state to default Clicking the reset button resets the input values in the dialog box to the initial values (under development). Key Bind Enable Key Bind Enable key bind (shortcut key) settings. Customize button Display the Key Bind Settings Dialog .
