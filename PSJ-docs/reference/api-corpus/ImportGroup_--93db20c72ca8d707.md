# ImportGroup()

ImportGroup()

Description​

Import Group written in CSV file.

Syntax​

ImportGroup(String filePath, Cursor SubGroup)

Inputs​

1. String[]​

Specify the csv file of group definition.

2. Cursor​

Specify the subGroup by cursor.

Return Code​

None.

Sample Code​

ImportGroup(["C:/Temp/group_file.csv"], 0:0)
