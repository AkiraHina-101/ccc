# フェース レイヤー

フェース レイヤー フェース レイヤー フェースをパーツの内側にオフセットしたフェースを作成します。 全体桁数 作成する面のオフセット量を入力します。 表面に沿った幅 チェックするとモデル面の形状に沿ったオフセット量と解釈されます。 レイヤー数 作成されるレイヤ数を入力します。 パーツを分離 作成されたレイヤ部分を別ボディにします。 ※レイヤ部分と元の部分の境界は共有面とします。 外形に強制統合 モデル形状の外側に合わせてオフセットします。 スムージングエッジ オフセットフェースのエッジを整えます。 エッジインプリントなし オフセットフェースの作成後に隣接面とのインプリント処理を実行しません。 -&nbsp操作手順&nbsp- 画面からオフセット対象となるフェース群を画面から選択します。 全体桁数にオフセット量、レイヤー数にレイヤ数を入力します。 作成されたレイヤ部分を別パーツとするには、パーツを分離 のチェックをONします。 適用またはOKボタンをクリックして演算を実行します。 作成されたレイヤ部分は別パーツとなり、境界面は共有面となります。 また、複数レイヤの場合も同様にそれぞれ別パーツとなります。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
