# 複数のソースファイルを組み込む

複数のソースファイルを組み込む

🎯 はじめに​

本チュートリアルでは、外部Pythonソースファイルを現在のスクリプトに組み込む方法を紹介します:

インストールされているJupiterのパスを取得する。
外部Pythonソースファイルを含むフォルダーパスを作成する。

外部Pythonソースファイルをシステムパスに追加する。

すべての外部Pythonソースファイル(モジュール):Sorts.pyとJPTModule.pyをインポートする。

Cubeパーツを作成する(外部Pythonソースファイル:JPTModule.pyのテスト用)。

Jupiter IDE内でインポートされたモジュールの使いやすさをテストする。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# インストールされているJupiterのパスを取得します。外部のPythonソースファイルを含むフォルダーパスを作成します。
jupiterPath = JPT.GetAppPathInfo(JPT.PathType.PROGRAM_PATH)
sourcePath = jupiterPath + '/SampleData/PSJ/PSJ-Utility/Utils'
print(sourcePath)

# システムパスにsourcePathを追加します。
import sys
sys.path.append(sourcePath)

# すべての外部Pythonソースファイル(モジュール):Sorts.pyとJPTModule.pyをインポートします
# Sorts.pyは並び替えアルゴリズムを含むPythonファイルです。
# JPTModule.pyはPSJユーティリティコードを含むPythonファイルです。
from Sorts import *
from Logger import *
from JPTModule import *

# 外部Pythonソースファイル:JPTModule.py　をテストするためにCubeパーツを作成します。 
Geometry.Part.Cube(strName="Cube_1", iPartColor=12999622)

# Jupiter IDEでインポートしたモジュールの使いやすさを確認します。

# Sorts.pyの使いやすさを確認します。
originList = [3,2,1]
print("並び替え前のリスト: {}".format(originList))
SortList = SortAlgorithms(originList).bubble_sort()
print("並び替え後のリスト: {}".format(SortList))

# Logger.pyの使いやすさを確認します。
logFile = 'D:file.log'
PrintFile.print_file(logFile, "これはテスト用文字列です")

# JPTModule.pyの使いやすさを確認します。
