# Tri to 4Tris

Tri to 4Tris Tri to 4Tris Convert one triangular element into four triangular elements. To Preview display an element with the mouse over the dividing line. Settings Auto Transition When checked, to ensure the integrity of the mesh division it will automatically create the mesh division of elements other than those specified. If you do not check this box, the integrity of the mesh division around after the split will no longer be observed because it will not place a mesh division of elements other than those specified. Merge Nodes When checked, it will join the nodes created by automatic mesh division for the elements other than those specified. CAD Projection If you check, it puts the node that was created by mesh division into CAD geometry. Auto Execution When checked, it will convert automatically when you select an element. -&nbspOperating Procedure (to increase the integrity of the mesh division)&nbsp- &nbspTurn on the Auto Transition check box. &nbspTurn on the Auto Execution check box. &nbspHover mouse over the triangular element that you want to convert, and then select the dividing line while displaying preview. &nbspSimultaneously convert selected. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
