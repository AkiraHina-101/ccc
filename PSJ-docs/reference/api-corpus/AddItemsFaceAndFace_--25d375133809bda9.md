# AddItemsFaceAndFace()

AddItemsFaceAndFace()

説明​

参照フェースの延長端にありますエッジを投影し、フェースのエッジを追加するアイテムを追加します。

構文​

AddItemsFaceAndFace(Cursor[] Face, int Extend Type)

入力​

1. Cursor []​

フェースリスト

2. Int​

拡張タイプ [Extend、Intersect]

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

AddItemsEdgeFaceandFace([6:62, 6:51],0)
