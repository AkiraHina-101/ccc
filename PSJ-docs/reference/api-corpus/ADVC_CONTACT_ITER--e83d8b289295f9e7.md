# ADVC_CONTACT_ITER

ADVC_CONTACT_ITER

説明​

ADVC接触イテレータのパラメータを制御するために使用されるデータ型です

属性​

iSubdivideMode​

サブディバイドモードを指定する Integer です。

デフォルト値は-1です。

iContactloopMax​

接触ループの最大値を指定する Integer です。

デフォルト値はDFLT_INTです。

iInternalContactloopMax​

内部接触ループの最大値を指定する Integer です。

デフォルト値はDFLT_INTです。

dSeparationTol​

分離許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

dRelativeSeparationTol​

相対的分離許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

dPenetrationTol​

浸透許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

dRelativePenetrationTol​

相対浸透許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

iMaxchp​

maxchpを指定する Integer です。

デフォルト値はDFLT_INTです。

iFrictionOnset​

摩擦発生を指定する Integer です。

デフォルト値は0です。

dStickSlipTol​

スティックスリップ許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

dFrictionTol​

摩擦許容値を指定する Double です。

デフォルト値はDFLT_DBLです。
