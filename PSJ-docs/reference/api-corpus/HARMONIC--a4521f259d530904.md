# HARMONIC

HARMONIC

説明​

Harmonicのパラメータを制御するために使用されるデータ型です。

属性​

dHarmonicStartFreq​

ハーモニック開始周波数を指定する Double 型の値です。

デフォルト値は0.0です。

dHarmonicEndFreq​

ハーモニック終了周波数を指定する Double 型の値です。

デフォルト値は1.0です。

iSubSteps​

サブステップを指定する Integer の値です。

デフォルト値は0です。

dAlphaD​

alpha d を指定する Double 型の値です。

デフォルト値は0.0です。

dBetaD​

beta d を指定する Double 型の値です。

デフォルト値は0.0です。

dDmprat​

dmprat を指定する Double 型の値です。

デフォルト値は0.0です。

bHarmonicOutputDisplacements​

ハーモニック出力変位を有効または無効にする Boolean 型の値です。

デフォルト値は False です。

bHarmonicOutputStress​

ハーモニック出力応力を有効または無効にする Boolean 型の値です。

デフォルト値は False です。
