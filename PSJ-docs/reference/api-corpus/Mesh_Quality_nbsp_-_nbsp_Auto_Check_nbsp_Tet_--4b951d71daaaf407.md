# Mesh Quality&nbsp;-&nbsp;Auto Check&nbsp;[Tet]

Mesh Quality&nbsp;-&nbsp;Auto Check&nbsp;[Tet] Mesh Quality&nbsp;-&nbsp;Auto Check&nbsp;[Tet] Make corrections to the solid mesh (Tet4 / Tet10) according to the number of quality standards. Quality Standard Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value. Aspect Ratio: If checked, detect and display elements with aspect ratio greater than or equal to the specified value. Volume: If checked, elements with volumes below the specified value will be detected and displayed. Jacobian Factor: If checked, detect and display elements of Jacobian value below the specified value. Tet Collapse: If checked, elements of Tet Collapse below the specified value will be detected and displayed. Tet Skew: If checked, elements of Tet Skew value greater than the specified value will be detected and displayed. ※Please refer to ＜definition of quality check method＞ for each item. Display Number of Entities: Display the number of displayed elements. Refresh Show Model: Press the Show Model button to restore the model display. -&nbspOperating Procedure&nbsp- &nbspSelect the part you want to check element shape. &nbspCheck the check box of the quality standard you want to check. &nbspPress the Apply or OK button. &nbspIf you want to restore the model view, press Show Model.
