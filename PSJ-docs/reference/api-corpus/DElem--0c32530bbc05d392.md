# DElem

DElem

説明​

これは Jupiter 内部の要素を表す DElem クラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | typeID | 要素の種類 ID（ID = 11）。
戻り値は Int notation of DItem Types（int）です。

 | id | 要素の外部 ID。
ID は重複する可能性がありますが、推奨されません。
再番号付け機能を使用して ID を変更できます。
戻り値は ID（int）です。

 | type | 要素のタイプ。
戻り値は ElemType です。

 | kind | 要素の種類。
戻り値は ElemKind です。

 | nodes | 要素に属する節点です。
戻り値は節点のリストです。

 | color* 1 | 要素の色に関する情報です。
この値は調整可能です。
戻り値は RGB 色です。

注意​

Footnotes​

属性名にアスタリスク(*)記号があると、その属性は現在の値から新しい値に変更/割り当てることができることを意味します。 ↩
