# MeshEdit.MoveNode.Absolute()

MeshEdit.MoveNode.Absolute()

Description​

Move node absolute

Syntax​

MeshEdit.MoveNode.Absolute(dDeltaX=0.0, dDeltaY=0.0, dDeltaZ=0.0, b1stCoord=True, b2ndCoord=True, b3rdCoord=True, crlNodes=[], crCoord=None)

Ribbon: MeshEdit » MoveNode » Absolute

Inputs​

dDeltaX​

A Double specifying the delta x.

The default value is 0.0.

dDeltaY​

A Double specifying the delta y.

The default value is 0.0.

dDeltaZ​

A Double specifying the delta z.

The default value is 0.0.

b1stCoord​

A B1ST_COORD specifying the coordinate.

The default value is True.

b2ndCoord​

A B2ND_COORD specifying the coordinate.

The default value is True.

b3rdCoord​

A B3RD_COORD specifying the coordinate.

The default value is True.

crlNodes​

A List of Cursor specifying the node.

The default value is [].

crCoord​

A Cursor specifying the coordinate.

The default value is None.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.Absolute(dDeltaX=0.0, dDeltaY=0.0, dDeltaZ=0.0, b1stCoord=True, b2ndCoord=True, b3rdCoord=True, crlNodes=[], crCoord=None)
