# ABAQUS_LBC_STEP_INFO

ABAQUS_LBC_STEP_INFO

Description​

A data type uses to control parameters of Abaqus Lbc Step Info

Attributes​

crStep​

A Cursor specifying step.

The default value is None.

crLbc​

A Cursor specifying lbc.

The default value is None.

iCurflag​

An Integer specifying curflag.

The default value is 0.
