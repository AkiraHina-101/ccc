# Equivalence

Equivalence Equivalence Combine the neighbouring nodes. Equivalence Distance Display the distance between two selected node. Tolerance Set the tolerance within which the command is operable. Merge Towards Choose the node towards which the other node will be merged. There are 3 options: First Node, Second Node and Mid-point. Multiple Node Join the nodes for the case where the multiple selected nodes are within tolerance. -&nbspOperating Procedure&nbsp- Equivalence 1 Pair of Nodes (Multiple Node is off) &nbspSelect the first node. &nbspSelect the second node. &nbspSelect one of the Merge Towards options: First Node, Second Node or Mid-point. &nbspClick the Apply button. &nbspOne of the two nodes will be merged to the First node/Second Node/Mid-point that you selected. Equivalence Many Pairs of Nodes (Multiple Node is on) &nbspSelect the first node of the first node pair. &nbspSelect the second node of the first node pair. &nbspGo on selecting other node pairs. &nbspSelect one of the Merge Towards options: First Node, Second Node or Mid-point. &nbspClick the Apply button. &nbspOne of the two nodes of each pair will be merged to the First node/Second Node/Mid-point that you selected. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
