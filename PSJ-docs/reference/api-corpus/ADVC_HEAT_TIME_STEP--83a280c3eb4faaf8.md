# ADVC_HEAT_TIME_STEP

ADVC_HEAT_TIME_STEP

詳細​

ADVC Heat Time Stepのパラメータを制御するために使用されるデータ型です。

属性​

iEndType​

終了タイプを指定する Integer です。

デフォルト値は1です。

dMaxTime​

最大時間を指定する Double です。

デフォルト値は1です。

iFixedAuto​

固定オートを指定する Integer です。

デフォルト値は0です。

dMaxChange​

最大変化量を指定する Double です。

デフォルト値はDFLT_DBLです。

dInitdt​

initdtを指定する Double です。

デフォルト値はDFLT_DBLです。

iDefineMaxdt​

define maxdtを指定する Integer です。

デフォルト値は0です。

dMaxdt​

maxdtを指定する Double です。

デフォルト値はDFLT_DBLです。

iDefineMindt​

define mindtを指定する Integer です。

デフォルト値は0です。

dMindt​

mindtを指定する Double です。

デフォルト値はDFLT_DBLです。

dFixeddt​

fixeddtを指定する Double です。

デフォルト値はDFLT_DBLです。

iOutputLast​

output lastを指定する Integer です。

デフォルト値は-1です。

iOutputInterval​

output intervalを指定する Integer です。

デフォルト値はDFLT_INTです。

iRestartLast​

restart lastを指定する Integer です。

デフォルト値は-1です。

iRestartInterval​

restart intervalを指定する Integer です。

デフォルト値はDFLT_INTです。

dOutputTimeInterval​

出力時間間隔を指定する Double です。

デフォルト値はDFLT_DBLです。

dRestartTimeInterval​

リスタート時間間隔を指定する Double です。

デフォルト値はDFLT_DBLです。

iOutputInit​

output initを指定する Integer です。

デフォルト値は-1です。
