# ADVC_AUTO_INCREMENT

ADVC_AUTO_INCREMENT

説明​

ADVC Auto Incrementのパラメータを制御するために使用するデータ型です。

属性​

iNewtonResidueIncrMax​

新トン残留増加最大値を指定する Integer です。

デフォルト値は DFLT_INT です。

iBeginResidueIncrCheck​

開始残留増加チェックを指定する Integer です。

デフォルト値は DFLT_INT です。

iBeginLogarithmicRateCheck​

開始対数率チェックを指定する Integer です。

デフォルト値は DFLT_INT です。

dCutBackFactorForDivergence​

発散のためのカットバックファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

dCutBackFactorForTooSlowConvergence​

収束が遅すぎるためのカットバックファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

dCutBackFactorForExcessiveDistortion​

過度な歪みのためのカットバックファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

iIncrEnlargeNewtonMax​

新トン最大インクリメントを指定する Integer です。

デフォルト値は DFLT_INT です。

iIncrEnlargeSuppress​

インクリメント増加を抑制する Integer です。

デフォルト値は DFLT_INT です。

dIncreaseFactorForStatic​

静的に増加するファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

dIncreaseFactorForDynamic​

動的に増加するファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

dIncreaseFactorForCreep​

クリープの増加ファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

dIncreaseFactorForRdnlk​

rdnlkの増加ファクターを指定する Double です。

デフォルト値は DFLT_DBL です。

dTemperatureIncrMax​

温度増加の最大値を指定する Double です。

デフォルト値は DFLT_DBL です。

iUseTemperatureIncrMax​

温度増加の最大値の使用を指定する Integer です。

デフォルト値は 0 です。

dHalfStepTol​

ハーフステップの許容値を指定する Double です。

デフォルト値は DFLT_DBL です。

dStraTol​

ストラ許容値を指定する Double です。

デフォルト値は DFLT_DBL です。

dCreepStraTol​

クリープストラ許容値を指定する Double です。

デフォルト値は DFLT_DBL です。
