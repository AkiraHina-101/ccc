# Shrink Mode Display

Shrink Mode Display a.no-uline {text-decoration:none} Shrink Mode Display By turning on the shrink mode display, each element is reduced in size by the shrink ratio. While the shrink mode display is ON, the shrink ribbon is displayed and detailed settings are available. Command List Panel Name Description Close Close Ends using shrink mode. 1D/2D/3D 1D 1D elements are targeted for shrink mode display. 2D 2D elements are targeted for shrink mode display (default: ON). 3D 3D elements are targeted for shrink mode display. Shrink Mode Settings Shrink Factor Shrink factor can be adjusted. Numerical increments = 0.01. Property Assigned Filters display of elements to which the property is assigned (Default: OFF). Default Reset shrink ratio to default (0.80).
