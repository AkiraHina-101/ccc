# CmdChartSetRange()

CmdChartSetRange()

説明​

手動でチャートの範囲を設定します。

構文​

CmdChartSetRange(double MinX, double MaxX, double IntervalX, double MinY, double MaxY, double IntervalY)

入力​

1. double ​

X軸の最小値

2. double ​

X軸の最大値

3. double ​

X軸の目盛間隔

4. double ​

Y軸の最小値

5. double ​

Y軸の最大値

6. double ​

Y軸の目盛間隔

戻り値​

なし。

サンプルコード​

CmdChartSetRange(0,540,20,-30,20,5)
