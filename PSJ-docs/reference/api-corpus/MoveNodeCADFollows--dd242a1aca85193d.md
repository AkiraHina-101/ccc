# MoveNodeCADFollows

MoveNodeCADFollows MoveNodeCADFollows Description Move node to mouse drag position Syntax MoveNodeCADFollows(Cursor[] node, double x, double y, double z) Inputs Cursor[] List with the nodes to move double x: 1st coordinate of the point where to move the node. double y: 2nd coordinate of the point where to move the node. double z: 3rd coordinate of the point where to move the node. Return Code 1 Succeeded 0 Failed Sample Code MoveNodeCADFollows([10:1992], 0.00523353, 0.01, 0.00789714)
