# MoveNodeCADFollows()

MoveNodeCADFollows()

説明​

節点をマウスのドラッグ位置に移動します

構文​

MoveNodeCADFollows(Cursor[] node, double x, double y, double z)

入力​

1. Cursor[]​

移動させる節点のリスト

2. Double​

x: 節点を移動させる座標の1番目

3. Double​

y: 節点を移動させる座標の2番目

4. Double​

z: 節点を移動させる座標の3番目

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

MoveNodeCADFollows([10:1992], 0.00523353, 0.01, 0.00789714)
