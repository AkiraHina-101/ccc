# MeshEdit.MirrorCopy()

MeshEdit.MirrorCopy()

Description​

Mirror copy of surface mesh

Syntax​

MeshEdit.MirrorCopy(crlFaces=[])

Ribbon: MeshEdit » MirrorCopy

Inputs​

crlFaces​

A List of Cursor specifying the face.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MirrorCopy(crlFaces=[])
