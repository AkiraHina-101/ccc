# Tools.TotalLoad.Node()

Tools.TotalLoad.Node()

Description​

Syntax​

Tools.TotalLoad.Node(crlTargets=[], crCoordinate=None, strOutput="Total", iPrecision=6)

Ribbon: Tools » TotalLoad » Node

Inputs​

crlTargets​

A List of Cursor specifying the target.

The default value is [].

crCoordinate​

A Cursor specifying the coordinate.

The default value is None.

strOutput​

A String specifying the output.

The default value is "Total".

iPrecision​

An Integer specifying the precision.

The default value is 6.

Return Code​

A String of 1 if success, or 0 if fail.
