# Tab Control

Tab Control Tab Control タブアイテム（ページ）のグループを作成します。 &nbsp;&nbsp;&nbsp;作成イメージ図： &nbsp;&nbsp;&nbsp;&nbsp※Tab ControlはTab Itemとセットで使用します。 Name &nbsp;&nbsp;&nbsp;Tab Controlコンポーネント名を入力します。 Enable &nbsp;&nbsp;&nbsp;使用の可否を指定します。 チェックオン &nbsp;:&nbsp;使用可能。 チェックオフ &nbsp;:&nbsp;使用不可。（グレーアウトされます） Width &nbsp;&nbsp;&nbsp;ページの最小幅を指定します。（単位：ピクセル） Height &nbsp;&nbsp;&nbsp;ページの最小高さを指定します。（単位：ピクセル）
