# Element Quality Check

Element Quality Check Element Quality Check Element Quality Check contains error check and quality check functions which can be used simultaneously with the command windows. Error Check Tab This tab is based on Mesh Cleanup Ribbon > Free Edges and Intersections functions which have been adjusted so that it can be used simultaneously with the command windows. Free Edges It will detect the Free Edge and Non-manifold errors. Number of Edges - Free: It displays the number of Free Edges. - Nonmanifold: It displays the number of Non-manifold. Display Options - Mesh Color: Set the display mesh number of layers around the Free Edge and Non-manifold. --> Original : Change only the color of edge, without changing the color of Mesh. --> Gray : It displays the color of the existing Edge. - Display All: If you have turned on, you will see all the Mesh around the Free Edge and Non-manifold. Number of Layers will be grayed out. - Number of Layers: Set number of layers of the display Mesh around the Free Edge and Non-manifold. - Free Edges: If you turn it on, it displays the Free Edge. - Check Free Edge by Part: If you turn it on, it displays the Free Edge part by part. - Nonmanifold: If you turn it on, it displays the Non-manifold. - Nonmanifold Threshold: Enter the minimum number of elements connection for the Non-manifold. - Hide Boundary Edges: It displays the Free Edge other than outer frame of the shell shape. Close Gap - Dist. Tolerance: Set the distance between nodes that can be moved up to at the time of execution. (For more than 1mm gap, Non-manifold does not automatically junction with respect to the model that is not closed, such as the mid-plane). - Close Gap: Automatically joining gaps between the elements. Output Options - Error Text: When it is turned on, the information of Free Edge is output to the Output window with the Text data and the Temp folder of Install Path. Check Button To start checking for free edges. Intersections For Element intersection error detection. Number of Edges - Tolerance: Set the Tolerance for element intersection display. - Number of Element: It displays the element number of elements intersection. - Display Type: Select the type of elements intersection display. --> Body Intersection Only : It displays the element intersection on the Part. --> All Intersection : The element intersection section between parts and on part is displayed. --> Between Bodies Intersection : It displays the element intersection only between parts. Layers - Number of Layers: Set the number of layers for mesh display around the element intersection position. - Layer Update: To update the number of display layer. Auto Cleanup - Cleanup: Intersecting parts will be automatically corrected. - Aggressive Cleanup: When checked, the function will clean up mesh quality over shape reproducibility. Output Options - Error Text: When it is turned on, the information of intersection is output to the Output window with the Text data and the Temp folder of Install Path. Check Button To start checking for intersections. -&nbspOperation Method (Error Check Tab - Free Edges)&nbsp- &nbspSelect the Part to be checked. &nbspChange the Layer number and check items in the Display Option if necessary. &nbspPress the Apply or OK button. &nbspAfter checking, click the Reset to Normal Display Mode icon &nbsp;in the main window to return to the original display. -&nbspOperation Method (Error Check Tab - Intersections)&nbsp- &nbspSelect the Part to be checked. &nbspChange the Tolerance and Display Type, if necessary. &nbspPress the Apply or OK button. &nbspAfter checking, click the Reset to Normal Display Mode icon &nbsp;in the main window to return to the original display. Quality Check Tab This tab is based on Mesh Cleanup Ribbon > Auto Check and Manual Check functions which have been adjusted so that it can be used simultaneously with the command window. 2D Elements Make corrections to the 2D mesh (Tri/Quad/Tri+Quad) according to the selected quality standard. Element Type Select one of element types to check quality: Tri, Quad or Tri+Quad. Mesh Quality Tools - Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value. - Aspect Ratio: If checked, detect and display elements with aspect ratio greater than or equal to the specified value. - Warping: If checked, detect and display elements with a warping value less than or equal to the specified value. - Skewness: If checked, elements with skewness less than or equal to the specified value will be detected and displayed. - Edge Length: If checked, detect and display elements with edge lengths less than the specified value. - Area: If checked, the element of the area below the specified value will be detected and displayed. - Node Valence: If checked, elements with more than the specified node valence will be detected and displayed. - Interior Angle: If checked, detect and display elements with angles less than the specified value. - Taper: If checked, detect and display the taper value more than the specified value. - Node Free Edges: Check the number of free edges connected to one node for Tri / Quad elements. - Duplicate Elements: If checked, duplicates will be detected and displayed. - Unstable: Check the number of (corner) nodes connecting with adjacent elements. It is used to detect elements of 1 (2) point connection where rigid motion occurs. - Time Step (LS-DYNA): Check timestep in the CFL condition by the LS-DYNA formula. - Time Step (Abaqus): Check timestep in the CFL condition by the Abaqus formula. Check Button: start checking mesh quality. Show Model Button: return to the original display. Auto Cleanup - Auto Cleanup: You can automatically correct the element by pressing Cleanup button. - Mode: Switch the mode at the time of the Cleanup. --> Standard: Standard --> Aggressive: Perform Cleanup taking into account the local settings, such as preserve. - Nonmanifold: To check and fix non manifold. Manual Cleanup Operate Manual Cleanup functions: - Dragging Node - Split - 2Tris to Quad - Collapse - 2Quads to Quad - Swap - 1Quad to 2Tris - Equivalence 3D Elements Make corrections to the 3D mesh (Tet/Hex) according to the selected quality standard. Element Type Select one of element types to check quality: Tet, Hex. Mesh Quality Tools - Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value. - Aspect Ratio: If checked, detect and display elements with aspect ratio greater than or equal to the specified value. - Min Angle: If checked, detect and display elements with min angle smaller than or equal to the specified value. - Max Angle: If checked, detect and display elements with max angle larger than or equal to the specified value. - Volume: Check element volume for Tetra / Hexa elements. - Jacobian: Check Jacobian for Tetra elements. - Tet Collapse: Check Tet Collapse for Tetra elements. - Tet Skew: Check Tet Skew for Tetra elements. - Edge Length: If checked, detect and display elements with edge lengths less than the specified value. - Unstable: Check the number of (corner) nodes connecting with adjacent elements. It is used to detect elements of 1 (2) point connection where rigid motion occurs. - Time Step (Abaqus): Check timestep in the CFL condition by the Abaqus formula. Check Button: start checking mesh quality. Show Model Button: return to the original display. Auto Cleanup (For Tetra elements only) - Auto Cleanup: You can automatically correct the element by pressing Cleanup button. - Tet Collapse Method: Switch the Tet Collapse Methods at the time of the Cleanup. --> S Method --> A Method --> D Method - Mode: Switch the mode at the time of the Cleanup. --> Standard: Standard --> Aggressive: Perform Cleanup taking into account the local settings, such as preserve. - Nonmanifold: To check and fix non manifold. Manual Cleanup Operate Manual Cleanup functions: - Dragging Node - Split - Normal Offset - Collapse - Along Direction - Swap - Straighten Midnodes - Equivalence -&nbspOperation Method (Quality Check Tab - 2D Elements)&nbsp- &nbspSelect the Part to be checked. &nbspSelect element type Tri/Quad/Tri+Quad and select mesh quality tools to be checked. &nbspPress the Check button to start checking for errors. &nbspSelect Auto Cleanup methods to fix errors if necessary. &nbspSelect Manual Cleanup tools to fix errors if necessary. &nbspAfter checking, click the Show Model button to return to the original display. -&nbspOperation Method (Quality Check Tab - 3D Elements)&nbsp- &nbspSelect the Part to be checked. &nbspSelect element type Tet/Hex and select mesh quality tools to be checked. &nbspPress the Check button to start checking for errors. &nbspSelect Auto Cleanup methods to fix errors if necessary. &nbspSelect Manual Cleanup tools to fix errors if necessary. &nbspAfter checking, click the Show Model button to return to the original display.
