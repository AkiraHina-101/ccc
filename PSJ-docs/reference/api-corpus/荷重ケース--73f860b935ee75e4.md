# 荷重ケース

荷重ケース 荷重ケース 荷重ケース ダイアログボックス このコマンドでは、荷重や拘束条件を束ねる荷重ケースを作成します。 荷重ケースは解析ソルバー入力データ作成時などに参照できます。 名前 作成する荷重ケースの名前を入力します。 ID Nastran向けLOAD、SPC、MPC IDを指定します。 係数 作成する荷重ケース全体にかかるNastran向け荷重係数を入力します。 荷重を係数倍する場合に使用します。 リストされたエンティティを一度に選択します。左から、全選択、全選択解除、選択と非選択を反転。 エンティティタイプ リスト内に表示されている条件を、選択したアイテムごとに表示します。 フィルター 入力した名前の一部により、表示項目をフィルタリングします。 全境界条件 作成された既存の荷重、拘束条件をリスト表示します。 選択にはチェックボックスを使用します。 チェックを入れた境界条件が属しているエンティティがハイライトされます。 選択した境界条件 作成する荷重ケースで使用する荷重や拘束条件をリスト表示します。 荷重毎に係数を入力します。 所属パーツ チェックを入れた境界条件が属しているパーツをリスト表示します。 クリックすると、所属パーツがハイライトされます。 -&nbsp操作手順&nbsp- 名前に作成する荷重ケース名を入力します。 必要に応じて係数に荷重係数を入力します(Nastran向け)。 作成されたすべての境界条件リストから荷重ケースに入れる荷重、拘束条件のチェックボックスを選択します。 選択された条件は選択した境界条件リストに表示されます。 適用またはOKボタンを押して荷重ケースを作成します。 *作成した荷重ケースはNastran出力のLoading / Boundary ConditionsのベースもしくはサブケースオプションのLOADで指定します。 &nbsp;下図のようなLOADカードが出力されます。 -&nbsp補足&nbsp- ツリーアイテム上の右クリックメニューから作成することも可能です。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
