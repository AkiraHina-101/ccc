# マクロウィンドウ

マクロウィンドウ マクロウィンドウ コマンド実行時のスクリプト情報を表示します。 マウス操作 マクロウィンドウ内でのマウス操作の一覧です。 マウス操作 機能 左ボタンクリック 行をハイライトします。Ctrlキー及びShiftキーと同時に使うことで、範囲選択することができます。 左ボタンダブルクリック マクロ行を実行します。 マウスホイール ウィンドウをスクロールします。 ツールバー マクロ操作用ツールバーです。 アイコン 名称 説明 マクロの読込み マクロウィンドウに、マクロファイルを読み込みます マクロの保存 マクロウィンドウ内のマクロ行を指定のマクロファイルにセーブします。 マクロの記録 ONのとき、操作をマクロウィンドウに記録します。 マクロの巻き戻し マクロの再生位置を先頭行に戻します。 マクロの再生 マクロウィンドウに表示されているマクロ行を全て順に実行します。 次のマクロ マクロを１行毎に実行します。 マクロの停止 マクロの実行を停止します。 マクロツール Macro Play時のマクロ実行時間間隔を調節します。 マクロビューポイント Macro Play時のマクロ実行時間間隔を調節します。 ショートカットメニュー マウス右クリックで表示されるメニューから、各コマンドを使用します。 コマンド 内容 すべて選択 マクロウィンドウ内の内容を全てハイライトします。 コピー ハイライトしたマクロ行をクリップボードにコピーします。 貼付け マクロウィンドウ内に、クリップボードの内容をペーストします。 クリアー マクロウィンドウの内容を全て消去します。
