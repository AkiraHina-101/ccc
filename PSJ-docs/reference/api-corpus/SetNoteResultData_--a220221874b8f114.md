# SetNoteResultData()

SetNoteResultData()

説明​

メモウィンドウ内の結果データのタイトルの表示を設定します。

構文​

SetNoteResultData(int NoteResultTitle、string NoteResultTitle)

入力​

1. Int​

結果データのタイトルをデフォルトまたはユーザー定義名として表示する方法を指定する整数です。

2. String​

結果データタイトルの任意のユーザー定義名を指定する文字列です。

戻り値​

"1": 成功しました。

"0": 失敗しました。

サンプルコード​

SetNoteResultData(1, "Result Data")
