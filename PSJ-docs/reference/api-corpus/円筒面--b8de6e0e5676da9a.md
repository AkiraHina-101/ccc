# 円筒面

円筒面 円筒面 このコマンドでは、円筒面を延長します。 オプション 延長タイプ &nbsp;&nbsp;&nbsp;延長するタイプを選択します。 平面：平面で延長します。 円筒面：円筒面で延長します。 方法 &nbsp;&nbsp;&nbsp;方法を選択します。 軸方向へ：延長するフェースの方向を座標平面で指定します。 フェースへ：指定したフェースまで平面を延長します。 エッジオフセット：指定したフェースを指定した長さで延長します。 円弧の角度：指定した中心角度で、選択したフェースと同じ曲率で延長します。 円周の長さ：指定した長さで、選択したフェースと同じ曲率で延長します。 パラメーター 座標平面 &nbsp;&nbsp;&nbsp;延長する座標平面を指定します。 XY ： XY平面上 YZ ： YZ平面上 ZX ： ZX平面上 z/x/y &nbsp;&nbsp;&nbsp;XY を選択した場合、Z 方向の座標値を入力します。 &nbsp;&nbsp;&nbsp;YZ を選択した場合、X 方向の座標値を入力します。 &nbsp;&nbsp;&nbsp;ZX を選択した場合、Y 方向の座標値を入力します。 角度オフセット &nbsp;&nbsp;&nbsp;オフセットしたい中心角度を入力します。 円弧の節点数 &nbsp;&nbsp;&nbsp;シリンダー面の分割数を入力します。 円周長さ &nbsp;&nbsp;&nbsp;シリンダー面の円弧の長さを入力します。 エッジオフセット 長さ &nbsp;&nbsp;&nbsp;オフセット値を入力します。 -&nbsp操作手順(平面｜軸方向へ)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;延長する座標平面を指定します。 &nbsp;z/x/yに座標値を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順(平面｜フェースへ)&nbsp- &nbsp;選択リストを開き「フェース延伸」をクリックして延長したいフェースを選択します。 &nbsp;「リファレンス」をクリックして延長先のフェースを選択します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順(平面｜エッジオフセット)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;オフセット値を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順(円筒面｜円弧の角度)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;オフセットしたい中心角度と円弧の節点数を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順(円筒面｜円周の長さ)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;円弧の節点数と延長する円周の長さを入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
