# RadioButton

RadioButton RadioButton Add a radio button. &nbsp;&nbsp;&nbsp;Creation image: Text &nbsp;&nbsp;&nbsp;Enter the text that appears next to the radio button. Name &nbsp;&nbsp;&nbsp;Enter the name of the RadioButton component. Checked &nbsp;&nbsp;&nbsp;Specify the default value. True &nbsp;:&nbsp;Check On False &nbsp;:&nbsp;Check Off Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the combo box. (Units: pixels) Height &nbsp;&nbsp;&nbsp;Specifies the minimum height of the combo box. (Units: pixels) Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Left Text &nbsp;&nbsp;&nbsp;Display the text to the left of the radio button. Group &nbsp;&nbsp;&nbsp;The nearby Radio Button components are in one group. Command to use Command Description Sample Code dlg.isbutton_checked("component name") Check whether the radio button is checked or not. Returns a Boolean value (True/False). Input: dlg.isbutton_checked("CheckBoxButton") Output: > True/False dlg.set_radiobutton_state("name", Bool) Specify the radio button status (checked or unchecked). Input: dlg.set_radiobutton_state("CheckBox1", True)
