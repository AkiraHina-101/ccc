# MODAL

MODAL

説明​

Modalのパラメータを制御するために使用されるデータ型です。

属性​

iModeMethod​

モードメソッドを指定する Integer です。

デフォルト値は 0 です。

iExtractNum​

抽出数を指定する Integer です。

デフォルト値は 1 です。

bExpandShape​

形状の拡大を有効化/無効化する Boolean です。

デフォルト値は True です。

iExpandNum​

拡大数を指定する Integer です。

デフォルト値は 0 です。

bUseApprox​

近似値の使用を有効化/無効化する Boolean です。

デフォルト値は False です。

bInclPrestressEffect​

事前応力効果の含有を有効化/無効化する Boolean です。

デフォルト値は False です。

bModalMemorySave​

モーダルメモリ保存を有効化/無効化する Boolean です。

デフォルト値は False です。

bResidualVector​

残留ベクトルを有効化/無効化する Boolean です。

デフォルト値は False です。

bModalOutputDisplacements​

モーダル出力変位を有効化/無効化する Boolean です。

デフォルト値は False です。

bModalOutputStrain​

モーダル出力ひずみを有効化/無効化する Boolean です。

デフォルト値は False です。
