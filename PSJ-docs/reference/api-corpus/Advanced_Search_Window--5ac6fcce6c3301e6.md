# Advanced Search Window

Advanced Search Window Advanced Search Window Advanced Search Window contains the search functions which can be used simultaneously with the command windows. Common Items Add to current selection When the check is ON, search results will be added to the selection list. When the check is OFF, the search results are cleared and replaced with new search results. ※The selection for search is always cleared. Search button Select entities according to the search settings. Show Adjacents Tab This tab is based on Geometry Ribbon > Extract > Show Adjacent Faces Function which has been adjusted so that it can be used simultaneously with the command window. Face Select adjacent faces. Element Select adjacent elements. Search All If checked, all faces (elements) adjacent to the start faces (elements) will be acquired. Number of layers Get adjacent faces (elements) within the range of the number of layers from the start faces / elements. Stop Include stop faces (elements) Include the selected stop faces (elements) in the selection result. Stop angle up to If the faces (elements) are connected at an angle greater than or equal to the angle specified here, the search is stopped. Preview Preview button Click the button to highlight the selection in the main window with the color on the right. Reset button Click the button to reset the selection preview. Start face (element) / stop face (element) You can select start faces (elements) and stop faces (elements) while checking in the list. Click "Clear" to cancel all selections. -&nbspOperation Method (Show Adjacents Tab)&nbsp- &nbspSelect the target from either face or element with the radio button. &nbspClick the "Start face" button and select the selection start face (or element) in the main window. &nbspClick the "Stop face" button and select the selection stop face (or element) in the main window. &nbspClick the "Preview" button to highlight the selection in the main window. &nbspClick the "Search" button to search and select. Find Features Tab This tab is based on Geometry Ribbon > Extract > Find Feature Function which has been adjusted so that it can be used simultaneously with the command window. Face Find and select faces with highlighted features. 4 sided Detect and select quadrilateral face surrounded by 4 edges. Planar Detect and select a plane face. Full cylinder Detect and select cylindrical faces. Half cylinder Detect and select a semi-cylindrical face. Disc Detect and select a disc-shaped face. Map mesh Detect and select map mesh faces. Cylinder If checked, the cylindrical face will be detected and selected. Disc If checked, a disc-like face is detected and selected。 4 corners If checked, faces of four corners will be detected and selected. Circle chamfer Select a circular chamfer face and delete it. Min thickness Specify the minimum thickness of the circular chamfer surface. Max thickness Specify the minimum thickness of the circular chamfer surface. Fillet Select the fillet surface。 Min face width Specify the minimum face width to search. Max face width Specify the maximum face width to search. Min curve radius Specify the minimum radius of the fillet to search. Max curve radius Specify the maximum radius of the fillet to search. Min angle Specify the minimum value of the angle of the fillet to search. Max angle Specify the maximum value of the angle of the fillet to search. Convex Search for convex fillets. Concave Search for concave fillets. Tiny faces Select tiny faces. Min face width Specify the minimum face width to search. Max face width Specify the maximum face width to search. Edge Detect and select edges with highlighted features. Line Select the edge of a straight line. Loop Select the edge of a loop shape. Full circle Select the edge of a circle. Half circle Select the edge of a semicircle. Bolt hole Select bolt hole edge within a range of diameters. Diameter min Minimum diamater of bolt hole. Diameter max Maximum diamater of bolt hole. Concentric circles Select the concentric edge of a specified edge. -&nbspOperation Method (Find Features Tab)&nbsp- &nbspHighlight the feature target you want to detect in the Faces and Edges list windows. &nbspIf the search parameter queries are displayed at the bottom of the list, enter the parameters. &nbspFor features other than concentric circles: Select the search target in the main window. If not selected, the displayed part will be searched. &nbspFor concentric circles: Select the reference edge. &nbspSearch and select features with the "Search" button. Find Entities Tab This tab is based on the Home Ribbon > Find Function which is easier to use. Match check box If checked, only the target that exactly matches the string entered in the search field will be searched and selected. Input ID / Name Enter the search target name, ID, and coordinate values. When searching multiple strings, enclose each string with "". If you want to search multiple IDs, please separate with blanks. Example: 1 2 3 Coordinate values are input in comma separated format of x, y, z. When entering multiple coordinate values, separate them with commas and enter them one after another. Example: 0, 0, 0, 10, 10, 10 Options List of search target entities. Search and select the checked object. From file Enter the search target name, ID, and coordinate values from a CSV file. ID Comma separated integer value Example 1: Line number ID description 1 1,2,3,4,5 Example 2: When including a line break Line number ID description 1 1,2,3 2 4,5 Name Comma separated names Example 1: Line number Name description 1 Cube_1,Cube_2,Cube_3 Example 2:When including a line break Line number Name description 1 Cube_1 2 Cube_2 3 Cube_3 Coordinate value Indicate #Position in the first line of the file. Describe X, Y, Z coordinate values one line at a time. Example: Line number Coordinate value description 1 #Position 2 469.38,-58.847,130 3 178.74,-70.421,130 4 146.97,-26.89,131.97 -&nbspOperation Method (Find Entities Tab)&nbsp- &nbspFrom the list of options, check the entities to search. &nbspEnter ID or name in the search field. &nbspClick Search button to search and select.
