# ADVC_STRUCT_TIME_STEP

ADVC_STRUCT_TIME_STEP

Description​

A data type uses to control parameters of ADVC Struct Time Step

Attributes​

iFixedOrAuto​

An Integer specifying fixed or auto.

The default value is 0.

iNumOfInc​

An Integer specifying number of increasement.

The default value is 1.

dMaxTime​

A Double specifying maximum time.

The default value is 1.0.

dMaxDt​

A Double specifying maximum dt.

The default value is DFLT_DBL.

dMinDt​

A Double specifying minimum dt.

The default value is DFLT_DBL.

iLoadType​

An Integer specifying load type.

The default value is -1.

iOutputLast​

An Integer specifying output last.

The default value is -1.

iOutputInterval​

An Integer specifying output interval.

The default value is DFLT_INT.

iRestartLast​

An Integer specifying restart last.

The default value is -1.

iRestartInterval​

An Integer specifying restart interval.

The default value is DFLT_INT.

dOutputTimeInterval​

A Double specifying output time interval.

The default value is DFLT_DBL.
