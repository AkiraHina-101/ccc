# Local Settings Model

Local Settings Model Local Settings Model Set the mesh size for the whole model faces in the specified space Mesh Parameters Name Set the mesh control name. Space Meshing Average Set the average size of the element Minimum Set the minimum size of the element. Maximum Set the maximum size of the element. Body Type Specify the spatial shape. Cube Specify the origin position and the length in each axis direction to select the entities in rectangular space. Spheroid Specify the origin position, Major Point and Minor Point in each axis direction to select the entities in spheroid space. Enclose Selects the faces that are completely covered by space shape. Preview Preview Preview the spatial shape by selecting the user desired color for spatial shape and face.
