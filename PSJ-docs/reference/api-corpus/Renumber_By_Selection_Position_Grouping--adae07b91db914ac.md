# Renumber | By Selection | Position Grouping

Renumber | By Selection | Position Grouping Renumber | By Selection | Position Grouping This section describes the rules for renumbering with coordinate values. In the case of renumbering in coordinate values, renumbering is performed in ascending order of the coordinate system. At this time, the positions of entities are grouped by the tolerance distance. If multiple entities are included within the tolerance distance, they will be renumbered in the original ID order. An example of node ID renumbering for 1 axis and 2 axes is shown.
