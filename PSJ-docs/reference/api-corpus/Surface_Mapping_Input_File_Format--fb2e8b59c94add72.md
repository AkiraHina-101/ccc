# Surface Mapping Input File Format

Surface Mapping Input File Format Surface Mapping Input File Format Indicate the file format of fluid file for surface mapping. Fluent (extension: .dat) Data output from Fluent. The first line is the title line, which describes what type of data is listed in each column. Data is separated by commas and spaces are ignored. From the keyword written in the title line, which condition is described is judged, and the tag is automatically set. If the conditions are the same and different title line keywords are listed, only the later keywords will be read. Title line keyword Condition pressure Pressure dynamic-pressure absolute-pressure total-pressure temperature Temperature wall-temp-out-surf heat-flux Heat flux heat-transfer-coef Temperature coefficient heat-transfer-coef-wall Star CD (extension: .dat / .txt) Data output from the Star CD. There is no title line. From the left column, ID, X coordinate value, Y coordinate value, Z coordinate value, Column1 value, Column2 value, ... and so on. Data is separated by spaces, and each data is separated by one or more single-byte spaces. CSV (extension: .csv) Data output from the Mapping function of TSV-Post / Jupiter-Post. Only surface convection can be used. There is no title line. Data are separated by commas and fixed in order of node, X, Y, Z, coefficient, temperature from left column. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
