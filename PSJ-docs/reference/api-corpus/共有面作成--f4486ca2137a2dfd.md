# 共有面作成

共有面作成 共有面作成 複数パーツのアセンブリモデルに対し、パーツ間に共有面を作成します。共有面化する為に、パーツ間のフェースをペアとして自動抽出し、フェースペア単位で共有面を作成します。 共有面を作成すると、グループウインドウの共有面作成にフェースペアのグループを作成します。 合わせ面検索 トレランス フェースペアを抽出するためのパーツ間の距離を入力します。 入力した距離以内にあるパーツ間のフェースを抽出し、フェースペアを作成します。 検索 フェースペアの抽出を行います。 合わせ面数/共有面数 検索ボタンで抽出したフェースペア数を表示します。 適用ボタンをクリックし共有面を作成した場合に、オプション名が共有面に変更します。作成した共有面の数を表示します。 検索結果/共有面 検索ボタンで抽出したフェースペアの一覧表示をします。 適用ボタンをクリックし共有面を作成した場合に、オプション名が共有面に変更します。 作成した共有面の一覧を表示します。 No. 検索した順に通し番号が振られます。番号の先頭にチェックボックスがあり、チェックが入っているフェースペアに共有面を作成します。 検索結果 フェースペアの一覧を表示します。 すべて選択 No.に表示しているチェックボックスにチェックを入れます。 すべて選択解除 No.に表示しているチェックボックスのチェックを外します。 共有面作成 エッジを結合 チェックを入れた場合に、共有面作成後のエッジ分割を防ぎます。 選択フィルター ボックスに入力した文字列で、合わせ面候補リストをフィルタリング表示します。 オン ボックスに入力した文字列を含むペアをリストに表示します。 オフ ボックスに入力した文字列を含まないペアをリストに表示します。 選択 フィルタリングを実行します。 リセット フィルタリングを解除します。 -&nbsp操作手順(モデルを対象に共有面を作成する場合)&nbsp- 必要に応じてトレランスの値をデフォルト値から変更します。 検索ボタンをクックします。 フェースペアの抽出結果がリスト表示されます。 リストの各フェースペアをクリックすると、モデル上の該当するフェースが色付きで表示されます。 共有面作成を行わないフェースペアがある場合は、チェックボックスを外します。 適用/OKボタンをクリックします。 -&nbsp操作手順(複数パーツを対象に共有面を作成する場合)&nbsp- 対象のパーツを複数選択します。 必要に応じてトレランスの値をデフォルト値から変更します。 検索ボタンをクックします。 フェースペアの抽出結果がリスト表示されます。 リストの各フェースペアをクリックすると、モデル上の該当するフェースが色付きで表示されます。 共有面作成を行わないフェースペアがある場合は、チェックボックスを外します。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
