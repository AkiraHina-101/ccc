# Perpendicular Line of Edge

Perpendicular Line of Edge a.no-uline {text-decoration:none} Perpendicular Line of Edge Create a line perpendicular to the two selected nodes in the selected face. Option Offset &nbsp;&nbsp;&nbsp;Enter the offset from the vertical. The first node selected is the base point. Break Face &nbsp;&nbsp;&nbsp;Break the face. -&nbspOperating Procedure&nbsp- &nbsp;Press the face button and select the face to be imprinted from the screen. Multiple face selections are possible. &nbsp;Press the node button and select 2 nodes in order from the screen to determine the direction. The first node is the origin of the offset amount. The imprint line is defined perpendicular to this direction. &nbsp;Enter the amount of offset from the vertical direction in Offset. &nbsp;Clear the Break Face check box if necessary. In this case, the imprinted face is not divided from the original face. &nbsp;Click the Apply / OK button. ※The target faces are flat and cylindrical. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
