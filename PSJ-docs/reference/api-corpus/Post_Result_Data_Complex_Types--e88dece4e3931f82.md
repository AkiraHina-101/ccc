# Post Result Data Complex Types

Post Result Data Complex Types

これは、ポスト結果データの複素型を表す列挙型です。

 | ID | ポスト結果データの複素型 | 説明

 | 0 | JPT.PostResultDataComplex.POST_COMPLEX_UNKNOWN | 未定義の複素値。

 | 1 | JPT.PostResultDataComplex.POST_COMPLEX_REAL | 実数結果を表示します。

 | 2 | JPT.PostResultDataComplex.POST_COMPLEX_IMG | 虚数結果を表示します。

 | 4 | JPT.PostResultDataComplex.POST_COMPLEX_AMP | 大きさの結果を表示します。

 | 8 | JPT.PostResultDataComplex.POST_COMPLEX_PHASE | 位相の結果を表示します。

 | 16 | JPT.PostResultDataComplex.POST_COMPLEX_PHASE_ANGLE | 特定の位相角で結果を表示します。

 | 32 | JPT.PostResultDataComplex.POST_COMPLEX_AMP_AND_PHASE | 特定の大きさと位相角で結果を表示します。
