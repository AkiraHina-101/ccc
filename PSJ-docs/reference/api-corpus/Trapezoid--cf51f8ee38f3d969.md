# Trapezoid

Trapezoid Trapezoid Create a trapezoid body. Part Properties Part Name Enter the name of the trapezoid body to be created. Trapezoid Local Coordinates Select any of the coordinate system. Circle Segment When checked, it creates the input vertices in Radius R (radius) Origin-X,Y,Z Specify the origin coordinates. Length in X(Top) Enter the length of the X-axis direction (Top). Length in X(Bottom) Enter the length of the X-axis direction (Bottom). Length in Y, Z Enter the length of the each of the Y, Z-axis direction. Radius If you check the Circle Segment, enter the radius.
