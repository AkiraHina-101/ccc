# ADVC_LOAD_NODE

ADVC_LOAD_NODE

説明​

ADVC Load Nodeのパラメータを制御するために使用されるデータ型です。

属性​

id_​

指定する ID です。

デフォルト値は0です。

modify_id​

指定する MODIFY_ID です。

デフォルト値は0です。

cr​

指定する Cursor です。

デフォルト値はNoneです。

crModify​

変更を指定する Cursor です。

デフォルト値はNoneです。

flag​

指定する FLAG です。

デフォルト値は1です。

shrink​

指定する SHRINK です。

デフォルト値は False です。

interference​

指定する INTERFERENCE です。

デフォルト値はDFLT_DBLです。

stabilized​

指定する STABILIZED です。

デフォルト値は0です。

residual_factor​

指定する RESIDUAL_FACTOR です。

デフォルト値はDFLT_DBLです。

effective_dist​

指定する EFFECTIVE_DIST です。

デフォルト値はDFLT_DBLです。

type_​

指定する TYPE です。

デフォルト値は0です。

cn​

指定する CN です。

デフォルト値はDFLT_DBLです。
