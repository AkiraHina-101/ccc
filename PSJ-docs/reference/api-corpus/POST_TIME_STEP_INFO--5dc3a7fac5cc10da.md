# POST_TIME_STEP_INFO

POST_TIME_STEP_INFO

Description​

A data type uses to define the information of post time step.

Attributes​

iMode​

An Integer specifying the using mode.

The default value is DFLT_INT.

dTime​

A Double specifying the value of time.

The default value is FLT_MAX.

dFrequency​

A Double specifying the frequency value.

The default value is FLT_MAX.

iBaseAnalysisType​

An Integer specifying the base analysis type.

The default value is 0.

strResultSetName​

A String specifying the result set name.

The default value is "".
