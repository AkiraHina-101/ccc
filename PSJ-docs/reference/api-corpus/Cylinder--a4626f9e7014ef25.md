# Cylinder

Cylinder Cylinder Create a cylindrical body. Part Properties Part Name Enter the name of the cylindrical body to be created. Cylinder Local Coordinates Select any of the coordinate system. Hollow Cylinder When checked, it creates a hollow shape. Tapered When checked, it creates a cylindrical shape in a tapered form. Origin-X,Y,Z Specify the origin coordinates. Inner Radius Enter the inner radius of the cylindrical body. Outer Radius Enter the outer radius of the cylindrical body. Inner Radius2 Enter the inner radius of the lower side of cylindrical body. (For Taper only) Outer Radius2 Enter the outer radius of the lower side of cylindrical body. (For Taper only) Height Enter the height of the cylindrical body. Number of Nodes in Circle Enter the number of nodes to be generated on the arc.
