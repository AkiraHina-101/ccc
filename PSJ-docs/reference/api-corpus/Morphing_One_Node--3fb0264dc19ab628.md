# Morphing | One Node

Morphing | One Node a.no-uline {text-decoration:none} Morphing | One Node Perform mesh deformation (morphing). While moving the selected node, move smoothly the nodes within the specified range from the selected node. It is used when changing the board thickness. ※After the morphing function is executed, the mesh is trimmed with the partial remeshing function. Parameters Strong Effect Distance &nbsp;&nbsp;&nbsp;Specify the range that is strongly affected by the movement of the selected entity as a distance. The nodes included in this range are moved by the distance specified by Move Distance. Weak Effect Distance &nbsp;&nbsp;&nbsp;Specify the range affected by the movement of the selected entity as a distance. The amount of movement of the nodes included in this distance range is 0 &lt; Movement Amount &lt; Movement Distance, and decreases as the distance from the selected entity increases. Effect Range &nbsp;&nbsp;&nbsp;Specify how to set the Strong Effect Distance / Weak Effect Distance. Both Side Faces Center the selected entity and set it to be spherical. The effects of movement extend to all nodes in the model. Selected Faces Set to follow the face connected to the selected entity. Direction Type &nbsp;&nbsp;&nbsp;Specify the movement type. Offset Values Move in the specified direction. Normal Offset Move in the direction perpendicular to the surface of the mesh. ※In the case of 1 node and in the case of face, the moving direction of the corner part is different. Move Distance Coordinates &nbsp;&nbsp;&nbsp;(Direction type: Normal Offset) Specify the amount of movement in the direction of each axis. Move Distance &nbsp;&nbsp;&nbsp; (Direction type: Offset Values) Specify the movement amount. Options Show Influence Node &nbsp;&nbsp;&nbsp;Preview the moving node. Show Preview &nbsp;&nbsp;&nbsp;The amount of movement of each node to be moved is previewed with an arrow. -&nbsp;Operating Procedure&nbsp;- &nbsp;Select a node on the screen. The Influence nodes are previewed. &nbsp;Change the parameters to adjust the movement amount. &nbsp;If you want to see the actual movement amount, turn on Show Preview. &nbsp;Press the Apply or OK button to move the nodes. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
