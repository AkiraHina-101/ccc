# Macro Window

Macro Window Macro Window This window is used to display the script information during command execution. Mouse Operation The following list shows the mouse operations available in the Macro window. Mouse Operation Function Left mouse click Highlight the line. Press the Ctrl/Shift keys to perform a range selection. Double-click using left button Perform the macro line. Mouse wheel Scroll the window. Toolbar This toolbar is used for macro operation. Icon Name Description Macro Load Loads the macro file into the macro window. Macro Save Saves the macro file specified in the macro line in the macro window. Macro Record Records the operation in the macro window when ON. Macro Rewind Rewinds the playback position of the macro to the first line. Macro Play Executes all of the macro lines displayed in the macro window in order. Macro Next Executes each line o the macro. Macro Stop Stops the macro execution. Macro Tool Adjusts the run time interval during macro play. Shortcut Menu Each command can be used from the menu displayed by right-clicking the tree item. Command Content Select All Highlight all contents in the macro window. Copy Copy the highlighted macro lines to the clipboard. Paste Paste the content of the clipboard to the macro window. Clear Delete all contents in the macro window. Remove Selected Lines Remove all selected lines.
