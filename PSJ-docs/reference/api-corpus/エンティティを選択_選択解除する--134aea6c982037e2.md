# エンティティを選択/選択解除する

エンティティを選択/選択解除する

🎯 はじめに​

このチュートリアルでは、表示ビューでエンティティを選択または選択解除する方法を学びます：

選択エンティティを Part に変更します。

Part エンティティタイプとIDでエンティティを選択/選択解除します。

Part エンティティタイプのすべてのエンティティを選択/選択解除します。

選択エンティティを Face に変更し、Face エンティティタイプのすべてのエンティティを選択します。

現在選択されているすべてのエンティティの選択を解除します。

選択方法のエンティティタイプの例:

Part: JPT.SelectMethodType.SELMTD_BODY

Face: JPT.SelectMethodType.SELMTD_FACE

Edge: JPT.SelectMethodType.SELMTD_EDGE

Node: JPT.SelectMethodType.SELMTD_NODE

2D Element: JPT.SelectMethodType.SELMTD_ELEM

このチュートリアルでは、Part (Body) と Face エンティティを使用します。他のエンティティも同様の方法で使用できます。

📖 チュートリアル​

# 日本語のエンコーディング
# coding: cp932

# Python APIウィンドウのログメッセージをクリア
JPT.ClearLog()

# サンプルモデルを作成
Geometry.Part.Cube()
Geometry.Part.Cube(dlOrigin=[0.01, 0.0, 0.0], strName="Cube_2", iPartColor=6409934)

# モデルを表示ビューにフィット
JPT.ViewFitToModel()

# 選択エンティティを 'Part' に変更
JPT.SetSelectMethod(JPT.SelectMethodType.SELMTD_BODY)

########## エンティティのタイプとIDで選択/選択解除 ##########

# ID 1の 'Part' エンティティを選択/選択解除
# 選択モード: True, 選択解除モード: False
JPT.SelectionByID(JPT.DItemType.BODY, 1, True)
JPT.SelectionByID(JPT.DItemType.BODY, 1, False)

########## エンティティのタイプで選択/選択解除 ##########

# タイプが 'Part' のすべてのエンティティを選択/選択解除
# 選択モード: True, 選択解除モード: False
JPT.SelectionByType(JPT.DItemType.BODY, True)
JPT.SelectionByType(JPT.DItemType.BODY, False)

# 選択エンティティを 'Face' に変更
# タイプが 'Face' のすべてのエンティティを選択
JPT.SetSelectMethod(JPT.SelectMethodType.SELMTD_FACE)
JPT.SelectionByType(JPT.DItemType.FACE, True)

# 現在選択されているすべてのエンティティの選択を解除
JPT.ClearAllSelection()
