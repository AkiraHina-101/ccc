# Document

Document

Description​

This is an instance of a Document class, represents Document information in Jupiter.

Properties​

 | Attribute | Description

 | docName | Name of Document.
The return value is Name of active Document (string).

 | docID | ID of Document.
The return value is ID of active Document (string).

 | docType | Type of Document.
The return value is DocPre if active Document is Pre Document,
 DocPost if Post Document and DocNone if none of DocPre or DocPost is specified.

 | docPath | Path of Document.
The return value is Path of active Document (string).
 If active Document does not have specific path, Undefined will be the return value
