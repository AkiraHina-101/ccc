# CADトリム

CADトリム CADトリム このコマンドでは、CAD形状のファセット（三角形パッチ形状）の数を削減することができます。 ＊JPT-Preでは、ファセットは、メッシング前のモデルの三角形一次要素と同義です。 （表面メッシュがきれいに作成できないとき、ファセットの数が多いためにアスペクト比が極大なファセットが存在することが原因の場合があります。そのような場合、本機能をお試し下さい。） 属性 トリムサイズ 削減するファセットの最大サイズを入力します。 トリム角度 削減するファセットの最大角度を入力します。 モデルの詳細 Tris要素の数 現在のファセット数（三角形要素数）が表示されます。 任意点の数 現在の点の数（節点数）が表示されます。 -&nbsp操作手順&nbsp- ファセット数を削減するパーツかフェースを選択します。 トリムサイズとトリム角度に削減するファセットの範囲を入力します。 適用/OKボタンをクリックします。ファセットが削減され、Tris要素の数と任意点の数が変化します。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
