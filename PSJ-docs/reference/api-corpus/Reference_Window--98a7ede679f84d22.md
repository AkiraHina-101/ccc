# Reference Window

Reference Window Reference Window Display the structure of the original CAD model in tree format after meshing the CAD model. Control Menu Adjust the display of the tree. Icon Name Description Clear Selection Clear all selected tree items. Expand All Expand all subtrees. Collapse All Collapse all subtrees. Toggle Sort Sort the part in order by name or ID. Show Both Display the overlapped mesh and reference Show Mesh Display the mesh of the currently displayed parts. Show Reference Display the reference of the currently displayed parts. Tree View Display the structure of CAD parts in tree format. Shortcut menu Right-click on any item in reference window to display the shortcut commands list. Execute the command by clicking on the command. Menu Content Select Select the reference of the part under the highlighted item. Hide Hide the reference of the part under the highlighted item. Hide Only Hide only the highlighted part item reference and display all references for other parts. Show Display the reference of the highlighted part item. Show Only Hide the reference of the parts other than the highlighted part item. Show All Display all references of parts in the model. Hide All Hide all references of parts in the model.B Invert Hide/Show Reverse the display / non-display state of parts reference in the model. Shortcut key list Shortcut key gives quick access to some of the functions through keyboard keys. Shortcut key Function Up and down arrow keys Move the highlight of tree item . F Fit the selected parts to the screen. Fit the entire model to the screen if parts are not selected. E Deselect the selected entity Ctrl+Mouse left click Highlight multiple tree items. Shift+Mouse left click Highlight multiple consecutive tree items.
