# STEADY_STATIC

STEADY_STATIC

Description​

A data type uses to control parameters of Steady Static

Attributes​

bSteadyStaticMemorySave​

A Boolean enable/disable steady static memory save.

The default value is False.

bSteadyStaticOutputHeatFlux​

A Boolean enable/disable steady static output heat flux.

The default value is False.

bSteadyStaticOutputTemperature​

A Boolean enable/disable steady static output temperature.

The default value is False.

bPivotsCheck​

A Boolean enable/disable pivots check.

The default value is True.

bSteadyStaticSinglePrecision​

A Boolean enable/disable steady static single precision.

The default value is False.

dSteadyStaticMultiplier​

A Double specifying steady static multiplier.

The default value is 0.0.

dSteadyStaticTemperatureDifference​

A Double specifying steady static temperature difference.

The default value is 0.0.

dSteadyStaticToleranceLevel​

A Double specifying steady static tolerance level.

The default value is 0.0.

iAdaptiveDescent​

An Integer specifying adaptive descent.

The default value is 0.

iSteadyStaticEquationSolver​

An Integer specifying steady static equation solver.

The default value is 0.
