# PostExportGeom()

PostExportGeom()

Description​

Export deformed shape by Post deformation as stl files.

Syntax​

PostExportGeom(string folder, bool bUseUnit)

Inputs​

1. string ​

Export file path.

2. bool ​

Use document unit.

Return Code​

"1": Succeeded.

"0": Failed.

Sample Code​

PostExportGeom("C:/Users/USERNAME/Desktop/temp", 1)
