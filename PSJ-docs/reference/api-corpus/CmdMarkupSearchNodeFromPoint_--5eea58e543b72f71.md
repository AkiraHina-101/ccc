# CmdMarkupSearchNodeFromPoint()

CmdMarkupSearchNodeFromPoint()

説明​

指定した位置に最も近い節点を検索し、ノートをその節点に置きます。

構文​

CmdMarkupSearchNodeFromPoint(double x, double y, double z)

入力​

1. double​

検索ポイントのX位置。

2. double​

検索ポイントのY位置。

3. double​

検索ポイントのZ位置。

戻り値​

1. bool​

成功（1）または失敗（0）。

サンプルコード​

CmdMarkupSearchNodeFromPoint(0.000000, 0.000000, 0.000000)
>> 1
