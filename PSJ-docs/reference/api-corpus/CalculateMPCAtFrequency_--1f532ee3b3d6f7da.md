# CalculateMPCAtFrequency()

CalculateMPCAtFrequency()

説明​

モデル参加係数ダイアログで特定の周波数のMPC結果を表示します。

構文​

CalculateMPCAtFrequency(cursor crResponse, double dFrequency)

入力​

1. cursor​

MPCを計算する応答を指定するカーソルです。

2. double​

MPCを計算する周波数を指定するダブルです。

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

CalculateMPCAtFrequency(0:0, 0.0)
