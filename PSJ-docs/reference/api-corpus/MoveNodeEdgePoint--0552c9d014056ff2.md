# MoveNodeEdgePoint

MoveNodeEdgePoint MoveNodeEdgePoint Description Move node(s) to an Edge Point position Syntax MoveNodeEdgePoint(double x, double y, double z, int[] node_list) Inputs double x: 1st coordinate of the point where to move the node. double y: 2nd coordinate of the point where to move the node. double z: 3rd coordinate of the point where to move the node. int[] List with the nodes to move Return Code 1 Succeeded 0 Failed Sample Code MoveNodeEdgePoint(0.00406953, 0.01, 0.01, [454])
