# SPACE_MESH

SPACE_MESH

Description​

A data type uses to control parameters of Space Mesh

Attributes​

iBodyType​

An Integer specifying body type.

The default value is 0.

bEnclosed​

A Boolean enable/disable enclosed.

The default value is False.

vOrigin​

A V_ORIGIN specifying origin.

The default value is 0.0.

vCenterPt​

A V_CENTER_PT specifying center pt.

The default value is 0.0.

vLength​

A V_LENGTH specifying length.

The default value is 0.01.

vAxisPt1​

A V_AXIS_PT1 specifying axis pt1.

The default value is 0.0.

vAxisPt2​

A V_AXIS_PT2 specifying axis pt2.

The default value is 0.0.

dMaxElemSize​

A Double specifying maximum elem size.

The default value is DFLT_DBL.
