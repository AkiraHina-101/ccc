# Tab Item

Tab Item Tab Item タブコンテナー内にタブを作成します。 &nbsp;&nbsp;&nbsp;作成イメージ図： &nbsp;&nbsp;&nbsp;&nbsp※Tab ItemはTab Controlとセットで使用します。 Name &nbsp;&nbsp;&nbsp;Tab Itemコンポーネント名を入力します。 Text &nbsp;&nbsp;&nbsp;タブのタイトルを入力します。 Orientation &nbsp;&nbsp;&nbsp;タブアイテムの並び方を指定します。 Horizontal &nbsp;:&nbsp;横並びにします。 Vertical &nbsp;:&nbsp;縦並びにします。
