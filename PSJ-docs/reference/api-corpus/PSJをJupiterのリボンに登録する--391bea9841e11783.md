# PSJをJupiterのリボンに登録する

PSJをJupiterのリボンに登録する

🎯 はじめに​

このチュートリアルでは、PSJをJupiterのリボンに組み込む方法を学びます。内蔵機能と同様に登録します。

アイコン付きのPSJファイルをカスタマイズされたリボンにボタンとして追加します。

区切り付きのPSJ関数のカスタマイズリボングループを作成します。

📖 チュートリアル​

PSJ-Commandカスタムフォルダ（設定 > パス設定 > PSJコマンド）で、作成したいリボン名として新しいフォルダを作成します。

作成したフォルダに、作成した.pyファイルをコピー（または置き換え）します。

アイコンが必要な場合は、.icoファイルを作成し、このリボンフォルダにコピー（または置き換え）します。
.icoファイルの名前は.pyファイルの名前と同じである必要があります。

2つ目のフォルダがない場合、リボン名がグループ名として使用され、リボンの最初の項目に配置されます。

以下のルールを使用して、PSJ関数のカスタマイズリボングループ（区切り付き）をさらに作成できます：

最初のフォルダ：リボン名（フォルダ名をリボン名として使用し、空白を受け入れる）

2つ目のフォルダ：グループ名（フォルダ名をグループ名として使用し、空白を受け入れる）

3つ目のフォルダ：関数名（Pythonファイル名を関数名として使用し、空白を受け入れる）

関数は番号プレフィックスを使用して並べ替えることができますが、同じ文字数である必要があります。
