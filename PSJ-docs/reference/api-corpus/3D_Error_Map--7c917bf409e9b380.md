# 3D Error Map

3D Error Map 3D Error Map Measure the surface error of two parts (target and reference). In addition to the contour view, user can create nodal groups (3D Error Map) for each surface error. The main applications to be the one of following: Measure the surface error/difference between mesh and CAD. For example, if a fillet is lost due to meshing, the stiffness will change. This feature allows you to measure the surface error before analysis and correct it in advance. Measure the surface error between the imaging data and the CAD/mesh. This function allows you to check the accuracy of reverse engineering results. Selection List Measure Part: Parts to be measured (Reference parts cannot be selected). Criterion Part: Reference parts (Both ordinary parts and reference parts can be selected). Measurement Corner Measure only the surface error of the corner nodes. Corner + Mid Measure the surface error of both corner nodes and middle nodes. Contour Num. Digits Specify the number of decimal places of the surface error to be displayed. Num. Division Specify the number of contour divisions. Max/Min Specify the maximum and minimum contour values. Show/Hide(Update) Switch between the display/non-display contour. This option is used to update the contour division number and the contour range. Group Num. Digits Specify the number of decimal of the surface error distance to create a group. Max/Min Specify the maximum and minimum value of the surface error to be created in a group. Create Group(Update) Create (or update) nodal groups in a dedicated group tree. -&nbspOperating Procedure (Error Calculation)&nbsp- Select a Measure part. Select a Criterion part. Click Apply. The error of the surface nodes of the measurement part is calculated in memory. Show/Hide (Update) and Create Group (Update) buttons will be enabled. -&nbspOperating Procedure (Contour Display *Available after Surface Error Calculation)&nbsp- Enter the parameters for the Contour. Click on Show/Hide (Update) button. The contour will be shown/hidden (updated). -&nbspOperating Procedure (Nodal Group Creation *Available after Surface Error Calculation)&nbsp- Enter the parameters for the Group. Click Create Group (Update) button. The nodal groups for each surface error are created (or updated). -&nbspSpecial Notes&nbsp- If there is no reference mesh in the search range, "1.7976931348623158e+308" will be set as the error value.
