# ユニバーサルファイル(Universal Files)

ユニバーサルファイル(Universal Files) ユニバーサルファイル(Universal Files) 選択したパーツ(Part)をユニバーサルフォーマットで出力します。 2D要素は三角形要素・四角形要素、3D要素は四面体要素・六面体要素をサポートしています。 選択リスト パーツ(Part)：ユニバーサルフォーマットで出力するパーツ（複数パーツ対応） -&nbsp操作手順&nbsp- 出力したいパーツ(Part)を選択します。 適用(Apply)またはOKボタンをクリックします。 ファイルパスとファイル名を入力して保存します。 -&nbsp各要素の節点順序&nbsp- 三角形一次要素 三角形二次要素 四角形一次要素 四角形二次要素 四面体一次要素 四面体二次要素 六面体一次要素 六面体二次要素 -&nbsp特記事項&nbsp- ユニバーサルフォーマット有限要素の節点順序に関する正式な仕様はありません。一部のソフトウェアで採用されている節点順序では、Jupiterや他のソフトとは異なり、コーナー節点IDに中間節点IDが挟まれるケースもございます。
