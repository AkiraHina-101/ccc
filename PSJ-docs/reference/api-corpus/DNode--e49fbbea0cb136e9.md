# DNode

DNode

Description​

This is an instance of a DNode class, represents a Node inside Jupiter.

Properties​

 | Attribute | Description

 | isFloating | Determine if the Node is a floating Node or not.
 The return value is True if it is a floating Node, False if not.

 | typeID | Type ID of the Node (ID = 10).
The return value is an Int notation of DItem Types (int).

 | id | External ID of the Node.
ID can be duplicated, but not recommended.
ID can be changed using the renumbering function.
The return value is ID (int).

 | pos | Position coordinate of the Node.
The return value is TVector3d.
