# Perpendicular Cylinder Line

Options Method &nbsp;&nbsp;&nbsp;Select how to specify the Imprint Line. Center Angle &nbsp;:&nbsp;Enter the angle at the cylindrical center of a perpendicular position. First selected Node will be the origin of the angle. Arc length &nbsp;:&nbsp;Enter the distance on the circumference of a perpendicular position. The first Node will be the base point. Imprint line is created along the axial direction of the cylindrical surface. &nbsp;Enter Offset amount at an angle or distance in the length / angle Offset. &nbsp;Turn on the opposite side check boxes as needed.
