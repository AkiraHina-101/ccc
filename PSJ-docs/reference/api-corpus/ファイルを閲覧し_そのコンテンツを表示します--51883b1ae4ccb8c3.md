ファイルを閲覧し、そのコンテンツを表示します

🎯 導入​

このチュートリアルでは、使用方法を学びます dlg.add_browser() ファイルを選択し、選択したファイルのコンテンツを内部に表示するには RichEditCtrl:

開いたファイル/フォルダーとaを作成します RichEditCtrl.

ファイルのコンテンツをに表示します RichEditCtrl ユーザーがファイルを選択した後.

📖 チュートリアル​

# 日本語のエンコーディング
# コーディング: cp932

from pyjdg import *

def set_to_rich_text(dlg, path_list):
    write_to_rich_text = ""
    for path in path_list:
        write_to_rich_text += path + "\n"
    dlg.set_item_text(name='selected_files',text=write_to_rich_text)

def main():
    dlg=JDGCreator(title="BrowserDemo",resizable=True,validation=True)
    dlg.add_browser(name="select_files",mode="file",file_filter="All Files(*.*)",
        multisel=True,layout="Window")
    dlg.add_richeditbox(name="selected_files",text="",width=200,height=200,layout="Window")
    dlg.add_label(name="Label3",text="ブラウザは、2つのパラメーターを持つ関数を受け入れます。 " \
        "1つはDLG、もう1つは文字列リストで、選択したファイルを返します",width=600,layout="Window")
    dlg.add_hlayout(name="footer",layout="Window")
    dlg.add_space(orientation="horizontal",layout="footer")
    dlg.add_button(name="ButtonOk",text="わかりました",layout="footer")
    dlg.add_button(name="ButtonCancel",text="キャンセル",layout="footer")
    dlg.add_space(orientation="horizontal",layout="footer")
    dlg.generate_window()
    dlg.on_browse(name="select_files",callfunc=set_to_rich_text)

if __name__=='__main__':
    main()
