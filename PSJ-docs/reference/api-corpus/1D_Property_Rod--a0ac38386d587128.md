# 1D Property Rod

1D Property Rod 1D Property Rod 1D Property Rod Dialog box Create a property data of one-dimensional Rod element. Name Set the name of the property. Property ID Enter the ID of the property. Property ID is entered so as not to overlap in the model. ROD Material Specify the material properties. Section Select from an existing element characteristic list. Area Enter the value of the cross-sectional area. Torsional Constant Enter the torsional constant. Torsional Stress Coefficient Enter the torsional stress factor. Non-structural Mass Enter the non-structural mass. Input Unit Length Select the unit of length.
