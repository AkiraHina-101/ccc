# スイープ - 円筒

スイープ - 円筒 スイープ - 円筒 選択した円弧エッジをスイープして、管状フェースを作成します。 選択リスト エッジ：スイープするエッジ 作成タイプ 作成するフェースの2D要素を選択します。 Tri3 &nbsp;:&nbsp;三角要素で作成します。 Quad4 &nbsp;:&nbsp;四辺形要素で作成します。 長さ 作成するフェースの長さを入力します。 方向 作成するフェースの方向を変更します。 メッシュサイズ（軸方向） 作成するフェースの軸方向のメッシュサイズを入力します。 オプション 新規作成 フェースを新規パーツとして作成します。 作成された新規パーツは、既存のパーツと選択されたエッジ上の節点で共有節点を持ち、デフォルト名は「Part_(パーツID)」となります。 -&nbsp操作手順&nbsp- エッジを選択します。 長さやメッシュサイズを入力します。 メインウィンドウに表示されるプレビューを確認して、必要に応じてスイープ方向を変更します。 適用/OKボタンをクリックします。 -&nbsp特記事項&nbsp- 選択するエッジは、ループしたエッジの一部である必要があります。フェース作成不可の場合は、プレビューが表示されません。 複数のフェース作成には対応しておりません。フェース作成不可の場合は、プレビューが表示されません。 選択するエッジは、ループしていればきれいな円でなくてもフェース作成が可能です。
