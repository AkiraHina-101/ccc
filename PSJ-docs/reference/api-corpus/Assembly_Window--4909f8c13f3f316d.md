# Assembly Window

Assembly Window Assembly Window The Assembly window shows geometries and mesh models displayed in the Main window as a tree structure. If the imported CAD data includes a sub-tree, the sub-tree is displayed as a sub-assembly. Tree Control Menu This menu is used to adjust the tree display. Icon Name Description Clear selection Clear the selection of all selected tree items. Expand all Expand all subtrees. Collapse all Collapse all subtrees. Toggle Sort Sort the order of parts by name or ID. Show mesh / reference Overlay the mesh and reference. Display mesh and reference parts superimposed on the currently displayed mesh or reference. Show mesh Restore from mesh / reference simultaneous display or reference display to normal mesh part display. Only the mesh parts of the currently displayed mesh or reference are displayed. Show reference Only the reference of the displayed mesh part is displayed. Only the oldest reference part (usually CAD) of the currently displayed mesh or reference is displayed. Tree View The assembly/part structure and boundary constraint condition/property settings are displayed in a tree format. Boundary constraint condition/property settings are added as a sub-tree of the whole model and also as a sub-tree of the defined parts. Click each tree item with the left mouse button to focus on that item. The settings of the selected item will be displayed in the Property view. By clicking on an item and highlighting it, the entity you are configuring is now previewed on the main window. The command window when creating an item now opens in edit mode by double-clicking the item. When the command dialog is launched in edit mode, highlighting another tree item with mouse click or arrow keys now switches to the command window (edit mode) of the highlighted item. Icon Name Description Assembly The parent item of multiple parts and boundary condition/property. The model assembly is the parent item of the whole document. Only one model assembly exists in one document. An assembly can become a child assembly of other assemblies. CAD Part This item includes an imported solid part from the CAD data. CAD Part(Shell) This item includes an imported shell part from the CAD data. Mesh Part(Tri3) This item includes a first order triangular element. Mesh Part(Tri6) This item includes a second order triangular element. Mesh Part(Quad4) This item includes a first order quadrilateral element. Mesh Part(Quad8) This item includes a second order quadrilateral element. Mesh Part(Tet4) This item includes a first order tetrahedral element. Mesh Part(Tet10) This item includes a second order tetrahedral element. Mesh Part(Penta6) This item includes a first order pentahedral element. Mesh Part(Penta15) This item includes a second order pentahedral element. Mesh Part(Hex8) This item includes a first order hexahedral element. Mesh Part(Hex20) This item includes a second order hexahedral element. Reference Maintain the original geometry when the part is changed using a command. LBC This item is a parent of connections, boundary conditions, and properties. Property This item is a parent of property items. Property A property item. Material A material item. Shortcut menu Each command can be used from the menu displayed by right-clicking the tree item. Menu Content Select Select the highlighted item. Hide Hide the highlighted item. Hide Only Hide the highlighted part and show all other parts. Show Show the highlighted part. Show Only Show the highlighted part and hide all other parts. Show All Show all parts in the model. Hide All Hide all parts in the model. Invert Hide/Show Invert the hiding or showing of the parts in the model. Collapse under Part Collapse the tree under the part in the model. Cut Move the highlighted part from one assemby to another. Copy Copy the highlighted part from one assemby to another. Paste Move the cut/copied part to the hightlighted assembly. Rename Change the name of the highlighted part. Change Random Color Assign a random color to the highlighted item and a part within its sub-tree. Change Single Color Assign an arbitrary color to the highlighted item and parts within its sub-tree. Add To Reference Add the highlighted part to Reference. Restore Original Part Return the highlighted part after meshing to CAD using Reference. Remove Solid Mesh Delete the solid from the part after creating a solid mesh. Edit Change the setting values of the highlighted boundary constraint condition/property item. Set Transparency Change the transparency setting of the highlighted part. Delete Delete the highlighted item and the items within its sub-tree. Reassign Color Assign to the part color specified when setting the material / property. Property view You can change the color, hide or show details of the focused tree item in the tree view. --> When viewing All Parts: number of parts, number of nodes, number of elements, number of configuration entities, file information (Jupiter version that created the file) etc. FEM element column shows the number of elements for which material properties have been set. Jupiter element items column shows the number of all elements. When viewing a part item: ID, number of nodes, number of elements, number of configuration entities, information of mesh size, etc. When viewing a boundary condition item: Content of each boundary condition setting. In order to change the boundary condition setting, right click the tree view item to select the Edit command from the shortcut menu. Surface Colors: Change the color of the surface faces, mesh lines and edges of the focused part and the transparency of the part. Show/Hide: Toggle between showing and hiding faces, mesh lines and edges of the focused part. Section Colors: Change the colour of surface faces, mesh lines and edges of the section. Show/Hide: Enable/disable the display/hiding of cross sections, capping, section edges, section elements and mesh lines. Note 1) This option can be applied when the section ribbon option is activated. Note 2) Contour is only applicable when using Post mode. Shortcut Key List The following shortcut keys are available when the focus is on the assembly window. View operation Shortcut key Operation F2 Highlight a tree item and press a key to rename the item. F3 Highlight a tree item and press a key to execute "Edit" in the right-click menu. Up and down arrow keys Move the highlight of the tree item. F Fit the selected part to the screen. When parts are not selected, the entire model is fitted to the screen. E Clear selection of selected entities. A Execute a command when the command dialog is launched. Space Execute a command when the command dialog is launched. Ctrl＋Mouse left click Highlight multiple tree items. Ctrl＋Mouse left click & drag Highlight multiple consecutive tree items at multiple locations. Shift＋Mouse left click Highlight multiple consecutive tree items.
