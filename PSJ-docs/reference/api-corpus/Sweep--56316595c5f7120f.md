# Sweep

Sweep Layer Create a solid mesh by sweeping in the normal direction from surface meshes (Tri and Quad mesh). Layer Parameters Base Face Type Sweep the source face, to specify what will be the location for shape after the sweep. Bottom: Specified face will be the bottom surface, to create a sweep shape toward the front side Middle: Create a sweep shape on both sides around the specified face Top Specified: Specified face will be the top surface, to create a sweep shape toward the bottom side Layer Width Specify the thickness of the layer upon layer. Number of Layers Specify the number of layers. Layer Options Body Separation Specify the isolation / integration state for the part that was created. Merge: Integrate all the layers in one part Separate: Separate the layers in different parts Separate Front-Back: Specify each front side of the layer and the back side for layer, in different parts Interface Specify the processing for the created layer and the border of the selected face. None: Do not perform special processing. Keep Surface: Copy the selected face and create a new surface part. Merge: Merge the node between the layer part and the selected face. * If you select and run an entity that contains 2nd element, a warning will be displayed. Convert to primary element and execute. -&nbspOperating Procedure&nbsp- &nbspSelect the surface to sweep. &nbspSpecify the even thickness. &nbspSpecify the number of layers. &nbspSet up the parts for layer. &nbspClick the Apply or OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
