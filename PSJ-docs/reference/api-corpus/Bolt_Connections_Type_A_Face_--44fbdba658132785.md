# Bolt Connections Type A (Face)

Bolt Connections Type A (Face) Bolt Connections Type A (Face) This command is used to create RBE2 elements in a circle on the top and bottom faces of a bolt hole, and connect the center using Bar or RBE2 elements. Type A includes a Pre Tension option, which is used to create bolt models including bolt tension settings. The bar elements of the bolt axis are divided in the center position in order to define the bolt tension using MPC connections. Bolt Modeling RBE Name Enter the name of the RBE item to be created. Bar Name Enter the name of the Bar item to be created. Show Bolt Image Display the schematic view of the bolt. The bolt type to be created can be changed. Shaft Type &nbsp;&nbsp;&nbsp;Specify the connection method between RBE elements. Cbar &nbsp;:&nbsp;Connects RBEs using Cbar elements. RBE2 &nbsp;:&nbsp;Connects RBEs using RBE elements. Bar Property Specify the Bar element property used by the bolt to be created from existing properties. Plane Tolerance Specify the tolerance angle value for creating RBEs when the target face is not a flat surface. Max Height Specify the maximum length of the shaft part connecting the RBEs. Max Diameter Specify the maximum diameter of the bolt hole to be extracted. Min Diameter Specify the minimum diameter of the bolt hole to be extracted. Pre Tension Load Solver &nbsp;&nbsp;&nbsp;Specify the solver. All &nbsp;:&nbsp;Specify all solvers. Abaqus &nbsp;:&nbsp;Use the ABAQUS Pre Tension command. Value Enter the bolt tension load. Input Unit Specify the input unit system. Direction Specify the bolt tension direction.(All only) Coordinate Specify the coordinate system referenced by the bolt tension direction.(All only) Bolt Fix Length Maintain the amount of bolt tension. Top Rbe Slot Select this checkbox when the bolt hole is a slotted hole in order to create the bolt model in the center of the hole. Face Press the radio button when selecting the face on the top side. Display the IDs of the selected faces. Factor Specify the range for RBE creation assuming the hole diameter to be 1. Hole Diameter Specify the standard value for defining the range for RBE creation. （By default, the diameter of the selected edge is displayed.） RBE Diameter Define the range for RBE creation by specifying the diameter size. In case a factor is specified, the value is automatically reflected. ※In case a value is directly entered and Factor x Hole Diamter ≠ RBE diamter, the RBE diameter value is prioritized. Bottom Rbe Slot Select this checkbox when the bolt hole is a slotted hole in order to create the bolt model in the center of the hole. Face Press the radio button when selecting the face on the bottom side. Display the IDs of the selected faces. Factor Specify the range for RBE creation assuming the hole diameter to be 1. Hole Diameter Specify the standard value for defining the range for RBE creation. （By default, the diameter of the selected edge is displayed.） RBE Diameter Define the range for RBE creation by specifying the diameter size.
