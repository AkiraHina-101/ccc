# MeshEdit.RemoveSolidMesh()

MeshEdit.RemoveSolidMesh()

Description​

Remove Solid Mesh

Syntax​

MeshEdit.RemoveSolidMesh(crlParts=[], bConvFirst=False)

Ribbon: MeshEdit » RemoveSolidMesh

Inputs​

crlParts​

A List of Cursor specifying the part.

The default value is [].

bConvFirst​

A Boolean specifying the conv first.

The default value is False.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.RemoveSolidMesh(crlParts=[], bConvFirst=False)
