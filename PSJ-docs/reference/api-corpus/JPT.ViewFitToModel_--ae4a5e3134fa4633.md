# JPT.ViewFitToModel()

JPT.ViewFitToModel()

Description​

Change the view of the current model to fit with the Jupiter display window.

Syntax​

JPT.ViewFitToModel()

Macro: ViewFitToModel

Inputs​

This utility function does not require any input value.

Return Code​

This utility function does not have output value.

Sample Code​

JPT.ViewFitToModel()
