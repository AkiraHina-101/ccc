Description​

Syntax​

MeshCleanup.Manual3D.Equivalence(crlNodes=[], iMergeTowards=0)

Ribbon: MeshCleanup » Manual3D » Equivalence

Inputs​

crlNodes​

A List of Cursor specifying the node.

The default value is [].

iMergeTowards​

An Integer specifying the merge towards.

The default value is 0.

Return Code​

A String of 1 if success, or 0 if fail.
