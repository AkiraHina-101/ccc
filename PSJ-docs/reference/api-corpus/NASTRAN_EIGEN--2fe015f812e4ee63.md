# NASTRAN_EIGEN

NASTRAN_EIGEN

Description​

A data type uses to control parameters of Nastran Eigen

Attributes​

dStartFreq​

A Double specifying the starting frequency value.

The default value is DFLT_DBL.

dEndFreq​

A Double specifying the ending frequency value.

The default value is DFLT_DBL.

iNoOfModes​

A Double specifying the number of modes.

The default value is DFLT_DBL.
