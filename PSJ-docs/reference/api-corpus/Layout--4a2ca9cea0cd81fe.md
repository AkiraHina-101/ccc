# Layout

Layout

Create a layout to arrange components inside.

Preview dialog:

Parameters​

Name​

Enter name of the layout.

Orientation​

Specify position of components inside.

Horizontal : arrange the inside components horizontally

Vertical : arrange the inside components vertically

Margin​

Left : put a margin to the left of the Group Box. (in pixels)

Top : put a margin above the Group Box. (in pixels)

Right : put a margin to the right of the Group Box. (in pixels)

Bottom : put a margin below the Group Box. (in pixels)

Visible​

Specify whether to show/hide the created Layout.

Check On : Show

Check Off : Hide

API associated with​

dlg.add_layout : Add a Layout to the creating dialog.

dlg.add_hlayout : Add a horizontal Layout to the creating dialog.

dlg.add_vlayout : Add a vertical Layout to the creating dialog.

dlg.hide_layout : Hide the Layout and all of its children components inside.

dlg.show_layout : Show the Layout and all the children components inside.
