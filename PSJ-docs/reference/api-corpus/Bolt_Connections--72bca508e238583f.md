# Bolt Connections

Bolt Connections Bolt Connections Model the bolt for analysis. Creation Method Edge Select the edges to create. Face Select the face to create. There are four types for Bolt modelling i.e, Type A, Type B, Type C and Type D. Type A &nbsp;:&nbsp;On the upper and lower surfaces of the bolt holes create a RBE2 element in a circle, and then join the centre with the bar element or RBE2 elements. Type B &nbsp;:&nbsp;Creates a RBE2 element in a circle on the top surface of the bolt hole, places RBE2 on the lower end that combines side face for the bolt holes and then joins the centre with the bar element or RBE2 elements. Type C &nbsp;:&nbsp;Place the RBE2 or RBE3 element on the side surfaces of the bolt hole and then join the centre with the spring element or RBE2 elements. Type D &nbsp;:&nbsp;Join opposite surfaces with MPC within the specified range around the bolt holes. For the Type A and Type B there is a Pretension Option, you can create a bolt model and set a bolt tightening force.
