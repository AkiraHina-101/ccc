# MeshCleanup.Manual2D.Swap()

MeshCleanup.Manual2D.Swap()

Description​

Swap Element Edge

Syntax​

MeshCleanup.Manual2D.Swap(crplElemEdge=[])

Ribbon: MeshCleanup » Manual2D » Swap

Inputs​

crplElemEdge​

A Cursor Pair List specifying the element edge.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshCleanup.Manual2D.Swap(crplElemEdge=[])
