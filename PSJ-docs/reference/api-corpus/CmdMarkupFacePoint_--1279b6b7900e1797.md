# CmdMarkupFacePoint()

CmdMarkupFacePoint()

説明​

選択されたFacePointにノートを追加します。

構文​

CmdMarkupFacePoint([int Element, float xpos, float ypos, float zpos])

入力​

1-4のセットのリスト。

1. int​

示された位置が含まれる要素ID。

2. float​

ビューでのx位置（グローバル座標）。

3. float​

ビューでのy位置（グローバル座標）。

4. float​

ビューでのz位置（グローバル座標）。

戻り値​

なし。

サンプルコード​

CmdMarkupFacePoint([[2746, 7.959929, 4.940016, 10.000000]])
