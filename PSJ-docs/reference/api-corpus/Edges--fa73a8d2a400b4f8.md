# Edges

Edges Displacement CS Define the displacement coordinate system to the node. The output of the node result by this setting refers to the local coordinate system After the displacement coordinate system settings you should be able to see the coordinate system set to the node information that is output to the Output window. ※Behaviour depends on the solver. Coordinate System Select the coordinate system Group by DCS When you click the "Create Groups" button, the node that has been set to the current displacement coordinate system are grouped into each displacement coordinate system. Coloured Node by DCS When you click the ON / OFF button, the nodal displacement coordinate system is set to display / hide colour contour. -&nbspOperating Procedure&nbsp- &nbspYou have to create multiple local coordinate systems in advance. &nbspSelect the entity that contains the node you want to set the displacement coordinate system and then click the Apply button. &nbspIf the displacement coordinate system settings are to be checked by the colour contour: Click next to the ON/OFF button near Coloured Node by DCS. &nbspIf you want to ensure in a group the displacement coordinate system setting: Click group by DCS next to Create Groups button. Check the group mode as the node group is created for each displacement coordinate system setting. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
