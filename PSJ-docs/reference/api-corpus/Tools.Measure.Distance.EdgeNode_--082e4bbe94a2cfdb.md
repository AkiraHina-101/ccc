# Tools.Measure.Distance.EdgeNode()

Tools.Measure.Distance.EdgeNode()

Description​

Measure Distance From Node to Edge

Syntax​

Tools.Measure.Distance.EdgeNode(crEdge, crNode, iPrecision=6)

Ribbon: Tools » Measure » Distance » EdgeNode

Inputs​

crEdge​

A Cursor specifying the edge.

This is a required input.

crNode​

A Cursor specifying the node.

This is a required input.

iPrecision​

An Integer specifying the precision.

The default value is 6.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Tools.Measure.Distance.EdgeNode(crEdge, crNode, iPrecision=6)
