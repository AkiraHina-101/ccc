# Load Case

Load Case Load Case Load Case Dialog Box This command creates a load case that bundles loads and constraints. Load cases can be referenced when creating analysis solver input data. Name Enter the name of the load case to be created. ID Specify LOAD, SPC and MPC ID for Nastran. Coefficient Enter the load factor for Nastran that applies to the entire load case to be created. Used when multiplying the load by a factor. All Created Boundary Conditions List existing created loads and constraints. Use the checkboxes to make a selection. Selected Boundary Conditions List the loads and restraints used in the load case to be created. Enter a coefficient for each load. -&nbspOperating Procedure&nbsp- &nbspEnter the load case name to be created in Name. &nbspEnter a weighting factor for the factor if necessary (for Nastran). &nbspFrom the list of all created boundary conditions, select the Load and Constraint checkboxes to be placed in the load case. The selected condition is displayed in the selected boundary condition list. &nbspPress the Apply or OK button to create a load case. *The created load case is specified by Nastran output under "Loading / Boundary Conditions" or with the subcase option "LOAD". &nbsp;The LOAD card as shown below is output. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
