# Capture

Capture Capture This function is used to capture screen shots of the Main window of the currently displayed document. Copy to Clipboard Copy the screen shot of the Main window to the clipboard. To Image Save the screen shot of the Main window as an image file. Rectangular Capture Save the specified range of the Main window as an image file. -&nbspOperating Procedure (Copy to Clipboard)&nbsp- &nbsp;Click the Copy to Clipboard button in order to copy the screen shot of the Main window to the clipboard. &nbsp;Launch an image viewer or editing software and press the Ctrl+V key to paste the image. -&nbspOperating Procedure (To Image)&nbsp- &nbsp;Click the To Image button in order to open the File Save dialog. &nbsp;Specify the file format and save the file in an arbitrary folder. -&nbspOperating Procedure (Rectangular Capture)&nbsp- &nbsp;Click the Rectangular Capture button and click/drag within the Main window. The rectangular area defined by the mouse is specified as the target range for capturing. &nbsp;Launch an image viewer or editing software and press the Ctrl+V key to paste the image. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
