# Mesh Quality[Quad]

Mesh Quality[Quad] Mesh Quality&nbsp;-&nbsp;Manual Check&nbsp;[Quad] Make corrections to the surface of the Surface mesh (Quad4 / Quad8). Element Quality Metric ： It specifies the quality verification method. ※Please refer to the ＜definition of quality confirmation method＞ for each menu item. Cutoff Value Minimum ： It displays the minimum value of the defined check type. Maximum ： It displays the maximum value of the defined check type. Average ： It displays the maximum value of the defined check type. Num of Entities ： It displays the number of element type of the selected model. Display Condition ： Set the inequality for the defined value. Value ： Enter the settings of elements to be displayed. Num of Entities ： It displays the number of elements that are displayed. Bar Chart ： You can see a bar chart distribution of the defined check type. No. of Div. in X ： Set the X direction division number. No. of Div. in Y ： Set the Y direction division number. Auto Cleanup Cleanup ： You can automatically correct the element by pressing Cleanup button. Mode: select the cleanup mode from Standard or Aggressive. Cleanup process Standard Aggressive Allowable face normal angle change of neighboring elements 60 degree 90 degree Collapse elem edges on an edge No Yes Nonmanifold ： To check and fix non manifold. Refresh Show Model ： Replace the model display by pressing the Show Model button. Defualt Settings Save as Default ： Save the Mesh Statistics settings as default. -&nbspOperating Procedure&nbsp- &nbspSelect the body you want to check for element shape. &nbspSpecify the quality verification method. &nbspConfigure setting of elements to be displayed. &nbspPress the Apply or OK button. &nbspIf you want to return to the original model display, press the Show Model button. ※Auto Cleanup function can not modify all of the elements automatically. If certain elements can not be corrected automatically, you must manually modify the elements using the Manual Cleanup feature.
