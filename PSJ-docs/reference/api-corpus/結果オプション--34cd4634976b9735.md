# 結果オプション

結果オプション 結果オプション 結果表示に関する設定を行います。 アイコン 名称 説明 結果ビューア― 結果ビューアーダイアログを表示します。 一部コンター 選択したエンティティのみコンターを表示します。 アンロード モデルから解析結果を取り除きます。 コンター表示 コンターの表示/非表示を切り替えます。 中間節点使用 中間節点を使用する時に選択します。 ベクトル表示 メニューの選択で、ベクトルの表示/非表示を切り替えます。 円図表示 円図の表示/非表示を切り替えます。 ダイアグラム表示 ダイアグラムの表示/非表示を切り替えます。（1D解析時の結果表示時） 変形を表示 変形の表示/非表示を切り替えます。 最大/最小表示 最大・最小値のラベルの表示/非表示を切り替えます。 現在表示されている要素に対して、最大値・最小値となる箇所にラベルを表示します。 （グループモードにした場合には、表示グループに対してラベルを表示します。） オリジナル表示 変形表示をしている際に、変形前の形状をモデルに重ねて表示します。 設定 結果設定ダイアログを開きます。 結果タイトル表示 結果タイトルの表示/非表示を切り替えます。 凡例表示 凡例の表示/非表示を切り替えます。
