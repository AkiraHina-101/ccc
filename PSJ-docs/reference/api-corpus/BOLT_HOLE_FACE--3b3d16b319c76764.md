# BOLT_HOLE_FACE

BOLT_HOLE_FACE

Description​

A data type uses to control parameters of bolt hole face.

Attributes​

crlMasterFaces​

A list of Cursor specifying master faces.

crlSlaveFaces​

A list of Cursor specifying slave faces.

dlCenterPoint​

A Double Vector specifying center point.

dlMasterPoint​

A Double Vector specifying center point.

dlSlavePoint​

A Double Vector specifying center point.

iBoltType​

An Int specifying Bolt Type.

0: Type A

1: Type B

2: Type C

3: Type D
