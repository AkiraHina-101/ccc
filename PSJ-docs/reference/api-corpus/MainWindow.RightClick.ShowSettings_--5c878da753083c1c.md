# MainWindow.RightClick.ShowSettings()

MainWindow.RightClick.ShowSettings()

Description​

Show Preferences settings.

Syntax​

MainWindow.RightClick.ShowSettings(...)

Macro: ShowSettings

Ribbon: MainWindow » RightClick » ShowSettings

Inputs​

This function does not require any input value.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MainWindow.RightClick.ShowSettings()
