# Alignment | Best Fit

Alignment | Best Fit Alignment | Best Fit Aligns selected parts with each other based on shape features. The ICP (Iterative closest point) method is used. This method finds the corresponding points between two point clouds and iteratively calculates them to minimize the error. Parameters Error The total difference in distance between nodes. The calculation is repeated until it is within this value. Max cycle The number of matrix calculation iterations. If too large, the calculation will take longer, but if too small, the values will not converge sufficiently and the positioning may be incomplete. Specify 1 or more. Algorighms Only "point to point" can be selected. Define the set of nodes contained in the selected faces/parts and move the part on the Dynamic Targets side so that the shapes calculated from the point sets of the Static and Dynamic targets match each other as closely as possible. -&nbspOperation (Parts selection)&nbsp- Click "Static Targets" in the Selection list. Then select the part to be moved. Click "Dynamic Targets" in the Selection list. Then select the part you want to moved. The Apply or OK button executes the function. "Dynamic Targets" moves to the nearest location to "Static Targets" along the feature of the shape. -&nbspOperation（Face Selection）&nbsp- Click "Static Targets" in the Selection list. Then select the faces on the part to be moved. Click "Dynamic Targets" in the Selection list. Then select the faces on the part you want to moved. The Apply or OK button executes the function. "Dynamic Targets" moves to the nearest location to "Static Targets" along the feature of the shape calculated from the nodes in seleted faces. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
