# JOB_ABAQUS_DATA

JOB_ABAQUS_DATA

Description​

A data type uses to control parameters of Job Abaqus Data

Attributes​

bRBE2toMPC​

A Boolean enable/disable r b e2to m p c.

The default value is False.

bRenameProcess​

A Boolean enable/disable rename process.

The default value is False.

iCodeType​

An Integer specifying code type.

The default value is 0.

iSurfDefType​

An Integer specifying surf def type.

The default value is 0.

iUnit​

An Integer specifying unit.

The default value is 0.

iWriteType​

An Integer specifying write type.

The default value is 0.

strDescription​

A String specifying description.

The default value is "".

strlUserText​

A List of String specifying user text.

The default value is ].

bExptNdEleGroups​

A Boolean enable/disable expt nd ele groups.

The default value is False.

bDeleteFloatingNodes​

A Boolean enable/disable delete floating nodes.

The default value is False.

bExptFaceElemGroups2Surface​

A Boolean enable/disable expt face elem groups2 surface.

The default value is False.

bLoadCase​

A Boolean enable/disable load case.

The default value is False.

bAutoAssignDummyProperty​

A Boolean enable/disable auto assign dummy property.

The default value is True.

crDummyMat​

A Cursor specifying dummy material.

The default value is None.
