# ToPost()

ToPost()

説明​

PreドキュメントをPostドキュメントに変換します。

構文​

ToPost(string docName, int[] options)

入力​

1. string​

変換する対象ドキュメントの名前です。

2. int []​

リストで指定された番号に対応するオプションがオンになります。

0: グループを引き継ぎます

1: 境界条件を引き継ぎます

2: 接続を引き継ぎます

3: ローカル座標を引き継ぎます

4: プロパティを引き継ぎます

戻り値​

なし。

サンプルコード​

ToPost("Jupiter1", [0, 1, 2, 3, 4])
