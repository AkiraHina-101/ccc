# NASTRAN_FREQUENCY

NASTRAN_FREQUENCY

Description​

A data type uses to Defines a set of frequencies to be used in the solution of frequency response problems by specification of a starting frequency, frequency increment, and the number of increments desired

Attributes​

dStartFrequency​

A Double specifying the first Frequency in set.

The default value is DFLT_DBL.

dIncrement​

A Double specifying the Frequency increment.

The default value is DFLT_DBL.

iNumberOfInc​

An Integer specifying the number of frequency increments.

The default value is DFLT_INT.
