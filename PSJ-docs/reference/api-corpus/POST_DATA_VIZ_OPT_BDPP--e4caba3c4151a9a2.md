# POST_DATA_VIZ_OPT_BDPP

POST_DATA_VIZ_OPT_BDPP

説明​

データ型は、FFT3Dを表示するための結果設定を行うために使用されます。

属性​

dLayerPointSize​

各層の変位点のサイズを指定する _Double_型。

デフォルト値は1.0です。

dLineWidth​

シリンダー形状の線の幅を指定する _Double_型。

デフォルト値は1.0です。

dPointSize​

点のサイズを指定する _Double_型。

デフォルト値は1.0です。

dDotDistance​

点の間の距離を指定する _Double_型。

デフォルト値は0.02です。
