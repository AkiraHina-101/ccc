# MPC Equation | Semi Auto

MPC Equation | Semi Auto MPC Equation | Semi Auto This function automatically creates the MPC between the nodes of the following distance tolerance. Semi Auto Name Enter the name to be registered. Parameters Coordinate Select the reference coordinate system. MPC Term Coef1(Slave) Enter the coefficients of the slave. DOF1(Slave) Choose the degree of freedom of the slave. Coef2(Master) Enter the coefficients of the master. DOF2(Master) Choose the degree of freedom of the master.
