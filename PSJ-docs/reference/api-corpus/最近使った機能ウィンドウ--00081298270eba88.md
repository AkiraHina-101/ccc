# 最近使った機能ウィンドウ

最近使った機能ウィンドウ 最近使った機能ウィンドウ 直近で使用したコマンドが表示されます。 表示されていないリボンで起動したコマンドに関しては×マークで表示されます。 具体例：Preドキュメント作業時にPost用コマンドのアイコンは×マークになります。 ショートカットメニュー一覧 マウス右クリックメニューで表示されるメニューから、各コマンドを使用します。 常に利用できるメニュー メニュー 内容 次機能予測を表示 これまでに使用されたコマンドの履歴から、次に使用する可能性が高いコマンドを予測して表示します。 最大アイコン数 選択された個数で、ウィンドウ内に表示させるコマンドのアイコンを表示します。 クリアー 履歴をすべて消去します。
