# MeshEdit.CreateNode.CenterOfSphere()

MeshEdit.CreateNode.CenterOfSphere()

Description​

Create node of center sphere

Syntax​

MeshEdit.CreateNode.CenterOfSphere(crlNodesOrFace=[], iNodeID=1)

Ribbon: MeshEdit » CreateNode » CenterOfSphere

Inputs​

crlNodesOrFace​

A List of Cursor specifying the node or face.

The default value is [].

iNodeID​

An Integer specifying the node ID.

The default value is 1.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.CreateNode.CenterOfSphere(crlNodesOrFace=[], iNodeID=1)
