# Material

Material Material Material Dialog Box Create material data that is referenced in the property data. Read from the material library, or you can create new ones. Search You can search for material by putting the string to the left for input box, and pressing the Search button. User Data Base It lists the material data that has been registered in the material database for use. It has the following features to list. [Double Click] You can edit an item. [Double Click：New] Allows you to create a new material data. [Double Click：Save] Permits you to store an item in the library. [Double Click：Delete] You can delete the item you have clicked. Library Database It lists the contents of the specified material library. You can register material data on the User database from the import in the right-click menu or drag and drop. It has the following features [Double-click] You can edit an item. [Right Click:Import] It will register material data to the User Database. ※Material not registered in the User Database can not be used. ※Specify from the default material library Home>Preference>Material Library. Library Path You can temporarily add material library. Select the library you want to add from the right edge of the folder icon. Material Dialog Box Create a material data that is referenced in the property data. Read from the material library, or you can create new. Name Enter the material name. Type Enter the material type name. (Any input) Standard Enter the material reference index. (Optional input) Material ID Enter the Material ID. You can not duplicate the material ID in the User Database list. Please select a non-overlapping id. Description Enter additional description of the material. (Optional input) Color The color set for the material. If there is no setting, black will be set. Used as the surface color of the part for certain features ( Reassign Colors , Property Report ). Structure, Thermal, Gasket, Fluid Pull-down Menu Each material items can be selected from the pull down menu to be used in structure, heat transfer, gaskets and fluids. The selected item will be added to the behaviour list below. Behavior List Item of the selected material constants are listed. It has the following features. [Double click] Clicking the item on the right side of the property window, opens it for editing. [Right click：New] You can add a new item. Content of the item is the same Structure, Thermal, Gasket, and Fluid pull-down menu. Property Window Material parameters of the selected item is displayed on the right side of the Property window. You can also perform the same operation by selecting Import from the right-click mouse menu button on the library of items. Material that has been added to the User Data Base table can be referred to at the time of creating property data. &nbspTo add a material library to the Library Data Base table, please select the library file from a folder icon in the Library Path.
