# ListBox

ListBox ListBox Add the list box. &nbsp;&nbsp;&nbsp;Creation image： Name &nbsp;&nbsp;&nbsp;Enter the name of the combo box component. Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Allow Multiple Selection &nbsp;&nbsp;&nbsp;Multiple items (items in the list box component) can be selected. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the combo box. (Units: pixels) Height &nbsp;&nbsp;&nbsp;Specifies the minimum height of the combo box. (Units: pixels) Source File &nbsp;&nbsp;&nbsp;Enter options from a text file. &nbsp;&nbsp;&nbsp;Structure of the Source File： &nbsp;&nbsp;&nbsp;&nbsp;Option1 &nbsp;&nbsp;&nbsp;&nbsp;Option2 &nbsp;&nbsp;&nbsp;&nbsp;Option3 &nbsp;&nbsp;&nbsp;&nbsp;Option4 &nbsp;&nbsp;&nbsp;&nbsp;Option5 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↓ &nbsp;&nbsp;&nbsp;&nbsp;Input result： Option Count &nbsp;&nbsp;&nbsp;Specify the number of items to be selected. Options * &nbsp;&nbsp;&nbsp;Enter the name of the item. Command to use Command Description Sample Code dlg.get_listbox_sel("name") Gets the position of the item selected in the list box. listbox = ["1", "2", "3", "4", "5"] When "4" is selected Input: a = dlg.get_listbox_sel("listbox") Output: > a = 3 dlg.get_len_listbox("name") Gets the length of the list box. listbox = ["1", "2", "3", "4", "5"] Input: a = dlg.get_len_listbox("listbox”) Output: > a = 3 dlg.set_listbox_sel(“Name”, Index) Switches the value selected in the list box. listbox = ["1", "2", "3", "4", "5"] Input: dlg.set_listbox_sel(“ListBox”, 3) ⇒ Selected value=”4” dlg.insert_listbox_option("name", position, "text") The value is added from the position selected in the list box (1 value 1 time). Input: dlg.insert_listbox_option("name", 1, "text") dlg.insert_listbox_options("name", position, [item list]) Adds a value from the position selected in the list box (multi-value once). Input: dlg.insert_listbox_options("name", 3, [item list])
