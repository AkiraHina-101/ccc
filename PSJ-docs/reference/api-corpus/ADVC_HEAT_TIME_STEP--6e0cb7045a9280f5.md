# ADVC_HEAT_TIME_STEP

ADVC_HEAT_TIME_STEP

Description​

A data type uses to control parameters of ADVC Heat Time Step

Attributes​

iEndType​

An Integer specifying end type.

The default value is 1.

dMaxTime​

A Double specifying maximum time.

The default value is 1.

iFixedAuto​

An Integer specifying fixed auto.

The default value is 0.

dMaxChange​

A Double specifying maximum change.

The default value is DFLT_DBL.

dInitdt​

A Double specifying initdt.

The default value is DFLT_DBL.

iDefineMaxdt​

An Integer specifying define maxdt.

The default value is 0.

dMaxdt​

A Double specifying maxdt.

The default value is DFLT_DBL.

iDefineMindt​

An Integer specifying define mindt.

The default value is 0.

dMindt​

A Double specifying mindt.

The default value is DFLT_DBL.

dFixeddt​

A Double specifying fixeddt.

The default value is DFLT_DBL.

iOutputLast​

An Integer specifying output last.

The default value is -1.

iOutputInterval​

An Integer specifying output interval.

The default value is DFLT_INT.

iRestartLast​

An Integer specifying restart last.

The default value is -1.

iRestartInterval​

An Integer specifying restart interval.

The default value is DFLT_INT.

dOutputTimeInterval​

A Double specifying output time interval.

The default value is DFLT_DBL.

dRestartTimeInterval​

A Double specifying restart time interval.

The default value is DFLT_DBL.

iOutputInit​

An Integer specifying output init.

The default value is -1.
