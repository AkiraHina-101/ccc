# PageItem

PageItem

ページコンテナー内にページを作成します PagesCtrl。

プレビューダイアログ：

パラメータ​

名前​

ページアイテムの名前を入力してください。

テキスト​

ページアイテムのヘッダーを指定します。

色​

背景色：テキストボックスの背景色を指定します。

テキストの色：テキストボックスに表示されるテキストの色を指定します。

フォント​

サイズ：テキストボックスに表示されるテキストのサイズを指定します。

太字：テキストを太字にするかどうかを指定します。

On をチェックする：テキストを太字にします

Off をチェックする：テキストを太字にしません

斜体：テキストを斜体にするかどうかを指定します。

On をチェックする：テキストを斜体にします

Off をチェックする：テキストを斜体にしません

下線：テキストに下線を付けるかどうかを指定します。

On をチェックする：テキストに下線を付けます

Off をチェックする：テキストに下線を付けません

取り消し線：テキストに横線を引いて取り消し線を付けるかどうかを指定します。

On をチェックする：テキストに取り消し線を付けます

Off をチェックする：テキストに取り消し線を付けません

表示​

作成した PageItem を表示するか非表示にするかを指定します。

On をチェックする：表示

Off をチェックする：非表示

関連する API​

dlg.add_pageitem：作成された/選択された PagesCtrl に新しい PageItem を追加します。
