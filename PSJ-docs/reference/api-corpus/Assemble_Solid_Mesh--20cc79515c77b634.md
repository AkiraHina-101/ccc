# Assemble Solid Mesh

Assemble Solid Mesh Assemble Solid Mesh This is an assembly function for solid mesh parts. This function is useful for replacing parts in a solid mesh model or adding new parts. Solid meshes will be remeshed and nodal points will be shared (shared faces will be created). Ex) Replacing the side cover mesh Before change: Boundary boundary nodes are not shared with other blocks (border mesh does not match) After change: Automatic boundary node sharing (border mesh are matching) The remeshed elements and nodes will be grouped under the name "AssembleSolidMesh". Selection list New Part: Additional part to assemble Assembled Part: Original assembly part(s) New Face: The face(s) is to be shared on the additional assembly part(s). Assembled Face: The face(s) is to be shared on the original assembly part(s). Parameter Tolerance Enter the distance between the parts to extract the face pair. Assemble the faces between the parts within the entered distance to create a shared surface. Connect Position Specify the creation position of the shared surface. Mid &nbsp;:&nbsp;Create a shared surface between the New Part and the Assembled Part. Master &nbsp;:&nbsp;Create a shared surface by fixing the position of the New Part. The shared surface of the Assembled Part moves to the position of the master face. Remesh Size Auto The mesh size around the new shared surface will be set automatically. Remesh Size Manual Manually enter the mesh size around the new shared surface. Ave &nbsp;:&nbsp;Average mesh size. Min &nbsp;:&nbsp;Minimum mesh size. Max &nbsp;:&nbsp;Maximum mesh size. -&nbspOperating Procedure&nbsp- Select a New Part or a New Face. Select Assembled Part(s) or Assembled Face(s). Change the parameters (Parameter) as needed. Click the Apply/OK button. A shared face is created (nodal covalent bond) by remeshing between the new part and the assembled part. -&nbspOperating Procedure (When a mesh error occurs)&nbsp- If a mesh error occurs, the remesh range will remain as a part. Manually correct the mesh error of the relevant part. Merge the relevant part back into the original part. -&nbspSpecial Notes (When selecting by part or by face)&nbsp- If you want to simplify the selection process, you can use New Part and Assembled Part to select the target faces automatically. However, depending on the shape of the mesh model, some unintended faces may be extracted as shared faces. If you want to improve the accuracy of the shared face extraction, you can directly select the target of the shared face on a face-by-face basis using New Face and Assembled Face. Also, since the shared face extraction range is limited to the selected face, a large tolerance can be entered. -&nbspPrecautions&nbsp- This function is only supported for tetrahedral elements. The element order of the New Part and the Assembled Part must be the same. Only one New Part is supported. Therefore, the New Face must also be selected from a single part.
