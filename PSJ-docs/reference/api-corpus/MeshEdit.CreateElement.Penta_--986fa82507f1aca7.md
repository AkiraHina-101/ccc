# MeshEdit.CreateElement.Penta()

MeshEdit.CreateElement.Penta()

Description​

Create penta element

Syntax​

MeshEdit.CreateElement.Penta(iParentEntityId=0, crlElems=[])

Ribbon: MeshEdit » CreateElement » Penta

Inputs​

iParentEntityId​

An Integer specifying the parent entity ID.

The default value is 0.

crlElems​

A List of Cursor specifying the element.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.CreateElement.Penta(iParentEntityId=0, crlElems=[])
