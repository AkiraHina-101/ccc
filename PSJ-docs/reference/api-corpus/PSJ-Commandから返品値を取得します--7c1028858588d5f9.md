# PSJ-Commandから返品値を取得します

PSJ-Commandから返品値を取得します

🎯 導入​

このチュートリアルでは、PSJコマンドの返品値から情報にアクセスし、引数を他のコマンドに渡す方法を学びます。

単一のエンティティから返品値を取得します。

エンティティのリストから返品値を取得します。

二重値のリストから返品値を取得します。

📖 チュートリアル​

# Python APIウィンドウでログメッセージをクリアします
JPT.ClearLog()

############ ケース1：単一のエンティティから値を返す ############
# 新しいキューブパーツを作成するときに戻り値を取得するGeometry.Part.cube（）は、2つの属性を持つ単一のオブジェクトを返します。
# typeId (int)
# ids = (tuple)
newCube = Geometry.Part.Cube()
JPT.Debugger(newCube)

# 2つの属性にアクセスします
listBodies = JPT.GetEntitiesByID(JPT.DItemType.BODY, newCube.ids[0])
listAllEntities = JPT.GetAllByType(newCube.typeId)

# PSJコマンドを他のコマンドに渡します
#Geometry.DeleteEntity.Part(crlPart=[newCube])

############ ケース2：エンティティのリストから値を返す ############
# 翻訳によってパーツを変換するときに戻り値を取得し、Geometry.Transform.Translation()リストオブジェクトを返します
newPartList = Geometry.Transform.Translation(crlParts=[newCube],
    dlTranslationVector=[[0.01, 0.01, 0.01]], bCreateNewPart=True, iCopyCount=2)
JPT.Debugger(newPartList)

# 2つの属性にアクセスして、NewPartListがリストになり、最初の要素にアクセスすることに注意してください
listBodies2 = JPT.GetEntitiesByID(JPT.DItemType.BODY, newPartList[0].ids[0])
listAllEntities2 = JPT.GetAllByType(newPartList[0].typeId)

# PSJコマンドを他のコマンドに返す値を渡すと、NewPartListがリストになっているので、必要ありません [] もう
Geometry.DeleteEntity.Part(crlParts=newPartList)

############ ケース3：二重値のリストから値を返す ############
# 2つのノード間の距離を測定するときに戻り値を取得し、Tools.Measure.Distance.TwoNodes()リストを2倍に返します
distance = Tools.Measure.Distance.TwoNodes(crNode1=Node(80), crNode2=Node(74))

# アクセスリストはダブルです
print(distance[0])
print(distance[1])
print(distance[2])
print(distance[3])
