# Layer Remesh

Layer Remesh Layer Remesh Remesh around the selected edges with one layer of Quad elements. Selection List Edge: Edge to be re-meshed around Face: Re-mesh face where the edge belongs Option Select faces button &nbsp;&nbsp;&nbsp;It automatically selects the faces that belong to the selected edges and stores them in the selection list. You can exclude unnecessary faces and add necessary faces manually. Type of both ends of line Select the type of the selected edge. Free Line &nbsp;&nbsp;&nbsp;A type of edge where the end of the edge (even on one side or the other) does not intersect with any other edges. Closed Line &nbsp;&nbsp;&nbsp;A type of edge that has both ends intersecting with other edges. Parameters Layer width &nbsp;&nbsp;&nbsp;Enter the width of the first layer of elements to be re-meshed. -&nbspOperating Procedure&nbsp- &nbsp;Select an edge. &nbsp;Select the faces to be remeshed by clicking on the "Select faces" button or selecting manually on the main window. &nbsp;After entering the width of the element, check the preview and click the Apply/OK button. -&nbspSpecial Notes&nbsp- &nbsp;If you select multiple faces on one side of an edge, the selected multiple faces will be merged. -&nbspOperation Video&nbsp- &nbspPress the "play' button to play the operation video. -->
