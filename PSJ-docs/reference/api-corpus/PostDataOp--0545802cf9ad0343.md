# PostDataOp

PostDataOp

説明​

これはPostDataOpクラスのインスタンスで、Jupiter内のポストデータオプション情報を表します。

プロパティ​

 | 属性 | 説明

 | loc | Location オプション情報。

 | cnv | Conversion オプション情報。

 | cont | Continuous Conversion オプション情報。

 | coord | Coordinate オプション情報。

 | load1D | Load 1D オプション情報。

 | load2D | Load 2D オプション情報。

 | complex | Complex オプション情報。

 | phaseAngle | 位相角の値。

 | userCoordSysId | ユーザー定義座標系のID。ユーザー定義座標系が指定されていない場合、IDは0に等しいです。
