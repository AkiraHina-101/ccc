# MoveNodeStraightenMidNodes()

MoveNodeStraightenMidNodes()

説明​

節点を正しい位置に移動します。

構文​

MoveNodeStraightenMidNodes(int[] taBodyKey, int[] taFaceKey, int[] taEdgeKey, int[] taNodeKey)

入力​

1. Int[]​

パートキーのカーソル（[ パート ID]）

2. Int[]​

フェースキーのカーソル（[フェース ID]）

3. Int[]​

エッジキーのカーソル（[エッジ ID]）

4. Int[]​

節点キーのカーソル（[節点 ID]）

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

MoveNodeStraightenMidNodes([], [25], [], [444, 460])
