# Connection | Gaps - 2 Faces

Connection | Gaps - 2 Faces Connection | Gaps - 2 Faces Create gap element between the nodes on the selected two faces. Connection Name Set the name of gap element to be created. Search Area Radius Specify the distance between the two nodes for connection. For distance more than this, Gap elements are not created. GAP Orientation by Select the orientation method of gap element. Orientation Vector Specified by the direction vector Coordinate system Specified by the coordinate system Coordinate System If you select specified by the coordinate system, select an existing coordinate system you want to use from the list. Orientation Vector If you select specified by the direction vector, enter a comma-separated direction vector in the order of X, Y, Z. U0 Enter the amount of initial open gap. F0 Enter the initial load value. KA Enter the axis stiffness value for the closed gap. KB Enter the axis stiffness value for the open gap KT Enter the transverse shear stiffness value when the gap is closed. MU1 Enter the static friction coefficient value of the adaptive gap element. MU2 Enter the dynamic friction coefficient value of the adaptive gap element. TMAX Enter the maximum allowable penetration amount to be used in the penalty value adjustment. MAR Enter the maximum allowable adjustment ratio to the adaptive penalty value KA and KT. TRMIN Enter the ratio of TMAX that defines the lower limit of the penetration tolerance value. Local Unit Specify the local unit system. Length Select the unit of length. Force Select the unit of force. -&nbspOperating Procedure&nbsp- &nbspIn Selection List ensure Master button is active to select the face that contains the node at one end of the gap element. &nbspIn Selection List ensure Slave button is active to select the face that contains the node at the other end of the gap element. &nbspIf you want to limit the connection range of the node pair at a distance between the nodes, enter distance for the Radius of Search Area. &nbspChoose how to specify the direction vector from Orientation By. Enter the direction vector according to the specified method. &nbspEnter the number, such as axial stiffness of gap element to it that of the input field. Select the Local Unit System of length and force, if necessary. &nbspClick the Apply or OK button to create the gap element between the nodes. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
