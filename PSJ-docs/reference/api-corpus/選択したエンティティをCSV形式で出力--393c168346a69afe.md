# 選択したエンティティをCSV形式で出力

選択したエンティティをCSV形式で出力

🎯 はじめに​

本チュートリアルでは、Jupiterモデルから選択したフェースの情報をCSVファイルに出力する方法について紹介します:

csvモジュールをインポートする。

Jupiterでユーザーによって選択されたフェースエンティティの選択リストを取得する。

選択したフェースの関連情報をCSVファイルに出力する。

スクリプトを実行する前に、モデルを準備し、モデル内のいくつかのフェースを選択する必要があります。

📖 チュートリアル​

# csvモジュールをインポートします。
import csv

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# Jupiterでユーザーが選択したフェースエンティティの選択リストを取得します。
listFaces = JPT.GetSelectedFaces()

# 選択したフェースの関連情報をCSVファイルに出力します。
with open(r"D:/facelist.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["No.", "ID", "Entity", "Part", "Information", "X", "Y", "Z"])
    i = 0
    for face in listFaces:
        i = i + 1
        listPart = JPT.GetEntitiesByAssociation(JPT.DItemType.FACE, JPT.AssociateType.AS_BODY, face.id)
        writer.writerow([i, str(face.id), "Face", listPart[0].name])
    print("出力が完了しました。")
