# Local CS Import Coordinate

Local CS Import Coordinate Local CS | Import Coordinate Load the local coordinate system contained in the following solver files. Readable file formats: *.bdf, *.adx, *.inp -&nbspOperation Procedure&nbsp- Click on the Import Coordinate command to open the Open dialog. Select the file containing the local coordinate system and click on the Open button to import coordinate system. -&nbspSpecial Note&nbsp- About the name, only files created in Jupiter format are supported for reading the name.
