# ERICONT_ORI_VEC_PROP

ERICONT_ORI_VEC_PROP

説明​

Ericont Ori Vec Prop のパラメータを制御するために使用されるデータ型です。

属性​

iConnId​

接続IDを指定する Integer です。

デフォルト値は0です。

iEndA​

end a を指定する Integer です。

デフォルト値は0です。

iEndB​

end b を指定する Integer です。

デフォルト値は0です。

dOrientVecX​

orient vec x を指定する Double です。

デフォルト値は0.0です。

dOrientVecY​

orient vec y を指定する Double です。

デフォルト値は0.0です。
