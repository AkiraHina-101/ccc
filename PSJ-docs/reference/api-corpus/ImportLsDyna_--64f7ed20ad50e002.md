# ImportLsDyna()

ImportLsDyna()

説明​

Ls-Dynaファイルをインポートします

構文​

ImportLsDyna(string[] m_vecPath, double m_faceAngle, double m_edgeAngle)

入力​

1. String[]​

複数のファイルパス

2. Double​

フェース角度

3. Double​

エッジ角度

戻り値​

"1": 関数は実行できます

"0": 関数は実行できません

サンプルコード​

ImportLsDyna(["D:/Test.k"], 1.0472, 1.0472)
