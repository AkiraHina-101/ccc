# ADVC_NORMAL_MODAL

ADVC_NORMAL_MODAL

Description​

A data type uses to control parameters of ADVC Normal Modal

Attributes​

iNumberModes​

An Integer specifying number modes.

The default value is 2.

iEigenNormalizationMethod​

An Integer specifying eigen normalization method.

The default value is -1.

dShift​

A Double specifying shift.

The default value is DFLT_DBL.

dCGCGPITolerance​

A Double specifying c g c g p i tolerance.

The default value is DFLT_DBL.

dCGCGPIEigenTolerance​

A Double specifying c g c g p i eigen tolerance.

The default value is DFLT_DBL.

iCGCGPILoopMax​

An Integer specifying c g c g p i loop maximum.

The default value is DFLT_INT.

dCGCGPIInnerTolerance​

A Double specifying c g c g p i inner tolerance.

The default value is DFLT_DBL.

iCGCGPIBlockSize​

An Integer specifying c g c g p i block size.

The default value is DFLT_INT.
