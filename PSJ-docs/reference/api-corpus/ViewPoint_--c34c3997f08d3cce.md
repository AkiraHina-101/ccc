# ViewPoint()

ViewPoint()

説明​

ビューポイントを設定します。

構文​

ViewPoint(int 方向)

入力​

1. Int​

方向: 事前設定されたビュー方向。

0: 左側を表示（-X）

1: 右側を表示（+X）

2: 下側を表示（-Y）

3: 上側を表示（+Y）

4: 後ろを表示（-Z）

5: 前を表示（+Z）

6: ユーザービュー1（+Y+Z+X）

7: ユーザービュー2（+Y-Z+X）

8: ユーザービュー3（+Y-X-Z）

9: ユーザービュー4（+Y-X+Z）

11: +Z+X+Y

12: +Z-X-Y

13: +X+Y+Z

14: +X-Z-Y

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

ViewPoint(1)
