# Contacts | FrontISTR - Contact Table

Contacts | FrontISTR - Contact Table Contacts | FrontISTR - Contact Table Contact pairs are automatically detected based on the gap distance between the parts, to create a contact definition. Contact Finding Tolerance Enter the gap distance between the parts to detect the contact pair. Displays the detected contact pair based on face input tolerance. Input Unit Specify the unit system of tolerance. Search Area Specify the range of contact pairs and candidate faces. When minimized, only faces found with search tolerance will be displayed as potential contact pairs. When maximized, it will display as a contact pair candidate up to the face that smoothly connects with the searched face. Check face direction When checked on, the contact pairs will not be created if the normal vectors of faces are in opposite directions. Master Basis Specify the criteria for contact segment to be master side in the detected contact pairs. Mesh size: Segment group whose average value of the element surface area is larger Area: Segment group with a larger total area Contact Type Define contact type for contact FrontISTR, easily control for same contact type setting. &nbsp;&nbsp;&nbsp;&nbsp;ID: Input ID. &nbsp;&nbsp;&nbsp;&nbsp;Interaction: Select neccessary interaction method. &nbsp;&nbsp;&nbsp;&nbsp;Normal Direction Convergence (NTOL): Input normal direction convergence parameter. &nbsp;&nbsp;&nbsp;&nbsp;Tangential Direction Convergence (TTOL): Input tangential direction convergence parameter. &nbsp;&nbsp;&nbsp;&nbsp;Normal Direction Penalty (NPENALTY): Input normal direction penalty parameter. &nbsp;&nbsp;&nbsp;&nbsp;Tangential Direction Penalty (TPENALTY): Input tangential direction convergence parameter. List Contact Type Created: Shows all previously created contact types. Also right click to get features like Edit and Delete. &nbsp;&nbsp;&nbsp;&nbsp;Edit: Modify parameter of Contact Type. &nbsp;&nbsp;&nbsp;&nbsp;Delete: Delete Contact Type. Find Contact Face is detected based on the input tolerance, contact pairs will be displayed in the table. Options Select the contact options that you want to appear in the table. Options title bar Contact pair in the item name is sorted by clicking on each. To change the Options to be displayed, specify from the Options button. Search box Displays only contact pair for partial matches. In addition, cancel the search by clicking the X button. Checkbox Among the detected contact pairs, check the contact pair that you wish to actually define. Contact pair is created with Apply (OK) button. Contact table Contacts in the model window is highlighted by selecting the contact pair displayed on the table. The color of the master / slave contact segment depends on the Preference> Display> LBC of the Master / Slave color settings. Contact option settings For contact Options you view and edit in the table. Contact options are divided into input methods such as numeric input, pull-down selection. Individual contact options can be edited after creating contact pair. Table function button Select All: Select all of the contact pairs Switch Master/Slave: Switch the master / slave segment group of the contact body Edit: The contact pairs that has been selected in the table open in the Manual Group dialog and can then be edited Delete: Remove the contact pair that have been selected in the table Export: Output existing contact pair Options information (contact pair with no check box in the table for On / Off) to a csv file Import: Read a csv file of contact Options information, to update the information for existing contact pairs in the table -&nbsp;Operating Procedure&nbsp;- Create a new contact pair &nbsp;Enter the respective tolerance value to Tolerance and Tolerance for TIED, click the Find Contact button. &nbsp;&nbsp;&nbsp;If you want to narrow the detection range, click the button after selecting multiple parts. Default is to detect contact between all of the parts (in parts unselected state). &nbsp;Select the contact pair displayed on the table and make sure where they point on the model window. &nbsp;Change the contact options of contact pairs, if necessary. Also clear the check box if there are any unwanted contact pair. &nbsp;Press the OK button to define the contact pair. &nbsp;Contact pair will be created in the Assembly tree under All Items> Contacts. Each contact pair can be edited through right-click> Edit. Add and review contact pairs using the contact table &nbsp;Start the Contact Table command to define the contact pairs. &nbsp;&nbsp;&nbsp;Existing contact pairs will be displayed in the table. &nbsp;By selecting an existing contact pair appearing in the table, you can see its position on the model window. &nbsp;If you want to search a new contact pair, select the part of the detection target and press the Find Contact button after you enter the Tolerance. &nbsp;&nbsp;&nbsp;If the newly detected contact pair candidate duplicates an existing contact pair, it will be displayed in red. &nbsp;Change the contact Options as necessary, to define the contact pair by clicking on the OK button. &nbsp;&nbsp;&nbsp;Newly added contact pairs will be marked with check box. Update the contact Options information about existing contact pair output &nbsp;Start the Contact Table command to define the contact pairs. &nbsp;Press the Export button at the bottom of the table, and then output the information file of contact Options. &nbsp;Open the output to csv file, and then change the setting of the contact Options.
