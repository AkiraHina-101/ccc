# JPT.DrawRect()

JPT.DrawRect()

説明​

ウィンドウ座標でメインウィンドウに四角形を描画します。

構文​

JPT.DrawRect()

入力​

left ​

四角形の左端のx座標をピクセル単位で指定する Int です。

top​

四角形の上端のy座標をピクセル単位で指定する Int です。

right​

四角形の右端のx座標をピクセル単位で指定する Int です。

bottom​

四角形の下端のy座標をピクセル単位で指定する Int です。

color​

矢印の色を表す16進数形式の Int です。

デフォルトの色はシアン（RGB(0, 255, 255)）です。

width​

矢印の軸の幅をピクセル単位で指定する Int です。

デフォルトは1です。

戻り値​

成功か失敗かを指定する Boolean です。

True: 成功

False: 失敗

サンプルコード​

JPT.ClearDraw()
# 左上隅が (10, 20) で、右下隅が (50, 100) の位置に、ピクセル単位で四角形を描画します
JPT.DrawRect(10, 20, 50, 100)

# 左上隅が (100, 200) で、右下隅が (400, 400) の位置に、赤色で四角形を描画します
JPT.DrawRect(100, 200, 400, 400, 255)

# 左上隅が (100, 10) で、右下隅が (200, 100) の位置に、幅5の黄色の四角形を描画します
JPT.DrawRect(100, 10, 200, 100, JPT.ConvertRGBToJPTColor(255,255,0), 5)
