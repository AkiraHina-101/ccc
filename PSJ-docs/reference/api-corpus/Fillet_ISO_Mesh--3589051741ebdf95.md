# Fillet ISO Mesh

Fillet ISO Mesh Fillet ISO Mesh This command extracts fillets and creates an ISO mesh (mapped mesh) of setting values in the extracted fillets. --> Step Operation &nbsp;&nbsp;&nbsp;Choose a method to extract the fillets. &nbsp;&nbsp;&nbsp;Select: Extract the fillet portion. &nbsp;&nbsp;&nbsp;Mapped: Creates a mapped mesh. --> --> Select Minimum Face Width &nbsp;&nbsp;&nbsp;Specify the minimum face width to search. Maximum Face Width &nbsp;&nbsp;&nbsp;Specify the maximum face width to search. Minimum Curve Radius &nbsp;&nbsp;&nbsp;Specify the minimum radius of the fillet to search. Maximum Curve Radius &nbsp;&nbsp;&nbsp;Specify the maximum radius of the fillet to search. Minimum Angle &nbsp;&nbsp;&nbsp;Specify the minimum value of the fillet angle to search. Maximum Angle &nbsp;&nbsp;&nbsp;Specify the maximum value of the fillet angle to search. Convex &nbsp;&nbsp;&nbsp;Search for convex fillets. Concave &nbsp;&nbsp;&nbsp;Search for concave fillets. Mapped Mesh Circumference Division &nbsp;&nbsp;&nbsp;Set the number of divisions in the fret circumferential direction. Axis Average Size &nbsp;&nbsp;&nbsp;Set the average mesh size in the fret axis direction. Error Tolerance &nbsp;&nbsp;&nbsp;Set the tolerance. -&nbsp;Operating Procedure&nbsp;- &nbsp;Select "Select" from the operation and select the target part or face group. &nbsp;Enter the maximum and minimum face width of the fillet to search. &nbsp;Enter the maximum and minimum curvature radius of the fret to be searched. &nbsp;Enter the minimum and maximum angle of the fret to be searched. &nbsp;Specify whether the fret to be searched is convex or concave. &nbsp;When the Apply button is clicked, fillet faces within the specified range are selected from the target part. &nbsp;Select "Mapped" from the operation. &nbsp;Enter the number of divisions in the circumferential direction of the fret mesh to be created. &nbsp;Enter the average mesh size in the axial direction of the fret mesh to be created. &nbsp;Enter the error tolerance when creating the mesh. &nbsp;Click the Apply / OK button to create an ISO mesh (mapped mesh) on the selected fillet face. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
