# HARMONIC

HARMONIC

Description​

A data type uses to control parameters of Harmonic

Attributes​

dHarmonicStartFreq​

A Double specifying harmonic start frequency.

The default value is 0.0.

dHarmonicEndFreq​

A Double specifying harmonic end frequency.

The default value is 1.0.

iSubSteps​

An Integer specifying sub steps.

The default value is 0.

dAlphaD​

A Double specifying alpha d.

The default value is 0.0.

dBetaD​

A Double specifying beta d.

The default value is 0.0.

dDmprat​

A Double specifying dmprat.

The default value is 0.0.

bHarmonicOutputDisplacements​

A Boolean enable/disable harmonic output displacements.

The default value is False.

bHarmonicOutputStress​

A Boolean enable/disable harmonic output stress.

The default value is False.
