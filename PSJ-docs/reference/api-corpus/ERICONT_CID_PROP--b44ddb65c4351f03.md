# ERICONT_CID_PROP

ERICONT_CID_PROP

Description​

A data type uses to control parameters of Ericont Cid Prop

Attributes​

iConnId​

An Integer specifying connection ID.

The default value is 0.

iEndA​

An Integer specifying end a.

The default value is 0.

iEndB​

An Integer specifying end b.

The default value is 0.
