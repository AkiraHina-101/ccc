# POST_DATA_VIZ_OPT_MAXMIN

POST_DATA_VIZ_OPT_MAXMIN

説明​

データ型は最大/最小値の表示設定の結果を設定するために使用されます。

属性​

iGroupMethod​

グループ方式を指定する Integer です。

0: 全体用

1: 各々用

デフォルト値は0です。

iMaxColor​

最大色を指定する Integer です。

デフォルト値は255です。

iMinColor​

最小色を指定する Integer です。

デフォルト値は16711680です。

iTextColor​

です。

デフォルト値は65535です。
