# Page Control

Page Control Page Control ページコンテナーを作成します（ウィザードに使用）。 &nbsp;&nbsp;&nbsp;作成イメージ図： &nbsp;&nbsp;&nbsp;&nbsp※Page CtrlはPage Itemとセットで使用します。 Name &nbsp;&nbsp;&nbsp;Page Controlコンポーネントを入力します。 Show Header &nbsp;&nbsp;&nbsp;ページアイテムのヘッダーテキストの表示/非表示を指定します。 チェックオン &nbsp;:&nbsp;表示します。 チェックオフ &nbsp;:&nbsp;表示しません。 Default Page &nbsp;&nbsp;&nbsp;デフォルトで表示するページを指定します。 &nbsp;&nbsp;&nbsp;※ 入力値は0からです。 Enable &nbsp;&nbsp;&nbsp;使用の可否を指定します。 チェックオン &nbsp;:&nbsp;使用可能。 チェックオフ &nbsp;:&nbsp;使用不可。（グレーアウトされます）。
