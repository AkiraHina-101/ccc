# フェース

フェース クローズホール モデルを対象に、フェースまたは要素が欠落している箇所（穴）を検索し、穴部にフェースを作成します。 フリーエッジ 長さ最小値 最小穴周りエッジ長を指定します。 長さ最大値 最大穴周りエッジ長を指定します。 検索 穴周りのエッジを検索します。 穴埋め条件 最小面積 穴部にフェースを作成する最小面積の閾値を指定します。ここで指定した値以上の穴部にフェースを作成します。 最大面積 穴部にフェースを作成する最大面積の閾値を指定します。ここで指定した値以下の穴部にフェースを作成します。 オプション フェースをマージ チェックを入れると、フェース作成後、隣接フェースと結合します。 エッジをマージ チェックを入れると、作成したフェース周りのエッジを結合します。 -&nbsp操作手順&nbsp- 検索 ボタンをクリックし、フリーエッジを検索します。検索の対象は、 自動の場合：モデル全体の穴部 エッジの場合：選択エッジの所属する穴 パーツの場合：選択パーツ上の穴部 です。 最小面積と最大面積にフェースを作成する最大最小面積の閾値を指定します。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
