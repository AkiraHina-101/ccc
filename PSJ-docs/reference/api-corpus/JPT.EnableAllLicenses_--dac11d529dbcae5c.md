# JPT.EnableAllLicenses()

JPT.EnableAllLicenses()

Description​

Enable/Disable all the licenses feature which is existing in the current Jupiter.

Syntax​

JPT.EnableAllLicenses(...)

Inputs​

BoolType​

A Bool describing the enable state of license:
True: Enable all the licenses.

False: Disable all the licenses.

This is a required input.

Return Code​

This utility function does not have output value.

Sample Code​

# Disable all the licenses
JPT.EnableAllLicenses(False)
