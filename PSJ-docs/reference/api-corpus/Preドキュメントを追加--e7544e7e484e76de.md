# Preドキュメントを追加

Preドキュメントを追加 Preドキュメントを追加 指定したPreドキュメントをインポートします。既存モデルとエンティティIDが重複した場合はIDオフセットもしくはIDリナンバーを行います。 パス設定 &nbsp;&nbsp;&nbsp;Preドキュメントのパス設定。 Preドキュメントを追加 &nbsp;&nbsp;&nbsp;現在開いているドキュメントに追加するPreドキュメントを選択します。 インポートモデル &nbsp;&nbsp;&nbsp;[インポートモデル]を選択して、インポートモデルのIDをオフセット/リナンバーパラメーターを入力します。 現在のモデル &nbsp;&nbsp;&nbsp;[現在のモデル]を選択してパラメーターを入力し、現在のモデルのIDをオフセット/リナンバーします。 オフセット/リナンバー &nbsp;&nbsp;&nbsp;[IDオフセット]または[IDリナンバー]オプションを選択します。 オプション &nbsp;&nbsp;&nbsp;重複IDを処理するには、2つのオプションがあります。 - IDオフセット : このオプションを使用すると、テキストボックスに指定された値を持つ選択したモデルのエンティティIDがオフセットされます。 例：IDオフセットを選択した場合 インポートモデルのエンティティIDはオフセットとして処理されます。 この例では、ノード、要素、フェース、エッジおよびパーツIDがオフセット処理されます。オフセット値は現在のモデルの対応するエンティティの最大ID値に設定されます。 [OK]を押してモデルをインポートすると、選択したモデルのエンティティのすべてのIDが、指定したオフセット値によってオフセットされます。 - IDリナンバー : このオプションを使用すると、エンティティIDを指定した開始IDでリナンバーしてインポートします。 例：IDリナンバーを選択した場合 現在のモデルの各エンティティIDの最大値+1の値を開始IDとして入力され、リナンバーされます。 この例では、ノード、要素、フェース、エッジおよびパーツIDがリナンバーされます。 [OK]を押すと、選択されたモデルの指定された番号変更したオブジェクトのすべてのIDが、指定された値にしたがって番号変更されます。 ログファイルを表示 &nbsp;&nbsp;&nbsp;オンの状態で、OKを押すと、IDオフセット/IDリナンバー情報を含むログファイルが表示されます。 単位系 オプション - 現在の単位系 : &nbsp;&nbsp;&nbsp;現在開いているドキュメントの単位系を保持します。インポートファイル内の数値は、現在のドキュメントの単位系に変換されます。 - インポート単位系 : &nbsp;&nbsp;&nbsp;インポートファイルの単位系を使用します。現在開いているドキュメント内の数値は、インポートファイルの単位系に変換されます。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
