# Auto Collapse

Auto Collapse Auto Collapse Delete and combine elements. This feature incorporates automatic processing into element edge selection / execution. Auto Collapse Auto Select (Element Edge) Among the element edges connected to the selected node, the shortest edge below tolerance is automatically selected. In free edge mode, functions can be executed continuously because the selection of nodes is not canceled. Collapse All Element Edges Among the element edges connected to the selected node, pull all element edges below tolerance into the node and delete the element.
