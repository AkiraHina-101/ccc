# Assemble Faces

Assemble Faces Assemble Faces For the assembly model of multiple parts, this dialog automatically searches for contact and creates a share surface with that face between the parts in the model. When you create a shared surface, a group of face pairs is created in Group tree of Group window. Mating Tolerance Enter the tolerance distance between the two adjacent faces that are in contact. Find Start the search of the face that is in contact when pressed Find button. Mating Face No./Assembled Face No. Display the number of face pairs in contact that are searched through the Find button. If you click the Apply button to create a shared surface, the option name will be changed to Assembled Face No. which displays the number of shared surface pairs that are created. Find Result/Assembled Faces Display the list of face pairs in contact that have been searched through the Find button. If you click the Apply button to create a shared surface, the option name will be changed to Assembled Faces. which displays a list of shared surface pairs that are created. No. Serial number for searching the order in which they will be created. A check box is displayed at the top of the ID number, only when share surface is created. Find Result Display a list of face pairs that have contacts based of part name. Select All Select all the check boxes that are displayed and then turn them on. Unselect All Select all the check boxes that are displayed and then turn them off. Imprinting Fit Edge When checked, it will prevent edge split after creation of a shared surface. -&nbspOperating Procedure (If you want to create a shared surface targeting the model)&nbsp- &nbspChange the value of tolerance from the default value, if necessary. &nbspClick on the Find button. &nbspResult of the face pair are listed. &nbspClick each line of the list, face will be selected and displayed on the screen. &nbspIf there is no need to create a shared surface from a face pair, uncheck the corresponding check box. &nbspClick Apply/OK button. -&nbspOperating Procedure (If you want to create a shared surface for multiple parts)&nbsp- &nbspSelect more than one part. &nbspChange the value of tolerance from the default value, if necessary. &nbspClick on the Find button. &nbspResults of the face pairs are listed. &nbspClick each row of the list, face will be selected and displayed on the screen. &nbspIf there is no need to create a shared surface from a face pair, uncheck the corresponding check box. &nbspClick Apply/OK button. -&nbspOperation Video&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
