# Sweep | Rotation

Sweep | Rotation Sweep | Rotation Creates a Hexa-mesh model from a hollow axisymmetric model. The original model is placed under the Reference. It can be used to create a new mesh for a CAD model or remesh a mesh model. Since the axial direction is defined by a single curved edge, and the number of mesh divisions in the circumferential direction (sweep direction) is defined by the mesh size at the maximum diameter position, so there is no need to specify coordinates or the number of divisions. ※Not compatible with solid object models (V5.0). Selection List Edge: Circumferential curved edge Mesh Size Section Specify the mesh size of the section to be rotated. Rotation Specify the circumferential mesh size for the largest diameter location. Cut Section View Cut Section Specify whether to display the model in section view. Display Direction Use to flip the view direction of the cross-section to the opposite side. Rotation Use to rotate the cross-section by a degree clockwise or counterclockwise. -&nbspOperating Procedure&nbsp- Enter the mesh size of the section to be rotated. ※The mesh sizes in the radial and axial directions are defined. Enter the circumferential mesh size for the largest diameter location. ※The number of mesh divisions in the circumferential direction is defined. Specify the position of the cross-section. ※The shape of the rotational cross-section is displayed in the main window. Perform a rotational sweep with this shape.
