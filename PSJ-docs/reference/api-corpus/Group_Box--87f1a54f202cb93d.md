# Group Box

Group Box Group Box Create a component group. &nbsp;&nbsp;&nbsp;Creation image： Text &nbsp;&nbsp;&nbsp;Enter the group name. Name &nbsp;&nbsp;&nbsp;Enter the name of the group box component. Has Check Label No &nbsp;:&nbsp;Always make the components in the group operational. Yes(Default==Checked) &nbsp;:&nbsp;Controls the operation of the components in the group. (Default: Check ON) Yes(Default==Unchecked) &nbsp;:&nbsp;Controls the operation of the components in the group. (Default: unchecked) IsCollapsed &nbsp;&nbsp;&nbsp;Sets the collapsible display of the group box. No &nbsp;:&nbsp;Doesn't collapsible Yes(Default==Collapsed) &nbsp;:&nbsp;Controls the operation of group box collapsible. (Default: check ON) Yes(Default==Expanded) &nbsp;:&nbsp;Controls the group box collapsible operation. (Default: unchecked) Orientation &nbsp;&nbsp;&nbsp;Specify the position of components. Horizontal &nbsp;:&nbsp;Arrange the components horizontal Vertical &nbsp;:&nbsp;Arrange the components vertically Width &nbsp;&nbsp;&nbsp;Specify the minimum width of the group box. (Unit: pixels) Height &nbsp;&nbsp;&nbsp;Specify the minimum height of the group box. (Unit: pixels) Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out）
