# Browser

Browser

ファイル/フォルダ選択を作成します。

プレビューダイアログ:

パラメータ​

名前​

ファイル/フォルダの名前を入力します。

有効​

有効化するかどうかを指定します。

チェック オン ： 利用可能

チェック オフ ： 利用不可（グレー表示）

モード​

選択モードを指定します。

ファイル ： ファイルタイプのみを選択できます。

フォルダ ： フォルダタイプのみを選択できます。

デフォルト​

表示するデフォルト（ファイル/フォルダ）リンク。

フィルター​

ユーザーが選択できるファイルタイプを入力します。

フィルタ形式:

説明1（拡張子1, 拡張子2, ...）、説明2（拡張子1, 拡張子2, ...）、...

複数選択の許可​

複数のファイルを選択できるかどうかを選択します。

チェック オン ： 許可

チェック オフ ： 不許可

表示​

作成したブラウザを表示/非表示にするか指定します。

チェック オン ： 表示

チェック オフ ： 非表示

関連API​

dlg.add_browser : 作成ダイアログにファイル/フォルダブラウザコンポーネントを追加します。

dlg.on_browse : 作成した関数をファイル/フォルダブラウザコンポーネントにバインドします。
