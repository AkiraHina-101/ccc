# ANSYS_CONTACT

ANSYS_CONTACT

説明​

Ansys Contactのパラメータを制御するために使用されるデータ型です。

属性​

dFricCoef​

摩擦係数を指定する Double です。

デフォルト値はDFLT_DBLです。

dPenaStiffness​

ペナ剛性を指定する Double です。

デフォルト値はDFLT_DBLです。

dPetrTolerance​

ペトル許容値を指定する Double です。

デフォルト値はDFLT_DBLです。

iStiffUpdate​

剛性更新を指定する Integer です。

デフォルト値は2です。

iAlgorithm​

アルゴリズムを指定する Integer です。

デフォルト値は2です。

iDetec​

検出を指定する Integer です。

デフォルト値は2です。

iBehavior​

動作を指定する Integer です。

デフォルト値は5です。
