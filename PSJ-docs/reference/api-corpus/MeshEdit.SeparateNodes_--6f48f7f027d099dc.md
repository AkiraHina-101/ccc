# MeshEdit.SeparateNodes()

MeshEdit.SeparateNodes()

Description​

Separate nodes

Syntax​

MeshEdit.SeparateNodes(crlShareNodes=[], crlTargets=[], iKeepNodeIDsOn=0)

Ribbon: MeshEdit » SeparateNodes

Inputs​

crlShareNodes​

A List of Cursor specifying the share nodes.

The default value is [].

crlTargets​

A List of Cursor specifying the target.

The default value is [].

iKeepNodeIDsOn​

An Integer specifying the keep node i ds on.

The default value is 0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.SeparateNodes(crlShareNodes=[], crlTargets=[], iKeepNodeIDsOn=0)
