# MeshEdit.RibThickness()

MeshEdit.RibThickness()

Description​

Mesh Edit Morphing Rib Thickness

Syntax​

MeshEdit.RibThickness(crlFaceMove=[], crlFaceFixed=[], dMove=3.00, dDistStrong=10.00, dDistWeak=20.00)

Ribbon: MeshEdit » RibThickness

Inputs​

crlFaceMove​

A List of Cursor specifying the face move.

The default value is [].

crlFaceFixed​

A List of Cursor specifying the face fixed.

The default value is [].

dMove​

A Double specifying the move.

The default value is 3.00.

dDistStrong​

A Double specifying the dist strong.

The default value is 10.00.

dDistWeak​

A Double specifying the dist weak.

The default value is 20.00.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.RibThickness(crlFaceMove=[], crlFaceFixed=[], dMove=3.00, dDistStrong=10.00, dDistWeak=20.00)
