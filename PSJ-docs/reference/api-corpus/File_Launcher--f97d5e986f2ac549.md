# File Launcher

File Launcher

File Launcher is used to assigned PSJ to a floating window for quickly access and execution.

Interface​

 | Button | Description

 | S | Register the Python file

 | C | Clear the registered Python file

 | R | Replace the registered Python file with another Python file

 | Func | Execute the registered Python program

Operating procedure​

When user selects a file, the green mark on the left side of the Function button turns red:
