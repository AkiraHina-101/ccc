# Trace | Part

Trace | Part a.no-uline {text-decoration:none} Trace | Part This command shows or hides parts using the connection information between parts. You can check which part is connected to the selected part and to which part it is connected. Search All &nbsp;&nbsp;&nbsp;If checked, all parts in the model will be searched regardless of the number of layers. Number of Layers &nbsp;&nbsp;&nbsp;Enter the number of layers to search when the Apply, Increase, or Decrease button is pressed. Trace Part Shared Faces / Nodes &nbsp;&nbsp;&nbsp;When checked, the part with the displayed part and the shared plane / shared node is displayed. Contact Conditions &nbsp;&nbsp;&nbsp;If checked, the part that is in contact with the displayed part will be displayed. Beam element / Bar element &nbsp;&nbsp;&nbsp;When checked, the part being connected by the displayed part and the beam / bar element is displayed. Spring / Bush / Gap &nbsp;&nbsp;&nbsp;When checked, the displayed part and the part connected with the spring element / bush / gap element are displayed. Rigid Elements &nbsp;&nbsp;&nbsp;When checked, the displayed part and the part connected by the rigid wall are displayed. MPC &nbsp;&nbsp;&nbsp;When checked, the displayed part and the part connected by MPC are displayed. Increase Layer &nbsp;&nbsp;&nbsp;The hierarchy for tracing connection information is +1. Decrease Layer &nbsp;&nbsp;&nbsp;The hierarchy for tracing connection information is -1. Reset Reset &nbsp;&nbsp;&nbsp;Reset the display (display all parts regardless of connection information). -&nbsp;Operating Procedure&nbsp;- &nbsp;Select a part to display connection information. &nbsp;Set connection information in Trace Part. &nbsp;Press Apply button. &nbsp;You can change the display of the hierarchy tracing the connection information and check it with the button of Add Layer / Reduce Layer. &nbsp;Press the reset button to restore the part display. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
