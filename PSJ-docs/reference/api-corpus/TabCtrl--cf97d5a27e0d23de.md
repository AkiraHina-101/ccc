# TabCtrl

TabCtrl TabCtrl Create a group of tab items (pages). &nbsp;&nbsp;&nbsp;Creation image： &nbsp;&nbsp;&nbsp;&nbsp※TabCtrl is used as a set with TabItem. Name &nbsp;&nbsp;&nbsp;Enter the name of the TabCtrl component. Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the created page. (Units: pixels) Height &nbsp;&nbsp;&nbsp;Specifies the minimum height of the created page. （Units: pixels）
