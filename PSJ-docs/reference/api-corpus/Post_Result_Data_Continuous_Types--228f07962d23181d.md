# Post Result Data Continuous Types

Post Result Data Continuous Types

これは、ポスト結果データ連続変換タイプを表す列挙型です。

 | ID | ポスト結果データ連続変換タイプ | 説明

 | 0 | JPT.PostResultDataCont.POST_CONT_UNKNOWN | 未定義の連続変換。

 | 1 | JPT.PostResultDataCont.POST_CONT_MAT | 素材による連続変換（素材境界で非連続な輪郭が表示されます）。

 | 2 | JPT.PostResultDataCont.POST_CONT_PROP | 特性による連続変換（要素特性境界で非連続な輪郭が表示されます）。

 | 4 | JPT.PostResultDataCont.POST_CONT_BLK | パート（ブロック）による連続変換。

 | 8 | JPT.PostResultDataCont.POST_CONT_ALL | 以上のいずれにも該当しない変換（すべての要素節点結果の平均による）。
