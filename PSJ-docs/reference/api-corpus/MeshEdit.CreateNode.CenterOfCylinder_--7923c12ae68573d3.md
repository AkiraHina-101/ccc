# MeshEdit.CreateNode.CenterOfCylinder()

MeshEdit.CreateNode.CenterOfCylinder()

Description​

Create node of center cylinder

Syntax​

MeshEdit.CreateNode.CenterOfCylinder(crlFaces=[], iNodeID=1)

Ribbon: MeshEdit » CreateNode » CenterOfCylinder

Inputs​

crlFaces​

A List of Cursor specifying the face.

The default value is [].

iNodeID​

An Integer specifying the node ID.

The default value is 1.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.CreateNode.CenterOfCylinder(crlFaces=[], iNodeID=1)
