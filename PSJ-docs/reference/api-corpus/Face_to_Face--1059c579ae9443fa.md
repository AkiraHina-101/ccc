# Face to Face

Face to Face Face to Face CAD Projection(Face to Face) Dialog Box To project mid-node or corner nodes of the mesh parts, to the CAD shape face you have selected. Options Corner Nodes Put a check when you want to place the corner node in the CAD shape. Mid Nodes Put a check when you want to place the mid-node to the CAD geometry. ID Check If it is checked, CAD parts and mesh parts must have the same ID for all of the entity such as parts, face, edge. Projection is not carried out unless they have the same ID. If not checked, you do not need to have the same ID. Projection is made between the entity at the most closest distance, but in some cases there is a risk that the projection might be to an unintended position. -&nbspOperating Procedure&nbsp- &nbspPress the CAD Face button on the Selection List, select the face from the screen that becomes a projection target. &nbspPress the Meshed Face button on the Selection List, select the face of the mesh part from the screen that becomes the projection target. &nbspCheck Corner Nodes option, if you want the corner node to be projected into CAD geometry. &nbspClick the Apply or OK button to execute the projection. Nodes on the selected faces will move on the CAD model. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
