# MeshEdit.MoveNode.CADFollows()

MeshEdit.MoveNode.CADFollows()

Description​

Syntax​

MeshEdit.MoveNode.CADFollows(crlNodes=[], dMovedPosX=0.0, dMovedPosY=0.0, dMovedPosZ=0.0)

Ribbon: MeshEdit » MoveNode » CADFollows

Inputs​

crlNodes​

A List of Cursor specifying the node.

The default value is [].

dMovedPosX​

A Double specifying the moved position x.

The default value is 0.0.

dMovedPosY​

A Double specifying the moved position y.

The default value is 0.0.

dMovedPosZ​

A Double specifying the moved position z.

The default value is 0.0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.CADFollows(crlNodes=[], dMovedPosX=0.0, dMovedPosY=0.0, dMovedPosZ=0.0)
