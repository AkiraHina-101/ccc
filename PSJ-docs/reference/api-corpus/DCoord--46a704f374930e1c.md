# DCoord

DCoord

説明​

これは Jupiter 内の Coordinate アイテムを表す DCoord クラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | isValid | Coordinate の検証を決定します。
Coordinate が有効である場合は True が返され、無効である場合は False です。

 | type | Coordinate のタイプ名。
戻り値はタイプ（文字列）です。

 | typeID | Coordinate のタイプ ID（ID = 27）。
戻り値はDItem Types の Int 表記（int）です。

 | tableID | Coordinate のテーブル ID。
戻り値はDTable Types の Int 表記（int）です。

 | id | Coordinate の外部 ID。
重複することができますが、推奨されません。
ID は再番号付け機能を使用して変更できます。
戻り値は ID（int）です。

 | targets | Coordinate の内容を保持します。
戻り値はDItem のリストです。

 | masters | Coordinate のマスター フェース/エッジ/節点です。
戻り値はDItem のリストです。

 | slaves | Coordinate のスレーブ フェース/エッジ/節点です。
戻り値はDItem のリストです。

 | parent | アセンブリ ツリー内の Coordinate の親であるサブアセンブリです。
戻り値はDItem のリストです。

 | isHidden | Coordinate の表示状態を決定します。
Coordinate が非表示の場合は True が返され、表示されている場合は False です。

 | name | Coordinate の名前です。

 | coordType | Coordinate のタイプです。
戻り値は Type（文字列）です。

 | coordPoints | Coordinate の定義済みのポイントのリストです。
戻り値は TVector3d です。

属性​

coordType​

 | 名前 | 説明

 | COORDINATE_RECT | 直交座標系（Oxyz）。

 | COORDINATE_CYLIN | 円柱座標 - (r, φ, z) 座標系で、（r, φ, z）はそれぞれ（半径距離、方位角、軸座標または高さ z）を表します。

 | COORDINATE_SPHERE | 球座標 - (r, θ, φ) 座標系で、（r, θ, φ）はそれぞれ（半径距離、方位角、極角）を表します。
