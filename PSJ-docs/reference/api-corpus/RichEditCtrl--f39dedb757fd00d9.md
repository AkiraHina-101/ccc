# RichEditCtrl

RichEditCtrl RichEditCtrl Add a rich text box. &nbsp;&nbsp;&nbsp;Creation image： Default &nbsp;&nbsp;&nbsp;Enter the text that is entered by default. Name &nbsp;&nbsp;&nbsp;Enter the name of the rich text component. Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the rich text box.（Unit: Pixels） Height &nbsp;&nbsp;&nbsp;Specifies the minimum height of the rich text box.（Unit: Pixels） Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out）
