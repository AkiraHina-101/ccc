# スプリット

スプリット スプリット 個々の要素のエッジを特定の比率またはノードで2つの要素のエッジに分割します。 分割 イクイバランス このオプションは、選択したノードと分割ノード（要素のエッジを分割するときに作成される）を1つのノードにマージするために使用します。 ※選択した要素を分割し、ノードを同時にマージするために使用します。 複数の要素エッジを同時に選択した場合、関数は同等のものを使用できません。 パラメーター この入力テキストは、分割後の元の要素の長さの比率によって2つの要素の長さを決定するために使用されます。 言い換えると、パラメータが分割ノードの場所を決定するために使用されることを理解することは同じ意味です。 ※比率範囲は0&lt;x&lt;1で、パラメータ値が範囲外の場合は動作しません。 -&nbsp操作手順 (1)&nbsp- 要素のエッジを分割するには &nbsp分割する要素のエッジを選択します。 &nbspパラメータテキストボックスに希望の比率を入力し、プレビューで確認します。 &nbsp[適用]ボタンをクリックします。 &nbsp選択した要素エッジは、特定の比率で2つの要素エッジに分割されます。 -&nbsp操作手順 (2)&nbsp- 要素エッジが2つのシェル要素間で接続されていない場合（フリーエッジが発生する）、同等の関数は、要素エッジを分割してフリーエッジを解決し、以下の操作のように分割ノードを選択したノードにマージします。 &nbsp同等性オプションをチェックします。 &nbsp分割する要素のエッジを選択します。 &nbsp目的のノードを選択して、マージされたノードを決定します。 &nbsp[適用]ボタンをクリックします。 &nbsp選択した要素のエッジが2つの要素のエッジに分割され、分割されたノードが選択したノードにマージされて1つのノードのみになります。 すべてのフリーエッジが削除されると、シェル要素は要素エッジで接続されます。 -&nbsp特記事項&nbsp- メッシュは、互いに対称な2つの要素に対して同じ結果を生成しません。以下は、分割後の結果です。 対称的なメッシュを取得するには、「QuadTo2Tris」や「2TristoQuad」などの他の関数でメッシュを変更します。 -&nbsp操作動画&nbsp- &nbsp・ｽﾄ撰ｿｽ・ｽ{・ｽ^・ｽ・ｽ・ｽ・ｽ・ｽ・ｽ・ｽ・ｽ・ｽﾆ托ｿｽ・ｽ・ｮ・ｽ謔ｪ・ｽﾄ撰ｿｽ・ｽ・ｽ・ｽ・ｽﾜゑｿｽ・ｽB -->
