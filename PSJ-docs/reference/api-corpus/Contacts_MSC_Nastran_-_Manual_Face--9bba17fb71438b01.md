Contact Properties | General Touching Distance Range（ERROR) Distance below which a node is considered touching a body. Separation Force (FNTOL) Separation force or stress on above which a node separates from a body. Friction Coefficient (FRIC) Friction coefficient. Interference Closure (CINTERF) Interference closure amount, normal to the contact surface. Searching Order(ISEARCH) Option for contact searching order, from Slave to Master or from Master to Slave, for deformable contact bodies. &nbsp;&nbsp;&nbsp;&nbsp;Double&nbsp;:&nbspThe search order is from lower BCBODOY ID's to higher ones first. &nbsp;&nbsp;&nbsp;&nbsp;Slave to Master&nbsp;:&nbspThe searching order is from Slave to Master. &nbsp;&nbsp;&nbsp;&nbsp;Program decision&nbsp;:&nbspLet the program decide which search order.; Modify Coordinates (ICOORD) Modify Coordinates. &nbsp;&nbsp;&nbsp;&nbsp;None&nbsp;:&nbsp;No modification. &nbsp;&nbsp;&nbsp;&nbsp;Modify position&nbsp;:&nbsp;Modify the coordinates of a node in contact with a deformable body so that stress-free initial contact can be obtained. &nbsp;&nbsp;&nbsp;&nbsp;Delay sliding&nbsp;:&nbsp;Extend the tangential error tolerance at sharp corners of deformable bodies to delay sliding off a contacted segment. &nbsp;&nbsp;&nbsp;&nbsp;Both effect&nbsp;:&nbsp;Have both Modify position and Delay sliding active. Friction Stress Limit (FRLIM) Friction stress limit. This entry is only used for friction type 6 (Coulomb friction using the bilinear model). Tolerance Bias Factor (BIAS) Contact tolerance bias. A non-blank entry will override the BIAS entered on the BCBODY entry. Condition Check (ISTYP) Check of contact conditions.
