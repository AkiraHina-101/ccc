# BASIC

BASIC

説明​

Basicのパラメータを制御するために使用されるデータ型です。

属性​

bBasicOutputDisplacements​

基本アウトプット変位を有効/無効にします。

デフォルト値は False です。

bOutputReactionLoad​

反力の出力を有効/無効にします。

デフォルト値は False です。

bBasicOutputStrain​

基本アウトプット歪みを有効/無効にします。

デフォルト値は False です。

bBasicOutputStress​

基本アウトプット応力を有効/無効にします。

デフォルト値は False です。

iAnalysisOption​

解析オプションを指定します（整数型）。

デフォルト値は0です。

bCalculatePrestressEffect​

予応力効果を計算するかどうかを有効/無効にします。

デフォルト値は False です。

dUniformTemperature​

一定温度を指定します（倍精度浮動小数型）。

デフォルト値は0.0です。

dReferenceTemperature​

基準温度を指定します（倍精度浮動小数型）。

デフォルト値は0.0です。

dEndLoadTime​

終了負荷時間を指定します（倍精度浮動小数型）。

デフォルト値は0.0です。

iTimeStep​

タイムステップを指定します（整数型）。

デフォルト値は0です。

iStepChosen​

選択されたステップを指定します（整数型）。

デフォルト値は0です。

iSubStepNum​

サブステップ数を指定します（整数型）。

デフォルト値は0です。

iMaxSubStep​

最大サブステップを指定します（整数型）。

デフォルト値は0です。

iMinStepNum​

最小ステップ数を指定します（整数型）。

デフォルト値は0です。

dTimeStepSize​

タイムステップサイズを指定します（倍精度浮動小数型）。

デフォルト値は0.0です。

dMinTimeStep​

最小タイムステップを指定します（倍精度浮動小数型）。

デフォルト値は0.0です。

dMaxTimeStep​

最大タイムステップを指定します（倍精度浮動小数型）。

デフォルト値は0.0です。

iWriteResultFre​

結果の書き込み頻度を指定します（整数型）。

デフォルト値は1です。
