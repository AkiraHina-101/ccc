# JPT.ClearOutputLog()

JPT.ClearOutputLog()

Description​

Clear all the text existing in the Output window.

Syntax​

JPT.ClearOutputLog()

Inputs​

This utility function does not require any input value.

Return Code​

This utility function does not have output value.

Sample Code​

# Clear all the text existing on the Output window
JPT.ClearOutputLog()
