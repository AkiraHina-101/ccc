# Key Bind

Key Bind Key Bind Make settings for key binds (shortcut keys). Key Bind Table It is a setting table of key binds consisting of general keys (a-z, F1-F12, Insert, Delete, Space, Home, PageUp, PageUp) and special keys (None, Ctrl, Shift, Ctrl + Shift). Command Table It is a function table. Arbitrary functions can be assigned to any key combination by describing the numerical value of # in the combination position of the Key Binds table. Add button Register a new command in the command table. Language Check the command name displayed when specifying each language. Command name Enter the key bind name. Function Enter the execution function with a macro. Edit button Edit the registered command selected on the command table. Remove button Remove the command selected on the command table from the command table.
