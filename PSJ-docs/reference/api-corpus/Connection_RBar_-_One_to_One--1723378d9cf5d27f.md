# Connection | RBar - One to One

Connection | RBar - One to One Connection | RBar - One to One This function is to create one to one (Master : Slave) Rbar (Rigid Beam Element). In this feature, only that case is supported in which all independent degrees of freedom are on one side of the node. ＊Master node and the slave node can be selected on the parts basis, face basis, edge basis, element-wise or on node basis. Master node and slave node (in the connection range) are connected. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius R of the connection range. Master Dofs UX - RZ All components of the independent DOF is specified to the node selected as master. Analysis Coordinate Frame Coordinate Select the reference coordinate system. Options for Abaqus Surface Definition Output Select how to define the surface. By Node Set Specify the node as a reference surface. By Element Set Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspThe master nodes are selected from parts, face, edge, element and node. &nbspThe slave nodes are selected from parts, face, edge, element and node. &nbspSet the parameters. &nbspClick Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
