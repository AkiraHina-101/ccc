# ImportGeomBDF()

ImportGeomBDF()

Description​

Import Geometry bdf file

Syntax​

ImportGeomBDF(string[] vecPath, bool use_unit)

Inputs​

1. String[]​

Path directory

2. Bool​

Use unit True = 1, False = 0

Return Code​

"1": The function can be executed

"0": The function cannot be executed

Sample Code​

ImportGeomBDF(["D:/test.bdf"], 1)
