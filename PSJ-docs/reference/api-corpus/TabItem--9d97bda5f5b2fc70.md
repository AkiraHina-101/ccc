# TabItem

TabItem

Create a tab item inside the tab container TabWnd.

Preview dialog:

Parameters​

Name​

Enter name of the tab item.

Text​

Enter header of the tab item.

Orientation​

Specify position of components inside the tab item.

Horizontal : Arrange the inside components horizontally

Vertical : Arrange the inside components vertically

API associated with​

dlg.add_tabwnd_page : Add a TabItem (page) to the TabWnd component.
