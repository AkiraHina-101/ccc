# Add JTDB

Add JTDB Add JTDB Import JTDB with options Offset or Renumber IDs for duplicated ID models. Path Setting &nbsp;&nbsp;&nbsp;Add JTDB path setting. Add JTDB &nbsp;&nbsp;&nbsp;Select a JTDB file to be added to currently opened JTDB. Imported Model &nbsp;&nbsp;&nbsp;Select Imported Model to input parameters to offset/renumber the IDs of the imported model. Current Model &nbsp;&nbsp;&nbsp;Select Current Model to input parameters to offset/renumber the IDs of the current model. Offset/Renumber &nbsp;&nbsp;&nbsp;Select Offset ID or Renumber ID option. Option &nbsp;&nbsp;&nbsp;There are two options to deal with the duplicate IDs: - Offset ID : with this option, the selected model's entity IDs with the specified values in the textboxes are offset: Example: OffsetID selected Imported model IDs are selected to be offset. In this example, Node, Element and Part IDs are duplicated, their default status will be checked ON and Offset values are originally set to the maximum IDs values of their corresponding entities in the Current Model. After pressing OK to import the model, all IDs of the selected model's entities will be offset (added) by the specified Offset values. - Renumber ID : with this option, the selected model's entity IDs with the specified values in the textboxes are renumbered: Example: RenumberID selected Current model IDs are selected to be renumbered. In this example, Node, Element and Part IDs are duplicated, their default status will be checked ON and Start ID values are originally set to the maximum IDs values of their corresponding entities in the Imported Model plus 1. End ID values are calculated by adding the Start ID values by the corresponding number of entities. Show log file &nbsp;&nbsp;&nbsp;When Checked ON, a log file with offset/renumber ID information will appear after pressing OK. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
