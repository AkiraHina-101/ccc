# JMesher Solid Meshing

JMesher Solid Meshing JMesher Solid Meshing Create a tetrahedral solid element. It is offered as a trial version of the new solid mesher. Element type TET4 &nbsp;&nbsp;&nbsp;Create a tetrahedron primary element. TET10 &nbsp;&nbsp;&nbsp;Create a tetrahedron quadratic element. General &nbsp;&nbsp;&nbsp;Enter the basic parameters to create solid mesh. &nbsp;&nbsp;&nbsp;You can change the following three parameters of the generated solid element: Min Edge Length, Max Edge Length, and Gradation. You can also control the internal mesh size. &nbsp;&nbsp;&nbsp;Both Min Edge Length and Max Edge Length can be omitted, but Gradation must be set. Edge Length Min Edge Length &nbsp;&nbsp;&nbsp;Enter a positive real number. &nbsp;&nbsp;&nbsp;To create a coarser mesh, set a minimum edge length that is larger than the average surface mesh size. Max Edge Length &nbsp;&nbsp;&nbsp;Enter a positive real number. &nbsp;&nbsp;&nbsp;To create a finer mesh, set the maximum edge length smaller than the average surface mesh size. Mesh Gradation Gradation &nbsp;&nbsp;&nbsp;Gradation controls mesh uniformity. A gradation equivalent to 1.05 means that the mesh is mostly homogeneous. &nbsp;&nbsp;&nbsp;The priority of gradation is higher than those of Min Edge Length and Max Edge Length. Therefore, if the user sets the gradation to 1.05, the conditions of minimum edge length and maximum edge length may not be observed. Attribute Speed vs. Quality &nbsp;&nbsp;&nbsp;Basically, run the mesher with optimization and then run it again in optimization only mode one or more times. &nbsp;&nbsp;&nbsp;Running the mesher several times can increase meshing time due to redundant post processing. &nbsp;&nbsp;&nbsp;There are three modes: &nbsp;&nbsp;&nbsp; - Fastest: The Mesher runs only once in the default optimization process. &nbsp;&nbsp;&nbsp; - Standard: The Mesher runs once in the default optimization process, and once more in optimization only mode. &nbsp;&nbsp;&nbsp; - Optimized: The mesher runs once in the default optimization process and then four times in optimization only mode. &nbsp;&nbsp;&nbsp;In most cases, it should be enough to get rid of "bad shape elements" in Standard mode. Multiple CPU mesh Max Theads &nbsp;&nbsp;&nbsp;It is not supported in V4.0. We plan to support this in future versions. &nbsp;&nbsp;&nbsp;Set up parallel processing. Parallelization is performed by assigning a core to each body. &nbsp;&nbsp;&nbsp;It is recommended to select one thread per available core on the machine used to achieve the best performance. Thus, on a 4-core machine, the optimal maximum number of threads is 4 threads (1 per core). Advanced &nbsp;&nbsp;&nbsp;Enter detailed parameters for solid mesh creation.
