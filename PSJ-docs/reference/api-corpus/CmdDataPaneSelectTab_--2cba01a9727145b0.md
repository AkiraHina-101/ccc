# CmdDataPaneSelectTab()

CmdDataPaneSelectTab()

説明​

ウォッチウィンドウの特定のタブをアクティブにします。

構文​

CmdDataWindowSelectTab(int TabID)

入力​

1. int​

タブID。
1 : 節点
2 : 要素
3 : 位置
4 : 節点プロットスキャン
5 : 要素プロットスキャン
6 : 位置プロットスキャン
7 : ひずみゲージ
8 : ピークサーチ
9 : 最大/最小
10 : 面積の最大/最小
11 : 疲労強度
12 : 比較

戻り値​

なし。

サンプルコード​

CmdDataWindowSelectTab(3)
