# グリッドメッシュ

グリッドメッシュ グリッドメッシュ このコマンドは、四角形形状・三角形形状・ディスク形状のフェースに対して、格子状メッシュ（マップメッシュ）を作成します。 フェース形状 操作 &ensp;&emsp;適切なフェース形状のタイプを選択します 四角形 : ４つの頂点を定義したフェースに、マップメッシュを作成します 三角形 : ３つの頂点を定義したフェースに、マップメッシュを作成します ディスク : ディスク形状のフェースに、メッシュを作成します 自動 : 適切なフェース形状のタイプを自動認識します（推奨） メッシュ数 UIコントロール: X ,Y &ensp;&emsp;X（短辺）およびY（長辺）方向のメッシュ数 &#126; : 分割数を増やす &ensp;&emsp;ヒント: キー &#147; をクリックして数を増やします。 マウスを上にスクロールして数を増やします &#128; : 分割数を減らす &ensp;&emsp;ヒント: キー &#148; をクリックして数を減らします。 マウスを下にスクロールして数を減らします。 : XとYの値を交換します。 &ensp;&emsp;フェースを選択すると、メッシュ分割数が自動的に提案されます。 固定 &ensp;&emsp;チェックボックスがチェックされている場合：新しいフェースを選択した後も、分割数が保持されます。 マウスとキーボードの制御 &ensp;&emsp; マウスポインタ メインウィンドウの分割数にマウスオーバーすると、GUI上の分割数がフォーカスされ、上下キーで数値を変更できます。 &ensp;&emsp; キーボード カーソルがGUIをフォーカスしている間のショートカット一覧: Tab キーでX軸とY軸の分割数のフォーカスを切り替えます。 上下キーでフォーカスされている分割数を増減します。 数字キーで分割数を入力します。 バックスペースキーで分割数を削除します。 スペースキーで機能を実行します。 平均サイズ &ensp;&emsp;マップメッシュのサイズが入力された平均値になるよう、X軸およびYメッシュ数を自動的に計算します。 アスペクト &ensp;&emsp;マップメッシュのアスペクト比が入力された値になるよう、片方の軸の分割数を固定して、もう片方の分割数を計算します。 &ensp;&emsp;※ (Yのメッシュサイズ) = アスペクト x (Xのメッシュサイズ) &ensp;&emsp;※ XとYのいずれかの固定チェックボックスがオンであること （バックグラウンド実行）メッシュ分割数のコネクションを保持 &ensp;&emsp;V5のグリッドメッシュから、複数フェースを同時にメッシングする場合、隣り合うフェース同士のメッシュ数が自動的にリンクされます。 &ensp;&emsp;次に選択されるフェースのメッシュ分割数は、以前に選択された隣接するフェースと共有するエッジのメッシュ数に基づいて、自動計算されます。隣接フェースと連続するように、分割数を手動入力する必要はありません。 遷移領域 隣接フェース &ensp;&emsp;周囲のフェースに遷移領域を作成します（マップメッシュされるフェースの外側一層のメッシュを変更します） ターゲットフェース &ensp;&emsp;マップメッシュされるフェースに遷移領域を作成します（マップメッシュされるフェースの内側一層のメッシュを変更します） グリッドメッシュタイプ 三角形 &ensp;&emsp;三角形要素を生成します。 四角形 &ensp;&emsp;四角形要素を生成します。 要素をスワップ &ensp;&emsp;三角形の対角線が最も短くなるように、要素エッジの方向を変更します。 &ensp;&emsp;※ このオプションは三角形要素のみに対応します。 複数選択 独立 &ensp;&emsp;選択したフェース毎にマップメッシュを生成します マージ &ensp;&emsp;選択したフェースをマージしてから、マップメッシュを生成します。 &ensp;&emsp;※ マージされたフェースのIDは、選択したフェースの最小IDになります。 詳細設定 グループボックスは折りたたむことができます。 グループを追加 &ensp;&emsp;グループの追加は、グリッドメッシュされたフェースの管理に役立ちます。 1 : グリッドメッシュが実行される度に、対象のフェースが、1つのフェースグループに追加されていきます。 複数 : グリッドメッシュが実行される度に、対象のフェースで、新しいフェースグループを作成します。 ローカルメッシュ設定を使用 &ensp;&emsp;ローカルメッシュ設定を考慮して、メッシュ数を提案します。 &ensp;&emsp;参照するローカルメッシュ設定は、エッジ分割数とフェースメッシュサイズです（フェースメッシュサイズが優先されます） &ensp;&emsp;※ フリーズメッシュがある場合、グリッドメッシュは機能しません。 CADプロジェクション &ensp;&emsp;作成されたマップメッシュを元のCAD形状に投影して、ジオメトリを維持します。 最適化 &ensp;&emsp;最適化は、メッシュのレイヤが大きく曲がる際のメッシュ分割を改善するために、特別に使用されます。 &ensp;&emsp;これにより、メッシュ分割がより均等でまっすぐになります。 &ensp;&emsp;※ 場合によっては、最適化を使用しない方が、パフォーマンスが向上します。 プレビュー &ensp;&emsp;プレビューを表示します（メッシュの最終結果ではありません） 選択リスト フェース &ensp;&emsp;グリッドメッシュを実行するフェースを選択します。 頂点の変更 &ensp;&emsp;[頂点の変更]ボタンをクリックして、機能をアクティブにします。 &ensp;&emsp;選択したフェースのエッジ上の節点をクリックすると、近くの頂点がその節点の位置に移動します。 &ensp;&emsp;マップメッシュのプレビュー結果が悪い場合、この操作で四角形や三角形の頂点位置を変更する事で、マップメッシュのデザインを調整できます。 境界節点をキープ &ensp;&emsp;選択したフェースのエッジ上の要素エッジを選択することにより、そのエッジの節点を保持します。 &ensp;&emsp;フェース形状別の、節点を保持できるエッジ数： 四角形 : 2つの隣接するエッジ 三角形 : 1つのエッジ ディスク : 1つのエッジ -&nbsp;操作手順&nbsp;- &nbsp;フェース形状: [自動]をオンにします。オフの場合は、目的の形状を選択します(四角形/三角形/ディスク) &nbsp;選択リスト: 対象フェースまたはグループフェースを選択します。 &nbsp;メッシュ数: メッシュ分割数を入力します。必要に応じて、平均サイズまたはアスペクト比を指定します。 &nbsp;グリッドメッシュタイプ: 作成するメッシュタイプを選択します。
