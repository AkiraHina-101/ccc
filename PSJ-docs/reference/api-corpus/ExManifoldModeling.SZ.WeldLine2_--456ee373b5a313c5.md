Description​

ExManifoldModeling.SZ.WeldLine2(crlFaces, crlParts, dLayerWidth, iLayerNumber)

Ribbon: ExManifoldModeling » SZ » WeldLine2

Inputs​

crlFaces​

A List of Cursor specifying the face.

This is a required input.

crlParts​

A List of Cursor specifying the part.

This is a required input.

dLayerWidth​

A Double specifying the layer width.

This is a required input.

iLayerNumber​

An Integer specifying the layer number.

This is a required input.

Return Code​

A String of 1 if success, or 0 if fail.
