# ツールメニュー

ツールメニュー ツールメニュー ダイアログやウィザードの作成に関する操作を行います。 ツールメニュー詳細 アイコン 名称 説明 ショートカットキー Make a new dialog 作成中の設定をクリアして新規画面を開きます。 F5 Open an existing database データベースファイルを開きます。 F4 Save dialog settings to database 作成したダイアログを外部データベースファイルに保存します。 F6 Undo 実行した操作を取り消し、ひとつ前の状態に戻します。 Redo 取り消した操作を再度実行します。 Show or hide code window コードウィンドウの表示/非表示を切り替えます。 F1 Preview dialog 作成したダイアログをプレビュー表示します。 F2 Integrate 作成したダイアログを任意フォルダに保存し、リボン内に実装します。 F3 Help ヘルプを表示します。(現在作成中)
