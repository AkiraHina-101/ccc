デフォルト値は0です。

アルゴリズムを指定する Integer です。

デフォルト値は0です。

デフォルト値は DFLT_DBL です。

dFRIC​

f r i c を指定する Double です。

デフォルト値は DFLT_DBL です。

dSLIDE​

s l i d e を指定する Double です。

デフォルト値は DFLT_DBL です。

iICOORD​

i c o o r d を指定する Integer です。

デフォルト値は DFLT_INT です。

dSFACT​

s f a c t を指定する Double です。

デフォルト値は DFLT_DBL です。

iIshellelemfaceSlave​
