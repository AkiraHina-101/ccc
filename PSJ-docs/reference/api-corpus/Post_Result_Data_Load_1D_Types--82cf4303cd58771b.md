# Post Result Data Load 1D Types

Post Result Data Load 1D Types

これはポスト結果データ読み込み1Dタイプを表す列挙型です。

 | ID | ポスト結果データ読み込み1Dタイプ | 説明

 | 0 | JPT.PostResultDataLoad1D.POST_LOAD1D_UNKNOWN | 未定義の1Dデータ。

 | 1 | JPT.PostResultDataLoad1D.POST_LOAD1D_PT_1 | ビーム要素の応力回復ポイント1を出力します。

 | 2 | JPT.PostResultDataLoad1D.POST_LOAD1D_PT_2 | ビーム要素の応力回復ポイント2を出力します。

 | 4 | JPT.PostResultDataLoad1D.POST_LOAD1D_PT_3 | ビーム要素の応力回復ポイント3を出力します。

 | 8 | JPT.PostResultDataLoad1D.POST_LOAD1D_PT_4 | ビーム要素の応力回復ポイント4を出力します。

 | 16 | JPT.PostResultDataLoad1D.POST_LOAD1D_MAX | ビーム要素の最大結果を出力します。

 | 32 | JPT.PostResultDataLoad1D.POST_LOAD1D_MIN | ビーム要素の最小結果を出力します。
