# Message Console Types

Message Console Types

これはメッセージコンソールタイプを表す列挙型です。

 | ID | メッセージコンソールタイプ | 説明

 | 1 | JPT.MsgConsoleType.MSG_EXECUTION | 実行メッセージ

 | 2 | JPT.MsgConsoleType.MSG_RETURN | 戻り値メッセージ

 | 3 | JPT.MsgConsoleType.MSG_EXECUTION_RETURN | 実行および戻り値メッセージ

 | 4 | JPT.MsgConsoleType.MSG_USER | ユーザーメッセージ（印刷/デバッグ）

 | 5 | JPT.MsgConsoleType.MSG_ALL | すべてのメッセージ
