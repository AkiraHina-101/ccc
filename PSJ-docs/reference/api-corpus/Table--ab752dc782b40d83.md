# Table

Table Table Add a table. &nbsp;&nbsp;&nbsp;Creation image： Name &nbsp;&nbsp;&nbsp;Enter the Table component. Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Show Grid Line &nbsp;&nbsp;&nbsp;Specify the display of the grid line. Check On &nbsp;:&nbsp;Displays a grid line Check Off &nbsp;:&nbsp;Does not display the grid line Show Row Number &nbsp;&nbsp;&nbsp;Specify the display of the line number. Check On &nbsp;:&nbsp;Displays the line number Check Off &nbsp;:&nbsp;Does not display the line number Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the table.（Unit: Pixels） Height &nbsp;&nbsp;&nbsp;Specifies the minimum height of the table.（Unit: Pixels） Pop Menu Options &nbsp;&nbsp;&nbsp;Specify the menu of right click. &nbsp;&nbsp;&nbsp;Supported Options： &nbsp;&nbsp;&nbsp;Cut, Copy, Paste, Insert Row, Delete Row, Clear Content, Read From File, Write To File Total Rows Count &nbsp;&nbsp;&nbsp;Specifies the default display of the number of lines. Column Setting &nbsp;&nbsp;&nbsp;Specify the type of the column. &nbsp;&nbsp;&nbsp;Heading*：Specify the type of column to be specified. Command to use Command Description Sample Code dlg.set_cell_value("table name", "(cell_row_id, cell_column_id)", "value") Set the value to the row/column of the specified index. Input: dlg.set_cell_value("table name", "(1, 1)", "value") dlg.get_cell_value("table name", "(cell_row_id, cell_column_id)") Gets the value of the specified index row/column. Input: dlg.get_cell_value("table name", "(1,1)") dlg.get_total_row("table name") Gets the total number of rows in the table. Input: dlg.get_total_row("table name") dlg.get_total_column("table name") Gets the total number of columns in the table. Input: dlg.get_total_column("table name")
