# Spring()

Spring()

説明​

スプリング接続を作成します

構文​

Spring(int method, String name, Cursor[] master, Cursor[] slave,Cursor coord, int springType,
    int ground, double tol, int dir, int distMode, int dof1, int dof2, double dampCoef,
    double stressCoef, double[3] transStiffness, double[3] rotStiffness, Cursor editObj )

入力​

1. Int​

スプリングを作成する方法、17: 任意のエンティティ（1:1）

2. String​

スプリングの名前

3. Cursor[]​

スプリングのマスターエンティティ

4. Cursor[]​

スプリングのマスターエンティティ

5. Cursor​

参照される座標系、NULLはグローバルです

6. Int​

スプリングのタイプ、0: 一般的、1: DoF、2: 均一DoF

7. Int​

接地しているかどうか、0: いいえ、1: はい

8. Double​

節点ペアを見つけるための許容値

9. Int​

スプリングの方向、0: 異方性、1: 等方性

10. Int​

分散モード、未使用

11. Int​

参照先のDoF

12. Int​

ターゲットのDoF

13. Double​

減衰係数

14. Double​

応力係数

15. Double[3]​

剛性

16. Double[3]​

回転剛性

17. Cursor​

編集モードに使用します

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

Spring(17, "Spring_1", [5:66316], [5:66299], 0:0, 2, 0, 0, 0, 0, 0, 0, 1.2, 1.5,
    [1000, 2000, 1000], [1.7976931e+308, 1.7976931e+308, 1.7976931e+308], 1, 0:0)
