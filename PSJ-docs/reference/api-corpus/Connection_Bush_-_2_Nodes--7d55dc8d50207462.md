# Connection | Bush - 2 Nodes

Connection | Bush - 2 Nodes Connection | Bush - 2 Nodes Create a bush element (generalized spring - damper) for the two selected nodes. Connections Name Set the name of bush element to be created. Bush Grounded When you check this box, one side is defined as the ground (spring). Orientation by Select the orientation method of the bush element. Orientation Vector Specified by the direction vector Coordinate system Specified by the coordinate system Coordinate System If you select specified by the coordinate system, select an existing coordinate system you want to use from the list. Orientation Vector If you select specified by the direction vector, enter a comma-separated direction vector in the order of X, Y, Z. Stiffness 1〜6 Enter stiffness value for each degree of freedom. Local Unit Select the unit system to be used in the stiffness value input. Damping coefficients 1〜6 Enter the damping coefficient for each degree of freedom. Local Unit Select the unit system to be used in the damping coefficient input. Damping constant 1〜6 Enter structural damping constant for each degree of freedom. Local Unit Select the unit system to be used in the structural damping constant input. Stress recovery translation Enter the stress recovery coefficient of the translation component. Stress recovery rotation Enter the stress recovery coefficient of the rotation component. Strain recovery translation Enter the strain recovery factor of the translation component. Strain recovery rotation Enter the strain recovery coefficient of the rotation component. -&nbspOperating Procedure&nbsp- &nbspIn Selection List ensure Master button is active to select the node at one end of the bush element. &nbspIn Selection List ensure Slave button is active to select the node at the other end of the bush element. &nbspChoose how to specify the direction vector from Orientation By. Enter the direction vector according to the specified method. &nbspEnter the values such as stiffness value, damping coefficient, structural damping constant, recovery factor in the input field. &nbspClick the Apply or OK button to create the bush element between the nodes. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
