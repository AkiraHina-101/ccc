# PSJでの行列の修正にnumpyを使用する

PSJでの行列の修正にnumpyを使用する

🎯 はじめに​

このチュートリアルでは、numpy ライブラリ を使用して以下のことを学びます:

節点位置を含むサイズ nx3 の行列を作成する (n は節点の数)。

軸に沿った最大値のインデックスを返す。

行列をソートする。

各行の平均値を計算する。

📖 チュートリアル​

# Encoding for Japanese
# coding: cp932

import numpy as np

# シンプルなパートを作成する
Geometry.Part.Cube()

# 配列を作成する
arr = np.array([[_.pos.x, _.pos.y, _.pos.z] for _ in JPT.GetAllNodes()])
print(arr.reshape(len(arr), 3))

# 軸が指定されていない場合は、全体の配列に対して動作する
print(np.argmax(arr))

# axis=1 の場合、各行に対して動作する
print(np.argmax(arr, axis=1))

# axis=0 の場合、各列に対して動作する
print(np.argmax(arr, axis=0))

# 全体の配列をソートする
print("全体の配列をソート: \n" + str(np.sort(arr, axis=None)))

# 各行に沿ってソートする
print("各行に沿ってソート: \n" + str(np.sort(arr, axis=1)))

# 各列に沿ってソートする
print("各列に沿ってソート: \n" + str(np.sort(arr, axis=0)))

for i in range(len(arr)):
    print("--- 平均: " + str(np.mean(arr[i])))
