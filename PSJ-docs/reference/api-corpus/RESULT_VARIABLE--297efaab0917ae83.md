# RESULT_VARIABLE

RESULT_VARIABLE

Description​

A data type uses to identify the selected result.

Attributes​

crReferencePostJob​

A Cursor specifying the reference post job.

The default value is None.

strName​

A String specifying the variable name.

The default value is "".

iAnalysisType​

An Integer specifying the analysis type.

The default value is 0.

iResultSet​

An Integer specifying the result step.

The default value is 0.

iTimeStep​

An Integer specifying the time step.

The default value is 0.

iResultType​

An Integer specifying the result type.

The default value is 0.

iResultPos​

An Integer specifying the result position.

The default value is 0.
