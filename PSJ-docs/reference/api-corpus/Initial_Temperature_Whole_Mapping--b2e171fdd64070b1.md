# Initial Temperature | Whole Mapping

Initial Temperature | Whole Mapping Initial Temperature | Whole Mapping This command maps temperature results of the Heat Transfer analysis from Nastran, ADVC (format2), ABAQUS, and CSV to the whole model as Initial Temperature. Name Name Set the Initial Temperature name. Value Result Type Select the format for the Temperature results file. In the case of CSV, enter the X coordinate value, Y coordinate value, Z coordinate value and temperature separated by commas. For example: 1,1,1,100 5,5,5,50 9,9,9,10 Mapping Result Selection Locate the Temperature results file. Step(Subcase) in Result Specify the ID of the step (subcase) that contains the temperature results. Input Unit Specify the input unit of temperature result values. Preview Mapping data Preview Show the preview of mapping data on selected part(s) same as original result data. Clear Remove the mapping data in preview. Result Preview Show the preview of mapping results on selected part(s). Clear Remove the mapping results in preview. Mapping Option Method Select the mapping method. Nearest : Use the result of the nearest node. -&nbspOperating Procedure&nbsp- From Result Type, select the format of the Temperature results file. Locate the Temperature Load file by pressing the Browse button. Select a method used for mapping from Method. Change other parameters as needed. Select the parts. Click Apply/OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
