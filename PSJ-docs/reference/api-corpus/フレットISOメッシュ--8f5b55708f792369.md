# フレットISOメッシュ

フレットISOメッシュ フレットISOメッシュ このコマンドではフィレットを抽出し、抽出したフィレットに設定値のISOメッシュ（マップドメッシュ）を作成します。 ステップ 操作 &nbsp;&nbsp;&nbsp;フィレット部分を抽出する方法を選びます。 &nbsp;&nbsp;&nbsp;選択 ：フィレット部分を抽出します。 &nbsp;&nbsp;&nbsp;マッピングされた形状 ：マップドメッシュを作成します。 &nbsp;&nbsp;&nbsp;XML ：情報をXMLファイル形式で入力します。 &nbsp;&nbsp;&nbsp;&nbsp;適用/OKボタンを押すと、ファイル入力ダイアログボックスが表示されます。 選択 最小フェース幅 &nbsp;&nbsp;&nbsp;検索するフェース幅の最小値を指定します。 最大フェース幅 &nbsp;&nbsp;&nbsp;検索するフェース幅の最大値を指定します。 最小曲率半径 &nbsp;&nbsp;&nbsp;検索するフィレットの半径の最小値を指定します。 最大曲率半径 &nbsp;&nbsp;&nbsp;検索するフィレットの半径の最大値を指定します。 最小角度 &nbsp;&nbsp;&nbsp;検索するフィレットの角度の最小値を指定します。 最大角度 &nbsp;&nbsp;&nbsp;検索するフィレットの角度の最大値を指定します。 凸面体 &nbsp;&nbsp;&nbsp;凸面フィレットを検索します。 凹面体 &nbsp;&nbsp;&nbsp;凹面フィレットを検索します。 マップドメッシュ 円周上の分割数 &nbsp;&nbsp;&nbsp;フレット円周方向の分割数を設定します。 軸の平均サイズ &nbsp;&nbsp;&nbsp;フレット軸方向の平均メッシュサイズを設定します。 エラートレランス &nbsp;&nbsp;&nbsp;トレランスを設定します。 -&nbsp;操作手順&nbsp;- &nbsp;操作から”選択”を選び、対象となるパーツかフェース群を選択します。 &nbsp;検索するフィレットのフェース幅の最大値、最小値を入力します。 &nbsp;検索するフレットの曲率半径の最大値、最小値を入力します。 &nbsp;検索するフレットの角度の最大値、最小値を入力します。 &nbsp;検索するフレットが凸形状か凹形状か指定します。 &nbsp;適用ボタンをクリックすると、指定した範囲内のフィレットフェースが対象パーツから選択されます。 &nbsp;操作から”マッピングされた形状”を選びます。 &nbsp;作成するフレットメッシュの円周方向の分割数を入力します。 &nbsp;作成するフレットメッシュの軸方向の平均メッシュサイズを入力します。 &nbsp;メッシュ作成時のエラートレランスを入力します。 &nbsp;適用/OKボタンをクリックすると、選択されたフィレットフェースにISOメッシュ（マップドメッシュ）を作成します。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
