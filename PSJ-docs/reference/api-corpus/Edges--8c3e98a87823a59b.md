# Edges

Edges Edge Set the mesh size unit of the edge. Define the settings for the entire mesh creation process, before the mesh creation. Configuration of the mesh size will be applied. Mesh Parameters Name Set the mesh control name. Freeze Mesh Freeze Mesh When checked, it maintains the current mesh. Mesh Size Mesh Size Set the size of the element. Average Set the average mesh size. Minimum Set the minimum mesh size. Maximum Set the maximum mesh size. Keep Entity Keep Entity When checked, it preserves the shape of the face at the time of creating mesh. Mesh Count Mesh Count When checked, it specifies the number of divisions of the edge. Number of Divisions Specify the number of divisions. Method Specify how to divide. Equal Equally divided Bias Biased division from the specified point (node) position (select a node as the starting point also) Bias-Center Biased division with dense center area Bias-Sides Biased division with both dense sides Bias Factor Bias factor (equal ratio “r” or equal difference “d”) Progression Specify the sequence of numbers. Geometric Equal ratio (*r) bias Arithmetic Equal difference (+d) bias Geometry Approximation Geometry Approximation When checked, you can make settings relating to the shape reproducibility. Trim Angle Specify the maximum facet angle for trimming. Advanced Option Local Mesh Preview When checked, you can preview the selected edge mesh with a required Mesh count. Note: If a small mesh size is set for the model size, it may take time to display the mesh preview.
