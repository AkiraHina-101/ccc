# マウスとキー

マウスとキー マウス メインウィンドウ上でのマウス操作設定を及びキーバインドを任意に変更します。各社CAD/CAEソフトウェアのマウスボタン設定をプリセットで用意しています。 プリセット マウスボタン設定リストです。リスト内アイテムをクリックして選択します。V4.1より、HMプリセットにビュー操作のキーバインドが追加されました。 新規作成 クリックすると、新規マウスボタン設定セット（MyPreset#）を作成します。 削除 クリックすると、作成したプリセットのうちハイライトしたものを削除します。 ※特殊プリセット HM, I-DEASプリセットに設定されたコントロールは、変更することはできません。また、他のプリセットで使用することもできません。 マウスボタン設定 プリセットで選択した設定の詳細が表示されます。新規に作成したプリセットは、マウスボタン及びキーを任意に割り付けることが可能です。 回転 ビュー回転操作を行うマウスボタン及びキーを指定します。 ビュー回転中心変更モード：マウス操作から回転中心の位置変更が行えるようになります。 -"回転"に割り当たっているボタンをクリックします。 -キーを使用する場合は、キー＋"回転"に割り当たっているボタンをクリックします。 パン ビュー平行移動操作を行うマウスボタン及びキーを指定します。 ズーム ビュー拡大・縮小操作を行うマウスボタン及びキーを指定します。 ズームインオペレーション ビュー拡大操作時にマウスカーソル及びホイールを動かす方向を指定します。 ビューフィット ※HMプリセットのみ表示 ビューフィット操作を行うマウスボタン及びキーを表示します。 エンティティ選択 エンティティ選択操作を行うマウスボタン及びキーを指定します。 共通 ポインタの速さ 回転・平行移動・拡大縮小の速度を調節します。 ピック範囲選択 エンティティ選択時のハイライト範囲をピクセル単位で指定します。 キーバインド キーバインド有効 キーバインド（ショートカットキー）の設定を有効にします。 カスタマイズボタン キーバインド設定ダイアログ を表示します。 リセットボタン キーバインド（ショートカットキー）の設定をリセットします。 ※V4.0からキーバインドの設定ファイルはバージョン毎に独立し、バージョン間のコンフリクトが無くなりました。 -&nbsp操作手順&nbsp- &nbsp;コマンドを起動し、各オプションを指定して適用もしくはOKボタンをクリックします。 -&nbsp操作手順（新規マウス設定の作成）&nbsp- &nbsp;コマンドを起動し、新規作成ボタンをクリックします。 &nbsp;プリセットにMyPreset#(#は整数）が新規作成されますので、クリックしてハイライトします。 &nbsp;任意のマウスボタン設定を多ないます。キーの欄にカーソルを合わせて設定したいキーのボタンを押すと、キーバインドを指定できます。キーバインドは各項目内のリセットボタンで消去できます。 適用もしくはOKボタンをクリックして、変更を保存します。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
