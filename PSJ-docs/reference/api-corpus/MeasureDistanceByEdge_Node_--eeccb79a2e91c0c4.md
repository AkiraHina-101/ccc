# MeasureDistanceByEdge_Node()

MeasureDistanceByEdge_Node()

説明​

エッジとノートの間の距離を測定します。

構文​

MeasureDistanceByEdge_Node(エッジのカーソル, ノートのカーソル, 整数 N)

入力​

1. Cursor​

エッジのカーソル（5:,=エッジID）

2. Cursor​

ノートのカーソル（10:,=ノートID）

3. Int N​

小数点以下の桁数を指定します（0<=N<=30）

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

MeasureDistanceByEdge_Node(5:18,10:459,6)
