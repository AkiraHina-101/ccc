# ADVC_CONVERGENCE

ADVC_CONVERGENCE

Description​

A data type uses to control parameters of ADVC Convergence

Attributes​

dCgTol​

A Double specifying cg tolerance.

The default value is DFLT_DBL.

dCgNrTol​

A Double specifying cg nr tolerance.

The default value is DFLT_DBL.

dCgDispTol​

A Double specifying cg displacement tolerance.

The default value is DFLT_DBL.

dCgNrDispTol​

A Double specifying cg nr displacement tolerance.

The default value is DFLT_DBL.

dCgDispLimitTol​

A Double specifying cg displacement limit tolerance.

The default value is DFLT_DBL.

dCgTotalDispLimitTol​

A Double specifying cg total displacement limit tolerance.

The default value is DFLT_DBL.

dNewtonTol​

A Double specifying newton tolerance.

The default value is DFLT_DBL.

dNewtonDispTol​

A Double specifying newton displacement tolerance.

The default value is DFLT_DBL.

dNewtonDispLimitTol​

A Double specifying newton displacement limit tolerance.

The default value is DFLT_DBL.

dNewtonTotalDispLimitTol​

A Double specifying newton total displacement limit tolerance.

The default value is DFLT_DBL.

iCgloopMax​

An Integer specifying cgloop maximum.

The default value is DFLT_INT.

iNewtonMax​

An Integer specifying newton maximum.

The default value is DFLT_INT.

dHtNlLoopTol​

A Double specifying ht nl loop tolerance.

The default value is DFLT_DBL.
