# TSV-Pre

TSV-Pre TSV-Pre TSV-Preファイル（.vdb）を読み込みます。 1つの.vdbファイルに復数のモデルが含まれている場合、モデル数だけのドキュメントを作成します。 データはテンポラリフォルダに一時保存されますので、必要なものを別名保存してください。 ※Mapping Convetionデータが含まれる場合の注意。 TSVからJupiterに正しくデータを渡すために、以下の点にご注意ください。 １）VDBファイルの単位系をJupiterで使用する単位系に正しく合わせてください。 特に温度は℃とKを正しく選択してください。 VDBインポート機能では、VDBファイルをインポート後に強制的にJupiterのドキュメント単位系をVDBファイルの単位系に合わせます。 Mappingデータは単位系がないので、VDBファイル読み込み時点の単位系を作業するドキュメント単位系にする必要があります。 ２）TSVのMapping Conventionデータのダイアログで単位系を正しく選択してください。こちらの単位も変換時に参照されます。 以上のように正しく設定されたデータは、Jupiterに正しい単位系で取り込まれます。 -&nbsp操作手順&nbsp- &nbsp;メニューを選択すると「ファイルを開く」ダイアログが表示されますので、読み込みたいデータを選択して「開く」ボタンをクリックします。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
