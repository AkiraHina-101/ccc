# Move Node

Move Node a.no-uline {text-decoration:none} Move Node Move a node or a floating node. Absolute &nbsp;&nbsp;&nbsp;Move to any position. Offset &nbsp;&nbsp;&nbsp;Move in any direction. Normal Offset &nbsp;&nbsp;&nbsp;Move in the vertical direction of the face. Along Direction &nbsp;&nbsp;&nbsp;Move in any direction. Point &nbsp;&nbsp;&nbsp;Indicate the destination by specifying an arbitrary point, and move the node. CAD Follows &nbsp;&nbsp;&nbsp;By dragging a node, you move it anywhere on the face. Project To Line &nbsp;&nbsp;&nbsp;Move on a straight line. Project To Plane (Element) &nbsp;&nbsp;&nbsp;Project the selected nodes or floating points at the shortest distance onto the plane defined by the element. Project To Plane (3 Nodes) &nbsp;&nbsp;&nbsp;Move any target node on the plane defined by the three reference nodes by the shortest distance. Straighten Midnodes &nbsp;&nbsp;&nbsp;Move the mid node to the linear interpolation position of the corner node. Along Cylinder &nbsp;&nbsp;&nbsp;Move the nodes on the defined virtual cylinder. Coincident Nodes &nbsp;&nbsp;&nbsp;Move multiple nodes to the same position. Equalize &nbsp;&nbsp;&nbsp;Arrange nodes on selected edges evenly. Scale &nbsp;&nbsp;&nbsp;Scale the selected node group while maintaining the ratio between nodes. Smoothing Refine Quality &nbsp;&nbsp;&nbsp;Smooth on the basis of element quality. Laplacian &nbsp;&nbsp;&nbsp;Smooth referring to surrounding nodes and element centers.
