# クレイワーク(Clay Work)

クレイワーク(Clay Work) クレイワーク(Clay Work) ソリッドメッシュパーツに対して、簡易デザイン変更をする機能です。 具体的には、小さな球体を積み重ね、ラッピングした形状をソリッドリメッシュにより、パーツに盛る、もしくは削ります。本機能実行後、そのまま再解析をすることができます。 例）ボルト穴の隣へのリブ追加を検討 球体配置 ソリッドメッシュ形状追加（該当箇所のみリメッシュ） リメッシュされた要素と節点は、「ClayWork」の名前でグループ化されます。 選択リスト(Selection list): プロセス(Process) = 球体配置(Spheres) フェース任意点(Face Point)：球体の中心位置をフェース任意点で選択 エッジ任意点(Edge Point)：球体の中心位置をエッジ任意点で選択 節点(Node)：球体の中心位置を節点で選択 選択リスト(Selection list): プロセス(Process) = ブーリアン 和(Boolean +) / ブーリアン 差(Boolean -) パーツ(Part)：ラッピング形状を盛る、もしくは削るパーツ(1つ) 操作(Operation) プロセス(Process) 実行するオペレーションを選択します。 球体配置(Spheres) 球体を作成します。 ブーリアン 和(Boolean +) 球体をラッピングして、その形状を選択したパーツに盛ります。 ブーリアン 差(Boolean -) 球体をラッピングして、その形状を選択したパーツから削ります。 球体配置パラメータ(Spheres Parameter) 半径(Radius) 球体の半径パラメータです。プレビュー中に変更できます。 ラッピング方法(Wrapping Method) タイプ(Type) 球体をラッピングする方法を選択します。 タイト(Tight) 球体全体を囲んで、ラッピング形状を作成します。 凸形状(Convex) 球体全体を最小の凸形状で囲んで、ラッピング形状を作成します。 -&nbsp操作手順&nbsp- プロセス(Process)で、球体配置(Spheres)を選択します。 フェース任意点(Face Point) / エッジ任意点(Edge Point) / 節点(Node)を選択して、球体の中心位置を指定します。球体のプレビューが表示されます。 必要に応じて、半径(Radius)を変更します。 タイト(Tight) でラッピングする場合：球体で目的の形状を作るように、敷き詰めて配置します。 凸形状(Convex)でラッピングする場合：目的の形状の凸部位置に、球体を配置します。 必要に応じて、不要な球体を削除したり、新しい球体を追加します。 実行(Apply)ボタンをクリックします。球体パーツが作成されます。 球体パーツは、「Temp_Sphere」という名前のサブアセンブリツリーに追加されます。 プロセス(Process)で、ブーリアン 和/差(Boolean +/-)を選択します。 タイプ(Type)を選択します。 タイト(Tight) を選択した場合：球体全体を囲んで、ラッピング形状を作成します。 凸形状(Convex)を選択した場合：球体全体を最小の凸形状で囲んで、ラッピング形状を作成します。 パーツ(Part)を選択します。球体のラッピング形状のプレビューが表示されます。 適用(Apply) / OKボタンをクリックします。 ブーリアン 和(Boolean +)を選択した場合：球体をラッピングして、その形状を選択したパーツに盛ります。 ブーリアン 差(Boolean -)を選択した場合：球体をラッピングして、その形状を選択したパーツから削ります。 -&nbsp注意事項&nbsp- リメッシュサイズは、球体周りの選択パーツの平均メッシュサイズです。 ブーリアン 和/差(Boolean +/-)でメッシングエラーが発生した場合は、下記が考えられます。 選択パーツに対して積み重ねた球体のサイズが大きい。 周囲のメッシュサイズに対して、積み重ねた球体が小さい。 タイト(Tight)：任意形状に適用できます。球体を隙間なく配置する必要があります。パーツ選択時のラッピング時間は少し遅いです。リメッシュ時間は同等です。 凸形状(Convex)：曲面に配置する場合や、長手方向に曲がった配置には適用できません。球体の配置が凸部のみです。パーツ選択時のラッピング時間が早いです。リメッシュ時間は同等です。
