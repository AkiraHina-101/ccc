# Add Pre Document

Add Pre Document Add Pre Document Import a Pre document to the current document. ID offset or ID renumbering are available to deal with duplicate IDs. Path Setting &nbsp;&nbsp;&nbsp;Specify the path to the Pre Document. Add Pre Document &nbsp;&nbsp;&nbsp;Select a Pre Document file to be added to active document. Imported Model &nbsp;&nbsp;&nbsp;Activate the button to input parameters to offset/renumber the IDs of the imported model. Current Model &nbsp;&nbsp;&nbsp;Activate the button to input parameters to offset/renumber the IDs of the current model. Offset/Renumber &nbsp;&nbsp;&nbsp;Setting configuration parameters for Offset/Renumber operation. Option &nbsp;&nbsp;&nbsp;There are two options available to deal with the duplicate IDs: Offset ID : The IDs of the selected model entities are offset using the specified values in the text boxes. Example: OffsetID is selected In this example, Imported model IDs are selected to be offset. Node, Element, Face, Edge and Part IDs are duplicated, their default state is checked. Offset values are originally set to the maximum ID numbers of their corresponding entities in the Current Model. After pressing OK button, all IDs of the specified objects of the selected model will be offset (added) at the specified values. Renumber ID : The IDs of the selected model entities are renumbered using the specified values in the text boxes. Example: RenumberID is selected In this example, Imported model IDs are selected to be renumbered. Node, Element, Face, Edge and Part IDs are duplicated, their default state is checked. Start values are originally set to the maximum ID numbers of their corresponding entities in the Current Model and plus one. End values are calculated by adding the corresponding number of entities of the selected model to the Start value. After pressing OK button, all IDs of the specified objects of the selected model will be renumbered according to the specified values. Show Log file &nbsp;&nbsp;&nbsp;When checked, a log file with offset/renumber ID information will appear after pressing OK. Unit System Option &nbsp;&nbsp;&nbsp;Select the units system to display in the current document. Current Unit System : Holds the units system of the current document. The numbers in the imported file are to be converted to the unit system of the current document. Imported Unit System : Use the units system of the import file. The numbers in the current document is to be converted to the unit system of the import file. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
