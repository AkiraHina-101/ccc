# MeshEdit.MoveNode.CoincidentNodes()

MeshEdit.MoveNode.CoincidentNodes()

Description​

Coincident Nodes

Syntax​

MeshEdit.MoveNode.CoincidentNodes(crlNodes=[], dTol=0.01, bDesOrder=False)

Ribbon: MeshEdit » MoveNode » CoincidentNodes

Inputs​

crlNodes​

A List of Cursor specifying the node.

The default value is [].

dTol​

A Double specifying the tolerance.

The default value is 0.01.

bDesOrder​

A Boolean specifying the des order.

The default value is False.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.CoincidentNodes(crlNodes=[], dTol=0.01, bDesOrder=False)
