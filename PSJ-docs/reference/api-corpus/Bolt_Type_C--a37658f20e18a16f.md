# Bolt Type C

Bolt Type C Bolt Type C This is the dialog that opens from the Auto Bolt Connection function to set the FEM conditions for bolt type A. Auto Bolt Connection Help For bolt type C, RBE2/RBE3 elements are created in the bolt hole and connect their center with the Spring/RBE2 element. Top Settings Connection Specify the type of rigid body (RBE2/RBE3) to be created for the upper bolt hole. The Top Settings and Bottom Settings can only be set for the same rigid body type. Bottom Settings Connection Specify the type of rigid body (RBE2/RBE3) to be created in the lower bolt hole. The Top Settings and Bottom Settings can only be set for the same rigid body type. Center Settings Connection Specify the type of rigid body to be created at the shaft center. None &nbsp;:&nbsp;No rigid body at the center of the axis. Spring &nbsp;:&nbsp;Create a Spring at the center of the axis. -&nbspOperating Procedure&nbsp- Select rigid body types and enter the parameters. Click the OK button. This dialog closes and highlights the button of the corresponding bolt type in the Auto Bolt Connection dialog.
