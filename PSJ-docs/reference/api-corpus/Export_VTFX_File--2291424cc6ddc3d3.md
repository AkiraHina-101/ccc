# Export VTFX File

Export VTFX File Export VTFX File Export Geometry information or Geometry and Result information for the active document in Web Viewer format(*.vtfx). Path Settings Model Name &nbsp;&nbsp;&nbsp;Input file name to export the data. If the text box is blank, show an error message and cancel the execution. Output Folder Path &nbsp;&nbsp;&nbsp;Input path to export the data. If the text box is blank, show an error message and cancel the execution. Options Model Type &nbsp;&nbsp;&nbsp;Select an exporting model type. Pre Export only Geometry. Post Export Geometry and selected result. Exclude bar part &nbsp;&nbsp;&nbsp;Bar parts (parts that contain only Edge) will not be exported if checked on. Export Surface Data Only &nbsp;&nbsp;&nbsp;3D element will not be exported if checked on. Moreover, results on 3D elements will not be exported. Export data position control button &nbsp;&nbsp;&nbsp;This button displays when Model Type is Post. After clicking this button, the below dialog will open. Select result position of 2D shell on it. 2D Element Data Top / Bottom / Average &nbsp;&nbsp;&nbsp;Select position. Data Location &nbsp;&nbsp;&nbsp;When there are 2 position about data location you can select it from pull down menu. Result Selection list &nbsp;&nbsp;&nbsp;This list displays when Model Type is Post. Here is same information as Result Tree on Result window, and export checked results. &nbsp;&nbsp;&nbsp;Display following two context menu when right click on the tree. Select result of all steps &nbsp;&nbsp;&nbsp;Select that result in all other timesteps. Unselect result of all steps &nbsp;&nbsp;&nbsp;Deselect that result in all other timesteps. -&nbsp操作手順(Model Type : Pre)&nbsp- &nbsp;Input Model Name and Output Folder Path. &nbsp;Select Pre on Model Type. &nbsp;Check on options if you need. &nbsp;Click Apply or OK button. -&nbsp操作手順(Model Type : Post)&nbsp- &nbsp;Input Model Name and Output Folder Path. &nbsp;Select Post on Model Type. &nbsp;Check on options if you need. &nbsp;If you have result for 2D shell, you can select result position of it by opening Data Position Control dialog from Export data position control button. &nbsp;Check on results you want to export. &nbsp;Click Apply or OK button. -&nbspNote&nbsp- &nbsp;This command doesn't export Solid Principal Stress.
