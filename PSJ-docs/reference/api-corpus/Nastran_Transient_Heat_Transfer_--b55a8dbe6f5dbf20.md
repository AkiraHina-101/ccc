In case of manual input add only the required number of data input from the Insert button. From the Import button read the file in csv format to create a table [Time, Factor]. After the data input click OK button to create the table. Input data table can be displayed in the Chart by selecting Time and Value in X, Y and clicking the Draw XYZ button. &nbsp;Create another time table in the same way if needed for other boundary conditions. Setting of temperature boundary conditions Set the time dependent temperature boundary conditions. In the following set constant temperature at time. &nbsp;Select Boundary Conditions>Thermal Conditions>Boundary Temperature command. &nbsp;Enter the temperature in Temperature and select the time dependent table created earlier in the Select Table. &nbsp;Select the entity that defines the temperature boundary conditions from the model, and click on the OK button to create temperature boundary conditions. Setting of the convective boundary conditions Set the time-dependent convection boundary conditions. In the following set the time dependent heat transfer coefficient. &nbsp;Select the Boundary Conditions>Thermal Conditions>Convection command. &nbsp;Enter the temperature in the External Temperature. Then enter the heat transfer coefficient in the Convection Coefficient and select the time-dependent table that you created earlier in the Time Dependent menu. &nbsp;Select the entity that defines the convective boundary from the model and click the OK button to create a convective boundary conditions. Setting the initial temperature conditions Set the initial temperature conditions. The following sets a fixed initial temperature in the entire model. &nbsp;Select Boundary Conditions>Initial Conditions>Initial Conditions>Initial Temperature command. &nbsp;Enter the initial temperature to Temperature. &nbsp;In order to set a fixed initial temperature in the entire model, click the initial temperature conditions and check the Use Default Temperature, without selecting the target entity and click the OK button to create the initial temperature conditions. If you want to set the initial temperature for each site then select an entity without a check. Creating Nastran input data Outputs the input data for the transient heat transfer analysis of Nastran (SOL159) &nbsp;Select the Analysis>Analysis>Nastran>Transient(SOL159) command. &nbsp;Set the time increment in the Solver Option> Time Increment (DT) from Job Option and the number of time steps in the Number of Time Steps (NDT). &nbsp;Define the other necessary option and click on the OK button to output the data file. -&nbspOperation Video&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
