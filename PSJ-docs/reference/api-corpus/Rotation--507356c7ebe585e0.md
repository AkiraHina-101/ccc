# Rotation

Rotation a.no-uline {text-decoration:none} Rotation Rotate the selected part. Operation Create New Part &nbsp;&nbsp;&nbsp;Copy the part after the parallel move, as a new Part. LBC Copy &nbsp;&nbsp;&nbsp;Also copy load constraints that were added to the existing part to a new part. Copy Count &nbsp;&nbsp;&nbsp;Enter the number of repetitions of the copy. Rotation Coordinate System &nbsp;&nbsp;&nbsp;Select the coordinate system to reference. Rotation Axis &nbsp;&nbsp;&nbsp;Select the axis of rotation. X Axis &nbsp;:&nbsp;Rotate around the X-axis of the selected coordinate system. Y Axis &nbsp;:&nbsp;Rotate around the Y-axis of the selected coordinate system. Z Axis &nbsp;:&nbsp;Rotate around the Z-axis of the selected coordinate system. Arbitrary Axis &nbsp;:&nbsp;To rotate for a specified angle value, about an axis that is specified in the X, Y, Z direction Vector. 2 Nodes &nbsp;:&nbsp;To rotate for a specified angle value, about the axis of the two Node directions selected from the screen. Edge &nbsp;:&nbsp;To rotate for a specified angle value, around the axis of the Edge direction that has been selected from the screen. Axis-X &nbsp;&nbsp;&nbsp;Enter the X coordinate of the rotation center location. Axis-Y &nbsp;&nbsp;&nbsp;Enter the Y coordinate of the rotation center location. Axis-Z &nbsp;&nbsp;&nbsp;Enter the Z-coordinate of the rotation center position. Center &nbsp;&nbsp;&nbsp;Decide the position of the center of rotation. Part Center &nbsp;:&nbsp;To define the center of the Part as the center of rotation. Node &nbsp;:&nbsp;To define the selected node from the screen as the center of rotation. Input &nbsp;:&nbsp;Enter the center of rotation in Center Global-X, Center Global-Y, the Center Global-Z. These are set in Global Coordinate. Rotation Angle &nbsp;&nbsp;&nbsp;Enter the rotation angle. Merge Nodes &nbsp;&nbsp;&nbsp;If checked, Face for rotate that are copied as the body in the model will have the nodes joined in the case where there is contact of the Face with copy source for body. Merge Tol. &nbsp;&nbsp;&nbsp;Enter the Tolerance of the coupling for Merge Node. -&nbspOperating Procedure&nbsp- &nbsp;If you want to create a new Part after the rotation, select the Create New Part. &nbsp;Turn on the LBC Copy to copy a load restraint conditions of the existing part to the new part. &nbsp;To repeat copy, enter the number of copies. &nbsp;Press the Part button and select the Part for rotation from the screen. &nbsp;If you want to rotate around the existing coordinate system axis, select an existing coordinate system from the Coordinate System and select one of the Rotation Axis from the X-axis, Y-axis, Z-axis. &nbsp;To rotate in arbitrary direction, select the Arbitrary Axis from Rotation Axis and enter the direction vector to X, Y, Z input box. &nbsp;To rotate around the selected 2 Node direction, select the 2 Nodes from Rotation Axis, and then select the two Node from the screen. &nbsp;To rotate around the selected Edge direction, select the Edge from Rotation Axis, and then select the Edge from the screen. &nbsp;For the rotation around the center of the Part, select the Part Center from Center. &nbsp;For the center of the Part as the Node position, select the Node from the Center, you pick the Node from the screen. &nbsp;To direct input the center of the Part, select the Input from the Center, enter the center of rotation in the Center Global-X, Center Global-Y, Center Global-Z in global coordinate. &nbsp;Enter the angle of rotation in the rotation angle. &nbsp;To Merge original Part and the Nodes after the copy, check the Merge Nodes, enter the Merge Tol. for the coupling tolerance. &nbsp;Press the Apply or OK button. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
