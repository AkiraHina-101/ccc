# Post Result Data Coordinate Types

Post Result Data Coordinate Types

これは、ポスト結果データ座標タイプを表す列挙型です。

 | ID | ポスト結果データ座標タイプ | 説明

 | 0 | JPT.PostResultDataCoord.POST_COORD_UNKNOWN | 未定義の座標系。

 | 1 | JPT.PostResultDataCoord.POST_COORD_GLOBAL | グローバル座標系（全体座標系の方向成分を使用して結果を表示）。

 | 2 | JPT.PostResultDataCoord.POST_COORD_ELEMENT | 要素座標系（要素座標系の方向成分を使用して結果を表示）。

 | 4 | JPT.PostResultDataCoord.POST_COORD_ANALYSIS | 解析座標系（ソルバから出力された方向成分を使用して結果を表示）。

 | 8 | JPT.PostResultDataCoord.POST_COORD_USER | ユーザー定義座標系（ユーザー定義座標系の方向成分を使用して結果を表示）。
