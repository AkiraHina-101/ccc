# Node to Edge

Node to Edge Node to Edge CAD Projection(Node to Edge) Dialog Box Project mid-node or corner nodes of the mesh parts, to the edge of the selected CAD geometry. Options Direction Specify the projection direction. Min Project in the shortest distance direction to the face. X/Y/Z/-X/-Y/-Z Project the selected CAD edges in the selected positive and negative direction. -&nbspOperating Procedure&nbsp- &nbspPress the CAD Edge button on the Selection List, select the edge from the screen that becomes a projection target. &nbspPress the Meshed Node button on the Selection List, select the nodes of the mesh part from the screen that becomes the projection target. &nbspChange the directions option as needed. &nbspClick the Apply or OK button to execute the projection. Nodes on the selected edges will move on the CAD model. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
