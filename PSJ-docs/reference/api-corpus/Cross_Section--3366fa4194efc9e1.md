Cross Section a.no-uline {text-decoration:none} Cross Section Turning on the section view will display a 3D mouse in the main window. While the 3D mouse is activated, the section ribbon is displayed, enabling detailed display settings. The cross-sectional view, which is displayed by cutting the shape at an arbitrary cross section, is adjusted using the 3D mouse displayed in the main window.
