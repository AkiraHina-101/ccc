# MoveNodeEdgePoint()

MoveNodeEdgePoint()

説明​

節点をエッジポイントの位置に移動します。

構文​

MoveNodeEdgePoint(double x, double y, double z, int[] node_list)

入力​

1. Double​

x: 節点を移動するポイントの1番目の座標です。

2. Double​

y: 節点を移動するポイントの2番目の座標です。

3. Double​

z: 節点を移動するポイントの3番目の座標です。

4. Int[]​

移動する節点のリストです。

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

MoveNodeEdgePoint(0.00406953, 0.01, 0.01, [454])
