# BOLT_TYPE_D

BOLT_TYPE_D

説明​

ボルトタイプDのパラメータを制御するために使用されるデータ型です。

属性​

iConType​

接続タイプを指定する Int。

0: RBE2

1: RBE3

デフォルト値は0です。

iConCase​

接続設定を指定する Int。

0: 直径による

1: レイヤーによる

デフォルト値は1です。

dConDiameter​

接続直径（節点）を指定する Double です。

デフォルト値は0.02です。

iConLayer​

接続レイヤー（フェース）のレイヤー数を指定する Int です。

デフォルト値は1です。
