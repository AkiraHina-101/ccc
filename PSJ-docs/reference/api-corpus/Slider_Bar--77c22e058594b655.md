# Slider Bar

Slider Bar

スライダーバーを作成します。

プレビューダイアログ：

パラメータ​

名前​

スライダーバーの名前を入力してください。

サイズ​

幅：スライダーバーの最小幅を指定します（ピクセル単位）

高さ：スライダーバーの最小高さを指定します（ピクセル単位）

最小​

スライダーバーコンポーネントの最小値を指定します。

最大​

スライダーバーコンポーネントの最大値を指定します。

初期位置​

スライダーバーコンポーネントのデフォルト値（デフォルト位置）を指定します。

垂直​

スライダーバーの表示方向を指定します。

オンをチェック：垂直表示

オフをチェック：水平表示

補助目盛を表示​

マイナースケールラインを表示するかどうかを指定します。

オンをチェック：マイナースケールを表示

オフをチェック：マイナースケールを非表示

境界線表示​

スライダーバーの境界線を表示するかどうかを指定します。

オンをチェック：境界線を表示

オフをチェック：境界線を非表示

目盛りを両側に表示​

目盛りの表示位置を指定します。

オンをチェック：両側に目盛りを表示

オフをチェック：片側だけに目盛りを表示

有効​

有効にするかどうかを指定します。

オンをチェック：有効

オフをチェック：無効（グレーアウト）

表示​

作成したスライダーバーを表示/非表示にするかを指定します。

オンをチェック：表示

オフをチェック：非表示

関連するAPI​

dlg.add_slider：作成ダイアログにスライダーバーを追加します。

dlg.set_slider_bothtics：スライダーバーの目盛りを両側/片側に表示します。

dlg.set_slider_show_border：スライダーバーの境界線を表示します。

dlg.set_slider_show_tics：スライダーバーの目盛りを表示します。

dlg.set_slider_vertical：スライダーバーを垂直または水平方向に表示します。
