# Morphing | Rib Thickness

Morphing | Rib Thickness a.no-uline {text-decoration:none} Morphing | Rib Thickness Change the thickness of the existing rib by deformation of the mesh (morphing). ※After the morphing function is executed, the mesh is trimmed with the partial remeshing function. Options Move Distance &nbsp;&nbsp;&nbsp;Specify the thickness increase (+) and decrease (-) value. The moving distance in the thickness direction increases or decreases by 2 from the center of rib. Strong Effect Distance &nbsp;&nbsp;&nbsp;Specify the range that is strongly affected by the movement of the selected entity as a distance. The nodes included in this range move by 1/2 of the distance specified in the movement distance. Weak Effect Distance &nbsp;&nbsp;&nbsp;Specify the range affected by the movement of the selected entity as a distance. The Movement Amount of the nodes included in this distance range is 0 &lt; Movement Amount &lt; Move Distance/2, and decreases as the distance from the selected entity increases. -&nbsp;Operating Procedure&nbsp;- &nbsp;Select the face in the thickness direction of the rib whose thickness you want to change. &nbsp;Enter the parameters and press OK to change the rib thickness. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
