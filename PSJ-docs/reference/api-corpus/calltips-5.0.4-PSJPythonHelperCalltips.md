////////////////////////////////////////////////////////////////////////////////////////////////////////////

//    #PSJ Python Hepler calltips (2 functions)

///////////////////////////////////////////////////////////////////////////////////////////////////////////
Function: convertXmlFileToDict
Description: Select-Deselect all entities by type
Input1: xml file path
Return: material dictionary (python dict)
Example: 
dictLibMaterial = convertXmlFileToDict(fileLibMaterialPath)
print(dictLibMaterial)
--------------------------------------------------------------------------
Function: convertXmlStringToDict
Description: Deselect all entities on view
Input1: xml file string
Return: material dictionary (python dict)
Example: 
dictLibMaterial = convertXmlStringToDict(stringLibMaterialPath)
print(dictLibMaterial)
--------------------------------------------------------------------------
