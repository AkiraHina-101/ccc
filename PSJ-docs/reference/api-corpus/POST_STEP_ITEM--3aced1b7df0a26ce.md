# POST_STEP_ITEM

POST_STEP_ITEM

Description​

A data type uses to control parameters of Post Step Item.

Attributes​

postTimeStepInfo​

A Class POST_TIME_STEP_INFO specifying the attributes of Post Time Step Information.

The default value is POST_TIME_STEP_INFO().

iAnalysisType​

An Integer specifying the Analysis type.

The default value is 0.

crPostJob​

A Cursor specifying the Post Job.

The default value is None.

iResultSet​

An Integer specifying the Result Set.

The default value is 0.

iTimeStep​

An Integer specifying the Time Step.

The default value is 0.
