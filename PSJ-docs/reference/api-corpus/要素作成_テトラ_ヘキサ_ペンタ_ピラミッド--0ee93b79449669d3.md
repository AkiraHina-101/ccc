# 要素作成 テトラ / ヘキサ / ペンタ / ピラミッド

要素作成 テトラ / ヘキサ / ペンタ / ピラミッド 要素作成 テトラ / ヘキサ / ペンタ / ピラミッド 選択した要素または節点から、ソリッド要素を作成します。 選択リスト 要素：ソリッド要素を接続する2D要素 節点：ソリッド要素を接続する節点 パーツ：作成したソリッド要素が属するパーツ（選択しない場合は、ソリッド要素が新しいパーツとして作成されます） パラメーター 作成するソリッド要素を選択します。 テトラ &nbsp;:&nbsp;テトラ要素(四面体)を作成します。 ヘキサ &nbsp;:&nbsp;ヘキサ要素(六面体)を作成します。 ペンタ &nbsp;:&nbsp;ペンタ要素(三角柱)を作成します。 ピラミッド &nbsp;:&nbsp;ピラミッド要素(四角錘)を作成します。 節点順を使用 チェックボックスをONにすると、3節点を選択したのち、次に選択する順の番号がメインウィンドウに表示されます。 方向 作成する要素の方向を切り替えます。 高さ 作成する要素の高さを入力します。 パーツ選択を保持 選択したパーツの選択状態を適用ボタン実行後も保持します。 -&nbsp操作手順(節点順を使用オプション)&nbsp- 節点順を使用オプションをONにして、節点選択することによりソリッド要素(ここでは一例としてヘキサ要素)を作成します。 要素を作成する節点を3点選択します。この場合、下図のように時計回りで選択すると、緑色のガイドラインが意図した方向に出ない為、反時計回りに3節点を選択します。 次は、メインウィンドウに4と数字が出ている方向にある、要素を作成したい節点を選択します。 次は、メインウィンドウに5と数字が出ている方向にある、要素を作成したい節点を選択します。 次は、メインウィンドウに6と数字が出ている方向にある、要素を作成したい節点を選択します。 次は、メインウィンドウに7と数字が出ている方向にある、要素を作成したい節点を選択します。 次は、メインウィンドウに8と数字が出ている方向にある、要素を作成したい節点を選択します。節点選択後、緑のガイドラインから変わってプレビューが表示されたら実行可能です。 -&nbsp要素作成方法(テトラ要素)&nbsp- テトラ要素の作成方法は、下図の通り選択が3通りあります。 -&nbsp要素作成方法(ヘキサ要素)&nbsp- ヘキサ要素の作成方法は、下図の通り選択が5通りあります。 -&nbsp要素作成方法(ペンタ要素)&nbsp- ペンタ要素の作成方法は、下図の通り選択が6通りあります。 -&nbsp要素作成方法(ピラミッド要素)&nbsp- ピラミッド要素の作成方法は、下図の通り選択が6通りあります。 -&nbsp特記事項&nbsp- 節点順を使用オプションがオフの際、完成形状に凹みがある場合は、自動生成ができないようになっています。 2次要素にも対応しています。選択した要素の次数が異なる場合は、エラーメッセージを表示します。 「パーツ選択を保持」だけは、GUI設定が保存されません。
