# ADVC_CONVERGENCE

ADVC_CONVERGENCE

説明​

ADVC収束のパラメーターを制御するために使用されるデータ型です。

属性​

dCgTol​

cg許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dCgNrTol​

cg nr許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dCgDispTol​

cg変位許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dCgNrDispTol​

cg nr変位許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dCgDispLimitTol​

cg変位制限許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dCgTotalDispLimitTol​

cg総変位制限許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dNewtonTol​

ニュートン許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dNewtonDispTol​

ニュートン変位許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dNewtonDispLimitTol​

ニュートン変位制限許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

dNewtonTotalDispLimitTol​

ニュートン総変位制限許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。

iCgloopMax​

cgloopの最大値を指定する Integer です。

デフォルト値は DFLT_INT です。

iNewtonMax​

ニュートンの最大値を指定する Integer です。

デフォルト値は DFLT_INT です。

dHtNlLoopTol​

ht nlループ許容誤差を指定する Double です。

デフォルト値は DFLT_DBL です。
