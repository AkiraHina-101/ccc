Cylindrical &nbsp;:&nbsp;Select the cylindrical coordinate system. Spherical &nbsp;:&nbsp;Select a spherical coordinate system. Order &nbsp;&nbsp;&nbsp;Specifies the meaning of the order in for the selection of the nodes. O.Z.ZX Plane &nbsp;:&nbsp;Select in the order of Origin, a point on the Z-axis and a point on the ZX plane. O,X,ZX Plane &nbsp;:&nbsp;Select in the order of Origin, a point on the X-axis and a point on the ZX plane. O,Y,XY Plane &nbsp;:&nbsp;Select in the order of Origin, a point on the Y-axis and a point on the XY plane. O,X,XY Plane &nbsp;:&nbsp;Select in the order of Origin, a point on the X-axis and a point on the XY plane. O,Z,YZ Plane &nbsp;:&nbsp;Select in the order of Origin, a point on the Z-axis and a point on the YZ plane. O,Y,YZ Plane &nbsp;:&nbsp;Select in the order of Origin, a point on the Y-axis and a point on the YZ plane. Name &nbsp;&nbsp;&nbsp;Enter the name of the coordinate system to be created. Refer Coordinate Frame Coordinate &nbsp;&nbsp;&nbsp;Choose from the default for coordinate system which is referred by the coordinate system to be created.
