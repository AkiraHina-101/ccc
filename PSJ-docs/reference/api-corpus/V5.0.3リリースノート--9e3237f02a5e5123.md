# V5.0.3リリースノート

V5.0.3リリースノート

Highlight updates

V5.0.3では、主にPost処理を強化するためのAPI機能を追加しました。また、新機能や新オプション用にマクロやPSJ Commandを更新しています。

カスタムノート（新機能）コントロール用の新規データタイプ、マクロ、APIを追加しました。

Postの結果表示情報を取得するAPIを追加しました。

Postドキュメント上の要素・節点操作の補助となるAPIを追加しました。

Postドキュメント上の要素・節点取得の際の不具合を修正しました。

表示中ドキュメントの有効化切り替え、選択、クローズを行うAPIを追加しました。

PSJ-GUIのクラッシュ問題や軽微な不具合を修正しました。

プリインストールされているpythonライブラリに、openpyxlを追加しました。

📝 API​

新規に27個のAPIコマンドを追加しました。
新規追加コマンド一覧

JPT.GetAppPathInfo(): PathTypeで指定されたパス情報を取得します。

JPT.SelectionByIDs(): ID指定したエンティティ（複数）を取得します。

JPT.IsSpatialPointRendered():指定した節点が、現在のビュー上に表示されているかどうかを確認します。

JPT.CastDItemToDPostElem():指定したDItemオブジェクトをDROElemオブジェクトに変換し、Post要素の情報を取得可能にします。

JPT.CloseAllGraphViews() : 表示されている全てのチャートビュー（グラフウィンドウ）を閉じます。

JPT.CloseGraphViewByDocumentName(): 指定したドキュメントに付随する全てのチャートビュー（グラフウィンドウ）を閉じます。

JPT.ConvertCoordinateFromGlobalToLocal(): 選択したDItemのグローバル座標系を、指定したローカル座標系に変換します。

JPT.HighlightByID(): アッセンブルツリーのLBC及びプロパティアイテムをハイライトします。同時に、メインウィンドウ上でハイライトしたLBC/プロパティに接続したパーツ・フェースの表示を変更します。

JPT.SetActiveDocumentByID(): IDで指定したドキュメントを有効化します。

JPT.SetActiveDocumentByName(): 名前で指定したドキュメントを有効化します。

GetAllCustomNotes: 存在しているすべてのカスタムノートを取得します。

GetAllCustomNoteCollections: 存在しているすべてのコレクションを取得します。

JPT.GetDocumentList(): 表示中のドキュメントのリストを取得します。

JPT.GetActiveDocument(): 現在使用中のドキュメント（有効ドキュメント）を取得します。

JPT.GetDocumentByID(): IDで指定したドキュメントを取得します。

JPT.GetDocumentByName(): 名前で指定したドキュメントを取得します。

JPT.CloseDocumentByID(): IDで指定したドキュメントを閉じます。

JPT.GetCurrentDeformation(): 現在の変形設定を取得します。

JPT.GetCurrentViewPoint(): 現在のビューポイント設定を取得します。

JPT.GetCurrentCrossSection(): 現在の断面設定を取得します。

JPT.GetCurrentContour(): 現在のコンター設定を取得します。

JPT.GetCurrentCircle(): 現在の円図設定を取得します。

JPT.GetCurrentDiagram(): 現在のダイアグラム設定を取得します。

JPT.GetCurrentVector(): 現在のベクトル設定を取得します。

JPT.GetCurrentAnimation(): 現在のアニメーション設定を取得します。

JPT.CastDItemToDRONode(): DItemオブジェクトをDPostNodeオブジェクトに変換します。

JPT.CastDItemToDROElem(): DPostNodeオブジェクトをDItemオブジェクトに変換します。

また、下記のコマンドが変更されました。
