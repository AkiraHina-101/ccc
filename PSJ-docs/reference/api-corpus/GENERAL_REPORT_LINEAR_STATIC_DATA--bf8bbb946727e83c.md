# GENERAL_REPORT_LINEAR_STATIC_DATA

GENERAL_REPORT_LINEAR_STATIC_DATA

説明​

線形静定データのパラメータを制御するために使用されるデータ型です。

属性​

strPartName​

パート名を指定する Integer です。

デフォルト値は "" です。

strPropName​

プロパティ名を指定する String です。

デフォルト値は "" です。

strMatName​

素材名を指定する String です。

デフォルト値は "" です。

dValue​

標準値を指定する String です。

デフォルト値は 0.0 です。
