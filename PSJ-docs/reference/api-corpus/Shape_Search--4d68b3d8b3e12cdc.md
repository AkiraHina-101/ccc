# Shape Search

Shape Search Shape Search Search and select the edges and faces of a specific shape from the selected parts. Selection List Part &nbsp;:&nbsp; Display the parts used to search for a specific shape Face &nbsp;:&nbsp; Display the searched faces Edge &nbsp;:&nbsp; Display edge to search for concentric circle and the searched edges Edge Search and select edges corresponding to the selected shape types in the selected parts. Arc Search and select the arc edge. This method supports searching not only for semi-circular arcs but also arcs created by an edge. All &nbsp;:&nbsp;Search and select all arc edges in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the arc edge to search and select it in the selected parts. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the arc edge to search and select it in the selected parts. The Max/Min radius will be used to search the target edges when option All is checked off. Circle/Concentric Search and select circular edges. This method supports searching not only for circles created by multiple edges but also by a single edge. In addition, when this option is selected, the concentric circles are searched and selected base on the selected target circle. All &nbsp;:&nbsp;Search and select all circular/concentric circular edges in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the circular/concentric circular edge to search and select it in the selected parts. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the circular/concentric circular edge to search and select it in the selected parts. The Max/Min radius will be used to search the target edges when option All is checked off. Circle Concentric Loop Search and select loop-shaped edges created by a single edge. Face Search and select faces corresponding to the selected shape types in the selected parts. Planar Search and select the planar faces. All &nbsp;:&nbsp;Search and select all conical faces in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the conical face to search and select it in the selected parts. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the conical face to search and select it in the selected parts. The Max/Min radius will be used to search the target faces when option All is checked off. Disc Search and select the disc-shaped faces. This method supports searching not only for disc-shaped faces created by a single face but also by multiple faces as long as they create a completed disc. All &nbsp;:&nbsp;Search and select all disc-shaped faces in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the disc-shaped face to search and select it in the selected parts. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the disc-shaped face to search and select it in the selected parts. The Max/Min radius will be used to search the target faces when option All is checked off. Hollow Disc Search and select the hollow disc-shaped faces. This method supports searching not only for a fully hollow disc-shaped face but also a part of a hollow disc-shaped face. All &nbsp;:&nbsp;Search and select all hollow disc-shaped faces in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the hollow disc-shaped face to search and select it in the selected parts Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the hollow disc-shaped face to search and select it in the selected parts. The Max/Min radius will be used to search the target faces when option All is checked off. Fully Cylinder Search and select the cylindrical faces. This method supports searching not only for cylindrical faces created by a single face but also by multiple faces. All &nbsp;:&nbsp;Search and select all cylindrical faces in the selected parts. All &nbsp;:&nbsp;Search and select all cylindrical faces created by one face in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the cylindrical face to search and select it in the selected parts. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the cylindrical face to search and select it in the selected parts. The Max/Min radius will be used to search the target faces when option All is checked off. Closed Partial Cylinder Search and select the closed partial cylindrical faces. This method supports searching not only for closed partial cylindrical faces created by a single face but also by multiple faces. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the opened partial cylindrical face to search and select it in the selected parts. The Max/Min radius will be used to search the target faces when option All is checked off. Fillet (Rad.) Search and select fillet faces by arc radius input. All &nbsp;:&nbsp;Search and select all fillet faces in the selected parts. Minimum radius &nbsp;:&nbsp;Enter the minimum radius of the fillet face to search and select it in the selected parts. Maximum radius &nbsp;:&nbsp;Enter the maximum radius of the fillet face to search and select it in the selected parts. The Max/Min radius will be used to search the target faces when option All is checked off. Convex &nbsp;:&nbsp;Search and select for convex fillets. Concave &nbsp;:&nbsp;Search and select for concave fillets. Fillet (Arc Len.) Search and select fillet faces by arc length input. All &nbsp;:&nbsp;Search and select all fillet faces in the selected parts. Minimum arc length &nbsp;:&nbsp;Enter the minimum arc length of the fillet face to search and select it in the selected parts. Maximum arc length &nbsp;:&nbsp;Enter the maximum arc length of the fillet face to search and select it in the selected parts. The Max/Min arc length will be used to search the target faces when option All is checked off. Convex &nbsp;:&nbsp;Search and select for convex fillets. Concave &nbsp;:&nbsp;Search and select for concave fillets. Tiny Face Search and select tiny faces. Minimum width &nbsp;:&nbsp;Enter the minimum width of the tiny face to search and select it in the selected parts Maximum width &nbsp;:&nbsp;Enter the maximum width of the tiny face to search and select it in the selected parts All faces with smaller side widths that satisfy the Max/Min width range will be searched and selected as tiny faces. Create Group Create a group for the searched faces and edges. Non &nbsp;:&nbsp;Do not create group. All One &nbsp;:&nbsp;Create a group containing all searched results (faces, edges) of all specified shape types for searching in the selected parts. One By One &nbsp;:&nbsp;Create separate groups containing the searched results (faces, edges) corresponding to each specified shape type for searching in the selected parts. Group name Enter the name of the group to be created. In the Group creation: If the option All One is selected and the group name is blank, a group called "FindFeature_Group_number" will be created. If a string (group name) is entered into the group name when the option All One is selected, a group will be created using that name. If the option One by One is selected and the group name is blank, a group called "(Edge / Face)_(searched shape name)_number" will be created. If a string (group name) is entered into the group name when the option One by One is selected, a group with name "Entered name + (Edge/Face)_(searched shape name)" will be created. -&nbsp;Operation Procedure (General)&nbsp;- Check the option of shape type you want to search for. Check "All" option or enter required values. Change group creation options if needed. Select target part (support to select multiple parts). Click the Apply/OK button. -&nbsp;Operation Procedure (Concentric circle)&nbsp;- Check the "Circle/concentric" option. Check "All" option or enter required values. Change group creation options if needed. Select target part (support to select multiple parts). Select a circle (or many circles) to be the target circle (The searched circles will be concentric with this target circle). You can select circles created by a single edge or multiple edges as long as they create a closed circle. Click the Apply/OK button.
