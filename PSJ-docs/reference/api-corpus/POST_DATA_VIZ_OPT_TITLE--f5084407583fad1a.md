# POST_DATA_VIZ_OPT_TITLE

POST_DATA_VIZ_OPT_TITLE

説明​

データ型は、タイトルを表示するための結果設定を行うために使用されます。

属性​

bResultName​

メインウィンドウで結果名を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bConvection​

メインウィンドウで対流を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bUnit​

メインウィンドウで単位を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bCoordinate​

メインウィンドウで座標を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bTotalMaxMin​

メインウィンドウで合計の最大/最小を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bFileName​

メインウィンドウでファイル名を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bLocation​

メインウィンドウで位置を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bVisibleMaxMin​

メインウィンドウで可視の最大/最小を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bAnimation​

メインウィンドウでアニメーションを表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bDeformRatio​

メインウィンドウで変形比率を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

bDetail​

メインウィンドウで詳細を表示するかどうかを指定する Boolean です。

デフォルト値は True です。

iResultTitleSize​

結果タイトルのフォントサイズのインデックスオプションを指定する Integer です。

デフォルト値は 6 です。

iResultDescriptionSize​

結果の説明のフォントサイズのインデックスオプションを指定する Integer です。

デフォルト値は 5 です。

iResultTitle​

結果タイトルのフォントサイズのインデックスオプションを指定する Integer です。

デフォルト値は 6 です。

iResultTitleColor​

結果タイトルのフォントカラーを指定する Integer です。

デフォルト値は 16777215 です。

bResultTitleBold​

結果タイトルを太字で表示するかどうかを指定する Boolean です。

デフォルト値は False です。

iResultDescription​

結果の説明のフォントサイズのインデックスオプションを指定する Integer です。

デフォルト値は 5 です。

iResultDescriptionColor​

結果の説明のフォントカラーを指定する Integer です。

デフォルト値は 16777215 です。

bResultDescriptionBold​

結果の説明を太字で表示するかどうかを指定する Boolean です。

デフォルト値は False です。

bUseBackground​

背景色を使用するかどうかを指定する Boolean です。

デフォルト値は False です。

iBackgroundFillColor​

背景の塗りつぶし色を指定する Integer です。

デフォルト値は 16777215 です。

iBackgroundBorderColor​

背景の境界色を指定する Integer です。

デフォルト値は 16777215 です。

dTransparency​

背景の透過度を指定する Integer です。

デフォルト値は 0.5 です。

bAdjustTitlePos​

画像キャプチャのためにタイトルの位置を調整するかどうかを指定する Boolean です。

デフォルト値は True です。
