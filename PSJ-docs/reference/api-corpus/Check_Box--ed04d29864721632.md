# Check Box

Check Box Check Box チェックボックスを追加します。 &nbsp;&nbsp;&nbsp;作成イメージ図： Text &nbsp;&nbsp;&nbsp;チェックボックスの横に表示されるテキストを入力します。 Name &nbsp;&nbsp;&nbsp;Check Boxコンポーネント名を入力します。 Checked &nbsp;&nbsp;&nbsp;デフォルト値を指定します。 チェックオン &nbsp;:&nbsp;チェックする。 チェックオフ &nbsp;:&nbsp;チェックしない。 Width &nbsp;&nbsp;&nbsp;チェックボックスの最小幅を指定します。（単位：ピクセル） Height &nbsp;&nbsp;&nbsp;チェックボックスの最小高さを指定します。（単位：ピクセル） Enable &nbsp;&nbsp;&nbsp;使用の可否を指定します。 チェックオン &nbsp;:&nbsp;使用可能。 チェックオフ &nbsp;:&nbsp;使用不可。（グレーアウトされます） Left text &nbsp;&nbsp;&nbsp;チェックボックスの左側にテキストを表示させます。 チェックオン &nbsp;:&nbsp;テキストを左側に表示させます。 チェックオフ &nbsp;:&nbsp;テキストを右側に表示させます。 使用コマンド コマンド 説明 サンプルコード dlg.isbutton_checked("component name") チェックボックスにチェックが入っているかどうか確認します。 ブール値(True/False)を返します。 Input: dlg.isbutton_checked("CheckBoxButton") Output: > True/False dlg.set_checkbox_state("name", Bool) チェックボックスのステータス（チェックの有無）を指定します。 Input: dlg.set_checkbox_state("CheckBox1", True)
