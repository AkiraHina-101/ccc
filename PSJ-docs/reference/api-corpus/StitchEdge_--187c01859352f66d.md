# StitchEdge()

StitchEdge()

説明​

エッジを縫合します

構文​

StitchEdge(double dTolerance, bool keepSlave, cursor[] taMaster, cursor[] taSlave)

入力​

1. Double​

縫合の許容差（m）

2. Bool​

スレーブを保持するかどうか 真 = 1, 偽 = 0

3. Cursor[]​

縫合用のマスターエッジ -> エッジカーソル ([5:エッジID])

4. Cursor[]​

縫合用のスレーブエッジ -> エッジカーソル ([5:エッジID])

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

StitchEdge(0.0003, 1, [5:18], [5:57])
