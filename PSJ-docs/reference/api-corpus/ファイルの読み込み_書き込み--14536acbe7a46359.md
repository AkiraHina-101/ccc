# ファイルの読み込み/書き込み

ファイルの読み込み/書き込み

🎯 はじめに​

本チュートリアルでは、PSJ-Utilityを使用してファイルの読み取りと書き込みを行う方法について紹介します:

読み込み/書き込みのためのファイルパスを設定する。

ファイルの存在を確認する。

さまざまな方法(1行ずつ直接/ファイル全体/特定の文字 など)でファイルの内容を読み込む。

追加または書き込みオプションでファイルに内容を書き込む。

サンプルコードを使用するには、ローカルディスクにテキストファイルを用意してください。

ファイルをC:ドライブに読み込み/書き込みする場合、管理者権限が問題になる可能性があることに注意してください。

ファイルを読み込んで表示した場合に文字化けする場合、あるいはUnicodeDecodeErrorというエラーが表示される場合はこちらを参照ください。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# ファイルのパスを設定します。存在するファイルである必要があります。
myFile = 'D:/myFile.txt'

# ファイルが存在するかどうかを確認します。存在しない場合、Python APIウィンドウに情報を表示します。
import os.path
if not os.path.exists(myFile):
    print("ファイルが存在しません!")

# 以下のコードを使用するために、ローカルディスクにテキストファイルを用意します。
########## ファイル読み込み ##########
# 1行ずつ読み込みます。Python APIウィンドウに内容が表示されます。
file = open(myFile, "r")
for line in file:
  print(line)
file.close()

# ファイル全体の内容を読み込みます。Python APIウィンドウに内容を表示します。
file = open(myFile, "r")
print(file.read())
file.close()

# ファイルの最初の4文字を読み取ります。Python APIウィンドウに内容を表示します。
file = open(myFile, "r")
print(file.read(4))
file.close()

########## ファイル書き込み ##########
# ファイルの末尾に'a'の内容を追加します。
file = open(myFile, "a")
file.write("\n新しい行を追加し、新しい内容を書き込みます。")
file.close()

# 追加後のファイルのすべての内容を'r'で読み込みます。Python APIウィンドウに内容が表示されます。
file = open(myFile, "r")
print(file.read())
file.close()

# 'w'の内容をファイルに書き込みます。ファイルが存在しない場合は、新規ファイルを作成します。
file = open(myFile, "w")
file.write("既存のファイル内容は削除されました。新しい内容で上書きします。")
file.close()

# 上書き後のファイルのすべての内容を'r'で読み込みます。Python APIウィンドウに内容が表示されます。
file = open(myFile, "r")
print(file.read())
file.close()
