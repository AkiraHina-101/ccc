Beam Beam 1D Property Beam Dialog Box Create a property data of one-dimensional Beam element. Name Set the name of the property. Property ID Enter the ID of the property. Property ID is entered so as not to overlap in the model. Section Type Specify the characteristics input type. General ： Enter the general cross-section properties. Library ： Use the cross-sectional shape library of Nastran. By Sketcher： By entering the cross section dimensions for the main profile, calculate section properties. BEAM Input Shape By entering the cross section dimensions for the main profile, calculate section properties. If you select the Library, its dimensions will be output as PBEAML. Material Specify the material properties. Section Choose from existing elements characteristic list. Vector Enter the direction vector to determine the element coordinate system. Orientation by Vector ：Element coordinate system defined by the direction vector Node ：Element coordinate system by the specified node definition (for Nastran) Area Enter the value of the cross-sectional area. Section Detail Inertia I1/Izz Enter the moment of inertia around the Z axis. Inertia I2/Iyy Enter the moment of inertia around the Y axis. Inertia I12/Izy Enter the moment of inertia around the ZY. Torsional Constant Enter the torsional constant. Non-structural Mass Enter the non-structural mass per unit length. Cy/Cz/Dy/Dz/Ey/Ez/Fy/Fz Enter the stress calculation position in C, D, E, and F points. NSM Inertia A/B Enter the non-structural mass inertia per unit length on nodes A, B.(around center of gravity ) Y/Z of NSM at Node A Enter the coordinate (Y, Z) of the gravity center of the non-structural mass at node A. Y/Z of NSM at Node B Enter the coordinate (Y, Z) of the gravity center of the non-structural mass at node B. Shear Stiffness Y/Z Enter the shear stiffness coefficient of Y / Z direction. Shear Area Relief Y, Z Enter the shear relaxation coefficient of Y / Z direction. Warp Coefficient at Node A, B Enter the warp coefficient at node A, B. Y, Z of NA at Node A Enter the (Y, Z) coordinate of the neutral axis of node A. Y, Z of NA at Node B Enter the (Y, Z) coordinate of the neutral axis of node B. Elem Related Info Elem Related Info It accesses the information of individual element setting.
