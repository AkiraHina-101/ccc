# 2Dプロパティ | 板厚分布

2Dプロパティ | 板厚分布 2Dプロパティ | 板厚分布 板厚分布ダイアログボックス 2Dプロパティとして手動設定した板厚情報や中立面機能で自動抽出した 板厚情報をコンター表示します。また最大板厚/最小板厚の数値を変更すれば コンター表示の内容を編集します。 ※中立面抽出機能はオプション機能になります。 板厚モデル コンター表示設定をします。 表示モード 表示方式を指定します。 Face thickness Mode 中立面作成後のメモリ上の板厚情報をコンター表示。 ※中立面抽出の直後に使用 ※中立面機能サポートまで隠す --> プロパティ板厚モード プロパティ上の板厚情報をコンター表示します。 ※板厚情報と材料を設定後に使用。 デフォルト コンター表示を解除します。 ※機能しないため確認する --> 板厚値 板厚を表示します。 最大板厚 指定されている最大板厚値。 最小板厚 指定されている最小板厚値。 分布 コンターレンジ設定をします。 分割数 コンターの分割数。（2〜99） 各板厚での設定 プロパティ板厚モード時のみ使用します。 異なる各板厚 プロパティ情報を参照してコンター表示の最大値、最小値、分割数を 自動で設定します。最大板厚/最小板厚と分割数は使用できなくなります。 表示方法 カラーコンター 板厚コンター描画の表示/非表示を切り替えます。 ※機能していないため確認する 3D 板厚の3次元描画の表示/非表示を切り替えます。 ※機能していないため確認する --> -&nbsp操作手順&nbsp- 板厚モデルからプロパティ板厚モードを選択します。 板厚値の最大/最小板厚にコンター表示する板厚範囲の最大値、最小値を入力します。 分布の分割数にコンター表示する板厚の分割数を入力します。 コンター表示を均等分割から実際の板厚毎の分割に変更する場合は、異なる各板厚チェックボックスをオンにします。 適用またはOKボタンをクリックして板厚コンター図を表示します。 コンター図を非表示にするには、ツールバーの標準画面に戻すアイコンを選択します。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 --> コンター表示設定 コンターモードで厚みプロパティ/荷重データの表示をONにします。 コンター設定リボンを有効にすると、データ名、入力単位、最大値/最小値などのデータ設定の詳細が表示されます。 コンターバーの最大値/最小値、分割数を変更することができます。 コマンド機能一覧 閉じる 設定リボンを閉じます。 2D/3D シェルの厚みを2Dまたは3Dビュー形状で表示します。 データ データの種類は以下の通りです: - 圧力 - 初期温度 - 温度荷重 - 境界温度 - 熱流束 - 表面対流 - 厚さ 入力単位 データの単位を表示します。境界条件を作成する際に定義したデータの種類に基づいて表示されます。 コンポーネント データのコンポーネントを表示をします。 例えば表面対流の場合、コンポーネントは境界条件のマッピング定義でユーザーが選択したものに基づいて、温度または係数として表示されます。 値 最大: コンター表示の最大値を設定します。 最小: コンター表示の最小値を設定します。 分割数 連続: カラーコンターの分割数を設定します。（2〜100）。 データ毎: データ毎は厚みプロパティのみ使用します。 グループ作成 （厚みプロパティのみ）: 厚みプロパティに基づいて面グループを作成します。 表示方法 カラーコンター: モデルのカラーコンター表示を選択します。 形状を表示: モデルの表示を選択します。 プロパティ無し: プロパティ設定がされていない面の表示を選択します。
