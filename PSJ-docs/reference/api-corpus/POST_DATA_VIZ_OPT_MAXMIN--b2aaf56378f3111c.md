# POST_DATA_VIZ_OPT_MAXMIN

POST_DATA_VIZ_OPT_MAXMIN

Description​

A data type is used to set up the result settings for displaying Max/Min value.

Attributes​

iGroupMethod​

An Integer specifying the the group method.

0: For All

1: For Each

The default value is 0.

iMaxColor​

An Integer specifying the maximum color.

The default value is 255.

iMinColor​

An Integer specifying the minimum color.

The default value is 16711680.

An Integer specifying the .

The default value is 65535.
