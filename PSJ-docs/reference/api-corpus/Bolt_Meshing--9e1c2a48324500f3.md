# Bolt Meshing

Bolt Meshing a.no-uline {text-decoration:none} Bolt Meshing This command is used to divide CAD bolts into upper and lower parts for meshing and defining load and boundary condition for ADVC. Name Enter the capital letter of the load and boundary condition to be created. Cutting Define the surface for dividing the bolts into upper and lower parts. Refer to the Body Cut command for details. Surface Meshing Define the mesh settings. Refer to the Surface Meshing command for details. PreTension Define load conditions. Refer to the PreTension command for details. If "Partition Only" is selected, create Abaqus pretension with setting of cross section and normal direction. -&nbspExample of function execution&nbsp- -&nbspOperating Procedure&nbsp- &nbspSelect the CAD bolt parts. &nbspEnter the capital letter of the load condition of the bolt in the Name field. &nbspDefine the position for dividing the bolts. &nbspDefine the mesh settings for bolts. &nbspDefine the load condition setting of the bolts. &nbsp;Click the Apply/OK button. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
