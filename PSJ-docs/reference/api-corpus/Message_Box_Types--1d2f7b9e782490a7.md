# Message Box Types

Message Box Types

これはメッセージボックスの種類を表す列挙型です。

 | ID | MsgBoxタイプ | 説明

 | 0 | JPT.MsgBoxType.MB_WARNING_YESNOCANCEL | Yes、No、Cancelボタンを持つ警告メッセージボックス

 | 1 | JPT.MsgBoxType.MB_WARNING_YESNO | Yes、Noボタンを持つ警告メッセージボックス

 | 2 | JPT.MsgBoxType.MB_WARNING_OK | OKボタンを持つ警告メッセージボックス

 | 3 | JPT.MsgBoxType.MB_WARNING_OKCANCEL | OK、Cancelボタンを持つ警告メッセージボックス

 | 4 | JPT.MsgBoxType.MB_INFORMATION_YESNOCANCEL | Yes、No、Cancelボタンを持つ情報メッセージボックス

 | 5 | JPT.MsgBoxType.MB_INFORMATION_YESNO | Yes、Noボタンを持つ情報メッセージボックス

 | 6 | JPT.MsgBoxType.MB_INFORMATION_OK | OKボタンを持つ情報メッセージボックス

 | 7 | JPT.MsgBoxType.MB_INFORMATION_OKCANCEL | OK、Cancelボタンを持つ情報メッセージボックス

 | 8 | JPT.MsgBoxType.MB_CRITICAL_OK | OKボタンを持つ重要メッセージボックス
