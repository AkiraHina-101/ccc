# 節点移動 | CADフォロー

節点移動 | CADフォロー 節点移動 | CADフォロー 節点をドラッグすることで、フェース上で任意に移動させることができます。また、ドラッグした節点周りの要素品質表示されます。 最適な要素品質となる位置に、自動的に移動させることもできます。 ポジション X, Y, Z ドラッグしている節点の座標を表示します。 要素品質 計測方法 評価する要素品質の種類を指定します。 要素品質についての詳細は、メッシュ修正 > 要素品質 > 自動チェック / 手動チェックを参照して下さい。 ストレッチ Tri/Quad/Tet/ヘキサ要素に対して、ストレッチをチェックします。 アスペクト比 Tri/Quad/Tet/ヘキサ要素に対して、アスペクト比をチェックします。 ワーピング Quad要素に対して、四角形要素を2つの三角形に分け、その間に生じる角度の最大値をチェックします。 スキューネス Quad要素に対して、対辺の中点を結んだ2つの線のなす角度をチェックします。 エッジ長さ Tri/Quad/Tet/ヘキサ要素に対して、要素エッジ長をチェックします。 面積 Tri/Quad要素に対して、要素面積をチェックします。 節点接続数 Tri/Quad要素に対して、一つの節点に対して、その節点を含む要素の数をチェックします。 内角 Tri/Quad要素に対して、節点周りの要素エッジ間角度の中で最も小さい値をチェックします。 ターパー Quad要素に対して、四角形要素内の3節点を結んだ三角形面積の平均値との最大差分をチェックします。 適合した要素 計測方法で選択した品質が適用される要素の種類を表示します。 自動 最適な要素品質となる位置に、自動的に移動させます。 -&nbsp操作手順（任意位置への手動移動）&nbsp- 評価する要素品質の種類を、計測方法で指定します。 一つの節点をドラッグします。 適用/OKボタンをクリックします。 -&nbsp操作手順（最適な要素品質となる位置への自動移動）&nbsp- 評価する要素品質の種類を、計測方法で指定します。 一つの節点をドラッグします。 自動ボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
