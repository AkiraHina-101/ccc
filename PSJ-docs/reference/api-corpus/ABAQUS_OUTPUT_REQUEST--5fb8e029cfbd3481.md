# ABAQUS_OUTPUT_REQUEST

ABAQUS_OUTPUT_REQUEST

説明​

Abaqus Output Request のパラメータを制御するために使用されるデータ型です。

属性​

strName​

名前を指定する String です。

デフォルト値は "" です。

strDescription​

説明を指定する String です。

デフォルト値は "" です。

iId​

ID を指定する Integer です。

デフォルト値は 0 です。

iOutputFiletype​

出力ファイルタイプを指定する Integer です。

デフォルト値は 0 です。

iDomainType​

ドメインタイプを指定する Integer です。

デフォルト値は 0 です。

iDomainId​

ドメイン ID を指定する Integer です。

デフォルト値は 0 です。

iFrequencyType​

周波数タイプを指定する Integer です。

デフォルト値は 0 です。

dFrequency​

周波数を指定する Double です。

デフォルト値は 0.0 です。

ParamTimePoint​

時間点を指定する PARAM_TIME_POINT です。

デフォルト値は TIME_POINTS() です。

iTiming​

タイミングを指定する Integer です。

デフォルト値は 0 です。
