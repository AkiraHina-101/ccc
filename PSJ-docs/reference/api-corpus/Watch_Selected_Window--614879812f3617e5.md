# Watch Selected Window

Watch Selected Window Watch Selected Window Display selected entity information. 繝ｻSelect tab Display a list of selected entities. 繝ｻLock List tab Display selected entities that are temporarily saved (locked). Display the ID, type, value, etc. of the selected entity when the following operations are performed: Entity selection Double-click an entity in the selection list on the Watch Selected Window. Click an entity in the fast pick window. Display information and error information at the time of command execution. Mouse Operation List of mouse operations in the output window. Mouse operation Function Left button click Highlight a line. The range can be selected by using the Ctrl key and the Shift key simultaneously. Mouse wheel Scroll the window. Shortcut Menu Use each command from the menu displayed by mouse right click. Command Content Select all Highlight all the contents displayed in the output window. Copy Copy the highlighted line to the clipboard. Clear Clear all the content displayed in the output window. Toolbar Icon Name Content Delete all items Delete all data in the selection table. Delete selected item Delete highlighted data in selection table. Check all Check all the check boxes. Items that are turned on will be displayed when the ID display is turned on. Uncheck all Clear all check boxes. Lock all Save all data in the selection table to the lock list. Lock Save the highlighted data in the selection table to the lock list. Load locked Read the data saved in the lock list into the selection table. Delete all locked Delete all the data in the lock list. Save Save all data in the selection table in csv format. -&nbspOperation Procedure&nbsp- &nbspWhen you select entities by picking in the main window, entities will be displayed in the selection list. &nbspWhen you click the entity column in the selection list, the clicked entity is highlighted in the main window. In addition, detailed information is displayed in the output window.
