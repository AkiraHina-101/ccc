# Connection | RBar - One to Many

Connection | RBar - One to Many Connection | RBar - One to Many This function is to create one to many (Master : Slave) Rbar (Rigid Beam Element). In this feature, only that case is supported in which all independent degrees of freedom are on one side of the node. ＊Master node and the slave node can be selected on the parts basis, face basis, edge basis, element-wise or on node basis. Master node and slave node (in the connection range) are connected. To prevent double bond with slave DOF, slave nodes that are within the connection range of multiple master nodes are connected to only the nearest master node. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius R of the connection range. Master Dofs UX - RZ All components of the independent DOF is specified to the node selected as master. Analysis Coordinate Frame Coordinate Select the reference coordinate system. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspThe master nodes are selected from parts, face, edge, element and node. &nbspThe slave nodes are selected from parts, face, edge, element and node. &nbspSet the parameters. &nbspClick Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
