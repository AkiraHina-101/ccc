# View Control

View Control View Control Control the current view by numerical input. Center The input coordinates are taken as the rotation center of the model. Reset The rotation center is reset. ※The numerical value being input is not reset. Rotate Rotate by the input angle around each axis. Pan Translate (pan) the view. Pan in Move to the right or up by the entered number. Pan out Move left or down by the entered number. Zoom The view is zoomed in / out at the input magnification rate. Fit Click the button to fit the entire model to the size of the main window. -&nbspOperation Procedure (Center)&nbsp- &nbspEnter coordinate values in x / y / z. &nbspClick the "Set" button. -&nbspOperation Procedure (Rotate)&nbsp- &nbspEnter the rotation angle in x / y / z. &nbspClick the "Rotate" button. -&nbspOperation Procedure (Pan)&nbsp- &nbspEnter the movement amount to the right / up. &nbspClick the "Pan In" or "Pan Out" button. -&nbspOperation Procedure (Zoom)&nbsp- &nbspEnter the magnification to zoom in or out. &nbspClick the "Zoom In" or "Zoom Out" button. &nbspClick the "Fit" button to fit the entire model to the size of the main window. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
