# ComboBox

ComboBox

コンボボックスを作成します。

プレビューダイアログ:

パラメータ​

名前​

コンボボックスの名前を入力します。

有効​

有効にするかどうかを指定します。

オン を選択：利用可能

オフ を選択：利用不可（グレー表示）

サイズ​

幅：コンボボックスの最小幅を指定します（ピクセル単位）

高さ：コンボボックスの最小高さを指定します（ピクセル単位）

Source File​

テキストファイルからオプションをインポートします。

ソースファイルの構造:

Option1
Option2
Option3
Option4
Option5

↓ インポート結果:

Options Count​

選択オプションの数を指定します。

表示​

作成したコンボボックスを表示/非表示にするかを指定します。

オン を選択：表示

オフ を選択：非表示

Options​

コンボボックス内の選択肢の名前を入力します。

関連API​

dlg.add_combobox : ダイアログにコンボボックスコンポーネントを追加します。

dlg.add_combobox_option : コンボボックスコンポーネントにオプションを追加します。

dlg.clear_combobox : 指定されたコンボボックスのすべてのオプションをクリアします。

dlg.get_combobox_sel : 選択されているコンボボックスオプションのインデックスを取得します。

dlg.get_combobox_option : 選択されているコンボボックスオプションの文字列値を取得します。

dlg.get_len_combobox : コンボボックスのサイズ（アイテム数）を取得します。

dlg.set_combobox_sel : 現在の選択をコンボボックスコンポーネントに設定します。

dlg.on_combobox_sel : コンボボックスアイテムが選択された後に作成された関数を実行します。

dlg.insert_combobox_option : コンボボックスコンポーネントの特定の位置にオプションを挿入します。

dlg.insert_combobox_options : コンボボックスコンポーネントの特定の位置に複数のオプションを挿入します。

dlg.remove_combobox_option : コンボボックス内の指定されたオプションを削除します。
