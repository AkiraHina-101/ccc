# CAD Import

CAD Import CAD Import This command is used to define the parameter settings for CAD import. Presets A list of targets for parameter settings for CAD import. Elysium Use the Elysium module to define the parameter settings for CAD import. Applicable CAD type: IGES, CatiaV5, STEP, ACIS and JT. CAD Type Specify the CAD type of the setting target. Parameters for IGES Fixed Curve Preference Specify the calculation method of the trim curve. Auto Stitch Control the ON/OFF of filling the gap of the IGES file without a topology. Stitch Tolerance Define the tolerance for filling the gap. Parameters for CATIA Convert hidden elements Control the ON/OFF of the conversion of hidden elements. Convert hidden instances Control the ON/OFF of the conversion of hidden instances. Convert coordinate system Control the ON/OFF of the conversion of coordinate systems. Parameters for STEP Create Seam Correct (adds seams lines) to topologies without an outer loop. Point Tolerance Specify the tolerance at the same point. Parameters for ACIS Heal Acis Before Version Control the ON/OFF of healing function. Parameters for JT Convert Geometry Type Specify the target element type for conversion. Convert General Body Control ON/OFF of the conversion of the GeneralBody types. Convert Axis Control ON/OFF of the conversion of coordinate systems. Convert Center Line Control ON/OFF of the conversion of the center line. Parameters for Elysium Curve Chord Tolerance The maximum divergence distance when converting the original surface into a facet plane. Curve Chord Angle (degree) Maintain areas with setting angles larger than the angle between facets of surface plane geometry. Convert Isolated Curve Convert single curves. Clean Self Intersecting Loops Detect and eliminate loops that are self-intersecting at vertex locations. 0: Do not do 2: Detect and eliminate self-intersecting loops at vertex locations 3: Detect and eliminate self-intersecting loops ※Before V3.1, this parameter was set internally at 2 state. ※If an edge that does not exist in the original CAD appears after loading the model, this option may affect the self-crossing loop cancellation processing. In that case, please specify 0 and use it. Reset Return the setting to the initial setting. Parasolid Use the Technostar module to define the parameter settings for Parasolid file import. Surface Plane Tolerance（m） The maximum divergence distance when converting the original surface into a facet plane. Surface Plane Angle (degree) Maintain areas with setting angles larger than the angle between facets of surface plane geometry. Curve Chord Tolerance（m） The maximum divergence distance when converting the original surface into a facet plane. Curve Chord Angle (degree) Maintain areas with setting angles larger than the angle between facets of curve chord geometry. Max Facet Width（m） Specify the maximum size of a single facet edge. Min Facet Width（m） Specify the minimum size of a single facet edge. Reset Return the setting to the initial setting. Spatial Use the Spatial module to define the parameter settings for CAD import. Surface Plane Tolerance Adjusted distance value (plane) of the CAD face and divided facet surface Surface Plane Angle (degree) Maintain areas with setting angles larger than the angle between facets of surface plane geometry. Max Facet Width Max Facet Width NX Multibody Configure multibody read settings. ON: Load multibody into one part. OFF: Separate the multibody into parts and load it under the subassembly. Reset Return the setting to the initial setting. ProE/Creo Use the Spatial module to define the parameter settings for CAD import. Curve Chord Tolerance The maximum divergence distance when converting the original surface into a facet plane. Curve Chord Angle (degree) Maintain areas with setting angles larger than the angle between facets of curve chord geometry.
