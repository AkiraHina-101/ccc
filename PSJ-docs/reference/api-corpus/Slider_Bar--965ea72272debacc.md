# Slider Bar

Slider Bar Slider Bar スライドバーを追加します。 &nbsp;&nbsp;&nbsp;作成イメージ図： Name &nbsp;&nbsp;&nbsp;Slider Barコンポーネント名を入力します。 Width &nbsp;&nbsp;&nbsp;スライドバーの最小幅を指定します。（単位：ピクセル） Height &nbsp;&nbsp;&nbsp;スライドバーの最小の高さを指定します。（単位：ピクセル） Min &nbsp;&nbsp;&nbsp;スライドバーの最小値。 Max &nbsp;&nbsp;&nbsp;スライドバーの最大値。 Pos &nbsp;&nbsp;&nbsp;スライドバーのデフォルト値（デフォルト位置）。 Vertical &nbsp;&nbsp;&nbsp;スライドバーの表示方向を指定します。 チェックオン &nbsp;:&nbsp;垂直方向に表示。 チェックオフ &nbsp;:&nbsp;水平方向に表示。 Show Minor Type in Tick Mark &nbsp;&nbsp;&nbsp;補助目盛線の表示/非表示を指定します。 チェックオン &nbsp;:&nbsp;表示する。 チェックオフ &nbsp;:&nbsp;表示しない。 ShowBorder &nbsp;&nbsp;&nbsp;スライドバーの境界線の表示/非表示を指定します。 チェックオン &nbsp;:&nbsp;表示する。 チェックオフ &nbsp;:&nbsp;表示しない。 Show tick marks on both side &nbsp;&nbsp;&nbsp;目盛の表示位置を指定します。 チェックオン &nbsp;:&nbsp;目盛を両側に表示。 チェックオフ &nbsp;:&nbsp;目盛を片側にのみ表示。 Enable &nbsp;&nbsp;&nbsp;使用の可否を指定します。 チェックオン &nbsp;:&nbsp;使用可能。 チェックオフ &nbsp;:&nbsp;使用不可。（グレーアウトされます）
