# Mesh Quality&nbsp;-&nbsp;Manual Check&nbsp;[Hex]

Mesh Quality&nbsp;-&nbsp;Manual Check&nbsp;[Hex] Mesh Quality&nbsp;-&nbsp;Manual Check&nbsp;[Hex] Make corrections to the solid mesh (Hex 8) according to the selected quality standard. Element Quality Metric：Select how to measure element quality from the pull-down menu. Stretch: If checked, detect and display elements with a stretch value less than or equal to the specified value. Aspect Ratio: If checked, elements with aspect ratios greater than or equal to the specified value will be detected and displayed. Edge length: If checked, element edges with a length greater than or equal to the specified value will be detected and displayed. Volume: If checked, elements with volumes below the specified value will be detected and displayed. Unstable: When checked, detect and display an element that is unstablely connected to other elements at corner nodes. ※Please refer to ＜definition of quality check method＞ for each item. Cutoff Value Minimum: Display the minimum value of the set check type. Maximum: Display the maximum value of the set check type. Average: Display the average value of the set check type. Number of Entities: Display the number of element types in the selected model. Display Condition: Set the inequality sign for the set value. Value: Enter the setting value of the element to be displayed. Number of Entities: Display the number of displayed elements. Refresh Show Model: Press the Show Model button to restore the model display. -&nbspOperating Procedure&nbsp- &nbspSelect the body you want to check the element shape. &nbspSelect the element quality measurement method. &nbspSet the threshold of the element to be displayed. &nbspPress the Apply or OK button. &nbspIf you want to restore the model view, press Show Model. ※The current automatic cleanup feature can not be applied to hex elements.
