# Connection | RBE3 - One to one

Connection | RBE3 - One to one Connection | RBE3 - One to one This function is to create one to one (Slave : Master) RBE3 (Interpolation constraining Element). ＊Slave node and the master node can be selected on the parts basis, face basis, edge basis, element-wise or on node basis. Slave node and master node (in the connection range) are connected. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius R of the connection range Slave Dofs UX - RZ Specify the component of slave degree of freedom. Master Dofs Weight Enter the weighting factor. UX - RZ Specify the component degrees of freedom with a weighting factor. Analysis Coordinate Frame Coordinate Select the reference coordinate system. Options for Abaqus Surface Definition Output Select how to define the surface. By Node Set Specify the node as a reference surface. By Element Set Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspThe slave nodes are selected from parts, face, edge, element and node. &nbspThe master nodes are selected from parts, face, edge, element and node. &nbspSet the parameters. &nbspClick Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
