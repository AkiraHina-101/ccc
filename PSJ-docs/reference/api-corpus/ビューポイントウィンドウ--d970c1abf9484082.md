# ビューポイントウィンドウ

ビューポイントウィンドウ ビューポイントウィンドウ ビューポイント操作用のウィンドウです。 ツールバー ビューポイント操作用ツールバーです。 アイコン 名称 説明 追加 現在のビューを新規ビューポイントとしてユーザービューポイントに追加します。 リネーム 既存のユーザービューポイントの名称を変更します。 削除 ユーザービューポイントを削除します。 インポート ユーザービューポイントファイルを読み込みます。 エクスポート ユーザービューポイントファイルを書き出します。 ビューポイントツリー ユーザービューポイント アイテムをダブルクリックすることで、プリセットビューポイントにビューを動かします。 また、 ユーザービューポイントダブルクリック時に回転・移動・ズームの各パラメータの有効・無効を、マウス右クリックから表示されるチェックボックスで操作可能です。 ユーザーフレーム ユーザーフレームは、ホームリボン内の範囲選択キャプチャからユーザーフレームコマンドで追加されます。 追加されたアイテムをダブルクリックすることで、範囲選択キャプチャフレームがメインウインドウに表示されます。 プリセットビュー アイコンをクリックし、プリセットビューポイントにビューを動かします。 ビューコントロール 中心 モデルの回転中心を設定します。 X,Y,Z &nbsp;:&nbsp;中心座標を入力します。 セット &nbsp;:&nbsp;指定した座標系に設定します。 リセット &nbsp;:&nbsp;設定を元に戻します。 回転 モデルの回転角度を設定します。 X,Y,Z,エッジ,法線 &nbsp;:&nbsp;回転角度を入力します。 X: X軸中心に回転します。 Y: Y軸中心に回転します。 Z: Z軸中心に回転します。 エッジ: 選択エッジを中心軸として、軸中心に回転します。 法線: 画面に対して垂直方向の軸を中心として、軸中心に回転します。 回転 &nbsp;:&nbsp;指定した角度で各軸まわりに回転します。 表示 &nbsp;:&nbsp;回転矢印を表示/非表示にします。 パン 画面上での移動距離を設定します。 左←,右→ &nbsp;:&nbsp;指定した距離で水平方向に移動します。 上↑,下↓ &nbsp;:&nbsp;指定した距離で垂直方向に移動します。 ズーム 画面上での拡大率を設定します。 ズームイン &nbsp;:&nbsp;指定した値で拡大します。 ズームアウト &nbsp;:&nbsp;指定した値で縮小します。 フィット &nbsp;:&nbsp;モデルをウィンドウの最適サイズに設定します。 -&nbsp;操作手順（ユーザービューポイントの追加）&nbsp;- &nbsp;メインウィンドウの画面上で、ビューを任意の位置に動かします。 &nbsp;ビューポイントウィンドウの「追加」アイコンをクリックします。 &nbsp;ユーザービューポイント名ダイアログが表示されますので、任意の名称を入力してOKをクリックします。新規ユーザービューポイントが追加されます。 &nbsp;ビューを動かした後、追加されたユーザービューポイントをダブルクリックします。追加した際のビューが復帰します。 ※追加したユーザービューポイント右クリックから、PanとZoomのチェックをOFFにすることで、現在のビューのフォーカス位置を保持したままモデルを回転することができます。これにより、任意座標系ビューとして使用することができます。 -&nbsp操作手順(中心)&nbsp- x/y/zに座標値を入力します。 「設定」ボタンをクリックします。 -&nbsp操作手順(回転)&nbsp- x/y/zに回転角度を入力します。 「回転」ボタンをクリックします。 -&nbsp操作手順(パン)&nbsp- 右/上に移動量を入力します。 「パンイン」または「パンアウト」ボタンをクリックします。 -&nbsp操作手順(ズーム)&nbsp- 拡大または縮小させる倍率を入力します。 「ズームイン」または「ズームアウト」ボタンをクリックします。 モデル全体をメインウィンドウのサイズに合わせて表示したい時は「フィット」ボタンをクリックします。
