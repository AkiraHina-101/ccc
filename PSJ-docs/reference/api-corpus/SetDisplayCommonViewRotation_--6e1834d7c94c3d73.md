# SetDisplayCommonViewRotation()

SetDisplayCommonViewRotation()

説明​

共通のビュー回転の表示を設定します。

構文​

SetDisplayCommonViewRotation(int AutomaticSwitch2D3D, int Show3DRotationRegion, int AutomaticFitInPresetViewOperation, int QuickRotation)

入力​

1. int​

2D/3D の自動切り替え

0: オフ

1: オン

2. int​

3D 回転領域の表示

0: オン

1: オフ

3. int​

プリセットビュー操作の自動フィット

0: オフ

1: オン

4. int​

クイック回転

0: オフ

1: オン

戻り値​

戻り値なし。

サンプルコード​

SetDisplayCommonViewRotation(0, 0, 1, 1)
