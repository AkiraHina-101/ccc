Solid Bolt Modeling | Mating Face Solid Bolt Modeling | Mating Face The following operations are automatically performed on solid bolts created in advance. ・Automatic placement of solid bolts ・Create a face for the seating area ・Setting Analysis Conditions &nbsp;&nbsp;&nbsp;Pretension for SunShine setting and contact setting The Solid Bolt Modeling > Size function allows you to create a solid bolt model. The solid bolt model (*.jth5) to be used should be placed in [User Profile]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB ※This folder is created when the Mating Face dialog is started. Selection list Part(Head) ：The part from which the head part of the bolt Part(Shaft) ：The part where the shaft portion of the bolt Edge(Head) ：The Edge of the area where the head of the bolt (manual operation) Face(Shaft) ：The Face of the area where the shaft of the bolt(manual operation) Mating Face Parameters Gap Tolerance Enter the clearance tolerance between the upper and lower parts of the mating surfaces. Bolt holes on the mating surfaces that are less than or equal to this gap will be searched. Angle Tolerance Enter the mating surface angle tolerance (deg) between the upper and lower parts. This parameter is used to determine the flatness of the mating surfaces and normally does not need to be changed. Fastening Holes Parameters Presets Size The bolt hole size selected in this menu is automatically entered into the minimum and maximum circle ranges below. The preset size of the bolt holes and the minimum and maximum indexes refer to 「[user profile]\AppData\Roaming\TechnoStar\JPT***\DataBase\SolidBoltDB\Bolt_range_size_chart.xlsx」 Edit this file if you want to change the minimum and maximum values that define the preset size. Min Circle Range Enter the minimum diameter of the bolt hole to be searched. Max Circle Range Enter the maximum diameter of the bolt hole to be searched. Seat Parameters Radius Factor Enter the radius factor for the bolt seating surface that creates the face. Contact Parameters Contact Type &nbsp;&nbsp;&nbsp;Select the type of contact to be set up. Mating Face &nbsp;:&nbsp;General (Sliding contact) Bolt Hole &nbsp;:&nbsp;Tied contact Seat &nbsp;:&nbsp;General (Sliding contact) Activation &nbsp;&nbsp;&nbsp;Turn ON to activate the function Touching Distance Range(ERROR) &nbsp;&nbsp;&nbsp;Distance below which a node is considered touching a body. Friction Coefficient (FRIC) &nbsp;&nbsp;&nbsp;Friction Coefficient. Interference Closure(CINTERF) &nbsp;&nbsp;&nbsp; Specify interference closure amount, normal to the contact surface (define for two faces in confact). Delayed Slide Off(SLIDE) &nbsp;&nbsp;&nbsp;Delayed slide off distance. This entry should not be made unless ICOORD >= 2. When using the delayed slide off option, a node sliding on a segment will slide off this segment only if it passes the node or edge at a sharp corner over a distance larger than the delayed slide off distance. Modify Coordinates（ICOORD) &nbsp;&nbsp;&nbsp;None: to ignore this option. &nbsp;&nbsp;&nbsp; Modify position: to modify the coordinates of a node in contact with a deformable body so that stress-free initial contact can be obtained. &nbsp;&nbsp;&nbsp;Delay sliding: to extend the tangential error tolerance at sharp corners of deformable bodies to delay sliding off a contacted segment. &nbsp;&nbsp;&nbsp;Both effect: to have both Modify position and Delay sliding active. Type of Tied Contact(JGLUE) &nbsp;&nbsp;&nbsp;This option is only relevant if the glue option is invoked (JGLUE > 0). &nbsp;&nbsp;&nbsp;Choose 0 if a node should not separate. &nbsp;&nbsp;&nbsp;Choose 1 to invoke the standard separation behavior based on the maximum residual force. &nbsp;&nbsp;&nbsp;Choose 2 to activate breaking glue. Penalty Factor(SFACT) &nbsp;&nbsp;&nbsp;Factor for increasing time steps due to number of iterations. Penalty Factor(SFACT T) &nbsp;&nbsp;&nbsp;Penalty factor (stiffness) used for segment-to-segment contact analysis, the program will calculate the value but the user can change it to improve convergence. Contact Damping(CDAMP) &nbsp;&nbsp;&nbsp;Contact Damping Coefficient.
