# Tools.DisplacementCS()

Tools.DisplacementCS()

Description​

Displace coordinate

Syntax​

Tools.DisplacementCS(crlInst=[], crCoordSystem=None)

Ribbon: Tools » DisplacementCS

Inputs​

crlInst​

A List of Cursor specifying the inst.

The default value is [].

crCoordSystem​

A Cursor specifying the coordinate system.

The default value is None.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Tools.DisplacementCS(crlInst=[], crCoordSystem=None)
