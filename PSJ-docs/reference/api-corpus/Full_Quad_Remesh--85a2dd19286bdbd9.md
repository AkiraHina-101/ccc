# Full Quad Remesh

Full Quad Remesh Full Quad Remesh Remesh all selected areas with square elements. It is necessary to meet the following conditions: 1. An even number of triangles are included in remesh range. 2. The shape of the remesh range is close to a triangle, square or pentagon. 3. Remesh range corresponds to each place (a remote place can not be executed at the same time). ※Edges within the remesh range are not retained. ※The surface position of the remesh area is aligned with the surface of the reference part. If there is a solid CAD and mid-plane reference part, give priority to the mid-plane reference part surface. Please note that if there is no reference, the remeshing range will be flat. Parameters Highlight TRI Highlight triangle element of display part Pattern Number of candidates for remeshing results Rev / Next button Switch preview display of remeshed result -&nbspOperation Procedure (when making triangular element into quadrilateral element)&nbsp- &nbspTurn on Highlight TRI, if necessary. &nbspSelect triangle and square elements of the remesh range to meet the conditions. &nbspSwitch the preview of the element pattern with the Rev button or the Next button as needed. ※If there are an odd number of triangles or if there is a problem with the selection, the preview will not be displayed. &nbspClick the Apply / OK button. &nbspAll selected areas are remeshed with square elements. -&nbspOperation Procedure (when smoothing a square element)&nbsp- &nbspIf necessary, turn on Highlight TRI. &nbspSelect the square element of the remesh range to meet the conditions. &nbspChange the preview of the remeshing result with the Rev button or Next button, as required. ※If there is a problem with the selection, it will not be previewed. &nbspClick the Apply / OK button. &nbspThe nodes of the selection rectangle are smoothed and rearranged.
