# Tools.Measure.Angle.ProjectedNode()

Tools.Measure.Angle.ProjectedNode()

Description​

Measure angle on projected node

Syntax​

Tools.Measure.Angle.ProjectedNode(crNode, strTarget="All", iPrecision=6)

Ribbon: Tools » Measure » Angle » ProjectedNode

Inputs​

crNode​

A Cursor specifying the node.

This is a required input.

strTarget​

A String specifying the target.

The default value is "All".

iPrecision​

An Integer specifying the precision.

The default value is 6.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Tools.Measure.Angle.ProjectedNode(crNode, strTarget="All", iPrecision=6)
