# PRETENSION_LOAD

PRETENSION_LOAD

Description​

A data type uses to control parameters of pretension load.

Attributes​

iSolverType​

An Int specifying Solver type.

0: All

1: Abaqus

The default value is 0.

dValue​

A Double specifying pretension load.

The default value is 0.

iUnit​

An Int specifying input unit setting.

The default value is 0.

bBoltFixLength​

A Bool specifying whether create bolt fix length.

The default value is False.
