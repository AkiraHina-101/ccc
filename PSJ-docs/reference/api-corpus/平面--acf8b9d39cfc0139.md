# 平面

平面 平面 このコマンドでは、平面を延長します。 オプション 延長タイプ &nbsp;&nbsp;&nbsp;延長するタイプを選択します。 平面：平面で延長します。 円筒面：円筒面で延長します。 方法 &nbsp;&nbsp;&nbsp;方法を選択します。 軸方向へ：延長するフェースの方向を座標平面で指定します。 フェースへ：指定したフェースまで平面を延長します。 エッジオフセット：指定したフェースを指定した長さで延長します。 座標系：任意の座標系を指定し、座標方向にエッジを引き伸ばしフェースを作成します。 パラメーター 座標平面 &nbsp;&nbsp;&nbsp;延長する座標平面を指定します。 XY ： XY平面上 YZ ： YZ平面上 ZX ： ZX平面上 z/x/y &nbsp;&nbsp;&nbsp;XY を選択した場合、Z 方向の座標値を入力します。 &nbsp;&nbsp;&nbsp;YZ を選択した場合、X 方向の座標値を入力します。 &nbsp;&nbsp;&nbsp;ZX を選択した場合、Y 方向の座標値を入力します。 エッジオフセット 長さ &nbsp;&nbsp;&nbsp;オフセット値を入れます。 座標系 座標系 &nbsp;&nbsp;&nbsp;任意の座標系を指定し、座標方向にエッジを引き伸ばしフェースを作成します。 軸 &nbsp;&nbsp;&nbsp;延長するフェースの方向を指定します。 マグニチュード &nbsp;&nbsp;&nbsp;延長する値を入力します。 その他 平面法線と同方向 &nbsp;&nbsp;&nbsp;チェックを入れると反対方向にフェースを作成します。 円弧の半径 &nbsp;&nbsp;&nbsp;円筒面の円弧の半径を入力します。 円弧の節点数 &nbsp;&nbsp;&nbsp;円筒面の円弧の分割数を入力します。 -&nbsp操作手順（平面｜軸方向へ)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;延長する座標平面を指定します。 &nbsp;z/x/yに座標値を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順（平面｜フェースへ)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「リファレンス」をクリックして延長先のフェースを選択します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順（平面｜エッジオフセット)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;オフセット値を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順（平面｜座標系)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;軸のプルダウンメニューから延長するフェースの方向を指定します。 &nbsp;マグニチュードに延長する値を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順（円筒面｜軸方向へ)&nbsp- &nbsp;選択リストを開き「フェース」をクリックして延長したいフェースを選択します。 &nbsp;「エッジ」をクリックして延長したいエッジを選択します。 &nbsp;延長する座標平面を指定します。 &nbsp;z/x/yに座標値を入力します。 &nbsp;シリンダー面の円弧の半径と節点数を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp操作手順（円筒面｜フェースへ)&nbsp- &nbsp;選択リストを開き「フェース延伸」をクリックして延長したいフェースを選択します。 &nbsp;「リファレンス」をクリックして延長先のフェースを選択します。 &nbsp;軸のプルダウンメニューから延長するフェースの方向を指定します。 &nbsp;円弧の半径と節点数を入力します。 &nbsp;適用またはOKをクリックします。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
