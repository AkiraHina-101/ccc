# POST_RESULT_KEY

POST_RESULT_KEY

説明​

選択された結果を識別するために使用されるデータ型です。

属性​

iAnalysisType​

解析タイプを指定する Integer です。

デフォルト値は0です。

iAnalysisID​

解析IDを指定する String です。

デフォルト値は0です。

iResultSet​

結果セットを指定する String です。

デフォルト値は0です。

iTimeStep​

タイムステップを指定する String です。

デフォルト値は0です。

iResultType​

カテゴリタイプを指定する String です。

デフォルト値は0です。

strResultName​

結果名を指定する String です。

デフォルト値は""です。

strResultCompName​

結果コンポーネント名を指定する String です。

デフォルト値は""です。

iResultPos​

結果位置を指定する String です。

デフォルト値は0です。
