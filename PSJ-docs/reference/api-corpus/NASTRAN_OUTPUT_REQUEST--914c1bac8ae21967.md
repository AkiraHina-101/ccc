# NASTRAN_OUTPUT_REQUEST

NASTRAN_OUTPUT_REQUEST

説明​

Nastran Output Requestのパラメータを制御するために使用されるデータ型です。

属性​

iValueDisplacement​

ずれ出力要求を指定する Integer です。

0: なし。

DFLT_INT: 全て。

デフォルト値はDFLT_INTです。

iValueSpcforces​

シングルポイント制約力出力要求を指定する Integer です。

0: なし。

DFLT_INT: 全て。

デフォルト値はDFLT_INTです。
