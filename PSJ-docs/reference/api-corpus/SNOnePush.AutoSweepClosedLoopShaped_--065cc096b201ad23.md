# SNOnePush.AutoSweepClosedLoopShaped()

SNOnePush.AutoSweepClosedLoopShaped()

Description​

Make hexa for closed loop shaped

Syntax​

SNOnePush.AutoSweepClosedLoopShaped(crlParts, dMeshSize, dLengthSize)

Ribbon: SNOnePush » AutoSweepClosedLoopShaped

Inputs​

crlParts​

A List of Cursor specifying the part.

This is a required input.

dMeshSize​

A Double specifying the mesh size.

This is a required input.

dLengthSize​

A Double specifying the length size.

This is a required input.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

SNOnePush.AutoSweepClosedLoopShaped(crlParts, dMeshSize, dLengthSize)
