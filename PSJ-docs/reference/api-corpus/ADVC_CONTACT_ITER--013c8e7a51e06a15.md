# ADVC_CONTACT_ITER

ADVC_CONTACT_ITER

Description​

A data type uses to control parameters of ADVC Contact Iter

Attributes​

iSubdivideMode​

An Integer specifying subdivide mode.

The default value is -1.

iContactloopMax​

An Integer specifying contactloop maximum.

The default value is DFLT_INT.

iInternalContactloopMax​

An Integer specifying internal contactloop maximum.

The default value is DFLT_INT.

dSeparationTol​

A Double specifying separation tolerance.

The default value is DFLT_DBL.

dRelativeSeparationTol​

A Double specifying relative separation tolerance.

The default value is DFLT_DBL.

dPenetrationTol​

A Double specifying penetration tolerance.

The default value is DFLT_DBL.

dRelativePenetrationTol​

A Double specifying relative penetration tolerance.

The default value is DFLT_DBL.

iMaxchp​

An Integer specifying maxchp.

The default value is DFLT_INT.

iFrictionOnset​

An Integer specifying friction onset.

The default value is 0.

dStickSlipTol​

A Double specifying stick slip tolerance.

The default value is DFLT_DBL.

dFrictionTol​

A Double specifying friction tolerance.

The default value is DFLT_DBL.
