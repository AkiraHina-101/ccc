# MeshCleanup.Manual3D.CreateHex()

MeshCleanup.Manual3D.CreateHex()

Description​

Create hex8 elements

Syntax​

MeshCleanup.Manual3D.CreateHex(iParentEntityId=0, crlElems=[], iSeprateN=1)

Ribbon: MeshCleanup » Manual3D » CreateHex

Inputs​

iParentEntityId​

An Integer specifying the parent entity ID.

The default value is 0.

crlElems​

A List of Cursor specifying the element.

The default value is [].

iSeprateN​

An Integer specifying the seprate n.

The default value is 1.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshCleanup.Manual3D.CreateHex(iParentEntityId=0, crlElems=[], iSeprateN=1)
