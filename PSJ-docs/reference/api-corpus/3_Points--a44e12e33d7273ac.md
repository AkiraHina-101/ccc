# 3 Points

3 Points a.no-uline {text-decoration:none} 3 Points Move the Target Part from the original position to the new position by the 3 pairs of coordinates points. Selection list Edge: Select the circular edge or the arc to determine the center position. Node: Select the Node to get the coordinate position value. Part: Select the Target Part to be moved. Coordinates Original Position &nbsp;&nbsp;&nbsp;Specify the coordinates of 3 points that define the original positions on the Target Part. Next Position &nbsp;&nbsp;&nbsp;Specify the coordinates of 3 points that define the destination positions. Operation Preview &nbsp;&nbsp;&nbsp;Display temporary results as a preview (not the final result of the mesh). Create New Part &nbsp;&nbsp;&nbsp;Copy the Target Part after moving as a new part. LBC Copy &nbsp;&nbsp;&nbsp;Also copy Load and Boundary Condition that were added to the existing part to a new part. Property Copy &nbsp;&nbsp;&nbsp;Also copy properties that were added to the existing part to a new part. Reference Copy &nbsp;&nbsp;&nbsp;Also copy references that were added to the existing part to a new part. -&nbspOperating Procedure&nbsp- &nbsp;Select the circular edges to get the original center coordinates on the Target Part. &nbsp;Select the circular edges to get the destination center coordinates. &nbsp;Select the Target Part to be moved. &nbsp;If you want to create a new Part after moving, turn on the Create New Part check box. &nbsp;Turn on the LBC Copy to copy Load and Boundary Condition of the existing part to the new part. &nbsp;Turn on the Property Copy to copy properties of the existing part to the new part. &nbsp;Turn on the Reference Copy to copy references of the existing part to the new part. &nbsp;Press the Apply or OK button. -&nbspNotes&nbsp- The input coordinates will automatically switch after each selection. Users can flexibly select between Edges and Nodes instead of selecting only Edges or Nodes. Users can identify the current selection by the highlighted textbox. Moreover, the markers are also supported to show in the Main Window to recognize the position. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
