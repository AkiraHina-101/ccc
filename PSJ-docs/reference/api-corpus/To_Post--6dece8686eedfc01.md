# To Post

To Post To Post Convert data of a model with settings information from an opening Pre document to a new Post document. Option All parts and settings information of the model will be converted from Pre document to a new Post document by five following options. Group Convert model with group information. The convertible group types are nodal group (node, vertex), 1D group (bar, edge, 1D element edge, element edge), 2D group (face, 2D element), and 3D group (part, solid element). LBC Convert model with LBC information. The convertible LBC types are Force, Pressure, and Fixed constraint. Connection Convert model with connection information. The convertible connection types are MPC, RBE2, RBE3, Bush, Connector, Gaps, RBar, Spring, and Damper. Coordinate Convert model with local coordinate information. Property Convert model with material property information. The convertible material property types are 1D Properties, 2D Properties, and 3D Properties. -&nbspOperating Procedure&nbsp- Launch the dialog. Select option to convert (support selecting multiple options). Click "OK" button to convert data. -&nbspSpecial Note&nbsp- &nbsp&nbsp&nbspIf no option is selected, only parts of the model are converted without any settings information.
