# Main Window

Main Window Main Window The geometry or mesh model is displayed. When multiple documents are open at the same time, click the tab at the top of the window or use the main window operation button on the right side of the ribbon menu to display the document you want to view. Mouse Operation A list of mouse operations in the main window. Mouse Operation Function Scroll button click and drag Rotate the view Wheel scroll Zoom in or out of the model view Right button click and drag Translate the view (Pan) Left button click Select one of the entity Left button click and drag Define the range to select multiple entities within the range Right button click Display shortcut menu Mouse settings can be changed in the preferences within the Home menu. Main Window Operation Buttons Control the display of the document window of the main window. Icon Name Description Minimize Minimize the active document display Cascade Indicate arranging the document you open inside the main window Close Close the document in display Settings can be changed in the preference command from the Home menu. Toolbar The main window has four toolbars: View toolbar, View option toolbar, Selection toolbar, and Selection option toolbar. These are used by clicking on the icon with the left mouse button. The settings of the display / non-display and arrangement of each toolbar can be changed from the Preference command in the Home menu. View Toolbar It is a toolbar that summarizes the functions related to the view operation. If you select "Yes" to the message "Delete connection center node and LBCs as well?", the connection settings and floating nodes directly connected to the entity will be deleted at the same time. In addition, if the deleted connection settings are also connected to boundary condition floating nodes, they are also deleted. Example 1: When mass element is connected to RBE2 center, mass element is deleted when RBE2 is deleted. Menu available when selecting groups Menu Content Hide Hide selected groups Show Display selected groups Edit Change settings of selected group Cursor Peripheral Entity Function By holding the Alt key and double-clicking the left mouse button on an entity, the list of entities near the double-clicked point of mouse cursor is displayed. It is possible to check each entity in the list, for example, in a part where detailed entities are concentrated. Also, by clicking on an item in the list, the corresponding entity is highlighted in the main window.
