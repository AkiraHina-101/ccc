# プリファレンス

プリファレンス プリファレンス Jupiter-Preの各種設定を行います。 リストメニュー マウスとキー メインウィンドウ上でのマウス操作及びキーバインドの設定を行います。 画面設定 メインウィンドウ上の各種表示設定を行います。 フォント メインウィンドウ上に表示されるフォント表示設定を行います。 色 メインウィンドウ上に表示されるエンティティの色設定を行います。 ツールバー メインウィンドウ上のツールバーの表示位置及び表示/非表示設定を行います。 背景 メインウィンドウの背景色の設定を行います。 単位 単位系の設定を行います。 ライセンス ライセンスオプションのON/OFF設定を行います。 言語設定 GUI及びヘルプファイルの言語表示設定を行います。 CADインポート CAD読み込み時のパラメータ設定を行います。 パス設定 各フォルダパス設定を行います。 表示桁数 Jupiter上の数値表示形式の設定を行います。 コマンド コマンドウィンドウの設定を行います。 保存/読込 ファイルの保存・読込に関連する設定を行います。 共通ボタン インポート 設定項目を保存したファイルを読み込みます。 エクスポート 設定項目をファイルに保存します。 OK 変更を適用し、プリファレンスを終了します。 キャンセル 変更をキャンセルしてプリファレンスを終了します。 適用 変更を適用します。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
