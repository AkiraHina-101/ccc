# Jupiterのライセンスを有効/無効にします

Jupiterのライセンスを有効/無効にします

🎯 導入​

このチュートリアルでは、Jupiterのライセンスを有効/無効にする方法を学びます。

特定のライセンスのステータスを確認します JPT_BASE 有効または無効です。

ライセンスを有効にします JPT_BASE.

ライセンスを無効にします JPT_BASE.

📖 チュートリアル​

# 日本語のエンコーディング
# コーディング: cp932

# Python APIウィンドウでログメッセージをクリアします
JPT.ClearLog()

# ライセンスのステータスを確認するJPT_BASEは有効かどうかです
isEnable = JPT.CheckLicense('JPT_BASE')
if isEnable == True:
    print('ライセンスJPT_BASE有効です')
else:
    print('ライセンスjPT_BASE無効です')

# ライセンスを有効にしますJPT_BASE
JPT.EnableLicenseFeature("JPT_BASE", 1)

#ライセンスを無効にしますJPT_BASE
JPT.EnableLicenseFeature("JPT_BASE", 0)
