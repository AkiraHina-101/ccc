# SHAPE_SEARCH_OPTION

SHAPE_SEARCH_OPTION

説明​

形状検索のパラメータを制御するために使用されるデータ型です。

属性​

iType​

検索対象を指定する Int です。

0: アーク

1: 円／同心円

2: ループ

3: 平面

4: 円錐

5: 円盤

6: 空洞円盤

7: 全体

8: 1つの面で構成される全体円筒

9: 閉じた部分円筒

10: 開いた部分円筒

11: フィレット（半径）

12: フィレット（円弧長）

13: 微小なフェース

bAll​

直径制限なしで検索するかを指定する Boolean です。

デフォルト値は False です。

dMin​

最小直径を指定する Double です。

デフォルト値は 0[m] です。

dMax​

最大直径を指定する Double です。

デフォルト値は 0.005 [m] です。
