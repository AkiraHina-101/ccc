# .pycファイルをPSJ環境で実行する方法

.pycファイルをPSJ環境で実行する方法

1. .pyファイルの準備​

使用するPSJモジュールをすべてimportしてください。

例：check.py

import JPT
import Geometry

Geometry.Part.Cube()
JPT.ViewFitToModel()
faces = JPT.GetAllFaces()
for face in faces:
    JPT.SelectionByID(JPT.EntityType.FACE, face.id, True)

2. .pyファイルを.pycへコンパイル​

コマンド例：

"C:\Program Files\TechnoStar\Jupiter_5.0.3\python.exe" -m py_compile C:\Temp\check.py

check.pyと同じ場所に、pycache というフォルダが作成され、フォルダ内に check.cpython-39.pyc が生成されます。

3. .pycを実行するスクリプト（Exec.py）の作成​

# pycファイルをロードして実行する
import importlib.util
spec = importlib.util.spec_from_file_location("module", r"C:\Temp\__pycache__\check.cpython-39.pyc")

module = importlib.util.module_from_spec(spec)
# exec_moduleを使ってモジュールを実行
try:
    spec.loader.exec_module(module)
except Exception as e:
    print(f"An error occurred: {e}")

4. Exec.py を実行​

IDE、バッチファイル、ランチャー、Jupiterリボンなどから実行可能です。

5. 注意事項​

.py → .pyc のコンパイルには Jupiter インストール場所直下の python.exe を使用してください。

標準出力はオーバーライドされているため、printは.pyc化すると動作しないことを確認しております。その場合、JPT.MsgOut()をご利用ください。

例：check_print.py

import JPT
import Geometry

Geometry.Part.Cube()
JPT.ViewFitToModel()
faces = JPT.GetAllFaces()
for face in faces:
    JPT.SelectionByID(JPT.EntityType.FACE, face.id, True)

JPT.MsgOut(f'A cube is created and all the {len(faces)}faces are selected.')

Exec.py

import importlib.util
import sys

# pycファイルをロードして実行する
spec = importlib.util.spec_from_file_location("module", r"C:\Temp\__pycache__\check_print.cpython-39.pyc")
module = importlib.util.module_from_spec(spec)

# exec_moduleを使ってモジュールを実行
try:
    spec.loader.exec_module(module)

except AttributeError as e:
    print(f"Error during module execution: {e}")
except Exception as e:
    print(f"An unexpected error occurred: {e}")

if __name__ == '__main__': ブロックは実行されません。必要があれば module.main() を明示的に呼び出してください。

例：Exec.py

try:
    spec.loader.exec_module(module)
    module.main()
except Exception as e:
    print(f"An error occurred: {e}")

PSJ Commandモジュールのインポートは、使用しているPSJのモジュール分追記する必要があります。
例えば、サーフェースメッシングのPSJ Commandを使用している場合、

import Meshing

が必要になります。

その他、.pyc化することで動作しなくなる関数がある可能性がございます。
