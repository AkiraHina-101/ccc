# Connection | RBE2 - To Circle Center

Connection | RBE2 - To Circle Center Connection | RBE2 - To Circle Center This function is to create one to many (Master : Slave) RBE2 (Rigid Element). ＊Slave node is available for selection on face basis and edge basis. Master node and slave node (in the connection range) are connected. The master node is created on the coordinates of the centre of the selected arc. This is useful when you want to create a RBE2 for a circle or a cylindrical shape. Connection Name Enter the name to be registered. Search Area All Specify the connection range as infinite. Tolerance Enter the radius R of the connection range. Reference Dofs UX - RZ Specify the component of the dependent DOF. Analysis Coordinate Frane Coordinate Select the reference coordinate system. Options for Abaqus Surface Definition Output Select how to define the surface. By Node Set Specify the node as a reference surface. By Element Set Specify the element as a reference surface. You can not configure an element to the slave entity (node, edge) and if it has been selected an error will be output. Options Only corner nodes Connect only to the corner nodes of the selected entity. -&nbspOperating Procedure&nbsp- &nbspSet the connection range. &nbspSelect the edge. Now, the coordinates of the master node is defined at the center of the edge. &nbspSelect a Face for the slave nodes. If you do not select a face, edge nodes are specified as slave. &nbspSet the parameters. &nbspClick Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
