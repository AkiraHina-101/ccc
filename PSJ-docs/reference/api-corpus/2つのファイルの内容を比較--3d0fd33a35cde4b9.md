# 2つのファイルの内容を比較

2つのファイルの内容を比較

🎯 はじめに​

本チュートリアルでは、2つのファイル(ログファイル、出力ファイルなど)の内容を比較する方法について紹介します:

インストールされているJupiterのパスを取得する。

内容を比較する2つのファイルのパスを設定する。

2つのファイルの内容を比較し、
比較結果(同じか異なるか)をPython APIウィンドウに表示する。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# ファイル比較モジュール'filecmp'をインポートします。
import filecmp

# インストールされているJupiterのパスを取得します。
jupiterPath = JPT.GetAppPathInfo(JPT.PathType.PROGRAM_PATH)

# 内容を比較する2つのファイルのパスを設定します。
myPath = jupiterPath + '/SampleData/PSJ/PSJ-Utility/Utils'
file1 = myPath + '/FileCompare1.txt'
file2 = myPath + '/FileCompare2.txt'

# 2つのファイルの内容を比較します。比較結果をPython APIウィンドウに表示します。
is_same_file = filecmp.cmp(file1,file2)
if is_same_file == 0:
   print('2つのファイルの内容は異なっています')
else:
   print('2つのファイルの内容は同じです')
