# Post Data Option

Post Data Option

Description​

This is an instance of a PostDataOp class, represents Post Data Option information in Jupiter.

Properties​

 | Attribute | Description

 | loc | Location option information.

 | cnv | Conversion option information.

 | cont | Continuous Conversion option information.

 | coord | Coordinate option information.

 | load1D | Load 1D option information.

 | load2D | Load 2D option information.

 | complex | Complex option information.

 | phaseAngle | Phase angle value.

 | userCoordSysId | ID of User-defined Coordinate System. 0 if none of user-defined Coordinate System specified.
