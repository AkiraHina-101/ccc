# 新しいPythonライブラリをインストールします

新しいPythonライブラリをインストールします

🎯 導入​

このチュートリアルでは、デフォルトでインストールされていない新しいPythonライブラリをインストールして、PSJ機能を拡張する方法を学びます。

新しいPythonライブラリを使用してインストールします pip.

新しいライブラリが既にインストールされているかどうかを確認します。

新しいインストールされたライブラリを使用してPSJを実行してみてください。

📖 チュートリアル​

コマンドプロンプトウィンドウから、Jupiterインストールフォルダーに配置して、下を実行します。

python -m pip install -t Lib\site-packages -U <package_name>

注意

木星がインストールされている場合 C:/ ドライブ、管理者としてコマンドプロンプトを実行する必要があります

Pythonライブラリモジュールは、次のようにインストールされます pip 応用

たとえば、インストールする場合 plotly 木星v5.0.2へのライブラリ、開くコマンドプロンプトウィンドウを開き、 C:\Program Files\TechnoStar\Jupiter_5.0.2、次に実行します:

python -m pip install -t Lib\site-packages -U plotly

以下のコマンドを使用して_plotly_がインストールされているかどうかを確認できます Jupiter built-in IDE.

import plotly
print(plotly.__version__)

以下のサンプルを使用して_plotly_でPSJをテストすることもできます。

# 日本語のエンコーディング
# コーディング: cp932

import plotly.graph_objects as go
from plotly.subplots import make_subplots

# リングサイクライドの方程式
# 見る https://en.wikipedia.org/wiki/Dupin_cyclide
import numpy as np
a, b, d = 1.32, 1., 0.8
c = a**2 - b**2
u, v = np.mgrid[0:2*np.pi:100j, 0:2*np.pi:100j]
x = (d * (c - a * np.cos(u) * np.cos(v)) + b**2 * np.cos(u)) / (a - c * np.cos(u) * np.cos(v))
y = b * np.sin(u) * (a - d*np.cos(v)) / (a - c * np.cos(u) * np.cos(v))
z = b * np.sin(v) * (c*np.cos(u) - d) / (a - c * np.cos(u) * np.cos(v))

fig = make_subplots(rows=1, cols=2,
                    specs=[[{'is_3d': True}, {'is_3d': True}]],
                    subplot_titles=['色はzに対応します', '色は原点までの距離に対応します'],
                    )

fig.add_trace(go.Surface(x=x, y=y, z=z, colorbar_x=-0.07), 1, 1)
fig.add_trace(go.Surface(x=x, y=y, z=z, surfacecolor=x**2 + y**2 + z**2), 1, 2)
fig.update_layout(title_text="リングサイクライド")
fig.show()
