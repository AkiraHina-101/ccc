# FileMenu.Save()

FileMenu.Save()

Description​

Save file JTDB

Syntax​

FileMenu.Save(strFileName="")

Ribbon: FileMenu » Save

Inputs​

strFileName​

A String specifying the file name.

The default value is "".

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

FileMenu.Save(strFileName="")
