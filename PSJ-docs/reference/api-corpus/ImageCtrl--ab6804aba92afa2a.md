# ImageCtrl

ImageCtrl

画像コンテナを作成します。

プレビューダイアログ：

パラメータ​

名前​

画像コンテナの名前を入力してください。

有効​

有効にするかどうかを指定します。

True : 利用可能

False : 利用不可（グレーアウト）

サイズ​

幅 : 画像コントロールの最小幅を指定します。（ピクセル単位）

高さ : 画像コントロールの最小高さを指定します。（ピクセル単位）

画像ファイル​

画像ファイルへのリンク。

動作​

画像コントロールの振る舞い状態を指定し、サイズを柔軟にコントロールします。

Greedy : ユーザー入力の幅と高さに基づいて表示画像を設定します。

Fixed : 元の画像サイズに基づいて表示画像を設定します。

Horizontal : 元の画像の高さに基づいて高さを固定し、水平方向のみリサイズを許可します。

Vertical : 元の画像の幅に基づいて幅を固定し、垂直方向のみリサイズを許可します。

表示​

作成したImageCtrlを表示/非表示にするかを指定します。

チェック オン : 表示

チェック オフ : 非表示

関連するAPI​

dlg.add_imagectrl : 作成ダイアログに画像を配置するための枠を追加します。

dlg.set_image_file : ImageCtrlに画像を設定します。
