# MESH_PART_INFO_TOOL

MESH_PART_INFO_TOOL

Description​

A data type uses to control parameters of Mesh Part Info Tool

Attributes​

strName​

A String specifying part name.

The default value is "".

iPartID​

An Integer specifying part i d.

The default value is 0.

strPropName​

A String specifying prop name.

The default value is "".

iPropId​

An Integer specifying prop ID.

The default value is 0.

iPropType​

An Integer specifying prop type.

The default value is 0.

strMatName​

A String specifying material name.

The default value is "".

iMatID​

An Integer specifying material i d.

The default value is 0.

strMatType​

A String specifying material type.

The default value is "".

iPartNode​

An Integer specifying part node.

The default value is 0.

iNpartnodeWithprop​

An Integer specifying npartnode withprop.

The default value is 0.

ilPartElement​

A List of Integer specifying part element.

The default value is [].
