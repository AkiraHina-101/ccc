# フェース指定

フェース指定 フェース指定 指定フェース間にMSC Nastran用接触設定を定義します。 マスター面となるフェース、およびスレーブ面となるフェースを選択し、接触設定を定義します。 基本 名前 接触対の名称を入力します。 アルゴリズム 接触設定対象エンティティを選択します。 &nbsp;&nbsp;&nbsp;&nbsp;フェース-フェース: フェース対フェース間接触 タイプ 接触定義の挙動タイプを選択します。 &nbsp;&nbsp;&nbsp;&nbsp;一般接触: 滑り接触 &nbsp;&nbsp;&nbsp;&nbsp;固着: 固着 マスター マスター面となるフェースを選択します。 スレーブ スレーブ面となるフェースを選択します。 &nbsp;&nbsp;&nbsp;&nbsp;M/S入替: マスターとスレーブを入れ替えます。 コンタクトプロパティ |
