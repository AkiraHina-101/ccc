# SetHiddingElementFactor()

SetHiddingElementFactor()

Description​

Set Optimized Shape value that is threshold for being a hidden element.

Syntax​

SetHiddingElementFactor(float OptimizedShape)

Inputs​

1. float ​

Specify Optimized Shape value to hide element.

Return Code​

Nothing.

Sample Code​

SetHiddingElementFactor(0.5)
