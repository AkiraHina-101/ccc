# ウィンドウのチェックボックスを更新する

ウィンドウのチェックボックスを更新する

🎯 はじめに​

このチュートリアルでは、Assembly Tree と Watch Selected Window のチェックボックスを操作する方法を学びます。

モデルを準備します。

エンティティを選択し、Watch Selected Window でアイテムのオン/オフを切り替えます。

Assembly Tree でアイテムのチェックをオン/オフしてエンティティを表示/非表示にします。

📖 チュートリアル​

# Python API ウィンドウのログメッセージをクリアする
JPT.ClearLog()

# モデルの準備...
JPT.Exec('CreateCube([0, 0, 0], [0.01, 0.01, 0.01], [10, 10, 10], "Cube_1", 7105764, 0:0)')
JPT.Exec('CreateCube([0.02, 0, 0], [0.01, 0.01, 0.01], [10, 10, 10], "Cube_2", 6409934, 0:0)')
JPT.Exec('CreateCube([0, 0.02, 0], [0.01, 0.01, 0.01], [10, 10, 10], "Cube_3", 13259210, 0:0)')
JPT.ViewFitToModel()

# Watch Selected Window でチェックボックスを選択して更新する
Home.Find(strSearch="1 2 3")
listParts = JPT.GetSelectedParts()
listIDParts = [part.id for part in listParts]
JPT.Debugger(listIDParts)
JPT.UpdateCheckboxWatchSelected(JPT.EntityType.BODY, listIDParts, JPT.BoolType.FALSE_VAL) # JPT.BoolType.TRUE_VAL はオンにすることを意味します

# Assembly Tree でアイテムのチェックをオン/オフしてエンティティを表示/非表示にする
JPT.UpdateCheckboxAssembly(JPT.EntityType.BODY, 1, 0) # チェックボックスをオフにする
JPT.UpdateCheckboxAssembly(JPT.EntityType.BODY, 1, 1) # チェックボックスをオンにする
JPT.UpdateCheckboxAssembly(JPT.EntityType.BODY, 2, 0) # チェックボックスをオフにする
