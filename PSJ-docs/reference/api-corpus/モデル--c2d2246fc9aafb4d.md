# モデル

モデル モデル モデル全体に対し、指定空間内に含まれるフェースに対してメッシュサイズを設定します。 全体メッシュ作成前に予め設定し、全体メッシュ作成時に設定したメッシュサイズが適用されます。 メッシュパラメーター 名前 メッシュコントロール名を設定します。 空間メッシング 平均 要素の平均サイズを設定します。 最小 要素の最小サイズを設定します。 最大 要素の最大サイズを設定します。 パーツタイプ 空間形状を指定します。 直方体 直方体の範囲を、原点位置と各軸方向の長さで指定します。 楕円体 楕円体の範囲を、中心位置と長辺点、短辺点の位置で指定します。 全内包のみ対象 空間形状に完全に内包されているフェースにのみ設定を行います。 プレビュー プレビュー 空間形状をプレビュー表示し、設定されるフェースの色をプレビューカラーに塗りつぶします。 リセット プレビューをリセットします。 曲面メッシング 曲面メッシング &nbsp;&nbsp;&nbsp;ONにすると、フィレット部を指定角度で分割する設定を行います。サーフェースメッシングの曲面メッシング設定を上書きします。 最大要素角（度） &nbsp;&nbsp;&nbsp;分割角度を設定します。 最小要素サイズ &nbsp;&nbsp;&nbsp;フィレット部の要素最小サイズを設定します。 ※最小メッシュサイズは、このサイズ以下に設定する必要があります。 -&nbsp操作手順&nbsp- メッシュサイズの各項目を入力します。 パーツタイプから空間形状を選択し、パラメータを入力してプレビューボタンをクリックします。 空間形状と重なったフェースがプレビュー色で表示されます。 全内包のみ対象のチェックを入れてプレビューをクリックすると、空間形状の内部に完全に囲まれたフェースのみがプレビュー色で表示されます。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- -->
