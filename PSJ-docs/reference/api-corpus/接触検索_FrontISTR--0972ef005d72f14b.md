# 接触検索 | FrontISTR

接触検索 | FrontISTR 接触検索 | FrontISTR パーツ間のギャップ距離により接触対候補を自動検出し、接触定義を作成します。 コンタクト 検索トレランス 接触対を検出するパーツ間のギャップ距離を入力します。入力トレランス以下のフェースを検出し接触対候補を表示します。 入力単位系 トレランスの単位系を指定します。 検索範囲 接触対候補フェースの範囲を指定します。 最小にすると、検索トレランスで検索されたフェースのみを接触対候補として表示します。 最大にすると、検索されたフェースと滑らかにつながるフェースまでを接触対候補として表示します。 フェース方向考慮 オンにすると、面の法線ベクトルが反対方向にある場合、接触ペアは作成されません。 マスター基準 検出された接触対候補でマスター側とする接触セグメントの判定基準を指定します。 メッシュサイズ: 要素面面積の平均値が大きいセグメントグループ 面積: 総面積の大きいセグメントグループ コンタクトタイプ FrontISTRの接触タイプを定義し、同じ接触タイプの設定を簡単にコントロールします。 &nbsp;&nbsp;&nbsp;&nbsp;ID: IDを入力します。 &nbsp;&nbsp;&nbsp;&nbsp;相互作用: 必要な方法を選択します。 &nbsp;&nbsp;&nbsp;&nbsp;法線方向収束 (NTOL): 法線方向収束パラメーターを入力します。 &nbsp;&nbsp;&nbsp;&nbsp;接線方向収束 (TTOL): 接線方向収束パラメーターを入力します。 &nbsp;&nbsp;&nbsp;&nbsp;法線方向ペナルティ (NPENALTY): 法線方向ペナルティパラメーターを入力します。 &nbsp;&nbsp;&nbsp;&nbsp;接線方向ペナルティ (TPENALTY): 接線方向ペナルティパラメーターを入力します。 List Contact Type Created: 作成したコンタクトタイプをすべて表示します。また、右クリックで編集や削除などの機能を利用することができます。 &nbsp;&nbsp;&nbsp;&nbsp;編集: コンタクトタイプのパラメータを変更します。 &nbsp;&nbsp;&nbsp;&nbsp;Delete: コンタクトタイプを削除します。 コンタクト検索 入力トレランスに基づいてフェースが検出され、接触対候補がテーブルに表示されます。 パーツを選択せずに実行する際は、パーツ全体で検索を実行することに対する意思確認メッセージが表示されます。 オプション テーブルに表示する接触オプションを選択します。 オプションタイトルバー 各タイトルをクリックすることでそのアイテム名称で接触対候補がソートされます。表示するオプションを変更するにはオプションボタンから指定します。 検索ボックス 部分一致する接触対候補のみ表示します。またXボタンをクリックすることで検索をキャンセルします。 チェックボックス 検出された接触対候補のうち、実際に定義する接触対にチェックします。適用（OK）ボタンで接触対が作成されます。 接触対テーブル テーブルに表示された接触対候補を選択することでモデルウィンドウに接触対箇所がハイライト表示されます。マスター/スレーブ接触セグメントの色はホーム>プリファレンス>画面設定>LBCのマスター色/スレーブ色の設定によります。 接触オプション設定 表示した接触オプションについて、テーブル内で編集します。 接触オプション毎に、チェックボックス、プルダウン選択、数値入力、別ダイアログ表示ボタンなど入力方法が分かれています。接触対作成後も個々に接触オプションは編集可能です。 テーブル用機能ボタン すべてオン: 全ての接触対候補を選択します。 マスター/スレーブ入替え: 接触対のマスター/スレーブセグメントグループを切り替えます。 すべてオフ: 全ての接触対候補の選択を解除します。 編集: テーブルで選択されている接触対候補を手動グループダイアログで開き、編集します。 削除: テーブルで選択されている接触対候補を削除します。 エクスポート: 既存接触対(テーブルのオン/オフにチェックボックスがない接触対)の接触オプション情報をcsvファイルに出力します。 インポート: 接触オプション情報のcsvファイルを読み込み、テーブル内の既存接触対の情報を更新します。
