# Face ID Copy

Face ID Copy a.no-uline {text-decoration:none} Face ID Copy Copy the face ID of similar shape parts in two different documents. Source Source Document &nbsp;&nbsp;&nbsp;Select the document from which you want to copy ID. Source Body &nbsp;&nbsp;&nbsp;Select the part from which you want to copy ID. Source Face &nbsp;&nbsp;&nbsp;Select the face from which you want to copy ID. Target Target Document &nbsp;&nbsp;&nbsp;Select the document to which you want to copy ID. Target Body &nbsp;&nbsp;&nbsp;Select the part to which you want to copy ID. Target Face &nbsp;&nbsp;&nbsp;Select the face to which you want to copy ID. Option Tolerance &nbsp;&nbsp;&nbsp;Enter the tolerance to judge the node position as a match.※Node IDs are copied only for nodes whose node positions are determined to match. Copy Information Start Solid Node ID &nbsp;&nbsp;&nbsp;The start node ID of the uncopied node is displayed. This is the ID obtained by adding 1 to the maximum value of the copied node ID. This ID is displayed for confirmation. Solid Node Count &nbsp;&nbsp;&nbsp;The number of nodes is displayed. This number is displayed for confirmation. End Solid Node ID &nbsp;&nbsp;&nbsp;The maximum value of the end node ID predicted from the start node ID and the number of nodes is displayed. This ID is displayed for confirmation. Start Solid Element ID &nbsp;&nbsp;&nbsp;The start element ID of the solid element not copied is displayed. This is an ID obtained by adding 1 to the maximum value of copied element IDs. This ID is displayed for confirmation. Solid Element Count &nbsp;&nbsp;&nbsp;The number of solid elements is displayed. This number is displayed for confirmation. End Solid Element ID &nbsp;&nbsp;&nbsp;Displays the maximum value of the end element ID predicted from the start element ID and the number of elements. This ID is displayed for confirmation. -&nbsp;Operation Procedure&nbsp;- &nbsp;Import both documents containing source and target parts into Jupiter. &nbsp;Select the copy source document and copy source part from the list. &nbsp;Select the copy target document and copy target part from the list.※Make sure that the copy source and copy target documents are not the same. &nbsp;Enter a tolerance value as required. &nbsp;Press the Apply or OK button to execute the command. -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
