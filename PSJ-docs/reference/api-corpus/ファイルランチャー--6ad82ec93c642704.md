# ファイルランチャー

ファイルランチャー

ファイルランチャーは、PSJ をフローティングウィンドウに割り当てて、簡単に実行することができます。

インターフェース​

 | ボタン | 説明

 | S | Python ファイルを登録します

 | C | 登録済みの Python ファイルをクリアします

 | R | 登録済みの Python ファイルを別の Python ファイルに置き換えます

 | Func | 登録した Python プログラムを実行します

操作方法​

Sボタンをクリックして、Python ファイルを選択します。

ファイルを選択すると、ファンクションボタンの左側にある緑色のマークが赤に変わります。

ファンクションボタンをクリックしてプログラムを実行します。
