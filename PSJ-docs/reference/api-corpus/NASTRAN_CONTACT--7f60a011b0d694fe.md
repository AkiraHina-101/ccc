# NASTRAN_CONTACT

NASTRAN_CONTACT

説明​

Nastran接触のパラメータを制御するために使用されるデータ型です。

属性​

iType​

タイプを指定する Integer です。

デフォルト値は0です。

iAlg​

アルゴリズムを指定する Integer です。

デフォルト値は0です。

r r o r を指定する Double です。

デフォルト値は0.5です。

dFNTOL​

f n t o l を指定する Double です。

デフォルト値はDFLT_DBLです。

dFRIC​

f r i c を指定する Double です。

デフォルト値はDFLT_DBLです。

dCINTERF​

c i n t e r f を指定する Double です。

デフォルト値はDFLT_DBLです。

iISEARCH​

i s e a r c h を指定する Integer です。

デフォルト値はDFLT_INTです。

iICOORD​

i c o o r d を指定する Integer です。

デフォルト値はDFLT_INTです。

dFRLIM​

f r l i m を指定する Double です。

デフォルト値はDFLT_DBLです。

dBIAS​

b i a s を指定する Double です。

デフォルト値はDFLT_DBLです。

iISTYP​

i s t y p を指定する Integer です。

デフォルト値はDFLT_INTです。

iIshellelemfaceSlave​

ishellelemface slave を指定する Integer です。

デフォルト値は0です。

iIshellelemfaceMaster​

デフォルト値は0です。

iIbeambarshellelemedgeSlave​
