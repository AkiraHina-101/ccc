# POST_RESULT_KEY

POST_RESULT_KEY

Description​

A data type uses to identify the selected result.

Attributes​

iAnalysisType​

An Integer specifying the analysis type.

The default value is 0.

iAnalysisID​

A String specifying the analysis ID.

The default value is 0.

iResultSet​

A String specifying the result set.

The default value is 0.

iTimeStep​

A String specifying the time step.

The default value is 0.

iResultType​

A String specifying the category type.

The default value is 0.

strResultName​

A String specifying the result name.

The default value is "".

strResultCompName​

A String specifying the result component name.

The default value is "".

iResultPos​

A String specifying the result position.

The default value is 0.
