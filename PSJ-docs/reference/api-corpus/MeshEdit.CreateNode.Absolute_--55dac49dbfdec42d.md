# MeshEdit.CreateNode.Absolute()

MeshEdit.CreateNode.Absolute()

Description​

Create node by input direct value

Syntax​

MeshEdit.CreateNode.Absolute(veclNodeCoord=[], ilNewNodeID=[])

Ribbon: MeshEdit » CreateNode » Absolute

Inputs​

veclNodeCoord​

A Vector List specifying the node coordinate.

The default value is [].

ilNewNodeID​

A List of Integer specifying the new node ID.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.CreateNode.Absolute(veclNodeCoord=[], ilNewNodeID=[])
