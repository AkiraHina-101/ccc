# MainWindow.RightClick.ShowSettings()

MainWindow.RightClick.ShowSettings()

説明​

設定の環境設定を表示します。

構文​

MainWindow.RightClick.ShowSettings(...)

マクロ: ShowSettings

リボン: MainWindow » RightClick » ShowSettings

入力​

この関数には入力値は不要です。

戻り値​

成功した場合は1の文字列、失敗した場合は0です。

サンプルコード​

MainWindow.RightClick.ShowSettings()
