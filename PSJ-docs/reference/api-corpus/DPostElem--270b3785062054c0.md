# DPostElem

DPostElem

説明​

これは Jupiter の内部でポスト要素を表す DPostElem クラスのインスタンスです。

プロパティ​

 | 属性 | 説明

 | typeID | ポスト要素のタイプID（ID = 193）。
戻り値は DItem Types の Int表記（int）です。

 | id | ポスト要素の外部IDです。
ポスト要素のIDはユニークです。
戻り値はID（int）です。

 | type | 要素のタイプです。
戻り値は ElemType です。

 | connectNode | 要素に属する節点です。
戻り値は DItemVector オブジェクトで、DItem 形式で全ての節点情報を保持しています。
