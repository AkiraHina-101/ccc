# MidPlaneEdit.AddItems.Edge.FaceTwoFace()

MidPlaneEdit.AddItems.Edge.FaceTwoFace()

Description​

Exent face to face

Syntax​

MidPlaneEdit.AddItems.Edge.FaceTwoFace(crRefFace=None, crExtFace=None, iExtendType=0)

Ribbon: MidPlaneEdit » AddItems » Edge » FaceTwoFace

Inputs​

crRefFace​

A Cursor specifying the reference face.

The default value is None.

crExtFace​

A Cursor specifying the extend face.

The default value is None.

iExtendType​

An Integer specifying the extend type.

The default value is 0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MidPlaneEdit.AddItems.Edge.FaceTwoFace(crRefFace=None, crExtFace=None, iExtendType=0)
