# Export Mesh Settings

Export Mesh Settings Template Copy(Window to Window) Copy the local setting to the other window of the model. Local Setting Copy Source Document &nbsp;&nbsp;&nbsp;Specify the window of the model to be the copy source for the local setting. Target Document &nbsp;&nbsp;&nbsp;Specify the window of the model to be copied for the local setting. Input Unit &nbsp;&nbsp;&nbsp;You can specify units of correction value between the model. Coordinate System &nbsp;&nbsp;&nbsp;Specifies correction direction of the coordinate system between the model. Magnitude &nbsp;&nbsp;&nbsp;Enter the correction distance between the model. Tolerance &nbsp;&nbsp;&nbsp;Enter the error tolerance between the model. Axis &nbsp;&nbsp;&nbsp;How to specify and select Inter-model correction direction. Arbitrary &nbsp;:&nbsp;Enter a component of the XYZ to specify the direction. X Axis &nbsp;:&nbsp;Specifies the X direction. Y Axis &nbsp;:&nbsp;Specifies the Y direction. Z Axis &nbsp;:&nbsp;Specifies the Z direction. 2Nodes &nbsp;:&nbsp;Select the 2 nodes to specify the direction. Edge &nbsp;:&nbsp;It specifies the direction to select the edge. X/Y/Z &nbsp;&nbsp;&nbsp;XYZ components of the correction direction vector between the model is displayed. -&nbspOperating Procedure&nbsp- &nbsp;Open the local setting copy source and target model in the software. &nbsp;After start-up, specify the window of the model from which to copy in Source Document. &nbsp;Specifies the window of the model to be copied in Target Document. &nbsp;If the position correction between the models is required, specify the coordinate system of the correction direction in Coordinate System. &nbsp;Enter the correct distance between the model in Magnitude. &nbsp;Enter the allowable value of the error between the model in Tolerance. &nbsp;Specify the Arbitrary in Axis. &nbsp;Specify the direction, enter the component of the XYZ. &nbsp;Click Apply / OK button. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
