# Temperature Loads | Whole Mapping

Temperature Loads | Whole Mapping Temperature Loads | Whole Mapping This command maps temperature results of the Heat Transfer analysis from Nastran, ADVC (format2), ABAQUS, and CSV to the whole model as Temperature Loads. Name Name Set the Temperature Load name. Value Result Type Select the format of the Temperature results file. Mapping Result Selection Locate the Temperature results file. Step(Subcase) in Result Specify the ID of the step (subcase) that contains the temperature results. Input Unit Specify the input unit of temperature result values. Preview Mapping data Preview Show the preview of mapping data on selected part(s) same as original result data. Clear Remove the mapping data in preview. Result Preview Show the preview of mapping results on selected part(s). Clear Remove the mapping results in preview. Mapping Option Method Select the mapping method. Nearest : Use the result of the nearest node. Output Mapped Results Browse Locate a destination to output the mapped file. -&nbspOperating Procedure&nbsp- Select the parts to apply the Temperature Load. Multiple selections are accepted. From Result Type, select the format of the Temperature results file. Locate the Temperature Load file by pressing the Browse button. Select a method used for mapping from Method. Click the Mapping data Preview or Result Preview button to show the mapping data or mapping results in preview as needed. Click Clear button to remove the preview. Change other parameters as needed. Click Apply/OK button. -&nbspOperation Videos&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
