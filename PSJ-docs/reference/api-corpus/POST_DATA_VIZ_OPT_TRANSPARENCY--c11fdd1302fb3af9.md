# POST_DATA_VIZ_OPT_TRANSPARENCY

POST_DATA_VIZ_OPT_TRANSPARENCY

Description​

A data type is used to set up the result settings for displaying the opacity.

Attributes​

iTransparencyOpt​

An Integer specifying the transparency option.

The default value is 0.

dTransparency​

A Double specifying the transparency value.

The default value is 0.0.

dOpaqueRangeMin​

A Double specifying the opaque range min.

The default value is 0.0.

dOpaqueRangeMax​

A Double specifying the opaque range max.

The default value is 0.0.
