# Text Box

Text Box Text Box テキストボックスを追加します。 &nbsp;&nbsp;&nbsp;作成イメージ図： Default &nbsp;&nbsp;&nbsp;デフォルトで入力されているテキストを入力します。 Align &nbsp;&nbsp;&nbsp;テキストの表示位置を指定します。 Left &nbsp;:&nbsp;左揃え Right &nbsp;:&nbsp;右揃え Center &nbsp;:&nbsp;中央揃え ReadOnly チェックオン &nbsp;:&nbsp;テキストの編集不可。(コピーは可能) チェックオフ &nbsp;:&nbsp;テキストの編集可能 Name &nbsp;&nbsp;&nbsp;Text Boxコンポーネント名を入力します。 Width &nbsp;&nbsp;&nbsp;テキストボックスの最小幅を指定します。（単位：ピクセル） Height &nbsp;&nbsp;&nbsp;テキストボックスの最小高さを入力します。（単位：ピクセル） Type &nbsp;&nbsp;&nbsp;テキストボックスに入力可能なデータ型を指定します。 Type &nbsp;&nbsp;&nbsp;テキストボックスに入力可能なデータ型を指定します。 String &nbsp;:&nbsp;文字列型 Double &nbsp;:&nbsp;倍精度浮動小数点型 Integer &nbsp;:&nbsp;整数型 Enable &nbsp;&nbsp;&nbsp;使用の可否を指定します。 チェックオン &nbsp;:&nbsp;使用可能。 チェックオフ &nbsp;:&nbsp;使用不可。（グレーアウトされます） 使用コマンド コマンド 説明 サンプルコード dlg.set_item_text("component name","text") テキストボックスに表示するテキストを設定します Input: dlg.set_item_text("Item", "text") dlg.get_item_text("component name") 入力されたテキスト情報を取得します。 Input: dlg.get_item_text("TextBox")
