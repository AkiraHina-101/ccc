Y-Z On 1 Point Select Y-Z Coordinate plane to split, along with the node on the same plane which is to be the starting point of division. X- Z On 1 Point Select X-Z Coordinate plane to split, along with the node on the same plane which is to be the starting point of division. Shared Face When this box is checked while dividing the parts, a shared surface is created at the division plane. Coordinate System Select the coordinate system for coordinate plane to split.
