# Bolt Type B

Bolt Type B Bolt Type B This is the dialog that opens from the Auto Bolt Connection function to set the FEM conditions for bolt type B. Auto Bolt Connection Help For bolt type B, RBE2/RBE3 element is created in a circular shape on the seating surface, and RBE2/RBE3 element is created on the fastening hole and their center is connected by the Bar/RBE2 element. Bolt tightening force certainly can be added with the Pre Tension Load option. Seat Settings Connection Select a type of rigid body (RBE2/RBE3) to be created for the bolt hole seat and threaded part. Seat Diameter(Node) Specify the diameter range that the rigid body is created at the nodes within. Seat Layer(Face) Specify the number of layers of faces around the bolt hole that the rigid body is created. Shaft Settings Shaft Specify the type of rigid body (RBE2/Bar) to be created for the bolt shaft. Bar Property Specify the Bar property applied for the bolt from existing properties when Shaft is defined as Bar element. If None is specified, the Bar element is set no property. Bottom Settings Center Position Specify the center position of the rigid body of the threaded part. Top &nbsp;:&nbsp;Top of cylinder Middle &nbsp;:&nbsp;Middle of cylinder Bottom &nbsp;:&nbsp;Bottom of cylinder Center Settings Connection Specify the type of rigid body to be created at the shaft center. Only Spring can be specified when RBE3 is used for the seat and RBE2 is used for the shaft. None &nbsp;:&nbsp;No rigid body at the center of the shaft. Spring &nbsp;:&nbsp;Create a Spring at the center of the shaft. PreTension &nbsp;:&nbsp;Create a PreTension at the center of the shaft. Pre Tension Load Set the bolt tightening force. Solver Specify the target solver. All &nbsp;:&nbsp;Specify all solvers. Abaqus &nbsp;:&nbsp;Use the ABAQUS PreTension command. Value Specify the bolt tightening force value. Input Unit Specify the unit system used for inputted values. Bolt Fix Length Specify whether to allow remaining unchanged the bolt tightening amount. -&nbspOperating Procedure&nbsp- Select rigid body types and enter the parameters. Click the OK button. This dialog closes and highlights the button of the corresponding bolt type in the Auto Bolt Connection dialog.
