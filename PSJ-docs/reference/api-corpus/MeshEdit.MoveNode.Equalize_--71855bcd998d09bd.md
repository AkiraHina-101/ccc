# MeshEdit.MoveNode.Equalize()

MeshEdit.MoveNode.Equalize()

Description​

Move node by equalize

Syntax​

MeshEdit.MoveNode.Equalize(crlEdges=[])

Ribbon: MeshEdit » MoveNode » Equalize

Inputs​

crlEdges​

A List of Cursor specifying the edge.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.Equalize(crlEdges=[])
