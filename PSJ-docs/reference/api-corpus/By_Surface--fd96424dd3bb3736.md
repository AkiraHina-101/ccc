# By Surface

By Surface By Surface Select parts to split along the specified surface. ※This function doesn't support cutting the shared face. Selection Plane Partition Only When it is checked, a partition is created inside. In this case, the parts are not split. Make Section Face If you check this box, in the case of dividing the parts, a face is created at the section. Shared Face When this box is checked while dividing the parts, a shared surface is created at the division plane. Separate Face When this box is checked while dividing the parts, if you want to create a face to the division place, it prevents the face to be coupled (merge) in the enclave. -&nbsp;Operation Procedure (When dividing a part and creating a face at the divided part)&nbsp;- &nbsp;Select the coordinate plane to split. &nbsp;Open the selection list window and click the Target button. &nbsp;Select the parts to split. &nbsp;Click the Cut button in the selection list window. &nbsp;Select the face to be divided. &nbsp;Select the Make Section Face check box. &nbsp;Click the Apply / OK button. -&nbsp;Operation Procedure (When creating partitions only without dividing parts)&nbsp;- &nbsp;Open the selection list window and click the Target button. &nbsp;Select the parts to split. &nbsp;Click the Cut button in the selection list window. &nbsp;Select the face to be divided. &nbsp;Select the Partition Only check box. &nbsp;Select the Make Section Face check box. &nbsp;Click the Apply / OK button. -&nbsp操作動画&nbsp-
