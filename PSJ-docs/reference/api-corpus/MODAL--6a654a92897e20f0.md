# MODAL

MODAL

Description​

A data type uses to control parameters of Modal

Attributes​

iModeMethod​

An Integer specifying mode method.

The default value is 0.

iExtractNum​

An Integer specifying extract number.

The default value is 1.

bExpandShape​

A Boolean enable/disable expand shape.

The default value is True.

iExpandNum​

An Integer specifying expand number.

The default value is 0.

bUseApprox​

A Boolean enable/disable use approx.

The default value is False.

bInclPrestressEffect​

A Boolean enable/disable incl prestress effect.

The default value is False.

bModalMemorySave​

A Boolean enable/disable modal memory save.

The default value is False.

bResidualVector​

A Boolean enable/disable residual vector.

The default value is False.

bModalOutputDisplacements​

A Boolean enable/disable modal output displacements.

The default value is False.

bModalOutputStrain​

A Boolean enable/disable modal output strain.

The default value is False.
