# 出力、マクロ、Pythonログを取得します

出力、マクロ、Pythonログを取得します

🎯 導入​

このチュートリアルでは、出力ウィンドウ、マクロウィンドウ、Python APIウィンドウからログを取得する方法を学びます。

マクロウィンドウでログコンテンツを取得します。
次に、マクロログコンテンツを保存するマクロファイル.jplを作成します。

Python APIウィンドウでログコンテンツを取得します。
次に、Python APIログコンテンツを保存するファイル.logを作成します。

出力ウィンドウでログコンテンツを取得します。
次に、ファイル.logを作成して、出力ログコンテンツを保存します。

📖 チュートリアル​

# マクロウィンドウでログコンテンツを取得します
# マクロログコンテンツを保存するマクロファイル.jplを作成する
logMacro = JPT.GetMacroLog()
print(logMacro)
fileMacro = open("D:/Macro.jpl", "w")
for line in logMacro:
    fileMacro.write(line)
fileMacro.close()

# Python APIウィンドウでログコンテンツを取得します
# python apiログコンテンツを保存するファイル.logを作成する
logAPI = JPT.GetPythonAPILog()
print(logAPI)
fileAPI = open("D:/PythonAPI.log", "w")
for line in logAPI:
    fileAPI.write(line)
fileAPI.close()

# 出力ウィンドウでログコンテンツを取得します
# ファイル.logを作成して、出力ログコンテンツを保存します
logOutput = JPT.GetOutputLog()
print(logOutput)
fileOutput = open("D:/Output.log", "w")
for line in logOutput:
    fileOutput.write(line)
fileOutput.close()
