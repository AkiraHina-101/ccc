# MeshEdit.AdjustOrientation()

MeshEdit.AdjustOrientation()

Description​

Adjust Orientation

Syntax​

MeshEdit.AdjustOrientation(crlParts=[], crlFaces=[], crlElems=[])

Ribbon: MeshEdit » AdjustOrientation

Inputs​

crlParts​

A List of Cursor specifying the part.

The default value is [].

crlFaces​

A List of Cursor specifying the face.

The default value is [].

crlElems​

A List of Cursor specifying the element.

The default value is [].

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.AdjustOrientation(crlParts=[], crlFaces=[], crlElems=[])
