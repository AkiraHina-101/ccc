# Group Box

Group Box Group Box グループボックスを作成します。 &nbsp;&nbsp;&nbsp;作成イメージ図： Text &nbsp;&nbsp;&nbsp;グループ名を入力します。 Name &nbsp;&nbsp;&nbsp;Group Boxコンポーネント名を入力します。 Has Check Label No &nbsp;:&nbsp;常にグループ内のコンポーネントを操作可能にします。 Yes(Default==Checked) &nbsp;:&nbsp;グループ内のコンポ―ネントの操作を制御します。（デフォルト：チェックON） Yes(Default==Unchecked) &nbsp;:&nbsp;グループ内のコンポーネントの操作を制御します。（デフォルト：チェックOFF） IsCollapsed &nbsp;&nbsp;&nbsp;グループボックスの折りたたみ表示の設定をおこないます。 No &nbsp;:&nbsp;折りたみ設定しない。 Yes(Default==Collapsed) &nbsp;:&nbsp;折りたたみの操作を制御します。（デフォルト：折りたたむ） Yes(Default==Expanded) &nbsp;:&nbsp;折りたたみの操作を制御します。（デフォルト：折りたたまない） Orientation &nbsp;&nbsp;&nbsp;コンポーネントの並びを指定します。 Horizontal &nbsp;:&nbsp;コンポーネントを横並びにします。 Vertical &nbsp;:&nbsp;コンポーネントを縦並びにします Width &nbsp;&nbsp;&nbsp;グループボックスの最小幅を指定します。（単位：ピクセル） Height &nbsp;&nbsp;&nbsp;グループボックスの最小高さを指定します。（単位：ピクセル） Enable &nbsp;&nbsp;&nbsp;使用の可否を指定します チェックオン &nbsp;:&nbsp;使用可能。 チェックオフ &nbsp;:&nbsp;使用不可。（グレーアウトされます。）
