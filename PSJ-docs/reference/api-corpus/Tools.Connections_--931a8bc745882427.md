# Tools.Connections()

Tools.Connections()

Description​

Renumber connection

Syntax​

Tools.Connections(listConnectRenumberTool)

Ribbon: Tools » Connections

Inputs​

listConnectRenumberTool​

A CONNECT_RENUMBER_TOOL List specifying the connect renumber tool.

This is a required input.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Tools.Connections(listConnectRenumberTool)
