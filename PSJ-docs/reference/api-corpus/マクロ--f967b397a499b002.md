# マクロ

マクロ

はじめに​

マクロは Jupiter ビルドイン機能と同等ですが、GUIはありません。

例：

CreateCube（[0、0、0]、[10、10、10]、[10、10、10]、 "Cube_1"、7105764、0：0） ： デフォルトの入力値で立方体を作成します。

ImprintLineS（[[7.8、0、10]、[2.2、10、10]]、[6:26]、1） ： 面上の２点間にエッジを引きます。

これらのマクロは、マクロ機能が正常に実行された直後に生成されます。

マクロウィンドウを使用して、記録、実行、保存、および再読み込みできます。

マクロウィンドウ上部にはツールバーが配置されており、左から、マクロの読み込み・保存・記録・巻き戻し・再生・次へ・停止・マクロ実行時間間隔を調節の操作となっています。

続きを読む

使用可能なマクロのリストは、スクリプト APIを参照してください。
