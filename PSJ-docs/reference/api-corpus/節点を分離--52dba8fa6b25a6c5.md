# 節点を分離

節点を分離 節点を分離 異なるパーツやフェース間で共有化された節点を分離します。 節点を分離 節点IDをキープ 節点分離後、共有節点時に使用していた節点IDを、どのパーツの節点に使用するか指示します。 なし &nbsp;:&nbsp;指定なし。 選択パーツ順 &nbsp;:&nbsp;選択したパーツ順に、節点IDを割り当てます。※フェースやエッジを選択時にはこのオプションは使用できません。 より高いパーツID &nbsp;:&nbsp;共有節点が所属していたパーツのIDが高い順に、節点IDを割り当てます。 より低いパーツID &nbsp;:&nbsp;共有節点が所属していたパーツのIDが低い順に、節点IDを割り当てます。 共有節点を選択 選択したパーツやフェース間の共有節点を選択します。 リセット 選択された共有節点をリセットします。 -&nbsp操作手順&nbsp- 節点を分離するエンティティを選択します。（パーツ、フェース） 共有節点を選択ボタンをクリックして、分離できる節点を選択します。 必要に応じて、共有を保持する節点を選択から除外します。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
