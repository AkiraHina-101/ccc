# JOB_ABAQUS_DATA

JOB_ABAQUS_DATA

説明​

Abaqusジョブデータのパラメータを制御するために使用されるデータ型です。

属性​

bRBE2toMPC​

Boolean 型の r b e2to m p c を有効化または無効化します。

デフォルト値は False です。

bRenameProcess​

Boolean 型のリネームプロセスを有効化または無効化します。

デフォルト値は False です。

iCodeType​

コードのタイプを指定する Integer です。

デフォルト値は 0 です。

iSurfDefType​

サーフェス定義タイプを指定する Integer です。

デフォルト値は 0 です。

iUnit​

単位を指定する Integer です。

デフォルト値は 0 です。

iWriteType​

書き込みタイプを指定する Integer です。

デフォルト値は 0 です。

strDescription​

説明を指定する String です。

デフォルト値は "" です。

strlUserText​

ユーザーテキストを指定する String のリストです。

デフォルト値は [] です。

bExptNdEleGroups​

Boolean 型の expt nd ele groups を有効化または無効化します。

デフォルト値は False です。

bDeleteFloatingNodes​

Boolean 型のフローティング節点の削除を有効化また無効化します。

デフォルト値は False です。

bExptFaceElemGroups2Surface​

Boolean 型の expt face elem groups2 surface を有効化または無効化します。

デフォルト値は False です。

bLoadCase​

Boolean 型のロードケースを有効化または無効化します。

デフォルト値は False です。

bAutoAssignDummyProperty​

Boolean 型のオートアサインダミープロパティを有効化または無効化します。

デフォルト値は True です。

crDummyMat​

ダミー素材を指定する Cursor です。

デフォルト値は None です。
