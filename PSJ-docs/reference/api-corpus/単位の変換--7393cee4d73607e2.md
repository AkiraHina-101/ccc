# 単位の変換

単位の変換

🎯 はじめに​

本チュートリアルでは、ユーザーGUIとPSJコマンド/マクロ間で単位を変換する方法を紹介します:

JPT.ConvertFromDocUnit() を使用し、入力値をJupiterの現在の単位系からSI[m]単位(Jupiterマクロ単位)に変換する。

JPT.ConvertFromMacroUnit() を使用し、指定した単位からSI[m]単位(Jupiterマクロ単位)に変換する。

JPT.ConvertValueToDocUnit() を使用し、入力値をSI[m]単位(Jupiterマクロ単位)からJupiterの現在の単位系に変換する。

Use JPT.ConvertValueToMacroUnit() を使用し、入力値をSI[m]単位(Jupiterマクロ単位)から指定した単位に変換する。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# 入力値を設定します。
inputValue = 1

# 入力値を現在Jupiterに設定されている単位から、Jupiteマクロによって単位(SI[m]単位)に変換します。
# 現在のJupiterで設定されている単位系を確認するには、Home -> Preferences -> Unit -> Current Unitを参照してください。
frDoc_toMacro  = JPT.ConvertFromDocUnit(inputValue, JPT.UnitType.Unit_Length)
print("現在のJupiterの単位系から: {} -> Jupiterマクロの単位系(SI[m])に変換: {}"
    .format(inputValue, frDoc_toMacro))

# 入力値を指定単位からJupiterマクロ単位(SI[m]単位)に変換します。
frSpeci_toMacro = JPT.ConvertFromMacroUnit(inputValue, JPT.UnitType.Unit_Length, "mm")
print(指定単位'mm'から: {} -> Jupiterマクロの単位系(SI[m])に変換: {}"
    .format(inputValue, frSpeci_toMacro))

# 入力値をJupiterマクロ単位(SI[m]単位)から現在のJupiter単位に変換します。
frMacro_toDoc = JPT.ConvertValueToDocUnit(inputValue, JPT.UnitType.Unit_Length)
print("Jupiterマクロの単位系(SI[m])から: {} -> 現在のJupiter単位系に変換: {}"
    .format(inputValue, frMacro_toDoc))

# 入力値をJupiterマクロ単位(SI[m]単位)から指定単位'mm'に変換します。
frMacro_toSpeci = JPT.ConvertValueToMacroUnit(inputValue, JPT.UnitType.Unit_Length, "mm")
print("Jupiterマクロの単位系(SI[m])から: {} -> 指定単位'mm'に変換: {}"
    .format(inputValue, frMacro_toSpeci))
