# TextBox

TextBox TextBox Add a text box. &nbsp;&nbsp;&nbsp;Creation image： Default &nbsp;&nbsp;&nbsp;Enter the text that is entered by default. Align &nbsp;&nbsp;&nbsp;Specify the display position of the text. Left &nbsp;:&nbsp;Left alignment Right &nbsp;:&nbsp;Right align Center &nbsp;:&nbsp;Align in the center ReadOnly Check On &nbsp;:&nbsp;Text cannot be edited. (Copying is possible.) Check Off &nbsp;:&nbsp;You can edit the text. Name &nbsp;&nbsp;&nbsp;Enter the name of the text box component. Width &nbsp;&nbsp;&nbsp;Specifies the minimum width of the text box. (Units: pixels) Height &nbsp;&nbsp;&nbsp;Enter the minimum height of the text box. (Units: pixels) Type &nbsp;&nbsp;&nbsp;Specify the data type that can be entered into the text box. Type &nbsp;&nbsp;&nbsp;Specify the data type that can be entered into the text box. String &nbsp;:&nbsp; string type Double &nbsp;:&nbsp;double precision floating point number type Integer &nbsp;:&nbsp;integer type Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Command to use Command Description Sample Code dlg.set_item_text("component name","text") Specifies the text of the selected component. Input: dlg.set_item_text("Item", "text") dlg.get_item_text("component name") Gets the text information of the selected component. Input: dlg.get_item_text("TextBox")
