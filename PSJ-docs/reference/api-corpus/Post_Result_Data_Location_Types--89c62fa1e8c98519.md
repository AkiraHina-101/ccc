# Post Result Data Location Types

Post Result Data Location Types

これは、ポスト結果データの場所の種類を表す列挙型です。

 | ID | ポスト結果データの場所の種類 | 説明

 | 0 | JPT.PostResultDataLoc.POST_LOC_UNKNOWN | 未定義の場所。

 | 1 | JPT.PostResultDataLoc.POST_LOC_ON_NODE | 要素点（平均）での結果。

 | 2 | JPT.PostResultDataLoc.POST_LOC_ON_ELEMENT | 要素上の結果。

 | 4 | JPT.PostResultDataLoc.POST_LOC_ON_ELEMENT_NODE | 要素節点（平均ではない）での結果。

 | 8 | JPT.PostResultDataLoc.POST_LOC_ON_INTEGRATION_POINT | 要素積分点での結果。
