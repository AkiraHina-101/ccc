# Geometry.Part.Elems()

Geometry.Part.Elems()

Description​

Create part from element

Syntax​

Geometry.Part.Elems(crlElems, strName)

Ribbon: Geometry » Part » Elems

Inputs​

crlElems​

A List of Cursor specifying the element.

This is a required input.

strName​

A String specifying the part name.

This is a required input.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

Geometry.Part.Elems(crlElems, strName)
