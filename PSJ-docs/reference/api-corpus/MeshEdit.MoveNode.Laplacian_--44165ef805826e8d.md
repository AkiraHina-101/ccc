# MeshEdit.MoveNode.Laplacian()

MeshEdit.MoveNode.Laplacian()

Description​

Syntax​

MeshEdit.MoveNode.Laplacian(crlTargets=[], iType=0, bWithCADFollow=False)

Ribbon: MeshEdit » MoveNode » Laplacian

Inputs​

crlTargets​

A List of Cursor specifying the target.

The default value is [].

iType​

An Integer specifying the type.

The default value is 0.

bWithCADFollow​

A Boolean specifying the with CAD follow.

The default value is False.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.MoveNode.Laplacian(crlTargets=[], iType=0, bWithCADFollow=False)
