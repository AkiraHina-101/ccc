# JPT.DrawArrow()

JPT.DrawArrow()

説明​

メインウィンドウに矢印を描画します。

構文​

JPT.DrawArrow()

入力​

listStartPoint ​

矢印の始点の座標を指定するリスト（例：[x1、y1、z1]）です。

値はSI単位[m]です。

listEndPoint ​

矢印の終点の座標を指定するリスト（例：[x2、y2、z2]）です。

値はSI単位[m]です。

color​

矢印の色を表す16進数形式の Int です。

デフォルトの色はシアン（RGB（0、255、255））です。

width​

矢印の幅をピクセル単位で指定する Float です。デフォルトは1.0です。

bothSides​

描画矢印の方向を指定する Boolean です。

False: プログラムは指定された矢印を1つだけ描画します。

True: プログラムは開始点から終点を指す矢印と逆方向を指す別の矢印の2つを描画します。

デフォルト値は False です。

threeDArrow​

矢印のスタイルを指定する Boolean です。

True: 矢印は3Dスタイルで描画されます。

False: フラットな矢印として描画されます。

デフォルト値は True です。

戻り値​

成功したか失敗したかを指定する Boolean です。

True: 成功した場合。

False: 失敗した場合。

サンプルコード​

#表示用のモデルを準備
Geometry.Part.Cube(dlLength=[10.0, 10.0, 10.0])
JPT.ViewFitToModel()

#デフォルトの幅とスタイルで[0, 0, 0]から[10, 20, 30]にシアン色の矢印を描画します：
JPT.DrawArrow([0, 0, 0], [10, 20, 30])

#幅2.5ピクセルの赤い矢印を[5, 5, 5]から[15, 15, 15]に描画します：
JPT.DrawArrow([5, 5, 5], [15, 15, 15], 255, 2.5)

#両方向に矢印を指す緑色の矢印を描画します：
JPT.DrawArrow([1, 1, 1], [4, 4, 4], 65280, 1.5, True)

#デフォルト幅で[2, 2, 0]から[4, 4, 0]に2Dスタイルの青い矢印を描画します：
JPT.DrawArrow([2, 2, 0], [4, 4, 0], 16711680, 1.0, False, False)
