# DBody

DBody

Description​

This is an instance of a DBody class, represents a Part inside Jupiter.

Properties​

 | Attribute | Description

 | name | Name of the Part.

 | typeID | Type ID of the Part (ID = 3).
The return value is an Int notation of DItem Types (int).

 | id | External ID of the Part.
ID can be duplicated, but not recommended.
ID can be changed using the renumbering function.
The return value is ID (int).

 | faces | The faces belong to the Part.
The return value is a list of faces.

 | edges | The edges belong to the Part.
The return value is a list of edges.

 | nodes | The nodes belong to the Part.
The return value is a list of nodes.

 | elems | The elements belong to the Part.
The return value is a list of elements.

 | vertex | The vertex belong to the Part.
The return value is a list of vertex.

 | connections | The connections attached to the Part.
The return value is a list of connections.

 | contacts | The contacts attached to the Part.
The return value is a list of contacts.

 | materials | The materials assigned to the Part.
The return value is a list of materials.

 | properties | The properties assigned to the Part. 
The return value is a list of properties.

 | loadAndBCs | The loads and boundary conditions attached to the Part.
The return value is a list of loads and boundary conditions.

 | localMeshSettings | The local mesh settings assigned to the Part.
The return value is a list of local mesh settings.

 | area | The total area of all faces belong the Part.
The return value is Area (float).

 | volume | The volume of the Part.
The return value is Volume (float).

 | mass | The mass of the Part.
The return value is Mass (float).

 | gravityCenter | The gravity center of the Part.
The return value is GravityCenter (list of float).

 | momentInertia | The moment of inertia of the Part.
The return value is MomentInertia (list of float).

 | color* 1 | Body face color information.
This value can be adjusted.
The return value is a RGB color.

 | colorMesh* 1 | Mesh of body color information.
This value can be adjusted.
The return value is a RGB color.

 | transparency* 1 | The transparency of the Part.
This value can be adjusted.
The return value is a transparency level (from 0 - 100).
