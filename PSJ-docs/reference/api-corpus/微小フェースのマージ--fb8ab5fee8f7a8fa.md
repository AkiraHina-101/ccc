# 微小フェースのマージ

微小フェースのマージ 微小フェースのマージ このコマンドでは、微小フェースを検索し、隣接フェースへマージします。 A：自動、B：選択、C：マージ、D：置き換え 選択リスト パーツ：「自動」または「選択」で微小フェースを検索するパーツ フェース：「選択」で微小フェースを選択する、もしくはMergeでマージするフェース 節点：「置き換え」で復帰させる境界エッジ上の節点 要素エッジ：「置き換え」で復帰させる境界エッジ上の要素エッジ 参照エッジ：「置き換え」で復帰させるマージされた境界エッジ ステップ 方法 操作を指定します。 自動 微小フェースを検索し、隣接フェースへマージを一気通貫で実行します。 選択 微小フェースの検索と選択のみを実行します。 ※検索対象となる微小フェースの定義：フェース形状を正規化した際の、最小幅と最大長が、指定範囲以下のフェースです。 マージ 選択されているフェースを、指定した面間角度以内の隣接フェースへマージします。 ※マージ対象となる隣接フェースの定義：接線上の面間角度の大きさが指定範囲以下のフェースです。 複数存在する場合は、面積が大きい方にマージします。 ※荷重境界条件や接触条件が設定されているフェースは、マージの対象から除外されます。 置き換え プレビューリストアボタンで破線表示された境界エッジを、節点や要素エッジ選択で指定し、 適用ボタンを押して境界エッジを復活させます。 ローカル設定を参照 ローカル設定が設定されているフェースは、マージの対象から除外されます。 リファレンス作成 マージ前のパーツを、リファレンスパーツとして残します。 選択 最小平均フェース幅 微小フェース検索範囲の最小幅（正規化したフェース形状）を入力します。 最大平均フェース幅 微小フェース検索範囲の最大長（正規化したフェース形状）を入力します。 ※フルシリンダーフェースの場合は高さを測ります。ディスクフェースの場合はディスク幅を測ります。 マージ 面角度 マージ対象となる面間角度の範囲（隣接フェースとの接線上の角度）を入力します。 プレビュー マージ予定のフェース色が変更されます。 リセット プレビューの表示を元に戻します。 リストア プレビューリストア 適用ボタンを押してマージされた境界エッジを破線で表示し、リストア（復帰）できるように準備をします。 ※OKやキャンセルボタンを押してコマンドを終了すると、境界エッジのリストアができなくなります。 節点または要素エッジによって選択された境界エッジ 適用ボタンを押すと選択された境界エッジがリストアされます。 -&nbsp操作手順1 (微小フェースの検索とマージ)&nbsp- 方法で自動を選択します。 最小/最大平均フェース幅を入力して、微小フェースの検索範囲を定義します。 面間角度を入力して、マージ範囲を定義します。 適用/OKをクリックします。 #2で検索された微小フェースが、#3の面間角度内の隣接フェースにマージされます。 -&nbsp操作手順2 (微小フェースの検索)&nbsp- 方法で選択を選択します。 最小/最大平均フェース幅を入力して、微小フェースの検索範囲を定義します。 適用/OKをクリックします。 #2で検索された微小フェースが、選択されます。 -&nbsp操作手順3 (選択フェースのマージ)&nbsp- 方法でマージを選択します。 マージ対象のフェースを選択します（パーツ選択かフェース選択） 面間角度を入力して、マージ範囲を定義します。 適用/OKをクリックします。 #2で検索された微小フェースが、#3の面間角度内の隣接フェースにマージされます。 -&nbsp操作手順4 (マージ後の境界エッジ復帰)&nbsp- 方法で置き換えを選択します。※自動またはマージでの適用ボタン実行後のみ プレビューリストアをクリックして、自動またはマージでマージされた境界エッジを破線で表示します。 復帰させる破線上の節点、または要素エッジを選択します。 適用/OKをクリックします。 #3でプレビューされた境界エッジが復帰します。 -&nbsp特記事項&nbsp- ディスクフェース領域は、完全円の外周、内周を求めて幅を計算して検出しております。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
