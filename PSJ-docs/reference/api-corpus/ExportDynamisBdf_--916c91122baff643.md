# ExportDynamisBdf()

ExportDynamisBdf()

Description​

Export Dynamis bdf file

Syntax​

ExportDynamisBdf(string strPath, TCursor job)

Inputs​

1. String​

bdf file path

2. Cursor​

job cursor

Return Code​

"1": The function can be executed

"0": The function cannot be executed

Sample Code​

ExportDynamisBdf("D:/TS-Solver.bdf", 148:2)
