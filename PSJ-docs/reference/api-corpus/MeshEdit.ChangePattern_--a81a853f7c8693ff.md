# MeshEdit.ChangePattern()

MeshEdit.ChangePattern()

Description​

Element ChangePattern

Syntax​

MeshEdit.ChangePattern(crlFaces=[], iPatternType=0)

Ribbon: MeshEdit » ChangePattern

Inputs​

crlFaces​

A List of Cursor specifying the face.

The default value is [].

iPatternType​

An Integer specifying the pattern type.

The default value is 0.

Return Code​

A String of 1 if success, or 0 if fail.

Sample Code​

MeshEdit.ChangePattern(crlFaces=[], iPatternType=0)
