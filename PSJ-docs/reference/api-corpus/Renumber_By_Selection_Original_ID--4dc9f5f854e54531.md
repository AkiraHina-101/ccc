# Renumber | By Selection | Original ID

Renumber | By Selection | Original ID Renumber | By Selection | Original ID Renumber the IDs of the selected entities in the order of the original IDs. Entity Type Nodes Renumber nodes in the selected entity. １D Elements Renumber 1D elements in the selected entity. 2D Elements Renumber 2D elements in the selected entity. 3D Elements Renumber 3D elements in the selected entity. Edges Renumber edge ID. Faces Renumber face ID. Parts Renumber selected parts. Coordinate Systems Renumber the selected coordinate systems. Start ID Set the renumber start ID. Increment Step Set the renumber increment value. Sort Order Ascending Renumber in ascending order. Descending Renumber in descending order. Preview By clicking the preview button, the IDs before and after the target number of the renumbered entity are displayed. Apply Perform renumbering. Cancel Close the dialog without executing renumbering. -&nbsp;Operation Procedure&nbsp;- &nbsp;Specify the entity that you want to renumber from the choice of entity type. &nbsp;Specify start ID, increment value, and sort order. &nbsp;Select an entity in the main window. &nbsp;Click the preview button to check the IDs before and after the renumber. &nbsp;Press the Apply button to execute the renumbering. -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
