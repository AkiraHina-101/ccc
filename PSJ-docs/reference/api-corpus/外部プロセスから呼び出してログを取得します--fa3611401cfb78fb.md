# 外部プロセスから呼び出してログを取得します

外部プロセスから呼び出してログを取得します

🎯 導入​

このチュートリアルでは、外部プロセスからログメッセージを呼び出して取得する方法を学習します。

Jupiter-Postに電話します。

OpenFoamから電話をかけてログメッセージを取得します。

スクリプトの下に実行する前に、アプリケーション（Jupiter-Post、OpenFoam）をインストールする必要があります。

📖 チュートリアル

import subprocess

＃Python APIウィンドウでログメッセージをクリアします
JPT.ClearLog()

#木星の投稿を開きます
subprocess.call(["C:\Program Files\TechnoStar\Jupiter-Post_4.1.7\PCAD_main.exe"])

#またはCMDによって開きます
#import os
#os.system('""C:\Program Files\TechnoStar\Jupiter-Post_4.1.7\PCAD_main.exe""')

#exeからログメッセージを取得すると、OpenFoamアプリケーションに使用できます。
process = subprocess.Popen(r"blockMesh.exe -case D:\OpenFoamCase -dict system/blockMeshDict_JPT",
                         stdout=subprocess.PIPE,
                         stderr=subprocess.STDOUT)
openfoam_log = ""
for line in iter(process.stdout.readline, b''):
    openfoam_log += str(line.rstrip()) + "\n";

print(openfoam_log)
