# CmdSaveOpenTsdv()

CmdSaveOpenTsdv()

Description​

Save / Load tree of Post Tools Window.

Syntax​

CmdSaveOpenTsdv(string file, int flag)

Inputs​

1. string ​

Save / Load file path.

2. int ​

Save or Load. 0: save, 1: load.

Return Code​

Nothing.

Sample Code​

CmdSaveOpenTsdv("C:/Temp/file.tsdb", 0)
