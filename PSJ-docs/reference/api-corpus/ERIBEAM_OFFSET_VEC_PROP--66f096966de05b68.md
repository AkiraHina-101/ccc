# ERIBEAM_OFFSET_VEC_PROP

ERIBEAM_OFFSET_VEC_PROP

Description​

A data type uses to control parameters of Eribeam Offset Vec Prop

Attributes​

iPropId​

An Integer specifying prop ID.

The default value is 0.

iElemId​

An Integer specifying elem ID.

The default value is 0.

dlOffsetVec​

A Double List specifying offset vec.

The default value is 0.
