# Manual 3D Create Tetra / Create Hexa / Create Penta / Create Pyramid

Manual 3D Create Tetra / Create Hexa / Create Penta / Create Pyramid Manual 3D Create Tetra / Create Hexa / Create Penta / Create Pyramid Create a solid element from the selected elements or nodes. Selection List Element: 2D Element linked with the solid element. Node: Nodes linked with the solid element. Part: The part to which the created solid element belongs (if not selected, the solid element will be created as a new part). Parameter Target Select a solid element type to be created. Tet &nbsp;:&nbsp;Creates a Tetra element (Tetrahedron). Hex &nbsp;:&nbsp;Create a Hexa element (Hexahedron). Penta &nbsp;:&nbsp;Create a Penta element (Triangular Prism). Pyramid &nbsp;:&nbsp;Create a Pyramid element (Square Pyramid). Use OrderNode When the check box is selected, the number of the next selection order is displayed in the main window from the fourth node. Direction Reverse the direction of the solid element to be created. Height Specify the height of the solid element to be created.
