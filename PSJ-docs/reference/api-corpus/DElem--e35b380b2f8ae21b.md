# DElem

DElem

Description​

This is an instance of a DElem class, represents an Element inside Jupiter.

Properties​

 | Attribute | Description

 | typeID | Type ID of the Element (ID = 11).
The return value is an Int notation of DItem Types (int).

 | id | External ID of the Element.
ID can be duplicated, but not recommended.
ID can be changed using the renumbering function.
The return value is ID (int).

 | type | Type of the Element.
The return value is ElemType.

 | kind | Kind of the Element.
The return value is ElemKind.

 | nodes | The nodes belong to the Element.
The return value is a list of nodes.

 | color* 1 | Element color information.
This value can be adjusted.
The return value is a RGB color.

Notice​

Footnotes​

An asterisk symbol * in attribute name means that attribute can be changed/assigned from the current to the new value. ↩
