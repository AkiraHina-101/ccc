# ERIBEAM_ORI_VEC_PROP

ERIBEAM_ORI_VEC_PROP

Description​

A data type uses to control parameters of Eribeam Ori Vec Prop

Attributes​

iPropId​

An Integer specifying prop ID.

The default value is 0.

iElemId​

An Integer specifying elem ID.

The default value is 0.

dlOrientVec​

A List of Double specifying orient vec.

The default value is 0.
