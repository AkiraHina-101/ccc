# DataPaneDeleteAllItems()

DataPaneDeleteAllItems()

説明​

Watch Data ウィンドウの特定のペイン内のすべてのアイテムを削除します。

構文​

DataPaneDeleteAllItems(int pane)

入力​

1. int​

ペイン番号。1: 節点、2: 要素、3: 位置、3: 節点プロットスキャン、4: 要素プロットスキャン、5: 位置プロットスキャン、6: 変形ゲージ、7: ピーク検索、8: 最大/最小、9: 面積最大/最小、10: 疲労強度、11: 比較。

戻り値​

なし。

サンプルコード​

DataPaneDeleteAllItems(1)
