Q1. のパラメーターを持つマクロでフォーマットを使用するにはどうすればよいですか？​

使用 %

targetParts=[3:1]
JPT.Exec('VolMeshing(%s, {1, 1.05, 0, 0.1, 1, 0, 1, 1, 0, 4, 1, 1, 1, 0}, 0, 65280)'%(targetParts))

使用 .format{}

targetParts=[3:1]
params={1, 1.05, 0, 0.1, 1, 0, 1, 1, 0, 4, 1, 1, 1, 0}
JPT.Exec('VolMeshing({0}, {1}, 0, 65280)'.format(targetParts,params)

または

targetParts=[3:1]
JPT.Exec('VolMeshing({0}, {{1, 1.05, 0, 0.1, 1, 0, 1, 1, 0, 4, 1, 1, 1, 0}}, 0, 65280)'.format(targetParts)

Q3. それぞれを分割する複数の返品値を取得するにはどうすればよいですか？​

import re
from itertools import groupby

def remove_dup_char(s, c):
    return ''.join(c if a==c else ''.join(b) for a,b in groupby(s))

result=JPT.Exec('FindHoles([], [], 0, 12.345, 0)')

splitted = re.split(r',\s*(?![^(\[\]]*\])', result)

res = []
for s in splitted:
  s = remove_dup_char(s, '[')
  s = remove_dup_char(s, ']')
  print (s)

Q8. 新しいモジュールをインストールするにはどうすればよいですか？​

フォルダーコピーによるインストール (まで V4.0.x)

JupiterのPythonバージョンを確認してください (で V4.0.2 は 3.6.3).

同じPythonバージョンをマシンにインストールします。

PythonのPIPコマンドを使用してモジュールをマシンにインストールします。
-> モジュールフォルダーが下に作成されます \Lib\site-package Pythonインストールフォルダーのフォルダー。

Jupiter-Preインストールフォルダーの下に作成されたフォルダーをコピーします \Lib\site-packages.

にインストールしますpip (V4.1 または後で)

管理者モードでコマンドプロンプトを開きます

木星インストールフォルダーに移動します

次のコマンドを入力します。

python -m pip install <module>

警告

Jupiterを更新すると、追加のインストールされたライブラリが基本的に残ります。
ただし、JupiterのPythonバージョンが更新されている場合、ライブラリは動作を停止する可能性があります。
その場合、適切なバージョンのライブラリを再インストールしてください。
