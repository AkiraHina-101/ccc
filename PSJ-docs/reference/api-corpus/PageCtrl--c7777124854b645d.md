# PageCtrl

PageCtrl PageCtrl Create a group of page items (wizard). &nbsp;&nbsp;&nbsp;Creation image： &nbsp;&nbsp;&nbsp;&nbsp※PageCtrl is used as a set of PageItem. Name &nbsp;&nbsp;&nbsp;Enter the PageCtrl component. Show Header &nbsp;&nbsp;&nbsp;Specify the display of the Text (header) of the PageItem. Check On &nbsp;:&nbsp;Display the header. Check Off &nbsp;:&nbsp;Does not display the header. Default Page &nbsp;&nbsp;&nbsp;Specify the page to be displayed by default. &nbsp;&nbsp;&nbsp;※ The number to be entered starts at zero. Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out）
