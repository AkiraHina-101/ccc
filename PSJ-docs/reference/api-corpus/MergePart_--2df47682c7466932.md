# MergePart()

MergePart()

説明​

パートのマージ

構文​

MergePart( _Double_ tolerance, _Boolean_ removeShareFace, _Cursor[]_ part)

入力​

1. Double​

許容誤差値を挿入します（m）

2. Bool​

共有面を削除するかどうか（True = 1、No = 0）

3. Cursor[]​

ターゲットパートのカーソル（[3：Part ID]）

戻り値​

"1": 関数が実行可能です

"0": 関数を実行できません

サンプルコード​

MergePart(1e-08, 1, [3:4, 3:1])
