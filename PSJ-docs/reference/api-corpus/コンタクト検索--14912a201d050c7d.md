マスター基準 &nbsp;&nbsp;&nbsp;検索されたフェースペアに関して、どちらを接触条件のマスター側にするか決定する計算方法を選択します。 メッシュサイズ &nbsp;:&nbsp;メッシュのサイズで計算 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;比較対象は、検索されたペア面の中にある要素エッジの平均長さです。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;平均の長さが長い方をマスターとします。 面積 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;:&nbsp;面積で計算（フェース単位） コンタクト検索 &nbsp;&nbsp;&nbsp;ボタンを押すとコンタクトの検索を始めます。 &nbsp;&nbsp;&nbsp;パーツを選択せずに実行する際は、パーツ全体で検索を実行することに対する意思確認メッセージが表示されます。 &nbsp;&nbsp;&nbsp;コンタクト検索結果に対して、左側のテキストボックスにパーツ名または面IDを入力して絞り込み表示を行います。 クリアー &nbsp;&nbsp;&nbsp;絞り込み表示を解除します。 コンタクトデータベース &nbsp;&nbsp;&nbsp;コマンド立ち上げ時に既存の接触条件の一覧表示をします。 &nbsp;&nbsp;&nbsp;また、コンタクト検索ボタンで検索された、接触しているフェースペアの一覧表示をします。 No. &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;:&nbsp;検索された順に通し番号が振られます。
