# マクロから実行して返品値を取得します

マクロから実行して返品値を取得します

🎯 導入​

このチュートリアルでは、マクロを実行してマクロから返品値を取得する方法を学びます。

Eマクロを実行して、キューブの三角形要素のストレッチ品質を確認します JPT.Exec('大きい').

マクロからの返品値を確認します（マクロの戻り値は文字列です）。

パーサーパターンを含む文字列ベクトル（文字列のリスト）を作成します（[パースマクロ結果]を参照してください(./parse-macro-result)詳細については).

文字列のリストとして各データ値を取得するために、マクロからの返品値を解析します。

📖 チュートリアル​

# Python APIウィンドウでログメッセージをクリアします
JPT.ClearLog()

# キューブを作成します
Geometry.Part.Cube(strName="Cube_1", iPartColor=12999622)

# マクロを実行して、三角形の要素のストレッチ品質メトリックを確認します JPT.Exec('大きい')
# マクロから文字列返品値を取得します。変数に割り当てます'resultMacro'
resultMacro = JPT.Exec('MC_Mesh_Quality_Manual_Check_Tri([3:1], 0, 0, 0.1)')

# マクロからの文字列戻り値を確認します
print(resultMacro)

# パーサーパターンを含む文字列ベクトルを作成します。例： "number", "list_cursor"
# チュートリアル「マクロ結果パーサー」を参照して、パーサーパターンの文字列データルールの詳細
ArgPatterns = JPT.StringVector()
ArgPatterns.append("number")
ArgPatterns.append("number")
ArgPatterns.append("number")
ArgPatterns.append("number")
ArgPatterns.append("number")
ArgPatterns.append("number")
ArgPatterns.append("list_cursor")
ArgPatterns.append("list_cursor")

# 文字列のリストとして各データ値を取得するために、マクロからの文字列戻り値を解析する
listArgs = JPT.MacroResultParser(resultMacro, ArgPatterns)
JPT.Debugger(listArgs)

macroResult = listArgs[0]
MinValue = listArgs[1]
MaxValue = listArgs[2]
AvgValue = listArgs[3]
TotalEntities = listArgs[4]
NumberFailedElements = listArgs[5]
ListFailedElems = listArgs[6]
ListFailedElemEdges = listArgs[7]
