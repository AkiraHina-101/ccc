# CheckPattern()

CheckPattern()

説明​

選択したフェース上のメッシュパターンをチェックします。選択したエンティティ間の一致/非一致メッシュパターンは、選択したオプションに基づいて表示されます。

構文​

CheckPattern(cursor[] Parts, bool bShowMismatch, bool bShowMatch, doulbe dTolerance)

入力​

1. cursor[]​

メッシュパターンの一致を確認する対象のパート。

2. bool​

メッシュパターンが一致しない部分を表示するかどうかを指定します。

3. Int​

メッシュパターンが一致する部分を表示するかどうかを指定します。

4. double​

メッシュパターンを検出するためのフェース間の距離を指定します。

戻り値​

2つのカーソルリストを文字列として返します：最初のリストにはメッシュパターンが一致したエンティティが含まれ、2番目のリストにはメッシュパターンが一致しないエンティティが含まれます。

サンプルコード​

CheckPattern([3:1, 3:2], 0, 1, 1e-05)
