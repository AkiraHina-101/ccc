# CmdMarkupSearchElementFromPoint()

CmdMarkupSearchElementFromPoint()

説明​

指定された位置に最も近い要素を検索し、要素にノートを追加します。

構文​

CmdMarkupSearchNodesFromMultiPoints(double x, double y, double z)

入力​

1. double​

検索ポイントのX座標。

2. double​

検索ポイントのY座標。

3. double​

検索ポイントのZ座標。

戻り値​

1. bool​

成功（1）または失敗（0）。

サンプルコード​

CmdMarkupSearchElementFromPoint(0.000000, 0.000000, 0.000000)
>> 1
