# RBAR_CONNECTION

RBAR_CONNECTION

Description​

A data type uses to control parameters of Rbar Connection

Attributes​

strName​

A String specifying name.

The default value is "".

iEType​

An Integer specifying e type.

The default value is 7.

iMethod​

An Integer specifying method.

The default value is 1.

crCoordSys​

A Cursor specifying coord sys.

The default value is None.
