# Smooth Face

Smooth Face Smooth Face Creates a face in the area surrounded by the selected nodes (or edges). It can be created if a preview is displayed. Faces can be either mesh or geometric faces. In the case of mesh faces, the shape is interpolated based on the continuity with the surroundings. Selection list: Share Face = OFF Edge: Select the boundary nodes of the face by edges. Node: Select the boundary nodes of the face. Part: Part to which the created face belongs (single part only) ※If not selected, it will be created as a new part. Selection list: Share Face = ON Edge: Select the boundary nodes of the face by edges. Node: Select the boundary nodes of the face. Part: Part A to which the shared surface belongs (single part only). Part: Part B to which the shared surface belongs (single part only). Face Type Geometry Face Create a geometry face. Mesh Face Create a mesh faces with shape interpolation. Share Face Create a shared surface between two parts. When this option is ON, two Parts are displayed in the Selection List. Select each Part of the shared surface to be created. Interpolation Interpolate free-edge shapes, etc., by making the facet size and mesh size uniform. Free edges may be created, so please refer to the notes. Mesh Face Parameter TRI Create the face from TRI elements. QUAD Create the face from QUAD elements. Gradation Factor Specify the factor (1 Connection continuity Select the continuity level. G0 (Point Continuity) : The face to be created and the adjacent faces share the same boundary edge. The joint will be bent. Recommended for creating flat mesh faces. G1 (Tangent Continuity) : The normal vectors of the face to be created and the adjacent faces are the same at the boundary edges. The joint will be smooth. Recommended for creating curved mesh faces. -&nbspOperating procedure (Create a mesh face)&nbsp- In Geometry Face/Mesh Face, select Mesh Face. Select boundary nodes (by edges) surrounding the face. Select a part to which the face belongs as needed. In TRI/QUAD, select an option. Set the Gradation Factor and Connection continuity while watching the preview. Turn on Interpolation as needed. Click Apply/OK. A mesh face is created for the selected part. If part is not selected, a mesh face is created as a new part. Example: Preview the enclosed plane mesh face (Connection Continuity = G0). Example: Preview the enclosed curved mesh face (Connection Continuity = G1). Example: Preview the bridging mesh face (Interpolation = OFF). Example: Preview the bridging mesh face (Interpolation = ON). -&nbspOperating procedure (Create a geometry face)&nbsp- In Geometry Face/Mesh Face, select Geometry Face. Select boundary nodes (by edges) surrounding the face. Select a part to which the face belongs as needed. Turn on Interpolation as needed. Click Apply/OK. A geometry face is created for the selected part. If part is not selected, a geometry face is created as a new part. Example: Preview the enclosed geometry face. Example: Preview the bridging geometry face. -&nbspOperating procedure (Create a shared face)&nbsp- Turn on Share Face. The Part in Selection List will be duplicated. In Geometry Face/Mesh Face, select an option. Select boundary nodes (by edges) surrounding the face creation range. Select each part that the shared face belongs to. For creating a mesh face, select TRI element type. For creating a mesh face, set the Gradation Factor and Connection continuity while watching the preview. Click Apply/OK. A shared face is created for 2 selected parts. Example: To close a hole in the shared surface of three parts, create a shared surface for each range between two parts. -&nbspNotes&nbsp- 1. If the preview does not show up. As above figure, the preview is not displayed when the top and bottom curved edges are selected. The solution is to create separate faces on an existing region instead of one. It is obtained by dividing the bounding edges into smaller ones, then selected a little at a time or selecting a few nodes at a time. Warning message when selecting parts. Share Face = OFF : If the number of parts belonging to the selected nodes is not one, a warning message will be displayed because the face to be created may be a shared face. If this is not a problem, click OK. Share Face = ON : If the number of parts belonging to the selected nodes is not two, a warning message will be displayed because it may be better to confirm the range of the shared face to be created. If this is not a problem, click OK. Front and back of the face. In some cases, the normal direction of the created face may be different from the surrounding faces. In this case, select the face and Right-click > Flip to correct the normal direction of the face. Free Edge by Interpolation option Interpolation option also changes the mesh size between the selected entities. Therefore, If the distance between the selected nodes is significantly different from the average, free edges may be created. Multiple separated closed area This function cannot create faces for multiple separated closed area at the same time. Apply/OK button will be deactivated. Please execute them one by one or automate them with PSJ.
