# NASTRAN_CASE_CONTROL

NASTRAN_CASE_CONTROL

説明​

Nastranケースコントロールのパラメータを制御するために使用されるデータ型です。

属性​

iECHO​

Bulk Dataのエコーリクエストを指定する Integer です。

0: エコーは出力されません。

1: ソートされたエコーが出力されます。

2: ソートされていないエコーが出力されます。

3: ソートされたエコーとソートされていないエコーが出力されます。

デフォルト値は0です。

strTitle​

印刷出力時にタイトルを指定する string です。

デフォルト値は "" です。
