# AddRib()

AddRib()

説明​

リブを追加します

構文​

AddRib(cursor part, cursor[] face_list, Cursor[] node_list, int width, int depth)

入力​

1. Cursor​

パート

2. Cursor[]​

フェースリスト

3. Cursor[]​

節点リスト

4. Int​

リブの幅

5. Int​

リブの奥行き

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

AddRib(3:10, [6:260, 6:26], [], 10, 0)
