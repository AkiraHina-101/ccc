# キャプチャー

キャプチャー a.no-uline {text-decoration:none} キャプチャー 表示ドキュメントのメインウィンドウの画面をキャプチャーします。 クリップボードにコピー メインウィンドウの画面をクリップボードにコピーします。 画像ファイルに保存 メインウィンドウの画面を画像ファイルとして保存します。 PPT形式で保存 メインウィンドウの画面をPPT形式ファイルに出力して保存します。 範囲選択キャプチャー メインウィンドウの画面内の指定した範囲を画像ファイルとして保存します。 -&nbsp;操作手順（クリップボードにコピー）&nbsp;- &nbsp; クリップボードにコピー ボタンをクリックすると、クリップボードに画面がコピーされます。 &nbsp;Paint等の画像閲覧・編集ソフトを起動し、Ctrl+Vキーで画面をペーストします。 -&nbsp;操作手順（画像ファイルに保存）&nbsp;- &nbsp; 画像ファイルに保存 ボタンをクリックすると、ファイルを保存するためにダイアログが開きます。 &nbsp;ファイル形式を指定し、任意の場所に保存します。 -&nbsp;操作手順（PPT形式で保存）&nbsp;- &nbsp; 画像ファイルに保存 ボタンをクリックすると、PowerPointを開いて画面がコピーされます。 &nbsp;PowerPointにて、ファイル形式や任意のファイル名と場所などを指定して保存します。 -&nbsp;操作手順（範囲選択キャプチャー）&nbsp;- &nbsp; 範囲選択キャプチャー ボタンをクリックし、メインウィンドウ内をマウスでクリック＆ドラッグします。クリック位置からドラッグ終了位置までの矩形範囲がキャプチャー対象として指定されます。 &nbsp;Paint等の画像閲覧・編集ソフトを起動し、Ctrl+Vキーで画面をペーストします。
