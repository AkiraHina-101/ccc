# エッジから

エッジから エッジから 取り付け面と、リブのパスを定義するエッジを指定し、既存のサーフェスメッシュ上にリブ形状を追加します。 リブパラメータ リブ板厚 リブの幅を設定します。 リブ高さ リブ取り付け面からのリブの高さを設定します。 方向 リブ取り付け面からのリブの高さを設定します。 ・鉛直オフセット：リブ取り付け面の面直方向にリブを取りつけます。 ・オフセット ：ベース平面で指定した面に対し面直方向にリブを取りつけます。 ・投影 ：ベース平面で指定した面に対し面直方向にリブを取りつけ、リブ上面を指定位置に揃えます。 座標系 リブ取り付けの際に参照する座標系を指定します。 ベース平面 方向をオフセット、投影を指定した場合にリブの抜き方向を指定します。 ・XY平面 ：XY平面に面直にリブを取り付つけます（抜き方向はZ方向）。 ・YZ平面 ：YZ平面に面直にリブを取り付つけます（抜き方向はX方向）。 ・ZX平面 ：ZX平面に面直にリブを取り付つけます（抜き方向はY方向）。 オフセット リブ作成位置を指定方向にオフセットします。方向は座標系で設定します。 X X方向の移動量 Y Y方向の移動量 Z Z方向の移動量 オプション その他の作成オプション・プレビューの設定を行います。 三角形 リブを三角リブにします。 ・オフ：三角リブを作成せず、通常のリブを作成します。 ・前方：開始点側の高い三角リブを作成します。 ・後方：終了点側の高い三角リブを作成します。 新規作成 リブを新規パーツとして作成します。 マージ リブと取り付けパーツをマージします。 プレビュー プレビューの表示をON/OFFします。 -&nbsp操作手順&nbsp- 取り付け面と、リブのパスになるエッジを指定します。 各パラメータを入力します。 適用/OKボタンをクリックします。 -&nbsp操作動画&nbsp- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
