# ファイルによるリナンバー

ファイルによるリナンバー a.no-uline {text-decoration:none} ファイルによるリナンバー CSVファイルに記載された情報をもとにリナンバーを行います。 リナンバーテーブル 各パーツに含まれる、節点/2D要素/3D要素のカウント数と開始IDを一覧表示します。 CSVファイルインポート &nbsp;&nbsp;&nbsp;テーブルに、CSVファイルの内容をインポートします。 CSVファイルエクスポート &nbsp;&nbsp;&nbsp;・テーブルの内容をCSVファイルにエクスポートします。 &nbsp;&nbsp;&nbsp;・パーツIDソート順でエクスポートされます。 オプション 競合の解決 &nbsp;&nbsp;&nbsp;共有節点・共有面要素のIDの振り方を決めます。 より小さいID(&lt;) 共有節点/面要素のIDは、パーツIDの小さい方に所属します。 より大きいID(&gt;) 共有節点/面要素のIDは、パーツIDの大きい方に所属します。 片方のパーツのみで共有節点をカウント &nbsp;&nbsp;&nbsp;IDのコピー先になるパーツをリストから選択します。 &nbsp;&nbsp;&nbsp;共有IDを、衝突の解消オプションで決められたパーツに所属するのものとしてカウントします。 チェックオンの場合 現状と同じ。 チェックオフの場合 ID数カウントの際に、IDを共有している両方のパーツでIDが重複してカウントされます。 -&nbsp;操作手順&nbsp;- &nbsp;モデルを作成します。 &nbsp;CSVファイルエクスポートボタンをクリックし、現在のモデルのナンバリング情報をCSVファイルに書き出します。 &nbsp;手順2で書き出したCSVファイルを編集し、任意のIDを指定します。 &nbsp;CSVファイルインポートボタンをクリックし、手順3で編集したCSVファイルを読み込みます。 &nbsp;適用ボタンをクリックし、リナンバーを実行します。 &nbsp;&nbsp; -&nbsp;注意事項&nbsp;- &nbsp;CSVファイルは同一モデルにのみ適用可能です。 &nbsp;CSVファイルエクスポート/インポート前後で、パーツ数・節点数・要素数に変更がないことが前提です。 &nbsp;リナンバー対象は、節点及び2D/3D要素のみで、1D要素のリナンバーは対象外です。 -&nbsp;操作動画&nbsp;- &nbsp再生ボタンを押すと操作動画が再生されます。 -->
