# エンティティリストの使用

エンティティリストの使用

🎯 はじめに​

本チュートリアルでは、エンティティリストの使用方法について紹介します:

パーツ名が完全一致する名前を指定し、パーツエンティティリストを取得して、そのパーツリストのサイズを表示する。

パーツ名が部分的に一致する名前を指定し、パーツエンティティリストを取得して、そのパーツリストのサイズを表示する。

新しい空のリストを作成し、既存のパーツリストから新しいリストにパーツを追加する。

パーツリストからパーツを削除/クリアーする。

📖 チュートリアル​

# Python APIウィンドウ内のログメッセージを消去します。
JPT.ClearLog()

# 3つのCubeパーツを作成します。
Geometry.Part.Cube(dlOrigin=[0.0, 0.0, 0.0], dlLength=[0.01, 0.01, 0.01], ilAxialNodes=[10, 10, 10],
    strName="Cube_1", iPartColor=12999622,  crLocalCoordinate=None)
Geometry.Part.Cube(dlOrigin=[0.01, 0.0, 0.0], dlLength=[0.01, 0.01, 0.01], ilAxialNodes=[10, 10, 10],
    strName="Cube_2", iPartColor=5093709,  crLocalCoordinate=None)
Geometry.Part.Cube(dlOrigin=[0.02, 0.0, 0.0], dlLength=[0.01, 0.01, 0.01], ilAxialNodes=[10, 10, 10],
    strName="Cube_3", iPartColor=6118877,  crLocalCoordinate=None)
JPT.ViewFitToModel()

# パーツリストを取得する名前を"Cube_1"とし、パーツ名が完全一致するエンティティリストを返します。
isNameMatch = 1
listPart1 = JPT.GetEntitiesByName(JPT.DTableType.DTABLE_BODY, "Cube_1", isNameMatch)
# パーツエンティティリストのサイズをチェックし、サイズが1であればPython APIウィンドウに表示します。
if len(listPart1) == 1:
    print("'listPart1'内にパーツ名が完全一致するパーツ'{}'というパーツが1つ存在します。".format(listPart1[0].name))

# パーツリストを取得する名前を"Cube"とし、パーツ名が部分一致するエンティティリストを返します。
isNameMatch = 0
listPart2 = JPT.GetEntitiesByName(JPT.DTableType.DTABLE_BODY, "Cube", isNameMatch)
# パーツエンティティリストのサイズをチェックし、サイズが3であればPython APIウィンドウに表示します。
if len(listPart2) == 3:
    print("'listPart2'内にパーツ名が部分一致する'{0}','{1}','{2}'という3つのパーツが存在します。".\
        format(listPart2[0].name,listPart2[1].name,listPart2[2].name))

# listPart2のエンティティがlistPart1のエンティティを含むかどうかを確認します。含む場合、その情報を表示します。
if listPart1[0] in listPart2:
    print("listPart2のエンティティはlistPart1のエンティティを含みます。")

# 新しい空のリスト、listPart3を作成し、listPart1とlistPart2のパーツを追加します。listPart3のサイズを表示します。
listPart3 = []
listPart3.append(listPart1[0])

for part in listPart2:
    listPart3.append(part)
print("listPart3のサイズ(総パーツ数): {} ".format(len(listPart3)))

# listPart3の1つ目のパーツを削除します。listPart3のサイズを表示します。
listPart3.pop(0)
print("listPart3のサイズ(総パーツ数): {} ".format(len(listPart3)))

# listPart3のすべてのパーツを消去します。listPart3のサイズを表示します。
listPart3.clear()
print("listPart3のサイズ(総パーツ数): {} ".format(len(listPart3)))
