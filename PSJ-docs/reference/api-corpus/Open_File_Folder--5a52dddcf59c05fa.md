# Open File/Folder

Open File/Folder Open File/Folder This is a component for linking File and Folder. &nbsp;&nbsp;&nbsp;Creation image： Name &nbsp;&nbsp;&nbsp;Open Enter the File/Folder component name. Enable &nbsp;&nbsp;&nbsp;Specify whether to use it or not. Check On &nbsp;:&nbsp;Available Check Off &nbsp;:&nbsp;Impossible to use（It will be grayed out） Mode &nbsp;&nbsp;&nbsp;Specify the selection mode. File &nbsp;:&nbsp;Only the file type can be selected. Folder &nbsp;:&nbsp;Only the Folder type can be selected. Default &nbsp;&nbsp;&nbsp;The default value (File/Folder) link to display. Filter &nbsp;&nbsp;&nbsp;Enter the File type you can choose. &nbsp;&nbsp;&nbsp;Filter format： &nbsp;&nbsp;&nbsp;&nbsp;Description 1 (Extension 1, Extension 2, …), Description 2 (Extension 1, Extension 2, …), … Allow Multiple Selection &nbsp;&nbsp;&nbsp;Multiple items can be selected. Check On &nbsp;:&nbsp;Multiple selections available Check Off &nbsp;:&nbsp;Can not select multiple
