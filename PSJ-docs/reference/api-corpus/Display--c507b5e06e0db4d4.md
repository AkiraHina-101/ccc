# Display

Display Display Control the display of the main window. Graphics Mode Change the type of shading. Smooth shading Smooth shading displays the model realistic. Element shading Element shading displays the model with element shaded surface. Display Mid-Node Click on the box to make the mid-side nodes visible. Enable Light Click on the box to increase the brightness of the model. Display FPS Click on the box to display the frames per second of the model in the main window bottom left. Synchronize connected floating nodes Show or hide the floating nodes connected to the connection element,when displaying or hiding the connection element. View Rotation Specify the method of rotation in the main window. Automatic switch 2D/3D Drag in ellipse space automatically determines 3D rotation, and drag outside space automatically judges 2D rotation. Show 3D Rotation Region Click on the box to display elliptical space when 2D / 3D automatic switch is on Automatic fit in preset view operation Model fits the entire screen automatically after model movement by preset view. Quick Rotation Click on the box to improve the model rotation speed by hiding the boundary condition/connection element automatically during model rotation. LBC Control the display settings of boundary condition. Display target entities Change the color of the entity set on which the boundary condition is applied OFF Choose OFF to not change the color of entity to which boundary conditions are applied. Always Choose Always to change the color of entity forever. Selected Choose Selected to change the color only for the selected entities. Marker Density Sets the density of the marker. One Per Target Entity Choose One Per Target Entity to display the boundary conditions with single marker for each target entity. Low Choose Low to display the random markers at nodes with Low Density. Middle Choose Middle to display the random markers at nodes with high Density. High Choose High to display the random markers at all nodes with highest Density. Effective area only Choose effective area only to Limit the contact marker only to the actual contact surface area. One Per condition Choose One Per condition to display only single marker for entire target entity. Value Display Display the boundary condition values, i.e., Magnitude of force, displacement, pressure,etc. OFF Choose OFF to not show the magnitude of boundary conditions. On Screen Choose On Screen to show the magnitude of boundary conditions on top left of main window.User can drag and place the magnitude box anywhere in main window. On 3D Choose On 3D to show the magnitude of boundary conditions along with markers. On 3D with unit Choose On 3D with unit to show the magnitude and unit of boundary conditions along with markers. Part Connection To Show or hide the LBC's which are connected to the parts,when user switch on/off the parts. OFF Choose OFF to remove the link between LBC's and parts. ON Choose ON to show/hide the corresponding LBC's when user switch on/off the parts. Opacity Set the transmittance of the surface with respect to the LBC and contact setting. Master color Specify the color of the face on the master side. Slave color Specify the color of the face on the slave side 3D marker Click on the box to make the LBC's in to 3D from 2D LBC Visualize Change the appearance of the LBC. Select option original for display the simple LBC and option visualize for display the LBC with more details. Constraint Change the appearance of the constraint condition. Spring Change the appearance of the spring element. RBE2/RBE3 Change appearance of RBE2/RBE3 connection element. Mass Change the appearance of the mass element. MPC Change appearance of MPC constraint condition. Bush Change the appearance of the bush element. Font Change the font size and text color. LBC Label Specify the font size/text color to be displayed on the boundary constraint label. Show ID Specify the font size/text color to be displayed on the Show ID. Other text Specify the font size/text color to be displayed on other text.
