# Boolean

Boolean Boolean Boolean Dialog Box Conduct a Boolean operation on a selected two bodies. Operation Type Select Select the type of Boolean operation to be performed. Boolean Plus Add the selected two bodies into one body. Boolean Minus Choose two bodies to remove the overlapping portions of the body, leaving only one body that you have selected. Boolean Product Select two bodies to extract the overlapping parts of the body. Two Body Cross Select two bodies to create edge in the face where the body are crossed. Boolean Minus2 Select two bodies to remove the overlapping portions of the body from the first body. The second body will create edge on the face that intersect body. Split for Asm Select the model which has zero-touch parts between the body, to delete the overlapping portions between the bodies. Alignment Tolerance Set the tolerance -&nbspOperating Procedure&nbsp- &nbspSelect the type of Boolean operation to be run from the Select. &nbspSelect the two bodies to be executed from the screen.
