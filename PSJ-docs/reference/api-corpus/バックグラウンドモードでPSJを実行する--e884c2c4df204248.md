# バックグラウンドモードでPSJを実行する

バックグラウンドモードでPSJを実行する

🎯 はじめに​

このチュートリアルでは、バックグラウンドモード（コマンドライン）でPSJスクリプトを実行する方法を学びます：

JupiterをUI付きで開き、PSJを実行する（フォアグラウンドモード）、UTF-8またはSJISエンコーディングで。

JupiterをUIなしで開き、PSJを実行する（バックグラウンドモード）、UTF-8またはSJISエンコーディングで。

ビュー、グラフィック、ログに関連する操作はバックグラウンドモードでは動作しません。

📖 チュートリアル​

コマンドプロンプトウィンドウから、以下のコマンドを使用してすべてのJupiterコマンドラインオプションを表示できます：

"C:\Program Files\TechnoStar\Jupiter_5.0.2\Start_It.bat" -help

結果は以下のように表示されます：

---

Jupiter Command Line
(c) TechnoStar Co. Ltd.

---

--[ Help ]--
Syntax: Start_it.bat [drive:][path][filename(.jpl/.py)] [-help/-?] [-b] [-mcr] [-py] [-t] [-sjis]
[-help] [-?] : Displays Jupiter Command Line Help
[-b] : Runs Jupiter on the background (No GUI)
[-mcr] : Runs Jupiter .JPL macro file
[-py] : Runs Jupiter .PY Python script file
[-t] : Displays the total execution time
[-sjis] : Read macro/python file as sjis

Pythonスクリプトファイル（*.py）をJupiter UIを起動して実行するには（フォアグラウンドモード）、以下のコマンドを使用します：

"C:\Program Files\TechnoStar\Jupiter_5.0.2\Start_It.bat" -py "\path_to_file\file.py"

SJISエンコーディングで実行するには：

"C:\Program Files\TechnoStar\Jupiter_5.0.2\Start_It.bat" -py -sjis "\path_to_file\file.py"

Pythonスクリプトファイル（*.py）をJupiter UIを起動せずに実行するには（バックグラウンドモード）、以下のコマンドを使用します：

"C:\Program Files\TechnoStar\Jupiter_5.0.2\Start_It.bat" -b -py "\path_to_file\file.py"

SJISエンコーディングで実行するには：

"C:\Program Files\TechnoStar\Jupiter_5.0.2\Start_It.bat" -b -py -sjis "\path_to_file\file.py"
