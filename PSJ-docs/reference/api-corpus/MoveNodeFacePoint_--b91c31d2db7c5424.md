# MoveNodeFacePoint()

MoveNodeFacePoint()

説明​

節点をフェースのポイント位置に移動します。

構文​

MoveNodeFacePoint(double x, double y, double z, int[] node_list)

入力​

1. Double​

x: 節点を移動するポイントの1つ目の座標です。

2. Double​

y: 節点を移動するポイントの2つ目の座標です。

3. Double​

z: 節点を移動するポイントの3つ目の座標です。

4. Int[]​

移動する節点のリスト

戻り値​

"1": 関数を実行できます

"0": 関数を実行できません

サンプルコード​

MoveNodeFacePoint(0.00505433,0.01,0.00508144, [191, 215])
