# ID Copy

Source Source Document &nbsp;&nbsp;&nbsp;Select the document from which you want to copy ID. Source Part &nbsp;&nbsp;&nbsp;Select the part from which you want to copy ID. Target Target Document &nbsp;&nbsp;&nbsp;Select the document to which you want to copy ID. Target Part &nbsp;&nbsp;&nbsp;Select the part to which you want to copy ID. Inside Solid Node ID Copy &nbsp;&nbsp;&nbsp;When selected, node IDs will be copied for internal nodes as well as surface nodes.※Node IDs are copied only for nodes whose node positions are determined to match. Copy Information Start Solid Node ID &nbsp;&nbsp;&nbsp;The start node ID of the uncopied node is displayed. This is the ID obtained by adding 1 to the maximum value of the copied node ID. End Solid Node ID &nbsp;&nbsp;&nbsp;The maximum value of the end node ID predicted from the start node ID and the number of nodes is displayed.
