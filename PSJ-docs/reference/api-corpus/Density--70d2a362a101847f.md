# Density

Density

説明​

これはDensityクラスのインスタンスであり、材料の密度特性を表します。

プロパティ​

 | 属性 | 説明

 | density | 密度特性のすべてのデータを指定する Tuple のリスト。

 | temperatureDependency | 温度依存データの使用を指定する Boolean 。

 | dependencies | 温度における依存関係の数を指定する Integer 。

Density Characteristic​

材料プロパティを定義するために KEY NAME または ID を使用できます。
関数で主に使用された材料プロパティのIDは、Int Notation 列で参照できます。
ただし、材料プロパティの意味を明示的に説明するために、ユーザーは ID の代わりに KEY NAME を指定できます。
例: DENSITY は ID = 0 と等しいです。

 | INT Notation | Key Name | 説明

 | 0 | DENSITY | 密度データを指定する Tuple 。

 | 130 | TEMPERATURE | 温度依存データを指定する Tuple 。

 | 143 | EXTRA_FIELDS | 追加フィールドデータを指定する Tuple 。

サンプルコード

sample_Mat = Properties.Material.Add(strMaterialName="Sample_Material", 
                                listMaterialProperty=[Density(density=[
                                    (DENSITY, [7850.000000000001]), 
                                    (TEMPERATURE, [100.0]), 
                                    (EXTRA_FIELDS, [[200.0], [300.0]])], 
                                    temperatureDependency=True, 
                                    dependencies=2)], 
                                iMaterialID=5, 
                                iMaterialColor=10264731)
JPT.Debugger(sample_Mat) #戻り値を確認します
